# DS-2023-02

## 1. 原题

有如下代码段：

```c
int mystery(int m,int n)
{
    int p=1;
    int x=m;
    int y=n;
    while(y!=0){
        if(y%2==0){
            x*=x;
            y/=2;
        }
        else{
            y-=1;
            p*=x;
        }
    }
    return p;
}
```

（1) $m,n$ 是两个整数， $m,n \geq 0$ ,请问函数 `mystery(m,n)` 的功能是什么？

（2）给出在最坏情况下，这段代码的时间复杂度，用 $n$ 的函数表示。

## 2. 答案

**（1）** 求幂：`mystery(m,n)` 返回 $m^{\,n}$（即 $m$ 的 $n$ 次方）。因 $p$ 初值为 $1$，当 $n=0$ 时循环一次也不执行而返回 $1$，符合 $m^{0}=1$；$m=n=0$ 时按同一约定返回 $1$（即 $0^{0}$ 取 $1$，这是该算法的自然行为）。这是**快速幂（二进制取幂 / 迭代式倍增）**算法。

**（2）** 最坏情况下循环体执行次数为 $\lfloor\log_2 n\rfloor+\big(n\ \text{的二进制中}\ 1\ \text{的个数}\big)\le 2\lfloor\log_2 n\rfloor+1$，每次执行 $O(1)$，故

$$T(n)=O(\log_2 n).$$

## 3. 题目分析

- 已知：三个循环变量 $p,x,y$，初值 $p=1$、$x=m$、$y=n$；循环不变地按 $y$ 的奇偶二选一执行——偶数则"底自乘、指数折半"，奇数则"指数减一、把当前底累积进 $p$"；
- 目标：（1）用一句话说明函数功能；（2）给出以 $n$ 表示的最坏时间复杂度；
- 关键约束：
  1. $m,n\ge 0$ 是题面给定的前提，故不必讨论负指数（否则 $y$ 为负时 `y%2==0` 与 `y/=2` 的行为会使循环不终止或结果错误）；
  2. 时间只随 $y$（即 $n$）变化，$m$ 的大小不影响循环次数——所以复杂度"用 $n$ 的函数表示"是可行的；
  3. "最坏情况"指在同等量级（同一 $\lfloor\log_2 n\rfloor$）的 $n$ 中循环次数最多者，即二进制位全为 $1$ 的 $n=2^{k}-1$；
- 命题意图：表面读代码，实质考两件事——**用不变式（循环不变量）解释迭代算法的功能**，以及**识别"每轮把规模减半"的循环结构 ⟹ 对数阶**（与 DS-2023-01 的四重嵌套 $O(N^{4})$ 形成同一章节的对照）。

## 4. 核心考点

核心考点：
DS00.02 算法与算法分析——由循环结构求语句频度与最坏时间复杂度；$y\to y/2$ 型循环 ⟹ $O(\log_2 n)$

辅助考点：

解释：两问的解题动作分别是"证明循环不变量"与"数循环次数"，均属算法分析而非任何具体数据结构的操作，故主标签 DS00.02；列 DS02.07 为辅助，是因为该题在教材语境里对应"递归过程的非递归化"这一应用点（求幂是教材讲递归时使用的例子）。

## 5. 解题思路

1. **先跑小例子找规律**（考场上心算即可）：`mystery(2,3)`：$y=3$ 奇 ⟹ $y=2,p=2$；$y=2$ 偶 ⟹ $x=4,y=1$；$y=1$ 奇 ⟹ $y=0,p=8$；返回 $8=2^{3}$。再试 `mystery(2,4)` 得 $16=2^{4}$ ⟹ 猜想"返回 $m^{n}$"；
2. **用循环不变量证明猜想**：断言 $P:\ p\cdot x^{y}=m^{n}$。初态成立；两种分支各保持 $P$（见第 6 节第二步）；终态 $y=0$ 且 $P$ 仍成立 ⟹ $p=m^{n}$。这一步同时回答了"$y$ 为什么会终止"（$y$ 严格递减且非负）；
3. **数循环次数**：把 $n$ 写成二进制。偶数分支做一次"右移一位"（$\log_2$ 规模减一），奇数分支只把末位的 $1$ 抹成 $0$（不减少位数）。故总次数 $=$ 位数贡献 $\lfloor\log_2 n\rfloor$ 次折半 $+$ 每个 $1$ 位贡献 $1$ 次减一；
4. **取最坏**：$1$ 的个数最多为 $\lfloor\log_2 n\rfloor+1$（$n=2^{k}-1$ 时取到），合计 $\le 2\lfloor\log_2 n\rfloor+1$ ⟹ $O(\log_2 n)$；
5. **自检**：与"朴素连乘 $O(n)$"比较，确认本题代码确实不是连乘（$x$ 在自乘、增长很快），并用小表核对次数公式。

## 6. 详细解答

### （1）功能

**第一步：列出状态转移。** 记循环每一轮开始时的三元组为 $(p,x,y)$，则

- 分支 A（$y$ 为偶数且 $y\ne 0$）：$(p,x,y)\to(p,\;x^{2},\;y/2)$；
- 分支 B（$y$ 为奇数）：$(p,x,y)\to(p\cdot x,\;x,\;y-1)$。

**第二步：循环不变量。** 断言

$$P:\quad p\cdot x^{\,y}=m^{\,n}.$$

- 初态：$p=1,x=m,y=n$ ⟹ $p x^{y}=m^{n}$ ✓；
- 分支 A 保持：$p\,(x^{2})^{\,y/2}=p\,x^{y}$ ✓；
- 分支 B 保持：$(p x)\,x^{\,y-1}=p\,x^{y}$ ✓。

**第三步：终止性与终态。** 两分支都使 $y$ 严格变小（$y\ge 2$ 时 $y/2<y$；$y\ge 1$ 奇数时 $y-1<y$），且 $y$ 非负，故循环必在有限步内结束；退出时 $y=0$，由 $P$ 得 $p\cdot x^{0}=p=m^{n}$。函数返回 $p$，即

$$\texttt{mystery(m,n)}=m^{\,n}.$$

**边界核对（与定义一致）**：$n=0$ ⟹ 返回 $1=m^{0}$（含 $m=0$ 时返回 $1$，即 $0^{0}$ 约定为 $1$）；$m=0,n\ge 1$ ⟹ $x=0$，第一次进入分支 B 或 A 后 $p$ 一旦乘上 $0$ 即为 $0$，最终返回 $0=0^{n}$；$m=1$ ⟹ 恒返回 $1$。

**说明**：这正是**快速幂**的迭代写法——$x$ 依次取 $m^{1},m^{2},m^{4},m^{8},\cdots$，$p$ 按 $n$ 的二进制位选择性累乘。例如 $n=13=(1101)_2$：$p$ 最终乘入 $m^{1}\cdot m^{4}\cdot m^{8}=m^{13}$。

### （2）最坏时间复杂度

设 $k=\lfloor\log_2 n\rfloor$（$n\ge 1$ 时 $n$ 的二进制共 $k+1$ 位）。

- 分支 A 使 $y$ 减半，最多发生 $k$ 次（$y$ 从 $n$ 降到 $0$ 需要右移 $k+1$ 位，但最后一次 $y=1$ 是奇数、走分支 B，故折半次数 $\le k$）；
- 分支 B 使 $y$ 减 $1$，发生次数等于 $n$ 的二进制中 $1$ 的个数，记作 $popcount(n)\le k+1$；
- 于是循环体总执行次数

$$C(n)=\lfloor\log_2 n\rfloor+popcount(n)\le 2\lfloor\log_2 n\rfloor+1 .$$

**最坏情况**取 $n=2^{k+1}-1$（二进制全 $1$）：$C= (k)+(k+1)=2k+1=2\lfloor\log_2 n\rfloor+1$。

每次循环只做一次取模、一次乘法/除法，均为 $O(1)$（按随机访问机的单位代价计），故

$$\boxed{T(n)=O(\log_2 n)}\quad(\text{最坏情况；最好情况 }n=2^{k}\text{ 时只需 }k+1\text{ 次循环，同为 }O(\log_2 n)\text{，两者同阶}).$$

**验算（次数公式对拍）**：

| $n$ | $(n)_2$ | $\lfloor\log_2 n\rfloor$ | $popcount(n)$ | 公式 $C(n)$ | 逐步模拟的循环次数 |
|---|---|---|---|---|---|
| $1$ | $1$ | $0$ | $1$ | $1$ | $1$ |
| $3$ | $11$ | $1$ | $2$ | $3$ | $3$ |
| $4$ | $100$ | $2$ | $1$ | $3$ | $3$ |
| $7$ | $111$ | $2$ | $3$ | $5$ | $5$ |
| $12$ | $1100$ | $3$ | $2$ | $5$ | $5$ |
| $13$ | $1101$ | $3$ | $3$ | $6$ | $6$ |
| $15$ | $1111$ | $3$ | $4$ | $7$ | $7$ |
| $31$ | $11111$ | $4$ | $5$ | $9$ | $9$ |

（后台另以程序对 $m\in[0,4]\times n\in[0,6]$ 全部 $35$ 组取值核对 `mystery(m,n)` 与 $m^{\,n}$ 完全相等，并统计 $n=1\sim 32$ 的循环次数与上表一致；正文全部步骤可手工复现。）

## 8. 考场标准答案

**（1）** 功能：计算 $m$ 的 $n$ 次幂 $m^{\,n}$（$m,n\ge 0$；$n=0$ 时返回 $1$）。

依据：循环不变量 $p\cdot x^{y}=m^{n}$。$y$ 为偶数时令 $x\leftarrow x^{2},\,y\leftarrow y/2$，$y$ 为奇数时令 $y\leftarrow y-1,\,p\leftarrow p\cdot x$，两操作均不改变 $p\,x^{y}$；$y$ 严格递减，退出时 $y=0$，故 $p=m^{n}$。该过程即**快速幂（二进制取幂）**。

**（2）** 时间复杂度：$T(n)=O(\log_2 n)$。

依据：每两次循环至多使 $y$ 右移一位，折半至多 $\lfloor\log_2 n\rfloor$ 次，减 $1$ 至多 $\lfloor\log_2 n\rfloor+1$ 次（$n$ 的二进制中 $1$ 的个数），循环体共执行不超过 $2\lfloor\log_2 n\rfloor+1$ 次，每次 $O(1)$。最坏情况为 $n=2^{k}-1$ 型，此时约 $2k-1$ 次，仍为 $O(\log_2 n)$。

## 9. 易错点

1. **把功能答成"$m\times n$"或"$n$ 个 $m$ 相乘的朴素循环"**：$x*=x$ 是底数自乘（倍增），不是计数循环；判断方法是代一组值（如 $m=2,n=3$ 得 $8$）；
2. **漏掉 $n=0$ 的约定**：$p$ 初值为 $1$，$n=0$ 直接返回 $1$，故 $0^{0}$ 也返回 $1$，答题时写明更严谨；
3. **复杂度答成 $O(n)$**：那是朴素连乘；本代码 $y$ 每两轮至少减半，必须按"折半型循环"取对数阶。反例自检：若 $T(n)=O(n)$，则 $n=1024$ 需上千次循环，而实际只需 $11$ 次；
4. **忽略"最坏"二字的具体含义**：最坏由 $n$ 的二进制位全为 $1$ 取到（$2\lfloor\log_2 n\rfloor+1$），最好（$n=2^{k}$）只需 $k+1$ 次，两者同阶，所以答案仍写 $O(\log_2 n)$；
5. **单位代价假设**：若考虑 $m^{n}$ 的位数爆炸与大整数乘法代价，则不再是 $O(\log_2 n)$；考研口径按 `int` 运算 $O(1)$ 计。

## 10. 一句话规律

判断"功能 + 复杂度"的通用套路：**先找循环不变量（哪些量的组合在每轮前后不变），再看控制变量每轮如何变化**——减常数 ⟹ 线性阶，除以常数 ⟹ 对数阶，乘常数 ⟹ 指数/多项式阶。
