# DS-2023-15

## 1. 原题

设一个有向图 $G=(V,E)$，其中：

$V=$ `{` $v_1,v_2,v_3,v_4,v_5$ `}`，

$E=$ `{` $<v_1,v_5>,<v_1,v_2>,<v_1,v_3>,<v_2,v_3>,<v_3,v_4>,<v_5,v_4>$ `}`，

给出其所有的拓扑序列。

## 2. 答案

共有 $3$ 条拓扑序列：

$$v_1\,v_2\,v_3\,v_5\,v_4,\qquad v_1\,v_2\,v_5\,v_3\,v_4,\qquad v_1\,v_5\,v_2\,v_3\,v_4$$

## 3. 题目分析

- 已知：$5$ 个顶点的有向图，$6$ 条弧：$v_1\to v_5$、$v_1\to v_2$、$v_1\to v_3$、$v_2\to v_3$、$v_3\to v_4$、$v_5\to v_4$；
- 目标：枚举**全部**拓扑序列（不是只求一条）；
- 关键约束：
  1. 拓扑序列要求每条弧 $\langle u,v\rangle$ 中 $u$ 排在 $v$ 之前，即求该有向图所确定的偏序集的**所有线性扩张**；
  2. 各顶点入度：$\mathrm{ID}(v_1)=0$，$\mathrm{ID}(v_2)=1$，$\mathrm{ID}(v_3)=2$，$\mathrm{ID}(v_4)=2$，$\mathrm{ID}(v_5)=1$——恰有一个入度为 $0$ 的顶点，故图无环且所有拓扑序列都以 $v_1$ 开头；
  3. "所有"意味着必须给出**不重不漏**的枚举依据，不能凭感觉列举；
- 命题意图：考查拓扑排序的执行过程（每步可选的零入度顶点集）以及由此产生的分支计数，检验是否理解"拓扑序列不唯一 ⟺ 某步同时存在多个可选顶点"。

## 4. 核心考点

核心考点：
DS04.04.03 拓扑排序（拓扑序列定义、删源点过程、拓扑序列不唯一的成因）

辅助考点：
DS04.01 图的基本概念（有向图的弧、入度/出度、$\sum \mathrm{ID}=\vert E\vert$ 的自检）
DS04.02.02 邻接表法（用邻接表登记各顶点的出边，便于逐条删弧）

解释：作答的第一步是把 $6$ 条弧整理成"每个顶点的出边表"（即邻接表口径），执行的是"选零入度点—删其出边"的拓扑排序过程；而"列出全部序列"则要求在每个分支点穷举，属 DS04.04.03 的完整口径。

## 5. 解题思路

1. **先立约束**：把每条弧翻译为"先后关系"，得 $v_1<v_2$、$v_1<v_3$、$v_1<v_5$、$v_2<v_3$、$v_3<v_4$、$v_5<v_4$；
2. **找起点**：只有 $v_1$ 入度为 $0$ ⟹ 所有拓扑序列首位必为 $v_1$；
3. **找终点**：$v_4$ 的入度为 $2$ 且没有任何出边（出度 $0$），其余点都排在 $v_4$ 之前 ⟹ $v_4$ 必为末位；
4. **中间三点穷举**：去掉首尾后只剩 $\{v_2,v_3,v_5\}$ 的排列，唯一残留约束是 $v_2<v_3$（$v_5$ 与 $v_2,v_3$ 之间无约束），故 $3!/2=3$ 种；
5. **用拓扑排序过程复核**：模拟"删源点"，每一步列出当前可选的零入度顶点集合，分支数恰为 $3$，与第 4 步一致；
6. 逐条回代检验：把 $3$ 个候选序列对 $6$ 条弧全部核对一遍（每条弧的起点均在终点之前），确认无遗漏、无多余。

## 6. 详细解答

### 第一步：建表（邻接表口径 + 入度）

| 顶点 | 出边（邻接表） | 入度 |
|---|---|---|
| $v_1$ | $v_5,\,v_2,\,v_3$ | $0$ |
| $v_2$ | $v_3$ | $1$ |
| $v_3$ | $v_4$ | $2$ |
| $v_4$ | （无） | $2$ |
| $v_5$ | $v_4$ | $1$ |

自检：$\sum \mathrm{ID}=0+1+2+2+1=6=\vert E\vert$ ✓

### 第二步：模拟拓扑排序（"零入度顶点栈"过程）

**第 1 步**：入度为 $0$ 的顶点集合 $=\{v_1\}$ → 只能选 $v_1$。
输出 $v_1$，删去 $v_1$ 的三条出边，入度变为 $\mathrm{ID}(v_2)=0$、$\mathrm{ID}(v_3)=1$、$\mathrm{ID}(v_5)=0$。

**第 2 步**：零入度集合 $=\{v_2,v_5\}$ → **出现分支**。

- **分支 A：选 $v_2$**。删 $v_2\to v_3$，$\mathrm{ID}(v_3)=0$。此时零入度集合 $=\{v_3,v_5\}$ → 又分两支：
  - A1：选 $v_3$ → 删 $v_3\to v_4$，$\mathrm{ID}(v_4)=1$；只能选 $v_5$ → 删 $v_5\to v_4$，$\mathrm{ID}(v_4)=0$；选 $v_4$。
    得 $v_1\,v_2\,v_3\,v_5\,v_4$
  - A2：选 $v_5$ → 删 $v_5\to v_4$，$\mathrm{ID}(v_4)=1$；只能选 $v_3$ → $\mathrm{ID}(v_4)=0$；选 $v_4$。
    得 $v_1\,v_2\,v_5\,v_3\,v_4$
- **分支 B：选 $v_5$**。删 $v_5\to v_4$，$\mathrm{ID}(v_4)=1$。零入度集合 $=\{v_2\}$ → 选 $v_2$，$\mathrm{ID}(v_3)=0$ → 选 $v_3$，$\mathrm{ID}(v_4)=0$ → 选 $v_4$。
  得 $v_1\,v_5\,v_2\,v_3\,v_4$

三条分支均输出 $5$ 个顶点（无剩余顶点），说明图中无环，且分支树已穷尽。

### 第三步：换一条独立路径复核（偏序集线性扩张计数）

弧集给出的直接约束：$v_1<v_2,\ v_1<v_3,\ v_1<v_5,\ v_2<v_3,\ v_3<v_4,\ v_5<v_4$。

- $v_1$ 是唯一极小元（其它点都有前驱）⟹ 首位固定为 $v_1$；
- $v_4$ 是唯一极大元（$v_4$ 无出边，且 $v_2<v_3<v_4$、$v_5<v_4$ 覆盖其余所有点）⟹ 末位固定为 $v_4$；
- 中间三个位置由 $\{v_2,v_3,v_5\}$ 填充，残留约束只有 $v_2<v_3$，故排列数 $=\dfrac{3!}{2}=3$，恰为

$$(v_2,v_3,v_5),\quad (v_2,v_5,v_3),\quad (v_5,v_2,v_3)$$

与第二步得到的三条序列一一对应 ✓（两条完全独立的路径结果相同）。

### 第四步：逐条回代检验

| 序列 | $v_1\!\to\!v_5$ | $v_1\!\to\!v_2$ | $v_1\!\to\!v_3$ | $v_2\!\to\!v_3$ | $v_3\!\to\!v_4$ | $v_5\!\to\!v_4$ |
|---|---|---|---|---|---|---|
| $v_1v_2v_3v_5v_4$ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| $v_1v_2v_5v_3v_4$ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| $v_1v_5v_2v_3v_4$ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

再举两个"看似可以"却被排除的排列，验证约束确实在起作用：
$v_1v_3v_2v_5v_4$ 违反 $v_2<v_3$；$v_1v_2v_5v_4v_3$ 违反 $v_3<v_4$。✓ 排除正确。

### 结论

拓扑序列共 $3$ 条：$v_1v_2v_3v_5v_4$、$v_1v_2v_5v_3v_4$、$v_1v_5v_2v_3v_4$。

## 7. 选项分析

不适用（综合应用题——列举/构造题）。

## 8. 考场标准答案

各顶点入度：$\mathrm{ID}(v_1)=0,\mathrm{ID}(v_2)=1,\mathrm{ID}(v_3)=2,\mathrm{ID}(v_4)=2,\mathrm{ID}(v_5)=1$。

拓扑约束：$v_1$ 先于 $v_2,v_3,v_5$；$v_2$ 先于 $v_3$；$v_3,v_5$ 先于 $v_4$。
故 $v_1$ 必为首位、$v_4$ 必为末位，中间 $\{v_2,v_3,v_5\}$ 只需满足 $v_2$ 在 $v_3$ 前，共 $3!/2=3$ 种。

全部拓扑序列（$3$ 条）：

$$v_1v_2v_3v_5v_4,\qquad v_1v_2v_5v_3v_4,\qquad v_1v_5v_2v_3v_4$$

## 9. 易错点

1. **漏掉 $v_1\to v_3$ 这条"跨越弧"**：即使漏掉它，$v_1$ 仍必先于 $v_3$（经 $v_2$ 传递），所以本题侥幸不影响结果；但判定时必须以"传递闭包"为准，不能只看有没有直接弧；
2. **误以为 $v_5$ 可以排在 $v_1$ 之前或与 $v_4$ 自由交换**：$v_5$ 受 $v_1<v_5<v_4$ 两端约束，只在 $\{v_2,v_3\}$ 之间可自由插位（$3$ 个可插位置中受 $v_2<v_3$ 限制后恰得 $3$ 条）；
3. **只写一条就收笔**：题面要求"所有的拓扑序列"，漏答即失分；判别"还有没有别的"的可靠方法是看每一步零入度顶点集合的大小是否大于 $1$（本题第 2 步 $\{v_2,v_5\}$、分支 A 的第 3 步 $\{v_3,v_5\}$ 各产生一次分叉，$2+1=3$ 条）；
4. **把拓扑序列与 DFS/BFS 序列混为一谈**：拓扑序列只受偏序约束，不要求"连通相邻"，例如 $v_1v_2v_5v_3v_4$ 中 $v_5$ 与 $v_2$ 之间并无弧。

## 10. 一句话规律

"求所有拓扑序列"题的定式：**先标入度定首元素，再找唯一极大元定末元素，中间只对无约束的点对做排列计数**，最后用"删源点过程"的分支树复核条数。
