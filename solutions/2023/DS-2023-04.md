# DS-2023-04

## 1. 原题

下列代码交换双向链表中两个相邻的元素。请填写完整代码。

双向链表存储结构：

```c
struct DLinkNode {
    ElementType data;
    struct DLinkNode *prior;  // Front pointer
    struct DLinkNode *next;   // Rear pointer
};

typedef struct DLinkNode *PtrToNode;
typedef PtrToNode DLinkList;
typedef PtrToNode Position;

/* P and AfterP are cells to be switched. */
void SwapWithNext(Position P, DLinkList L) {
    Position BeforeP,AfterP;

    BeforeP=P->prior;
    AfterP=P->next;

    P->next=AfterP->next;

    ___________(1)__________;
    AfterP->next=P;
    ___________(2)__________;
    ___________(3)__________;
    AfterP->prior=BeforeP;
}
```

## 2. 答案

交换的是结点 $P$ 与其后继 $A\!fterP$，交换后的链接关系为

$$BeforeP\ \leftrightarrows\ AfterP\ \leftrightarrows\ P\ \leftrightarrows\ (AfterP\text{ 的原后继 }AA).$$

三空填：

| 空位 | 填写内容 | 建立的链接关系 |
|---|---|---|
| (1) | `if(AfterP->next != NULL) AfterP->next->prior = P;` | $AA\to prior=P$（$AA$ 存在时） |
| (2) | `P->prior = AfterP;` | $P\to prior=AfterP$ |
| (3) | `if(BeforeP != NULL) BeforeP->next = AfterP;` | $BeforeP\to next=AfterP$ |

（(2)、(3) 两条语句互换位置仍然正确；(1) 必须位于 `AfterP->next=P;` **之前**，或改用尚未被改写的 `P->next` 来表达同一关系，见第 6 节第四步。）

## 3. 题目分析

- 已知：双向链表结点含 `prior`、`next` 两个指针域；`BeforeP`、`AfterP` 已分别取好 $P\to prior$、$P\to next$；已给出的第一条语句 `P->next = AfterP->next;` 把 $P$ 的后继改成了 $AA$（$A\!fterP$ 的原后继）；已给出的最后两条是 `AfterP->next=P;` 与 `AfterP->prior=BeforeP;`；
- 目标：补三条语句，使 $P$ 与 $AfterP$ 在链表中位置互换，且**双向链表的每一条边都改对**；
- 关键约束：
  1. 交换两个相邻结点共涉及 **6 条边**：$BeforeP\to next$、$AfterP\to prior$、$AfterP\to next$、$P\to prior$、$P\to next$、$AA\to prior$；题面已给出其中 3 条（$P\to next$、$AfterP\to next$、$AfterP\to prior$），余下 3 条正是三个空；
  2. **读写冲突顺序**：`P->next` 在第三条语句处已被改写为 $AA$，而 `AfterP->next` 要到 `AfterP->next=P;` 才改变；因此凡是要用"$AA$ 这个结点"的语句，必须写在 `AfterP->next=P;` 之前（此时 `AfterP->next` 仍是 $AA$），否则就得改用 `P->next`；
  3. **边界**：$AA$ 可能为空（$P$ 是倒数第二个结点），必须先判空再写 `AA->prior`；$BeforeP$ 是否可能为空取决于是否带头结点——若按本函数签名带 `L`（教材/题面惯例为头结点），则 $BeforeP$ 至少是头结点、不必判空；若不带头结点且 $P$ 是首元结点，则 $BeforeP$ 为 NULL，必须判空（且此时还需外部更新表头指针，本题函数无法完成，故题面默认带头结点）；
- 命题意图：考双向链表插入/删除的**指针修改顺序与判空意识**（DS01.02.03）。本题不是"背代码"，而是给定了语句骨架，要求按"目标形态 + 已有语句改写了哪些指针"反推缺的三条。

## 4. 核心考点

核心考点：
DS01.02.03 链式存储：双向链表与循环链表——双向结点 `prior/next` 双域维护、相邻结点交换（等价于"摘除再反插"）时 6 条边的完整修改与空指针判别

辅助考点：
DS01.02.02 链式存储：单链表——`next` 链的断开与重接是本题的一半，本题的易错处恰在"另一半 `prior` 链也要同步"

## 5. 解题思路

1. **画出交换前的形态**：$BeforeP \leftrightarrows P \leftrightarrows AfterP \leftrightarrows AA$；
2. **画出目标形态**：$BeforeP \leftrightarrows AfterP \leftrightarrows P \leftrightarrows AA$；
3. **列差集**：把两形态下每条边逐一比较，列出需要执行的赋值——$P\to next=AA$、$AA\to prior=P$、$AfterP\to next=P$、$P\to prior=AfterP$、$BeforeP\to next=AfterP$、$AfterP\to prior=BeforeP$，共 6 条；
4. **对照骨架**：6 条中已有 3 条（$P\to next$、$AfterP\to next$、$AfterP\to prior$），剩下的 3 条即三个空；
5. **定顺序**：$AA\to prior=P$ 这条语句里的 $AA$ 只能用 `AfterP->next`（在 `AfterP->next=P;` 之前）或 `P->next`（此后仍为 $AA$）来表达——骨架把它排在 `AfterP->next=P;` 之前，故空 (1) 用 `AfterP->next`，并且必须判空；
6. **验证**：用 $1\sim 7$ 的双向链表分别令 $P$ 为首元结点、中间结点、倒数第二个结点，沿 `next` 正向与沿 `prior` 反向各走一遍，检查两条链互为逆序且结点数不变。

## 6. 详细解答

### 第一步：交换前后的形态

交换前（$P$ 与 $AfterP$ 相邻，$AA$ 表示 $AfterP\to next$，可能为 NULL）：

```
BeforeP  <->  P  <->  AfterP  <->  AA
```

交换后的目标：

```
BeforeP  <->  AfterP  <->  P  <->  AA
```

### 第二步：列出目标形态要求的全部 6 条边

| 编号 | 目标边 | 对应赋值语句 | 骨架中是否已给 |
|---|---|---|---|
| ① | $P\to next=AA$ | `P->next = AfterP->next;` | 已给（第三句） |
| ② | $AA\to prior=P$ | `AfterP->next->prior = P;`（须在 `AfterP->next` 被改写前使用，并判空） | **缺 → 空 (1)** |
| ③ | $AfterP\to next=P$ | `AfterP->next = P;` | 已给 |
| ④ | $P\to prior=AfterP$ | `P->prior = AfterP;` | **缺 → 空 (2)** |
| ⑤ | $BeforeP\to next=AfterP$ | `BeforeP->next = AfterP;` | **缺 → 空 (3)** |
| ⑥ | $AfterP\to prior=BeforeP$ | `AfterP->prior = BeforeP;` | 已给（最后一句） |

### 第三步：填法与顺序理由

- **空 (1)** 处：`P->next` 已改为 $AA$，`AfterP->next` 尚未改动（仍是 $AA$）。此处写
  `if(AfterP->next != NULL) AfterP->next->prior = P;`
  即 ②。它**必须**排在 `AfterP->next=P;` 之前：一旦 $AfterP\to next$ 被改成 $P$，`AfterP->next->prior=P` 就变成 `P->prior=P`（自指环），链表被破坏。
- **空 (2)** 处写 ④ `P->prior = AfterP;`：此时 $P$ 的两个指针域分别已指向 $AA$（`next`）与旧值 $BeforeP$（`prior`），把它改为 $AfterP$ 完成 $P$ 侧的接线。
- **空 (3)** 处写 ⑤ `BeforeP->next = AfterP;`：把前驱的后继指针指向新的第一个结点。若链表**不带头结点**且 $P$ 可能是首元结点，则 $BeforeP$ 为 NULL，须写作 `if(BeforeP != NULL) BeforeP->next = AfterP;`（并且此时还应更新表头指针，本函数无法更新，故题面按带头结点设计，`BeforeP` 恒不为 NULL）。
- 最后骨架给出 ⑥，$AfterP$ 侧接线完成。

### 第四步：等价变体（阅卷可接受）

因为 ② 也可在 `AfterP->next=P;` 之后用**尚未被改写的** `P->next`（其值仍为 $AA$）来表达，所以

- (1) `P->prior = AfterP;`、(2) `if(P->next != NULL) P->next->prior = P;`、(3) `BeforeP->next = AfterP;`

是另一组完全正确的填法。**唯一不可交换的是"②必须早于 `AfterP->next=P;`"这一约束（若用 `AfterP->next` 取 $AA$）**；其余语句两两顺序无关。反之，若把 ② 写成 `AfterP->next->prior=P;` 却排在 `AfterP->next=P;` 之后，或漏掉判空，都是错误填法。

### 第五步：验算（三条链走查）

取带头结点的双向链表 `H,1,2,3,4,5,6,7`，令 $P$ 为数据 $3$ 的结点（$BeforeP=2$、$AfterP=4$、$AA=5$）。执行补全后的函数：

| 语句 | 执行后的关键指针 |
|---|---|
| `BeforeP=P->prior; AfterP=P->next;` | $BeforeP=2$、$AfterP=4$ |
| `P->next=AfterP->next;` | $3\to next=5$ |
| 空 (1)：`AfterP->next!=NULL` 成立，`AfterP->next->prior=P;` | $5\to prior=3$ |
| `AfterP->next=P;` | $4\to next=3$ |
| 空 (2)：`P->prior=AfterP;` | $3\to prior=4$ |
| 空 (3)：`BeforeP->next=AfterP;` | $2\to next=4$ |
| `AfterP->prior=BeforeP;` | $4\to prior=2$ |

沿 `next` 自头结点走：$H,1,2,\mathbf{4,3},5,6,7$ ✓
沿 `prior` 自尾结点走：$7,6,5,\mathbf{3,4},2,1,H$ ✓（恰为正向序列之逆，说明 6 条边全部改对、无孤立结点）

**边界 1（$AA=$ NULL）**：令 $P$ 为数据 $6$、$AfterP$ 为数据 $7$（$7\to next=$ NULL）。空 (1) 判空成立（`AfterP->next` 为 NULL）故不写 $AA$，其余同法，结果 $H,1,2,3,4,5,\mathbf{7,6}$，正反向走查一致 ✓

**边界 2（$P$ 为首元结点）**：$BeforeP=H$（头结点，非 NULL），空 (3) 写 `H->next=AfterP` ✓，表头不需更新，这正是"带头结点"设计的用意。

**边界 3（$P$ 为尾结点）**：$AfterP=P\to next=$ NULL，`AfterP->next` 非法访问——题面注释 `/* P and AfterP are cells to be switched */` 已限定 $P$ 与 $AfterP$ 均为链中相邻结点，故该情形不在函数职责内（调用方须保证 $P$ 不是尾结点）。

（后台以 C 程序实现上述补全并在 $7$ 结点表上执行三种 $P$ 取值，正、反向遍历结果与手工走查逐项一致；程序仅作验证，正文可人工复现。）

## 8. 考场标准答案

```c
/* P 与 AfterP 为待交换的相邻结点，BeforeP = P->prior，AA = AfterP->next */
void SwapWithNext(Position P, DLinkList L) {
    Position BeforeP, AfterP;

    BeforeP = P->prior;
    AfterP = P->next;

    P->next = AfterP->next;

    if (AfterP->next != NULL)        /* (1) AA 的后向指针指向 P */
        AfterP->next->prior = P;
    AfterP->next = P;
    P->prior = AfterP;               /* (2) P 的前向指针指向 AfterP */
    BeforeP->next = AfterP;          /* (3) BeforeP 的后向指针指向 AfterP */
    AfterP->prior = BeforeP;
}
```

若不保证带头结点，则 (3) 写作 `if(BeforeP != NULL) BeforeP->next = AfterP;`。

时间复杂度 $O(1)$，辅助空间 $O(1)$（仅三个指针变量）。

## 9. 易错点

1. **漏改 $AA\to prior$（即空 (1)）**：只改 $P$、$AfterP$、$BeforeP$ 三个结点的指针，导致从 $AA$ 往回走时仍指向 $AfterP$，反向链断裂——这是本题最常见的丢分点；
2. **把空 (1) 填到 `AfterP->next=P;` 之后**：此时 `AfterP->next->prior=P` 实际执行的是 `P->prior=P`，$P$ 自指成环；若确实想放在后面，必须改用 `P->next` 取 $AA$；
3. **忘记判空**：$P$ 是倒数第二个结点时 $AA=$ NULL，`AfterP->next->prior=P` 会解引用空指针；
4. **只写 `next` 不写 `prior`**：双向链表每个"换位"动作都要同时维护两条链，共 6 条边，缺一条即破坏结构；
5. **误以为需要修改头指针**：带头结点时首元结点的交换由 `BeforeP->next` 承担（$BeforeP$ 即头结点），表头地址不变——这正是本题函数能"只传 $P$ 和 $L$"即可完成交换的原因。

## 10. 一句话规律

链表指针改写的通用三步：**先画目标形态 → 列出目标形态下每一条边的赋值 → 按"哪个指针已被改写"给语句排序并补判空**；双向链表要牢记"每条边都有左右两份"。
