# DS-2023-16

## 1. 原题

画出一个二叉树，使得它既满足大根堆的要求，又满足二叉查找树的要求。

## 2. 答案

**每个结点都只有左孩子、且关键字沿链严格递减**的单支二叉树。例如（$10$ 以内取 $5$ 个关键字）：

```
      5
     /
    4
   /
  3
 /
2
/
1
```

一般形式：根为最大关键字，其左孩子为次大关键字，……，最下层为最小关键字，全树无任一结点拥有右孩子。结点个数可为任意 $n\ge 1$（取 $n$ 个互异关键字按递减序挂在左链上）。

## 3. 题目分析

- 已知：两个同时成立的要求——
  - **大根堆要求**：任一结点的关键字 $\ge$ 其左、右孩子（从而 $\ge$ 其整个子树中的所有关键字）；
  - **二叉查找树（BST）要求**：任一结点的左子树所有关键字 $<$ 该结点 $<$ 其右子树所有关键字；
- 目标：画出一棵（或一类）满足两者的二叉树；
- 关键约束：把两条性质在**同一个结点**上取交集——
  - 堆性质给出"该结点 $\ge$ 右子树中任意关键字"；
  - BST 性质给出"该结点 $<$ 右子树中任意关键字"（右子树非空时）；
  - 二者不可能同时成立 ⟹ **右子树必须为空**；
- 命题意图：考查对两种结构定义的**精确理解**（尤其"堆是父子不等式、BST 是左右子树分界"这一语义差别），以及由定义做小型证明的能力，而非记忆某个具体图。

## 4. 核心考点

核心考点：
DS06.07 堆与堆排序（大根堆的定义：$k_i\ge k_{2i}$，$k_i\ge k_{2i+1}$，即父结点不小于孩子，具有传递性到整个子树）

辅助考点：
DS05.07.01 二叉搜索（排序）树（左 $<$ 根 $<$ 右，且对任意子树递归成立）
DS03.02.01 二叉树的定义及主要特征（"只有左孩子的单支树"是合法的二叉树形态；其深度为 $n$）

解释：本题的解答完全由"堆的父子不等式"与"BST 的左右分界"两条定义推出，故主考点落在堆的定义（DS06.07），BST（DS05.07.01）为并列的另一半条件；所画图形本身是退化二叉树，属 DS03.02.01 的形态概念。

## 5. 解题思路

1. 先尝试"常规形状"是否可行：取 $3$ 个关键字 $1,2,3$ 画一棵满二叉树。堆要求根最大（$3$ 在根），BST 要求根最小（$3$ 应在最右下）——**矛盾**，说明形状不能"正常"；
2. 定位矛盾的来源：堆把最大值推向**根**，BST 把最大值推向**最右下的叶**。两者只有在"最大值的根没有右子树"时才不冲突；
3. 抽象成一般论证：对任意结点 $x$，若其右子树非空，则 BST 要求 $x<$ 右子树中所有关键字，而堆要求 $x\ge$ 右子树中所有关键字，矛盾 ⟹ 每个结点都无右孩子；
4. 于是形状被唯一确定为**左单支链**；再定关键字次序：沿左链，堆要求父 $\ge$ 子，BST 要求左子树 $<$ 父，两者同向 ⟹ 只需沿链**递减**即可，两个条件同时自动满足；
5. 作图并回代检验：对画出的树逐结点检查"父 $\ge$ 子"与"左子树全部 $<$ 父"，并检查 BST 的中序遍历是否得到递增序列（$1,2,3,4,5$）——这是最快的复核手段。

## 6. 详细解答

### 第一步：证明"任一结点的右子树必为空"

设二叉树 $T$ 同时满足大根堆与 BST 条件，取 $T$ 中任一结点 $x$。

- 若 $x$ 的右子树非空，任取 $y\in T_R(x)$。由 BST 定义（$x$ 是 $T_R(x)$ 中所有结点的祖先，$y$ 在 $x$ 的右子树中）：
$$key(x)<key(y)$$
- 由大根堆定义（父子不等式沿路径传递，$x$ 是 $y$ 的祖先）：
$$key(x)\ge key(y)$$

两式矛盾，故假设不成立，**$x$ 无右孩子**。由 $x$ 的任意性，$T$ 中每个结点都无右孩子。

### 第二步：确定形状

每个结点都无右孩子 ⟹ $T$ 是"只有左孩子的单支链"，结点总数 $n$ 即树深 $n$（第 $i$ 层恰一个结点）。

### 第三步：确定关键字的排列方向

设链上自上而下为 $x_1,x_2,\cdots,x_n$（$x_1$ 为根）。

- 堆条件：$key(x_i)\ge key(x_{i+1})$，$i=1,\cdots,n-1$；
- BST 条件：$x_{i+1}$ 在 $x_i$ 的左子树中，且 $T_L(x_i)=\{x_{i+1},\cdots,x_n\}$，故要求 $key(x_i)>\;key(x_j)$ 对所有 $j>i$ 成立。

由于关键字互异，$key(x_1)>key(x_2)>\cdots>key(x_n)$ 即**沿链严格递减**，此时两个条件同时满足（递减序列自动保证"$x_i$ 大于其下方所有结点"）。

### 第四步：充分性验证（回代检验）

取 $n=5$、关键字 $5,4,3,2,1$ 自上而下挂在左链上：

1. **堆条件**：$5\ge4$、$4\ge3$、$3\ge2$、$2\ge1$ ✓（每个父结点均不小于其唯一孩子）；
2. **BST 条件**：每个结点的左子树就是它下方的整条链，其关键字均小于该结点 ✓；所有结点右子树为空，右子树条件自动成立 ✓；
3. **第二方法（中序检验）**：BST 的充要条件是中序遍历递增。该树的中序遍历为"先走到最左下再回溯"，即 $1,2,3,4,5$，严格递增 ✓；
4. **再用堆的数组口径检验**：把该树按层编号，结点 $i$ 的左孩子编号为 $2i$，序列自顶向下为 $(5,4,3,2,1)$，需满足 $k_i\ge k_{2i}$：$5\ge4$、$4\ge2$（编号 $2$ 的孩子在编号 $4$）……逐位核对即"沿链递减"，成立 ✓。

### 第五步：关于"堆是否必须是完全二叉树"的说明

教材中"堆"定义为**完全二叉树**上满足 $k_i\le k_{2i},k_i\le k_{2i+1}$（大根堆取 $\ge$）的序列。若严格要求所画二叉树同时是**完全二叉树**，则"每个结点都无右孩子"与"完全"只能同时成立于 $n\le 2$：

- $n=1$：单结点，平凡满足；
- $n=2$：根 $2$ 与其左孩子 $1$，既是完全二叉树，又满足堆与 BST ✓；
- $n\ge3$：完全二叉树要求第 $2$ 层先填满右子树，与"无右孩子"冲突。

因此最保守的画法是**两结点树（根 $2$、左孩子 $1$）**——它在两种口径下都成立；若按"堆性质＝父子不等式"这一通常题意，则可任意取左单支链（如第四步的 $5$ 结点图）。考场建议：画 $3$ 结点以上的左单支链，并在图旁注明"每个结点仅有左孩子，故其右子树为空，两条件不冲突；关键字沿链递减"，必要时补一句"$n\le2$ 时该树还是完全二叉树"。

## 8. 考场标准答案

画法：**只有左子树的单支链，关键字自上而下递减。**

```
5
└─左孩子: 4
         └─左孩子: 3
                   └─左孩子: 2
                             └─左孩子: 1
（任一结点都没有右孩子）
```

（正确写法即：根 $5$，左孩子 $4$，$4$ 的左孩子 $3$，$3$ 的左孩子 $2$，$2$ 的左孩子 $1$；每个结点均无右孩子。）

理由（两行）：
① 若某结点有右子树，则 BST 要求"根 $<$ 右子树所有关键字"，而大根堆要求"根 $\ge$ 右子树所有关键字"，矛盾 ⟹ 所有结点无右孩子；
② 无右孩子后，堆条件与 BST 条件都化为"父 $>$ 子"，故沿左链递减即同时满足。中序遍历 $1,2,3,4,5$ 递增，验证 BST 成立 ✓。

## 9. 易错点

1. **画成"根最大 + 左右子树各为堆"的完全二叉树**（如根 $5$、左 $4$、右 $3$……）：违反 BST——$5$ 的右子树中出现了比 $5$ 小的关键字，而 BST 要求右子树全部大于根；
2. **画成右单支链**（$1\to2\to3\to4\to5$）：这是合法 BST，但违反大根堆（父 $1<$ 子 $2$）；它恰好是**小根堆** + BST 的答案，方向记反即全错；
3. 认为"堆和 BST 不可能同时满足"而空答：$n\ge1$ 时左单支链恒可构造，本题是有解的；
4. 忘记说明关键字必须**递减**：只画形状不写数值关系，堆条件可能不成立（例如左链上挂 $2,5,3,4,1$ 就不是堆）；
5. 关键字取等值：BST 要求互异（或按约定处理相等情况），作答时应取互异关键字以免争议。

## 10. 一句话规律

"同时满足两种结构性质"的作图题，先把两条性质在**同一个结点上取交集**推出结构限制（本题：右子树必空），再在该限制下安排关键字——限制往往比图形本身更值钱。
