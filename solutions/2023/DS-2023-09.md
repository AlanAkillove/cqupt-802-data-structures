# DS-2023-09

## 1. 原题

在一棵度为 $4$ 的树 $T$ 中，若有 $18$ 个度为 $4$ 的结点， $10$ 个度为 $3$ 的结点， $6$ 个度为 $2$ 的结点， $6$ 个度为 $1$ 的结点，则树 $T$ 的叶子结点个数是____________________。

## 2. 答案

**$81$** 个叶子结点（此时树 $T$ 共有 $121$ 个结点）。

## 3. 题目分析

- 已知：树 $T$ 的度为 $4$（即结点最大度数 $=4$）；$n_4=18$、$n_3=10$、$n_2=6$、$n_1=6$；
- 目标：求 $n_0$（叶子结点个数）；
- 关键约束（两条独立的计数关系，必须同时成立）：
  1. **按结点分类计数**：$n=n_0+n_1+n_2+n_3+n_4=n_0+40$；
  2. **按边（分支）计数**：树中除根结点外，每个结点恰被一条边指向，故"总分支数 $=\sum_i i\cdot n_i$"等于"结点数 $-\,1$"，即 $n=1+\sum_i i\cdot n_i$；
- 命题意图：DS03.01 中树的结点计数基本性质——"结点数 = 度数之和 + 1"。题目把四个度数分组给出，正是为了让考生先算分支总数；
- 干扰点："$6$ 个度为 $1$ 的结点"在 $n_0=1+\sum_{i\ge2}(i-1)n_i$ 这一推导式里系数为 $0$（$1-1=0$），看起来"没用"，但在 $n=1+\sum i\cdot n_i$ 中确实贡献 $6$ 条分支，不可漏算。

## 4. 核心考点

核心考点：
DS03.01 树的基本概念——结点的度、树的度，以及"$n=\sum_i n_i$ 与 $n=1+\sum_i i\,n_i$"两个恒等式联立求叶子数

解释：本题只涉及"度"与结点计数的抽象关系，不需要二叉树性质（DS03.02）也不涉及存储结构（DS03.03），故主标签 DS03.01、无辅助考点。

辅助考点：无。

## 5. 解题思路

1. **算分支总数**：$B=\sum_i i\cdot n_i=4\times18+3\times10+2\times6+1\times6$；
2. **由"结点数 = 分支数 + 1"得总结点数** $n=B+1$（$+1$ 是根结点，它不被任何边指向）；
3. **减去已知度 $\ge1$ 的结点数**：$n_0=n-(n_1+n_2+n_3+n_4)$；
4. **用另一路推导式复核**：$n_0=1+\sum_{i\ge2}(i-1)n_i$，两法结果必须一致；
5. **合理性检查**：树度为 $4$ 且 $n_4=18>0$ ✓；$n_0\ge 2$（非平凡的树至少两个叶子？对一般树只需 $n_0\ge1$，此处 $81$ 远大于 $1$）✓；各 $n_i$ 非负 ✓。

## 6. 详细解答

### 第一步：方法一（分支计数）

树中每个结点（根除外）都由其父结点的一条分支指向，故

$$B=\sum_{i=1}^{4} i\cdot n_i=4\times18+3\times10+2\times6+1\times6=72+30+12+6=120 .$$

于是总结点数

$$n=B+1=120+1=121 .$$

又

$$n=n_0+n_1+n_2+n_3+n_4=n_0+6+6+10+18=n_0+40 ,$$

所以

$$n_0=121-40=\boxed{81} .$$

### 第二步：方法二（叶子计数推导式，独立复核）

把 $n=\sum_i n_i$ 代入 $n=1+\sum_i i\,n_i$：

$$\sum_{i\ge0}n_i=1+\sum_{i\ge1}i\,n_i
\ \Longrightarrow\ n_0=1+\sum_{i\ge1}(i-1)n_i=1+\sum_{i\ge2}(i-1)n_i$$

（$i=1$ 项系数为 $0$，故只需从 $i=2$ 起算。）代入数据：

$$n_0=1+\bigl[(2-1)\times6+(3-1)\times10+(4-1)\times18\bigr]=1+(6+20+54)=1+80=81\ \checkmark$$

两法一致。

### 第三步：验算（把全部数据代回自查）

| 量 | 值 | 核对 |
|---|---|---|
| $n_0$ | $81$ | 叶子 |
| $n_1$ | $6$ | |
| $n_2$ | $6$ | |
| $n_3$ | $10$ | |
| $n_4$ | $18$ | |
| 结点总数 $n$ | $81+6+6+10+18=121$ | 与 $B+1=120+1$ ✓ |
| 分支总数 $B$ | $0\times81+1\times6+2\times6+3\times10+4\times18=120$ | 与 $n-1=120$ ✓ |

两方向闭合，结果唯一。

（后台以 C 程序按 $\texttt{for}(i=1..4)\ B+=i*n[i]$、$\texttt{n}=B+1$、$\texttt{n0}=n-\sum_{i\ge1}n_i$ 计算，输出 $\texttt{leaves}=81$、$n=121$，与手工一致；程序仅作验证，正文可手工复现。）

**答案：$81$。**

## 8. 考场标准答案

设 $n_i$ 为度为 $i$ 的结点个数，$n$ 为结点数。树中：

$$n=1+\sum_{i} i\,n_i \quad(\text{结点数}=\text{分支数}+1),\qquad n=\sum_i n_i$$

$$n=1+(4\times18+3\times10+2\times6+1\times6)=1+120=121$$

$$n_0=n-(n_1+n_2+n_3+n_4)=121-(6+6+10+18)=\boxed{81}$$

（可直接记结论：$n_0=1+\sum_{i\ge2}(i-1)n_i=1+(1\times6+2\times10+3\times18)=81$。）

## 9. 易错点

1. **漏掉根结点的 $+1$**：写成 $n=B=120$，从而得 $n_0=80$。"$n-1$"是边数（分支数），还原 $n$ 必须加回根；
2. **漏算度为 $1$ 的结点的分支贡献**：在方法一中把 $1\times n_1=6$ 丢掉，会得 $B=114$、$n=115$、$n_0=75$。度为 $1$ 的结点在方法二的 $(i-1)$ 加权式中确实不出现，在方法一的 $i\,n_i$ 中必须出现，两处不能混用；
3. **误套二叉树公式**：如用二叉树"$n_0=n_2+1$"（那里只有度 $0,1,2$ 且以"儿子数"计度），对度为 $4$ 的树不成立；
4. **把"树的度为 $4$"理解成"树有 $4$ 层"**：树的度指结点的最大度数，与深度无关；
5. **算术错误**：$4\times18=72$、$3\times10=30$、$2\times6=12$、$1\times6=6$，合计 $120$；建议按方法二再算一遍交叉核对（$1+6+20+54=81$）。

## 10. 一句话规律

一般树的叶子计数永远只用两条恒等式联立：**$n=\sum_i n_i$（按结点分类数）** 与 **$n=1+\sum_i i\,n_i$（按分支数，$+1$ 是根）**；合并后得到可直接套用的 $n_0=1+\sum_{i\ge2}(i-1)n_i$。
