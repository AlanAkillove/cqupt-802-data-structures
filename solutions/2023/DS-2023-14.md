# DS-2023-14

## 1. 原题

在含有 $n$ 个结点的三叉链表中有____________________个空链域。

## 2. 答案

$n+2$

## 3. 题目分析

- 已知：二叉树含 $n$ 个结点，存储方式为**三叉链表**——每个结点设三个指针域 `lchild`（左孩子）、`rchild`（右孩子）、`parent`（双亲）；
- 目标：统计整棵树中值为空的指针域（空链域）总数；
- 关键约束：
  1. 指针域总数 $3n$，与树的形态无关；
  2. "非空链域"分两类计数：孩子指针非空数 $=$ 树中的边数 $=n-1$；双亲指针非空数 $=$ 有双亲的结点数 $=n-1$（仅根结点无双亲）；
- 命题意图：把教材中"二叉链表有 $n+1$ 个空链域"这一经典结论，推广到带 `parent` 域的三叉链表，考查的是"按指针语义分类双计数"的基本功，而不是死记结论。

## 4. 核心考点

核心考点：
DS03.02.02 二叉树的存储结构（链式存储：二叉链表/三叉链表的结点结构，以及空指针个数的计算）

辅助考点：
DS03.01 树的基本概念（$n$ 个结点的树恰有 $n-1$ 条分支/边，"边数 = 非空孩子指针数"）

解释：本题的整个推导只用到两条事实——"三叉链表每个结点 3 个指针"与"一棵 $n$ 结点二叉树共有 $n-1$ 条父子边"，前者属 DS03.02.02，后者属 DS03.01。

## 5. 解题思路

1. 先定总量：$3n$ 个指针域；
2. 再定"被用掉"的量——按语义分两组：
   - 左、右孩子指针：每个非根结点被其双亲的某个孩子指针恰好指一次 ⟹ 非空孩子指针数 $=n-1$；
   - 双亲指针：除根外每个结点各有一个非空 `parent` ⟹ 非空双亲指针数 $=n-1$；
3. 两组不重不漏（分属不同字段），故非空总数 $2(n-1)$；
4. 空链域 $=3n-2(n-1)=n+2$；
5. 用特例复核：$n=1$ 时应为 $3$；$n=3$ 的满二叉树应为 $5$——与公式一致。

## 6. 详细解答

### 第一步：结点结构与指针总量

```c
typedef struct BTNode {
    ElementType data;
    struct BTNode *lchild, *rchild, *parent;   /* 三叉链表：三个指针域 */
} BTNode, *BiTree;
```

$n$ 个结点 ⟹ 指针域总数 $3n$。

### 第二步：非空链域计数（按语义分两组）

**孩子指针组**（`lchild` + `rchild`，共 $2n$ 个域）：
树中每条边都由某个结点的左或右孩子指针承载，且一个非空孩子指针恰好对应一条边。$n$ 个结点的二叉树有 $n-1$ 条边，故

$$\#\{\text{非空孩子指针}\}=n-1,\qquad \#\{\text{空孩子指针}\}=2n-(n-1)=n+1$$

（$n+1$ 即教材中"二叉链表空链域"结论，可作为本题的中间校验量。）

**双亲指针组**（`parent`，共 $n$ 个域）：
除根结点外，每个结点都有唯一双亲，故

$$\#\{\text{非空双亲指针}\}=n-1,\qquad \#\{\text{空双亲指针}\}=n-(n-1)=1$$

（唯一为空的就是根的 `parent`。）

### 第三步：合计

$$\#\{\text{空链域}\}=(n+1)+1=n+2$$

或一次性写为

$$3n-\big[(n-1)+(n-1)\big]=3n-2n+2=n+2$$

### 第四步：特例验证（第二方法）

- $n=1$（只有根）：三个指针全空 ⟹ $3=1+2$ ✓
- $n=2$（根 + 左孩子）：根的 `rchild` 空、根的 `parent` 空、孩子的 `lchild`、`rchild` 空 ⟹ $4=2+2$ ✓
- $n=3$（满二叉树）：两个叶子各 $2$ 个空孩子指针（$4$ 个）$+$ 根的 `parent`（$1$ 个）$=5=3+2$ ✓
- $n=3$（单支链 根→左→左）：结点 1 的 `rchild` 空、结点 2 的 `lchild`、`rchild` 空、结点 3 的 `lchild`、`rchild` 空、结点 1 的 `parent` 空 ⟹ $5=3+2$ ✓ 与形态无关。

四个特例（含两种不同形态的 $3$ 结点树）均得 $n+2$，公式对形态不敏感，与"总量 $3n$、边数 $n-1$ 均与形态无关"的推导一致。

## 8. 考场标准答案

三叉链表每个结点有 $3$ 个指针域，共 $3n$ 个。
其中非空者：左、右孩子指针共 $n-1$ 个（等于边数），`parent` 指针共 $n-1$ 个（除根外每结点一个）。

$$\text{空链域}=3n-2(n-1)=\boxed{n+2}$$

## 9. 易错点

1. 只算孩子指针的 $n+1$ 个空域，忘了 `parent` 域还有 $1$ 个空（根的双亲），少答 $1$；
2. 误把"三叉链表"当成"三叉树（每结点至多 3 个孩子）的链表存储"，于是写 $4n-(n-1)=3n+1$——本题"三叉"指**每个结点三个指针域**，不是三叉树；
3. 认为结果与树的形态（满/完全/单支）有关：空链域总数只依赖 $n$，形态只改变"空在哪里"，不改变"共有几个"；
4. 与 DS03.02.02 中"线索二叉树利用空链域存放线索"混淆：线索化正是利用了这里的 $n+1$ 个孩子空域，若题目改问"中序线索化后可插入多少条线索"，答案口径是 $n+1$（孩子空域数），不是 $n+2$。

## 10. 一句话规律

链式存储的"空指针计数"题一律三步：**算总域数 → 按语义分组算非空域数（孩子域看边数 $n-1$、双亲域看非根结点数 $n-1$）→ 相减**；结论对树的形态不敏感。
