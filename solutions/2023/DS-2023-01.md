# DS-2023-01

## 1. 原题

有一段代码：

```c
int brute(int a[], int N)
{
    int i,j,k,m;
    for(i=0;i<N;i++)
        for(j=i+1;j<N;j++)
            for(k=j+1;k<N;k++)
                for(m=k+1;m<N;m++)
                    if(a[i]+a[j]+a[k]+a[m]==0) 
                        return 1;
    return 0;
}
```

假设 $N=1000$ 时，执行这段代码需要 $1000$ 秒时间。当 $N = 10000$ 时，请预测它的运行时间是多少秒。

## 2. 答案

约 $10^{7}$ 秒，即 $1000 \times 10^{4}=10\,000\,000$ 秒（按一天 $86400$ 秒折合约 $115.7$ 天）。

## 3. 题目分析

- 已知：一个四重嵌套循环，四个下标满足 $0\le i<j<k<m<N$，最内层 `if` 对每个满足该不等式的四元组做一次求和比较；给出"规模 $N=1000$ 时耗时 $1000$ 秒"这一实测标定值；
- 目标：把耗时外推到 $N=10000$。外推唯一依赖的是**耗时关于 $N$ 的增长阶**，而不是常数因子（常数已被 $1000$ 秒这个标定值吸收）；
- 关键约束：
  1. 时间复杂度按**基本操作（最内层判定语句）的执行次数**计量，机器、编译器、数据分布假定不变，故"同一段代码、同一口径"下耗时与语句频度成正比；
  2. 代码含 `return 1` 提前退出，即运行时间与输入数据有关；题面把"$N=1000$ 执行这段代码需要 $1000$ 秒"作为已知条件，含义是按同一（最坏/完整扫描）口径计时，外推时只需比较频度的比值；
- 命题意图：表面是"预测运行时间"，实质是考**由代码结构读出语句频度、再由频度主导项读出增长阶**（DS00.02 的核心能力）。四重"下三角式"嵌套是 $O(N^{4})$ 的标准模板，本题要求把 $\left(\frac{10000}{1000}\right)^{4}=10^{4}$ 这一放大倍数正确乘回去。

## 4. 核心考点

核心考点：
DS00.02 算法与算法分析——语句频度（最内层基本操作的执行次数）与时间复杂度 $T(n)=O(f(n))$；已知一个规模的耗时按增长阶外推另一个规模的耗时

解释：题目不涉及任何线性表/树/图的结构与操作，数组 `a[]` 只作为随机访问的载体；全部解题动作是"数语句执行次数 → 取主导项 → 求比值"，正是教材第 1 章"算法的效率（时间复杂度）"的考法，故主标签 DS00.02。

辅助考点：无（不需要 DS01.02.01 顺序存储等知识即可判定；"提前 `return`"只影响常数与低阶项，不改变本题分析所依据的增长阶）。

## 5. 解题思路

1. **找基本操作**：嵌套最深处的 `if(a[i]+a[j]+a[k]+a[m]==0)` 执行次数最多，取它为频度计量对象；
2. **数次数**：四个下标严格递增 $i<j<k<m$，每个这样的四元组恰好被访问一次 ⟹ 次数 $=\binom{N}{4}=\frac{N(N-1)(N-2)(N-3)}{24}$；
3. **读增长阶**：$\binom{N}{4}\sim\frac{N^{4}}{24}$，故 $T(N)=c\cdot N^{4}$（其余三层循环的条件判断次数为 $\binom{N}{3},\binom{N}{2},N$ 量级，均被 $N^4$ 吸收）；
4. **用标定值消去常数**：$\dfrac{T(10000)}{T(1000)}=\left(\dfrac{10000}{1000}\right)^{4}=10^{4}$，所以 $T(10000)=1000\ \text{秒}\times10^{4}=10^{7}$ 秒；
5. **自检**：用精确的 $\binom{N}{4}$ 比值（而非渐近式）复算，看差别是否在"预测"可接受范围内（见第 6 节第三步）。

## 6. 详细解答

**第一步：最内层语句的执行次数**

四重循环的界为 $0\le i<N$、$i+1\le j<N$、$j+1\le k<N$、$k+1\le m<N$，即从 $\{0,1,\cdots,N-1\}$ 中**任取 4 个不同下标并按升序排列**恰好对应一次内层判定，故

$$F(N)=\binom{N}{4}=\frac{N(N-1)(N-2)(N-3)}{24}.$$

**第二步：整段代码的频度量级**

各层循环体（含循环控制语句）的执行总次数为

$$N+\binom{N}{2}+\binom{N}{3}+\binom{N}{4}=\Theta(N^{4}),$$

主导项是 $\binom{N}{4}\sim\frac{1}{24}N^{4}$，因此 $T(N)=c\,N^{4}$（$c$ 为与机器、编译器、单次判定代价有关的常数）。

**第三步：外推**

$$\frac{T(10000)}{T(1000)}=\left(\frac{10000}{1000}\right)^{4}=10^{4}=10000\ \text{倍},$$

$$T(10000)=1000\ \text{秒}\times 10^{4}=10^{7}\ \text{秒}.$$

**第四步：验算（用精确频度而非渐近式）**

$$\binom{1000}{4}=\frac{1000\cdot999\cdot998\cdot997}{24}=41\,417\,124\,750,$$
$$\binom{10000}{4}=\frac{10000\cdot9999\cdot9998\cdot9997}{24}=416\,416\,712\,497\,500,$$
$$\frac{\binom{10000}{4}}{\binom{1000}{4}}=10054.2\ \Longrightarrow\ T\approx 1000\times10054.2=1.0054\times10^{7}\ \text{秒}.$$

与渐近式所得 $10^{7}$ 秒相差约 $0.5\%$，说明"预测值 $10^{7}$ 秒"成立（预测本身只要求量级正确）。

**第五步：换算成可读的时间尺度（便于检查答案合理性）**

$$\frac{10^{7}\ \text{秒}}{3600}\approx 2777.8\ \text{小时}\approx 115.7\ \text{天},$$

即规模扩大 $10$ 倍后，$O(N^{4})$ 算法从"约 $16.7$ 分钟"变成"约四个月"——这正是本题想让学生体会的：多项式阶算法在规模增长时的不可承受性。

**答案：约 $10^{7}$ 秒。**

不适用（程序阅读题）。

## 8. 考场标准答案

最内层判定语句对每个满足 $0\le i<j<k<m<N$ 的四元组执行一次，频度

$$F(N)=\binom{N}{4}=\frac{N(N-1)(N-2)(N-3)}{24}=\Theta(N^{4})\ \Longrightarrow\ T(N)=cN^{4}.$$

故

$$T(10000)=T(1000)\times\left(\frac{10000}{1000}\right)^{4}=1000\times10^{4}=10^{7}\ \text{秒}\approx115.7\ \text{天}.$$

（该代码为"判断数组中是否存在 4 个元素之和为 0"的穷举算法，四次方阶增长使规模扩大 10 倍即耗时扩大 1 万倍。）

## 9. 易错点

1. **把倍数算成 $10$ 或 $100$**：规模比是 $10$，但时间是"规模比的**循环重数**次方"，四重嵌套 ⟹ $10^{4}$ 而非 $10$；写成 $10^{4}$ 秒（漏乘已知的 $1000$ 秒）同样常见；
2. **误把频度当 $N^{4}$ 而认为与 $\binom{N}{4}$ 不同阶**：$\binom{N}{4}=\frac{N^{4}-6N^{3}+\cdots}{24}$ 与 $N^{4}$ 同阶，比值外推时系数 $\frac{1}{24}$ 自动约去，故不影响答案（第 6 步验算给出严格值仅差 $0.5\%$）；
3. **被 `return 1` 干扰**：提前退出使实际耗时依赖数据，但题面已用"$N=1000$ 需要 $1000$ 秒"完成同口径标定，外推仍按增长阶进行，不必（也无法）另行估计命中位置；
4. **单位换算**：$10^{7}$ 秒不要误写成 $10^{7}$ 分钟/小时。

## 10. 一句话规律

嵌套循环的时间外推只看两件事：**循环重数决定幂次、规模比取同次方**——$k$ 重线性嵌套 ⟹ 时间比 $=(\text{规模比})^{k}$；对数阶则只取 $(\text{规模比})$ 的对数倍（如 $O(N\log N)$ 的倍数是 $10\times\frac{\log 10000}{\log 1000}$）。
