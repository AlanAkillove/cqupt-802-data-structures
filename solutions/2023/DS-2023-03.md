# DS-2023-03

## 1. 原题

一个单链表按序存放一个整数序列 `{1,2,3,4,5,6,7}` ，且该单链表作为函数 `rearrange` 的输入。请写出执行函数 `rearrange` 后的输出。

```c
struct node{
    int value;
    struct node *next;
};

void rearrange(struct node *list) 
{
    struct node *p, *q;
    int temp;
    if((!list)||!list->next)
        return;
    p=list;
    q=list->next;
    while(q) 
    {
        temp=p->value;
        p->value=q->value;
        q->value=temp;
        p=q->next;
        q=p?p->next:0;
    }
}
```

## 2. 答案

执行后链表中的序列为 **`2,1,4,3,6,5,7`**。

即：相邻两结点成对交换数据域（第 $1$、$2$ 个互换，第 $3$、$4$ 个互换，第 $5$、$6$ 个互换），结点个数为奇数时**最后一个结点保持不动**。

## 3. 题目分析

- 已知：一条**无头结点**的单链表，$7$ 个结点的数据域依次为 $1\sim 7$；函数用两个指针 $p,q$ 同步扫描，每轮交换 $p,q$ 两结点的 `value`，然后 $p$ 跳到"下下个"结点、$q$ 再往后一个；
- 目标：写出函数调用后链表的内容（输出序列）；
- 关键约束：
  1. 交换的是**数据域的值**，不是结点之间的链接——链表的物理次序始终不变，改变的只是各结点里存的数；
  2. 循环条件是 `while(q)`，且 $p=q\to next$、$q=p?p\to next:0$：说明每轮消耗**两个**结点，$q$ 为空即停止；
  3. 入口处的 `if((!list)||!list->next) return;` 处理空表与单结点（此时什么都不改）；
- 命题意图：考单链表上"双指针步长"的阅读能力——判断 $p,q$ 每轮到底前进几个结点、以及奇偶长度对最后一次交换的影响（DS01.02.02）。这类题的失分点几乎都在"把 $p$ 的推进写成 $p=p\to next$"或"多交换一轮"。

## 4. 核心考点

核心考点：
DS01.02.02 链式存储：单链表——结点结构 `value/next`、沿 `next` 的扫描、通过临时变量交换两结点的数据域

辅助考点：无（本题不涉及双链/循环链表的指针修改，也不需要 DS01.02.03 的知识）。

## 5. 解题思路

1. **先给结点编号**：记 $A_1\sim A_7$，初值 $A_i\to value=i$，$A_7\to next=\text{NULL}$；
2. **确定 $p,q$ 的初值**：$p=A_1$、$q=A_2$（题面 `p=list; q=list->next;`）；
3. **写出循环体的"位移量"**：交换 $p,q$ 的值之后 `p=q->next`、`q=p->next` ⟹ 一轮之后 $p$ 前进 $2$ 个结点、$q$ 前进 $2$ 个结点，且始终保持 $q$ 是 $p$ 的直接后继；
4. **逐轮列表**：每轮记录"交换了哪两个结点""交换后整表内容"，直到 $q$ 为空；
5. **检查边界**：第 3 轮交换 $(A_5,A_6)$ 后 $p=A_7$、$q=A_7\to next=\text{NULL}$，循环终止 ⟹ $A_7$ 里的 $7$ 从头到尾未被改动；这一结论必须由表格得出，不能凭"奇数长度末尾不动"的直觉直接写（该直觉是否成立正是需要验证的内容）。

## 6. 详细解答

**逐轮模拟**（表内"链表内容"按 $A_1\to A_2\to\cdots\to A_7$ 的物理顺序写出各结点的 `value`）：

| 轮 | 进入时 $p$ | 进入时 $q$ | 动作（交换 $p,q$ 的 `value`） | 交换后链表内容 | 轮末 $p$ | 轮末 $q$ |
|---|---|---|---|---|---|---|
| 初 | $A_1$ | $A_2$ | — | $1,2,3,4,5,6,7$ | $A_1$ | $A_2$ |
| 1 | $A_1(1)$ | $A_2(2)$ | $A_1\leftrightarrow A_2$ | $2,1,3,4,5,6,7$ | $A_3$ | $A_4$ |
| 2 | $A_3(3)$ | $A_4(4)$ | $A_3\leftrightarrow A_4$ | $2,1,4,3,5,6,7$ | $A_5$ | $A_6$ |
| 3 | $A_5(5)$ | $A_6(6)$ | $A_5\leftrightarrow A_6$ | $2,1,4,3,6,5,7$ | $A_7$ | $\text{NULL}$ |
| 终 | — | — | `while(q)` 不成立，退出 | $2,1,4,3,6,5,7$ | — | — |

**第 3 轮末的指针细节**：`p = q->next`，此时 $q=A_6$，$A_6\to next=A_7$ ⟹ $p=A_7$；接着 `q = p ? p->next : 0`，$p\ne$ NULL，故 $q=A_7\to next=\text{NULL}$。下一轮判断 `while(q)` 为假，退出。

**结论**：$A_7$ 从未参与交换（它只被 $p$ 访问过一次，而那次 $q$ 已经为空），其值保持 $7$。最终输出

$$\boxed{2,1,4,3,6,5,7}$$

**规律总结（用于自检）**：该函数把序列 $(a_1,a_2,a_3,a_4,\cdots,a_{2t-1},a_{2t})$ 变成 $(a_2,a_1,a_4,a_3,\cdots,a_{2t},a_{2t-1})$；若长度为奇数 $2t+1$，则末尾元素 $a_{2t+1}$ 原样保留。

**代入验证**：$(1,2,3,4,5,6,7)$ 中 $t=3$，按规律得 $(2,1,4,3,6,5,7)$ ✓，与表格逐轮结果一致。

**偶长对照（后台程序另测）**：输入 $1\sim 8$ 得 $2,1,4,3,6,5,8,7$——末两位也交换，说明"最后一个不动"确实只发生在奇数长度时，规律与模拟互洽。

**空表 / 单结点**：`if((!list)||!list->next) return;` 直接返回，链表不变；两个结点时执行一轮，得 $2,1$。

## 8. 考场标准答案

$p,q$ 初指向第 $1$、第 $2$ 个结点；每轮交换 $p,q$ 两结点的 `value`，随后 $p\Leftarrow q\to next$、$q\Leftarrow p\to next$，即两指针各前进两个结点、$q$ 始终是 $p$ 的后继。

$7$ 个结点依次交换 $(A_1,A_2)$、$(A_3,A_4)$、$(A_5,A_6)$ 三轮后 $q$ 为空，$A_7$ 未参与交换。

故输出为 **`2,1,4,3,6,5,7`**。

（功能一句话：把单链表中相邻两结点的数据成对互换，奇数个结点时最后一个不变。）

## 9. 易错点

1. **误以为交换的是指针（结点次序被打乱）**：代码只交换 `value`，链表的链接关系完全没动；若按"断链重接"去画，会把结果写成 $2,1,4,3,6,5,7$ 之外的形态（如把 $A_7$ 也前移）；
2. **指针步长算错**：把 `p=q->next; q=p?p->next:0;` 读成 $p,q$ 各走一步，就会得到 $1,3,2,5,4,7,6$ 之类的错误答案；关键是 $p$ 先跳到 $q$ 的后继、$q$ 再跳一步，一轮共前进两个结点；
3. **多算一轮**：忘了 $q$ 为空即停，误把 $A_7$ 与 NULL 交换（崩溃）或认为 $A_7$ 与 $A_1$ 首尾呼应交换；
4. **忽略 `q=p?p->next:0` 的判空**：该三目表达式正是防止 `p->next` 在 $p=$ NULL 时越界访问，读代码时要看出"链表长度为偶数时最后一轮 $p$ 落在尾结点、$q$ 变 NULL"这一处理。

## 10. 一句话规律

读链表代码先定两件事：**指针每轮前进几个结点**、**交换的是数据域还是链接**；随后按"结点编号 + 每轮一行"列表模拟，长度奇偶与末尾结点的去向自然浮现。
