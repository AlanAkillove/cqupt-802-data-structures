# DS-2023-24

## 1. 原题

给定一个 $n\times m$ 的矩形位图，位图中的每个像素不是白色就是黑色，但至少有一个是白色的。第 $i$ 行第 $j$ 列的像素被称作像素 $(i,j)$。两个像素 $p_1=(i_1,j_1)$，$p_2=(i_2,j_2)$ 之间的距离定义为：

$$d(p_1,p_2)=|\,i_1-i_2\,|+|\,j_1-j_2\,|$$

现在请设计一个时间复杂度尽可能低的算法来计算图中每个像素与离其最近的"白像素"的距离。

输入：第 $1$ 行包含两个整数 $n$ 和 $m$（$1\le n\le 150$，$1\le m\le 150$），用一个空格隔开。接下来 $n$ 行，每一行都包含一个长度为 $m$ 的 $01$ 串。第 $i+1$ 行第 $j$ 列的字符若为 $1$，则像素 $(i,j)$ 是白色；否则是黑色的。

输出：包含 $n$ 行，每行有 $m$ 个用空格隔开的整数。第 $i$ 行 $j$ 列的整数表示 $(i,j)$ 与离其最近的白像素之间的距离。

要求：

（1）描述算法的基本设计思想；

（2）根据设计思想，采用类 C 语言的伪代码描述算法，关键之处给出注释。

（3）说明你所设计的算法的时间复杂度。

## 2. 答案

**(1) 设计思想**：把位图看成一张**四邻接无权图**——每个像素是一个顶点，相邻（上下左右）像素之间有一条权为 $1$ 的边。题中所给距离 $|i_1-i_2|+|j_1-j_2|$ 恰等于图中两顶点之间的最短路径长度（每步只能把一个坐标改变 $1$）。于是"每个像素到最近白像素的距离"就是**多个源点到全图顶点的最短距离**，可用一次**多源广度优先搜索**求解：扫描整张位图，把所有白像素的距离置 $0$ 并同时全部入队（相当于增设一个与所有白像素相连的超级源），然后反复出队队头像素、检查它的四个邻点，凡未被访问过的邻点令其距离 $=$ 当前像素距离 $+1$ 并入队。由 BFS 的"按层扩展"性质，每个像素**第一次被访问时的层号就是它到最近白像素的距离**，且每个像素至多入队一次，故时间 $O(n\cdot m)$，已是该问题的最优量级（必须输出 $n\cdot m$ 个数）。

**(2) 类 C 伪代码**：见第 8 节。

**(3) 时间复杂度**：$O(n\cdot m)$；空间复杂度 $O(n\cdot m)$。

## 3. 题目分析

- 已知：$n\times m$（$n,m\le 150$）的 $01$ 矩阵，$1$ 表示白；白像素个数 $W\ge 1$（题面保证）；距离为曼哈顿距离；
- 目标：对**每个**像素求 $\min\{d((i,j),(p,q))\mid (p,q)\ \text{为白像素}\}$，输出 $n\times m$ 的整数矩阵；
- 关键约束：
  1. 输出规模本身是 $n\cdot m$，故任何算法的时间下界为 $\Omega(nm)$，"时间复杂度尽可能低"即要求达到 $O(nm)$ 线性级；
  2. 若按定义对每个像素遍历全部白像素求最小值，代价为 $O(nmW)$，最坏 $150^2\times150^2\approx5\times10^8$，不可取；
  3. 曼哈顿距离**不能**靠"只扫一遍"求出（最近白像素可能位于任一象限方向），这是备选动态规划法必须做**两遍**扫描的原因；
- 命题意图：把"队列的层次扩展"与"数组建模"结合，考查学生能否识别出**多源最短距离 = 一次 BFS**这一转化（DS02.07 队列应用），以及顺序队列的数组实现与越界判断（DS02.02、DS02.04）。

## 4. 核心考点

核心考点：
DS02.07 栈、队列和数组的应用（用队列的 FIFO 层次特性求解"到最近特殊元素距离"这一类问题；把二维数组下标与邻接关系结合建模）

辅助考点：
DS02.02 栈和队列的顺序存储结构（用一维数组 `queue[]` 模拟队列，`front/rear` 双下标，元素总数不超过 $n\cdot m$ 故不会队满）
DS04.03.02 广度优先搜索（BFS 的"首次到达即最短"性质、多源入队的超级源解释、$O(V+E)$ 与本题 $O(nm)$ 的对应关系）
DS02.04 多维数组的存储（以 `dist[i][j]` 兼作距离数组与访问标记数组，行优先下的一次访问为 $O(1)$）

解释：本题不要求写图的存储结构，但解法的灵魂是"位图即网格图、BFS 即分层扩散"，其能力落点在队列与数组的应用，故 primary 取 DS02.07；顺序队列的实现细节与 BFS 的最短性论证分别构成辅助考点。

## 5. 解题思路

1. **先翻译距离**：看到 $|i_1-i_2|+|j_1-j_2|$ 就想到"只能上下左右走的网格步数"——这一步把几何度量变成图论最短路径，是选择算法的关键；
2. **反向思考**：与其问"每个黑像素离白像素多远"（$n m$ 次查询），不如问"每个白像素能影响到哪些像素、几步影响到"——从所有白像素同时向外扩散，一层一层标记，天然就是 BFS；
3. **确认多源 BFS 的正确性**：把所有源点同时置于第 $0$ 层入队，等价于新增一个虚拟源点连向它们；BFS 层号单调不减，因此任一像素第一次被碰到时走的步数必然最少；
4. **选定数据结构**：距离用二维整型数组 `dist[][]`，并用 $-1$ 表示"未访问"，使**距离数组兼任访问标记**，省掉一个 `visited[][]`；队列用一维数组 `queue[]`（最多 $n\cdot m$ 个元素），元素为 `(x,y)` 二元组；
5. **写扩散代码**：出队 $\to$ 四方向试走 $\to$ 判越界与未访问 $\to$ 定距离并入队；
6. **复杂度与边界自检**：每个像素入队出队各一次、每次做 $O(1)$ 工作 $\Rightarrow O(nm)$；检查"全白""只有一个白""$n=1$"三种极端输入是否退化正确。

## 6. 详细解答

### 第一步：把位图建成图，并证明"图距离 $=$ 曼哈顿距离"

记 $G=(V,E)$，$V=\{(i,j)\mid 1\le i\le n,\,1\le j\le m\}$，$|V|=nm$；$E$ 为四邻接边，$|E|=2nm-n-m$（横向 $n(m-1)$ 条、纵向 $m(n-1)$ 条，均无向）。

**断言**：$G$ 中 $(i_1,j_1)$ 到 $(i_2,j_2)$ 的最短路径长度 $=|i_1-i_2|+|j_1-j_2|$。

- $\ge$：每条边只改变行号或列号之一，且改变量为 $1$，故 $k$ 步最多使 $|\Delta i|+|\Delta j|$ 减少 $k$，从 $0$ 走到目标至少需 $|i_1-i_2|+|j_1-j_2|$ 步；
- $\le$：先沿列方向走 $|j_1-j_2|$ 步到 $(i_1,j_2)$，再沿行方向走 $|i_1-i_2|$ 步到 $(i_2,j_2)$，恰为该步数，且中间点均在矩形内（坐标单调介于两端之间）。

故"到最近白像素的曼哈顿距离" $=$ "$G$ 中到最近源点的最短路径长度"，BFS 适用。

### 第二步：多源 BFS 的正确性

设白像素集合 $S$，$|S|=W\ge1$。初始化 $\forall p\in S:\ dist[p]=0$ 且全部入队。

- **不变式**：队列中元素按 $dist$ 值非降排列，且任一时刻 $dist[v]\ne -1$ 当且仅当 $v$ 已被某条从 $S$ 出发、长度为 $dist[v]$ 的路径到达；
- **归纳**：出队 $u$ 时其 $dist[u]$ 已是 $S$ 到 $u$ 的最短长度（否则存在更短的到达路径，其前驱比 $u$ 早出队，会更早给 $u$ 赋一个更小的值，与"首次赋值即定型"矛盾）；对每个未访问邻点 $v$ 令 $dist[v]=dist[u]+1$，即给出长度 $dist[u]+1$ 的到达路径，且任何到达 $v$ 的路径必经 $v$ 的某个邻点，而该邻点的 $dist$ 不小于 $dist[u]$，故 $dist[v]$ 不可能更小；
- **终止**：$G$ 连通，$W\ge1$，故 $nm$ 个顶点最终全部被访问，队列清空时所有 $dist$ 即为所求。

（直观解释：第 $0$ 层是全部白像素，第 $1$ 层是它们的邻点，第 $k$ 层恰是"到最近白像素距离为 $k$"的像素集合——BFS 的层就是答案的分组。）

### 第三步：$3\times3$ 实例手工验证

输入（$n=3,m=3$）：

```
1 0 0
0 0 0
0 0 1
```

白像素 $S=\{(1,1),(3,3)\}$。初始化 $dist$ 全 $-1$，$(1,1),(3,3)$ 置 $0$ 并入队，`queue=[(1,1),(3,3)]`，`front=0`。

| 出队 | $dist$ | 四邻处理 | 入队新增 | 队列剩余 |
|---|---|---|---|---|
| $(1,1)$ | $0$ | $(2,1)\to1$、$(1,2)\to1$ | $(2,1),(1,2)$ | $(3,3),(2,1),(1,2)$ |
| $(3,3)$ | $0$ | $(2,3)\to1$、$(3,2)\to1$ | $(2,3),(3,2)$ | $(2,1),(1,2),(2,3),(3,2)$ |
| $(2,1)$ | $1$ | $(3,1)\to2$、$(2,2)\to2$ | $(3,1),(2,2)$ | $(1,2),(2,3),(3,2),(3,1),(2,2)$ |
| $(1,2)$ | $1$ | $(1,3)\to2$；$(2,2)$ 已有值不改 | $(1,3)$ | $\cdots$ |
| $(2,3)$ | $1$ | $(2,2)$ 已访问，跳过 | — | $\cdots$ |
| $(3,2)$ | $1$ | $(3,1)$ 已访问，跳过 | — | $\cdots$ |
| $(3,1),(2,2),(1,3)$ | $2$ | 邻点均已访问 | — | 空 |

输出：

```
0 1 2
1 2 1
2 1 0
```

**逐点核对**（按定义 $\min$ 两个白像素）：$(2,2)$：$\min(2+2,\,1+1)=2$ ✓；$(1,3)$：$\min(0+2,\,2+0)=2$ ✓；$(3,1)$：$\min(2+0,\,0+2)=2$ ✓；$(2,3)$：$\min(1+2,\,1+0)=1$ ✓。全部吻合。

### 第四步：与"两遍扫描动态规划"口径对拍

备选算法（不需队列）：令 $dist[i][j]=0$（白）或 $+\infty$（黑），

- 正遍（$i$ 升、$j$ 升）：$dist[i][j]=\min(dist[i][j],\,dist[i-1][j]+1,\,dist[i][j-1]+1)$；
- 反遍（$i$ 降、$j$ 降）：$dist[i][j]=\min(dist[i][j],\,dist[i+1][j]+1,\,dist[i][j+1]+1)$。

对第三步实例执行：正遍（只能从左上方向右下方接力）得

```
0 1 2
1 2 3
2 3 0
```

（此时 $(2,3)$ 与 $(3,2)$ 均为 $3$：它们各自的最近白像素 $(3,3)$ 分别位于其下方与右方，而正遍只能利用已算出的**上方与左方**信息。）反遍修正 $(2,3):3\to1$、$(3,2):3\to1$，其余不变，最终

```
0 1 2
1 2 1
2 1 0
```

与 BFS 结果完全一致 ✓（原理：正遍覆盖"最近白点位于左上方"的情形，反遍覆盖"右下方"，而"左下—右上"方向的情形可由"正遍走完竖段 $+$ 反遍补横段"接力得到，两遍合起来对 $d_4$ 度量是充分的）。

### 第五步：复杂度与规模核算

- 时间：初始化扫描 $nm$；BFS 中每个顶点至多入队 $1$ 次、出队 $1$ 次，出队时做 $4$ 次 $O(1)$ 邻点检查，故 $T=O(nm+4nm)=O(nm)$；
- 空间：`pic[][]` $+ $ `dist[][]` $+ $ `queue[]` $\le nm+4nm+2nm$ 个字，$S=O(nm)$；
- 规模代入：$n=m=150\Rightarrow nm=22500$，$T\approx 9\times10^4$ 次基本操作，队列最多容纳 $22500$ 个元素，均在考场手写与实机器内存范围内；
- 对比朴素法 $O(nmW)$：最坏 $W=nm=22500$ 时约 $5.1\times10^8$，慢三个数量级，说明"多源 BFS"确是题面要求的"尽可能低"。

### 第六步：边界情况检查

| 情况 | 输入特征 | 算法行为 | 结果 |
|---|---|---|---|
| 全白 | $W=nm$ | 初始化后全部 $dist=0$ 入队；出队时四邻均已访问，无新入队 | 输出全 $0$ ✓ |
| 仅一个白像素 | $W=1$ | 退化为标准单源 BFS | 输出该点的菱形等距层 ✓ |
| $n=1$ 或 $m=1$ | 一维 | 四邻检查中越界方向被 `1<=x<=n` 拦下，等价于左右两邻 | 一维最近 $1$ 的距离 ✓ |
| 白像素全在边界 | — | 不影响正确性（BFS 不依赖源点位置） | ✓ |
| 队满 | — | 数组长度取 $n\cdot m$，每点最多入队一次，`rear<=n*m` 恒成立 | 无需判满 ✓ |

## 8. 考场标准答案

**(1) 基本设计思想**

把 $n\times m$ 位图看作四邻接无权图：像素为顶点，上下左右相邻像素之间连一条权为 $1$ 的边，则两像素间的最短路径长度恰为题中的曼哈顿距离 $|i_1-i_2|+|j_1-j_2|$。于是问题化为"以全部白像素为源点的多源最短路径"。

解法是一次多源广度优先搜索：先扫描整个位图，白像素距离置 $0$ 并全部进队（相当于增设一个连向所有白像素的超级源），黑像素距离置 $-1$ 兼作"未访问"标记；随后当队非空时取出队头像素，检查它的上、下、左、右四个邻点，凡在图内且距离仍为 $-1$ 者，令其距离 $=$ 队头距离 $+1$ 并进队。由 BFS 按层扩展的性质，任一像素第一次被访问时的层号就是它到最近白像素的距离；每个像素进出队各一次，故总时间为 $O(n\cdot m)$，与输出规模同阶，已达下界。

**(2) 类 C 伪代码**

```c
#define MAXN 152

typedef struct { int x, y; } Pos;      /* 像素坐标 */

char pic[MAXN][MAXN];                  /* pic[i][j] = '1' 表示白像素 */
int  dist[MAXN][MAXN];                 /* 距离数组，-1 表示尚未访问 */
int  dx[4] = { -1, 1, 0, 0 };           /* 四邻方向增量：上、下、左、右 */
int  dy[4] = { 0, 0, -1, 1 };

void NearestWhite(int n, int m)
{
    static Pos q[MAXN * MAXN];         /* 顺序队列：最多 n*m 个像素，不会队满 */
    int front = 0, rear = 0;           /* 队头/队尾下标，q[front..rear-1] 为队中元素 */
    int i, j, k, x, y;

    /* ---- 第一步：建图并装入全部源点（多源 BFS 的初始化） ---- */
    for (i = 1; i <= n; i++)
        for (j = 1; j <= m; j++)
            if (pic[i][j] == '1') {            /* 白像素：距离 0，直接入队 */
                dist[i][j] = 0;
                q[rear].x = i; q[rear].y = j; rear++;
            } else {
                dist[i][j] = -1;               /* 黑像素：未知，待扩展 */
            }

    /* ---- 第二步：按层向外扩散，首达即最短 ---- */
    while (front < rear) {                     /* 队空判据 */
        Pos p = q[front]; front++;             /* 出队 */
        for (k = 0; k < 4; k++) {              /* 依次考察四个邻点 */
            x = p.x + dx[k];  y = p.y + dy[k];
            if (x >= 1 && x <= n && y >= 1 && y <= m   /* 越界判断 */
                && dist[x][y] == -1) {         /* 未访问才扩展，保证每点只进队一次 */
                dist[x][y] = dist[p.x][p.y] + 1;   /* 层号 = 前驱层号 + 1 */
                q[rear].x = x; q[rear].y = y; rear++;
            }
        }
    }

    /* ---- 第三步：按要求格式输出 ---- */
    for (i = 1; i <= n; i++) {
        for (j = 1; j <= m; j++)
            printf("%d%c", dist[i][j], j == m ? '\n' : ' ');
    }
}
```

**(3) 时间复杂度**

设像素总数 $N=n\cdot m$。初始化遍历全部像素，代价 $O(N)$；BFS 中每个像素至多进队一次、出队一次，每次出队做 $4$ 次 $O(1)$ 的邻点判断，代价 $O(4N)=O(N)$；输出 $O(N)$。故

$$T(N)=O(N)=O(n\cdot m),\qquad S(N)=O(n\cdot m)$$

因算法至少要输出 $n\cdot m$ 个整数，$\Omega(nm)$ 是下界，本算法已达最优量级。

## 9. 易错点

1. **只把某一个白像素入队**（做成单源 BFS）：题面要求"至少有一个白像素"，若有多个而只入队一个，其余白像素的距离会被算成正数；必须**全部**白像素同时入队、距离 $0$；
2. **忘记判越界**：网格不是环，$(1,j)$ 的"上邻"不存在，缺 `x>=1 && x<=n` 会访问非法下标（或读到脏数据）；
3. **不检查 `dist[x][y]==-1` 就入队**：同一像素会被反复入队，最坏退化成指数级重复扩展，且距离被覆盖成更大的值；
4. **把 $-1$ 与 $0$ 混用**：若黑像素初始化为 $0$，则无法区分"未访问"与"白像素"，必须用 $-1$（或另设 `visited[][]`）；
5. **误以为扫一遍即可**：若用动态规划法只做正向一遍，会漏掉"最近白像素在右下方"的像素；一遍扫描不充分，必须正、反两遍（见第 6 节第四步）；
6. **距离公式理解错**：本题是曼哈顿（街区）距离，不是欧氏距离，不能开方，也不能用 $8$ 邻接（斜向）扩展，否则层数会偏小；
7. **队列容量开小**：用循环队列时要留一个空位判满；本题用长度 $n\cdot m$ 的一维数组顺序队列，配合"每点最多入队一次"可直接免去判满，但数组必须开成 $N$ 大小而不是 $150$。

## 10. 一句话规律

"每个元素到最近的某类元素的距离"型题目，通解是**多源 BFS**：把所有目标元素一次性置 $0$ 入队，让队列按层次向外扩散，**首达即最短**，时间从 $O(N\cdot W)$ 降到 $O(N)$；在网格上它等价于距离变换，也可用"正遍 $+$ 反遍"两趟动态规划得到同阶解。
