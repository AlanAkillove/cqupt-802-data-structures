# DS-2026-12

## 1. 原题

若长度为 $n$ 的线性表采用链式存储结构，在其第 $i$ 个位置插入一个元素的时间复杂度为____________________。

## 2. 答案

$O(n)$。

## 3. 题目分析

- 已知：线性表长度为 $n$，存储结构为**链式**（单链表，仅给头指针，无随机访问能力）；操作为"在第 $i$ 个位置插入一个元素"（插入后新元素成为第 $i$ 个元素）；
- 目标：该操作的时间复杂度（以 $n$ 表示，$i$ 可取 $1\sim n+1$）；
- 关键约束：单链表只能沿 `next` 逐后继移动，从头指针走到第 $i-1$ 个结点需移动 $i-1$ 次链接（带头结点约定，$i=1$ 时 $0$ 次、$i=n+1$ 时 $n$ 次）；
- 命题意图：考"链式存取结构的随机访问缺失"——插入本身的指针修改是 $O(1)$，但**定位**是 $O(n)$，二者不可混为一谈。

## 4. 核心考点

核心考点：
DS01.02.02 链式存储：单链表（顺序访问特性、插入操作的"先定位后改链"两步）

辅助考点：
DS01.02.01 顺序存储（顺序表：插入/删除与移动次数）——与本题构成"同为一元操作、代价来源不同"的对照

解释：题目问的是链表上的插入代价，主考点在链式存储；但答案的说服力来自与顺序表的对比（顺序表插入代价在"移动元素"、链表插入代价在"查找位置"），故把顺序存储列为辅助考点。

## 5. 解题思路

1. 拆操作：链表插入 = ① 找到第 $i-1$ 个结点 `p`；② `s->next=p->next; p->next=s;`；
2. ② 是常数次赋值 ⟹ $O(1)$，所以全部代价在 ①；
3. ① 只能顺链扫描，链接移动次数 $=i-1$（$i=1$ 时 $0$ 次，$i=n+1$ 时走到表尾共 $n$ 次），随 $i$ 线性增长，最坏 $O(n)$；
4. 若按"各插入位置等概率"求平均：$\frac{1}{n+1}\sum_{i=1}^{n+1}(i-1)=\frac{n}{2}=\Theta(n)$，与最坏同阶 ⟹ 时间复杂度 $O(n)$；
5. 复核：与顺序表对比确认结论合理——顺序表插入平均移动 $n/2$ 个元素也是 $O(n)$；链表的优势是"不移动元素"，而非"定位快"。

## 6. 详细解答

**操作分解与代价**

```c
Status ListInsert(LinkList &L, int i, ElemType e)   // 在第 i 个位置插入 e
{
    LinkList p = L;            // 带头结点：p 指向第 0 个结点
    int j = 0;
    while(p && j < i-1) { p = p->next; j++; }   // ① 定位第 i-1 个结点：扫描 i-1 次链接
    if(!p) return ERROR;                        // i 非法
    LinkList s = (LinkList)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;                          // ② 改链：常数次操作
    p->next = s;
    return OK;
}
```

- ① 中 `while` 循环执行 $i-1$ 次（带头结点约定下，从表头结点走到第 $i-1$ 个数据结点），取值范围 $0\sim n$，故**最坏 $O(n)$**；
- ② 三次指针/数据操作为 $O(1)$；
- 合计 $T(n,i)=\Theta(i)$，按插入位置等概率的平均代价

$$\bar T=\frac{1}{n+1}\sum_{i=1}^{n+1}(i-1)=\frac{n}{2}=\Theta(n)$$

**结论**：时间复杂度 $O(n)$（与顺序表同为 $O(n)$，但代价构成不同）。

**对照表（同一插入操作在两种存储结构下的代价来源）**

| 存储结构 | 定位第 $i-1$ 个元素 | 腾出位置 | 总代价 |
|---|---|---|---|
| 顺序表 | $O(1)$（下标直接访问） | 平均移动 $n/2$ 个元素，$O(n)$ | $O(n)$ |
| 单链表 | 平均/最坏扫描 $\Theta(n)$ | 无需移动，改 2 个指针 $O(1)$ | $O(n)$ |
| 双向/循环链表（**已给出该位置结点指针**） | $O(1)$ | 改 2~4 个指针 | $O(1)$ |

第三行是本题的典型对照情形：如果题目说明"已持有第 $i-1$ 个结点的指针"，插入才降到 $O(1)$；本题只给"第 $i$ 个位置"这一下标，定位代价必须计入。

不适用（填空题）。

## 8. 考场标准答案

$O(n)$。理由：单链表不支持随机访问，在第 $i$ 个位置插入须先从头指针顺链查找第 $i-1$ 个结点（需 $O(i)$、最坏 $O(n)$ 时间），插入时只修改两个指针为 $O(1)$，故整体时间复杂度由查找决定，为 $O(n)$。

## 9. 易错点

1. 误答 $O(1)$：把"链表插入不需移动元素"错当成"整个插入操作是常数时间"，忽略了定位过程；
2. 与顺序表结论混记：两者都是 $O(n)$，但顺序表贵在移动、链表贵在查找；若题目改问"已知指针指向插入位置的前驱结点"，链表才是 $O(1)$；
3. 忽略头结点约定导致计数差 $1$（移动 $i-1$ 次还是 $i-2$ 次）——不影响 $O(n)$ 的结论，但影响"平均比较次数"类题目的具体数值；
4. 若题目为**按值有序插入**（如本库 DS-2026-03 的有序表操作），同样是 $O(n)$，但扫描终止条件由下标计数改为按值比较，勿把两种定位方式混写。

## 10. 一句话规律

线性表上"按下标定位"的复杂度由存储结构决定：顺序表随机访问 $O(1)$、链表 $O(n)$；判断复杂度时把操作拆成"定位 + 修改"两段，各段分别计价再取最大。

## 11. 关联知识

- 链式存储其它操作的复杂度：按位取值 $O(n)$、按值查找 $O(n)$、删除已定位结点 $O(1)$、表头插入 $O(1)$；
- 顺序表插入/删除的平均移动次数（$n/2$、$(n-1)/2$）是同一考点的另一半；“同一逻辑结构不同存储结构下运算实现效率不同”止于 DS00.01 三要素概念，辨析类题可参照 DS-2005-13；
