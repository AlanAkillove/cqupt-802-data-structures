# DS-2026-02

## 1. 原题

给定一个共享栈，栈大小为 $m$ ，栈 $1$ 的初始栈顶指针 $top[0]$ 值初始指向 $-1$ ，栈 $2$ 的初始栈顶指针 $top[1]$ 值初始指向 $m$ ，请填写完整代码。

共享栈存储类型可以描述为（题目中未给出该部分存储结构）：

```c
typedef struct 
{
    int data[MaxSize];
    int top[2];//栈顶指针
    int bot[2];//栈尾指针
}TwStack;
```

初始化、入栈和出栈操作函数如下：

```c
void InitStack(TwStack &S)
{
    S.bot[0]=-1;
    S.bot[1]=m;
    S.top[0]=-1;
    S.top[1]=m;
}

    return true;
}

    else if(i==1)
```

## 2. 答案

- (1) `S.top[0]+1==S.top[1]`（栈满：两栈顶指针相邻）
- (2) `++S.top[0]`（栈 1 先上移栈顶再存元素）
- (3) `--S.top[1]`（栈 2 先下移栈顶再存元素）
- (4) `S.top[0]--`（栈 1 先取栈顶元素再下移栈顶）
- (5) `S.top[1]++`（栈 2 先取栈顶元素再上移栈顶）

## 3. 题目分析

- 已知：一段数组空间被两个栈共享，栈 1 的栈底在低端（`bot[0]=-1`，向大址增长），栈 2 的栈底在高端（`bot[1]=m`，向小址增长）；`i` 为栈号参数；
- 目标：补全栈满判断与两侧进栈、出栈的下标表达式；
- 关键约束：`Pop` 中给出的栈空条件 `S.top[i]==S.bot[i]` 说明 `top[i]` **直接指向当前栈顶元素**（栈 1 空时 `top[0]==-1`，栈 2 空时 `top[1]==m`，均为"指向空位"的初值）；
- 命题意图：考共享栈（双向增长顺序栈）的栈满条件与"先移后存 / 先取后移"的下标方向感。

## 4. 核心考点

核心考点：

辅助考点：

解释：本题不写新函数，只补表达式，但每空都取决于"两个栈顶相向增长、相遇即满"这一共享栈特有约定，故主考点落在顺序存储结构（.02）而非一般概念。

## 5. 解题思路

1. 先看 `InitStack`：`bot` 与 `top` 初值相同，说明 `top` 指栈顶元素本身，与单栈"top 指栈顶元素"的写法一致（不是"指栈顶下一位"）；
2. 栈 1 向高址增长：进栈必须先 `top[0]` 加 1 再写入 → 前置自增 `++S.top[0]`；出栈必须先读 `data[top[0]]` 再回退 → 后置自减 `S.top[0]--`；
3. 栈 2 向低址增长：方向全部相反 → `--S.top[1]` 与 `S.top[1]++`；
4. 满的判据不再是"某个 top 到边界"，而是**两栈共享空间被占满**：`top[0]+1==top[1]`（相邻即无空位可再入栈）；
5. 用具体 $m$ 值手推一遍容量（见第 6 节表）验证不会越界、不会假满。

## 6. 详细解答

补全后的代码：

```c
bool Push(TwStack &S,int i,int x)
{
    if(S.top[0]+1==S.top[1])          // (1) 两栈顶相遇 -> 共享栈满
        return false;
    if(i==0)
        S.data[++S.top[0]]=x;         // (2) 栈1向高址增长：先移后存
    else if(i==1)
        S.data[--S.top[1]]=x;         // (3) 栈2向低址增长：先移后存
    return true;
}

bool Pop(TwStack &S,int i,int &x)
{
    if(S.top[i]==S.bot[i])
        return false;                 // 栈空（题已给）
    if(i==0)
        x=S.data[S.top[0]--];         // (4) 先取栈顶，再回退
    else if(i==1)
        x=S.data[S.top[1]++];         // (5) 先取栈顶，再回退
    return true;
}
```

**手工验证**（取 $m=8$，`data[0..7]`，交替入栈）：

| 操作 | 判满检查 | 结果下标 | top[0] | top[1] | 已占单元 |
|---|---|---|---|---|---|
| 初始 | — | — | -1 | 8 | 0 |
| Push(0,10) | -1+1=0 ≠ 8 | data[0] | 0 | 8 | 1 |
| Push(1,30) | 0+1=1 ≠ 8 | data[7] | 0 | 7 | 2 |
| Push(0,20) | 1 ≠ 7 | data[1] | 1 | 7 | 3 |
| Push(1,40) | 2 ≠ 7 | data[6] | 1 | 6 | 4 |
| Push(0,50) | 2 ≠ 6 | data[2] | 2 | 6 | 5 |
| Push(1,60) | 3 ≠ 6 | data[5] | 2 | 5 | 6 |
| Push(0,70) | 3 ≠ 5 | data[3] | 3 | 5 | 7 |
| Push(1,80) | 4 ≠ 5 | data[4] | 3 | 4 | 8 |
| Push(0,90) | 3+1=4 == top[1] | **满，返回 false** | 3 | 4 | 8 |

- 容量恰为 $m=8$ 个单元（`data[0..7]` 全被占用），**不牺牲任何空间**，说明 (1) 写 `==` 而非 `>=`+空位 是正确的；
- 出栈：`Pop(0,&x)` 依次得 70,50,20,10（`top[0]` 3→-1，末次 `top[0]==bot[0]` 返回 false）；`Pop(1,&x)` 依次得 80,60,40,30（`top[1]` 4→8），两栈均满足 LIFO ✓；
- 若把 (1) 写成 `S.top[0]==S.top[1]`（错），则会在 `top[0]=3,top[1]=4` 时仍允许 `++top[0]→4` 覆盖栈 2 的栈顶元素 `data[4]`；
- 若把 (2) 写成 `S.top[0]++`（错），首次入栈会写入 `data[-1]`，越界。

**复杂度**：`Push`/`Pop` 均为 $O(1)$ 时间、不额外占空间；$m$ 个单元由两栈共享，最坏情形（一栈独占）可用容量仍为 $m$。

## 8. 考场标准答案

(1) `S.top[0]+1==S.top[1]`
(2) `++S.top[0]`
(3) `--S.top[1]`
(4) `S.data[S.top[0]--]` 位置处填 `S.top[0]--`
(5) `S.data[S.top[1]++]` 位置处填 `S.top[1]++`

一句话理由：两栈栈底分置两端、相向增长，栈顶指针指向当前栈顶元素，故入栈"先移后存"、出栈"先取后移"，满条件为两栈顶指针相邻。

## 9. 易错点

1. (1) 误写 `S.top[0]==S.top[1]`：共享栈满的边界是"相邻"，等号成立时已发生覆盖；
2. (2)(3) 与 (4)(5) 的前/后置自增自减混淆——入栈是"移动后写入"（前置），出栈是"读出后移动"（后置），写成后置自增 `S.top[0]++` 会越界写 `data[-1]`；
3. 两栈增长方向搞反：栈 2 的 `top[1]` 初值为 $m$（越界位置），必须**先减再用**，不能 `++`；
4. 忽略 (1) 的栈满判断而只判栈空，导致 `data` 越界写入栈 2 区。

## 10. 一句话规律

双向增长的共享栈：满看"两栈顶是否相遇"（`top[0]+1==top[1]`），空看"栈顶是否回到本栈栈底"（`top[i]==bot[i]`）；入栈一律前置移动、出栈一律后置回退，方向由该栈朝哪个边界增长决定。
