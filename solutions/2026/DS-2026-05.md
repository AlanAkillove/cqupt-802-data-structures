# DS-2026-05

## 1. 原题

下面的代码是判断一个二叉树是否为平衡二叉树，若是平衡二叉树通过参数 $depth$ 返回树的深度，并返回 $true$ ；若不是平衡二叉树，则返回 $false$ ，此时 $depth$ 的值无意义。请填写完整代码。

二叉树的链式存储结构描述如下：

```c
typedef struct BiTNode{
    ElemType data;
    struct BiTNode *lchild,*rchild;
}BiTNode,*BiTree;
```

判断平衡二叉树函数如下：

```c
bool isBalanced(BiTree T,int &depth)
{
    if(T==NULL)
    {
        depth=0;
        return true;
    }
    int deepleft,deepright;

    if(_____(1)_____)
    {
        int dif=deepleft-deepright;
        if(_____(2)_____)
        {
            depth=(deepleft>deepright?deepleft:deepright)+1;
            return true;
        }
    }
    return false;
}
```

## 2. 答案

- (1) `isBalanced(T->lchild,deepleft) && isBalanced(T->rchild,deepright)`
- (2) `dif>=-1 && dif<=1`（等价写法 `dif==-1||dif==0||dif==1`，或 `abs(dif)<=1`）

## 3. 题目分析

- 已知：二叉链表结点定义；函数签名 `bool isBalanced(BiTree T, int &depth)`——返回值表示"是否平衡"，引用参数 `depth` 回传深度；空树分支已给出（`depth=0; return true;`）；局部变量 `deepleft`、`deepright` 已声明但未被赋值；
- 目标：用一棵树"左右子树都平衡"且"本层高度差不超过 1"两个条件补全判定；
- 关键约束：`dif=deepleft-deepright` 写在 (1) 之后的 `if` 体内，说明 (1) 必须完成**两次递归调用并回填 `deepleft`/`deepright`**；(2) 是根结点处的平衡判据；
- 命题意图：考 AVL 的定义（任一结点左右子树高度差绝对值 $\le 1$）+ 后序式递归"自底向上同时返回两个信息（布尔 + 深度）"的写法。

## 4. 核心考点

核心考点：
DS05.07.02 平衡二叉树（平衡的定义：任一结点左右子树深度差 $\le 1$；本题判据 `dif>=-1 && dif<=1`）

辅助考点：

解释：题目不考旋转，只考"什么是平衡"这一形式化条件如何落到代码，以及递归如何把子树的深度经引用参数传回来，故主考点为 AVL 概念、辅考点为二叉链表与递归。

## 5. 解题思路

1. 空树已处理，剩下的活儿是：先得到左右子树的深度与平衡性 → 再判根本身的平衡 → 最后回填 `depth`；
2. 深度只能靠递归返回，而 `deepleft`/`deepright` 是 `int` 局部变量、函数形参是 `int &depth` ⟹ 只能写成 `isBalanced(T->lchild,deepleft)` 与 `isBalanced(T->rchild,deepright)` 两次调用；
3. 进入 `if` 体才计算 `dif` 并可能 `return true`，故 (1) 必须是"**两个子树都平衡**"的合成条件 ⟹ 逻辑与 `&&`（不可用 `||`，也不能只调一侧）；
4. (2) 是 AVL 平衡条件在**本结点**的表达式：$|h_L-h_R|\le 1$，即 `dif>=-1 && dif<=1`；
5. 用三棵小树走查：满二叉（真）、左右深度 1/2（真，AVL 允许差 1）、左右深度 1/3（假）——见第 6 节。

## 6. 详细解答

补全后的代码：

```c
bool isBalanced(BiTree T,int &depth)
{
    if(T==NULL){ depth=0; return true; }      // 空树：深度 0，视为平衡
    int deepleft,deepright;

    // (1) 左右子树都必须平衡，同时把它们的深度经引用参数带回
    if(isBalanced(T->lchild,deepleft) && isBalanced(T->rchild,deepright))
    {
        int dif=deepleft-deepright;
        if(dif>=-1 && dif<=1)                 // (2) 本结点满足 |hL-hR|<=1
        {
            depth=(deepleft>deepright?deepleft:deepright)+1;   // 树高 = 较高子树 + 1
            return true;
        }
    }
    return false;                             // 子树不平衡 或 本层高度差>=2
}
```

**正确性说明**：设断言 $P(T)$ =「`isBalanced(T,depth)` 返回 true 当且仅当以 $T$ 为根的树是平衡二叉树，且此时 `depth` 等于 $T$ 的深度」。
- 基例 $T=NULL$：空树平衡，深度 $0$ ✓；
- 归纳：$T\neq NULL$ 时，由归纳假设两次调用分别给出左右子树的平衡性与深度 $h_L,h_R$。`&&` 短路保证仅当两侧都平衡才继续；此时唯一可能破坏平衡的就是本层 $|h_L-h_R|\ge2$，(2) 正是排除它；通过后 `depth=max(h_L,h_R)+1` 符合深度定义 ✓。若某一侧不平衡，函数落到末尾 `return false`，与"此时 `depth` 无意义"的题设吻合。

**三组走查**：

| 树形 | $h_L$ | $h_R$ | $dif$ | (2) 结果 | 返回（及 `depth`） | 应为 |
|---|---|---|---|---|---|---|
| 根 + 左右两个叶子 | 1 | 1 | 0 | 真 | true，depth=2 | 平衡 ✓ |
| 根、左叶子、右侧带一个孙子（深度 2） | 1 | 2 | -1 | 真 | true，depth=3 | 平衡（差 1 允许）✓ |
| 根、左叶子、右侧链状深度 3 | 1 | 3 | -2 | 假 | false | 非平衡 ✓ |

第二、三行正是 AVL 判定的分界：差 $1$ 合格、差 $2$ 不合格。

**复杂度**（$n$ 为结点数）：每结点至多进入一次递归、做常数次比较与加法，时间 $O(n)$；空间为递归栈，最坏（单支树）$O(n)$、最好 $O(\log n)$。

## 8. 考场标准答案

(1) `isBalanced(T->lchild,deepleft) && isBalanced(T->rchild,deepright)`
(2) `dif>=-1 && dif<=1`

配套说明（可一句带过）：两次递归经引用参数带回左右子树深度，`&&` 保证左右子树均平衡后才在本层检查高度差不超过 1，满足则 `depth=max(deepleft,deepright)+1` 并返回 true。

## 9. 易错点

1. (1) 用 `||` 连接：只有一侧平衡就进入本层判定，会漏判另一侧的失衡；
2. (1) 只写一次递归（如 `isBalanced(T->lchild,deepleft)`）：`deepright` 未被赋值即参与 `dif` 计算，结果不可预期；
3. (2) 只写 `dif<=1`：漏了下界，右子树比左子树高 2 以上时会被误判为平衡；
4. 误写成 `dif==deepleft-deepright` 之类的赋值/比较混淆，或把 `abs(dif)<=1` 写成 `abs(dif)<1`（则退化成"完全二叉树式"的过紧条件）；
5. 以为空 (1) 要写深度计算式：`depth=...` 已在骨架给出，(1) 的产物是 `deepleft`/`deepright`。

## 10. 一句话规律

"判断二叉树是否具备某种整体性质 + 同时回传一个统计量"的题，一律写成后序递归：用引用/指针参数带回子树信息，用返回值（或另一参数）表示判定结果，本层条件只对根成立即可（性质可递归分解时）。

## 11. 关联知识

- 平衡二叉树的其它考点：给定插入序列构造 AVL 与四类旋转（本库 DS-2026-18 第 (3) 问即"边插入边平衡调整"）；
- AVL 最坏深度为 $O(\log n)$，故查找长度优于一般二叉排序树（DS-2026-18 第 (2) 问的比较）；
- 若不用引用参数，也可让递归返回一个含「深度 + 是否平衡」两个域的结构体（同一思想）；但若另外写一个独立的“求深度”函数并在每层重复调用，则退化为 $O(n^2)$（每个结点重复计算子树高度），本题骨架的写法正是为了避免它。
