# DS-2026-04

## 1. 原题

分析下列程序的输出结果，并给出算法的时间复杂度，其中 $n$ 为 $8$ 。

```c
int a[]={23,33,16,79,34,79,29,86};

void riddle1(int n)
{
    if(n==1)
        return ;
    riddle1(n-1);
    if(a[n-1]<a[n-2])
        printf("%d ",a[n-1]);
    else
        printf("%d ",a[n-2]);
}

int riddle2(int n)//两函数不确定是哪个
{
    if(n==1)
        return a[0];
    int p=riddle2(n-1);
    if(p<a[n])
        return p;
    else return a[n];
}
```

> 订正说明转录：题干未指明分析哪个函数（回忆版备注"两函数不确定是哪个"保留在代码注释中）；另若按 $n=8$ 分析，$riddle2$ 递归中访问 $a[8]$ 越界（数组仅 $8$ 个元素，下标 $0\sim7$），源文数据疑有缺陷，保留原文。

## 2. 答案

**riddle1(8) 的输出**：

```
23 16 16 34 34 29 29
```

（每个数后各带一个空格，行末也有一个空格；共 $7= n-1$ 个输出。）
语义：按 $i=1,2,\cdots,7$ 顺序输出相邻两元素 $a[i-1],a[i]$ 中的**较小者**。

**riddle2 的行为**：函数只返回值、不打印。$riddle2(n)=\min\{a[0],a[2],a[3],\cdots,a[n]\}$——注意它**漏比较 $a[1]$**，且 $n=8$ 时访问 $a[8]$ 越界（数组只有 $a[0]\sim a[7]$）。若按合法下标范围取 $n=7$，返回 $\min\{23,16,79,34,79,29,86\}=16$。

**时间复杂度**：两者同为 $T(n)=T(n-1)+O(1)$，$T(1)=O(1)$ ⟹ $T(n)=O(n)$；$n=8$ 时递归调用 $8$ 层、附加栈空间 $O(n)$。

## 3. 题目分析

- 已知：全局数组 $a[0..7]=\{23,33,16,79,34,79,29,86\}$；两个"递归调用自身 $n-1$"的函数；实参 $n=8$；
- 目标：写出程序运行输出（哪个函数未指明 ⟹ 两个都要分析），并给出时间复杂度；
- 关键约束：`riddle1` 的递归调用在 `printf` **之前**（尾递归式展开），故输出顺序是 $n$ 由小到大；`riddle2` 的比较对象是 $a[n]$ 而非 $a[n-1]$（下标偏移）；
- 命题意图：考递归执行过程模拟（展开顺序、活动记录栈）+ 递推式求复杂度，兼考读题时对下标边界的敏感。

## 4. 核心考点

核心考点：
DS02.07 栈、队列和数组的应用（递归工作栈：调用顺序与返回顺序相反，决定打印先后）

辅助考点：
DS00.02 算法与算法分析（递推式 $T(n)=T(n-1)+O(1)$ 求解、语句频度与 $n$ 的线性关系）

解释：题目要求"分析输出结果"，本质是模拟递归在工作栈上的压入/弹出次序；第二问"时间复杂度"落在绪论章的算法分析节点，故二者作主辅搭配。数组在此只是被递归下标访问的载体，不构成独立考点。

## 5. 解题思路

1. **先看递归调用位置**：`riddle1` 是"先递归、后打印"，因此最先进入的 `riddle1(8)` 最后打印——把打印按 $n=2,3,\cdots,8$ 从小到大列出即可；
2. **把 if-else 语义化**：条件 `a[n-1]<a[n-2]` 时打印 $a_{n-1}$，否则打印 $a_{n-2}$，两分支合起来恰是 $\min(a[n-2],a[n-1])$，于是逐对取小、不必逐个跟踪分支；
3. **`riddle2` 同样先递归后返回**，但返回值逐级上传：$riddle2(n)=\min(riddle2(n-1),a[n])$，基例是 $a[0]$，展开后比较集合是 $\{a[0],a[2],\dots,a[n]\}$（$a[1]$ 从未被比较，这是回忆版代码的原始写法，须如实指出）；
4. **越界检查**：$n=8$ ⟹ `a[8]` 不在数组内，源文数据有缺陷，回答时分两种口径说明（合法上界 $n=7$ 的结果 / $n=8$ 时行为未定义）；
5. **复杂度**：每层递归只做常数量工作（一次比较 + 一次打印或一次比较 + 一次返回），得 $T(n)=T(n-1)+c$ ⟹ $O(n)$。

## 6. 详细解答

### 6.1 riddle1 的递归展开

调用链（自外向内压栈）：

```
riddle1(8) → riddle1(7) → riddle1(6) → … → riddle1(2) → riddle1(1) 返回
```

`riddle1(1)` 命中 `n==1` 直接返回，不打印。由于打印语句在递归调用**之后**，输出按 $n=2,3,\cdots,8$ 的顺序产生：

| 打印时的 $n$ | 比较 $a[n-1]$ 与 $a[n-2]$ | 条件 $a[n-1]<a[n-2]$ | 打印值 |
|---|---|---|---|
| 2 | $a[1]=33$ vs $a[0]=23$ | 假（33>23） | $a[0]=23$ |
| 3 | $a[2]=16$ vs $a[1]=33$ | 真 | $a[2]=16$ |
| 4 | $a[3]=79$ vs $a[2]=16$ | 假 | $a[2]=16$ |
| 5 | $a[4]=34$ vs $a[3]=79$ | 真 | $a[4]=34$ |
| 6 | $a[5]=79$ vs $a[4]=34$ | 假 | $a[4]=34$ |
| 7 | $a[6]=29$ vs $a[5]=79$ | 真 | $a[6]=29$ |
| 8 | $a[7]=86$ vs $a[6]=29$ | 假 | $a[6]=29$ |

输出：`23 16 16 34 34 29 29 `（$7$ 个数，每个后一个空格）。

**语义核对**：打印值序列 $=\min(23,33),\min(33,16),\min(16,79),\min(79,34),\min(34,79),\min(79,29),\min(29,86)$ $=23,16,16,34,34,29,29$ ✓（与逐层表格一致，两种方法互验）。

### 6.2 riddle2 的递归展开

$$riddle2(1)=a[0]=23$$
$$riddle2(k)=\min(riddle2(k-1),\,a[k]),\quad k\ge 2$$

| $k$ | $p=riddle2(k-1)$ | $a[k]$ | 返回 $\min$ |
|---|---|---|---|
| 1 | — | $a[0]=23$ | 23 |
| 2 | 23 | $a[2]=16$ | 16 |
| 3 | 16 | $a[3]=79$ | 16 |
| 4 | 16 | $a[4]=34$ | 16 |
| 5 | 16 | $a[5]=79$ | 16 |
| 6 | 16 | $a[6]=29$ | 16 |
| 7 | 16 | $a[7]=86$ | 16 |
| 8 | 16 | $a[8]$ **越界** | 未定义 |

结论：$riddle2$ 试图"递归求数组最小值"，展开后被比较的是 $a[0]$ 与 $a[2..n]$，$a[1]=33$ 被跳过；合法调用上界应为 $n=7$（结果 $16$，恰为全数组最小值）。$n=8$ 时读 $a[8]$ 属数组越界，运行结果不可预期——这是源文数据缺陷，答题时应指出。该函数**没有输出语句**，故"输出结果"一问只能由 `riddle1` 满足。

### 6.3 时间复杂度

两者都满足 $T(n)=T(n-1)+c$（每层一次比较 + 一次打印/返回），$T(1)=c_0$：

$$T(n)=c_0+c(n-1)=O(n)$$

- $n=8$ 时 $riddle1$ 实际发生 $8$ 次函数调用（含直接返回的 $n=1$ 那层）、$7$ 次比较、$7$ 次打印；
- 空间：递归工作栈深度 $n$ ⟹ $O(n)$（$n=8$ 时 $8$ 个活动记录）。

## 7. 选项分析

不适用（程序阅读分析题）。

## 8. 考场标准答案

1. `riddle1(8)` 输出：`23 16 16 34 34 29 29`（先递归到 $n=1$ 再回溯打印，打印内容为相邻两元素的较小者，$n=2\sim8$ 共 $7$ 个）；
2. `riddle2` 无输出，$riddle2(n)=\min(a[0],a[2],\cdots,a[n])$，未比较 $a[1]$；取合法上界 $n=7$ 时返回 $16$；按 $n=8$ 调用会越界访问 $a[8]$，行为未定义（源文数据缺陷）；
3. 时间复杂度：$T(n)=T(n-1)+O(1)\Rightarrow T(n)=O(n)$；空间复杂度 $O(n)$（递归栈）。

## 9. 易错点

1. 把 `riddle1` 的打印顺序当成"$n$ 从大到小"——递归调用写在 `printf` 前，输出必为回溯时产生，即 $n$ 从小到大（写成 `86 29 79 34 79 16 33` 一类即为顺序反了）；
2. 误以为 `if-else` 打印的是较大者：两分支分别打印 $a[n-1]$（当它更小）与 $a[n-2]$（当它更小或相等），合起来是取**较小**值；
3. $n$ 与下标的换算：`riddle1` 用 $a[n-1],a[n-2]$（合法），`riddle2` 用 $a[n]$（$n=8$ 越界），两者不能混为一谈；
4. 忘记说明 $riddle2$ 没有输出语句，只答"输出 16"。

## 10. 一句话规律

递归程序阅读三步：定基例 → 看递归调用与输出的**先后位置**（调用在前则输出按规模从小到大，调用在后则相反）→ 把每层要访问的下标写成 $n$ 的函数并核对是否越界。

## 11. 关联知识

- 递归本质上是系统栈上的工作记录（DS02.07），"先调用后打印"对应深度优先式回溯；把 `riddle1` 的递归改写为 `for(i=2;i<=n;i++)` 即得等价的非递归版本，输出相同；
- $T(n)=T(n-1)+O(1)\Rightarrow O(n)$ 是最简递推，同型分析见 DS-2005-20（语句频度与时间复杂度）；
- 若两函数都要"求最小值"，`riddle2` 的正确写法应为 `if(p<a[n-1]) return p; else return a[n-1];`（下标统一为 $n-1$）。
