# DS-2026-16

## 1. 原题

**16、** 说明：回忆版综合应用题的序列、图不一定与考试一致，综合题顺序不一定一致

已知某二叉树的先序序列为 $ABCDEFG$ ，中序序列为 $BADCFEG$ 。

（1）画出该二叉树，并给出该二叉树的后序序列；

（2）画出该二叉树的三叉链表结构；

（3）画出该二叉树对应的树或森林。

> 订正说明转录：源文作"序列 图不一定与考试一致"，据题意补顿号为"序列、图"。该句为**回忆版不确定性备注**（置于"三、综合应用题"卷首，对本节 16~23 题通用）：先序/中序序列以及本节各题图形、题序均可能与考场实际不同，本解析按卷面给出的序列作答。

## 2. 答案

**（1）二叉树**

```
        A
       / \
      B   C
         / \
        D   E
           / \
          F   G
```

后序序列：$B\;D\;F\;G\;E\;C\;A$（写作 $BDFGECA$）。

**（2）三叉链表**：$7$ 个四域结点 `lchild | data | parent | rchild`，指针配置见第 6 节表（空链域共 $n+2=9$ 个）。

**（3）对应的森林**（该二叉树根结点有右孩子，故不对应一棵树而对应森林，共 $4$ 棵树）

```
森林 F = ( T1, T2, T3, T4 )

 T1: A       T2: C      T3: E      T4: G
     |           |          |
     B           D          F
```

## 3. 题目分析

- 已知：先序 $ABCD\to G$（$ABCDEFG$）与中序 $BADCFEG$，$7$ 个互异结点；
- 目标：三问层层递进——① 由两组遍历序列**还原**二叉树并导出第三种遍历；② 把还原出的逻辑结构落成**存储结构**（三叉链表）；③ 把二叉树按"左孩子右兄弟"逆变换成**树/森林**；
- 关键约束：
  1. 先序 + 中序（或后序 + 中序）可唯一确定一棵二叉树；先序与后序不能；
  2. 先序的首元素必为（子）树根，用它在中序中切分左、右子树；
  3. 三叉链表比二叉链表多一个 $parent$ 域，孩子链不变；
  4. 二叉树 → 树/森林 的法则：结点的**左孩子**是该结点在原树中的**第一个孩子**，**右孩子**是它的**下一个兄弟**；
- 命题意图：一次考完"遍历互推 → 存储结构 → 树与二叉树转换"三个 DS03 核心操作，属于结构类综合题的标准组合。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（由先序 + 中序确定二叉树、再求后序）

辅助考点：
DS03.02.02 二叉树的存储结构——三叉链表（$lchild/parent/rchild$ 三指针 + 数据域）的指针配置；
DS03.03.02 森林与二叉树的转换——本题是逆变换，且因根有右孩子而得到**森林**而非一棵树

解释：三问分别落在"遍历互推""存储结构""转换"三个节点上，正是一棵综合题的三块得分点；若只会第一问，后两问按定义亦可直接写出，故列两条辅助考点。

## 5. 解题思路

1. **定根切分**：先序首元素 $A$ 是根；在中序中 $A$ 左边 $B$ 是左子树的全部结点（$1$ 个），右边 $BADCFEG$ 去掉 $A$ 后的 $DCFEG$ 是右子树（$5$ 个）——"先序中左子树紧跟根、长度由中序切分结果决定"；
2. **递归下推**：右子树先序 $CDEFG$ → 根 $C$；中序 $DCFEG$ 中 $C$ 左有 $D$（左子树 $1$ 结点）、右有 $FEG$（$3$ 结点）；再对 $FEG$ 用先序 $EFG$ → 根 $E$，中序里 $F$ 在左、$G$ 在右；
3. **验证**：对画出的树写出先序、中序，与题面逐字符比对（这是防错的必要一步）；
4. **后序**：左→右→根递归，或直接用"先序/中序 → 后序"的递归切分；
5. **三叉链表**：把每条父子边填进 $lchild/rchild$，再反向填 $parent$，根结点 $parent=\wedge$；顺手用"空链域 $=n+2$"自检；
6. **森林**：沿根的右链 $A\to C\to E\to G$ 得到 $4$ 个树根，每个树根的children 由其左孩子沿右链展开。

## 6. 详细解答

### （1）还原二叉树并求后序

逐层切分（"先序剩余段的第一个 = 根；中序中根的左侧 = 左子树结点集"）：

| 步骤 | 先序段 | 中序段 | 根 | 左子树结点 | 右子树结点 |
|---|---|---|---|---|---|
| ① | $ABCDEFG$ | $BADCFEG$ | $A$ | $B$（$1$ 个） | $D,C,F,E,G$（$5$ 个） |
| ② | $B$ | $B$ | $B$ | 空 | 空 → $B$ 为 $A$ 的左孩子 |
| ③ | $CDEFG$ | $DCFEG$ | $C$ | $D$（$1$ 个） | $F,E,G$（$3$ 个） |
| ④ | $D$ | $D$ | $D$ | 空 | 空 → $D$ 为 $C$ 的左孩子 |
| ⑤ | $EFG$ | $FEG$ | $E$ | $F$ | $G$ → $F$ 左孩子、$G$ 右孩子 |

得二叉树：

```
        A            先序：A B C D E F G  ✓ 与题面一致
       / \           中序：B A D C F E G  ✓ 与题面一致
      B   C          后序：B D F G E C A
         / \
        D   E
           / \
          F   G
```

**后序序列**（左→右→根）：$B$（$A$ 的左子树）；$D$（$C$ 的左）；$F,G,E$（$E$ 的左、右、根）；$C$；$A$ ⟹

$$BDFGECA$$

### （2）三叉链表结构

结点类型（四域：左孩子、数据、双亲、右孩子，$\wedge$ 表示空指针）：

```c
typedef struct TriBox{
    struct TriBox *lchild, *parent, *rchild;
    ElemType data;
}TriBox, *TriTree;
```

指针配置表（结点编号按上图位置，便于对照）：

| 编号 | data | $lchild$ | $parent$ | $rchild$ |
|---|---|---|---|---|
| ① | $A$ | ②（$B$） | $\wedge$（根） | ③（$C$） |
| ② | $B$ | $\wedge$ | ①（$A$） | $\wedge$ |
| ③ | $C$ | ④（$D$） | ①（$A$） | ⑤（$E$） |
| ④ | $D$ | $\wedge$ | ③（$C$） | $\wedge$ |
| ⑤ | $E$ | ⑥（$F$） | ③（$C$） | ⑦（$G$） |
| ⑥ | $F$ | $\wedge$ | ⑤（$E$） | $\wedge$ |
| ⑦ | $G$ | $\wedge$ | ⑤（$E$） | $\wedge$ |

逻辑图（实线为 $lchild/rchild$，虚线为 $parent$，此处按"每结点四域"横排）：

```
  ∧ → [ ∧ | A | ∧  | C ]            （A 的 parent 域 = ∧）
          ↑________________↓ parent（由 C、B 的 parent 域指回）
  ∧ → [ ∧ | B | →A | ∧ ]
  ∧ → [ D | C | →A | E ]
  ∧ → [ ∧ | D | →C | ∧ ]
  ∧ → [ F | E | →C | G ]
  ∧ → [ ∧ | F | →E | ∧ ]
  ∧ → [ ∧ | G | →E | ∧ ]
```

**自检**：三叉链表每结点有 $3$ 个指针域，共 $3n=21$ 个。其中非空者两类：$lchild/rchild$ 恰对应树的 $n-1=6$ 条边（每条边被一个左/右孩子指针记一次），$parent$ 域对除根外的 $6$ 个结点各非空一次，故非空指针共 $6+6=12$ 个，空链域 $=21-12=9=n+2$ ✓（逐行数上表 $\wedge$：①$1$、②$2$、③$0$、④$2$、⑤$0$、⑥$2$、⑦$2$，合计 $9$ ✓）。

### （3）二叉树 → 森林

法则（左孩子右兄弟的逆用）：结点的**左孩子** $=$ 它在原树中的**第一个孩子**，结点的**右孩子** $=$ 它的**下一个兄弟**。

- 根 $A$ 有右孩子 $C$ ⟹ 该二叉树**不对应一棵树**，而对应森林；沿右链 $A\to C\to E\to G$ 得 $4$ 个树根；
- 各树根的孩子们（先取左孩子，再沿该孩子的右链找兄弟）：
  - $A$：左孩子 $B$，$B$ 无右孩子 ⟹ $A$ 只有孩子 $B$；
  - $C$：左孩子 $D$，$D$ 无右孩子 ⟹ $C$ 只有孩子 $D$；
  - $E$：左孩子 $F$，$F$ 无右孩子 ⟹ $E$ 只有孩子 $F$；
  - $G$：无左孩子 ⟹ $G$ 为单结点树。

```
   T1     T2     T3     T4
   A      C      E      G
   |      |      |
   B      D      F
```

结点总数核对：$2+2+2+1=7$ ✓；且 $T_1,T_2,T_3,T_4$ 的"孩子—兄弟"链正是原二叉树的左、右链，转换可逆。

## 8. 考场标准答案

**（1）** 二叉树同第 6 节图（$A$ 为根，左孩子 $B$，右孩子 $C$；$C$ 左 $D$ 右 $E$；$E$ 左 $F$ 右 $G$）；后序序列 $BDFGECA$。

**（2）** 三叉链表：$7$ 个四域结点，$lchild/rchild$ 按上图连，$parent$ 反向连，$A$ 的 $parent$ 为空；空链域共 $9$ 个。

**（3）** 根 $A$ 有右孩子，故对应森林 $F=(T_1,T_2,T_3,T_4)$：

$$T_1:\;A\text{（孩子 }B\text{）},\quad T_2:\;C\text{（孩子 }D\text{）},\quad T_3:\;E\text{（孩子 }F\text{）},\quad T_4:\;G$$

书写要点：先写"左孩子 = 第一个孩子、右孩子 = 下一个兄弟"的法则，再画 $4$ 棵树，最后可用"结点数守恒 $=7$"自检。

## 9. 易错点

1. **切分长度算错**：中序里 $A$ 的左侧有 $1$ 个结点 $B$，故先序中 $A$ 之后只能取 $1$ 个（$B$）作左子树，剩下 $CDEFG$ 全属右子树；若把 $C$ 误划给左子树，整棵树形态即错；
2. **误以为"根有右孩子"仍是一棵树**：二叉树对应**一棵树**的充要条件是根结点无右孩子；本题 $A$ 有右孩子 $C$，答案必须是森林，写成"树 $A$ 带孩子 $B,C$"是概念错误；
3. **森林转换时把右链孩子当自己的孩子**：$C$ 不是 $A$ 的孩子而是 $A$ 的兄弟（同为树根）；$D$ 才是 $C$ 的孩子；
4. **三叉链表漏 $parent$ 或只画根的反向指针**：$parent$ 域对**每个非根结点**都必须非空，共 $n-1=6$ 条；
5. 后序写成中序或层序：$BDFGECA$ 中 $E$ 必须在 $F,G$ 之后、$C$ 之前，$A$ 必须在最后。

## 10. 一句话规律

"先序定根、中序定界"还原二叉树后，一切后续问题（第三种遍历、存储结构、与树/森林的互转）都在这棵已确定的树上做**机械映射**；判断"是树还是森林"只看**根有没有右孩子**。
