# DS-2026-01

## 1. 原题

下面代码是关于深度优先生成树，请填写完整代码。图的邻接表存储结构及功能函数如下：

## 2. 答案

- (1) `G.vertices[v].firstarc`
- (2) `DFSTree(G, p->adjvex)`

## 3. 题目分析

- 已知：邻接表类型定义、外层扫描函数 `DFS_Tree`（对每个未访问顶点启动一次 `DFSTree`，处理非连通图）；
- 目标：补全"输出生成树边"的 DFS；
- 关键约束：与教材 `DFS` 唯一区别是——发现未访问邻接点时**先打印树边 `(v, p->adjvex)` 再递归**；
- 命题意图：考"邻接表遍历方式 + DFS 递归骨架 + 生成树边的判定（首次到达未访问点的边）"。

## 4. 核心考点

核心考点：
DS04.03.01 深度优先搜索（DFS 生成树）

辅助考点：
DS04.02.02 邻接表法（`firstarc/nextarc` 链表扫描）

解释：空 (1) 考邻接表取顶点 v 的第一条边；空 (2) 考 DFS 递归深入。生成树边即"把新顶点带入遍历的那些边"，故打印时机在递归调用前。

## 5. 解题思路

1. `p` 要沿 v 的边表扫描，初值必为边表头指针 → `G.vertices[v].firstarc`；
2. 找到未访问邻接点 `p->adjvex`：打印树边后必须**继续从它出发深探**（否则退化成 BFS/单层扫描）→ 递归 `DFSTree(G, p->adjvex)`；
3. 用教材 DFS 函数比对验证：结构一致，仅多了打印。

## 6. 详细解答

```c
void DFSTree(ALGraph G, int v)
{
    visited[v]=true;
    ArcNode *p=G.vertices[v].firstarc;      // (1) 取 v 的第一条边
    while(p!=NULL)
    {
        if(!visited[p->adjvex])
        {
            printf("Tree edge:%d %d\n",v,p->adjvex);
            DFSTree(G, p->adjvex);          // (2) 递归深探
        }
        p=p->nextarc;
    }
}
```

正确性说明：每个顶点恰在被首次发现时打印一条入边（根除外），共打印 $n-c$ 条边（$c$ 为连通分量数），恰为生成森林的边数 ✓。

**复杂度**（$n$ 为顶点数、$e$ 为边/弧数）：每个顶点访问一次，每条边（无向图两弧计一次入表）检查一次：时间 $O(n+e)$；空间（递归栈）最坏 $O(n)$。

## 8. 考场标准答案

(1) `G.vertices[v].firstarc`
(2) `DFSTree(G, p->adjvex)`

## 9. 易错点

1. (1) 写成 `G.vertices[v].data` 或漏 `.firstarc` 层级——邻接表是"顶点表 + 边表"两级结构；
2. (2) 误填 `visited[p->adjvex]=true`：置访标志在 `DFSTree` 开头已做，填它则不会继续深探，逻辑变成只打印 v 的一层树边。

## 10. 一句话规律

邻接表上的 DFS 模板：`for(p=firstarc; p; p=p->nextarc)` 扫边 + 对未访问邻接点递归；生成树边 = 首次到达未访问顶点的那条边。

## 11. 关联知识

- 把递归换成栈仍得 DFS；把 `while` 边扫描换成队列则得 BFS 生成树；
- 非连通图的 DFS 生成**森林**，外层 `for` 每个未访问顶点启动一次（本题 `DFS_Tree` 已给出）。
