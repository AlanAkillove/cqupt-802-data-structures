# DS-2026-24

## 1. 原题

**24、** 编号为 $1$ 到 $n$ 的 $n$ 个人围成一个圈，现从编号为 $s$ 的人开始按顺时针方向报数（从 $1$ 开始报），报到 $m$ 的人离开圈子。然后他的下一个人开始重新从 $1$ 开始报数，重复此过程，直到所有人都离开为止。

举例：$n=8,s=1,m=4$ ，离开次序为 $4,8,5,2,1,3,7,6$

要求使用链表实现，使用 $C$ 语言完成下列函数，关键之处给出注释。

```c
void joseph(int n,int s,int m)
```

（卷面本节无订正说明。）

## 2. 答案

**算法要点**：以**单循环链表**表示这 $n$ 个人（结点数据域存编号，指针域指向顺时针的下一个人）；用两个工作指针 $pre$（前驱）与 $cur$（当前报数者），每轮把 $cur$ 沿 $next$ 移动 $m-1$ 次即落到"报到 $m$"的人，输出其编号后用 $pre->next=cur->next$ 将其摘下，并令 $cur=pre->next$ 从下一个人重新开始报数；重复 $n$ 轮直到链表为空。

**运行结果**：`joseph(8,1,4)` 输出 `4 8 5 2 1 3 7 6`，与卷面样例一致 ✓

**复杂度**：时间 $O(n\times m)$（建表 $O(n)$ + $n$ 轮、每轮至多 $m-1$ 步移动 + $O(1)$ 删除）；空间 $O(n)$（$n$ 个链表结点）。

完整代码见第 6 节 / 第 8 节。

## 3. 题目分析

- 已知：$n$ 个编号 $1\sim n$ 的人首尾相接成圈；起点编号 $s$（$1\le s\le n$）；报数上限 $m$（$m\ge1$）；
- 输出：按**离开次序**依次输出各人编号（题面"完成下列函数"为 `void` 型，故以打印方式输出，不需返回结构）；
- 关键约束（决定实现的三条语义）：
  1. **圈是循环的**——报到末尾要回到开头，天然对应循环链表的"尾结点 $next$ 指向首结点"，无需任何取模运算；
  2. **报数从 $1$ 开始**——起点 $s$ 本人报 $1$，故"报到 $m$"是从 $s$ 起沿圈**移动 $m-1$ 步**到达的那个人（这是最容易差一步的地方）；
  3. **下一轮由出圈者的下一个人重新报 $1$**——删除结点后必须让"当前指针"停在被删结点的后继上，同时前驱指针要跟着修正；
  4. 题面要求"使用链表实现"，故不允许用数组 + 取模的下标模拟作为主解；
- 命题意图：考 DS01.02.03 循环链表的**建环、定位、删除**三个基本操作的综合运用，并检验"前驱指针"这一单链表删除的必要条件意识（循环单链表无 head 可依，必须自己维护 $pre$）。

## 5. 解题思路

1. **先把题意翻译成指针动作**：
   - "围成一个圈" ⟹ 建 $n$ 个结点的循环单链表；
   - "从 $s$ 开始" ⟹ 把 $cur$ 移到编号 $s$ 的结点，且 $pre$ 停在它的直接前驱；
   - "报到 $m$ 的人离开" ⟹ $cur$ 走 $m-1$ 步后删除；
   - "他的下一个人重新从 $1$ 报" ⟹ 删除后 $cur=pre->next$；
2. **为什么必须维护 $pre$**：单链表删除结点 $p$ 需要其前驱来改 $next$；循环表里也没有"表头可退"，所以 $pre$ 必须显式跟着走（每步 `pre=cur; cur=cur->next;`）；
3. **$pre$ 的初值**：建环后尾结点是首结点的逻辑前驱，故令 $cur$ 指向首结点、$pre$ 指向尾结点，再同步前移到编号 $s$；
4. **循环几轮**：人数递减，最稳妥的写法是"外部循环 $n$ 次"（或 `while (cur->next != cur)` 再补输出最后一人），两种都要保证最后一人被输出；
5. **用卷面样例自检**：$n=8,s=1,m=4$ 手工推一遍前三个出圈者（$4,8,5$）即可确认"走 $m-1$ 步"没有差一错误。

## 6. 详细解答

### 设计思想

把每个人抽象成一个只含编号与后继指针的结点，$n$ 个结点串成循环单链表。报数过程就是沿 $next$ 的**有限步移动**，出圈就是**单链表结点删除**。设 $cur$ 为当前正在报数的人、$pre$ 为 $cur$ 的前驱：

- 报数 $1$ 时 $cur$ 即起点，故报到 $m$ 者满足 $cur$ 从起点出发移动了 $m-1$ 步；
- 删除：$tmp=cur;\ pre->next=cur->next;\ cur=cur->next;$ 释放 $tmp$；删除后 $cur$ 恰为"下一个人"，即下一轮报 $1$ 者，$pre$ 不需额外修正（它已是新 $cur$ 的前驱）；
- 重复 $n$ 轮，每人恰好出圈一次。

### 存储结构定义

```c
typedef struct JSNode{
    int num;                     /* 人的编号 1..n */
    struct JSNode *next;         /* 顺时针方向的下一个人 */
}JSNode, *JSList;
```

### 算法代码（C 语言，教材风格）

```c
void joseph(int n, int s, int m)
{
    JSNode *first, *cur, *pre, *tmp;
    int i, k;

    if (n <= 0 || m <= 0 || s < 1 || s > n) return;    /* 非法输入直接返回 */

    /* ---------- （1）建立含 n 个结点的循环链表 1->2->...->n->1 ---------- */
    first = (JSNode *)malloc(sizeof(JSNode));
    first->num = 1;
    cur = first;
    for (i = 2; i <= n; i++) {
        tmp = (JSNode *)malloc(sizeof(JSNode));
        tmp->num = i;
        cur->next = tmp;                               /* 新结点接到尾部 */
        cur = tmp;
    }
    cur->next = first;            /* 关键：尾结点的 next 指向首结点，链表成环 */

    /* ---------- （2）定位报数起点 s：cur 指向 s，pre 为其前驱 ---------- */
    pre = cur;                    /* cur 现为尾结点，即首结点的前驱 */
    cur = first;
    while (cur->num != s) {       /* 沿环逐步前移，编号唯一故必停 */
        pre = cur;
        cur = cur->next;
    }

    /* ---------- （3）n 轮报数出圈 ---------- */
    for (k = n; k >= 1; k--) {    /* k：本轮开始前圈中剩余人数 */
        for (i = 1; i < m; i++) { /* 起点报 1，故报到 m 只需再走 m-1 步 */
            pre = cur;
            cur = cur->next;      /* 环状推进，无需取模 */
        }
        printf("%d ", cur->num);          /* 报到 m 的人离开圈子 */
        tmp = cur;
        pre->next = cur->next;    /* 关键：用前驱跳过 cur 完成删除 */
        cur = cur->next;          /* 下一个人重新从 1 开始报数 */
        free(tmp);                /* 释放已出圈结点 */
    }
    printf("\n");
}
```

**核心不变量**：每轮内层 `for` 开始时，$cur$ 指向"本轮报 $1$ 的人"、$pre$ 始终满足 $pre->next == cur$；内层循环结束时 $cur$ 恰为"报到 $m$ 的人"。删除后该不变量对新 $cur$ 依然成立（$pre->next$ 已指向新 $cur$），因此下一轮无需重新寻找前驱——这是本算法正确性的关键，也是 $pre$ 必须与 $cur$ 同步移动的原因。

### 样例走查（$n=8,\,s=1,\,m=4$）

| 轮 | 圈中剩余（从起点顺时针） | 报数过程（括号内为报的数） | 出圈者 | 下轮起点 |
|---|---|---|---|---|
| 1 | $1,2,3,4,5,6,7,8$ | $1(1)\,2(2)\,3(3)\,\underline{4(4)}$ | $4$ | $5$ |
| 2 | $1,2,3,5,6,7,8$ | $5(1)\,6(2)\,7(3)\,\underline{8(4)}$ | $8$ | $1$ |
| 3 | $1,2,3,5,6,7$ | $1(1)\,2(2)\,3(3)\,\underline{5(4)}$ | $5$ | $6$ |
| 4 | $1,2,3,6,7$ | $6(1)\,7(2)\,1(3)\,\underline{2(4)}$ | $2$ | $3$ |
| 5 | $1,3,6,7$ | $3(1)\,6(2)\,7(3)\,\underline{1(4)}$ | $1$ | $3$ |
| 6 | $3,6,7$ | $3(1)\,6(2)\,7(3)\,\underline{3(4)}$ | $3$ | $6$ |
| 7 | $6,7$ | $6(1)\,7(2)\,6(3)\,\underline{7(4)}$ | $7$ | $6$ |
| 8 | $6$ | $6(1)\,6(2)\,6(3)\,\underline{6(4)}$ | $6$ | — |

出圈次序 $4,8,5,2,1,3,7,6$ ✓ 与卷面"举例"完全一致。

注意第 $6$ 轮起就出现"同一人多次报数"（圈中人少于 $m$），第 $8$ 轮只剩一人——**单结点的自环**（$cur->next==cur$）也能被同一套代码正确处理，这正是循环链表写法相对"下标取模"在边界上的稳健之处。

### 边界与异常情况

1. $n\le0$、$m\le0$、$s\notin[1,n]$：函数开头统一判非法返回（也可打印错误信息，考场写出检查即可）；
2. $m=1$：内层 `for` 一次也不执行，$cur$ 即出圈者，退化为"从 $s$ 起顺时针依次出圈"，结果应为 $s,s+1,\dots,n,1,\dots,s-1$，代码不需特判；
3. $n=1$：建环时 `cur->next = first` 使首结点自指，$pre$ 初值即其自身，一轮后输出唯一编号，正确；
4. 结点必须**先保存再释放**（`tmp=cur; ... free(tmp);`），若先 `free(cur)` 再取 `cur->next` 则是悬空指针访问；
5. 循环轮数用 $k=n$ 递减而不是 `while(cur!=pre)` 之类的指针条件，可避免"剩最后一个结点时 $cur==pre$ 提前退出、漏输出最后一人"的经典错误。

### 复杂度分析

- 建循环链表：$n$ 次申请与链接，$O(n)$；定位起点：至多 $n-1$ 步，$O(n)$；
- 报数出圈：外层 $n$ 轮，内层每轮 $m-1$ 步移动，删除与释放各 $O(1)$，共 $O(n\times m)$；
- **时间 $O(n\times m)$，空间 $O(n)$**（$n$ 个结点）。若 $m$ 与 $n$ 同量级则为 $O(n^2)$。

## 8. 考场标准答案

**设计思想**：$n$ 个人用**循环单链表**表示，结点存编号、$next$ 指向顺时针下一个人。先建环，再让 $cur$ 定位到编号 $s$ 的结点、$pre$ 作其前驱；然后重复 $n$ 轮：每轮把 $cur$ 沿 $next$ 移动 $m-1$ 步（因起点报 $1$）落到"报到 $m$"的人，输出其编号，用 $pre->next=cur->next$ 删除该结点，并令 $cur=cur->next$ 使下一个人重新报 $1$。

**代码**：见第 6 节 `joseph` 函数（存储结构 `JSNode{num,next}`；三处关键注释为"尾结点指回首结点成环""前驱同步 $pre=cur$""用前驱删除并让后继重新报 $1$"）。

**运行示例**：`joseph(8,1,4)` 输出 `4 8 5 2 1 3 7 6`。

**复杂度**：时间 $O(n\times m)$，空间 $O(n)$。

## 9. 易错点

1. **走 $m$ 步而不是 $m-1$ 步**：题面明说"从 $1$ 开始报"，起点本人占掉报数 $1$，故内层循环条件是 `i < m`（共 $m-1$ 次移动）；写成 `i <= m` 时 $n=8,s=1,m=4$ 会输出 $5,1,6,\dots$，与题给样例不符——**考卷上应先用样例验一步**；
2. **忘记维护前驱 $pre$**：只移动 $cur$ 则删除时找不到前驱，要么改不成环、要么必须每次再从头遍历一圈（退化成 $O(n^2m)$）；
3. **建环后没有 $pre$ 指向首结点的前驱**：若令 `pre = first` 而 $s\ne1$，第一次删除会把 $first$ 的后继改错、丢一个结点；
4. **`free` 时机错**：先释放再使用 `cur->next` 属悬空指针；
5. **终止条件用 `cur != pre`**：只剩一个结点时 $pre==cur$ 会提前退出，最后一人永不输出；
6. 删除后忘记 `cur = cur->next`，下一轮从被删者重新开始，等于把同一个人报两次；
7. 把"顺时针"理解成编号增大方向即可，若反向建环则输出次序完全不同（本题按编号增大方向）。

## 10. 一句话规律

约瑟夫环 = **循环链表 + "走 $m-1$ 步删一个"**：起点占报数 $1$ 所以只走 $m-1$ 步；单链表删除必带前驱指针 $pre$，删除后 $cur$ 直接落到后继就天然满足"下一个人重新报 $1$"；写完一定用题面给的样例手推第一轮。
