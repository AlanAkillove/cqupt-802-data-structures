# DS-2026-03

## 1. 原题

假设有两个带头结点线性表 $A$ 和 $B$ ，它们的元素都是依值递增有序排列，并且分别表示两个集合，现要求另辟空间构成一个线性表 $C$ ，其元素为 $A$ 和 $B$ 中元素的交集，且表 $C$ 中的元素也依值递增有序排列。借助线性表 $A$ 空间存放线性表 $C$ ，请填写完整代码。

```c

{
    LNode *pa=A->next;
    LNode *pb=B->next;
    LNode *pc=A;
    LNode *temp;

    {

        {
            _____(2)_____;
            pc=pa;
            pa=pa->next;
            temp=pb;
            pb=pb->next;

        }
        else if(pa->data<pb->data)

            pa=pa->next;

        }
        else
        {

            pb=pb->next;
            free(temp);
        }
    }

    while(pb)
    {
        temp=pb;
        pb=pb->next;
        free(temp);
    }

    while(pa)
    {
        temp=pa;
        pa=pa->next;
        free(temp);
    }
    _____(3)_____;
    free(B);
    return OK;
}
```

## 2. 答案

- (1) `pa!=NULL && pb!=NULL`（等价写法 `pa && pb`）
- (2) `pc->next=pa`
- (3) `pc->next=NULL`

功能：求两个递增有序集合表的交集，结果链在 $A$ 的原结点空间上递增有序，$B$ 的结点全部释放。

## 3. 题目分析

- 已知：$A$、$B$ 均带头结点、元素值递增有序、代表集合（无重复元素）；`pa`/`pb` 指向两表当前数据结点，`pc` 指向结果表 $C$ 的**最后一个已确定结点**（初值为 $A$ 的头结点）；
- 目标：补全循环条件、"元素相等时把 $A$ 的该结点接入 $C$"的链接语句、以及循环结束后的收尾语句；
- 关键约束：代码骨架已定——相等分支中随后执行 `pc=pa; pa=pa->next;` 并 `free` 掉 $B$ 的相等结点，说明 $C$ **复用 $A$ 的结点**（题面"借助线性表 A 空间存放线性表 C"）；两个收尾 `while` 分别删除 $B$、$A$ 的剩余结点；
- 命题意图：考有序链表归并型操作（双指针同步后移）+ 原地重用结点空间 + 尾结点的 `next` 置空。

## 4. 核心考点

核心考点：
DS01.02.02 链式存储：单链表（头结点、`next` 改写、结点申请与释放、双指针扫描）

辅助考点：

解释：三个空全是单链表指针操作（循环终止条件、挂链、断链封口），故主考点落在单链表；"求交集且保持有序"是线性表应用的经典场景，作辅助考点。

## 5. 解题思路

1. 归并型双指针扫描的循环条件必为"两表都还有未处理结点"→ `pa && pb`（一旦任一表走完，交集不可能再增加）；
2. 逐分支核对 `pc` 的角色：`pc=pa` 在 (2) **之后**执行，说明 (2) 的作用是把 `pa` 结点接到 $C$ 的尾部，即 `pc->next=pa`；此时 `pa->next` 仍指向 $A$ 的后继，链没有断；
3. 核对删除分支是否需要改链：`pa<pb` 时删除的正是 `pc` 的后继（$C$ 尾部之后的第一个非交集结点），`pc->next` 由下一次相等时的 `pc->next=pa` 自动修正，因此不需要额外改链——这是本算法能省略前驱指针的原因；
4. 收尾：循环退出后剩余结点全部 `free`，$C$ 的最后一个结点仍带着指向已释放结点的 `next`，必须封口 → `pc->next=NULL`；最后 `free(B)` 释放 $B$ 头结点（骨架已给）。

## 6. 详细解答

补全后的代码（只列主体）：

```c
LNode *pa=A->next, *pb=B->next, *pc=A, *temp;   // pc：C 的尾结点，初为 A 的头结点

while(pa!=NULL && pb!=NULL)                     // (1)
{
    if(pa->data==pb->data)                      // 属于交集：保留 A 的结点
    {
        pc->next=pa;                            // (2) 挂到 C 尾部
        pc=pa;                                   // 尾指针后移
        pa=pa->next;
        temp=pb; pb=pb->next; free(temp);        // 释放 B 中的重复结点
    }
    else if(pa->data<pb->data)                  // A 的小者不属于交集，删除
    { temp=pa; pa=pa->next; free(temp); }
    else                                        // B 的小者不属于交集，删除
    { temp=pb; pb=pb->next; free(temp); }
}
while(pb){ temp=pb; pb=pb->next; free(temp); }   // 清空 B 剩余
while(pa){ temp=pa; pa=pa->next; free(temp); }   // 清空 A 剩余（不属于交集）
pc->next=NULL;                                   // (3) C 封口
free(B);                                          // 释放 B 的头结点
```

**手工推演**（$A=\{1,3,5,7,9,11\}$，$B=\{2,3,5,8,9,10\}$，应得 $C=\{3,5,9\}$）：

| 步 | pa | pb | 分支 | 动作 | pc | C 链 |
|---|---|---|---|---|---|---|
| 1 | 1 | 2 | pa<pb | free(1) | 头 | 头 |
| 2 | 3 | 2 | pa>pb | free(2) | 头 | 头 |
| 3 | 3 | 3 | == | `头->next=3`，free(B 的 3) | 3 | 头→3 |
| 4 | 5 | 5 | == | `3->next=5`（原本即 5，恒等） | 5 | 头→3→5 |
| 5 | 7 | 8 | pa<pb | free(7) | 5 | 头→3→5 |
| 6 | 9 | 8 | pa>pb | free(8) | 5 | 头→3→5 |
| 7 | 9 | 9 | == | `5->next=9`，free(B 的 9) | 9 | 头→3→5→9 |
| 8 | 11 | 10 | pa>pb | free(10)，pb=NULL | 9 | 头→3→5→9 |
| 退出 | 11 | NULL | (1) 假 | `while(pa)` free(11) | 9 | 头→3→5→9 |
| (3) | | | | `9->next=NULL` | | 头→3→5→9→NULL |

检查：(3) 之前 `pc=9` 的 `next` 仍指向已被 `free` 的结点 11，若不封口就是悬链（野指针），故 (3) 必不可少 ✓；结果严格递增有序 ✓；$B$ 的数据结点与头结点全部释放，$A$ 的非交集结点释放，无泄漏 ✓。

**复杂度**（$m=|A|$、$n=|B|$）：每次循环至少推进一个指针，时间 $O(m+n)$；不申请新结点，附加空间 $O(1)$。

## 8. 考场标准答案

(1) `pa!=NULL && pb!=NULL`
(2) `pc->next=pa`
(3) `pc->next=NULL`

## 9. 易错点

1. (1) 写成 `pa->next && pb->next`：会漏掉两表最后一个元素可能属于交集的情况（上例中 9 恰在 $B$ 的末位之前，若 $A$、$B$ 末元素相同则直接丢解）；
2. (2) 误填 `pc->next=pa; pc=pa` 之外的形式（如 `pc=pc->next`）：`pc` 必须先由 `pa` 定位，直接后移会让 `C` 与 `A` 脱钩；
3. (3) 忘写 `pc->next=NULL`：尾结点指向已 `free` 的内存，遍历结果表时越界；
4. 误按"另辟空间"另建新结点：与骨架中 `free(temp)`（释放 $B$ 相等结点、释放 $A$ 非交集结点）矛盾，本算法必须复用 $A$ 的结点。

## 10. 一句话规律

有序链表做集合运算（交/并/差）就是双指针同步后移：比大小决定"谁被丢弃"、相等决定"谁被保留"；结果若复用某表空间，收尾必须对尾结点 `next` 置空，并把两表余下结点逐一释放。

## 11. 关联知识

- 同型操作：并集（相等时保留一个、另一表结点与余下结点都要处理）、差集 $A-B$（相等时两边同时删）；
- 双指针"比大小定去留"的代价分析在选择题中也出现过：两个各有 $n$ 个元素的有序表归并，最少比较 $n$ 次（DS-2005-22、DS-2007-05），交集同理只需一趟线性扫描；
- 单链表单趟遍历完成判定/改造的写法可对照 DS-2006-43（判断单链表是否为 fibonacci 序列）；
- 若要求"另辟空间"版本，则需 `malloc` 新结点并以 `pc->next=newNode` 建链（对照记忆本题的原地版本）；
- 头结点的作用：使 $C$ 的建链对第一个元素与后续元素统一处理（`pc` 初值为头结点即为此）。
