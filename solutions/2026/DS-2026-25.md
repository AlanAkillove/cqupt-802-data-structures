# DS-2026-25

## 1. 原题

**25、** 设一棵二叉树中的各结点的值互不相同，其先序遍历序列和中序遍历序列分别存在两个一维数组 $A[1,\cdots,n]$ 和 $B[1,\cdots,n]$ 中，试编写算法建立该二叉树的二叉链表，使用 $C$ 语言，关键之处给出注释。

二叉树的链式存储结构描述如下：

```c
typedef struct BiTNode{
    ElemType data;
    struct BiTNode *lchild,*rchild;
}BiTNode,*BiTree;
```

（卷面本节无订正说明。）

## 2. 答案

**算法思想**：先序序列的**第一个元素是根**；在中序序列中找到该根，其**左侧全部是左子树的结点、右侧全部是右子树的结点**，由此定出左子树结点个数 $lcnt$，从而把两个数组同时切成对应左、右子树的两段，递归建之。

**函数原型**：`BiTree Build(ElemType A[], ElemType B[], int n)`（内部调用带区间参数的递归函数 `BuildSub(A, as, B, bs, len)`）。

**复杂度**：时间 $O(n^2)$，附加空间 $O(n)$（递归栈最坏 $O(n)$）。

完整代码与走查见第 6 节、第 8 节。

## 3. 题目分析

- 已知：两个长度均为 $n$ 的一维数组，$A[1..n]$ 为先序序列、$B[1..n]$ 为中序序列；**各结点的值互不相同**（题面给定，这是"先序 + 中序能唯一确定一棵二叉树"的必要条件）；
- 输出：对应的二叉链表（`BiTree` 根指针），每个结点由 `malloc` 生成，叶子结点的 `lchild`、`rchild` 必须为 `NULL`；
- 关键约束：
  1. 递归的三段信息是"**先序起点 $as$ + 中序起点 $bs$ + 段长 $len$**"，只要这三者确定，子问题就唯一确定，不需要传整个数组下标区间；
  2. 划分依据只能是**中序**（先序只给出根，不能划分左右），故必须在中序段内**查找** $A[as]$，得到 $k$；
  3. $lcnt=k-bs$ 是左右子树长度的唯一来源；右子树长度 $=len-1-lcnt$，两者之和应为 $len-1$（自检式）；
  4. 递归出口：$len\le 0$ 返回 `NULL`（对应"空子树"），这保证叶子的两个孩子指针被正确置空；
- 命题意图：考 DS03.02.03 中"由遍历序列确定二叉树"这一性质的**算法化**——不是纸上画树，而是把它写成对数组下标的递归划分，同时检验 DS03.02.02 二叉链表的建结点操作与孩子指针置空是否严谨。

## 5. 解题思路

1. **先写小规模实例**：拿 $3$ 个结点（如先序 `ABC`、中序 `BAC`）在纸上确认"$A[1]$ 是根、中序里根左边 $1$ 个 ⟹ 左孩子 $1$ 个"，把直觉固定下来；可直接沿用本卷 DS-2026-16 的 $7$ 结点例子做完整走查；
2. **确定递归参数**：与其传 $[low,high]$ 两段四个下标，不如传"起点 + 长度"（$as,bs,len$），因为两段的长度相同、都是 $len$，少一个参数少一处出错；
3. **找根的位置**：值互不相同但**无序**，中序段内只能顺序查找，写一个 `Locate` 辅助函数；这一步是 $O(len)$，也是总复杂度 $O(n^2)$ 的来源；
4. **递归两支**：左支 `BuildSub(A, as+1, B, bs, lcnt)`；右支 `BuildSub(A, as+1+lcnt, B, k+1, len-1-lcnt)`——先序右段的起点必须是"$as$ 跳过根、跳过整个左段"，这是唯一需要小心的下标算式；
5. **回验**：对建好的树重新做先序与中序遍历，应与 $A$、$B$ 逐位相同（充分且必要，因为值互异时两种序列唯一确定树形）。

## 6. 详细解答

### 正确性依据（两条定义 + 一条归纳）

- 先序定义：$A[\text{段首}]$ 是该段所表示子树的**根**；
- 中序定义：在 $B$ 中，根把该段分成"左子树的全部结点"与"右子树的全部结点"，且**左段长度就是左子树结点数**；
- 归纳：设长度 $<len$ 的段都能正确建树。长度为 $len$ 的段，根为 $A[as]$，左子树结点集为 $B[bs..k-1]$（共 $lcnt=k-bs$ 个）、右子树结点集为 $B[k+1..bs+len-1]$（共 $len-1-lcnt$ 个）；先序中紧随根的 $lcnt$ 个元素恰是左子树结点（先序"根左右"），其后 $len-1-lcnt$ 个恰是右子树结点，故两个递归子问题都满足"先序段与中序段对应同一棵子树"，规模严格小于 $len$，由归纳假设正确 ⟹ 整树正确。$len=0$ 返回空树、$len=1$ 生成叶子，均在归纳基础上成立。

### 代码（C 语言，教材风格）

```c
typedef struct BiTNode{
    ElemType data;
    struct BiTNode *lchild,*rchild;
}BiTNode,*BiTree;

/* 在 B[bs .. bs+len-1] 中顺序查找值 x，返回其下标；未找到返回 0 */
int Locate(ElemType B[], int bs, int len, ElemType x)
{
    int i;
    for (i = bs; i < bs + len; i++)
        if (B[i] == x) return i;        /* 值互不相同，找到即可返回 */
    return 0;                           /* 0 表示非法（两序列不匹配） */
}

/* 由先序段 A[as .. as+len-1] 与中序段 B[bs .. bs+len-1] 建立一棵子树，返回根指针 */
BiTree BuildSub(ElemType A[], int as, ElemType B[], int bs, int len)
{
    BiTree t;
    int k, lcnt;

    if (len <= 0) return NULL;          /* 递归出口：空子树，保证孩子指针被置空 */

    t = (BiTNode *)malloc(sizeof(BiTNode));
    if (t == NULL) exit(1);             /* 分配失败 */
    t->data = A[as];                    /* 关键 1：先序段首元素是子树根 */

    k = Locate(B, bs, len, A[as]);      /* 关键 2：在中序段中定位根 */
    if (k == 0) { free(t); return NULL; }   /* 序列不匹配，输入非法 */

    lcnt = k - bs;                      /* 关键 3：根左侧的个数 = 左子树结点数 */

    t->lchild = BuildSub(A, as + 1,      B, bs,      lcnt);
    t->rchild = BuildSub(A, as + 1 + lcnt, B, k + 1, len - 1 - lcnt);
    /* 左段：先序从 as+1 起取 lcnt 个；右段：先序跳过根与左段，即 as+1+lcnt 起 */
    return t;
}

/* 题面要求的入口：A[1..n] 先序、B[1..n] 中序 */
BiTree Build(ElemType A[], ElemType B[], int n)
{
    if (n <= 0) return NULL;            /* 空树 */
    return BuildSub(A, 1, B, 1, n);
}
```

**说明**：`ElemType` 按题面未指定具体类型，上例以可 `==` 比较的类型（`char`/整数）为准；若为字符串需改用 `strcmp`。

### 走查示例（沿用本卷 DS-2026-16 的数据）

先序 $A=$ `A B C D E F G`（下标 $1\sim7$），中序 $B=$ `B A D C F E G`。

| 调用 | $as$ | $bs$ | $len$ | 根 $A[as]$ | $k$ | $lcnt=k-bs$ | 右段长度 $len-1-lcnt$ |
|---|---|---|---|---|---|---|---|
| ① | $1$ | $1$ | $7$ | `A` | $2$ | $1$ | $5$ |
| ② 左 | $2$ | $1$ | $1$ | `B` | $1$ | $0$ | $0$ |
| ③ 右 | $3$ | $3$ | $5$ | `C` | $4$ | $1$ | $3$ |
| ④ | $4$ | $3$ | $1$ | `D` | $3$ | $0$ | $0$ |
| ⑤ | $5$ | $5$ | $3$ | `E` | $6$ | $1$ | $1$ |
| ⑥ | $6$ | $5$ | $1$ | `F` | $5$ | $0$ | $0$ |
| ⑦ | $7$ | $7$ | $1$ | `G` | $7$ | $0$ | $0$ |

建树结果：

```
            A
          /   \
        B       C
               / \
              D   E
                 / \
                F   G
```

（表中每次"右段长度为 $0$"都对应一次 `len<=0 → NULL` 的递归返回，因此 $B,D,F,G$ 四个叶子的孩子指针均为 `NULL`。）

**回验**：对该树作先序遍历得 `A B C D E F G` ✓，作中序遍历得 `B A D C F E G` ✓，与题给数组逐位相同；该树的后序为 `B D F G E C A`，与本卷 DS-2026-16 第（1）问答案一致（三处相互印证）。

**另一组自检**（$len=3$ 的退化情形）：先序 `ABC`、中序 `CBA` ⟹ 根 `A`，$k=1$，$lcnt=0$，右段长 $2$；递归得 `A` 无左孩子、右孩子 `B`，`B` 的右孩子 `C`——是一条左斜…实为**右单支**树，与"中序倒序 ⟹ 所有结点只有右孩子"的规律吻合 ✓。

### 复杂度分析

- **时间**：每层递归对段长 $len$ 作一次 $O(len)$ 的顺序查找，加上 $O(1)$ 建结点；设 $T(len)=T(lcnt)+T(len-1-lcnt)+c\cdot len$。
  - 最坏（每次 $lcnt=0$，树退化为单支）：$T(n)=T(n-1)+cn \Rightarrow O(n^2)$；
  - 最好（每次均分）：$T(n)=2T(n/2)+cn=O(n\log n)$；
  - 故按上界记 **$O(n^2)$**。若允许附加空间，可先建立"值 $\to$ 中序下标"的定位表把查找降为 $O(1)$，总时间降为 $O(n)$（属优化写法，考场写出 $O(n^2)$ 并正确分析即可）；
- **空间**：$n$ 个结点占 $O(n)$；递归深度等于树高，最坏 $O(n)$、最好 $O(\log n)$，故附加空间 $O(n)$。

### 边界与异常情况

1. $n=0$（空树）：入口函数直接返回 `NULL`；
2. $len=1$：$k=bs$、$lcnt=0$、右段长 $0$，两次递归均返回 `NULL`，生成一个叶子——**孩子指针必须显式置 `NULL`**，否则是新结点的随机值（本实现靠递归返回值天然满足）；
3. 两序列不匹配（如中序段内找不到根 $A[as]$）：`Locate` 返回 $0$ 并释放已分配结点，避免内存泄漏与后续越界；
4. 结点值**有重复**时题设被破坏，树形不唯一，本算法只给出其中一种可能形态——须在卷面注明"依题设各结点值互不相同"；
5. 数组下标从 $1$ 开始（题面 $A[1..n]$），代码中所有区间均以 $1$ 基书写，若改用 $0$ 基需整体平移，不要混用；
6. `malloc` 返回值判空、`free` 失败分支——考场代码写出判空即算严谨。

## 8. 考场标准答案

**基本设计思想**：先序序列的首元素是子树根；在中序序列中定位该根，其左侧结点构成左子树、右侧结点构成右子树，左段长度即为左子树结点数 $lcnt$；据此把两个数组各切成对应左右子树的两段，递归执行，段长为 $0$ 时返回空指针。

**代码**：见第 6 节的 `Locate`、`BuildSub`、`Build`（三处关键注释为"先序段首元素是根""在中序段中定位根""根左侧个数即左子树结点数"，右子树的先序段起点为 $as+1+lcnt$）。

**复杂度**：时间 $O(n^2)$（每层一次线性查找，最坏树退化为单支；平衡时 $O(n\log n)$），空间 $O(n)$（$n$ 个结点 + 深度至多 $n$ 的递归栈）。

## 9. 易错点

1. **右子树的先序起点写成 $as+2$ 或 $as+lcnt$**：正确是 $as+1+lcnt$（跳过根自己、再跳过整段左子树）；写错会整棵子树错位；
2. **用先序去划分左右**：先序中"根的右侧"并不等于"左子树全部结点"（左子树的子孙也紧跟其后），**只有中序能划分**；
3. **右段长度算错**：右段长 $=len-1-lcnt$（要除去根自己）。常见的错写 $bs+len-k$ 实际等于 $len-lcnt$，比正确值多 $1$，会使右子树多吞一个结点、最终树比原树多一层；
4. **忘记空段返回 `NULL`**：少了 `if (len<=0) return NULL;`，叶子孩子指针未置空，遍历时崩溃或死循环；
5. **递归出口写成 `if (len==1)` 单独处理**：虽可特殊正确，但会漏掉 $len=0$ 的分支，导致孩子指针悬空；统一用 $len\le0$ 返回空最稳；
6. 忘记题设"值互不相同"是**必要条件**：若值可重复，先序 + 中序不能唯一确定二叉树，算法返回的形态依赖查找顺序（此时应说明口径）。

## 10. 一句话规律

"由两种遍历序列建树"的递归模板：**取一个序列的端点作根 → 到另一个序列里定位它 → 用左边个数定左右段长 → 两个序列同步切段递归**；先序（或后序）负责"给根"，中序负责"分左右"，时间代价全在"定位根"的线性查找上。
