# DS-2019-07

## 1. 原题

假设一个有 $n$ 个顶点和 $e$ 条弧的有向图用邻接表表示，则删除与某个顶点 $v_i$ 相关的所有弧的时间复杂度是（）。

A. $O(n)$

B. $O(e)$

C. $O(n+e)$

D. $O(n\times e)$

## 2. 答案

**C**（$O(n+e)$）

## 3. 题目分析

- 已知：有向图，$n$ 个顶点、$e$ 条弧，采用**邻接表**表示——每个顶点一个表头结点，其后挂的是**以该顶点为弧尾**（即从它出发）的边结点，结点数合计 $e$；
- 目标：删除"与顶点 $v_i$ 相关的所有弧"，即删除**所有以 $v_i$ 为尾的弧**（出边）**和所有以 $v_i$ 为头的弧**（入边），求所需时间量级；
- 关键约束：邻接表只能沿"出边"方向高效访问；要找出"以 $v_i$ 为头"的弧，必须到其他顶点的链表里逐个查 $adjvex$ 字段；
- 命题意图：考"**邻接表的访问方向性**"——它把出边信息集中、把入边信息打散，因此"删除相关弧"必然包含一次全表扫描。选项 A（$O(n)$）是**邻接矩阵**下的同类操作代价，属定向干扰。

## 4. 核心考点

核心考点：
DS04.02.02 邻接表法——表头向量 $n$ 个结点、边链表共 $e$ 个边结点；有向图的邻接表只存出边，入边需遍历所有链表

辅助考点：
DS04.02.01 邻接矩阵法——与本题对比：矩阵中删一行一列只需 $O(n)$，正是干扰项 A 的来源

解释：本题不需要遍历算法或具体操作实现，考的是"在某种存储结构上完成某操作的代价"，因此主归存储结构节；同时"删同一批弧，两种结构代价不同"是典型的存储结构比较（能力标签加 `COMPARISON`），故列 DS04.02.01 为辅助。

## 5. 解题思路

1. 把"与 $v_i$ 相关的弧"**拆成两部分**：出边集合 $\{(v_i,v_j)\}$ 与入边集合 $\{(v_k,v_i)\}$——这一步是全部关键，只算出边会误选 A/B；
2. 出边部分：$v_i$ 的整个边链表就是要删的东西，摘除表头并释放链上结点，代价 $=1+$ 出度$(v_i)$；
3. 入边部分：以 $v_i$ 为头的弧分散在**其他顶点的边链表**中，只能把 $n-1$ 条链表全部走一遍，检查每个边结点的 $adjvex$ 是否为 $i$，代价 $=(n-1)+\sum_{k\ne i}\text{出度}(v_k)$；
4. 两部分相加：表头访问合计 $n$ 次，边结点合计至多 $e$ 个 ⟹ $O(n+e)$；
5. 用三类极端情形自检：① 星形（$v_i$ 出度 $=e=n-1$、无入边）⟹ 仍需走一遍表头，操作数 $\approx 2n$ ，量级 $n$；② $v_i$ 出度 0、入度 $=n-1$ 且无其余弧（$e=n-1$）⟹ 必须扫完 $n-1$ 条链表才能定位那些指向 $v_i$ 的弧，量级 $n$；③ 稠密情形（$e=\Theta(n^2)$） ⟹ 被边结点项主导，量级 $e$。三类合起来即与图形态无关的上界 $O(n+e)$。

想到这一点的线索：邻接表 + "与某顶点相关"这类措辞，第一反应就是"**入边要找遍所有链表**"，因此必含 $e$ 项；再加上表头 $n$ 项，答案只能是 $O(n+e)$。

## 6. 详细解答

**存储结构约定**：邻接表由 $n$ 个表头结点 $head[0\cdots n-1]$ 组成，$head[k]$ 的边链表每个结点形如

```c
typedef struct ArcNode{
    int adjvex;              // 该弧指向的顶点（弧头）
    struct ArcNode *nextarc;
} ArcNode;
```

$head[k]$ 挂的是所有 $\langle v_k, v_j\rangle$（以 $v_k$ 为**尾**的弧），全部边结点个数恰为 $e$。

**第一部分：删去以 $v_i$ 为尾的弧**

`p = head[i].firstarc;` 逐个 `free` 到链尾，再置 `head[i].firstarc = NULL`。
执行次数 $=$ 出度$(v_i)$，记 $d^+(v_i)$，即 $O(1+d^+(v_i))$。

**第二部分：删去以 $v_i$ 为头的弧**

这些弧存在于别的链表里，形如某 $head[k]$ 链表中 $adjvex=i$ 的结点。要找到它们，须对每个 $k\ne i$ 走完整条链表：

$$T_{\text{入}}=\sum_{k\ne i}\big(1+d^+(v_k)\big)=(n-1)+\sum_{k\ne i}d^+(v_k)$$

其中 $\sum\limits_{k\ne i}d^+(v_k)\le \sum\limits_{k}d^+(v_k)=e$。故 $T_{\text{入}}=O(n+e)$。

**合并**

$$T=O\big((1+d^+(v_i))+(n-1)+\sum_{k\ne i}d^+(v_k)\big)=O(n+e)$$

（因为 $1+d^{+}(v_i)\le 1+e$，被 $n+e$ 吸收。）所以时间复杂度为 $O(n+e)$，选 C。

**自我验证（两个具体图代入计数）**

- 例 1：$n=4$，弧集 $\{\langle1,2\rangle,\langle1,3\rangle,\langle1,4\rangle,\langle2,4\rangle,\langle3,4\rangle\}$，$e=5$，删与 $v_1$ 相关的弧。出边 3 条（链 1 上 3 个结点）；入边：走链 2、链 3、链 4，检查结点 $\langle2,4\rangle,\langle3,4\rangle,\;$(链4 空) 共 2 个结点 $+$ 3 个表头 $=5$ 次基本操作，总计 $3+5=8$ 次；$n+e=9$，$\max(n,e)=5$ ⟹ 落在 $O(n+e)$ 内且明显超过 $n=4$、接近 $n+e$ ✓
- 例 2：$n$ 个顶点、$e=n-1$ 条弧构成一棵以 $v_1$ 为根的出边树（$\langle 1,2\rangle,\langle 1,3\rangle,\cdots$）。删与 $v_1$ 相关的弧：出边 $n-1$ 个结点全删，入边为 0 但须查遍 $n-1$ 个空表头 ⟹ 约 $2n-2$ 次 $=O(n)$；此时 $n+e=2n-1$，仍为 $O(n+e)$ 的正确上界（说明本题问的是**该操作在该存储结构下的通用代价**，取与图形态无关的最紧上界 $O(n+e)$）。

**对照邻接矩阵（说明 A 的来源）**：若用邻接矩阵 $A[0\cdots n-1][0\cdots n-1]$，删与 $v_i$ 相关的所有弧只需把第 $i$ 行（出边）与第 $i$ 列（入边）清零，共 $2n$ 次赋值 ⟹ $O(n)$，与 $e$ 无关。这正是选项 A 的由来，也说明"$O(n)$"不是邻接表的答案。

## 7. 选项分析

- A（$O(n)$）：错。这是**邻接矩阵**下的代价（删一行一列）；邻接表要定位入边必须遍历边结点，边结点总数是 $e$，不能被 $n$ 吸收；
- B（$O(e)$）：错。漏了表头向量：即使 $e=0$（空图）也要检查/访问 $n$ 个表头才能确认没有相关弧，故必须含 $n$ 项。当 $n\gg e$（稀疏到极端）时 $O(e)$ 是低估；
- C：正确。$O(n+e)$ = 扫一遍所有表头（$n$）＋扫一遍所有边结点（$\le e$）；
- D（$O(n\times e)$）：错。只有采用"每删一条入边就从头重扫全部链表"的低效实现，或对每个 $k$ 都重复整表遍历，才可能得到 $n\cdot e$；正确的一次遍历写法不会超过 $n+e$。该选项考的是"是否会把遍历做重复"。

## 8. 考场标准答案

有向图的邻接表**只存出边**，故：

- 删以 $v_i$ 为尾的弧：释放 $head[i]$ 的边链表，$O(d^+(v_i))$；
- 删以 $v_i$ 为头的弧：必须遍历其余 $n-1$ 个链表，检查每个边结点的 $adjvex$，$O\big((n-1)+\sum_{k\ne i}d^+(v_k)\big)=O(n+e)$。

合计 $O(n+e)$，**选 C**。（对照：邻接矩阵下同操作为 $O(n)$；逆邻接表/十字链表可把入边操作降为只扫 $v_i$ 的一条入边链。）

## 9. 易错点

1. 只删"出边"就以为完成（得 $O(e)$ 或 $O(n)$）——题面"与该顶点**相关**的所有弧"包含入边，这是本题的胜负点；
2. 忘记邻接表本身还要访问表头向量，漏掉 $n$ 项而选 B；
3. 混淆"求度数"与"删弧"：在有向图邻接表上求 $v_i$ 的**入度**同样要 $O(n+e)$（遍历所有链表），求**出度**只要 $O(d^+(v_i))$；
4. 把无向图情形套进来：无向图邻接表中一条边占**两个**边结点，删与 $v_i$ 关联的所有边仍需遍历所有链表（$O(n+e)$ 结论不变，但边结点总数为 $2e$）。

## 10. 一句话规律

凡在**有向图邻接表**上做"与该顶点相关"的操作（删弧、求入度、找前驱），代价都是"扫一遍表头 ＋ 扫一遍所有边结点" $=O(n+e)$；只有"沿出边方向"的操作才能降到该顶点链表的长度。
