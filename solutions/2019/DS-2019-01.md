# DS-2019-01

## 1. 原题

对于双向循环链表，每个结点有两个指针域 $next$ 和 $prior$ ，分别指向前驱和后继。在 $p$ 指向的结点之后插入 $s$ 指针所指结点的操作应为（）。

A. `p->next = s; s->prior = p; p->next->prior = s; s->next = p->next;`

B. `p->next = s; p->next->prior = s; s->prior = p; s->next = p->next;`

C. `s->prior = p; s->next = p->next; p->next = s; p->next->prior = s;`

D. `s->prior = p; s->next = p->next; p->next->prior = s; p->next = s;`

## 2. 答案

**D**

## 3. 题目分析

- 已知：双向循环链表，结点含 $next$（指向后继）与 $prior$（指向前驱）两个指针域；$p$ 指向链中某结点，$s$ 指向待插入的新结点；
- 目标：选出能把 $s$ 插到 $p$ 之后的**正确语句次序**；
- 关键约束：插入后要同时满足 4 条链关系——$p\to next=s$、$s\to prior=p$、$s\to next=q$、$q\to prior=s$（其中 $q$ 是 $p$ 的**原**后继）；且赋值语句是**有顺序的**，前一条会改变后一条所读取的存储位置；
- 命题意图：表面是"背一段插入代码"，实质考"**指针改写的读写依赖顺序**"——凡要读 $p\to next$ 的旧值，必须在改写 $p\to next$ 之前完成；凡要写 $q\to prior$，也必须借旧 $p\to next$ 找到 $q$。这是链表操作最常见的越界/断链错误来源。

## 4. 核心考点

核心考点：
DS01.02.03 链式存储：双向链表与循环链表（含双向循环）——双向链表插入需修改 4 个指针域，且互为读依赖

辅助考点：
DS01.02.01/DS01.02.02 中的"先用后改"原则同样适用于单链表插入（此处只借用其读依赖思想），故列 DS01.02.02 为辅助

解释：本题不涉及双向循环链表特有的判空/终止条件（如 `p->next==head`），核心矛盾全在"**双向**链表一次要改 4 个指针、其中两个必须读 $p\to next$ 的旧值"，因此归 DS01.02.03。循环性与头结点并不影响插入语句本身，只是题目给定的场景。

## 5. 解题思路

1. 先把"应达到的终态"画出来：设 $p$ 的原后继为 $q$，插入后应为 $\cdots \leftrightarrows p \leftrightarrows s \leftrightarrows q \leftrightarrows \cdots$，即 4 个赋值 $s\to prior=p$、$s\to next=q$、$q\to prior=s$、$p\to next=s$，一个都不能少；
2. 找出**读依赖**：$q$ 只能通过旧 $p\to next$ 得到，所以凡含 `p->next`（作右值）或 `p->next->prior` 的语句，都必须排在 `p->next = s;` **之前**；
3. 用这一条先淘汰"第一条就是 `p->next = s;`"的 A、B（旧 $q$ 一丢，后面两条都无法正确执行）；
4. 剩下 C、D 比较：C 把 `p->next->prior = s;` 放在 `p->next = s;` 之后，此时 `p->next` 已是 $s$，该语句变成 `s->prior = s`，把第 1 步刚设好的 $s\to prior=p$ 覆盖掉，且 $q$ 的 $prior$ 始终没改 → 淘汰 C；
5. D 次序为"先填 $s$ 的两个域 → 再改 $q\to prior$（趁 $p\to next$ 还是旧值）→ 最后改 $p\to next$"，四项齐备，选 D。

想到这一点的线索：四个选项都是同 4 条语句的不同排列，说明考的不是"改哪几个指针"而是"**先后顺序**"，于是只问自己一句：哪条语句先执行会毁掉另一条语句要读的值？

## 6. 详细解答

记 $q$ 为插入前 $p$ 的后继，即初始时 $q=p\to next$，且 $q\to prior=p$。终态要求见 §5 第 1 步。

**逐选项模拟（按语句顺序改写内存状态）**

- **A**：`p->next = s;` → $p\to next=s$，旧 $q$ 从 $p$ 侧不可达（丢失）；`s->prior = p;` → 正确；`p->next->prior = s;` → 现在 $p\to next$ 是 $s$，故等价于 `s->prior = s`，把刚设好的 $s\to prior=p$ **改成自指**；`s->next = p->next;` → $s\to next=s$，又是自指。终态：$p\to next=s$、$s\to prior=s$、$s\to next=s$，$q$ 及其后整段链与 $s$ 脱开。✗
- **B**：`p->next = s;` → 同样先丢 $q$；`p->next->prior = s;` → 即 `s->prior = s`；`s->prior = p;` → 修正为 $s\to prior=p$；`s->next = p->next;` → $s\to next=s$（自指）。$q\to prior$ 从未被改为 $s$，从 $q$ 向前链跳不过去 $s$。✗
- **C**：`s->prior = p;` ✓；`s->next = p->next;` → $s\to next=q$ ✓（此时 $p\to next$ 仍是旧值，读得对）；`p->next = s;` ✓；`p->next->prior = s;` → 此刻 $p\to next$ 已变为 $s$，此句实为 `s->prior = s`，**覆盖**第一条的正确结果，造成 $s$ 前驱自指，同时 $q\to prior$ 仍等于 $p$。✗
- **D**：`s->prior = p;` ✓；`s->next = p->next;` → $s\to next=q$ ✓；`p->next->prior = s;` → 此时 $p\to next$ **尚未修改**，仍是 $q$，故 $q\to prior=s$ ✓；`p->next = s;` → ✓。四条赋值恰好等于 §5 第 1 步的终态要求。✓

**用具体结点验证（自我验证）**

取长度为 3 的双向循环链表：结点 1、2、3，$1\to next=2$，$2\to next=3$，$3\to next=1$，$2\to prior=1$，$3\to prior=2$，$1\to prior=3$。令 $p=$ 结点 1，$s=$ 新结点 4，期望终态 $1\leftrightarrows4\leftrightarrows2\leftrightarrows3\leftrightarrows1$。

按 D 执行：$4\to prior=1$；$4\to next=p\to next=2$；$p\to next\to prior$ 即 $2\to prior=4$；$1\to next=4$。得
$1\to next=4$、$4\to prior=1$、$4\to next=2$、$2\to prior=4$、$2\to next=3$、$3\to next=1$、$1\to prior=3$ —— 顺 $next$ 走一圈：1→4→2→3→1，共 4 个结点各一次；顺 $prior$ 走一圈：1→3→2→4→1，同样 4 个，两向对称 ✓（循环未被破坏）。

按 C 执行到第 4 句：$4\to prior=1$ 被改写为 $4\to prior=4$，且 $2\to prior$ 仍为 1，于是从 1 出发 $1\to next=4\to next=2$ 能走通，但从 2 向前 $2\to prior=1$ 直接跳回 1，越过了 4——双向链表"两个方向必须互为逆序"的性质被破坏 ✗，与前述分析一致。

## 7. 选项分析

- A：错。首句即覆盖 $p\to next$，丢失原后继 $q$；后续两条对 $p\to next$ 的读写全部落在 $s$ 自身，得到 $s\to prior=s$、$s\to next=s$ 的双自指环；
- B：错。同样是"先改 $p\to next$"，$q\to prior$ 永远得不到修改，插入结点在 $next$ 方向能到、$prior$ 方向漏掉；
- C：**最具迷惑性**。前两句正确，问题在最后两句顺序颠倒——`p->next->prior = s;` 排在 `p->next = s;` 之后，语义变成 `s->prior = s`，既覆盖了正确的前驱，又漏改 $q$ 的前驱。典型误区是"只要四条语句都在，顺序无所谓"；
- D：正确。两个"读 $p\to next$ 旧值"的语句（`s->next = p->next;`、`p->next->prior = s;`）都排在唯一"写 $p\to next$"的语句之前。

## 8. 考场标准答案

在双向链表中 $p$ 之后插入 $s$，需修改 4 个指针，且**凡读旧 $p\to next$ 的语句必须先于写 $p\to next$ 的语句**：

```c
s->prior = p;              // 新结点的前驱
s->next  = p->next;        // 新结点的后继 = 原后继 q（此时 p->next 还是旧值）
p->next->prior = s;        // 原后继 q 的前驱改为 s
p->next = s;               // 最后才把 p 的后继指向 s
```

故选 **D**。（时间复杂度 $O(1)$，空间复杂度 $O(1)$；若为带头结点的循环链表，此段代码无需头结点参与。）

## 9. 易错点

1. 认为"四条语句齐全即可"，忽略 `p->next->prior = s;` 必须趁 $p\to next$ 还是旧 $q$ 时执行（C 选项即此陷阱）；
2. 首句写 `p->next = s;` 造成原后继不可达（A、B 选项即此陷阱）——单向链表插入中"先接新再断旧"的口诀在双向链表里必须扩展为"**先填 $s$，再改 $q$，最后改 $p$**"；
3. 只改两个指针（如只动 $p\to next$ 与 $s\to prior$）——双向链表插入漏改 $next$ 方向会导致某方向遍历跳过或死循环，检查时应"两向各走一遍"。

## 10. 一句话规律

指针题的语句排序题只有一个判断标准：**列出每条语句读谁、写谁，任何"读旧值"的语句都不能排在"写该旧值"的语句之后**，剩下的排列必然正确。
