# DS-2019-23

## 1. 原题

对于一个具有 $n$ 个结点的单链表，在已知的结点 $*p$ 后插入一个新结点的时间复杂度为____________________ ，在给定值为 $x$ 的结点后插入一个新结点的时间复杂度为____________________ 。

## 2. 答案

- 第一空（在**已知结点 $*p$** 之后插入）：$O(1)$
- 第二空（在**值等于 $x$ 的结点**之后插入）：$O(n)$

## 3. 题目分析

- 已知：含 $n$ 个结点的单链表（只含一个指针域 `next`，无从后向前的链接）；
- 目标：分别给出两种"插入位置给出方式"下的插入操作时间复杂度；
- 关键约束：两空的差别**只在"如何得到插入位置"**，插入本身的指针改写量相同；
- 命题意图：考"单链表的插入代价来自定位而非搬移"这一核心性质，并与顺序表（搬移代价来自后移元素）形成对照。第一空给出的是**结点指针**，第二空给出的是**结点值**，二者的定位代价一个是零、一个是线性。

## 4. 核心考点

核心考点：
DS01.02.02 链式存储：单链表（插入只需改两个指针；无随机存取，按值访问必须自头向后扫描）

辅助考点：
DS01.02.01 顺序存储（顺序表：插入/删除/查找与移动次数）——两空对照的另一半：顺序表即便已知位置也要搬移元素，链表即便要遍历也不需要搬移

解释：本题问的是"链表操作的成本构成"，属 DS01.02.02 的基本性质；把它与顺序表的成本构成并列比较才能想清两空为何不同，故辅助挂 DS01.02.01。按 `docs/knowledge_taxonomy.md` 的交叉横断说明，复杂度分析本身不另立知识点，能力上用 `COMPLEXITY_ANALYSIS` 标注。

## 5. 解题思路

1. 把一次插入拆成两步：**定位前驱结点** ＋ **改写指针**，分别计数；
2. 第一空：前驱就是题给的 $p$，定位代价 $0$；插入只需 `s->next = p->next; p->next = s;` 两条赋值，与 $n$ 无关 ⟹ $O(1)$；
3. 第二空：只给值 $x$，单链表不支持按下标随机访问，只能从头结点起 `while(p && p->data != x) p = p->next;` 逐个比较，最坏比较 $n$ 次（$x$ 在表尾或不存在），定位即已 $\Theta(n)$；随后的两条指针赋值不再增加量级 ⟹ $O(n)$；
4. 反向校验：若把本题换成**顺序表**，第一空（已知位置）也要搬移 $O(n)$ 个元素，第二空是"查找 $O(n)$ ＋ 搬移 $O(n)$"仍为 $O(n)$——可见"已知结点指针 ⟹ 常数"是链表独有的优势，正是本题想突出的结论。

## 6. 详细解答

**（1）第一空：在已知结点 $*p$ 之后插入 $*s$**

```c
s->next = p->next;      /* ① 新结点接管 p 的原后继 */
p->next = s;            /* ② p 指向新结点 */
```

基本操作为 $2$ 次指针赋值（另有申请结点的 $O(1)$），不含任何与 $n$ 相关的循环，故时间复杂度为 $O(1)$。

注意与"在 $*p$ **之前**插入"对比：单链表只能向后走，要在 $p$ 前插入必须先找 $p$ 的前驱，退化为 $O(n)$；本题问的是"之后"，所以是 $O(1)$。

**（2）第二空：在值为 $x$ 的结点之后插入 $*s$**

```c
p = L->next;                        /* 从首元结点起顺序扫描 */
while (p != NULL && p->data != x)   /* 按值查找：最坏比较 n 次 */
    p = p->next;
if (p == NULL) return ERROR;        /* 值为 x 的结点不存在 */
s->next = p->next;
p->next = s;
```

定位阶段最坏比较 $n$ 次（$x$ 恰为最后一个结点），等概率时可查中时平均比较 $\frac{n+1}{2}$ 次，两者量级都是 $\Theta(n)$；插入阶段仍是 $O(1)$。总代价 $T(n)=\Theta(n)+O(1)=O(n)$。

**（3）两空合并对照表**

| 给定信息 | 定位代价 | 插入（改指针）代价 | 合计 |
|---|---|---|---|
| 结点指针 $*p$ | $0$ | $O(1)$ | $O(1)$ |
| 结点值 $x$ | $O(n)$（顺序扫描） | $O(1)$ | $O(n)$ |
| 顺序表中的位置 $i$（对照） | $O(1)$ | $O(n)$（后移 $n-i+1$ 个元素） | $O(n)$ |

第三行说明：链表的 $O(n)$ 花在"找"，顺序表的 $O(n)$ 花在"搬"，两者来源不同但量级相同；只有"链表＋已给指针"这一组合能压到 $O(1)$。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

第一空 $O(1)$：插入位置的前驱 $p$ 已由指针给出，只需 `s->next=p->next; p->next=s;` 两次指针修改，与表长无关。

第二空 $O(n)$：单链表无随机存取，须从头结点起按值顺序扫描找到值为 $x$ 的结点（最坏比较 $n$ 次），定位完成后插入本身仍是 $O(1)$，故总代价由查找主导，为 $O(n)$。

## 9. 易错点

1. 两空都填 $O(n)$：忽略了第一空已给出结点指针，"定位"这一步被免掉；
2. 第一空误填 $O(n)$ 而理由是"要移动元素"：链表插入不移动任何元素，把顺序表的搬移代价串味过来了；
3. 看清"之后"与"之前"：在 $*p$ **之前**插入需要找前驱，答案是 $O(n)$，与本题第一空不同；
4. 严格说第二空应写 $O(n)$ 而非 $\Theta(n)$ 以外的模糊表达（"线性时间""约 $n$ 次"等表述不规范）。

## 10. 一句话规律

链表插入的代价 ＝ 定位代价 ＋ $O(1)$：**给了指针就是常数，给了关键字就得遍历**；顺序表则相反，位置可直达、元素要搬移。
