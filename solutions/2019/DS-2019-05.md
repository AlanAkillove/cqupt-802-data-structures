# DS-2019-05

## 1. 原题

下述编码中哪一个不是前缀码（）。

A. $(00,01,10,11)$

B. $(0,1,00,11)$

C. $(0,10,110,111)$

D. $(1,01,000,001)$

## 2. 答案

**B**

## 3. 题目分析

- 已知：四组二进制码字集合（每组 4 个码字）；
- 目标：找出**不满足前缀码定义**的那一组；
- 关键约束：前缀码（无前缀码）的定义——**任一码字都不能是另一个码字的前缀（起始子串）**，这样才能在无分隔符的情况下唯一、即时地译码；
- 命题意图：表面看四串 0/1，实质考"**为什么哈夫曼编码一定是前缀码**"的逆向理解——前缀码等价于"所有码字都挂在编码二叉树的**叶子**上"；一旦某个码字对应内部结点（如 B 中的 `0` 与 `1`），它下面还挂着别的码字，译码就会歧义。

## 4. 核心考点

核心考点：
DS03.04.01 哈夫曼树与哈夫曼编码（WPL、编码构造）——前缀编码的定义与"码字必为叶子"的性质

辅助考点：
DS02.06.01 串的定义、存储结构与串相等判定——判断"甲是乙的前缀"即判断甲是否等于乙的长度为 $|\text{甲}|$ 的前端子串

解释：本题不要求构造哈夫曼树或算 WPL，只考哈夫曼编码之所以能唯一译码的根本条件（前缀性质），仍属该节点的"编码构造"要求；前缀判定本身是串上的运算，故列 DS02.06.01 为辅助。

## 5. 解题思路

1. 把定义转成可操作的检查程序：把每组码字按**长度从小到大**排序，然后对每个较短码字 $c$，检查是否存在较长码字以 $c$ 开头（即比较前 $|c|$ 位）；发现一对即判"不是前缀码"；
2. 先用最"瘦"的码字筛：长度为 1 的码字最危险——若组内同时有 `0` 和以 `0` 开头的长码字，立刻失败；
3. 逐组筛：A 全为 2 位、互不相同 ⟹ 无前后缀关系；B 有 `0` 又有 `00` ⟹ 失败（也只需再看 `1` 与 `11`，两处都失败）；C、D 长度为 1 的码字（分别为 `0`、`1`）与其它码字首字母不同，再逐对查余下组合，均通过；
4. 用两个独立方法复核：Kraft 不等式 $\sum 2^{-l_i}\le 1$ 是前缀码的**必要条件**，B 算得 $1.5>1$ 直接判死；再把四组码画到二叉前缀树（Trie）上，B 的 `0`、`1` 落在内部结点。

想到这一点的线索：选项 B 出现"1 位码字与 2 位码字并存且首字母相同"，这是前缀码最典型的破坏形态，先查它最省力。

## 6. 详细解答

**定义**：码字集合 $C$ 是前缀码 $\iff$ 不存在 $c_1,c_2\in C$（$c_1\ne c_2$）使 $c_1$ 是 $c_2$ 的前缀。

**逐组检查**

- **A** $\{00,01,10,11\}$：四个码字等长（2 位），等长的两个不同串互不为前缀（前缀要求长度更短），故无任何前后缀关系 ⟹ **是**前缀码。
- **B** $\{0,1,00,11\}$：`0` 是 `00` 的前缀（`00` 的前 1 位为 `0`）；同时 `1` 是 `11` 的前缀。存在两组破坏 ⟹ **不是**前缀码。
- **C** $\{0,10,110,111\}$：`0` 与其余码字比较——`10`、`110`、`111` 首位均为 `1`，不以 `0` 开头 ✓；`10` 与 `110`/`111` 比较——二者前 2 位为 `11` ≠ `10` ✓；`110` 与 `111` 等长且不同 ✓ ⟹ **是**前缀码。
- **D** $\{1,01,000,001\}$：`1` 与 `01`/`000`/`001` 比较——三者首位均为 `0` ✓；`01` 与 `000`/`001` 比较——二者前 2 位为 `00` ≠ `01` ✓；`000` 与 `001` 等长且不同 ✓ ⟹ **是**前缀码。

**复核一（Kraft 不等式，必要条件）**：对前缀码必有 $\sum_i 2^{-l_i}\le 1$（$l_i$ 为码字长度）。

- A：$4\times\frac14=1$ ✓；
- B：$\frac12+\frac12+\frac14+\frac14=\frac32>1$ ✗ ⟹ 必不是前缀码；
- C：$\frac12+\frac14+\frac18+\frac18=1$ ✓；D：$\frac12+\frac14+\frac18+\frac18=1$ ✓。

（注意 Kraft 只是必要条件，满足它仍可能有前后缀关系，所以本题仍以上面的逐对检查为准，Kraft 用于反向确认 B。）

**复核二（编码二叉树 / 前缀 Trie）**：把码字沿"0 走左、1 走右"插入二叉树。

- B 的插入结果：根的两个孩子（深度 1 的**内部结点**）就已是码字 `0` 与 `1`，而 `00`、`11` 挂在它们之下成为孙子 ⟹ 码字对应内部结点，译码时"走到该结点还能继续往下走"，破坏即时译码；
- C：`0` 是根的左孩子（叶子）；`10` 是根的右孩子的左孩子（叶子）；`110`、`111` 是根的右孩子的右孩子的两个孩子（叶子）⟹ 全部码字为叶子 ✓；
- D：`1` 是根的右孩子（叶子）；`01` 是根的左孩子的右孩子（叶子）；`000`、`001` 是根的左孩子的左孩子的两个孩子（叶子）⟹ 与 C 结构镜像对称，全部码字为叶子 ✓。

**译码歧义实例（自我验证）**：用 B 编码接收串 `0011`，可切分为 `0|0|1|1`（4 个字符）、`00|1|1`（3 个字符）、`0|0|11`、`00|11` 等多种读法，译码结果不唯一；而 C 收到 `010111111`：`0|10|111|111` 唯一（首位 0 必须整体作 `0`，其后 `1` 必须与下一位组成 `10`，再后 `111`…），逐字符可即时译出 ✓。可见只有 B 不是前缀码。

## 7. 选项分析

- A（$00,01,10,11$）：是前缀码。等长码字集必为前缀码（互不为前缀），它就是 2 位定长编码，也恰是 4 个等概率符号的哈夫曼编码；
- B（$0,1,00,11$）：**不是**前缀码（本题答案）。`0` 是 `00` 的前缀、`1` 是 `11` 的前缀；Kraft 和为 $1.5$，破坏必要条件；码字落在编码树的内部结点；
- C（$0,10,110,111$）：是前缀码。长度递增的码字首位依次被"屏蔽"（`0` 之后的码字都以 `1` 开头，`10` 之后的码字以 `11` 开头），构成一条"单支链＋叶子"的极端形态，正是 4 个概率悬殊符号可能得到的哈夫曼编码；
- D（$1,01,000,001$）：是前缀码。结构与 C 镜像对称（`1` 之后码字均以 `0` 开头，`01` 之后以 `00` 开头），Kraft 和亦为 1。

## 8. 考场标准答案

前缀码要求"任一码字都不是另一码字的前缀"。

- B 中 `0` 是 `00` 的前缀（且 `1` 是 `11` 的前缀），译码不唯一（`0011` 可切成 `0|0|1|1` 或 `00|11` 等）；
- 又 Kraft 和 $\frac12+\frac12+\frac14+\frac14=\frac32>1$，违反前缀码必要条件。

A、C、D 逐对检查均无前后缀关系（Kraft 和都等于 1）。**选 B**。

## 9. 易错点

1. 只在"长度相差 1"的码字对之间找前缀，漏查 `0` 与 `000` 这类跨两级的对（正确做法：以短码字为准，扫描所有更长的码字）；
2. 见到"Kraft 和 $=1$"就断定是前缀码——它只是必要条件，不是充分条件（如 $\{0,01,011,111\}$ 的 Kraft 和为 $1$，但 `0` 是 `01` 的前缀，仍不是前缀码）；本题只需用它排除 B，方向不能反；
3. 把"定长码一定不是前缀码"当成常识错误：定长码（选项 A）恰恰一定是前缀码，只是平均长度未必最优；
4. 误判 C/D：它们形如 $\{0,10,110,1111\}$ 的"延伸链"看似互相包含，实际每一位错开，需按首位分组检查而非凭长相判断。

## 10. 一句话规律

判前缀码就一句话："**按长度升序，拿每个短码字去比所有长码字的前若干位**"；辅以 Kraft 和 $\sum2^{-l_i}\le1$ 做快速排除，再想一层"码字必须是编码树的叶子"即可确认。

## 11. 关联知识

- 哈夫曼编码天然生成前缀码：从根到叶子的路径标号，叶结点不会出现在其它码字的前缀位置，参见 DS-2017-32（给定 8 种字符频次构造 Huffman 树与前缀编码）、DS-2016-29（已知哈夫曼树叶子数求总结点数，叶子 100 个 → 总结点 199，即内部结点 99 个）；
- 前缀码的"即时译码"性质与串的匹配（DS02.06.02）相关：非前缀码需要回溯才能译码，前缀码可边读边译；
- 本卷第 11 题（中缀转后缀）同样是"用符号串的书写规则消除歧义"的问题，可与前缀码对照记忆：后缀表达式靠运算符元数固定（二目）且无括号来消歧，前缀码靠"无前缀"消歧；
- 定长编码 vs 哈夫曼变长编码的 WPL 比较是问答题常型（A 组即 $n=4$ 的定长编码）。
