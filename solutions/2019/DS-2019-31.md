# DS-2019-31

## 1. 原题

请阅读下列算法，回答问题：

（1）这是什么类型的排序算法，该排序算法稳定吗？

（2）设置 $r(0)$ 的作用是什么？

（3）若将 $while$ 语句中判断条件改为 `x<=r(j)`，该算法将会有什么变化？

（4）若将 $while$ 语句中判断条件改为 `x<=r(j)`，该算法是否还能正确工作？

```c
sort(r,n) 
{
    for(i=2;i<=n;i++)
    { 
        x=r(i);
        r(0)=x;
        j=i-1;
        while(x<r(j))
        {
            r(j+1)=r(j);
            j=j-1; 
        }
        r(j+1)=x; 
    }
}
```

## 2. 答案

**（1）** 这是**直接插入排序**（简单插入排序，Insertion Sort）：每趟把 $r(i)$ 插入到前面已排好的有序区 $r(1\cdots i-1)$ 中，外层循环 $i=2\cdots n$ 共 $n-1$ 趟。该算法**是稳定的**（内层只在 $x<r(j)$ 严格成立时才后移，遇相等关键字立即停，待插记录落在同键记录之后，同键记录的相对次序不变）。

**（2）** $r(0)$ 起**两个**作用：① **工作单元/暂存**——`x=r(i); r(0)=x;` 把待插记录取出，$r(0)$ 保存其值，同时腾出 $r(i)$ 这个"空位"供后移链使用；② **监视哨（sentinel）**——因为 $r(0)$ 里存的就是 $x$ 本身，当内层比较一直向前推进到 $j=0$ 时，条件 $x<r(0)$ 必为**假**（自身不可能小于自身），循环自动终止，于是**不需要在 $while$ 里再写 $j\ge1$ 的越界判断**，把"边界检查"与"关键字比较"合并成一次判断，省掉内层每次循环的一半判断开销。

**（3）** 条件改为 `x<=r(j)` 后，比较"相等"时也成立 ⟹ **与 $x$ 相等的关键字也会被后移**，待插记录最终插到那一串同键记录的**最前面**（而不是最后面）。排序结果的**关键字序列仍然有序**，但**相同关键字记录的相对次序被颠倒**，即**算法由稳定变为不稳定**。（另见（4）：在本代码结构下还会引发哨兵失效的越界问题。）

**（4）** **不能正确工作。** 原代码的内层终止完全依赖监视哨：$r(0)=x$ 后，$x<r(0)$ 为假 ⟹ 停机。改成 $x<=r(j)$ 后，$j$ 递减到 $0$ 时 $x<=r(0)$ **恒为真**（自己小于等于自己），循环不会在 $j=0$ 处停下：接着执行 $r(1)=r(0)$、$j$ 变为 $-1$，继续访问 $r(-1)$ —— **数组下标越界**（未定义行为：轻则读到无关键值使循环永不终止／不断覆写 $r(1)$，重则程序崩溃），且 $j+1\le 0$ 时 `r(j+1)=x` 也写到有效区之外。因此算法在"最小元素需要插到表头"的那一趟就会出错。补救办法是补上边界判断 `while(j>=1 && x<=r(j))`（此时排序功能正确，但如（3）所述**不再稳定**），或让 $r(0)$ 存一个"比所有关键字都小"的极值（此时又无法充当暂存单元，需另设 `x` 变量）。

## 5. 解题思路

1. **认骨架**：外层 `for(i=2;i<=n;i++)` ＋ 内层"从 $i-1$ 起向前比、边比边后移、最后写回 $r(j+1)=x$" ⟹ 这是"把第 $i$ 个记录插入前面 $i-1$ 个已排好序的记录中"的标准插入排序特征（区别于冒泡的相邻交换、选择的"找最小再换"、折半插入的 `while(low<=high)`）；
2. **判稳定**：只看内层的"停"条件 —— 遇到 $r(j)$ 时若 $x==r(j)$ 是否后移。$x<r(j)$：相等就停 ⟹ 新记录排在同键记录**之后** ⟹ 稳定；
3. **拆 $r(0)$**：从两处代码证据说话 —— `r(0)=x`（赋值，说明它暂存）、`while(x<r(j))` 里没有 `j>=1`（说明循环靠 $r(0)$ 的值为哨兵来终止）；
4. **改条件做实验**：用一个**含同键记录**的小表 $r=(2,3,3^{*})$ 分别按两种条件手排一遍，直接观察落位差异 ⟹ 得（3）；再用"需要插到表头"的那一趟（$x$ 比前面所有元素都小）观察 $j$ 会不会穿过 $0$ ⟹ 得（4）；
5. **交叉复核**：对照教材写法（$R[0]$ 作哨兵的 `InsertSort`）与本库同型题 DS-2016-40、DS-2017-37 的追踪表，确认"每趟比较次数含 1 次哨兵比较"这一口径与本题（2）一致。

## 6. 详细解答

### （1）算法识别与稳定性

**结构对照**（把源文圆括号下标改写为方括号以便阅读，语义不变）：

```c
void InsertSort(SqList *L)          /* 教材风格：L->r[1..n]，r[0] 作监视哨 */
{
    for (i = 2; i <= n; i++) {      /* n-1 趟，第 i 趟把 r[i] 插入有序区 r[1..i-1] */
        x = r[i];  r[0] = x;        /* 暂存待插记录 */
        for (j = i - 1; x < r[j]; j--)  /* 比 x 大的都后移 */
            r[j + 1] = r[j];
        r[j + 1] = x;               /* x 落位 */
    }
}
```

与题面代码逐行一致，故为**直接插入排序**。

**排除其他算法的依据**：

| 候选 | 特征 | 本题代码是否具备 |
|---|---|---|
| 直接插入排序 | 前缀 $r[1\cdots i-1]$ 有序、"暂存—后移—落位" | ✅ 完全一致 |
| 折半插入排序 | 在有序区内用 `low/high` 二分找插入位置 | ❌ 无 $low/mid/high$，是顺序前扫 |
| 冒泡排序 | 相邻两两比较交换，每趟确定一个最值 | ❌ 无相邻交换 |
| 简单选择排序 | 每趟选最小者的下标再交换 | ❌ 无"找最小下标"过程 |
| 希尔排序 | 按增量 $d$ 分组插入，$d$ 逐趟折半 | ❌ 只有 $d=1$ 一种跨度 |

**稳定性**：内层后移的条件是 $x<r(j)$（**严格**小于）。当 $x$ 与 $r(j)$ 关键字相等时条件为假、循环停止，$x$ 被写入 $r(j+1)$，即插在**已存在的同键记录之后**，同键记录的相对次序保持不变 ⟹ **稳定**。

用含同键的表验证（记两个 $49$ 为 $49_a$（原在前）、$49_b$）：$r=(49_a, 38, 65, 49_b, 13)$（下标 $1\cdots5$，$r(0)$ 空闲）

| 趟 $i$ | 取出 $x$ | 后移过程 | 趟后 $r[1\cdots i]$ |
|---|---|---|---|
| 1（$i=2$） | $38$ | $38<49_a$ ⟹ $49_a$ 移到 $r(2)$；$j{=}1$ 比 $r(1){=}38$? 继续 $j{=}0$，$38<r(0){=}38$ 假 ⟹ 停 | $38,49_a,65,49_b,13$ |
| 2 | $65$ | $65<49_a$ 假 ⟹ 不动 | $38,49_a,65,49_b,13$ |
| 3 | $49_b$ | $49_b<65$ ⟹ $65$ 后移；$49_b<49_a$ **假**（相等即停）⟹ $49_b$ 落在 $49_a$ **之后** | $38,49_a,49_b,65,13$ |
| 4 | $13$ | $13<65,13<49_b,13<49_a,13<38$ 全真，四个后移；$j{=}0$ 撞哨兵停 | $13,38,49_a,49_b,65$ |

最终 $49_a$ 仍在 $49_b$ 之前 ✓ 稳定。同时第 4 趟正好演示了 $r(0)$ 如何终止循环（见（2））。

**复杂度**（$n$ 为记录个数）：时间 最坏（逆序）$O(n^2)$、最好（正序）$O(n)$、平均 $O(n^2)$；空间 $O(1)$（只用 $r(0)$、$x$、$j$ 等常数量）。

### （2）$r(0)$ 的作用（一物两用）

1. **暂存待插记录（工作单元）**：`x=r(i); r(0)=x;` —— 内层是一个"后移链"：$r(i-1)\to r(i)$、$r(i-2)\to r(i-1)\cdots$，若不先把 $r(i)$ 的值存起来，第一次后移就会把它覆盖丢失。$r(0)$（以及变量 $x$）承担了这份备份；有效数据只占 $r(1)\cdots r(n)$，故 $r(0)$ 是**特意空出来的下标 0 号单元**；
2. **监视哨，消灭越界判断**：若没有哨兵，内层必须写成 `while(j>=1 && x<r(j))`，每循环一次要做**两次**判断；由于 $r(0)=x$，当 $x$ 比 $r(1)\cdots r(i-1)$ 都小时，$j$ 会一路减到 $0$，此时 $x<r(0)$ 即"$x<x$"**必假**，循环恰好停止且 $j+1=1$（$x$ 落到位 1，正确位置）。于是**"是否越界"被合并进了"关键字比较"这一次判断里**，判断次数减半；这就是第 4 趟 $x=13$ 那行"$j{=}0$ 撞哨兵停"的机制。

一句话：**$r(0)$ 既是"备份寄存器"，又是"自动刹车片"**，而刹车之所以有效，靠的是"哨兵值 ＝ 待插值 ⟹ 严格小于不成立"。

对照本库 DS-2016-40 的表述："监视哨 $R[0]$ 的作用是把下标越界判断合并进关键字比较"，与本题（2）完全一致；哨兵思想在查找章的同源应用见 DS-2018-16（顺序查找算法 9.1 用 $r[0]$ 作监视哨，成功 $ASL=\frac{n+1}{2}$、失败 $ASL=n+1$）。

### （3）改为 `x<=r(j)` 后的变化

内层后移条件放宽为"小于等于也要移"，于是：

- **相等关键字也被后移**：$x$ 会越过所有与它相等的记录，插到这一串同键记录的**最前面** ⟹ **同键记录的相对次序被颠倒 ⟹ 稳定性被破坏**（由稳定变不稳定）；
- 用上面的表复算第 3 趟（$x=49_b$）：$49_b\le 65$ ⟹ $65$ 后移；$49_b\le 49_a$ **现在为真** ⟹ $49_a$ 也后移；$49_b\le 38$ 假 ⟹ 停，$49_b$ 落在位 2：

  $$r=(38,\ \mathbf{49_b},\ 49_a,\ 65,\ 13)$$

  $49_b$ 跑到了 $49_a$ **前面**，与原序列次序相反 ⟹ 不稳定（对照（1）表第 3 趟的结果 $38,49_a,49_b,65$，差异一目了然）；
- **关键字序列本身仍有序**（只按关键字看，$38\le49\le49\le65$ 仍成立）——即"结果没错但相对次序错了"，这正是"不稳定"的标准形态；
- **每趟的代价变大**：同键记录也要搬动，比较与后移次数增加（如本例第 3 趟由 $2$ 次比较、$1$ 次后移变为 $3$ 次比较、$2$ 次后移）；总时间仍为 $O(n^2)$，但常数增加；
- 更本质地说：$x<=r(j)$ 与 $x<r(j)$ 的差别恰在"相等"这一边界上，而**插入排序的稳定性正建立在这个边界如何处理之上**——这也正是（4）要追问的：同一改动会不会把哨兵机制也破坏掉。

### （4）改为 `x<=r(j)` 后能否正确工作

**不能。** 关键是哨兵与新条件冲突：

- 原终止逻辑：$r(0)=x \Rightarrow x<r(0)$ 恒**假** ⟹ 循环必停在 $j\ge 0$；
- 新终止逻辑：$r(0)=x \Rightarrow x\le r(0)$ 恒**真** ⟹ 循环**不会**在 $j=0$ 停下：执行 $r(1)=r(0)$（把哨兵里的 $x$ 又抄回位 1），$j$ 变为 $-1$，再判 $x<=r(-1)$ —— 访问数组**下标越界**（未定义行为）。

后果与触发条件：

| 情形 | 原条件 $x<r(j)$ | 新条件 $x<=r(j)$ |
|---|---|---|
| $x$ 大于 $r(1)$（不需插到表头） | $j\ge1$ 处正常停 | $j\ge1$ 处正常停（**本趟侥幸无事**） |
| $x$ 不大于前缀中任何记录（即 $x\le r(1)$，需插到最前） | 停在 $j=0$，落位 $1$，正确 | 穿过 $j=0$ 继续，$j=-1$ 访问 $r(-1)$ ⟹ **越界**；若 $r(-1)$ 恰使条件为真，则不断 $r(0)=r(-1)\cdots$ 覆写、甚至死循环 |

例如 $r=(38,49,13,\dots)$：第 $3$ 趟 $x=13$，$13\le49$、$13\le38$ 皆真，$j$ 减到 $0$；$13\le r(0)=13$ 仍真 ⟹ $r(1)=13$、$j=-1$、访问 $r(-1)$ 越界。而"每趟都有可能出现本趟最小者"，所以错误几乎必然发生（只要 $n\ge3$ 且序列中有需要插到最前的记录）。

**两种可行的修补**（答出其一即为完整）：

1. 补边界判断：`while(j>=1 && x<=r(j))` —— 此时算法功能正确（仍能得到有序序列），但 $r(0)$ 退化为单纯的暂存单元、失去哨兵作用，且每趟多一次判断；由于仍按 $x<=r(j)$ 后移，**不稳定**；
2. 把 $r(0)$ 换成"比一切关键字都小"的极值哨兵（另设变量 `x` 暂存待插记录），此时 $x<=r(0)$ 为假可停机，但仍**不稳定**。

结论对照：（3）答"**结果有序但稳定性丢失、代价略增**"，（4）答"**按原代码结构不能正确工作，哨兵失效导致下标越界；须加 $j\ge1$ 判断才能运行，但那时仍不稳定**"。

## 8. 考场标准答案

**（1）** 直接插入排序（简单插入排序）。外层 $i=2\cdots n$ 共 $n-1$ 趟，每趟将 $r(i)$ 插入前缀有序区 $r(1\cdots i-1)$。算法**稳定**：内层仅当 $x<r(j)$ 时后移，遇相等关键字即停止，待插记录总插在同键记录之后。时间 $O(n^2)$（最好 $O(n)$），空间 $O(1)$。

**（2）** $r(0)$ 有双重作用：① 暂存本趟待插记录 $x$（腾出空位供连续后移）；② 作**监视哨**，因 $r(0)$ 的值就是 $x$，当 $x$ 需插到表头时 $j$ 递减到 $0$ 后 $x<r(0)$ 必为假，循环自动终止，从而免去 `while` 中的 $j\ge1$ 越界判断（把边界检查与关键字比较合并为一次判断）。

**（3）** 相等关键字也满足后移条件，故 $x$ 会越过全部同键记录插到它们**前面**，相同关键字记录的相对次序被颠倒 —— 排序结果仍有序，但**算法不再稳定**；同键记录被多搬一次，比较与移动次数略增。

**（4）** **不能正确工作**：$r(0)=x$ 使 $x<=r(0)$ **恒为真**，监视哨失效，$j$ 由 $0$ 继续减为 $-1$ 并访问 $r(-1)$，产生下标越界（未定义行为，可能死循环/崩溃）。必须改为 `while(j>=1 && x<=r(j))`（或让 $r(0)$ 存极小值）才能正常运行，但那时算法仍然**不稳定**。

## 9. 易错点

1. 把（3）（4）当成同一问重复作答：（3）问**行为/结果**（稳定性、次序、代价），（4）问**可行性**（哨兵是否失效、是否越界），必须分层答；
2. （1）答成"折半插入排序"：没有 $low/mid/high$，前缀是顺序向前扫描的，只能是直接插入；
3. 答稳定性时只说"稳定"不给理由：判据是"相等时是否后移"，要指出 $x<r(j)$ 相等即为假、$x$ 落在同键记录之后；
4. （2）只答"作哨兵"漏"暂存"，或只答"暂存"漏"哨兵"：题面 `x=r(i); r(0)=x;` 两行是双重作用的全部证据，须同时指出"省去 $j\ge1$ 判断"这一实质好处；
5. 误以为哨兵的作用是"存放最小值/初值"：$r(0)$ 里放的是**待插记录本身**，靠"$x<x$ 不成立"停机，不是靠"哨兵值极小"；
6. （4）误答"仍能正确工作、只是不稳定"：忽略了 $r(0)=x$ 这个前提——正因为哨兵值等于 $x$，$\le$ 才会恒真；这一点是本题的区分度所在；
7. 混淆"越界一定崩溃"与"越界是未定义行为"：卷面写成"哨兵失效、$j$ 减为负数、访问 $r(-1)$ 越界，算法不能正确工作"即可，不必断言程序必然崩溃；
8. 忽略 $n=1$ 与"前缀已有序不需移动"的边界情形：外层循环不进／内层一次即停时两种写法都没有问题，故反例必须取"需要插到表头"的那一趟才有力。

## 10. 一句话规律

读排序代码先认**骨架**（外层 $i=2..n$ ＋ 内层"暂存—前扫后移—落位"＝直接插入），再认**停条件**：插入排序的稳定性只取决于"相等时停不停"——相等就停则稳定，相等仍移则不稳定；而**监视哨只对严格不等式生效**（$j$ 减到 $0$ 时 $x<r(0)$ 必假才停），所以把 $<$ 改成 $\le$ 会同时"破坏稳定性"和"让哨兵失效导致越界"。
