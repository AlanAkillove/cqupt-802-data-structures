# DS-2019-28

## 1. 原题

假设以 $I$ 和 $O$ 分别表示入栈和出栈操作。栈的初态和终态均为空，入栈和出栈的操作序列可表示为仅由 $I$ 和 $O$ 组成的序列，称可以操作的序列为合法序列，否则称为非法序列。

（1）下面所示的序列中哪些是合法的?

A. $IOIIOIOO$

B. $IOOIOIIO$

C. $IIIOIOIO$

D. $IIIOOIOO$

（2）通过对（$1$）的分析，写出一个算法，判定所给的操作序列是否合法。（假定被判定的操作序列已存入一维数组 $char\ A[]$ 中，若操作序列合法，返回 $true$，否则返回 $false$）。

## 2. 答案

**（1）** 合法序列：**A、D**；非法序列：**B、C**。

| 序列 | 逐步栈内元素个数（余额） | 违规点 | 结论 |
|---|---|---|---|
| A. $IOIIOIOO$ | $1,0,1,2,1,2,1,0$ | 无 | **合法** |
| B. $IOOIOIIO$ | $1,0,\mathbf{-1},\dots$ | 第 $3$ 步 $O$ 时栈已空 | 非法 |
| C. $IIIOIOIO$ | $1,2,3,2,3,2,3,2$ | $I$ 有 $5$ 个、$O$ 只有 $3$ 个，终态 $bal=2\neq0$ | 非法 |
| D. $IIIOOIOO$ | $1,2,3,2,1,2,1,0$ | 无 | **合法** |

**（2）** 判据：**任一前缀中 $I$ 的个数不少于 $O$ 的个数，且整个序列中 $I$ 与 $O$ 的个数相等**。算法见第 6 节（时间 $O(n)$，空间 $O(1)$）。

## 3. 题目分析

- 已知：由字符 $I$（入栈）、$O$（出栈）组成的序列；栈初态、终态均为空；
- 目标：① 判别给出的 4 个长度为 8 的序列合法性；② 由判别过程抽象出通用判定算法；
- 关键约束：栈"后进先出"在本题只体现为一条**数量约束**——出栈前栈里必须有元素；不涉及具体元素值，因此不必真的建一个栈，一个计数器即可；
- 命题意图：考栈的 LIFO 特性 → "合法操作序列"的充要条件，并考"由具体判别归纳成算法"的设计能力（与计数/前缀和思想结合）。

## 4. 核心考点

核心考点：
DS02.01 栈和队列的基本概念（栈的 LIFO 特性；合法进出栈序列的判定条件——前缀中入栈数不少于出栈数、总数相等）

辅助考点：
DS02.02 栈和队列的顺序存储结构（"空栈不能出栈"即顺序栈 `top==0`（或 `top==-1`）时 `Pop` 非法的实现对应）
DS02.03 栈和队列的链式存储结构（链栈 `top==NULL` 时出栈非法，是同一判据的另一存储表现；算法中 `bal==0` 即"栈空"的抽象）

解释：题目本质是栈的概念性质（DS02.01），写算法时 `bal==0` 就是"栈空"这一条件在顺序栈/链栈里的判据（DS02.02/DS02.03 交叉）。

## 5. 解题思路

1. **把序列翻译成余额**：设 $bal$ 为当前栈内元素个数，$I$ 使 $bal{+}{+}$，$O$ 使 $bal{-}{-}$；
2. **定充要条件**：初态终态都空 ⟺ ①每个前缀 $bal\ge 0$（等价于"任意前缀里 $\#I\ge\#O$"，且中途 $bal=0$ 时下一个字符不能是 $O$）；②末态 $bal=0$（$\#I=\#O$）。两条同时成立即合法——这正是对 4 个选项逐个打勾的尺子；
3. **逐字符套条件**得第 2 节表格：B 违反①（第 3 步 $bal<0$）、C 违反②（终态 $bal=2$），A、D 两条全满足；
4. **算法化**：把"逐字符扫描＋两个检查点"直接写成一遍循环，遇到非法立刻返回 `false`，循环结束再判 `bal==0`；
5. **复核（第二法）**：把 $I/O$ 序列作用到入栈顺序 $1,2,3,4$ 上，看能否得到一个合法的出栈序列（能 ↔ 操作序列合法），并与 Catalan 数 $C_4=\frac{1}{5}\binom{8}{4}=14$ 对照——长度 8 的合法序列恰有 14 个，A、D 均在其内。

## 6. 详细解答

### （1）四个序列的逐步判定

**A. $I\,O\,I\,I\,O\,I\,O\,O$**

| 步 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 操作 | I | O | I | I | O | I | O | O |
| $bal$ | 1 | 0 | 1 | 2 | 1 | 2 | 1 | **0** |

全程 $bal\ge 0$ 且末态 $bal=0$ ⟹ **合法**。

**B. $I\,O\,O\,I\,O\,I\,I\,O$**

| 步 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 操作 | I | O | O | I | O | I | I | O |
| $bal$ | 1 | 0 | **−1** ✗ | — | — | — | — | — |

第 $3$ 步在栈空（$bal=0$）时执行出栈 ⟹ **非法**（扫描到此处即可判 `false`，后面无须再看）。

**C. $I\,I\,I\,O\,I\,O\,I\,O$**

| 步 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 操作 | I | I | I | O | I | O | I | O |
| $bal$ | 1 | 2 | 3 | 2 | 3 | 2 | 3 | **2** |

每个前缀都满足 $bal\ge 0$，但 $\#I=5,\#O=3$，末态 $bal=2\neq 0$，与"终态为空栈"矛盾 ⟹ **非法**。

**D. $I\,I\,I\,O\,O\,I\,O\,O$**

| 步 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 操作 | I | I | I | O | O | I | O | O |
| $bal$ | 1 | 2 | 3 | 2 | 1 | 2 | 1 | **0** |

全程 $bal\ge 0$ 且末态 $bal=0$ ⟹ **合法**。

### （2）第二法复核：翻译成出栈序列

设入栈元素依次为 $1,2,3,4$（第 $k$ 个 $I$ 压入 $k$），模拟得：

- A：出栈时刻依次为第 2、5、7、8 步，对应元素 $1,3,4,2$ ⟹ 出栈序列 $(1,3,4,2)$，合法；
- B：第 3 步要求出栈但无元素 ⟹ 无法产生任何出栈序列，非法；
- C：只有 3 个 $O$，只能出栈 $3$ 个元素，余 $2$ 个在栈内 ⟹ 终态非空，非法；
- D：出栈时刻为第 4、5、7、8 步，对应 $3,2,4,1$ ⟹ 出栈序列 $(3,2,4,1)$，合法。

两法结论一致：**A、D 合法，B、C 非法**。

补充校验：长度 $2n$（$n$ 个 $I$、$n$ 个 $O$）的合法序列个数即 Catalan 数 $C_n=\frac{1}{n+1}\binom{2n}{n}$；$n=4$ 时 $C_4=14$，而全部 $\binom{8}{4}=70$ 种"$4$ 个 $I$、$4$ 个 $O$"的排列中仅 14 种合法，B 属于"前缀违规"类，C 甚至不在 $\binom{8}{4}=70$ 之内（$I/O$ 个数不等），这也解释了为什么 C 的违规点是终态而非前缀。

### （3）算法设计思想

判定只需统计"栈内元素个数"这一标量，无须真栈：

1. 令 $bal=0$（对应初态空栈）；
2. 自左向右扫描 $A[0\cdots n-1]$，每个字符 $c$：
   - $c=='I'$：$bal{+}{+}$（入栈总可行）；
   - $c=='O'$：若 $bal==0$ 则"空栈出栈"，立即返回 `false`；否则 $bal{-}{-}$；
   - 其他字符：不是合法的操作符号，返回 `false`；
3. 扫描完毕返回 $bal==0$（保证终态为空栈，即 $\#I=\#O$）。

正确性：步骤 2 保证了"每个前缀 $\#I\ge\#O$"（即 $bal\ge0$ 恒成立），步骤 3 保证了 $\#I=\#O$；这两条正是题设"初态与终态均为空"的充要条件。

### （4）教材风格 C 代码

```c
#include <stdbool.h>       /* C99；若用 C89 可将返回值改为 int，用 1/0 表示 true/false */

/* 判定操作序列 A[0..n-1]（仅含 'I' 入栈、'O' 出栈）是否为合法序列 */
bool JudgeStackSeq(char A[], int n)
{
    int bal = 0;                       /* bal：扫描过程中栈内元素个数，初态空栈为 0 */
    int i;

    for (i = 0; i < n; i++) {
        if (A[i] == 'I') {
            bal++;                     /* 入栈：任何时刻都可执行 */
        } else if (A[i] == 'O') {
            if (bal == 0)              /* 空栈不能出栈 —— 前缀中 O 多于 I */
                return false;
            bal--;
        } else {
            return false;              /* 出现非 I/O 字符，序列本身不合法 */
        }
    }
    return (bal == 0);                 /* 终态必须是空栈，即 I 与 O 个数相等 */
}
```

若教材未启用 `stdbool.h`，可等价写作：

```c
int JudgeStackSeq(char A[], int n)     /* 返回 1 合法，0 非法 */
{
    int i, bal = 0;
    for (i = 0; i < n; i++) {
        if (A[i] == 'I')      bal++;
        else if (A[i] == 'O') { if (bal == 0) return 0; bal--; }
        else                  return 0;
    }
    return bal == 0 ? 1 : 0;
}
```

调用示例（对应第（1）问）：

```c
char s1[] = "IOIIOIOO", s2[] = "IOOIOIIO", s3[] = "IIIOIOIO", s4[] = "IIIOOIOO";
/* JudgeStackSeq(s1,8)=true, (s2,8)=false, (s3,8)=false, (s4,8)=true */
```

### （5）复杂度分析

设 $n$ 为**操作序列的长度**（即数组 $A[]$ 中 $I$、$O$ 字符的总数，第（1）问中 $n=8$）：

- **时间复杂度 $O(n)$**：只有一重循环，每个字符至多被访问一次、每次做常数次比较与加减；最坏情况（合法序列）恰好执行 $n$ 次循环，非法序列可能提前退出，故上界为 $O(n)$；
- **空间复杂度 $O(1)$**：仅用 $bal$、$i$ 两个辅助变量，不随 $n$ 增长；
- 对照写法：若真的建一个顺序栈（压入/弹出字符），时间同为 $O(n)$，但空间为 $O(n)$（栈深最坏 $n/2$）。本题只关心"能否操作"，与元素值无关，故可把栈压缩成一个计数器——这是本题从"模拟"升级为"判定"的关键一步，也是满分点。

## 8. 考场标准答案

**（1）** $A$、$D$ 是合法序列；$B$、$C$ 是非法序列。

理由：设 $bal$ 为栈中元素个数（初态 $0$），$I$ 使 $bal{+}{+}$、$O$ 使 $bal{-}{-}$，合法要求**任何前缀 $bal\ge0$ 且末态 $bal=0$**。

- A：$1,0,1,2,1,2,1,0$ —— 满足，合法；
- B：第 $3$ 个操作 $O$ 时 $bal$ 已为 $0$，空栈出栈，非法；
- C：$5$ 个 $I$、$3$ 个 $O$，末态 $bal=2\neq0$，与"终态为空栈"矛盾，非法；
- D：$1,2,3,2,1,2,1,0$ —— 满足，合法。

**（2）** 判据：**序列中 $I$ 与 $O$ 个数相等，且每个前缀中 $I$ 的个数不少于 $O$ 的个数**。算法（一遍扫描，$O(n)$ 时间、$O(1)$ 空间）：

```c
bool JudgeStackSeq(char A[], int n)
{
    int i, bal = 0;
    for (i = 0; i < n; i++) {
        if (A[i] == 'I') bal++;
        else if (A[i] == 'O') { if (bal == 0) return false; bal--; }
        else return false;
    }
    return bal == 0;
}
```

## 9. 易错点

1. 只判 $\#I=\#O$ 而漏掉前缀条件：$OI\cdots$ 型序列个数可相等但一开始就出栈，非法；本题 B 正是"$O$ 提前"的反例（B 的 $\#I=\#O=4$ 却非法），**只按个数相等判会把 B 误判为合法**——这是本题最大的陷阱；
2. 只判前缀条件而漏掉终态条件：C 每个前缀都非负，但终态剩 $2$ 个元素，违反"终态为空"；两个检查点必须都写；
3. 忘记 `return bal == 0` 而写成 `return true`：等价于漏掉条件②；
4. 无谓地建真栈：浪费 $O(n)$ 空间且代码冗长；写清 $bal$ 的含义（"栈内元素个数"）比建栈更贴近命题意图；
5. 忘记处理非 $I/O$ 字符（含串尾 `'\0'`）：若把数组长度 $n$ 误传为 `sizeof(A)` 而非 `strlen(A)`，会读到结束符；判据中加 `else return false` 可兜住；
6. 与"出栈序列的排列个数"混淆：本题问的是**操作序列**是否可执行，不是"以 $1..n$ 入栈能得多少种出栈序列"（后者才用 Catalan 数，如本库 DS-2016-05）。

## 10. 一句话规律

栈的合法操作序列判据＝"**余额法**"：$I$ 记 $+1$、$O$ 记 $-1$，**前缀和恒非负（空栈不出栈）且总和为 $0$（终态空栈）**；两者缺一即非法，判定时用一个计数器一遍扫描即可。
