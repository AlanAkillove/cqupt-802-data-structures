# DS-2019-33

## 1. 原题

快速排序算法中，如何选取一个界值（又称为轴元素），影响着快速排序的效率，而且界值也并不一定是被排序序列中的一个元素。例如，我们可以用被排序序列中所有元素的平均值作为界值。用 $C$ 语言编写算法实现以平均值为界值的快速排序方法（注：待排序数据存储在数组 $R[]$ 中，数组最小下标为 $S$，数组最大下标为 $T$）。

## 2. 答案

**算法骨架（三步）**：

1. **求界值**：一趟累加得 $pivot=\dfrac{1}{T-S+1}\sum_{k=S}^{T}R[k]$（用 `double` 保存，避免整型截断）；
2. **一趟划分**（双指针相遇式交换）：$i$ 从左向右找第一个 $>pivot$ 的元素，$j$ 从右向左找第一个 $\le pivot$ 的元素，两者交换，$i{+}{+},j{-}{-}$，直到 $i>j$；结束时 $i=j+1$，且
   $$R[S\cdots j]\ \text{全部}\ \le pivot,\qquad R[i\cdots T]\ \text{全部}\ > pivot$$
3. **递归**两个子区间 $[S,j]$ 与 $[i,T]$；**递归前先判守卫**：若划分没有把区间真正切开（$j\ge T$ 或 $i\le S$，即区间内元素全部等于平均值）就直接返回，否则死循环。

完整代码见第 6 节（3）。复杂度：设 $n=T-S+1$ 为本段记录个数，**平均时间 $O(n\log n)$、最坏 $O(n^2)$**；**空间**为递归栈，平均 $O(\log n)$、最坏 $O(n)$；算法**不稳定**。

## 3. 题目分析

- 已知：数组 $R[]$，待排段为 $R[S\cdots T]$（$S$、$T$ 分别为最小、最大下标）；界值规则＝**该段所有元素的平均值**；
- 目标：写出这个"变体快速排序"的 C 语言算法，并（卷面隐含）说明其正确性与效率；
- **本题的关键约束（也是与普通快排的全部差异）**：
  1. 平均值**一般不等于任何一个元素**（题面已点明"界值也并不一定是被排序序列中的一个元素"）⟹ 不能照抄教材 `Partition` 的"挖坑填子／枢轴归位"写法：那套写法的前提是"枢轴是某个元素，最终要落到一个数组位置上"，而这里若把 $pivot$ 写进数组就会**覆盖并丢失一个数据**；
  2. 于是划分只能保证"**左半 $\le pivot$、右半 $>pivot$**"这一**二分不变量**，划分结束后**不存在"枢轴位置"**，$pivot$ 只活在寄存器/变量里；
  3. 由 2 推出：递归区间不能再写成 `QuickSort(S, pivotpos-1)` 与 `QuickSort(pivotpos+1, T)`（没有可排除的枢轴位置），只能写成 $[S,j]$ 与 $[j{+}1,T]$；这就带来"某一侧可能等于整个区间"的风险，**必须显式加终止守卫**；
  4. 平均值随区间变化，每次划分前都要重新求和 ⟹ 每层多一个 $O(len)$ 的求和趟（不改变总量级）；
- 命题意图：考"快排的本质是**按一个任意界值做的二分**"这一理解，而不是背 `Partition` 的代码形式；同时考"当算法的某个前提（枢轴是元素）被抽掉后，代码要怎么改、会多出什么坑（死循环）"。

## 4. 核心考点

核心考点：
DS06.06 快速排序（"一趟划分把序列分成左右两半 ＋ 递归"的框架；划分只需满足"左小右大"，枢轴不必归位；界值选取影响效率）

## 5. 解题思路

1. **先问"教材写法能不能直接用"**：教材 `Partition(R,low,high)` 第一步是 `pivotkey = R[low]`（把枢轴**取成一个元素**并腾出坑位），最后一步是 `R[low] = pivotkey`（枢轴归位）。本题 $pivot$ 是平均值，不是元素 ⟹ **两头都不能照抄**，必须换成"不依赖枢轴归位"的划分形式；
2. **选划分形式**：可选 (a) 双指针相遇式交换（Hoare 风格）、(b) 前后双下标"小值左移、大值右移"（`i`/`j` 分离收集）。两者都不需要枢轴归位；(a) 原地、只用一个交换，最简洁 ⟹ 取 (a)；
3. **定不变量**（这是全题正确性的支点）：划分过程中始终有
   - $R[S\cdots i-1]\le pivot$（$i$ 左边已确认"不大"）、
   - $R[j+1\cdots T]>pivot$（$j$ 右边已确认"更大"）、
   - 中间 $R[i\cdots j]$ 未检查；
   循环退出时 $i=j+1$，两个不变量拼起来正好覆盖整段 ⟹ 划分正确；
4. **定递归区间**：$[S,j]$ 与 $[i,T]$，且 $i=j+1$ 保证**不重不漏**；长度 $\le1$ 的区间天然有序，作为递归出口 `if (S >= T) return;`；
5. **找新的死循环风险**：若区间内所有元素都等于平均值（例如 $\{2,2,2\}$），则 $i$ 一路冲到 $T+1$、$j$ 停在 $T$ ⟹ 左区间 $[S,T]$ 与原区间相同 ⟹ 无限递归。补守卫 `if (j >= T || i <= S) return;`（此时该段元素全相等，本就已有序，直接返回是正确行为）；
6. **处理数值细节**：求和用 `long`（防溢出）、平均值用 `double`（防整型截断；若题目数据为整型且允许截断，取整后仍满足"左 $\le$ 界值 $<$ 右"吗？——见第 6 节（5）的讨论：截断后仍是一个合法的界值，只是划分会偏斜）；
7. **手工跑一遍**：$\{4,1,3,2,5\}$（第 6 节（4））验证结果有序；再用 $\{2,2,2\}$ 验证守卫、用 $\{1,1,1,1,100\}$ 验证最坏退化、用 $\{5a,5b,1\}$ 验证不稳定。

## 6. 详细解答

### （1）与普通快排的差异对照

| 环节 | 教材快排（`Partition`，枢轴取 $R[low]$） | 本题（界值取平均值） |
|---|---|---|
| 界值来源 | 序列中的某个元素 | $\dfrac{1}{T-S+1}\sum R[k]$，**通常不是元素** |
| 划分手段 | 挖坑填子（或交换），**枢轴最终落进数组** | 只能**两两交换**，界值始终留在变量里，**不进数组** |
| 一趟后的形态 | $R[low\cdots pivotpos-1]\le pivot$，$R[pivotpos]=pivot$ 归位，右侧 $>pivot$ | $R[S\cdots j]\le pivot$、$R[j+1\cdots T]>pivot$，**没有"归位"位置** |
| 递归区间 | $[low,pivotpos-1]$ 与 $[pivotpos+1,high]$（可排除枢轴） | $[S,j]$ 与 $[j+1,T]$（不可排除任何元素） |
| 终止条件 | $low\ge high$ 即自然收敛 | 除 $S\ge T$ 外，还须防"整段未被切开" ⟹ **必须加守卫** |
| 每趟额外代价 | 无 | 多一趟求和 $O(len)$（不改变总量级） |

一句话：**快排的本质是"按任意界值把区间二分成'不大于'与'大于'两侧，再各自递归"**，"枢轴是元素、要归位"只是教材实现的一个便利特例；本题正是要抽掉这个特例。

### （2）算法设计思想（写卷面时的说明文字）

1. 若本段长度 $T-S+1\le 1$，无需划分，直接返回；
2. 顺序累加 $R[S\cdots T]$ 得 `sum`，取 $pivot=(double)sum/(T-S+1)$；
3. 置 $i=S,\ j=T$，反复执行：
   - $i$ 右移，跳过所有 $R[i]\le pivot$；
   - $j$ 左移，跳过所有 $R[j]>pivot$；
   - 若此时仍有 $i\le j$，说明 $R[i]$ 是"左边站错队的大值"、$R[j]$ 是"右边站错队的小值"，交换之，并令 $i{+}{+},\ j{-}{-}$；
   - 直到 $i>j$；
4. 划分后 $i=j+1$：$R[S\cdots j]$ 全 $\le pivot$、$R[i\cdots T]$ 全 $>pivot$；
5. 若 $j\ge T$ 或 $i\le S$，说明本段元素全部等于 $pivot$（已有序），返回；否则递归处理 $[S,j]$ 与 $[i,T]$。

**核心不变量**（划分期间）：$R[S..i-1]\le pivot$ 且 $R[j+1..T]>pivot$；**递归不变量**：进入 `QuickSortAvg(R,S,T)` 时，该段之外的元素不再被本层及更深层触碰，且每层划分都保持"左侧元素只与左侧交换"。

### （3）C 语言代码（教材风格）

```c
typedef int ElemType;

void QuickSortAvg(ElemType R[], int S, int T)
{
    int    i = S, j = T, k;
    long   sum = 0;                    /* 累加求和，long 防溢出 */
    double pivot;                      /* 界值 = 平均值，不是数组元素 */

    if (S >= T) return;                /* 长度 <= 1：递归出口 */

    for (k = S; k <= T; k++)           /* ① 求界值 */
        sum += R[k];
    pivot = (double)sum / (T - S + 1);

    while (i <= j) {                   /* ② 一趟划分：双指针相向扫描并交换 */
        while (i <= j && R[i] <= pivot) i++;   /* i 停在左边第一个 > pivot 者 */
        while (i <= j && R[j] >  pivot) j--;   /* j 停在右边第一个 <= pivot 者 */
        if (i <= j) {                          /* 两边各站错队一个：交换归位 */
            ElemType tmp = R[i];
            R[i] = R[j];
            R[j] = tmp;
            i++;  j--;
        }
    }
    /* 退出时必有 i == j + 1：R[S..j] 全部 <= pivot，R[i..T] 全部 > pivot */

    if (j >= T || i <= S) return;      /* ③ 守卫：整段未被切开（段内元素全等于平均值） */

    QuickSortAvg(R, S, j);             /* ④ 递归左半 */
    QuickSortAvg(R, i, T);             /*    递归右半 */
}

/* 调用：QuickSortAvg(R, 0, n - 1);   （若数组下标从 1 开始则 QuickSortAvg(R, 1, n);） */
```

**代码细节逐条说明**

- 两个内层 `while` 都带 `i <= j`：防止在一侧已全部合格时无限冲出区间（例如整段都 $\le pivot$ 时，$i$ 会一直加到 $j+1$ 而必须停）；
- 交换后必须 `i++; j--;`：否则 $R[i]$（换过来的小值）与 $R[j]$（换过来的大值）会被再次判一遍，虽然不影响正确性，但当 $i==j$ 时会原地打转、无法退出；
- 划分**不写 `pivot` 进数组**：这是本题与教材写法最直观的区别，写错就会丢一个数据；
- 守卫 `j >= T || i <= S`：`j >= T` 意味着 $i$ 冲到了 $T+1$（全段 $\le pivot$）；`i <= S` 意味着 $j$ 退到了 $S-1$（全段 $>pivot$，由平均值的定义这几乎不可能，但作为对称保护写上）。此时该段元素全部相等（因为 $\sum R[k]/len$ 落在 $[\min,\max]$ 之间，"全 $\le$ 平均"只能"全 $=$ 平均"），已有序，直接返回即可；
- 若不允许使用 C99 的"语句中间声明变量"（如 `ElemType tmp` 写在 `if` 块内），可把 `tmp` 提到函数开头的声明段，与教材 `Partition` 的写法保持一致。

### （4）手工走查（正确性验证）

**例 1：$R=\{4,1,3,2,5\}$，$S=0$，$T=4$**

第 1 层：$sum=15$，$pivot=3.0$，$i=0,j=4$

| 动作 | $i$ | $j$ | 数组状态 |
|---|---|---|---|
| $R[0]=4\le3$? 否 ⟹ $i$ 停在 $0$ | 0 | — | $4,1,3,2,5$ |
| $R[4]=5>3$ ⟹ $j=3$；$R[3]=2>3$? 否 ⟹ $j$ 停在 $3$ | 0 | 3 | $4,1,3,2,5$ |
| $i\le j$ ⟹ 交换 $R[0]\!\leftrightarrow\!R[3]$，$i=1,j=2$ | 1 | 2 | $\mathbf{2},1,3,\mathbf{4},5$ |
| $R[1]=1\le3$ ⟹ $i=2$；$R[2]=3\le3$ ⟹ $i=3$；此时 $i=3>j=2$ 内层停 | 3 | 2 | $2,1,3,4,5$ |
| 外层 $i\le j$ 为假 ⟹ 退出 | 3 | 2 | $2,1,3,4,5$ |

守卫：$j=2<T=4$、$i=3>S=0$ ⟹ 未命中，继续递归。左 $[0,2]=\{2,1,3\}$（全 $\le3$ ✓）、右 $[3,4]=\{4,5\}$（全 $>3$ ✓）。

第 2 层（左 $[0,2]$）：$sum=6$，$pivot=2.0$，$i=0,j=2$

- $R[0]=2\le2$ ⟹ $i=1$；$R[1]=1\le2$ ⟹ $i=2$；$R[2]=3\le2$? 否 ⟹ $i$ 停在 $2$；
- $R[2]=3>2$ ⟹ $j=1$；此时 $i=2>j=1$ ⟹ 退出；
- 左 $[0,1]=\{2,1\}$（$\le2$ ✓）、右 $[2,2]=\{3\}$（$>2$ ✓）；守卫未命中。

第 3 层（$[0,1]$）：$sum=3$，$pivot=1.5$，$i=0,j=1$

- $R[0]=2\le1.5$? 否 ⟹ $i=0$；$R[1]=1>1.5$? 否 ⟹ $j=1$；交换 $R[0]\!\leftrightarrow\!R[1]$ ⟹ $\{1,2\}$，$i=1,j=0$ ⟹ 退出；
- 左 $[0,0]=\{1\}$、右 $[1,1]=\{2\}$，均长度 $1$，递归出口返回。

第 2 层（右 $[3,4]=\{4,5\}$）：$pivot=4.5$ ⟹ $R[3]=4\le4.5$（$i\to4$）、$R[4]=5\le4.5$? 否 ⟹ $i=4$；$R[4]=5>4.5$ ⟹ $j=3$ ⟹ 退出；左 $[3,3]$、右 $[4,4]$ 均返回。

**最终 $R=\{1,2,3,4,5\}$ ✓ 有序。**

**例 2（守卫）：$R=\{2,2,2\}$，$S=0$，$T=2$** — $pivot=2$；$i$ 从 $0$ 一路加到 $3$（全部 $\le2$），$j$ 保持 $2$ ⟹ 退出时 $i=3,j=2$；左区间 $[0,2]$ 与原区间相同 ⟹ 若无守卫则无限递归；守卫 `j >= T`（$2\ge2$）命中 ⟹ 返回 ✓（该段本就全相等、已有序，返回是正确行为）。

**例 3（最坏退化）：$R=\{1,1,1,1,100\}$，$S=0$，$T=4$** — $sum=104$，$pivot=20.8$；$i=0,j=4$：

- 内层①：$R[0]=R[1]=R[2]=R[3]=1\le20.8$ ⟹ $i$ 一路加到 $4$；$R[4]=100\le20.8$? 否 ⟹ $i$ 停在 $4$；
- 内层②：$R[4]=100>20.8$ ⟹ $j=3$；此时 $i=4>j=3$，内层因 $i\le j$ 为假而停，$i\le j$ 不成立 ⟹ **本轮一次交换也未发生**；
- 退出时 $i=4=j+1$ ✓；划分结果：左 $[0,3]=\{1,1,1,1\}$（全 $\le20.8$ ✓）、右 $[4,4]=\{100\}$（全 $>20.8$ ✓），不重不漏；
- 守卫：$j=3<T=4$、$i=4>S=0$ ⟹ 未命中，继续递归；左段长度由 $5$ 只减到 $4$（且该段全相等，下一层即被守卫剪掉）。

本例结果 $\{1,1,1,1,100\}$ 已有序 ✓，但划分比是 $4:1$。把数据改成 "$n-1$ 个小值 ＋ 一个极大值"（如 $\{1,2,3,\cdots,n-1,M\}$，$M$ 足够大）时，平均值仍只比 $n-1$ 略大，每轮只能切掉一个元素 ⟹ $T(n)=T(n-1)+O(n)=O(n^2)$。**可见"取平均值作界值"并不能消除最坏情形**，它只是把"端点枢轴＋序列已有序"这一典型退化（$\{1,2,3,\cdots,n\}$ 的平均值恰为中间值，划分反而最平衡）缓解了。

**例 4（不稳定）：$R=\{5a,5b,1\}$**（$5a,5b$ 为相同关键字的两条记录）— $pivot=11/3\approx3.67$；$i=0$（$5a\le3.67$ 假）、$j=2$（$1>3.67$ 假）⟹ 交换 $5a$ 与 $1$ ⟹ $\{1,5b,5a\}$，$i=1,j=1$；继续：$R[1]=5b\le3.67$ 假 ⟹ $i=1$；$R[1]=5b>3.67$ ⟹ $j=0$ ⟹ 退出。左 $[0,0]=\{1\}$、右 $[1,2]=\{5b,5a\}$；右段长度 $2$，$pivot=5$ ⟹ 全部 $\le5$ ⟹ 守卫命中返回。**最终 $\{1,5b,5a\}$：两条 $5$ 的相对次序由 $a,b$ 变成 $b,a$ ⟹ 不稳定** ✓（与第 6 节（6）"快排不稳定"的结论一致）。

### （5）关于"整型平均值"的说明

若写 `pivot = sum / (T - S + 1);`（整型除法，向下取整），算法**仍然正确**（任何落在 $[\min R,\max R]$ 内的界值都能给出合法的二分），但：

- 取整后的界值可能**小于真正的平均值**，使右半偏小、左半偏大，划分更不平衡 ⟹ 效率向 $O(n^2)$ 靠拢；
- 极端情况：段内元素为 $\{1,2\}$，整型平均 $=1$ ⟹ $R[0]=1\le1$（$i\to1$）、$R[1]=2\le1$? 否 ⟹ $i=1$；$R[1]=2>1$ ⟹ $j=0$ ⟹ 退出，左 $[0,0]$、右 $[1,1]$ ✓ 仍划开；
- 但若界值取整后**恰好等于段内最大值**（如 $\{1,2,2\}$，整型平均 $=1$；或 $\{3,3,3\}$ 平均 $=3$）⟹ 可能出现"全段 $\le pivot$"，此时**守卫是唯一的救命稻草**。

因此推荐写成 `double pivot = (double)sum / (T - S + 1);`，并**始终保留守卫**。

### （6）复杂度分析（写明各符号含义）

设本段记录个数 $n=T-S+1$，递归共 $\log n$ 层（平均）。

- **每层代价**：求和 $O(len)$ ＋ 划分 $O(len)$（每个元素至多被两个内层 `while` 各扫过一次，交换次数 $\le len/2$）⟹ 每层合计 $O(n)$（与教材快排"一趟划分 $O(n)$"同量级，只是多出一个同阶的求和趟）；
- **平均时间**：界值为平均值时，划分比通常接近常数比例（元素大致分布在均值两侧），递归树深 $\Theta(\log n)$ ⟹ $T(n)=2T(n/2)+O(n)=\boxed{O(n\log n})$；
- **最坏时间**：若数据高度偏斜（例如 $n-1$ 个小值 ＋ $1$ 个大值，平均值只比小值略大 ⟹ 每轮只切掉 $1$ 个元素），递归深度 $n$，$T(n)=T(n-1)+O(n)=\boxed{O(n^2)}$（见例 3）；比较次数上界 $\sum_{k=2}^{n}2k=O(n^2)$；
- **空间**：无辅助数组，只有递归栈 ＋ 每层的 $i,j,k,sum,pivot$ 常数个变量 ⟹ 平均 $O(\log n)$、最坏 $O(n)$；
- **稳定性**：**不稳定**（交换跨越了相等关键字，见例 4）；
- **附加讨论（卷面可作改进说明）**：① 当 $T-S+1$ 小于某个阈值（如 $8{\sim}15$）时改用直接插入排序，可省掉递归与求和开销；② 求和趟可与别的工作合并（如"三数取中"），但"平均值"本身要求全局扫描，这是该界值策略的固有代价——它比"取端点"更抗偏斜，却比"中位数近似（median-of-medians）"实现简单得多。

## 8. 考场标准答案

**基本思想**：以本段元素的平均值 $pivot$ 为界值，用**双指针相向扫描＋交换**做一次划分，使 $R[S\cdots j]\le pivot$、$R[j+1\cdots T]>pivot$；由于 $pivot$ 不是数组元素，不能像教材那样"枢轴归位"，故递归区间取 $[S,j]$ 与 $[j+1,T]$，并在递归前判断"本段是否真的被切开"以避免死循环。

```c
void QuickSortAvg(int R[], int S, int T)
{
    int i = S, j = T, k;
    long sum = 0;
    double pivot;
    int  tmp;

    if (S >= T) return;                       /* 长度不超过 1，有序 */
    for (k = S; k <= T; k++) sum += R[k];     /* ① 求界值：平均值 */
    pivot = (double)sum / (T - S + 1);

    while (i <= j) {                          /* ② 一趟划分（界值不进数组） */
        while (i <= j && R[i] <= pivot) i++;  /*   左边找第一个 > pivot 者 */
        while (i <= j && R[j] >  pivot) j--;  /*   右边找第一个 <= pivot 者 */
        if (i <= j) {                         /*   两者交换，各归其侧 */
            tmp = R[i]; R[i] = R[j]; R[j] = tmp;
            i++; j--;
        }
    }
    if (j >= T || i <= S) return;             /* ③ 未划开（段内全相等）：终止防死循环 */

    QuickSortAvg(R, S, j);                    /* ④ 递归左半 R[S..j] */
    QuickSortAvg(R, i, T);                    /*    递归右半 R[i..T]，i == j+1 */
}
```

**复杂度**：$n=T-S+1$ 为待排记录数；每层"求和＋划分"$O(n)$，平均递归深度 $\log n$ ⟹ 平均 $O(n\log n)$；数据偏斜时每轮只切出一个元素 ⟹ 最坏 $O(n^2)$；空间为递归栈，平均 $O(\log n)$、最坏 $O(n)$；算法**不稳定**。

## 9. 易错点

1. **照抄教材 `Partition` 的挖坑写法**：把 `pivot`（平均值）当成 `R[low]` 保存后开始腾坑，最后 `R[low]=pivot` ⟹ **覆盖掉一个真实数据**，且数组里出现了一个"不存在的元素"。这是本题最典型的错解；
2. **递归区间写成排除"枢轴位置"**：如 `QuickSortAvg(R,S,pivotpos-1)`——本题没有 $pivotpos$，划分后只有 $j$；且必须保证两个子区间**不重（$i=j+1$）不漏（覆盖 $S\cdots T$）**；
3. **漏掉终止守卫**：段内元素全相等（$\{2,2,2\}$）时 $i$ 冲出右端、$j$ 停在 $T$，左区间等于原区间 ⟹ **无限递归（栈溢出）**。这是本题区别于普通快排的新坑，必须显式处理；
4. 内层 `while` 漏写 `i <= j`：单侧全部合格时指针会冲出区间，访问越界；
5. 交换后忘记 `i++; j--;`：$i==j$ 时原地打转，死循环；
6. 用整型除法取平均且不加守卫（见第 6 节（5））：界值被截断后更容易出现"全段 $\le pivot$"；求和用 `int` 还可能溢出；
7. 界值比较方向不自洽：若左侧写 $R[i]<pivot$、右侧写 $R[j]\ge pivot$，则等于 $pivot$ 的元素全被甩到右边，虽然仍正确，但与"左 $\le$、右 $>$"的递归不变量描述不符，写文档/说明时容易前后矛盾（两者必须成对出现，且与递归区间的划分一致）；
8. 误答"平均值为界值一定能得到平衡划分"：平均值只保证"不是最小值也不是最大值"，**不保证**两侧数量相当——$\{1,1,1,1,100\}$ 就是划分比 $\approx 3:1$ 的反例（例 3），最坏仍是 $O(n^2)$；
9. 误答"该算法稳定"：划分靠交换，相同关键字的相对次序会变（例 4 给出 $\{5a,5b,1\}\to\{1,5b,5a\}$）；
10. 把 $S$、$T$ 理解成"数组长度"：题面明确 $S$ 是**最小下标**、$T$ 是**最大下标**，段长是 $T-S+1$，求平均时除数别写错；调用形式是 `QuickSortAvg(R, 0, n-1)`（或 $1$ 基的 `QuickSortAvg(R, 1, n)`）。

## 10. 一句话规律

快排的真正定义是"**任取一个界值把区间二分成'不大于'与'大于'两侧，再各自递归**"：一旦界值不是元素（平均值、中位数、外给值都属此类），就必须①改用"交换式划分"、不许把界值写进数组，②递归区间不能排除枢轴位置，③**补一条"划分没切开就返回"的守卫**否则死循环；复杂度不变（平均 $O(n\log n)$、最坏 $O(n^2)$），因为平衡与否取决于数据分布，而不是界值是不是元素。
