# DS-2019-24

## 1. 原题

在 $n$ 个记录的有序顺序表中进行折半查找，最大比较次数是____________________ 。

## 2. 答案

$$\lfloor \log_2 n \rfloor + 1\qquad(\text{与 } \lceil \log_2 (n+1)\rceil \text{ 恒等})$$

即"折半查找判定树的高度"。

## 3. 题目分析

- 已知：长度为 $n$ 的**有序**顺序表，查找方式为折半（二分）；
- 目标：一次成功查找中关键字比较次数的**最大值**（最坏情形）；
- 关键约束：每次比较后区间长度由 $m$ 缩为 $\lfloor m/2\rfloor$ 或 $\lceil m/2\rceil-1$ 级别，查找过程对应判定树上一条根到结点的路径；"最大" ⟹ 路径最长 ⟹ 树最深层；
- 命题意图：考"折半查找 ⟷ 判定树高度"这一换算，公式必须带取整口径，不能写成含糊的 $O(\log_2 n)$。

## 4. 核心考点

核心考点：
DS05.04 折半查找法（判定树的构造：根取 $mid=\lfloor(low+high)/2\rfloor$，成功查找的比较次数等于该结点在判定树中的层号，最坏即树高）

辅助考点：
DS03.02.01 二叉树的定义及主要特征（第 $i$ 层至多 $2^{i-1}$ 个结点 ⟹ 高度 $h$ 的二叉树至多 $2^h-1$ 个结点，这是"至少/至多"换算的工具）
DS05.01 查找的基本概念（比较次数是衡量查找效率的基本量，"最大比较次数"是最坏情形口径，与 ASL 的平均口径相区分）

解释：本题主体是 DS05.04 的判定树性质；证明树高公式要用二叉树的层结点上界（DS03.02.01）；而"最大"这一措辞属于 DS05.01 的最坏/平均口径辨析。

## 5. 解题思路

1. 把折半查找过程画成**判定树**：每个记录占一个结点，比较顺序就是从根向下走的路径；
2. 于是"最大比较次数"＝"判定树的高度"（成功结点的最深层）；
3. 判定树是"平衡"的：任一子树的两支结点数至多差 $1$，因此高度达到同规模二叉树的最小可能值 $h=\lfloor\log_2 n\rfloor+1$；
   - 由 $2^{h-1}-1 < n \le 2^{h}-1$（前 $h-1$ 层填满还差一点，第 $h$ 层还有结点）解出 $h$；
4. 用 $n=1,2,\cdots,8$ 手工模拟折半过程核对公式，并检查 $n=2^k-1$（满树）与 $n=2^k$（多一层）两个临界情形。

## 6. 详细解答

**（1）判定树模型**

折半查找的递归过程为

$$mid=\Big\lfloor\frac{low+high}{2}\Big\rfloor,\quad
\begin{cases} key=R[mid] & \text{查找成功}\\ key<R[mid] & \text{进入 } [low,\,mid-1]\\ key>R[mid] & \text{进入 } [mid+1,\,high]\end{cases}$$

把每次取的 $R[mid]$ 作为结点、两个子区间作为左右子树，得到的二叉树即**判定树**。查找某记录时比较次数 ＝ 该记录结点在判定树中的**层号**（根为第 $1$ 层）。故

$$K_{\max} = \{\text{判定树的高度}\} = h$$

**（2）求高度**

判定树每次把区间对半分，故任一结点的左右子树结点数至多差 $1$，树是平衡的，高度取同结点数的最小值。高度为 $h$ 的二叉树最多 $2^{h}-1$ 个结点、高度为 $h-1$ 的二叉树最多 $2^{h-1}-1$ 个结点，于是 $n$ 满足

$$2^{h-1}-1 < n \le 2^{h}-1 \;\Longleftrightarrow\; 2^{h-1} \le n < 2^{h} \;\Longleftrightarrow\; h-1 \le \log_2 n < h$$

$$\Longrightarrow\; h=\lfloor \log_2 n \rfloor + 1$$

又因 $n$ 为整数时 $\lfloor\log_2 n\rfloor+1=\lceil\log_2(n+1)\rceil$（两式在 $n=2^k-1$ 与 $2^k-1<n<2^{k+1}-1$ 两段上分别取等），故两种写法均可。

**（3）逐个实算核对**（下标 $1\cdots n$，$mid=\lfloor(low+high)/2\rfloor$，走最长路径）

| $n$ | 最长比较链（区间长度变化） | 实测 $K_{\max}$ | $\lfloor\log_2 n\rfloor+1$ |
|---|---|---|---|
| $1$ | $1$ | $1$ | $1$ ✓ |
| $2$ | $2\to1$ | $2$ | $2$ ✓ |
| $3$ | $3\to1$ | $2$ | $2$ ✓ |
| $4$ | $4\to2\to1$ | $3$ | $3$ ✓ |
| $5$ | $5\to2\to1$ | $3$ | $3$ ✓ |
| $7$ | $7\to3\to1$ | $3$ | $3$ ✓（满树，$2^3-1$） |
| $8$ | $8\to4\to2\to1$ | $4$ | $4$ ✓（刚越过 $2^3-1$） |

$n=7$ 与 $n=8$ 是临界对照：$7$ 个结点恰好铺满 $3$ 层，第 $8$ 个结点必须新开一层，最大比较次数由 $3$ 跳到 $4$，与公式一致。

**（4）口径提醒**

"最大比较次数"是**查找成功**的最坏情形（对某个具体记录而言）；若问"查找不成功"，比较次数等于路径上经过的内部结点数，其最大值同样是判定树高度 $h=\lfloor\log_2 n\rfloor+1$（本库 DS-2016-32 即"最多比较次数 $\lfloor\log_2 100\rfloor+1=7$"的具体数值版）。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

折半查找过程对应其判定树，成功查找的比较次数等于该结点在判定树中的层号，最大比较次数即判定树高度。判定树左右两支结点数至多差 $1$，是平衡的，由 $2^{h-1}\le n<2^{h}$ 解得

$$K_{\max}=h=\lfloor \log_2 n\rfloor+1\quad\big(=\lceil\log_2(n+1)\rceil\big)$$

## 9. 易错点

1. 写成 $O(\log_2 n)$：填空要的是**确切表达式**，量级记号不给分；
2. 漏取整或取整方向错：写成 $\log_2 n$（非整数）或 $\lceil\log_2 n\rceil$（$n=8$ 时给 $3$，实际为 $4$）都不对；$\lceil\log_2 n\rceil$ 与 $\lfloor\log_2 n\rfloor+1$ 只在 $n$ 非 $2$ 的幂时相等；
3. 误当作"顺序查找"：有序表的顺序查找最坏是 $n$ 次（带哨兵时 $n+1$），与折半无关；
4. 忘记"有序"这一前提：折半查找只适用于**有序**顺序表，若题目改为"无序表折半查找"则方法本身不成立。

## 10. 一句话规律

折半查找的一切"次数"问题都翻译成**判定树**：成功看结点层号、失败看外部结点层号，最大次数就是树高 $\lfloor\log_2 n\rfloor+1$；遇到具体数值先套 $2^k-1$ 找最近的满树规模再定层。

- DS-2016-32（$100$ 个元素折半查找最多比较次数 $=\lfloor\log_2 100\rfloor+1=7$）：本题公式的数值代入版；
- DS-2016-34（对具体有序表折半查找某值，写出比较序列）：本题"最长路径"的具体路径版；
- DS-2019-17（本卷第 17 题：有序表 $(12,24,36,48,60,72,84)$ 折半查找 $72$ 的比较次数）：$n=7$ 恰为满判定树（树高 $3$），$72$ 是根 $48$ 的右孩子、位于第 $2$ 层，故只比较 $2$ 次——是本题公式之下的一条**具体路径**，可与"最大 $3$ 次"对照；
- DS05.04 判定树同时是"失败 ASL"的计算载体：$n$ 个记录的判定树有 $n+1$ 个外部结点，其层数分布决定查找不成功的平均比较次数。
