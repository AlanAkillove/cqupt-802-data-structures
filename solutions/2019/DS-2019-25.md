# DS-2019-25

## 1. 原题

求从某源点到其余各顶点的 $Dijkstra$ 算法在图的顶点数为 $10$ ，用邻接矩阵表示图时计算时间约为 $10ms$ ，则在图的顶点数为 $40$ ，计算时间约为____________________ $ms$ 。

## 2. 答案

约 $160\ ms$

## 3. 题目分析

- 已知：同一算法（Dijkstra 求单源最短路径）、同一存储结构（邻接矩阵），规模 $n_1=10$ 时耗时 $T_1=10ms$；
- 目标：规模 $n_2=40$ 时的耗时 $T_2$；
- 关键约束：题目给出"邻接矩阵表示"这一条件，就是在提示按**该存储下的时间复杂度**做比例外推；假设运行时间与基本操作次数成正比（同机同实现）；
- 命题意图：考 Dijkstra 在邻接矩阵上的时间复杂度 $O(n^2)$（与边数无关），并能把复杂度记号翻译成"倍数计算"。

## 4. 核心考点

核心考点：
DS04.04.02 最短路径（Dijkstra 的执行的轮数与每轮工作量：$n-1$ 轮，每轮"选最小 $dist$"＋"松弛邻接点"）

辅助考点：
DS04.02.01 邻接矩阵法（每轮在一维 `dist` 数组上扫全部顶点找最小值，且邻接信息按行取，正是 $O(n^2)$ 的来源；若改用邻接表＋堆，量级会变成 $O((n+e)\log n)$，本题口径随之改变）

解释：本题不要求算路径，只考"算法复杂度 ⟶ 时间外推"，所以主知识点落在 Dijkstra 本身，辅助挂其存储前提。按 `docs/knowledge_taxonomy.md` 交叉横断说明，复杂度分析不另立知识点，用 `COMPLEXITY_ANALYSIS` 能力标签体现。

## 5. 解题思路

1. 写出教材版 Dijkstra 的循环结构：外层 $n-1$ 轮，每轮内含"扫描 $dist$ 数组取未定最小者（$O(n)$）"与"用新定点的一行邻接信息松弛（$O(n)$）"；
2. 得 $T(n)=c\cdot n^2$ 量级（与边数 $e$ 无关，这是邻接矩阵实现的特点）；
3. 用比例消去未知常数 $c$：$\dfrac{T_2}{T_1}=\left(\dfrac{n_2}{n_1}\right)^2=\left(\dfrac{40}{10}\right)^2=16$；
4. $T_2=16\times 10ms=160ms$。

## 6. 详细解答

**（1）为什么是 $n^2$**

教材（严蔚敏）邻接矩阵版 Dijkstra 的骨架：

```c
for (v = 1; v <= n; ++v) { dist[v] = A[v0][v]; final[v] = FALSE; }   /* 初始化：O(n) */
dist[v0] = 0; final[v0] = TRUE;
for (i = 1; i <= n - 1; ++i) {          /* 共 n-1 轮 */
    在 final==FALSE 的顶点中找 dist 最小者 u;      /* 扫描 n 个元素：O(n) */
    final[u] = TRUE;
    for (v = 1; v <= n; ++v)                        /* 沿 A[u][1..n] 松弛：O(n) */
        if (!final[v] && dist[u] + A[u][v] < dist[v]) { dist[v] = dist[u] + A[u][v]; path[v] = u; }
}
```

- 第 1 步初始化：$\Theta(n)$；
- 第 2 步：$n-1$ 轮 × 每轮 $\big(\Theta(n)+\Theta(n)\big)$ ＝ $\Theta(n^2)$；

故 $T(n)=\Theta(n^2)$，记 $T(n)\approx c\,n^2$。注意**与边数无关**：即使图很稀疏，按邻接矩阵仍要对整行整列扫描，这正是题目强调"用邻接矩阵表示图"的原因。

**（2）比例外推**

$$\frac{T_2}{T_1}=\frac{c\cdot 40^2}{c\cdot 10^2}=\Big(\frac{40}{10}\Big)^2=16 \quad\Longrightarrow\quad T_2=16\times 10ms=160ms$$

**（3）交叉核对（用"每轮成本"另一种数法）**

$n=10$：$9$ 轮，每轮约 $10+10=20$ 次基本操作，共约 $180$ 次 $=10ms$ ⟹ 每次约 $0.0556ms$；
$n=40$：$39$ 轮，每轮约 $40+40=80$ 次，共约 $3120$ 次 ⟹ $3120\times0.0556\approx173ms$。

两种数法差别在于"每轮 $2n$ 次"与"$n^2$ 次"的近似口径（$39\times80=3120$ 对 $40^2=1600$ 的 $2$ 倍关系，$9\times20=180$ 对 $10^2=100$），本质都是 $\Theta(n^2)$；考研口径取"规模比平方"，即 $160ms$。第（3）条只用于确认"量级为平方、答案在百毫秒级"，不改变结论。

**（4）若换成其他实现的对照（防止记错量级）**

| 存储/实现 | 时间复杂度 | 同条件下 $n:10\to40$ 的倍数 |
|---|---|---|
| 邻接矩阵（本题） | $O(n^2)$ | $16$ 倍 ⟹ $160ms$ |
| 邻接表＋简单找最小 | $O(n+e)$ | 取决于 $e$ 的增长，无法由题设确定 |
| 邻接表＋二叉堆 | $O((n+e)\log n)$ | 同上 |

可见本题唯一可确定的外推依据就是"$n^2$"，题面给出邻接矩阵正是为锁定这一量级。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

邻接矩阵实现的 Dijkstra 需 $n-1$ 轮，每轮做一次"扫 $dist$ 取最小"（$O(n)$）与一次"沿一行松弛"（$O(n)$），总时间 $T(n)=O(n^2)$，与边数无关。故

$$T_2=T_1\times\Big(\frac{40}{10}\Big)^2=10\times16=160\ (ms)$$

## 9. 易错点

1. 把 Dijkstra 的量级记成 $O(n+e)$ 或 $O(n^3)$：前者是邻接表遍历/带堆实现的口径，后者是 Floyd（求**所有**点对最短路径）的口径；本题是"单源＋邻接矩阵"，取 $n^2$；
2. 忘记平方：按线性放大得 $40ms$（把 $n$ 与 $n^2$ 混淆）；
3. 误以为耗时还与边数有关而答"无法确定"：题设已锁定存储结构为邻接矩阵，扫描整行整列的次数只由 $n$ 决定；
4. 表述要写"约 $160ms$"：题面本身用"约为"，因为外推假设了运行时间与基本操作数严格成正比。

## 10. 一句话规律

"规模变大几倍、时间变几倍"类填空题＝**先定复杂度量级，再做比例外推**：$T\propto n^k \Rightarrow$ 倍数 $=(\text{规模比})^k$；$n^2\!\to16$ 倍、$n^3\!\to64$ 倍、$n\log n\!\to$ 需逐项算。
