# DS-2019-16

## 1. 原题

若一组记录的排序码为 $(46,79,56,38,40,84)$，则利用堆排序的方法建立的初始堆为____________________ 。

## 2. 答案

$$(84,\ 79,\ 56,\ 38,\ 40,\ 46)$$

即按数组下标 $1\sim6$（层序）排好的**大顶堆**：堆顶 $84$ 为最大关键字。对应的完全二叉树形态为

```
              84
           /      \
        79          56
       /  \        /
     38    40    46
```

（堆排序对升序序列建的是大顶堆；若题目另指明建小顶堆，结果为 $(38,40,56,79,46,84)$，见第 12 节口径说明。）

## 3. 题目分析

- 已知：$n=6$ 个记录的排序码序列 $(46,79,56,38,40,84)$，按输入次序存放于 $R[1\cdots6]$（堆排序以顺序表为存储结构，下标即完全二叉树的层序编号）；
- 目标：执行堆排序的**第一步"建初始堆"**，输出建堆完成后的序列；
- 关键约束：
  1. 教材建堆方法是**自底向上筛选**：从最后一个非终端结点 $i=\lfloor n/2\rfloor$ 开始，依次对 $i=\lfloor n/2\rfloor,\dots,2,1$ 各做一次"以 $i$ 为根的子树调整为堆"（`AdjustDown`/`Sift`），**不是**逐个插入建堆（后者得到的合法堆形态可能不同，且不是"堆排序的方法"）；
  2. 一次调整是**反复下沉**：把 $R[i]$ 与左右孩子中的较大者比较，若孩子更大就交换，然后继续在被交换到的子层上重复，直到不再需要交换或到达叶子；
  3. 下标映射：结点 $i$ 的左孩子 $2i$、右孩子 $2i+1$，$2i>n$ 即无孩子（叶子）；
  4. 输出必须是**层序（数组下标序）**的一列关键字，不是中序或先序；
- 命题意图：考"建初始堆"这一具体过程的完整执行（本库 2012/2014/2015 三年都只问"必须从哪个结点开始调整"，本题要求把整个过程做完），因此既考起点 $\lfloor n/2\rfloor$ 的定位，也考每次下沉的交换判断。

## 4. 核心考点

核心考点：
DS06.07 堆与堆排序（堆的定义：$R[i]\ge R[2i],R[i]\ge R[2i+1]$；筛选法建初始堆的起点与逐次下沉）

解释：题目就是建堆这一步本身，属该节点"建堆"子项最直接的操作题。

辅助考点：
DS03.02.02 二叉树的存储结构（顺序存储下 $i$ 与 $2i,2i+1$ 的父子关系、$\lfloor n/2\rfloor$ 是最后一个非叶结点）

解释：判断"谁是谁的孩子""哪一层是叶子"完全依赖完全二叉树的顺序存储编号性质，这是执行调整的前提。

## 5. 解题思路

1. 先把序列"立成树"：按层序把 $6$ 个数填入完全二叉树的 $6$ 个位置（$n=6$ 时形态为：根、两层内部结点、第 3 层 $3$ 个结点）；
2. 定起点：$\lfloor 6/2\rfloor=3$，故需调整的下标依次是 $3,2,1$（下标 $4,5,6$ 是叶子，无须调整）；
3. 按 $i=3\to2\to1$ 顺序，每次做"取较大孩子、必要时交换、继续下沉"；
4. 每步之后立刻把当前数组写出来（第 6 节表），保证可回溯；
5. 结束后做**双重检查**：① 逐内部结点核对 $R[i]\ge$ 其子女；② 核对堆顶 $=$ 原序列最大值 $84$、且元素集合与原序列相同（没有丢失或改写数值）。

想到这一点的线索："利用堆排序的方法建立初始堆"这句话里的"堆排序的方法"就是筛选法，而筛选法的唯一非平凡输入是起点 $\lfloor n/2\rfloor$——所以第一步永远是"把序列画成树并圈出最后一个非叶结点"。

## 6. 详细解答

**（1）初始形态（$n=6$，下标即层序）**

```
        1:46
       /     \
   2:79       3:56
   /  \       /
4:38  5:40  6:84
```

叶子为下标 $4,5,6$（因 $2\times4=8>6$），最后一个非终端结点为下标 $3=\lfloor 6/2\rfloor$。

**（2）$i=3$：以 $56$ 为根的子树调整**

结点 $3$ 只有左孩子 $6$（$2\cdot3+1=7>6$）。比较 $R[6]=84$ 与 $R[3]=56$：$84>56$ ⟹ 交换。结点 $6$ 已是叶子，调整结束。

$$R=(46,79,\underline{84},38,40,\underline{56})$$

**（3）$i=2$：以 $79$ 为根的子树调整**

孩子为 $R[4]=38$、$R[5]=40$，较大者为 $40$。$79\ge40$ ⟹ 不必交换，调整结束。

$$R=(46,79,84,38,40,56)\quad(\text{无变化})$$

**（4）$i=1$：以 $46$ 为根的子树调整（需两次下沉）**

- 第一次：孩子 $R[2]=79$、$R[3]=84$，较大者为 $84$（下标 $3$）。$46<84$ ⟹ 交换 $R[1]\leftrightarrow R[3]$：

$$R=(\underline{84},79,\underline{46},38,40,56)$$

- 第二次：$46$ 现处下标 $3$，其孩子为 $R[6]=56$。$46<56$ ⟹ 交换 $R[3]\leftrightarrow R[6]$：

$$R=(84,79,\underline{56},38,40,\underline{46})$$

- 下标 $6$ 是叶子（$2\times6=12>6$）⟹ 下沉终止。

**（5）结果与堆序复核**

$$R=(84,79,56,38,40,46)$$

| 内部结点下标 | 关键字 | 左孩子（$2i$） | 右孩子（$2i+1$） | 是否满足 $R[i]\ge$ 子女 |
|---|---|---|---|---|
| 1 | 84 | $2:79$ | $3:56$ | $84\ge79,84\ge56$ ✓ |
| 2 | 79 | $4:38$ | $5:40$ | $79\ge38,79\ge40$ ✓ |
| 3 | 56 | $6:46$ | — | $56\ge46$ ✓ |

再核对两条全局条件：① 堆顶 $84$ 恰为原序列最大值 ✓；② 结果元素多重集 $\{84,79,56,38,40,46\}$ 与原序列 $\{46,79,56,38,40,84\}$ 完全相同（建堆只交换、不改动数值）✓。

**（6）另一路径验证（自顶向下观察"谁必须下沉"）**

不执行算法也能预判结果：原序列中 $84$ 在下标 $6$（第 3 层），它要成为堆顶必须一路上浮 $6\to3\to1$，路径上的 $56$、$46$ 依次下沉；$56$ 最终停在 $3$ 号位，$46$ 被换到 $6$ 号位——与第（4）步的两次交换完全一致；$79$ 本来就在 $2$ 号位且大于其两个孩子，无须移动。两条推理互相印证 ⟹ 结果唯一。

**答案**：$(84,79,56,38,40,46)$。

## 7. 选项分析

不适用（填空题）。本题无备选支；常见错误结果与成因：

- $(84,79,56,38,40,46)$ 写成 $(84,79,56,46,38,40)$：把 $38,40,46$ 按"原顺序"而非"交换后的位置"填写，即漏掉 $46$ 与 $56$、$84$ 的两次交换；
- $(84,79,46,38,40,56)$：只做了一次交换（$46\leftrightarrow84$）就停止下沉，忘了继续检查 $46$ 的新位置；
- $(46,38,56,79,40,84)$ 之类：起点取错（从叶子或从 $i=1$ 单向往下做一遍），根本不构成堆；
- 只答"堆顶是 84"而漏写整个序列：本题要求"建立的初始堆"，须给出全部 $6$ 个关键字的层序排列。

## 8. 考场标准答案

$n=6$，最后一个非叶结点为 $\lfloor n/2\rfloor=3$，依次对 $i=3,2,1$ 做筛选（大顶堆）：

$$\begin{aligned}
&(46,79,56,38,40,84)\xrightarrow{i=3:\,56\leftrightarrow84}(46,79,84,38,40,56)\\
\xrightarrow{i=2:\,79\ge38,40\ \text{不变}}&(46,79,84,38,40,56)\\
\xrightarrow{i=1:\,46\leftrightarrow84,\ 46\leftrightarrow56}&(84,79,56,38,40,46)
\end{aligned}$$

故初始堆为 $\boxed{(84,79,56,38,40,46)}$。

## 9. 易错点

1. **起点取错**：从 $i=n$ 或 $i=1$ 开始单向调整。正确起点是 $\lfloor n/2\rfloor$（最后一个非终端结点），且方向是 $i$ 递减；
2. **下沉只做一层**：$i=1$ 时把 $46$ 与 $84$ 交换后就收工，漏掉 $46$ 在下标 $3$ 处还要与孩子 $56$（交换前在下标 $6$）再换一次；口诀是"**换一次就要重新检查新的一层**"；
3. **孩子取错**：结点 $3$ 只有左孩子 $6$（$2\cdot3+1=7>6$），不要凭空比较一个不存在的右孩子；
4. **比较对象错**：调整时要与"**左右孩子中较大者**"比较并交换，而不是只与左孩子比（$i=1$ 处若只与左孩子 $79$ 交换，会得到 $(79,46,84,\dots)$，不是堆）；
5. **输出顺序写错**：答案要按数组下标（层序）写，写成中序遍历序列会完全看不出堆序；
6. **堆型搞错**：升序堆排序建**大顶堆**（堆顶最大）。若误建小顶堆，堆顶会是 $38$，与"最大值应在堆顶"的排序目的相反。

## 10. 一句话规律

建初始堆三步：**画成完全二叉树 → 从 $\lfloor n/2\rfloor$ 号结点起自底向上逐个"下沉"（与较大孩子交换，换完继续往下查）→ 用"堆顶是最大元、元素集合不变、每个内部结点不小于子女"三条件复核**。
