# DS-2019-11

## 1. 原题

中缀算式 $(3+4X)-2Y/3$ 对应的后缀算式为____________________。

## 2. 答案

$$3\ \ 4\ \ X\ \ *\ \ +\ \ 2\ \ Y\ \ *\ \ 3\ \ /\ \ -$$

即后缀（逆波兰）算式为 **`3 4 X * + 2 Y * 3 / -`**（运算对象均为单字符时可连写作 `34X*+2Y*3/-`）。

## 3. 题目分析

- 已知：一个中缀算式 $(3+4X)-2Y/3$，含括号与 `+`、`-`、`*`、`/` 四种运算符（共出现 $5$ 次，其中 `*` 出现两次），运算对象为 $3,4,X,2,Y,3$；
- 目标：写出等价的**后缀算式**（运算符位于其两个运算对象之后，逆波兰式）；
- 关键约束（三条都会直接影响结果）：
  1. **隐式乘法要补回**：$4X$、$2Y$ 是代数写法，按算式处理时必须先补显式乘号，成为 $4*X$、$2*Y$，否则后缀式中会少一个运算符，操作数与运算符的数目关系不成立；
  2. **优先级**：`*`、`/` 高于 `+`、`-`；括号 $(3+4X)$ 优先于一切；
  3. **同优先级左结合**：$2Y/3$ 应理解为 $(2*Y)/3$ 而非 $2*(Y/3)$ —— 二者后缀式不同，是本题最容易翻车之处；
- 命题意图：检验"中缀 ⟷ 后缀"互译的标准方法（算符优先栈，或表达式树的后序遍历），并顺带考"隐式运算符的还原"与"左结合"这两个书写细节。后缀式无括号、无需记优先级，是栈在表达式求值中最经典的应用（教材引入逆波兰式的动机正是"扫描一遍即可求值"）。

## 4. 核心考点

核心考点：
DS02.07 栈、队列和数组的应用（表达式求值：中缀式 ⟷ 后缀式互译，算符优先与括号消去）

辅助考点：
DS03.02.03 二叉树的遍历（表达式二叉树的后序遍历即后缀算式；先序＝前缀、加括号的中序＝中缀）

解释：本题的求解对象是"表达式的符号表示形式"，属 DS02.07 中栈应用的经典条目；而"后缀式＝表达式树的后序序列"这一结构性事实（DS03.02.03）给出了另一条完全不依赖栈的推法，二者互为验证，故列为辅助。

## 5. 解题思路

1. **先把算式规范化**：补隐式乘号、明确结合性，得到等价显式中缀式 `(3 + 4*X) - 2*Y/3`；
2. **用"加括号—运算符后移"法直接写**：把每个运算按其实际结合次序**完全加括号**
   $$((3+(4*X))-((2*Y)/3))$$
   然后把每个运算符移到**与它配对的右括号之外**（即紧跟它的两个运算对象之后），括号全部去掉，即得后缀式；
3. **用表达式树复核**：根是最后执行的运算（最外层的 `-`），左子树是 $3+4*X$，右子树是 $2Y/3$；对树做后序遍历（左—右—根），序列必须与第 2 步相同；
4. **用算符优先栈再复核一遍**：自左向右扫描，遇运算对象直接输出，遇 `(` 入栈，遇 `)` 弹出并输出直到 `(`，遇运算符先把栈顶**优先级不低于它**的运算符弹出输出（`*`、`/` 之间因左结合要弹，`+`、`-` 遇 `*`、`/` 不弹），再把自己入栈；扫描完弹空栈；
5. **求值验证**：给 $X$、$Y$ 代两组数，分别用中缀（按优先级）与后缀（栈式求值）算，结果一致才收笔。

想到这一点的线索：写后缀式不要"凭感觉移动符号"，永远走"**完全加括号 → 运算符贴着右括号往外搬**"这条机械步骤，或者画出表达式树读后序——两种都是零判断量的程序化方法。

## 6. 详细解答

### 6.1 预处理：还原隐式运算符

$4X$、$2Y$ 按代数惯例分别是 $4\times X$、$2\times Y$，补上运算符后原式为

$$(3+4*X)-2*Y/3$$

运算符共 $5$ 个（`+`、`*`、`*`、`/`、`-`），运算对象共 $6$ 个（$3,4,X,2,Y,3$），满足"$n$ 个二元运算符配 $n+1$ 个运算对象"（$5+1=6$ ✓），可作为后续检查的基准数目。

### 6.2 方法一：完全加括号 ＋ 运算符后移

按真实执行次序（括号优先 → 乘除 → 加减，同级左结合）逐层加括号：

$$\Big(\;\big(3+(4*X)\big)\;-\;\big((2*Y)/3\big)\;\Big)$$

执行次序为：$4*X$ → $3+(\cdot)$ → $2*Y$ → $(\cdot)/3$ → 最后相减。

把每个运算符移到其所在括号的**右括号之后**，再删去所有括号：

| 子表达式 | 括号内形式 | 运算符后移结果 |
|---|---|---|
| $4*X$ | $(4*X)$ | `4 X *` |
| $3+4X$ | $(3+(4*X))$ | `3 4 X * +` |
| $2*Y$ | $(2*Y)$ | `2 Y *` |
| $2Y/3$ | $((2*Y)/3)$ | `2 Y * 3 /` |
| 整体相减 | $\big((3+(4*X))-((2*Y)/3)\big)$ | `3 4 X * + 2 Y * 3 / -` |

得后缀式 $3\ 4\ X\ *\ +\ 2\ Y\ *\ 3\ /\ -$。

### 6.3 方法二：表达式二叉树的后序遍历（独立复核）

最外层运算 `-` 为根；其左子为 `+`（左孩子 $3$，右孩子 `*`），其右子为 `/`（左孩子 `*`，右孩子 $3$）：

```
                 -
             /       \
           +            /
         /   \       /   \
        3     *     *     3
             / \   / \
            4   X 2   Y
```

（叶子自左至右为 $3,4,X,2,Y,3$，内部结点自上而下、自左至右为 `+`、`*`、`*`、`/`、`-`。）

后序遍历"左—右—根"：

- 左子树 `+`：先遍历其左 $3$，再遍历其右子树 `*`（得 `4 X *`），最后根 `+` → `3 4 X * +`；
- 右子树 `/`：先遍历其左子树 `*`（得 `2 Y *`），再遍历其右 $3$，最后根 `/` → `2 Y * 3 /`；
- 整棵树根 `-` → 拼接得 `3 4 X * + 2 Y * 3 / -`。

与方法一逐字相同 ✓。同时可读出不含括号的后缀式为何能唯一确定运算次序：树形已把优先级与结合性编码在结构里。

### 6.4 方法三：算符优先栈逐符号走查（第三种复核，也是通用算法）

扫描串 `(3+4*X)-2*Y/3`，`out` 为输出串，`stk` 为运算符栈（左端为栈底）：

| # | 读入符号 | 动作依据 | 动作 | $out$ | $stk$ |
|---|---|---|---|---|---|
| 1 | `(` | 左括号直接入栈 | push | （空） | `(` |
| 2 | `3` | 运算对象 | output | `3` | `(` |
| 3 | `+` | 栈顶是 `(`，不弹 | push | `3` | `(` `+` |
| 4 | `4` | 运算对象 | output | `3 4` | `(` `+` |
| 5 | `*` | `*` 优先级高于栈顶 `+`，不弹 | push | `3 4` | `(` `+` `*` |
| 6 | `X` | 运算对象 | output | `3 4 X` | `(` `+` `*` |
| 7 | `)` | 弹到 `(` 为止 | pop `*`、pop `+`、丢弃 `(` | `3 4 X * +` | 空 |
| 8 | `-` | 栈空 | push | `3 4 X * +` | `-` |
| 9 | `2` | 运算对象 | output | `3 4 X * + 2` | `-` |
| 10 | `*` | `*` 高于栈顶 `-`，不弹 | push | `3 4 X * + 2` | `-` `*` |
| 11 | `Y` | 运算对象 | output | `3 4 X * + 2 Y` | `-` `*` |
| 12 | `/` | `/` 与栈顶 `*` **同级**，因乘除**左结合**须先弹栈顶 | pop `*`；新栈顶 `-` 低于 `/`，停 | `3 4 X * + 2 Y *` | `-` `/` |
| 13 | `3` | 运算对象 | output | `3 4 X * + 2 Y * 3` | `-` `/` |
| 14 | 结束 | 弹空栈 | pop `/`、pop `-` | `3 4 X * + 2 Y * 3 / -` | 空 |

第 **12** 步是本题唯一有判断量的一步：`2Y/3` 读作 `(2*Y)/3`，故 `*` 必须先于 `/` 输出；若错按右结合处理会得到 `2 Y 3 / *`，对应中缀 $2*(Y/3)$——数值虽巧合相同（$Y=3$ 时），符号串与算法含义都不同。

三种方法输出完全一致。

### 6.5 自我验证：代入求值（两法互验）

后缀式的正确性可用"它与中缀式对任意赋值结果相同"来检验。取 $X=1,\ Y=3$：

- 中缀按优先级：$(3+4\times1)-2\times3/3=7-2=5$；
- 后缀栈式求值（遇运算符取**次栈顶 $op$ 栈顶**）：

| 符号 | 栈内容（右端为栈顶） |
|---|---|
| `3 4 X(=1)` | `3 4 1` |
| `*` | `3 4` |
| `+` | `7` |
| `2 Y(=3)` | `7 2 3` |
| `*` | `7 6` |
| `3` | `7 6 3` |
| `/` | `7 2` |
| `-` | `5` |

得 $5$，与中缀一致 ✓（结束时栈中恰剩一个元素，也是格式合法的旁证）。

再取一组不同的值 $X=2,\ Y=6$ 以防巧合：

- 中缀：$(3+8)-12/3=11-4=7$；
- 后缀：$3,4,2\to *$ 得 $4\times2=8$；$+$ 得 $3+8=11$；$2,6\to*$ 得 $12$；再除 $3$ 得 $4$；末了 $11-4=7$ ✓。

两组赋值、四条独立计算全部吻合，故后缀式为

$$\boxed{3\ \ 4\ \ X\ \ *\ \ +\ \ 2\ \ Y\ \ *\ \ 3\ \ /\ \ -}$$

### 6.6 附：通用转换规则（教材风格伪代码）

```c
/* 中缀 ⟶ 后缀：运算对象为单字符，运算符只有 + - * /，括号成对 */
while (ReadCh(c)) {                    /* c 为当前读入符 */
    if (IsOperand(c)) PutOnOut(c);                    /* 运算对象直接输出 */
    else switch (c) {
        case '(': Push(opnd, c); break;
        case ')': while (GetTop(opnd, t) && t != '(') { Pop(opnd, t); PutOnOut(t); }
                   Pop(opnd, t);                       /* 丢弃左括号 */
                   break;
        default : while (GetTop(opnd, t) && Precede(t, c)) {   /* 栈顶不低则先弹 */
                       Pop(opnd, t); PutOnOut(t);
                   }
                   Push(opnd, c);
    }
}
while (!StackEmpty(opnd)) { Pop(opnd, t); PutOnOut(t); }        /* 弹空剩余运算符 */
```

其中 $Precede(t,c)$ 在 $t$、$c$ 同为 `*`、`/` 时取真（左结合 ⟹ 先弹栈顶），在 $t$ 为 `+`、`-` 而 $c$ 为 `*`、`/` 时取假。时间 $O(n)$，$n$ 为符号个数。

## 8. 考场标准答案

先把隐式乘法补回、按左结合加全括号：$((3+(4*X))-((2*Y)/3))$，再把每个运算符移到其右括号之后并删括号：

$$\text{后缀算式：}\ 3\ \ 4\ \ X\ \ *\ \ +\ \ 2\ \ Y\ \ *\ \ 3\ \ /\ \ -$$

（书写上可用空格分隔，也可因运算对象均为单字符而连写为 `34X*+2Y*3/-`；后缀式中**不应再出现括号**。）

## 9. 易错点

1. **漏掉隐式乘号**：把 $4X$ 当一个运算对象，写出 `3 4 + ...`（少一个 `*`，且把 `+` 提前）。检查办法：运算符个数应为"运算对象个数 $-1$"，本题是 $6$ 个对象、$5$ 个运算符；
2. **$2Y/3$ 的结合方向弄反**：写成 `2 Y 3 / *`（即 $2*(Y/3)$）。乘除同级**左结合**，须先算 $2*Y$，正确片段是 `2 Y * 3 /`；
3. **丢了最外层的减号或把它放错位置**：整棵树最后执行的运算是 `-`，所以后缀式**最后一个符号必为 `-`**；根的左端是 `3 4 X * +`，右端是 `2 Y * 3 /`，写成 `3 4 X * + - 2 Y * 3 /` 是典型错误（减号两侧的操作数位置颠倒/错位）；
4. **后缀式里仍保留括号**：后缀式的意义就在于用位置取代优先级，出现括号即为概念未通；
5. **把括号内的 `+` 与括号外的 `*` 次序排错**：$(3+4X)$ 内部 `+` 最后执行，故 `3 4 X * +` 中 `+` 必在该片段末尾——"先算的符号先出现"；
6. 误以为 $4X$ 中 $4$ 与 $X$ 谁在前无所谓（乘法可交换，$4\ X\ *$ 与 $X\ 4\ *$ 同值），但减法、除法不可交换：`3` 与 `2Y/3` 的先后、`2 Y * 3 /` 中 $3$ 的位置都不能动，答卷时按原式左右顺序写最稳妥。

## 10. 一句话规律

中缀转后缀永远走机械两步——**"按真实次序完全加括号，再把每个运算符搬到它配对的右括号外面"**（等价于画表达式树读后序）；转完必查两件事：后缀式末尾是最后执行的运算符、运算符数 $=$ 运算对象数 $-1$。

## 11. 关联知识

- **表达式树三序对应**：先序＝前缀式（本题为 `- + 3 * 4 X / * 2 Y 3`）、中序＋括号＝中缀式、后序＝后缀式；由任一序列还原树再读另一序列，是表达式类题目通用的互验手段（见 DS-2015-25：由先序建表达式树求值；DS-2017-29、DS-2014-26：由后序＝逆波兰式求值）；
- **后缀式求值**（本题的逆向问法）：遇对象压栈、遇运算符弹出两目计算后压回，且必须"次栈顶 $op$ 栈顶"，见 DS-2018-21（`abcd-*+ef/-` 求值得 $-4$）；
- **栈在表达式中的另一用途**是括号匹配（DS-2016-04 及 DS-2015-06、DS-2007-15：判括号配对最佳数据结构为栈），与本节点"算符优先栈"同一 LIFO 机制；
- 本卷第 5 题（前缀码判定）与本题同为"靠书写规则消歧"：后缀式靠运算符元数固定（二目）且无括号来消除优先级歧义，前缀码靠"任一码字非他人前缀"实现即时译码；
- 若有负号（一元取负）或多字符数（如 $123$、变量名 $XY$），须先用词法切分保证"运算符数 $=$ 对象数 $-1$"，否则本题的检查手段会失效。
