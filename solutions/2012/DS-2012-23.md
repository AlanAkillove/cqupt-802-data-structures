# DS-2012-23

## 1. 原题

设栈 $S$ 和队列 $Q$ 的初始状态皆为空，元素 $a,b,c,d,e$ 和 $f$ 依次通过一个栈，一个元素出栈后即进入队列 $Q$ ，若 $6$ 个元素出队列的顺序是 $c,e,d,f,b,a$ 则栈 $S$ 至少应该容纳____________________ 个元素。

## 2. 答案

$4$。

即顺序栈的容量（可同时存放的元素个数上限）至少为 $4$，才能实现题设的出队顺序。

## 3. 题目分析

- 已知：入栈顺序固定为 $a,b,c,d,e,f$（"依次通过一个栈"）；每个元素出栈后立即进入队列；出队顺序为 $c,e,d,f,b,a$；
- 目标：求满足上述进出过程所需的**最小栈容量**，即所有合法调度中栈内元素个数的最大值的下确界；
- 关键约束：
  1. 队列先进先出、**不改变顺序**，因此"出栈序列"与"出队序列"完全相同 ⟹ 问题化归为：入栈序列 $a,b,c,d,e,f$ 能否得到出栈序列 $c,e,d,f,b,a$，若能得到，实现它时栈最多同时装几个元素；
  2. 入栈顺序固定，出栈顺序被目标序列**逐步锁定**：某一时刻只能弹出"当前应当输出的那个元素"，因此可以出栈的时机不是自由选择，而是由目标序列唯一决定（要么栈顶恰好是待输出元素，要么继续入栈）；
  3. 栈容量不足即发生上溢，过程出错，故"至少容纳"就是峰值大小；
- 命题意图：把"栈的 LIFO 合法性判定"与"队列的 FIFO 保序性"两个性质叠在一起考查，最终落点不是输出序列本身而是**过程的空间峰值**——这要求学生真正逐步模拟进出过程，而不是背结论。

## 4. 核心考点

核心考点：
DS02.01 栈和队列的基本概念（栈的后进先出特性、队列的先进先出特性、给定进栈序列判断出栈序列的过程模拟）

辅助考点：
DS02.02 栈和队列的顺序存储结构（顺序栈的容量与上溢：栈内元素个数达到容量时不能再入栈）

解释：题目的推理对象是"某个元素出栈后进入队列"这一串联结构，判定依据完全是两种结构的逻辑特性（LIFO 与 FIFO），故主体归 DS02.01；而"至少容纳多少个元素"是对顺序栈容量/上溢的量化，属 DS02.02，作为辅助标签。本题不涉及任何具体算法实现或地址计算，因此不打 `ALGORITHM_DESIGN`，能力以 `TRACE`（逐步模拟）为主、`CALCULATION`（求峰值并做下界论证）为辅。

## 5. 解题思路

1. **转化**：队列保序 ⟹ 出栈序列就是 $c,e,d,f,b,a$。先确认"目标可达成"，再谈容量；
2. **贪心模拟**：按入栈顺序 $a\to f$ 逐个压入，每当栈顶等于"下一个待输出元素"就立即弹出——因为入栈顺序固定，若该元素已进栈且已在栈顶，继续压入只会把它压在下面导致永远弹不出，所以"能弹就弹"是唯一可行的调度；顺带记录每一步的栈内元素个数；
3. **读峰值**：全部步骤中的最大栈内元素个数即所求上界；
4. **补下界（证明不能再小）**：找出某个"必然同时在场"的时刻——$e$ 出栈的一瞬间，$a,b,d$ 三个元素都已入栈且都还没出栈，故栈内至少 $4$ 个元素；于是峰值不可能低于 $4$；
5. 上下界相同 ⟹ 答案唯一为 $4$。

## 6. 详细解答

**第一步：把队列条件翻译为栈条件**

队列 $Q$ 只做"保序中转"：入队顺序 $=$ 出队顺序。题设出队顺序为 $c,e,d,f,b,a$，故

$$\text{出栈序列} = c,\,e,\,d,\,f,\,b,\,a$$

而"依次通过一个栈"给出入栈序列固定为 $a,b,c,d,e,f$。

**第二步：逐操作模拟（栈底在左）**

| 序号 | 操作 | 栈内内容（底 $\to$ 顶） | 栈内元素个数 | 本次弹出 |
|---|---|---|---|---|
| 1 | push $a$ | $a$ | 1 | — |
| 2 | push $b$ | $a\ b$ | 2 | — |
| 3 | push $c$ | $a\ b\ c$ | 3 | — |
| 4 | pop | $a\ b$ | 2 | $c$（第 1 个输出）✓ |
| 5 | push $d$ | $a\ b\ d$ | 3 | — |
| 6 | push $e$ | $a\ b\ d\ e$ | **4** ← 峰值 | — |
| 7 | pop | $a\ b\ d$ | 3 | $e$（第 2 个输出）✓ |
| 8 | pop | $a\ b$ | 2 | $d$（第 3 个输出）✓ |
| 9 | push $f$ | $a\ b\ f$ | 3 | — |
| 10 | pop | $a\ b$ | 2 | $f$（第 4 个输出）✓ |
| 11 | pop | $a$ | 1 | $b$（第 5 个输出）✓ |
| 12 | pop | 空 | 0 | $a$（第 6 个输出）✓ |

弹出序列依次为 $c,e,d,f,b,a$，与题设完全一致 ⟹ 该序列是**合法**的出栈序列，且上述调度是可行的。

**第三步：说明该调度是唯一可行的（所以峰值不是"碰巧"取到）**

设当前应当输出的元素为 $x$（即目标序列中尚未输出的第一个）。分三种情形看此刻能做什么：

- 若 $x$ 尚未入栈：只能继续 push（不 push 就无法让 $x$ 进入栈），这是被迫的；
- 若 $x$ 已入栈但不在栈顶：挡住它的元素都是在 $x$ 之后入栈的，要取到 $x$ 就必须先把挡路元素弹出，可一旦弹出它们就抢在 $x$ 前面输出，与"目标序列此刻应输出 $x$"矛盾；继续压入新元素只会叠得更高，故此时过程卡死，序列非法；
- 若 $x$ 已入栈且在栈顶：只能立即 pop（再压入新元素会把 $x$ 压住，转入上一条的死局）。

可见每一步操作都被目标输出序列强制确定，整条操作序列唯一，上表就是唯一的过程，其栈内个数峰值 $4$ 也是该过程的固有峰值（不存在另一种"峰值更小"的调度）。

**第四步：单独给出下界论证（容量为什么不能是 3）**

考察 $e$ 出栈的那一刻，此时输出进度为"$c$ 已出、$e$ 正出"：

- $a$：出栈排在第 5 位，尚未出栈 ⟹ 仍在栈中；
- $b$：出栈排在第 6 位，尚未出栈 ⟹ 仍在栈中（且被压在 $a$ 之上，两者都不能提前弹出，否则会打乱输出序列）；
- $d$：入栈序在 $e$ 之前（第 4 个入栈），出栈序在 $e$ 之后（第 3 个出栈）⟹ 此刻仍在栈中；
- $e$：此刻正在出栈 ⟹ 在栈中且位于栈顶。

故该时刻栈中至少同时存在 $\{a,b,d,e\}$ 四个元素，容量 $3$ 的顺序栈在此之前就已上溢（第 6 步 push $e$ 时无法写入）。所以所需容量 $\ge 4$；结合第二步模拟中容量 $4$ 即可完成全过程，容量 $=4$。

**参考实现（教材风格，仅用于说明计数方式）**

```c
/* in[] 为固定入栈序列，out[] 为给定的出栈(出队)序列，两者长度均为 m */
/* 返回完成该过程所需的最大栈内元素个数；若序列非法则返回 -1 */
int NeedStackSize(char in[], char out[], int m)
{
    SqStack S;
    SElemType e;
    int i = 0, j = 0, top = 0, maxDeep = 0;   /* top 为栈内元素个数 */

    InitStack(S);
    while (j < m) {
        if (top > 0 && GetTop(S) == out[j]) {  /* 栈顶正是待输出元素：弹出 */
            Pop(S, &e);  --top;  ++j;
        } else if (i < m) {                    /* 否则继续按序入栈 */
            Push(S, in[i]);  ++i;  ++top;
            if (top > maxDeep) maxDeep = top;  /* 记录峰值 */
        } else {
            return -1;                         /* 待输出元素不在栈中：序列非法 */
        }
    }
    return maxDeep;                            /* 本例执行结果为 4 */
}
```

**结论**：栈 $S$ 至少应该容纳 $\boxed{4}$ 个元素。

## 8. 考场标准答案

$4$。

考场写法（可直接誊抄）：队列不改变顺序，故出栈序列为 $c,e,d,f,b,a$。按入栈序 $a,b,c,d,e,f$ 模拟：

$$\underbrace{push\,a,b,c}_{\text{栈内 }3}\ pop\,c \to \underbrace{push\,d,e}_{\text{栈内 }4}\ pop\,e \to pop\,d \to push\,f \to pop\,f \to pop\,b \to pop\,a$$

栈内元素个数依次为 $1,2,3,2,3,4,3,2,3,2,1,0$，最大值为 $4$；又 $e$ 出栈瞬间 $a,b,d,e$ 必同时在栈中，故容量不能小于 $4$。答案 $4$。

## 9. 易错点

1. **把队列当成"再倒一次"**：误认为出队顺序是出栈顺序的逆序，于是先反推一个"出栈序列 $a,b,f,d,e,c$"再做模拟，结果全错。队列是 FIFO，进出顺序一致，中转栈才是改变顺序的唯一环节；
2. **答成 $3$**：只看到"前三个 $a,b,c$ 入栈后弹出 $c$"这一步的峰值 $3$，漏掉 $d,e$ 是在 $a,b$ 仍留在栈中时压入的。判断峰值必须整程模拟，或在关键输出时刻做"谁必然在场"的分析（见第 6 节第四步）；
3. **答成 $6$**：把"依次通过一个栈"误解为"六个元素全部入栈后再出栈"。若真如此，输出只能是 $f,e,d,c,b,a$（逆序），与题设不符；入栈与出栈是交替进行的；
4. **计数时机写错**：峰值应统计**入栈之后**的栈内个数（如上表第 6 步 $4$），若只统计"弹出之后"的个数会漏掉最大值；
5. **先判合法性再谈容量**：本题的 $c,e,d,f,b,a$ 合法，但同型题也可能给出非法序列，例如入栈序 $a,b,c,d,e,f$ 配出栈序 $d,b,c,e,f,a$：$d$ 出栈时栈中为 $a,b,c$，$b$ 被 $c$ 压在下面，而目标序列要求紧接着输出 $b$ —— 弹出 $c$ 会抢在 $b$ 前面输出、不弹又取不到 $b$，过程卡死。遇到这种序列的正确结论是"不可能实现"，此时不存在可用的栈容量（判据见第 6 节第三步）。

## 10. 一句话规律

"栈接队列"题型三步走——队列 FIFO 保序（出栈序列 $=$ 出队序列）、按固定入栈序贪心模拟（栈顶是待输出元素就弹、否则压入，调度唯一）、读栈内个数峰值并挑一个"某元素出栈瞬间谁必然在场"的时刻证下界；问"至少容纳几个"就是要这个峰值。
