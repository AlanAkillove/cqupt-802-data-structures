# DS-2012-24

## 1. 原题

用数组 $Q$ （其下标在 $0,\cdots,n-1$ ，共有 $n$ 个元素）表示一个循环队列， $f$ 为当前队头元素的前一个位置， $r$ 为队尾元素位置，假定队列中元素个数总小于 $n$ ，求队列中元素个数的公式是____________________ 。

## 2. 答案

$$(\,(r-f+n)\,)\bmod n$$

即 `(r - f + n) % n`。

## 3. 题目分析

- 已知：循环队列的存储数组 $Q[0\cdots n-1]$（容量 $n$ 个下标）；指针语义被题面**明确给出**——$f$ 是"当前队头元素的前一个位置"，$r$ 是"队尾元素位置"；另给定"队列中元素个数总小于 $n$"；
- 目标：用 $n,f,r$ 表示队列中当前的元素个数；
- 关键约束：
  1. 下标是环形的，$r$ 可能已经回绕到 $f$ 之前，直接写 $r-f$ 会得到负数；
  2. 两个指针的"错位方向"决定要不要加 $1$：本题 $f$ 空着一格（指队头的前驱）、$r$ 压在队尾元素上，两者从两端各偏一格，恰好在计数上互补；
  3. "元素个数总小于 $n$"保证 $f=r$ 唯一地表示空队，也使公式的取模只需做一次；
- 命题意图：考循环队列"指针约定 → 长度公式"的换算，重点不在记住 $(r-f+n)\bmod n$ 这个式子，而在于**按题面给的约定现场推出来**——同一式子在另一套常见约定（$f$ 指队头元素本身、$r$ 指队尾元素的下一位置）下也成立，而第三套约定（两指针都指元素本身）则要加 $1$，只会背公式容易在约定变化时答错。

## 5. 解题思路

1. **锁定约定**：$f$ 不存元素（它是队头元素的前驱位置），$r$ 存着队尾元素。于是元素恰好排在下标
   $$f+1,\ f+2,\ \cdots,\ r\qquad(\text{下标按模 } n \text{ 循环})$$
   上，"元素个数"就是这段环形区间包含的格数；
2. **拆两种情形**（去掉"循环"的抽象，各自用普通算术数格子）：
   - 未回绕 $r\ge f$：区间不退化，个数 $=r-(f+1)+1=r-f$；
   - 回绕 $r<f$：分成两段 $[f+1,\,n-1]$ 与 $[0,\,r]$，个数 $=(n-1-f)+(r+1)=r-f+n$；
3. **合并**：两式统一写作 $(r-f+n)\bmod n$——未回绕时 $r-f+n\in[n,\,2n-1]$ 取模减掉 $n$ 得 $r-f$，回绕时 $r-f+n\in[1,\,n-1]$ 取模不变，两情形都被覆盖；
4. **边界自检**：空队（$f=r$）应得 $0$、只有一个元素（$r\equiv f+1$）应得 $1$、回绕（$r<f$）应得 $r-f+n$、装到最多（$r\equiv f-1$）应得 $n-1$，与"元素个数总小于 $n$"吻合；
5. **实例复核**：代入本卷第 7 题的真实数据（$n=6$，$rear=0$、$front=3$，删 $2$ 个、加 $1$ 个）逐步核对公式与人工计数一致。

## 6. 详细解答

**第一步：本题约定下的入队/出队动作**

设数组为 $Q[0\cdots n-1]$，$f$、$r$ 按题面语义定义，则

```c
/* 入队：先在环上前进一格，再写入 —— r 始终压在队尾元素上 */
Q.rear = (Q.rear + 1) % n;
Q.base[Q.rear] = x;               /* 队满时禁止此操作 */

/* 出队：先在环上前进一格，再读出 —— f 始终空在队头前驱上 */
Q.front = (Q.front + 1) % n;
x = Q.base[Q.front];
```

队空条件为 `Q.front == Q.rear`（此时环上区间 $[f+1,\dots,r]$ 一格也没有）。

**第二步：分情形数格子**

记"队头元素的下标"为 $h\equiv f+1\pmod n$，队尾元素下标为 $r$，则元素个数为从 $h$ 沿入队方向走到 $r$ 的格数（含两端）。

- **情形 1：$r\ge f$（含 $r=f$ 的空队，且尚未回绕）**

  元素连续存放于 $Q[f+1\cdots r]$，个数
  $$L=r-(f+1)+1=r-f$$

- **情形 2：$r<f$（队尾已回绕到数组前端）**

  元素分两段：$Q[f+1\cdots n-1]$ 共 $(n-1)-(f+1)+1=n-f-1$ 格；$Q[0\cdots r]$ 共 $r-0+1=r+1$ 格。合计
  $$L=(n-f-1)+(r+1)=r-f+n$$

**第三步：合并为一个取模公式**

$$L=\begin{cases}r-f, & r\ge f\\[4pt] r-f+n, & r<f\end{cases}\qquad=\qquad (r-f+n)\bmod n$$

验证合并的正确性：由 $0\le f,r\le n-1$ 得 $-(n-1)\le r-f\le n-1$，两边加 $n$ 后
$$1\ \le\ r-f+n\ \le\ 2n-1\ <\ 2n$$
（下界 $1$ 在 $r=0,\ f=n-1$ 时取到，此时仅 $Q[0]$ 一格里有元素；上界 $2n-1$ 在 $r=n-1,\ f=0$ 时取到。）所以"加 $n$ 再取模"至多减一次 $n$，恰好把情形 1 的 $r-f+n\in[n,2n-1]$ 拉回 $r-f$，情形 2 的 $r-f+n\in[1,n-1]$ 原样保留；$r=f$（空队）时 $r-f+n=n$，取模得 $0$ ✓。因此一次取模即覆盖全部情形，不需要额外的条件判断。

$$\boxed{\,L=(r-f+n)\bmod n\,}$$

**第四步：四个边界复核**

| 状态 | 指针关系 | 人工数格子 | 公式 $(r-f+n)\bmod n$ |
|---|---|---|---|
| 空队 | $r=f$ | $0$ | $n\bmod n=0$ ✓ |
| 仅 $1$ 个元素（$f=2,r=3,n=6$） | $r=f+1$ | $1$ | $(3-2+6)\bmod 6=1$ ✓ |
| 回绕（$f=4,r=1,n=6$，元素在 $5,0,1$） | $r<f$ | $3$ | $(1-4+6)\bmod 6=3$ ✓ |
| 装到最多（$r\equiv f-1\pmod n$） | $r-f+n=n-1$ | $n-1$ | $n-1$ ✓（与"元素个数总小于 $n$"一致） |

**第五步：用本卷第 7 题的真实数据交叉验证**

DS-2012-07 给出 $n=6$、初始 $rear=0$、$front=3$：

- 公式给出元素个数 $(0-3+6)\bmod 6=3$，即元素位于 $Q[4],Q[5],Q[0]$，人工数格子同为 $3$ ✓；
- 删除 $2$ 个：$front$ 前进两格 $3\to 5$；再插入 $1$ 个：$rear$ 前进一格 $0\to 1$；
- 该题答案为 A（$rear=1$、$front=5$），代入公式得 $(1-5+6)\bmod 6=2$，与"原有 $3$ 个、删 $2$ 剩 $1$、加 $1$ 变 $2$"完全一致 ✓。

两处独立核对均自洽，说明本题所用约定与公式无误。

**第六步：三套常见约定的对照（防混淆）**

| 约定 | $f$（队头指针）指向 | $r$（队尾指针）指向 | 元素个数 | 队满条件 |
|---|---|---|---|---|
| **本题** | 队头元素的前一个位置 | 队尾元素本身 | $(r-f+n)\bmod n$ | $(r+1)\bmod n=f$（最多 $n-1$ 个） |
| 另一常见式 | 队头元素本身 | 队尾元素的下一个位置 | $(r-f+n)\bmod n$（同式） | $(r+1)\bmod n=f$（最多 $n-1$ 个） |
| 两指针都指元素本身 | 队头元素本身 | 队尾元素本身 | $(r-f+1+n)\bmod n$ | 需增设 `count` 或牺牲一位，否则 $f=r$ 无法区分队空/队满 |

第一、二行同式并非巧合：$f$ 与 $r$ 各向相反方向偏一格，偏掉的 $+1$ 与 $-1$ 相互抵消；第三行两端都指元素本身，没有这种抵消，故必须补 $+1$。

**参考实现（教材风格）**

```c
/* 约定：Q.front 为队头元素的前一个位置，Q.rear 为队尾元素位置，数组容量为 n */
int QueueLength(CSqQueue Q, int n)
{
    return (Q.rear - Q.front + n) % n;   /* 本卷第 7 题数据代入得 3，删 2 加 1 后得 2 */
}
```

时间复杂度 $O(1)$，仅需一次加法与一次取模；空间复杂度 $O(1)$。

**结论**：队列中元素个数的公式是 $(r-f+n)\bmod n$。

## 8. 考场标准答案

$$(r-f+n)\bmod n\qquad(\text{写作 }(r-f+n)\%n\text{ 亦可})$$

一行推导可直接誊写：元素占据下标 $f+1,\dots,r$（模 $n$ 循环）。未回绕（$r\ge f$）时个数为 $r-f$；回绕（$r<f$）时为 $(n-f-1)+(r+1)=r-f+n$。两式合并即 $(r-f+n)\bmod n$。

## 9. 易错点

1. **漏写 $+\,n$**：只写 $r-f$，一旦队尾回绕（$r<f$）就得到负数。加 $n$ 是把负差值抬进 $[0,n)$ 的标准手法，取模符号也须作用于整个 $r-f+n$；
2. **误加 $1$**：写成 $(r-f+1+n)\bmod n$。本题 $f$ 指向队头元素的**前驱**，即从 $f$ 出发走 $r-f$ 步正好落到队尾元素，两端不需要再补 $1$；只有"$f$、$r$ 都指元素本身"的约定才需 $+1$，判据是"$f$ 这一格里到底有没有元素"；
3. **把 $r=f$ 当成队满**：在该约定下 $f=r$ 表示**队空**，队满是 $(r+1)\bmod n=f$（此时元素个数 $n-1$），题面"元素个数总小于 $n$"正是在提示这个约定下永远留不出第 $n$ 格；
4. **照搬别的约定的结论**：把 DS-2007-01 的"牺牲一个单元判满"与本题长度式混用，或在本题约定下多余的补上 $+1$。两套公式必须按当次题面的指针措辞现推；
5. **写 $(r-f)\%n$**：形式上像在取模，但 $r-f<0$ 时该表达式在 C 语言中返回负值（余数符号跟随被除数），并不等于环形长度，必须先把被加数抬正再取模。

## 10. 一句话规律

循环队列长度只会数"环上从 $f$ 到 $r$ 走几格"：先按题面措辞确定 $f$、$r$ 各自是"压在元素上"还是"空在一侧"，再分未回绕/回绕两类数格子，最后用"加一个容量 $n$ 再取模"合并——两端各偏一格的约定（$f$ 指前驱、$r$ 指队尾，或 $f$ 指队头、$r$ 指后继）都得同一式 $(r-f+n)\bmod n$，两端都指元素本身时式子多一个 $+1$。
