# DS-2012-38

## 1. 原题

已知二叉树的先序序列和中序序列分别为 $ABDGCEFH$ 和 $DGBAECHF$

（1）画出该二叉树；

（2）写出此二叉树的后序序列；

（3）画出与此二叉树对应的森林。

## 2. 答案

**(1)** 二叉树（8 个结点）：

```
        A
      /   \
     B     C
    /     / \
   D     E   F
    \       /
     G     H
```

即广义表写法 $A\big(B(D(\varnothing,G)),\;C(E,\,F(H,\varnothing))\big)$。

**(2)** 后序序列：$G\,D\,B\,E\,H\,F\,C\,A$（写作 **GDBEHFCA**）。

**(3)** 对应的森林含 **3 棵树**（根依次为 $A$、$C$、$F$）：

```
树①          树②      树③
  A            C        F
  |            |        |
  B            E        H
 / \
D   G
```

## 3. 题目分析

- 已知：同一棵二叉树的**先序** $ABDGCEFH$ 与**中序** $DGBAECHF$（各 8 个互异字母，长度相等）；
- 目标：还原唯一的二叉树 → 导出后序 → 按"左孩子—右兄弟"规则反变换为森林；
- 约束：先序 + 中序（或中序 + 后序）可唯一确定一棵二叉树；先序 + 后序则不能（本题不属该情形）；
- 命题意图：三问串起 DS03 的两条主线——**由遍历序列重建树**（切根定位）与**树/森林与二叉树的对应**（`left-child, right-sibling`），并要求会用三种序列互检。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（先序"根左右"给出根的位置、中序"左根右"给出左右子树的划分，二者联用递归重建）

辅助考点：
DS03.02.03.01 前序遍历（每棵子树的根是该段先序的首字符）；DS03.02.03.03 后序遍历（重建后按"左右根"输出，用于第 (2) 问）；DS03.03.02 森林与二叉树的转换（第 (3) 问：二叉树的右链是兄弟、左链是第一个孩子）

解释：第 (1)(2) 问是纯遍历互推，第 (3) 问的"二叉树 → 森林"是 DS03.03.02 的逆向应用；根结点 $A$ 有右孩子 $C$，说明 $A$ 在森林中不是唯一的树，这正是"二叉树的根有右链 ⟺ 对应的是森林而非一棵树"这一性质的直接体现。

## 5. 解题思路

1. **定根**：先序第一个字符必为整棵树的根 → $A$；
2. **切分**：在中序中找到 $A$，其左侧 $DGB$ 是左子树的全部结点（3 个），右侧 $ECHF$ 是右子树的全部结点（4 个）；
3. **对齐**：回到先序，根 $A$ 之后先取 3 个（$BDG$）作左子树的先序，剩下 4 个（$CEFH$）作右子树的先序——**结点数由中序决定，这是先序分段唯一化的关键**；
4. 对左右两部分各自递归执行 1~3，直到区间长度为 1；
5. 重建完成后，直接按"左→右→根"递归输出后序，再用"先序/中序"回读一遍作双向校验；
6. 第 (3) 问按转换规则反向读图：任一结点的**左孩子**是它在树中的**第一个孩子**，沿**右孩子**链走下去是它的**弟弟**；根的右链把森林的若干棵树串起来。

## 6. 详细解答

### (1) 重建二叉树

**第 1 层**：先序 $A|BDG|CEFH$，中序 $DGB|A|ECHF$ → 根 $A$；左子树结点集 $\{D,G,B\}$（先序段 $BDG$、中序段 $DGB$），右子树结点集 $\{E,C,H,F\}$（先序段 $CEFH$、中序段 $ECHF$）。

**第 2 层（左子树）**：先序 $B|DG$，中序 $DG|B$ → 根 $B$；$B$ 在中序中最右 ⇒ $B$ **无右子树**，左子树结点集 $\{D,G\}$（先序段 $DG$、中序段 $DG$）。

**第 3 层（B 的左子树）**：先序 $D|G$，中序 $D|G$ → 根 $D$；$D$ 在中序中最左 ⇒ $D$ **无左孩子**，$G$ 是 $D$ 的**右孩子**。

**第 2 层（右子树）**：先序 $C|EFH$，中序 $E|C|HF$ → 根 $C$；左子树 $\{E\}$，右子树 $\{H,F\}$（先序段 $FH$、中序段 $HF$）。

**第 3 层**：$C$ 的左孩子 $=E$（单结点，无孩子）。$C$ 的右子树：先序 $F|H$，中序 $H|F$ → 根 $F$，$H$ 在 $F$ 左侧 ⇒ $H$ 是 $F$ 的**左孩子**，$F$ 无右孩子。

汇总各结点的孩子：

| 结点 | 左孩子 | 右孩子 | 依据 |
|---|---|---|---|
| A | B | C | 中序中 A 左 3 右 4 |
| B | D | —（空） | 中序段 DGB 中 B 居最右 |
| C | E | F | 中序段 ECHF 中 C 左 1 右 2 |
| D | —（空） | G | 中序段 DG 中 D 居最左 |
| E | — | — | 单结点 |
| F | H | —（空） | 中序段 HF 中 F 居最右 |
| G | — | — | 单结点 |
| H | — | — | 单结点 |

图形即第 2 节所示（8 结点，深度 4，叶子为 $G,E,H$）。

### (2) 后序序列

按"左子树 → 右子树 → 根"递归：

- $D$ 的子树：(左空) $G$ $D$ → $G,D$；$B$ 的子树：$G,D$ (右空) $B$ → $G,D,B$；
- $F$ 的子树：$H$ (右空) $F$ → $H,F$；$C$ 的子树：$E$ ; $H,F$ ; $C$ → $E,H,F,C$；
- 根 $A$：$G,D,B$ ; $E,H,F,C$ ; $A$。

$$\text{后序} = G\,D\,B\,E\,H\,F\,C\,A$$

**双向校验**（用重建出的树回读先序与中序）：

- 先序（根左右）：$A$ → $B$ 子树 $B,D,G$ → $C$ 子树 $C,E,F,H$ ⇒ $A\,B\,D\,G\,C\,E\,F\,H$ ✓ 与题设 $ABDGCEFH$ 一致；
- 中序（左根右）：$D$ 子树 $D,G$ → $B$ → $A$ → $E$ → $C$ → $H$ → $F$ ⇒ $D\,G\,B\,A\,E\,C\,H\,F$ ✓ 与题设 $DGBAECHF$ 一致；
- 三种序列结点集相同、且后序满足"根必在最后、最左叶子 $G$ 必在最先" ✓。

（另可用"先序 + 中序 ⟹ 后序"的直接递推核对：先序 $A|BDG|CEFH$、中序 $DGB|A|ECHF$ ⟹ 后序 $=$ 后序$(BDG,DGB)$ + 后序$(CEFH,ECHF)$ + $A$ = $GDB$ + $EHFC$ + $A$ = $GDBEHFCA$ ✓。）

### (3) 二叉树 → 森林

转换规则（教材"左孩子—右兄弟"表示法的逆用）：二叉树中结点 $x$ 的**左孩子**是 $x$ 在原树中的**第一个孩子**，$x$ 的**右孩子**（及沿右链继续下去的结点）是 $x$ 的**下一个兄弟**。

**第一步：找森林中各棵树的根** —— 从 $A$ 出发沿右链：$A \to C \to F$（$F$ 无右孩子，止）。故森林有 **3 棵树**，根依次是 $A$、$C$、$F$。

**第二步：求每个结点的孩子**（取左孩子，再沿其右链展开成兄弟序列）：

| 结点 | 左孩子 | 沿右链展开 | 在原树中的孩子序列 |
|---|---|---|---|
| A | B | B 无右孩子 | 只有 $B$ |
| B | D | $D \to G$（$D$ 的右孩子） | $D,\;G$ |
| D | 空 | — | 无孩子（叶） |
| G | 空 | — | 无孩子（叶） |
| C | E | E 无右孩子 | 只有 $E$ |
| E | 空 | — | 无孩子（叶） |
| F | H | H 无右孩子 | 只有 $H$ |
| H | 空 | — | 无孩子（叶） |

得到森林：

```
第①棵：  A          第②棵：  C      第③棵：  F
          |                   |               |
          B                   E               H
        /   \
       D     G
```

**校验**（森林 → 二叉树应还原）：第①棵 $A(B(D,G))$ 转换：$A$ 的左孩子 $=B$，$B$ 的左孩子 $=D$、$D$ 的右孩子 $=G$（$D,G$ 是兄弟）✓；第②棵 $C(E)$：$C$ 的左孩子 $=E$ ✓；第③棵 $F(H)$：$F$ 的左孩子 $=H$ ✓；三棵树互为兄弟 ⟹ $A$ 的右孩子 $=C$、$C$ 的右孩子 $=F$ ✓。与 (1) 中的二叉树完全一致。

**补充**：该森林若按"先根/后根"遍历，先根序列 $A,B,D,G,C,E,F,H$ 恰等于二叉树的先序，后根序列 $D,G,B,E,H,F,C,A$ 恰等于二叉树的中序——这是 DS03.03.03 中"树的先根遍历 ↔ 二叉树先序、树的后根遍历 ↔ 二叉树中序"对应关系的实例。

## 8. 考场标准答案

(1) 由先序首字符定根 $A$，在中序中 $A$ 左 3 右 4 ⟹ 左子树先序 $BDG$/中序 $DGB$、右子树先序 $CEFH$/中序 $ECHF$，递归得：

```
        A
      /   \
     B     C
    /     / \
   D     E   F
    \       /
     G     H
```

(2) 后序（左右根）：**GDBEHFCA**。

(3) 按"左孩子=第一个孩子、右孩子=下一个兄弟"，根沿右链 $A\to C\to F$ ⟹ 森林有 3 棵树：

```
  A        C      F
  |        |      |
  B        E      H
 / \
D   G
```

## 9. 易错点

1. 分段时**不用中序的结点数去切先序**，凭字母顺序猜左右子树范围（如误把 $C$ 归入左子树）——正确做法永远是"中序定规模、先序定根"；
2. 忽略"某段中序里根居最左/最右 ⟹ 该结点无左/无右孩子"：$B$ 在中序段 $DGB$ 中最右 ⟹ $B$ 无右孩子；$D$ 在中序段 $DG$ 中最左 ⟹ $D$ 无左孩子。漏掉这一步会多挂或少挂空链，进而把 $G$、$H$ 的左右位置放错；
3. 第 (2) 问写成 $GDBEHFCA$ 时把 $E$、$H$ 顺序颠倒（$E$ 是 $C$ 的左孩子，先序后仍在 $C$ 的子树内，后序中 $E$ 先于 $H,F,C$）；
4. 第 (3) 问把"右链"读成"孩子"（得到 $A$ 有孩子 $C$ 的错误结论），或只画 1 棵树（忘记根 $A$ 有右孩子 ⟹ 对应的是森林）；
5. 误把 $D$、$G$ 当成父子：在二叉树里 $G$ 确实是 $D$ 的右孩子，但在森林中它们是**兄弟**（同为 $B$ 的孩子）——两个图形语言不能混用。

## 10. 一句话规律

"先序定根、中序切分"是重建二叉树的唯一口诀：中序给出左右子树的**规模**，先序给出子树的**根**，递归即可；而二叉树与森林的互转只需记住"左为孩子、右为兄弟"，根的右链长度就是森林中树的棵数。
