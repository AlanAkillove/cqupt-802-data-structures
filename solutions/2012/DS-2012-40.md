# DS-2012-40

## 1. 原题

已知初始序列（ $50,80,63,45,48,92$ ），写出直接插入排序的各趟排序的结果。

## 2. 答案

按"第 $i$ 趟把第 $i+1$ 个记录插入前面长度为 $i$ 的有序子表"（教材约定，$n=6$ 共 $5$ 趟）：

| 趟次 | 插入的记录 | 趟后序列（竖线左为有序子表） |
|---|---|---|
| 初始 | — | $\mid 50,80,63,45,48,92$ |
| 第 1 趟 | 80 | $50,80 \mid 63,45,48,92$（与本趟前相同） |
| 第 2 趟 | 63 | $50,63,80 \mid 45,48,92$ |
| 第 3 趟 | 45 | $45,50,63,80 \mid 48,92$ |
| 第 4 趟 | 48 | $45,48,50,63,80 \mid 92$ |
| 第 5 趟 | 92 | $45,48,50,63,80,92 \mid$ |

## 3. 题目分析

- 已知：含 6 个记录的初始序列，采用**直接插入排序**（升序）；
- 目标：写出**每一趟结束时的整表状态**（不是只写有序子表，也不是只写比较过程）；
- 约束：每趟只处理**一个**待插入记录，前缀始终保持有序；一趟内只做"从右向左扫描有序子表 + 逐个后移 + 落位"；
- 命题意图：考插入排序"趟"的粒度定义（一趟插一个记录）与"有序区只增不减"的不变式，同时用 $80$、$92$ 两个"本来就有序"的记录检验学生是否理解"趟数与记录移动次数可以很小甚至为 0"。

## 4. 核心考点

核心考点：
DS06.02.01 直接插入排序（把 $R[i]$ 插入 $R[1..i-1]$ 的有序表中：先置 $R[0]=R[i]$ 作哨兵，从 $j=i-1$ 起边比较边后移，最后 $R[j+1]=R[0]$）

辅助考点：
DS06.01 排序的基本概念（"趟"的定义、稳定性——本序列关键字互异，不涉及等值稳定问题）

解释：本题只要求模拟过程，属 TRACE；写"趟"必须先锁定"一趟做什么"的约定，否则趟数会差一，故把 DS06.01 的趟概念列为辅助考点。

## 5. 解题思路

1. 定约定：$n$ 个记录做 $n-1$ 趟，第 $i$ 趟处理 $R[i+1]$；初始时把 $R[1]=50$ 视为长度 1 的有序表；
2. 每趟三步：① 取出待插记录（暂存哨兵位）；② 从有序子表**右端**向左比较，凡"比它大"者整体后移一个位置；③ 遇到第一个"不大于它"的记录，把待插记录落在其后；
3. 关键不变式：一趟结束后，$R[1..i+1]$ 有序、$R[i+2..n]$ 保持**初始原序不动**——写答案时未处理部分必须照抄初始序列，不能“顺手”整理；
4. 末趟（第 5 趟）后整表有序，可据此自检：把 5 个结果连起来看，有序区长度应依次为 $2,3,4,5,6$。

## 6. 详细解答

**算法（教材风格，$R[0]$ 用作哨兵/暂存单元）**：

```c
void InsertSort(SqList *L)                 /* L->r[1..n] 为待排记录 */
{
    for (i = 2; i <= L->length; i++)
        if (L->r[i].key < L->r[i-1].key) { /* 仅当待插记录小于有序表最大者才需移动 */
            L->r[0] = L->r[i];             /* 哨兵，避免越界 */
            j = i - 1;
            while (L->r[0].key < L->r[j].key) {
                L->r[j+1] = L->r[j];       /* 比它大的记录逐个后移 */
                j--;
            }
            L->r[j+1] = L->r[0];           /* 落位 */
        }
}
```

**逐趟推导**（数组下标 1~6）：

**第 1 趟**（$i=2$，待插 $80$）：与 $R[1]=50$ 比较，$80>50$ ⟹ 不需后移，$80$ 原地落位。
$$ (50,80,63,45,48,92)\to(50,\mathbf{80},63,45,48,92) $$
比较 1 次，后移 0 次。有序区 $[50,80]$。

**第 2 趟**（$i=3$，待插 $63$）：$63<80$ ⟹ $80$ 后移到 $R[3]$；$63>50$ ⟹ 停止，落位 $R[2]$。
$$ (50,80,\mathbf{63},45,48,92)\to(50,\mathbf{63},80,45,48,92) $$
比较 2 次，后移 1 次。有序区 $[50,63,80]$。

**第 3 趟**（$i=4$，待插 $45$）：$45<80$、$45<63$、$45<50$ ⟹ 三者依次后移；$j$ 减到 $0$，与哨兵 $R[0]=45$ 比较 $45<45$ 为假 ⟹ 落位 $R[1]$。
$$ (50,63,80,\mathbf{45},48,92)\to(\mathbf{45},50,63,80,48,92) $$
比较 4 次（含 1 次哨兵比较），后移 3 次。有序区 $[45,50,63,80]$。

**第 4 趟**（$i=5$，待插 $48$）：$48<80$、$48<63$、$48<50$ ⟹ 后移 3 次；$48>45$ ⟹ 停止，落位 $R[2]$。
$$ (45,50,63,80,\mathbf{48},92)\to(45,\mathbf{48},50,63,80,92) $$
比较 4 次，后移 3 次。有序区 $[45,48,50,63,80]$。

**第 5 趟**（$i=6$，待插 $92$）：$92>80$ ⟹ 不需后移，原地落位。
$$ (45,48,50,63,80,\mathbf{92})\to(45,48,50,63,80,\mathbf{92}) $$
比较 1 次，后移 0 次。整表有序。

**汇总核对**：

| 量 | 数值 |
|---|---|
| 趟数 | $n-1=5$ |
| 关键字比较总次数 | $1+2+4+4+1=12$ |
| 记录后移总次数 | $0+1+3+3+0=7$ |
| 最终序列 | $45,48,50,63,80,92$（升序 ✓） |

**自检依据**：① 每趟有序区长度严格 $+1$（$2\to3\to4\to5\to6$）；② 未处理部分始终为初始的 $63,45,48,92$ 相对原序（第 3 趟后为 $48,92$，第 4 趟后为 $92$）；③ 每趟结果都是前一趟结果的一次"插入"，绝无两处同时变化。

## 7. 选项分析

不适用（问答题）。

## 8. 考场标准答案

$n=6$，共 $5$ 趟（第 $i$ 趟插入第 $i+1$ 个记录）：

```
初始      (50  80  63  45  48  92)
第1趟     (50  80  63  45  48  92)   插入80，无需移动
第2趟     (50  63  80  45  48  92)   插入63，80后移
第3趟     (45  50  63  80  48  92)   插入45，50/63/80后移
第4趟     (45  48  50  63  80  92)   插入48，50/63/80后移
第5趟     (45  48  50  63  80  92)   插入92，无需移动
```

总比较 12 次、总后移 7 次；时间复杂度 $O(n^2)$（本例接近最好情形，序列基本有序），最好 $O(n)$，空间 $O(1)$，且是**稳定**排序。

## 9. 易错点

1. **趟的约定错位**：把"第 1 趟"当成"处理 $R[1]$"，从而只写 4 趟或整体错位一趟。约定必须写明"第 $i$ 趟插入第 $i+1$ 个记录，共 $n-1$ 趟"；
2. 第 1 趟与第 5 趟**序列没有变化**（$80$、$92$ 本来就在正确一侧），容易被误认为"漏写了一趟"而擅自改动序列；
3. 一次把多个记录插入（例如第 2 趟就写成 $45,50,63,80,48,92$）——一趟只允许一个新记录移动，未处理部分必须照抄原序；
4. 与**冒泡/选择排序**的趟结果混淆：选择排序第 1 趟会把最小值 $45$ 换到首位，插入排序第 1 趟只动 $80$；若第 1 趟就写出 $45$ 开头，说明用的是别的算法；
5. 统计比较次数时漏掉哨兵那次比较（第 3 趟 $45<45$ 为假），或把"后移次数"与"落位写入次数"混为一谈。

## 10. 一句话规律

直接插入排序写各趟：每趟只把**一个新记录**塞进左侧有序区（从右向左比、比它大的整体后移），右侧未处理部分一律照抄原题——有序区长度 $2,3,\cdots,n$ 是检查趟数与结果的最硬指标。

## 11. 关联知识

- DS06.02.02 折半插入排序：本序列若改用折半查找插入位置，趟后结果**完全相同**，只是每趟比较次数由"顺序扫描"降为 $O(\log i)$，移动次数不变；
- DS06.03 冒泡排序、DS06.04 简单选择排序的"趟"含义与本题不同（一趟确定一个最值的位置），对比本库 DS-2012-34（对另一序列作直接选择排序第二趟结果）可见差别；
- DS06.11 排序算法识别：本题"前缀有序、每趟只插一个元素"的中间结果特征，正是反推"这是插入排序"的判据（本库 DS-2012-18 快速排序第一趟结果、DS-2012-20 时间复杂度不受初始状态影响者，均为同族辨析题）；
- 直接插入排序在"局部有序"时接近 $O(n)$，与 DS-2012-19（局部有序时最佳内部排序为直接插入排序）结论一致。
