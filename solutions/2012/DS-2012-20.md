# DS-2012-20

## 1. 原题

时间复杂度不受待排序序列初始状态的影响，总是 $O(n^2)$ 的是（）。

A. 直接插入排序

B. 快速排序

C. 简单选择排序

D. 归并排序

## 2. 答案

**C**（简单选择排序）。

## 3. 题目分析

- 已知：四个内部排序方法；衡量指标是"时间复杂度对初始序列状态的依赖性"；
- 目标：找出**同时**满足两个条件的方法——① 最好、最坏、平均情形同为 $O(n^2)$（即与初态无关）；② 量级确实是 $n^2$；
- 关键约束：本题是"双条件筛选"。与初态无关的有简单选择排序（$\Theta(n^2)$）与归并排序（$\Theta(n\log_2 n)$）；量级为 $n^2$ 的有直接插入排序（最坏）与简单选择排序；两条件的交集只有简单选择排序；
- 命题意图：考"依赖性 × 复杂度量级"这张二维表，与本年度 DS-2012-19（利用有序性的方法）互为镜像；同时以归并排序作为"不受影响但量级不对"的干扰项，检验学生是否只会背"不受影响"半句。

## 4. 核心考点

核心考点：
DS06.11 排序算法应用（各内部排序方法的最好/最坏/平均时间复杂度、稳定性与辅助空间对照）

辅助考点：
DS06.04 简单选择排序（每趟在未排序区做一次完整的线性扫描取极值，扫描次数固定）

解释：答案的落点是"为什么选择排序的比较次数是恒定的"，这来自它的执行机制——第 $i$ 趟的比较次数恒为 $n-i$，与序列是否有序毫无关系。

## 5. 解题思路

1. 先算"与初态无关"这一维：写出各法在第 $i$ 趟所作比较次数的表达式，看它是否含"$d_i$（与序有关量）"；
   - 简单选择排序：第 $i$ 趟在未排序区 $R[i+1..n]$ 中找最小，比较 $n-i$ 次，$\sum_{i=1}^{n-1}(n-i)=\frac{n(n-1)}{2}$，**恒定**；
   - 归并排序：趟数 $\lceil\log_2 n\rceil$ 固定、每趟 $O(n)$，**恒定**；
   - 直接插入排序：第 $i$ 趟比较 $d_i+1$ 次，$d_i$ 是前面比 $R[i]$ 大的元素个数，**随初态在 $1$ 到 $i$ 之间变化**；
   - 快速排序：每趟划分后子问题的规模取决于枢轴落点，**随初态在平衡与极不平衡之间变化**；
2. 再筛量级：恒定的两个里，归并是 $\Theta(n\log_2 n)$，不满足"总是 $O(n^2)$"（严格说它虽是 $O(n^2)$ 的上界，但题意指的是"总是 $n^2$ 量级"，归并不属于这一档）；简单选择排序 $\Theta(n^2)$ ✓；
3. 反向确认 A、B 的"受影响"实例：完全有序时插入排序只做 $n-1$ 次比较（$O(n)$）、而基本快排（端点枢轴）比较次数达 $\frac{n(n-1)}{2}$（$O(n^2)$）——两者的最好/最坏比值为 $\Theta(n)$ 级差异，故不满足条件①。

## 6. 详细解答

**简单选择排序的机制**（教材 10.3）：

```c
/* R[1..n] 为待排序记录，本趟在 R[i..n] 中选关键字最小者，与 R[i] 交换 */
for (i = 1; i < n; ++i) {
    k = i;
    for (j = i + 1; j <= n; ++j)      /* 这一层的比较次数恒为 n-i，与序列当前状态无关 */
        if (R[j].key < R[k].key) k = j;
    if (k != i) { R[0] = R[i]; R[i] = R[k]; R[k] = R[0]; }
}
```

- 比较次数：$\displaystyle\sum_{i=1}^{n-1}(n-i)=\frac{n(n-1)}{2}=\Theta(n^2)$，**与初始状态完全无关**（内层循环无条件走完）；
- 移动次数：最好 $0$（已有序，每次 $k=i$ 不交换）、最坏 $3(n-1)$（每次都要交换），至多 $O(n)$——这正是它"移动少、比较固定"的特征；
- 辅助空间 $O(1)$；不稳定（交换可能破坏相同关键字的相对次序，如 $(5_a,5_b,1)$ 第一趟交换 $5_a$ 与 $1$ 后 $5_a$ 落到 $5_b$ 之后）。

⟹ 同时满足"不受初态影响"与"总是 $O(n^2)$"，选 C。

**其余三项的依赖性核对**：

| 方法 | 最好情形 | 最坏情形 | 平均 | 是否受初态影响 |
|---|---|---|---|---|
| A. 直接插入排序 | $O(n)$（已有序） | $O(n^2)$（逆序） | $O(n^2)$ | 是 |
| B. 快速排序 | $O(n\log_2 n)$（每次均衡划分） | $O(n^2)$（有序 + 端点枢轴） | $O(n\log_2 n)$ | 是 |
| C. 简单选择排序 | $\Theta(n^2)$ | $\Theta(n^2)$ | $\Theta(n^2)$ | **否** |
| D. 归并排序 | $\Theta(n\log_2 n)$ | $\Theta(n\log_2 n)$ | $\Theta(n\log_2 n)$ | 否，但量级为 $n\log_2 n$ |

A 被"量级不恒定 + 受初态影响"两条同时否掉；B 亦然；D 只输在量级上（它是"不受初态影响、总是 $O(n\log_2 n)$"的代表，见 DS-2007-16 的问法）。

**答案**：C。

## 7. 选项分析

- A. 直接插入排序：错。基本操作次数为 $O(n+I)$（$I$ 为逆序对数），初态有序时 $O(n)$、逆序时 $O(n^2)$，既受初态影响又不"总是 $n^2$"；
- B. 快速排序：错。序列已（近乎）有序且取端点为枢轴时划分退化，比较次数 $\frac{n(n-1)}{2}$；而均衡划分时 $O(n\log_2 n)$，同样受初态影响；
- C. 简单选择排序：正确。每趟比较次数固定，总计 $\frac{n(n-1)}{2}$，与初态无关且恒为 $n^2$ 量级；
- D. 归并排序：错。它确实不受初态影响，但恒为 $\Theta(n\log_2 n)$，不是 $O(n^2)$ 档；本题最强干扰项，陷阱在题干后半句"总是 $O(n^2)$"。

## 8. 考场标准答案

选 **C**。

简单选择排序第 $i$ 趟须在 $R[i+1..n]$ 中逐个比较取最小者，比较 $n-i$ 次，与序列当前是否有序无关，总比较次数

$$\sum_{i=1}^{n-1}(n-i)=\frac{n(n-1)}{2}=\Theta(n^2)$$

直接插入排序（$O(n)\sim O(n^2)$）与快速排序（$O(n\log_2 n)\sim O(n^2)$）的时间均随初始状态变化；归并排序虽不受初始状态影响，但恒为 $O(n\log_2 n)$。故满足"不受初态影响且总是 $O(n^2)$"的只有简单选择排序。

## 9. 易错点

1. 只读前半句"不受初始状态影响"就选 D（归并排序）：题干有两个限定，量级必须是 $n^2$；
2. 把"简单选择排序"与"堆排序"混为一谈：堆排序也不受初态影响，但恒为 $O(n\log_2 n)$，且本题选项里没有堆排序；两者同为"选择类"却不同档；
3. 记成"选择排序最好 $O(n)$"：受初态影响的是**移动**次数（$0\sim 3(n-1)$），比较次数恒定不变，$O(n)$ 那条属于插入排序；
4. 忘记快排的最坏情形恰是"有序"：本题 B 与本年度 DS-2012-19 的结论（局部有序选插入排序）共用这条事实，两处别记反。

## 10. 一句话规律

内部排序里"比较次数与初始状态无关"的只有选择类中的简单选择排序（$\Theta(n^2)$）与归并排序（$\Theta(n\log_2 n)$）；再叠加量级要求，$n^2$ 档 ⟹ 简单选择排序，$n\log_2 n$ 档 ⟹ 归并排序（稳定）或堆排序（不稳定）。
