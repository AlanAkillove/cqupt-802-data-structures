# DS-2012-05

## 1. 原题

设计 一个把十进制数转换为八进制数的算法，采用（）数据结构最佳。

A. 栈

B. 队列

C. 顺序结构线性表

D. 链式结构线性表

## 2. 答案

**A**（栈）。

## 3. 题目分析

- 已知：十进制转八进制的标准手算法是"除 8 取余，逆序排列"——余数序列先得到最低位（LSD），最后得到最高位（MSD）；
- 目标：为该转换挑选**最佳**的数据结构；
- 关键约束："先进来的余数是低位、要后输出"，即产出序与输出序**方向相反**，需要 LIFO 缓冲；
- 命题意图：考“按运算的时序特征选择数据结构”——把栈的后进先出性质对应到“逆序输出”这一需求上（栈的应用实例中“进制转换”即为此类）。

## 4. 核心考点

核心考点：
DS02.07 栈、队列和数组的应用（数制转换是栈的典型应用之一）

辅助考点：
DS02.01 栈和队列的基本概念（LIFO 与 FIFO 的输出次序差异）

解释：整个算法只有两种操作——按余数产生顺序压入、按相反顺序弹出打印。能被"尾部进、尾部出"完整表达的缓冲需求正是栈；队列（FIFO）会原样保留余序，输出成低位在前的错结果。

## 5. 解题思路

1. 手算一例看清次序：$(100)_{10}$ 转八进制：$100\div 8=12$ 余 $4$；$12\div 8=1$ 余 $4$；$1\div 8=0$ 余 $1$。余数产生序 $4,4,1$，而正确答案要写成 $144$（逆序）；
2. 由"产生序与需要的输出序相反"判定需要的缓冲是"后进先出"型；
3. 逐个核对候选：栈 = LIFO ✓；队列 = FIFO ✗；顺序表/链表虽也能存，但要输出时必须显式地从尾到头扫描（顺序表可逆序下标遍历，链表仍需借助栈或递归），都不如"push/pop"两操作直接，且不需要随机访问或按位置插入删除的能力；
4. 补充一致性检查：递归实现数制转换之所以能"先递归再打印"就得到正确顺序，本质是**系统用调用栈替你做了逆序缓冲**，反过来证明该问题需要的是栈。

## 6. 详细解答

**算法原理**：设十进制整数 $N\ge 0$，按 $N=\sum_{k} d_k 8^k$ 展开，则

$$d_0=N\bmod 8,\quad N_1=\lfloor N/8\rfloor,\quad d_1=N_1\bmod 8,\ \cdots$$

即第 $t$ 次得到的余数正是八进制从低到高的第 $t$ 位；输出要求高位在前，故需把余数序列**倒过来**。

**算法（教材风格 C，用链栈）**：

```c
void DecToOct(int N)
{
    LinkStack S;  int d;
    InitStack(S);
    if (N == 0) { printf("0"); return; }   /* 边界：0 的八进制仍是 0 */
    if (N < 0)  { printf("-"); N = -N; }   /* 边界：负数先输出符号 */
    while (N > 0) { Push(S, N % 8); N = N / 8; }   /* 低位余数先进栈 */
    while (!StackEmpty(S)) { Pop(S, d); printf("%d", d); }  /* 高位先出 */
    DestroyStack(S);
}
```

**实例跟踪**（$N=100$）：

| 步骤 | $N$ | 余数 $d$（入栈） | 栈（左为栈底） |
|---|---|---|---|
| 1 | 100 | 4 | `4` |
| 2 | 12 | 4 | `4,4` |
| 3 | 1 | 1 | `4,4,1` |
| 出栈 | — | — | 输出 $1,4,4$ ⟹ $(144)_8$ ✓ |

验算：$1\times 64+4\times 8+4=100$ ✓，说明“栈缓冲 + 逆序输出”得到正确结果；若把栈换成队列，输出将是 $4,4,1$，即 $(441)_8=4\times 64+4\times 8+1=289_{10}\ne 100$，错误。

**规模分析**：位数 $=\lfloor\log_8 N\rfloor+1$，故时间 $O(\log_8 N)$、栈深（附加空间）$O(\log_8 N)$。栈对本题是"刚好够用"：只在一端进出，无须顺序表的随机访问，也无须链表的按位置插入。

**C、D 为何不是"最佳"**：顺序表/链表都能完成存储任务，但"逆序输出"要么依赖顺序表的下标反向遍历（把结构当成数组用，未体现运算特性、且要预先知道位数），要么需为链表再引入一个栈或递归；而栈的 `Push/Pop` 与该问题的"进入—倒出"过程一一对应，代码最短、语义最贴切，故选 A 而不是 C、D。

**答案**：A。

## 7. 选项分析

- A. 栈：正确。余数按低位→高位产生，输出需高位→低位，LIFO 恰好完成逆序；
- B. 队列：错。FIFO 保持产生顺序，输出为"低位在前"，结果错误（实例中得 $441$ 而非 $144$）；
- C. 顺序结构线性表：错。可行但非最佳：需要额外记录长度并反向遍历，且用不到"随机访问、按位置插入删除"这些顺序表的优势；
- D. 链式结构线性表：错。同样可行但更差——单链表只能正向访问，要逆序输出还得自身再借栈或递归，等于绕了一圈回到栈。

## 8. 考场标准答案

选 **A**。

十进制转八进制用"除 8 取余"：第 $t$ 次所得余数是八进制自低向高的第 $t$ 位，而书写要求高位在前，二者次序相反。栈的后进先出正好充当逆序缓冲：每得一个余数 `Push`，算法末尾逐个 `Pop` 输出即可。时间 $O(\log_8 N)$、空间 $O(\log_8 N)$。队列次序相同故错；线性表可行但需额外逆序手段，不如栈直接。

## 9. 易错点

1. 误选 B：把"先进先出"当成"排队处理就对了"，没手算一位余数验证输出方向；
2. 误选 C/D：以"数组也能存余数"为由选线性表——本题问的是**最佳**，判据是"运算需求与结构特性的匹配度"，不是"能不能做"；
3. 漏边界：$N=0$ 时 `while(N>0)` 一次不执行，若不特殊处理会输出空串；负数需先取绝对值并单独输出符号。

## 10. 一句话规律

判断"该用栈还是队列"只需一句：**产出的次序与需要的输出次序相反用栈，相同用队列**；手算一个最小实例把两序写出来，答案立刻分明。
