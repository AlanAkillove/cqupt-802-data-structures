# DS-2012-42

## 1. 原题

已知序列 $45,15,20,35,25,60$ ，请画出依次插入该序列的 $AVL$ 树（平衡二叉树）。

## 2. 答案

依次插入后的平衡二叉树（$6$ 个结点，树高 $3$）：

```
        35
      /    \
    20      45
   /  \        \
  15   25      60
```

过程中共发生 **3 次调整**：

| 插入 | 失衡根 $A$ | 类型 | 操作 |
|---|---|---|---|
| 20 | 45 | LR | 先左旋 $15$、再右旋 $45$ |
| 25 | 45 | LL | 右旋 $45$（一次单旋） |
| 60 | 20 | RR | 左旋 $20$（一次单旋） |

插入 $15$、$35$ 后树仍平衡，不需调整。

## 3. 题目分析

- 已知：关键字序列 $45,15,20,35,25,60$，按此次序逐个插入；
- 目标：画出**每插入一个关键字并调整平衡之后**的 AVL 树（"依次插入"要求体现过程，不能只给终态）；
- 约束：AVL 定义——① 是二叉排序树；② 任一结点的左右子树高度差的绝对值 $\le 1$；
- 关键机制：每次插入只可能在**插入路径上的某个结点**首次破坏平衡，取"从插入点向上第一个 $|BF|=2$"的结点，即**最小不平衡子树的根 $A$**；以 $A$ 为轴做一次单旋（LL/RR）或一次双旋（LR/RL）后，该子树的**高度回落到插入前的值**，故插入情形下**一次插入至多调整一次**，不必继续向上；
- 命题意图：考四种失衡形态（LL、RR、LR、RL）的识别与旋转，本题三种形态各出现一次（LR、LL、RR），区分度集中在"失衡根取哪一层"和"旋转后子树高度回落"。

## 4. 核心考点

核心考点：
DS05.07.02 平衡二叉树（平衡因子 $BF$ 的计算、最小不平衡子树、LL/RR/LR/RL 四种旋转）

辅助考点：
DS05.07.01 二叉排序树（插入仍按"小左大右"从根下落；旋转后必须仍保持中序有序）

解释：AVL 是"带平衡约束的 BST"，插入的下落规则完全来自 DS05.07.01，本题的区分度全部在旋转环节，故主考点为 DS05.07.02、辅助为 DS05.07.01。

## 5. 解题思路

1. **下落**：把新关键字按 BST 规则挂成叶子；
2. **回算 $BF$**：沿"插入路径"自底向上重算各结点子树高度与 $BF=h_L-h_R$（只需看路径上的结点，其余子树未变）；
3. **找 $A$**：路径上**最靠近插入点**的 $|BF|=2$ 的结点即最小不平衡子树的根（更上层的结点此时即使 $|BF|$ 也等于 $2$，也不优先处理）；
4. **定形态**：看新结点落在 $A$ 的哪一侧、又落在 $A$ 的孩子结点的哪一侧——同侧（LL/RR）用**单旋**（朝相反方向转一次），异侧（LR/RL）用**双旋**（先反方向转孩子、再反向转 $A$）；
5. **重挂**：旋转后的子树整体接回 $A$ 原来的父结点，并核对该子树高度是否已回落到插入前的值；
6. **终检**：对最终树做中序遍历（应升序）+ 逐点核 $|BF|\le1$（见第 6 节末）。

## 6. 详细解答

记 $BF(x)=h_L(x)-h_R(x)$，空子树高度取 $0$；括号内数字为该结点当前的 $BF$。

**① 插入 45**：作根。

```
  45(0)
```

**② 插入 15**：$15<45$ → $45$ 的左孩子。$BF(45)=1$、$BF(15)=0$ ⟹ 平衡，不调整。

```
   45(1)
  /
15(0)
```

**③ 插入 20**：$20<45$ → 左子树；$20>15$ → $15$ 的右孩子。

```
     45(2)
    /
  15(-1)
    \
     20(0)
```

回算：$BF(15)=-1$、$BF(45)=h_L-h_R=2-0=+2$ ⟹ 失衡。插入路径 $45\to15\to20$，最靠近插入点的失衡结点 $A=45$；新结点位于 $A$ 的**左**子树（$15$）的**右**侧 ⟹ **LR 型**，作双旋"先左旋 $15$、再右旋 $45$"：

- 左旋 $15$：$20$ 上升，$15$ 降为 $20$ 的左孩子，$20$ 的原左子树（空）改挂为 $15$ 的右孩子 → 得 $45\big(20(15,\varnothing),\varnothing\big)$；
- 右旋 $45$：$20$ 上升为该子树根，$45$ 降为 $20$ 的右孩子，$20$ 的原右子树（空）改挂为 $45$ 的左孩子。

```
     20(0)
    /     \
 15(0)   45(0)
```

旋转后该子树高 $2$（插入前为 $1$）：本次插入使树长高一层，但失衡已消除，且 $A$ 就是根，无需再向上处理 ✓。

**④ 插入 35**：$35>20$ → 右子树 $45$；$35<45$ → $45$ 的左孩子。

```
      20(-1)
    /       \
 15(0)     45(1)
           /
        35(0)
```

回算：$BF(45)=1$、$BF(20)=1-2=-1$ ⟹ 全部 $|BF|\le1$，**不需调整**。

**⑤ 插入 25**：$25>20$ → 右子树 $45$；$25<45$ → 左子树 $35$；$25<35$ → $35$ 的**左**孩子。

```
        20(-1)            ← 先别看，按路径自底向上算
      /       \
   15(0)     45(2)   ← 失衡
             /
          35(1)
          /
       25(0)
```

插入路径 $20\to45\to35\to25$，自底向上回算：$BF(35)=1-0=1$；$BF(45)=h_L(35\text{ 子树}=2)-h_R(\varnothing=0)=+2$ ⟹ **第一个**失衡结点 $A=45$（此时 $BF(20)=1-3=-2$ 也已达 $2$，但按"最靠近插入点"约定先处理 $45$）；新结点在 $A$ 的**左**子树（$35$）的**左**侧 ⟹ **LL 型**，只需对 $A=45$ 作**一次右旋**：

- 右旋 $45$：$35$ 上升取代 $45$ 的位置（成为 $20$ 的右孩子），$45$ 降为 $35$ 的右孩子，$35$ 的原右子树（空）改挂为 $45$ 的左孩子。

```
        20(-1)
      /       \
   15(0)     35(0)
            /     \
         25(0)   45(0)
```

**关键回落检查**：旋转后 $35$ 子树的高度为 $2$，而插入 $25$ **之前**该子树（根为 $45$）的高度也是 $2$ ⟹ 上层结点 $20$ 的 $BF$ 保持插入前的 $-1$，**并未失衡**，调整到此结束（这正是"一次插入至多一次调整"的根据；若把 $35$ 子树高度误算成 $3$，就会凭空再多做一次 RL 双旋而把根错换成 $25$）。

**⑥ 插入 60**：$60>20$ → 右子树 $35$；$60>35$ → 右子树 $45$；$60>45$ → $45$ 的右孩子。

```
        20(-2)      ← 失衡
      /       \
   15(0)     35(-1)
            /     \
         25(0)   45(-1)
                    \
                    60(0)
```

回算：$BF(45)=-1$、$BF(35)=1-2=-1$、$BF(20)=1-3=-2$ ⟹ 唯一失衡结点 $A=20$（整棵树的根）；新结点在 $A$ 的**右**子树（$35$）的**右**子树（$45$）的右侧 ⟹ **RR 型**，对 $A=20$ 作**一次左旋**：

- 左旋 $20$：$35$ 上升为整棵树的根，$20$ 降为 $35$ 的左孩子，$35$ 的原左子树 $25$ 改挂为 $20$ 的右孩子。

```
        35(0)
      /       \
   20(0)     45(-1)
   /    \        \
 15(0) 25(0)    60(0)
```

即第 2 节所示的最终 AVL 树。

**三性质校验**：

1. **BST 性质**：中序遍历 $15,20,25,35,45,60$ —— 严格升序 ✓（旋转不改变中序序列，这是每次旋转后最快捷的正确性判据）；
2. **平衡性**：$BF(15)=BF(25)=BF(60)=BF(20)=BF(35)=0$、$BF(45)=-1$ —— 全部 $|BF|\le1$ ✓；
3. **规模**：$6$ 个结点、树高 $3$；与 DS05.07.02 的"高度 $h$ 的 AVL 最少结点数"$N(3)=4\le 6<N(4)=7$ 一致，故 $6$ 结点 AVL 的高度只能是 $3$ ✓（高度 $2$ 最多容纳 $3$ 个结点，放不下 $6$ 个）。

**与普通 BST 的对照**：同一序列若不调整，建成的是 $45\big(15(\varnothing,20(\varnothing,35(25,\varnothing))),60\big)$，结点 $20$ 处 $BF=-2$（左空右高）、单支链长 $4$，查找最长比较 $5$ 次；调整后树高从 $4$ 降到 $3$，最长比较 $3$ 次——这就是 AVL 存在的理由（构造过程见本库 DS-2012-39 的普通 BST 插入）。

## 8. 考场标准答案

逐插入画树并标注失衡点与旋转类型：

| 插入 | 插入后形态（简写 $A(B,C)$） | 失衡根 $A$ | 类型 | 调整 | 调整后树 |
|---|---|---|---|---|---|
| 45 | $45$ | — | — | 无 | $45$ |
| 15 | $45(15)$，$BF(45)=1$ | — | — | 无 | $45(15,\varnothing)$ |
| 20 | $45(15(\varnothing,20))$，$BF(45)=2$ | 45 | LR | 左旋 15、右旋 45 | $20(15,45)$ |
| 35 | $20(15,45(35))$，$BF(20)=-1$ | — | — | 无 | $20(15,45(35,\varnothing))$ |
| 25 | $20(15,45(35(25)))$，$BF(45)=2$ | 45 | LL | 右旋 45 | $20(15,35(25,45))$ |
| 60 | $20(15,35(25,45(\varnothing,60)))$，$BF(20)=-2$ | 20 | RR | 左旋 20 | $35(20(15,25),45(\varnothing,60))$ |

最终 AVL 树：

```
        35
      /    \
    20      45
   /  \        \
  15   25      60
```

验算：中序 $15,20,25,35,45,60$ 升序；各结点 $BF\in\{0,\pm1\}$；$6$ 结点、树高 $3$。

## 9. 易错点

1. **失衡根取错层**：插入 $25$ 时把 $A$ 取成更上层的 $20$（应取"从插入点向上第一个 $|BF|=2$"的 $45$）——取错层会多做一次双旋，把根错换成 $25$，最终树完全不同；
2. **旋转类型判反**：判型要看"新结点在 $A$ 的哪一侧、再在 $A$ 的孩子结点的哪一侧"，同侧（LL/RR）单旋、异侧（LR/RL）双旋；本题第 ⑤ 步 $25$ 在 $45$ 的**左子树的左侧**，是 LL（右旋），不是 RL；
3. **忘记"高度回落"**：右旋 $45$ 后 $35$ 子树高 $2$，与插入前同高，故 $20$ 的 $BF$ 仍是 $-1$ 而非 $-2$；把高度算成 $3$ 就会误判 $20$ 失衡、多此一举；
4. **旋转时子树接错**：左旋/右旋都要把"上升结点靠近被旋结点那一侧的子树"摘下来挂到被旋结点上——第 ⑥ 步左旋 $20$ 时 $35$ 的左子树 $25$ 必须挂成 $20$ 的右孩子，漏挂即丢结点；
5. 只画最终树、不写"依次插入"的中间过程与旋转类型：题干"依次插入"意味着过程是分步给分点；
6. 忘记校验中序：任何一次旋转后中序序列必须始终是 $15,20,25,35,45,60$，这是发现挂错父子最快捷的手段。

## 10. 一句话规律

AVL 插入三步——"按 BST 下落、沿插入路径自底向上找**第一个** $|BF|=2$ 的结点、同侧单旋异侧双旋"；旋完必查"该子树高度是否回落到插入前的值"（回落则上层不再失衡），旋的对错一律用"中序是否仍升序"来判。

## 11. 关联知识

- DS05.07.02 的"高度 $h$ 的 AVL 最少结点"$N(h)=N(h-1)+N(h-2)+1$：$N(1)=1,N(2)=2,N(3)=4,N(4)=7,N(5)=12$ —— 本库 DS-2012-35（高度 4 的 AVL 最少结点数 $=7$）与 DS-2012-16（$12$ 结点 AVL 的最大深度 $=5$，因 $N(5)=12$）即该递推的直接应用；
- DS05.07.01 二叉排序树的插入与删除（本库 DS-2012-39）：同一批关键字建成普通 BST 会在结点 $20$ 处失衡，AVL 靠旋转把树高压到 $O(\log n)$；
- AVL 的**删除**比插入复杂：子树高度每次减 $1$ 会逐层向上传播，一次删除可能需要沿路径多次旋转，本题只考插入情形；
- 与 DS05.05.01/DS05.05.02 的 B 树对照：两者都用结构约束保证树高 $O(\log n)$，B 树靠"多分支 + 结点内关键字"，AVL 靠"二叉 + 旋转"（本库 DS-2012-17 考 B 树阶的性质）。
