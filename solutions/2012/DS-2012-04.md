# DS-2012-04

## 1. 原题

将长度为 $n$ 的单链表链接在长度为 $m$ 的单链表之后的算法的时间复杂度为（）。

A. $O(1)$

B. $O(n)$

C. $O(m)$

D. $O(m+n)$

## 2. 答案

**C**（$O(m)$）。

## 3. 题目分析

- 已知：两个**单链表**，长度分别为 $n$（被接在后面者）与 $m$（作为前段者），仅给出头指针，未说明带有尾指针；
- 目标：把 $n$ 链表整体挂到 $m$ 链表的**后面**，求该操作的时间复杂度；
- 关键约束：单链表只能沿 `next` **单向**访问结点，要修改某个结点的指针必须先访问到它；把 $A$ 链接到 $B$ 链之后，需要修改的是 **$B$ 链的最后一个结点**的 `next`；
- 命题意图：考"单链表访问的单向性 → 定位尾结点必须遍历"这一根本限制，同时检验是否看清"谁接在谁之后"（决定遍历的是哪一条链）。

## 4. 核心考点

核心考点：
DS01.02.02 链式存储：单链表（单向访问、无随机访问、尾结点定位代价）

辅助考点：
DS01.02.03 链式存储：双向链表与循环链表（带尾指针的循环链表可在 $O(1)$ 完成同类合并，是选项 A 成立所缺的前提）

解释：算法的代价全部花在"找到长度为 $m$ 的链表的终端结点"上——从头结点出发逐个数到第 $m$ 个结点，需 $m-1$ 或 $m$ 次指针跟踪（视是否带头结点），量级为 $O(m)$；接上之后只做常数次指针赋值。长度为 $n$ 的链表一个结点都不用访问，故结果与 $n$ 无关。

## 5. 解题思路

1. 先明确"链接后应有的逻辑结构"：$b_1,\cdots,b_m,a_1,\cdots,a_n$，唯一需要改的指针是 $b_m\to\text{next}$ 由 `NULL` 改为指向 $a_1$（或 $A$ 的头结点）；
2. 问"能否一步到达 $b_m$"：单链表只有头指针，$b_m$ 不是可直接访问的对象 ⟹ 必须从 $b_1$ 沿 `next` 走 $m-1$ 步；
3. 统计代价：走链 $O(m)$ + 改指针 $O(1)$ = $O(m)$；
4. 检查 $n$ 是否进入代价：$a_1$ 已由其头指针给出，其后续结点不需要访问 ⟹ $n$ 不出现，排除 B、D；
5. 检查 A 的可能性：只有额外给出尾指针（或采用带尾结点指针的循环链表）才可能 $O(1)$，题面未给 ⟹ 排除 A。

## 6. 详细解答

**设定**：两链表均带头结点，头指针为 $La$（长度 $n$）、$Lb$（长度 $m$）；链接后要求 $Lb$ 表的 $m$ 个结点在前、$La$ 表的 $n$ 个结点在后，且不复制数据（只改指针）。

**算法（教材风格 C）**：

```c
void Concat(LinkList La, LinkList Lb)   /* 把 La 接在 Lb 之后 */
{
    LinkList p = Lb;
    while (p->next != NULL)      /* 沿 next 单向寻找 Lb 的终端结点 */
        p = p->next;             /* 该循环执行 m 次（p 从头结点走到第 m 个结点）*/
    p->next = La->next;          /* 常数时间：把 La 的首元接到 Lb 尾部 */
    free(La);                    /* 摘除 La 的头结点，仍为常数时间 */
}
```

**代价分析**（$m,n$ 为两链表结点数）：

| 步骤 | 执行次数 | 量级 |
|---|---|---|
| 找 $Lb$ 终端结点（`while` 走链） | $m$ 次指针跟踪 | $O(m)$ |
| 改 `p->next`、释放头结点 | $2$ 次操作 | $O(1)$ |
| 访问 $La$ 的任一数据结点 | $0$ 次 | — |

合计 $T(m,n)=m+2=O(m)$。

**为什么不是 $O(n)$ 或 $O(m+n)$**：$La$ 链上结点的相对次序完全不变，也不需要为它寻找任何位置，一个结点都不访问；被"走一遍"的只有 $Lb$ 链。若题目反向表述"将长度为 $m$ 的单链表链接在长度为 $n$ 的单链表之后"，则走的是长度为 $n$ 的链，代价变为 $O(n)$——**代价挂在"作为前段的那条链"上**。

**为什么不是 $O(1)$**：$O(1)$ 要求 $b_m$ 已知。若结构改为"带尾指针 `rear` 的单循环链表"，则 $rear\to next$ 就是终端结点，直接改两个指针即可（且不必走链），此时才是 $O(1)$。题面只说"单链表"，默认只有头指针。

**答案**：C。

## 7. 选项分析

- A. $O(1)$：错。需要"已知尾结点位置"（尾指针、或带 `rear` 的循环链表）这一额外前提，题面未给；单链表从头指针出发无法常数时间到达尾部；
- B. $O(n)$：错。$n$ 是**被接在后段**的链表长度，它的结点全程不需要访问；把 $n$ 当作遍历对象恰好把两条链的角色弄反；
- C. $O(m)$：正确。定位长度为 $m$ 的前段链表的终端结点是唯一的线性代价来源；
- D. $O(m+n)$：错。这是"既要走 $m$ 链、又要走 $n$ 链"（例如依次复制两个链表的全部结点，或求两条链的总长度）的代价，链接只改指针不复制数据。

## 8. 考场标准答案

选 **C**：$O(m)$。

单链表只能沿 `next` 单向访问，把 $A$（长 $n$）接到 $B$（长 $m$）之后必须修改 $B$ 的终端结点的指针，而该结点只能从头指针出发走 $m$ 步才能到达；接上后仅做常数次指针赋值，且 $A$ 的结点一个也不访问。故 $T(m,n)=m+O(1)=O(m)$。

## 9. 易错点

1. 方向判断错：记住结论"**遍历的是前段链（被接在后面的那条不需要走）**"，本题前段长 $m$ ⟹ $O(m)$；
2. 选 D：以为两条链都要处理。链表运算要区分"改指针"（局部 $O(1)$）与"访问/复制数据"（线性），链接属前者；
3. 忽视题面隐含约定：若明确"两链表都带尾指针"或"带头结点单链表的最后一个结点指针已知"，答案会变 $O(1)$。做选择题时按"只有头指针"的标准模型解释题目，不要擅自加条件；
4. 与顺序表拼接混淆：顺序表拼接必须搬移后一个表的 $n$ 个元素，代价 $O(n)$ 且可能触发整体扩容，与链表结论不可互相套用。

## 10. 一句话规律

链表类操作的时间复杂度只看"**必须走到哪个结点**"：能由已知指针直接命中的结点是 $O(1)$，需要从头走的结点其序号就是代价；因此先问"要改谁的指针"，再看"那个结点离头结点多远"。
