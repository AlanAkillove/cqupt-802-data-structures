# DS-2012-09

## 1. 原题

数组 $a$ 中，每个元素 $a[i][j]$ 的长度为 $4$ 个字节，行下标 $i$ 从 $0$ 到 $7$ ，列下标 $j$ 从 $0$ 到 $9$ ，从首地址 $a$ 开始连续存放在存储器内，该数组按行优先存放时，元素 $a[7][4]$ 的起始地址为（）。

> 订正说明转录：源文作"从首地址连续存放"，未命名首地址；因各选项均以 $a$ 表示首地址（如 $a+192$ ），据题意补"从首地址 $a$ 开始"。

A. $a+192$

B. $a+188$

C. $a+300$

D. $a+296$

## 2. 答案

**D**（$a+296$）。

## 3. 题目分析

- 已知：数组维界 $i\in[0,7]$、$j\in[0,9]$，即 $8$ 行 $10$ 列共 $80$ 个元素；每个元素占 $L=4$ 字节；首地址（元素 $a[0][0]$ 的起始地址）为 $a$；存放方式**行优先**；
- 目标：求 $a[7][4]$ 的起始地址；
- 关键约束：行优先 = 先固定行、列下标变化最快 ⟹ 某元素之前完整的行数与它在本行内的列序共同决定偏移；偏移按**元素个数**算，再乘 $L$ 换成字节；
- 命题意图：考多维数组地址计算的基本式，检验两件事——① 是否用"每行元素个数（列数 $10$）"作 stride 而不是行数 $8$；② 是否明白起始地址要加的是"该元素**之前**的元素个数 $\times L$"，不含自身。

## 4. 核心考点

核心考点：
DS02.04 多维数组的存储（行优先地址公式 $Loc(a[i][j])=Loc(a[0][0])+(i\times cols+j)\times L$）

解释：数组下标均从 $0$ 开始，公式无多余常数项，属最干净的一档。若下标从 $1$ 起（如本年度 DS-2012-26 的对称矩阵 $A[1\cdots10,1\cdots10]$），式中出现 $i-1$、$j-1$，本题刻意选了 $0$ 起下标，把区分度全部留给"stride 取列数""不含自身"两点。

## 5. 解题思路

1. 确定行优先的 stride：一行的元素个数 = 列下标取值数 = $10$（$0\sim9$）；
2. 数出 $a[7][4]$ 之前的元素个数：前 $7$ 行整行（下标 $0\sim6$）共 $7\times10=70$ 个，加上第 $7$ 行中它前面的 $a[7][0]\sim a[7][3]$ 共 $4$ 个 ⟹ $74$；
3. 换字节：$74\times4=296$，加首地址 ⟹ $a+296$；
4. 用两个边界自查：$a[0][0]$ 应得 $a+0$（公式给 $(0\times10+0)\times4=0$ ✓）；最后一个元素 $a[7][9]$ 应得 $a+(80-1)\times4=a+316$（公式给 $(70+9)\times4=316$ ✓），且全表共 $80\times4=320$ 字节，$296<316<320$ 合理；
5. 与错误口径对照定位干扰项：把 stride 误为行数 $8$ 或列数取错会得 $a+156$（列优先值）等；多算自身一个元素得 $a+300$；行列下标颠倒求成 $a[4][7]$ 得 $a+188$。

## 6. 详细解答

**参数**：行数 $R=8$（$i:0\sim7$）、列数 $C=10$（$j:0\sim9$）、元素长度 $L=4$ 字节、首地址 $Loc(a[0][0])=a$。

**行优先地址公式**（下标 $0$ 起）：

$$Loc(a[i][j])=a+(i\times C+j)\times L$$

**代入** $(i,j)=(7,4)$：

$$i\times C+j=7\times10+4=74\ (\text{个元素位于它之前})$$
$$Loc=a+74\times4=a+296$$

**逐元素验证**（把前若干与关键位置写出）：

| 元素 | 之前元素数 $iC+j$ | 地址 |
|---|---|---|
| $a[0][0]$ | $0$ | $a$ |
| $a[0][9]$ | $9$ | $a+36$ |
| $a[1][0]$ | $10$ | $a+40$ |
| $a[6][9]$ | $69$ | $a+276$ |
| $a[7][0]$ | $70$ | $a+280$ |
| $a[7][4]$ | $74$ | $a+296$ ✓ |
| $a[7][9]$ | $79$ | $a+316$ |

各行首地址依次相差 $C\times L=40$ 字节（$a[1][0]=a+40$、$a[7][0]=a+280$ ✓），同行内相邻元素相差 $4$ 字节（$a[7][4]=a[7][0]+4\times4=a+296$ ✓）——两种走法得到同一地址，说明计数无误。

**总空间核对**：数组共 $R\times C=80$ 个元素，占 $320$ 字节，地址区间 $[a,\,a+316]$（末元素起点），$a+296$ 落在区间内且是第 $75$ 个元素的起点 ✓。

**列优先对照**（若题面改为列优先）：$Loc=a+(j\times R+i)\times L=a+(4\times8+7)\times4=a+156$，不在选项中，可见选项设计并未把"行/列优先颠倒"设为陷阱，而是考了 stride 与"是否含自身"。

**答案**：D。

## 7. 选项分析

- A. $a+192$：错。$192=48\times4$，对应"前面有 $48$ 个元素"的位置（如把行列下标颠倒后再多算一格，$4\times10+8=48$），既颠倒了 $i,j$ 又偏移一位；
- B. $a+188$：错。$188=47\times4$，恰是把目标写成 $a[4][7]$ 按行优先计算的结果（$4\times10+7=47$）——行、列下标角色互换的典型错误；
- C. $a+300$：错。$300=75\times4$，把"该元素自身"也算进了偏移（$74+1$）；起始地址应加"之前"的字节数；
- D. $a+296$：正确。$7\times10+4=74$ 个元素在前，$74\times4=296$ 字节。

## 8. 考场标准答案

行优先、下标 $0$ 起，列数 $C=10$、元素长 $L=4$：

$$Loc(a[i][j])=a+(i\times C+j)\times L$$
$$Loc(a[7][4])=a+(7\times10+4)\times4=a+74\times4=\boxed{a+296}$$

选 **D**。

## 9. 易错点

1. **stride 取错**：行优先时"跳过一整行"要乘的是**列数 $10$**，不是行数 $8$（$8$ 是列优先时的 stride）；
2. **含不含自身**：起始地址 = 首地址 + 之前元素的总字节数，别写成 $(iC+j+1)L$（即选项 C 的 $a+300$）；
3. **下标起点**：本题 $i,j$ 从 $0$ 起，公式无 $-1$；若换成 $1$ 起的 $A[1\cdots10,1\cdots10]$（本年度 DS-2012-26）必须写成 $((i-1)C+(j-1))L$，两套公式不可混用；
4. **单位**：偏移的"元素个数"必须乘 $L=4$ 才是地址增量，直接写 $a+74$ 是常见漏乘；
5. 行/列优先看反（得 $a+156$）：虽然本题选项中未出现，但改变问法时这是最容易失分的一处。

## 10. 一句话规律

地址题三步走：① 认清优先方向，定 stride（行优先 stride = 列数）；② 数"目标之前有几个元素"（完整行数 × stride + 行内偏移）；③ 乘元素长度并检查是否含自身；最后用首元素 $a[0][0]\to a$ 和末元素两个边界复核。
