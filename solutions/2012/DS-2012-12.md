# DS-2012-12

## 1. 原题

对二叉树所有结点进行编号（从 $1$ 开始），要求每个结点的编号大于其左右孩子的编号，同一结点的左右孩子中，其左孩子的编号小于其右孩子的编号，则可采用（）次序的遍历实现编号。

A. 先序

B. 中序

C. 后序

D. 从根开始的层次遍历

## 2. 答案

**C**（后序遍历：左子树 → 右子树 → 根）。

## 3. 题目分析

- 已知：编号按**遍历访问的先后顺序**依次赋 $1,2,3,\cdots$（第 $k$ 个被访问的结点得编号 $k$）；
- 目标：找出能同时满足两条约束的遍历次序；
- 两条约束翻译：
  ① "结点编号 $>$ 其左、右孩子编号" ⟺ **每个结点必须在它的两个孩子之后被访问**（孩子的编号更小 = 孩子更早被访问）；
  ② "左孩子编号 $<$ 右孩子编号" ⟺ **左子树必须先于右子树被访问完**；
- 命题意图：考"三种深度优先遍历的区别只在根结点的访问时机（根左、左根右、左右根）"这一本质，并要求能把编号大小关系反推为访问先后关系。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（先/中/后序中"根"的位置决定父子访问先后）

辅助考点：
DS03.02.03.03 后序遍历（左右根：子树全部结点先于根被访问）

解释：三条深度优先遍历对"左子树整体先于右子树整体"是完全一致的（都先递归左、再递归右），差别只在根：先序根最先、中序根居中、后序根最后。约束①要求根在两个孩子之后 ⟹ 只能是后序；约束②用来排除"右左右"之类的变体并确认 C 项的内部次序，两者合起来唯一确定后序。

## 5. 解题思路

1. 先把"编号大小"统一换成"访问先后"：编号越大 ⟺ 越晚被访问。约束①读作"父晚于子"，约束②读作"左孩子早于右孩子"；
2. 逐一双核：先序（根左右）根最早，与①相反 → 排除；层次遍历（从根开始）根得 $1$，同样与①相反 → 排除；中序（左根右）根在左孩子之后但在右孩子之前，①不满足 → 排除；
3. 后序（左右根）：根在左右孩子之后 ✓①；整棵左子树（含左孩子）先于整棵右子树（含右孩子）访问 ✓② → 选中；
4. 用一棵 $6$ 结点的二叉树做完整验证，逐条检查两条约束（见第 6 节），确认结论。

## 6. 详细解答

**记号**：设第 $k$ 个被访问的结点编号为 $k$，于是"编号大"等价于"访问晚"。

**四种遍历逐一检验**（考察任一内部结点 $x$ 及其左孩子 $L$、右孩子 $R$）：

| 遍历 | 局部次序 | $x$ 与 $L,R$ 的先后 | 约束①（父晚于两子） | 约束②（左先于右） |
|---|---|---|---|---|
| A 先序 | 根 → 左 → 右 | $x$ 最先 | ✗（父早于子） | ✓ |
| B 中序 | 左 → 根 → 右 | $L\prec x\prec R$ | ✗（$x$ 早于 $R$） | ✓ |
| C 后序 | 左 → 右 → 根 | $L\prec R\prec x$ | ✓ | ✓ |
| D 层次（从根开始） | 逐层自上而下 | 父必先于子（父在第 $d$ 层，子在 $d+1$ 层） | ✗ | ✓ |

只有 C 同时满足两条。

**实例验证**：取二叉树 $A\big(B(D,E),\,C(\varnothing,F)\big)$，即 $A$ 的左孩子 $B$（其两个孩子为 $D,E$）、右孩子 $C$（仅有右孩子 $F$）。

后序遍历访问次序：$D\ \ E\ \ B\ \ F\ \ C\ \ A$，据此编号

$$D{=}1,\;E{=}2,\;B{=}3,\;F{=}4,\;C{=}5,\;A{=}6$$

逐条核对：

- $A=6>B=3$ ✓、$A=6>C=5$ ✓；
- $B=3>D=1$ ✓、$B=3>E=2$ ✓；
- $C=5>F=4$ ✓（$C$ 无左孩子，约束中"左孩子编号小于右孩子"这一条对无左孩子的结点不产生要求；若约定"缺右孩子时左孩子编号仍小于其右孩子"则无从谈起，本题不涉此细节）；
- 左右孩子次序：$A$ 的 $B=3<C=5$ ✓、$B$ 的 $D=1<E=2$ ✓。

全部满足，后序可行。

**反例验证其它三项**（同一棵树）：

- 先序 $A,B,D,E,C,F$ → $A=1$，要求"$A$ 大于其孩子"立刻失败；
- 中序 $D,B,E,A,C,F$ → $A=4$ 而其右孩子 $C=5$，$A<C$ 失败（父小于右孩子）；
- 层次 $A,B,C,D,E,F$ → $A=1$ 失败；
可见三条错误选项都在"根 vs 孩子"这一处矛盾，其中中序只错在右孩子一侧，最具迷惑性。

**一般性说明**：后序遍历保证"任一结点的编号大于其**全部子孙**的编号"（不只孩子），因为递归先完整走完左右子树才访问根；这正是"父大于子"所需的更强性质。也因此该编号方案等价于把树按"自底向上"的拓扑序编号，教材中销毁二叉树（`DestroyBiTree`：先销毁左右子树再释放根）采用的就是后序，是同一性质的应用。

**答案**：C。

## 7. 选项分析

- A. 先序（根左右）：错。根最先被访问，编号最小，恰好与"父编号大于子"完全相反；先序实现的是"每个结点编号**小于**其孩子、左孩子小于右孩子"这一镜像要求；
- B. 中序（左根右）：错。左孩子 $<$ 根 $<$ 右孩子，故根必小于其右孩子，违反约束①；这是本题最强干扰项（它满足②，且对"只有左孩子"的结点看似也满足①）；
- C. 后序（左右根）：正确。左右子树整体先于根 ⟹ 根编号最大；左子树先于右子树 ⟹ 左孩子编号小于右孩子；
- D. 从根开始的层次遍历：错。访问按“逐层自上而下”进行，父结点所在层必早于子结点层，故父编号恒小于子编号，与约束①相反。（与①相容的是“逆层次”（自底向上）访问，那不属于本题选项；题干 D 项已明写“从根开始”。）

## 8. 考场标准答案

编号从 $1$ 起按访问次序递增，故"编号大于孩子"= "在孩子之后被访问"，"左孩子编号小于右孩子"= "左子树先于右子树访问完"。

三种深度优先遍历都是"先左后右"，只有后序把根放在最后（左 → 右 → 根），使任一结点晚于其左右孩子 ⟹ 选 **C**（后序）。

验证：树 $A(B(D,E),C(\varnothing,F))$ 的后序为 $D,E,B,F,C,A$，编号 $1,2,3,4,5,6$，父均大于子、左子均小于右子 ✓。

## 9. 易错点

1. 把"编号大于孩子"读成"父应先被访问"（编号大 ⟺ 访问晚，这一步方向最容易弄反）；一旦方向反了就会选 A；
2. 只看第一条约束就排除中序、留下"后序 vs 层次"，又误以为层次遍历"逐层递增"也满足某种大小关系——从根开始的层次遍历父必小于子，同样不满足；
3. 忘记核对第二条：若只要求"父大于子"，则"右左右"等变体次序也可满足，题干的"左孩子编号小于右孩子"正是用来锁定标准的左→右→根；
4. 与"完全二叉树顺序存储编号"（$i$ 的孩子是 $2i,2i+1$，父编号**小于**子编号）混淆——那是自根递增的编号方案，与本题要求相反。

## 10. 一句话规律

凡"编号/序号 + 大小约束"的遍历题，先把大小关系翻译成访问先后（编号大 = 访问晚），再看"根排在子树的什么位置"，四种遍历的次序表一对即得答案。

## 11. 关联知识

- 先序：根→左→右、中序：左→根→右、后序：左→右→根，层次：自顶向下同层自左向右——四者的"根位置"差异是本题全部区分度所在；
- DS-2007-07（先根序列中 $x$ 在 $y$ 之前而后根序列中 $x$ 在 $y$ 之后，判 $x,y$ 关系）与本题同属"由访问先后反推结构关系"，方向恰好相反（那题从次序推父子，本题从父子约束选次序）；
- DS-2006-18（"中序遍历时某结点的直接后继是它右子树中第一个被访问的结点"）是遍历次序的另一条局部性质，可与本题对照记忆；
- DS-2012-11（只有度 $0$、度 $2$ 结点的二叉树最少结点数）与本题同年，共同覆盖 DS03.02 的"计数"与"遍历"两条主线；
- 遍历与算法实现：后序用于"先处理完子树再处理根"的问题——求树的高度、销毁二叉树、表达式树求值（本题的编号要求即其抽象表述）。
