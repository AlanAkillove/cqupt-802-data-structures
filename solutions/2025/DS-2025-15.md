# DS-2025-15

## 1. 原题

**15、** 已知一棵二叉查找树/二叉排序树($BST$)的先序遍历序列为 $23,15,12,18,56,29,34,71$。

（1）请画出此二叉树的形态；

（2）请给出这棵树的后序遍历序列；

（3）画出此二叉树的中序线索二叉树；

（4）画出与此二叉树对应的森林。

（本题无订正说明；题面"二叉查找树/二叉排序树"为同一名词的两种写法。）

## 2. 答案

**（1）二叉树形态**

```
            23
          /    \
       15       56
      /  \     /  \
    12   18   29   71
                 \
                 34
```

**（2）后序遍历序列**：$12,\;18,\;15,\;34,\;29,\;71,\;56,\;23$

**（3）中序线索二叉树**：中序序列 $12,15,18,23,29,34,56,71$；空链域改线索情况见下表（实线孩子不变）

| 结点 | 左域 | 右域 |
|---|---|---|
| $12$ | **NULL**（$ltag=1$） | 线索 → $15$ |
| $15$ | 孩子 $12$ | 孩子 $18$ |
| $18$ | 线索 → $15$ | 线索 → $23$ |
| $23$ | 孩子 $15$ | 孩子 $56$ |
| $29$ | 线索 → $23$ | 孩子 $34$ |
| $34$ | 线索 → $29$ | 线索 → $56$ |
| $56$ | 孩子 $29$ | 孩子 $71$ |
| $71$ | 线索 → $56$ | **NULL**（$rtag=1$） |

**（4）对应的森林**（三棵树）

```
T1:  23          T2:  56          T3:  71
    /  \              /  \
  15   18           29   34
  |
  12
```

即 $T_1=23(15(12),18)$、$T_2=56(29,34)$、$T_3=71$。

## 3. 题目分析

- 已知：**仅**一条先序序列 $23,15,12,18,56,29,34,71$，且告知该树是 BST；
- 目标：四问——定形、求后序、中序线索化、逆转换为森林；
- 关键约束与突破口：
  1. BST 的定义（左 $<$ 根 $<$ 右，且左右子树仍是 BST）使中序序列必为**递增序列** $12,15,18,23,29,34,56,71$；
  2. "先序 + 中序"可**唯一**确定二叉树，故仅凭先序（配合 BST 性质隐含的中序）就能定形，不必猜；等价地，按先序给出的次序逐个插入空树，得到的就是唯一形态；
  3. 线索化口径为**中序**，规则"空左域装直接前驱、空右域装直接后继"，$n$ 结点二叉链表恰有 $n+1=9$ 个空域；
  4. "二叉树 → 森林"是 DS03.03.02 转换的**逆过程**：左指针解释为"第一个孩子"、右指针解释为"下一个兄弟"，根沿右链下去的每个结点各是一棵树的根；
- 命题意图：一题四合一，把 DS05.07.01（BST 构造）、DS03.02.03（遍历互推）、DS03.02.04（线索化）、DS03.03.02（树形转换）串成一条链，且后三问全部依赖第 (1) 问的形态正确——一步错则步步错。

## 4. 核心考点

核心考点：
DS05.07.01 二叉搜索（排序）树（由先序序列重建 BST：逐元素插入；中序有序性用于反查形态）

辅助考点：
DS03.02.03 二叉树的遍历（先序→后序的互推，须先定形再递归）
DS03.02.04 线索二叉树（中序线索化：空域 $\to$ 前驱/后继，$ltag/rtag$ 标记，$n+1$ 个空域）
DS03.03.02 森林与二叉树的转换（"左孩子右兄弟"的逆映射，右链长度 = 树的棵数）

解释：本题的"入口"是 BST 独有的性质（先序即可定形，一般二叉树仅给先序不能定形），故主考点取 DS05.07.01；(2)(3)(4) 问则分别是遍历、线索化、转换三个模块的标准作图，都只用到 (1) 的结果，属辅助考点。

## 5. 解题思路

1. **定形用"插入法"最稳**：先序序列的第一个元素 $23$ 是根；其后每个元素从根出发按"小往左、大往右"下行，第一个空位即插入点。这样机械执行 $8$ 次即得树形，不需要"猜"；
2. **立刻用两条不变式自查形态**：① 中序遍历必须是递增的 $12,15,18,23,29,34,56,71$（BST 的定义性质）；② 先序遍历必须还原题给序列。二者同时成立，形态才可信；
   - 特别提醒 $18$ 的位置：$18>15$ 故它是 $15$ 的**右**孩子，不能因为先序中 $18$ 紧跟 $12$ 就挂成 $12$ 的右孩子（$12$ 的右子树中的值必须 $<15$）；
   - 同理 $34>29$ 且 $34<56$，故挂在 $29$ 的右孩子；
3. **求后序**：按"左→右→根"递归展开，每棵子树单独算再拼接，最后核对首元素是最左叶、末元素是根 $23$；
4. **中序线索化**：先把中序序列写成带序号的一行（查前驱/后继用），再逐个结点判断"左/右孩子是否为空"，空则填前驱或后继，最后数线索条数应为 $n+1=9$（其中 $2$ 个 NULL）；
5. **转森林**：沿根的右链 $23\to56\to71$ 数出 $3$ 棵树；每棵树内部按"左＝头孩、右＝亲兄弟"展开；用"森林先根遍历 = 二叉树先序"回验。

## 6. 详细解答

### 第一步：(1) 由先序重建 BST

按先序 $23,15,12,18,56,29,34,71$ 逐个插入空树：

| 序 | 插入 | 比较路径 | 落位 |
|---|---|---|---|
| 1 | $23$ | 空树 | 根 |
| 2 | $15$ | $15<23$ | $23$ 的左孩子 |
| 3 | $12$ | $12<23,\;12<15$ | $15$ 的左孩子 |
| 4 | $18$ | $18<23,\;18>15$ | $15$ 的**右**孩子 |
| 5 | $56$ | $56>23$ | $23$ 的右孩子 |
| 6 | $29$ | $29>23,\;29<56$ | $56$ 的左孩子 |
| 7 | $34$ | $34>23,\;34<56,\;34>29$ | $29$ 的右孩子 |
| 8 | $71$ | $71>23,\;71>56$ | $56$ 的右孩子 |

得到

```
            23
          /    \
       15       56
      /  \     /  \
    12   18   29   71
                 \
                 34
```

**形态自检（两条）**：
- 中序（左根右）：$12,15,18,23,29,34,56,71$ —— 严格递增 ✓ BST 性质成立；
- 先序（根左右）：$23\to15\to12\to18\to56\to29\to34\to71$ —— 与题给序列逐位相同 ✓

（若误把 $18$ 挂成 $12$ 的右孩子，中序虽仍递增，但先序也仍是 $23,15,12,18,56,\dots$；此时须用 BST 定义再查：$18$ 落在 $15$ 的左子树内 ⟹ 必须 $<15$，矛盾，故只能挂 $15$ 的右侧。**"先序 + BST 定义"两条件合起来才唯一确定形态。**）

### 第二步：(2) 后序遍历序列

自底向上，$\mathrm{post}(x)=\mathrm{post}(x_{\text{左}})\,\mathrm{post}(x_{\text{右}})\,x$：

- $\mathrm{post}(12)=12$，$\mathrm{post}(18)=18$ ⟹ $\mathrm{post}(15)=12,\;18,\;15$
- $\mathrm{post}(34)=34$；$29$ 无左子树 ⟹ $\mathrm{post}(29)=34,\;29$
- $\mathrm{post}(71)=71$ ⟹ $\mathrm{post}(56)=34,\;29,\;71,\;56$
- $\mathrm{post}(23)=\underbrace{12,18,15}_{\text{左}}\;\underbrace{34,29,71,56}_{\text{右}}\;23$

$$\boxed{\text{后序：}\;12,\;18,\;15,\;34,\;29,\;71,\;56,\;23}$$

**交叉验证（第二方法）**：用"先序 + 中序"独立重构后序。根 $23$；中序中 $23$ 左侧 $\{12,15,18\}$ 为左子树、右侧 $\{29,34,56,71\}$ 为右子树。左子树先序 $15,12,18$ ⟹ 根 $15$，其左 $\{12\}$、右 $\{18\}$，后序 $12,18,15$；右子树先序 $56,29,34,71$、中序 $29,34,56,71$ ⟹ 根 $56$，左子树为 $29(\varnothing,34)$ 后序 $34,29$，右子树 $71$，得后序 $34,29,71,56$。合并后序 $12,18,15,34,29,71,56,23$ ✓ 与第一步递归结果完全一致。

### 第三步：(3) 中序线索二叉树

**(a) 中序序列并编号**（查前驱/后继的表）：

| 序 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 结点 | $12$ | $15$ | $18$ | $23$ | $29$ | $34$ | $56$ | $71$ |

**(b) 逐结点判空域并填线索**（左空 → 中序直接前驱；右空 → 中序直接后继；`ltag/rtag`$=1$ 表示该域为线索）：

| 结点 | 左孩子 | 右孩子 | 空域处理 |
|---|---|---|---|
| $12$ | ∅ |  | 左域 $=\varnothing$ 且无前驱 ⟹ **NULL**（$ltag=1$）；右域 ⟹ 线索 → $15$ |
| $15$ | $12$ | $18$ | 无空域，不加线索 |
| $18$ | ∅ | ∅ | 左线索 → $15$；右线索 → $23$ |
| $23$ | $15$ | $56$ | 无空域 |
| $29$ | ∅ | $34$ | 左线索 → $23$；右域为实孩子 |
| $34$ | ∅ |  | 左线索 → $29$；右线索 → $56$ |
| $56$ | $29$ | $71$ | 无空域 |
| $71$ | ∅ |  | 左线索 → $56$；右域无后继 ⟹ **NULL**（$rtag=1$） |

**计数校验**：空链域总数 $=n+1=8+1=9$；上表空域 $=12(2)+18(2)+29(1)+34(2)+71(2)=9$ ✓，其中线索 $7$ 条 $+2$ 个 NULL（中序首结点 $12$ 的左域、末结点 $71$ 的右域）。

**(c) 卷面画法**：实线孩子保持第一步的树形不变，用**虚线**画出 $7$ 条线索：$12.\text{右}\to15$、$18.\text{左}\to15$、$18.\text{右}\to23$、$29.\text{左}\to23$、$34.\text{左}\to29$、$34.\text{右}\to56$、$71.\text{左}\to56$；并在 $12$ 的左域、$71$ 的右域标 $ltag=1/rtag=1$ 且指向 NULL。

**(d) 线索正确性回验**：从"最左结点 $12$"出发、沿右线索/右子树反复走 `Next()`，应得中序：$12\xrightarrow{R}15\xrightarrow{\text{右孩子? 否，}15\text{ 有右孩子}}18\xrightarrow{R}23\xrightarrow{\text{进入 }56\text{ 的最左}}29\xrightarrow{R}34\xrightarrow{R}56\xrightarrow{\text{进入 }71\text{ 的最左}}71$，序列 $12,15,18,23,29,34,56,71$ ✓ 递增，线索无误。

### 第四步：(4) 二叉树 → 森林（逆转换）

规则（"左孩子右兄弟"的反向解读）：结点的**左孩子**＝它在树中的第一个孩子；沿**右链**下去的每个结点＝依次相邻的亲兄弟；根结点自身的右链上的结点＝森林中下一棵树的根。

- **数树的棵数**：根的右链 $23\to56\to71\to\varnothing$，长 $3$ ⟹ 森林有 $3$ 棵树；
- $T_1$：根 $23$；$23$ 的左孩子 $15$ 是头孩，$15$ 的右链 $15\to18$ ⟹ $23$ 的孩子为 $15,18$；$15$ 的左孩子 $12$ 是它的头孩，$12$ 无右链 ⟹ $15$ 只有一个孩子 $12$；$12,18$ 无左孩子 ⟹ 叶子。
  $$T_1=23(15(12),18)$$
- $T_2$：根 $56$（原 $23$ 的右孩子）；$56$ 的左孩子 $29$ 是头孩，$29$ 的右链 $29\to34$ ⟹ $56$ 的孩子为 $29,34$；两者均无左孩子 ⟹ 叶子。
  $$T_2=56(29,34)$$
- $T_3$：根 $71$（$56$ 的右孩子）；$71$ 无左孩子 ⟹ 单结点树。
  $$T_3=71$$

```
T1:   23            T2:   56            T3:   71
     /   \               /  \
   15    18            29   34
    |
   12
```

**回验（两条对应等式）**：
- 森林先根遍历 $=$ 二叉树先序：$T_1:23,15,12,18$；$T_2:56,29,34$；$T_3:71$ ⟹ $23,15,12,18,56,29,34,71$ ✓ 与题给先序一致；
- 森林中序（后根）$=$ 二叉树中序：$T_1:12,15,18,23$；$T_2:29,34,56$；$T_3:71$ ⟹ $12,15,18,23,29,34,56,71$ ✓ 递增；
- 结点数 $4+3+1=8$ ✓ 无增无减。

## 8. 考场标准答案

**(1)** 以 $23$ 为根，按先序逐个插入：

```
            23
          /    \
       15       56
      /  \     /  \
    12   18   29   71
                 \
                 34
```

**(2)** 后序：$12,\;18,\;15,\;34,\;29,\;71,\;56,\;23$

**(3)** 中序 $12,15,18,23,29,34,56,71$；虚线（线索）$7$ 条：$12.\text{右}\to15$、$18.\text{左}\to15$、$18.\text{右}\to23$、$29.\text{左}\to23$、$34.\text{左}\to29$、$34.\text{右}\to56$、$71.\text{左}\to56$；$12.\text{左}=\mathrm{NULL}$、$71.\text{右}=\mathrm{NULL}$（共 $9=n+1$ 个空域）。

**(4)** 森林共 $3$ 棵树：$T_1=23(15(12),18)$、$T_2=56(29,34)$、$T_3=71$。

## 9. 易错点

1. **$18$ 挂错父结点**（挂成 $12$ 的右孩子）：先序中 $12,18$ 相邻最容易诱导这个错误；判据是 $18>15$，它不可能在 $15$ 的左子树里；
2. **$34$ 挂错**：$34<56$ 且 $34>29$，只能是 $29$ 的右孩子，不是 $56$ 的右孩子（$56$ 的右子树须全 $>56$）；
3. **线索化用错遍历口径**：本题要**中序**线索，前驱/后继必须取自中序序列；若按先序/后序填，$18$ 的左线索会错指（中序前驱是 $15$，后序前驱是 $12$）；
4. **给非空域也加线索**：$15,23,56$ 三个结点左右孩子齐全，**没有线索**，画图时不要给它们画虚线；
5. **NULL 的个数**：只有中序**首**结点的左域和中序**末**结点的右域置 NULL（$12.\text{左}$、$71.\text{右}$），其余 $7$ 个空域必须填指针；
6. **森林棵数数错**：棵数＝根沿右链能走到的结点数（$23\to56\to71$ 共 $3$），不是"左孩子个数"；把 $56$ 当成 $23$ 的儿子是最典型的错误；
7. **兄弟方向搞反**：$29,34$ 是 $56$ 的孩子且 $29$ 在左（$29$ 的右链指向 $34$），写成 $34$ 为兄、$29$ 为弟会使先根遍历变成 $56,34,29$，与二叉树先序不符——用第 6 节回验等式可立即查出。

## 10. 一句话规律

BST 给先序即可定形（逐元素插入 + "中序必递增"回查）；一棵二叉树转森林时，**右链长度就是树的棵数**，而"二叉树先序＝森林先根、二叉树中序＝森林中序"这两条等式是全部作图题免费的检查器。

## 11. 关联知识

- DS05.07.01：BST 的先序序列等价于"按该次序插入空树的输入序列"，因此同一先序与同一插入序列得到同一棵树；删除结点会破坏形态，本题未涉及；
- DS03.02.03：一般二叉树"只给先序"不能定形，本题能定形全靠 BST 性质（中序递增）——这正是"先序 + BST"与"先序 + 中序"两种定形途径的联系；
- DS03.02.02：$n$ 个结点的二叉链表有 $n+1$ 个空链域，是第 (3) 问线索条数的计数依据（本题 $n=8$，空域 $9$，线索 $7$）；
- DS03.03.02 / DS03.03.03：第 (4) 问与本库 DS-2023-18（森林→二叉树 + 后序线索化）互为逆过程，两题对照可完整覆盖"树/森林 ⇄ 二叉树 ⇄ 线索树"这条转换链；
- DS05.07.01 的查找性能：本题树高为 $3$（结点 $34$ 最深），若继续插入 $>71$ 的关键字则会沿右链拉长，BST 退化为单支树的趋势可见。
