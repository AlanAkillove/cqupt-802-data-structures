# DS-2025-02

## 1. 原题

**2、** 下列代码交换双向链表中 $p$ 结点和 $p$ 结点的前驱。请填写完整代码。

双向链表存储结构及功能函数如下：

```c
struct DLinkNode
{
    ElementType data;
    struct DLinkNode *prior;  // Front pointer
    struct DLinkNode *next;   // Rear pointer
};

void SwapWithPrevious(DLinkNode *p)
{
    DLinkNode *q=p->prior;
    _____①_____;
    p->next=q;
    //原回忆版中②在q->prior=p的后面,此处交换两者顺序
    _____②_____;
    q->prior=p;
    p->prior->next=p;
    q->next->prior=q;
}
```

> 编者说明转录：本题卷面**未设"> 订正说明"条目**，源文只在函数体内以行内注释说明"原回忆版中②在 `q->prior=p` 的后面，此处交换两者顺序"——即编者把待填空 ② 移到 `q->prior=p;` **之前**呈现，答题时必须按当前（已调整）的语句顺序填写。

## 2. 答案

| 空位 | 填写内容 | 建立的链接 |
|---|---|---|
| ① | `q->next = p->next;` | $q\to next=Y$（$Y$ 为 $p$ 的原后继） |
| ② | `p->prior = q->prior;` | $p\to prior=X$（$X$ 为 $q$ 的原前驱） |

即补全后：

```c
DLinkNode *q = p->prior;
q->next = p->next;      /* ① */
p->next = q;
p->prior = q->prior;    /* ② */
q->prior = p;
p->prior->next = p;
q->next->prior = q;
```

② 亦可写作 `p->prior = p->prior->prior;`（此刻 `p->prior` 尚未改动、仍为 $q$，再取一次 `prior` 即 $X$）。

## 3. 题目分析

- 已知：双向链表结点含 `prior`（前驱）与 `next`（后继）两个指针域；$q$ 已取为 $p\to prior$；骨架给出四条链接修改 `p->next=q`、`q->prior=p`、`p->prior->next=p`、`q->next->prior=q`；
- 目标：补两条语句，使结点 $p$ 与其前驱 $q$ **在链表上互换位置**（交换的是链接而非数据域）；
- 关键约束：
  1. 相邻两结点交换共牵涉 **6 条边**：$X\to next$、$p\to prior$、$p\to next$、$q\to prior$、$q\to next$、$Y\to prior$（其中 $X=q\to prior$、$Y=p\to next$）；骨架已给 4 条，缺的 2 条正是两个空；
  2. **读改写冲突**决定语句顺序：$Y$ 只能从 `p->next` 读出，而下一句 `p->next=q` 立即把它覆盖 ⟹ ① 必须在 `p->next=q` 之前；$X$ 只能从 `q->prior` 读出，而 `q->prior=p` 会把它覆盖 ⟹ ② 必须在 `q->prior=p` 之前（这正是编者调整顺序的原因）；
  3. 骨架通篇**不判空**，说明其设计前提是 $X$、$Y$ 都存在（带头结点的双向循环链表，或调用方保证 $p$ 既不是紧随头结点的第一个结点、也不是尾结点），见第 6 节边界讨论；
- 命题意图：考"双向链表每个换位动作要同时维护前、后两条链"以及"指针改写顺序必须避让读改写冲突"（DS01.02.03）。本题无法靠背插入/删除代码完成，必须按目标形态倒推。

## 4. 核心考点

核心考点：
DS01.02.03 链式存储：双向链表与循环链表——`prior/next` 双域的对称维护、相邻结点交换（等价于"摘下一结点再反插到其前"）时 6 条边的完整改写、语句先后次序与空指针前提

辅助考点：
DS01.02.02 链式存储：单链表——`next` 链的断开与重接只是本题的一半，另一半是 `prior` 链同步；把交换看成"单链表上摘下 $q$ 插入到 $p$ 之后"可帮助核对边集

解释："交换 $p$ 与其前驱"在双链上等价于把 $q$ 摘出后插到 $p$ 的后面：摘除时 $X\to next=p$、$p\to prior=X$ 两条边同时得到，插入时 $p\to next=q$、$q\to prior=p$、$q\to next=Y$、$Y\to prior=q$ 四条边得到——与目标形态的 6 条边完全一致，可作独立核对。

## 5. 解题思路

1. **画交换前形态**：$H\ (\text{头})\leftrightarrows X\leftrightarrows q\leftrightarrows p\leftrightarrows Y$；
2. **画目标形态**：$H\leftrightarrows X\leftrightarrows p\leftrightarrows q\leftrightarrows Y$；
3. **列目标形态要求的全部赋值**（6 条），逐条与骨架比对，标出缺失者；
4. **给缺失语句定位**：$q\to next=Y$ 只能写成 `q->next=p->next`（$Y$ 尚存于 `p->next` 的唯一时刻是 `p->next=q` 之前）⟹ 空 ①；$p\to prior=X$ 只能写成 `p->prior=q->prior`（$X$ 尚存于 `q->prior` 的唯一时刻是 `q->prior=p` 之前）⟹ 空 ②；
5. **确认已给语句在新顺序下仍正确**：`p->prior->next=p` 中 `p->prior` 须已是 $X$（依赖 ② 完成），`q->next->prior=q` 中 `q->next` 须已是 $Y$（依赖 ① 完成）——两条都排在最后，自洽；
6. **验算**：取带头结点的双向链表，令 $p$ 取不同位置的结点，沿 `next` 正向与沿 `prior` 反向各走一遍，检查两链互逆且结点数不变；再试 $p$ 为尾结点的情形，确认必须判空，从而读出骨架的前置条件。

## 6. 详细解答

### 第一步：记号与形态

记 $q=p\to prior$（待与 $p$ 交换的前驱结点），$X=q\to prior$（$q$ 的前驱），$Y=p\to next$（$p$ 的后继）。

交换前：

```
X  <->  q  <->  p  <->  Y
```

交换后（目标）：

```
X  <->  p  <->  q  <->  Y
```

### 第二步：列出目标形态的 6 条边并比对骨架

| 编号 | 目标边 | 对应赋值语句 | 骨架中是否已给 |
|---|---|---|---|
| ① | $q\to next=Y$ | `q->next = p->next;`（须在 `p->next=q` 之前） | **缺 → 空位 ①** |
| ② | $p\to prior=X$ | `p->prior = q->prior;`（须在 `q->prior=p` 之前） | **缺 → 空位 ②** |
| ③ | $p\to next=q$ | `p->next = q;` | 已给 |
| ④ | $q\to prior=p$ | `q->prior = p;` | 已给 |
| ⑤ | $X\to next=p$ | `p->prior->next = p;`（`p->prior` 此时已是 $X$） | 已给（倒数第二句） |
| ⑥ | $Y\to prior=q$ | `q->next->prior = q;`（`q->next` 此时已是 $Y$） | 已给（最后一句） |

差集恰为两条，与两个空位数目吻合，说明所填既不多也不少。

### 第三步：为什么两个空不能互换内容

假设把 ① 填成 `p->prior = q->prior;`、② 填成 `q->next = p->next;`，按骨架顺序执行：

- `q = p->prior`；
- `p->prior = q->prior` ⟹ $p\to prior=X$；
- `p->next = q` ⟹ $p\to next=q$，**此时 $Y$ 已无处可取**（`p->next` 被覆盖，`q->next` 仍为旧值 $p$）；
- `q->next = p->next` ⟹ `q->next = q`，$q$ 自指成环，$Y$ 及其后的整段链表全部丢失；

故填法唯一（② 的等价写法 `p->prior = p->prior->prior;` 除外）。同理，若按"原回忆版"把 ② 置于 `q->prior=p;` 之后，则那一刻 `q->prior` 已是 $p$，`p->prior=q->prior` 变成 `p->prior=p`，同样自指成环——这正是编者特意调整顺序并注明的原因。

### 第四步：手工走查验算

取带头结点 $H$ 的双向链表 $H,0,1,2,3,4,5$（结点编号即 `data`），令 $p$ 为数据 $3$ 的结点（$q$ 为 $2$、$X$ 为 $1$、$Y$ 为 $4$）：

| 语句 | 执行后的关键指针 |
|---|---|
| `q = p->prior;` | $q=2$（$X=q\to prior=1$，$Y=p\to next=4$） |
| 空 ①：`q->next = p->next;` | $2\to next=4$ |
| `p->next = q;` | $3\to next=2$ |
| 空 ②：`p->prior = q->prior;` | $3\to prior=1$ |
| `q->prior = p;` | $2\to prior=3$ |
| `p->prior->next = p;` | $1\to next=3$ |
| `q->next->prior = q;` | $4\to prior=2$ |

沿 `next` 自 $H$ 走：$H,0,1,\mathbf{3,2},4,5$ ✓
沿 `prior` 自尾结点 $5$ 走：$5,4,\mathbf{2,3},1,0,H$ ✓（恰为正向序列之逆，说明 6 条边全部改对、无结点失联、结点总数不变）

后台 C 程序另对 $p$ 取数据 $1,2,3,4$ 各做一次交换，正反向链均为互逆序列且数据结点恒为 $6$ 个，结果同上（程序仅作验证，本表可手工复现）。

### 第五步：边界与骨架的前置条件

- **$p$ 紧随头结点之后（$q$ 即头结点）**：$X=q\to prior=$ NULL，空 ② 使 `p->prior` 为 NULL，随后 `p->prior->next=p` 解引用空指针崩溃。故本函数不负责把首元结点与头结点交换（头结点不参与数据，交换它无意义）；若链表为**带头结点的双向循环链表**，则 $X$ 恒为头结点、不为空，该情形自然消失；
- **$p$ 为尾结点**：$Y=$ NULL，空 ① 使 `q->next` 为 NULL，最后一句 `q->next->prior=q` 解引用空指针崩溃。若需在非循环链表上支持交换尾结点，须把最后一句改写为 `if(q->next) q->next->prior=q;`（但骨架已给定不可改，故应理解调用方需保证 $p$ 不是尾结点）；在**双向循环链表**上尾结点的 `next` 是头结点，同样不必判空；
- 综上，骨架通篇不判空并非疏漏，而是默认"带头结点的双向循环链表"或"$p$ 为中间结点"的教材常见约定；答题时把两条语句填对即可，无需自行加守卫（可在说明中点出前置条件）。

**答案：① `q->next = p->next;` ② `p->prior = q->prior;`**

## 8. 考场标准答案

```c
void SwapWithPrevious(DLinkNode *p)
{
    DLinkNode *q = p->prior;   /* q 为待交换的前驱结点 */
    q->next = p->next;         /* ① q 接管 p 的原后继 Y（必须早于 p->next=q） */
    p->next = q;               /*    p 成为 q 的前驱 */
    p->prior = q->prior;       /* ② p 接管 q 的原前驱 X（必须早于 q->prior=p） */
    q->prior = p;
    p->prior->next = p;        /*    X->next = p */
    q->next->prior = q;        /*    Y->prior = q */
}
```

要点：交换相邻结点共改 6 条边，凡"取旧值"的语句必须排在该指针域被改写之前；本函数只动指针不动 `data`。时间复杂度 $O(1)$，辅助空间 $O(1)$（仅一个指针变量 $q$）。

## 9. 易错点

1. **把 ① 写成 `q->next = p;`** 之类"接回原状"的废话——$q\to next$ 原本就是 $p$，写了等于没改，$Y$ 仍被 `p->next=q` 抹掉，链表从 $p$ 之后全部丢失；
2. **两空内容互换**（或按"原回忆版"顺序答题）：导致 `q->next=q` 或 `p->prior=p` 自指成环，这是本题最典型的失分点，必须看清新骨架里 ② 已提到 `q->prior=p` 之前；
3. **只改 `next` 链、漏改 `prior` 链**（或反之）：双向链表的每条边都有"左右两份"，漏一条则反向遍历断裂——检查方法是正向、反向各走一遍，两序列必须互逆；
4. **误答成"交换 data"**：题面要求交换**结点**（改链接）。若只写 `ElementType t=p->data; p->data=q->data; q->data=t;`，虽然序列值互换了，但与骨架给出的四条指针语句自相矛盾，不符合填空要求；
5. **忽视不判空的前提**：在非循环链表上直接对尾结点调用会崩溃，答题时宜注明"$p$ 须有前驱的前驱与后继"或"链表带头结点且为双向循环"。

## 10. 一句话规律

链表指针改写题的固定三步：**画目标形态 → 列出目标形态下每一条边的赋值并与骨架求差 → 按"哪个指针域即将被覆盖"给缺失语句排序**；双向链表永远要数"两条链"，验证永远靠"正反向走查互逆 + 结点数不变"。
