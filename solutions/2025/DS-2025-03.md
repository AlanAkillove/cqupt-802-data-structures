## 2. 答案

| 空位 | 填写内容 | 作用 |
|---|---|---|
| ① | `p->next = Q->rear->next;` | 令新结点指向**当前队头结点**（此边在下一句将被覆盖，必须早于它取值） |

## 3. 题目分析

- 已知：队列用**不带方向区分的循环单链表**表示，整个 `LinkQueue` 只保存一个尾指针 `rear`，没有 `front`、也没有头结点。由循环性可推出全部关键位置：
  - **队头结点** $=Q\to rear\to next$（尾结点的后继即首元结点）；
  - **队尾结点** $=Q\to rear$；
  - **判空** $Q\to rear==\text{NULL}$（骨架的两处 `if` 正是这一约定）；
  - **队满**：链式结构不存在满的概念；
- 目标：补出入队、出队各一条缺失语句，使两函数对任意入/出队序列都保持"环完整、FIFO 正确"；
- 关键约束（环形不变式）：任何非空时刻，沿 `rear->next` 起走恰好经过队列中所有结点一次并回到 `rear->next`，且首元即队头、`rear` 即队尾；
  1. 入队是把 $p$ **插在尾结点之后**（即插到环的"队尾"位置），因此新结点必须接管"尾结点 → 队头"这条边，同时尾结点的 `next` 改指 $p$，最后尾指针前移；
  2. 出队是删除 `rear->next` 所指的队头结点，需把尾结点的 `next` 改成"队头的后继"；但当队列只剩一个结点时，`rear` 本身就是那个结点（`Q->rear==p`），删除后必须整体置空，否则 `rear` 悬空指向已出队结点；
- 命题意图：考"只设尾指针的循环链表表示队列"这一教材经典技巧（DS02.03 链式队列 + DS01.02.03 循环链表）：**省掉 front 指针而仍能 O(1) 取队头/队尾**；同时考指针改写中"先取旧值、后覆盖"的顺序意识（与本卷第 2 题同源，只是环形结构使空指针问题自动消失）。

## 5. 解题思路

1. **先把结构读透**：在纸上画出 $n=1,2,3$ 个结点时的环——$n=1$：$a\to next=a$，$rear=a$；$n=3$：$a\to b\to c\to a$，$rear=c$，队头 $=rear\to next=a$；
2. **给入队定"目标形态"**：插入 $p$ 后应为 $a\to b\to c\to p\to a$，$rear=p$；与骨架的三条语句比对：`Q->rear->next=p` 完成 $c\to next=p$，`Q->rear=p` 完成尾指针前移，**缺的正是 $p\to next=a$**；而 $a$ 此刻只能由 `Q->rear->next` 取到，且必须在 `Q->rear->next=p` 之前取 ⟹ ① 填在首位；
3. **给出队定"目标形态"**：删除队头 $p$ 后，$n\ge 2$ 时应为 $b\to\cdots\to rear\to b$，即 `Q->rear->next = p->next`（骨架已给）；$n=1$ 时环中唯一结点被取走，队列变空 ⟹ 必须 `Q->rear = NULL`，这就是 ②；
4. **逐项排除其他写法**（见第 6 节第三步）：把 ① 写成 `p->next = Q->rear;`、`p->next = NULL;`，把 ② 写成 `Q->rear->next = NULL;`、`free(p);`、`p = NULL;` 都破坏不变式；
5. **验算**：手工模拟"入队 3 个 → 出队 3 个"的每一步环状态；再检查两个边界（空队出队、出到只剩一个结点）与"清空后重新入队"。

## 6. 详细解答

以下用 $a,b,c,\dots$ 表示结点，环的写法 $x\to y$ 表示 $x\to next=y$。

### 第一步：入队（`else` 分支，当前 $n\ge 2$）

设入队前队列为 $a\to b\to c\to a$，$rear=c$（队头 $a=rear\to next$）。目标：$a\to b\to c\to p\to a$，$rear=p$。

三条语句依次为：

1. **空 ①**：`p->next = Q->rear->next;` ⟹ $p\to next=a$（新结点接住"尾→头"这条边，环仍完整，只是多了一条 $c\to a$ 的临时重复入边）；
2. `Q->rear->next = p;` ⟹ $c\to next=p$（原 $c\to a$ 被覆盖，$a$ 的入边由第 1 步的 $p\to next=a$ 保住）；
3. `Q->rear = p;` ⟹ $rear=p$。

结果：$a\to b\to c\to p\to a$，队头仍是 $rear\to next=a$，队尾 $p$ ✓。

空队分支（`if`）无需填空，其正确性可对照理解：$n=0$ 时 `Q->rear=p; p->next=p;` 使单结点自环，$rear\to next=rear=p$，队头=队尾= $p$，与 `else` 分支的不变式一致。

### 第二步：出队

设出队前 $a\to b\to c\to a$，$rear=c$。

- `p = Q->rear->next;` ⟹ $p=a$（**队头**结点，即待删除者）；
- 判断 `Q->rear == p`：
  - **不成立**（$n\ge 2$）：执行 `Q->rear->next = p->next;` ⟹ $c\to next=b$，环变为 $b\to c\to b$（若原为 3 结点），队头改为 $rear\to next=b$ ✓；$p$ 已与环断开，作为函数值返回给调用者（是否 `free` 由调用方决定，骨架未含释放语句）；
  - **成立**（$n=1$）：说明环中只有 $p$ 这一个结点，取走后队列应为空 ⟹ **空 ②**：`Q->rear = NULL;`；
- `return p;`：两种情形都要返回被删结点，故 ② 不能写成 `p = NULL;`（那会使调用者收到 NULL、误判为空队出队失败，且 $rear$ 仍悬空）。

### 第三步：错误写法的排除（逐条给反例）

| 位置 | 误填 | 后果 |
|---|---|---|
| ① | `p->next = Q->rear;` | $n=3$ 时得 $p\to next=c$；随后 $c\to next=p$，$rear=p$，环成 $p\leftrightarrows c$，**原有的 $a,b$ 全部失联**（除非 $n=1$，$n=1$ 时二者等价，故极易看错） |
| ① | `p->next = NULL;` | 出队扫描 `rear->next` 时得到 NULL，环被破坏，第二次出队即崩溃 |
| ① | 写在 `Q->rear->next=p;` 之后 | `p->next = Q->rear->next = p`，$p$ 自环，队头 $a$ 丢失 |
| ② | `Q->rear->next = NULL;` | $rear$ 未变，仍指向被出队结点，队列"非空"却含一个已删除结点；下次入队走 `else` 分支 ⟹ $p\to next=NULL$，逻辑全错 |
| ② | `Q->rear = p = NULL;` | 丢失返回结点，`return p` 返回 NULL，调用方无法取得出队元素 |
| ② | 漏填（空语句） | $n=1$ 出队后 $rear$ 仍指向该结点、$p\to next=p$，队列看似"还有一个元素"，随后入队/出队结果错乱 |

### 第四步：完整序列验算

依"空队 → 入队 $a,b,c$ → 出队三次 → 再出队一次 → 重新入队 $d$"手工模拟：

| 操作 | 环状态（队头→…→队尾） | `Q->rear` |
|---|---|---|
| 初始 | 空 | NULL |
| 入 $a$ | $a\to a$ | $a$ |
| 入 $b$ | $a\to b\to a$ | $b$ |
| 入 $c$ | $a\to b\to c\to a$ | $c$ |
| 出队 | 返回 $a$；环变为 $b\to c\to b$ | $c$（尾指针不变，队头改为 $rear\to next=b$） |
| 出队 | 返回 $b$；环变为 $c\to c$ | $c$ |
| 出队 | 空（走 `Q->rear==p` 分支置 NULL），返回 $c$ | NULL |
| 再出队 | `Q->rear==NULL` ⟹ 返回 NULL（不改动结构） | NULL |
| 入 $d$ | 走空队分支：$d\to d$ | $d$ |

出队顺序 $a,b,c$ 与入队顺序相同 ⟹ FIFO 成立；空队再出队安全返回 NULL；清空后可正常再入队 ✓

（后台 C 程序按上述序列实测：入队 $1\sim5$ 后连续出队得 `1 2 3 4 5`，出尽后 `rear==NULL`、再出队返回 NULL，随后入队 $6$ 得队头 $6$，与本表逐项一致；程序仅作验证。）

### 第五步：复杂度

两函数均只做常数次指针操作 ⟹ 时间 $O(1)$；无额外结点/数组，辅助空间 $O(1)$。整个队列占 $n$ 个结点空间，$n$ 由入队次数决定，不受静态数组长度限制（这是相对顺序队列"假溢出"的优势，见第 11 节）。

**答案：① `p->next = Q->rear->next;` ② `Q->rear = NULL;`**

## 8. 考场标准答案

```c
void EnQueue(LinkQueue *Q, LinkNode *p)
{
    if (Q->rear == NULL) {          /* 空队：新结点自环，既是队头也是队尾 */
        Q->rear = p;
        p->next = p;
    } else {
        p->next = Q->rear->next;    /* ① 新结点指向队头结点（须早于下一句） */
        Q->rear->next = p;          /*    原队尾的后继改为新结点 */
        Q->rear = p;                /*    尾指针前移 */
    }
}

LinkNode *DeQueue(LinkQueue *Q)
{
    LinkNode *p;
    if (Q->rear == NULL) return NULL;   /* 空队 */
    p = Q->rear->next;                  /* 队头结点 */
    if (Q->rear == p) Q->rear = NULL;   /* ② 只剩一个结点：出队后为空 */
    else Q->rear->next = p->next;       /*    越过队头重接环 */
    return p;
}
```

要点：只设尾指针时**队头 = `rear->next`**；入队插在尾结点之后，出队删尾结点的后继；仅剩一个结点时出队须把尾指针置空。入队、出队均 $O(1)$，辅助空间 $O(1)$。

## 9. 易错点

1. **找不到队头**：误以为 `Q->rear` 就是队头，于是把 ① 写成 `p->next = Q->rear;` 或把出队的 `p` 取成 `Q->rear`。本题结构的队头恒为 `rear->next`；
2. **① 的顺序**：必须先取 `Q->rear->next`（旧队头）再接环；写在 `Q->rear->next=p;` 之后即取到被覆盖后的新值 $p$，造成自环；
3. **② 的两种极端**：写成 `Q->rear->next=NULL`（把环打断而尾指针悬空），或只写 `free(p)`（丢失返回值且 `rear` 仍指向已释放内存）；正确做法是把**尾指针**置空；
4. **误加 `p->next = NULL;`**：循环链表的尾结点后继必须是队头，置 NULL 后它就不再是循环链表，后续所有 `rear->next` 操作失效；
5. **忽略空队判断的既有分支**：骨架已给出 `Q->rear==NULL` 的入队/出队处理，填空时不应改动或重复置空，否则答题会被判"改写题目给定语句"。

## 10. 一句话规律

用循环单链表表示队列（或串/表）时，把"表尾结点"当作唯一持久指针，则**队头 = 尾的后继**、判空靠"尾指针为空"（或 `rear->next==rear` 表示只剩一个）；凡"在环上插入/删除"，一律先按目标环列出各条边，再检查哪条边的旧值即将被覆盖——那条取值语句必须排在最前。
