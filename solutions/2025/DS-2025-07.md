# DS-2025-07

## 1. 原题

**7、** 已知数组 $A_{9\times 3\times 5\times 8}$，其中 $A[0][0][0][0]$ 的地址为 $100$，每一个整数占 $4B$，则 $A[2][1][4][7]$ 的地址为____________________。

> 订正说明转录：源文未指明数组的存储次序；按行优先（最后一维下标变化最快，C 语言约定）计算为 $100+319\times 4=1376$，按列优先存储则结果不同，作答时请写明所设存储次序。

（本题题面不含图片。）

## 2. 答案

按**行优先**（最后一维下标变化最快，C 语言约定）存储：

$$\boxed{1376}$$

按**列优先**（第一维下标变化最快，Fortran 约定）存储则为 $100+1064\times 4=4356$。两种口径的计算过程见第 6 节，考场应答时须写明所设存储次序。

## 3. 题目分析

- 已知：四维数组 $A$ 的各维长度为 $9,3,5,8$（即下标范围 $[0\sim8][0\sim2][0\sim4][0\sim7]$）；$A[0][0][0][0]$ 的地址（数组首地址）为 $100$；每个元素占 $4$ 字节；目标元素 $A[2][1][4][7]$，其四个下标均在各维范围内（$2<9$、$1<3$、$4<5$、$7<8$）✓；
- 目标：求 $A[2][1][4][7]$ 的地址 $=\text{首地址} + \text{该元素之前的元素个数}\times 4$；
- 关键约束：**"该元素之前的元素个数"依赖存储次序**，而回忆版题面未交代次序 ⟹ 必须先声明假设（编者按 C 语言的行优先处理，本解析同）；
- 核心量：各维的**元素 stride（步长）**——行优先时
  - 第 $4$ 维（长度 $8$）下标加 $1$ ⟹ 地址差 $1$ 个元素；
  - 第 $3$ 维（长度 $5$）下标加 $1$ ⟹ 跨过 $1$ 个 $8$ 元组 ⟹ 差 $8$；
  - 第 $2$ 维（长度 $3$）下标加 $1$ ⟹ 差 $5\times 8=40$；
  - 第 $1$ 维（长度 $9$）下标加 $1$ ⟹ 差 $3\times 5\times 8=120$；
- 命题意图：考 DS02.04 的一般多维数组地址公式 $Loc(a_{i_1i_2i_3i_4})=Loc(a_{0000})+\big(i_1 d_2 d_3 d_4+i_2 d_3 d_4+i_3 d_4+i_4\big)\times L$（行优先），检验"高位下标乘后面所有维长度之积"这一乘法结构在四维下是否仍算得准；同时（借编者的订正说明）提示"存储次序是指南题的必备前提"。

## 4. 核心考点

核心考点：
DS02.04 多维数组的存储——行优先/列优先的下标变化快慢方向、各维步长（stride）由"其内层各维长度之积"给出、地址 $=$ 首地址 $+$ 偏移量 $\times$ 元素长度

辅助考点：
无（本题只用到 DS02.04 一条地址公式；其余均为算术核对与量纲检查，不牵扯其他知识点）

解释：题目只需一条公式，属 DS02.04 的定义层应用；但因题面缺"存储次序"这一前提，解题必须做两种口径的并列计算与对比，故能力标签取 CONCEPT（口径辨析）+ CALCULATION + COMPARISON。

## 5. 解题思路

1. **先定口径**：题面未说明，按 C 语言约定取行优先（最后一维下标变化最快），并在答卷上写明；
2. **写出各维步长**：从内向外累乘——$1$、$8$、$5\times8=40$、$3\times5\times8=120$（分别对应第 $4,3,2,1$ 维下标每加 $1$ 所跨过的元素数）；
3. **代入目标下标** $(2,1,4,7)$：偏移量 $=2\times120+1\times40+4\times8+7\times1=319$；
4. **换算地址**：$100+319\times4=100+1276=1376$；
5. **验算**：(a) 用"逐层跳过几个完整低维数组"的分层说法复核 $319$；(b) 用末元素 $A[8][2][4][7]$ 的偏移量应为 $9\times3\times5\times8-1=1079$ 复核步长体系自洽；(c) 独立按列优先再算一遍得 $4356$，确认两口径确实不同、从而说明"必须写明假设"；
6. 若题目改成"按列优先"或"给 $A[1][1][1][1]$ 起始下标"，同一套步长方法按新方向重列即可（见第 9 节易错点 3）。

## 6. 详细解答

### 第一步：行优先——分层"跳过多少个低维数组"

$A$ 可看作 $9$ 个"三维块"（每块 $3\times5\times8=120$ 个元素），每个三维块含 $3$ 个"二维片"（每片 $5\times8=40$ 个元素），每片含 $5$ 行（每行 $8$ 个元素）。

要求 $A[2][1][4][7]$ 之前有多少个元素：

| 层次 | 下标 | 跳过的完整低维数组 | 元素数 |
|---|---|---|---|
| 第 1 维 | $i_1=2$ | $2$ 个 $3\times5\times8$ 块 | $2\times120=240$ |
| 第 2 维 | $i_2=1$ | $1$ 个 $5\times8$ 片 | $1\times40=40$ |
| 第 3 维 | $i_3=4$ | $4$ 个长度 $8$ 的行 | $4\times8=32$ |
| 第 4 维 | $i_4=7$ | 同行内前驱 | $7$ |
| 合计 | | | $240+40+32+7=319$ |

$$Loc=100+319\times 4=100+1276=\boxed{1376}$$

### 第二步：行优先——通用公式复核

行优先地址公式（下标自 $0$ 起，各维长度记 $d_1=9,d_2=3,d_3=5,d_4=8$，元素长 $L=4$，基址 $B=100$）：
$$Loc= B+\big(i_1 d_2 d_3 d_4+i_2 d_3 d_4+i_3 d_4+i_4\big)L$$
代入：
$$Loc=100+\big(2\times3{\times}5{\times}8+1\times5\times8+4\times8+7\big)\times4=100+(240+40+32+7)\times4=1376$$
与第一步逐层计数一致 ✓

### 第三步：列优先对照

列优先（第一维下标变化最快，Fortran 约定）的步长由**外向内累乘**：
$$\text{stride}_1=1,\quad \text{stride}_2=d_1=9,\quad \text{stride}_3=d_1 d_2=27,\quad \text{stride}_4=d_1 d_2 d_3=135$$
偏移量 $=2\times1+1\times9+4\times27+7\times135=2+9+108+945=1064$
$$Loc=100+1064\times4=100+4256=4356$$

两口径结果不同（$1376\neq 4356$），证实"存储次序"是必需前提；编者按 C 语言约定取 $1376$ 为本卷答案。

### 第四步：合理性验算

- 总元素数 $N=9\times3\times5\times8=1080$，数组占 $100\sim100+1080\times4-1=4419$；两个候选地址 $1376$、$4356$ 均落在该区间内 ✓；
- 行优先下末元素 $A[8][2][4][7]$ 的偏移量应为 $N-1=1079$：$8\times120+2\times40+4\times8+7=960+80+32+7=1079$ ✓ ⟹ 步长体系 $\{120,40,8,1\}$ 自洽；
- 相邻性检查：行优先下 $A[0][0][0][0]$ 与 $A[0][0][0][1]$ 地址差 $4B$（同一维内只差一个元素），而 $A[0][0][1][0]$ 与前者差 $8\times4=32B$（跨过一行的 $8$ 个元素）——这正是"最后一维变化最快"的含义；
- 列优先下同样验证末元素：$8\times1+2\times9+4\times27+7\times135=8+18+108+945=1079=N-1$ ✓。

（后台 C 程序对 `int A[9][3][5][8]` 打印相邻下标元素的地址差，实测四维 stride 依次为 $120,40,8,1$（单位：元素），与第一、二步一致；程序仅作验证，正文计算可手工复现。）

## 8. 考场标准答案

设各维长度 $d_1=9$、$d_2=3$、$d_3=5$、$d_4=8$，元素长度 $L=4B$，首地址 $B_0=100$。**按行优先（最后一维下标变化最快）存储**：

$$A[2][1][4][7]\ \text{之前的元素数}=2d_2d_3d_4+1\cdot d_3d_4+4\cdot d_4+7=240+40+32+7=319$$

$$Loc(A[2][1][4][7])=100+319\times4=1376$$

**答：$1376$（假设按行优先存储；若按列优先存储，偏移量为 $2+9+108+945=1064$，地址为 $4356$）。**

## 9. 易错点

1. **忘记写明存储次序**：题面确实没给，直接写 $1376$ 而不注明假设，遇到按 Fortran 口径命题的评分标准就无从申辩；规范做法是"按行优先（C 约定）计算，故为 $1376$"；
2. **步长乘错维**：行优先时第 $1$ 维的下标应乘其**内层各维**长度之积 $d_2d_3d_4=3\times5\times8=120$；常见错误是连当前维一起乘（乘成 $d_1d_2d_3=135$，那是列优先的步长），或漏乘某一维（乘成 $5\times8=40$）；记忆口诀：**"该下标乘以它后面（更内层）所有维的长度之积"**；
3. **把行列优先的累乘方向搞反**：行优先的步长由内向外累乘（$1,8,40,120$），列优先由外向内累乘（$1,9,27,135$），两者不可混用；列优先时第 $4$ 维步长是 $d_1d_2d_3=135$，不是 $8$；
4. **下标从 $1$ 起的口径混入**：若数组按 Pascal 风格下标自 $1$ 开始，偏移量要用 $i_k-(\text{下界})$；本题基址元素是 $A[0][0][0][0]$，下标自 $0$ 起，直接用下标值即可，不必减 $1$；
5. **算出偏移量后忘记乘 $L$**（写成 $419$）或**忘记加基址**（写成 $1276$）；
6. 把 $A_{9\times3\times5\times8}$ 误读成"共有 $9+3+5+8$ 个元素"或某维长度颠倒——各维长度只是乘积关系，顺序影响步长，须与下标 $[2][1][4][7]$ 逐位对应。

## 10. 一句话规律

多维数组求地址永远是三步：**定次序 → 算各维步长（行优先"乘内层各维"、列优先"乘外层各维"）→ 偏移量 $\times L +$ 基址**；末元素偏移量应恰为"总元素数 $-1$"，这是最快的自检法。
