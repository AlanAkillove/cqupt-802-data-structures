# DS-2025-21

## 1. 原题

**21、** 给定一个单链表，找到倒数第 $k$ 个元素。如果找到该元素，打印该元素的值并返回 $1$，否则返回 $0$。

（1）描述算法的基本设计思想；

（2）根据设计思想，采用 $C$ 语言描述算法。

结点定义如下：

```c
typedef struct node
{
    int data;
    struct node *next;
}LNode,*LinkList;
```

（本题无订正说明；题面未说明是否带头结点，本解析按**不带头结点**、`L` 即首元结点处理，并在第 6、9 节给出带头结点的改法。）

## 2. 答案

**设计思想（第 (1) 问）**：设链表长度为 $n$，倒数第 $k$ 个结点即正数第 $n-k+1$ 个结点。用两个指针 $p$、$q$ 保持 $k$ 个结点的固定间距：$p$ 与 $q$ 都先指向首元结点，令 $p$ 先向后移动 $k$ 次；此后 $p$、$q$ 以相同速度同时后移，当 $p$ 走到 `NULL` 时，$q$ 恰好走了 $n-k$ 步，落在正数第 $n-k+1$ 个结点，即倒数第 $k$ 个结点。若 $p$ 在前 $k$ 步内已到达 `NULL`，说明 $k>n$（或 $k\le 0$、表空），返回 $0$。

**参考代码（第 (2) 问）**：

```c
int FindKthToTail(LinkList L, int k)
{
    LNode *p = L, *q = L;
    int i;
    if (L == NULL || k <= 0)        /* 空表或 k 非法 */
        return 0;
    for (i = 0; i < k; i++)         /* p 先走 k 步 */
    {
        if (p == NULL)              /* 不足 k 个结点，k > n */
            return 0;
        p = p->next;
    }
    while (p != NULL)               /* p、q 同速后移 */
    {
        p = p->next;
        q = q->next;
    }
    printf("%d\n", q->data);        /* q 即倒数第 k 个结点 */
    return 1;
}
```

时间复杂度 $O(n)$，空间复杂度 $O(1)$，只需一趟扫描。

## 3. 题目分析

- 已知：不带头结点的单链表 `LinkList L`（结点只有 `data` 与 `next`，**没有** `prior`、没有表长域）；整数 $k$；
- 目标：定位倒数第 $k$ 个结点，打印其 `data` 并返回 $1$；不存在则返回 $0$；
- 关键约束与口径：
  1. 单链表只能**从前往后**遍历，无法由表尾倒着数——所以"先求表长 $n$ 再走 $n-k+1$ 步"必然要**两趟**扫描；
  2. 题面"找到/找不到"包含两类失败：$k>n$（数不够）、以及 $k\le 0$、空表等非法输入，代码必须显式处理并返回 $0$；
  3. "打印该元素的值"是**输出要求**，不是返回值语义——返回值只表示"找到与否"（$1/0$），不要写成返回结点的值；
- 命题意图：考单链表上**双指针（快慢指针）保持定长间距**这一典型技巧，替代"先数长度"的两趟做法；同时考查边界判断是否写全（$k>n$、$k=0$、空表、$k=n$、单结点）；
- 与"求表长再定位"的对比：两法时间同为 $O(n)$，但双指针只需**一趟**遍历，在链表很长、结点分散于内存时访问次数减半，且不需要保存 $n$——这是本题标准答案选择双指针的原因。

## 5. 解题思路

1. **先把"倒数"翻译成"正数"**：倒数第 $k$ 个 $=$ 正数第 $n-k+1$ 个。这一步把问题变成"定位第 $i$ 个结点"，但 $n$ 未知是障碍；
2. **朴素解**：第一趟数出 $n$，第二趟走 $n-k+1$ 步——正确但两趟，先写下它作为对照与验证基准；
3. **消除"必须先知道 $n$"的障碍**：注意到"倒数第 $k$ 个结点到表尾的距离恰好是 $k-1$ 条边"，即它比表尾"早 $k$ 步"。于是让一个指针 $p$ 提前走 $k$ 步去"探路"，另一个指针 $q$ 留在表头，之后两者同步移动——$p$ 到 `NULL` 的那一刻，$q$ 与 `NULL` 之间正好隔着 $k$ 个位置；
4. **不变量**（第 (1) 问写出它比只叙述步骤更有说服力）：同步阶段每一步之后，$p$ 与 $q$ 之间始终相隔 $k$ 条链；
5. **边界**：$k\le 0$ 直接返回 $0$；$L$ 为 `NULL`（空表）返回 $0$；探路阶段 $p$ 变成 `NULL` 说明 $k>n$，返回 $0$；$k=n$ 时探路循环最后一次进入循环体时 $p$ 指向第 $n$ 个结点（非空），执行 `p = p->next` 后 $p$ 才为 `NULL`，循环正常结束而不触发 `return 0`，随后同步循环一次也不执行，$q$ 停在首元结点——正是倒数第 $n$ 个 ✓（这一情形最容易被误判为失败，必须单独走查）；
6. **用小例子验证**：$1\to2\to3\to4\to5$，$k=2$ 应得 $4$；$k=1$ 应得 $5$；$k=5$ 应得 $1$；$k=6$ 应返回 $0$（见第 6 节走查表）。

## 6. 详细解答

### 第一步：设计思想（第 (1) 问完整表述）

设单链表 $L$ 不带头结点，$n$ 为结点个数（未知）。倒数第 $k$ 个结点存在当且仅当 $1\le k\le n$，它是正数第 $n-k+1$ 个结点。

算法使用两个指针 $p$、$q$，初始均指向首元结点：

- **阶段一（探路）**：$p$ 沿 `next` 向后移动 $k$ 次。若在某次移动**之前** $p$ 已为 `NULL`，说明链表中不足 $k$ 个结点（$k>n$），算法返回 $0$；
- **阶段二（同步后移）**：$p$、$q$ 每次各移动一个结点，直到 $p$ 为 `NULL`。此阶段 $p$ 又移动了 $n-k$ 次（从第 $k+1$ 个结点走到 `NULL`），故 $q$ 从首元结点出发移动了 $n-k$ 次，停在正数第 $n-k+1$ 个结点上；
- **输出**：打印 `q->data`，返回 $1$。

**核心不变量**：阶段二每一轮开始时，从 $q$ 出发沿 `next` 走 $k$ 步恰好到达 $p$。当 $p==NULL$ 时，$q$ 到表尾（`NULL`）的距离为 $k$ 个位置，即 $q$ 是倒数第 $k$ 个结点。

### 第二步：参考代码（第 (2) 问）

```c
int FindKthToTail(LinkList L, int k)
{
    LNode *p = L, *q = L;
    int i;
    if (L == NULL || k <= 0)        /* 空表，或 k 非正 */
        return 0;
    for (i = 0; i < k; i++)         /* 阶段一：p 先走 k 步 */
    {
        if (p == NULL)              /* 走到第 k 步前已越界 => k > n */
            return 0;
        p = p->next;
    }
    while (p != NULL)               /* 阶段二：p、q 同速 */
    {
        p = p->next;
        q = q->next;
    }
    printf("%d\n", q->data);        /* 倒数第 k 个结点的值 */
    return 1;
}
```

**带头结点时的改法**：若约定 `L` 为头结点（`L->next` 才是首元结点），只需把初始化改为 `LNode *p = L->next, *q = L->next;` 并把判空条件写成 `if (L == NULL || L->next == NULL || k <= 0)`，其余不变。

### 第三步：手工走查（$n=5$，链表 $1\to2\to3\to4\to5$）

| $k$ | 阶段一后 $p$ 指向 | 阶段二移动次数 | $q$ 最终指向 | 输出 | 返回值 | 期望（正数第 $n-k+1$ 个） |
|---|---|---|---|---|---|---|
| $1$ | 第 $2$ 个结点($2$) | $4$ | 第 $5$ 个($5$) | $5$ | $1$ | 第 $5$ 个 $=5$ ✓ |
| $2$ | 第 $3$ 个结点($3$) | $3$ | 第 $4$ 个($4$) | $4$ | $1$ | 第 $4$ 个 $=4$ ✓ |
| $3$ | 第 $4$ 个结点($4$) | $2$ | 第 $3$ 个($3$) | $3$ | $1$ | 第 $3$ 个 $=3$ ✓ |
| $5$ | `NULL`（走满 $5$ 步） | $0$（循环不执行） | 第 $1$ 个($1$) | $1$ | $1$ | 第 $1$ 个 $=1$ ✓ |
| $6$ | 第 $6$ 次进入循环体时 $p$ 已为 `NULL` | — | — | — | $0$ | $k>n$，返回 $0$ ✓ |
| $0$ | 未进入阶段一 | — | — | — | $0$ | $k\le0$ 非法 ✓ |

**边界补充**：空表（$L$ 为 `NULL`）、$k$ 为负数、单结点表取 $k=1$（返回该结点值）与 $k=2$（返回 $0$）均已逐一代入代码分支验证，行为与题意一致。

### 第四步：备选解（两趟：先数长度再定位）

```c
int FindKthToTail_2Pass(LinkList L, int k)
{
    LNode *q;
    int n = 0, i;
    for (q = L; q != NULL; q = q->next)   /* 第一趟：数长度 */
        n++;
    if (k <= 0 || k > n)                  /* 不存在 */
        return 0;
    for (q = L, i = 1; i < n - k + 1; i++)/* 第二趟：走到第 n-k+1 个 */
        q = q->next;
    printf("%d\n", q->data);
    return 1;
}
```

两法结果完全一致（本解析对 $k=-1\sim 7$、空表、单结点两种情形逐一比对，输出相同 ✓）。备选解胜在直观、便于验证；主解胜在只需一趟扫描、且是命题者想要的技巧。

### 第五步：复杂度分析

- **主解（双指针）**：阶段一至多 $k$ 次移动（$k\le n$ 时恰好 $k$ 次），阶段二 $n-k$ 次移动，合计 $n$ 次结点访问，**时间 $O(n)$**；只用了 $p,q,i$ 三个辅助变量，**空间 $O(1)$**。$k>n$ 时在阶段一第 $n+1$ 次迭代即退出，仍为 $O(n)$。
- **备选解（两趟）**：时间同为 $O(n)$，但结点被访问 $n+(n-k+1)$ 次，约为主解的两倍；空间 $O(1)$。
- 单链表无法随机访问是这里必须"走步"的根因：若数据在顺序表中，直接 `A[n-k]` 即可 $O(1)$ 定位。

## 8. 考场标准答案

**(1) 基本设计思想**：倒数第 $k$ 个结点是正数第 $n-k+1$ 个结点。设置指针 $p$、$q$ 都指向首元结点；先让 $p$ 向后移动 $k$ 个结点，若中途 $p$ 变为 `NULL` 则链表长度不足 $k$，返回 $0$；然后 $p$、$q$ 每次各移一个结点同步后移，直到 $p$ 为 `NULL`，此时 $q$ 与表尾相隔 $k$ 个位置，即 $q$ 所指结点就是倒数第 $k$ 个结点，打印 `q->data` 并返回 $1$。算法只需一趟扫描，时间 $O(n)$，附加空间 $O(1)$。

**(2) C 语言描述**：见第 6 节第二步代码（`FindKthToTail`）。

**评分要点**：① 说明"倒数第 $k$ = 正数第 $n-k+1$"或等价的间距不变量；② 两指针先走 $k$ 步再同步；③ $k>n$、空表、$k\le0$ 的失败分支返回 $0$；④ 找到时**打印**结点值且返回 $1$；⑤ 复杂度结论 $O(n)$/$O(1)$ 正确。

## 9. 易错点

1. **$p$ 先走的步数写成 $k-1$ 或 $k+1$**：正确是 $k$ 步。走 $k-1$ 步会让 $q$ 停在倒数第 $k-1$ 个（偏一位），是最常见的失分点；务必用"$k=n$ 应停在第 $1$ 个"这一极端情形自检；
2. **判空位置放错**：`if (p == NULL) return 0;` 必须在 `p = p->next;` **之前**（即"移动前检查能否移动"）。若写在移动之后，则 $k=n$ 时会误判为"越界失败"而返回 $0$，把正确答案吃掉；
3. **忘记 $k\le0$ 与空表**：$k=0$ 时 `for` 循环一次不执行、`while` 正常走完，$q$ 会停在最后一个结点而被当作"倒数第 $0$ 个"输出——语义错误，必须先挡掉；
4. **返回值语义写反**：题面要求"找到打印值并返回 $1$，否则返回 $0$"，返回的是**逻辑标志**，不是元素值；写成 `return q->data;` 不得分；
5. **`printf` 放在返回之后**或忘了打印：第 (2) 问的"打印该元素的值"是硬性输出要求；
6. **移动 $p$ 时未保存后继**：本题只是单向移动，`p = p->next;` 安全；但若在阶段一之后需要回头找表头，就没有指针可用了——这正是必须同时保留 $q$ 的原因；
7. **把带头结点与不带头结点混用**：题面定义 `typedef struct node{...}LNode,*LinkList;` 未给头结点，若按 `L->next` 起步会整体偏一位；作答时应**在卷面写明约定**；
8. 用数组先把链表存下来再倒着数：空间 $O(n)$ 且需两趟，虽正确但不是本题期望的 $O(1)$ 空间解法，可能扣"空间效率"分。

## 10. 一句话规律

链表上"倒数第 $k$ 个"一律用**快慢双指针保持 $k$ 步间距**：快指针先走 $k$ 步，之后同速前进，快指针撞 `NULL` 时慢指针就是答案；写完后用"$k=n$ 应停在首元结点"和"$k=n+1$ 应返回 $0$"两句自检。
