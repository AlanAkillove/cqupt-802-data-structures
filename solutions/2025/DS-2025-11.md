# DS-2025-11

## 1. 原题

**11、** 设广义表 $L=((a,b),(c,d))$，求 $getHead(getTail(L))=$ ____________________。

（本题无订正说明，题面不含图片。）

## 2. 答案

$$\boxed{(c,d)}$$

结果是 $L$ 的第二个元素——一个**子表** $(c,d)$；既不是原子 $c$，也不是表 $((c,d))$。

## 3. 题目分析

- 已知：广义表 $L=((a,b),(c,d))$。它是一层表，含 $2$ 个元素：第 $1$ 个元素是子表 $(a,b)$，第 $2$ 个元素是子表 $(c,d)$；故 $L$ 的**长度** $=2$，**深度** $=2$（元素最高嵌套层数为 $1$，加外层共 $2$ 层）；
- 目标：按顺序做两个运算——先 $getTail$（取表尾），再 $getHead$（取表头）；
- 关键定义（两条，必须记准括号规则）：
  1. **表头 $getHead(L)$**：$L$ 的**第一个元素**，可以是原子也可以是子表；返回时**不外加括号**；
  2. **表尾 $getTail(L)$**：$L$ 中**除第一个元素之外其余元素组成的表**；即使剩下的元素是原子，结果也要**带一层表括号**（这是学生最常丢的地方）；非空表的表尾一定还是表；长度为 $1$ 的表其表尾为 $()$（空表，不是 NULL、不是原子）；
- 易混淆点：本题 $getTail(L)=((c,d))$ 有**两层**括号——外层是"表尾必须是表"给的，内层是元素 $(c,d)$ 自带的；随后 $getHead$ 剥掉外层取走那个元素，得 $(c,d)$；
- 命题意图：考 DS02.08 表头/表尾的形式定义与“括号层数”敏感训练，是本类运算中最基础的两步题（对比本库 DS-2006-33 需连做四层 $head/tail$ 运算）。

## 4. 核心考点

核心考点：
DS02.08 广义表的定义——表头（第一个元素，可为原子或子表）与表尾（其余元素构成的表，必带括号）的定义及嵌套括号层数

辅助考点：
无（本题不涉及广义表的链式存储实现与深度/长度计算以外的内容；括号层数检查用 $L=((a),(b))$ 类同型表代入即可）

解释：全部推理只依赖表头、表尾两条定义，故主考点唯一取 DS02.08；链式存储（`hp/tp` 结点）只是同一规则的图形化表述，不构成本题的独立考点。

## 5. 解题思路

1. **先把 $L$ 的元素逐个列出来**：$L$ 的 $2$ 个元素是 $e_1=(a,b)$、$e_2=(c,d)$——这一步决定后面所有结论，务必按逗号切分而不是按括号切分；
2. **按定义做第一步 $getTail(L)$**：去掉 $e_1$，剩余元素 $e_2$ 组成表 ⟹ $getTail(L)=(\,e_2\,)=((c,d))$；
3. **再做 $getHead$**：对表 $((c,d))$ 取第一个元素，其唯一元素就是 $e_2=(c,d)$ ⟹ 结果 $(c,d)$；
4. **括号层数自检**：$getTail$ 使层数 $+1$（相对于元素自带层数），$getHead$ 使层数 $-1$（剥掉最外层）；本题"先尾后头"层数回到元素本身，故答案与 $e_2$ 完全相同，是 $(c,d)$；
5. **反证排除**：若要得到原子 $c$，必须再取一次表头，即 $getHead(getHead(getTail(L)))=c$；本题少一层，所以不能答 $c$（见第 9 节）。

## 6. 详细解答

### 第一步：分解 $L$

$$L=\big(\,(a,b),\;(c,d)\,\big)$$

| 属性 | 值 |
|---|---|
| 长度（最外层的元素个数） | $2$ |
| 第 $1$ 个元素 | 子表 $(a,b)$ |
| 第 $2$ 个元素 | 子表 $(c,d)$ |
| 深度 | $2$ |

### 第二步：$getTail(L)$

表尾 = 除首元素外其余元素组成的**表**：

$$getTail(L)=\big(\,(c,d)\,\big)=((c,d))$$

注意这里必须保留两层括号：外层是"表尾是表"这一规定加的，内层 $(c,d)$ 是元素自身携带的。

### 第三步：$getHead(((c,d)))$

表头 = 该表的**第一个元素**（连同其自身结构整体取出）：

$$getHead(getTail(L))=getHead\big(((c,d))\big)=(c,d)$$

结果是一个子表。

### 第四步：链式表示下的核对（教材 `hp/tp` 约定）

广义表的头尾链表中，每个元素结点带 `tag`（原子/子表标记）、`hp`（指向该元素）与 `tp`（指向下一个元素结点）：

```c
typedef enum { ATOM, LIST } ListTag;
typedef struct GLNode {
    ListTag tag;                       /* ATOM: 原子; LIST: 子表 */
    union {
        AtomType atom;                 /* 原子值 */
        struct GLNode *hp;             /* 子表的表头指针 */
    } data;
    struct GLNode *tp;                 /* 表尾指针：指向同层的下一个元素结点 */
} GLNode, *GList;
```

$L$ 的链表为 $1$ 个头结点，其后同层串接 $2$ 个元素结点（第 $1$ 个指向子表 $(a,b)$，第 $2$ 个指向子表 $(c,d)$）：

- $getTail(L)$：沿头结点的 `tp` 走一步，得到"以第 $2$ 个元素结点为表头的表"，即 $((c,d))$ —— 与第二步一致；
- $getHead(getTail(L))$：再取该表首元素结点的 `hp`，指向的就是子表 $(c,d)$ —— 与第三步一致 ✓

### 第五步：代入同型表验证规则

取结构同型、元素更易辨的 $L'=((a),(b))$：$getTail(L')=((b))$，$getHead(getTail(L'))=(b)$——答案恰为 $L'$ 的第 $2$ 个元素本身。可见"先尾后头"的作用就是**取第 $2$ 个元素**，与本题 $(c,d)$ 一致 ✓

再看本库同族题 DS-2006-33（$L=((a,b,c),(d,e,f))$ 求 $head(tail(head(tail(L))))$）：同一套规则逐步展开为
$$tail(L)=((d,e,f))\to head=\,(d,e,f)\to tail=((e,f))\to head=e$$
其答案 $e$ 正是一个原子（因为多套了一层 $head$），与本题"少一层、停在子表 $(c,d)$"形成清晰对照，两题互验 ✓

**答案：$(c,d)$。**

## 8. 考场标准答案

$L=((a,b),(c,d))$ 的长度为 $2$，两个元素依次为 $(a,b)$、$(c,d)$。

$$getTail(L)=((c,d))\quad(\text{表尾必带一层表括号})$$
$$getHead(getTail(L))=getHead(((c,d)))=(c,d)\quad(\text{表头取第一个元素本身})$$

**答：$(c,d)$（子表）。**

## 9. 易错点

1. **答成 $c$**：把"表头"理解成"最里面的原子"。$c$ 需要再取一层表头：$getHead(getHead(getTail(L)))=c$；$getHead$ 一次只剥一层，且剥掉的是**最外层表的括号**，不是元素自己的括号；
2. **答成 $((c,d))$**：漏做了 $getHead$，或者误以为 $getHead$ 不改变括号层数——$getHead$ 是"取元素"，会把外层表剥掉；
3. **答成 $(d)$ 或 $d$**：错误地认为 $getTail$ 会去掉元素 $(c,d)$ 的首原子。$getTail$ 作用在**外层表**上，只去掉外层表的第一个元素 $(a,b)$，不会伸进子表内部；
4. **按括号而非逗号切分元素**：把 $L$ 看成 $4$ 个元素 $a,b,c,d$ 或 $3$ 个元素，导致 $getTail$ 结果完全不同。正确做法是"最外层括号内，按最外层的逗号切分"；
5. **忘记表尾必为表**：写成 $getTail(L)=(c,d)$（少一层括号），随后一步 $getHead$ 就会错取到 $c$——本题若按此错误中间值继续算，恰好得到错误答案 $c$，这是最常见的连锁失误路径。

## 10. 一句话规律

广义表的 $head/tail$ 运算只看**最外层括号内按逗号切分的元素序列**：$getHead$ 取第 $1$ 个元素（剥一层括号，可交出原子或子表），$getTail$ 交出第 $2$ 个及以后所有元素并**始终套上一层表括号**；"先 $tail$ 再 $head$"就是"取第 $2$ 个元素"。
