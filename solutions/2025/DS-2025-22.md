# DS-2025-22

## 1. 原题

**22、** 给定一棵二叉树，输出从根结点到叶子结点的最长路径，打印路径的结点值，并输出该路径的长度。

（1）描述算法的基本设计思想；

（2）根据设计思想，采用 $C$ 语言描述算法。

二叉树的链式存储结构描述如下：

```c
typedef struct BiTNode{
    ElemType data;
    struct BiTNode *lchild,*rchild;
}BiTNode,*BiTree;
```

（本题无订正说明。题面未给出 `ElemType` 的具体类型，本解析按 `typedef int ElemType;` 实现，若为 `char` 只需把输出格式符改为 `%c`；"路径的长度"本解析按**路径上结点个数**口径给出，若按"边数"口径应减 $1$，见第 9 节第 5 条。）

## 2. 答案

**设计思想（第 (1) 问）**：从根到叶子的一条路径，正是先序（深度优先）递归下降时"当前正在考察的那一串结点"。因此以前序遍历为骨架，用一个共享数组 `path[]` 和长度 `len` 保存根到当前结点的路径：进入结点时把它的 `data` 追加到 `path[len]`（`len++`），离开时回退（`len--`，即回溯）。当且仅当访问到**叶子结点**时，`path[0..len-1]` 就是一条完整的根到叶路径，将其长度 `len` 与已得到的最长长度比较，若更长就把整段路径复制保存到 `best[]`。遍历结束时 `best[]` 中即为所求，打印结点值序列并输出长度。

**参考代码（第 (2) 问，核心递归）**：

```c
void LongestPath(BiTree bt, ElemType path[], int len,
                 ElemType best[], int *pBestLen)
{
    int i;
    if (bt == NULL) return;                  /* 空树/空子树 */
    path[len] = bt->data;
    len++;                                   /* 当前结点入路径 */
    if (bt->lchild == NULL && bt->rchild == NULL)   /* 叶子：一条完整路径 */
    {
        if (len > *pBestLen)
        {
            *pBestLen = len;
            for (i = 0; i < len; i++) best[i] = path[i];
        }
    }
    else
    {
        LongestPath(bt->lchild, path, len, best, pBestLen);
        LongestPath(bt->rchild, path, len, best, pBestLen);
    }
    /* len 为值传递，返回时自动恢复，无需显式回溯 */
}
```

**输出封装**：

```c
void PrintLongestPath(BiTree bt)
{
    ElemType path[MaxSize], best[MaxSize];
    int bestLen = 0, i;
    LongestPath(bt, path, 0, best, &bestLen);
    if (bestLen == 0) { printf("空树，无根到叶路径\n"); return; }
    printf("最长路径: ");
    for (i = 0; i < bestLen; i++) printf("%d ", best[i]);
    printf("\n路径长度: %d\n", bestLen);
}
```

## 3. 题目分析

- 已知：二叉链表存储的二叉树 `BiTree bt`（无双亲指针、无结点计数字段）；
- 目标：**输出**（打印结点值）从根到**叶子**的最长路径，并输出该路径的长度；
- 关键约束与口径：
  1. "叶子"指 `lchild==NULL && rchild==NULL` 的结点——不是"最深结点"，也不是"右孩子为空的结点"；只有到叶子，路径才算"完整"，中途结点不能成为候选答案；
  2. "最长"指路径上结点个数最多，等价于"该路径长度 $=$ 树的深度"，因此答案路径的条数可能不止一条（等长时题面只要求"输出……的一条"）；
  3. 二叉树没有双亲指针，**无法从叶子反向走到根**，所以必须在向下走的同时把路径记下来（数组或递归栈），这是本题选择"遍历 $+$ 路径数组"的根本原因；
  4. 空树没有根到叶路径，必须单独处理（否则打印出未初始化的数组内容）；
- 命题意图：考**前序遍历与回溯的配合**——"进入时登记、离开时撤销"这一模式（同框架可用于求树高、求所有根到叶路径、判断是否平衡等）；同时考"什么时候才算找到一条完整路径"（叶子判定）；
- 陷阱提示：把"最长路径"误当成"中序/层次序列"、把"路径"误写成"从某结点到叶子"、忘记在返回时回退 `len`（若 `len` 改为指针或全局变量传递，回退就是必须的，见第 9 节第 2 条）。

## 5. 解题思路

1. **先确定"候选答案何时产生"**：路径必须以根为起点、以叶子为终点，所以只有递归走到叶子的那一刻，`path[0..len-1]` 才是一个完整候选——把判定条件写成"两个孩子都为空"，而不是"到了空树"（若以 `bt==NULL` 为候选，则度为 $1$ 的结点会被重复计入两条"假路径"，长度虽相同但会产生多余分支）；
2. **再确定"路径怎么存"**：递归向下时，当前结点的所有祖先恰好就是递归栈上的那些结点；用一个与递归同生同灭的数组 `path[]` 显式保存最省事——进入时 `path[len]=data`，离开时 `len` 回退；
3. **最后确定"怎么比最长"**：维护 `best[]` 与 `*pBestLen`，只在 `len > *pBestLen` 时整段复制（严格大于，保证等长时保留先找到的那条，即"最左"的那条）；
4. **递归函数只负责"找"，不负责"打印"**：打印放在外层封装函数里，遍历结束后一次输出，避免"边遍历边打印"导致中途结果被覆盖；
5. **另一条思路（自底向上）**：先递归求每棵子树的深度，再自根向下"哪边深就往哪边走"，边走边打印——不需要路径数组，也不需回溯，作为第 6 节第四步的备选解，并与主解结果互相验证；
6. **小样例走查**：用第 6 节第一步给出的 $7$ 结点树（深度 $4$，两条等长路径）逐层填 `path[]`，检查回溯是否干净、最终输出是否为其中一条。

## 6. 详细解答

### 第一步：走查用样例树

```
            1
          /   \
        2       3
       /         \
      4           5
     /             \
    6               7
```

结构说明：$1$ 的左孩子 $2$、右孩子 $3$；$2$ 只有左孩子 $4$；$3$ 只有右孩子 $5$；$4$ 只有左孩子 $6$；$5$ 只有右孩子 $7$。叶子结点只有 $6$ 与 $7$（注意 $2,3,4,5$ 度数均为 $1$，不是叶子）。根到叶路径共 $2$ 条：$1\text{-}2\text{-}4\text{-}6$ 与 $1\text{-}3\text{-}5\text{-}7$，长度均为 $4$，恰等于树的深度。

### 第二步：主解逐步走查（`path[]` 与 `best[]` 的变化）

| 访问结点 | 动作 | `path[0..]` 内容 | $len$ | 是否叶子 | `best[]` 与 `*pBestLen` |
|---|---|---|---|---|---|
| $1$ | 写入并 $len\!+\!1$ | $1$ | $1$ | 否 | 空，$0$ |
| $2$ | 写入 | $1,2$ | $2$ | 否 | 空，$0$ |
| $4$ | 写入 | $1,2,4$ | $3$ | 否 | 空，$0$ |
| $6$ | 写入 | $1,2,4,6$ | $4$ | **是** | $1,2,4,6$，$4$ ★ |
| （返回 $6$） | $len$ 恢复为 $3$ | $1,2,4,(\cdot)$ | $3$ | — | 不变 |
| （返回 $4$） | $len$ 恢复为 $2$ | $1,2,(\cdot)$ | $2$ | — | 不变 |
| （返回 $2$、返回 $1$） | $len$ 恢复为 $1$ | $1,(\cdot)$ | $1$ | — | 不变 |
| $3$ | 写入 | $1,3$ | $2$ | 否 | 不变 |
| （$3$ 的左孩子为空） | 立即返回 | $1,3$ | $2$ | — | 不变 |
| $5$ | 写入 | $1,3,5$ | $3$ | 否 | 不变 |
| $7$ | 写入 | $1,3,5,7$ | $4$ | **是** | $4>4$ 不成立 ⟹ **不更新** |
| （逐层返回） | — | — | — | — | 最终 $1,2,4,6$，$4$ |

输出：`最长路径: 1 2 4 6`，`路径长度: 4`。

**两点观察**：① 返回时并未真正清零 `path[]`，只是 $len$ 回退，之后更浅层的写入会自然覆盖旧值——这正是"共享数组 $+$ 长度"实现的要点；② 第二条等长路径 $1,3,5,7$ 因判据是**严格大于**而未替换第一条，符合"输出……的一条"的题面要求（若要输出全部最长路径，把 `>` 改成 `>=` 并逐条打印即可）。

### 第三步：主解完整代码（第 (2) 问）

```c
#include <stdio.h>
#define MaxSize 100
typedef int ElemType;                /* 题面未指定，此处取 int */

typedef struct BiTNode{
    ElemType data;
    struct BiTNode *lchild,*rchild;
}BiTNode,*BiTree;

/* bt     : 当前子树根
   path   : 根到当前结点的路径（共享数组，随递归深入而延长）
   len    : 当前路径长度（值传递，返回即恢复 —— 隐式回溯）
   best   : 迄今最长的根到叶路径
   pBestLen : 其长度（指针传递，供各层共享与更新） */
void LongestPath(BiTree bt, ElemType path[], int len,
                 ElemType best[], int *pBestLen)
{
    int i;
    if (bt == NULL)
        return;
    path[len] = bt->data;
    len++;
    if (bt->lchild == NULL && bt->rchild == NULL)   /* 叶子：候选路径完整 */
    {
        if (len > *pBestLen)
        {
            *pBestLen = len;
            for (i = 0; i < len; i++)
                best[i] = path[i];                  /* 整段保存 */
        }
    }
    else
    {
        LongestPath(bt->lchild, path, len, best, pBestLen);
        LongestPath(bt->rchild, path, len, best, pBestLen);
    }
    /* len 是值参数，此处无需 len--；
       若把 len 改为全局变量或 int* 传递，则必须在此写 len--; 完成回溯 */
}

void PrintLongestPath(BiTree bt)
{
    ElemType path[MaxSize], best[MaxSize];
    int bestLen = 0, i;
    LongestPath(bt, path, 0, best, &bestLen);
    if (bestLen == 0)
    {
        printf("空树，不存在根到叶路径\n");
        return;
    }
    printf("最长路径: ");
    for (i = 0; i < bestLen; i++)
        printf("%d ", best[i]);
    printf("\n路径长度: %d\n", bestLen);            /* 结点个数口径 */
}
```

### 第四步：备选解（自底向上求深度 + 自顶向下沿最深分支走）

思路：结点 $t$ 到叶子的最长路径长度 $d(t)=1+\max(d(t_l),d(t_r))$，$d(\text{空})=0$。先由后序递归算出 $d$，再从根出发：若 $d(lchild)\ge d(rchild)$ 就走左孩子，否则走右孩子，边走边打印，走到空即止——所得即一条最长根到叶路径。

```c
int TreeDepth(BiTree bt)                 /* 后序：返回深度 */
{
    int dl, dr;
    if (bt == NULL) return 0;
    dl = TreeDepth(bt->lchild);
    dr = TreeDepth(bt->rchild);
    return (dl > dr ? dl : dr) + 1;
}

void PrintLongestPath_Down(BiTree bt)    /* 自顶向下沿最深分支打印 */
{
    int dl, dr, d = TreeDepth(bt);       /* 先取树深，即最长路径长度 */
    printf("最长路径: ");
    while (bt != NULL)
    {
        printf("%d ", bt->data);
        dl = TreeDepth(bt->lchild);
        dr = TreeDepth(bt->rchild);
        bt = (dl >= dr) ? bt->lchild : bt->rchild;   /* 哪边深往哪边走 */
    }
    printf("\n路径长度: %d\n", d);
}
```

对第 6 节第一步的样例树：`TreeDepth` 返回 $4$；下走过程为 $1\to$（左深 $3\ge$ 右深 $3$）$\to 2\to$（左深 $2>$ 右深 $0$）$\to 4\to$（左深 $1>$ 右深 $0$）$\to 6\to$ 空，打印 $1\ 2\ 4\ 6$，长度 $4$ ✓ 与主解完全一致。

（该写法不需路径数组、不需回溯，代码更短；但每次循环都要重算子树深度，最坏 $O(n\cdot d)$，且长度需在循环外先单独调用一次 `TreeDepth(bt)` 保存。若把深度写回结点的附加域，则降为 $O(n)$。卷面若时间紧张，写这一版同样能得主体分。）

### 第五步：复杂度分析

- **主解**：每个结点恰好访问一次，每次访问做 $O(1)$ 的写入与判叶子；仅在"发现更长路径"时多做一次 $O(d)$ 的整段复制（$d$ 为树深）。故时间最坏 $O(n\cdot d)$——**退化情形**是每层都刷新纪录（如完全左斜树，第 $i$ 个叶子路径长 $i$），复制代价 $\sum i=O(d^2)=O(n^2)$；一般情形（纪录只刷新常数次）为 $O(n)$。空间：递归栈 $O(d)$ 加两个长度 $O(d)$ 的数组，合计 $O(d)$，最坏 $O(n)$（单支树），最好 $O(\log n)$（平衡树）。
- **改进到严格 $O(n)$**：不复制路径，只记下"最长路径最后经过的结点"，或给每个结点存"父结点 $+$ 到叶长度"，遍历后沿父指针回溯打印；也可把 `best[]` 的复制改为在叶子处**直接打印** `path[0..len-1]`（若题面允许"边走边输出"且只要一条）。
- **备选解**：`TreeDepth` 每次 $O(n)$，主循环最多 $d$ 次调用，最坏 $O(n\cdot d)$；用"记忆化/写回结点"后为 $O(n)$，空间 $O(d)$。
- 两法在本解析的样例树、单结点树（输出该结点、长度 $1$）、空树（输出"空树，无路径"）三种输入上结果一致。

## 8. 考场标准答案

**(1) 基本设计思想**：以先序遍历为框架，用数组 `path[]` 与长度 $len$ 记录"根到当前结点"的路径：访问结点时 `path[len++]=bt->data`，其左右子树递归返回后 $len$ 回退（回溯）。当访问到叶子结点（`lchild` 与 `rchild` 均为空）时，`path[0..len-1]` 即一条完整的根到叶路径，将 $len$ 与已保存的最长长度比较，若更长则把该段路径复制保存到 `best[]` 并更新最长长度。整棵树遍历完毕后，`best[]` 中即为所求最长路径，顺序打印其结点值并输出其长度（结点数）。空树时无路径。时间复杂度 $O(n)$（最坏 $O(n^2)$，因保存路径需整段复制），空间复杂度 $O(d)$（$d$ 为树深，最坏 $O(n)$）。

**(2) C 语言描述**：见第 6 节第三步代码（`LongestPath` + `PrintLongestPath`）。

**评分要点**：① 说明"前序遍历 $+$ 路径数组 $+$ 回溯"三要素；② 叶子判定条件写成"左右孩子皆空"；③ 到叶子时与当前最长比较并**保存整条路径**（只记长度拿不到"打印路径"的分）；④ 递归返回时正确回退长度；⑤ 空树边界；⑥ 复杂度结论与口径。

## 9. 易错点

1. **把"最长路径"打印成"某条路径"或"遍历序列"**：必须先比较长度再决定保存，且保存的是**根到叶子的完整一段**，不是中序/层次序列；
2. **忘记回溯**：若把 $len$ 定义成全局变量或 `int *`，递归返回时**必须**写 `len--;`，否则右子树的路径会接在左子树的尾巴后面，出现 $1,2,4,6,3,5,7$ 这类"拼接串"。本解析主解把 $len$ 作**值传递**，回溯由栈帧自动完成——两种写法都对，但必须与自己的声明一致，卷面宜在注释里点明；
3. **叶子判据写成 `bt->lchild==NULL || bt->rchild==NULL`**：用"或"会把度为 $1$ 的结点当叶子，导致路径在中间截断（如样例树中 $4$ 会被当成叶子，输出长度 $3$ 的 $1,2,4$）。必须用"且"；
4. **在 `bt==NULL` 处判叶子**：能得出正确长度，但度为 $1$ 的结点会生成两条等长的重复候选，且 $len$ 会多算一层空结点，容易连带把长度写成 $5$；统一在"非空且两孩子皆空"处处理最稳；
5. **"路径长度"口径**：本解析按**结点个数**输出（样例为 $4$）；若按"路径长度 $=$ 边数"的教材口径应为 $3$。两种都常见，**卷面必须先写明口径**，否则与参考答案比对时会被误判；
6. **只记长度不记路径**：`if (len > max) max = len;` 之后打印不出结点值，本题要求"打印路径的结点值"，必须保存整段；
7. **数组越界**：`path[]`、`best[]` 长度应不小于树的最大可能深度；最坏（单支树）深度为 $n$，故 `MaxSize` 要按结点数上界取，或对 $len \ge MaxSize$ 做保护；
8. **空树未处理**：`bt==NULL` 时 `bestLen` 仍为 $0$，若不判断就打印 `best[0..-1]` 会输出垃圾内容。

## 10. 一句话规律

凡是"根到某类结点的路径"类问题（根到叶、根到指定结点、所有路径、最长/最短路径），都用**同一个模板**：前序递归 $+$ 共享数组"进入登记、离开撤销" $+$ 在**满足终止条件的那个结点处**处理整段路径；只需换掉"什么时候算一条"的判据即可。
