# DS-2025-04

## 1. 原题

**4、** 下列代码实现带头结点的单链表的简单选择排序，请填写完整代码。

单链表存储结构如下：

```c
typedef struct LNode
{
    ElemType data;
    struct LNode *next;
}LNode,*LinkList;
```

选择排序功能函数如下：

```c
void SelectionSort(LinkList &L)
{
    LNode *p,*q,*min;
    _____①_____;

    while(p!=NULL)
    {
        min=p;
        q=p->next;

        while(q!=NULL)
        {
            if(q->data<min->data)
                min=q;
            q=q->next;
        }

        if(_____②_____)
        {
            ElemType temp=p->data;
            p->data=min->data;
            min->data=temp;
        }
        _____③_____;
    }
}
```

（本题无订正说明，题面不含图片。）

## 2. 答案

| 空位 | 填写内容 | 作用 |
|---|---|---|
| ① | `p = L->next;` | 令 $p$ 指向**首元结点**（头结点 `L` 不存数据，不参与排序），即"第 $1$ 个待定位位置" |
| ② | `min != p;` | 判断本轮选出的最小元是否已在位置 $p$ 上；不在才交换两者 `data`（避免自交换） |
| ③ | `p = p->next;` | $p$ 前移一个结点，进入下一趟 |

补全后的完整函数见第 8 节。

## 3. 题目分析

- 已知：带头结点单链表（`L` 为头结点地址，`L->next` 是首元结点）；骨架给出"一趟"的完整结构——`min=p; q=p->next;` 起扫描，`while(q!=NULL)` 中用 `q->data<min->data` 维护最小元指针，随后用 `ElemType temp` **交换数据域**（不是摘链重插）；
- 目标：补三处语句，使整个函数完成"逐趟在无序区选最小、放到当前位置"的简单选择排序；
- 关键约束：
  1. 链表**只能顺序扫描**，没有数组的下标随机访问，因此一趟的"无序区起点"必须由指针 $p$ 表示，扫描由 $q$ 完成；
  2. 交换采用**数据域互换**，结点位置始终不变 ⟹ 填空不涉及任何 `next` 改写，只需保证"选元—交换—推进"三件事；
  3. 头结点必须被排除在排序范围之外（否则其 `data` 会被当作第一个关键字参与比较与交换）；
  4. 每趟之后 $p$ 之前的所有结点已是全局最小的若干元素，且 $p$ 自身不会再被后续趟重新检查（这正是选择排序"已就位前缀"的不变式，与数组版 $\sum_{k\le i}R_k$ 已就位一致）；
- 命题意图：把 DS06.04 简单选择排序从数组搬到链上，考两件事——**同一算法在不同存储结构上的实现差异**（下标 $i\to$ 指针推进）与**"按值交换"与"按链交换"的取舍**（本题骨架选前者，故 $O(1)$ 空间、无需前驱指针）；能力上属程序填空 + 执行过程模拟。

## 4. 核心考点

核心考点：
DS01.02.02 链式存储：单链表——头结点的作用与"从 `L->next` 开始遍历"的约定、沿 `next` 的顺序扫描、通过结点指针访问/交换 `data`

辅助考点：
DS06.04 简单选择排序——"第 $i$ 趟在 $R_i\cdots R_n$ 中选最小并与 $R_i$ 交换"的趟定义、比较次数恒为 $\frac{n(n-1)}{2}$（与初始排列无关）、交换次数 $\le n-1$

解释：三处填空中 ①③ 是纯链表操作（起点与推进），② 是选择排序的算法语义（是否需要交换）。本题主结构是被排序的线性链式表，按本库交叉横断约定，程序填空题的 `primary_topic` 归被考查的数据结构章节，排序算法本身作辅助考点。

## 5. 解题思路

1. **对照数组版写出伪代码**：数组版是
   `for(i=0;i<n-1;i++){ min=i; for(j=i+1;j<n;j++) if(a[j]<a[min]) min=j; if(min!=i) swap(a[i],a[min]); }`
   ——把下标 $i$ 换成指针 $p$、下标 $j$ 换成指针 $q$，两重循环的骨架已与题面一一对应；
2. **找出数组版与骨架的三处"缺项"**：外层循环开始前 $i$ 的初始化（→ ①）、`if(min!=i)`（→ ②）、`i++`（→ ③）；
3. **用头结点约定校准 ①**：题面 `L` 是头结点地址，而"第 $1$ 个记录"是 `L->next` ⟹ ① = `p = L->next;`；若填 `p = L;`，则头结点的 `data` 被当作关键字，第一趟会把全表最小值写进头结点，链表凭空"少一个元素且顺序错乱"；
4. **确认 ② 的判据**：内层结束时 `min` 必满足 `min->data <= p->data`（因为 `min` 初值为 $p$ 且只被更小者替换），故"需要交换"等价于"最小元不是 $p$ 自己"，写 `min != p`；
5. **确认 ③**：一趟结束后 $p$ 位置已就位，下一趟从其后继开始 ⟹ `p = p->next;`，填 `q`、`min` 都会破坏循环（死循环或漏趟）；
6. **验算**：手工模拟 4 结点表 `5,3,8,1` 的四趟过程，检查每趟的 `min` 归属、是否交换、趟末表内容与比较次数；再用空表、单结点、已排序表检查边界。

## 6. 详细解答

### 第一步：函数结构解读

- 外层 `while(p!=NULL)`：共执行 $n$ 趟（$n$ 为数据结点个数）。第 $k$ 趟时 $p$ 指向第 $k$ 个数据结点；
- `min=p; q=p->next;`：以当前位置 $p$ 的结点为"当前最小"，用 $q$ 扫描 $p$ 之后的所有结点；
- 内层 `while(q!=NULL){ if(q->data<min->data) min=q; q=q->next; }`：在 $p$ 及其后继（即无序区）中选出 `data` 最小者，`min` 指向该结点。内层比较次数为"无序区长度 $-1$"，即第 $k$ 趟比较 $n-k$ 次；
- `if(②){ 交换 p->data 与 min->data }`：把最小元放到第 $k$ 个位置；
- `③`：推进到下一个位置。

不变式：每趟结束时，前 $k$ 个数据结点的 `data` 恰为全表最小的 $k$ 个值且已升序就位，其后结点内容未被本趟改动（选择排序的典型特征——**前缀就位、中段原封不动**，这一点也是识别选择排序趟结果的判据，参见 DS-2022-32）。

### 第二步：三处填空的推导

**① = `p = L->next;`**
`while(p!=NULL)` 与内层 `q=p->next` 都以 $p$ 为"数据结点"，而头结点不存数据，故起点必须是首元结点。带不带头结点的链表在遍历起点上的这一区别正是教材反复强调的约定：头结点使插入/删除首元结点无需特殊处理，但**遍历数据元素要从 `L->next` 开始**。

**② = `min != p`**
内层若有 `q->data < min->data` 才会更新 `min`，因此内层结束时 `min` 或者仍是 $p$（$p$ 本身就是无序区最小者），或者指向某个更靠后的结点。
- 若 `min == p`，交换语句执行 `p->data` 与自身互换，是无用操作（值不变，不影响正确性，但代码冗余），填 `min != p` 恰好跳过；
- 若 `min != p`，必须交换，才能把最小值送到位置 $p$。
故判据为 `min != p`（等价写法 `p != min`）。注意不能填 `p->data < min->data`：由上面的分析该条件恒为假，会使交换永不执行、排序完全失效。

**③ = `p = p->next;`**
$p$ 已就位，无序区起点后移一个结点。若不写或写成 `p = min;`（$min$ 可能等于 $p$）则死循环；写成 `p = q;` 则 $q$ 此刻恒为 NULL，一趟即终止（只剩最小值在前，其余未排序）。

### 第三步：手工模拟（4 个数据结点，初值 `5,3,8,1`）

| 趟 | 进入时 $p$ | 内层扫描范围与比较 | `min` 归属 | `min!=p`？ | 交换 | 趟末表内容 |
|---|---|---|---|---|---|---|
| 1 | $A(5)$ | $B(3),C(8),D(1)$：$3<5$ 改 $min{=}B$；$8<3$ 否；$1<3$ 改 $min{=}D$ | $D(1)$ | 是 | $A\leftrightarrow D$ | `1,3,8,5` |
| 2 | $B(3)$ | $C(8),D(5)$：均不小于 $3$ | $B(3)$ | **否** | 无 | `1,3,8,5` |
| 3 | $C(8)$ | $D(5)$：$5<8$ 改 $min{=}D$ | $D(5)$ | 是 | $C\leftrightarrow D$ | `1,3,5,8` |
| 4 | $D(8)$ | 无序区仅剩自己，内层不进入 | $D(8)$ | 否 | 无 | `1,3,5,8` |
| 结束 | $p=D\to next=$ NULL | — | — | — | — | 输出 `1 3 5 8` ✓ |

比较次数 $=3+2+1+0=6=\frac{4\times 3}{2}$ ✓（与初始排列无关，见第五步）；交换次数 $=2\le n-1=3$。

### 第四步：边界检查（算法题补充检查）

- **空表**（`L->next == NULL`）：① 使 `p = NULL`，外层 `while` 不进入，函数原地返回，安全 ✓；
- **单结点**：一趟：`min=p`、内层不进、② 不成立、`p=p->next=NULL` 结束，表不变 ✓；
- **两结点已升序**（`1,2`）：第 1 趟 `min` 仍为 $p$（$2\not<1$），不交换；第 2 趟空扫描。结果 `1,2` ✓（验证 ② 在"最小元已在位"时的作用是避免无意义自交换，而非正确性所必需）；
- **两结点逆序**（`2,1`）：第 1 趟 `min` 指向第 2 个结点，交换得 `1,2` ✓；
- **关键字相等**（如 `3,3,1`）：内层用严格 `<`，第一次遇到 $1$ 才更新 `min`，两个 $3$ 之间不换 ⟹ 相对次序保持，但该算法整体**不稳定**（因为跨越式的"最小值与远处位置交换"会打乱同关键字结点的前后关系，例如 `5a,1,5b` 排序后两个 $5$ 顺序互换）；
- **循环终止**：`p` 每趟沿 `next` 严格前移一个结点，链表无环 ⟹ 至多 $n$ 趟后 `p==NULL`，必然终止。

### 第五步：复杂度

- 比较次数：$\sum_{k=1}^{n}(n-k)=\frac{n(n-1)}{2}$，**与初始排列无关**（这正是 DS-2017-17 所考"比较次数与记录初始排列无关"的排序方法之一）；
- 交换（数据域互换）次数：$\le n-1$，每次交换 $3$ 个赋值；
- 时间 $O(n^{2})$；辅助空间 $O(1)$（仅 $p,q,min$ 三个指针与一个临时变量，不另开结点、不递归）。

（后台 C 程序实测：输入 `5,3,8,1,9,2,7,4` 输出 `1 2 3 4 5 7 8 9`，空表、单结点、已排序 `1,2` 三种边界均正常，比较计数为 $\frac{n(n-1)}{2}$；程序仅作验证，正文表格可手工复现。）

**答案：① `p = L->next;` ② `min != p` ③ `p = p->next;`**

## 8. 考场标准答案

```c
void SelectionSort(LinkList &L)
{
    LNode *p, *q, *min;
    p = L->next;                       /* ① 从首元结点起，头结点不参与排序 */

    while (p != NULL) {                /* 每趟把 p 位置上的元素就位 */
        min = p;                       /*    先假设 p 为无序区最小 */
        q = p->next;
        while (q != NULL) {            /*    扫描 p 之后的全部结点 */
            if (q->data < min->data)
                min = q;               /*    记录最小元所在结点 */
            q = q->next;
        }
        if (min != p) {                /* ② 最小元不在 p 上才交换数据域 */
            ElemType temp = p->data;
            p->data = min->data;
            min->data = temp;
        }
        p = p->next;                   /* ③ 处理下一个位置 */
    }
}
```

功能：对带头结点单链表作简单选择排序，逐趟在" $p$ 及其后继"中取最小者的数据域换到 $p$；比较次数恒为 $\frac{n(n-1)}{2}$，交换次数 $\le n-1$，时间 $O(n^{2})$，空间 $O(1)$，算法不稳定。

## 9. 易错点

1. **① 写成 `p = L;`**：头结点被当成第一个关键字参与比较与交换，最小值被写进头结点的 `data`，输出时若仍从 `L->next` 打印就会"丢一个元素且首元素不是全局最小"——这是本题最容易犯 also 最难自查出的错误；
2. **② 填成恒假或恒真条件**：如 `p->data < min->data`（恒假，从不交换）或 `min != q`（与算法无关，可能自交换失效）；正确判据只能建立在"`min` 是否等于本轮起点 $p$"上；
3. **③ 写成 `p = min;` 或漏写**：前者当 `min == p` 时原地不动，死循环；后者同样死循环。填 `p = q;` 则 $q$ 恒为 NULL，只排好第一个位置；
4. **想改成"摘链 + 重插"的指针交换版**：骨架已把交换动作写成 `ElemType temp = p->data; …`，填空不得改写既有语句；指针交换版虽稳定，但需要前驱指针与更多 `next` 修改，属另一道题；
5. **误答比较次数依赖输入**：选择排序的比较次数固定 $\frac{n(n-1)}{2}$，不像冒泡/插入排序那样在有序输入下降到 $O(n)$（对比 DS-2025-05，那里才是"随输入只影响交换次数、不影响比较次数"的另一类情形——两题都要看清"给定输入"这一问法其实不影响阶）。

## 10. 一句话规律

把数组算法搬到链表时，先写下数组版并把"下标 $i$ 的初始化 / 趟内判据 / $i++$"三项一一映射为"起点指针 / 比较判据 / 指针推进"，填空位置就自然浮现；带头结点的表，遍历数据永远从 `L->next` 开始。
