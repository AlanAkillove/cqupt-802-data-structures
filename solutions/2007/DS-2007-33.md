# DS-2007-33

## 1. 原题

设图 $G$ 采用邻接表存储，则图的深度优先遍历算法（访问每个顶点一次）的时间复杂度是____________________ 。

## 2. 答案

$$O(n+e)$$

其中 $n=|V|$ 为顶点数、$e=|E|$ 为边数（若为有向图则 $e$ 为弧数）。无向图的邻接表共有 $2e$ 个边结点，故也常写作 $O(n+2e)$，二者量级相同。

## 3. 题目分析

- 已知：图 $G=(V,E)$ 以**邻接表**存储（`adjlist`：长度为 $n$ 的头结点向量 + 每个顶点的邻接点单链表）；DFS 遍历保证"访问每个顶点一次"（含 `visited[]` 标记，非连通图需对每个未访问顶点补一次 `DFSTraverse`）；
- 目标：整个遍历过程的时间复杂度表达式；
- 关键约束：复杂度由两部分累加——① 每个顶点被访问（进/出递归、置 `visited`）一次；② 每个顶点的邻接链表被**完整扫描一次**（这是与邻接矩阵的本质差别：矩阵要扫 $n$ 个格子，链表只扫真实的邻居）；
- 命题意图：考"存储结构决定遍历代价"这一核心结论，并与邻接矩阵 DFS 的 $O(n^2)$ 形成对比；括号中"访问每个顶点一次"是在提示：不计重复访问，只算一次完整遍历。

## 4. 核心考点

核心考点：
DS04.03.01 深度优先搜索（DFS 的遍历过程与 `visited` 标记机制）

辅助考点：
DS04.02.02 邻接表法（头结点向量 + 边结点链表，无向图边结点总数 $2e$）

解释：结论 $O(n+e)$ 的"$e$"这一半完全来自邻接表的链长统计（DS04.02.02），"$n$"这一半来自 DFS 每顶点访问一次（DS04.03.01）；能力标签用 `COMPLEXITY_ANALYSIS`（按交叉横断说明，复杂度分析不单列知识点，主结构归图章）。

## 5. 解题思路

1. 写出 DFS 的骨架：`DFSTraverse` 对 $n$ 个头结点各判一次 `visited`；`DFS(v)` 内 `for(p=adj[v].first; p; p=p->next)` 遍历该顶点的全部邻接链表；
2. 分项计数：
   - 顶点侧：每个顶点至多进入 `DFS` 一次（`visited` 拦截），每次的固定开销 $O(1)$ ⟹ 共 $O(n)$；
   - 边侧：第 $i$ 个头结点的链表被扫描 $\deg(i)$ 次（无向图）或 出度 次（有向图），全部链表长度之和 $=2e$（无向）/ $e$（有向）⟹ 共 $O(e)$；
3. 合并：$O(n)+O(e)=O(n+e)$；
4. 交叉验证：换成邻接矩阵，"边侧"变成每个顶点扫一行 $n$ 个元素 ⟹ $O(n^2)$，说明本题结论对存储结构的依赖点在哪；
5. 检查边界：非连通图（`DFSTraverse` 外层循环仍只 $n$ 次判定）、$e=0$（空图无边，退化为 $O(n)$，被 $O(n+e)$ 覆盖）。

## 6. 详细解答

**存储结构（教材风格定义）**

```c
typedef struct ArcNode {           /* 边结点 */
    int adjvex;                    /* 该边所指的顶点位置 */
    struct ArcNode *nextarc;
} ArcNode;

typedef struct VNode {             /* 头结点 */
    VertexType data;
    ArcNode *first;                /* 指向第一条依附该顶点的边 */
} VNode, AdjList[MAXV];            /* 邻接表 = 长度为 n 的头结点向量 */
```

**遍历骨架**

```c
Boolean visited[MAXV];

void DFSTraverse(AdjList adj, int n)        /* 保证每个顶点被访问一次 */
{
    int i;
    for (i = 0; i < n; i++) visited[i] = FALSE;
    for (i = 0; i < n; i++)
        if (!visited[i]) DFS(adj, i);       /* 非连通图时启动多个 DFS 过程 */
}

void DFS(AdjList adj, int v)
{
    ArcNode *p;
    visited[v] = TRUE;                      /* 访问顶点 v */
    for (p = adj[v].first; p != NULL; p = p->nextarc)
        if (!visited[p->adjvex]) DFS(adj, p->adjvex);
}
```

**代价分项统计**

| 开销来源 | 计数 | 说明 |
|---|---|---|
| `DFSTraverse` 外层初始化 + 判 `visited` | $O(n)$ | $n$ 个头结点各一次 |
| `DFS(v)` 被调用的次数 | $\le n$ 次 | 每次调用必先置 `visited[v]=TRUE`，故同一顶点不会二次进入 |
| 每个顶点的 `for` 循环扫描次数 | $\sum_i \deg(i)$（无向）$=2e$ | 链表长度即该顶点的度；每个顶点的链表只在自己那次 `DFS` 调用中被完整扫一遍 |
| `if(!visited[...])` 判断次数 | 与上一行同阶 $=2e$ | 每个边结点判一次 |

合计

$$T(n,e)=O(n)+O(2e)=O(n+e)$$

有向图时 $\sum_i$ 出度 $=e$，结论同为 $O(n+e)$。

**空间代价（顺带区分，避免答题混淆）**：邻接表本身 $O(n+2e)$；DFS 递归栈深度最坏 $O(n)$；`visited` 数组 $O(n)$。题目问的是**时间**复杂度，不要答成空间。

**与邻接矩阵的对比（同一算法、不同存储）**

| 存储结构 | DFS 时间复杂度 | 决定因素 |
|---|---|---|
| 邻接矩阵 | $O(n^2)$ | 每个顶点都要扫完长度为 $n$ 的一行 |
| 邻接表 | $O(n+e)$ | 只扫真实存在的 $2e$ 个边结点 |

稀疏图（$e\ll n^2$）时邻接表明显更快；完全图（$e=\frac{n(n-1)}{2}$）时 $O(n+e)=O(n^2)$，两者同阶——这也解释了"邻接表优势在稀疏图"这一常见判断。

**实例核对**：$n=5$、$e=4$ 的一条链 $v_1\!-\!v_2\!-\!v_3\!-\!v_4\!-\!v_5$。邻接表边结点共 $2e=8$ 个（各顶点链长即度：$1,2,2,2,1$，求和 $=8$）。手工执行 `DFSTraverse`：`DFS` 调用 $5$ 次（$=n$），链表结点访问总次数 $1+2+2+2+1=8$（$=2e$），加上外层 $5$ 次 `visited` 判定 ⟹ 操作量 $\propto n+2e=13$，与 $O(n+e)$ 吻合 ✓。

**答案**：$O(n+e)$（$n$ 为顶点数，$e$ 为边数）。

## 8. 考场标准答案

$O(n+e)$，其中 $n$ 为顶点数、$e$ 为边数。

理由：邻接表中每个顶点至多进 `DFS` 一次（$O(n)$）；每个顶点的邻接链表恰被完整扫描一次，无向图边结点总数 $2e$（有向图 $e$），故找邻接点的总代价 $O(e)$。两项相加 $O(n+2e)=O(n+e)$。
（对比：邻接矩阵存储时为 $O(n^2)$。）

## 9. 易错点

1. 答成 $O(n^2)$：那是**邻接矩阵**下 DFS 的复杂度，题干已限定"邻接表存储"，两问答案不同，必须按存储结构作答；
2. 答成 $O(n)$ 或 $O(e)$：漏掉一项。$O(n)$ 只在"每个顶点无边"时成立，$O(e)$ 在孤立顶点存在时不覆盖外层 $n$ 次判定；
3. 忽略"访问每个顶点一次"的实现依赖 `visited[]`：若没有标记数组，DFS 会沿边反复回到已访问顶点，复杂度分析不成立（本题括号即为此提示）；
4. 与 BFS 混淆：邻接表 BFS 同为 $O(n+e)$（多一个队列，空间 $O(n)$），但**邻接矩阵**下 DFS/BFS 都是 $O(n^2)$——本题结论对 DFS、BFS 同样成立，真正的分界是存储结构；
5. 把无向图边结点数写成 $e$：邻接表中无向边存两份，链长总和是 $2e$（写成 $O(n+2e)$ 更严谨，量级不变）。

## 10. 一句话规律

图算法的复杂度分析一律"分项相加"：**顶点侧 $O(n)$ + 边侧 $O(\text{边结点总数})$**；邻接表边侧是 $O(e)$、邻接矩阵边侧是 $O(n^2)$，DFS、BFS、拓扑排序、连通分量计数都套这一模式。
