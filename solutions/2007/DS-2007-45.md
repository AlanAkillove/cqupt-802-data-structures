# DS-2007-45

## 1. 原题

某二叉树使用二叉链表存储，通过中序遍历打印结点数据可得到从大到小的数据序列，请编写一个函数将此二叉树进行变换以得到一棵二叉排序树（提示：可通过将所有结点的左右子树交换得到，请定义必要的数据结构）。

## 2. 答案

**设计思想**：题设"中序遍历得到从大到小的序列"说明这棵树是二叉排序树的**镜像形态**（每个结点实际是"左子树全大、右子树全小"）。对任一二叉树，**把每个结点的左右子树交换一次**，所得新树的中序序列恰好是原中序序列的**逆序**；原序列严格递减，逆序后即严格递增，由"二叉排序树 ⟺ 中序序列递增"可知新树就是一棵二叉排序树。故只需递归遍历一遍二叉链表，逐结点交换 `lchild` 与 `rchild`（**只改指针，不动数据域**）。

**代码（教材风格 C）**：

```c
typedef struct BTNode {
    ElemType data;
    struct BTNode *lchild, *rchild;
} BTNode, *BTree;

void SwapLR(BTree t)                 /* 交换 t 的左右子树，并对两棵子树递归进行 */
{
    BTNode *tmp;
    if (t == NULL) return;           /* 空树：已是二叉排序树，直接返回 */
    tmp = t->lchild;                 /* 必须先暂存，否则改链后原子树丢失 */
    t->lchild = t->rchild;
    t->rchild = tmp;
    SwapLR(t->lchild);               /* 变换新的左、右子树 */
    SwapLR(t->rchild);
}

void ConvertToBST(BTree bt)          /* 主函数：bt 为二叉链表根指针 */
{
    SwapLR(bt);                      /* 变换在原链表上就地完成，无附加结点 */
}
```

**复杂度**：时间 $O(n)$，$n$ 为二叉树中**结点个数**（每个结点恰好被访问一次，做 $3$ 次指针赋值的常数量工作，共 $3n$ 次基本操作）；空间 $O(h)$，$h$ 为二叉树的**高度**（递归工作栈深度，最坏为单支树时 $h=n$ 即 $O(n)$，树平衡时 $h=\lfloor\log_2 n\rfloor+1$ 即 $O(\log n)$）。

## 3. 题目分析

- 已知：一棵以**二叉链表**存储的二叉树 $T$，且 `Inorder(T)` 输出**从大到小**的序列（关键字互异，记为 $a_n>a_{n-1}>\cdots>a_1$ 形式）；
- 目标：写一个**函数**（题面明确要求"定义必要的数据结构"）就地变换 $T$，使其成为一棵二叉排序树；
- 关键约束与线索：
  1. 题面已给出提示"交换所有结点的左右子树"，考查重心不在"想出做法"，而在**为什么这样做是对的**与**代码写得更规范**（数据结构定义、递归边界、暂存指针）；
  2. "所有结点"⟹ 必须遍历整棵树，$n$ 个结点一个都不能漏（漏一个结点，其子树内部大小关系就仍颠倒）；
  3. 变换只能是**指针层面的改接**：数据域不需要（也不应该）搬运，因此与"重新逐个插入建树"相比省去了比较与关键字移动；
  4. 二叉树的中序遍历定义为"左→根→右"，交换左右子树恰好把该序列整体倒过来——这是本题唯一需要的结构性质；
- 隐含前提：若允许关键字相等，"从大到小"应理解为**不增**，交换后得**不降**序列，此时需按"左 $\le$ 根 $<$ 右"之类的广义 BST 定义才成立；考研题默认关键字互异（二叉排序树定义本身亦禁止重复关键字）。
- 命题意图：把 DS05.07.01 的"中序有序性"这一判别定理与 DS03.02.02/DS03.02.03 的遍历、二叉链表操作结合，命一道"就地改指针"的算法实现题。

## 5. 解题思路

1. **翻译题设**：中序输出递减 ⟹ 对每个结点 $x$，其左子树中所有关键字 $>x$ 的数据、右子树中所有关键字 $<x$ 的数据（这正是 BST 定义的左右相反版本，即 BST 的镜像）；
2. **确定目标形态**：BST 只要求"左 $<$ 根 $<$ 右"且中序递增。既然中序序列只差一个方向，就把序列整体倒过来 ⟹ 需要一种"使中序反序"的树变换；
3. **找出变换**：把每个结点的左右子树互换，中序遍历"左根右"就变成了访问原树的"右根左"，全局效果即中序逆序（第 6 节 (2) 归纳证明）；
4. **写成算法**：交换操作对每个结点独立且只需做一次 ⟹ 任何遍历次序（前序/后序/层次）都能完成；选最省事的"前序式：先交换本结点，再递归两棵子树"；
5. **补边界**：空树、仅根结点（交换后仍是自身，若原树单结点则已满足递减 ⟹ 直接是 BST）；
6. **验证**：取一棵满足题设的 6 结点树手工变换，回代中序，检查是否递增且满足 BST 逐结点大小关系（第 6 节 (4)）；再用"最坏 $n$ 次比较"的复杂度口径核对 $O(n)$。

## 6. 详细解答

### (1) 数据结构定义与接口约定

```c
typedef ElemType;                       /* 关键字可比较的数据类型，约定互异 */

typedef struct BTNode {
    ElemType data;
    struct BTNode *lchild, *rchild;     /* 二叉链表：左、右孩子指针 */
} BTNode, *BTree;

/* 约定：BTree bt 为根结点指针（不是"根指针的地址"，因为本题不改根结点本身，
   只改各结点的孩子指针；根结点地址在变换前后保持不变。） */
```

> 若要求"变换后根指针也能对空树安全赋值"，可把形参写成 `BTree *pbt`，函数内用 `(*pbt)` 访问根结点；两种写法在本题等价，因为交换操作从不改变根结点自身。

### (2) 引理一：交换全部结点的左右子树 ⟹ 新树中序 = 原树中序的逆序

设原树为 $T$，变换后为 $T'$。对结点数 $n$ 归纳。

- $n=0$（空树）与 $n=1$（仅根 $r$）：中序分别为 $\varnothing$ 与 $(r)$，逆序是自身，而 $T'$ 亦为同一棵树，结论成立；
- 设结论对结点数 $<n$ 的树成立。考虑 $n\ge 2$ 的 $T$：记根为 $r$，左子树 $L$、右子树 $R$，则
  $$Inorder(T)=Inorder(L),\ r,\ Inorder(R)$$
  变换时 $r$ 的左右孩子互换，故 $T'$ 的左子树是 $R'$（$R$ 交换后的树）、右子树是 $L'$，于是
  $$Inorder(T')=Inorder(R'),\ r,\ Inorder(L')$$
  由归纳假设 $Inorder(R')=reverse(Inorder(R))$、$Inorder(L')=reverse(Inorder(L))$，代入得
  $$Inorder(T')=reverse(Inorder(R)),\ r,\ reverse(Inorder(L))=reverse\big(Inorder(L),\ r,\ Inorder(R)\big)=reverse(Inorder(T))$$

  归纳完成。同时可见：**变换不改变结点集合，只把中序次序整体反转**。

### (3) 引理二与正确性结论

**引理二（BST 判别定理，双向）**：

- 必要性：若 $T$ 是二叉排序树，则对每个结点有 $key(L)<key(r)<key(R)$，递归得中序"左→根→右"必为递增序列；
- 充分性：若中序序列严格递增，则任一结点 $r$ 的左子树所有结点在中序中出现在 $r$ **之前** ⟹ 关键字均小于 $r$；右子树结点均出现在 $r$ **之后** ⟹ 均大于 $r$；递归对每棵子树成立，故 $T$ 满足二叉排序树定义。

**正确性**：题设 $Inorder(T)$ 严格递减 ⟹ 由引理一 $Inorder(T')$ 严格递增 ⟹ 由引理二（充分性）$T'$ 是二叉排序树。$\blacksquare$

算法终止性：每次递归调用作用在规模严格更小的子树上（$|L|,|R|\le n-1$），且空树即返回 ⟹ 有限步终止；每个结点被访问恰一次 ⟹ 每个结点被交换恰一次（无重复交换，避免"交换两次还原"的错误）。

### (4) 完整代码

```c
void SwapLR(BTree t)                 /* 交换 t 的左右子树，并对两棵子树递归进行 */
{
    BTNode *tmp;
    if (t == NULL) return;           /* 递归边界：空树（t->lchild 为空时也走这里）*/
    tmp = t->lchild;                 /* 先暂存原左孩子 */
    t->lchild = t->rchild;           /* 改接两指针，注意顺序：不能先覆盖 lchild */
    t->rchild = tmp;
    SwapLR(t->lchild);               /* 处理新的左子树（原右子树）*/
    SwapLR(t->rchild);               /* 处理新的右子树（原左子树）*/
}

void ConvertToBST(BTree bt)          /* 题目要求的函数 */
{
    SwapLR(bt);                      /* 就地变换，不新增/删除结点 */
}
```

**验证用的辅助函数（非必须得分点，可附以说明"如何检查"）**：

```c
void InorderCheck(BTree t)           /* 中序遍历并检查是否递增 */
{
    static BTNode *pre = NULL;       /* 记录刚才访问的结点，注意多棵树调用需复位 */
    if (t) {
        InorderCheck(t->lchild);
        if (pre != NULL && pre->data >= t->data)
            printf("不是二叉排序树！\n");
        printf("%d ", t->data);
        pre = t;
        InorderCheck(t->rchild);
    }
}
```

**等价写法（后序式，同样正确）**——因为"交换"这个动作与递归先后的组合只要保证**每个结点恰好交换一次**即可：

```c
void SwapLR_Post(BTree t)
{
    BTNode *tmp;
    if (t == NULL) return;
    SwapLR_Post(t->lchild);          /* 先递归原左子树 */
    SwapLR_Post(t->rchild);          /* 再递归原右子树 */
    tmp = t->lchild;                 /* 最后交换本结点 */
    t->lchild = t->rchild;
    t->rchild = tmp;
}
```

层次（非递归）写法亦可：用队列逐出队结点交换左右孩子并入队其孩子，时间仍 $O(n)$，空间 $O(n)$（队列最存一层 $\le \lceil n/2\rceil$ 个结点）。

### (5) 实例走查（构造满足题设的树并验证）

原树 $T$（题设要求中序递减，构造如下）：

```
            (5)
           /   \
        (8)     (2)
        / \     /
      (9) (6) (3)
```

中序遍历：$9,8,6,5,3,2$ —— 严格递减 ✓ 符合题设。

逐结点交换左右孩子后得 $T'$（$8$ 的 $9,6$ 互换；$2$ 的左孩子 $3$ 变为右孩子；叶结点交换后不变）：

```
            (5)
           /   \
        (2)     (8)
          \     / \
          (3) (6) (9)
```

- 新中序：$2,3,5,6,8,9$ —— 严格递增 ✓（恰为原序列逆序，与引理一一致）；
- 逐结点 BST 校验：根 $5$ 的左子树 $\{2,3\}$ 全 $<5$、右子树 $\{6,8,9\}$ 全 $>5$ ✓；$2$ 无左孩子、右孩子 $3>2$ ✓；$8$ 的左 $6<8$、右 $9>8$ ✓；三个叶平凡成立 ✓ ⟹ $T'$ 是二叉排序树；
- 结点集合未变（仍是 $\{2,3,5,6,8,9\}$）、结点数仍 $6$，只改了 $4$ 个结点的指针（$5,8,2$ 实际改动，$9,6,3$ 为叶，交换为空操作）。

### (6) 复杂度分析（含 $n$ 的含义）

设 $n$ 为二叉树中的**结点总数**，$h$ 为二叉树的**高度**（仅含根结点的树高为 $1$）：

- **时间**：`SwapLR` 对每个结点调用一次（递归体在非空时执行 $3$ 次指针赋值 + $2$ 次递归调用），共 $n$ 次执行、$3n$ 次指针操作 ⟹ $T(n)=O(n)$，与树的形态**无关**（不存在"最坏情况变慢"的问题）。递推式 $T(n)=T(|L|)+T(|R|)+c,\ T(0)=0$，解为 $T(n)=cn$。
- **空间**：递归栈深度不超过树高 ⟹ $S(n)=O(h)$。最坏（原树为单支，题设允许：例如依次"左挂更大者"形成全左链）时 $h=n$，$S=O(n)$；树接近完全二叉树时 $h=\lfloor\log_2 n\rfloor+1$，$S=O(\log n)$。
- **与其他做法的对比**：

| 做法 | 时间 | 空间 | 是否移动数据域 |
|---|---|---|---|
| 本题：交换左右子树 | $O(n)$ | $O(h)$ | 否（只改指针）|
| 中序取出序列 → 逆序 → 依次插入建 BST | 平均 $O(n\log n)$，最坏 $O(n^2)$（序列有序时退化为单支）| $O(n)$ | 是（重建新树）|
| 中序取出 → 对**原树**按序回写数据域（结点位置不动）| $O(n)$ | $O(h)$ | 是（搬 $n$ 个数据域）|

交换法之所以是标准答案：**不搬运数据、只改 $n$ 组指针**，且与树形态无关恒为线性。

## 8. 考场标准答案

**数据结构定义**：

```c
typedef struct BTNode {
    ElemType data;
    struct BTNode *lchild, *rchild;
} BTNode, *BTree;
```

**设计思想**：该树中序序列递减，即每个结点"左子树更大、右子树更小"，是二叉排序树的镜像。将每个结点的左右子树交换后，整棵树的中序序列变为原序列的逆序，即变为递增；而"中序递增"是二叉排序树的充要条件，故变换后即得二叉排序树。算法只需一次遍历，逐结点交换 `lchild` 与 `rchild`。

**代码**：

```c
void SwapLR(BTree t)
{
    BTNode *tmp;
    if (t == NULL) return;
    tmp = t->lchild;
    t->lchild = t->rchild;
    t->rchild = tmp;
    SwapLR(t->lchild);
    SwapLR(t->rchild);
}

void ConvertToBST(BTree bt) { SwapLR(bt); }
```

**复杂度**：时间 $O(n)$，$n$ 为结点总数（每结点访问一次、交换一次）；空间 $O(h)$，$h$ 为树高（递归栈），最坏 $O(n)$、平衡时 $O(\log n)$。

## 9. 易错点

1. **忘记定义数据结构**：题面明写"请定义必要的数据结构"，只给函数体不写 `BTNode`/`BTree` 定义会被扣分；
2. **交换时不暂存**：写成 `t->lchild = t->rchild; t->rchild = t->lchild;` —— 第二句用的已是改过的新 `lchild`，结果左右子树相同、原左子树整体丢失（内存泄漏且结构错误）；必须 `tmp` 暂存或严格按"暂存→两次赋值"顺序；
3. **在"中序遍历的过程中"顺手交换**：`SwapLR(t->lchild); 交换; SwapLR(t->rchild);` 中的第二次递归进入的是**原左子树**（已被换到右边），造成同一子树被交换两次（等于没换）而另一子树未被处理。正确做法是**前序式**（先交换，再按新指针递归两棵子树）或**后序式**（先按原指针递归两棵子树，最后交换本结点），如第 6 节 (4) 所示；
4. **只交换了根的左右子树**：题设要求"所有结点"，仅交换根只把两棵子树整体换位，子树内部仍是倒序；同理，"交换每个结点的孩子指针"要遍历到每一个结点；
5. **误以为要重新排序数据域**：数据一个都不用动，也不需要比较关键字大小 —— 一旦开始"逐个结点找插入位置"，就把 $O(n)$ 的题做成了 $O(n^2)$；
6. **边界与口径**：空树 `bt == NULL` 直接返回（不写 `if` 会在第一句解引用时崩溃）；单结点树交换后仍是它自身，本来就是 BST；含重复关键字时"从大到小"含相等，需说明按左 $\le$ 根 $<$ 右的广义定义才成立，一般答题写"关键字互异"即可；
7. **复杂度只答 $O(n)$ 不说空间、不说明 $n$ 是结点数**：算法实现题通常时间、空间各占分，且要求指明量的含义。

## 10. 一句话规律

凡是"中序序列方向反了"的二叉树，一律用**逐结点交换左右子树**（$O(n)$、只改指针不改数据）修正方向；判断一棵二叉树是不是 BST，永远先问"它的中序序列是否递增"。
