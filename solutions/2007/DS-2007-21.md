# DS-2007-21

## 1. 原题

两个串相等的准确含义是____________________ 。

## 2. 答案

两个串的**长度相等**，并且**各对应位置上的字符都相同**——即两串是由完全相同的字符按完全相同的次序排成的有限字符序列（`StrEqual(S,T) ⟺ S.length==T.length 且 ∀i: S.ch[i]==T.ch[i]`）。

## 3. 题目分析

- 已知：串（String）的定义——由零个或多个字符组成的**有限序列**，记作 $s='a_1a_2\cdots a_n'$，$n$ 为串长；
- 目标：给出"两串相等"的**准确**（充要）含义；
- 关键约束：串是**序列**型对象，序列相等的数学定义是"长度相同且逐位元素相同"，两个条件缺一不可；
- 命题意图：考"串与线性表的关系"这一概念起点——串的元素（字符）类型单一、整体作为不可分割的数据对象参与比较；因此"相等"不是指存储地址相同、也不是指含有相同的字符集合，而是**逐位同序同长**。题干用"准确含义"四字，正是要排除只答一半（如只说"字符相同"）的不完整表述。

## 4. 核心考点

核心考点：

解释：本题考的是"串"这一章的定义层知识，是 DS02.06 模式匹配的前置概念（BF/KMP 的每次"比较"就是在判长度 $m$ 的字符段与模式串是否逐位相等）。

## 5. 解题思路

1. 回到串的形式定义：串是**有限字符序列**，序列由"长度 + 位置→字符的映射"完全确定；
2. 于是"两串相等"当且仅当两个序列相同，展开即两条：长度相等、对应位置字符相同；
3. 自检是否漏条件：只给"长度相等"（`"abc"` 与 `"abd"`）不够；只给"含相同字符"（`"abc"` 与 `"cba"`）也不够；两者合起来仍不够（还需**对应位置**一致，即次序相同）；
4. 用补充表述加固：等价的程序口径 `S.length==T.length && strcmp/逐字符比较全部相等`。

## 6. 详细解答

**定义层**

串 $S=(c_1c_2\cdots c_m)$、$T=(d_1d_2\cdots d_n)$，其中 $c_i,d_j$ 取自字符集。$S$ 与 $T$ 相等当且仅当

$$m=n\quad\text{且}\quad \forall\, i\ (1\le i\le m):\ c_i=d_i$$

即"**长度相等，且各对应位置上的字符相同**"。此时也称两串的内容相同；反之，若只是字符集合相同而次序不同（如 `"ab"` 与 `"ba"`），或只是长度相同而字符不同（如 `"ab"` 与 `"ac"`），都不相等。

**几个边界情形（帮助确认定义的完备性）**

| 情形 | 是否相等 | 说明 |
|---|---|---|
| 空串 `""` 与空串 `""` | 相等 | 长度均为 $0$，"逐位相同"空虚成立 |
| 空串 `""` 与空格串 `" "` | 不相等 | 长度 $0\neq1$；空格串含一个字符 `' '`，**不是**空串 |
| `"abc"` 与 `"abc "` | 不相等 | 长度 $3\neq4$（末尾空格也是字符） |
| `"abc"` 与 `"ABC"` | 不相等 | 字符不同（区分大小写，与字符的机内编码值比较一致） |

**与模式匹配的关系（该定义的用处）**

串的一种基本运算是"定位/匹配"：`Index(S,T,pos)` 求 $T$ 在 $S$ 中首次出现的位置。所谓"$T$ 在 $S$ 的第 $i$ 个位置起匹配成功"，其严格含义正是子串 $S[i\cdots i+m-1]$ 与 $T$ **相等**，即本题的两条判据。BF 算法从 $i$ 起逐位比较、KMP 算法借助 $next$ 数组跳过必然不匹配的位置，二者对"匹配"的判定标准都是本条定义；因此本题虽为概念填空，实为 DS02.06 算法题的定义地基。

**规范作答**

两个串的长度相等，并且各对应位置上的字符都相同（即两串所含字符序列完全相同）。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

两个串的长度相等，且各对应位置上的字符都相同（两串的字符序列完全相同）。

可写作：$\mathit{StrEqual}(S,T)\iff S.\mathit{length}==T.\mathit{length}\ \wedge\ \forall i\,(1\le i\le S.\mathit{length}): S.\mathit{ch}[i]==T.\mathit{ch}[i]$。

## 9. 易错点

1. 只答"所含字符相同"漏掉"长度相等 + 对应位置"：`"ab"` 与 `"ba"`、`"ab"` 与 `"abc"` 都会被误判为相等；
2. 把"空串"与"空格串 `' '`"混为一谈：前者长度为 $0$，后者长度为 $1$，二者不相等；
3. 答成"存储内容相同/地址相同"：串相等是**逻辑**上的内容比较，与顺序存储还是链式存储、与存放位置无关；
4. 误引入"字典序比较"：两串可以比较大小（逐字符按编码值比较，遇到第一个不同字符即定序），但"相等"与"大小"是两回事，本题答案不涉及大小关系。

## 10. 一句话规律

一切"序列型对象"（串、数组、广义表中的元素序列）的相等判定都是同一句话：**长度相等且逐位相同**；答题时两条必须都写，缺一即扣分。
