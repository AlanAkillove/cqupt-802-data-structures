# DS-2007-15

## 1. 原题

设计一个判别表达式中左、右括号是否配对出现的算法，采用（）数据结构最佳。

A. 栈

B. 队列

C. 顺序结构线性表

D. 链式结构线性表

## 2. 答案

**A**（栈）。

## 3. 题目分析

- 已知：表达式中的左、右括号可能多层嵌套，如 `(a*(b+c))-d`；要求判别"配对出现"；
- 目标：选出实现该判别的**最佳**辅助结构；
- 关键约束：括号的匹配规则是"**最近**打开的那个左括号，必须最先被当前右括号闭合"——即匹配关系呈嵌套（后进先出）结构；
- 命题意图：考"由问题的匹配次序特征选择数据结构"。与本年度 DS-2007-14（保序 ⟹ 队列）互为对照；C、D 两项考查学生是否明白"顺序/链式"只是存储方式，不决定运算的受限次序。

## 4. 核心考点

核心考点：
DS02.07 栈、队列和数组的应用（括号匹配——栈的经典应用）

辅助考点：
DS02.01 栈和队列的基本概念（LIFO 与 FIFO 的特性差异是"最佳"二字的判据）

解释：题面只问"采用什么结构最佳"，不要求写完整程序，但必须能给出算法骨架与不变量，才能说明为何"最近打开的最先闭合"只能是栈。

## 5. 解题思路

1. 写出匹配规则：从左到右扫描，遇到右括号时，与它配对的应当是**它左边最近的那个尚未匹配的左括号**；
2. "最近未匹配"= 最后进入、最先取出 ⟹ 后进先出 ⟹ 栈；
3. 设计不变量：栈中始终保存"已出现但尚未闭合的左括号"，且按出现次序自底向顶排列；扫描结束时栈空 ⟺ 全部配对成功；
4. 复杂度核对：每个字符至多入栈一次、至多出栈一次，时间 $O(n)$、空间最坏 $O(n)$，已是该问题的最优量级；
5. 排除 B（队列取出的是最早打开的左括号，跨层错配）、C/D（线性表可在两端任意增删，虽能实现，但不受限的访问方式使匹配点需要从头查找，且语义上不如栈直接）。

## 6. 详细解答

**（1）为什么必须是后进先出**

考察 `(( ) ( ))` 这类嵌套串。设扫描到某个右括号 `)`，与它配对的左括号必须满足两个条件：在它左边、且是**尚未匹配**的左括号中下标最大者。因为若与更早的左括号配对，就会与中间那个左括号的匹配区间交叉，违反括号嵌套的结构定义（区间要么不相交、要么严格包含）。

"最后进入、最先取出"正是栈的定义，故用栈存放待匹配的左括号，取栈顶即得配对对象，一步到位。

**（2）算法与不变量**

```c
/* 判别表达式 str 中圆括号是否配对：1 为配对，0 为不配对 */
int Match(char str[])
{
    Stack s;                       /* 顺序栈，元素为左括号 */
    char c;
    int i = 0;
    InitStack(&s);
    while (str[i] != '\0') {
        if (str[i] == '(') {
            Push(&s, str[i]);                 /* 左括号入栈，等待闭合 */
        } else if (str[i] == ')') {
            if (StackEmpty(&s)) return 0;     /* 无左括号可配：右括号多余 */
            Pop(&s, &c);                      /* 与最近打开的左括号配对 */
        }
        i++;
    }
    return StackEmpty(&s) ? 1 : 0;            /* 栈非空：左括号多余 */
}
```

- **不变量**：任一时刻，栈中自底向顶的左括号，其位置严格递增，且都还没有右括号与之配对；
- **失败出口有两个**：① 遇右括号时栈空（右多）；② 扫描结束时栈非空（左多）。只判其中一个是最常见的漏判；
- 复杂度：时间 $O(n)$（$n$ 为表达式长度，每字符至多一次入栈、一次出栈），空间最坏 $O(n)$（形如 `(((…` 时）。

**（3）用队列会怎样（反证 B）**

若把左括号入队，则遇到右括号时出队的是**最早**打开的那个左括号，与"当前右括号应闭合最近打开的左括号"这条规则不符，具体表现为两点：

- 定位失效：队列只能给出"还有一个左括号没闭合"这一**计数**信息，给不出"是哪一个"，因此无法报告错配位置；
- 混合括号时会误判：对串 `[(])`，先进先出口径下扫描到第 3 个字符 `]` 时出队取到最早入队的 `[`（类型恰好相符），扫描到第 4 个字符 `)` 时出队取到 `(`（也相符），于是被判为"配对"；而实际上 `]` 必须闭合最近打开的 `(`，类型不符，该串非法。栈在扫描到 `]` 时栈顶正是 `(`，一比对即判错（同型情形见 2016 年第 4 题）。

故只有栈能直接实现该匹配规则。

**（4）排除 C、D**

顺序表与链表描述的是**存储方式**，不是**存取次序限制**。用线性表也能实现：每次遇右括号时从头（或从尾）线性查找最近的未匹配左括号，最坏退化为 $O(n^2)$；或者人为限制只在表尾插入、表尾删除——那实际上就是在模拟栈。因此"最佳"仍是栈：语义直接、代码最短、复杂度 $O(n)$。

**答案**：A。

## 7. 选项分析

- A. 栈：正确。括号匹配的本质是"最近打开的最先闭合"，LIFO 与嵌套区间结构一一对应，$O(n)$ 可解；
- B. 队列：错。FIFO 取出的是最早打开的左括号，无法定位"最近的未匹配左括号"；多种括号混合嵌套时（如 `[(])`）判不出交叉错配；
- C. 顺序结构线性表：错。能实现但需查找，最坏 $O(n^2)$；"顺序/链式"是存储层面的选择，与本题的匹配次序无关，不是"最佳"；
- D. 链式结构线性表：错。同 C，且链表还额外付出指针空间；若限制只在表尾进出，则已等价于栈（不如直接声明用栈）。

## 8. 考场标准答案

选 **A（栈）**。

理由：从左向右扫描表达式，遇左括号入栈；遇右括号时，与它配对的必是**栈顶**（最近打开、尚未闭合）的左括号——若栈空则右括号多余，判不配对；扫描结束后栈非空则左括号多余，亦不配对。括号的嵌套区间"要么不相交、要么严格包含"，正是后进先出结构，故栈最佳。时间 $O(n)$、空间最坏 $O(n)$，每字符至多进出栈各一次。

## 9. 易错点

1. 只判"左右括号数量相等"：`) (` 数量相等却不配对，必须靠"遇右括号时栈不能空"这条中间检查；
2. 漏掉扫描结束后的"栈空"检查，只处理了右括号多余的情况；
3. 多种括号混合（`(`、`[`、`{`）时忘记比较**类型**：出栈时应核对栈顶括号与当前右括号是否同类，否则 `[(])` 会被误判为配对；
4. 因"表达式是线性存储的"而选顺序表——题问的是**辅助结构**，不是表达式本身的存放方式。

## 10. 一句话规律

凡是"当前元素要与**最近一个尚未处理完**的同类元素配对/消解"的问题（括号匹配、表达式求值、递归返回、撤销、浏览器前进后退、HTML 标签闭合），一律用栈；凡是"当前元素要与**最早一个**等待的元素配对"（缓冲、排队、层序、BFS），一律用队列。
