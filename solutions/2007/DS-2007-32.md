# DS-2007-32

## 1. 原题

已知一个无向图的邻接矩阵表示，计算第 $j$ 个结点的度的方法是____________________ 。

## 2. 答案

**统计邻接矩阵第 $j$ 行中非零元素的个数**（因无向图的邻接矩阵对称，第 $j$ 列结果相同）：

$$TD(j)=\sum_{i=1}^{n}(A[j][i]\neq 0),\qquad \text{（0/1 矩阵时直接 } TD(j)=\sum_{i=1}^{n}A[j][i}\text{）}$$

## 3. 题目分析

- 已知：无向图 $G=(V,E)$，$|V|=n$，其邻接矩阵 $A=(a_{ij})_{n\times n}$，$a_{ij}=1$（或 $\mathrm{TRUE}$）表示 $(v_i,v_j)\in E$，否则 $a_{ij}=0$；
- 目标：给出由 $A$ 求第 $j$ 个结点度的**方法**（描述性填空，不要求具体数值）；
- 关键约束：无向图的每条边 $(v_j,v_i)$ 在 $A$ 中同时占据 $a_{ji}$ 与 $a_{ij}$ 两个位置（矩阵关于主对角线对称），因此与 $v_j$ 关联的边恰好一一对应第 $j$ 行的 $1$；
- 命题意图：考邻接矩阵"元素含义 ↔ 图的边的关联"这一双向翻译能力，并顺带考"无向图矩阵对称 ⟹ 行、列等价"以及"有向图要分入度/出度"的对比意识。

## 4. 核心考点

核心考点：
DS04.02.01 邻接矩阵法（矩阵元素与边的对应关系、对称性）

辅助考点：
DS04.01 图的基本概念（无向图中结点的度：与该结点关联的边数）

解释：答案的"数值来源"是邻接矩阵的存储定义（DS04.02.01），"求什么"则是度的概念（DS04.01）；两者缺一不能把方法写准确。

## 5. 解题思路

1. 回到定义：$v_j$ 的度 $=\{e\in E: e \text{ 与 } v_j \text{ 关联}\}$ 的元素个数；
2. 翻译到矩阵：与 $v_j$ 关联的每条边 $(v_j,v_i)$ 使 $a_{ji}=1$，反之第 $j$ 行每个 $1$ 代表一条与 $v_j$ 关联的边 ⟹ 数第 $j$ 行的 $1$ 即可；
3. 用对称性说明"第 $j$ 列也行"：$a_{ji}=a_{ij}$，故按列统计结果相同（有向图不成立，须区分出度=第 $j$ 行、入度=第 $j$ 列）；
4. 特例检查：自环 $(v_j,v_j)$ 只占 $a_{jj}$ 一个位置，但按度的定义贡献 $2$，故严格表述应为"第 $j$ 行非零元素个数，若有自环则 $a_{jj}$ 计 $2$"（一般图/不讨论自环时按非零元素个数即可）；
5. 用一个 4 顶点小图手算核对。

## 6. 详细解答

**方法表述（可写入答卷）**

设邻接矩阵为 $A[n][n]$，求第 $j$ 个结点的度：令计数器 $count=0$，扫描第 $j$ 行的 $n$ 个元素，每遇到一个非零（即 $1$/$\mathrm{TRUE}$）元素 $count$ 加 $1$，扫描结束 $count$ 即为所求：

```c
int Degree(int A[][MAXV], int n, int j)     /* j 为顶点下标，0 <= j < n */
{
    int i, count = 0;
    for (i = 0; i < n; i++)
        if (A[j][i] != 0)      /* 该位置为 1（或 TRUE）说明 (vj, vi) 是图中的边 */
            count++;
    return count;              /* 无向图：第 j 行的 1 的个数即 vj 的度 */
}
```

时间复杂度 $O(n)$（只扫一行；若整矩阵全求一遍为 $O(n^2)$）。

**正确性论证**

无向图邻接矩阵定义：

$$a_{ij}=\begin{cases}1,& (v_i,v_j)\in E\\ 0,& \text{否则}\end{cases}$$

集合 $\{i : a_{ji}=1\}=\{i : (v_j,v_i)\in E\}$ 恰是"与 $v_j$ 关联的边的另一端点集合"，其基数按度的定义就是 $TD(v_j)$（无自环时端点与边一一对应）。故

$$TD(v_j)=\sum_{i=1}^{n} a_{ji}\quad\text{（第 } j \text{ 行求和）}$$

又因无向图中 $(v_j,v_i)=(v_i,v_j)$ ⟹ $a_{ji}=a_{ij}$ ⟹ $A$ 对称 ⟹ 第 $j$ 行的非零元素个数与第 $j$ 列相同，两种写法皆可。

**实例核对**（$V=\{v_1,v_2,v_3,v_4\}$，$E=\{(v_1,v_2),(v_1,v_3),(v_2,v_3),(v_3,v_4)\}$）

$$A=\begin{pmatrix}0&1&1&0\\ 1&0&1&0\\ 1&1&0&1\\ 0&0&1&0\end{pmatrix}\quad\text{（行、列顺序均为 } v_1,v_2,v_3,v_4\text{）}$$

- 直接看图数：$v_3$ 关联 $(v_1,v_3),(v_2,v_3),(v_3,v_4)$ 三条边 ⟹ $TD(v_3)=3$；
- 第 $3$ 行非零元素个数 $=1+1+0+1=3$ ✓；第 $3$ 列非零元素个数 $=1+1+0+1=3$ ✓（对称）；
- 全部度数之和 $2+2+3+1=8=2|E|=2\times4$ ✓ 与握手定理一致，进一步验证方法正确。

**答案**：统计（求和）邻接矩阵第 $j$ 行的非零元素个数（第 $j$ 列等价）。

## 8. 考场标准答案

设邻接矩阵为 $A$，则第 $j$ 个结点的度

$$TD(j)=\sum_{i=1}^{n}(A[j][i]\neq 0)$$

即**逐个元素扫描第 $j$ 行，统计其中 $1$（非零）元素的个数**；因无向图的邻接矩阵对称，统计第 $j$ 列结果相同。时间复杂度 $O(n)$。
（若为有向图：第 $j$ 行的 $1$ 个数是**出度**，第 $j$ 列的 $1$ 个数是**入度**，二者之和才是度。）

## 9. 易错点

1. 答成"第 $j$ 行与第 $j$ 列非零元素个数之和"：无向图矩阵对称，行、列统计的是同一批边，相加会把度放大一倍（该写法只在"行=出度、列=入度"的有向图求度总和时才对）；
2. 带权网中把 $\infty$（无边占位符）当成"非零元素"计入：正确判据是"该位置表示一条边"，即 $a_{ij}\neq 0$ 且 $a_{ij}\neq \infty$；
3. 忽略自环：自环 $(v_j,v_j)$ 只落在 $a_{jj}$ 一个位置，但按定义贡献度 $2$，严谨答案需注明"不含自环"或对 $a_{jj}$ 计 $2$；
4. 与邻接表口径混淆：邻接表求度是"数第 $j$ 个顶点链表中的边结点个数"（本年度第 33 题、第 39 题涉及），不能把邻接矩阵的"行求和"答成"链表长度"。

## 10. 一句话规律

邻接矩阵里"某顶点的度"永远是"数它那一行（或那一列）的边标记"：无向图行列等价（对称），有向图行=出度、列=入度，求和前先问一句"矩阵对称吗"。
