# DS-2007-35

## 1. 原题

快速排序算法的思想是____________________ 。

## 2. 答案

**通过一趟排序将待排序记录分割成独立的两部分，其中一部分记录的关键字均比另一部分记录的关键字小**：具体做法是选取（通常取当前区间的第一个）记录作为**枢轴（pivot）**，通过区间两端的交替扫描与移动，把所有关键字比枢轴小的记录安置到枢轴之前、比枢轴大的记录安置到枢轴之后，此时**枢轴到达其最终位置**；然后再分别对这两个子区间递归地重复上述过程，直到每个区间长度不超过 $1$，整个序列即有序。

要点四句话：① 选枢轴；② 一趟划分（partition），枢轴就位；③ 左右子区间递归；④ 区间长度为 $1$ 或 $0$ 时递归结束。

## 3. 题目分析

- 已知：概念题，要求叙述快速排序算法的基本思想（不是写代码、不是算趟结果）；
- 目标：给出教材口径的完整表述，需含"枢轴""一趟划分""两部分分别小于/大于枢轴""递归"四个要素；
- 关键约束：快排属于**交换排序**（与冒泡同族），且是**分治**型：与归并排序"先分解、合并时有序"不同，快排是"**划分时就确定枢轴的最终位置**"，因此递归到区间长度为 $1$ 即完成，无需额外的合并步骤；
- 命题意图：考"能否用一句话讲清算法机制"，并隐含与本年度第 36 题（选择排序逐趟过程）的对照——两种排序"每一趟的产出"完全不同（快排一趟只让一个元素就位，选择排序一趟让一个元素就位但按位置顺序）。

## 4. 核心考点

核心考点：
DS06.06 快速排序（枢轴、一趟划分的机制、递归分解）

辅助考点：
DS06.01 排序的基本概念（"趟"的概念、算法稳定性、时间/空间代价）

解释：思想的每一要素都属 DS06.06 的过程定义；而"一趟""不稳定""平均 $O(n\log_2 n)$、最坏 $O(n^2)$、递归栈 $O(\log n)$"这些评价性结论属 DS06.01 的通用概念，作为辅助支撑答案的完整性。

## 5. 解题思路

1. 先答机制骨架（选枢轴 → 划分 → 枢轴就位 → 递归两侧），这是得分主体；
2. 补一句"属于交换排序 + 分治策略"以点明方法族；
3. 用一个小例子（$7$ 个关键字）手推一趟划分，验证"左小右大、枢轴就位"确为所述机制；
4. 补评价（平均/最坏复杂度、稳定性、递归空间），说明"为什么快"以及"什么时候不快"；
5. 与归并、选择排序各比一句，防止表述互相污染（例如不要写成"每趟选出最小者"，那是选择排序）。

## 6. 详细解答

**（一）教材口径的完整表述**

快速排序（Quicksort）是**交换排序**的一种，采用**分治**策略。其基本思想是：

> 通过一趟排序将待排序记录分割成独立的两部分，其中一部分记录的关键字均比另一部分记录的关键字小，则可分别对这两部分记录继续进行排序，以达到整个序列有序。

一趟排序（划分）的做法：选取一个记录作为枢轴（教材默认取当前区间的第一个记录），设置两个下标 $low$、$high$ 分置区间两端，从 $high$ 起向左搜索第一个关键字小于枢轴的记录并移到 $low$ 处，再从 $low$ 起向右搜索第一个关键字大于枢轴的记录并移到 $high$ 处，交替进行直到 $low$ 与 $high$ 相遇，此时把枢轴放入该位置。划分结束后：

$$\underbrace{R[low..pivot-1]}_{\text{关键字}\le \text{枢轴}}\quad \underbrace{R[pivot]}_{\text{枢轴（已最终就位）}}\quad \underbrace{R[pivot+1..high]}_{\text{关键字}\ge \text{枢轴}}$$

对左右两个子区间递归执行同一过程，递归终止条件是区间长度为 $0$ 或 $1$。

**（二）一趟划分的手工验证**

取关键字序列 $(49,38,65,97,76,13,27)$，枢轴 $=49$，$low=1$，$high=7$：

| 步骤 | 动作 | 序列状态（`_` 为空洞） |
|---|---|---|
| 初态 | 取出枢轴 $49$ | `_ 38 65 97 76 13 27` |
| ① | $high$ 左移遇 $27<49$，移到 $low$ | `27 38 65 97 76 13 _` |
| ② | $low$ 右移遇 $65>49$，移到 $high$ | `27 38 _ 97 76 13 65` |
| ③ | $high$ 左移遇 $13<49$，移到 $low$ | `27 38 13 97 76 _ 65` |
| ④ | $low$ 右移遇 $97>49$，移到 $high$ | `27 38 13 _ 76 97 65` |
| ⑤ | $high$ 左移至 $low=4$，相遇 | `27 38 13 _ 76 97 65` |
| ⑥ | 枢轴填入 $4$ | `27 38 13 [49] 76 97 65` |

验证：左侧 $\{27,38,13\}$ 全部 $<49$，右侧 $\{76,97,65\}$ 全部 $>49$，枢轴已在最终位置 ✓ —— 这正是"一部分均比另一部分小"的含义。再对 $[1..3]$ 与 $[5..7]$ 递归即可。

**（三）算法骨架（教材风格 C/C++）**

```c
int Partition(SqList *L, int low, int high)     /* 一趟划分，返回枢轴位置 */
{
    ElemType pivot = L->r[low];                /* 以区间首记录为枢轴 */
    while (low < high) {
        while (low < high && L->r[high].key >= pivot.key) high--;
        L->r[low] = L->r[high];                /* 比枢轴小的记录移到左端 */
        while (low < high && L->r[low].key <= pivot.key) low++;
        L->r[high] = L->r[low];                /* 比枢轴大的记录移到右端 */
    }
    L->r[low] = pivot;                         /* 枢轴就位 */
    return low;
}

void QSort(SqList *L, int low, int high)       /* 递归排序 L->r[low..high] */
{
    if (low < high) {
        int pivotloc = Partition(L, low, high);
        QSort(L, low, pivotloc - 1);           /* 左子区间 */
        QSort(L, pivotloc + 1, high);          /* 右子区间 */
    }
}
```

**（四）性能与性质（思想的自然推论）**

| 项目 | 结论 | 原因 |
|---|---|---|
| 平均时间 | $O(n\log_2 n)$ | 每次划分大致对半分，递归树深 $\log_2 n$，每层总工作量 $O(n)$ |
| 最坏时间 | $O(n^2)$ | 序列已（逆）序且总取首元素为枢轴 ⟹ 划分极不平衡（一侧空、一侧 $n-1$） |
| 空间 | $O(\log_2 n)$（递归栈），最坏 $O(n)$ | 递归深度 |
| 稳定性 | 不稳定 | 一趟中记录会跨过枢轴远距离交换 |
| 每趟产出 | 只有**一个**记录（枢轴）最终就位 | 与选择排序"每趟按位置顺序定一个"不同 |

**（五）与相近算法的一句话区分**

- 归并排序：也是分治，但"先递归排序两侧、再**合并**"，枢轴不预先就位（且归并稳定、空间 $O(n)$）；
- 冒泡排序：同为交换排序，但只比较**相邻**记录，一趟让一个最值沉底；
- 选择排序：每趟在未有序区间中**选最小**者放到区间首位（本年度第 36 题即其逐趟过程），不做"两侧夹逼"的划分。

## 8. 考场标准答案

快速排序是基于**分治**的交换排序：通过一趟排序将待排序记录分割成独立的两部分——选取一个记录作为枢轴，从区间两端交替扫描、移动，使所有关键字比枢轴小的记录都排在枢轴之前、比枢轴大的记录都排在枢轴之后，此时枢轴到达最终位置；然后分别对左、右两个子区间递归地重复这一过程，直到区间长度为 $1$，整个序列即有序。

平均时间复杂度 $O(n\log_2 n)$，最坏 $O(n^2)$，辅助空间 $O(\log_2 n)$，**不稳定**。

## 9. 易错点

1. 只答"选一个基准，小的放左边大的放右边"而漏掉**递归**与"枢轴最终就位"这两个采分点；
2. 与归并排序的分治表述混淆：快排是"**划分时**确定枢轴位置、无需合并"，归并是"**合并时**才产生有序"；
3. 把"一趟"的产出说错：快排一趟只保证**枢轴一个**记录就位（不是"最大者沉底"，那是冒泡；也不是"最小者前置"，那是选择排序）；
4. 漏写"不稳定"：一趟中记录与枢轴侧的远距离移动会破坏相同关键字的相对次序；
5. 划分实现口径不统一：本题按严蔚敏版"两端交替扫描 + 空洞移动"叙述；若答"左右指针相遇后交换"的写法，一趟结果形态会不同（2021 年第 32 题第 2 行即为该写法的产物），作答时宜与教材一致。

## 10. 一句话规律

凡"分治型"排序都可按三问作答：**分解点在哪（快排=枢轴就位）、递归对谁做（两侧子区间）、何时结束（区间长度 ≤1）**；再补"平均 $O(n\log_2 n)$、最坏 $O(n^2)$、不稳定"三句即可覆盖此类概念题的全部采分点。
