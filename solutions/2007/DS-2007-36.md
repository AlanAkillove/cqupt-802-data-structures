# DS-2007-36

## 1. 原题

**36、** 用选择排序方法对序列 $(65,38,97,76,13,27)$ 按从小到大的顺序进行排序，写成排序过程与结果。

## 2. 答案

共需 $n-1=5$ 趟，每趟在未有序区间 $R[i..6]$ 中选出关键字最小的记录，与 $R[i]$ 交换：

| 趟 | 交换操作 | 趟后序列 |
|---|---|---|
| 初始 | — | $(65, 38, 97, 76, 13, 27)$ |
| 第 1 趟 | $13 \leftrightarrow 65$ | $(\mathbf{13}, 38, 97, 76, 65, 27)$ |
| 第 2 趟 | $27 \leftrightarrow 38$ | $(13, \mathbf{27}, 97, 76, 65, 38)$ |
| 第 3 趟 | $38 \leftrightarrow 97$ | $(13, 27, \mathbf{38}, 76, 65, 97)$ |
| 第 4 趟 | $65 \leftrightarrow 76$ | $(13, 27, 38, \mathbf{65}, 76, 97)$ |
| 第 5 趟 | $76$ 已在位，不交换 | $(13, 27, 38, 65, \mathbf{76}, 97)$ |

**排序结果**：$(13,27,38,65,76,97)$。

总比较次数 $5+4+3+2+1=15=\frac{n(n-1)}{2}$；交换 $4$ 次（按每次交换 $3$ 次记录移动计，共 $12$ 次移动）。

## 3. 题目分析

- 已知：初始序列 $R=(65,38,97,76,13,27)$，$n=6$；升序；算法限定为**简单选择排序**；
- 目标：写出**逐趟过程**（$n-1=5$ 行中间状态）与**最终结果**；
- 关键约束（本题采用的教材口径）：
  1. 第 $i$ 趟在 $R[i..n]$ 中选取关键字最小的记录，其位置记为 $min$；
  2. 若 $min\neq i$，则交换 $R[i]$ 与 $R[min]$；$min=i$ 时该趟不产生交换（$R[i]$ 本已就位）；
  3. 每趟结束后，$R[1..i]$ 即为全局最小的 $i$ 个记录且已有序，此后不再参与比较；
  4. $n$ 个记录只需 $n-1$ 趟（前 $n-1$ 个就位后第 $n$ 个必然就位）；
- 命题意图：考"能否严格按趟执行并正确记录每趟产出"，同时隐含对比较次数、交换次数等性能指标的掌握（本题未明问，但答完过程后附上是标准加分写法）；
- 注意区分：选择排序的一趟"**选最小者放到当前位置**"，与冒泡排序一趟"相邻比较、最大者沉底"、快速排序一趟"枢轴就位"（本年度第 35 题）三者产出的形态完全不同。

## 4. 核心考点

核心考点：
DS06.04 简单选择排序（第 $i$ 趟在 $R[i..n]$ 中选最小并与 $R[i]$ 交换；$n-1$ 趟；比较 $\frac{n(n-1)}{2}$ 次）

辅助考点：
DS06.01 排序的基本概念（"趟"的定义、稳定性、比较/移动次数与初态的关系）

解释：逐趟写过程属 DS06.04 的机制执行；而"每趟产出什么、为什么只需 $n-1$ 趟、移动次数最少 $0$ 最多 $3(n-1)$、算法不稳定"这些评价性结论属 DS06.01。能力标签以 `TRACE`（机械跟踪算法状态）为主，`CALCULATION`（比较/移动次数统计）为辅。

## 5. 解题思路

1. 先确认口径与趟数：$n=6$ ⟹ 写 $5$ 趟，每趟"选最小 + 与本轮起点交换"；
2. 逐趟执行：每趟把 $R[i]$ 先当作"当前最小"，再让 $R[i+1..n]$ 依次与之比较，实时更新最小值下标；一趟结束后才做一次交换（**不是边比边换**）；
3. 每趟做完立即自检两条：① $R[1..i]$ 是否已升序；② $R[1..i]$ 是否恰为原序列中最小的 $i$ 个值（元素不能凭空丢失或重复）；
4. 统计代价：第 $i$ 趟比较 $n-i$ 次 ⟹ 总数 $\sum_{i=1}^{n-1}(n-i)=\frac{n(n-1)}{2}=15$；实际发生交换 $4$ 次；
5. 结果核对：末趟序列与"把原序列直接排序"的答案一致 ⟹ $(13,27,38,65,76,97)$ ✓。

## 6. 详细解答

**（一）算法（教材风格 C/C++，$R[1..n]$）**

```c
void SelectionSort(SqList *L)              /* 简单选择排序，L->r[1..L->length] */
{
    int i, j, min;
    ElemType t;
    for (i = 1; i < L->length; i++) {      /* n 个记录共 n-1 趟 */
        min = i;                           /* 先假设 R[i] 最小 */
        for (j = i + 1; j <= L->length; j++)
            if (L->r[j].key < L->r[min].key) min = j;   /* 只记下标，不作交换 */
        if (min != i) {                    /* 最小者不在位时才交换 */
            t = L->r[i]; L->r[i] = L->r[min]; L->r[min] = t;
        }
    }
}
```

要点：内层循环全程**只比较、只更新 $min$**，一趟结束时才做一次交换；因此比较次数与初始状态**无关**。

**（二）逐趟执行明细**

记 $n=6$，加粗为趟后已有序的 $R[1..i]$ 前缀。

**第 1 趟**（$i=1$，待选区间 $R[1..6]=65,38,97,76,13,27$）

| 比较对象 $R[j]$ | 38 | 97 | 76 | 13 | 27 |
|---|---|---|---|---|---|
| 当前最小下标 $min$ | 2（值38） | 2（值38） | 2（值38） | 5（值13） | 5（值13） |

$5$ 次比较 ⟹ $min=5$，$13\neq 65$ ⟹ 交换 $R[1]\leftrightarrow R[5]$：

$$(\mathbf{13},38,97,76,65,27)$$

**第 2 趟**（$i=2$，$R[2..6]=38,97,76,65,27$）：比较 $4$ 次，$min=6$（值 $27$）⟹ 交换 $R[2]\leftrightarrow R[6]$：

$$(13,\mathbf{27},97,76,65,38)$$

**第 3 趟**（$i=3$，$R[3..6]=97,76,65,38$）：比较 $3$ 次，$min=6$（值 $38$）⟹ 交换 $R[3]\leftrightarrow R[6]$：

$$(13,27,\mathbf{38},76,65,97)$$

**第 4 趟**（$i=4$，$R[4..6]=76,65,97$）：比较 $2$ 次（$65<76$ 使 $min=5$；$97>65$ 不变），$min=5$ ⟹ 交换 $R[4]\leftrightarrow R[5]$：

$$(13,27,38,\mathbf{65},76,97)$$

**第 5 趟**（$i=5$，$R[5..6]=76,97$）：比较 $1$ 次，$min=5=i$ ⟹ 不交换：

$$(13,27,38,65,\mathbf{76},97)$$

**（三）每趟自检**

| 趟 | 前缀是否升序 | 前缀是否恰为全局最小的 $i$ 个 | 元素多重集是否守恒 |
|---|---|---|---|
| 1 | $[13]$ ✓ | $\{13\}$ ✓ | ✓ |
| 2 | $[13,27]$ ✓ | $\{13,27\}$ ✓ | ✓ |
| 3 | $[13,27,38]$ ✓ | $\{13,27,38\}$ ✓ | ✓ |
| 4 | $[13,27,38,65]$ ✓ | $\{13,27,38,65\}$ ✓ | ✓ |
| 5 | $[13,27,38,65,76]$ ✓ | $\{13,27,38,65,76\}$ ✓ | ✓ |

**（四）代价统计**

| 项目 | 计算 | 结果 |
|---|---|---|
| 趟数 | $n-1$ | $5$ |
| 比较次数 | $\sum_{i=1}^{n-1}(n-i)=5+4+3+2+1=\frac{n(n-1)}{2}$ | $15$（与初态无关） |
| 交换次数 | 实际发生 $4$ 次（第 5 趟 $min=i$ 未交换） | $4$ |
| 记录移动次数 | $4\times3=12$（每次交换记 $3$ 次移动） | $12$（最少 $0$、最多 $3(n-1)=15$） |
| 时间复杂度 | $O(n^2)$ | — |
| 空间 | 仅 $min$、$t$ 等辅助变量 | $O(1)$ |
| 稳定性 | 不稳定 | 见（五） |

**（五）排序过程与结果的规范书写（考场呈现形式）**

```
初始        (65, 38, 97, 76, 13, 27)
第1趟  13↔65  (13, 38, 97, 76, 65, 27)
第2趟  27↔38  (13, 27, 97, 76, 65, 38)
第3趟  38↔97  (13, 27, 38, 76, 65, 97)
第4趟  65↔76  (13, 27, 38, 65, 76, 97)
第5趟  无交换  (13, 27, 38, 65, 76, 97)
排序结果：(13, 27, 38, 65, 76, 97)
```

**（六）补充验证：为什么第 5 趟可以不交换**

第 4 趟后 $R[1..5]=13,27,38,65,76$ 已升序，$R[6]=97$ 是剩余唯一记录，故 $R[5..6]$ 中最小者必为 $R[5]$，$min=5=i$，交换无操作。同理，$n$ 个记录只需 $n-1$ 趟。

**（七）稳定性反例（顺带说明，本题序列未触发）**

取 $(5_a, 5_b, 1)$：第 1 趟选出 $1$ 与 $5_a$ 交换得 $(1, 5_b, 5_a)$，两个 $5$ 的相对次序被颠倒 ⟹ 简单选择排序**不稳定**（本题各趟未出现相同关键字，不影响结果）。

## 8. 考场标准答案

采用简单选择排序，$n=6$ 共 $5$ 趟，第 $i$ 趟在 $R[i..6]$ 中选出关键字最小者并与 $R[i]$ 交换：

$$
\begin{aligned}
\text{初始}\quad &(65,\ 38,\ 97,\ 76,\ 13,\ 27)\\
\text{第1趟}\quad &(13,\ 38,\ 97,\ 76,\ 65,\ 27) && 13\leftrightarrow 65\\
\text{第2趟}\quad &(13,\ 27,\ 97,\ 76,\ 65,\ 38) && 27\leftrightarrow 38\\
\text{第3趟}\quad &(13,\ 27,\ 38,\ 76,\ 65,\ 97) && 38\leftrightarrow 97\\
\text{第4趟}\quad &(13,\ 27,\ 38,\ 65,\ 76,\ 97) && 65\leftrightarrow 76\\
\text{第5趟}\quad &(13,\ 27,\ 38,\ 65,\ 76,\ 97) && 76\ \text{已在位，无交换}
\end{aligned}
$$

**排序结果**：$(13,27,38,65,76,97)$。

整个排序过程共比较 $5+4+3+2+1=15$ 次，交换 $4$ 次（移动 $12$ 次），时间复杂度 $O(n^2)$，空间 $O(1)$，算法不稳定。

## 9. 易错点

1. **边比边换**：正确做法是一趟内只记录最小值下标 $min$，趟末才交换一次；若每次比较成功就交换，中间状态就会与标准答案不符（虽然最终仍有序，但过程分丢失）；
2. **写 6 趟**：$n$ 个记录只需 $n-1=5$ 趟，最后一趟必无操作，多写反而说明未理解"前 $n-1$ 个就位则第 $n$ 个自动就位"；
3. **第 5 趟硬写一次交换**：此时最小者就是 $R[5]=76$ 本身，应写"不交换/76 已在第 5 位"，写成"$76\leftrightarrow 97$"是错的；
4. 与**冒泡排序**混淆：冒泡一趟是相邻比较、把最大者沉底（第 1 趟后 $97$ 会在末位），而本题第 1 趟后末位是 $27$，两者中间状态差异明显，可用于自查答错方法；
5. 与**直接插入排序**混淆：插入排序第 1 趟后为 $(38,65,97,76,13,27)$（前 2 个有序），与本题第 1 趟结果不同；2021 年第 32 题第 1 行正是两算法结果重合的特例，勿把经验"第一趟看不出来"推广到本题；
6. 漏写"每趟的交换对象"：题目要求"排序**过程**与结果"，只给最终有序序列不得过程分；
7. 比较次数误按 $n^2$ 或 $n(n+1)/2$ 计：正确为 $\frac{n(n-1)}{2}=15$，且该值与初态无关（这是选择排序区别于插入、冒泡的关键性质）。

## 10. 一句话规律

简单选择排序逐趟只需机械执行"**第 $i$ 趟：从 $R[i..n]$ 里挑最小，与 $R[i]$ 换一次**"——每趟**恰好一次交换（可能不换）**、**恰好 $n-i$ 次比较**，故 $n-1$ 趟、$\frac{n(n-1)}{2}$ 次比较、比较次数与初态无关。

## 11. 关联知识

- 本年度第 35 题（快速排序的思想）：同为"一趟"，快排一趟只让**枢轴**按大小关系就位（位置不定），选择排序一趟让**第 $i$ 小的记录**按位置就位——对照记忆可避免两种中间状态混淆；
- 本年度第 40 题（以 `Zhao,Qian,Sun,Li,Zhou,Wu,Zheng,Wang` 建初始堆）：堆排序是简单选择排序的改进，用堆顶代替"顺序扫描 $n-i$ 次"来选最小者，把每趟选取代价由 $O(n)$ 降为 $O(\log n)$；
- 本年度第 16 题（"时间复杂度基本不受初态影响、为 $O(n\log_2 n)$ 且稳定"选归并排序）：本题正是其干扰项 A 的原型——简单选择排序的比较次数虽也不受初态影响，但它是 $O(n^2)$ 且不稳定的；
- 本年度第 17 题（基本有序时最省时间选插入排序）：与本题形成对照，选择排序在基本有序时**不会**变快（仍比较 $15$ 次）；
- 2021 年第 32 题（由 5 行中间状态识别排序算法）：可用本题第 6 节（二）的逐趟模板去复现"直接选择排序"那一行，其"选择/插入第一趟同形"的歧义值得警惕；
- 2006 年第 25 题（判断"快速排序最差情况下 $O(n^2)$，性能不比冒泡更好"）与本题同属 DS06 的性能评价类结论，可一并整理进"各排序最好/最坏/平均、空间、稳定性"总表。
