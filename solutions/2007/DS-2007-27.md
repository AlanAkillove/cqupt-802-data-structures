# DS-2007-27

## 1. 原题

某表达式二叉树按先序遍历的结果为 $*a+-bcd$ ，令 $a=2,b=6,c=4,d=2$ ，则表达式的值等于____________________ 。

## 2. 答案

$8$（对应的表达式树求得的算式为 $a*((b-c)+d)=2*((6-4)+2)=8$）。

## 3. 题目分析

- 已知：一棵**表达式二叉树**的先序序列 $*a+-bcd$（$7$ 个字符：运算符 $*,+,-$ 各一个，操作数 $a,b,c,d$ 各一个），以及 $a=2,b=6,c=4,d=2$；
- 目标：按该树的实际结构求表达式的值；
- 关键约束：表达式二叉树中**运算符在内部结点、操作数在叶子**，且本题出现的运算符都是二元运算符 ⟹ 每个内部结点恰有两个孩子（严格二叉树）。这一约束使"先序序列 + 遇运算符即知有两个子树"足以**唯一**还原树形，不需要第二个遍历序列；
- 命题意图：考"由遍历序列确定二叉树"的构造能力，并检验是否理解"表达式的值由**树的形状**决定，而不是由运算符优先级决定"——本题树的形状与常规优先级解读不同，是最主要的失分点。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（由遍历序列确定二叉树）

辅助考点：
DS03.02.03.01 前序遍历（"根–左–右"的读取顺序是建树切分依据）
DS03.04.02 树与二叉树的其他应用（表达式树：操作数在叶、运算符在内部结点，后序遍历即后缀式）

解释：本题第一步是"由先序还原树"（DS03.02.03 的核心技能），第二步是"按树求值"（表达式树这一经典应用，DS03.04.02）。因表达式树是"严格二叉树"，先序序列本身即自定位（每个运算符固定消耗两个子树），故无需补充中序/后序。

## 5. 解题思路

1. 先做相容性检查：运算符 $3$ 个（内部结点）、操作数 $4$ 个（叶子），$n_0=n_2+1$（$4=3+1$）成立 ⟹ 数据自洽，确实存在这样的严格二叉树；
2. 按先序"根–左–右"递归切分：读一个字符，若为操作数则生成叶子并返回；若为运算符则先建其左子树、再建其右子树；
3. 建完核对字符是否恰好用完（不多不少 $7$ 个），并写出中序/后序以确认结构；
4. 按树自底向上求值（等价于对后序序列 $abc-d+*$ 用栈模拟）；
5. 复核：把树的中序加括号还原成表达式，再代入数值，看两次的算式是否一致。

## 6. 详细解答

**第一步：建树（先序序列 $*a+-bcd$ 逐个字符读取）**

| 读入 | 动作 | 当前树（局部） |
|---|---|---|
| `*` | 运算符，作整棵树根，先建左子树 | 根 $*$ |
| `a` | 操作数 ⟹ 叶子，挂为 $*$ 的左孩子 | $*.left=a$ |
| `+` | 运算符 ⟹ 挂为 $*$ 的右孩子，再建它的左右子树 | $*.right=+$ |
| `-` | 运算符 ⟹ 挂为 $+$ 的左孩子，再建它的左右子树 | $+.left=-$ |
| `b` | 操作数 ⟹ $-$ 的左孩子 | $-.left=b$ |
| `c` | 操作数 ⟹ $-$ 的右孩子，$-$ 完成，回到 $+$ | $-.right=c$ |
| `d` | 操作数 ⟹ $+$ 的右孩子，$+$ 完成，整棵树完成 | $+.right=d$ |

$7$ 个字符恰好用完 ⟹ 构造封闭，树唯一。

```
            *
          /   \
         a     +
             /   \
            -     d
           / \
          b   c
```

孩子关系表：

| 结点 | 左孩子 | 右孩子 |
|---|---|---|
| $*$ | $a$ | $+$ |
| $+$ | $-$ | $d$ |
| $-$ | $b$ | $c$ |
| $a,b,c,d$ | — | — |

**第二步：验证序列（回代）**

- 前序（根–左–右）：$*$，左子树 $a$，右子树 $+\to(-\to b,c)\to d$ ⟹ `* a + - b c d` ✓ 与题面一致；
- 中序（左–根–右）：$a$，$*$，$(b-c)$ 的中序 $b-c$，$+$，$d$ ⟹ `a*b-c+d`，加括号还原树形为 $a*((b-c)+d)$；
- 后序（左–右–根）：$a$，$(b\,c\,-)$，$d$，$+$，$*$ ⟹ `abc-d+*`（即后缀式）。

三个序列均由同一棵树导出，说明树形无误。

**第三步：按树求值**

自底向上：

$$-(b,c)=b-c=6-4=2$$
$$+(2,d)=2+2=4$$
$$*(a,4)=2\times 4=8$$

或用后序（后缀式）$abc\text{-}d\text{+}*$ 的栈模拟：压 $2,6,4$ → 遇 $-$：$6-4=2$ → 栈 $2,2$ → 压 $2$ → 栈 $2,2,2$ → 遇 $+$：$2+2=4$ → 栈 $2,4$ → 遇 $*$：$2\times4=8$ ✓。

**答案**：$8$。

**注意（本题的关键辨析）**：若不看树形、只把中序串 $a*b-c+d$ 按"先乘除后加减"的常规优先级计算，会得到 $2*6-4+2=10$，这是**错误**答案。表达式树一旦确定，其结构就固定了运算次序，优先级信息已经"编译"进树形里，不能再套用。

## 8. 考场标准答案

先序 $*a+-bcd$，表达式树为严格二叉树（运算符结点两个孩子），递归建树得

```
      *
     / \
    a   +
       / \
      -   d
     / \
    b   c
```

对应表达式 $a*((b-c)+d)$，代入 $a=2,b=6,c=4,d=2$：

$$2\times((6-4)+2)=2\times 4=\boxed{8}$$

## 9. 易错点

1. **按运算符优先级重算**（得 $10$）：树形已决定运算次序，中序串只是树的副产品，不能脱离括号直接按优先级算；
2. 建树时把运算符后面的子串当成它的右子树（漏掉“先左后右”的认领顺序）：$-$ 紧跟在 $+$ 之后，故 $-$ 是 $+$ 的**左**孩子、$d$ 才是右孩子；若颠倒则得到 $a*(d+(b-c))=2*(2+2)=8$ 这一“巧合同值”的不同树，中序回代时会发现与 $a*((b-c)+d)$ 结构不一致，必须以前序逐字符认领为准；
3. 忘记检查字符是否恰好用完：若序列不合法（如操作数与运算符不满足 $n_0=n_2+1$），建树会在中途"缺孩子"，此时应怀疑题面抄错而非强行补结点；
4. 把先序当后序/中序读（本年度第 41 题等才是"两序列定树"，本题只给一个序列，靠的正是表达式树的严格二叉性质）。

## 10. 一句话规律

表达式树"一个序列定树"：先序里遇操作数就收叶子、遇运算符就依次认领左右两个孩子，建树后**一定要回代写出前/中/后序验证**；求值一律按树形（或其后缀式）自底向上，绝不能按中序串的运算符优先级重算。
