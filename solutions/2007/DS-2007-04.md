# DS-2007-04

## 1. 原题

若长度为 $n$ 的线性表采用顺序存储结构，在其第 $i$ 个位置插入一个元素的时间复杂度为（）。 ( $1 \leq i \leq n+1$ )

A. $O(0)$

B. $O(1)$

C. $O(n)$

D. $O(n^2)$

## 2. 答案

**C**（$O(n)$）。

## 3. 题目分析

- 已知：长度为 $n$ 的线性表，**顺序存储**（地址连续的数组）；插入位置为第 $i$ 个位置，$1\le i\le n+1$；
- 目标：完成一次插入所需时间的量级；
- 关键约束：顺序存储必须保持"逻辑相邻 ⟹ 物理相邻"，在第 $i$ 个位置插入就要把第 $i$ 至第 $n$ 个元素（共 $n-i+1$ 个）整体后移一格；
- 命题意图：考"顺序表插入的代价来源是元素移动"，并要求区分"定位（$O(1)$ 随机访问）"与"移动（$O(n)$）"两段代价。

## 4. 核心考点

核心考点：
DS01.02.01 顺序存储（插入/删除引起的元素移动次数与时间复杂度）

辅助考点：
DS01.02.02 链式存储：单链表（对照项：链表中"已知位置指针"的插入是 $O(1)$，用来否证 B）

解释：一次插入 = 找位 + 移动 + 写入。顺序表下标可直接算地址（找位 $O(1)$、写入 $O(1)$），但移动 $n-i+1$ 个元素不可回避，故整体由移动项决定，为 $O(n)$。这正是本题与链表的本质对比点。

## 5. 解题思路

1. 写出移动元素个数 $m(i)=n-i+1$，取最坏位置 $i=1$ 得 $m=n$，最好位置 $i=n+1$ 得 $m=0$；
2. 时间复杂度按最坏情形计：$O(n)$；再算等概率平均 $\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac{n}{2}$，同为 $O(n)$，两条口径互证；
3. 用"顺序表插入不可能与 $n$ 无关"否证 A、B：只要 $i$ 可能为 $1$，就必须搬动 $n$ 个元素；
4. 用"每元素只被移动常数次（一次）"否证 D：总移动量是 $n$ 的一次函数，不是 $n^2$。

## 6. 详细解答

**代价分解**：设顺序表 `ElemType A[MaxSize]`，表长 $n$，在第 $i$ 个位置（$1\le i\le n+1$）插入 $e$：

```c
for (k = n; k >= i; --k)   /* 从表尾向前逐个后移 */
    A[k] = A[k-1];
A[i-1] = e;                /* 下标从 0 起时第 i 个位置为 i-1 */
n = n + 1;
```

- 循环执行次数 $=n-i+1$（把第 $i,\cdots,n$ 个元素后移）；
- 其余操作（赋值、表长加一、判溢出）均 $O(1)$。

**最坏情况**：$i=1$（插在表头）⟹ 移动 $n$ 次 ⟹ $T(n)=O(n)$。
**最好情况**：$i=n+1$（插在表尾）⟹ 移动 $0$ 次 ⟹ $T(n)=O(1)$。
**平均情况**（设 $n+1$ 个插入位置等概率）：

$$\bar T=\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac{1}{n+1}\sum_{j=0}^{n}j=\frac{n(n+1)}{2(n+1)}=\frac{n}{2}=O(n)$$

最坏与平均同为 $O(n)$，故选 C。

**与 D 的分界**：$O(n^2)$ 对应"嵌套两层与 $n$ 相关的循环"。本题只有一次遍历，单个元素只被搬动一次，移动总量 $\le n$，不平方。若连续插入 $n$ 个元素（$n$ 次操作共移动 $O(n^2)$）才是平方量级，那是"建表"而非"一次插入"的代价。

**交叉验证**：2005 年第 1 题（DS-2005-01）问"在第 $i$ 个元素之前插入需向表尾方向移动多少个元素"，答案为 $n-i+1$，与本题第 6 节的移动次数完全一致；把 $n-i+1$ 对 $i$ 取最坏即得 $O(n)$。

## 7. 选项分析

- A. $O(0)$：错。$O(0)$ 不是规范的时间复杂度记号（任何算法至少执行常数次操作，应记 $O(1)$），且与"必须移动元素"矛盾；
- B. $O(1)$：错。这是**链式表**在已持有位置指针时的插入代价，或顺序表"仅在表尾插入"这一最好情形的代价，不能代表一般位置 $i$；
- C. $O(n)$：正确。移动 $n-i+1$ 个元素，最坏 $n$ 个、平均 $n/2$ 个；
- D. $O(n^2)$：错。一次插入只有一层与 $n$ 相关的循环，量级为线性，把"建表共 $n$ 次插入"的总代价混成了单次代价才会得到平方。

## 8. 考场标准答案

顺序存储要求元素在数组中连续存放，在第 $i$ 个位置插入须将第 $i\sim n$ 共 $n-i+1$ 个元素后移：最坏（$i=1$）移动 $n$ 次，平均 $\frac{n}{2}$ 次，其余操作 $O(1)$，故时间复杂度为 $O(n)$。选 **C**。

（对照：链表在已找到前驱结点时插入为 $O(1)$；顺序表连续插入 $n$ 个元素的总代价才是 $O(n^2)$。）

## 9. 易错点

1. 把"顺序表可随机访问（定位 $O(1)$）"误当成"插入 $O(1)$"——定位便宜、移动昂贵，本题问的是整次插入；
2. 只看到最好情形（插在表尾不移动）而选 B；时间复杂度默认取最坏情形，题干给了 $1\le i\le n+1$ 就是在提示存在表头这一最坏位置；
3. 与"建表"混淆：$n$ 次插入的总代价 $O(n^2)$ 不是单次插入的代价。

## 10. 一句话规律

顺序表上"插入/删除"的复杂度一律先写移动次数 $n-i+1$（插入）或 $n-i$（删除），再取最坏位置即得 $O(n)$；只有"表尾插入"和"按下标访问"才是 $O(1)$。

## 11. 关联知识

- DS-2005-01：同一模型下"移动元素个数 $n-i+1$"的填空形式；
- DS01.02.02 单链表插入：`s->next = p->next; p->next = s;` 两条指针操作 $O(1)$，但按位查找前驱需 $O(n)$，故"按位插入"总量级仍是 $O(n)$（省的是移动，不是查找）；
- 顺序表插入前还需判溢出（`length == MaxSize`），属 $O(1)$ 附加开销。
