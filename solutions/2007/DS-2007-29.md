# DS-2007-29

## 1. 原题

一棵树 $T$ 采用二叉链表 $BT$ 存储，如果树 $T$ 中某结点为叶子结点，则在二叉链表 $BT$ 中所对应的结点一定满足____________________ 。

## 2. 答案

**左指针为空**，即 $BT$ 中该结点满足 `lchild == NULL`（没有左孩子）；其右指针 `rchild` **不一定**为空。

## 3. 题目分析

- 已知：树 $T$（一般树，结点孩子数任意）以二叉链表 $BT$ 存储——一般树用二叉链表存储只能是**孩子兄弟表示法**（左指针指第一个孩子，右指针指下一个兄弟）；
- 目标：把"树中是叶子"这一**树语义**翻译成 $BT$ 中的**指针条件**，且要满足"一定"（充分必然，不添加多余限制）；
- 关键约束：树中叶子 ⟺ 该结点没有任何孩子 ⟺ 它没有"第一个孩子" ⟺ `lchild == NULL`；而"有没有兄弟"与"是不是叶子"无关，故 `rchild` 可真可假；
- 命题意图：考孩子兄弟表示法两个指针的语义是否真的理解——学生常把"二叉链表中的叶子（两指针均空）"与"树中的叶子（无孩子）"混为一谈。

## 4. 核心考点

核心考点：
DS03.03.01 树的存储结构（孩子兄弟表示法：左孩子–右兄弟指针的语义）

辅助考点：
DS03.03.02 森林与二叉树的转换（树/森林 ↔ 二叉树的形态对应，"树中叶子对应二叉树中无左孩子的结点"是该对应的直接推论）

解释：本题不要求画图转换，但结论正是"树转二叉树"时每条边的去向（变成左孩子指针）与每个兄弟关系（变成右指针）的直接体现，故主考点 DS03.03.01、辅助 DS03.03.02。

## 5. 解题思路

1. 写出存储约定：`lchild` → 树中第一个孩子；`rchild` → 树中的下一个兄弟（同一双亲下）；
2. 按定义双向翻译："树中叶子" = "孩子数为 $0$"，孩子数为 $0$ ⟹ 不存在第一个孩子 ⟹ `lchild==NULL`（必要性）；反之 `lchild==NULL` ⟹ 无第一个孩子 ⟹ 孩子数为 $0$ ⟹ 是叶子（充分性），故实为**充要**条件；
3. 检验 `rchild` 能否进入答案：构造反例（同一双亲的两个叶子结点，前者 `rchild` 指向后者）⟹ 不能；
4. 检验"两指针均空"这一常见误答：即上一步反例，说明它只是"树中叶子且无右兄弟"的额外情形（等价于该叶是其双亲的最右孩子）。

## 6. 详细解答

**存储约定（孩子兄弟表示法）**

```c
typedef struct CSNode {
    ElemType data;
    struct CSNode *lchild, *rchild;   /* lchild: 第一个孩子; rchild: 下一个兄弟 */
} CSNode, *CSTree;                     /* 即题中所述的二叉链表 BT */
```

**必要性证明**：设树中结点 $x$ 是叶子，即 $x$ 的孩子数为 $0$。$BT$ 中 $x.\mathit{lchild}$ 指向 $x$ 的第一个孩子；$x$ 无孩子 ⟹ 第一个孩子不存在 ⟹ $x.\mathit{lchild}=\mathtt{NULL}$。

**充分性证明**：若 $x.\mathit{lchild}=\mathtt{NULL}$，则 $x$ 无第一个孩子。树中若有孩子，必存在"最左的孩子"（第一个孩子），矛盾 ⟹ $x$ 无任何孩子 ⟹ $x$ 是树中的叶子。

故 **"$x$ 是树 $T$ 的叶子" ⟺ "$BT$ 中 $x.\mathit{lchild}==\mathtt{NULL}$"**，填"左指针为空（`lchild == NULL`）"。

**为什么不能答 `rchild == NULL` 或 `lchild == NULL && rchild == NULL`（反例）**

设树 $T$ 为根 $A$ 有三个孩子 $B,C,D$，且 $B,C,D$ 都没有孩子：

```
树 T：  A                孩子兄弟链表 BT：
        |                A
      B C D              └─ lchild → B ─ rchild → C ─ rchild → D
                         （B、C、D 的 lchild 均为 NULL）
```

- $B$ 在树 $T$ 中是叶子，但 $B.\mathit{rchild}$ 指向 $C$，**非空** ⟹ "叶子 ⟹ rchild==NULL" 不成立；
- 只有 $D$（最右孩子）满足 `rchild==NULL`。因此 `lchild==NULL && rchild==NULL` 对应的是"树中叶子**且为该双亲的最右孩子**"，比"叶子"更强，不符合"一定满足"；
- 补充：$A$ 的 `rchild` 为空是因为它在树中无兄弟（若 $T$ 是森林中的一棵树，则根结点的 `rchild` 指向森林中下一棵树的根，仍可能非空）。

**对照：二叉树意义下的"叶子"**

若被存储的对象本身就是二叉树（如本年度第 45 题的二叉链表），"叶子"才对应 `lchild==NULL && rchild==NULL`。本题对象是**普通树**，两种"叶子"含义不同，这是本题唯一的陷阱。

**答案**：`lchild == NULL`（左链为空，即无左孩子）。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

树的孩子兄弟表示法中，`lchild` 指示第一个孩子、`rchild` 指示下一个兄弟。
树中结点为叶子 ⟺ 无孩子 ⟺ 无第一个孩子 ⟺ `lchild == NULL`（右指针是否有值取决于它有无右兄弟，故不确定）。

## 9. 易错点

1. 答成 `lchild == NULL && rchild == NULL`（把二叉树的叶子定义搬过来）：反例是"有右兄弟的叶子结点"，其 `rchild` 非空；
2. 答成 `rchild == NULL`：混淆了"无孩子"与"无兄弟"；
3. 记反指针语义（以为左指兄弟、右指孩子）：若按此错误约定，答案会整体颠倒，须以严蔚敏教材"左孩子–右兄弟"为准；
4. 忽略"一定满足"的逻辑强度：`rchild==NULL` 是"可能满足"，不能作为必然结论填写。

## 10. 一句话规律

树的孩子兄弟链表中，**左指针管"孩子"、右指针管"兄弟"**：凡问"树中的某性质"就在 `lchild` 一侧找，凡问"兄弟/最右孩子/森林中下一棵树"就在 `rchild` 一侧找。
