# DS-2007-13

## 1. 原题

若用数组 $A[1 \cdots n]$ 作为栈 $S_1,S_2$ 共有的空间。对于任何一个栈，只有在数组 $A$ 全满时才不能进行入栈操作。那么空间利用率最高的设置方式是（）。

> 订正说明转录：源文题干末有编者批注"（选项 $A[0]$ 改成 $A[1]$）"，属于修订备注而非题面，已删除。

A. $S_1$ 以 $A[1]$ 作为栈底，而 $S_2$ 以 $A[\frac{n}{2}]$ 作为栈底，同方向增长

B. $S_1$ 以 $A[1]$ 作为栈底，而 $S_2$ 以 $A[n]$ 作为栈底，相对方向增长

C. $S_1$ 以 $A[\frac{n}{2}-1]$ 作为栈底，而 $S_2$ 以 $A[\frac{n}{2}]$ 作为栈底，反向增长

D. $S_1$ 以 $A[\frac{n}{2}]$ 作为栈底，而 $S_2$ 以 $A[n]$ 作为栈底，同方向增长

## 2. 答案

**B**（两栈栈底分置数组两端 $A[1]$ 与 $A[n]$，相向（相对）增长）。

## 3. 题目分析

- 已知：一个数组 $A[1\cdots n]$ 同时充当两个栈的存储区；题设要求"只有当 $A$ **整体**满时才禁止入栈"，即不允许出现"数组还有空格、某个栈却报上溢"的情形；
- 目标：在四种"栈底位置 + 增长方向"的组合中，挑出让该要求成立且空间利用率最高的方案；
- 关键约束：入栈是否成功只取决于**两栈已用元素总数**是否达到 $n$，而不能取决于某个栈自己的"分区边界"；
- 命题意图：考"共享栈（两栈共享一个数组）"的经典设计——把两个栈底钉在数组两端、栈顶相向推进，使 $n$ 个单元成为两栈**公共**的可用池；与本年度 DS-2007-01、DS-2007-12 的"循环队列牺牲一格"是同一类"用指针约定换空间"的问题。

## 4. 核心考点

核心考点：
DS02.02 栈和队列的顺序存储结构（共享栈的栈底设置、增长方向与队满/栈满条件）

解释：本题不涉及任何代码，全部难度在于把"栈满"重新理解为**全局**条件。方案 A、C、D 本质都是"把数组切成固定两半"，每个栈的上限由分区决定；只有 B 让两个栈共享中间未分配区，其满条件写成 $top_1+1==top_2$（$top$ 为各自栈顶下标），恰好等价于"数组被占满"。

## 5. 解题思路

1. 把题设翻译成不等式：设两栈元素数为 $|S_1|$、$|S_2|$，要求"可入栈 $\iff |S_1|+|S_2|<n$"，即**不能**存在"$|S_1|+|S_2|<n$ 但某栈已不能入栈"的情况；
2. 固定分区方案（栈底不在两端、或方向相同）必然给单个栈设一个小于 $n$ 的硬上限，故违反该等价条件；
3. 检验 B：$S_1$ 从 $A[1]$ 向上、$S_2$ 从 $A[n]$ 向下，$S_1$ 占 $A[1\cdots top_1]$、$S_2$ 占 $A[top_2\cdots n]$，两栈占用格数之和 $=top_1+(n-top_2+1)$，中间空闲格数 $=top_2-top_1-1$；空闲格为 $0$ 当且仅当 $top_2=top_1+1$，即数组全满 ⟹ 与题设完全一致；
4. 用极端用例（$|S_1|=n,|S_2|=0$）反向排除 A、C、D。

## 6. 详细解答

**记号**：$top_1$ 为 $S_1$ 的栈顶下标（$S_1$ 占据自其栈底向增长方向的连续区段），$top_2$ 为 $S_2$ 的栈顶下标。

**方案 B 的验证**：取 $S_1$ 栈底 $A[1]$、向上增长，$top_1$ 初值 $0$（空栈）；$S_2$ 栈底 $A[n]$、向下增长，$top_2$ 初值 $n+1$。

- $S_1$ 已占 $A[1\cdots top_1]$，共 $top_1$ 格；$S_2$ 已占 $A[top_2\cdots n]$，共 $n-top_2+1$ 格；
- 中间未使用区为 $top_1+1\cdots top_2-1$，格数 $=(top_2-1)-(top_1+1)+1=top_2-top_1-1$；
- $S_1$ 可入栈 $\iff top_1+1<top_2$；$S_2$ 可入栈 $\iff top_2-1>top_1$ —— **两者是同一个不等式** $top_2-top_1>1$；
- 该不等式被破坏 $\iff top_2=top_1+1$，此时已用格数 $=top_1+(n-top_2+1)=top_1+n-top_1-1+1=n$，即**数组 $A$ 全满**。

于是"只有数组全满才不能入栈"成立，且任一栈单独最多可用到 $n$ 格（另一栈为空时），两栈之和恒为 $n$，不存在任何被浪费的固定预留区 ⟹ 空间利用率最高。

**排除其余方案（构造反例）**：设 $n=10$，$|S_1|=5$、$|S_2|=0$。

- A：$S_1$ 栈底 $A[1]$、$S_2$ 栈底 $A[5]$，同方向（向上）增长 ⟹ $S_1$ 最多只能用到 $A[4]$（再往上就写进 $S_2$ 的区段）。$|S_1|=5$ 时 $S_1$ 已上溢，而 $A[6\cdots10]$ 全是空格，数组并未全满 ⟹ 违反题设；
- C：$S_1$ 栈底 $A[4]$、$S_2$ 栈底 $A[5]$，反向（相互背离）增长 ⟹ $S_1$ 可用 $A[1\cdots4]$（4 格）、$S_2$ 可用 $A[5\cdots10]$（6 格），上限被锁死为 $4$ 与 $6$；$|S_1|=5$ 同样在上溢，而 $S_2$ 那 6 格完全空闲 ⟹ 违反题设；
- D：$S_1$ 栈底 $A[5]$、$S_2$ 栈底 $A[10]$，同方向（向上）增长 ⟹ $S_2$ 只有 $A[10]$ 一格可用，第 2 次入栈即上溢，而此时 $A[1\cdots4]$ 从未被使用 ⟹ 违反题设且利用率最差。

A、C、D 共同缺陷：把数组划成**固定**区段，各栈容量之和虽为 $n$，但单个栈容量上限小于 $n$，一旦两栈元素数不均衡就出现"整体有空格、局部已上溢"。

**答案**：B。

## 7. 选项分析

- A. 栈底 $A[1]$ 与 $A[\frac n2]$、同方向增长：错。$S_1$ 被夹在 $A[1\cdots\frac n2-1]$ 内，容量硬上限 $\frac n2-1$，$S_2$ 空时也借不出去；
- B. 栈底 $A[1]$ 与 $A[n]$、相对方向增长：正确。满条件 $top_1+1==top_2$ 恰为"数组全满"，两栈共享中间全部空闲区，利用率最高；
- C. 栈底 $A[\frac n2-1]$ 与 $A[\frac n2]$、反向增长：错。栈底挤在数组中部且相互背离，等价于把数组对半固定切分，容量上限各为 $\frac n2-1$ 与 $\frac n2+1$，不均衡即浪费；
- D. 栈底 $A[\frac n2]$ 与 $A[n]$、同方向增长：错。$S_2$ 只剩 $1$ 格，$A[1\cdots\frac n2-1]$ 永久空闲，利用率最低。

## 8. 考场标准答案

选 **B**。

两栈共享 $A[1\cdots n]$：令 $S_1$ 自 $A[1]$ 起向上增长（$top_1$ 初值 $0$），$S_2$ 自 $A[n]$ 起向下增长（$top_2$ 初值 $n+1$）。

```c
/* 入栈 S1 */
if (top1 + 1 == top2) return OVERFLOW;   /* 数组全满，才判上溢 */
A[++top1] = x;
/* 入栈 S2 */
if (top1 + 1 == top2) return OVERFLOW;
A[--top2] = x;
```

两栈可入栈的条件同为 $top_2-top_1>1$，即中间仍有空闲格；$top_2=top_1+1$ 时已用格数 $=top_1+(n-top_2+1)=n$，正是"数组 $A$ 全满"。任一栈最多可独占 $n$ 格，无固定预留浪费，故利用率最高。

## 9. 易错点

1. 误以为"栈底位置随便定，只要方向相反就行"——关键是**两个栈底必须钉在数组的两端**，若像 C 那样都放在中部，即使反向增长也退化成固定分区；
2. 忽略"同方向增长"的后果：同向时后一个栈的栈底就是前一个栈的硬边界（A、D），共享失去意义；
3. 把满条件写成 $top_1==top_2$：正确写法是 $top_1+1==top_2$，与循环队列"牺牲一格"（DS-2007-01 的 $front==(rear+1)\%m$）形似而含义不同——共享栈并没有牺牲格子，$n$ 格全部可用。

## 10. 一句话规律

"共享空间 + 只有整体满才禁止插入"的结构，一律把两个操作端放在数组**两端相向推进**（共享栈如此，双端堆、循环队列的"两指针夹区间"亦如此）；只要出现固定分界线，局部上溢与整体未满就必然并存。
