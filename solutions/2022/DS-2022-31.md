# DS-2022-31

## 1. 原题

**31、** 考虑序列: $mississippi$ ，请：

（1） 采用赫夫曼（ $Huffman$ ）编码算法对上述序列编码，给出相应的 $Huffman$ 树，以及每个字符的 $Huffman$ 码。

（2）一共需要多少 $bit$ 位？

## 2. 答案

### 第 (1) 问

**频次统计**（$11$ 个字母，$4$ 种字符）：

| 字符 | $m$ | $i$ | $s$ | $p$ |
|---|---|---|---|---|
| 频次（权值） | 1 | 4 | 4 | 2 |

**Huffman 树**（左分支记 $0$、右分支记 $1$）：

```
            (11)
           /    \
        s(4)    (7)
               /    \
            i(4)    (3)
                   /    \
                m(1)    p(2)
```

括号内为分支结点的权（= 子树叶子权之和）；$m,i,s,p$ 为四个叶子。

**每个字符的 Huffman 码**（一种合法答案）：

| 字符 | 频次 | 编码 | 码长 |
|---|---|---|---|
| $s$ | 4 | $0$ | 1 |
| $i$ | 4 | $10$ | 2 |
| $m$ | 1 | $110$ | 3 |
| $p$ | 2 | $111$ | 3 |

（$i$ 与 $s$ 的位次可互换，$0/1$ 也可整体对调，得到的码不同但**码长集合 $\{1,2,3,3\}$ 与总位数不变**。）

### 第 (2) 问

$$\text{总位数}=WPL=1\times 3+2\times 3+4\times 2+4\times 1=3+6+8+4=\mathbf{21}\ bit$$

（等长编码需 $\lceil\log_2 4\rceil=2$ 位/字符，共 $11\times 2=22$ 位；Huffman 编码用 $21$ 位。）

## 3. 题目分析

- 已知：一个由 $11$ 个字母组成的字符序列（串）$mississippi$，其中只含 $4$ 种不同字符；
- 目标：(1) 以各字符**出现次数为权**构造 Huffman 树并给出前缀码；(2) 求该串编码后的总比特数；
- 关键约束与依据：
  1. Huffman 算法的输入是**权值集合**，本题权值必须自己从串中清点得到——这是第 0 步，也是唯一容易出错的地方；
  2. 贪心规则：每次从当前森林中选取**根权最小的两棵树**合并，共做 $n-1=3$ 次合并，得到 $2n-1=7$ 个结点的严格二叉树（无度为 $1$ 的结点）；
  3. 频次相同的字符（$i$ 与 $s$ 都是 $4$）在合并中地位对称 ⟹ 树形与码表不唯一，但**带权路径长度 WPL 唯一**；
  4. 第 (2) 问的"一共需要多少 bit"指把整个序列（$11$ 个字符）编码后的位数之和，即 $\sum_i freq_i\times l_i=WPL$，不是树的结点数、也不是不同码字的个数；
- 命题意图：给一串文本，看会不会做"统计频次 → 建树 → 定码 → 算 WPL"这条完整流水线（DS03.04.01），并顺带考"能否把串（DS02.06.01）看成字符的有限序列并按字符计数"。

核心考点：

## 5. 解题思路

1. **先把权值做出来**：逐字符数 $m,i,s,p$ 的出现次数，并用"频次之和 $=11=$ 串长"自检；
2. **按贪心建树**：把 $\{1,2,4,4\}$ 排好序，每次取最前面两个合并，把新权插回有序序列，重复 $3$ 次到只剩一棵树。写下每一步的森林快照，可避免"取错两个"；
3. **定码**：约定左 $0$ 右 $1$，从根到叶子沿路径拼接；写完立刻用"任一码字都不是另一码字的前缀"检查前缀性质；
4. **算位数（两法互校）**：法一 $WPL=\sum w_il_i$；法二把整串按码表逐个替换成 $01$ 串再数长度。两者必须相等；
5. **合理性反查**：频次最小的字符码长必须最长（$m$ 为 $3$ 位），频次最大的码长最短（$s$ 为 $1$ 位）；若出现反向，说明建树时合并顺序取错了。

## 6. 详细解答

### 6.1 频次统计

串 $m\ i\ s\ s\ i\ s\ s\ i\ p\ p\ i$（$11$ 个字符）：

- $m$：第 $1$ 位，$1$ 次；
- $i$：第 $2,5,8,11$ 位，$4$ 次；
- $s$：第 $3,4,6,7$ 位，$4$ 次；
- $p$：第 $9,10$ 位，$2$ 次。

自检 $1+4+4+2=11$ ✓（等于串长），字符种类 $n=4$。

### 6.2 逐趟建树（森林快照）

初始森林（按权升序）：$\{m(1),\ p(2),\ i(4),\ s(4)\}$

| 趟 | 取出的两个最小根 | 合并成新结点 | 合并后森林 |
|---|---|---|---|
| 1 | $m(1)$，$p(2)$ | $u_1(3)$ | $\{u_1(3),\ i(4),\ s(4)\}$ |
| 2 | $u_1(3)$，$i(4)$ | $u_2(7)$ | $\{s(4),\ u_2(7)\}$ |
| 3 | $s(4)$，$u_2(7)$ | $u_3(11)$ | $\{u_3(11)\}$（只剩一棵树，结束） |

要点：第 2 趟取的是**新结点 $u_1(3)$ 与 $i(4)$**，而不是 $i(4)$ 与 $s(4)$——合并产生的新权必须与剩余叶子一起重新参加比较。

结点总数 $=n+(n-1)=4+3=7=2n-1$ ✓；树中每个分支结点都有两个孩子（严格二叉树）✓。

所得树即第 2 节的图：$u_3$ 的孩子为 $s$ 与 $u_2$；$u_2$ 的孩子为 $i$ 与 $u_1$；$u_1$ 的孩子为 $m$ 与 $p$。

**各叶子深度**：$l_s=1,\ l_i=2,\ l_m=3,\ l_p=3$。

### 6.3 编码与前缀性质检验

约定"向左取 $0$、向右取 $1$"，从根到叶子读取路径：

- $s$：$0$
- $i$：$1\to 0=10$
- $m$：$1\to 1\to 0=110$
- $p$：$1\to 1\to 1=111$

前缀检验：$\{0,10,110,111\}$ 中，$0$ 不是任何码的前缀之外的前缀（$10,110,111$ 均以 $1$ 开头）；$10$ 与 $110/111$ 第二位不同；$110$ 与 $111$ 第三位不同 ⟹ 互不为前缀 ✓ 可译码无歧义。

### 6.4 第 (2) 问：总位数的两种算法

**法一（WPL 公式）**：

$$WPL=\sum_{i=1}^{4} w_il_i=1\times3+4\times2+4\times1+2\times3=3+8+4+6=21$$

**法二（整串替换后数长度）**：

$$\underbrace{110}_{m}\underbrace{10}_{i}\underbrace{0}_{s}\underbrace{0}_{s}\underbrace{10}_{i}\underbrace{0}_{s}\underbrace{0}_{s}\underbrace{10}_{i}\underbrace{111}_{p}\underbrace{111}_{p}\underbrace{10}_{i}$$

长度 $=3+2+1+1+2+1+1+2+3+3+2=21$ ✓ 两法一致。

**对照（说明贪心确实最优）**：若第 2 趟错误地取 $i(4)$ 与 $s(4)$ 合并，得 $u(8)$ 再与 $u_1(3)$ 合并成 $11$，此时四个叶子深度全为 $2$，总位数 $=11\times 2=22>21$；若按字母出现先后依次两两配对，同样是 $22$ 位。可见"每趟只取当前最小的两棵"不是形式要求，而是位数最少的保证。

**对照（等长编码）**：$4$ 种字符各需 $2$ bit，$11$ 个字符共 $22$ bit；Huffman 利用频次不均衡省下 $1$ bit（本例文本短，节省比例有限；字符频次越悬殊，节省越明显）。

## 8. 考场标准答案

**(1)** 频次 $m=1,\ p=2,\ i=4,\ s=4$（合计 $11$）。

建树（每趟取两个最小权合并）：

```
第1趟  1 + 2 = 3
第2趟  3 + 4 = 7
第3趟  4 + 7 = 11
```

Huffman 树（左 0 右 1）：

```
            (11)
           /    \
        s(4)    (7)
               /    \
            i(4)    (3)
                   /    \
                m(1)    p(2)
```

编码：$s=0$，$i=10$，$m=110$，$p=111$（码长 $\{1,2,3,3\}$；$i,s$ 可互换、$0/1$ 可对调）。

**(2)** 总位数 $=WPL=1\times3+2\times3+4\times2+4\times1=21\ bit$。

## 9. 易错点

1. **频次数错**：$mississippi$ 中 $i$ 与 $s$ 各 $4$ 次、$p$ 为 $2$ 次（不是 $1$ 次）、$m$ 为 $1$ 次；数完必须用"频次和 $=11$"校验，错一个数整棵树和位数全变。
2. **合并时忘记把新结点放回集合重新比较**：第 2 趟应取 $u_1(3)$ 与 $i(4)$，取 $i(4)$ 与 $s(4)$ 会得到深度全为 $2$ 的非最优树（$22$ 位），这是本题最容易踩的坑。
3. **把第 (2) 问理解成"编码需要几位"或"树有多少结点"**：题问的是**整个序列**编码后的总比特数，等于 WPL；$7$ 个结点、$4$ 个码长之类都不是答案。
4. **码表与树形不自洽**：写了树就要按树读码，且必须声明"左 $0$ 右 $1$"的约定；若只给码表不给树，或码表不满足前缀性质，都得不到第 (1) 问的分数。
5. **误以为编码答案唯一**：$i/s$ 交换、左右子树对调、$0/1$ 反指派都会改变码字，但 $WPL$ 与码长分布不变——阅卷看的是"树形正确 + 码与树一致 + 位数 $21$"。

## 10. 一句话规律

给文本求 Huffman 编码：**先统计频次当权值，再"每趟取当前最小两棵合并并把新权送回集合"，$n$ 个字符必得 $2n-1$ 个结点的严格二叉树；编码总位数就是 WPL，可用"逐字符替换后数长度"复算。**
