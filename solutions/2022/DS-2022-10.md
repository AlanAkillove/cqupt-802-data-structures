# DS-2022-10

## 1. 原题

用于求无向图的所有连通分量的算法是（）。

A. 广度优先遍历

B. 拓扑排序

C. 求最短路径

D. 求关键路径

## 2. 答案

**A**（广度优先遍历；深度优先遍历同样可以，但未在选项中列出）。

## 3. 题目分析

- 已知：一个无向图（可能不连通），"连通分量"指极大连通子图；
- 目标：选出能够**求出所有连通分量**的算法；
- 关键约束：
  1. 求连通分量需要的是"遍历"能力——从某个顶点出发能且仅能到达它所在连通分量的全部顶点；
  2. 对每个尚未访问的顶点重新发起一次遍历，**发起次数就等于连通分量的个数**，每次访问到的顶点集合就是一个连通分量；
  3. DFS 与 BFS 都满足这一性质（二者只是访问次序不同，可达顶点集合相同）；
  4. 拓扑排序只对有向无环图（AOV 网）有意义，输出的是一个顶点线性序列，不回答"哪些顶点互相连通"；最短路径、关键路径同样是"有向/带权"或"单源"问题，与"所有连通分量"这一目标不对应；
- 命题意图：考"图的遍历是图的连通性分析工具"这一本质（DS04.03.02/DS04.03.01），并用三个"名字像算法、用途不对口"的选项测学生是否真懂各算法的输入前提与输出对象。

## 4. 核心考点

核心考点：
DS04.03.02 广度优先搜索——BFS 从起点出发访问到的顶点集恰为该起点所在的连通分量；教材"求无向图连通分量"的直接应用

解释：选项给出的具体算法是 BFS，故主标签取 DS04.03.02（taxonomy 中该节点的名称已含"序列、最短路径树含义"，其"遍历即连通性分析"的用途与 DS04.03.01 并列）；

辅助考点：
DS04.03.01 深度优先搜索——DFS 版本同样是求连通分量的标准做法（教材的遍历主过程就是“对每个尚未访问的顶点发起一次遍历”，并在发起处计数），二者构成“同一功能、两种次序”的比较
DS04.01 图的基本概念——"连通子图""极大连通子图（连通分量）"的定义是判定"哪个算法能求出它"的准绳

## 5. 解题思路

1. 先把"求所有连通分量"翻译成操作要求：需要一个能把"与起点连通的所有顶点"一次收集齐的过程，并对剩余未收集顶点重复该过程；
2. 检查遍历算法：BFS 的可达集 $=$ 连通分量（第 6 节 (1) 双向证明），DFS 同理 ⟹ 遍历类算法可用；
3. 检查另三个：拓扑排序前提是有向无环图且输出线性序；最短路径输出距离/路径，且在非连通图上部分顶点距离为 $\infty$，它不"收集"分量；关键路径前提是 AOE 网（有向、带权、单源单汇）⟹ 都不适用；
4. 结论：唯一正确选项 A。

## 6. 详细解答

### （1）"一次遍历恰好走遍一个连通分量"的证明

设无向图 $G=(V,E)$，$S$ 是 $G$ 的一个连通分量，$s\in S$。

- **$\subseteq$（遍历不越出分量）**：BFS 从 $s$ 出发，每次只沿一条边把邻接顶点加入队列，故被访问的每个顶点都存在一条自 $s$ 出发的路径。若某访问顶点 $v\notin S$，则 $s$ 与 $v$ 连通，与"极大连通子图"矛盾（$S\cup\{v\}$ 及其间路径仍连通，$S$ 不极大）。故所有访问顶点都属于 $S$；
- **$\supseteq$（遍历不漏分量内顶点）**：任取 $v\in S$，由连通性，$S$ 中存在路径 $s=u_0,u_1,\dots,u_k=v$。BFS 按"到起点的边数（层数）"递增扩展：$u_0$ 入队并被访问；设 $u_0,\dots,u_{i}$ 均被访问，则访问 $u_i$ 时其邻接点 $u_{i+1}$ 若未访问必被入队，故也会被访问。归纳得 $v$ 被访问 ✓

于是"从 $s$ 出发的一次 BFS 所得顶点集 $=S$"。对 $V$ 中仍未访问的顶点再发起一次 BFS，又得到另一个连通分量；重复直到所有顶点访问完毕，**发起次数 $=$ 连通分量个数**，各次访问集即为全部分量。

（把"按层扩展"换成"一路走到底再回溯"就是 DFS，上述两条包含关系同样成立——可达集与遍历次序无关，故 DFS 也适用，只是选项中未列。）

### （2）伪代码（教材遍历主过程的计数版本）

```c
/* visited[] 全局初值 0；G 为无向图，以邻接表或邻接矩阵存储 */
int CompCount = 0;
void BFSComp(void)                 /* 求无向图全部连通分量 */
{
    int v;
    for (v = 0; v < G.vexnum; v++)         /* 对每个顶点检查是否已归属某分量 */
        if (!visited[v]) {
            CompCount++;                   /* 每发起一次遍历即发现一个新分量 */
            BFS(v);                        /* 本次遍历访问到的顶点集就是第 CompCount 个连通分量 */
        }
}
```

关键点：`if (!visited[v])` 这一句成立当且仅当 $v$ 与前面所有已访问顶点不连通，故它必属于一个新的连通分量。

### （3）其余三个选项为何不适用

- **拓扑排序（B）**：定义在**有向无环图（AOV 网）**上，输出顶点的线性序使所有弧从前指向后；无向图（尤其含环时）根本没有拓扑序可言，其过程也不产生"顶点集合的划分"；
- **求最短路径（C）**：Dijkstra/Floyd 输出的是距离与路径。虽然无权图的 BFS 最短路径与遍历同源，但"求最短路径"作为算法目标并不遍历全图各分量（单源版本只在起点所在分量内有有限距离，其它分量距离为 $\infty$，且算法不会自动对每个分量分别发起），不能回答"有几个分量、各含哪些顶点"；
- **求关键路径（D）**：定义在 **AOE 网**（有向、带权、唯一源点与汇点）上，输出的是边（活动）序列与时间余量，与无向图的连通性无关。

**答案：A**

## 7. 选项分析

- A（广度优先遍历）：**正确**。按层扩展能收集起点所在连通分量的全部顶点，对未访问顶点反复发起即得所有分量；
- B（拓扑排序）：错。适用对象是有向无环图，输出线性序列，不划分顶点集；误选原因：把"图的算法"笼统当作"都能分析连通性"；
- C（求最短路径）：错。单源最短路径只在起点所在分量内有效，且算法目标是距离不是集合划分；误选原因：把"无权图 BFS 可求最短路径"这一反向关系混为一谈；
- D（求关键路径）：错。AOE 网专用，有向带权，且要求源点汇点唯一；无向图的连通分量概念与之无关。

## 8. 考场标准答案

求无向图的所有连通分量：以**遍历**为工具——`for` 每个未访问顶点发起一次 BFS（或 DFS），每次访问到的顶点集即一个连通分量，发起次数即分量个数。（可达集 $=$ 极大连通子图的顶点集，故遍历可解。）
拓扑排序用于 AOV 网、关键路径用于 AOE 网、最短路径求距离，均不用于求连通分量。选 **A**。

## 9. 易错点

1. **以为"只有 DFS 能求连通分量"**：DFS、BFS 都可以，判据是"遍历的可达集等于连通分量"，与访问次序无关；本题只给了 BFS，故选 A，不要因为"教材例题用 DFS"就判无正确选项；
2. **把最短路径与遍历混为一谈**：无权图单源最短路径确由 BFS 实现，但"求最短路径"这一算法目标不包含"对每个未访问顶点重新发起"的循环，因而不产出全部分量；
3. **忽略算法的输入前提**：拓扑排序要求有向无环、关键路径要求 AOE 网，题面是"无向图"，前提即不符；
4. **计数细节**：连通分量个数等于**遍历发起次数**而不是访问次数；若图已连通，则只发起 1 次。

## 10. 一句话规律

"判断图的连通性/求分量/求生成森林"一律用遍历（DFS 或 BFS），"排序类"与"路径类"算法各以其图种（有向无环、AOE 网）和输出对象区分用途——先看题面的图是有向还是无向，再看问的是"集合"还是"序"还是"距离"。
