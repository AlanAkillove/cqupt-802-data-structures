# DS-2022-33

## 1. 原题

**33、** 设计一个算法，将一个用循环链表表示的稀疏多项式分解成两个多项式，使这两个多项式中各自仅含奇次项或偶次项，并要求利用原链表中的结点空间构成这两个链表。要求：

（1）描述算法的基本设计思想；

（2）根据设计思想，采用 $C$ 或 $C++$ 语言描述算法，关键之处给出注释；

（3）说明所设计算法的时间复杂度和空间复杂度。

提示：其中稀疏多项式采用的循环链表存储结构 $LinkedPoly$ 定义为

```c
typedef struct PolyNode{
    float coef; //单项式的系数
    int exp; //单项式的指数
    struct PolyNode *next;
}PolyNode;

typedef PolyNode* LinkedPoly;
```

算法描述，只需要给出如何将循环链表 $L$ 分成满足要求的两个循环链表的操作，即完善下述函数：

```c
void Divide (LinkedPoly L){
    ......
}
```

## 2. 答案

**（1）设计思想**：在原链表的结点集合上"一次遍历、按指数奇偶分挂"。取原头结点 $L$ 兼作**偶次项链**的头结点，另新建**一个**头结点 $O$ 作奇次项链的头；用两个尾指针 $pe$、$po$ 分别指向两链当前的最后一个结点。工作指针 $p$ 从首元结点 $L\to next$ 出发，每步先用 $q$ 保存 $p\to next$，再把 $p$ 摘下来按 $p\to exp$ 的奇偶接到 $pe$ 或 $po$ 之后并前移相应尾指针，最后令 $p=q$；当 $p$ 回到 $L$ 时扫描结束，把 $pe\to next$ 置为 $L$、$po\to next$ 置为 $O$，两条链各自成环。全过程只做指针改写，不申请也不释放数据结点，故 $n$ 个数据结点全部复用，且两链中项的相对次序与原多项式一致。

**（2）代码**：见第 8 节（含"补输出参数"与"改返回类型"两种签名写法）。

**（3）复杂度**：设原多项式有 $n$ 个项结点，时间复杂度 $O(n)$（每结点仅被访问一次、每次做常数次指针操作）；空间复杂度 $O(1)$（只新增 $1$ 个头结点与 $3\sim4$ 个指针变量，未复制任何数据结点）。

## 3. 题目分析

- 输入：一条**带头结点的循环链表** $L$，每个数据结点存一项（系数 $coef$、指数 $exp$），尾结点 $next$ 指回 $L$；
- 输出：两条循环链表——一条只含偶次项、一条只含奇次项，且**所有数据结点都是原来那批结点**；
- 关键约束：
  1. **"利用原链表中的结点空间"**是硬要求：不允许 `malloc` 新的数据结点再复制 $coef/exp$，只能改 `next` 指针；也因此**不需要**释放任何结点；
  2. 循环链表没有 `NULL` 作为扫描终点，终止条件必须写成"指针回到头结点"（`p != L` 或 `do…while(p != L)`），摘链时若不用 $q$ 先保存后继就会**断链**；
  3. 拆完必须**分别收尾成环**：两条链各有一个环闭动作，漏掉任何一条都会得到"尾结点 `next` 指向另一条链的中间结点"的错误结构（这是本题最常见的失分点）；
  4. 指数为 $0$ 的常数项属**偶次项**（$0\bmod 2=0$）；稀疏多项式可能含**负指数**，而 C 语言中 `-3 % 2 == -1`，故判奇要用 `exp % 2 != 0`，不能写 `exp % 2 == 1`；
  5. 题给签名 `void Divide(LinkedPoly L)` 形参只有一个，**无法把两条链的头同时回传**——必须对签名作最小补充（增加输出参数，或把返回类型改为 `LinkedPoly` 并让 $L$ 带回其中一条链），第 8 节两种写法都给出，第 12 节说明理由；
- 命题意图：DS01.02.03 的循环链表指针操作（摘挂、成环、终止条件）+ DS01.03 的多项式应用背景，考"原地拆分"这一链式存储的经典操作范式。

## 4. 核心考点

核心考点：
DS01.02.03 链式存储：双向链表与循环链表——循环链表的扫描终止条件、原地摘挂结点、尾指针闭合成环；"复用原结点"意味着只动指针不动数据

辅助考点：

DS01.02.02 链式存储：单链表——本算法用到的"前插/尾插 + 保存后继"技巧与单链表完全一致，两条链在闭合之前就是两条普通的尾插单链表

解释：题目不涉及顺序表，也不涉及双向链表的 `prior` 域，核心全在"循环 + 原地拆分"，故主考点唯一。

## 5. 解题思路

1. **先明确"拆"的语义**：不是复制，而是把原来的一条环"剪成两条环"。想象把结点按颜色（奇/偶）重新串起来，结点本身不动；
2. **决定用什么当两条链的头**：原头结点 $L$ 反正要保留，直接把它给偶链，能省一个结点也更贴合"利用原结点空间"；奇链必须另起一个头结点 $O$（否则它的头无法与数据结点区分）——于是"附加空间 $=1$ 个结点"是这道题的自然下界；
3. **想清楚扫描顺序**：单链表只能往后走 ⟹ 一趟从头到尾顺序处理即可，无需回溯；每处理一个结点要"先保存后继再摘链"，这是所有链表原地操作的固定套路；
4. **用尾插法保持原次序**：用尾指针 $pe/po$（而不是头插）才能保证分解后的多项式仍按原链表中的项次序排列（若原表按指数升序排列，拆分后两链仍各自升序，可继续用于相加等运算）；
5. **收尾**：扫描结束时 $pe、po$ 停在两条链的最后一个结点上，令它们分别指回 $L$ 和 $O$；
6. **最后过一遍边界清单**：空表、只有一个结点、全奇、全偶、含 $exp=0$、含负指数——每个都在第 6.4 节验证，再确认没有 `NULL` 出现在任何"应当成环"的位置。

## 6. 详细解答

### 6.1 存储结构约定

采用教材对多项式的常规约定：$L$ 为**头结点**（不存数据），数据结点 $a_1,\dots,a_n$ 依次链接，且 $a_n\to next=L$，构成一个环：

```
L → a1 → a2 → a3 → … → an → (回到 L)
```

（若原表是"无头结点的循环链表"，见 6.5 的变体说明。）

### 6.2 算法不变量与正确性论证

循环不变量（每次进入循环体时对结点 $p$ 处理完毕）：

- **I1（划分正确）**：$pe$ 所在的链（自 $L$ 起）中所有结点 $exp$ 为偶，$po$ 所在链中所有结点 $exp$ 为奇；
- **I2（保序）**：两链中的结点序列分别是"已扫描过的偶次项/奇次项"在原表中的先后子序列（尾插保证）；
- **I3（不丢不重）**：已扫描的结点全部且仅挂在两链之一上，未扫描结点仍由 $q$ 及其后继串成一条链，且 $q$ 的下一个待处理者可达；
- **I4（结点数守恒）**：两链数据结点总数 $=$ 已扫描结点总数，扫描结束时 $=n$，即全部原结点被复用。

由 I3 可知"必须先用 $q$ 保存 $p\to next$"——否则执行 `pe->next = p` 一类的改写后，$p$ 的原后继就再也找不到了（这是原地拆分与复制式拆分的唯一实质差别）。

循环结束时 $p=L$，全部 $n$ 个结点处理完毕；此时 $pe,po$ 分别是两链的尾结点，执行 $pe\to next=L$、$po\to next=O$ 后两条链都满足循环链表定义。I1 给出"各自仅含奇次项或偶次项"，I4 给出"利用原结点空间"，故算法满足题面全部要求。

### 6.3 逐行代码走查

以自造示例（**非题面数据**，仅为演示）$L$ 表示 $3-4x^2+x^4+2x^6$ 与 $2x+5x^3+7x^5+9x^7$ 混排的原多项式，按原表次序取

$$8\text{ 项：}(3,0),(2,1),(-4,2),(5,3),(1,4),(7,5),(2,6),(9,7)$$

| 步 | $p$（$exp$） | 奇偶 | 动作 | 偶链（$L$ 起） | 奇链（$O$ 起） |
|---|---|---|---|---|---|
| 初 | — | — | $pe=L,\ po=O,\ O\to next=O$ | $L$（空环） | $O$（空环） |
| 1 | $exp=0$ | 偶 | 摘挂到 $pe$ 后 | $L\to(3,0)$ | $O$ |
| 2 | $exp=1$ | 奇 | 摘挂到 $po$ 后 | $L\to(3,0)$ | $O\to(2,1)$ |
| 3 | $exp=2$ | 偶 | 同上 | $L\to(3,0)\to(-4,2)$ | $O\to(2,1)$ |
| 4 | $exp=3$ | 奇 | 同上 | $L\to(3,0)\to(-4,2)$ | $O\to(2,1)\to(5,3)$ |
| 5 | $exp=4$ | 偶 | 同上 | $\dots\to(1,4)$ | 同上 |
| 6 | $exp=5$ | 奇 | 同上 | $\dots\to(1,4)$ | $\dots\to(7,5)$ |
| 7 | $exp=6$ | 偶 | 同上 | $\dots\to(2,6)$ | 同上 |
| 8 | $exp=7$ | 奇 | 同上 | $\dots\to(2,6)$ | $\dots\to(9,7)$ |
| 收尾 | $p=L$ | — | $pe\to next=L,\ po\to next=O$ | 成环 | 成环 |

结果：偶次项多项式 $3-4x^2+x^4+2x^6$，奇次项多项式 $2x+5x^3+7x^5+9x^7$；$8$ 个结点全部复用，两链各含 $4$ 个结点，$4+4=8$ ✓ 结点数守恒。

### 6.4 边界情况

| 情况 | 执行结果 | 是否正确 |
|---|---|---|
| 空表（$L\to next=L$） | 循环体一次不执行，$pe=po$ 的初值即两链头，收尾后 $L\to next=L$、$O\to next=O$，得两条空循环链表 | ✓（须保证收尾语句仍执行，故不能把闭合写在循环体内） |
| 只有 $1$ 个结点 | 该结点进偶链或奇链，另一链为空环 | ✓ |
| 全为偶次项 | $po$ 始终 $=O$，收尾 $O\to next=O$ 得空奇链 | ✓ |
| 全为奇次项 | $pe$ 始终 $=L$，收尾 $L\to next=L$ 得空偶链 | ✓ |
| 含 $exp=0$ 的常数项 | $0\%2==0$ ⟹ 归入偶链 | ✓（数学上常数项即 $0$ 次偶次项） |
| 含负指数（如 $exp=-3$） | C 语言 $-3\%2==-1$，用 `!= 0` 判奇则正确归入奇链；若写 `== 1` 会被误判为偶 | ✓（须用 `!= 0` 口径） |
| $L==NULL$（连头结点都没有） | 无法拆分，直接返回（或按题意视为非法输入） | ✓ 需在函数开头判空 |

### 6.5 两点补充说明

1. **若无头结点**（$L$ 即首元结点）：拆分时偶链的头指针初值为空，第一个偶次结点要特判"作为偶链首结点"；为免特判，考场可先"造一个头结点"再套用 6.2 的代码，最后返回 $L'=Pe\to next$。本题提示中 $L$ 用作循环链表的遍历终止标志，按带头结点解释最自然。
2. **保序性**：若改用头插（把结点插到 $pe\to next$ 位置之前），两链会各自逆序；题目未要求逆序，且原多项式通常按指数升序排列，逆序会破坏后续相加/相乘运算的前提，故采用尾插。

## 8. 考场标准答案

### （1）基本设计思想

一趟扫描原循环链表，按结点指数的奇偶把结点分别**尾插**到两条新链上：偶次项链复用原头结点 $L$，奇次项链新建一个头结点 $O$；每处理一个结点前先用指针 $q$ 保存其后继，处理完令 $p=q$；当 $p$ 回到 $L$ 时扫描结束，再让两条链的尾结点分别指回 $L$ 和 $O$ 完成闭合。整个过程只改指针、不复制数据结点，故原结点空间全部被利用，附加空间仅 $1$ 个头结点。

### （2）代码（写法一：补两个输出参数，推荐）

```c
typedef struct PolyNode{
    float coef;          // 单项式的系数
    int   exp;           // 单项式的指数
    struct PolyNode *next;
} PolyNode;
typedef PolyNode* LinkedPoly;

/* 偶次项链以原头结点 L 为头，奇次项链以新建头结点 *Odd 为头 */
void Divide(LinkedPoly L, LinkedPoly *Even, LinkedPoly *Odd)
{
    if (L == NULL) return;                       /* 非法/不存在，直接返回 */

    LinkedPoly O  = (LinkedPoly)malloc(sizeof(PolyNode)); /* 只为奇链新建 1 个头结点 */
    PolyNode  *pe = L,                            /* pe：偶链尾指针 */
              *po = O,                            /* po：奇链尾指针 */
              *p  = L->next, *q;                  /* p：工作指针，q：保存后继 */

    O->next = O;                                 /* 奇链先置为空循环链表 */

    while (p != L) {                             /* 循环链表的终止条件：回到头结点 */
        q = p->next;                             /* 关键①：先保存后继，否则摘链后断链 */

        if (p->exp % 2 != 0) {                   /* 关键②：用 !=0 判奇，兼容负指数；exp=0 归偶 */
            po->next = p;  po = p;               /* 尾插到奇链，保序 */
        } else {
            pe->next = p;  pe = p;               /* 尾插到偶链，保序 */
        }

        p = q;                                   /* 关键③：用事先保存的后继前进 */
    }

    pe->next = L;                                /* 关键④：偶链闭合（空链时 pe==L，仍成立） */
    po->next = O;                                /* 关键⑤：奇链闭合（空链时 po==O，仍成立） */

    *Even = L;   *Odd = O;                       /* 偶链用原头结点带回，奇链用新头结点带回 */
}
```

### （2）代码（写法二：严格保留题给的单参数形态，只把返回类型改为 `LinkedPoly`）

```c
/* 题给签名为 void Divide(LinkedPoly L)，但一个形参无法同时带回两条链的头；
   此处令 L 带回偶次项链（复用原头结点），返回值带回奇次项链的头结点 */
LinkedPoly Divide(LinkedPoly L)
{
    LinkedPoly O = (LinkedPoly)malloc(sizeof(PolyNode));
    PolyNode *pe = L, *po = O, *p = L->next, *q;
    O->next = O;
    while (p != L) {
        q = p->next;
        if (p->exp % 2 != 0) { po->next = p; po = p; }
        else                 { pe->next = p; pe = p; }
        p = q;
    }
    pe->next = L;  po->next = O;
    return O;                                    /* 调用形如 Odd = Divide(L); 偶链即 L */
}
```

调用示例（写法一）：

```c
LinkedPoly Even, Odd;
Divide(L, &Even, &Odd);      /* Even 即原 L；Odd 为新建头结点；两表均为循环链表 */
```

### （3）复杂度

设原循环链表含 $n$ 个数据结点：

- **时间复杂度 $O(n)$**：单层循环，每个结点恰好处理一次，循环体内只有常数次指针改写与一次取模运算；
- **空间复杂度 $O(1)$**：仅新增 $1$ 个头结点与 $pe,po,p,q$ 等几个指针变量，没有递归、没有辅助数组，$n$ 个数据结点全部原地复用（满足"利用原链表中的结点空间"）。

## 9. 易错点

1. **忘了先用 $q$ 保存后继**：`pe->next = p` 之类的改写会覆盖 $p$ 所在链路的后继信息，导致后续结点全部丢失——原地拆分与"新建结点复制"最大的区别就在这里。
2. **收尾时漏掉一条链的闭合**：只写 `pe->next = L` 而忘 `po->next = O`，奇链尾结点仍指向原表中它的后继（一个偶链结点或 $L$），两链被"串"在一起，两条都不是循环链表；阅卷按结构错误重扣。
3. **终止条件写成 `p != NULL`**：循环链表没有 `NULL` 尾，会死循环（或提前越界）。若用 `do…while` 则要单独处理空表，`while(p != L)` 从 $L\to next$ 起最省事。
4. **判奇用 `exp % 2 == 1`**：负指数在 C 中取模结果为 $-1$，会被错分进偶链；应统一写 `exp % 2 != 0`。另外 $exp=0$ 的常数项必须归偶链。
5. **用 `malloc` 复制新结点**：违反"利用原链表中的结点空间"这一硬性要求，即使结果正确也要扣分；同理也不该 `free` 任何结点。
6. **用头插导致逆序**：拆分后两链与原表次序相反，破坏"按指数升序"的隐含约定，影响后续多项式运算。
7. **忽视空表/全奇/全偶**：把"取第一个偶结点作为偶链头"之类的特判写漏，会在 $n=0$ 或某类项不存在时访问空指针；本解法用"哨兵头结点 + 尾指针"使这些情况自动退化，无需特判。

## 10. 一句话规律

链表"原地拆分成多条表"的通用套路是：**每条结果链配一个哨兵头结点 + 一个尾指针，扫描时"先存后继、再摘挂、后前进"，结束时逐条闭合成环（单链表则置 `NULL`）**——空间 $O(1)$、时间 $O(n)$，且天然处理空链与保序。
