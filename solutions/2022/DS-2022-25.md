# DS-2022-25

## 1. 原题

表达式 `A/B+D$E+F/H` 中，运算符的优先级由高到低依次为 `+,/,$` ，均右结合，则相应的后缀式是____________________。

（题面转录说明：`$` 是本题自定义的运算符，不是数学公式定界符；优先级列表 `+,/,$` 的含义是 **`+` 最高、`/` 次之、`$` 最低**。）

## 2. 答案

**`ABD+/EF+H/$`**

即后缀式（逆波兰式）为：$A\ B\ D\ +\ /\ E\ F\ +\ H\ /\ \$$。

## 3. 题目分析

- 已知：中缀表达式 `A/B+D$E+F/H`；三种运算符的优先级由高到低为 `+` > `/` > `$`；三种运算符**均为右结合**；
- 目标：写出等价的后缀式（运算符紧跟在其两个运算对象之后）；
- 关键约束：
  1. 优先级与通常的算术约定**相反**——本题 `+` 最高、`$` 最低，不能按"先乘除后加减"的直觉处理；
  2. 右结合只在**同一优先级出现两个及以上相邻运算符**时才起作用；本题 `+`、`/` 各出现两次，但都被更低优先级的 `$` 隔开，不构成同级串联，故"右结合"这一条件不改变本表达式的结构（属于命题者设置的干扰信息）；
  3. 后缀式中运算对象相对次序不变，运算符次序由**运算的先后次序**决定。
- 命题意图：考 DS02.07"栈的应用——表达式求值/形式转换"中的算符优先级语义：能否按给定的（非常规）优先级正确恢复表达式树，再由树得到后缀式。

## 4. 核心考点

核心考点：
DS02.07 栈、队列和数组的应用（表达式求值：中缀/后缀/前缀三种形式与运算符优先级的对应关系）

辅助考点：
DS02.01 栈和队列的基本概念——算符优先法用栈暂存运算符，"栈顶运算符优先级是否高于当前运算符"决定弹出还是压入；
DS02.06.01 串的定义——最终答案本身是一个字符序列，书写时运算对象与运算符的排列顺序即为后缀串的内容

解释：本题不要求写程序，但要求会**手工执行**教材中"表达式转换/求值"所用的那套优先级规则，因此主归 DS02.07；转换过程的机制是栈，故辅助 DS02.01。

## 5. 解题思路

1. **先还原运算次序**：把优先级列表当成"谁先算"的清单——`+` 最先算、`/` 第二、`$` 最后算；
2. 用"最低优先级的运算符决定根"这一递归观点切分：`$` 最低且只有一个 ⟹ 它是整棵表达式树的根，左子树由 `A/B+D` 构成、右子树由 `E+F/H` 构成；
3. 子式内再按同一规则切分：`A/B+D` 中 `+` 高于 `/` ⟹ 先算 `B+D`，故该子式是 $A/(B+D)$；`E+F/H` 中 `+` 高于 `/` ⟹ 先算 `E+F`，故该子式是 $(E+F)/H$；
4. 得到完全加括号形式 $((A/(B+D))\ \$(\ (E+F)/H))$，**按"左子树→右子树→根"后序遍历**即得后缀式；
5. 用第二套方法（教材的算符优先法：从左到右扫描，运算对象直接输出、运算符按优先级压栈/出栈）独立再做一遍，两法结果一致才填。

## 6. 详细解答

### 方法一：按优先级递归加括号（表达式树 + 后序遍历）

优先级：$+ : 3,\quad / : 2,\quad \$ : 1$（数值越大越先算）。

**第 1 步：找整棵表达式的最外层（最低优先级）运算符。**
`A/B+D$E+F/H` 中优先级最低的是 `$`（第 5 个字符），它把表达式分成两段：

- 左段 $L_1=$ `A/B+D`
- 右段 $R_1=$ `E+F/H`

**第 2 步：解析左段 `A/B+D`。** 其中含 `/`（级 2）与 `+`（级 3）。`+` 优先级更高 ⟹ `+` 先结合，其两个运算对象是紧邻的 `B` 与 `D`：

$$A/B+D \;=\; A/(B+D)$$

（注意：不能读成 $(A/B)+D$——那要求 `/` 比 `+` 先算，与题设优先级相反。）

**第 3 步：解析右段 `E+F/H`。** 含 `+`（级 3）与 `/`（级 2）。`+` 先算 ⟹ 先结合 `E` 与 `F`，再与 `/` 结合：

$$E+F/H \;=\; (E+F)/H$$

（`/` 是右结合，但此处 `/` 的左运算对象 $(E+F)$、右运算对象 $H$ 都已由优先级确定，右结合无额外作用。）

**第 4 步：合成完全加括号式。**

$$\Big(A/(B+D)\Big)\ \$\ \Big((E+F)/H\Big)$$

表达式树（缩进式，根为 `$`，每行的子运算符在下层）：

```
$                          ← 根：最后算的运算符
|-- /                      ← 左子式 A/(B+D)
|   |-- A
|   |-- +
|       |-- B
|       |-- D
|-- /                      ← 右子式 (E+F)/H
    |-- +
    |   |-- E
    |   |-- F
    |-- H
```

**第 5 步：后序遍历（左子树、右子树、根）读出的运算符序列即后缀式。**
左子树 `/(A,+(B,D))` → `A B D + /`；右子树 `/(+(E,F),H)` → `E F + H /`；最后跟根 `$`：

$$\text{后缀式} = A\;B\;D\;+\;/\;E\;F\;+\;/\;\$ \quad\Longrightarrow\quad \texttt{ABD+/EF+H/\$}$$

### 方法二：算符优先法（教材"栈求表达式"的手工模拟）

规则：运算对象直接输出；遇运算符时，**栈顶运算符优先级严格高于当前运算符**则弹出输出（右结合故取"严格高于"，等于时不弹出），否则压栈；扫描结束依次弹空。

| 扫描字符 | 动作 | 输出串 | 栈（底→顶） |
|---|---|---|---|
| `A` | 对象直接输出 | `A` | 空 |
| `/` | 栈空，压入 | `A` | `/` |
| `B` | 输出 | `A B` | `/` |
| `+` | 栈顶 `/`(2) 不高于 `+`(3)，压入 | `A B` | `/ +` |
| `D` | 输出 | `A B D` | `/ +` |
| `$` | 栈顶 `+`(3)>1 ⟹ 弹出；再 `/`(2)>1 ⟹ 弹出；栈空后压入 `$` | `A B D + /` | `$` |
| `E` | 输出 | `A B D + / E` | `$` |
| `+` | 栈顶 `$`(1) 不高于 3，压入 | `A B D + / E` | `$ +` |
| `F` | 输出 | `A B D + / E F` | `$ +` |
| `/` | 栈顶 `+`(3)>2 ⟹ 弹出；栈顶 `$`(1) 不高于 2，压入 `/` | `A B D + / E F +` | `$ /` |
| `H` | 输出 | `A B D + / E F + H` | `$ /` |
| 结束 | 弹出 `/`、`$` | `A B D + / E F + H / $` | 空 |

两法结果完全一致：**`ABD+/EF+H/$`** ✓

### 反向验证（把后缀式再算回中缀）

对 `ABD+/EF+H/$` 从左到右扫描，遇运算符就取其前面两个"完整子式"加括号：
`A B D +` → $A/(B+D)$；继续 `E F +` → $(E+F)$，遇 `/` → $((E+F)/H)$；遇最后的 `$` → $\big(A/(B+D)\big)\ \$\ \big((E+F)/H\big)$，去掉多余括号即 `A/B+D$E+F/H` 在题设优先级下的读法 ✓

## 8. 考场标准答案

```
ABD+/EF+H/$
```

推导要点（卷面可写三行）：
① `$` 优先级最低 ⟹ 根：`A/B+D` $ `E+F/H`；
② `+` 优先级最高 ⟹ 左段 $A/(B+D)$、右段 $(E+F)/H$；
③ 后序读树：$A\,B\,D\,+\,/\;E\,F\,+\,/\;\$$。

## 9. 易错点

1. **按算术习惯想当然**：把 `/` 当作比 `+` 优先，得到 `AB/CD+*…` 一类的错误结构；本题明确"由高到低为 `+,/,$`"，`+` 才是最先算的；
2. **误以为"右结合"必须用上**：右结合只影响同级运算符串联（如 `A/B/C` 在右结合下是 $A/(B/C)$）。本题 `+` 与 `/` 各出现两次但互不相邻（被 `$` 隔断），结合性不改变结果；若把表达式误读成 `A/B+D$E+F/H` 中 `+`、`/` 同级，才会出现结合性歧义；
3. **`$` 的位置写成前缀/中缀**：后缀式中运算符必须出现在它的两个运算对象**之后**，末位一定是 `$`（根运算符最后输出）；
4. **左右子式顺序颠倒**：后缀式保持运算对象原次序 `A B D E F H`，若写成 `A B D + / E F H + / $` 就把右段的 `+` 位置放错（对应 $(E+F)/H$ 的合法后缀只能是 `EF+H/`）；
5. **漏掉 `/` 的两次出现**：原式有两个 `/`，后缀式中也必须恰好有两个 `/`，可用"运算符个数与种类不变"作快速自检。

## 10. 一句话规律

中缀转后缀先做一件事——**按题给优先级把表达式还原成完全加括号的形式（等价于画表达式树）**，然后后序遍历输出；优先级列表方向（"由高到低"还是"由低到高"）必须第一个确认，结合性只在同级运算符相邻时才起作用。
