# DS-2022-22

## 1. 原题

对于长度为 $18$ 的有序顺序表，若采用折半查找，则查找第 $15$ 个元素的查找次数为____________________。

## 2. 答案

**$4$** 次（比较路径为 $A[9]\to A[14]\to A[16]\to A[15]$，即第 $15$ 号元素在折半查找判定树中位于第 $4$ 层）。

口径说明：按教材 `mid = (low + high) / 2`（整数除法，即向下取整）计算。若改用向上取整 `mid = ⌈(low+high)/2⌉`，同一题面会得到 $2$ 次（路径 $A[10]\to A[15]$）——这是本题唯一依赖约定的地方，详见第 9、12 节。

## 3. 题目分析

- 已知：有序顺序表长度 $n=18$（下标按教材记 $1\sim18$）；查找对象是**表中第 $15$ 个元素**（即值为 $A[15]$ 的关键码，一定存在，属查找成功）；查找方法为折半（二分）查找；
- 目标：求查找该元素时的**比较次数**（"查找次数"在本课程内即关键字比较次数，一次 `mid` 位置上的比较计 $1$ 次）；
- 关键约束：
  1. 折半查找的区间是闭区间 $[low,high]$，每步 $mid=\lfloor (low+high)/2\rfloor$，比较后一半收缩为 $[low,mid-1]$ 或 $[mid+1,high]$，$low>high$ 时终止；
  2. 比较次数等于该元素在**判定树**中的层次——本题因此有两种等价做法：模拟区间收缩，或画判定树数层次；
  3. $n=18$ 的判定树各层结点数为 $1,2,4,8,3$（前四层共 $15$ 个，第 $5$ 层剩 $3$ 个），树高 $5=\lfloor\log_2 18\rfloor+1$；
  4. 本题问的是**单个指定元素**的次数，不是全表平均（那是本卷第 14 题的问法），因此取中口径会影响结果，必须写明约定；
  5. 下标从 $1$ 起还是从 $0$ 起**不影响**比较次数（区间长度与收缩结构同构），可用来自查是否算错；
- 命题意图：考 DS05.04 的"折半查找过程 ⟷ 判定树路径"这一对应，检验学生能否真正逐步收缩区间并计数，而不是套用"最多比较 $\lfloor\log_2 n\rfloor+1$ 次"这一上界结论（$18$ 的上界是 $5$，直接填 $5$ 是最常见的错答）。

## 4. 核心考点

核心考点：
DS05.04 折半查找法（算法 `Search_Bin` 的区间收缩过程：$mid=\lfloor(low+high)/2\rfloor$、按比较结果取左半或右半；折半查找路径与判定树上"根到该结点的路径"一一对应，比较次数 $=$ 结点层次）

辅助考点：无（判定树本身就在 DS05.04 之内；题面只问单个元素，不涉及 ASL 的加权计算（DS05.01），分层统计只用作核对）。

解释：本题的求解动作是"按规则逐步执行折半查找并数比较次数"，全部落在 DS05.04；因不涉及平均长度或失败区间计数，不设辅助标签。

## 5. 解题思路

1. 先固定口径：$1$ 起下标、$mid=\lfloor(low+high)/2\rfloor$、目标下标 $k=15$；
2. 列表逐步模拟，每步写清 $low$、$high$、$mid$、$A[mid]$ 与 $A[15]$ 的大小关系及收缩方向，边走边数比较次数；
3. 收缩到 $low=high=15$ 时 $mid=15$，比较相等，查找成功，总次数即计数结果；
4. **第二法**（判定树层次）：把 $n=18$ 的判定树按层列出（第 2 层 $4,14$；第 3 层 $2,6,11,16$；第 4 层 $1,3,5,7,10,12,15,17$），直接读 $15$ 所在层次 $=4$，与逐步模拟一致；
5. **第三法**（换下标基准）：改用 $0$ 起下标（目标 $A[14]$，区间 $[0,17]$）再走一遍，仍得 $4$ 次 ⟹ 结果与下标起点无关，排除"差一"类错误；
6. 量级核对：$4$ 应介于 $1$ 与树高 $5$ 之间，且全表平均 $ASL=\frac{64}{18}\approx3.56$，第 $15$ 号在平均之上一点，合理。

## 6. 详细解答

### （1）逐步模拟（$mid=\lfloor(low+high)/2\rfloor$，下标 $1\sim18$，目标第 $15$ 个元素）

| 步 | $low$ | $high$ | $low+high$ | $mid=\lfloor\frac{low+high}{2}\rfloor$ | $A[mid]$ 与 $A[15]$ 比较 | 收缩结果 |
|---|---|---|---|---|---|---|
| $1$ | $1$ | $18$ | $19$ | $9$ | $A[9]<A[15]$（$9<15$） | $low=mid+1=10$ |
| $2$ | $10$ | $18$ | $28$ | $14$ | $A[14]<A[15]$ | $low=15$ |
| $3$ | $15$ | $18$ | $33$ | $16$ | $A[16]>A[15]$ | $high=mid-1=15$ |
| $4$ | $15$ | $15$ | $30$ | $15$ | $A[15]=A[15]$，**查得** | 结束 |

（表中最左列"步"即比较次数；每一步只做一次关键字比较。查得时恰好 $low=high=mid$，属正常终止，不是 $low>high$ 的失败终止。）

比较次数 $=\boxed{4}$。

### （2）第二法：判定树读层次

$n=18$、$mid$ 向下取整时的折半查找判定树，各层结点（表下标）为：

| 层次 | 结点（下标） | 个数 | 来源区间 |
|---|---|---|---|
| $1$ | $9$ | $1$ | $[1,18]$ |
| $2$ | $4,\;14$ | $2$ | $[1,8]\to4$；$[10,18]\to14$ |
| $3$ | $2,\;6,\;11,\;16$ | $4$ | $[1,3],\,[5,8],\,[10,13],\,[15,18]$ |
| $4$ | $1,\;3,\;5,\;7,\;10,\;12,\;\mathbf{15},\;17$ | $8$ | 各上层结点的孩子区间 |
| $5$ | $8,\;13,\;18$ | $3$ | $[8,8],\,[13,13],\,[18,18]$ |

内部结点合计 $1+2+4+8+3=18$ ✓ 与表长一致；树高 $5=\lfloor\log_2 18\rfloor+1$ ✓。

目标 $15$ 出现在**第 $4$ 层**，其到根的路径为 $9\to14\to16\to15$，与第（1）步的模拟序列逐位相同 ✓ 两法互证。

（顺带核对：第 $4$ 层的 $15$ 是第 $3$ 层 $16$ 的左孩子——因为 $[15,15]$ 由 $[15,18]$ 取 $mid=16$ 后向左收缩得到；$17$ 则是 $16$ 的右孩子（区间 $[17,18]$），其右子树下的 $18$ 落在第 $5$ 层。可见"$15$ 比 $17$ 浅一层、比 $18$ 浅一层"的排列是本棵树的真实形态，不是笔误。）

### （3）第三法：换 $0$ 起下标复算（排除差一错误）

区间 $[low,high]=[0,17]$，目标下标 $14$（第 $15$ 个元素）：

$$mid=\lfloor\tfrac{0+17}{2}\rfloor=8\ (\text{第 }1\text{ 次})\to mid=\lfloor\tfrac{9+17}{2}\rfloor=13\ (\text{第 }2\text{ 次})\to mid=\lfloor\tfrac{14+17}{2}\rfloor=15\ (\text{第 }3\text{ 次})\to mid=\lfloor\tfrac{14+14}{2}\rfloor=14\ (\text{第 }4\text{ 次，查得})$$

同为 $4$ 次 ✓ 说明结果不随下标起点改变（$0$ 起路径 $8,13,15,14$ 恰为 $1$ 起路径 $9,14,16,15$ 各减 $1$）。

### （4）量级与统计核对

全表查找成功的 $ASL$（按第（2）步分层加权）：

$$ASL_{成功}=\frac{1\times1+2\times2+3\times4+4\times8+5\times3}{18}=\frac{1+4+12+32+15}{18}=\frac{64}{18}\approx3.56$$

- 单个元素 $15$ 的次数 $4$ 满足 $1\le4\le5$（树高）✓ 且略高于平均值 $3.56$，与"第 $15$ 号处在结点数最多的第 $4$ 层"一致 ✓；
- 对照本库 DS-2020-13（同一张 $n=18$ 的表查第 $12$ 个元素，$A[9]\to A[14]\to A[11]\to A[12]$，$4$ 次）：$12$ 也在第 $4$ 层，两题层次一致、次数一致 ✓ 说明本解析的判定树与该库既有结论同源。

**填空答案**：$4$（次）。

## 8. 考场标准答案

```c
/* 教材风格：1 起下标的有序表 R[1..18]，折半查找第 15 个元素，返回比较次数 */
typedef struct {
    KeyType key;          /* 关键码域（其它域从略） */
} RedType;
typedef struct {
    RedType r[MaxSize + 1];   /* r[0] 闲置或作哨兵，下标 1..n */
    int     length;
} SSTable;

int BSearch_Count(SSTable ST, int k) {     /* k 为目标元素的下标 */
    int low = 1, high = ST.length, mid, cnt = 0;
    while (low <= high) {
        mid = (low + high) / 2;            /* 整数除法：向下取整 */
        ++cnt;                             /* 每确定一个 mid 比较一次关键码 */
        if (ST.r[mid].key == ST.r[k].key) return cnt;
        else if (ST.r[mid].key <  ST.r[k].key) low  = mid + 1;
        else                                high = mid - 1;
    }
    return -1;                             /* 查找失败（本题不会走到这里） */
}
```

调用 `BSearch_Count(ST, 15)` 的执行轨迹：$mid=9$（比 $1$ 次，向右）$\to mid=14$（$2$ 次，向右）$\to mid=16$（$3$ 次，向左）$\to mid=15$（$4$ 次，相等）⟹ 返回 $4$。

考场书写版：

$$[1,18]\xrightarrow{mid=9}[10,18]\xrightarrow{mid=14}[15,18]\xrightarrow{mid=16}[15,15]\xrightarrow{mid=15}\text{查得}$$

比较次数 $=\boxed{4}$。

时间复杂度 $O(\log n)$，本例共 $4$ 次关键码比较（不超过树高 $\lfloor\log_2 18\rfloor+1=5$）。

## 9. 易错点

1. **直接填树高 $5$ 或"最多比较次数"**：$\lfloor\log_2 18\rfloor+1=5$ 是**最坏情况上界**，只对第 $5$ 层的 $8,13,18$ 三个元素成立；问"第 $15$ 个元素"必须实算路径（这是本题最主要的失分点）；
2. **只数"收缩次数"漏掉最后一次成功比较**：得 $3$；正确记法是每确定一个 $mid$ 就计一次比较，找到 $A[mid]=A[15]$ 的那一步同样要比较一次；
3. **向上取整口径**（本题真正的口径敏感处）：若用 $mid=\lceil(low+high)/2\rceil$，路径为 $[1,18]\to10$、$[11,18]\to15$，只比 $2$ 次即命中。教材与算法 `Search_Bin` 的 `mid=(low+high)/2` 是**整数除法（向下取整）**，本库一律按此口径（见 DS-2020-13、DS-2022-14），故答案取 $4$。注意 $n=18$ 时"整表 $ASL$"对两种口径都相同（均 $64/18$），但**个别元素**的次数会不同——第 $12$ 号两种口径都是 $4$ 次，第 $15$ 号则是 $4$ 与 $2$ 之分，这类差异只能靠约定消除；
4. **$mid$ 的加减一再出错**：向左收缩是 $high=mid-1$、向右是 $low=mid+1$，写成 $high=mid$ 会造成区间不收缩而死循环，写成 $low=mid$ 则次数多算；
5. **把"第 $15$ 个元素"读成"下标 $15$"（混淆元素序号与下标）**：按"$1$ 起、第 $15$ 个"，目标是 $A[15]$，在判定树中位于**第 $4$ 层**，查得需 $4$ 次（$9\to14\to16\to15$）；若误把"第 $15$ 个"当成"$0$ 起下标 $15$"，那对应的是 $1$ 起的**第 $16$ 号**，位于**第 $3$ 层**（第 $3$ 层结点为 $2,6,11,16$，见第（2）步分层表），只需 $3$ 次（$9\to14\to16$）——两者是**不同的目标元素**，次数当然不同，不可混为一谈；第（3）步"下标基准不影响次数"验证的是**同一个元素**（$1$ 起第 $15$ 个 $=$ $0$ 起 $A[14]$）换基准仍 $4$ 次，不能用它来掩盖"把序号读成下标"的审题错误；
6. **误当成查找失败或问 $ASL$**：题面"查找第 $15$ 个元素"意味着该元素存在（成功口径），不要引入外部结点或失败区间层次（$n=18$ 的失败口径要数 $19$ 个外部区间）。

## 10. 一句话规律

折半查找问"某一个元素的比较次数"只有一条路：**逐步写 $low,high,mid$ 的收缩表并数 $mid$ 的个数**，或等价地画判定树读该结点的层次；两者必须逐项一致，且结果一定落在 $[1,\lfloor\log_2 n\rfloor+1]$ 内——超出这个范围就是算错，把上界当答案也是错。
