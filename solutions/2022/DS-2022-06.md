# DS-2022-06

## 1. 原题

一棵左子树为空的二叉树在前序线索化后，其中空的链域的个数是（）。

A. 不确定

B. $0$

C. $1$

D. $2$

## 2. 答案

**D**（$2$ 个：根结点的左指针域与先序最后一个结点的右指针域）。

## 3. 题目分析

- 已知：一棵二叉树采用二叉链表存储，"左子树为空"（题面只给这一条件，未给结点数）；对它做**前序线索化**；
- 目标：求线索化**之后**仍然为空的指针域（空链域）个数；
- 关键约束：
  1. 线索化的作用对象是**原本为空的指针域**——把空左域改成指向前驱的线索、空右域改成指向后继的线索，非空域（指向真实孩子）一律不动；
  2. 若某空域对应的结点在前序序列中**没有前驱**（即根结点）或**没有后继**（即先序最后一个结点），则该空域无法填上线索，仍是空的；
  3. 题设"左子树为空"保证**根的左域为空**，这正是"无前驱的空域"存在的前提——少了这个条件，答案会由 $2$ 变 $1$；
- 命题意图：考"线索化究竟消耗掉哪些空域"这一构造层面的理解（DS03.02.04），并借助 $n+1$ 空域的计数结论（DS03.02.02）把答案收敛到"只剩两个特殊位置"；四个选项中 B（$0$）对应"以为线索化能把所有空域填满"，C（$1$）对应"只想到最后一个结点、忘了根也可能留空"，A（不确定）对应"以为答案与 $n$ 有关"。

## 4. 核心考点

核心考点：
DS03.02.04 线索二叉树——前序线索化的构造规则：只有空的左/右指针域被改造成前驱/后继线索，非空域保持不变；无前驱（序列首）与无后继（序列尾）的空的指针域仍为 `NULL`

解释：本题问的是线索化完成后的结构状态，判定完全依赖线索化算法"在什么条件下写线索"的规则，故主标签为 DS03.02.04（taxonomy 该节点已含"概念与构造"）。

辅助考点：
DS03.02.02 二叉树的存储结构——$n$ 个结点的二叉链表共有 $2n$ 个指针域，其中 $n-1$ 个指向孩子、$n+1$ 个为空，这是"空域总数 $\to$ 剩余空域"计法的底数
DS03.02.03 二叉树的遍历——必须先确定前序序列中"谁是第一个、谁是最后一个"，才能判断某个空域有没有前驱/后继；先序末结点必无孩子这一事实来自遍历定义

## 5. 解题思路

1. 先用 DS03.02.02 的计数：线索化前空域有 $n+1$ 个（$n$ 个左域中空的加上右域中空的），线索化就是把这些空域逐个"填线索"；
2. 反过来问：**哪些空域填不上线索？** 只有两种——该结点在前序里没有前驱（空的左域），或没有后继（空的右域）；
3. 前序里"没有前驱"的只有第一个结点即根；"没有后继"的只有最后一个结点；
4. 检查这两个结点的对应域是否真的为空：根的空左域由题设"左子树为空"直接给出 ✓；先序末结点必无左、右孩子（否则孩子会排在它之后），故其右域亦空 ✓；
5. 于是剩余空域 $=1+1=2$，与 $n$ 无关（排除 A）；再用三个具体规模（$n=1$、右斜三结点、根左空四结点）逐域枚举核对。

## 6. 详细解答

### （1）计数的底：二叉链表的空域总数

$n$ 个结点的二叉链表有 $2n$ 个指针域；除根外每个结点被恰好一个指针域指向（父结点的左或右域），共 $n-1$ 个非空域，故

$$\text{空域数}=2n-(n-1)=n+1$$

前序线索化就是把其中"有前驱/后继可指"的空域改为线索，**非空域不参与线索化**。因此线索化后仍为空的域数 $=$ 空域总数 $-$ 能填上线索的空域数 $=$ "无前驱的空左域"数 $+$ "无后继的空右域"数。

### （2）先序序列的首、尾结点

- **首结点是根**：前序 $=$ 根 $\to$ 左 $\to$ 右，根排第一，**无前驱**。若根的左域为空（题设条件），这个空域无处可指，线索化后仍为空 ⟹ 贡献 $1$ 个空域。
- **末结点必无孩子**：设先序最后访问的结点为 $v$。若 $v$ 有左孩子 $l$，按定义 $l$ 紧随 $v$ 之后被访问，与"$v$ 在最后"矛盾；右孩子同理。故 $v$ 左右域皆空，且 $v$ **无后继**：其空右域无法填线索，仍为空 ⟹ 再贡献 $1$ 个空域。（$v$ 的空左域则不同：$v$ 在序列中有前驱，故其左域可填上前驱线索。）

### （3）其余空域都能被填上

- 除根外的任何结点在前序中都有前驱（至少有它的父结点排在它之前），故其空左域都能填前驱线索；
- 除末结点外的任何结点在前序中都有后继，故其空右域都能填后继线索。

所以**与 $n$ 无关**，剩余空域恒为 $2$（前提是树非空且根的左子树为空，即题设条件）。

### （4）三个实例逐域枚举（自我验证）

**实例一：$n=1$（单结点 $a$，其左子树为空，满足题设）**

| 结点 | 左域 | 右域 |
|---|---|---|
| $a$ | 空，且 $a$ 是根无前驱 ⟹ 仍空 | 空，且 $a$ 是末结点无后继 ⟹ 仍空 |

剩余空域 $=2$ ✓（此例同时否证 B、C）

**实例二：$n=3$ 右斜链 $a\to b\to c$（每个结点的左子树都为空，是题设的特殊情形）**

初始空域 $n+1=4$：$a_L,b_L,c_L,c_R$。前序 $a,b,c$。

- $a_L$：无前驱 ⟹ 空；
- $b_L$：前驱 $a$ ⟹ 填线索；
- $c_L$：前驱 $b$ ⟹ 填线索；
- $c_R$：无后继 ⟹ 空。

剩余 $=2$ ✓

**实例三：$n=4$，根 $p$ 无左孩子，$p$ 的右孩子 $q$，$q$ 的左孩子 $a$、右孩子 $b$（只有根的左子树为空的一般情形）**

前序 $p,q,a,b$。初始空域 $n+1=5$：$p_L,a_L,a_R,b_L,b_R$。

- $p_L$：无前驱 ⟹ 空；
- $a_L$：前驱 $q$ ⟹ 线索；$a_R$：后继 $b$ ⟹ 线索；
- $b_L$：前驱 $a$ ⟹ 线索；$b_R$：$b$ 是末结点，无后继 ⟹ 空。

剩余 $=2$ ✓（此例说明"每个结点左子树都为空"与"仅根的左子树为空"两种读法结果相同）

### （5）与教材算法的对应

教材中先序线索化用一个 `pre`（前驱指针，初值 `NULL`）实现：

```c
void PreThread(BiTree T, BiTree *pre)     /* pre 为指向"前驱结点"的指针，初值 NULL */
{
    if (T) {
        if (!T->lchild) { T->ltag = 1; T->lchild = *pre; }   /* 空左域填前驱线索；根时 *pre 为 NULL，仍为空 */
        if (*pre && !(*pre)->rchild) { (*pre)->rtag = 1; (*pre)->rchild = T; }  /* 前驱的空右域填后继线索 */
        *pre = T;
        if (T->ltag == 0) PreThread(T->lchild, pre);
        PreThread(T->rchild, pre);
    }
}
```

根的左域得到 `*pre == NULL`，故仍为空；递归结束后，最后一个结点的右域从未被回填（回填只发生在"有后继"时），仍为空。与 (2)(3) 的结论一致。

**答案：D**

## 7. 选项分析

- A（不确定）：错。这是"没看出剩余空域与 $n$ 无关"的选择——空域总数虽随 $n$ 变化（$n+1$），但填不上的只有序列首、尾两处，与 $n$ 无关；
- B（$0$）：错。误以为线索化能把所有空域都填上；序列首结点无前驱、末结点无后继，这两处的空域无处可指；
- C（$1$）：错。只数了"最后一个结点的空右域"，漏掉"根结点的空左域"——而题面特意给出"左子树为空"正是为了保证根的空左域存在。若题设为"根有左孩子"，答案才是 $1$；
- D（$2$）：**正确**。根的空左域 $+$ 先序末结点的空右域。

## 8. 考场标准答案

二叉链表 $n$ 个结点共有 $n+1$ 个空指针域，前序线索化只能给"在先序序列中存在前驱/后继"的空域填线索。

- 根结点是先序首元素，无前驱；由题设其左子树为空 ⟹ 根的左域线索化后仍为空（$1$ 个）；
- 先序最后一个结点必无孩子、无后继 ⟹ 其右域仍为空（$1$ 个）；
- 其余空域全部被前驱/后继线索占用。

故空链域个数 $=2$，选 **D**。

## 9. 易错点

1. **漏数根结点**：只想到"最后一个结点无线索"而选 C（$1$）。判断"根要不要计入"必须回头看题设条件——本题"左子树为空"就是让你计入根的空左域；
2. **把线索当作空**：混淆"空链域"与"线索域"。若把线索也算作空域，答案应为 $n+1$，而四个选项均不含该表达式（除 $n=1$ 的特例外），按选项即可反推题目所指是"仍为 `NULL` 的域"；
3. **误用中序线索化的结论**：中序线索化时"最左结点的左域、最右结点的右域"为空，数目同样是 $2$，但两个结点的身份不同；把"先序末结点"换成"中序最右结点"就会在其它题上错位；
4. **忘记先序末结点必无孩子**：它是"一路向右 + 最后的左子树末端"走到的，若它有孩子，孩子必排在它之后，矛盾。

## 10. 一句话规律

线索化后剩余空域数 $=$ 遍历序列首结点中原本为空的左域 $+$ 序列末结点原本为空的右域 $=0\sim2$ 个，具体取决于首/末结点对应域是否本来就空——先写出遍历序列的首尾是谁，再看题设给了哪些空域。
