# DS-2022-19

## 1. 原题

用有向无环图描述表达式 $(a+b)*((a+b)/a)$ ，至少需要顶点的数目为____________________。

## 2. 答案

**$5$**（顶点为 $a$、$b$、$+$、$/ $、$*$ 共 $5$ 个，弧 $6$ 条；关键在于公共子表达式 $(a+b)$ 在图中只保留**一个**加法顶点，被除法和乘法共同引用）。

## 3. 题目分析

- 已知：表达式 $(a+b)*((a+b)/a)$；描述工具是**有向无环图（DAG）**——顶点表示变量或运算，弧 $\langle u,v\rangle$ 表示"$v$ 要用到 $u$ 的值"（操作数指向运算符）；
- 目标：满足"能正确描述该表达式"的 DAG 中**顶点数的最小值**；
- 关键约束：
  1. **必须有向、必须无环**：若允许环，则可以无限绕圈、失去"求值次序"的意义；DAG 才能对应表达式的合法求值顺序（存在拓扑序）；
  2. **共享是本题的得分点**：DAG 相对表达式二叉树的唯一优势，就是让相同子表达式只出现一次（多条弧指向同一顶点）；若不许共享，题目就退化成"数表达式二叉树的结点"（$9$ 个）；
  3. 变量顶点也计入顶点总数：$a$、$b$ 是图中入度为 $0$ 的源点，删掉它们运算就失去操作数，故不可省略；
  4. 同一个运算符（如两个 $+$）只有在**所表示的子表达式完全相同**时才能合并为一个顶点；本题两个 $+$ 都对应 $(a+b)$，可合并；若写成 $(a+b)*(a+c)$，两个加法顶点就不可合并；
  5. "至少" ⟹ 必须既**构造**（给出 $5$ 个顶点的图）又**证明下界**（说明不可能只有 $4$ 个），只给构造不算完整解答；
- 命题意图：考 DS04.01 中"有向图/无环图"这一概念的实际用法——能否把"公共子表达式"翻译成"多个弧头指向同一顶点"，并顺带与 DS03.04.02 的表达式二叉树作代价对比（顶点数由 $9$ 降到 $5$，即存储/计算量的节省）。

## 4. 核心考点

核心考点：
DS04.01 图的基本概念——有向图、弧、入度/出度、有向无环图这组定义；"用 DAG 描述表达式"是这些定义的标准应用场景，共享顶点即"一个顶点可被多条弧指向"

辅助考点：
DS03.04.02 树与二叉树的其他应用——表达式二叉树（每个运算符一个内部结点、每个变量一个叶结点，同名子表达式也要重复存放），它是本题"至少"二字的对照物：不允许共享时的顶点数 $9$

解释：题目的结构对象是有向无环图（DS04.01），不涉及存储结构（DS04.02.x）与遍历（DS04.03.x）；表达式树只是用来作对照与下界说明，故列为辅助。

## 5. 解题思路

1. 先把表达式的**语法层次**拆开：最外层是 $*$，左操作数 $(a+b)$、右操作数 $(a+b)/a$；右操作数又是 $/$，其左操作数仍是 $(a+b)$、右操作数 $a$；
2. 列出"不同的值"有哪些：变量值 $a$、$b$；中间值 $t_1=a+b$、$t_2=t_1/a$；最终值 $t_3=t_1*t_2$——共 $5$ 个，这就是 $5$ 个顶点的来源（**每个不同的值配一个顶点**）；
3. 把"谁用了谁"写成弧：$a\to+$、$b\to+$、$+\to/$、$a\to/$、$+\to*$、$/\to*$，得 $6$ 条弧；
4. 自查无环：按 $a,b,+,/,*$ 排序，每条弧都从序号小指向序号大 ⟹ 这是一个拓扑序 ⟹ 确为 DAG；
5. 证不可更少：$a$、$b$ 两个变量顶点必须存在（$2$ 个）；加法、除法、乘法产生三个互不相同的值，各需一个顶点（$3$ 个）；合计 $\ge5$，与第 2 步构造吻合 ⟹ 最小值 $=5$；
6. 反向核对：若按表达式二叉树（不共享）画，应得 $9$ 个顶点，$9-5=4$ 恰是被共享省去的"$1$ 个重复 $+$ 结点 $+$ $2$ 个重复 $a$ 叶 $+$ $1$ 个重复 $b$ 叶"。

## 6. 详细解答

### （1）拆出表达式中互不相同的"值"

令

$$t_1=a+b,\qquad t_2=t_1/a=(a+b)/a,\qquad t_3=t_1*t_2=(a+b)*((a+b)/a)$$

表达式在求值过程中出现的值共 $5$ 个：原始变量 $a$、$b$，中间结果 $t_1$（一次加法）、$t_2$（一次除法）、最终结果 $t_3$（一次乘法）。

**注意** $(a+b)$ 在书写上出现两次，但它的值是同一个 $t_1$ ⟹ 在 DAG 中只配一个顶点；而两个 $+$ 若对应不同的子表达式（如 $(a+b)$ 与 $(a+c)$）就不能合并。

### （2）顶点与弧的清单

| 顶点 | 含义 | 入度 | 出度 | 指向（出弧） |
|---|---|---|---|---|
| $a$ | 变量 $a$ | $0$ | $2$ | $\langle a,+\rangle$、$\langle a,/\rangle$ |
| $b$ | 变量 $b$ | $0$ | $1$ | $\langle b,+\rangle$ |
| $+$ | 运算 $t_1=a+b$ | $2$ | $2$ | $\langle +,/\rangle$、$\langle +,*\rangle$ |
| $/$ | 运算 $t_2=t_1/a$ | $2$ | $1$ | $\langle /,*\rangle$ |
| $*$ | 运算 $t_3=t_1*t_2$ | $2$ | $0$ | ——（汇点，表达式的值） |

顶点数 $=5$，弧数 $=\sum$出度 $=2+1+2+1+0=6$，也 $=\sum$入度 $=0+0+2+2+2=6$ ✓ 两法一致。

按"操作数 $\to$ 运算符"把 $6$ 条弧分层列出（每行左侧为入弧来源，右侧为该顶点表示的值）：

```
a → +      b → +        顶点 + ：t1 = a+b     ← 公共子表达式，只有一个顶点
a → /      + → /        顶点 / ：t2 = t1/a    ← 它的左入弧直接来自上面的 +
+ → *      / → *        顶点 * ：t3 = t1*t2   ← 汇点，即表达式的值
```

（$5$ 个顶点自下而上排成 $\{a,b\}\to +\to /\to *$ 的四层结构；$a$ 发出两条弧、$+$ 发出两条弧，正是"共享"的体现。）

### （3）确认它是"有向无环图"

取顶点序 $a,\;b,\;+,\;/,\;*$，逐条检查 $6$ 条弧均由序号小者指向序号大者：

$$a\to +,\ a\to /,\ b\to +,\ +\to /,\ +\to *,\ /\to *$$

全部满足 ⟹ 这是一个拓扑有序列，图中不存在有向回路的顶点能出现在自己的后继位置 ⟹ 无环 ✓（反之，若图中有环，则不存在这样的线性序。）

### （4）下界证明：为什么不能少于 $5$ 个顶点

- 变量 $a$ 与 $b$ 是表达式中仅有的原始数据，图中每个运算顶点的入弧必须来自"它所需的值"的顶点。若删去 $a$ 或 $b$ 的顶点，则加法（或除法）没有对应的操作数来源，图不再描述原表达式 ⟹ 至少 $2$ 个变量顶点；
- 求值过程中产生了 $3$ 个**互不相同**的结果值 $t_1\ne t_2\ne t_3$（$a+b$、$(a+b)/a$、$(a+b)*((a+b)/a)$ 一般不相等），一个顶点只能表示一个值，一个运算顶点也只表示一次运算 ⟹ 至少 $3$ 个运算顶点；
- 两类顶点不可能重合（变量顶点入度为 $0$，运算顶点入度 $\ge1$）⟹ 总数 $\ge 2+3=5$。

结合第（2）步已构造出 $5$ 个顶点的合法 DAG ⟹ **最小值恰为 $5$**。

### （5）与表达式二叉树（不允许共享）对照

按 DS03.04.02 的表达式二叉树画：根为 $*$，其左孩子为 $+$（叶 $a,b$），右孩子为 $/$（左子树为另一个 $+$，叶 $a,b$；右孩子为叶 $a$）。

$$\text{内部结点（运算符）}=4\ (+,\ +,\ /,\ *)，\qquad \text{叶结点（变量）}=5\ (a,b,a,b,a)$$

$$\text{二叉树结点总数}=4+5=9$$

改用 DAG 后省去的 $4$ 个顶点正好是"第二个 $+$ 结点 $+$ 它的两个叶 $a,b$ $+$ 分母位置的 $a$ 叶"（它们分别并入已有的 $+$、$a$、$b$ 顶点）：$9-4=5$ ✓ 与（2）（4）一致，这也说明本题的"至少"来自共享而非删减运算。

**填空答案**：$5$。

## 8. 考场标准答案

把表达式写成 $t_1=a+b$、$t_2=t_1/a$、$t_3=t_1*t_2$，公共子表达式 $t_1$ 只留一个顶点。

- 顶点：$a,\ b,\ +,\ /,\ *$ —— 共 $\boxed{5}$ 个；
- 弧（$6$ 条）：$\langle a,+\rangle,\langle b,+\rangle,\langle a,/\rangle,\langle +,/\rangle,\langle +,*\rangle,\langle /,*\rangle$；
- 拓扑序 $a,b,+,/,*$ 存在 ⟹ 无向环成立；
- 因 $a,b$ 两个变量顶点不可省、$+,/,*$ 三个不同结果各占一顶点，故不可能少于 $5$ 个。

若要把这张图存进内存（考场说明用），可按教材风格的邻接表写法：

```c
/* DAG 顶点：value 记录该顶点代表的变量名或运算符，弧自操作数指向运算符 */
typedef struct DAGNode {
    char            value;      /* 'a' 'b' '+' '/' '*' */
    int             indegree;   /* 入度，拓扑排序时用 */
    ArcNode        *firstarc;   /* 出弧链表头指针 */
} DAGNode, ADG[MaxVertexNum];

typedef struct ArcNode {
    int             adjvex;     /* 该弧指向的顶点下标 */
    struct ArcNode *nextarc;    /* 同属同一顶点的下一条出弧 */
} ArcNode;
```

（说明"共享"只需一句话：以 $+$ 为尾的两条入弧 $\langle a,+\rangle,\langle b,+\rangle$ 只登记一次，而 $/$ 与 $*$ 的左入弧都写成 $adjvex=+\,$。）

## 9. 易错点

1. **漏掉变量顶点**：只数运算符 $+,/,*$ 得 $3$——题面问的是 DAG 的"顶点数目"，变量在图中同样是入度为 $0$ 的顶点，必须计入；
2. **不做共享、直接数表达式二叉树的结点数**：得 $9$——这是"最多"而非"至少"，本题的"至少"正是要求把重复的 $(a+b)$ 合并；
3. **共享做过头**：把 $a$ 与 $b$ 也并为一个顶点（得 $4$），或把 $/$ 与 $*$ 混用同一顶点，图就不再等价于原表达式（不同值必须不同顶点）；
4. **误认为两个 $+$ 一定要两个顶点**：判定标准是"两个加法是否表示同一个值"，$(a+b)$ 与 $(a+b)$ 同值可并，$(a+b)$ 与 $(a+c)$ 异值不可并；
5. **弧的方向写反**（自运算符指向操作数）：那样得到的图无法用拓扑序表达"先算操作数再算运算符"的依赖关系，也和本库拓扑排序题（DS-2021-11、DS-2018-29）的约定冲突；两种画法顶点数相同，但答案说明要按"操作数 → 运算符"统一；
6. **只给构造不给下界**（或反之）：填空题虽不写过程，判断"至少"时若不会证下界，遇到变式（如问 $(a+b)*(c+d)*\,(a+b)$ 需要几个顶点）就会失手。

## 10. 一句话规律

用 DAG 描述表达式的顶点数 $=$ **表达式中互不相同的"值"的个数**：每个变量一个顶点、每种只需计算一次的运算一个顶点，重复出现的子表达式并入已有顶点（多条入弧共享同一顶点），并一律用"是否存在拓扑序"自查有没有成环。
