# DS-2015-36

## 1. 原题

对长度为 $n$ 的关键字序列进行快速排序的时间复杂度为____________________ 。

## 2. 答案

平均情况 $O(n\log_2 n)$，最坏情况 $O(n^{2})$。

完整表述（推荐答卷写法）：快速排序在划分均匀时耗时 $O(n\log_2 n)$（这也是它的平均复杂度）；当每次选取的枢轴恰好是当前区间的极值（例如序列已按枢轴取向排好或倒序排列、又固定取第一个元素作枢轴），划分退化成 $0$ 与 $n-1$ 的不对称拆分，比较次数达 $n(n-1)/2$，即最坏 $O(n^{2})$。完整的答法还应补上：空间复杂度为递归栈 $O(\log_2 n)$（最坏 $O(n)$），且排序不稳定。

## 3. 题目分析

- 已知：待排序序列长度 $n$，排序方法为**快速排序**（DS06.06：选枢轴 pivot ⟶ 一趟划分使左半 $\le$ 枢轴 $\le$ 右半 ⟶ 对两子区间递归）；
- 目标：给出时间复杂度。空格只有一处，而快速排序的复杂度是**分情形**的，故答案必须把"平均"与"最坏"两层都说清（见第 12 节口径说明）；
- 关键约束：
  1. 快排的耗时 $=$ 各趟划分的比较次数之和，而一趟划分的代价与当前区间长度成正比（$\Theta(m)$ 对长度 $m$ 的区间）；总代价取决于**划分树的高**与**每层的工作量**；
  2. 最好/平均：枢轴把区间大致二等分 ⟹ 每层总工作量 $n$、共 $\log_2 n$ 层 ⟹ $n\log_2 n$；
  3. 最坏：枢轴总是一端极值 ⟹ 划分树退化为深度 $n-1$ 的单支链，第 $i$ 次划分处理长度 $n-i+1$ 的区间 ⟹ 总数 $\sum_{k=1}^{n}(k-1)=n(n-1)/2$；
  4. 快排的复杂度**依赖数据初始状态**，这正是它与"恒为 $O(n\log_2 n)$"的堆排序、归并排序的本质区别，也是本卷第 17 题（"初始数据有序时花费时间反而最多"选快速排序）的考点；
  5. 教材通行写法：说"快速排序的时间复杂度"若不附加条件，一般指**平均** $O(n\log_2 n)$，同时必须记住最坏 $O(n^2)$（本库 DS-2006-25 的判断题就是拿最坏情形命题的）；
- 命题意图：本卷把排序的性能考查拆成三处——第 12 题（局部有序宜用直接插入）、第 17 题（初始有序反而最慢的是快排）、第 36 题（快排的复杂度），第 41 题（简答快排思想并写出第一趟结果）。本题要求把"平均 $O(n\log_2 n)$、最坏 $O(n^2)$"这一对结论记牢，并理解两者由何而来。

## 4. 核心考点

核心考点：
DS06.06 快速排序（一趟划分的代价、递归深度与初始序列的关系、平均 $O(n\log_2 n)$ 与最坏 $O(n^2)$ 两个结论及其成因）

辅助考点：
DS06.11 排序算法应用（把快排与堆排、归并、冒泡、直接插入在同一张复杂度表里对照，是"哪种排序最坏也是 $O(n\log_2 n)$""哪种对初始有序最敏感"一类题的通用背景）；DS00.02 算法与算法分析（渐进记号只保留最高阶项，以及"最好/最坏/平均"三种情形的区分）

解释：单写 $O(n\log_2 n)$ 只答了一半，单写 $O(n^2)$ 也错；本题真正的知识是"同一算法在不同输入下复杂度不同，且分界点是划分的均衡程度"，因此主考点 DS06.06 必须配合 DS00.02 的"分情形复杂度"观念与 DS06.11 的横向对照才完整。

## 5. 解题思路

1. **写出一趟划分的代价**：对长度 $m$ 的区间做一次 partition，双向扫描共比较约 $m-1$ 次 ⟹ $\Theta(m)$；
2. **平均情形递推**：枢轴等可能落在任一位置，粗略取"二等分"模型 $T(n)=2T(n/2)+\Theta(n)$，展开或主定理得 $T(n)=\Theta(n\log_2 n)$；
3. **最坏情形递推**：每次划分为 $(0,n-1)$，$T(n)=T(n-1)+\Theta(n)$，逐层求和得 $n(n-1)/2=\Theta(n^2)$；
4. **找出最坏的输入**：以"取首元素为枢轴"的教材写法为例，正序与逆序序列都会使枢轴成为区间最小/最大值 ⟹ 本卷第 17 题的现象；
5. **补空间与稳定性**：递归需栈，深度 $=$ 划分树高 ⟹ 平均 $O(\log_2 n)$、最坏 $O(n)$；划分中元素跨区间交换 ⟹ 不稳定；
6. **用小数据自检**：$n$ 个元素的最坏比较数依次为 $0,1,3,6,10,15,21,28$（$n=1..8$，即三角数），与 $n(n-1)/2$ 完全吻合；平均情形取 $n=8$ 时 $n\log_2 n=24$，量级与 $n^2/2=32$ 接近但 $n$ 增大后差距迅速拉开（$n=1024$：$10240$ 对 $523776$）。

## 6. 详细解答

### 6.1 快速排序的代价结构

教材风格写法（双向交替扫描，取首元素为枢轴）：

```c
int Partition(SqList *L, int low, int high) {   /* 一趟划分，返回枢轴最终位置 */
    int pivot = L->r[low];                       /* 枢轴：区间第一个元素 */
    while (low < high) {
        while (low < high && L->r[high] >= pivot) --high;
        L->r[low] = L->r[high];                  /* 比枢轴小的换到左边 */
        while (low < high && L->r[low]  <= pivot) ++low;
        L->r[high] = L->r[low];                  /* 比枢轴大的换到右边 */
    }
    L->r[low] = pivot;                           /* 枢轴归位 */
    return low;
}
void QuickSort(SqList *L, int low, int high) {
    if (low < high) {                            /* 区间长度 >= 2 才需要划分 */
        int p = Partition(L, low, high);
        QuickSort(L, low, p - 1);
        QuickSort(L, p + 1, high);
    }
}
```

关键观察：一趟 `Partition` 的比较次数不超过区间长度，记 $m=\text{len}$，代价为 $\Theta(m)$（本库 DS-2005-18 指出"每趟都能确定一个元素的最终位置"，即每趟至多消耗 $m$ 次比较换来一个就位元素）。总时间 $=$ 所有递归调用区间长度之和。

### 6.2 平均情形：$O(n\log_2 n)$

**（a）等分模型（快速量级判断）**：若每次枢轴都落在正中，则

$$T(n)=2T(n/2)+cn$$

按递归树计算：第 $i$ 层有 $2^{i}$ 个长度 $n/2^{i}$ 的区间，每层合计工作量 $cn$；层数到 $n/2^{i}=1$ 止，即 $\log_2 n$ 层，故

$$T(n)=cn\log_2 n=\Theta(n\log_2 n)$$

**（b）严格递推（枢轴位置等概率）**：设枢轴 rank 均匀分布于 $1..n$，左右子区间长度为 $j-1$ 与 $n-j$，则

$$T(n)=cn+1\!\cdot\!\sum_{j=1}^{n}\frac{1}{n}\big[T(j-1)+T(n-j)\big]=cn+\frac{2}{n}\sum_{k=0}^{n-1}T(k)$$

两边乘 $n$ 得 $nT(n)=cn^{2}+2\sum_{k=0}^{n-1}T(k)$；对 $n-1$ 写出同式并相减：

$$nT(n)-(n-1)T(n-1)=2cn-1+2T(n-1)\ \Longrightarrow\ (n+1)T(n)=(n-1)T(n-1)+2cn-1$$

两边除 $n(n+1)$ 并令 $S(n)=T(n)/(n+1)$，得 $S(n)=S(n-1)+\dfrac{2cn-1}{n(n+1)}$。由于 $\dfrac{2cn-1}{n(n+1)}=\Theta(1/n)$，累加得 $S(n)=\Theta(\log_2 n)$，回代即

$$T(n)=(n+1)\,S(n)=\Theta(n\log_2 n)$$

数值核对：$n=8$ 时 $n\log_2 n=24$；$n=1024$ 时 $n\log_2 n=10240$。

### 6.3 最坏情形：$O(n^{2})$

若每次枢轴都是当前区间的极值，划分成 $()$ 与 $(n-1)$：

$$T(n)=T(n-1)+c(n-1),\qquad T(1)=0$$

逐层展开求和：

$$T(n)=c\sum_{k=2}^{n}(k-1)=c\cdot\frac{n(n-1)}{2}=\Theta(n^{2})$$

**达到最坏的输入**（按 6.1 的"取首元素为枢轴"）：正序序列 $1,2,\cdots,n$ 与逆序序列 $n,\cdots,2,1$——此时枢轴恒为最小或最大值，划分完全不平衡，比较次数恰为三角数。

| $n$ | $2$ | $3$ | $4$ | $5$ | $6$ | $7$ | $8$ |
|---|---|---|---|---|---|---|---|
| 最坏比较数 $n(n-1)/2$ | $1$ | $3$ | $6$ | $10$ | $15$ | $21$ | $28$ |

逐项与手算单支链划分（第一次比 $1$ 次、第二次比 $2$ 次……）一致 ✓。

本卷第 17 题说的就是这个现象："初始数据有序时，花费时间反而最多"的算法选 **C. 快速排序**；而本卷第 12 题（每个元素距最终位置不远）宜用直接插入排序（最好情形 $O(n)$），两题正好把"初始有序对不同算法意味着天堂或地狱"分成对照。

### 6.4 空间复杂度与稳定性

- 递归栈深度 $=$ 划分树高 $h$：平均 $h=\lceil\log_2 n\rceil$ ⟹ $O(\log_2 n)$；最坏 $h=n-1$ ⟹ $O(n)$（本库 DS-2014-41 采此表述"栈空间 $O(\log_2 n)\sim O(n)$"）；
- 划分过程让元素跨越枢轴交换位置，相同关键字的相对次序会被打乱 ⟹ **不稳定**；
- 改进方向（了解即可，用于解释"最坏可避免"）：三数取中选枢轴、随机化枢轴、小区间切换插入排序、尾递归折半——这些都能把 $O(n^2)$ 的发生概率压到极低，但教材仍把 $O(n^2)$ 记为最坏复杂度。

### 6.5 与其它内排序的横向对照（DS06.11）

| 方法 | 平均时间 | 最坏时间 | 最好时间 | 附加空间 | 稳定 |
|---|---|---|---|---|---|
| 直接插入排序 | $O(n^{2})$ | $O(n^{2})$ | $O(n)$ | $O(1)$ | 稳定 |
| 冒泡排序 | $O(n^{2})$ | $O(n^{2})$ | $O(n)$ | $O(1)$ | 稳定 |
| 简单选择排序 | $O(n^{2})$ | $O(n^{2})$ | $O(n^{2})$ | $O(1)$ | 不稳定 |
| 希尔排序 | $O(n^{1.3})$（增量相关） | $O(n^{2})$ | — | $O(1)$ | 不稳定 |
| **快速排序** | $\mathbf{O(n\log_2 n)}$ | $\mathbf{O(n^{2})}$ | $O(n\log_2 n)$ | $O(\log_2 n)\sim O(n)$ | 不稳定 |
| 堆排序 | $O(n\log_2 n)$ | $O(n\log_2 n)$ | $O(n\log_2 n)$ | $O(1)$ | 不稳定 |
| 二路归并排序 | $O(n\log_2 n)$ | $O(n\log_2 n)$ | $O(n\log_2 n)$ | $O(n)$ | 稳定 |

表中"快排最坏 $O(n^2)$、其余三种 $O(n\log_2 n)$ 方法最坏仍是 $O(n\log_2 n)$"这一行差，是 2017 年第 11 题（"时间复杂度不受数据初始状态影响，恒为 $O(n\log_2 n)$ 的是（）"）中把快速排序排除的理由；也是本库 DS-2006-25 判"快排最差时性能并不比冒泡排序更好"为**正确**的理由（同为 $O(n^2)$，且快排还有栈开销与交换开销）。

### 6.6 结论

**答案**：平均 $O(n\log_2 n)$，最坏 $O(n^{2})$（空间为递归栈 $O(\log_2 n)$，最坏 $O(n)$；排序不稳定）。

## 8. 考场标准答案

设长度 $n$。一趟划分耗时 $\Theta(n)$。

- 平均（划分近似均衡）：$T(n)=2T(n/2)+\Theta(n)\Rightarrow T(n)=O(n\log_2 n)$；
- 最坏（枢轴恒为极值，如取首元素而序列已正序/逆序）：$T(n)=T(n-1)+\Theta(n)=\Theta\!\left(\frac{n(n-1)}{2}\right)=O(n^{2})$。

$$\boxed{\text{平均 } O(n\log_2 n)\ \text{；最坏 } O(n^{2})}$$

（附加：空间 $O(\log_2 n)$～$O(n)$，不稳定。）

## 9. 易错点

1. **只写 $O(n\log_2 n)$ 不提最坏**：本题空格只一处，但"快排复杂度"的标准答语必须包含最坏情形，否则遇到本库 DS-2006-25 那种"最差不比冒泡好"的判断题会判错；
2. **只写 $O(n^2)$**：把最坏当成"时间复杂度"的唯一答案，忽略了平均 $O(n\log_2 n)$——快排之所以是"目前认为最快的内排序"，凭的正是平均性能；
3. **对数底写错或漏写**：应写 $\log_2 n$（渐进记号下底数可省，但教材与本题习惯写 $\log_2 n$）；把 $n\log_2 n$ 误写成 $n+\log_2 n$ 或 $n^{2}\log_2 n$ 是常见的表达式错误；
4. **把最坏条件说反**：最坏不是"随机乱序"，而是"对所用枢轴取法而言已（倒）有序"。同一序列，换枢轴取法结论不同，故答题要写明"取第一个元素为枢轴时，正序/逆序即最坏"（本卷第 17 题的正确解说是这一句）；
5. **与归并、堆排混记**：归并是 $O(n\log_2 n)$ 但**最坏也是**，代价 $O(n)$ 辅助空间且稳定；堆排 $O(n\log_2 n)$、$O(1)$ 空间但不稳定；快排是唯一"平均最优、最坏退化到 $O(n^2)$"的（本库 DS-2006-25、2017 年第 11 题都考这一区分）；
6. **忘记比较空间口径**：若题目另问"所需辅助空间"，答案是栈深 $O(\log_2 n)$（最坏 $O(n)$），不要答 $O(1)$（那是堆排序、直接插入的口径）；
7. **误判稳定性**：快排不稳定；写"稳定"会在"要求 $O(n\log_2 n)$ 且必须稳定"一类的选择题（如 2022 年第 11 题的问法）中错选。

## 10. 一句话规律

快速排序的复杂度只看**划分树的高**：每层工作量都是 $\Theta(n)$，树高 $\log_2 n$（均衡划分，平均）即 $O(n\log_2 n)$，树高退化到 $n-1$（枢轴总取极值，如取首元素遇正序/逆序）即 $O(n^{2})$。因此凡"快排复杂度"类问题一律两答——**平均 $O(n\log_2 n)$、最坏 $O(n^{2})$**，并顺手补上"栈空间 $O(\log_2 n)$～$O(n)$、不稳定"；横向对照时记住"最坏仍守 $O(n\log_2 n)$"的是堆排序与归并排序，"对初始有序最敏感"的是快排（变慢）与直接插入（变快）。

- DS-2015-26（本卷第 26 题：顺序表插入平均移动 $n/2$）：与本题同属"平均情形复杂度"的计算范式——先建立与位置相关的代价模型，再取期望，最后保留最高阶项（DS00.02）。

## 12. 来源与可信度

- 原题来源：2015 回忆版题面篇 `真题/2015/2015重庆邮电大学802数据结构真题.md` 二、填空题第 36 题；题面无订正说明、不含图，"长度为 $n$ 的关键字序列""快速排序""时间复杂度"三处按源文原样转录；
- 答案来源：独立推导（划分代价 $\Theta(m)$ + 等分递推 $T(n)=2T(n/2)+cn$ 与枢轴等概率严格递推 + 极不平衡递推 $T(n)=T(n-1)+c(n-1)$ + $n=2..8$ 三角数手算核对 + 与堆排/归并/插入的横向对照）；本库 DS-2014-41、DS-2006-25、DS-2007-35、DS-2005-18 与本卷第 17 题共五处口径一致；未实际抓取解析篇网页，仅按要求登记其地址备查；
- 教材依据：严蔚敏、吴伟民《数据结构（C 语言版）》第 8 章 8.4 快速排序——"平均时间性能 $O(n\log_2 n)$，是目前认为所有同量级 $n$ 的排序方法中平均性能最优的排序算法；若待排序序列正序或逆序，则每次划分只划分出比上一次少一个记录的子序列，最坏情况时间性能 $O(n^2)$；所需辅助空间为最大递归深度 $O(\log_2 n)$；且排序过程不稳定"；
- **口径说明（潜在歧义，非来源冲突）**：本题空格仅一处，而教材结论分"平均"与"最坏"两层。单填 $O(n\log_2 n)$（教材对"快速排序时间复杂度"的默认表述，指平均情形）判为可接受，但更完整的答法是"平均 $O(n\log_2 n)$，最坏 $O(n^2)$"；本解析按后者作答，并在 6.3 给出最坏情形的准确触发条件（取首元素为枢轴且序列正序/逆序），避免出现"快排最坏 $O(n^2)$ 是因为随机数据"这类方向性错误。两种表述不构成不同来源之间的冲突，只是详略之别，故 `solution_status` 仍记为 verified；
- 多来源冲突：无；争议：无（上项口径备注不属于冲突）；
- 最终可信度：high。
