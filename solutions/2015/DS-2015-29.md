# DS-2015-29

## 1. 原题

设二叉树 $T$ 的前序遍历序列和中序遍历序列分别是： $b,d,c,a,e,f$ 和 $c,d,e,a,b,f$ ，则其后序遍历序列为____________________ 。

## 2. 答案

$c,e,a,d,f,b$。

还原出的二叉树为：根 $b$；左子树以 $d$ 为根（$c$ 是其左孩子，$a$ 是其右孩子，$e$ 是 $a$ 的左孩子）；$f$ 是 $b$ 的右孩子。

## 3. 题目分析

- 已知：一棵二叉树的**前序**（根左右）序列 $b,d,c,a,e,f$ 与**中序**（左根右）序列 $c,d,e,a,b,f$，两序列均含 $6$ 个字母、无重复关键字（这是"两序列唯一定树"的前提）；
- 目标：求**后序**（左右根）序列；
- 关键约束：
  1. 前序的第一个元素必是**当前（子）树的根**；
  2. 在中序里找到该根，其**左侧**全部是左子树的结点、**右侧**全部是右子树的结点，由此定出左右子树的结点数 $k$ 与 $m$；
  3. 回到前序，紧跟根之后的 $k$ 个元素是左子树的前序，再后面 $m$ 个是右子树的前序 ⟹ 子问题同型，递归即可；
  4. 只有前序+后序 **不能**定树（两者都只给出根的位置，无法区分左右），必须有一趟"左—根—右"的中序参与切分；
  5. 结点数为 $6$，还原过程中每一步的左右子树结点数之和必须与父问题一致（$1+k+m$ 守恒），这是最好的自查手段；
- 命题意图：考"由两种遍历序列唯一确定二叉树"这一 DS03.02.03 的核心结论与手工递归切分能力。本卷第 11 题（看图写后序）是"给树写序列"的正向，本题是"给序列还原树再写序列"的反向，两题一正一反构成遍历节的主要考查面；同一问法在 2013 年第 25 题、2014 年第 30 题、2016 年第 31 题反复出现（数据不同、方法完全一样）。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（前序/中序/后序的递归定义、由前序 + 中序唯一确定二叉树、序列互推）

辅助考点：
DS03.02.03.01 前序遍历（"根在最前"是定根依据）；DS03.02.03.03 后序遍历（"根在最后、左右子树依次连续"是答案的形态检验）

解释：题解的全部动作是"前序定根 → 中序定左右 → 递归"，属遍历互推的标准流程（DS03.02.03）；两个辅助节点标明本题实际调用的两种序列性质——若给的是层次序列（如 DS-2006-36），切分依据就完全不同，故需区分。

## 5. 解题思路

1. **取根**：前序首元素 $b$ = 整棵树的根；
2. **切分**：在中序 $c,d,e,a,\underline{b},f$ 中定位 $b$ ⟹ 左子树结点集合 $\{c,d,e,a\}$（$4$ 个）、右子树集合 $\{f\}$（$1$ 个）；
3. **回前序分配**：前序中 $b$ 之后的 $4$ 个 $d,c,a,e$ 属左子树（其首元素 $d$ 即左子树的根），剩下的 $f$ 属右子树；
4. **递归**：对左子树重复 1–3（根 $d$；中序 $c,\underline{d},e,a$ ⟹ 左 $\{c\}$、右 $\{e,a\}$；于是 $c$ 是 $d$ 的左孩子，$\{e,a\}$ 构成右子树，其根为前序中的 $a$，中序 $e,\underline{a}$ 说明 $e$ 在 $a$ 左边 ⟹ $e$ 是 $a$ 的左孩子、$a$ 无右孩子）；
5. **读后序**：对还原的树按"左—右—根"输出：$d$ 的子树给出 $c,\;(e,a),\;d$；根 $b$ 的右子树给出 $f$；最后输出 $b$ ⟹ $c,e,a,d,f,b$；
6. **反向验证**：对还原的树重算前序与中序，若与题面两序列逐元素相同，则树建对，后序自然可信。

## 6. 详细解答

### 6.1 第一层：定根 $b$、分左右

| 项 | 内容 |
|---|---|
| 前序 $b,d,c,a,e,f$ | 首元素 $b$ ⟹ 根 $=$ $b$ |
| 中序 $c,d,e,a,\mathbf{b},f$ | $b$ 左侧 $c,d,e,a$ 共 $4$ 个 ⟹ 左子树 $4$ 个结点；$b$ 右侧 $f$ 共 $1$ 个 ⟹ 右子树 $1$ 个结点 |
| 前序剩余 $d,c,a,e,f$ 分配 | 前 $4$ 个 $d,c,a,e$ = 左子树前序；余下 $f$ = 右子树前序 |

计数守恒检查：$1$（根）$+4+1=6$ ✓。右子树只有 $f$ 一个结点，它是 $b$ 的孩子；因它出现在中序 $b$ 的**右侧**，故必为 $b$ 的**右孩子**（若错挂成左孩子，重算的中序将变成 $f,c,d,e,a,b$，与题面不符；本例中 $f$ 在后序里仍处倒数第二位、看不出错，但换成“已知后序求树”一类题就会直接导到错树，故方向必须从中序读准）。

### 6.2 第二层：左子树（前序 $d,c,a,e$，中序 $c,d,e,a$）

- 根 $=d$（前序首）；
- 中序 $c,\mathbf{d},e,a$ ⟹ $d$ 的左子树结点集合 $\{c\}$（$1$ 个），右子树结点集合 $\{e,a\}$（$2$ 个）；
- 前序去掉 $d$ 后为 $c,a,e$：第一个 $c$ 是左子树（单结点，即 $d$ 的左孩子，叶子）；其后两个 $a,e$ 是右子树的前序；
- 计数守恒：$1+1+2=4$ ✓。

### 6.3 第三层：$d$ 的右子树（前序 $a,e$，中序 $e,a$）

- 根 $=a$；
- 中序 $e,\mathbf{a}$ ⟹ $a$ 的左子树 $\{e\}$、右子树为空；
- 故 $e$ 是 $a$ 的**左孩子**，$a$ 无右孩子；
- 计数守恒：$1+1+0=2$ ✓。

（若此处误把 $e$ 挂成 $a$ 的右孩子，则中序会变成 $a,e$，与题面 $e,a$ 矛盾——这一"方向"错误正是本题最容易失分的地方，用 6.5 的回对即可排除。）

### 6.4 还原出的二叉树与后序

```
            b
          /   \
        d      f
       / \
      c   a
         /
        e
```

结点位置核对：$b$ 深度 $1$；$d,f$ 深度 $2$；$c,a$ 深度 $3$；$e$ 深度 $4$。度 $2$ 结点 $=\{b,d\}$（$2$ 个），叶子 $=\{c,e,f\}$（$3$ 个），满足 $n_0=n_2+1$ ✓（结构性自检）。

按"左子树 → 右子树 → 根"递归输出后序：

- $e$ 是 $a$ 的左孩子、$a$ 无右孩子 ⟹ 子树 $a$ 的后序：$e,a$；
- 子树 $d$ 的后序：左 $c$ → 右 $(e,a)$ → 根 $d$ ⟹ $c,e,a,d$；
- 子树 $f$ 的后序：$f$；
- 整树后序：$c,e,a,d$ → $f$ → $b$ ⟹ $\boxed{c,e,a,d,f,b}$。

### 6.5 反向验证（对还原的树重算两序列）

| 遍历 | 重算结果 | 题面 | 一致 |
|---|---|---|---|
| 前序（根左右） | $b$ + 前序$(d$ 子树$)$ + 前序$(f)$；$d$ 子树 $=d,c,(a,e)$ ⟹ $b,d,c,a,e,f$ | $b,d,c,a,e,f$ | ✓ |
| 中序（左根右） | 中序$(d$ 子树$),b,$f$；$d$ 子树 $=c,d,$（$e,a$）$=c,d,e,a$ ⟹ $c,d,e,a,b,f$ | $c,d,e,a,b,f$ | ✓ |
| 后序（左右根） | $c,e,a,d,f,b$ | — | 待求答案 |

两序列同时回对成功，说明还原的树与题面完全吻合（二叉树由前序 + 中序唯一确定，故不存在另一棵树也满足题面），后序答案随之确定。

**补充硬约束检查**（可用来快速排除错误答案）：后序中根 $b$ 必在**最后一位**；$d$ 必出现在其两个孩子 $c$、$a$ 之后（即 $d$ 在 $c$ 与 $a$ 右边）；$a$ 必在 $e$ 之后。$c,e,a,d,f,b$ 满足全部三条 ✓。

**答案**：$c,e,a,d,f,b$。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

前序 $b,d,c,a,e,f$ 定根 $b$；中序 $c,d,e,a,b,f$ 得左子树 $\{c,d,e,a\}$、右子树 $\{f\}$。
左子树前序 $d,c,a,e$ 定根 $d$，中序 $c, d, e, a$ 得 $d$ 的左孩子 $c$、右子树 $\{e,a\}$；右子树前序 $a,e$ 定根 $a$，中序 $e,a$ 得 $e$ 为 $a$ 的左孩子。

```
        b
       / \
      d   f
     / \
    c   a
       /
      e
```

后序（左右根）$=\underline{\text{后序}(d\text{子树})}\;\underline{f}\;b=c,e,a,d,f,b$。

## 9. 易错点

1. **$e$ 与 $a$ 的左右方向错**：中序 $e,a$ 只说明 $e$ 在 $a$ 的**左边**（$e$ 是 $a$ 的左孩子或 $a$ 左子树中的结点），若挂成右孩子，重算的中序变为 $a,e$ 与题面不符 ⟹ 养成"建完回对"的习惯；
2. **用前序切分、用中序定根**：分工记反。口诀——**前序（后序）给"谁是根"，中序给"哪些在左、哪些在右"**；
3. **前序中子树区间长度取错**：左子树结点数必须取自**中序切分的结果**（$4$ 个），再到前序里取同样长度的前缀；若按直觉多取或少取一个，后面整棵子树都会错位；
4. **误以为"前序 + 后序"也能定树**：两者都只定位根，无法区分左右，答案不唯一；同理"中序 + 后序"可以（后序定根、中序切分），"中序 + 层次"也可（DS-2006-36），但切分方法不同，不要照搬；
5. **字母与结点漏数**：$6$ 个结点的树后序也必须恰好 $6$ 个字母，写完后数一遍个数、并核对每个字母恰出现一次（漏掉 $f$ 或重复 $e$ 是常见的笔误型错误）；
6. **把根写错位置**：后序的根一定在序列末尾、前序的根一定在开头。若答案写作 $b,c,e,a,d,f$ 之类把 $b$ 放前面，说明把前序当成后序输出。

## 10. 一句话规律

"两序列定一棵树"永远是三步循环：**前序（或后序、层次）取根 → 中序定左右分界 → 回到第一个序列按长度切区间**，一路递归到区间长度 $\le1$；建完必把两条已知序列重算一遍回对，再读所求序列——根的位置（后序在末、前序在首）与"父在子后/子在父后"的次序是三条免费的快速校验。
