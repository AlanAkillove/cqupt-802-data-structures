# DS-2015-46

## 1. 原题

设计一算法，使得在尽可能少的时间内重排数组，将所有取负值的关键字放在所有取非负值的关键字之前。

（1）先给出算法思想；

（2）再描述具体算法，必要时请给予注释说明；

（3）请分析算法的时间复杂度。

## 2. 答案

**主解（原地、最快）**：借用快速排序"一趟划分"的思想——以"负数 / 非负数"为判据，设置两个下标 $i$（从左向右）与 $j$（从右向左）：$i$ 跳过已就位的负数、$j$ 跳过已就位的非负数，当 $A[i]$ 为非负而 $A[j]$ 为负时交换二者；$i=j$ 时划分完成。时间 $O(n)$，空间 $O(1)$，**不稳定**。

```c
/* 重排 A[0..n-1]：所有负数移到所有非负数之前；O(n) 时间、O(1) 附加空间 */
void Divide(int A[], int n)
{
    int i = 0, j = n - 1, t;
    while (i < j) {
        while (i < j && A[j] >= 0)  j--;     /* 自右向左找一个负数 */
        while (i < j && A[i] <  0)  i++;     /* 自左向右找一个非负数 */
        if (i < j) {                          /* 左右各找到一个"错位"元素 */
            t = A[i]; A[i] = A[j]; A[j] = t;  /* 交换，二者同时就位 */
            i++; j--;
        }
    }
}
```

**备选解（保持稳定）**：用辅助数组做两趟筛选，先抄负数再抄非负数。时间 $O(n)$，空间 $O(n)$，**稳定**。

```c
void DivideStable(int A[], int n)
{
    int *B = (int *)malloc(n * sizeof(int));  /* 等长辅助数组 */
    int k = 0, i;
    for (i = 0; i < n; i++) if (A[i] <  0) B[k++] = A[i];   /* 先按原序放负数 */
    for (i = 0; i < n; i++) if (A[i] >= 0) B[k++] = A[i];   /* 再按原序放非负数 */
    for (i = 0; i < n; i++) A[i] = B[i];                    /* 回写 */
    free(B);
}
```

## 3. 题目分析

- 已知：含 $n$ 个整数的一维数组，元素可正、可负、可为 $0$；
- 目标：把数组重排成"负数段在前、非负数段在后"，**只要求分区，不要求各段内部有序**；
- 关键约束："尽可能少的时间"——$O(n^2)$ 的冒泡式交换不满足要求，应做到线性时间；此外隐含两条常见评分要求：**只用常数附加空间**、**只扫描一趟数组**；
- 概念澄清：题面说"负值"与"非负值"，故 $0$ 归入**后段**（判据是 `A[i] < 0` 与 `A[i] >= 0`，不是 `> 0`）；
- 命题意图：考"快速排序一趟划分"这一**基本操作思想的迁移**（把"以 pivot 为界"换成"以 $0$ 为界"），与 DS01.02.01 顺序表的原地访问能力（随机存取使双指针成为可能）。本题与教材 10.3 节的 `Partition` 只差一个判别条件。

## 5. 解题思路

1. **先排除低效解**：双重循环"发现逆序对就交换"最坏 $O(n^2)$，不满足"尽可能少的时间"；
2. **想清不变式**：扫描过程中始终保持"$A[0..i-1]$ 全为负数、$A[j+1..n-1]$ 全为非负数"，中间 $A[i..j]$ 是未检查区；每处理一个元素要么 $i$ 右移、要么 $j$ 左移，故总步数 $\le n$；
3. **两个内层循环必须带 $i<j$**：否则全负或全非负时指针会越界；
4. **交换后同时 $i\mathrel{+}\mathrel{+}$、$j\mathrel{-}\mathrel{-}$**：被交换的两个元素已各自就位，不必再比较（不写也能正确运行，但会多两次比较）；
5. **用四类数据自测**：混合、全负、全非负、含 $0$，逐一在草稿上走查指针移动；
6. 若题目追加"保持相对次序"，则改用辅助数组两趟筛选（主解不稳定是其固有缺陷，必须换方法而非修补）。

## 6. 详细解答

**（1）算法思想（卷面表述）**

把"负数在前、非负数在后"看成以 $0$ 为分界的一次划分。设两个下标 $i$、$j$ 分别指向待处理区间的左端与右端：$i$ 自左向右跳过已经是负数的元素，找到第一个非负元素；$j$ 自右向左跳过已经是非负数的元素，找到第一个负元素；此时 $A[i]$、$A[j]$ 恰好"站错位置"，交换它们使二者同时就位，并令 $i$ 右移、$j$ 左移。重复上述过程直到 $i=j$，此时 $i$ 左边（含已交换部分）全为负数、$j$ 右边全为非负数，划分完成。整个过程每个元素至多被访问常数次，故为线性时间；只用了 $i,j,t$ 三个辅助变量，故为原地算法。

**（2）正确性论证（不变式）**

循环不变式：每轮开始时
 $$A[0..i-1]\ \text{全为负数},\qquad A[j+1..n-1]\ \text{全为非负数}$$

- **初值**：$i=0,\;j=n-1$ 时两个区间为空，不变式平凡成立；
- **保持**：内层第一个 $while$ 使 $j$ 停在 $A[j]<0$ 处（或 $i=j$）；内层第二个 $while$ 使 $i$ 停在 $A[i]\ge 0$ 处（或 $i=j$）。若仍有 $i<j$，则交换 $A[i]$ 与 $A[j]$ 后，新的 $A[i]$ 为负、新的 $A[j]$ 非负，于是 $i\mathrel{+}\mathrel{+}$、$j\mathrel{-}\mathrel{-}$ 之后不变式重新成立。若内层循环是因 $i=j$ 而终止，则未交换任何东西，不变式依旧成立；
- **终止**：外层 $while$ 结束时 $i\ge j$，即 $A[0..i-1]$ 与 $A[j+1..n-1]$ 两段首尾相接覆盖整个数组（$i>j$ 时甚至重叠），故全数组满足"负数在前、非负数在后"。

**（3）样例走查**

**例 1**：$A=(-3,\;5,\;-2,\;8,\;0,\;-7,\;4,\;-1)$，$n=8$，$i=0,j=7$

| 轮 | $i$ 停在 | $j$ 停在 | 动作 | 数组状态 |
|---|---|---|---|---|
| 1 | $i=1$（$5\ge0$） | $j=7$（$-1<0$） | 交换 $A[1],A[7]$ | $(-3,\mathbf{-1},-2,8,0,-7,4,\mathbf{5})$，$i=2,j=6$ |
| 2 | $i=3$（$8\ge0$） | $j=5$（$-7<0$） | 交换 $A[3],A[5]$ | $(-3,-1,-2,\mathbf{-7},0,\mathbf{8},4,5)$，$i=4,j=4$ |
| 3 | — | — | $i=j=4$，外层循环退出 | $(-3,-1,-2,-7,0,8,4,5)$ |

结果前 $4$ 个全为负、后 $4$ 个全为非负 ✓，共 $2$ 次交换、$8$ 次元素访问（$i$ 走 $4$ 步、$j$ 走 $4$ 步）。

**例 2（全负）**：$A=(-5,-2,-9)$，$i=0,j=2$：$A[2]<0$ 故 $j$ 不动；第二个内层循环把 $i$ 一路推到 $i=j=2$；`if` 不成立；外层 $i<j$ 不成立退出。数组不变 ✓（无越界）。

**例 3（全非负）**：$A=(3,0,7)$，$i=0,j=2$：第一个内层循环把 $j$ 一路退到 $j=0$（$A[0]=3\ge0,A[1]=0\ge0,A[2]=7\ge0$）；此时 $i=j=0$，两个内层循环与 `if` 均不执行，外层退出。数组不变 ✓。

**例 4（含 0 与等值负数）**：$A=(0,-1,0,-1)$，$i=0,j=3$：$A[3]=-1<0$ 故 $j$ 停在 $3$；$A[0]=0\ge0$ 故 $i$ 停在 $0$；交换 $A[0]$ 与 $A[3]$ → $(-1,-1,0,0)$，$i=1,j=2$；下一轮 $A[2]=0\ge0$ 使 $j$ 退到 $1$，$i=j=1$，外层循环退出。最终 $(-1,-1,0,0)$ ✓（两个 $0$ 全部落在后段）。

**（4）复杂度分析**

- **时间**：外层每轮至少使 $i$ 右移或 $j$ 左移（内层扫描的步数与交换次数之和不超过 $n$），故元素比较次数 $\le n$、交换次数 $\le \lfloor n/2\rfloor$，总时间复杂度 $T(n)=O(n)$，且已是最优（任何正确算法至少要读一遍数组，下界 $\Omega(n)$）；
- **空间**：仅 $i,j,t$ 三个辅助变量，$S(n)=O(1)$，原地算法；
- **稳定性**：**不稳定**。例 1 中原序列负数的相对次序为 $-3,-2,-7,-1$，结果为 $-3,-1,-2,-7$，$-1$ 被提到了 $-2,-7$ 前面；非负数 $5,8,0,4$ 变为 $0,8,4,5$ 同样被打乱。若题目要求稳定，须改用第（5）步的辅助数组法。

**（5）备选解（稳定版）的分析与走查**

$A=(-3,5,-2,8,0,-7,4,-1)$：第一趟抄出负数得 $B=(-3,-2,-7,-1)$，第二趟抄出非负数得 $B=(-3,-2,-7,-1,5,8,0,4)$，回写。
两段内部**完全保持原相对次序** ✓。时间 $3n=O(n)$，空间 $n$ 个整数的辅助数组 $=O(n)$。

两法对比：

| 方案 | 时间 | 空间 | 稳定性 | 适用场合 |
|---|---|---|---|---|
| 双指针划分（主解） | $O(n)$ | $O(1)$ | 不稳定 | 题面强调"尽可能少的时间"、未要求保序——**本题首选** |
| 辅助数组两趟筛选 | $O(n)$ | $O(n)$ | 稳定 | 追加"保持原有相对次序"时 |

## 8. 考场标准答案

**(1) 算法思想**：以 $0$ 为分界作一次划分。令 $i$ 从头、$j$ 从尾相向扫描：$i$ 跳过负数直到遇到非负数，$j$ 跳过非负数直到遇到负数，两者都停下且 $i<j$ 时交换 $A[i]$ 与 $A[j]$（交换后二者同时就位），$i$ 右移、$j$ 左移；当 $i=j$ 时结束，此时 $i$ 之前全为负数、$i$ 之后全为非负数。每个元素至多被访问一次，故为线性时间，且只花常数附加空间。

**(2) 代码**：见第 2 节 `Divide`（含注释）。

**(3) 时间复杂度**：元素比较至多 $n$ 次、交换至多 $\lfloor n/2\rfloor$ 次，$T(n)=O(n)$；附加空间 $S(n)=O(1)$。该算法不稳定（若要求稳定则用 $O(n)$ 空间的辅助数组两趟筛选法）。

## 9. 易错点

1. **判据写成 $A[i]>0$**：题面是"负值"与"非负值"，$0$ 必须落在后段，判据应为 `A[i] < 0` 与 `A[j] >= 0`；写成 `A[j] > 0` 会把 $0$ 挤到负数前面；
2. **内层 $while$ 漏写 $i<j$**：全负或全非负时指针会冲出数组边界（越界访问），这是本题最常见的扣分点；
3. **交换后忘记 $i\mathrel{+}\mathrel{+}$、$j\mathrel{-}\mathrel{-}$**：结果仍正确但会多两次比较；更糟的是若把交换改成"只 $i\mathrel{+}\mathrel{+}$"则可能死循环；
4. **初值 $j$ 取 $n$**：数组下标是 $0..n-1$，$j$ 必须初始化为 $n-1$；
5. 用"额外数组按正负分两次拷贝"当主解却不交代空间：那会把空间从 $O(1)$ 变成 $O(n)$，与"尽可能少的时间"虽不冲突，但若卷面未说明就容易被追问；
6. 声称该算法"稳定"：划分式重排天然不稳定，须举出反例（如本题例 1 中 $-1$ 被提前）；
7. 误以为还要"各段内部有序"：题目只要求分区，**不需要**再排序，多做排序会把 $O(n)$ 变成 $O(n\log n)$。

## 10. 一句话规律

"把满足某条件的元素全部移到前面 + 要求快"的题，一律套**快排一趟划分的双指针模板**——左右各找一个"错位"元素、交换、相向移动，两个内层循环都要带 $i<j$ 防越界；时间 $O(n)$、空间 $O(1)$、结论"不稳定"三句话一起写全。
