# DS-2015-47

## 1. 原题

设计一算法判断某一二叉树是否为二叉排序树。

（1）二叉树用二叉链表的形式表示，定义如下：

（2）先给出算法思想，再描述算法，必要时请给予注释说明。

```c
typedef struct node
{ 
    DataType data; 
    struct node *lchild,*rchild; 
}BinTNode;
```

## 2. 答案

**算法思想**：二叉排序树（BST）的**中序遍历序列必为严格递增序列**；反之，中序序列严格递增的二叉树必为二叉排序树。因此只需对二叉树做一次中序遍历，在访问每个结点时把它与**刚刚访问过的前驱结点**比较：若前驱的关键字不小于当前结点的关键字，则中序序列不严格递增，该树不是二叉排序树。用一个全局指针 `pre` 保存中序前驱即可，无需额外数组。

```c
typedef struct node
{
    DataType data;
    struct node *lchild, *rchild;
} BinTNode, *BinTree;

BinTNode *pre = NULL;                 /* 全局变量：中序遍历中的直接前驱结点 */

/* 判断 T 是否为二叉排序树：是返回 1，否返回 0 */
int IsBST(BinTree T)
{
    if (T == NULL)  return 1;                       /* 空树是二叉排序树 */
    if (!IsBST(T->lchild))  return 0;               /* ① 左子树必须是 BST */
    if (pre != NULL && pre->data >= T->data)        /* ② 中序前驱必须严格小于当前结点 */
        return 0;
    pre = T;                                        /* ③ 当前结点成为后继的前驱 */
    return IsBST(T->rchild);                        /* ④ 右子树必须是 BST */
}
```

调用前须置 `pre = NULL;`（`pre` 为全局变量时，同一程序内多次调用要**逐次重置**）。

**备选解（区间法，不用全局变量）**：

```c
/* 检查 T 的所有关键字是否落在 (low, high) 开区间内；无下界/上界时用 flag 屏蔽比较 */
int IsBSTRange(BinTree T, DataType low, DataType high, int hasLow, int hasHigh)
{
    if (T == NULL) return 1;
    if (hasLow  && T->data <= low)  return 0;       /* 不大于下界 */
    if (hasHigh && T->data >= high) return 0;       /* 不小于上界 */
    return IsBSTRange(T->lchild, low,  T->data, hasLow,  1)   /* 左子树上界收紧为根 */
        && IsBSTRange(T->rchild, T->data, high, 1, hasHigh);  /* 右子树下界收紧为根 */
}
```

## 3. 题目分析

- 已知：以二叉链表存储的二叉树，结点类型如题面所给（`DataType data; lchild; rchild;`），未说明 `DataType` 具体类型；
- 目标：返回"是/否二叉排序树"的判定结果；
- 关键约束：
  - 必须**整棵树**都满足 BST 定义——每个结点的左子树**所有**结点 $<$ 该结点 $<$ 右子树**所有**结点，而不只是"结点与自己左右孩子"的大小关系；
  - 教材对二叉排序树的定义中关键字**互不相同**，故判据是"严格递增"，出现相等即判非（`>=` 而不是 `>`）；
  - `DataType` 未指定，卷面按整型比较书写即可；若为字符串，把 `pre->data >= T->data` 换成 `strcmp(pre->data, T->data) >= 0`；
- 命题意图：考 DS05.07.01 的核心性质"BST ⇔ 中序严格递增"，以及把该性质落成一次带"游标"的中序遍历（DS03.02.03.02）的能力。本库 DS-2024-21 为同题（"编写代码及思想，判断一棵树是否为二叉排序树，结构体已给出"），可对照练习。

解释：本题的"算法设计"分量不大，真正的考点是**判据选得对不对**（整棵树 vs 局部父子）与**边界处理全不全**（空树、等值、单支退化）。

## 5. 解题思路

1. 从定义出发找等价判据：BST 的定义是递归的（左子树所有 $<$ 根 $<$ 右子树所有，且左右子树本身也是 BST），直接按定义写需要"子树最大值/最小值"，比较繁琐；
2. 换成中序判据：中序遍历"左→根→右"恰好把"左子树所有结点、根、右子树所有结点"按顺序输出，所以 BST 的中序序列严格递增，且其逆否命题也成立——这是最简判据；
3. 遍历过程中不存数组，只存"上一个访问的结点" `pre`，比较后更新——把 $O(n)$ 空间降为 $O(1)$；
4. 递归返回时若已判非，必须**逐层向上返回 0**（写成 `if (!IsBST(...)) return 0;` 而不是丢掉返回值）；
5. 用四类树自测：正常 BST、左右孩子大小颠倒的树、含相等关键字的树、"父子局部满足但整体不满足"的树（第 9 节反例）。

## 6. 详细解答

**（1）判据的等价性证明（算法思想的理论依据）**

设二叉树 $T$ 的中序序列为 $S(T)$。

- **必要性**：若 $T$ 是 BST，则对任意结点 $x$，其左子树全部结点 $<x<$ 其右子树全部结点。中序遍历按"左子树序列、$x$、右子树序列"拼接，对结点数归纳可证 $S(T)$ 严格递增；
- **充分性**：若 $S(T)$ 严格递增，则对任意结点 $x$，$x$ 的左子树的所有结点在 $S(T)$ 中都排在 $x$ 之前，故关键字都小于 $x$；右子树的所有结点都排在 $x$ 之后，故关键字都大于 $x$；这正满足 BST 定义（对每结点成立，故整棵树成立）。

因此"中序严格递增"与"是 BST"等价，判定算法只需检查相邻两项是否递增。

**（2）算法执行过程说明**

递归按中序"左→根→右"推进。每当程序走到"访问根"这一步（即 `pre = T;` 之前），`pre` 指向的正是中序序列中 $T$ 的**直接前驱**。于是：

$$\text{若 } pre\neq NULL \text{ 且 } pre\texttt{->}data \ge T\texttt{->}data,\ \text{则 } S(T) \text{ 在该处出现"不升"，判非 BST}$$

三个语句的顺序不可调换：必须先递归左子树、再比较、再更新 `pre`、最后递归右子树。

**（3）走查验证**

**例 1（是 BST）**：取本卷第 39 题构造出的树

```
        36
       /  \
     31    66
    /  \   /
  20   32 48
```

中序访问次序：$20\to31\to32\to36\to48\to66$。逐次比较：$(20,31),(31,32),(32,36),(36,48),(48,66)$ 全部满足 $pre<T$ ✓，`pre` 依次更新，最终返回 $1$ ✓。

**例 2（不是 BST：孩子大小颠倒）**：把例 1 中的 $32$ 改为 $30$。中序序列 $20,31,30,36,48,66$；访问 $30$ 时 `pre` 指向 $31$，$31\ge 30$ → 立即返回 $0$ ✓。

**例 3（不是 BST：局部满足、整体不满足）**——本题最关键的测试用例：

```
      60
     /
   30
     \
     70
```

结点 $70$ 在 $60$ 的**左子树**中，却大于 $60$，故不是 BST。但"只比较结点与其左右孩子"的做法会判它是 BST（$30<60$ ✓、$70>30$ ✓）。本算法：中序序列为 $30,70,60$；访问 $60$ 时 `pre` 指向 $70$，$70\ge 60$ → 返回 $0$ ✓ 正确识别。

**例 4（含相等关键字）**：根 $50$、左孩子 $50$。中序 $50,50$；第二次访问时 `pre->data >= T->data`（$50\ge50$ 成立）→ 返回 $0$ ✓（教材 BST 定义要求关键字互不相同）。

**例 5（空树与单结点）**：`IsBST(NULL)` 直接返回 $1$ ✓；单结点树时左子树为空、`pre` 为 `NULL` 故跳过比较、`pre=T`、右子树为空 → 返回 $1$ ✓。

**例 6（退化为单支）**：全部结点只有右孩子且递增 $10\to20\to30$，中序即 $10,20,30$ ✓ 判为 BST（BST 允许不平衡）。

**（4）交叉验证：区间法**

对例 3：进入根 $60$（无界）→ 递归左子树 $30$，上界收紧为 $60$ → 递归 $30$ 的右子树 $70$，下界 $30$、上界 $60$，$70\ge 60$ → 返回 $0$ ✓。两法对六个例子结论完全一致。

**（5）复杂度分析**

- **时间**：每个结点至多被访问一次，每次访问做常数次工作（一次比较 + 一次指针赋值），故 $T(n)=O(n)$，$n$ 为结点数；一旦提前判非则更早结束；
- **空间**：除 `pre` 外只有递归工作栈，深度等于树高 $h$，故 $S(n)=O(h)$；最好（平衡）$O(\log n)$，最坏（单支退化）$O(n)$。若改用"中序结果存入数组再逐个比较"，空间将固定为 $O(n)$，本解法优于之；
- 区间法同样 $O(n)$ 时间、$O(h)$ 栈空间，但每层多传两个界值参数。

## 8. 考场标准答案

**算法思想**：二叉排序树的中序遍历序列必为严格递增序列，反之亦然。故只需做一次中序遍历，用全局指针 `pre` 记住刚刚访问过的结点；访问当前结点 $T$ 时，若 `pre` 非空且 `pre->data >= T->data`，说明中序序列出现"不升"，该树不是二叉排序树，返回 $0$；否则令 `pre = T` 后继续遍历右子树。空树规定为二叉排序树，返回 $1$。

**代码**：见第 2 节 `IsBST`（含注释，调用前置 `pre = NULL;`）。

**复杂度**：时间 $O(n)$；空间为递归栈 $O(h)$（$h$ 为树高，最坏 $O(n)$）。

## 9. 易错点

1. **只比较"结点与其左右孩子"**（本题最大的坑）：写成 `if (T->lchild->data > T->data || T->rchild->data < T->data) return 0;` 是**错误**的。反例见例 3——$60$ 的左孩子的右孩子为 $70$，父子局部全部满足，但整棵树不是 BST。必须保证"左子树**所有**结点 $<$ 根 $<$ 右子树**所有**结点"，用中序前驱或上下界区间才能覆盖；
2. **判据写成 `>` 而非 `>=`**：教材 BST 定义中关键字互不相同，出现相等即不是 BST；
3. **`pre` 忘记更新或更新时机错**：必须在比较**之后**、进入右子树**之前**执行 `pre = T;`；若放在递归左子树之前，比较的就不是直接前驱；
4. **`pre` 未初始化 / 多次调用未重置**：全局 `pre` 在第二次调用时仍残留上次的值，会把上一棵树的最后结点当作前驱而误判；应在外层包装函数里置 `pre = NULL;`；
5. **比较前未判 `pre != NULL`**：第一次访问（最左结点）时 `pre` 为空，直接解引用会崩溃；
6. **丢失递归返回值**：写成 `IsBST(T->lchild); if (...) return 0;` 会让左子树的判定结果被忽略；必须 `if (!IsBST(T->lchild)) return 0;`；
7. 忽略空树：`T == NULL` 应返回 $1$（空树是 BST），漏写会使整棵树的返回值取决于后续分支；
8. 用"把中序序列存进数组再比较相邻元素"的写法：结果正确，但空间从 $O(h)$ 升到 $O(n)$，卷面应说明取舍；
9. `DataType` 为字符串时直接用 `>=` 比较的是指针而非内容，须改 `strcmp`（本题按整型书写即可，但可加注说明）。

## 10. 一句话规律

"判断是否 BST"的标准模板就一句话——**中序遍历 + 一个前驱指针**：`if (pre && pre->data >= T->data) return 0; pre = T;`；凡是"只比父子"的写法一律错，凡是不用中序性质而直接按定义递归的，改用"上下界区间"也等价可行。
