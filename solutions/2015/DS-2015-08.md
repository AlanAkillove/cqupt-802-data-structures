# DS-2015-08

## 1. 原题

链表不具有的特点是（）。

A. 可随机访问任一元素

B. 插入、删除不需要移动元素

C. 不必事先估计存储空间

D. 所需空间与线性表长度成正比

## 2. 答案

**A**（可随机访问任一元素）。

## 3. 题目分析

- 已知：四个关于"链表"（以单链表为代表）的特点陈述，要求挑出**链表不具备**的那一个——注意本题是否定式问法，方向与其他"选优点"题相反；
- 目标：逐项判定每条陈述是否为链表的真实属性；
- 关键约束：**随机访问（随机存取）**在数据结构中有严格定义——能在与位置序号 $i$ 无关的常数时间 $O(1)$ 内直接定位到第 $i$ 个元素。顺序表靠"基址 $+$ 偏移量"的地址运算实现它；链表结点是任意散布在内存中的一块块，结点之间唯一的联系是指针，故定位只能沿链行走；
- 命题意图：考查"顺序存储 vs 链式存储"两类结构特点的辨析，尤其是把"随机访问"这一术语与普通语意上的"随便访问哪个元素"区分开——链表当然能访问到任一元素（遍历即可），但**不能随机（直接）访问**。

## 4. 核心考点

核心考点：
DS01.02.02 链式存储：单链表（结址由指针链接、只能顺序存取、按需动态分配、空间与长度线性相关）

辅助考点：
DS01.02.01 顺序存储（顺序表：插入/删除/查找与移动次数）

解释："随机访问"是顺序存储的定义性能力，判断链表是否具备它，必须先有此参照才能说清"缺的是哪一条"；B、C、D 三项同样是与顺序表对比后得出的链表优点，故把顺序存储列为辅助考点。

## 5. 解题思路

1. 先把"随机访问"落到可操作判据上：是否存在 $O(1)$ 的"给序号即得元素"的方法（等价于能按下标做地址计算）；
2. 检查链表能提供什么：只有头指针 `head` 与每个结点内部的 `next`，因此要取第 $i$ 个结点必须从 `head` 起走 $i-1$ 步指针跟踪，代价随 $i$ 线性增长 ⟹ 无随机访问，A 项即答案；
3. 逐个确认 B、C、D 确实是链表**具有**的特点：B 靠修改指针（本卷第 7 题的顺序表搬移正是它的反面）；C 靠 `malloc` 按需取空间（顺序表须先定 `MaxSize`）；D 因 $n$ 个结点占用 $n\times$ 结点大小，是线性关系（指针域只让存储密度小于 $1$，不破坏正比）；
4. 用"平均比较次数"复核 A：若 $i$ 等概率取 $1\sim n$，成功访问第 $i$ 个结点平均需跟踪 $\frac{n-1}{2}$ 次指针，为 $\Theta(n)$，与随机访问要求的 $O(1)$ 相差一个数量级，结论稳固。

## 6. 详细解答

**（1）随机访问的判据与地址依据**

随机访问（random access）指：对任意合法的 $i$，定位第 $i$ 个元素所需时间不与 $i$ 有关，即 $O(1)$。

- 顺序表：元素 $a_i$ 的地址 $=\text{base}+(i-1)\times c$（`base` 为首地址、`c` 为元素占用的字节数），一次乘加即算出地址，硬件直接寻址 ⟹ **具有**随机访问；
- 链表：结点地址由分配器决定、彼此无算术关系（本卷第 3 题：地址连续与否都可以），第 $i$ 个结点的地址**无法由公式算出**，只能从 `head` 出发沿 `next` 逐跳 ⟹ **不具有**随机访问。

**（2）链表取第 $i$ 个元素的实际代价（教材风格 C）**

```c
Status GetElem_L(LinkList L, int i, ElemType &e)   /* L 为带头结点单链表 */
{
    p = L->next;  j = 1;                           /* 从第 1 个结点起计数 */
    while (p && j < i) { p = p->next; ++j; }       /* 顺链向后跟踪 i-1 次 */
    if (!p || j > i)  return ERROR;                /* 第 i 个元素不存在 */
    e = p->data;
    return OK;
}
```

跟踪次数 $=i-1$：访问表尾结点需走 $n-1$ 步。设访问各位置等概率，平均跟踪次数

$$\frac{1}{n}\sum_{i=1}^{n}(i-1)=\frac{n-1}{2}=\Theta(n)$$

即链表是**顺序访问**结构，A 项不成立（正是本题答案）。

**（3）确认 B、C、D 为链表具有的特点**

| 陈述 | 链表的实现机制 | 是否成立 |
|---|---|---|
| B. 插入、删除不需要移动元素 | 只修改前后结点的 `next`（前插：`s->next=p->next; p->next=s;`），其余结点原地不动；代价全在"找位置"上 | ✓ 具有 |
| C. 不必事先估计存储空间 | 每插入一个结点现场 `malloc`，表长可动态伸缩；不存在"表满溢出"需预留 `MaxSize` 的问题 | ✓ 具有 |
| D. 所需空间与线性表长度成正比 | $n$ 个结点耗空间 $n\times(\text{数据域}+\text{指针域})$，是 $n$ 的线性函数（比例为结点大小） | ✓ 具有 |

关于 D 的常见疑虑：链表的指针域是"额外开销"，使**存储密度**（数据域所占比例）小于 $1$（见 DS-2012-03），但"存储密度小于 $1$"与"空间与长度成正比"是两件事——前者说的是比例，后者说的是随 $n$ 的增长阶，链表的空间仍是 $\Theta(n)$，正比关系成立。

**（4）反向自检（把顺序表的四条特点列出来对照）**

| 特点 | 顺序表 | 单链表 |
|---|---|---|
| 随机访问任一元素 | ✓ | ✗（本题 A） |
| 插入/删除需移动元素 | 需（第 $i$ 位置插入搬 $n-i+1$ 个，本卷第 7 题） | 不需（B） |
| 需事先估计存储空间 | 需（定 `MaxSize`） | 不需（C） |
| 空间与长度成正比 | ✓（$n\times c$） | ✓（$n\times$ 结点大小，D） |

唯一"顺序表有而链表没有"的正是随机访问 ⟹ 选 A。

**答案**：A。

## 7. 选项分析

- A. 可随机访问任一元素：**链表不具有**，即本题答案。随机访问要求 $O(1)$ 定位，而单链表只能从头指针顺链行走，定位第 $i$ 个结点需 $i-1$ 次指针跟踪（平均 $\Theta(n)$）；"能访问到"与"能随机访问"不是一回事；
- B. 插入、删除不需要移动元素：链表具有。插删只改动常数个指针，其余结点原地不动——这是链表最主要的优点（其代价转化为"必须先查找到操作位置"，见 DS-2014-07、DS-2013-38）；
- C. 不必事先估计存储空间：链表具有。结点动态分配、表长可增可减，不必像顺序表那样预先声明最大容量；
- D. 所需空间与线性表长度成正比：链表具有。空间 $=n\times$ 结点大小，随 $n$ 线性增长；指针域只是使存储密度小于 $1$，并不改变正比关系。

## 8. 考场标准答案

选 **A**。

随机访问是指在与序号无关的常数时间内直接定位第 $i$ 个元素，它依赖"元素地址 $=$ 首址 $+$ 偏移量"的地址计算，只有连续的顺序存储能做到。链表的结点地址由指针链接、分布任意，访问第 $i$ 个结点必须从头指针起沿 `next` 走 $i-1$ 步，平均耗时与表长成正比（$\Theta(n)$），因此"可随机访问任一元素"是顺序存储的特点而非链表的特点。B（插删只改指针不搬元素）、C（按需动态分配空间）、D（空间 $=n\times$ 结点大小，与长度成正比）都是链表具有的特点。

## 9. 易错点

1. **把"不能随机访问"误读为"不能访问第 $i$ 个元素"**：链表当然能访问任何元素（遍历即可），缺的是"直接/等耗时"这一条；
2. 因指针域开销而误选 D：指针域影响的是**存储密度**（$<1$，见 DS-2012-03），不影响"空间随长度线性增长"的正比关系；顺序表空间 $=n\times c$ 同样是正比；
3. 忽略题干的否定式问法："不具有"，看到 B、C 这类正确表述反而下手（本库同类题 DS-2013-03 问"优点"，答案就落在 B/C 一侧，两题方向相反）；
4. 把"插入删除不需要移动元素"理解为"插入删除的时间复杂度是 $O(1)$"：不搬元素不等于快——若表头开始查找位置，整体仍是 $O(n)$（DS-2014-07 考的就是这一点），准确说法是"不需要移动元素"而非"运算耗时 $O(1)$"；
5. 与"链式存储地址可以不连续"混为一谈：那是本卷第 3 题的结论，是"不能随机访问"的原因，不是本题答案。

## 10. 一句话规律

判断"随机访问"只看一件事：能否用"首址 $+$ 序号 $\times$ 元素大小"一步算出地址——顺序存储能、链式存储只能顺链走；链表的三大优点（不搬元素、不需预估空间、空间与长度成正比）要与之严格分开记。
