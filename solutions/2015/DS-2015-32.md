# DS-2015-32

## 1. 原题

$G$ 为无向图，如果从 $G$ 的某个顶点出发进行一次遍历，即可访问图的每个顶点，则该图一定是____________________ 图。

## 2. 答案

**连通图**。

无向图的一次遍历（DFS 或 BFS）从起点出发，只能沿边逐步走到与起点有路径相通的顶点，即恰好访问起点的整个连通分量。题设说这一次遍历访问了全部顶点，说明 $G$ 只有一个连通分量，按定义 $G$ 是连通图。

## 3. 题目分析

- 已知：无向图 $G=(V,E)$；存在某个顶点 $v$，从 $v$ 出发做**一次**遍历（不重新换起点、不启动第二轮），访问到的顶点集合 $=V$；
- 目标：由这个观察事实推出 $G$ 一定具有的性质（填一个图的分类名称）；
- 关键约束：
  1. 遍历的可达性：DFS/BFS 都只把"当前已访问顶点的、尚未访问的邻接点"入栈/入队，故被访问到的顶点集恰为 $\{u\mid v$ 到 $u$ 存在路径$\}$，即 $v$ 所在的**连通分量**；
  2. 图的分类（无向图）：连通图——任意两顶点都有路径相通，等价于"仅一个连通分量"；非连通图——连通分量数 $\ge 2$，各分量之间没有边；
  3. 本题条件是"存在某个顶点"即可，而结论"连通图"意味着"任意顶点都行"——一旦图连通，起点选谁都覆盖全图，这两者等价，不必担心条件弱；
  4. 遍历方式不限：题面说"一次遍历"，DFS 与 BFS 都符合；由于覆盖集合与遍历方式无关（都是整个连通分量），答案与选 DFS 还是 BFS 无关（对比 2007 年第 34 题把方式指定为广度优先，答案相同）；
- 命题意图：考"连通分量"与"遍历覆盖范围"之间的对应关系（DS04.01 概念层），并用它解释为什么教材的图遍历算法 `DFSTraverse` 必须外层再套一个"对每个顶点检查、未访问则从它出发再来一次"的循环——那个循环正是为非连通图准备的（见 6.3）。

## 4. 核心考点

核心考点：
DS04.01 图的基本概念（无向图的连通性、连通图与连通分量的定义、极大连通子图）

辅助考点：
DS04.03.01 深度优先搜索（DFS）与 DS04.03.02 广度优先搜索（BFS）：两者都是"从给定起点出发、沿边扩展、只访问可达顶点"的搜索过程，是题面"一次遍历"的具体所指

解释：判据本身是遍历的行为特征（一次搜索＝覆盖一个连通分量），但要用它作逻辑推断，必须先有"连通图 ⟺ 只有一个连通分量"这条定义级等价关系，故主考点定在 DS04.01，两种遍历算法作为理解题面的辅助背景（本题不要求真的执行某种遍历、也不要求写序列）。

## 5. 解题思路

1. **把"一次遍历"翻译成集合语言**：从 $v$ 出发的一次遍历访问的顶点集合 $R(v)=\{u:\ v\leadsto u\}$，即 $v$ 的可达集 $=$ $v$ 所在连通分量的顶点集；
2. **用上题设**：$R(v)=V$（全部顶点都被访问）；
3. **反证**：若 $G$ 不连通，则存在至少两个连通分量，$V$ 被划分为若干互不相连的极大部分；$v$ 只属于其中一个，另一部分中任取顶点 $u$，$v$ 到 $u$ 无线可走 ⟹ $u\notin R(v)$，与题设矛盾；
4. **得结论**：$G$ 只有一个连通分量 ⟹ $G$ 是连通图；
5. **确认方向**：题问"一定是____图"，是必要条件方向（观察事实 ⟹ 分类），不必证"连通图一定满足该观察"（那也成立，但题面没问）；顺手确认答案不是"生成树""强连通"等其它术语：强连通针对有向图，题面已声明无向图。

## 6. 详细解答

### 6.1 定义与等价关系

- **连通**：若无向图 $G$ 中顶点 $v_i$ 到 $v_j$ 存在一条路径，则称 $v_i,v_j$ 连通；
- **连通图**：若 $G$ 中**任意**两个顶点都连通，则称 $G$ 为连通图；
- **连通分量**：$G$ 的**极大连通子图**。任何无向图（含非连通图）都可唯一分解为若干个连通分量，不同分量之间没有边相连。

三条概念串成一条等价链：

$$G\ \text{是连通图}\ \Longleftrightarrow\ G\ \text{的连通分量个数为}\ 1\ \Longleftrightarrow\ \text{任一顶点的可达集} = V$$

### 6.2 遍历的覆盖范围（核心论证）

以 DFS 为例（BFS 同理），其递归过程是

```c
void DFS(Graph G, int v) {
    visited[v] = TRUE;          /* 访问顶点 v */
    for (Each w adjacent to G.vertices[v])
        if (!visited[w]) DFS(G, w);
}
```

归纳可证：`DFS(G, v)` 结束时被标记 `visited` 的顶点集恰为 $v$ 的可达集。

- **不遗漏**：可达集内任一顶点 $u$，取 $v\leadsto u$ 的一条最短路径，沿该路径逐步递归必然把 $u$ 访问到；
- **不越界**：算法只在"邻接"关系上前进，被访问的顶点当然与 $v$ 有路径。

于是"从 $v$ 出发一次遍历访问所有顶点" $\Longleftrightarrow$ $v$ 的可达集 $=V$ $\Longleftrightarrow$ 整个图就是 $v$ 的一个连通分量，且没有别的分量。

### 6.3 反证与对照：非连通图为什么做不到

设 $G$ 有两个分量 $C_1\ni v$、$C_2\ne\varnothing$。任取 $u\in C_2$：$C_1,C_2$ 之间无边 ⟹ $v$ 到 $u$ 不可达 ⟹ 该次遍历不会访问 $u$，"即可访问图的每个顶点"被推翻。

这也解释了教材里图遍历的完整写法为什么要加外层循环：

```c
void DFSTraverse(Graph G) {          /* 非连通图的完整遍历：需多次调用 DFS */
    for (v = 0; v < G.vexnum; ++v) visited[v] = FALSE;
    for (v = 0; v < G.vexnum; ++v)
        if (!visited[v]) DFS(G, v);  /* 每个连通分量各启动一次 */
}
```

**外层循环启动 `DFS` 的次数 $=$ 连通分量的个数**。题设说"一次即可"，等于宣告分量数为 $1$，即连通图——这是本题最本质的读法。

### 6.4 实例验证（$n=4$ 的两个对照图）

| 图 | 边集 | 是否连通 | 从 $v_1$ 一次 DFS 的访问集 | 是否覆盖全部 $4$ 个顶点 |
|---|---|---|---|---|
| $G_1$ | $(v_1,v_2),(v_2,v_3),(v_3,v_4)$ | 连通（一条链） | $\{v_1,v_2,v_3,v_4\}$ | ✓ 与题设一致 |
| $G_2$ | $(v_1,v_2),(v_3,v_4)$ | 非连通（$2$ 个分量） | $\{v_1,v_2\}$ | ✗ 遗漏 $v_3,v_4$ |

$G_2$ 即使换成 BFS、即使把起点换成别的顶点，一次搜索都只覆盖一个分量，验证了"非连通 ⟹ 不可能一次遍历覆盖全图"。

### 6.5 结论

**答案**：连通（图）。

不适用（填空题）。

## 8. 考场标准答案

一次遍历（DFS 或 BFS）只能访问与起点有路径相通的全部顶点，即起点所在的**一个连通分量**。题设该次遍历访问了图的每个顶点，说明 $G$ 只有一个连通分量，故 $G$ 一定是 $\boxed{\text{连通}}$ 图。

## 9. 易错点

1. **答成"强连通图"**：强连通是**有向图**的概念（任意两顶点互可达需沿弧方向），题面首句已限定"$G$ 为无向图"，术语要用错对象；有向图对应的答案才是强连通/弱连通；
2. **答成"连通分量"**：填空处要的是"该图一定是____图"这一整体分类名称，"连通分量"是极大连通**子**图，用来描述局部而非整个图；
3. **误答"完全图"**：题设条件只保证"有路径可达"，不保证"两两有边"——链 $v_1-v_2-v_3-v_4$ 就是连通但远非完全的反例（本库 DS-2013-34 的单循环赛场次对应的是完全图边数 $n(n-1)/2$，那是更强条件，两者别混）；
4. **答成"有 $n-1$ 条边的图"**：连通只要求**至少** $n-1$ 条边（本库 DS-2013-30、DS-2014-31），$n-1$ 条边且连通即树，但题设并未限定边数，不能反过来把"一定是"落到边上；
5. **忽略"一次"这个关键词**：若题面允许换起点多次启动搜索，则任何图（含非连通图）都能被完整"走遍"，结论就不成立；"一次"正是把分量数钉成 $1$ 的那个约束，读题要圈出它；
6. **以为起点指定很重要**：连通图中任取起点都满足题设，非连通图中任取起点都不满足；"存在某个顶点"与"任意顶点"在此等价，不必在这一点上纠结。

## 10. 一句话规律

无向图遍历的"一次"等于"一个连通分量"：`DFSTraverse` 外层循环启动搜索的次数就是连通分量个数，所以"从某顶点出发一次遍历就能访问所有顶点" ⟺ 分量数为 $1$ ⟺ 连通图。看到这类题先问三件事：图是有向还是无向（决定用"连通"还是"强连通"）、允许几次搜索（"一次"是关键约束）、结论问的是不是整体分类（不要答成子图术语）。
