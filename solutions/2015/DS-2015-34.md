# DS-2015-34

## 1. 原题

已知一个无向图的邻接矩阵表示，计算第 $j$ 个结点的度的方法是____________________ 。

## 2. 答案

**统计邻接矩阵第 $j$ 行中非零元素（即边存在标记 $1$）的个数**：

$$TD(j)=\sum_{i=1}^{n}\big(A[j][i]\neq 0\big)\qquad(\text{0/1 矩阵时即 } TD(j)=\sum_{i=1}^{n}A[j][i])$$

由于无向图的邻接矩阵关于主对角线对称，"第 $j$ 行"换成"第 $j$ 列"结果相同，两种写法都算对。

## 3. 题目分析

- 已知：无向图 $G=(V,E)$，$|V|=n$，以邻接矩阵 $A=(a_{ij})_{n\times n}$ 存储，$a_{ij}=1$（或 $\mathrm{TRUE}$）表示 $(v_i,v_j)\in E$，$a_{ij}=0$ 表示无边；求第 $j$ 个结点的度；
- 目标：给出一个**方法**（描述性填空，不要求具体数值），即一条"从矩阵到度"的计算规则；
- 关键约束：
  1. 度的定义：无向图中顶点 $v_j$ 的度 $=$ 与 $v_j$ 关联的边的条数（DS04.01）；
  2. 矩阵元素的语义：第 $j$ 行第 $i$ 列为 $1$ ⟺ 边 $(v_j,v_i)$ 存在，即 $v_i$ 是 $v_j$ 的邻接点。因此"第 $j$ 行里 $1$ 的个数" $=$ "$v_j$ 的邻接点个数" $=$ $\deg(v_j)$；
  3. 对称性：$(v_j,v_i)$ 与 $(v_i,v_j)$ 是同一条边 ⟹ $a_{ji}=a_{ij}$，故行和与列和等价（这一点在有向图中不成立，见 6.3）；
  4. 对角线：无向图一般约定无自环，$a_{jj}=0$；若允许自环，则自环在矩阵中只占对角线一个位置，却应给该顶点贡献 $2$ 度，需要按约定另加（见 6.4）；
  5. 若是**网**（带权图）的邻接矩阵，"无边"常记为 $\infty$ 而非 $0$，此时判据要换成"非 $\infty$ 且非对角元"，见 6.5；
- 命题意图：考邻接矩阵"存储元素 ↔ 图的边"的双向翻译能力（DS04.02.01），并顺带考"无向图矩阵对称 ⟹ 行列等价"和"有向图必须分入度/出度"的对比意识。同一题面在 2007 年第 32 题原样出现过；本卷第 19 题（邻接矩阵的空间只与顶点数有关）、第 33 题（度和 $=2e$）与本题同属图的存储与基本概念组。

## 4. 核心考点

核心考点：
DS04.02.01 邻接矩阵法（$a_{ij}$ 的取值与边的对应关系、无向图矩阵的对称性、主对角线约定）

辅助考点：
DS04.01 图的基本概念（无向图中顶点的度的定义——决定"要求什么"）；DS04.03.01 深度优先搜索（教材 DFS 中"扫描第 $v$ 行找邻接点"的循环正是本方法的算法化形态）

解释：答案必须由两条知识拼起来才完整——只知"度"不知道矩阵元素含义，无法给出算法；只知矩阵不知道度对应"邻接点个数"，会误答成"第 $j$ 行元素之和是否为 $1$"。故主考点是 DS04.02.01，DS04.01 提供目标量定义，DS04.03.01 给出该方法的算法出处。

## 5. 解题思路

1. **写出矩阵元素的定义**：$a_{ji}=1\iff$ 边 $(v_j,v_i)$ 存在；
2. **把度翻译成邻接点计数**：$\deg(v_j)=|\{i:(v_j,v_i)\in E\}|$；
3. **两步合并**：$\deg(v_j)=$ 第 $j$ 行中 $1$ 的个数 ⟹ 方法即"沿第 $j$ 行累加计数"；
4. **补对称性说明**：无向图 $a_{ji}=a_{ij}$，故第 $j$ 列亦可（写答案时注明，防止判卷认为方向错）；
5. **实例核对**：画一个 $4$ 顶点小图，逐行数 $1$ 的个数，再直接在图上数每个顶点的度，两表逐项相等（6.2）；
6. **边界情形自查**：对角线为 $0$（无自环）不影响；若有自环须额外 $+1$（6.4）；若为带权网则把判据改成"非 $\infty$"（6.5）。

## 6. 详细解答

### 6.1 方法的严格表述

设邻接矩阵为 `A[n][n]`，第 $j$ 个结点的度为

```c
int Degree(MGraph G, int j) {     /* 无向图：求第 j 个结点的度 */
    int d = 0, i;
    for (i = 0; i < G.vexnum; ++i)
        if (G.arcs[j][i] == 1)    /* 邻接矩阵第 j 行第 i 列为 1，即存在边 (vj, vi) */
            ++d;                  /* 无向图一般无自环，arcs[j][j] = 0，不计数 */
    return d;
}
```

文字答案即上述代码的一句话版本：**统计（累加）邻接矩阵第 $j$ 行中非零元素（$1$）的个数**（等价地统计第 $j$ 列）。

### 6.2 实例验证

取无向图 $G$：$V=\{v_1,v_2,v_3,v_4\}$，$E=\{(v_1,v_2),(v_1,v_3),(v_2,v_3),(v_3,v_4)\}$。其邻接矩阵（$\infty$/空表示无边，此处用 $0$）：

| $A$ | $v_1$ | $v_2$ | $v_3$ | $v_4$ | 行中 $1$ 的个数 | 图上直接数度 |
|---|---|---|---|---|---|---|
| $v_1$ | $0$ | $1$ | $1$ | $0$ | $2$ | $\deg(v_1)=2$ ✓ |
| $v_2$ | $1$ | $0$ | $1$ | $0$ | $2$ | $\deg(v_2)=2$ ✓ |
| $v_3$ | $1$ | $1$ | $0$ | $1$ | $3$ | $\deg(v_3)=3$ ✓ |
| $v_4$ | $0$ | $0$ | $1$ | $0$ | $1$ | $\deg(v_4)=1$ ✓ |

行和序列 $(2,2,3,1)$ 与真实度序列逐项相同 ✓；行和总计 $8=2\times 4$ 条边 $=2e$，与本卷第 33 题的握手定理一致（一致性自检）。同时可看出矩阵关于主对角线对称，故按列统计 $v_3$ 也得到 $3$ ✓。

### 6.3 为什么"行、列等价"只在无向图成立

- **无向图**：$(v_j,v_i)$ 与 $(v_i,v_j)$ 是同一条边 ⟹ $a_{ji}=a_{ij}$ ⟹ 第 $j$ 行的 $1$ 与第 $j$ 列的 $1$ 一一对应，两种写法都给 $\deg(v_j)$；
- **有向图**：$a_{ji}=1$ 表示弧 $v_j\to v_i$，故
  - 第 $j$ **行**中 $1$ 的个数 $=$ **出度** $\deg^+(v_j)$；
  - 第 $j$ **列**中 $1$ 的个数 $=$ **入度** $\deg^-(v_j)$；
  - 度 $=$ 行和 $+$ 列和。

本题题面第一句已限定"无向图"，所以答"第 $j$ 行（或第 $j$ 列）非零元素个数"完全正确；若把本题换成有向图，答案必须拆成入度与出度两段（这正是本卷第 20 题考"有向图邻接表中顶点出现次数 $=$ 入度"的同一类区分）。

### 6.4 自环与对角线的约定

题面按教材的简单图约定，$a_{jj}=0$，第 $j$ 行的 $1$ 与关联边一一对应，无需修正。

若某图允许自环 $(v_j,v_j)$：它在矩阵中只占据 $a_{jj}$ **一个**位置，但按定义自环给 $v_j$ 贡献 $2$ 度（见本卷第 33 题第 12 节所述约定）。此时"第 $j$ 行非零元素个数"会少算 $1$，正确写法是

$$\deg(v_j)=\sum_{i\ne j}(a_{ji}\neq 0)\;+\;2\cdot[a_{jj}\neq 0]$$

答卷中一般无需写出这一修正（题目默认无自环），但把它当作检查自己是否真懂"元素—边"对应关系的练习。

### 6.5 若邻接矩阵存的是"网"（带权无向图）

无边常用 $\infty$（或一个约定的极大值）表示，有边处存权值（可为任意实数，包括 $0$ 或负数）。此时"非零元素个数"这一判据失效（权值可能恰为 $0$），应表述为：

**统计第 $j$ 行中"不为 $\infty$ 且不是对角元素"的个数**。

实例见本库 DS-2013-41、DS-2014-42（两题所给邻接矩阵均以 $\infty$ 记无边），其中顶点 $C$ 的行 `3, ∞, 0, 4, ∞, 9`（DS-2014-42）按此法数得度为 $3$（邻 $A,D,F$）。

### 6.6 结论

**答案**：统计邻接矩阵第 $j$ 行中非零元素（$1$）的个数（因矩阵对称，取第 $j$ 列等价），即 $TD(j)=\sum_{i=1}^{n}(A[j][i]\neq 0)$。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

无向图的邻接矩阵满足 $a_{ji}=1\iff$ 边 $(v_j,v_i)$ 存在，故与 $v_j$ 关联的边与第 $j$ 行的 $1$ 一一对应。

$$\boxed{\text{求第 } j \text{ 行（或第 } j \text{ 列）中非零元素（}1\text{）的个数，即 } \sum_{i=1}^{n}a_{ji}}$$

（无向图矩阵对称，行列等价；若为带权网，判据改为"非 $\infty$"；有向图则行和为出度、列和为入度。）

## 9. 易错点

1. **答成"第 $j$ 行元素之和"却不说前提**：对 $0/1$ 矩阵这句话成立，但必须先声明"$a_{ij}$ 取 $1$ 表示有边"；若图是网（权值矩阵），直接相加得到的是权值和而不是度——判据是"非零/非 $\infty$ 的**个数**"，不是"数值之和"；
2. **只写"第 $j$ 行"忘了说明可用列**：本题无向图行列皆可，但答案要写出行（或列）并点明对称性，避免被误判为方向不清；
3. **把行列与有向图情形混用**：如果图是有向的，"第 $j$ 行元素个数"只是**出度**，答"度"就漏了入度（本卷第 20 题正是这一区分）；题面已说无向图，不要反过来把有向图的答案写上；
4. **把对角元算进去**：无自环时 $a_{jj}=0$ 不影响；一旦题目给出允许自环的图，按"非零元素个数"会把一个自环只算作 $1$ 度，与 $2$ 度的定义不符（见 6.4），此时需要修正；
5. **答成"第 $j$ 行非零元素的个数乘 $2$"**：与握手定理（本卷第 33 题的 $\sum\deg=2e$）混淆——那个 $2$ 倍是**所有顶点度数之和**与边数的关系，单个顶点的度不存在乘 $2$；
6. **答成"第 $j$ 行的遍历复杂度 $O(n)$"**：题问"方法"而非"时间开销"，答复杂度是答非所问（可在补充说明中提一句"需扫描一整行，故 $O(n)$"，但主答案必须是统计非零元素个数）。

## 10. 一句话规律

邻接矩阵读图的三条口诀：**行（列）里数 $1$ 得度**（无向图，行列等价）、**行出列入**（有向图：行和为出度、列和为入度）、**全矩阵数 $1$ 得 $2e$**（握手定理的存储版）。方法类填空要把"取哪一行/列 $+$ 按什么判据计数 $+$ 为什么可以互换"三段都写出来才完整。
