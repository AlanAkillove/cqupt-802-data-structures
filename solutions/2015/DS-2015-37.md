# DS-2015-37

## 1. 原题

对于键值序列 `{12,13,11,18,60,15,7,18,25,100}` 里建初始堆，必须从键值为____________________ 的结点开始对每个结点进行一次堆调整。

## 2. 答案

**60**（序列第 5 个元素，即最后一个非叶结点）。

## 3. 题目分析

- 已知：长度为 $n=10$ 的键值序列，按顺序存储方式视为一棵完全二叉树；
- 目标：指出"自底向上建初始堆"时**第一个被调整**的结点的关键字；
- 关键约束：建堆只需对**非叶结点**做筛选，叶子结点自成一堆；调整次序为"从最后一个非叶结点起，自右向左（下标由大到小）逐个调整"；
- 命题意图：考"最后一个非叶结点是 $\lfloor n/2\rfloor$"这一建堆入口条件（本库 2014-36 为完全同型的表述，2019-16 则要求写出建堆结果，可对照）。

## 4. 核心考点

核心考点：
DS06.07 堆与堆排序——初始堆的构造（筛选法建堆的起点 $\lfloor n/2\rfloor$）

辅助考点：
DS03.02.02 二叉树的存储结构——顺序存储下"双亲下标 $i$、孩子下标 $2i$ 与 $2i+1$"的对应关系，正是判断"谁是最后一个非叶结点"的依据

解释：本题不要求算出堆的最终形态，只考建堆的**起始位置**，其推导完全依赖"完全二叉树顺序存储的下标关系"，故主节点取建堆所在的 DS06.07，辅助取 DS03.02.02。

## 5. 解题思路

1. 把序列按下标 $1\sim10$ 写成完全二叉树（顺序存储天然就是完全二叉树形态，无需重建）；
2. 用性质"下标 $i$ 无孩子 $\iff 2i>n$"判定叶子：$2i>10 \Rightarrow i\ge 6$，故 $6\sim10$ 全是叶子；
3. 于是最大的非叶下标为 $\lfloor n/2\rfloor=\lfloor10/2\rfloor=5$，对应键值 $60$（$i=5$ 有左孩子 $2i=10$，即键值 $100$）；
4. 复核：若序列按下标 $0$ 存放（部分教材写法），起点为 $\lfloor n/2\rfloor-1=4$，该位置上的元素仍是 $60$——**答案与下标起点约定无关**；
5. 该结论对大根堆、小根堆同样成立：建堆起点只由树形决定，与"大根/小根"的比较方向无关。

## 6. 详细解答

**（1）按顺序存储画出完全二叉树**（括号内为下标，$n=10$）

```
                    12(1)
                 /         \
            13(2)           11(3)
           /     \          /     \
       18(4)    60(5)    15(6)   7(7)
        /   \     /
    18(8) 25(9) 100(10)
```

**（2）确定叶子与非叶结点**

顺序存储的完全二叉树中，结点 $i$ 的左孩子为 $2i$。令 $2i>n=10$，得 $i\ge 5.5$，即 $i=6,7,8,9,10$ 无孩子，是叶子；
反过来，$i\le 5$ 都有左孩子：$i=5$ 的左孩子为 $2i=10$（键值 $100$，因 $2i+1=11>10$ 故它只有左孩子）。
所以**最后一个非叶结点是第 5 个，键值 60**。

**（3）建堆的调整次序**

自底向上、由右至左，依次对 $i=5,4,3,2,1$ 各做一次筛选（一趟"下沉"调整），即从键值 $60$ 的结点开始。

**（4）验证：把 $i=5$ 漏掉会怎样**

若从 $i=4$ 才开始调整，则第一步 $i=5$ 的子树 $\{60_{(5)},\,100_{(10)}\}$ 不满足大根堆条件（$60<100$），建出的不是堆；反之若从 $i=6$（键值 15）开始，$6\sim10$ 本就是叶子，做调整是空操作，仍会再往前调到 $i=5$——两种改法都说明"必须且只需从 60 开始"。

**（5）补充：完整建堆过程（以大根堆为例，用于自证）**

| 调整结点 | 下标（键值） | 与孩子比较 | 调整后的序列（下标 1…10） |
|---|---|---|---|
| 起点 | $5\,(60)$ | 左孩子 $10\,(100)$，$100>60$ 交换 | 12,13,11,18,**100**,15,7,18,25,60 |
| | $4\,(18)$ | 孩子 $18,25$，$25$ 最大，交换 | 12,13,11,**25**,100,15,7,18,18,60 |
| | $3\,(11)$ | 孩子 $15,7$，$15$ 最大，交换 | 12,13,**15**,25,100,11,7,18,18,60 |
| | $2\,(13)$ | 孩子 $25_{(4)},100_{(5)}$，$100$ 最大，交换；$13$ 下沉到 $5$ 号位后又与左孩子 $10$（$60$）交换 | 12,100,15,25,13,11,7,18,18,60 → 12,100,15,25,**60**,11,7,18,18,**13** |
| | $1\,(12)$ | 孩子 $100_{(2)},15_{(3)}$，$100$ 最大，交换；$12$ 在 $2$ 号位又与 $60_{(5)}$ 换、再在 $5$ 号位与 $13_{(10)}$ 换 | 100,12,15,25,60,11,7,18,18,13 → 100,60,15,25,12,11,7,18,18,13 → **100,60,15,25,13,11,7,18,18,12** |

最终大根堆为 `{100,60,15,25,13,11,7,18,18,12}`，逐点检验 $r_i\ge r_{2i},r_i\ge r_{2i+1}$ 全部成立 ✓（此段仅为验证，非本题所问）。

**答案**：60。

## 8. 考场标准答案

**60**。

建初始堆采用"自底向上筛选"：顺序存储的完全二叉树中，结点 $i$ 的左孩子为 $2i$，令 $2i>n$ 得叶子从 $i=\lfloor n/2\rfloor+1$ 开始，故最后一个非叶结点为 $i=\lfloor n/2\rfloor$。本题 $n=10$，$\lfloor10/2\rfloor=5$，序列第 5 个元素即 $60$，从它开始依次对第 $5,4,3,2,1$ 个结点各做一次调整。

## 9. 易错点

1. 误从**最后一个叶子**（100）或第一个元素（12）开始：叶子无需调整，建堆必须从最后一个非叶结点 $\lfloor n/2\rfloor$ 起、向**前**逐个调整；
2. 记错公式：$\lceil n/2\rceil$、$n/2-1$ 等写法在 $n$ 为奇偶不同时出错，标准写法是 $\lfloor n/2\rfloor$（$1$ 起编号）；
3. 忽略下标起点：$0$ 起编号时起点是 $\lfloor n/2\rfloor-1$，若仍按 $1$ 起编号去取"第 5 个元素"会取到 15（键值错位），本题若按下标 $0\sim9$ 存放，起点下标为 $4$，其键值仍是 $60$；
4. 把"一次堆调整"误解为"一次比较"：一趟筛选（`Sift`）可能沿路径连续下沉多层（如第 2 个结点 13 先与 100 换、再与 60 换），仍算对该结点做了一次调整。

## 10. 一句话规律

建堆（以及"插入后调整"以外的所有自底向上操作）入口永远是最后一个非叶结点 $\lfloor n/2\rfloor$；先数清 $n$，再查该下标上的键值即可，与大根/小根无关。
