# DS-2015-13

## 1. 原题

请指出在顺序表 `{2,5,7,10,14,15,18,23,35,41,52}` 中，用二分法查找关键码 $12$ 需做多少次关键字比较（）。

A. $2$

B. $3$

C. $5$

D. $4$

## 2. 答案

**D**（$4$ 次）。依次与 $15,7,10,14$ 比较，第 $4$ 次后区间为空，查找失败。

## 3. 题目分析

- 已知：长度 $n=11$ 的**有序**顺序表，元素自下标 $1$ 起为 $A[1..11]=2,5,7,10,14,15,18,23,35,41,52$；待查关键码 $K=12$；
- 目标：按折半（二分）查找的标准执行过程，数出**关键字比较的次数**；
- 关键约束：
  1. $K=12$ **不在表中**，故本题是"查找失败"型计数——次数等于查找路径上内部结点的个数，也等于"落到哪个外部结点"的层次减 $1$；
  2. 取中约定必须固定：教材与本库同型题（DS-2014-33、DS-2012-31）一律用 $mid=\lfloor (low+high)/2\rfloor$；
  3. 每次比较后区间收缩为 $[low, mid-1]$ 或 $[mid+1, high]$，循环终止条件是 $low>high$；
- 命题意图：查"折半查找能否手工逐轮执行"。四个选项 $2,3,4,5$ 恰好覆盖了"少算一轮""把成功与失败口径混用""把 $\lceil\log_2(n+1)\rceil$ 当上限直接套用"三类典型失误。

## 4. 核心考点

核心考点：
DS05.04 折半查找法（区间收缩过程、判定树与查找路径、失败查找的比较次数）

辅助考点：
DS05.01 查找的基本概念（"比较次数"以关键字比较为单位、查找成功与查找失败两种口径的区别）

解释：解题手续完全是 DS05.04 的机械执行；但要把"找不到"与"比较次数"这两件事说清楚，需要 DS05.01 关于 ASL 统计口径的概念支撑——失败情形比较的是"路径上的内部结点数"，而不是外部结点数。

## 5. 解题思路

1. 先确认表的长度与下标起点：$n=11$，按 $1..11$ 编号（写成 $0..10$ 亦同，见第 6 节第（3）步）；
2. 定死取中公式 $mid=\lfloor(low+high)/2\rfloor$，逐轮写出 $(low,mid,high)$ 三元组与被比较的元素值；
3. 每轮用 $K$ 与 $A[mid]$ 的大小关系决定收缩方向，直到 $low>high$；
4. 数出比较次数 $=4$，与选项比对；
5. 用**判定树**独立复核：$12$ 落在 $10$ 与 $14$ 之间，其外部结点是 $A[4]=10$ 的右孩子 $A[5]=14$ 的左孩子，路径 $6\to3\to4\to5$ 长 $4$；
6. 再做一次**约定不变性检验**：改用 $0$ 起下标、或改用 $mid=\lceil(low+high)/2\rceil$，看次数是否仍为 $4$（结论：仍为 $4$，故答案不依赖取中口径）。

## 6. 详细解答

**（1）逐轮执行（下标 $1..11$，$mid=\lfloor(low+high)/2\rfloor$）**

| 轮次 | $low$ | $high$ | $mid=\lfloor\frac{low+high}{2}\rfloor$ | $A[mid]$ | 与 $K=12$ 比较 | 区间变化 |
|---|---|---|---|---|---|---|
| 1 | $1$ | $11$ | $6$ | $15$ | $12<15$ | $high=5$ |
| 2 | $1$ | $5$ | $3$ | $7$ | $12>7$ | $low=4$ |
| 3 | $4$ | $5$ | $4$ | $10$ | $12>10$ | $low=5$ |
| 4 | $5$ | $5$ | $5$ | $14$ | $12<14$ | $high=4$ |
| 终止 | $5$ | $4$ | — | — | $low>high$，查找失败 | — |

被比较的关键字依次为 $15,7,10,14$，共 **$4$ 次**。

**（2）判定树复核**

$n=11$ 的折半查找判定树（按上表的中点选取规则）为：

```
                        [6]15
                 /                \
            [3]7                  [9]35
           /    \                /      \
       [1]2    [4]10        [7]18     [10]41
         \        \          \           \
        [2]5     [5]14      [8]23      [11]52
```

内部结点共 $11$ 个、树高 $4$。查找 $K=12$ 的路径为 $[6]\to[3]\to[4]\to[5]$，即 $15,7,10,14$；$12$ 应挂在 $[5]14$ 的左孩子位置（外部结点），落在第 $5$ 层 ⟹ 失败时的比较次数 $=5-1=4$ ✓，与（1）一致。

**（3）取中口径与下标起点的不变性检验**

- 改用 $0$ 起下标（$0..10$）：$mid=5\to2\to3\to4$，对应元素 $15,7,10,14$，仍 $4$ 次；
- 改用 $mid=\lceil(low+high)/2\rceil$（$1$ 起下标）：$6\to3\to5\to4$，对应元素 $15,7,14,10$，仍 $4$ 次（只是次序颠倒）。

即"比较 $4$ 次"对两种常见约定都成立，答案不依赖取中细节。

**（4）折半查找的算法描述（教材风格 C，用于说明上表的每一行从何而来）**

```c
int BinarySearch(SqList L, KeyType K)     /* L.r[1..L.length] 按键值递增排列 */
{
    low = 1; high = L.length; cnt = 0;                     /* cnt 记录比较次数 */
    while (low <= high) {
        mid = (low + high) / 2;                            /* 向下取整 */
        ++cnt;                                             /* 一次关键字比较 */
        if (K == L.r[mid].key) return mid;                 /* 查找成功 */
        else if (K < L.r[mid].key) high = mid - 1;         /* 落在左半区间 */
        else low = mid + 1;                                /* 落在右半区间 */
    }
    return 0;                                              /* low>high：查找失败 */
}
```

代入 $n=11$、$K=12$ 调用，循环执行 $4$ 轮后 $low=5>high=4$ 退出，`cnt` $=4$。

**答案**：D。

## 7. 选项分析

- A. $2$：错。只走到第 $2$ 轮（比较 $15,7$）就停了；此时区间为 $[4,5]$ 尚未收缩为空，$12$ 是否在其中还未判定，不能提前结束；
- B. $3$：错。对应"比较 $15,7,10$ 后见 $12>10$ 就断定找不到"——但 $A[4]=10$ 之后还有 $A[5]=14$ 未比，区间 $[5,5]$ 非空，必须再比一次；这是把"找到插入位置"误当成"判定不存在"的典型失误；
- C. $5$：错。$5$ 是判定树中该失败结点（外部结点）所在的层次，比较次数应取"路径上的内部结点个数"$=5-1=4$；把外部结点本身也算作一次比较就多算了一次（树高为 $4$，成功与失败的最大比较次数都是 $4$，不可能出现 $5$）；
- D. $4$：正确。逐轮执行与判定树路径长度两条独立方法均得 $4$。

## 8. 考场标准答案

取 $low=1,high=11$，$mid=\lfloor(low+high)/2\rfloor$：

$$A[6]=15\ (12<15,\ high=5)\to A[3]=7\ (12>7,\ low=4)\to A[4]=10\ (12>10,\ low=5)\to A[5]=14\ (12<14,\ high=4)$$

此时 $low=5>high=4$，循环结束，查找失败。共比较 $15,7,10,14$ 四个关键字，**$4$ 次**，选 **D**。

## 9. 易错点

1. **提前终止**：把"$K$ 已大于当前中点、且下一格就是比 $K$ 大的元素"当成判定完成，少算最后一次比较（漏成 $3$ 次）；判据是**只有 $low>high$ 才允许宣布失败**；
2. **成功/失败口径混用**：$K=12$ 不在表中，属查找失败；若误按"成功查找第 $i$ 个元素的比较次数"去查表（如本库 DS-2012-31 查 $50$、DS-2006-30 查 $A[12]$），会走错路径；
3. **取中约定不统一**：$\lfloor\rfloor$ 与 $\lceil\rceil$ 得到的比较**次序**不同（本题恰次数相同，但 DS-2014-33 那类"依次与哪些元素比较"的问法答案会不同），一题之内必须固定一种；
4. 误用公式 $\lceil\log_2(n+1)\rceil$：$n=11$ 时该值为 $4$，恰好与本题答案相同，但它是**最大比较次数（树高）**的一般上界，不能代替逐轮执行——换成本卷第 13 题以外的关键码（如 $K=1$ 需 $4$ 次、$K=15$ 只需 $1$ 次）就不成立了；
5. 下标起点看错：表若按下标 $0..10$ 存放，元素序列相同但 $mid$ 数值不同，写过程时要先声明自己的编号约定。

## 10. 一句话规律

折半查找的"比较次数"题一律手打三列表（$low$、$high$、$mid$ 及 $A[mid]$）逐轮收缩，直到 $low>high$ 才准停；次数即路径上内部结点个数，等于查找失败所落外部结点的层次减 $1$，也等于判定树中该路径的长度。
