# DS-2015-06

## 1. 原题

设计一个判别表达式中左、右括号是否配对出现的算法，采用（）数据结构最佳。

A. 栈

B. 队列

C. 顺序结构线性表

D. 链式结构线性表

## 2. 答案

**A**（栈）。

## 3. 题目分析

- 已知：一个表达式串，其中含左括号与右括号（可能只有一种括号，也可能有 `(`、`[`、`{` 多种），要求判别它们是否"配对出现"；
- 目标：为这一判别选择**最佳**的数据结构；
- 关键约束：配对的定义是"每个右括号与其**最近的、尚未闭合的**左括号配对，且配对后两者之间的一切括号已闭合"——即**最近打开的最先闭合**（nested / LIFO 结构）；
- 命题意图：考"按运算需求选结构"。本题与第 4 题（打印缓冲区选队列）恰好构成一组对照：一个要求"保持到达次序"（FIFO），一个要求"逆着到达次序"（LIFO）。C、D 两项用来钓"栈不就是线性表吗"这一包含关系上的含糊——题问"最佳"，指操作限制与问题结构严格吻合的那一个。

## 4. 核心考点

核心考点：
DS02.07 栈、队列和数组的应用（括号匹配是教材列举的栈的典型应用之一）

辅助考点：
DS02.01 栈和队列的基本概念（LIFO 与 FIFO 的定义与区别，用于否证 B）

解释：题目落在"栈和队列的应用"一节（DS02.07），判定的依据则是两种结构的操作限制（DS02.01）。本题不要求写代码（同型题 DS-2007-15 亦未要求），但解题时应能在头脑中跑出完整的扫描过程，故能力标签含 `APPLICATION`。

## 5. 解题思路

1. 把"配对"翻译成扫描过程：从左到右读字符，遇到左括号就"记住它、等待闭合"；遇到右括号，必须先去闭合**最近那个还没闭合的左括号**；
2. 观察"记住"的顺序与"使用"的顺序相反：最后遇到的左括号最先被使用 ⟹ 这正是 LIFO，即栈；
3. 定出算法骨架：左括号 `push`；右括号时若栈空⟹不配对（右多），若栈顶不是与之同类的那一种左括号⟹不配对（交叉，如 `([)]`），否则 `pop`；扫描结束后栈非空⟹不配对（左多）。三种失败情形都要覆盖；
4. 否证其余选项：队列给出的是"最早那个未闭合的左括号"，与"最近"相反（用 $([\,])$ 作反例）；顺序/链式线性表允许在任意位置插入删除，本身不携带任何次序约束，用它实现该算法时实际上就是在手工模拟一个栈，且顺序表还要承担移动元素的代价——都不是"最佳"。

## 6. 详细解答

**（1）问题的结构就是 LIFO**

考虑嵌套关系：`(( ))` 中，最内层的右括号闭合的是**最后**出现的那个左括号。一般地，设左括号出现次序为 $l_1,l_2,\cdots,l_m$，若表达式合法，则它们的闭合次序必为 $l_m,l_{m-1},\cdots,l_1$（后开先闭）。"进入次序"与"取出次序"相反 ⟹ 栈。

**（2）栈算法（教材风格 C 描述）**

```c
/* 只含一种括号的情形：left 为左括号字符，right 为右括号字符 */
Status Match(char exp[])          /* exp: 表达式串 */
{
    Stack S;  InitStack(S);       /* 工作栈，存放未闭合的左括号 */
    for (p = exp; *p != '\0'; ++p) {
        if (*p == left)  Push(S, *p);            /* 左括号入栈，等待闭合 */
        else if (*p == right) {
            if (IsEmpty(S))  return ERROR;       /* 右括号多余 */
            Pop(S, e);                           /* 与最近的未闭合左括号配对 */
        }
    }
    return IsEmpty(S) ? OK : ERROR;              /* 栈非空说明左括号多余 */
}
```

多类括号（`()`、`[]`、`{}`）时只需把判据改成"栈顶必须是与该右括号同类的左括号"，其余完全相同：

```c
else if (*p == ')' || *p == ']' || *p == '}') {
    if (IsEmpty(S)) return ERROR;
    Pop(S, e);
    if (Pair(e, *p) == FALSE) return ERROR;      /* e 与 *p 不属同类 ⟹ 交叉，如 ([)] */
}
```

三种失败情形都被覆盖：右括号多余（弹空栈时仍来右括号）、左括号多余（扫描结束栈非空）、交叉配对（栈顶类型不符）。

**（3）为什么队列不行（反例）**

若用队列：左括号从队尾入、从队头出，得到的是**最早**那个未闭合的左括号。对合法表达式 $([\,])$：

| 扫描到 | 队列内容（头→尾） | 队头 | 期望配对对象 | 结果 |
|---|---|---|---|---|
| `(` | `(` | `(` | —— | 入队 |
| `[` | `(` `[` | `(` | —— | 入队 |
| `]` | `(` `[` | `(` | `[` | ✗ 误判为不配对 |

而用栈时栈顶恰为 `[`，正确配对。可见队列会把合法表达式判为非法 ⟹ B 不可用。

**（4）为什么 C、D 不是"最佳"**

顺序表/链表只规定"元素在线性次序上可任意位置插入、删除、访问"，并不自带"最后进入者最先取出"的约束；要用它们做本题，就必须人为限定"只在表尾插入、只在表尾删除"（顺序表）或"只在表头插入、只在表头删除"（链表）——这恰好就是栈的定义。也就是说，C、D 是**实现手段**（顺序栈、链栈），而题目问的是**数据结构类型**；且顺序线性表若在表头删除需整体前移 $n-1$ 个元素，效率反而最差。故选 A。

**答案**：A。

## 7. 选项分析

- A. 栈：正确。"最近打开的最先闭合"与 LIFO 严格对应，一次扫描 $O(n)$、辅助空间最坏 $O(n)$，实现只需 `Push`/`Pop`/`IsEmpty` 三个操作；
- B. 队列：错。FIFO 给出的是最早的未闭合左括号，会把合法式 $([\,])$ 判为非法（反例见第 6 节）；队列适合"保持到达次序"的场景（如本卷第 4 题的打印缓冲区）；
- C. 顺序结构线性表：错（次强干扰项）。约束过宽，不体现"只在端点操作"；若真用它实现"在表头删除"，每次删除需前移约 $n/2$ 个元素，代价高于栈；
- D. 链式结构线性表：错。同为约束过宽；把它限定为"仅头插、仅头删"后就是链栈，等于绕回 A，故不是本题所问的答案层次。

## 8. 考场标准答案

选 **A**。

括号配对的规则是"每个右括号先与最近的、尚未闭合的左括号配对"，即后进的左括号先被使用，与栈的后进先出特性完全吻合：遇左括号入栈，遇右括号则取栈顶配对并弹出；若栈空遇右括号（右多）、栈顶类型不符（交叉）、扫描结束时栈非空（左多）均判不配对。队列给出的是最早未闭合的左括号（反例 $([\,])$ 被误判），一般线性表未对操作位置作限制、约束过宽，故栈最佳。

## 9. 易错点

1. 因"栈也是线性表"而选 C 或 D：题目问"采用什么数据结构**最佳**"，要选与问题约束严格对应的那一类受限结构，而不是它的上位概念（同型题 DS-2007-15 的排除理由一致）；
2. 只判"左右括号个数相等"就宣布配对：这无法发现交叉情形 `([)]` 与位置错乱情形 `)(`；个数相等只是必要条件；
3. 漏掉"扫描结束后栈必须为空"这一判定：`((()` 左右个数虽不等会被弹出失败抓住，但如只写"遇右括号弹栈"而不检查最终栈空，就会漏判左括号多余；
4. 与表达式**求值**混淆：求值需要操作数栈与运算符栈两个栈（或转后缀表达式），本题只判括号配对，一个栈足够——不要因为"表达式"三个字就联想到队列（后缀表达式求值确实常用栈，而"层次遍历/缓冲"才用队列）；
5. 多类括号时忘记比较**类型**，只判栈空与否。

## 10. 一句话规律

看到"配对/匹配/嵌套/撤销/返回上一步"这类"最近者优先"的需求就选栈；看到"排队/顺序转出/不改变到达次序"就选队列——两题（本卷第 4、6 题）正好是这一判据的正反两面。
