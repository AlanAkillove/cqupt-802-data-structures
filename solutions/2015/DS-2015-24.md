# DS-2015-24

## 1. 原题

用顺序存储的方法将完全二叉树中的所有结点逐层存放在数组 $R[0,\cdots,n-1]$ （下标从 $0$ 开始计）中，结点 $R[i]$ 若有右子女，则右子女结点的下标是____________________ 。

## 2. 答案

**$2i+2$**（其存在条件为 $2i+2\le n-1$，即 $i\le\lfloor (n-3)/2\rfloor$）。

注意本题与教材默认的"下标从 $1$ 开始"差一个平移：$0$ 起时左子女是 $2i+1$、**右子女是 $2i+2$**、双亲是 $\lfloor (i-1)/2\rfloor$。

## 3. 题目分析

- 已知：$n$ 个结点的**完全二叉树**，结点按"逐层、自左向右"的层序次序连续存入数组 $R[0\,..\,n-1]$，即数组下标就是层序位置号（起点为 $0$）；
- 目标：由父结点下标 $i$ 表示出其**右子女**的下标；
- 关键约束：
  1. **下标起点是本题唯一的陷阱**。源文特意括注"下标从 $0$ 开始计"，而严蔚敏教材正文与大多数辅导书给出的 $2i$、$2i+1$、$\lfloor i/2\rfloor$ 三件套是以 $1$ 为起点的，照搬就错；
  2. 必须依赖**完全**二叉树的连续性：只有结点按层序无空洞地排列，下标与父子关系之间才有纯算术公式；一般的非完全二叉树做顺序存储时要按满二叉树编号补假结点，公式虽同但要额外判空；
  3. "若有右子女"是题面给定的前提，意味着该位置不越界，即 $2i+2\le n-1$；答 $\,2i+2\,$ 是主体，写出越界条件是加分的严谨表述；
  4. 左、右子女的先后：层序排列下，同一父结点的左子女先于右子女入数组，故两者下标相邻且右比左大 $1$；
- 命题意图：检验二叉树顺序存储的核心下标映射，并特别检查能否处理"编号起点平移"这一常见变式。本库 DS-2007-24 是同一道题的 $1$ 起版本，两题配对练习效果最好。

## 5. 解题思路

1. 先明确约定：下标 $i$ 从 $0$ 起，教材公式从 $1$ 起，两者相差 $1$，不可混用；
2. **最快路径（平移换算）**：把 $i$ 换成 $1$ 起编号 $k=i+1$ → 用教材公式 $2k+1$ → 再把结果减 $1$ 换回 $0$ 起，得 $2i+2$；
3. **不依赖教材公式的按层推导**：写出第 $d$ 层的下标起点 $2^{d}-1$，把 $i$ 拆成"层起点 $+$ 层内左起序号 $j$"，子女在第 $d+1$ 层的第 $2j+1$ 位，直接算出下标并与 $2i+2$ 比对；
4. **举例验证**：取 $n=7$（满二叉树）逐点数，再取 $n=6$、$n=10$ 检查越界判定与"度为 $1$ 的结点"；
5. 顺带把配套公式（左子女、双亲）一并写出，并做一组等价性检查（如"子女的父回到原结点"）。

## 6. 详细解答

**（1）方法一：下标平移换算**

教材中按 $1\sim n$ 编号的完全二叉树，结点 $k$ 的右子女编号为 $2k+1$。

本题数组从 $0$ 开始，故下标 $i$ 对应的 $1$ 起编号是 $k=i+1$。于是其右子女的 $1$ 起编号为

$$2k+1=2(i+1)+1=2i+3$$

再转回 $0$ 起下标（减 $1$）：

$$(2i+3)-1=\boxed{2i+2}$$

同一换算给出 $0$ 起下标的完整三件套：

| 关系 | 下标从 $1$ 起 | 下标从 $0$ 起（本题口径） |
|---|---|---|
| 左子女 | $2i$ | $2i+1$ |
| 右子女 | $2i+1$ | $2i+2$ |
| 双亲 | $\lfloor i/2\rfloor$（$i>1$） | $\lfloor (i-1)/2\rfloor$（$i>0$） |

**（2）方法二：按层直接推导（自我验证，不用教材公式）**

以 $0$ 为起点逐层编号时，第 $d$ 层（$d$ 从 $0$ 起计，即根在第 $0$ 层）的下标区间是

$$\big[\,2^{d}-1,\ \ 2^{d+1}-2\,\big]$$

设 $i$ 是第 $d$ 层从左起的第 $j$ 个结点（$j$ 从 $0$ 起），则

$$i=(2^{d}-1)+j$$

完全二叉树按层序连续存放，第 $d$ 层第 $j$ 个结点的两个子女必是第 $d+1$ 层第 $2j$、$2j+1$ 个位置；第 $d+1$ 层的起点为 $2^{d+1}-1$，所以右子女下标为

$$(2^{d+1}-1)+(2j+1)=2^{d+1}+2j$$

另一方面

$$2i+2=2\big(2^{d}-1+j\big)+2=2^{d+1}+2j$$

两式恒等 ⟹ 公式 $2i+2$ 对任意层、任意位置的结点都成立。

（检查一致性：左子女 $=(2^{d+1}-1)+2j=2^{d+1}+2j-1=2i+1$，与右子女恰相差 $1$，符合"左先右后"。）

**（3）方法三：具体树验证**

$n=7$（满二叉树，下标 $0\sim6$）：

```
            0
        1       2
      3   4   5   6
```

| $i$ | $2i+2$ | 图中 $R[i]$ 的右子女 | 吻合 |
|---|---|---|---|
| $0$ | $2$ | $2$ | ✓ |
| $1$ | $4$ | $4$ | ✓ |
| $2$ | $6$ | $6$ | ✓ |
| $3,4,5,6$ | $\ge 8$ | 无（越界，均为叶子） | ✓（前提"若有右子女"不成立） |

$n=6$（最后一层只有 $3,4,5$）：$R[1]$ 的右子女 $=2\cdot1+2=4\le 5$ ✓；$R[2]$ 的左子女 $=2\cdot2+1=5$ 存在、右子女 $=6>5$ 不存在，故 $R[2]$ 度为 $1$ ——题面"若有右子女"正是为了排除这种边界情形。

$n=10$（下标 $0\sim9$，第 $4$ 层为 $7,8,9$）：$R[3]$ 右子女 $=8$ ✓；$R[4]$ 左子女 $=9$ 存在而右子女 $=10$ 越界（度 $1$）；$R[5]$ 的 $2\cdot5+1=11>9$，是编号最小的叶子。由此得"最小叶子下标 $=\lfloor n/2\rfloor$"（$n=10$ 时为 $5$），与本库 DS-2006-28 的结论一致——这是公式正确的又一个侧面印证。

**（4）教材风格 C 语言写法**

```c
/* 完全二叉树的顺序存储：R[0..n-1]，下标从 0 开始 */
#define LEFT(i)    (2 * (i) + 1)      /* 左子女下标 */
#define RIGHT(i)   (2 * (i) + 2)      /* 右子女下标，本题所求 */
#define PARENT(i)  (((i) - 1) / 2)    /* 双亲下标，i > 0 时有意义 */

int HasRightChild(int i, int n)
{
    return RIGHT(i) <= n - 1;   /* 越界即无右子女 */
}
```

双亲公式用 $i=2$ 验证：$\lfloor (2-1)/2\rfloor=0$，与图中 $R[2]$ 的双亲是根 $R[0]$ 一致；若误用 $\lfloor i/2\rfloor$ 会得到 $1$，错判为 $R[1]$ 的孩子——这正是"$0$ 起与 $1$ 起不能混用"的典型后果。

**（5）与本题第 23 题的下标口径互查**

本卷第 23 题的完全二叉树 $n=36$：第 $5$ 层下标区间为 $[2^{4}-1,\,2^{5}-2]=[15,30]$（$16$ 个结点），第 $6$ 层为 $[31,35]$（$5$ 个结点）。用本题公式判断第 $5$ 层哪些结点有右子女：$2i+2\le 35\Rightarrow i\le 16$，即 $i=15,16$ 有两个子女、$i=17$ 只有左子女 $35$（$2\cdot17+2=36>35$）——有子女的结点是 $15,16,17$ 共 $3$ 个，与第 23 题 $\lceil 5/2\rceil=3$ 完全吻合。

**答案**：$2i+2$（须满足 $2i+2\le n-1$）。

## 8. 考场标准答案

$2i+2$。

数组下标从 $0$ 起，而教材的 $2i$、$2i+1$ 是下标从 $1$ 起的形式。令 $1$ 起编号 $k=i+1$，右子女为 $2k+1=2i+3$，换算回 $0$ 起下标即 $(2i+3)-1=2i+2$。

配套记忆（$0$ 起）：左子女 $2i+1$、右子女 $2i+2$、双亲 $\lfloor (i-1)/2\rfloor$；右子女存在的条件为 $2i+2\le n-1$。

## 9. 易错点

1. **照搬教材公式答 $2i+1$**：那是 $1$ 起下标的右子女，或 $0$ 起下标的**左**子女。题面括号里的"下标从 $0$ 开始计"就是命题人唯一的考点；
2. **左右颠倒**：写成左子女 $2i+2$、右子女 $2i+1$。判据是"层序中左先右后，两者下标相邻"，故大者为右；
3. 忘记越界条件：严格答案要带 $2i+2\le n-1$。若题目改问"如何判断 $R[i]$ 有无右子女"，就必须答这条不等式；
4. 双亲公式写成 $\lfloor i/2\rfloor$：$0$ 起时应为 $\lfloor (i-1)/2\rfloor$，见第（4）步 $i=2$ 的反例；
5. 以为顺序存储可以随便用：公式成立的前提是**完全**二叉树（结点连续、无空洞）。一般二叉树若强行顺序存储，需按满二叉树编号补假结点并额外判空，$2i+2$ 指向的格子可能是空位；
6. 把 $n$ 当成数组长度 $n-1$ 或反之：越界判定的右端是 $n-1$（最大下标），不是 $n$。

## 10. 一句话规律

二叉树顺序存储的下标公式只由**编号起点**决定：**起点是 $1$ 就记『左 $2i$、右 $2i+1$、父 $\lfloor i/2\rfloor$』；起点是 $0$ 就整体减 $1$，变成『左 $2i+1$、右 $2i+2$、父 $\lfloor (i-1)/2\rfloor$』。**做题时先看题面把数组写成 $R[1..n]$ 还是 $R[0..n-1]$，再动笔。
