# DS-2015-03

## 1. 原题

线性表采用链表存储时地址（）。

A. 必须是连续的

B. 部分地址必须是连续的

C. 一定是不连续的

D. 连续不连续都可以

## 2. 答案

**D**（连续不连续都可以）。

## 3. 题目分析

- 已知：线性表采用**链式存储结构**（链表）；
- 目标：判断结点的**物理存储地址**受到什么约束；
- 关键约束：链式存储的定义只规定"用指针域指示逻辑上的前后继关系"，对结点存放的物理位置**不作任何要求**；因此"地址是否连续"是分配器行为的结果，而不是数据结构的条件。要判对本题，必须把"不要求连续"与"一定不连续"区分开——前者是定义，后者是一个额外的强断言；
- 命题意图：考"逻辑结构与存储结构相对独立"这一绪论观点，并用 C 项钓出"链表 $=$ 地址不连续"这一过度简化的记忆式理解。

## 4. 核心考点

核心考点：
DS01.02.02 链式存储：单链表（链表的存储特点：结点任意散布于内存、逻辑次序由 `next` 指针维持）

辅助考点：
DS01.02.01 顺序存储（顺序表：地址必须连续是**顺序**存储的定义特征，用于对照排除 A、B）
DS00.01 数据结构基本概念（逻辑结构与存储结构是两个层面，同一逻辑结构可有多种存储实现）

解释：本题问的是链式存储结构的定义性特征（DS01.02.02），判断时须与顺序存储的"地址连续"要求对比（DS01.02.01），并落到"逻辑结构不依赖物理位置"这一绪论结论（DS00.01）。

## 5. 解题思路

1. 先明确"地址连续"是谁的要求：这是**顺序存储**的定义（逻辑相邻 $\Rightarrow$ 物理相邻，可用基址 $+\ i\times$ 长度直接算地址），据此 A、B 立即排除；
2. 再看链表的定义：结点 $=$ 数据域 $+$ 指针域，结点之间靠指针链接，**新结点从空闲链取哪块内存由分配器决定**，定义里没有任何关于地址的约束；
3. 关键一步：定义"不要求连续" $\ne$ "要求不连续"。要否证 C，只需举出"地址连续但逻辑结构仍是链表"的实例：
   - **静态链表（游标实现）**：所有结点存放在一个数组 `space[MAXSIZE]` 中，地址完全连续，而逻辑次序由游标（相当于 `next`）指示——它仍是链表；
   - **连续动态分配**：依次 `malloc` 若干大小相同的结点时，分配器常把它们排在相邻地址上；
4. 存在地址连续的链表，也存在地址不连续的链表 ⟹ 两者都可能，选 D。

## 6. 详细解答

**（1）链式存储的定义**

链式存储结构中，每个结点至少包含数据域与指针域：

```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

线性表的第 $i$ 个元素在第 $i-1$ 个结点所指的地址处，**而不是**由某个基址算出。定义对结点地址的唯一要求是"该地址可被访问"，不要求彼此相邻。因此：

- 逻辑上相邻的两个结点，物理地址可以相隔很远；
- 逻辑上相邻的两个结点，物理地址也**可以恰好相邻**。

两种情形都不违反定义 ⟹ 地址"连续不连续都可以"。

**（2）A、B 的否证**

若"必须连续"（A）成立，则链表就等价于顺序表，无需指针域，也无法在不知道总长的情况下分配空间；"部分地址必须连续"（B）同样没有依据——哪怕只有两个结点，也没有任何一条规则要求它们必须相邻。这两项描述的正是顺序存储特征（对照 DS-2005-10：判断"线性表的唯一存储形式是数组"为错误）。

**（3）C 的否证（构造反例）**

反例一（静态链表）：设 `struct { ElemType data; int cursor; } space[6];`，令 `space[0].cursor=3`，`space[3].cursor=5`，`space[5].cursor=0`（结束）。这三个结点在数组中地址依次为 $b$、$b+3s$、$b+5s$（$s$ 为结点大小），全部**连续分布在同一段内存**中，但逻辑上是 $a_1\!\to\!a_2\!\to\!a_3$ 的链。可见"地址连续"与"链式存储"完全可以并存。

反例二（动态分配）：连续调用三次 `malloc(sizeof(LNode))`，在无其他分配请求时通常返回相邻地址 $p$、$p+s$、$p+2s$，此时链表三个结点的地址是连续的。

故"一定是不连续的"过绝对，C 错。

**（4）D 成立**

链表既不要求地址连续（否则退化为顺序表），也不要求地址不连续（否则与分配器行为矛盾），地址连续与否都不影响它作为链式存储结构 ⟹ 选 D。

## 7. 选项分析

- A. 必须是连续的：错。这是**顺序存储**的定义特征；链表若必须连续存放，就失去了"不必事先估计空间、插删不移动元素"的全部优点；
- B. 部分地址必须是连续的：错。定义中不存在任何"至少某几个结点必须相邻"的要求，属凭空添加的约束；
- C. 一定是不连续的：**最强干扰项**。把"不要求连续"误读成"必须不连续"。静态链表（游标实现，结点全在一段数组里）与连续 `malloc` 的结果都是地址连续的链表，构成反例；
- D. 连续不连续都可以：正确。链表的本质是"以指针表达逻辑次序"，物理位置自由。

## 8. 考场标准答案

选 **D**。

链式存储结构用指针域表示元素间的前后继关系，对结点的物理地址不作任何要求：新结点的地址由内存分配子系统决定，可能分散各处，也可能恰好相邻（静态链表把所有结点放在同一数组中，地址全连续，仍是链表）。"地址必须连续"是顺序存储的特征，"一定不连续"则把"不要求"错当成"禁止"，故只有 D 正确。

## 9. 易错点

1. 把"链式存储**可以**不连续"记成"链式存储**必须**不连续"而选 C——本题的区分点全在这一个词的强度上；
2. 只想到动态链表（`malloc` 出来的结点通常分散）而不知道静态链表/游标实现这一现成的反例；
3. 由"地址不连续"进一步推出"链表不能访问第 $i$ 个元素"：地址不连续只意味着**不能随机存取**（不能由基址算地址），第 $i$ 个元素仍可顺链查找到，代价 $O(n)$（见本卷第 8 题与 DS-2013-38）；
4. 混淆"存储密度"与"地址连续性"：链表存储密度小于 $1$ 是因为指针域额外占空间（DS-2012-03），与地址是否连续无关。

## 10. 一句话规律

凡是"必须/一定/只能"式的绝对表述，先找反例：链表的定义只约束**指针**、不约束**地址**，静态链表就是"地址连续的链表"这一现成反例；"不要求连续"永远不等于"要求不连续"。
