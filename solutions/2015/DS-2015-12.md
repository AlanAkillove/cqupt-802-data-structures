# DS-2015-12

## 1. 原题

已知数据表 $A$ 中每个元素距其最终位置不远，则采用（）排序算法最节省时间。

A. 堆排序

B. 直接插入排序

C. 快速排序

D. 简单选择排序

## 2. 答案

**B**（直接插入排序）。

## 3. 题目分析

- 已知：待排序列满足"每个元素距其最终位置不远"，即序列**基本有序**（局部有序）；用逆序对个数 $I$ 度量，该条件等价于 $I$ 远小于最坏情形的 $n(n-1)/2$，通常按 $I=O(n)$ 处理；
- 目标：在四种内部排序方法中选出**耗时最少**的那一个；
- 关键约束：必须区分两类算法——**比较次数随初态变化**的（直接插入、冒泡、快排）与**比较次数与初态无关**的（简单选择、堆排序）。基本有序这一条件只对前一类中的"插入类"与"冒泡类"有利，对后一类毫无帮助；而快排在基本有序时反而受害（若取首元素为枢轴，每趟只划分出一个元素）；
- 命题意图：考查"按数据初态选排序方法"。四个选项恰好覆盖"越有序越快（B）""与初态无关（A、D）""越有序越慢（C）"三种行为，是一道纯辨析题。

## 4. 核心考点

核心考点：
DS06.02.01 直接插入排序（比较与移动次数和逆序对数的关系、最好情况 $O(n)$）

辅助考点：
DS06.11 排序算法应用（算法识别——由中间结果反推算法、复杂度与比较）
DS06.06 快速排序（partition 结果、比较次数）
DS06.04 简单选择排序

解释：选定答案要靠直接插入排序的代价公式（DS06.02.01），但排除另外三项需要各方法的比较次数特性表（DS06.11），其中"初态有序时快排最费时间"这一反常行为由本卷第 17 题单独考过（DS06.06），选择排序恒为 $n(n-1)/2$ 次比较（DS06.04）。

## 5. 解题思路

1. 把"距最终位置不远"翻译成可计算的量：逆序对数 $I$ 很小（$I=O(n)$）；
2. 直接插入排序的总代价与 $I$ 线性相关：每趟的比较次数 $=1+$（该元素需跨越的距离），全部趟合计比较 $(n-1)+I$、移动 $I$ 次 ⟹ 总量 $O(n+I)=O(n)$，四类中最优；
3. 排除 A：堆排序建堆 $O(n)$、$n-1$ 次"换顶 $+$ 调整"每次 $O(\log n)$，总 $\Theta(n\log n)$，**与初态无关**，有序与否都省不下来；
4. 排除 D：简单选择排序第 $i$ 趟必在无序区做一次全长扫描，比较次数恒为 $\sum_{i=1}^{n-1}(n-i)=n(n-1)/2=\Theta(n^2)$，同样与初态无关；
5. 排除 C：快速排序在"基本有序"且取端点为枢轴时退化为每趟只分离一个元素，递归深度 $n$、比较次数 $\Theta(n^2)$——正是本卷第 17 题描述的现象；
6. 数值对照（$n=100$、$I=100$）：插入 $\approx199$ 次比较，堆 $\approx1.3\times10^3$，选择 $=4950$，快排退化 $\approx4950$ ⟹ 选 B。

## 6. 详细解答

**（1）"距最终位置不远"的形式化**

设序列中满足 $i<j$ 且 $A[i]>A[j]$ 的二元组个数为 $I$（逆序对数）。序列完全有序时 $I=0$，完全逆序时 $I=n(n-1)/2$。"每个元素离它的最终位置不远"意味着每个元素只需向前（或向后）移动常数级距离，故 $I$ 与 $n$ 同阶，即 $I=O(n)$。

**（2）直接插入排序的代价**

第 $i$ 趟（把 $A[i]$ 插入前面 $i-1$ 个已排好的元素中）的比较次数等于"$A[i]$ 需要向前跨越的元素个数 $+1$"，因此

$$\text{总比较次数}=(n-1)+I,\qquad \text{总移动次数}=I$$

（最好情况 $I=0$：每趟只比较 $1$ 次即发现无需移动，共 $n-1$ 次比较，即本库 DS-2005-08 的结论。）

当 $I=O(n)$ 时，总比较 $(n-1)+I=O(n)$，**时间复杂度降为线性**，这是四种方法中唯一能被"基本有序"这一条件直接兑现成 $O(n)$ 的。

```c
void InsertSort(SqList &L)              /* 逐个把 L.r[i] 插入前面有序区 */
{
    for (i = 2; i <= L.length; ++i)
        if (L.r[i].key < L.r[i - 1].key)          /* 已有序时此判断即跳过，仅 1 次比较 */
        {
            L.r[0] = L.r[i];                      /* 哨兵，免每趟下界检查 */
            for (j = i - 1;  L.r[0].key < L.r[j].key;  --j)
                L.r[j + 1] = L.r[j];              /* 后移一个元素，次数 = 跨越距离 */
            L.r[j + 1] = L.r[0];
        }
}
```

**（3）其余三种方法的代价（与初态的关系）**

| 方法 | 比较次数 | 是否受益于"基本有序" | $n=100$、$I=100$ 时的量级 |
|---|---|---|---|
| A. 堆排序 | 建堆 $\le 2n$、$n-1$ 次调整各 $\le 2\lceil\log_2 n\rceil$，总 $\Theta(n\log n)$ | 否（初态只影响建堆常数，调整照常做） | $\approx1.3\times10^3$ |
| B. 直接插入排序 | $(n-1)+I$ | **是**，$I=O(n)$ 时退化为 $O(n)$ | $\approx199$ |
| C. 快速排序 | 平均 $\Theta(n\log n)$；取端点为枢轴且序列有序时 $n(n-1)/2$ | **反受其害**（本卷第 17 题） | $\approx4950$ |
| D. 简单选择排序 | 恒 $\dfrac{n(n-1)}{2}$ | 否（每趟都要扫完无序区才能确定最小值） | $4950$ |

**（4）快排为何在"基本有序"时最慢（第 3 行的展开）**

设每次取子表第一个元素为枢轴。若序列已按升序排列，则枢轴恰是当前子表的最小值，划分后左半为空、右半含其余全部元素，递归式为

$$T(n)=T(n-1)+\Theta(n)\ \Longrightarrow\ T(n)=\Theta(n^2)$$

"每个元素距最终位置不远"正是这种情形的近似版本：划分极不平衡，比较次数接近 $n(n-1)/2$。所以 C 不但"不省"，反而可能是四者中最费时间的。

**（5）交叉验证：与"比较次数与初态无关"的判据对照**

本库 DS-2014-12 的结论是"关键字比较次数与记录初始排列次序无关"的方法为简单选择排序一类（堆排序、归并排序同属此类）。据此可一步排除 A、D：既然与初态无关，题面给的"基本有序"条件对它们毫无价值，也就不可能"最节省时间"。剩下 B 与 C，B 随有序程度单调变快、C 随有序程度变慢 ⟹ 答案 B。

**答案**：B。

## 7. 选项分析

- A. 堆排序：错。$\Theta(n\log n)$ 且与初态无关，"基本有序"省不下任何一次调整；它是"对空间要求严格、需不稳定排序"时的选择，而不是本条件下的最优；
- B. 直接插入排序：正确。比较 $(n-1)+I$、移动 $I$，$I=O(n)$ 时总代价 $O(n)$，且稳定、原地，是"局部有序"场景的教科书式选择；
- C. 快速排序：错（最强反向干扰项）。基本有序时若取端点为枢轴，划分退化为单侧递归，比较次数 $\approx n(n-1)/2$，恰是"初始数据有序时花费时间反而最多"的那个算法（本卷第 17 题）；
- D. 简单选择排序：错。比较次数恒为 $n(n-1)/2$，与初态完全无关，再有序也要每趟扫完无序区。

## 8. 考场标准答案

选 **B**。

"每个元素距其最终位置不远"即序列基本有序，逆序对数 $I=O(n)$。直接插入排序的比较次数为 $(n-1)+I$、移动次数为 $I$，此时总代价为 $O(n)$，是四者中唯一能达到线性的。堆排序恒 $\Theta(n\log n)$、简单选择排序恒比较 $n(n-1)/2$ 次，两者都不因初态有序而减少工作量；快速排序在基本有序且取端点为枢轴时退化为 $\Theta(n^2)$，反而最费时。故最节省时间的是直接插入排序。

## 9. 易错点

1. 把"有序"当成快排的优势：口诀是"**无序快、有序慢**"——快排的平均性能建立在划分的随机均衡上，序列越有序（对端点枢轴而言）越不均衡；本题与卷内第 17 题是同一知识点的正反两面；
2. 认为"堆排序也很快所以选 A"：$\Theta(n\log n)$ 是**与初态无关**的下界表现，题面条件形同虚设，比较基数远大于插入排序在线性情形下的 $n+I$；
3. 想到"折半插入排序"却选错：折半插入把比较次数降到 $O(n\log n)$，但**移动次数不变**（仍是 $I$）；在基本有序时直接插入只需 $(n-1)+I=O(n)$ 次比较，反而比折半插入更省，故"局部有序"场景的最佳答案仍是直接插入排序；
4. 混淆"希尔排序"：希尔排序在初态上表现优于直接插入，但它不在本题选项中，且其比较次数同样依赖增量序列与初态，不能凭"预排序"直觉去替换答案；
5. 忽略"稳定/原地"等附加维度：本题只问时间，若题目改问"哪种排序稳定且适合局部有序"，答案仍是直接插入排序（堆排序、快排、简单选择排序均不稳定）。

## 10. 一句话规律

按初态选排序：先看算法的比较次数是否随初态变化——插入类与冒泡类"越有序越快"（基本有序时 $O(n)$），选择类与堆排序"与初态无关"，快排"越有序越慢"（退化 $\Theta(n^2)$）；题目给"基本有序/局部有序"就选直接插入（或冒泡），给"完全无序且要求平均快"才选快排，给"要求最坏情况也有保证且空间受限"才选堆排序。
