# DS-2015-25

## 1. 原题

某表达式二叉树按先序遍历的结果为 $+a*+bcd$ ，令 $a=6,b=3,c=4,d=2$ ，则表达式的值等于____________________ 。

## 2. 答案

$20$。

该先序序列对应的表达式树唯一确定，算式为 $a+((b+c)\times d)$，代入得 $6+(3+4)\times 2=6+14=20$。

## 3. 题目分析

- 已知：一棵**表达式二叉树**（运算量在叶子、运算符在内部结点）的先序（根左右）遍历序列 $+a*+bcd$，以及四个运算量的取值 $a=6,b=3,c=4,d=2$；
- 目标：求该表达式的值；
- 关键约束：
  1. 表达式树中**每个运算符结点恰有两棵子树**（二叉树形态：左子树为左操作数、右子树为右操作数），**每个操作数结点没有孩子**；这条结构性约束使先序序列能被"无歧义"地切分，从而还原出的树是唯一的（不像"先序 + 中序"那样需要两个序列）；
  2. 先序的读取顺序是"根 → 左子树全部 → 右子树全部"，因此序列的第一个符号必是**整棵树的根运算符**，第二个符号若为操作数则它就是根的左孩子；
  3. 求值必须按**树的结构**做，不能按字符串的算术优先级去读：树已经隐含了运算次序，括号由结构给出。
- 命题意图：考"由遍历序列还原二叉树"（DS03.02.03）与"表达式树的求值"（DS03.04.02）两件事的结合，本卷以先序给出（与本库 2007 年第 27 题同型），对照 2013 年第 27 题、2014 年第 26 题、本年度之后的 2017 年第 29 题则以**后序**给出——后序即后缀表达式，可直接栈式求值，先序则须先建树（或反向扫描）。

## 4. 核心考点

核心考点：
DS03.04.02 树与二叉树的其他应用（表达式二叉树的表示：操作数为叶、运算符为内部结点，由树求值与由序列还原）

辅助考点：
DS03.02.03.01 前序遍历（"根—左—右"的递归切分，本题唯一的还原依据）；DS02.07 栈、队列和数组的应用（用栈式扫描对前缀表达式求值，作为第二种校验手段）

解释：题目本质是"表达式树"这一树的应用形态（DS03.04.02），把它和遍历序列互推（DS03.02.03）绑在一起；而复核时使用的是前缀表达式求值的栈过程模拟（DS02.07），三者共同构成本题的完整解法链。

## 5. 解题思路

1. **确认序列类型**：先序 = 根左右，序列首元素 $+$ 是整棵树的根；
2. **递归切分**：从序列头开始逐个读符号——读到运算符就"开一个新结点，并依次建它的左子树、右子树"；读到操作数就"建一个叶子并把它交回给父结点"；因运算符必然消耗两个子树，切分不需要试探回溯，一遍即成；
3. **画出树并写出中缀算式**：得到 $a+((b+c)\times d)$；
4. **代入求值**：先算括号内 $b+c=7$，再乘 $d=2$ 得 $14$，最后加 $a=6$ 得 $20$；
5. **反向复核两件事**：① 用"自右向左扫描前缀式 + 栈"再算一次值；② 对还原出的树重新做一次先序，检查是否恰好得到题给的 $+a*+bcd$（这一步能排除"树建错但值巧合"的情形）。

## 6. 详细解答

### 6.1 由先序序列还原表达式树

按 6 步递归消耗序列（记指针从左到右移动）：

| 读入符号 | 动作 | 说明 |
|---|---|---|
| $+$（第 1 个） | 建根结点 $+$，需求左、右两棵子树 | 先序首符号即树根 |
| $a$（第 2 个） | 建叶子 $a$，挂为根的**左孩子** | 操作数无孩子，一个符号消耗完左子树 |
| $*$（第 3 个） | 建结点 $*$，挂为根的**右孩子**，它还需两棵子树 | |
| $+$（第 4 个） | 建结点 $+$，挂为 $*$ 的左孩子，它还需两棵子树 | |
| $b$、$c$（第 5、6 个） | 叶 $b$、叶 $c$ 分别挂为该 $+$ 的左、右孩子 | 内层 $+$ 的子树齐了（$b+c$） |
| $d$（第 7 个） | 叶 $d$ 挂为 $*$ 的**右孩子** | $*$ 的子树齐了（$(b+c)*d$） |

序列恰好消耗完（共 $7$ 个符号：$3$ 个运算符 $+$、$*$、$+$ 与 $4$ 个操作数 $a,b,c,d$），且最后一步同时闭合了根 $+$ 的右子树 ⟹ 还原成功、树唯一。

得到的树（缩进表示层次）：

```
        +
       / \
      a   *
         / \
        +   d
       / \
      b   c
```

### 6.2 由树写中缀表达式并求值

- 内层结点 $+_1$（$*$ 的左孩子）：$b+c$；
- 结点 $*$：$(b+c)\times d$；
- 根 $+$：$a+((b+c)\times d)$。

代入 $a=6,b=3,c=4,d=2$：

$$b+c=3+4=7$$
$$(b+c)\times d=7\times 2=14$$
$$a+((b+c)\times d)=6+14=\boxed{20}$$

### 6.3 复核一：前缀表达式自右向左栈式求值

先序 $+a*+bcd$ 即前缀式（波兰式）。自右向左扫描，遇操作数入栈，遇运算符则**先弹出的作左操作数、后弹出的作右操作数**，算完压回：

| 扫描符号 | 栈内内容（左→右为底到顶） | 运算 |
|---|---|---|
| $d$ | $2$ | 入栈 |
| $c$ | $2,4$ | 入栈 |
| $b$ | $2,4,3$ | 入栈 |
| $+$ | $2,7$ | 弹 $3$（左）、$4$（右）：$3+4=7$ |
| $*$ | $14$ | 弹 $7$（左）、$2$（右）：$7\times2=14$ |
| $a$ | $14,6$ | 入栈 |
| $+$ | $20$ | 弹 $6$（左）、$14$（右）：$6+14=20$ |

栈顶余 $20$ ✓（若误把弹出顺序颠倒，乘法、加法在此题仍可交换，减法/除法题就必须严格区分左右，见第 9 节）。

### 6.4 复核二：对还原的树重算三种遍历

| 遍历 | 序列 |
|---|---|
| 先序（根左右） | $+,a,*,+,b,c,d$ → $+a*+bcd$ ✓ 与题面完全一致 |
| 中序（左根右） | $a,+,b,+,c,*,d$ → $a+b+c*d$（不加括号会歧义，故须按树补括号为 $a+((b+c)*d)$） |
| 后序（左右根） | $b,c,+,d,*,a,+$ → $bc+d*a+$ |

后序序列即后缀式，按其求值：$3,4,+ \to 7$；$7,2,* \to 14$；$14,6,+ \to 20$ ✓（第三次独立得值）。先序能唯一还原本树，而重算的先序又与题面逐符号相同，故不存在"另一种树形也能给出 $+a*+bcd$"的可能（表达式树中运算符必带两子树，任何改挂法都会使先序符号顺序或孩子数改变）。

**答案**：$20$。

## 8. 考场标准答案

先序 $+a*+bcd$ 的第一个符号 $+$ 为树根，$a$ 为其左孩子；其余 $*+bcd$ 构成根的右子树，其根为 $*$，左子树为 $+$（孩子 $b,c$），右孩子为 $d$：

$$\text{表达式}=a+((b+c)\times d)$$

代入 $a=6,b=3,c=4,d=2$：

$$6+(3+4)\times 2=6+14=\boxed{20}$$

## 9. 易错点

1. **按算术优先级读串**：把 $+a*+bcd$ 直接当 "$a+b*c+d$" 之类去凑，得到 $6+3\times4+2$ 一类的错值；必须先还原树，运算次序由树的层次决定，与符号优先级无关；
2. **切分位置错**：把 $*$ 的右孩子错认成 $c$（即让内层 $+$ 只拿到一个孩子），根本原因是没记住"运算符结点必须消耗两棵子树"；按 6.1 的表格逐符号计数即可避免；
3. **符号数校验缺失**：$7$ 个符号的表达式树必含 $3$ 个内部结点、$4$ 个叶子（$n_0=n_2+1$，见本年度第 27 题同款关系）；建完树一数结点，若内部结点不是 $3$ 个或叶子不是 $4$ 个，说明建错；
4. **栈式求值时左右操作数颠倒**：本题只有加法与乘法，交换后数值不变，**错了也发现不了**；若换成 $-$、$/ $（如 2013 年第 27 题 $abcd-*+ef/-$），顺序错就得错值，故复核时要按"先弹出的是左操作数"这一约定写死；
5. **把先序当后序**：后序才是后缀表达式、可自左向右扫描求值；先序须自右向左扫描或先建树，两种扫描方向不要混用。

## 10. 一句话规律

表达式树的遍历序列是一枚"结构钥匙"：**先序（前缀）自右向左求值、后序（后缀）自左向右求值、中序需补括号**；由先序还原树靠的正是"运算符必有两子树、操作数必为叶子"这一约束，所以建完一定要把遍历序列反向重算一遍回对题面。
