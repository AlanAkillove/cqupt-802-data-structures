# DS-2015-41

## 1. 原题

简要说明快速排序的排序思想。根据所给序列（ $49,38,65,97,76,13,27,50$ ），设选第一个元素为支点/参考值（ $pivot$ ），写出快速排序的第一趟排序的结果。

## 2. 答案

**排序思想**：任取一个记录（本题取第一个记录 $49$）作为基准（支点 $pivot$），从表的两端交替地向中间扫描，把所有比基准小的记录移到基准之前、比基准大的记录移到基准之后，这一过程称为**一趟快速排序（划分 $partition$）**；划分结束后基准落在它的最终位置，表被分成两个独立子表，再对两个子表分别递归地做同样的划分，直到各子表长度不超过 $1$，排序完成。

**第一趟排序结果**：

$$(27,\;38,\;13,\;\underline{49},\;76,\;97,\;65,\;50)$$

即左半 $(27,38,13)$ 全部 $<49$，右半 $(76,97,65,50)$ 全部 $>49$，$49$ 已在最终位置（下标 4）。

## 3. 题目分析

- 已知：含 $8$ 个关键字的序列 $49,38,65,97,76,13,27,50$；约定"选第一个元素为支点"；
- 目标：① 叙述快排思想；② 写出**第一趟**（一次划分）之后的序列；
- 关键约束：一趟划分只做一次"基准归位 + 左右划分"，**不递归**；划分过程中其余记录的相对次序会被打乱，故不能答成"排好序的样子"；
- 命题意图：本序列正是严蔚敏教材演示快速排序所用的例子（教材表 9-6 的第一趟结果），考"能否按教材的挖补式 $Partition$ 逐步执行"，而不是背一个"最终有序序列"。同时呼应本卷第 17 题（初始有序时快排最费时）与第 36 题（快排时间复杂度）这两个快排概念考点。

## 4. 核心考点

核心考点：
DS06.06 快速排序——划分（partition）的思想与一趟执行结果

辅助考点：
DS06.01 排序的基本概念——"趟"的定义（一趟划分只能确定**基准一个**元素的最终位置，这与堆排序、简单选择排序每趟确定一个、冒泡每趟确定一个、插入每趟确定一个的对比是常见命题点）

解释：本题既要复述算法思想（CONCEPT），又要机械执行一趟划分（TRACE）；"第一趟结束只能确定一个元素的最终位置"正是 DS06.01 中"趟"概念的典型体现。

## 5. 解题思路

1. 把 $49$ 取出暂存，视其原位置（下标 1）为一个"空坑"；不变式：**坑的左边都 $<49$，坑的右边都 $>49$，坑两侧已扫描过的区间与原始数据一致**；
2. 从**右端**开始向左找第一个比 $49$ 小的记录，把它填进左边的坑，自己原位置成为新坑；
3. 再从**左端**向右找第一个比 $49$ 大的记录，填进右边的坑；
4. 交替进行直到两个指针相遇，把暂存的 $49$ 填入最后的坑——基准归位，一趟结束；
5. 写完结果后必做两项检查：① 基准左侧全部 $<49$、右侧全部 $>49$；② 元素多重集与原序列相同（无丢失、无重复）。

## 6. 详细解答

**（1）一趟划分的逐步执行**（下标 $1\sim8$，$i$ 自左向右、$j$ 自右向左，$pivot=49$ 暂存于工作量，$▢$ 表示当前的“坑”）

| 步 | 动作 | 指针变化 | 序列状态（下标 1…8） |
|---|---|---|---|
| 初 | 取出 $49$ 作基准，1 号位成坑 | $i=1,j=8$ | $▢,38,65,97,76,13,27,50$ |
| 1 | $j$ 左移：$50\ge49$、$27<49$ 停 → $r[1]\leftarrow27$ | $j=8\to7$ | $27,38,65,97,76,13,▢,50$（坑移至 7） |
| 2 | $i$ 右移：$27,38\le49$、$65>49$ 停 → $r[7]\leftarrow65$ | $i=1\to3$ | $27,38,▢,97,76,13,65,50$（坑移至 3） |
| 3 | $j$ 左移：$65\ge49$、$13<49$ 停 → $r[3]\leftarrow13$ | $j=7\to6$ | $27,38,13,97,76,▢,65,50$（坑移至 6） |
| 4 | $i$ 右移：$97>49$ 停 → $r[6]\leftarrow97$ | $i=3\to4$ | $27,38,13,▢,76,97,65,50$（坑移至 4） |
| 5 | $j$ 左移：$76\ge49$ 继续，$j=4=i$ 相遇，扫描结束 | $j=6\to4$ | 同上 |
| 6 | 把暂存的 $49$ 填入 4 号坑 | — | $27,38,13,\mathbf{49},76,97,65,50$ |

**第一趟结果**：$27,38,13,\underline{49},76,97,65,50$。

**（2）结果自检**

- 大小关系：左侧 $\{27,38,13\}$ 均 $<49$ ✓；右侧 $\{76,97,65,50\}$ 均 $>49$ ✓；
- 多重集：$\{13,27,38,49,50,65,76,97\}$ 与原序列 $\{49,38,65,97,76,13,27,50\}$ 完全相同 ✓（无丢失、无重复）；
- 基准位置：$49$ 落在第 $4$ 个位置，恰为它在最终有序表中的位置 ✓；一趟只确定这**一个**元素的最终位置。

**（3）后续递归（题目未问，列出以说明"思想"的完整性）**

$$\underbrace{(27,38,13)}_{\text{子表1，枢轴 }27}\quad 49 \quad \underbrace{(76,97,65,50)}_{\text{子表2，枢轴 }76}$$

子表 1 以 $27$ 为基准再划分得 $(13,27,38)$；子表 2 以 $76$ 为基准划分得 $(50,65),76,(97)$……如此递归，最终得到 $13,27,38,49,50,65,76,97$。

**（4）教材风格的一趟划分算法（供书写"具体过程"时对照）**

```c
typedef int ElemType;
/* 对 r[low..high] 作一趟划分，r[low] 兼作暂存单元（哨兵），返回基准的最终位置 */
int Partition(ElemType r[], int low, int high)
{
    ElemType pivot = r[low];                    /* 选第一个元素为支点 */
    while (low < high) {
        while (low < high && r[high] >= pivot)  --high;   /* 自右向左找第一个小于 pivot 的记录 */
        r[low] = r[high];                                 /* 小于 pivot 的记录移到低端 */
        while (low < high && r[low] <= pivot)   ++low;    /* 自左向右找第一个大于 pivot 的记录 */
        r[high] = r[low];                                 /* 大于 pivot 的记录移到高端 */
    }
    r[low] = pivot;                             /* 基准归位 */
    return low;
}
```

对本序列调用 `Partition(r,1,8)` 返回 $4$，表变为 $27,38,13,49,76,97,65,50$，与第（1）步走查一致 ✓。

**（5）复杂度与性质（叙述"思想"时一并写出更完整）**

平均时间 $O(n\log_2 n)$，最坏（序列已有序且总取第一个元素为基准）退化为 $O(n^2)$（本卷第 17 题）；空间为递归栈 $O(\log_2 n)$（最坏 $O(n)$）；**不稳定**；每趟只确定一个元素的最终位置。

## 8. 考场标准答案

**思想**：取某一记录为基准（pivot），通过一趟划分将序列分成两部分——凡比基准小的都在其左、比基准大的都在其右，基准落到最终位置；再对左右两部分分别递归地做同样的划分，直至各部分长度不超过 1。平均时间复杂度 $O(n\log_2 n)$，最坏 $O(n^2)$，不稳定，一趟只确定一个元素的最终位置。

**一趟过程**（$pivot=49$，$▢$ 为当前的坑）：

$$▢\,38\,65\,97\,76\,13\,27\,50 \;\xrightarrow{\;j:27\;}\; 27\,38\,65\,97\,76\,13\,▢\,50 \;\xrightarrow{\;i:65\;}\; 27\,38\,▢\,97\,76\,13\,65\,50$$

$$\xrightarrow{\;j:13\;}\; 27\,38\,13\,97\,76\,▢\,65\,50 \;\xrightarrow{\;i:97\;}\; 27\,38\,13\,▢\,76\,97\,65\,50 \;\xrightarrow{\;i=j=4\;}\; 27\,38\,13\,\mathbf{49}\,76\,97\,65\,50$$

**第一趟结果**：$(27,38,13,49,76,97,65,50)$。

## 9. 易错点

1. 答成"最终有序序列"：第一趟只完成**一次划分**，$76,97,65,50$ 的相对次序仍是原序列中的次序（$76,97,65,50$），不要顺手排成 $50,65,76,97$；
2. 划分写法混用导致结果不同：本题按教材"挖补（移动记录）"式划分，结果为 $27,38,13,49,76,97,65,50$；若改用"左右指针相遇后交换 $a[i]$ 与 $a[j]$、最后把 $a[1]$ 与 $a[j]$ 交换"的**交换式**划分，同一序列一趟结果为 $13,38,27,49,76,97,65,50$。两者都满足"左小右大"，但中间记录次序不同——考试应按教材（或题面所给代码）的写法作答，并在卷面写明所用划分方式；
3. 扫描方向记反：教材规定**先从右向左**扫描（因基准取自低端，低端先成坑），若先从左向右会覆盖基准值；
4. 边界指针漏写 $low<high$ 条件：内层两个 $while$ 都必须带 $low<high$，否则序列已有序时指针会越界；
5. 把"趟"与"比较次数/移动次数"混淆：本趟划分中记录关键字与基准共比较 $11$ 次（$50,27\mid 27,38,65\mid 65,13\mid 13,97\mid 97,76$）、记录移动 $5$ 次（含最后的基准归位），这些不是本题所问，但常被误当作"趟数"来答；注意被移动进坑的那个值会被相邻方向的扫描**再比较一次**（如 $27$、$65$、$13$、$97$），故比较次数大于元素个数。

## 10. 一句话规律

快排"一趟"题的固定解法：基准入坑 → 右往左找小的填左坑 → 左往右找大的填右坑 → 交替至指针相遇 → 基准归位；写完只查两件事（基准左小右大、元素不重不漏），并记住"一趟只定一个位置"。
