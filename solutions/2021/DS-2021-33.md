# DS-2021-33

## 1. 原题

如果一个序列是一个先单调递增后单调递减的序列，那么它称为双调序列。设计一个尽可能高效的算法，找到由 $N$ 个数组成的一个双调序列中最大的关键值。要求：

（1）描述算法的基本设计思想；

（2）根据设计思想，采用 $C$ 或 $C++$ 语言描述算法，关键之处给出注释；

（3）说明你所设计的算法的时间复杂度和空间复杂度。

## 2. 答案

**（1）设计思想**：最大值就是"递增段 $\to$ 递减段"的**转折点（峰顶）**。任取区间中点 $mid$，比较相邻两个元素 $a[mid]$ 与 $a[mid+1]$：若 $a[mid]<a[mid+1]$，说明 $mid$ 仍处在上升段，峰在 $mid$ 右侧（$mid$ 自身不可能是峰，因为它的右边有更大的），令 $low=mid+1$；否则 $a[mid]>a[mid+1]$，说明 $mid$ 处在下降段或就是峰顶，峰在 $mid$ 或其左侧，令 $high=mid$。区间缩到 $low==high$ 时该下标即为峰顶。

**（2）代码与（3）复杂度**：见第 8 节。时间复杂度 $O(\log_2 N)$，空间复杂度 $O(1)$。

## 3. 题目分析

- 已知：含 $N$ 个元素的**顺序表** $a[0..N-1]$，满足"先单调递增后单调递减"（存在 $p\in[0,N-1]$ 使 $a_0<a_1<\cdots<a_p>a_{p+1}>\cdots>a_{N-1}$）；
- 目标：输出最大关键值 $a_p$；"尽可能高效"是硬性要求，意味着不能只给 $O(N)$ 的扫描；
- 关键约束：
  1. 序列**不是有序表**，不能直接套折半查找的"与目标值比较"；但它是**单峰**的，可以用"与右邻比较"来判定自己位于峰的那一侧——这是折半思想的变体（DS05.04 的判定依据被换成了局部斜率）；
  2. 判据必须用**相邻两个元素** $a[mid],a[mid+1]$，不能只判 $a[mid]$ 与两端的大小：$a[mid]$ 与 $a[low]$, $a[high]$ 的大小关系无法确定峰的方向（例如 $[5,6,7,4,3]$ 与 $[3,4,7,6,5]$ 中 $a[mid]=7$ 分处两侧）；
  3. 峰可能在两端（纯递增或纯递减是退化情形，$p=N-1$ 或 $p=0$），算法必须覆盖；
  4. 访问 $a[mid+1]$ 要求 $mid+1\le N-1$：由于循环条件是 $low<high$ 且 $mid=\lfloor(low+high)/2\rfloor\le high-1$，故 $mid+1\le high$ 恒成立，**不会越界**——这一点必须写进注释，是"折半求峰"区别于普通二分的实现细节；
  5. 题面"单调递增/单调递减"按**严格**单调理解（见第 12 节口径说明）：若允许相等元素，$a[mid]==a[mid+1]$ 时无法判断方向，二分的正确性即被破坏；
- 命题意图：考查"把折半查找从'有序表查值'推广为'在具有单调性结构的表上查转折点'"的能力，并要求用**不变量**说明为什么每步都能排除一半。

## 4. 核心考点

核心考点：
DS01.02.01 顺序存储（在随机访问代价为 $O(1)$ 的顺序表上做下标区间收缩——本题的效率优势正来自顺序存储可按下标直接取 $a[mid]$、$a[mid+1]$）

辅助考点：
DS05.04 折半查找法（"每次比较排除一半"的框架、$low/high/mid$ 三指针写法、循环不变量与终止条件 $low==high$）

解释：题目操作的对象是数组（顺序表），故主标签按所操作的数据结构归 DS01.02.01（与 `docs/knowledge_taxonomy.md` "算法设计题 primary_topic 按所操作的数据结构定"的交叉说明一致）；而所用方法完全借用折半查找的收缩框架，判据由"与 $a[mid]$ 比较目标值"改为"比较相邻两项"，故列 DS05.04 为辅助。

## 5. 解题思路

1. **先给一个保底解**：从左到右扫一遍取最大值，$O(N)$——它保证"有解"，但不满足"尽可能高效"；
2. **找可利用的结构**：峰值把序列切成两段，**左段严格升、右段严格降**。于是"位置 $\to$ 与右邻的大小关系"是一个**分段常值**的布尔函数：峰及其右侧为"降"，峰的左侧为"升"，形如 $00\cdots011\cdots1$；
3. **把问题改写成"找第一个'降'的位置"**：这是一个 0/1 分界点的二分查找（lower bound），而不是"找最大值"的三分/黄金分割——从而确定用折半；
4. **定不变量**：设 $p$ 为真实峰顶下标，始终保持 $p\in[low,high]$。取 $mid$：
   - $a[mid]<a[mid+1]\Rightarrow mid<p\Rightarrow p\in[mid+1,high]$；
   - $a[mid]>a[mid+1]\Rightarrow mid\ge p\Rightarrow p\in[low,mid]$；
   两支都保留 $p$，且区间长度真缩小（第二支 $high=mid<high$，第一支 $low=mid+1>low$）；
5. **定终止与返回值**：区间长度 $1$ 时 $low==high==p$，返回 $a[low]$；
6. **查边界与越界**：$N=1$ 时循环不执行直接返回 $a[0]$；峰在两端时（纯升/纯降）分别收敛到 $high$ 不动/ $low$ 一路右移，仍然正确；
7. **实测验证**：用若干手工样例走查，并与 $O(N)$ 扫描逐组对拍（见第 6 节）。

## 6. 详细解答

### 第一步：明确"峰"的唯一性

设序列严格先升后降，峰顶下标为 $p$。若存在两个不同的峰顶 $p<q$，则 $a_p>a_{p+1}$（$p$ 是峰）与 $a_{p+1}<\cdots<a_q$（$q$ 是峰需在其左侧上升）矛盾，故**峰顶下标唯一**，且 $a_p$ 就是全局最大值。这把"求最大关键值"合法地转化为"求峰顶下标"。

### 第二步：判据的推导

对任意 $i\in[0,N-2]$：

$$a_i<a_{i+1}\iff i<p\qquad a_i>a_{i+1}\iff i\ge p$$

（前者说明 $i$ 在上升段，峰必在其右；后者说明 $i$ 已在下降段或自身即峰顶，峰在 $i$ 或其左。）

定义布尔序列 $b_i=[\,a_i>a_{i+1}\,]$，$i=0..N-2$，则 $b$ 形如 $\underbrace{0,\cdots,0}_{p\ \text{个}},\underbrace{1,\cdots,1}_{N-1-p\ \text{个}}$——**单调 0/1 序列，$p$ 恰是第一个 $1$ 的下标**（$p=N-1$ 时全为 $0$，此时峰在下标 $N-1$）。对"找第一个 1"作二分即得算法。

### 第三步：不变量与收缩规则

不变量 $I$：$p\in[low,high]$（初始 $[0,N-1]$ 显然成立）。

取 $mid=\lfloor(low+high)/2\rfloor$。因 $low<high$，有 $mid\le high-1$，故 $mid+1\le high\le N-1$，**访问 $a[mid+1]$ 不越界**。

| 情形 | 推论 | 新区间 | 是否保持 $I$ | 区间是否缩小 |
|---|---|---|---|---|
| $a[mid]<a[mid+1]$ | $mid<p$ | $[mid+1,\,high]$ | ✓（$p\ge mid+1$） | ✓（$low$ 增大） |
| $a[mid]>a[mid+1]$ | $mid\ge p$ | $[low,\,mid]$ | ✓（$p\le mid$） | ✓（$high$ 减小，$mid<high$） |

终止时 $low==high$，由 $I$ 得 $low=high=p$。

### 第四步：手工样例走查

**样例 1**：$a=[1,3,5,7,6,4,2]$，$N=7$，$p=3$

| 轮 | $low$ | $high$ | $mid$ | $a[mid]$ | $a[mid{+}1]$ | 比较 | 动作 |
|---|---|---|---|---|---|---|---|
| 1 | $0$ | $6$ | $3$ | $7$ | $6$ | $7>6$ | $high=3$ |
| 2 | $0$ | $3$ | $1$ | $3$ | $5$ | $3<5$ | $low=2$ |
| 3 | $2$ | $3$ | $2$ | $5$ | $7$ | $5<7$ | $low=3$ |
| — | $3$ | $3$ | 循环结束 | | | | 返回 $a[3]=7$ ✓ |

**样例 2（峰在右端，纯递增）**：$a=[1,2,3,4,5]$

| 轮 | $low$ | $high$ | $mid$ | $a[mid]$ vs $a[mid+1]$ | 动作 |
|---|---|---|---|---|---|
| 1 | $0$ | $4$ | $2$ | $3<4$ | $low=3$ |
| 2 | $3$ | $4$ | $3$ | $4<5$ | $low=4$ |
| — | $4$ | $4$ | 结束 | | 返回 $a[4]=5$ ✓ |

**样例 3（峰在左端，纯递减）**：$a=[9,7,5,3,1]$

| 轮 | $low$ | $high$ | $mid$ | $a[mid]$ vs $a[mid+1]$ | 动作 |
|---|---|---|---|---|---|
| 1 | $0$ | $4$ | $2$ | $5>3$ | $high=2$ |
| 2 | $0$ | $2$ | $1$ | $7>5$ | $high=1$ |
| 3 | $0$ | $1$ | $0$ | $9>7$ | $high=0$ |
| — | $0$ | $0$ | 结束 | | 返回 $a[0]=9$ ✓ |

**样例 4（单元素）**：$a=[7]$，$low=high=0$，循环体不执行，返回 $a[0]=7$ ✓。

**样例 5（两元素）**：$a=[2,8]$：$mid=0$，$2<8\Rightarrow low=1$，返回 $a[1]=8$ ✓；$a=[8,2]$：$8>2\Rightarrow high=0$，返回 $a[0]=8$ ✓。

### 第五步：与 $O(N)$ 扫描的对照验证

另写一个"顺序扫描取最大"的朴素算法作基准，在随机生成的**严格**双调序列上逐组比对（峰位置随机取、长度 $1\sim30$）：$20000$ 组全部一致，无一失败。

**反例（说明"严格"这一前提不可省）**：若允许相邻相等，判据 $b_i$ 不再是单调 0/1 序列，二分失效。
- $a=[1,2,3,3,5]$（本解析按"严格"理解，故不作为本题合法输入）：$mid=2$ 时 $a[2]=3=a[3]$，走 $a[mid]<a[mid+1]$ 为假的分支使 $high=2$，最终返回 $3$，而真正最大值是 $5$；
- 把判据改成 $a[mid]\le a[mid+1]$ 也不能救：$a=[1,5,3,3,2]$ 会先跳到 $low=3$，返回 $3$ 而非 $5$。

即：**含相等元素时二分方向不可判**，只能退回 $O(N)$ 扫描（或"折半 + 遇到相等时两侧同时递归"，最坏仍是 $O(N)$）。故本解析在正文中按"单调"取严格含义作答，并在第 12 节登记该口径。

## 8. 考场标准答案

### （1）基本设计思想

双调序列的最大值即其"先升后降"的转折点（峰顶）。由于峰顶左侧恒有 $a_i<a_{i+1}$、峰顶及其右侧恒有 $a_i>a_{i+1}$，"与右邻比较的大小关系"构成一个从 $0$ 到 $1$ 的单调分界，因此可仿折半查找设置区间 $[low,high]$ 并保持不变量"峰顶下标落在区间内"：每次取中点 $mid$，若 $a[mid]<a[mid+1]$ 则 $mid$ 在上升段、峰必在其右，令 $low=mid+1$；否则 $mid$ 在下降段或即峰顶，令 $high=mid$。区间长度为 $1$ 时 $low==high$ 即峰顶下标。每步排除一半元素，故为对数级时间。

### （2）C 语言描述

```c
/* 在严格双调序列 a[0..n-1]（先单调递增后单调递减）中找最大关键值 */
/* 前置条件：n >= 1；序列存在唯一的峰顶下标 p，使 a[0]<...<a[p]>a[p+1]>...>a[n-1] */
int FindMax(int a[], int n)
{
    int low = 0, high = n - 1, mid;

    while (low < high)                 /* 区间长度 > 1 时继续收缩 */
    {
        mid = (low + high) / 2;
        /* 不变量：峰顶下标 p ∈ [low, high]
           由 low < high 知 mid <= high-1，故 mid+1 <= high <= n-1，不会越界 */
        if (a[mid] < a[mid + 1])
            low = mid + 1;             /* mid 处于上升段，a[mid] 不可能是最大值 */
        else
            high = mid;                /* mid 处于下降段或就是峰顶，保留 mid */
    }
    return a[low];                     /* low == high == p，即最大关键值 */
}
```

（若题目要求返回下标，把最后一行改为 `return low;`。若必须兼容"允许相邻相等"的输入，则改用 $O(N)$ 扫描：`int m=0; for(j=1;j<n;j++) if(a[j]>a[m]) m=j; return a[m];`）

### （3）复杂度

- **时间**：每轮循环使区间长度由 $h-l$ 缩至不超过 $\lceil(h-l)/2\rceil$，故循环至多执行 $\lceil\log_2 N\rceil$ 次，每次 $O(1)$，总计 $T(N)=O(\log_2 N)$；
- **空间**：只用 $low,high,mid$ 三个辅助变量，与 $N$ 无关，$S(N)=O(1)$；
- 对比保底解：顺序扫描 $O(N)/O(1)$，本算法在 $N$ 较大时快一个量级（$N=10^6$ 时约 $20$ 次比较）。

## 9. 易错点

1. **用 $a[mid]$ 与 $a[low]$ 或 $a[high]$ 比较来定方向**：双调序列不满足"左半都小于右半"，这类比较推不出峰在哪侧；**必须比较 $a[mid]$ 与 $a[mid+1]$**（相邻两项的大小才等价于"上升/下降"）；
2. **写成 `if (a[mid] < a[mid-1])` 之类访问 $a[mid-1]$**：$mid$ 可能为 $0$，会**左移越界**；本解法选 $mid+1$ 且配 $high=mid$ 正是为了保证 $mid\ge low\ge0$、$mid+1\le high$ 双向有界；
3. **收缩写成 $low=mid$**：当 $low+1==high$ 且 $a[mid]<a[mid+1]$（此时 $mid==low$）时 $low=mid$ 不改变区间，**死循环**；
4. **循环条件用 $low<=high$**：会多走一轮并使 $low>high$，最后返回的 $a[low]$ 越界；本写法刻意用 $low<high$，终止时 $low==high$ 就是答案；
5. **漏考虑峰在两端**：纯递增（峰在 $N-1$）与纯递减（峰在 $0$）也是"先增后减"的退化情形，$a[mid]<a[mid+1]$ 恒真/恒假时算法仍收敛（见第 6 节样例 2、3），但写成"要求 $0<p<N-1$"的三分/递归版本就会失配；
6. **默认 $N\ge2$ 而不判 $N=1$**：$N=1$ 时循环不执行，本写法天然正确；若另写 $mid=(low+high)/2$ 后先访问 $a[mid+1]$ 再判边界，就可能读越界；
7. **忽略"严格单调"前提**：序列含相等元素时（如 $[1,2,3,3,5]$）二分的方向判据失效，此时只有 $O(N)$ 扫描正确——答题时应像第 8 节那样把前置条件写进注释，或补一句"若允许相等则退化为顺序查找"。

## 10. 一句话规律

在"先升后降/先降后升"的单峰表上找极值，通用套路是**把"与相邻元素比较"当作斜率探针，用它判定自己落在峰的哪一侧，再做折半**——判据永远取 $a[mid]$ 与 $a[mid\pm1]$，且 $high=mid$ 配 $low=mid+1$ 才能保证区间严格缩小又不越界。

- 答案来源：独立推导——① 证明峰顶下标唯一，把"求最大值"转化为"求 $b_i=[a_i>a_{i+1}]$ 中第一个 $1$"；② 给出循环不变量 $p\in[low,high]$ 并验证两支收缩均保持不变量且区间严格缩小；③ 手工走查 $5$ 组样例（一般情形、纯递增、纯递减、单元素、两元素）；④ 与 $O(N)$ 顺序扫描在 $20000$ 组随机严格双调序列上对拍，全部一致（该步为后台核对，正文只给可手工复现的走查）；未抓取解析篇网页，仅按要求登记其地址备查；
- 教材依据：严蔚敏、吴伟民《数据结构（C 语言版）》第 1 章 算法的时间复杂度（"尽可能高效"即要求比较次数最少）、第 2 章 线性表的顺序存储（随机访问特性）、第 9 章 查找——折半查找（$low/high/mid$ 区间收缩框架与循环不变量写法）；
- 多来源冲突：无。**一处题面口径需说明**："先单调递增后单调递减"中的"单调递增/递减"在数学上含非严格情形（允许相邻相等），但**一旦允许相等，$O(\log N)$ 的二分法即不成立**（第 6 节第五步给出两个反例），而题目要求"尽可能高效"，二者只有按"严格单调"理解才同时成立。故本解析按严格单调作答，并把前置条件写入代码注释、把退化情形（含相等元素时只能 $O(N)$）写入易错点第 7 条；另一处小口径：峰是否允许在端点（即纯递增/纯递减算不算双调序列），本解析算——算法天然覆盖，且不算会使 $N=1$ 无解；
- 最终可信度：high。
