# DS-2021-07

## 1. 原题

下列序列中，哪一个是堆（ ）？

A. $75,65,30,15,25,45,20,10$

B. $75,65,45,10,30,25,20,15$

C. $75,45,65,30,15,25,20,15$

D. $75,45,65,10,25,30,20,15$

## 2. 答案

**C**（序列 $75,45,65,30,15,25,20,15$ 构成一个大顶堆）。

## 3. 题目分析

- 已知：四个长度 $n=8$ 的关键字序列；序列按**顺序存储**理解为一棵完全二叉树——层序编号 $1\sim8$，结点 $i$ 的左孩子 $2i$、右孩子 $2i+1$、双亲 $\lfloor i/2\rfloor$；
- 目标：判断哪个序列满足堆的定义；
- 关键约束：堆只约束**父子之间**的大小关系（大顶堆：$k_i\ge k_{2i}$ 且当 $2i+1\le n$ 时 $k_i\ge k_{2i+1}$；小顶堆反向），**同层/叔侄之间没有任何要求**；需要检查的只有 $i=1,2,\dots,\lfloor n/2\rfloor=4$ 这四个非终端结点；
- 命题意图：考"把一维序列翻译成完全二叉树再逐对比较"这一机械动作，并用 B/D 两个"只有最后一处错"的序列排查"只查上半部分/只查左右孩子之一"的漏检。

## 4. 核心考点

核心考点：
DS06.07 堆与堆排序（堆的形式化定义 $k_i\ge(\le) k_{2i},k_{2i+1}$，以及"堆只约束父子"这一辨析）

辅助考点：
DS03.02.01 二叉树的定义及主要特征（完全二叉树层序编号的 $2i/2i+1/\lfloor i/2\rfloor$ 关系，是把序列还原成树形的前提）

解释：判堆的第一步是把下标换算成父子（完全二叉树编号性质），第二步才是大小比较（堆定义）；本库中"建初堆从第 $\lfloor n/2\rfloor$ 个结点开始调整"（DS-2012-36、DS-2015-37）用的正是同一套下标关系，可见它属于两个节点的共用基础。

## 5. 解题思路

1. **先定方向**：四个序列的根（第 1 个元素）都是 $75$，而 $75$ 恰是各自序列的最大值 ⟹ 若某个序列是堆，只能是**大顶堆**（小顶堆要求根最小，直接排除小顶解释，四个选项无需再按小顶各查一遍）；
2. **列出待检查的对**：$n=8$，非终端结点为 $i=1,2,3,4$；需比较 7 对父子：$(1,2),(1,3),(2,4),(2,5),(3,6),(3,7),(4,8)$；
3. 对每个序列逐对验证，一旦发现"父 $<$ 子"即判非堆；
4. 把通过的序列画成树形再复核一遍（防止下标数错），并确认结点 4 的**单个**左孩子（下标 8）也被检查到——这是本题唯一容易漏的一边。

## 6. 详细解答

下标与层序对应关系（$n=8$ 的完全二叉树）：

```
              [1]
           /       \
        [2]         [3]
       /   \       /   \
     [4]   [5]   [6]   [7]
     /
   [8]
```

即父 1 的子为 2、3；父 2 的子为 4、5；父 3 的子为 6、7；父 4 的子只有 8（$2\times4+1=9>8$）。

**A：$75,65,30,15,25,45,20,10$**

| 父子对 | 值 | 大顶要求 | 结论 |
|---|---|---|---|
| (1,2) | 75,65 | ✓ | |
| (1,3) | 75,30 | ✓ | |
| (2,4)(2,5) | 65 vs 15,25 | ✓ | |
| (3,6) | **30,45** | $30\ge45$ | ✗ **违反** |
| (3,7) | 30,20 | ✓ | |
| (4,8) | 15,10 | ✓ | |

结点 3 的值 $30$ 小于其左孩子 $45$ ⟹ A 不是大顶堆；又因根 $75$ 最大，也不可能的小顶堆。**A 非堆**。

**B：$75,65,45,10,30,25,20,15$**

前三组全部通过（$75\ge65,45$；$65\ge10,30$；$45\ge25,20$），检查最后一组：

| 父子对 | 值 | 大顶要求 | 结论 |
|---|---|---|---|
| (4,8) | **10,15** | $10\ge15$ | ✗ **违反** |

结点 4（值 $10$）只有左孩子 $15$，$10<15$ ⟹ **B 非堆**。这正是"最后一个结点的单孩子"漏检的典型。

**C：$75,45,65,30,15,25,20,15$**

| 父子对 | 值 | 大顶要求 | 结论 |
|---|---|---|---|
| (1,2) | 75,45 | ✓ | ✓ |
| (1,3) | 75,65 | ✓ | ✓ |
| (2,4) | 45,30 | ✓ | ✓ |
| (2,5) | 45,15 | ✓ | ✓ |
| (3,6) | 65,25 | ✓ | ✓ |
| (3,7) | 65,20 | ✓ | ✓ |
| (4,8) | 30,15 | ✓ | ✓ |

七对全部满足 ⟹ **C 是大顶堆**。树形为

```
              75
           /      \
        45          65
       /  \        /  \
     30    15    25    20
     /
    15
```

注意 $45<65$（兄弟之间无序）、$15$ 出现两次（堆允许相等关键字），都不违反定义。

**D：$75,45,65,10,25,30,20,15$**

| 父子对 | 值 | 大顶要求 | 结论 |
|---|---|---|---|
| (3,6) | 65,30 | ✓ | |
| (3,7) | 65,20 | ✓ | |
| (4,8) | **10,15** | $10\ge15$ | ✗ **违反** |

与 B 同型错误（结点 4 的值小于其左孩子），只是这一序列把 B 中的 $45/10,30$ 换成了 $65/10,25$ ⟹ **D 非堆**。

**第二条复核途径（自底向上看每支）**：大顶堆要求"每个子树根是该子树的最大值"。
C 中：以 45 为根的子树 $\{45,30,15,15\}$ 最大值 45 ✓；以 65 为根的子树 $\{65,25,20\}$ 最大值 65 ✓；全树最大值 75 在根 ✓。
A 中：以 30 为根的子树 $\{30,45,20\}$ 最大值是 45 而非 30 ✗；
B、D 中：以 10 为根的子树 $\{10,15\}$ 最大值是 15 ✗。
两条途径结论一致。

**答案**：C。

## 7. 选项分析

- A（$\dots,30,15,25,45,20,10$）：错。结点 3 的 $30$ 与其左孩子 $45$ 违反大顶关系——$45$ 与 $30$ 在序列中相隔很远（下标 3 与 6），但下标 $2\times3=6$ 使其成为父子，这是"看序列不看下标"的典型漏判；
- B（$\dots,10,30,25,20,15$）：错。前三层完全合法，只在结点 4（值 $10$）与其左孩子 $15$ 处违反；漏检第 8 个元素（$n$ 为偶数时最后一个非叶结点只有一个左孩子）就会误判为堆；
- C：正确，大顶堆；
- D（$\dots,10,25,30,20,15$）：错。与 B 相同一个失败点（结点 4 的 $10$ 小于其左孩子 $15$）；B 与 D 的前三个结点完全相同，差异只在结点 4 及其子树，是专门针对“最后那一对”设计的近似干扰项。

## 8. 考场标准答案

把序列按层序写成完全二叉树，只需检查 $i=1\sim\lfloor n/2\rfloor=4$：

$$k_i\ge k_{2i},\quad 2i+1\le n \text{ 时 } k_i\ge k_{2i+1}$$

四序列的根均为最大值 $75$，只可能是大顶堆。逐序列查违反对：
A：$k_3=30<k_6=45$ ✗；B：$k_4=10<k_8=15$ ✗；D：$k_4=10<k_8=15$ ✗；
C：$75\!\ge\!45,65$；$45\!\ge\!30,15$；$65\!\ge\!25,20$；$30\!\ge\!15$ 全部成立 ⟹ **选 C**（大顶堆）。

## 9. 易错点

1. **只按书写顺序两两比较**（$75>45>65$？看着"乱了"就判非堆）：堆不管同层大小，$45$ 与 $65$ 是兄弟，$45<65$ 完全合法；
2. **漏算单孩子**：$n=8$ 时结点 4 只有左孩子 $8$，B、D 的错误就藏在这唯一一对上；判据是 $2i\le n$ 就必须查、$2i+1\le n$ 才查右边；
3. **下标起点弄错**：堆的下标关系这里按 $1$ 起（$2i,2i+1$）；若数组从 $0$ 起则孩子为 $2i+1,2i+2$，两套公式混用会把每一对父子都配对错（与 DS-2017-08 相同的坑）；
4. **忽略"根是最大值 ⟹ 只可能是大顶堆"这一步**：不去先定方向，就会对每个序列重复检查大小两种堆，浪费时间还容易数错。

## 10. 一句话规律

判堆只需一句话：把序列当完全二叉树，逐个非终端结点（$1\sim\lfloor n/2\rfloor$）验它不小于（大于）自己**存在的**孩子，兄弟之间一律不管。
