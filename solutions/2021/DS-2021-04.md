# DS-2021-04

## 1. 原题

实现一个队列需要（ ）个栈。

A. $1$

B. $2$

C. $3$

D. $4$

## 2. 答案

**B**（$2$ 个栈）。

## 3. 题目分析

- 已知：可用的构造部件只有栈（LIFO，只能在一端进出）；要实现的目标结构是队列（FIFO，一端进、另一端出，进出次序一致）；
- 目标：求"能实现队列"所需的**最少**栈的个数（题干"需要"按最少必要量理解，这也是四个数字选项唯一有意义的口径）；
- 关键约束：栈只能访问栈顶。若只有一个栈，"最早入队的元素"永远沉在栈底，被后入者压住，无法在保留其余元素的前提下先取出它；
- 命题意图：考两种结构次序互补的本质——**两次 LIFO 复合即成 FIFO**（逆序的逆序是正序），并要求能写出两栈法（DS02.07 的应用层），而不是只记结论。

## 4. 核心考点

核心考点：
DS02.01 栈和队列的基本概念（LIFO 与 FIFO 的次序差异，及其相互模拟的可能性）

辅助考点：
DS02.07 栈、队列和数组的应用（用栈作部件构造队列，是"受限结构互相实现"的典型应用；配套结论"用两个队列实现一个栈"方向相反）

解释：本题判定的是"需要几个"，答案的来源是 LIFO/FIFO 的次序性质（DS02.01）；而真正写出实现、说清均摊代价属于应用层（DS02.07），考纲把"栈和队列的应用"单列一节，本题的实现部分即落在该节点。

## 5. 解题思路

1. 先证 **$2$ 个够用**：设 `s1` 专司入队、`s2` 专司出队；出队时若 `s2` 非空直接弹 `s2`，若 `s2` 空则把 `s1` 全部倒入 `s2`（一次整体逆序），再弹顶。栈内两次逆序 ⟹ 输出次序回到入队次序；
2. 再证 **$1$ 个不够**：给反例——依次入队 $a,b$ 后要求出队得 $a$。单栈中 $a$ 在栈底，弹出它必须先把 $b$ 弹出（$b$ 就会被错误地先于 $a$ 出队），且弹出 $b$ 之后无法把它"放回"到 $a$ 上面（再压回就变成 $a$ 在 $b$ 之上，次序仍错）。一般地，单栈能输出的只有"当前已入元素"的某一种逆序安排，无法同时保存"待出"与"待逆"两段信息；
3. 既然 $2$ 个是可行且最少的，选 B；C、D 是"能用但非必需"，与"需要"不符。

## 6. 详细解答

**第一步：两栈法的完整定义**

设两个栈 $S_1$（入队栈）、$S_2$（出队栈），均初空。

- `enQueue(x)`：`Push(S1, x)`；
- `deQueue()`：
  - 若 $S_2$ 非空：`Pop(S2)` 并返回；
  - 若 $S_2$ 空而 $S_1$ 非空：反复 `Pop(S1)`→`Push(S2)` 直到 $S_1$ 空，然后 `Pop(S2)`；
  - 两栈皆空：返回下溢（队空）。

**第二步：为什么次序对了（不变量）**

设入队次序为 $x_1,x_2,\dots,x_m$。所有元素先经 $S_1$ 压入，$S_1$ 中自顶向下为 $x_m,\dots,x_1$；一次性倒入 $S_2$ 后，$S_2$ 中自顶向下为 $x_1,x_2,\dots,x_m$ —— 栈顶恰是**最早**入队者，故 `Pop(S2)` 给出 FIFO 次序。

不变量：$S_2$ 中的元素始终是"尚未出队的元素中较早的那一批"，且自顶向下按入队次序排列；$S_1$ 中的元素是"更晚加入"的一批。两者合起来等价于一个队列。只要 $S_2$ 非空就不去动 $S_1$，故不会出现次序交错。

**第三步：模拟核对（入队 a、b、c，再出队两次、入队 d、再全部出队）**

| 操作 | $S_1$（底→顶） | $S_2$（底→顶） | 出队结果 |
|---|---|---|---|
| enQ a | $a$ | 空 | — |
| enQ b | $a,b$ | 空 | — |
| enQ c | $a,b,c$ | 空 | — |
| deQ | 空 | $c,b$ | $a$ ✓ |
| deQ | 空 | $c$ | $b$ ✓ |
| enQ d | $d$ | $c$ | — |
| deQ | $d$ | 空 | $c$ ✓（先取 $S_2$，不受 $S_1$ 干扰） |
| deQ | 空 | 空 | $d$ ✓ |

与队列 `a b c d` 的出队次序完全一致；特别地，第 7 行验证了"新元素在 $S_1$、旧元素在 $S_2$"混合时仍是先进先出。

**第四步：单栈不可能（反证）**

只有一个栈时，可用操作仅 `Push`、`Pop`、读栈顶。取入队序列 $a,b$：此时栈内容自底向上 $a,b$。队列要求下一个出队元素是 $a$，但栈顶是 $b$；为取 $a$ 必须先弹出 $b$ ，而 $b$ 一旦弹出就成为输出序列的一员，输出变成 $b,a$，违反 FIFO。若想"暂存 $b$ 再取回"，唯一的存放处还是同一个栈——把 $b$ 再压回去，栈又变回 $b$ 在 $a$ 之上，问题原样复现。故 $1$ 个栈不可能实现队列，$A$ 排除。

（有一种常见误读："用一个栈加递归来实现队列"，即把栈顶元素逐个弹出、递归到栈底取出最早元素、回溯时再压回去。注意递归的返回地址与暂存元素本身就存放在系统调用栈中，那个隐式的调用栈就是第二个栈——它并未推翻下界，反而是"两个 LIFO 部件"的另一种写法。本题口径下"需要几个栈"指显式可用的栈结构个数，答案仍为 $2$。）

**第五步：代价（附带结论）**

每个元素一生至多被 `Push` 两次（进 $S_1$、进 $S_2$）、`Pop` 两次，故 $n$ 次入队 + $n$ 次出队的总操作数 $4n$，**均摊**每次 $O(1)$；最坏单次 `deQueue` 为 $O(k)$（$k$ 为 $S_1$ 长度），但不会连续发生。空间 $O(n)$（两个栈合计）。

**答案**：B。

## 7. 选项分析

- A（$1$）：错。单个栈只有一个可用端点，"队头"与"队尾"必然重合，见第四步反例；
- B（$2$）：正确。两个栈分别承担队尾（入端）与队头（出端），两次逆序复合为正序，且 $2$ 是不可再减的下界；
- C（$3$）：错。三个栈当然也能实现队列（多出的一个闲置即可），但题干问"需要"几个，即最少必要量，$3$ 不是答案；此类"够用但非最少"的干扰项靠"能否举出只用两个的方案"来排除；
- D（$4$）：错。同 C，$4$ 个栈可实现但非必需；$n\ (n\ge 2)$ 个栈都能实现队列，故这类题的四个数字选项只有"最小可行值"那一项成立，判据就是第 6 节的两条证明（$2$ 可行、$1$ 不可行）。

## 8. 考场标准答案

**需要 $2$ 个栈**（选 B）。理由：

- 充分：$S_1$ 供入队、$S_2$ 供出队，`deQueue` 时若 $S_2$ 空就把 $S_1$ 整体倒入 $S_2$，则 $S_2$ 栈顶即最早入队元素 ⟹ 实现 FIFO；
- 必要：仅 $1$ 个栈时，入队 $a,b$ 后栈顶为 $b$ 而队头应为 $a$，取 $a$ 必先弹出 $b$，次序不可恢复 ⟹ 单栈无法实现。

```c
typedef struct { Stack S1, S2; } Queue;      /* 两栈模拟的队列 */

Status EnQueue(Queue *q, ElemType x) { return Push(&q->S1, x); }

Status DeQueue(Queue *q, ElemType *e)
{
    if (StackEmpty(&q->S2)) {                /* 出队栈空才搬运一次 */
        if (StackEmpty(&q->S1)) return ERROR;/* 两栈皆空 ⟹ 队空 */
        while (!StackEmpty(&q->S1)) {
            Pop(&q->S1, e);
            Push(&q->S2, *e);
        }
    }
    return Pop(&q->S2, e);
}
```

时间：入队 $O(1)$，出队均摊 $O(1)$（最坏单次 $O(k)$）；空间 $O(n)$。

## 9. 易错点

1. **误选 A**：把"栈能存所有元素"当成"能按队首取元素"，忽略了队头沉在栈底这一根本障碍；
2. **搬运时机写错**：`deQueue` 中若"每次都把 $S_1$ 倒入 $S_2$"，会把刚入队的元素插到旧元素前面，破坏 FIFO（第 6 节第三步第 7 行正是检查这一点的用例）；正确写法是**仅当 $S_2$ 空时**才搬运；
3. **队空条件判错**：队空是"$S_1$ 与 $S_2$ **同时**为空"，只判 $S_1$ 空会漏掉"$S_1$ 空但 $S_2$ 还有存货"的可出队状态；
4. **与反向命题混淆**："用栈实现队列"与"用队列实现栈"是两个相反方向。前者必须有 $2$ 个栈（单栈的次序错乱无法自行恢复）；后者课堂上通常也按"$2$ 个队列"作答，但若允许把出队元素重新入队（轮转），单个队列也能以每次入栈 $O(n)$ 的代价模拟栈——本题不考这一变体，只需记住"栈 $\to$ 队列：$2$ 个"这个方向的最小必要量为 $2$。

## 10. 一句话规律

栈与队列互为"次序的逆"，两次逆序即回到正序 ⟹ 一个结构模拟另一个只需 $2$ 个部件；问"需要几个"永远答"最少够用"的那个数。
