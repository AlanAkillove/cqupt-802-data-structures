# DS-2021-06

## 1. 原题

若 $X$ 是二叉中序线索树中一个有左孩子的结点，且 $X$ 不为根，则 $X$ 的前驱为（）。

A. $X$ 的双亲

B. $X$ 的右子树中最左的结点

C. $X$ 的左子树中最右的结点

D. $X$ 的左子树中最右的叶子结点

> 订正说明转录：源文选项 C、D 完全重复（均为"$X$ 的左子树中最右的结点"），系抄录脱漏；据此类题的常规干扰项设计，将 D 恢复为"$X$ 的左子树中最右的叶子结点"（正确答案仍为 C，中序前驱是左子树最右结点，不必是叶子）。

## 2. 答案

**C**（$X$ 的左子树中最右的结点）。

## 3. 题目分析

- 已知：一棵**中序线索二叉树**（按中序遍历次序把空链域改造成指向前驱/后继的线索）；结点 $X$ **有左孩子**（故 $X$ 的 `ltag = 0`，其左链域仍是真实的左孩子指针而不是前驱线索）；$X$ 不是根；
- 目标：确定 $X$ 在**中序序列**中的直接前驱位于何处；
- 关键约束：线索只是"把遍历次序存下来"的指针，前驱/后继的位置由**遍历定义本身**决定，因此本题实质是"中序遍历中，一个有左子树的结点，它前面那一个结点在哪"；
- 命题意图：考中序"左–根–右"的结构化理解——$X$ 之前的所有结点全在其左子树内，且左子树中**最后**被访问的是"最右下的那个结点"；同时用 D 的"叶子"二字设置概念陷阱（最右结点不等于叶子）。

## 4. 核心考点

核心考点：
DS03.02.04 线索二叉树（前驱/后继的定位规则：有左子树时前驱在左子树内，线索只在链域为空时才使用）

辅助考点：
DS03.02.03.02 中序遍历（"左–根–右"是本题全部结论的来源）
DS03.02.02 二叉树的存储结构（二叉链表 + `ltag/rtag` 标志域，是"线索树"这一形态的实现基础）

解释：题干用"线索树"作场景，问的却是"前驱的结构位置"，因此主线是线索化规则（DS03.02.04）；而该规则本身就是中序遍历次序的指针化表达（DS03.02.03.02），两者互为表里；`ltag` 标志与空链域的利用则属存储结构（DS03.02.02）。

## 5. 解题思路

1. 先撇开"线索"二字，直接按中序定义写访问次序：$X$ 的子树被访问为「(X 的左子树的中序序列) → X → (X 的右子树的中序序列)」；
2. 因此 $X$ 的直接前驱 = 左子树中序序列的**最后一个**结点；
3. "左子树中序的最后一个结点"怎么找？在中序里最后被访问的结点是"沿着右链一路走到底"的那个——即左子树的**最右**结点（它必定没有右孩子，但**可以有左孩子**）；
4. 用一个"最右结点带左孩子"的实例排除 D；用"无前驱/有右孩子"等情形排除 A、B；
5. 回到线索树语境复核：$X$ 的 `lchild` 因为 `ltag=0` 存放的是左孩子而非前驱线索，所以求 $X$ 的前驱必须"入左子树、走右链"，与第 3 步一致。

## 6. 详细解答

**第一步：由中序定义定位**

设 $X$ 的左孩子为 $L$。中序遍历 $X$ 的子树：

$$\text{Inorder}(X)=\big[\ \text{Inorder}(L)\ ,\ X\ ,\ \text{Inorder}(R_X)\ \big]$$

故 $X$ 的直接前驱是 $\text{Inorder}(L)$ 的最后一个元素。

**第二步：中序序列的最后一个结点 = 该子树的最右结点**

对任意子树 $T$，中序最后被访问的结点满足"没有右孩子"：若它有右孩子，右子树还会在它之后被访问。反之，从 $T$ 的根出发反复走 `rchild`（走不到为止）得到的结点 $p$ 没有右孩子，其左子树已在 $p$ 之前访问完，$p$ 之后（在本子树内）再无结点 ⟹ $p$ 就是中序最后一个结点。

把 $T=L$ 代入：$X$ 的中序前驱 $=$ 左子树 $L$ 中"沿右链到底"的结点，即 **$X$ 左子树中最右的结点**。

**第三步：反例排除 D（"最右的叶子结点"）**

取如下树（$X$ 有左孩子 $A$，$A$ 无右孩子但有左孩子 $B$）：

```
      X
     /
    A
   /
  B
```

中序序列为 $B,\ A,\ X$，$X$ 的前驱是 $A$。$A$ 是左子树中最右的结点，但 $A$ 有左孩子 $B$，**不是叶子**。因此 D 的"叶子"限定使结论不总成立 ⟹ D 错（C 对）。

**第四步：排除 A、B**

- A（$X$ 的双亲）：仅当 $X$ **无左子树**且 $X$ 是其双亲的**左孩子**（或更一般地，$X$ 无左子树时前驱沿祖先链向上找第一个"其右子树含 $X$ 的祖先"，若 $X$ 为左孩子则恰为双亲）时才成立；本题明说 $X$ 有左孩子，前驱必落在左子树内，与双亲无关。用上第三步的树：若 $X$ 的双亲是 $P$，中序中 $P$ 出现在 $X$ **之后**（$P$ 的左子树含 $X$），$P$ 反而是祖先而非前驱；
- B（右子树中最左的结点）：那是 $X$ 的**中序后继**（当 $X$ 有右孩子时），方向恰好相反。用上树补一个右孩子 $C$（$C$ 有左孩子 $D$）：中序 $B,A,X,D,C$，$X$ 之后第一个是 $D$——右子树最左结点，是后继不是前驱；
- D（最右的**叶子**结点）：见第三步反例；
- C：正确。

**第五步：在线索树里"怎么取到"这个前驱（与线索化规则对照）**

- 若 $X$ 无左孩子（`ltag=1`）：`X->lthread` 直接指向其前驱，$O(1)$；
- 若 $X$ 有左孩子（`ltag=0`，即本题情形）：**不能**用 `X->lchild` 当线索（它是真实左孩子），必须执行“进入左子树、沿 `rchild` 走到底”的查找；而线索化时那个走到底的结点因无右孩子，其 `rtag=1`、`rthread` 恰好指向 $X$ ——这也从反面印证了它是 $X$ 的前驱。

**答案**：C。

## 7. 选项分析

- A（$X$ 的双亲）：错。这是"$X$ 无左子树且为双亲的左孩子"时的前驱形态；题设给出"有左孩子"，前驱必在其左子树内。题干的"$X$ 不为根"在"有左孩子"前提下对结论没有影响（有左孩子时无论是否根，前驱都是左子树最右结点），它是为干扰"根无前驱/要往上找"这一联想而设；
- B（$X$ 的右子树中最左的结点）：错。这是**后继**规则，把前驱与后继的方向记反就会选它；
- C（$X$ 的左子树中最右的结点）：正确。"左子树中序的最后一个是 $X$ 前面那一个"，而中序最后访问者必无右孩子，即沿右链到底的结点；
- D（$X$ 的左子树中最右的**叶子**结点）：错。最右结点只保证"无右孩子"，可能有左孩子（第三步反例中的 $A$）；只有当左子树是一条纯右链时，最右结点才恰是叶子，故 D 只是特例。

## 8. 考场标准答案

中序为"左–根–右"，$X$ 有左孩子 ⟹ $X$ 之前的结点全部落在其左子树内，其中最后被访问者即 $X$ 的直接前驱；中序最后访问的结点必无右孩子，故为左子树中沿右链走到的**最右结点**，该结点不必是叶子（可带左孩子）。选 **C**。

求前驱的教材风格片段：

```c
BTNode* InPre(BTNode *x)          /* 求中序前驱：x 有左孩子 */
{
    BTNode *p = x->lchild;
    while (p->rtag == 0)          /* 沿右链向下，rtag==0 表示右链域仍是孩子指针 */
        p = p->rchild;
    return p;                     /* 左子树中最右结点即前驱 */
}
```

时间 $O(h)$（$h$ 为左子树右链长度，最坏 $O(n)$），空间 $O(1)$。

## 9. 易错点

1. **被"线索树"三字带偏**：以为答案要在线索里直接读出来。$X$ 有左孩子时 `lchild` 是真实指针，前驱必须靠结构规则推，线索只在链域为空时才是捷径；
2. **前驱/后继方向搞反**：口诀应为——前驱："有左走左、左中走右到底"；后继："有右走右、右中走左到底"。本题 B 项正是把两条口诀的后继那半塞进前驱的问法；
3. **默认"最右结点=叶子"**：忽略"最右"只约束右孩子，不约束左孩子（第三步反例是这类题的标准否证手段，务必记住 $B,A,X$ 这一形）；
4. **忽视"叶子"与"终端结点"在带标志域语境下的差别**：线索树中判"叶子"要看两个链域是否都为 0（都是孩子），仅 `rtag=1` 只说明右边空。

## 10. 一句话规律

中序前驱/后继只看遍历定义：前驱 = 左子树最右结点，后继 = 右子树最左结点；没有左（右）子树时才轮到祖先或线索出场。
