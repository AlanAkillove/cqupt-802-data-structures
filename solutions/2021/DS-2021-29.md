# DS-2021-29

## 1. 原题

已知一棵二叉树的先序序列：$ABDGJEHCFIKL$，中序序列：$DJGBEHACKILF$。

（1）画出此二叉树的形态。

（2）画出此二叉树的后序线索树。

（3）采用孩子兄弟表示法来存储该二叉树，请画出此二叉树的存储结构。

（4）画出与此二叉树对应的森林。

## 2. 答案

**（1）二叉树形态**（$12$ 个结点）：

```
             A
          /     \
        B         C
       / \         \
      D   E         F
       \   \       /
        G   H     I
       /       / \
      J       K   L
```

各结点分支：$A\!:\!(B,C)$、$B\!:\!(D,E)$、$C\!:\!(\varnothing,F)$、$D\!:\!(\varnothing,G)$、$E\!:\!(\varnothing,H)$、$F\!:\!(I,\varnothing)$、$G\!:\!(J,\varnothing)$、$H$ 叶、$I\!:\!(K,L)$、$J,K,L$ 叶。

**（2）后序序列** $J\,G\,D\,H\,E\,B\,K\,L\,I\,F\,C\,A$；$13$ 个空链按此序列置线索（见第 6 节表 29-1）。

**（3）孩子兄弟表示法**：左指针 $=$ 第一个孩子、右指针 $=$ 下一兄弟，链域内容与（1）的二叉链表完全相同，只是指针语义改名（见第 6 节表 29-2）。

**（4）对应的森林**：共 $3$ 棵树——

```
  T1:     A           T2:  C          T3:   F
        / | \                        / \
       B  E  H                      I    L
      / \                          /
     D   G                        K
         |
         J
```

## 3. 题目分析

- 已知：先序 $ABDGJEHCFIKL$、中序 $DJGBEHACKILF$（同一棵二叉树的两种遍历，结点集 $\{A,\dots,L\}$，$n=12$）；
- 目标：① 还原树形；② 后序线索化；③ 以孩子兄弟方式表达同一结构；④ 还原该二叉树所"对应"的森林；
- 关键约束：
  1. **先序 + 中序可唯一确定二叉树**（先序定根、中序划左右），这是（1）的唯一解依据；先序与后序、中序与后序的组合都不能唯一确定，故本题给的组合是"有解且唯一"的那一组；
  2. 线索化必须按**后序**这一指定次序：空左链指后序前驱、空右链指后序后继；结点若有真实孩子则不放线索（这是与"全部改成线索"的常见误解的分界）；
  3. （3）与（4）是**同一份链结构的两种读法**：二叉树的左/右指针读作"孩子/兄弟"就是一棵树/森林，读作"左/右子树"就是（1）的树形——所以（3）不需要重新画一套指针，只需换标注；
  4. （4）中"根链"的判定：二叉树**根的右链**（$A\to C\to F$）上的每个结点都是森林中一棵树的根，这是"二叉树 ⟶ 森林"逆向转换的机械规则；
- 命题意图：一题串起 DS03 的四条主线——**由遍历序列定树 → 线索化 → 存储结构 → 树/森林与二叉树的对应**，考查学生是否清楚"同一张二叉链表可以有两种语义解释"，而不是把四问当成四道孤立的题。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（由先序/中序序列唯一确定二叉树：先序首元素为根，中序中根的位置把序列切成左右子树，递归进行）

辅助考点：
DS03.02.04 线索二叉树（后序线索化：$ltag/rtag$ 标记 + 空链存前驱/后继，前驱后继取自**后序**序列而非中序）
DS03.03.01 树的存储结构（孩子兄弟表示法的指针语义：左孩子—右兄弟）
DS03.03.02 森林与二叉树的转换（二叉树 ⟶ 森林：根的右链上各结点为各棵树的根；结点的左子树为其孩子链）

解释：（1）是"定树"，属 DS03.02.03 的核心用途；（2）是线索化，虽与遍历共用次序概念，但构造对象（线索树）独立成点 DS03.02.04；（3）（4）分别落在树的存储结构与树/二叉树转换上，因题目要求"画出存储结构"与"画出森林"，属构造型考查。

## 5. 解题思路

1. **（1）定根切左右**：先序首 $A$ 为根 → 在中序中找到 $A$，其左 $DJGBEH$ 为左子树结点、右 $CKILF$ 为右子树结点 → 回先序取对应长度片段 $BDGJEH$ / $CFIKL$，对两半递归；
2. **递归到底的判据**：子树结点集只有一个字母时即为叶；出现"中序中根在最左"说明该子树**无左子树**（本例 $C$、$D$、$E$、$G$、$F$ 都命中这一情形，是本题树形偏"瘦"的原因）；
3. **（2）先写后序再挂线索**：由树形写出后序 $JGDHEBKLIFCA$；对每个结点检查左右孩子是否存在，**缺哪一侧就把那一侧指针指向后序中的前驱（缺左）或后继（缺右）**；空链总数应为 $n+1=13$，可作计数自检；
4. **（3）只改语义不改连线**：把（1）的每条左指针标为"首孩子"、每条右指针标为"下一兄弟"，列成链表域表即可；
5. **（4）沿右链拆树**：$A$ 的右孩子 $C$ 是 $A$ 的"兄弟" ⟹ $C$ 是第二棵树的根；$C$ 的右孩子 $F$ ⟹ 第三棵树的根；$F$ 右链为空 ⟹ 共 $3$ 棵树。每棵树内部：结点的左孩子及其右链 = 该结点的全部孩子；
6. **反向验证**：把（4）的森林重新转换回二叉树，应与（1）逐指针相同；或用"树的先根序列 = 对应二叉树的先序、树的后根序列 = 对应二叉树的中序"核对。

## 6. 详细解答

### （1）由先序与中序重建二叉树

**第 1 层**：先序 $A\,BDGJEH\,CFIKL$，首元素 $A$ 为根。中序 $DJGBEH\;A\;CKILF$ ⟹ 左子树含 $6$ 个结点 $\{D,J,G,B,E,H\}$，右子树含 $5$ 个结点 $\{C,K,I,L,F\}$。

**第 2 层（左子树）**：先序片段 $B\,DGJEH$ ⟹ 根 $B$。中序 $DJG\;B\;EH$ ⟹ $B$ 的左子树 $\{D,J,G\}$、右子树 $\{E,H\}$。

**第 3 层（$B$ 的左）**：先序 $D\,GJ$ ⟹ 根 $D$。中序 $DJG\;D$——$D$ 在中序中位于 $\{D,J,G\}$ 的最左，其左侧无元素 ⟹ **$D$ 无左孩子**，$\{J,G\}$ 全在右子树。先序 $G\,J$ ⟹ $G$ 为 $D$ 的右孩子；中序 $J\;G$ ⟹ $J$ 在 $G$ 左侧 ⟹ $J$ 是 $G$ 的左孩子。

**第 3 层（$B$ 的右）**：先序 $E\,H$ ⟹ 根 $E$。中序 $E\;H$ ⟹ $E$ 无左孩子、$H$ 是 $E$ 的右孩子。

**第 2 层（右子树）**：先序 $C\,FIKL$ ⟹ 根 $C$。中序 $C\;KILF$ ⟹ $C$ **无左孩子**，$\{K,I,L,F\}$ 全在右子树。先序 $F\,IKL$ ⟹ $F$ 为 $C$ 的右孩子。中序 $KIL\;F$ ⟹ $F$ 无右孩子，$\{K,I,L\}$ 在 $F$ 的左子树。先序 $I\,KL$ ⟹ $I$ 为 $F$ 的左孩子；中序 $K\;I\;L$ ⟹ $K$ 是 $I$ 的左孩子、$L$ 是 $I$ 的右孩子。

**结果**（与第 2 节图一致）：

| 结点 | 左孩子 | 右孩子 | | 结点 | 左孩子 | 右孩子 |
|---|---|---|---|---|---|---|
| $A$ | $B$ | $C$ | | $G$ | $J$ | $\varnothing$ |
| $B$ | $D$ | $E$ | | $H$ | $\varnothing$ | $\varnothing$ |
| $C$ | $\varnothing$ | $F$ | | $I$ | $K$ | $L$ |
| $D$ | $\varnothing$ | $G$ | | $J$ | $\varnothing$ | $\varnothing$ |
| $E$ | $\varnothing$ | $H$ | | $K$ | $\varnothing$ | $\varnothing$ |
| $F$ | $I$ | $\varnothing$ | | $L$ | $\varnothing$ | $\varnothing$ |

**回代核对**：按此树形重新遍历——
先序 $A\!\to\!B\!\to\!D\!\to\!G\!\to\!J\!\to\!E\!\to\!H\!\to\!C\!\to\!F\!\to\!I\!\to\!K\!\to\!L$ $=ABDGJEHCFIKL$ ✓
中序 $D\!\leftarrow\!J\!\leftarrow\!G\!\leftarrow\!D\,B\,E\!\leftarrow\!H\,A\,C\,K\!\leftarrow\!I\!\leftarrow\!L\,F$ $=DJGBEHACKILF$ ✓
两序列均与题面完全一致，故树形正确且唯一。

**结点计数自检**：$n_0=4$（$H,J,K,L$）、$n_1=5$（$C,D,E,F,G$）、$n_2=3$（$A,B,I$），满足 $n_0=n_2+1$ ✓，总数 $4+5+3=12$ ✓。

### （2）后序线索树

先写出后序序列（左→右→根递归）：

$$J\;\;G\;\;D\;\;H\;\;E\;\;B\;\;K\;\;L\;\;I\;\;F\;\;C\;\;A$$

（可核对：后序末元素为根 $A$ ✓；$G$ 在 $D$ 前、$J$ 在 $G$ 前，符合"以 $D$ 为根的子树 $JGD$"。）

线索规则：**左孩子为空 ⟹ 左链指后序前驱；右孩子为空 ⟹ 右链指后序后继**；有真实孩子的一侧保持原样。

表 29-1 后序线索树（"实"表示该侧为真实孩子，"线"表示线索）

| 结点 | 左链 | 右链 | 说明 |
|---|---|---|---|
| $J$ | 线 $\to\varnothing$ | 线 $\to G$ | 后序首结点，无前驱 |
| $G$ | 实 $\to J$ | 线 $\to D$ | $G$ 的后继是 $D$ |
| $D$ | 线 $\to G$ | 实 $\to G$ | 左空右不空：左链指前驱 $G$ |
| $H$ | 线 $\to D$ | 线 $\to E$ | 叶，两侧皆线索 |
| $E$ | 线 $\to H$ | 实 $\to H$ | 左空右不空 |
| $B$ | 实 $\to D$ | 实 $\to E$ | 无空链，不挂线索 |
| $K$ | 线 $\to B$ | 线 $\to L$ | 叶 |
| $L$ | 线 $\to K$ | 线 $\to I$ | 叶 |
| $I$ | 实 $\to K$ | 实 $\to L$ | 无空链 |
| $F$ | 实 $\to I$ | 线 $\to C$ | 右空：后继为 $C$ |
| $C$ | 线 $\to F$ | 实 $\to F$ | 左空：前驱为 $F$ |
| $A$ | 实 $\to B$ | 实 $\to C$ | 无空链，后序末结点亦无后继 |

**计数自检**：线索数 $=$ 空链数 $=n+1=13$。表中线索条数 $=2(J)+1(G)+1(D)+2(H)+1(E)+2(K)+2(L)+1(F)+1(C)=13$ ✓。

**图示（按后序串逐个结点标注空链去向，`┄>` 为线索）**：

```
后序：J ┄> G ┄> D ┄> H ┄> E ┄> B ┄> K ┄> L ┄> I ┄> F ┄> C ┄> A

J: 左┄>NULL   右┄>G        H: 左┄>D    右┄>E         K: 左┄>B    右┄>L
G: 左→J(实)  右┄>D        E: 左┄>H    右→H(实)      L: 左┄>K    右┄>I
D: 左┄>G     右→G(实)     B: 左→D(实) 右→E(实)      F: 左→I(实) 右┄>C
                                                    I: 左→K(实) 右→L(实)
                                                    C: 左┄>F    右→F(实)
                                                    A: 左→B(实) 右→C(实)
（→ 为真实孩子指针，┄> 为线索；共 13 条线索 = 空链数 n+1）
```

（图中 $B,I,A$ 三结点两侧均为真实孩子，无线索；$J$ 的左线索为空指针 $\varnothing$。）

### （3）孩子兄弟表示法

孩子兄弟表示法结点形式（教材风格）：

```c
typedef struct CSNode {
    ElemType data;
    struct CSNode *firstchild, *nextsibling;   /* 左：第一个孩子  右：下一兄弟 */
} CSNode, *CSTree;
```

**关键认识**：二叉链表与孩子兄弟链表在**结点数、指针值上完全相同**，只是把 `lchild/rchild` 读作 `firstchild/nextsibling`。因此本题（3）的答案就是把（1）的表重抄一遍并改列名：

表 29-2 存储结构（$12$ 个结点，$data\ midx\ firstchild\ nextsibling$）

| 结点 | $firstchild$（左） | $nextsibling$（右） |
|---|---|---|
| $A$ | $B$ | $C$ |
| $B$ | $D$ | $E$ |
| $C$ | $\varnothing$ | $F$ |
| $D$ | $\varnothing$ | $G$ |
| $E$ | $\varnothing$ | $H$ |
| $F$ | $I$ | $\varnothing$ |
| $G$ | $J$ | $\varnothing$ |
| $H$ | $\varnothing$ | $\varnothing$ |
| $I$ | $K$ | $L$ |
| $J$ | $\varnothing$ | $\varnothing$ |
| $K$ | $\varnothing$ | $\varnothing$ |
| $L$ | $\varnothing$ | $\varnothing$ |

指针域示意（每个结点写成 $(data\mid firstchild\mid nextsibling)$，$\varnothing$ 表示空指针）：

```
A: (A | →B | →C)      F: (F | →I | ∅ )      K: (K | ∅  | ∅ )
B: (B | →D | →E)      G: (G | →J | ∅ )      L: (L | ∅  | ∅ )
C: (C | ∅  | →F)      H: (H | ∅  | ∅ )
D: (D | ∅  | →G)      I: (I | →K | →L)
E: (E | ∅  | →H)      J: (J | ∅  | ∅ )
```

把同一组指针按“兄弟链”展开看更直观（$\to$ 为 $nextsibling$，$\downarrow$ 为 $firstchild$）：

```
森林的三棵树根链：   A → C → F
A 的孩子链：    ↓ B → E → H
B 的孩子链：    ↓ D → G
G 的孩子链：    ↓ J
F 的孩子链：    ↓ I → L
I 的孩子链：    ↓ K
（C、D、E、H、J、K、L 的孩子链为空，即它们是叶）
```

### （4）对应的森林

按"结点的右链 $=$ 兄弟链、左孩子 $=$ 首孩子"读表 29-2：

- **根的右链** $A\to C\to F\to\varnothing$ ⟹ 森林有 $3$ 棵树，根依次 $A$、$C$、$F$；
- **$A$ 的孩子**：$A$ 的左孩子 $B$，沿 $B$ 的右链 $B\to E\to H\to\varnothing$ ⟹ $A$ 有三棵子树，孩子为 $B,E,H$；
- **$B$ 的孩子**：$B$ 的左孩子 $D$，沿右链 $D\to G\to\varnothing$ ⟹ 孩子 $D,G$；
- **$D$ 的孩子**：$D$ 的左孩子为空 ⟹ $D$ 为叶；
- **$G$ 的孩子**：$G$ 的左孩子 $J$，$J$ 无右兄弟 ⟹ 孩子 $J$；$J$ 无左孩子 ⟹ 叶；
- **$E$、$H$ 的孩子**：左孩子均为空 ⟹ 都是叶；
- **$C$ 的孩子**：左孩子为空 ⟹ 第二棵树只有根 $C$；
- **$F$ 的孩子**：左孩子 $I$，沿 $I$ 的右链 $I\to L\to\varnothing$ ⟹ 孩子 $I,L$；
- **$I$ 的孩子**：左孩子 $K$，$K$ 无右兄弟 ⟹ 孩子 $K$；**$L$ 无孩子**；

$$T_1=A\bigl(B(D,\,G(J)),\;E,\;H\bigr),\qquad T_2=(C),\qquad T_3=F\bigl(I(K),\;L\bigr)$$

```
  T1:        A            T2:  C            T3:      F
           / | \                                / \
         B   E   H                            I    L
        / \                                  /
       D   G                                K
           |
           J
```

**反向验证（森林 ⟶ 二叉树）**：把 $T_1,T_2,T_3$ 按"左孩子—右兄弟"重新连成二叉树：$A$ 的左为 $B$、右为 $C$（$T_2$ 的根作 $A$ 的兄弟）；$C$ 的右为 $F$（$T_3$ 的根）；$B$ 的左为 $D$、右为 $E$，$E$ 的右为 $H$；$D$ 的右为 $G$，$G$ 的左为 $J$；$F$ 的左为 $I$、$I$ 的右为 $L$、$I$ 的左为 $K$——与（1）的表逐格相同 ✓。

**序列旁证**：森林的**先根**序列 $A,B,D,G,J,E,H,C,F,I,K,L$ 等于二叉树的先序 ✓；森林的**后根**序列 $D,J,G,B,H,E,A,C,K,L,I,F$ 等于二叉树的中序 ✓（这正是"树/森林的先根、后根 $\leftrightarrow$ 二叉树的先序、中序"定理的实例）。

## 8. 考场标准答案

**（1）** 树形见第 2 节图；核心是 $A$ 为根、$B,C$ 为左右子树之根，$C,D,E,F,G$ 各缺一个孩子（$C,D,E$ 缺左、$F,G$ 缺右）。

**（2）** 后序序列 $J\,G\,D\,H\,E\,B\,K\,L\,I\,F\,C\,A$；按表 29-1 挂 $13$ 条线索（$J$ 左、$A$ 无右线索，故 $J$ 左链为 $\varnothing$）。

**（3）** 表 29-2：$firstchild/nextsibling$ 两列取值与二叉链表的 $lchild/rchild$ 完全相同。

**（4）** 森林含 $3$ 棵树：$T_1=A(B(D,G(J)),E,H)$、$T_2=C$、$T_3=F(I(K),L)$。

书写顺序建议：先做（1）并在图上就地标出每个结点的左右孩子，（2）（3）（4）全部由（1）的图直接导出，不必重画；（2）务必先抄出后序序列再挂线索，可避免"前驱后继数错"。

## 9. 易错点

1. **（1）中把"中序里根在最左"当成"根在最左即无右子树"**：$C$、$D$、$E$ 三结点在中序中位于其子树片段的最左端，含义是**无左孩子、右子树非空**，方向极易写反（写反后 $F$ 会挂到 $C$ 的左边，后序线索与森林全部跟着错）；
2. **（2）用中序线索的套路套后序**：后序的前驱/后继**不是**"最右叶/双亲"那类简单关系，必须先把后序序列完整写出，再按"前一个/后一个"取值；例如 $D$ 的后序前驱是 $G$（不是 $J$），$F$ 的后继是 $C$（不是 $I$）；
3. **（2）给有孩子的结点也挂线索**：线索只占用**空链**，$B,I,A$ 两侧都有真实孩子，不得改动；$D$ 只有左链空，右链是真实孩子 $G$，本表中"左线索 $\to G$"与"右孩子 $\to G$"恰好同值，属巧合，不要误以为两列合并；
4. **（2）漏算 $n+1$ 条线索**：$12$ 个结点的二叉树空链恒为 $13$，画完数一遍即可自查；
5. **（3）另起炉灶重画一套指针**：孩子兄弟表示法与二叉链表同构，改动连线反而错；只需换列名；
6. **（4）把森林画成 1 棵树**：常见错法是忽略"根的右链上每个结点都是独立的树根"，把 $C,F$ 当成 $A$ 的孩子。正确判据是 $A$ 的右孩子 $C$ 表示"$C$ 是 $A$ 的兄弟"，而 $A$ 是森林第一棵树的根，其兄弟只能是**下一棵树的根**；
7. **（4）孩子顺序颠倒**：沿"首孩子 $\to$ 右兄弟"链读出的次序即树中孩子从左到右的次序，$A$ 的孩子是 $B,E,H$（不可写成 $H,E,B$）。

## 10. 一句话规律

"先序 + 中序"定树是**唯一**的，其余组合不唯一；定树之后，后序线索只需"抄出后序串、空链指前后邻"，而孩子兄弟表示法与二叉链表**同构**——森林不过是把根的右链读成"兄弟树"，因此四问共用一张图，画错只会错在第一问。
