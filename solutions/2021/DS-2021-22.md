# DS-2021-22

## 1. 原题

顺序查找 $3$ 个元素的顺序表，若查找第 $1$ 、第 $2$ 和第 $3$ 个元素的查找概率分布是 $\frac{1}{2}$ 、 $\frac{1}{3}$ 和 $\frac{1}{6}$ ，则查找任一元素的平均查找长度为____________________。

> 订正说明转录：源文作“则则查找”，衍字“则”，据题意修正。

## 2. 答案

**$\dfrac{5}{3}\approx 1.67$**。

（口径：顺序查找自表头向后逐个比较，查找位于第 $i$ 个位置的元素需比较 $i$ 次，即 $C_i=i$；题面按"第 $1$、第 $2$、第 $3$ 个元素"的顺序给出 $P_1=\frac12,P_2=\frac13,P_3=\frac16$。）

## 3. 题目分析

- 已知：长度 $n=3$ 的顺序表；查找成功时各元素的概率 $P_1=\frac12,\;P_2=\frac13,\;P_3=\frac16$（**不等概率**，且已按降序排在表头方向）；
- 目标：查找**成功**的平均查找长度 $ASL=\sum_{i=1}^{n}P_iC_i$（"查找任一元素"即对全部元素取期望，未涉及查找失败）；
- 关键约束：
  1. 概率归一：$\frac12+\frac13+\frac16=\frac{3+2+1}{6}=1$ ✓（说明这确实是一个分布，无需再除以总和）；
  2. 顺序查找的比较次数由**位置**决定：$C_i=i$（第 $1$ 个元素一比就中，第 $3$ 个要比 $3$ 次），这与元素的关键字大小无关，只与它在表中的下标有关；
  3. 求和：$ASL=1\cdot\frac12+2\cdot\frac13+3\cdot\frac16$；
- 表面问题：套公式算一个数；背后的知识点：**ASL 是"比较次数"关于"被查中概率"的期望**，以及"不等概率时把概率大的元素放前面能降低 ASL"这一顺序查找的优化思想；
- 命题意图：用最小的 $n=3$ 检查两件事——① 是否知道 $C_i=i$（而不是错误地代 $\frac12,\frac13,\frac16$ 去乘别的量）；② 是否会算分数期望并与等概率结论 $\frac{n+1}{2}=2$ 作对比。

## 4. 核心考点

核心考点：
DS05.02 顺序查找法——不等概率情形下查找成功的 $ASL=\sum_{i=1}^{n}P_iC_i$，其中 $C_i=i$；"按查找概率递减排序存放元素可使 ASL 最小"

辅助考点：
DS05.01 查找的基本概念——平均查找长度是各元素"查找概率 × 查找该元素所需比较次数"的加权和，且须先确认概率之和为 $1$、区分"成功"与"失败"两种口径

解释：题目要求算出具体的 ASL 数值，计算本身依赖顺序查找"第 $i$ 个元素比较 $i$ 次"这一 DS05.02 的特定结论，故主标签 DS05.02；ASL 的定义与"成功/失败"口径辨析属 DS05.01，列为辅助。

## 5. 解题思路

1. 先验算概率归一性，确认题目给的是**完整分布**（否则要除以一个总和，是另一类题）；
2. 写出比较次数序列：$C_1=1,C_2=2,C_3=3$；
3. 按定义加权求和，通分到分母 $6$：$\frac{3}{6}+\frac{4}{6}+\frac{3}{6}=\frac{10}{6}=\frac53$；
4. 复核：与等概率基准 $\frac{n+1}{2}=2$ 比大小——本题概率降序、大概率落在比较次数少的位置，故 ASL **应小于** $2$，$\frac53\approx1.67<2$ ✓ 方向正确（若算出 $\frac73$ 说明把概率与位置配错了）；
5. 再复核：枚举 $\{P_1,P_2,P_3\}$ 与 $\{C_1,C_2,C_3\}$ 配对的全部 $6$ 种方案（第 6 节表），确认题面"第 $1$、第 $2$、第 $3$ 个"的写法对应其中最小值 $\frac53$。

## 6. 详细解答

**（1）按定义直接计算（主路线）**

顺序查找（自表头向后扫描）中，查找第 $i$ 个元素需比较 $i$ 次，故 $C_i=i\ (i=1,2,3)$。

$$ASL=\sum_{i=1}^{3}P_iC_i=1\times\frac12+2\times\frac13+3\times\frac16=\frac12+\frac23+\frac12$$

通分（公分母 $6$）：

$$ASL=\frac{3}{6}+\frac{4}{6}+\frac{3}{6}=\frac{10}{6}=\boxed{\dfrac{5}{3}}\approx1.67$$

| 元素 | 表中位置 | 比较次数 $C_i$ | 查找概率 $P_i$ | 贡献 $P_iC_i$ |
|---|---|---|---|---|
| 第 $1$ 个 | $1$ | $1$ | $\frac12$ | $\frac12=\frac{3}{6}$ |
| 第 $2$ 个 | $2$ | $2$ | $\frac13$ | $\frac23=\frac{4}{6}$ |
| 第 $3$ 个 | $3$ | $3$ | $\frac16$ | $\frac12=\frac{3}{6}$ |
| 合计 | — | — | $1$ ✓ | $\frac{10}{6}=\frac53$ |

**（2）把期望读作整数计数（免通分复核）**

设按题给分布共进行 $6$ 次查找（$6$ 是三个概率分母的最小公倍数），则其中 $3$ 次查第 $1$ 个元素（每次比 $1$ 次）、$2$ 次查第 $2$ 个元素（每次比 $2$ 次）、$1$ 次查第 $3$ 个元素（比 $3$ 次）。总比较次数
$$3\times1+2\times2+1\times3=3+4+3=10$$
平均每次查找的比较次数 $=\dfrac{10}{6}=\dfrac{5}{3}$ ✓
（这一步把分数运算完全转成整数运算，可避开主路线中可能出现的通分错误；两条路线结果一致。）

**（3）与等概率基准对照（判方向的复核）**

等概率时 $ASL=\sum_{i=1}^{n}\frac1n\cdot i=\frac{n+1}{2}=\frac{3+1}{2}=2$（见 DS-2018-16、DS-2016-21）。
本题把**最大**概率 $\frac12$ 放在**比较次数最少**的位置 $1$，把**最小**概率 $\frac16$ 放在位置 $3$，符合"概率降序排列使 ASL 最小"的 rearrangement 不等式，因此结果必须**严格小于** $2$：$\frac53<2$ ✓；而 $\frac73>2$ 是把概率配反（升序排列）得到的最大值，可作为排除项。

**（4）穷尽性检查（六种配对全列）**

把三个概率 $\{\frac12,\frac13,\frac16\}$ 分配到比较次数 $\{1,2,3\}$ 的三个槽位，共 $3!=6$ 种：

| 位置 1（$C=1$） | 位置 2（$C=2$） | 位置 3（$C=3$） | $ASL$ |
|---|---|---|---|
| $\frac12$ | $\frac13$ | $\frac16$ | $\frac12+\frac23+\frac12=\mathbf{\frac53}$ ← 题面顺序 |
| $\frac12$ | $\frac16$ | $\frac13$ | $\frac12+\frac13+1=\frac{11}{6}$ |
| $\frac13$ | $\frac12$ | $\frac16$ | $\frac13+1+\frac12=\frac{11}{6}$ |
| $\frac13$ | $\frac16$ | $\frac12$ | $\frac13+\frac13+\frac32=\frac{13}{6}$ |
| $\frac16$ | $\frac12$ | $\frac13$ | $\frac16+1+1=\frac{13}{6}$ |
| $\frac16$ | $\frac13$ | $\frac12$ | $\frac16+\frac23+\frac32=\frac73$ |

题面明确"查找第 $1$、第 $2$ 和第 $3$ 个元素的概率**依次**是 $\frac12,\frac13,\frac16$"，对应第一行，$ASL=\frac53$（同时是六种中的最小值，与（3）的判定吻合）。

**（5）参照算法（说明 $C_i=i$ 从何而来）**

```c
typedef struct {
    KeyType   key;       /* 关键字域 */
    OtherInfo others;    /* 其余数据域 */
} ElemType;

typedef struct {
    ElemType *elem;      /* elem[1..length] 存数据元素, elem[length+1] 用作哨兵 */
    int       length;    /* 当前表长 */
} SqList;

int Search_Sq(SqList L, KeyType key)
/* 自表头向后顺序查找关键字等于 key 的元素 */
/* 查找成功返回其位序(1..L.length), 失败返回 0            */
{
    int i = 1;
    L.elem[L.length + 1].key = key;         /* 哨兵: 循环内不必每轮判越界 */
    while (L.elem[i].key != key)            /* 第 i 轮恰好比较到第 i 个元素 */
        ++i;
    return (i > L.length) ? 0 : i;
}
```

由该循环可见：命中表中第 $i$ 个元素时，`while` 恰好执行了 $i$ 次比较，故 $C_i=i$（哨兵只在查找不到时才被碰到，不影响成功情形的比较次数，见第 9 节第 3 条）。

**答案**：$\dfrac{5}{3}$（约 $1.67$）。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

顺序查找中查找第 $i$ 个元素需比较 $i$ 次，故
$$ASL=\sum_{i=1}^{3}P_iC_i=1\times\frac12+2\times\frac13+3\times\frac16=\frac{3+4+3}{6}=\frac{10}{6}=\boxed{\dfrac{5}{3}}\ (\approx1.67)$$

填：$\dfrac{5}{3}$。

## 9. 易错点

1. **把概率与比较次数配错位置**：常见错答 $\frac73$（来自 $\frac16\times1+\frac13\times2+\frac12\times3$，即把降序概率当成升序）。自查方法：概率大的元素排在表头时应使 ASL **低于**等概率值 $2$，算出大于 $2$ 就说明配反了；
2. **忘记概率要归一**：本题 $\sum P_i=1$ 恰好成立；若题目给的是"未归一权重"（如 $2:1:1$），必须除以总和，否则结果偏大。养成先写 $\frac12+\frac13+\frac16=1$ 这一步的习惯；
3. **混入"查找失败"的比较次数**：带哨兵的顺序查找失败需比较 $n+1=4$ 次（哨兵处终止），但题面问的是"查找任一**元素**"，即成功情形的期望，不涉及失败口径（本库 DS-2016-21 已把两种口径分开算过）；
4. **误代二分/折半的公式**：顺序表若**有序**且用折半查找，$n=3$ 的判定树给出 $ASL_{succ}=\frac{1\times1+2\times2}{3}=\frac53$（等概率下也是 $\frac53$，巧合相同），但本题明说"顺序查找"，必须用 $C_i=i$ 而不是判定树层数；两个 $\frac53$ 来源不同，不能混为一谈（折半见 DS-2021-14）；
5. **以为"等概率结论 $\frac{n+1}{2}$ 可以直接套"**：套上会得到 $2$，是错题——题干特意给了三个不相等的概率；
6. **写成小数丢分**：$\frac53$ 是循环小数 $1.666\cdots$，填空应写分数 $\frac53$（或注明 $\approx1.67$），写 $1.7$ 会因四舍五入被判不精确。

## 10. 一句话规律

不等概率的顺序查找 ASL 只有一句：**$ASL=\sum P_i\cdot i$（第 $i$ 个位置比较 $i$ 次）**；算完拿等概率基准 $\frac{n+1}{2}$ 比大小即可自查——概率"前大后小"则结果必小于基准，"前小后大"则必大于基准。
