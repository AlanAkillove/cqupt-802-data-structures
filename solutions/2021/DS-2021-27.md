# DS-2021-27

## 1. 原题

阅读下面代码：

假设当 $N=3500$，上述代码运行 $1$ 秒。那么，当 $N=35000$ 时，该代码的运行时间最接近下面哪个时间？请给出简单的分析过程。

A. $10\ seconds$

B. $20\ seconds$

C. $1\ minute$

D. $2\ minutes$

E. $1\ hour$

F. $2\ hours$

```c
int count=0;
int N=a.length;
sort(a);
for(int i=0;i<N;i++) 
{
    for(int j=i+1;j<N;j++) 
    {
        if(BinarySearch(a,a[i]+a[j])) 
            count++;
    }
}
```

## 2. 答案

**D（$2\ minutes$）**。

代码的时间代价为 $O(N^2\log_2 N)$，$N$ 扩大 $10$ 倍时运行时间扩大 $10^2\times\dfrac{\log_2 35000}{\log_2 3500}=100\times1.282\approx128$ 倍，即约 $128$ 秒，与 $2$ 分钟（$120$ 秒）最接近。

## 3. 题目分析

- 已知：一段程序（先排序，再对每一对下标 $i<j$ 作一次折半查找）；$N=3500$ 时运行 $1$ 秒；
- 目标：外推 $N=35000$（扩大 $10$ 倍）时的运行时间，并从 $6$ 个候选中挑最接近者；
- 关键约束：
  1. 必须**先读出程序的增长函数**，不能凭"规模 10 倍 ⟹ 时间 10 倍"的直觉；
  2. 双重循环的执行次数是 $\binom{N}{2}=\frac{N(N-1)}{2}$（内层从 $i+1$ 起，不是 $N^2$ 全额），量级仍为 $N^2$；
  3. 循环体内的 `BinarySearch` 在**已排序**数组上折半查找，代价 $O(\log_2 N)$（最多 $\lfloor\log_2 N\rfloor+1$ 次比较）；
  4. `sort(a)` 只执行一次，量级至多 $O(N^2)$（若为简单排序）或 $O(N\log_2 N)$（若为高效排序），**都被 $N^2\log_2 N$ 支配**，不影响结论；
  5. 题目问"最接近"，说明允许 $\log$ 因子取不同底、允许忽略低阶项，答案应对这些口径不敏感；
- 命题意图：这是 DS-2021-24 的"逆问题"（那里给时间问规模，这里给规模问时间），并且多考一层——**从代码中提取语句频度**：识别"双重循环 $\times$ 折半查找"这一乘积结构，以及判断"排序只算一次、可忽略"。

## 4. 核心考点

核心考点：
DS00.02 算法与算法分析（语句频度统计、时间复杂度的量级、由"$T$ 秒 $\leftrightarrow$ 规模 $N$"做外推估算）

辅助考点：
DS05.04 折半查找法（折半查找的比较次数为 $O(\log_2 N)$，这是内层因子 $\log N$ 的来源；而"查找前必须先排序"正是代码第一行 `sort(a)` 存在的原因）

解释：本题不考折半查找的实现细节，只借用其"每次比较规模减半"的结论作为复杂度因子，故列辅助；得分点全在"统计频度 + 解比例"。

## 5. 解题思路

1. **拆结构**：把代码拆成"一次性开销"（`sort`）与"重复性开销"（双重循环），后者是主体；
2. **数频度**：内层 `if` 语句的执行次数 $=\sum_{i=0}^{N-1}(N-1-i)=\frac{N(N-1)}{2}$，每次附带 $O(\log_2 N)$ 的折半查找 ⟹ $T(N)=c\cdot\frac{N(N-1)}{2}\log_2 N$；
3. **作比例**（避免求未知常数 $c$）：$\dfrac{T(35000)}{T(3500)}\approx 10^2\cdot\dfrac{\log_2 35000}{\log_2 3500}$；
4. **算数值**：$\log_2 3500\approx11.77$、$\log_2 35000\approx15.10$，比值 $1.282$ ⟹ 倍数 $\approx128$ ⟹ 约 $128$ 秒；
5. **对候选取最近**：$6$ 个候选换算成秒为 $10,20,60,120,3600,7200$，$128$ 与 $120$ 差 $8$，与 $60$ 差 $68$ ⟹ 选 **D**；
6. **敏感性检验**：若把 $\log$ 因子整个忽略（当作 $O(N^2)$）得 $100$ 秒，仍最接近 $120$；若误当作 $O(N^3)$ 得 $1000$ 秒，最近的仍是 $120$（$|1000-120|<|1000-3600|$）——三条路径都落在 D，说明答案对口径变化稳健。

## 6. 详细解答

### 第一步：统计语句频度

设数组长度 $N$。

- `sort(a)`：执行 $1$ 次排序，代价记为 $S(N)$；无论 $S(N)=O(N\log_2 N)$（快排/归并）还是 $S(N)=O(N^2)$（简单插入/选择），由第三步可知它都不是主导项；
- 双重循环：外层 $i=0,\dots,N-1$，内层 $j=i+1,\dots,N-1$，内层体执行次数

$$F(N)=\sum_{i=0}^{N-1}\bigl(N-1-i\bigr)=(N-1)+(N-2)+\cdots+1+0=\frac{N(N-1)}{2}$$

- 每次内层体调用 `BinarySearch(a, a[i]+a[j])`：在 $N$ 个有序元素上折半，比较次数 $\le\lfloor\log_2 N\rfloor+1$，即 $O(\log_2 N)$。

故总时间

$$T(N)=S(N)+c\cdot\frac{N(N-1)}{2}\cdot(\log_2 N+1)\ \approx\ c'\cdot N^2\log_2 N$$

（$c$、$c'$ 为与机器相关的常数，两次运行相同，故可在比例中消去。）

### 第二步：代入两个规模

$$\frac{T(35000)}{T(3500)}=\frac{35000\times34999}{3500\times3499}\times\frac{\log_2 35000+1}{\log_2 3500+1}$$

- 二次因子：$\dfrac{35000\times34999}{3500\times3499}=\dfrac{1\,224\,965\,000}{12\,246\,500}=100.026\approx100$（即 $\binom{N}{2}$ 之比 $=\frac{612\,482\,500}{6\,123\,250}=100.02$）；
- 对数因子：$\log_2 3500=\dfrac{\ln 3500}{\ln 2}=\dfrac{8.1605}{0.6931}=11.77$，$\log_2 35000=\dfrac{10.4631}{0.6931}=15.10$；取 $+1$ 后为 $12.77$ 与 $16.10$，比值 $1.261$；不取 $+1$ 时比值 $1.282$。两种取法都在 $1.26\sim1.29$ 之间。

$$\frac{T(35000)}{T(3500)}\approx100\times1.28=128$$

已知 $T(3500)=1$ 秒，故 $T(35000)\approx128$ 秒。

### 第三步：与六个候选比较（单位统一为秒）

| 候选 | 秒数 | 与 $128$ 秒的差 |
|---|---|---|
| A $10\ s$ | $10$ | $118$ |
| B $20\ s$ | $20$ | $108$ |
| C $1\ min$ | $60$ | $68$ |
| **D $2\ min$** | **$120$** | **$8$** ✓ 最小 |
| E $1\ h$ | $3600$ | $3472$ |
| F $2\ h$ | $7200$ | $7072$ |

⟹ 选 **D**。

### 第四步：交叉验证（绝对操作数法，不依赖比例技巧）

$N=3500$ 时内层体执行 $6\,123\,250$ 次，每次折半查找约 $11.77$ 次比较，合计约 $7.2\times10^{7}$ 次比较，耗时 $1$ 秒 ⟹ 该机器约每秒执行 $7.2\times10^{7}$ 次比较。
$N=35000$ 时内层体执行 $612\,482\,500$ 次，每次约 $15.10$ 次比较，合计约 $9.25\times10^{9}$ 次比较。
$$\frac{9.25\times10^{9}}{7.2\times10^{7}}\approx128\ \text{秒}\ \checkmark$$ 与第二步一致。

### 第五步：敏感性检验（说明答案不依赖口径选择）

| 采用的量级 | 倍数 | 时间 | 最接近 |
|---|---|---|---|
| $O(N^2\log_2 N)$（正确） | $128$ | $128\ s$ | **D** |
| 忽略 $\log$ 因子，按 $O(N^2)$ | $100$ | $100\ s$ | **D**（$|100-120|=20<|100-60|=40$） |
| 误按 $O(N^3)$ | $1000$ | $1000\ s$ | **D**（$|1000-120|<|1000-3600|$） |
| 误按 $O(N)$ | $10$ | $10\ s$ | A（**唯一会翻盘的错法**：把内层 $j$ 从 $i+1$ 看成"总共只扫一遍"） |

前三行说明"选 D"对 $\log$ 因子与排序开销的处理非常稳健；第四行则是本题真正要防的错误——**漏掉双重循环的 $N^2$**。

### 补充：程序在做什么（与结论无关，但可佐证"折半查找必须 $O(\log N)$"）

`sort(a)` 之后数组递增有序，这正是折半查找的前提；内层对每一对 $(i,j)$ 检查"$a_i+a_j$ 是否也在数组中出现"，命中则 `count++`。所以程序统计的是"两元素之和仍为数组中元素"的无序对个数——一个 $O(N^2\log N)$ 的朴素算法（若改用散列或双指针可降到 $O(N^2)$，但本题不要求）。

**答案**：D。

## 7. 选项分析

本题虽列在综合应用题下，但题面给出 $6$ 个候选时间，逐项核对如下：

- A（$10\ s$）：错。相当于按 $O(N)$ 估算，只把"外层循环 $10$ 倍"计入，完全漏掉内层循环与折半查找；
- B（$20\ s$）：错。无对应的合理误算路径（约等于 $O(N)$ 再乘 $2$），属凑数干扰项；
- C（$1\ min=60\ s$）：错。对应"$100$ 倍但被四舍五入到 $1$ 分钟"的想法——$100\ s$ 与 $60\ s$ 差 $40\ s$，与 $120\ s$ 只差 $20\ s$，即使按最粗的 $O(N^2)$ 口径也应选 D；这是本题最强的干扰项；
- **D（$2\ min=120\ s$）：正确**。$O(N^2\log_2 N)$ 给出 $128\ s$，与 $120\ s$ 相差不到 $7\%$；
- E（$1\ h=3600\ s$）：错。需要倍数达到 $3600$，相当于把量级误判为 $N^{3.5}$ 左右，或在“秒→分→时”的换算链上多乘了一个 $30$；与 $128\ s$ 相差一个数量级；
- F（$2\ h$）：错。相当于再乘 $60$，是"秒/分/时"单位链上的连续误算。

## 8. 考场标准答案

选 **D**。

分析过程（考场书写版）：

1. 内层 `if` 的执行次数为 $\sum_{i=0}^{N-1}(N-1-i)=\frac{N(N-1)}{2}=\Theta(N^2)$；
2. 每次 `BinarySearch` 在有序表上折半，比较次数 $\Theta(\log_2 N)$；`sort(a)` 只执行一次且为 $O(N\log_2 N)$ 或 $O(N^2)$，被主导项吸收；
3. 故 $T(N)=\Theta(N^2\log_2 N)$；
4. $\dfrac{T(35000)}{T(3500)}=10^2\times\dfrac{\log_2 35000}{\log_2 3500}=100\times\dfrac{15.10}{11.77}\approx128$；
5. $T(3500)=1\ s\Rightarrow T(35000)\approx128\ s$，与 $2\ minutes=120\ s$ 最接近 ⟹ **D**。

## 9. 易错点

1. **只看到"规模 10 倍"就选 A**：本题最大的失分点，等于认为程序是线性的；必须逐层数循环；
2. **把内层次数算成 $N^2$ 而非 $\frac{N(N-1)}{2}$**：本题不影响结论（比例中系数被消去），但若题目改问"比较次数是多少"就会错约 $2$ 倍；
3. **忘记折半查找自带 $\log N$**：按 $O(N^2)$ 得 $100\ s$——虽然本题仍选 D，但同型题若候选是 $60\ s$ 与 $100\ s$ 就会选错；
4. **把 `sort(a)` 当成主导项**：排序只做 $1$ 次、循环做 $\Theta(N^2)$ 次，量级上被支配；即便排序是 $O(N^2)$ 也仍被 $N^2\log N$ 支配；
5. **单位换算失误**：候选混用秒/分/小时，比较前必须统一成秒（$1\ min=60$、$1\ h=3600$）；
6. **对数换底疑虑**：$\log$ 因子取 $2$ 底、$10$ 底或自然底对**比值**影响极小（$\frac{\log 35000}{\log 3500}$ 与底数无关，因为换底常数在比例中消去）——真正影响比值的是"是否加 $1$"（$1.26$ vs $1.28$），不改变选项。

## 10. 一句话规律

"给规模问时间"类的估算题：**先数循环层数与每层内的调用代价，写成 $f(N)$，再用 $f(10N)/f(N)$ 作比例**——$N^2$ 给 $100$ 倍、额外的 $\log N$ 只给 $1.2\sim1.3$ 倍，因此答案总落在"比 $100$ 倍略大"的那个候选上。
