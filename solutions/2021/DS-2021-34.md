# DS-2021-34

## 1. 原题

设有一个正整数序列组成的有序单链表（按递增有序，且允许有相等的整数存在），请设计一个用最小的时间和最小空间的算法实现下列功能：

(a) 确定在序列中比正整数 $x$ 大的数有几个（相同的数只计算一次，如序列 $\{3,5,6,6,8,10,11,13,13,16,17,20,20\}$ 中比 $10$ 大的数有 $5$ 个）；

(b) 将单链表中比正整数 $x$ 小的数按递减次序排列；

(c) 将正整数比 $x$ 大的偶数从单链表中删除。

要求：

（1）描述算法的基本设计思想；

（2）根据设计思想，采用 $C$ 或 $C++$ 语言描述算法，关键之处给出注释；

（3）说明你所设计的算法的时间复杂度和空间复杂度。

提示：节点定义供参考

```c
typedef struct node {
    int data;
    struct node *next;
} LNode,*LinkList;
```

提示：算法定义形式供参考

```c
void FunctionExam(LinkList L1, int x) 
{ 
    ...... 
}
```

## 2. 答案

以题面样例 $L1:\ 3\to5\to6\to6\to8\to10\to11\to13\to13\to16\to17\to20\to20$、$x=10$ 为例：

- **(a)** 比 $10$ 大的**不同**取值有 $11,13,16,17,20$ 共 $cnt=5$ 个；
- **(b)** 比 $10$ 小的 $3,5,6,6,8$ 改为递减 $8,6,6,5,3$；
- **(c)** 删除比 $10$ 大的偶数 $16,20,20$；
- 处理后的单链表为 $L1:\ 8\to6\to6\to5\to3\to10\to11\to13\to13\to17$。

算法：一趟分段处理，时间 $O(n)$、空间 $O(1)$。完整代码见第 8 节。

## 3. 题目分析

- **输入**：带头结点的单链表 `L1`（数据结点自 `L1->next` 起按 `data` **递增有序**，允许相等）；正整数 `x`；
- **输出**：链表被就地修改（(b)(c) 生效）；(a) 的结果 $cnt$ 需报告——因题面给定函数为 `void`，本解析在函数内输出 $cnt$（等价地可把返回值改为 `int` 或增加一个 `int &cnt` 形参，阅卷时说明即可）；
- **数据结构选择**：必须用链表原语（头插、前驱删除），不得借助数组、栈或递归——否则违背"最小空间"；
- **核心不变量**：
  1. 因链表递增有序，"$<x$ 的元素"必是链表的一个**前缀**，一旦遇到 $data\ge x$ 的结点，其后所有结点都 $\ge x$ —— 这是"一趟扫描即可分段"的根据；
  2. 头插法会把插入次序**逆置**：按升序逐个头插 $\Rightarrow$ 结果降序，正好满足 (b)，无需额外排序；
  3. 在升序段上"值与前一个不同才计数"即可实现 (a) 的"相同只算一次"；
  4. 删除结点时始终持有其**前驱** $pre$，且 $pre$ 只在结点被保留时前进 —— 保证 (c) 的删除不断链；
- **边界情况**：空表；$x$ 比所有元素都小（前缀为空）；$x$ 比所有元素都大（后缀为空，全部头插）；$x$ 不在表中；表中存在 $data==x$ 的结点（**既不满足 (a) 的"大于"、也不满足 (c) 的"大于"，必须保留**）；末尾连续多个待删结点；
- **命题意图**：三问共用一趟扫描，考查"能否看出**有序性**带来的分段"（(a)(c) 只需看后缀、(b) 只需看前缀），以及"头插逆置 + 前驱删除"这两个链表基本技巧的组合使用；"最小的时间和最小的空间"是在明示：**不要另开数组、不要排序、不要 $O(n^2)$ 地逐个数**。

## 5. 解题思路

1. **先问"有序性能省掉什么"**：$<x$ 者必成前缀 ⟹ 不需要比较全部结点来决定谁该逆置；$\ge x$ 者必成后缀且仍升序 ⟹ 相同值必相邻，"值变化才计数"即可去重。两条合起来把三问压缩到一趟扫描；
2. **(b) 的实现选择**：链表原地逆置有"三指针翻转"与"头插到工作头结点"两种，后者代码最短且不易断链，故取后者——把前缀结点逐个 `p->next=shead->next; shead->next=p;`，升序进、降序出；
3. **(a)(c) 在同一趟后缀扫描中完成**：$cnt$ 用"与上一个计入值不同"判重；删除用 $pre$ 前驱摘链并 `free`。注意**先计数后删除**，二者读的是同一个 $p\to data$，顺序颠倒不影响结果，但先计数能避免"删掉的值没被统计"的疑虑；
4. **拼接**：逆置段的原首结点（最小者）在头插后成为**段尾**，须用变量 $tail$ 记住它，最后 `tail->next = 后缀的头`；若前缀为空则直接让 `L1->next` 指向后缀；
5. **逐例走查**：以题面样例为主例，另备空表、全小于 $x$、全大于 $x$、$x$ 不在表中、单结点等边界用例（第 6 节）。

## 6. 详细解答

### 第一步：把三问映射到链表的两个区段

设链表数据结点为 $a_1a_2\cdots a_n$，$a_1\le a_2\le\cdots\le a_n$。存在分界位置 $k$（可能 $k=0$ 或 $k=n$）使

$$a_1\le\cdots\le a_k<x\le a_{k+1}\le\cdots\le a_n$$

- **(b)** 只作用于前缀 $a_1..a_k$：改成 $a_k,\dots,a_1$（递减）；
- **(a)**、**(c)** 只作用于后缀 $a_{k+1}..a_n$：(a) 统计其中**不同取值**且 $>x$ 的个数（即排除 $==x$ 的那些），(c) 删除其中 $>x$ 的偶数；
- 三段工作在同一次遍历中完成：第一次遇到 $a_i\ge x$ 时前缀处理结束、后缀处理开始。

### 第二步：题面样例逐步走查（$x=10$）

**阶段 1：摘取 $<10$ 的前缀并头插逆置**

| 步 | $p\to data$ | 判 $<x$ | 头插后 $shead$ 链（头→尾） | $tail$ | $p$ 移到 |
|---|---|---|---|---|---|
| 1 | $3$ | 真 | $3$ | $3$ | $5$ |
| 2 | $5$ | 真 | $5,3$ | $3$ | $6$ |
| 3 | $6$ | 真 | $6,5,3$ | $3$ | $6$ |
| 4 | $6$ | 真 | $6,6,5,3$ | $3$ | $8$ |
| 5 | $8$ | 真 | $8,6,6,5,3$ | $3$ | $10$ |
| 6 | $10$ | **假** | 退出阶段 1 | $3$ | 停在 $10$ |

令 `rhead->next = p`（即后缀 $10,11,13,13,16,17,20,20$），$pre=rhead$，$cnt=0$。

**阶段 2：一趟扫描后缀，同时完成 (a) 计数与 (c) 删除**

| 步 | $p\to data$ | $>x$ ? | (a) 计数（与 $last$ 比较） | 偶数 ? | (c) 动作 | $pre$ 停在 |
|---|---|---|---|---|---|---|
| 1 | $10$ | 否（$==x$） | 不计 | 不判 | 保留 | $10$ |
| 2 | $11$ | 是 | $cnt\!:\!0\to1$，$last\!=\!11$ | 否 | 保留 | $11$ |
| 3 | $13$ | 是 | $13\neq11$，$cnt\!:\!1\to2$，$last\!=\!13$ | 否 | 保留 | 第一个 $13$ |
| 4 | $13$ | 是 | $13==last$，**不重复计** | 否 | 保留 | 第二个 $13$ |
| 5 | $16$ | 是 | $16\neq13$，$cnt\!:\!2\to3$，$last\!=\!16$ | **是** | `pre->next=17`，释放 $16$ | 第二个 $13$ |
| 6 | $17$ | 是 | $17\neq16$，$cnt\!:\!3\to4$，$last\!=\!17$ | 否 | 保留 | $17$ |
| 7 | $20$ | 是 | $20\neq17$，$cnt\!:\!4\to5$，$last\!=\!20$ | **是** | `pre->next=20'`，释放该 $20$ | $17$ |
| 8 | $20$ | 是 | $20==last$，不重复计 | **是** | `pre->next=NULL`，释放该 $20$ | $17$ |
| 9 | `NULL` | — | — | — | 结束 | — |

**(a) 结果 $cnt=5$**（对应 $11,13,16,17,20$ 五个不同取值，与题面"比 $10$ 大的数有 $5$ 个"吻合 ✓）。

**阶段 3：拼接**：$tail$（结点 $3$）的 $next$ 接上后缀首结点 $10$，并令 `L1->next = shead->next`（$8$）。

$$L1:\;8\to6\to6\to5\to3\to10\to11\to13\to13\to17$$

**核对三问**：(a) $cnt=5$ ✓；(b) 前缀 $8,6,6,5,3$ 递减 ✓；(c) $16,20,20$ 已删，$10$（等于 $x$，不属"比 $x$ 大"）保留 ✓。

### 第三步：边界用例走查

| 用例 | $x$ | $cnt$ | 结果链表 | 说明 |
|---|---|---|---|---|
| 空表 | $4$ | $0$ | 空 | 阶段 1、2 均不执行，`L1->next = rhead->next = NULL` ✓ |
| $1,1,2,2,3,3$ | $3$ | $0$ | $2,2,1,1,3,3$ | 无 $>3$ 者；前缀 $1,1,2,2$ 逆置 ✓ |
| $5,5,5$ | $1$ | $1$ | $5,5,5$ | 前缀为空，走 `L1->next=rhead->next` 分支 ✓ |
| $5,5,5$ | $9$ | $0$ | $5,5,5$ | 后缀为空，全部头插逆置（本例对称看不出）✓ |
| $1,2,3,4$ | $2$ | $2$ | $1,2,3$ | $>2$ 的不同值为 $3,4$；$4$ 为偶数被删 ✓ |
| $2,4,6,8$ | $5$ | $2$ | $4,2$ | 前缀 $2,4$ 逆置为 $4,2$；$6,8$ 均 $>5$ 且为偶数被删，$cnt$ 计 $6,8$ 两个不同值 ✓ |
| $7$ | $7$ | $0$ | $7$ | $data==x$ 既不计数也不删除 ✓ |
| $7$ | $3$ | $1$ | $7$ | $7>3$ 且为奇数，计数并保留 ✓ |
| $7$ | $9$ | $0$ | $7$ | $7<9$ 进入前缀，逆置后仍为 $7$ ✓ |

（$cnt$ 的参照值由"集合 $\{a_i\mid a_i>x\}$ 的元素个数"独立算出，逐例相符。）

### 第四步：正确性说明

- **前缀完整性**：阶段 1 的循环条件为 `p != NULL && p->data < x`。由链表递增有序，若某结点 $data\ge x$，其后所有结点亦 $\ge x$，故循环终止点恰是分界位置 $k$，前缀被完整摘取，不会有 $<x$ 的结点残留在后缀中；
- **(b) 的逆序性**：头插法使第 $i$ 个插入的结点位于第 $i-1$ 个之前，故插入次序 $a_1,a_2,\dots,a_k$（升序）产生的链为 $a_k,\dots,a_2,a_1$（降序）；相等元素保持相邻，不影响"递减次序"要求；
- **(a) 的去重性**：后缀仍升序，相同值必然相邻，故"与上一次计入值 $last$ 不等才 $cnt++$"精确等于统计不同取值个数；$data==x$ 的结点因不满足 $>x$ 而被排除，符合"比 $x$ **大**"；
- **(c) 的删除合法性**：删除时 $pre$ 是链中 $p$ 的前驱且 $pre$ 指向的结点必被保留（$pre$ 只在保留时前进），故 `pre->next = q` 后链不断；$q$ 在摘链前已保存，`free(p)` 不会造成悬空访问；连续多个待删结点由 $pre$ 不动来保证逐个摘除（见走查第 7、8 步）；
- **拼接正确性**：$tail$ 在阶段 1 首次摘取时被记为"原前缀的首结点"，头插逆置后它正是新前缀段的**尾结点**，故 `tail->next = rhead->next` 即完成两段合并；前缀为空时 $shead\to next==NULL$，改由 `L1->next` 直接挂后缀，两种情形都恰好接一次。

## 8. 考场标准答案

### （1）基本设计思想

利用链表"递增有序"的性质：比 $x$ 小的结点必构成链表的一个前缀，其余结点构成后缀且仍保持升序。因此只需一趟扫描，把三问分别压到两个区段上完成：

- 对前缀（$data<x$）逐个执行**头插**，插入次序是升序而头插会逆置，得到的段自然满足 (b) 的递减次序；用 $tail$ 记住该段的尾结点以便拼接；
- 对后缀（$data\ge x$）顺序扫描：凡 $data>x$ 且其值与本段上一次计入值不同者 $cnt++$，即得 (a)（相同值相邻，判一次即可去重）；同时凡 $data>x$ 且为偶数者，用前驱指针 $pre$ 将其摘链并释放，即得 (c)；$data==x$ 的结点既不计数也不删除；
- 最后把逆置段与处理后的后缀首尾相接，即得所求链表。整个过程只改动指针，不引入任何与 $n$ 相关的辅助空间，也不重复扫描。

### （2）C 语言描述

```c
typedef struct node {
    int data;
    struct node *next;
} LNode, *LinkList;

/* L1 为带头结点的单链表，数据结点递增有序（允许相等），x 为给定的正整数 */
void FunctionExam(LinkList L1, int x)
{
    LNode *p, *q, *pre, *tail = NULL;
    LNode *shead = (LNode *)malloc(sizeof(LNode));   /* <x 段的工作头结点 */
    LNode *rhead = (LNode *)malloc(sizeof(LNode));   /* >=x 段的工作头结点 */
    int cnt = 0, last = 0;                           /* cnt:(a) 的结果  last:上一个计入值 */

    shead->next = NULL;
    rhead->next = NULL;

    /* ---- 阶段 1：把 <x 的前缀逐个头插到 shead（升序进、降序出，完成 (b)）---- */
    p = L1->next;
    while (p != NULL && p->data < x)
    {
        q = p->next;                       /* 先保存后继，防止断链 */
        if (tail == NULL) tail = p;        /* 第一个被摘下的结点，逆置后是本段尾 */
        p->next = shead->next;             /* 头插 */
        shead->next = p;
        p = q;
    }
    rhead->next = p;                       /* p 是第一个 >=x 的结点，其后为后缀段 */

    /* ---- 阶段 2：一趟扫描后缀，同时完成 (a) 计数与 (c) 删除 ---- */
    pre = rhead;                           /* pre 始终是 p 的前驱，且 pre 所指结点必被保留 */
    while (p != NULL)
    {
        q = p->next;
        if (p->data > x)                   /* ==x 的结点不统计、不删除 */
        {
            if (cnt == 0 || p->data != last)   /* 后缀升序，相同值必相邻：只计第一次 */
            {   cnt++;  last = p->data;    }   /* (a) 计数 */
            if (p->data % 2 == 0)              /* (c) 比 x 大的偶数：摘链并释放 */
            {   pre->next = q;  free(p);   }
            else
            {   pre = p;                   }   /* 保留时才推进前驱 */
        }
        else
        {   pre = p;                       }
        p = q;
    }

    /* ---- 阶段 3：两段拼接；释放工作头结点 ---- */
    if (shead->next != NULL)               /* 前缀非空：tail 是逆置段的尾结点 */
    {   tail->next = rhead->next;  L1->next = shead->next;  }
    else
    {   L1->next = rhead->next;    }       /* 前缀为空：直接挂后缀 */
    free(shead);  free(rhead);

    printf("比 %d 大的数有 %d 个\n", x, cnt);   /* (a) 的结果；亦可改为返回 int */
}
```

### （3）复杂度

设链表数据结点个数为 $n$。

- **时间**：阶段 1 处理前缀 $k$ 个结点、阶段 2 处理后缀 $n-k$ 个结点，每个结点**恰好被访问一次**，每次仅做常数次比较与指针修改，故 $T(n)=O(n)$；阶段 3 为 $O(1)$。这是"最小时间"的体现——三问共用一趟扫描，不再有任何嵌套遍历或排序；
- **空间**：仅使用 $p,q,pre,tail$ 四个指针变量与 $cnt,last$ 两个整型变量，外加 $2$ 个临时头结点，均为与 $n$ 无关的常数，故 $S(n)=O(1)$。

## 9. 易错点

1. **忘了 $data==x$ 的结点要保留**：(a) 是"比 $x$ **大**"、(c) 是"比 $x$ **大**的偶数"，把条件写成 $data\ge x$ 会少算 $cnt$ 并误删等于 $x$ 的偶数（如样例中的 $10$ 会被删掉）；
2. **(a) 不去重**：直接 `cnt++` 得 $7$（样例中 $13,13,20,20$ 各多算一次）而非 $5$；去重靠"与上一次计入值不等"，而这一步骤**依赖后缀仍升序**（相同值相邻），链表若无序则此法失效；
3. **头插前先保存后继**：`p->next = shead->next;` 会覆盖 $p$ 原来的 $next$，若未先执行 `q = p->next;` 就丢失整条后续链；同理阶段 2 中 `pre->next = q` 之前也必须已保存 $q$；
4. **$tail$ 记错结点**：$tail$ 是**第一个**被摘下的结点（原前缀首结点、值最小者），头插逆置后它才是段尾；若记成最后一个摘下的结点，拼接时会形成环或丢结点；
5. **删除时不维护前驱**：单链表删除必须拿到前驱，若让 $pre$ 无条件前进，删掉 $p$ 后 $pre$ 就成了悬空指针（样例第 7、8 步连续两个 $20$ 正是这种情形）；
6. **前缀为空时误用 $tail$**：$x$ 不大于任何元素时阶段 1 一次都不执行，$tail$ 仍为 `NULL`，此时必须走 `L1->next = rhead->next` 分支，直接 `tail->next=...` 会崩溃；
7. **工作头结点忘接回**：`shead`/`rhead` 是临时分配的哨兵，拼接后必须 `free`，且**绝不能**把它们留在链表中（否则链表多出两个数据域未初始化的结点）；
8. **误开辅助数组**：把结点值抄进数组排序再重建链表，虽然结果对，但空间 $O(n)$、时间 $O(n\log n)$，直接违背"最小的时间和最小的空间"；
9. **(a) 的输出口径**：题面函数为 `void`，若不说明 $cnt$ 如何送出（打印或改签名）会留下"结果无处返回"的扣分点，应在答卷上注明。

## 10. 一句话规律

有序单链表上的多任务题，先问"**有序性让我能分段吗**"：$<x$ 必成前缀、$\ge x$ 必成后缀且仍升序，于是"前缀头插逆置 + 后缀一趟扫描（值变化才计数、按条件前驱删除）+ 两段拼接"就能把三问压进 $O(n)$ 时间、$O(1)$ 空间。
