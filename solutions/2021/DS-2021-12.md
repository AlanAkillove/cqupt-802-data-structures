# DS-2021-12

## 1. 原题

判断一个有向图是否存在回路，除可利用拓扑排序方法外，还可以用（）。

A. 求关键路径的方法

B. 求最短路径的方法

C. 广度优先遍历的方法

D. 深度优先遍历的方法

## 2. 答案

**D**（深度优先遍历的方法）。

## 3. 题目分析

- 已知：一个**有向图**，要判定其中是否存在回路（有向环）；题面已承认"拓扑排序法"可行，要求另找一种同样可行的方法；
- 目标：在四个"图算法"中选出能作为**有向图判环依据**的那一个；
- 关键约束：
  1. 判环方法必须是**充要**的——既能报出有环，也能确认无环，不能只对某类图有效；
  2. 有向图的环不能靠"碰到已访问顶点"来判定：有向图中一条弧 $<u,v>$ 的终点 $v$ 已被访问，完全可能只是"两条不相干的路径汇合到 $v$"（汇合点/交叉弧），不构成环；
  3. 拓扑排序判环的原理是"输出顶点数 $<|V|$ 则有环"，本质是**入度消元**；另一种等价刻画是**是否存在一种遍历顺序使邻接矩阵可上三角化**，而 DFS 的"回边"正是这种顺序的产物；
- 命题意图：表面在选算法，实质考查"有向图有环 ⟺ DFS 生成森林中存在回边"这一条与拓扑排序等价的判定定理，同时检验能否排除"看起来也能判环"的广度优先遍历（BFS 判环只在**无向图**中成立）。

## 4. 核心考点

核心考点：
DS04.03.01 深度优先搜索（DFS 生成森林中的边分类；有向图存在回路 $\iff$ 存在一条指向当前 DFS 栈上顶点的回边）

辅助考点：
DS04.04.03 拓扑排序（题面给出的对照方法：有向图无环 $\iff$ 存在拓扑有序序列，故拓扑排序输出个数 $<|V|$ 即判有环）
DS04.03.02 广度优先搜索（选项 C 的辨析对象：BFS 的"层"结构无法区分回边与交叉边）
DS04.04.04 关键路径（选项 A 的辨析对象：AOE 网以"无环"为前提，不是判环工具）

解释：本题答案的成立依赖 DFS 的边分类定理，故主标签取 DS04.03.01；但四个选项全部是"图的应用算法"，判错任何一个都需要知道它的适用前提，因此把拓扑排序、BFS、关键路径三项列为辅助考点。

## 5. 解题思路

1. 先把"判环"翻译成可执行的判据：必须存在一个**可在有限步内验证的等价条件**；
2. 回忆拓扑排序为什么能判环：它按"入度为 0"消元，若消不完（输出个数 $<|V|$），剩下的顶点必互相依赖成环——所以另一个方法要么也构造这种"先后依赖矛盾"，要么直接找一条"从某顶点出发又回到自身"的有向路径；
3. DFS 的递归栈恰好记录了"当前这条路径上的所有顶点"。若沿弧走到一个**还在栈上**的顶点，就找到了一条回边，即找到环；若所有弧的终点都不在当前路径上（只是"以前访问完并已退栈"的顶点），则不能判环——这正是 DFS 能判、BFS 不能判的分界；
4. 用本卷第 11 题的图（$6$ 顶点 $6$ 弧、无环）当"试金石"：任何声称能判环的方法，在这个图上必须给出"无环"的结论；据此检验 C——BFS 从 $v_1$ 出发访问 $v_2,v_3,v_6$ 后，处理 $v_4$ 的邻接点 $v_2$ 时 $v_2$ 早已访问过，若照搬无向图"见已访问顶点即有环"的判据就会误报，故 C 不成立；
5. A、B 直接按定义排除：关键路径的前提是 AOE 网无环，最短路径讨论的是带权路径长度，两者都不提供"有无回路"的判据。

## 6. 详细解答

**第一步：把四个选项统一放到"判环"这个任务下检验**

一个方法能判有向图回路，必须给出与"存在 $v_{i_1}\to v_{i_2}\to\cdots\to v_{i_k}\to v_{i_1}$（$k\ge1$）"等价的判据。

**第二步：D 正确——DFS 判环的定理与执行方式**

定理：有向图 $G$ 中存在回路 $\iff$ $G$ 的某次深度优先遍历生成森林中存在**回边**，即存在弧 $<u,v>$ 使得遍历到 $u$ 时 $v$ 是"当前 DFS 路径（递归栈）上的顶点"。

- 充分性：若 $v$ 在当前路径上，则 DFS 已经沿树边从 $v$ 走到了 $u$（$v$ 是 $u$ 的祖先），再加上弧 $<u,v>$，就得到回路 $v\to\cdots\to u\to v$；
- 必要性：设存在回路 $C$。取 DFS 中**最先**进入 $C$ 的顶点 $w$，沿 $C$ 的弧依次看：只要当前顶点未被访问就继续深入（DFS 的定义），直到某个顶点 $x$ 被访问过时，$x$ 的入口是沿 $C$ 从上一步顶点直接走来的，故 $x$ 必在当前递归路径上，这条弧即回边。

实现上只需两个标记数组（教材风格）：

```c
/* visited[v]=1 表示已访问；onPath[v]=1 表示在当前 DFS 递归路径上 */
Status DFSCycle(ALGraph G, int v, int visited[], int onPath[]) 
{
    visited[v] = 1;  onPath[v] = 1;                 /* 进栈：v 成为当前路径顶点 */
    for (各弧 <v,w>) 
    {
        if (!visited[w]) 
        {   if (DFSCycle(G, w, visited, onPath))  return TRUE;  }
        else if (onPath[w])  return TRUE;            /* 指向路径上的点：找到回路 */
    }
    onPath[v] = 0;                                   /* 退栈：v 不再在当前路径上 */
    return FALSE;
}
```

时间 $O(|V|+|E|)$（邻接表），与拓扑排序判环同阶，故 D 是拓扑排序之外的**真正可用**替代方法。

**第三步：C 不成立——BFS 缺少"当前路径"这一概念**

BFS 的辅助队列只区分"已入队/未入队"，其层次结构给出的是"距离"，不是"祖先—后代"关系。有向图中遇到一条指向已访问顶点的弧，可能是**交叉弧**（指向另一棵 BFS 树或同层/前层的非祖先顶点），未必成环。

反例（本卷第 11 题的图，已证无环）：$E=\{<v_1,v_2>,<v_2,v_3>,<v_3,v_6>,<v_4,v_2>,<v_4,v_5>,<v_5,v_6>\}$。从 $v_1$ 出发 BFS：第 0 层 $v_1$，第 1 层 $v_2$，第 2 层 $v_3$，第 3 层 $v_6$；若再从 $v_4$ 起遍历，处理 $<v_4,v_2>$ 时 $v_2$ 已访问——按"见已访问顶点即有环"的（无向图）判据会误报有环，而该图确有 $7$ 个拓扑序列、无回路。故 C 不能作为有向图判环方法。

（补充：若把 BFS 改造成"统计入度、逐层删零入度顶点"，那已经是拓扑排序的 Kahn 实现，属于题面已排除的"拓扑排序方法"，不是"另一种方法"。）

**第四步：A、B 不成立**

- A（求关键路径）：关键路径定义在 **AOE 网**上，而 AOE 网的前提是"有向无环图"——有回路则 $ve$（事件最早发生时间）按拓扑序递推无法收敛，算法根本不适用（见 DS-2019-10：关键路径是"最长路径"且必在无环网上讨论）。它把"无环"当输入条件，而不是用来检验条件，故不能判环；
- B（求最短路径）：Dijkstra/Floyd 求的是两顶点间带权路径的最小长度。无环图可以没有最短路径意义下的差别，有环图（权值为正时）也照样能求出最短路；环的存在与否不改变算法的可执行性，也不产生任何"有环/无环"的输出，故与判环无关。

**第五步：与拓扑排序判环的等价性自检**

拓扑排序判环："输出顶点数 $<|V|$ ⟹ 有环"。DFS 判环："存在回边 ⟹ 有环"。两者对同一图必须给出相同结论：若 DFS 无回边，则按"退栈次序的逆序"排列顶点，所有弧都从早指向晚，即得到一个拓扑序（无环）；反之若有拓扑序，则沿弧编号严格增大，不可能出现指向路径上祖先的弧（无回边）。两条判据互相印证，D 与题面给出的方法等价可用。

**答案**：D。

## 7. 选项分析

- A（求关键路径的方法）：错。关键路径算法要求输入是 AOE 网（有向**无环**图），"无环"是它的前提而非结论，用它判环属于循环论证；
- B（求最短路径的方法）：错。最短路算法对有无回路都照常运行，其输出（路径长度）不编码"是否存在环"这一信息；只有"负权回路"这类特殊情形才会被最短路算法间接暴露，而一般"是否存在回路"不能靠它判定；
- C（广度优先遍历的方法）：错（典型干扰项）。BFS 能判**无向图**的环（同一顶点被两条不同路径到达），但在有向图中"指向已访问顶点的弧"可能是交叉弧，会误报；把 BFS 用于有向图判环的唯一途径是退化为按入度消元，而那已是拓扑排序本身；
- D（深度优先遍历的方法）：对。DFS 的递归栈保存"当前路径"，遇到指向栈上顶点的弧即回边，回边存在 $\iff$ 有回路，判据充要且 $O(|V|+|E|)$。

## 8. 考场标准答案

选 **D**。

理由（可书写版）：有向图存在回路的充要条件是"深度优先遍历过程中出现一条指向**当前递归栈上顶点**的弧（回边）"。DFS 天然维护当前路径，故可判环：找到回边即有回路；全部顶点遍历完仍无回边，则按退栈逆序即得拓扑序，说明无回路。

排除：A 中关键路径要求输入本身是 AOE 网（必无回路），不能反用；B 中最短路径与顶点间先后依赖无关；C 中 BFS 只记录"是否访问过"，无法区分回边与交叉弧（如本卷第 11 题的无环图中 $<v_4,v_2>$ 就指向已访问顶点），会误判。

## 9. 易错点

1. **把无向图判环的结论搬到有向图**：无向图 DFS/BFS 中"遇到已访问的非父顶点即有环"成立，因为无向边天然对称；有向图必须要求该顶点"在当前路径上"，否则只是两条路径汇合；
2. **误以为 BFS 与 DFS 只是访问顺序不同、能力等价**：判有向图环依赖"当前路径"这一栈信息，队列没有这个信息，这是两者本质差别，不是效率差别；
3. **混淆"拓扑排序可用栈实现"与"栈/队列遍历"**：拓扑排序的实现既可用栈也可用队列（Kahn），但题面问的是"除拓扑排序外"的方法，选 C 属于把实现工具当成了新算法；
4. **忽视 AOE/AOV 的前提**：关键路径（AOE）与拓扑排序（AOV）都建立在"有向无环"之上，凡"用它们判环"的选项都要按循环论证排除（同 DS-2019-10 中"最长回路/最短回路"两项的排除逻辑）。

## 10. 一句话规律

有向图判环只有两条等价路：拓扑排序看"顶点消不消得完"，DFS 看"有没有指向当前递归栈的回边"；凡是只记"访问过/没访问过"的判据（BFS 式）都只能判无向图。
