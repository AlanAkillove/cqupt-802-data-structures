# DS-2021-02

## 1. 原题

一些随机产生的数采用线性链表存储，在下面这些排序方法中，（）的时间复杂度是最小的。

A. 插入排序

B. 快速排序

C. 堆排序

D. 归并排序

## 2. 答案

**D**（归并排序）。

## 3. 题目分析

- 已知：① 数据是**随机产生**的（不是"近乎有序"，也不是"完全逆序"，故可按平均/最坏的一般情形分析）；② 数据的存储结构是**线性链表**（只能从头结点沿 `next` 顺序访问，**没有**按下标 $O(1)$ 的随机存取能力）；
- 目标：在四种排序方法中选出在该条件下**时间复杂度最小**者；
- 关键约束：题干的限定不是"渐近意义下哪种算法最快"（那种比较隐含了可随机存取的顺序表），而是"在**链表**上跑哪种算法最快"。因此必须同时看两件事——算法的量级、以及算法对**访问方式**的依赖程度；
- 命题意图：考"存储结构决定算法可行性"这一主线（DS01.02.02 与 DS06 的交叉）。堆排序的 `2i/2i+1` 孩子定位、教材版快排的双向指针扫描、折半类操作都以顺序存储为前提；归并排序只做"相邻两段的头结点比较与链接"，与链表天然契合。

## 4. 核心考点

核心考点：
DS06.11 排序算法应用（各排序方法的复杂度、稳定性与适用存储结构对照）

辅助考点：
DS01.02.02 链式存储：单链表（"顺序访问、不可随机存取"是本题的决定性约束）
DS06.08 二路归并排序（为何归并在链表上不产生额外元素移动、不需要随机访问）

解释：本题不是让你算某一趟结果，而是要在四种方法之间做**性质比较**，比较的维度正是 DS06.11 的"复杂度与比较"；而"比较"之所以有胜负，是因为 DS01.02.02 给出的链表访问约束把依赖随机存取的方法判了出局。

## 5. 解题思路

1. 先列四法在**顺序表**上的量级（平均/最坏）与附加空间、稳定性；
2. 再问"这一算法的每一步是否只需顺序访问"：
   - 插入排序：只需顺序比较，可用；但量级本身是 $O(n^2)$；
   - 堆排序：建堆与每次 `HeapAdjust` 都要在 $\lfloor n/2\rfloor$ 个下标间来回跳（父 $\lfloor i/2\rfloor$、子 $2i/2i+1$），链表上取一次孩子就得遍历，代价整体退化到不低于 $O(n^2)$，实际上教材做法是先搬进数组——即"堆排序要求顺序存储"；
   - 快速排序：平均 $O(n\log n)$、最坏 $O(n^2)$，且严蔚敏版一趟划分是 `i`、`j` 从区间两端**相向扫描并交换**，依赖随机存取；
   - 归并排序：任何情形都是 $O(n\log n)$，合并两段的"取较小者"只需比较两个链表的当前头结点并把结点**摘下来链接**，无须下标、无须移动元素；
3. 结论：在链表这一约束下唯一"量级低且不依赖随机存取"的是归并排序 ⟹ D。

## 6. 详细解答

**第一步：四法的基本量（$n$ 为结点数，数据随机）**

| 方法 | 平均时间 | 最坏时间 | 附加空间 | 稳定性 | 对存储结构的要求 |
|---|---|---|---|---|---|
| 直接插入排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 稳定 | 顺序/链式均可 |
| 快速排序 | $O(n\log n)$ | $O(n^2)$ | $O(\log n)$（递归栈） | 不稳定 | 教材划分需**随机存取** |
| 堆排序 | $O(n\log n)$ | $O(n\log n)$ | $O(1)$ | 不稳定 | 需**顺序存取**（$2i,2i+1$） |
| 二路归并排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n)$（数组）/ $O(\log n)$ 或 $O(1)$（链表重链） | 稳定 | 只需**顺序访问**，链表天然适配 |

**第二步：按链表约束淘汰**

- **A 插入排序**：在链表上可以正常实现（找到插入位置后只改指针，不移动元素），但其比较/移动总量在随机数据下仍是 $\Theta(n^2)$。量级上已不是最小 ⟹ 淘汰。
- **C 堆排序**：堆是用**下标**定义完全二叉树关系的——编号 $i$ 的左孩子 $2i$、右孩子 $2i+1$、双亲 $\lfloor i/2\rfloor$。链表没有这种"一步跳到第 $2i$ 个结点"的能力，取一次孩子需从头走 $O(i)$。若强行在链表上做 `HeapAdjust`，`BuildHeap` 的 $\sum O(\log i)$ 次调整每次都退化为线性查找，总量超过 $O(n\log n)$。故堆排序事实上要求顺序存储 ⟹ 淘汰。
- **B 快速排序**：严蔚敏教材的一趟划分用 `i`、`j` 两个下标从当前区间左右两端相向扫描、在停住处交换记录，并要求 `R[0]` 作枢轴暂存——全部基于数组随机存取。链表上要实现同样的划分需要频繁"取第 $k$ 个结点/回到区间中点"，代价退化；且快排的最坏量级是 $O(n^2)$（当每次枢轴取到极值时，见 DS-2015-36），随机数据只保证**平均**好，不保证**最坏**好 ⟹ 不是"最小"的稳定答案。
- **D 归并排序**：自底向上做 $\lceil\log_2 n\rceil$ 趟两两合并，每趟对每个结点只做常数次比较与一次指针重挂，总比较次数 $\le n\lceil\log_2 n\rceil$，**任何输入下都是** $O(n\log n)$；合并时"谁的当前头小就把谁摘下来接在结果链尾部"，只需要顺序访问，还省掉了数组版 $O(n)$ 的辅助空间。量级最小且与链表最适配 ⟹ 选中。

**第三步：量级比较（同一 $n$ 下的相对结论）**

链表上的实际量级为：插入 $\Theta(n^2)$ > 快排（退化后不低于 $\Theta(n^2)$，且最坏本就是 $\Theta(n^2)$）≈ 堆排（孩子定位使调整代价上升）> 归并 $\Theta(n\log n)$。

**答案**：D。

## 7. 选项分析

- A（插入排序）：错。链表上可实现且不搬元素，但比较次数在随机数据下期望为 $\Theta(n^2)$，量级不是最小；只有当数据"近乎有序"时插入才占优（DS-2015-17 的情形），本题明说"随机产生"；
- B（快速排序）：错（相对 D）。平均 $O(n\log n)$ 但**最坏** $O(n^2)$，且教材划分依赖下标双向扫描即随机存取，在链表上不是自然选择。补充口径说明：若把快排改写成"链表摘链成三条子链"的实现，它在链表上也是平均 $O(n\log n)$，此时与 D 只在"最坏保证"上分高下——本库取 D，因为归并的最坏量级也是 $O(n\log n)$，"时间复杂度最小"在随机+最坏两种读法下都成立；
- C（堆排序）：错。$O(n\log n)$ 的量级本身不差，但堆的性质完全建立在下标 $2i$、$2i+1$ 上，链式存储无法随机定位孩子，实际代价远高于 $O(n\log n)$，是四者中"存储结构与算法最不匹配"的一个；
- D（归并排序）：正确。平均与最坏均为 $O(n\log n)$，只需顺序访问，链表上重链即可完成合并，附加空间也小于数组版。

## 8. 考场标准答案

链表只能顺序访问：堆排序需按下标 $2i,2i+1$ 定位孩子，快速排序（教材版）需下标双向扫描划分——两者在链表中代价退化；直接插入排序与归并排序都可用链表，但前者随机数据下为 $O(n^2)$，后者恒为 $O(n\log n)$ 且只需比较两段头结点后摘链。故选 **D 归并排序**。

链表归并的关键操作（考场可只写结论，代码供理解）：

```c
LNode* MergeList(LNode* ha, LNode* hb)     /* 两条有序链合并，只改指针不新建结点 */
{
    LNode h; h.next = NULL;                /* 临时头结点 */
    LNode *t = &h;
    while (ha && hb) {
        if (ha->data <= hb->data) { t->next = ha; ha = ha->next; }
        else                      { t->next = hb; hb = hb->next; }
        t = t->next;
    }
    t->next = ha ? ha : hb;
    return h.next;
}
```

时间 $O(n\log n)$（$\lceil\log_2 n\rceil$ 趟，每趟 $O(n)$），链表版附加空间 $O(1)$（自底向上）或 $O(\log n)$（递归版栈深）。

## 9. 易错点

1. **只看算法平均量级、忽略题干"链表"**：不少同学直接背"快排平均最快"而选 B，本题的限定词是存储结构，快排/堆排的优势建立在数组上；
2. **混淆"插入排序在链表上不移动元素"与"因此快"**：不搬元素只省掉移动代价，比较次数仍是 $\Theta(n^2)$（DS-2014-07 式的"链表上找位置也要 $O(n)$"）；
3. **忽略"随机产生"这一限定**：若数据近乎有序，答案会变成插入排序；题干给出输入分布，正是为了排除这个方向；
4. **归并的"空间 $O(n)$"当成否决理由**：那是**数组**版的辅助空间；链表版靠重挂指针完成合并，不需要 $n$ 个临时单元，因此"归并费空间"不能用来否定 D。

## 10. 一句话规律

排序选型题先读两个限定词——**输入分布**和**存储结构**：需要下标跳转的算法（堆、快排）在链表上一律降档，只比较相邻头结点的算法（归并）在链表上保持原量级。
