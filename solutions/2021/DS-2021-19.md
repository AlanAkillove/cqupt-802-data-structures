# DS-2021-19

## 1. 原题

现有按中序遍历二叉树的结果为 $abc$ ，有____________________种不同形态的二叉树可以得到这一遍历结果。

## 2. 答案

**5** 种。

## 3. 题目分析

- 已知：一棵二叉树，$3$ 个结点，中序遍历（左—根—右）所得序列为 $a,b,c$；
- 目标：求能得到该中序序列的二叉树**形态**种数；
- 关键约束：
  1. 中序遍历的规则是"先递归访问左子树、再访问根、最后递归访问右子树"，因此**根把中序序列切成两段**：若根是第 $k$ 个字符，则 $a\cdots$ 的前 $k-1$ 个字符全在左子树、其余全在右子树，且两子树内部的中序次序仍须保持；
  2. 反过来，任一形态的 $3$ 结点二叉树，都**恰好有一种**给 $3$ 个结点标号的方式使中序为 $abc$（按中序访问次序依次贴 $a,b,c$）⟹ "中序为 $abc$ 的树"与"$3$ 个结点的二叉树形态"一一对应，计数问题化为形态计数；
  3. 二叉树是**有序**结构：左、右孩子互换即不同形态（这是本题与"一般树的形态计数"分岔之处）；
- 命题意图：考"由遍历序列确定二叉树"这一族结论的另一面——只给中序**不能**定树，其不确定度恰等于形态数（卡特兰数）；同时检测是否清楚"中序定标号、形态定结构"的对应关系。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（中序遍历的"左—根—右"切分性质；仅凭中序序列无法唯一确定二叉树，需再给定先序或后序）

辅助考点：
DS03.02.01 二叉树的定义及主要特征（二叉树左右有序 ⟹ 同一批结点的形态数服从卡特兰数）

解释：题目的限制条件来自中序遍历（"根把序列切成左右两段"是唯一的分类依据），故主标签 DS03.02.03；而计数对象是"二叉树形态"，其有序性与卡特兰递推属 DS03.02.01。与本库 DS-2019-02（无遍历限制、纯问 $3$ 结点形态数，主 DS03.02.01）相区别：本题多了一层"中序为 $abc$"的语言，需要先把该条件翻译成"形态与标号的一一对应"。

## 5. 解题思路

1. 用中序切分性质做**按根分类**：根只能是 $a$、$b$、$c$ 三者之一；
   - 根 $=a$：左子树空，右子树含 $\{b,c\}$ 且中序为 $bc$；
   - 根 $=b$：左子树 $\{a\}$、右子树 $\{c\}$；
   - 根 $=c$：左子树含 $\{a,b\}$ 且中序为 $ab$，右子树空；
2. 子问题递归：$2$ 个结点且中序固定 ⟹ $2$ 种形态（链向右、链向左）；$1$ 个结点 ⟹ $1$ 种；
3. 合计 $2+1+2=5$，并逐棵回写中序验证都是 $abc$（排除"数了却不满足条件"的错误）；
4. 换两条独立路线复核：① 形态数递推 $f(3)=\sum_{i=0}^{2}f(i)f(2-i)=1\cdot2+1\cdot1+2\cdot1=5$；② 卡特兰公式 $\frac{1}{3+1}\binom{6}{3}=\frac{20}{4}=5$；
5. 说明穷尽性：任何满足条件的树必有 $a,b,c$ 之一为根，三类互斥且已逐类枚举，故不存在第 $6$ 棵。

## 6. 详细解答

**记法**：用 `根(左子树,右子树)` 表示树形，空子树记空格。

**（1）按根分类穷举**

- **根为 $a$**：左子树为空，右子树由 $b,c$ 构成且其中序必须是 $bc$。
  - 树 1：`a( , b( , c))` —— $b$ 有右孩子 $c$。中序：$a$，再访问 $b$ 的左（空）、$b$、$b$ 的右 $c$ ⟹ $abc$ ✓
  - 树 2：`a( , c(b, ))` —— $c$ 有左孩子 $b$。中序：$a$，再 $c$ 的左子树 $b$、然后 $c$ ⟹ $abc$ ✓
- **根为 $b$**：$a$ 必须在左、$c$ 必须在右（中序里 $b$ 前的是左子树、$b$ 后的是右子树）。
  - 树 3：`b(a, c)`。中序 $abc$ ✓（唯一形态）
- **根为 $c$**：右子树为空，左子树由 $a,b$ 构成且中序为 $ab$。
  - 树 4：`c(a( , b), )` —— $a$ 有右孩子 $b$。中序：先 $a$ 的左（空）、$a$、$a$ 的右 $b$，再根 $c$ ⟹ $abc$ ✓
  - 树 5：`c(b(a, ), )` —— $b$ 有左孩子 $a$。中序：$a$、$b$，再根 $c$ ⟹ $abc$ ✓

图形对照：

```
树1      a          树2      a          树3        b
            \                         \          /   \
             b          c              c        a     c
              \         /
               c       b

树4          c          树5          c
            /                       /
           a                       b
            \                     /
             b                   a
```

**（2）计数**

$$N=\underbrace{2}_{\text{根 }a}+\underbrace{1}_{\text{根 }b}+\underbrace{2}_{\text{根 }c}=\boxed{5}$$

**（3）路线二：形态数递推**

设 $f(n)$ 为 $n$ 个结点的二叉树形态数，$f(0)=1$（空树）。按"左子树 $i$ 个结点、右子树 $n-1-i$ 个"分类，左右有序故

$$f(n)=\sum_{i=0}^{n-1}f(i)f(n-1-i)$$

$f(1)=f(0)f(0)=1$，$f(2)=f(0)f(1)+f(1)f(0)=2$，

$$f(3)=f(0)f(2)+f(1)f(1)+f(2)f(0)=2+1+2=5\ \checkmark$$

这与第（1）步"根为 $a/b/c$ 三类各 $2,1,2$ 棵"逐项对应（左子树结点数 $0,1,2$）。

**（4）路线三：卡特兰数公式**

$$f(n)=\frac{1}{n+1}\binom{2n}{n}\ \Longrightarrow\ f(3)=\frac{1}{4}\binom{6}{3}=\frac{20}{4}=5\ \checkmark$$

**（5）验算与自洽性检查**

- 逐棵回写中序：树 1~树 5 的中序均为 $abc$ ✓（$5/5$ 通过，无"多算"）；
- 逐棵检查结点数：每棵恰 $3$ 个结点、且 $a,b,c$ 各出现一次 ✓（无"漏算/重复"）；
- 穷尽性：任一满足条件的树，其根必为 $a,b,c$ 之一，且中序切分强制"根左边全在左子树、根右边全在右子树"，三类互斥完备，$2+1+2$ 已覆盖全部 ⟹ 不存在第 $6$ 棵；
- 对照"标号唯一性"：任取一个 $3$ 结点形态，按中序访问次序依次赋 $a,b,c$，得到的树必在上面的 $5$ 棵之中 ⟹ 本题答案与"$3$ 个结点的二叉树形态数"相同。

**答案**：$5$。

## 8. 考场标准答案

中序为 $abc$ 时，根只能是 $a$、$b$、$c$ 之一，且根左侧的字符全在其左子树、右侧的全在右子树：

- 根 $a$：右子树由 $b,c$ 组成（中序 $bc$）⟹ $2$ 种；
- 根 $b$：左 $a$、右 $c$ ⟹ $1$ 种；
- 根 $c$：左子树由 $a,b$ 组成（中序 $ab$）⟹ $2$ 种。

$$N=2+1+2=5$$

即 $f(3)=\dfrac{1}{3+1}\dbinom{6}{3}=5$（卡特兰数），与"三个结点的二叉树形态数"一致。

## 9. 易错点

1. **以为中序能唯一确定二叉树**：只给中序 ⟹ $5$ 种可能；必须"中序 $+$ 先序"或"中序 $+$ 后序"才能定唯一一棵（见 DS-2021-29 的重建过程）；
2. **漏掉"只有右孩子/只有左孩子"的两种不同形态**：$2$ 个结点时答案是 $2$ 而不是 $1$，本题 $5$ 中有 $4$ 棵来自这一层；二叉树左右有序，把 `a( ,b)` 与 `a(b, )` 视为同一种就会答成 $3$；
3. **切分方向搞反**：根**左侧**的字符属于左子树，右侧属于右子树；若弄反，"根 $=a$ 有 $2$ 种"会被错写成"根 $=a$ 时左子树含 $b,c$"，虽然计数侥幸仍是 $2$，但举出的树形中序不是 $abc$；
4. **与一般树的形态数混用**：$3$ 个结点的（有序）**树**只有 $C_2=\frac{1}{3}\binom{4}{2}=3$ 种形态，$3$ 个结点的**二叉树**有 $5$ 种，两者相差在"二叉树区分左、右孩子（含独孩子时区分左右）"；
5. **卡特兰数下标**：$n$ 个结点的二叉树形态数是 $C_n=\frac{1}{n+1}\binom{2n}{n}$，$n=3$ 时是 $C_3=5$；若误用 $C_{n-1}$ 会得 $2$；
6. **把"形态"与"标号方案"重复相乘**：本题中序已把标号钉死（每个形态只对应一种标法），不能再乘 $3!=6$；若问"中序可以是 $abc$ 的带标号树有几棵"才是另一回事。

## 10. 一句话规律

"给一种遍历序列问形态数"= 按根的位置分类 + 子问题递归，结果总是卡特兰数 $\frac{1}{n+1}\binom{2n}{n}$；只有"中序 $+$ 先序（或后序）"才把答案压成 $1$。
