# DS-2021-01

## 1. 原题

设 $N$ 是描述问题规模的非负整数，下列程序段的时间复杂度是（）。

A. $O(\log N)$

B. $O(N)$

C. $O(N\log N)$

D. $O(N^2)$

```c
static int fun(int N)
{
    if(N==1) 
        return 0;
    return 1+fun(N/2);
}
```

## 2. 答案

**A**（$O(\log N)$）。

## 3. 题目分析

- 已知：一个单分支（每层只发起一次递归调用）的递归函数，递归参数为 `N/2`（整数除法即 $\lfloor N/2\rfloor$），递归出口为 `N==1`，每层除递归外只做常数次工作（一次比较、一次加法、一次返回）；
- 目标：判定该程序段的时间复杂度量级；
- 关键约束：规模不是"每次减 1"而是"每次折半"，因此层数是对数级而非线性级；语句频度 $=O(\text{递归调用次数})$；
- 命题意图：表面读代码判复杂度，实质考查**递归式 $T(N)=T(N/2)+O(1)$ 的求解**，以及与线性递归 $T(N)=T(N-1)+O(1)$（如 DS-2013-21 的阶乘）在量级上的对照——两者代码形状几乎一样，差别只在参数是 `N/2` 还是 `N-1`。

## 4. 核心考点

核心考点：
DS00.02 算法与算法分析（语句频度、时间复杂度的渐近量级；递归式的求解）

辅助考点：
DS02.07 栈、队列和数组的应用（递归由运行栈实现，递归深度即附加空间 $O(\log N)$，是同一份代码的空间结论）

解释：题干问的是"时间复杂度"这一绪论概念，与题目操作的具体数据结构无关，故主标签落在 DS00.02（与本库 DS-2013-21、DS-2017-01 的打标口径一致）；而"折半递归为什么不会多算代价"要靠递归工作栈来解释——每层一个栈帧、共 $\log N$ 层，故辅助列 DS02.07。

## 5. 解题思路

1. 先确认"基本操作"：函数体内除递归调用外只有比较与加法，代价记为常数 $c$；
2. 写递归式：$T(N)=T(\lfloor N/2\rfloor)+c$，$T(1)=c$；
3. 看参数变化序列：$N\to\lfloor N/2\rfloor\to\lfloor N/4\rfloor\to\cdots\to 1$，需折半多少次？——即 $N$ 的二进制位数减一，$\lfloor\log_2 N\rfloor$ 次；
4. 迭代展开求和：$T(N)=(\lfloor\log_2 N\rfloor+1)c=\Theta(\log N)$；
5. 用小规模值代入验证（第 6 节表），并改写成一个 `while` 循环版做交叉核对。

## 6. 详细解答

**第一步：调用链**

`fun(N)` 在 `N!=1` 时执行 `return 1+fun(N/2)`。C 语言的 `/` 对正整数是截断除法，故实参序列为

$$N,\ \lfloor N/2\rfloor,\ \lfloor N/2^2\rfloor,\ \cdots,\ \lfloor N/2^k\rfloor$$

递归持续到 $\lfloor N/2^k\rfloor=1$，即 $2^k\le N<2^{k+1}$，所以

$$k=\lfloor\log_2 N\rfloor$$

即递归体（第 4 行 `return`）被执行 $k=\lfloor\log_2 N\rfloor$ 次，出口判断共发生 $k+1$ 次。

**第二步：递归式求解（迭代展开法）**

$$T(N)=T(N/2)+c=T(N/4)+2c=\cdots=T(N/2^k)+kc$$

取 $k=\lfloor\log_2 N\rfloor$，此时 $T(N/2^k)=T(1)=c$，故

$$T(N)=(k+1)c=(\lfloor\log_2 N\rfloor+1)c=\Theta(\log N)$$

返回值本身也恰是 $\lfloor\log_2 N\rfloor$（`fun(8)=3`、`fun(16)=4`），可见"返回值 $=\log N$ 量级"与"执行次数 $=\log N$ 量级"是一致的。

**第三步：逐值核对**

| $N$ | 实参变化链 | 递归体执行次数 $\lfloor\log_2 N\rfloor$ | 出口判断次数 |
|---|---|---|---|
| 1 | $1$ | 0 | 1 |
| 2 | $2\to1$ | 1 | 2 |
| 3 | $3\to1$ | 1 | 2 |
| 4 | $4\to2\to1$ | 2 | 3 |
| 8 | $8\to4\to2\to1$ | 3 | 4 |
| 16 | $16\to8\to4\to2\to1$ | 4 | 5 |
| 1000 | $1000\to500\to250\to125\to62\to31\to15\to7\to3\to1$ | 9 | 10 |

$N$ 从 8 增到 16（翻倍）次数只加 1；$N$ 从 16 增到 1000（约 62 倍）次数只加 5 —— 次数随 $N$ 呈对数增长，不呈线性/平方增长。

**第四步：等价循环版交叉验证**

```c
int fun(int N)          /* 与递归版等价的迭代写法 */
{
    int k = 0;
    while (N > 1) { N = N / 2; k++; }
    return k;
}
```

循环体执行次数同样是 $\lfloor\log_2 N\rfloor$，量级 $O(\log N)$，与第三步结论吻合。

**第五步：附加空间（附带结论）**

递归版在返回前栈上同时存在 $k+1$ 个栈帧，故空间 $S(N)=\Theta(\log N)$；循环版为 $O(1)$。这不改变时间量级，但说明"折半递归"的代价实体是 $O(\log N)$ 深的运行栈（DS02.07）。

**答案**：A。

## 7. 选项分析

- A（$O(\log N)$）：正确。参数每次折半，递归层数 $\lfloor\log_2 N\rfloor$，每层 $O(1)$；
- B（$O(N)$）：错。这是把递归参数写成 `N-1`（线性递归，如 DS-2013-21 的 `Factorial(n)`）时的量级；本题参数是 `N/2`。误选的原因是"看到递归就以为与规模同阶"，或把返回值 $\lfloor\log_2 N\rfloor$ 误当作执行次数 $N$；
- C（$O(N\log N)$）：错。$N\log N$ 需要"$\log N$ 层、每层做 $O(N)$ 工作"（如归并排序的自顶向下分析），而本题每层只有常数次运算，没有随 $N$ 增长的循环；
- D（$O(N^2)$）：错。需要两层与规模相关的循环或"每层 $O(N)$ 且共 $O(N)$ 层"，本题既无嵌套循环也无线性递归深度。

## 8. 考场标准答案

设每层除递归外代价为常数 $c$，则

$$T(N)=T(\lfloor N/2\rfloor)+c,\quad T(1)=c$$

实参按 $N\to\lfloor N/2\rfloor\to\cdots\to1$ 收缩，层数 $k=\lfloor\log_2 N\rfloor$，故

$$T(N)=(k+1)c=O(\log N)\quad\Rightarrow\text{选 A}$$

（附加空间 $O(\log N)$，等价迭代版 `while(N>1) N/=2;` 亦为 $O(\log N)$ 时间、$O(1)$ 空间。）

## 9. 易错点

1. **只看"有没有循环"而误判**：递归程序判复杂度要数"调用次数 × 每层非递归代价"，本题是"对数次 × 常数"，不是"常数次 × 常数"（那才是 $O(1)$，如 DS-2015-01 中循环上界被赋成常量 $10$ 的情形）；
2. **把参数折半当参数减一**：`fun(N/2)` 与 `fun(N-1)` 只差一个符号，量级却差一个 $\log$；
3. **整数除法与取整**：$N$ 不是 2 的幂时层数是 $\lfloor\log_2 N\rfloor$ 而非 $\log_2 N$，量级不变，但个别 $N$ 值（如 $N=3$ 直接到 1）会让"层数 $=\log_2 N$"的等式不成立，推导时应写 $\lfloor\log_2 N\rfloor$；
4. **边界情形**：题面说 $N$ 是"非负整数"，而 `N==1` 是唯一出口，若 $N=0$，则 $0/2=0$，递归永不终止（栈溢出）。按"描述问题规模"的常规约定取 $N\ge1$ 分析，本题结论不受影响；$N<0$ 同理不终止——这一点是题面措辞的瑕疵，不影响选项判定。

## 10. 一句话规律

单分支递归的量级只看"参数几步到出口"：每次折半 ⟹ $O(\log N)$，每次减一 ⟹ $O(N)$；再乘上"每层除递归外的工作量"就是总复杂度。
