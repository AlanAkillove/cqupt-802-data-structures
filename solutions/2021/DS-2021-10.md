# DS-2021-10

## 1. 原题

图的广度优先遍历算法中使用队列作为其辅助数据结构，那么在算法执行过程中每个顶点进队次数最多为（ ）。

A. $1$

B. $2$

C. $3$

D. $4$

## 2. 答案

**A**（每个顶点进队次数最多为 $1$ 次）。

## 3. 题目分析

- 已知：BFS 以队列作辅助结构；遍历过程带访问标记数组 `visited`；
- 目标：判定"同一个顶点"在整个 BFS（含非连通图的外层循环）中被放入队列的**次数上限**；
- 关键约束：队列在 BFS 中只承担"保存已发现（已标记）但尚未扩展的顶点"这一职责，它不是"候选清单"——一个顶点只有在**第一次**被判定为未访问时才入队；
- 命题意图：检验是否真正理解 `visited` 与 `EnQueue` 的**先后次序**（标记在入队前完成，而不是出队后完成）。这是 BFS 与"某些不做判重的图搜索（如某些求路径条数的 DFS）"的分界点；同时与 DS02.01 中"队列是先进先出的排队结构"呼应——队列在这里保证的是"先被发现的顶点先扩展"，从而得到层次性（DS-2016-14），与进队次数无关。

## 4. 核心考点

核心考点：
DS04.03.02 广度优先搜索（BFS 的队列驱动过程、访问标记 `visited` 的设置时机、每顶点"进队一次、出队一次、访问一次"）

辅助考点：
DS02.01 栈和队列的基本概念（队列在遍历中作辅助结构的角色；本题问"进队次数"，须先弄清队列存的是什么）
DS04.03.01 深度优先搜索（对照项：DFS 的每顶点被"访问"一次，但可能作为递归/入栈候选被多次检查到，判重同样靠 `visited`）

解释：题目字面上在问"队列"，实质在问"BFS 的判重时机"，决定答案的是遍历算法的实现约定而非队列的抽象性质，故主标签取 DS04.03.02；DS02.01 只是术语载体。

## 5. 解题思路

1. 先把教材版 BFS 的循环体拆成两句：**发现邻接点 → 判未访问 → 置标记 → 入队**，看清"置标记"发生在"入队"之前；
2. 抓不变量：`visited[w]` 一经置 `TRUE` 不再复位，且"入队"只出现在"置标记"之后，于是"第 $w$ 个顶点入队"这一动作的前置条件 `!visited[w]` 对固定的 $w$ **至多成立一次**；
3. 由此得上界 $1$；起点自身也是"置标记 + 入队"各一次，故可达顶点恰好进队 $1$ 次，不可达顶点进队 $0$ 次 ⟹ "最多"为 $1$；
4. 用一个小图手工模拟复核（无向图上同一顶点在两个顶点的边表中各出现一次，若不判重就会进队两次，恰好验证判重的作用）；
5. 反推干扰项来源：B、C、D 对应"顶点在邻接表中出现的次数""被扫描到的次数"等不同计量对象，把它们与"进队次数"区分开即可排除。

## 6. 详细解答

**第一步：写出决定性的实现细节**

教材（严蔚敏版）以邻接表存储时的 BFS：

```c
void BFSTraverse(ALGraph G)
{
    for (v = 0; v < G.vexnum; ++v) visited[v] = FALSE;
    InitQueue(Q);
    for (v = 0; v < G.vexnum; ++v)
        if (!visited[v]) {              /* 非连通图：对每个连通分量各起一次 */
            visited[v] = TRUE;
            EnQueue(Q, v);              /* 起点进队：唯一一次 */
            while (!QueueEmpty(Q)) {
                DeQueue(Q, u);
                Visit(u);
                for (p = G.adjlist[u].firstedge; p; p = p->next) {
                    w = p->adjvex;
                    if (!visited[w]) {
                        visited[w] = TRUE;   /* 关键：标记先于入队 */
                        EnQueue(Q, w);       /* 故此处对同一 w 至多执行一次 */
                    }
                }
            }
        }
}
```

**第二步：不变量论证**

对任意固定顶点 $w$，能执行 `EnQueue(Q, w)` 的位置只有两处：作为起点的 `EnQueue(Q, v)` 与循环内的 `EnQueue(Q, w)`，两处**都紧邻在 `visited[w] = TRUE` 之后**。

又 `visited` 在整个 `BFSTraverse` 期间只被置 `TRUE`、从不复位，故 `!visited[w]` 为真的情形一旦耗尽就永久失效。于是

$$\#\{\,w \text{ 进队}\,\}\le 1$$

若 $w$ 与起点连通，则它一定会被发现（它所在连通分量的某次扫描中必碰到它），进队次数恰为 $1$；若不连通，则 $0$ 次。两种情形合起来，"最多"即 $1$。⟹ **A 成立**。

**第三步：手工模拟复核（$4$ 顶点无向图，边 $(1,2),(1,3),(2,3)$，从 $1$ 出发）**

| 步 | 出队 | 扫描到的邻接点 | 判重后入队 | 队列（队头在左） | 各顶点累计进队次数 |
|---|---|---|---|---|---|
| 0 | — | — | $1$（起点） | $[1]$ | $1{:}1$ |
| 1 | $1$ | $2,3$ 均未访问 | $2,3$ | $[2,3]$ | $1{:}1,\ 2{:}1,\ 3{:}1$ |
| 2 | $2$ | $1$ 已访问；$3$ **已访问**（第 1 步入队时已标记） | — | $[3]$ | 全部仍为 $1$ |
| 3 | $3$ | $1,2$ 均已访问 | — | $[\,]$ | 全部为 $1$ |

注意第 2 步：顶点 $3$ 在邻接表中出现两次（$1$ 的链表里、$2$ 的链表里），若"出队时才标记"，它就会在第 2 步再次入队（进队 $2$ 次）——这正是干扰项 B 的来路，但不是教材 BFS 的实现。模拟结果与不变量论证一致：**每顶点进队 $1$ 次**。

**第四步：出队次数与"检查次数"的区分（顺带自证结论不是巧合）**

- 进队 $=1$ 次 ⟹ 出队也 $=1$ 次（队列不重复、不丢失），故 `Visit(u)` 每顶点也只执行 $1$ 次，这正是"遍历"的定义要求（每个顶点被访问且仅被访问一次）；
- 而**邻接点被检查（扫描边结点）的总次数**是 $O(e)$（无向图 $2e$ 个边结点，见 DS-2005-07），与"顶点进队次数"是两个量——本题问的是后者。

**答案**：A。

## 7. 选项分析

- A（$1$）：**正确**。判重在入队前完成 ⟹ 每顶点至多进队一次；可达顶点恰好一次，不可达零次；
- B（$2$）：错误。这是"标记放在出队之后"的错误实现所得结果，或在无向图中把"一个顶点在两条边结点中出现两次"误当成进队两次（边 $(1,2)$ 使 $2$ 入队、边 $(2,3)$ 之外还有 $(1,3)$ 使 $3$ 被第二次检查到，但检查≠进队）；
- C（$3$）：错误。$3$ 通常来自"该顶点度为 $3$，会被 $3$ 个邻接点各检查一次"这种误算，计的是扫描次数；
- D（$4$）：错误。同上，且 $4$ 无任何标准量与之对应（既不是进队次数，也不是无向图边结点数 $2e$ 的关系），属凑数选项。

## 8. 考场标准答案

选 **A**。

理由：BFS 的队列只存放"已发现而未扩展"的顶点，实现中对每个邻接点 $w$ 都是先判 `!visited[w]`、随即 `visited[w]=TRUE`、然后 `EnQueue(w)`。由于标记不会复位，条件 `!visited[w]` 对同一顶点至多成立一次，故每个顶点**最多进队 $1$ 次**（可达则恰 $1$ 次，不可达则 $0$ 次），出队亦为 $1$ 次。

一句话记法：**进队一次、出队一次、访问一次；边被扫多次，点只进队一次。**

## 9. 易错点

1. **把"被检查次数"当成"进队次数"**：无向图顶点 $w$ 在邻接表中出现 $d(w)$ 次，会被 $d(w)$ 条边结点检查到，但只有第一次检查（`visited` 仍为假）才导致入队；
2. **误以为起点不进队**：起点同样"标记 + 入队 + 出队"各一次，队列空是遍历结束的标志，不能把起点排除在计数之外；
3. **与非连通图混淆**：外层 `for` 会对每个连通分量重新起队，但每个顶点只属于一个连通分量，总进队次数仍不超过 $1$（不会因为"多个分量"而累加）；
4. **与 DFS 的结论混用**：DFS 用栈/递归，每个顶点被**访问**一次，但作为递归候选可能被多次检查；"每点一次"是访问语义上的共同点，"进队/进栈"的实现细节不同；
5. **忽略本题的实现前提**：若真按"出队时才标记"写代码，进队次数可以超过 $1$（最坏与度有关），因此作答时要按教材标准实现——这一点是本题唯一的口径依赖处，已在本解析第 6 节代码中写明。

## 10. 一句话规律

凡是"队列/栈里会不会重复出现同一个顶点"的问题，只看一句：**判重标记是在入队（入栈）之前置位，还是之后**——之前置位则每顶点至多进一次。
