# DS-2021-26

## 1. 原题

假设称正读和反读都相同的字符序列为"回文"，例如，$abba$ 和 $abcba$ 是回文，$abcde$ 和 $ababab$ 则不是回文，下面代码判别读入的一个以 `@` 为结束符的字符序列是否是"回文"。请给出缺失的 $5$ 行代码。

```c
Status SymmetryString(char* p)
{
    Queue q;
    if(!InitQueue(q)) 
        return 0;
    Stack s;
    InitStack(s);
    ElemType e1,e2;
    while(___________(1)__________)
    {
        Push(s,*p);
        EnQueue(q,*p);
        ___________(2)__________;
    }
    while(!StackEmpty(s))
    {
        ___________(3)__________;
        ___________(4)__________;
        if(___________(5)__________)
            return FALSE;
    }
    return OK;
}
```

## 2. 答案

| 空位 | 填写内容 | 作用 |
|---|---|---|
| (1) | `*p != '@'` | 以结束符 `@` 为界控制读入（`@` 本身不入栈不入队） |
| (2) | `p++` | 指针后移，读下一个字符 |
| (3) | `Pop(s, e1)` | 出栈：取**逆序**方向的第 $i$ 个字符 |
| (4) | `DeQueue(q, e2)` | 出队：取**顺序**方向的第 $i$ 个字符 |
| (5) | `e1 != e2` | 正读与反读的第 $i$ 位不同 ⟹ 不是回文，返回 `FALSE` |

（(3)(4) 两行互换不影响正确性，因为二者互不依赖。）

## 3. 题目分析

- 已知：字符指针 `p` 指向以 `@` 结束的字符序列；已初始化好的一个栈 `s` 与一个队列 `q`；`e1,e2` 为 `ElemType`（字符）型局部变量；函数返回 `Status`（`OK`/`FALSE`）；
- 目标：补全 $5$ 行，使函数实现"回文判定"；
- 关键约束：
  1. 骨架已给定：**第一段 `while` 把每个字符同时压栈和入队**，第二段 `while(!StackEmpty(s))` 边出栈边出队并比较——命题者已锁定"用栈得到逆序、用队列得到顺序"这一算法路线，填空只需还原语义，不需要另设计；
  2. 循环条件写的是 `!StackEmpty(s)`，说明第二段以栈取空为终止；由于栈、队列中字符个数始终相同，不必再判队列空；
  3. 判不等时 `return FALSE`、全部相同才 `return OK`，故 (5) 必须填"**不相等**"这一条件（写成 `e1 == e2` 会把结论完全颠倒）；
  4. `@` 是结束符而不是串内容，(1) 必须保证 `@` 不被 `Push`/`EnQueue`，否则参与比较、且指针会越界；
- 命题意图：把 DS02.01 的两大特性（**栈后进先出、队列先进先出**）合成一个"同一份数据两种访问次序"的对偶结构，考查学生能否看出 `e1` 是"从尾往头读"、`e2` 是"从头往尾读"，从而把"回文"这个"正读反读相同"的定义机械翻译成"逐位相等"。

## 5. 解题思路

1. **先读懂骨架的意图**：第一段循环对每个字符做 `Push(s,*p); EnQueue(q,*p);`——同一字符同时进两个结构，说明命题者要"存两份"；指针推进 `p++` 只能放在 (2)；
2. **确定比较的方向**：第二段要"每次各取出一个字符比较"。栈顶取出的是**最后进入**的字符（逆序第 $1$ 个），队头取出的是**最先进入**的字符（顺序第 $1$ 个）；两者第 $1$ 次比较即 $c_n$ 与 $c_1$，第 $2$ 次 $c_{n-1}$ 与 $c_2$……恰好是"反读 vs 正读"的逐位对照 ⟹ (3)(4) 是 `Pop` 与 `DeQueue`；
3. **确定结论的极性**：`if(_____) return FALSE;` 位于比较处，故条件应为"这一对不相等" ⟹ `e1 != e2`；
4. **补边界**：(1) 处填 `*p != '@'`，使 `@` 不入结构、空序列（第一个字符就是 `@`）时两个循环都不执行而直接 `return OK`（空序列是回文）；
5. **用三组样例走查验证**（见第 6 节）：偶长回文 `abba@`、非回文 `abcda@`、空序列 `@`，并检查比较次数与提前返回行为。

## 6. 详细解答

### 补全后的完整代码

```c
Status SymmetryString(char* p)
{
    Queue q;
    if(!InitQueue(q)) 
        return 0;
    Stack s;
    InitStack(s);
    ElemType e1,e2;
    while(*p != '@')            /* (1) 未到结束符则继续读入 */
    {
        Push(s,*p);             /* 每个字符同时进栈（供逆序取出）*/
        EnQueue(q,*p);          /* 同时进队（供顺序取出）*/
        p++;                    /* (2) 指针后移，读下一个字符 */
    }
    while(!StackEmpty(s))       /* 栈空即全部字符比较完毕 */
    {
        Pop(s, e1);             /* (3) 出栈：逆序方向取第 i 个字符 */
        DeQueue(q, e2);         /* (4) 出队：顺序方向取第 i 个字符 */
        if(e1 != e2)            /* (5) 正读反读第 i 位不同 → 非回文 */
            return FALSE;
    }
    return OK;
}
```

### 算法正确性说明

设读入的字符序列为 $c_1c_2\cdots c_n$（`@` 之前）。

- 入栈后栈内自顶向下为 $c_n,c_{n-1},\cdots,c_1$，故第 $i$ 次 `Pop` 得 $e_1=c_{n-i+1}$；
- 入队后队列自头至尾为 $c_1,c_2,\cdots,c_n$，故第 $i$ 次 `DeQueue` 得 $e_2=c_i$；
- 第 $i$ 次比较即 $c_{n-i+1}$ 与 $c_i$，$i=1,2,\cdots,\lceil n/2\rceil$ 时覆盖全部对称位对（$i>n/2$ 后与前面重复，但仍相等，不影响结论）；
- 因此“只要有**一次**比较出现 $e_1\ne e_2$ 就 `return FALSE`” ⟺ 存在 $i$ 使 $c_i\ne c_{n-i+1}$ ⟺ 序列不是回文；反之循环正常结束 ⟺ $\forall i,\ c_i=c_{n-i+1}$ ⟺ 序列是回文 ✓

### 走查 1：`abba@`（偶长回文，应返回 OK）

| 步骤 | 动作 | 栈（顶→底） | 队（头→尾） | $e_1$ | $e_2$ | 比较 |
|---|---|---|---|---|---|---|
| 读入 | `Push/EnQueue` a | a | a | | | |
| 读入 | b | b,a | a,b | | | |
| 读入 | b | b,b,a | a,b,b | | | |
| 读入 | a | a,b,b,a | a,b,b,a | | | |
| 遇 `@` | (1) 假，退出读入循环 | | | | | |
| 第 1 次 | 出栈/出队 | b,b,a | b,b,a | a | a | 相等 |
| 第 2 次 | 出栈/出队 | b,a | b,a | b | b | 相等 |
| 第 3 次 | 出栈/出队 | a | a | b | b | 相等 |
| 第 4 次 | 出栈/出队 | 空 | 空 | a | a | 相等 |
| 结束 | 第 4 次出栈后栈空，`StackEmpty(s)` 真 | | | | | **return OK** ✓ |

### 走查 2：`abcda@`（非回文，应返回 FALSE）

栈顶→底 `a,d,c,b,a`，队头→尾 `a,b,c,d,a`。
第 1 次：$e_1=a,e_2=a$ 相等；第 2 次：$e_1=d,e_2=b$ **不等** ⟹ `return FALSE` ✓（此时剩余字符不再检查，属正确的提前退出）。

### 走查 3：`@`（空序列，应返回 OK）

(1) 首次判断即为假，两个循环都不执行，直接 `return OK` ✓（空序列正读反读相同，是回文）。

### 走查 4：`abcba@`（奇长回文，中间字符自比）

栈 `a,b,c,b,a`（顶→底），队 `a,b,c,b,a`。比较对依次为 $(a,a),(b,b),(c,c),(b,b),(a,a)$，全部相等 ⟹ `return OK` ✓。最中间字符 $c_3=$`c` 与自身比较，恒等，无需特判。

### 各空位的其他可接受写法

- (1) 亦可写 `*p!='@' && *p!='\0'`（若担心串中没有 `@`，但按题面"以 `@` 为结束符"，`*p != '@'` 即标准答案）；写成 `p != '\0'`（比较指针与字符）是**类型错误**；
- (2) `p++`、`++p`、`p = p + 1` 等价；若误写 `p--` 则死循环；
- (3)(4) 若教材版本采用返回值形式，可写 `e1 = Pop(s);` / `e2 = DeQueue(q);`；两行顺序可互换；但若 (3) 写成 `GetTop(s,e1)` 而不 `Pop`，栈永不腾空 ⟹ 死循环（`while(!StackEmpty(s))` 的条件不会变假）；
- (5) 只能填"不等"形式：`e1 != e2`（`e1 == e2` 会把回文判成非回文）。

## 8. 考场标准答案

```
(1) *p != '@'
(2) p++
(3) Pop(s, e1)
(4) DeQueue(q, e2)
(5) e1 != e2
```

一句话理由：栈把入序**倒过来**、队列把入序**保持原样**，于是"出栈序列"就是反读、"出队序列"就是正读；逐位比较，一旦 `e1 != e2` 即不是回文；`@` 只作结束标志，不参与比较。

复杂度：设串长为 $n$，读入 $n$ 次、比较至多 $n$ 次，时间 $O(n)$；栈与队列各存 $n$ 个字符，空间 $O(n)$。（若改用"快慢指针 + 原地逆置"的解法可做到 $O(1)$ 附加空间，但本题骨架已限定为栈+队列。）

## 9. 易错点

1. **(5) 的比较方向写反**（填 `e1 == e2`）：骨架是"命中即 `return FALSE`"，填成相等就把回文判为非回文，这是本题最常见的失分点；
2. **(1) 写成 `p != '@'`**：`p` 是 `char*`，`*p` 才是当前字符；漏写解引用后循环条件恒假或恒真（取决于实现），且 `@` 会被读入结构；
3. **把 `@` 也压栈入队**：则 `@` 会与末位字符比较，任何串都会因 `@` 与首字符不等而判为非回文；
4. **(3) 用 `GetTop` 代替 `Pop`**：只取栈顶不弹出，栈永不为空，第二个 `while` 死循环；
5. **误以为要判队列空**：第二段循环条件已给定 `!StackEmpty(s)`，由于两结构元素数恒等，无需再判 `!QueueEmpty(q)`；若自己另写循环条件反而可能与骨架冲突；
6. **忘了 (2) 是指针推进**：`p++` 只能写在读入循环内，若写进比较循环则第一个循环永不终止。

## 10. 一句话规律

"正读反读是否相同"这类题的通用构造：**同一序列同时进栈和进队，再同步出栈、出队逐位比较**——栈给逆序、队列给顺序，一次配对即一次对称检查；凡是"命中即 `return FALSE`"的骨架，比较条件一定要填"不等"。
