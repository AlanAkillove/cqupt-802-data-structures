# DS-2005-19

## 1. 原题

**19、** 理想情况下，在散列表中查找一个元素的时间复杂度为 $O(1)$ 。（）

## 2. 答案

√（正确）

## 3. 题目分析

- 已知：散列（哈希）表查找，限定条件为"理想情况"；
- 目标：判断其时间复杂度是否为 $O(1)$（与表长 $m$、元素个数 $n$ 无关的常数阶）；
- 关键约束：散列查找的代价 = 计算散列函数 + 沿冲突探测链的比较次数；"理想情况"即**不产生冲突**（或装填因子 $\alpha=n/m$ 保持为小于 1 的常数，平均探测长度有界），此时比较次数不随 $n$ 增长；
- 命题意图：考"散列法之所以特殊，是因为它绕过了比较/判定的下界 $\log_2 n$，直接把关键字换算成地址"这一核心思想，并要求区分"理想情况"与"最坏情况（全部冲突）"。

## 4. 核心考点

核心考点：
DS05.06.01 散列函数与冲突处理方法（散列寻址的直接定址特性、冲突对查找长度的影响）

辅助考点：
DS05.01 查找的基本概念（平均查找长度 ASL 与时间复杂度的关系）

解释：本题判定"复杂度阶"，需把"比较次数"这一 ASL 概念与 $O(\cdot)$ 记号挂钩；而决定比较次数的正是冲突是否发生，故主考点落在冲突处理一侧。

## 5. 解题思路

1. 写出散列查找的过程：$addr=H(key)$ → 访问 $T[addr]$ → 命中则结束，冲突则按探测策略（线性探测/二次探测/链地址）继续；
2. 取"理想情况"的第一种口径：**无任何冲突** ⟹ 每个关键字的 $H(key)$ 互不相同，查找至多比较 1 次 ⟹ $O(1)$；
3. 取第二种口径（更一般的"理想"）：装填因子 $\alpha=n/m$ 固定（$<1$），用教材给出的 ASL 公式验证其与 $n$ 无关，仅为 $\alpha$ 的常数函数；
4. 反向确认边界：若表被填满或所有关键字同义词（$H$ 值全相同），退化为 $O(n)$（线性探测）或 $O(n)$（链地址中的单链），但那不是"理想情况"，题干已排除；
5. 结论：√。

## 6. 详细解答

**算法过程（以线性探测再散列为例）**

```c
int HashSearch(HashTab HT, KeyType key)     /* HT.m 为表长, 空单元标记为 0 */
{
    int d0 = H(key), d = d0, i = 1;
    while (HT.elem[d] != 0 && HT.elem[d].key != key) {
        d = (d0 + i) % HT.m;                /* 线性探测下一地址 */
        if (++i > HT.m) return FAIL;        /* 探测整表未命中 */
    }
    return (HT.elem[d].key == key) ? d : FAIL;
}
```

比较次数 = 探测的单元数。

**口径一：无冲突（最字面的"理想情况"）**
若表内所有关键字的象 $H(key)$ 两两不同，则待查关键字（若在表中）一次命中，比较次数 $=1$；若不在表中且该地址为空，也是 $1$ 次即可判定失败。故时间复杂度 $=O(1)$，与 $n$ 无关。

**口径二：装填因子 $\alpha=\dfrac{n}{m}$ 为常数（教材给出的平均性能）**
严蔚敏教材对散列表查找平均长度的结论（线性探测再散列）为

$$S_{\text{成功}} \approx \frac{1}{2}\Big(1+\frac{1}{1-\alpha}\Big),\qquad S_{\text{失败}} \approx \frac{1}{2}\Big(1+\frac{1}{(1-\alpha)^{2}}\Big)$$

链地址法为 $S_{\text{成功}}\approx 1+\frac{\alpha}{2}$、$S_{\text{失败}}\approx \alpha$（不同教材常数项略有差异）。
关键结构：**这些表达式只含 $\alpha$，不含 $n$。** 散列表的固有设计原则是"表长 $m$ 与元素个数 $n$ 同阶增长"（即 $\alpha$ 取常数，如 $0.6\sim0.9$），于是 $S$ 是与规模无关的常数 ⟹ 平均时间复杂度 $O(1)$。

**与比较树下界的对照（说明这不是"另一个更快的算法"而是换了寻址方式）**
顺序查找 $O(n)$、折半查找 $O(\log_2 n)$ 都建立在"关键码之间可比较、需逐次缩小范围"的模型上；散列法把关键字经 $H$ 直接算成**地址**，跳过了比较过程，因此可以突破 $\log_2 n$ 的下界。代价是空间（$m>n$）与冲突处理。

**最坏情况（题干已排除，仅作对照）**：若 $n$ 个关键字全部映射到同一象（同义词冲突），线性探测时查最后一个插入的元素需比较 $n$ 次，链地址法退化为长度为 $n$ 的单链，复杂度 $O(n)$。可见"$O(1)$"依赖于"$H$ 分布均匀 + $\alpha$ 受控"这两个"理想"前提。

**结论**：√。

## 8. 考场标准答案

√。散列查找先由 $H(key)$ 直接算出地址，理想情况（不产生冲突，或装填因子 $\alpha=n/m$ 保持为小于 1 的常数）下比较次数为常数：线性探测时 $S_{成功}\approx\frac12\big(1+\frac{1}{1-\alpha}\big)$、链地址法时 $S_{成功}\approx1+\frac{\alpha}{2}$，均与元素个数 $n$ 无关，故时间复杂度为 $O(1)$。最坏情况（全部同义词冲突）才退化为 $O(n)$。

## 9. 易错点

1. 忽略"理想情况"四字而答 ×：散列**最坏**确为 $O(n)$，但题干已限定理想条件，问的是该方法的平均/理想性能；
2. 把 $O(1)$ 误解为"不需要计算散列函数"：$H(key)$ 的计算本身是常数时间（除留余数等），若散列函数涉及长串遍历则其代价要计入 $O(1)$ 的常数；
3. 忘记 $\alpha$ 是"常数"而非"很小"：$\alpha\to1$ 时 $S_{失败}$ 会急剧增大（分母 $(1-\alpha)^2$），但仍是与 $n$ 无关的常数；真正的退化是表满；
4. 与本年度 DS-2005-09（装填因子越小则……）混淆口径：装填因子小 ⟹ 冲突少 ⟹ 平均查找长度小，两者是同一件事的两个问法。

## 10. 一句话规律

散列表的 $O(1)$ 来自"关键字→地址"的直接换算，其成立条件是"散列函数均匀 + 装填因子有界"；判断散列性能题先看题干给的是理想（平均）口径还是最坏口径。

## 11. 关联知识

- 装填因子 $\alpha$ 是散列表性能的唯一综合参数，冲突处理方法的差异也体现在 ASL 上，故本题与 DS-2005-09 构成同一知识组；
- 散列不支持顺序访问与范围查询，折半查找/BST 支持（本题库中 DS-2005-23 涉及 BST 的有序性）；
- 教材中散列表的 ASL 计算（成功/失败两口径）属 DS05.06.02，是本题结论的定量练习形式。
