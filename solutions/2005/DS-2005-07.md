# DS-2005-07

## 1. 原题

对于一个具有 $n$ 个顶点和 $e$ 条边的无向图，若采用邻接表表示，则所有邻接表中的结点总数为____________________。

## 2. 答案

$2e$ 个（边表结点/表结点）。
若把 $n$ 个表头结点（顶点向量）一并计入，则整个邻接表结构的结点总数为 $n + 2e$；本题问"邻接表**中**的结点"，取 $2e$。

## 3. 题目分析

- 已知：无向图，顶点数 $n$，边数 $e$；存储结构为邻接表；
- 目标：所有邻接链表中的结点总数；
- 关键事实：无向图的每条边 $(u,v)$ 同时进入 $u$ 的链表和 $v$ 的链表，**被存两次**；
- 命题意图：考邻接表的存储代价分析——"边表结点总数 = 各顶点度数之和"，并与有向图（只存出边，共 $e$ 个弧结点）作对比。

## 4. 核心考点

核心考点：
DS04.02.02 邻接表法（顶点表 + 边表的两级结构、无向图的对称存储）

辅助考点：
DS04.01 图的基本概念（握手定理 $\sum_{v}\deg(v) = 2e$）

解释：邻接表中第 $i$ 个链表挂的就是顶点 $i$ 的全部邻接点，链表结点数 $=\deg(i)$；因此"所有邻接表的结点总数"就是"所有顶点度数之和"，直接由握手定理给出 $2e$。

## 5. 解题思路

1. 把"邻接表中的结点"翻译成数学量：第 $i$ 个链表结点数 $=\deg(v_i)$；
2. 求和：$\sum_{i=1}^{n}\deg(v_i)$；
3. 用握手定理：无向图中每条边为两个端点各贡献 1 度，故总和 $=2e$；
4. 画一个 3 顶点 3 边的小图手工数结点验证。

## 6. 详细解答

**结构回顾**（教材风格定义）：

```c
typedef struct ArcNode {          // 边表结点（表结点）
    int adjvex;                   // 该边另一端点的位置
    struct ArcNode *nextarc;
} ArcNode;

typedef struct VNode {            // 表头结点（顶点向量元素）
    VertexType data;
    ArcNode *firstarc;
} VNode, AdjList[MAXVEX];
```

**推导**：设无向图 $G=(V,E)$，$|V|=n$，$|E|=e$。顶点 $v_i$ 的邻接链表中，每个邻接点占一个 `ArcNode`，故该链表结点数为 $\deg(v_i)$。所有链表结点总数

$$T = \sum_{i=1}^{n} \deg(v_i) = 2e$$

最后一个等号即**握手定理**：每条边 $(v_i,v_j)\in E$ 恰好贡献 $\deg(v_i)$ 与 $\deg(v_j)$ 各 1，即被计入 2 次。

**手算验证**：取三角形图 $V=\{0,1,2\}$，$E=\{(0,1),(1,2),(0,2)\}$，$n=3,e=3$。

```
0: [1] -> [2]
1: [0] -> [2]
2: [1] -> [0]
```

边表结点共 $6 = 2\times 3 = 2e$ ✓；三个顶点度数分别为 $2,2,2$，和为 $6$ ✓。

**再验一例（不规整）**：$n=4$，$e=2$，边 $(0,1),(2,3)$（非连通也成立）：各链表长度 $1,1,1,1$，共 $4 = 2\times 2$ ✓。

**有向图对比**：若为 $n$ 顶点 $e$ 弧的有向图，邻接表只存**出弧**，结点总数为 $e$（即 $\sum \text{out-degree} = e$）；这正是无向图与有向图在邻接表空间上的关键差异。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

$$2e$$

（每条无向边在两个端点的链表中各存一个边结点；$\sum_{i}\deg(v_i)=2e$。）

## 9. 易错点

1. 答成 $e$——那是**有向图**邻接表（只存出弧）的结果，无向图必须乘 2；
2. 答成 $n+2e$ 或 $n$——把顶点向量中的 $n$ 个**表头结点**与边表结点混计；本题"邻接表中的结点"指边表结点，若题目明确问"邻接表结构所含结点总数"才计头结点；
3. 忘记邻接表的结点数与 $n$ 无关，只由 $e$ 决定（$n$ 是干扰量）。

## 10. 一句话规律

邻接表空间分析一律落到"$\sum$ 度（或 $\sum$ 出度）"，再用握手定理换成 $2e$（有向图 $e$），比记结论稳。

## 11. 关联知识

- 邻接矩阵法：$n^2$ 个元素，与 $e$ 无关 → 稠密图宜用矩阵，稀疏图（$e \ll n^2$）宜用邻接表；
- 求无向图各顶点度数：邻接表需遍历链表 $O(n+2e)$，邻接矩阵需扫行 $O(n^2)$；
- 十字链表（DS04.02.03）正是为弥补邻接表"有向图不便查入度"而设。
