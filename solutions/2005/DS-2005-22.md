# DS-2005-22

## 1. 原题

**22、** 将两个各有 $n$ 个元素的有序表归并成一个有序表，最少需要比较（）次。

A. $n-1$

B. $n$

C. $2n-1$

D. $2n$

## 2. 答案

答案：**B**（$n$ 次）

## 3. 题目分析

- 已知：两个**有序**（设非降）表 $A=(a_1\le\cdots\le a_n)$、$B=(b_1\le\cdots\le b_n)$；用标准两路归并（双游标逐个取小者）得到长度 $2n$ 的有序表；
- 目标：**最少**比较次数（最好情形）；
- 关键约束：① 每次两元素比较至多把**一个**元素写入结果表；② 一旦某个表被取空，另一表的剩余元素可**直接整段搬移，不再比较**；
- 命题意图：考"归并操作的比较次数区间 $[n,\,2n-1]$"，并区分"最少"与"最多"（$2n-1$ 是另一问法）。

## 4. 核心考点

核心考点：
DS01.03 线性表的应用（有序表的合并——顺序表与链表同法）

辅助考点：
DS06.08 二路归并排序（归并操作 `Merge` 正是其基本步骤，比较次数即其代价度量）

解释：本题的运算对象是"两个有序线性表"，操作即教材线性表应用一节给出的有序表合并算法；该算法又是归并排序的趟内操作，故两节点都相关，主结构取线性表应用。

## 5. 解题思路

1. 写出标准归并的循环结构，明确"比较 ⟺ 从两表各选一"的对应关系；
2. **构造最好情形**：让两表关键字值域完全不重叠（$A$ 全部 $<B$ 的全部），此时 $A$ 的 $n$ 个元素逐个与 $b_1$ 比较后全部取出，$A$ 空 ⟹ 恰 $n$ 次比较；
3. **证明不能更少**：设比较 $c$ 次。归并终止时必有一表剩余元素被无比较搬移，即存在一个表（不妨 $A$）是"被比较逐个取空"的：$A$ 的 $n$ 个元素每个至少赢得一次比较，而每次比较至多取走一个元素 ⟹ $c\ge n$；
4. 上下界合流：最少 $=n$，选 B；顺带核对 $2n-1$ 是**最多**比较次数（两表交错时）。

## 6. 详细解答

**算法（顺序表版，链表同理）**

```c
void Merge(RcdType R[], int low, int mid, int high, RcdType T[])
{   /* 把有序表 R[low..mid] 与 R[mid+1..high] 归并到 T[low..high] */
    int i = low, j = mid + 1, k = low;
    while (i <= mid && j <= high) {                 /* 每轮 1 次比较，输出 1 个元素 */
        if (R[i].key <= R[j].key) T[k++] = R[i++];
        else                      T[k++] = R[j++];
    }
    while (i <= mid)  T[k++] = R[i++];              /* 剩余段搬移，不再比较 */
    while (j <= high) T[k++] = R[j++];
}
```

**上界构造（$n$ 次可达）**
取 $A=(1,2,\dots,n)$、$B=(n+1,n+2,\dots,2n)$：

| 比较次数 | 比较的元素 | 输出 | 游标状态 |
|---|---|---|---|
| 1 | $a_1=1$ vs $b_1=n+1$ | $1$ | $i=2,j=1$ |
| 2 | $a_2=2$ vs $b_1$ | $2$ | $i=3,j=1$ |
| $\vdots$ | $\vdots$ | $\vdots$ | $\vdots$ |
| $n$ | $a_n=n$ vs $b_1$ | $n$ | $i=n+1$（$A$ 空），$j=1$ |

第 $n$ 次比较后 `i<=mid` 不成立，退出第一循环，$B$ 的 $n$ 个元素整段搬移（零比较）。总计**恰好 $n$ 次**。

**下界证明**
设某次归并共比较 $c$ 次。第一循环每轮**恰执行一次比较并恰输出一个元素**，故第一循环共输出 $c$ 个元素；其后剩余元素在无比较的搬移循环中输出。
归并结束时两表都空。若 $A$ 是靠搬移循环清空的，说明进入搬移时 `j > high`，即 $B$ 已在前 $c$ 次比较中被取空 ⟹ $B$ 的 $n$ 个元素全部由比较产生（每个元素被输出时都消耗了它参与的那次比较），故 $c\ge n$；同理若 $B$ 靠搬移清空，则 $c\ge n$。
剩下的可能是"两表在 $c$ 次比较后同时空"：不可能，因为每次比较只输出一个元素，输出 $c$ 个元素最多消耗一个表的 $n$ 个加上另一表的 $c-n$ 个；要使两表同时空需 $c=2n$，而第 $2n$ 次比较前每表各余 1 个元素，该次比较必输出一表的那个元素并使该表空、循环条件立刻失败，另一表的元素只能进入搬移——即此时 $c=n+(\text{另一表已取数})$，仍有一表经过搬移。综上必有 $c\ge n$。

**结论**：最少比较次数 $=n$，选 **B**。

**对照：最多比较次数**
当两表元素在值域上完全交错（如 $A=(1,3,5,\dots,2n-1)$、$B=(2,4,6,\dots,2n)$）时，每轮比较只能送走一个元素，直到某一表只剩最后 1 个元素时还需一次比较定胜负；总次数 $=(2n-1)$。一般结论：

$$n\ \le\ \text{比较次数}\ \le\ 2n-1$$

故 C 是"最多"的答案，D 超出上界不可能，A 低于下界不可能。

## 7. 选项分析

- **A（$n-1$）**：错。低于下界——被取空的那个表的 $n$ 个元素各需至少一次比较，$n-1$ 次比较至多输出 $n-1$ 个元素，无法清空任一表（$n\ge1$）；$n-1$ 常见于"$n$ 个元素的有序表内部/连通图最少边数"等别的计数模型，此处易混；
- **B（$n$）**：**正确**。$A$ 的最大值小于 $B$ 的最小值时取得（第 6 节构造），并有下界证明支撑；
- **C（$2n-1$）**：错（答非所问）。这是**最多**比较次数，出现在两表元素交错的情形；题目问"最少"；
- **D（$2n$）**：错。超过上界 $2n-1$：最后一次比较之后必有一个表的剩余元素靠搬移输出，不可能对每个元素都比较两次。

## 8. 考场标准答案

选 **B**。
两表 $A,B$ 各 $n$ 个元素，归并时每一轮"比较一次、输出一个元素"，某一表被取空后另一表剩余元素无需比较直接搬移。最好情形：$A$ 的全部元素都小于 $B$ 的最小元素（如 $A=1..n$，$B=n+1..2n$），$A$ 的 $n$ 个元素依次与 $b_1$ 比较后全部取出，共 $n$ 次比较，之后 $B$ 整段搬移。故最少 $n$ 次。（最多 $2n-1$ 次。）

## 9. 易错点

1. 把"最少"看成"最多"而选 C——本题两问都常见，务必盯住题干关键字；
2. 误选 A：以为"$2n$ 个元素排好序只需 $2n-1$ 次关系判定"这类直觉，忽略了"必须把某一表的 $n$ 个元素逐个比较掉才能触发免比较搬移"；
3. 忘记"剩余段免比较"这一优化：若写成"每次比较后仍逐个判断"的低效实现，次数会虚高；
4. 表长不等时（$n_1\le n_2$）区间应为 $[n_1,\ n_1+n_2-1]$，不要死记 $n$。

## 10. 一句话规律

归并类计数题盯住两条：每轮比较恰输出一个元素、某表空后剩余免比较——于是"最少 = 短表长度""最多 = 两表长度和 − 1"。

## 11. 关联知识

- 有序表合并是教材线性表应用的代表算法（顺序表版需额外 $O(m+n)$ 辅助空间；链表版可原地重排指针，仅需 $O(1)$ 附加空间，见本年度 DS-2005-03 双向链表结点结构一类链表操作题）；
- 二路归并排序把长度 $2n$ 的表自底向上逐趟归并，趟数 $\lceil\log_2\text{段数}\rceil$、每趟比较总量 $O(n)$，总时间 $O(n\log n)$、辅助空间 $O(n)$——正是本年度 DS-2005-26 的考点（四选项中归并排序辅助空间最多）；
- 归并的稳定来自"相等时取左表元素"（上面代码中的 `<=`）。
