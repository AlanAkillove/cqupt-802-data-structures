# DS-2005-02

## 1. 原题

在一个循环队列中，队头指针指向队头元素的____________________。

## 2. 答案

**前一个位置**（即队头元素的前驱位置）。

> 本题为约定依赖型概念题，详见第 12 节说明。

## 3. 题目分析

- 已知：循环队列（顺序存储 + 模运算回绕）；
- 目标：填出队头指针 `front` 相对于**队头元素**所指的位置；
- 约束：循环队列有两种主流指针约定——(A) `front` 指向队头元素本身、`rear` 指向队尾元素的下一位置；(B) `front` 指向队头元素的前一个位置、`rear` 指向队尾元素本身。两种约定下队空条件同为 `front == rear`，但队满条件的判法不同；
- 命题意图：考"循环队列的指针语义"这一基本概念。

## 4. 核心考点

核心考点：
DS02.02 栈和队列的顺序存储结构（循环队列中 `front`/`rear` 的确切指向）

辅助考点：
DS02.01 栈和队列的基本概念（队头/队尾的逻辑定义）

解释：循环队列的全部运算（入队、出队、判空、判满）都建立在"两个指针各自指向哪里"这一约定之上，指向不清则后续所有下标计算都会错一位。

## 5. 解题思路

1. 先审题干措辞：题目已经说出"指向**队头元素的**____"，说明空格处要填的是一个**相对位置**，而不是"队头元素"本身；
2. 若采用约定 (A)（`front` 指向队头元素本身），题干应写成"队头指针指向____"，空格填"队头元素"，与本题句式不符；
3. 故出题人采用约定 (B)：`front` 指向队头元素的前一个位置，空格填"前一个位置"；
4. 一致性检验：约定 (B) 下出队操作为 `front = (front+1) % M; x = Q.base[front];`，入队操作为 `rear = (rear+1) % M; Q.base[rear] = x;`，`front == rear` 恰表示队空——三件事互相自洽，说明该约定成立。

## 6. 详细解答

设数组长度为 $M$，队头元素所在下标为 $h$。

**约定 (B)（本题采用的约定）**：`front` 指向队头元素的前一个位置，即

$$front = (h - 1 + M) \bmod M$$

- 出队：`front = (front + 1) % M;` 后 `base[front]` 即为被删的队头元素；
- 入队：`rear = (rear + 1) % M; base[rear] = x;`，`rear` 始终指向队尾元素；
- 队空：`front == rear`（`rear` 回绕追上 `front` 的"前一个位置"这一说法不成立，实际是当队列中无任何元素时二者重合于同一位置）；
- 队满：约定 (B) 常配合"牺牲一个存储单元"判满，条件为 `(rear + 1) % M == front`。

**约定 (A)（严蔚敏教材的约定）**：`front` 直接指向队头元素，`rear` 指向队尾元素的**下一个**位置；此时若问"队头指针指向什么"，答案是"队头元素本身"。

两种约定的取舍只能由题干句式决定。本题句式为"指向队头元素的____"，只能填相对位置，故取约定 (B)，答案为**前一个位置**。

## 8. 考场标准答案

前一个位置（队头元素的前驱位置）。

## 9. 易错点

1. 直接照搬严蔚敏教材"front 指向队头元素"填"本身"，与题干"队头元素的___"句式冲突；
2. 把循环队列的 `front` 与链队的 `front`（链队的头指针必然指向队头结点/头结点）混为一谈；
3. 记住指向后仍写错出入队语句的下标顺序（应"先移指针再存取"还是"先存取再移指针"取决于约定）。

## 10. 一句话规律

循环队列的指针题，**先由题干措辞锁定约定，再据此推出队空/队满条件与出入队语句**，切忌把两套约定的结论混用。

## 11. 关联知识

- 队列长度（约定 B、牺牲一格判满）：$L = (rear - front + M) \bmod M$；
- 判满的另一路数是增设 `size` 或 `tag` 标志，此时即使 `front` 指向队头元素本身也不会产生歧义。
