# DS-2005-11

## 1. 原题

线性表的逻辑顺序与存储顺序总是一致的。（）

## 2. 答案

×（错误）。顺序存储时一致，链式存储时**不一定**一致，故"总是"不成立。

## 3. 题目分析

- 已知：命题"线性表的逻辑顺序与存储顺序**总是**一致"；
- 目标：判真假；
- 关键概念：**逻辑顺序**指元素在线性表中的先后次序（$a_i$ 是 $a_{i+1}$ 的前驱）；**存储顺序**指元素在内存中的物理地址先后次序；
- 命题意图：考"顺序存储 vs 链式存储"的本质区别——是否用物理相邻表达逻辑相邻。

## 4. 核心考点

核心考点：
DS01.01 线性表的基本概念（逻辑结构与存储结构的对应关系）

辅助考点：
DS01.02.01 顺序存储（物理相邻 ⇔ 逻辑相邻，两者一致）
DS01.02.02 链式存储（物理任意，靠指针维持逻辑次序，两者可不一致）

解释：本题与 DS-2005-10 同源，只是从"存储形式是否唯一"换成"逻辑次序是否总等于物理次序"，判据都是链式存储的存在。

## 5. 解题思路

1. 命题含绝对量词"总是"，只需找一个反例；
2. 链式存储的定义明确允许"一组**任意**的存储单元"——地址可离散、可递减；
3. 构造具体反例：依次插入 $a_1,a_2,a_3$，若 `malloc` 返回地址满足 `addr(a_3) < addr(a_1) < addr(a_2)`，逻辑顺序 $a_1,a_2,a_3$ 与物理顺序 $a_3,a_1,a_2$ 不一致；
4. 顺序表情形下确实一致，但这只是**特例**，不能推广为"总是"→ ×。

## 6. 详细解答

**两种存储结构的对比**：

| 存储方式 | 逻辑相邻如何体现 | 逻辑顺序与存储顺序 |
|---|---|---|
| 顺序存储（顺序表） | 物理地址相邻，$\\&a_{i+1} = \\&a_i + L$ | **一致** |
| 链式存储（链表） | 结点内的 `next` 指针 | **不一定一致** |

**反例（链式存储）**：设依次申请三个结点，动态分配返回的地址为

```
a1 的结点地址 0x2000,  a2 的结点地址 0x1000,  a3 的结点地址 0x1800
next 链： a1(0x2000) → a2(0x1000) → a3(0x1800) → NULL
```

逻辑顺序为 $a_1, a_2, a_3$；按物理地址升序排列为 $a_2(0x1000),\ a_3(0x1800),\ a_1(0x2000)$。两者明显不同，但链表完全合法、遍历结果仍是 $a_1,a_2,a_3$。故"总是一致"为**假**。

**为何顺序表一致**：顺序表要求"地址连续的存储单元依次存放"，"依次"二字已经把逻辑次序钉死为物理次序，所以顺序表是一致的情形——这正是命题具有迷惑性的原因：它对一半的存储方式成立。

## 7. 选项分析

不适用（判断题）。

## 8. 考场标准答案

×。顺序表中逻辑顺序与存储（物理）顺序一致；链表中元素存放在任意的、可不连续的存储单元中，逻辑次序由指针维持，与物理地址次序无关，故并非"总是一致"。

## 9. 易错点

1. 只想到顺序表这一最常见情形而判"√"；
2. 把"逻辑顺序"误解为"元素的值的大小次序"——本题讨论的是**元素在线性表中的位次**，与关键字值无关；
3. 认为"链表结点是连续 `malloc` 出来的所以地址也连续"——即使实际地址恰好递增，那也只是实现的巧合，链表的**定义**不要求这一点，判断命题真假须以定义为准。

## 10. 一句话规律

凡"逻辑结构与存储结构是否总一致"的判断题，一律先问"有没有链式实现"——有链式，"总是"即被否。

## 11. 关联知识

- 由本命题可推出两条实用结论：顺序表可随机访问（下标直接换算地址），链表必须从头指针顺序扫描；
- 树的**孩子兄弟表示法**（DS03.03.01）、图的**邻接表**（DS04.02.02）同样体现"逻辑关系由指针而非地址维持"；
- 与之相反，**邻接矩阵**（DS04.02.01）、**顺序表**、数组的顺序存储（DS02.04）都是"物理位置编码逻辑关系"的典型。
