# DS-2005-17

## 1. 原题

**17、** 对任意一个图，从它的某个顶点出发进行一次深度优先或广度优先搜索遍历，可访问到该图的每一个结点。（）

## 2. 答案

×（错误）

## 3. 题目分析

- 已知：任意图（题干说"任意一个图"，含无向图与有向图、连通与非连通）；从**某个**顶点出发做**一次** DFS 或 BFS；
- 目标：判断是否必然访问到图中所有顶点；
- 关键约束：一次搜索只能到达从起点**可达**的顶点集合；DFS/BFS 的"完整遍历"还需要外层对所有顶点做"未访问则启动一次搜索"的循环；
- 命题意图：考"一次搜索（DFS/BFS）"与"图的遍历（连通分量/强连通分量的 forest 式扫描）"这两个概念的差别，并考"连通/强连通"定义。

## 4. 核心考点

核心考点：
DS04.03.01 深度优先搜索（一次 DFS 的可达集、与"遍历整个图"的区别）

辅助考点：
DS04.03.02 广度优先搜索（同一区别的 BFS 版本）
DS04.01 图的基本概念（连通、连通分量、强连通、可达性）

解释：本题不需要任何实现细节，只需要区分"从一个顶点出发的一次搜索"与"教材 DFSTraverse/BFSTraverse 中带外层 for 循环的完整遍历"，并用非连通图/有向不可达图给出反例。

## 5. 解题思路

1. 明确一次搜索的访问范围：从 $v$ 出发，DFS/BFS 沿边（弧）推进，能且只能访问 $v$ 所在连通分量（无向图）或 $v$ 可达的顶点集（有向图）；
2. 全称命题"任意一个图"→ 造反例：
   - 无向非连通图：两个孤立三角形，起点在其中一个 ⟹ 另一个 3 个顶点全访问不到；
   - 有向图：取一条单向链 $a\to b\to c$，从 $c$ 出发 ⟹ 只能访问 $c$；
3. 反向印证：教材的"图遍历"算法（`DFSTraverse`/`BFSTraverse`）之所以要写外层 `for` 对每个未访问顶点再启动一次搜索，正是因为单次搜索覆盖不全——算法结构本身就承认了本题为假；
4. 结论：×。

## 6. 详细解答

**反例一（无向非连通图）**

$G_1=(V_1,E_1)$，$V_1=\{1,2,3,4,5,6\}$，$E_1=\{(1,2),(2,3),(1,3),(4,5),(5,6),(4,6)\}$，即两个互不相连的三角形。从顶点 $1$ 出发：

- DFS（邻接矩阵、按编号从小到大探测）访问顺序 $1,2,3$；
- BFS 访问顺序 $1,2,3$；

两者都只覆盖了 $1$ 所在的连通分量，顶点 $4,5,6$ 的 `visited` 标志始终为假。$G_1$ 有 $2$ 个连通分量，一次搜索只得到 $1$ 个分量上的（生成）树。

**反例二（有向图不可达）**

$G_2$：顶点 $\{a,b,c\}$，弧 $\langle a,b\rangle,\langle b,c\rangle$。从 $c$ 出发，$c$ 的邻接（出边）表为空，一次 DFS/BFS 仅访问 $c$；即使从 $a$ 出发能访问 $a,b,c$，也不能改变"题干说任意顶点、任意图"为假的事实。若按"强连通"要求，$G_2$ 本身就不是强连通图。

**算法层面的印证**

教材在无向图上的完整遍历写作：

```c
void DFSTraverse(MGraph G)          /* 遍历图 G：保证访问所有连通分量 */
{
    int v;
    for (v = 0; v < G.vexnum; ++v) visited[v] = FALSE;
    for (v = 0; v < G.vexnum; ++v)
        if (!visited[v]) DFS(G, v); /* 每个未访问顶点启动一次新的 DFS */
}
```

外层 `for` 的存在即为"单次 DFS 覆盖不全"的官方说明：对连通图它只会执行一次 `DFS` 调用，对含 $c$ 个连通分量的图会执行 $c$ 次，得到的是 **DFS 森林**而非一棵树。

**结论**：×。（正确表述应为：对**连通**无向图（或从某顶点出发可到达全部顶点的有向图），一次 DFS/BFS 可访问所有顶点；一般图需从每个未访问顶点各启动一次搜索。）

## 7. 选项分析

不适用（判断题型）。

## 8. 考场标准答案

×。一次 DFS/BFS 只能访问起点所在连通分量（无向图）或起点可达的顶点集（有向图）。反例：两个无公共顶点的三角形组成的无向图，从任一顶点出发一次遍历只能访问 3 个顶点，另 3 个访问不到；有向图 $a\to b\to c$ 从 $c$ 出发只能访问 $c$。因此教材的遍历算法 `DFSTraverse` 必须加外层循环对每个未访问顶点再启动一次搜索，非连通图得到的是生成**森林**。

## 9. 易错点

1. 把"图的遍历算法"（含外层 for）与"一次 DFS/BFS"混为一谈，从而误判为 √——题干的"**一次**"是关键词；
2. 只想到无向连通图这一"默认情形"，忘了题干说的是"任意一个图"；
3. 有向图中混淆"可达"与"强连通"：即便从 $a$ 能到所有点，也不代表图强连通。

## 10. 一句话规律

看到"任意一个图 + 一次遍历 + 所有顶点"，先问两个问题：图连通吗（有向图强连通/单向可达吗）？算法有没有外层循环？两个条件缺一，覆盖就不全。

## 11. 关联知识

- $n$ 个顶点的无向图，一次从 $v$ 出发的 DFS 能访问全部顶点 ⟺ $v$ 所在连通分量为全图，即图连通（与本年度 DS-2005-06"$n$ 个顶点无向连通图至少 $n-1$ 条边"同为图的连通性基本结论）；
- 邻接矩阵上一次 DFS/BFS 的时间为 $O(n^2)$，邻接表上为 $O(n+e)$；完整遍历（含外层循环）总量相同；
- 本年度 DS-2005-16（无向图邻接矩阵对称）与本题同属图的基本存储/遍历概念组。
