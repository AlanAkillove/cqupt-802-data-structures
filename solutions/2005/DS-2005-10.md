# DS-2005-10

## 1. 原题

线性表的唯一存储形式是数组。（）

## 2. 答案

×（错误）

## 3. 题目分析

- 已知：命题"线性表的**唯一**存储形式是数组"；
- 目标：判定该命题真假；
- 关键：区分**逻辑结构**（线性表：$n$ 个元素的有序序列）与**存储结构**（实现方式）；
- 命题意图：考"同一逻辑结构可有多种存储结构"这一数据结构最基本的思想；题干中的"唯一"是绝对化措辞，通常即为破绽。

## 4. 核心考点

核心考点：
DS01.01 线性表的基本概念（逻辑结构与存储结构分离）

辅助考点：
DS01.02.01 顺序存储（顺序表——用数组实现）
DS01.02.02 链式存储：单链表（用结点+指针实现，非数组）

解释：线性表是逻辑结构，顺序表和链表是它的两种存储结构；判此题只需给出一种非数组的实现即可否证"唯一"。

## 5. 解题思路

1. 把命题写成"∀线性表的存储形式 $S$，$S$ 是数组"，这是**全称+唯一**命题；
2. 否证只需一个反例：单链表——结点动态分配、由 `next` 指针串联，逻辑上仍是线性表，但物理上不是数组；
3. 再确认反例的合法性：链表满足线性表定义（存在唯一首元素、唯一尾元素，除首元素外每个元素有唯一前驱，除尾元素外每个元素有唯一后继）；
4. 结论：×。

## 6. 详细解答

**线性表的定义**（逻辑结构）：$n\ (n\ge 0)$ 个类型相同的元素构成的**有限序列** $(a_1, a_2, \dots, a_n)$，元素之间是"一对一"的线性关系。定义中**不涉及任何存储细节**。

**其存储实现至少有两种**：

1. **顺序存储**：用一组**地址连续**的存储单元依次存放元素，即顺序表——通常由数组实现；
2. **链式存储**：用一组**任意**（可离散分布）的存储单元存放元素，每个结点额外保存指示后继的指针，即链表。

```c
// 顺序表：底层是数组
typedef struct { ElemType *elem; int length; } SqList;

// 单链表：底层不是数组，而是动态申请的结点
typedef struct LNode { ElemType data; struct LNode *next; } LNode, *LinkList;
```

**反例核对**：链表 $a_1 \to a_2 \to a_3 \to \mathtt{NULL}$ 中，元素逻辑次序由指针维持，`a_2` 的结点地址完全可以小于 `a_1` 的结点地址——它依然是线性表，但**不是**数组。故"唯一存储形式是数组"为**假**。

**进一步否证**：还存在**循环链表**、**双向链表**、**静态链表**（用数组下标模拟指针，形式上是数组但语义是指针）等多种实现，"唯一"更无从谈起。

## 7. 选项分析

不适用（判断题）。

## 8. 考场标准答案

×。线性表是逻辑结构，其存储结构至少包括顺序存储（顺序表，一般用数组实现）和链式存储（链表，结点+指针，不要求地址连续）两种，故"唯一"错误。

## 9. 易错点

把"顺序表是线性表"倒推成"线性表只能顺序存储"。正确关系是：**顺序表 ⊂ 线性表的实现方式之一**。

## 10. 一句话规律

判断题中出现"唯一""只能""总是""所有"等绝对化量词时，第一反应是**构造一个反例**；线性表类的反例几乎总是"链表"。

## 11. 关联知识

- 与本卷第 11 题（逻辑顺序与存储顺序是否总一致）构成同一知识点的两问：正因为存在链式存储，两种说法才都错；
- 顺序表支持 $O(1)$ 随机访问、链表不支持；链表插入删除不需移动元素、顺序表需要——两者互补，恰说明"一种逻辑结构多种存储结构"的价值；
- 静态链表（DS01.02.02 相关）用数组承载指针语义，是"存储形式"与"逻辑结构"可以进一步分离的典型例子。
