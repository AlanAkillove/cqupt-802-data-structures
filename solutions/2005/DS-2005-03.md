# DS-2005-03

## 1. 原题

在双向链表中，每个结点有两个指针域，一个指向其____________________结点，另一个指向其____________________结点。

## 2. 答案

第一空：**前驱**（直接前驱）；第二空：**后继**（直接后继）。
（两空顺序可互换。）

## 3. 题目分析

- 已知：双向链表（double linked list）的结点结构；
- 目标：说出两个指针域各自的语义；
- 约束：双向链表的核心特征是**前后向均可直接移动**，这要求每个结点同时保存两个方向的链接；
- 命题意图：考双向链表结点的定义——`prior`/`next` 两域与单链表 `next` 域的差别。

## 4. 核心考点

核心考点：
DS01.02.03 链式存储：双向链表（结点含 `prior`、`data`、`next` 三域）

辅助考点：
DS01.02.02 链式存储：单链表（对比：仅有一个后继指针）

解释：双向链表的定义性内容就是"两个指针域分别指向前驱与后继"；理解这一点才能解释为什么双向链表可以在**已知结点指针**的前提下 $O(1)$ 完成插入删除，而单链表需要知道**前驱**才能删除。

## 5. 解题思路

1. 回忆双向链表结点定义：`typedef struct DNode { ElemType data; struct DNode *prior, *next; } DNode, *DLinkList;`；
2. `prior` 域沿前向链接，指向逻辑上紧邻本结点**之前**的结点 → 前驱；
3. `next` 域沿后向链接，指向逻辑上紧邻本结点**之后**的结点 → 后继；
4. 验证对称性：对任意结点 `*p`（非首非尾），恒有 `p->prior->next == p` 且 `p->next->prior == p`，两域语义互逆，符合"前驱/后继"这一对偶命名。

## 6. 详细解答

双向链表的结点结构（教材风格）：

```c
typedef struct DNode {
    ElemType      data;    // 数据域
    struct DNode *prior;   // 前驱指针：指向前驱结点
    struct DNode *next;    // 后继指针：指向后继结点
} DNode, *DLinkList;
```

设双向链表为 $d_1 \rightleftarrows d_2 \rightleftarrows d_3 \rightleftarrows \cdots$，则对结点 $d_2$：

- `d2->prior` 指向 $d_1$，即 $d_2$ 的**直接前驱**；
- `d2->next`  指向 $d_3$，即 $d_2$ 的**直接后继**。

对首结点，`prior` 为 `NULL`（非循环时）；对尾结点，`next` 为 `NULL`（非循环时）。若是**双向循环链表**，则首结点的 `prior` 指向尾结点、尾结点的 `next` 指向首结点，两域的"前驱/后继"语义不变。

**功能验证**：在 `*p` 之前插入 `*s` 的语句

```c
s->prior = p->prior;  s->next = p;
p->prior->next = s;   p->prior = s;
```

四条语句之所以能把 `s` 完整织入链条，正是因为每个结点同时持有前驱与后继两个方向的链接——若只有 `next`（单链表），第一步 `p->prior` 无从取得。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

一个指向其**前驱（直接前驱）**结点，另一个指向其**后继（直接后继）**结点。

## 9. 易错点

填成"上一个存储单元 / 下一个存储单元"——链表结点的物理位置与逻辑顺序无关，`prior`/`next` 指的是**逻辑上的前驱后继**，不是内存相邻地址。

## 10. 一句话规律

凡是"某结构每个结点有 $k$ 个指针域"的填空题，先写出该结构的 `typedef`，指针域的**变量名**通常就是答案的语义。

## 11. 关联知识

- 双向链表删除 `*p`：`p->prior->next = p->next; p->next->prior = p->prior; free(p);`，无需像单链表那样先找前驱；
- 与 DS01.02.03 中的双向循环链表相比，仅"空指针"改为"回指"，两域语义完全一致；
- 树的**三叉链表**（DS03.02.02）同理多出一个指向双亲的指针域，可类比记忆。
