# DS-2005-04

## 1. 原题

设 $n$ 行 $n$ 列的下三角矩阵 $A$ 已压缩到一维数组 $s[1 \cdots \frac{n\times(n+1)}{2}]$ 中，若按行序为主存储，则元素 $A[i,j]$ 在 $S$ 中的存储位置是____________________。

## 2. 答案

$$k = \frac{i(i-1)}{2} + j \qquad (1 \leq j \leq i \leq n)$$

当 $i < j$（上三角区域）时，$A[i,j]$ 为同一常数，不存入 $s$（$s$ 的下标范围恰为 $\frac{n(n+1)}{2}$，无剩余单元）。

## 3. 题目分析

- 已知：$n$ 阶**下三角**矩阵，压缩到**下标从 1 开始**的一维数组 $s[1 \cdots \frac{n(n+1)}{2}]$，**按行序为主**存放；
- 目标：求二维下标 $(i,j)$ 到一维下标 $k$ 的映射公式；
- 约束：$\frac{n(n+1)}{2}$ 恰好等于下三角（含对角线）元素个数 ⇒ 只有 $i \geq j$ 的元素被存储；
- 命题意图：考压缩存储的**计数式推导**能力——"数出目标元素之前存了多少个元素"，而不是死记公式。

## 4. 核心考点

核心考点：
DS02.05 特殊矩阵的压缩存储（下三角矩阵按行压缩的下标映射）

辅助考点：
DS02.04 多维数组的存储（行优先 = 先变列下标的计数思想）

解释：本题不是简单的"行列优先地址计算"，而是"跳过不存储的元素后重新编号"，其本质仍是行优先计数：先数完整的前 $i-1$ 行，再数第 $i$ 行内的前 $j-1$ 个。

## 5. 解题思路

1. 明确"存储位置 = 该元素之前已存储的元素个数 + 1"（因 $s$ 下标从 1 起）；
2. 下三角矩阵第 $r$ 行有 $r$ 个待存元素（$a_{r,1} \sim a_{r,r}$），第 $r$ 行之后的 $n-r$ 个元素是常数，不存；
3. 前 $i-1$ 行的元素总数为 $1 + 2 + \cdots + (i-1) = \frac{i(i-1)}{2}$；
4. 第 $i$ 行内 $a_{i,j}$ 前面还有 $j-1$ 个元素，故其序号为 $\frac{i(i-1)}{2} + (j-1) + 1 = \frac{i(i-1)}{2} + j$；
5. 用一个 $3 \times 3$ 小矩阵逐个元素手算复核（见第 6 节）。

## 6. 详细解答

**推导**：按行序为主压缩，存储顺序为

$$a_{1,1},\ a_{2,1}, a_{2,2},\ a_{3,1}, a_{3,2}, a_{3,3},\ \dots,\ a_{n,1}, \dots, a_{n,n}$$

$a_{i,j}$（$i \geq j$）之前的元素分两段：

- 完整的前 $i-1$ 行：$\displaystyle\sum_{r=1}^{i-1} r = \frac{(i-1)i}{2}$ 个；
- 第 $i$ 行中排在它前面的 $a_{i,1} \sim a_{i,j-1}$：$j-1$ 个。

因 $s$ 的下界为 1，故

$$k = \frac{i(i-1)}{2} + (j-1) + 1 = \boxed{\frac{i(i-1)}{2} + j}$$

**手算验证**（取 $n=3$，$s$ 长度为 $\frac{3\times4}{2}=6$）：

| 元素 | 公式 $\frac{i(i-1)}{2}+j$ | 存储序列中的实际位置 |
|---|---|---|
| $a_{1,1}$ | $0+1=1$ | $s[1]$ ✓ |
| $a_{2,1}$ | $1+1=2$ | $s[2]$ ✓ |
| $a_{2,2}$ | $1+2=3$ | $s[3]$ ✓ |
| $a_{3,1}$ | $3+1=4$ | $s[4]$ ✓ |
| $a_{3,2}$ | $3+2=5$ | $s[5]$ ✓ |
| $a_{3,3}$ | $3+3=6$ | $s[6]$ ✓ |

**端点验证**：$a_{n,n}$ 应为最后一个 → $\frac{n(n-1)}{2}+n = \frac{n(n+1)}{2}$ ✓；$a_{i,1}$（每行首元素）→ $\frac{i(i-1)}{2}+1$，恰为该行第一个新位置 ✓。

**$i<j$ 的情形**：$s$ 的容量 $\frac{n(n+1)}{2}$ 已被下三角元素占满，故上三角的常数不占数组空间，通常另设一个变量 `c` 存放；访问 $a_{i,j}$（$i<j$）时直接返回 `c`。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

$$\frac{i(i-1)}{2}+j \quad (i \geq j)$$

（若数组下界为 0，则为 $\frac{i(i-1)}{2}+j-1$；本题 $s[1\cdots]$ 下界为 1。）

## 9. 易错点

1. **下界混淆**：本题 $s$ 从下标 1 开始，写成 $\frac{i(i-1)}{2}+j-1$（从 0 开始的公式）会整体错位；
2. **行序/列序混淆**：若按**列序**为主压缩，公式变为 $\frac{(j-1)(2n-j+2)}{2}+i$（前 $j-1$ 列每列 $n-r+1$ 个元素），与本题完全不同；
3. 前 $i-1$ 行求和误算成 $\frac{i(i+1)}{2}$（多算了第 $i$ 行）；
4. 忘记说明 $i<j$ 时不存储，被追问"上三角元素在哪"时答不出。

## 10. 一句话规律

压缩存储下标公式一律用"**数前面有多少个元素再加 1（或加数组下界）**"现推，不要背公式；推完必须用 $n=3$ 的小矩阵或首尾端点复核。

## 11. 关联知识

- $n$ 阶对称矩阵压缩（存下三角）映射与本题相同；若存上三角则需做 $(i,j)\to(j,i)$ 转置代入；
- 三对角（带状）矩阵按行压缩为 $b[i] = a[i,\,i-1+k]$ 型的线性映射，同样是"数前面"的方法，见 DS02.05；
- 数组元素地址 $= \text{base} + k \times L$（$L$ 为每个元素占用的存储单元数），本题只问"存储位置"即下标 $k$。
