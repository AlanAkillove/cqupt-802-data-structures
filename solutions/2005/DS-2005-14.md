# DS-2005-14

## 1. 原题

**14、** 删除二叉排序树中的一个结点，再重新插入进去，一定能得到原来的二叉排序树。（）

## 2. 答案

×（错误）

## 3. 题目分析

- 已知：一棵二叉排序树（BST），执行"删除其中一个结点 → 再把该关键字重新插入"这一复合操作；
- 目标：判断结果树是否**一定**与原树相同；
- 关键约束：教材的 BST 删除规则分三情况，其中"左右子树均非空"时用**中序后继（或前驱）替代**，这会改变结点位置；插入则总是把新结点挂成叶子；
- 命题意图：区分"删除+插入保持 **BST 性质（中序递增）**"与"保持 **树的形态**"——前者成立，后者不成立。

## 4. 核心考点

核心考点：
DS05.07.01 二叉搜索（排序）树（构造、删除、中序有序性）

辅助考点：
DS03.02.03.02 中序遍历（"中序后继"的定义与查找方式）

解释：本题的判断完全依赖删除算法的细节——被删结点左右子树皆非空时，教材用它中序后继的值覆盖并删除后继结点，这一"跨子树的搬动"是不可逆的；而插入算法只会把关键字挂到某条查找路径末端的空链上。两算法不对称，所以形态不能保证还原。

## 5. 解题思路

1. 先明确"得到原来的二叉排序树"指**形态与内容都相同**（同一棵树），而不只是中序序列相同；
2. 按被删结点的度数分三类讨论：
   - 叶结点：删除后其父的空链位置不变，重插必回到原处 → 形态还原；
   - 单孩子结点：孩子子树整体上移一层，重插时比较路径已改变 → 一般不还原；
   - 双孩子结点：后继上移，重插的后继关键字会被挂到别处 → 一般不还原；
3. 对"不还原"的两类各构造一个最小反例，并核对反例的中序序列仍递增（确认操作过程合法、错误在于形态）；
4. 全称命题"一定能"被反例否证 → ×。

## 6. 详细解答

**约定**：采用严蔚敏教材的删除规则——① 叶子直接删；② 只有左（或右）子树则用该子树根替代被删结点；③ 左右子树均非空则取其**中序后继**（右子树中最左结点）的值替代，再删除该后继结点。插入规则：从根开始比较，小走左、大走右，直到空链挂上新叶子。

**反例一（双孩子结点，3 个结点的最小树）**

原树 $T$：

```
      2
     / \
    1   3
```

中序：$1,2,3$。删除根 $2$ → 属情况 ③，右子树（仅结点 3）的最左结点是 $3$，用 $3$ 覆盖根并删去原 $3$：

```
    3
   /
  1
```

再把 $2$ 插入：$2<3$ → 走左到结点 $1$；$2>1$ → 挂为 $1$ 的右孩子：

```
    3
   /
  1
    \
     2
```

得到的树根是 $3$、高为 $3$；原树根是 $2$、高为 $2$。**形态不同**（中序仍是 $1,2,3$，说明它仍是一棵合法的 BST，但不是"原来的二叉排序树"）。

**反例二（单孩子结点）**

原树：

```
    5
   /
  3
 /
2
```

删除 $3$（只有左孩子 $2$）→ 情况 ②，$2$ 上移挂到 $5$ 的左链：

```
    5
   /
  2
```

重插 $3$：$3<5$ → 左孩子 $2$；$3>2$ → 挂为 $2$ 的右孩子：

```
    5
   /
  2
    \
     3
```

原树是"向左的一条链"，结果树出现右孩子 → 形态不同。

**正面情形（说明为何不能判 √ 也不能判"完全不行"）**：若被删的是**叶子**结点，删除只置空其父的一条链，重插时查找路径与原路径逐点相同（路径上其他结点未动），故必然回到原位置。因此"有时能得到原树"，题干的"**一定**"过强。

**结论**：×。

## 7. 选项分析

不适用（判断题型）。

## 8. 考场标准答案

×。删除与插入不是互逆操作：删除双孩子结点时要用中序后继覆盖被删结点（后继从右子树被搬到上层），重插时该后继关键字会被重新挂到查找路径末端成为叶子，树的形态一般改变。
反例：$\{1,2,3\}$ 建成根为 $2$、左右孩子为 $1,3$ 的 BST，删除 $2$ 得根 $3$ 左孩子 $1$，再插入 $2$ 得 $3\to1\to2$ 的右链，与原树形态不同。仅当被删结点是叶子时才能还原，故"一定"不成立。

## 9. 易错点

1. 把"删除后重插，中序序列仍是 $1,2,3$"误当成"得到原来的二叉排序树"——**形态**与**BST 性质**是两件事，本题问的是形态；
2. 忽略情况 ③ 的"后继搬动"，以为删除只是把某条指针置空；
3. 用"删除叶子成立"的特例外推为全称成立（正是题干设的陷阱）。

## 10. 一句话规律

BST 的"删除→重插"检验的是操作可逆性：插入永远产生新叶子，而删除可能让内部结点上移/被搬走，凡涉及"一定能还原"的结构操作，先按被删结点的度数分类找最小反例。

## 11. 关联知识

- 保持形态的删除写法存在：把被删结点的双孩子情形改为"用左子树整体接到右子树最右结点之下"等变体，但教材标准算法不做此保证；
- 同一棵树的不同插入次序产生不同形态，是本命题的"镜像"事实：BST 的形态由关键字的到达次序决定，而非仅由关键字集合决定；
- 相关本年度题目：DS-2005-23（BST 的哪种遍历得到有序序列）与本题共用"中序有序性"这一核心性质。
