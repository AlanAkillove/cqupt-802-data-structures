# DS-2005-08

## 1. 原题

利用插入排序算法对 $n$ 个记录进行排序，最佳情况下，对关键字进行的比较次数为____________________次。

## 2. 答案

$n-1$ 次（最佳情况为输入序列已经正序，每个待插记录只需与有序区最后一个记录比较 1 次即可确定位置）。

## 3. 题目分析

- 已知：直接插入排序，$n$ 个记录；情形：**最佳情况**；
- 目标：关键字**比较**次数（注意不是移动次数，也不含"把待插记录暂存到哨位"的赋值）；
- 约束：插入排序从第 2 个记录起，共做 $n-1$ 趟插入；
- 命题意图：考"插入排序的比较次数与初始有序度相关"这一特性，以及最佳情形的精确计数。

## 4. 核心考点

核心考点：
DS06.02.01 直接插入排序（每趟的比较与移动过程、最好/最坏情形）

辅助考点：
DS06.01 排序的基本概念（"最佳情况"指什么输入、按关键字比较次数度量）

解释：插入排序的代价 = 比较次数 + 移动次数；最佳情况下两者都取到最小值，比较次数恰为趟数 $n-1$，这正是它“对基本有序表高效”的原因（同一性质在本卷第 27 题中作为选型依据出现）。

## 5. 解题思路

1. 确定最佳输入：序列已按关键字**正序**，此时每个新记录都应插在有序区末尾之后；
2. 逐趟统计：第 $i$ 趟（$i=2,\dots,n$）把 $R[i]$ 与 $R[i-1]$ 比较一次，因 $R[i].\text{key} \geq R[i-1].\text{key}$ 立即成立，循环终止 → 每趟恰 1 次比较；
3. 求和：$\sum_{i=2}^{n} 1 = n-1$；
4. 用 $n=1$（$0$ 次）与 $n=4$（$3$ 次）手算核对。

## 6. 详细解答

**算法**（教材风格，$R[1]$ 起存储，$R[0]$ 作哨位）：

```c
void InsertSort(SqList *L) {          // L->length = n
    for (i = 2; i <= L->length; i++)
        if (L->r[i].key < L->r[i-1].key) {   // ← 每趟至少做 1 次关键字比较
            L->r[0] = L->r[i];               // 哨位，不参与关键字比较计数
            for (j = i - 2; L->r[j].key > L->r[0].key; j--)
                L->r[j+1] = L->r[j];         // 后移
            L->r[j+1] = L->r[0];
        }
}
```

**最佳情形分析**：设输入已正序，则对每个 $i\ (2 \leq i \leq n)$，外层 `if` 的判断 `L->r[i].key < L->r[i-1].key` 恰好**一次比较即判为假**，内层移动循环根本不执行。

$$\text{比较次数} = \sum_{i=2}^{n} 1 = n - 1$$

**移动次数**（顺带核对）：最佳情况下除每趟的"哨位赋值 + 原位赋回"外无实质移动，记录不挪位。

**手算验证**（$n=4$，输入 $1,2,3,4$）：

| 趟 $i$ | 比较 | 结果 |
|---|---|---|
| 2 | $R[2]$ vs $R[1]$：$2<1$? 否 | 1 次 |
| 3 | $R[3]$ vs $R[2]$：$3<2$? 否 | 1 次 |
| 4 | $R[4]$ vs $R[3]$：$4<3$? 否 | 1 次 |

共 $3 = n-1$ ✓。$n=1$ 时不进入循环，$0 = 1-1$ ✓。

**对照最坏情形**：逆序时第 $i$ 趟需比较 $i$ 次（与 $R[i-1]\dots R[1]$ 各一次，再加哨位处终止比较），总数 $\sum_{i=2}^{n} i = \frac{(n+2)(n-1)}{2}$，量级 $O(n^2)$——与最佳 $n-1$ 形成鲜明对比。

不适用（填空题）。

## 8. 考场标准答案

$$n-1$$

（最佳情况为输入正序，每趟仅需 1 次比较，共 $n-1$ 趟。）

## 9. 易错点

1. 答成 $n$：把"第 1 个记录自成一趟"也算进去，实际插入从第 2 个记录开始，共 $n-1$ 趟；
2. 与**折半插入排序**混淆：折半插入即使最佳情况也要做 $\sum_{i=2}^{n}\lceil \log_2 i \rceil$ 量级的比较，**不会**降到 $n-1$（它只减少移动，不减少比较）；
3. 把哨位 `L->r[0]` 的赋值当作一次关键字比较；
4. 与冒泡排序最佳情形（$n-1$ 次比较、0 次交换）记号混淆——两者结论相同但理由不同。

## 10. 一句话规律

"趟数 × 每趟最少比较数"是插入/冒泡类排序最佳情形的通用算法；而"是否正序输入"决定了每趟能否一次比较就退出。

## 11. 关联知识

- 插入排序**稳定**，空间 $O(1)$，最佳 $O(n)$、最坏与平均 $O(n^2)$；
- 因“基本有序时高效”，插入排序常用于小规模或近乎有序的子序列（希尔排序即其分组推广，DS06.05）；
- 本题与 2005 卷第 27 题（元素已距最终位置不远时应选何种排序）互为呼应，答案同为插入排序。
