# DS-2024-03

## 1. 原题

合并两个非递减的链表为一个非递增链表（不带头结点），以下是部分代码，请补全代码使其正确实现功能，假设链表的长度分别为 $n$ 和 $m$ ，分析这段代码的时间复杂度。

```c
Node* mergeAndReverse(Node *La,Node *Lb)
{
    Node *Lc=NULL;//非递增链表的头指针
    Node *hc=NULL;//临时指针，用于构建链表
    
    while(_____①_____)
    {
        Node *p=NULL;
        if(_____②_____)
        {
            p=La;
            La=La->next;
        }
        else
        {
            p=Lb;
            Lb=Lb->next;
        }
        _____③_____;
        _____④_____;
    }
    while(La!=NULL)
    {
        Node *p=La;
        La=La->next;
        p->next=Lc;
        Lc=p;
    }
    while(Lb!=NULL)
    {
        Node *p=Lb;
        Lb=Lb->next;
        p->next=Lc;
        Lc=p;
    }
    return Lc;
}
```

## 2. 答案

| 空位 | 填写内容 | 作用 |
|---|---|---|
| ① | `La != NULL && Lb != NULL` | 两表都未扫空时才继续比较（归并主循环） |
| ② | `La->data <= Lb->data` | 取当前较小者（等值取 `La`，保持相对次序） |
| ③ | `p->next = Lc` | 头插第 1 步：让摘出的结点 $p$ 接住当前表头 |
| ④ | `Lc = p` | 头插第 2 步：表头改为 $p$ |

时间复杂度 $O(n+m)$（每个结点恰好被摘取并头插一次）；附加空间 $O(1)$。

## 3. 题目分析

- 已知：两条**不带头结点**的单链表 `La`、`Lb`，各自按 `data` **非递减**有序；长度分别 $n$、$m$；骨架已给出归并主循环的"摘结点"部分（`p=La; La=La->next;` 与对称分支）以及循环结束后两段完整的"剩余结点逐个头插"代码；
- 目标：补四个空使函数返回一条**非递增**链表 `Lc`；并给出时间复杂度；
- 关键约束：
  1. 输入升序、输出降序，**方向相反** ⟹ 不能像通常的"合并两个有序链表"那样尾插保序，必须**头插**：按升序取出的结点，后取出的被插到更前面，成品自然降序（非递增）；
  2. 题面已给的两段收尾循环写的正是 `p->next=Lc; Lc=p;` —— 这**锁定了 ③④ 的形式**：主循环内的两句必须与收尾两句一致，否则已排好的部分与剩余部分方向不统一，结果不是非递增；
  3. `Lc` 初值为 `NULL`，因此第一次头插得到 `p->next = NULL` 的单结点表，空表语义正确（不带头结点的链表用 `NULL` 表示空）；
  4. 摘结点必须"先保存后继再改 `p->next`"——骨架已用 `p=La; La=La->next;` 完成，故 ③ 改写 `p->next` 不会丢失 `La` 的剩余部分；
- 命题意图：表面是"补全代码"，实质考两件事——① **头插法的逆序效应**（DS01.02.02／DS02.07：头插序列等价于压栈，输出次序与插入次序相反），② **归并骨架的循环条件与判空**（DS01.03 有序表合并：主循环只在两表同时非空时比较，单边剩余由收尾循环处理）。

## 4. 核心考点

核心考点：
DS01.02.02 链式存储：单链表——不带头结点的空表表示（`Lc==NULL`）、头插法建表 `p->next=Lc; Lc=p;`、摘链时必须先保存后继、`next` 域的改写次序

辅助考点：
DS01.03 线性表的应用——两个有序表的归并（"比较取小 + 单边剩余直接接续"这一框架，本题把"接续"改成头插）
DS02.07 栈、队列和数组的应用——头插法本质上是把结点依次压栈，"后进先出"把升序输入翻成降序输出，这正是本题方向反转的实现机制

解释：主标签取 DS01.02.02，因为四个空的正确填写全部依赖单链表头插的指针语义；而"两个非递减表合成一个表"的过程属于线性表应用里的有序表合并（DS01.03），"非递减进、非递增出"的方向差则由头插的栈式性质提供（DS02.07），故列为辅助。

## 5. 解题思路

1. **先定方向**：输入非递减、输出非递增 ⟹ 谁最后被接上谁排在最前 ⟹ 只能头插，不能尾插；
2. **用已给的收尾代码反推 ③④**：骨架的两段收尾循环都是 `Node *p=...; La=La->next; p->next=Lc; Lc=p;`，主循环里 `p` 已摘好，缺的就是 `p->next=Lc;` 与 `Lc=p;` 这两句 ⟹ ③ = `p->next = Lc`、④ = `Lc = p`；
3. **定 ①**：主循环体内 ② 要同时读 `La->data` 与 `Lb->data`，两者都必须非空 ⟹ ① 是 `La != NULL && Lb != NULL`（写成 `||` 会让某一表已空时解引用空指针）；
4. **定 ②**：`if` 分支走 `La` 摘点、`else` 走 `Lb`，且要求取"当前较小者"以保证取出序列非递减 ⟹ ② = `La->data <= Lb->data`（`<` 亦可，结果同样非递增，只是等值时的相对次序不同）；
5. **验证**：取 $5{+}6=11$ 个结点、含重复值的两表逐步走查（第 6 节第三步），检查成品是否非递增、结点数是否等于 $n+m$；再验两条边界（一空表、两空表）。

## 6. 详细解答

### 第一步：为什么头插能把升序变降序

设按算法取出的结点值序列为 $b_1\le b_2\le\cdots\le b_{n+m}$（下标为取出次序）。头插法的规则是"新结点插到表头"，故第 $k$ 次头插后的表为

$$Lc:\ b_k \to b_{k-1} \to \cdots \to b_1 .$$

全部插完（$k=n+m$）得到 $b_{n+m}\to b_{n+m-1}\to\cdots\to b_1$，即**非递增** ✓。

**取出序列 $b$ 为何非递减**：主循环每轮在两个"当前表头"中取较小者，而两条输入表本身非递减，摘去表头后剩下的仍非递减——这正是归并排序"merge"过程的不变量：已输出的 $b$ 序列是两表全部元素的多重集合中从小到大逐个释放的。收尾两段循环把一个表剩下的（比已取出的所有值都大或相等）继续头插，$b$ 的非递减性保持。

### 第二步：四个空的排除性论证

| 空 | 可选项 | 排除理由 |
|---|---|---|
| ① | `La!=NULL && Lb!=NULL` | 若写 `La!=NULL \|\| Lb!=NULL`，当 `La==NULL`、`Lb!=NULL` 时 ② 处 `La->data` 解引用空指针；若只写 `La!=NULL && Lb!=NULL` 之外的单边条件，另一表提前耗尽同样崩 |
| ② | `La->data <= Lb->data` | 与 `if/else` 两个分支的摘链对象配套：`if` 分支摘 `La`，故条件应为"`La->data` 不大于 `Lb->data`"。反向写 `>=` 会把较大的先取出，头插后成品变成非**递减**序列，方向错 |
| ③ | `p->next = Lc` | 必须是"新结点接住旧表头" |
| ④ | `Lc = p` | 必须是"表头指针下移"。③④ **不可交换**：若先 `Lc=p`，再执行 `p->next=Lc`，则 $p\to next = p$ 形成自指环，遍历永不终止 |

关于源文声明但未使用的 `Node *hc=NULL;`：四处空位中没有任何一处需要 `hc`——三处头插（主循环 ③④ 与两段收尾循环）都直接以 `Lc` 作表头指针并返回 `Lc`。`hc` 是回忆版保留的冗余变量（若一定要用它，须把三处头插统一改为写 `hc`，并在返回前 `Lc=hc;`，与题面已给的收尾代码冲突），删除不影响正确性。

### 第三步：逐步走查（验算）

取 $La=(1,3,3,5,9)$（$n=5$）、$Lb=(2,2,4,7,8,20)$（$m=6$），含重复值以检验等值分支。表中"取出"列写 `a` 表示走 `if`（摘 $La$）、`b` 表示走 `else`（摘 $Lb$）。

| 轮 | ① 判断 | ② 比较 | 取出 | $p$ | ③ `p->next=Lc` | ④ `Lc=p` 后的 $Lc$ |
|---|---|---|---|---|---|---|
| 1 | 均非空 | $1\le 2$ | a | $1$ | $\to NULL$ | $1$ |
| 2 | 均非空 | $3>2$ | b | $2$ | $\to 1$ | $2,1$ |
| 3 | 均非空 | $3>2$ | b | $2$ | $\to 2,1$ | $2,2,1$ |
| 4 | 均非空 | $3\le 4$ | a | $3$ | $\to 2,2,1$ | $3,2,2,1$ |
| 5 | 均非空 | $3\le 4$ | a | $3$ | $\to 3,2,2,1$ | $3,3,2,2,1$ |
| 6 | 均非空 | $5>4$ | b | $4$ | $\to 3,3,2,2,1$ | $4,3,3,2,2,1$ |
| 7 | 均非空 | $5\le 7$ | a | $5$ | $\to 4,\cdots$ | $5,4,3,3,2,2,1$ |
| 8 | 均非空 | $9>7$ | b | $7$ | $\to 5,\cdots$ | $7,5,4,3,3,2,2,1$ |
| 9 | 均非空 | $9>8$ | b | $8$ | $\to 7,\cdots$ | $8,7,5,4,3,3,2,2,1$ |
| 10 | 均非空 | $9\le 20$ | a | $9$ | $\to 8,\cdots$ | $9,8,7,5,4,3,3,2,2,1$ |
| — | $La==NULL$ ⟹ ① 为假，退出主循环 | | | | | |
| 收尾 | `while(Lb)`：$p=20$，$Lb=NULL$，$20\to Lc$，$Lc=20$ | | | | | $20,9,8,7,5,4,3,3,2,2,1$ |

检查：
- 结果 $20,9,8,7,5,4,3,3,2,2,1$ 相邻元素均满足"前 $\ge$ 后" ⟹ **非递增** ✓
- 结点总数 $11=n+m$，元素多重集合 $\{1,2,2,3,3,4,5,7,8,9,20\}$ 与两输入之并一致 ⟹ 无结点多丢、无新建、无重复挂接 ✓
- 两条输入表在算法结束时均为 `NULL`（结点全部搬走），故 `Lc` 与原表共享存储，属**就地**合并 ✓

**边界 1（一空表）**：$La=(1,3,3,5,9)$、$Lb=\text{NULL}$。主循环 ① 第一次即为假，直接由 `while(La)` 收尾 ⟹ $Lc=9,5,3,3,1$ 非递增 ✓（这说明 ① 用 `&&` 时单边为空是安全路径，而非缺陷。）

**边界 2（两表皆空）**：两次 ① 与两段收尾都不执行，返回 `Lc = NULL`，与"空结果的空链"约定一致 ✓。

**边界 3（全部 $La$ 元素都不大于 $Lb$ 的最小者）**：$La=(1,2)$、$Lb=(5,6)$ ⟹ 主循环把 $La$ 取空（2 轮），收尾把 $Lb$ 头插 ⟹ $6,5,2,1$ ✓。

（后台以 C 程序按上述填法组装完整函数，对"$5{+}6$ 含重复值、单边为空、双边为空、$La$ 全部较小、两表值域完全相同"共 $5$ 组用例执行，检查"结果非递增 / 结点总数 $=n+m$ / 元素多重集合相同"三项性质全部通过，其中第一组的输出与上表逐轮一致；程序仅作验证，正文可人工复现。）

### 第四步：时间复杂度与空间复杂度

- 主循环每轮**恰好摘走一个结点**并头插它，收尾两循环同样每轮摘走一个结点。结点总数 $n+m$，每个结点被处理恰好一次（一次摘链 + 一次头插，各含常数次指针读写）；① 的判断执行 $n+m+1$ 次、② 的比较在主循环内执行 $\le\min$ 相关次数但总数不超过 $n+m$。故
$$T(n,m)=O(n+m),$$
且这是**紧**界：最好情形（一空表）仍要把非空表的 $n+m$ 个结点全部头插一遍，$\Omega(n+m)$。
- 附加空间：只用了 `Lc`、`p` 等常数个指针变量，**没有新建任何结点** ⟹ $S=O(1)$。
- 对比：若采用"新建结点 + 尾插"生成结果表，则时间仍 $O(n+m)$ 但空间为 $O(n+m)$；本题的原地头插做法在空间上更优（代价是原两条表被拆散，不再可用）。

## 8. 考场标准答案

```c
/* 输入：两条非递减、不带头结点的单链表 La(长 n)、Lb(长 m)
   输出：一条非递增单链表 Lc（原地复用结点，不新申请） */
Node* mergeAndReverse(Node *La, Node *Lb)
{
    Node *Lc = NULL;                 // 非递增链表的头指针
    while (La != NULL && Lb != NULL) // ① 两表均非空才比较
    {
        Node *p = NULL;
        if (La->data <= Lb->data)    // ② 取当前较小者，等值取 La
        {   p = La;  La = La->next;  }
        else
        {   p = Lb;  Lb = Lb->next;  }
        p->next = Lc;                // ③ 头插第 1 步：新结点接住旧表头
        Lc = p;                      // ④ 头插第 2 步：表头指向新结点
    }
    while (La != NULL)               // 以下为题面已给的收尾：剩余结点继续头插
    {   Node *p = La;  La = La->next;  p->next = Lc;  Lc = p;  }
    while (Lb != NULL)
    {   Node *p = Lb;  Lb = Lb->next;  p->next = Lc;  Lc = p;  }
    return Lc;
}
```

（源文声明的 `Node *hc = NULL;` 在四处填空中用不到，可直接删去。）

时间复杂度 $O(n+m)$：共 $n+m$ 个结点，每个结点被摘取并头插一次；附加空间 $O(1)$（就地复用原结点）。

## 9. 易错点

1. **① 写成 `La!=NULL || Lb!=NULL`**：某表已空时 ② 会读空指针的 `data` 而崩溃；归并主循环的条件永远是"**与**"，单边剩余交给收尾循环；
2. **③④ 顺序颠倒**：先 `Lc=p` 再 `p->next=Lc` 得到 $p\to next=p$ 的自指环；头插的两句顺序是"先接旧表、再改头指针"，与教材 `s->next=L; L=s;` 一致；
3. **② 的比较方向写反**（`>=`）：取出序列变成非递增，头插后成品反而是非递减，与题面要求相反；
4. **忘记摘链已在 `if` 分支里完成**，把 ③ 写成 `p->next = Lc; La = La->next;` 之类：`p` 就是原 `La`，先改 `p->next` 会丢后继；本题骨架顺序 `p=La; La=La->next;` 已把这一点处理好，填空时不要"热心"重复；
5. **误以为还要处理头结点**：题面明确"不带头结点"，故空表判据是 `Lc==NULL`，返回的 `Lc` 即首元结点；若按带头结点改写（`Lc` 为哨兵）则返回 `Lc->next`，与骨架的 `return Lc;` 不符；
6. **担心等值元素**：非递增允许相等，`<=` 与 `<` 都能得到合法结果，差别只在两个相等元素谁排前面（`<=` 保持 $La$ 的元素先被取出、因而排在后面），答题时按 `<=` 写并注明"等值取 $La$"最稳妥。

## 10. 一句话规律

"两个有序表合并成**反向**有序表"的题，只需把归并的"尾插保序"换成"**头插造序**"：取出次序与成品次序互为逆序，于是升序进 ⟹ 降序出；判断 ③④ 顺序的口诀永远是"**先让新结点接住旧表头，再移动表头指针**"。
