# DS-2024-09

## 1. 原题

在哈夫曼树中，已知有 $1247$ 个结点，叶子结点的个数为____________________。

## 2. 答案

$$\boxed{624}$$

即该哈夫曼树有 $624$ 个叶子结点（度为 $0$ 的结点），从而有 $1247-624=623$ 个分支结点（度均为 $2$）。

## 3. 题目分析

- **已知**：一棵哈夫曼树（最优二叉树）的结点总数 $n=1247$；
- **目标**：叶子结点个数 $n_0$；
- **关键约束**（两条，缺一不可）：
  1. **哈夫曼树中不存在度为 $1$ 的结点**——它由若干单结点树（叶子）"每次挑两棵权值最小的合并成一棵新树"逐步构造，每引入一个新结点必然同时挂上两个孩子，故每个分支结点的度恰为 $2$（这类树也叫**正则二叉树**）；即 $n_1=0$；
  2. **二叉树的结点计数性质** $n_0=n_2+1$；
  由这两条得 $n=n_0+n_1+n_2=n_0+(n_0-1)=2n_0-1$，故 $n_0=(n+1)/2$；
- **隐含的可解性检查**：$n=1247$ 为奇数，与"$n=2n_0-1$ 必为奇数"一致；题面未给叶子权值，说明本题只考**结构计数**，不考 WPL 与编码；
- **命题意图**：考哈夫曼树的**构造方式所决定的形态特征**（DS03.04.01）——"没有度为 $1$ 的结点"这一条与"结点总数必为奇数""$n=2n_0-1$"是同一事实的三种说法；再叠加二叉树基本性质（DS03.02.01）做一步代数。表面像"要画树才能数"，实际一句公式即可。

## 4. 核心考点

核心考点：
DS03.04.01 哈夫曼树与哈夫曼编码——哈夫曼树的构造过程（$m$ 个带权叶子经 $m-1$ 次两两合并得到 $2m-1$ 个结点的树）、"无度为 $1$ 的结点"这一由构造方式直接保证的形态性质

辅助考点：
DS03.02.01 二叉树的定义及主要特征——结点计数性质 $n_0=n_2+1$（由"分支数 $=$ 结点数 $-1$ 且 $=$ 各结点度数之和"推出），是本题第二、三条路线的依据
DS03.01 树的基本概念——度、叶子（终端结点）的定义，保证"$n_1=0$"这一条件的正确理解（度为 $1$ 的结点在本树中不存在，故总结点只由叶子与度 $2$ 结点两类构成）

解释：主标签落在 DS03.04.01，因为"哈夫曼树没有度为 $1$ 的结点"必须从哈夫曼树的构造规则读出，换成任意一棵一般二叉树该题就不可解（只知 $n$ 无法定 $n_0$）；计数性质本身属 DS03.02.01/DS03.01，故列辅助。

## 5. 解题思路

1. **抓住构造规则 ⟹ 形态约束**：哈夫曼树是"每次合并两棵树"长出来的，新结点总是有两个孩子 ⟹ 全树只有度 $0$ 与度 $2$ 两类结点 ⟹ $n=n_0+n_2$；
2. **把"合并次数"翻译成结点数**（最直观的一条路线）：若叶子有 $n_0$ 个，则初始有 $n_0$ 棵单结点树，每合并一次树的棵数减 $1$，最后剩 $1$ 棵 ⟹ 合并次数 $=n_0-1$，而每次合并恰好新增 $1$ 个分支结点 ⟹ 分支结点数 $n_2=n_0-1$；
3. **列方程**：$n=n_0+n_2=n_0+(n_0-1)=2n_0-1=1247\Rightarrow n_0=(1247+1)/2=624$；
4. **换两条独立路线复核**：① 用性质 $n_0=n_2+1$（与第 2 步结论等价但来源不同，那里靠过程计数、这里靠度数求和）；② 用"边数"角度：$n-1$ 条边 $=\sum$度数 $=2n_2$，解出 $n_2=623$ 再得 $n_0=n-n_2=624$；
5. **做两项数值自检**：$624+623=1247$ ✓（和等于给定总数）；$1247$ 为奇数 ✓（若题给偶数则说明题面或理解有误，因为哈夫曼树结点数只能是奇数）；
6. **用一个小例子对照**：$4$ 个字符构树需 $3$ 次合并、共 $4+3=7=2\times4-1$ 个结点，与公式同型（DS-2022-31 即此例）。

## 6. 详细解答

### 第一步：哈夫曼树的形态约束

哈夫曼树的构造算法（教材 `HuffmanTree`）：

```c
/* 设有 n0 个带权叶子，权值存于 w[1..n0]；哈夫曼树以结点数组 HT 存储 */
HTNode HT[2*n0];            /* HT[0] 不用，结点总数恰为 2*n0-1 */
for (i = 1; i <= n0; i++)   /* 第一步：n0 个单结点森林，左右孩子与双亲均置 0 */
    { HT[i].weight = w[i]; HT[i].parent = HT[i].lchild = HT[i].rchild = 0; }
for (k = n0 + 1; k <= 2*n0 - 1; k++)      /* 共需新建 n0-1 个分支结点 */
{
    Select(HT, k-1, &s1, &s2);            /* 在双亲为 0 的结点中取两棵根权最小的树 */
    HT[s1].parent = HT[s2].parent = k;
    HT[k].lchild = s1;  HT[k].rchild = s2;  HT[k].weight = HT[s1].weight + HT[s2].weight;
}
```

从循环可读出两件事：

1. 新建结点的编号从 $n_0+1$ 到 $2n_0-1$，**每个新结点都同时被赋 `lchild` 与 `rchild`** ⟹ 它的度必为 $2$；原有 $n_0$ 个结点度必为 $0$（它们只能是叶子，因为合并时它们被挂为新结点的孩子后就不再是"根"，也不会再被加上孩子）；
2. 新建结点个数 $=(2n_0-1)-n_0=n_0-1$，即**合并次数为 $n_0-1$**。

故哈夫曼树中 $n_1=0$，结点只分两类：$n_0$ 个叶子与 $n_2=n_0-1$ 个分支结点。

### 第二步：路线一——按构造过程列方程

设叶子数为 $n_0$，由第一步：

$$n=n_0+n_2=n_0+(n_0-1)=2n_0-1 .$$

代入 $n=1247$：

$$2n_0-1=1247\ \Longrightarrow\ n_0=\frac{1247+1}{2}=\frac{1248}{2}=624 .$$

分支结点数 $n_2=1247-624=623$（即合并了 $623$ 次）。

### 第三步：路线二——用二叉树计数性质 $n_0=n_2+1$

性质（与哈夫曼树无关，对任何二叉树成立）：$n_0=n_2+1$。
证明思路：$n=n_0+n_1+n_2$；又树的边数 $=n-1$，同时边数 $=\sum(\text{各结点的度})=n_1+2n_2$（每个结点为它的父结点贡献一条边，按孩子数计边）。两式相减：

$$n_0+n_1+n_2-1=n_1+2n_2\ \Longrightarrow\ n_0=n_2+1 .$$

对哈夫曼树再补上 $n_1=0$：

$$n=n_0+n_2=n_0+(n_0-1)=2n_0-1\ \Longrightarrow\ n_0=\frac{n+1}{2}=624 .$$

结果与路线一相同 ✓（两条路线的差别在于"$n_2=n_0-1$"是从构造过程得出、还是从度数求和得出，来源独立）。

### 第四步：路线三——直接从边数解 $n_2$

由 $n_1=0$ 与"$n$ 个结点的树有 $n-1$ 条边"：

$$2n_2=n-1=1247-1=1246\ \Longrightarrow\ n_2=623,$$
$$n_0=n-n_2=1247-623=624 .$$

第三步与前两步用的是同一个恒等式但求解顺序不同（先定 $n_2$ 再回减），可作为**算术上的独立验算**：$1246/2=623$ 整除成立，说明 $n_1=0$ 的假设与数据自洽 ✓。

### 第五步：数值验算与形态对照

1. **和检验**：$n_0+n_2=624+623=1247=n$ ✓；
2. **性质检验**：$n_0=n_2+1$，即 $624=623+1$ ✓；
3. **奇偶检验**：$n=2n_0-1=2\times624-1=1247$ 为奇数 ✓（哈夫曼树的结点总数不可能为偶数；若题给偶数如 $1248$，则应立刻怀疑题面或"存在度 $1$ 结点"的错误假设）；
4. **小数对照**（同一公式的实例验证）：$4$ 个叶子构造哈夫曼树需 $3$ 次合并，总结点 $=4+3=7=2\times4-1$，与 DS-2022-31 中 `mississippi`（$4$ 种字符）所构树"共 $2n-1=7$ 个结点"完全一致 ✓——本题只是把该关系反过来由 $n$ 求 $n_0$。

### 第六步：常见误算的排除

| 误算写法 | 得数 | 错在哪里 |
|---|---|---|
| $n_0=n/2$ | $623.5$（被迫取 $623$） | 漏了"$-\,1$"，把 $2n_0-1$ 当成 $2n_0$ |
| $n_0=(n-1)/2$ | $623$ | 移项方向错（应由 $2n_0=n+1$ 得 $(n+1)/2$）；$623$ 实际是分支结点数 $n_2$ |
| $n_0=n-1$ | $1246$ | 把"边数"当成叶子数 |
| 按完全二叉树层数推算 | 无法确定 | 哈夫曼树**一般不是**完全二叉树，形态随权值而定，本题无权值 ⟹ 只能靠计数关系，不能靠层 |

其中"$623$"是最有迷惑性的错误答案，它是分支结点（合并次数）的个数，正好比正确答案小 $1$。

（后台另以 C 程序按 `HuffmanTree` 流程对 $n_0=624$ 个叶子构树并统计结点数与叶子数，得总数 $1247$、叶子 $624$、分支 $623$、$n_1=0$；程序仅作验证，本节全部步骤可手工复现。）

## 8. 考场标准答案

**$624$**。

考场书写（两行即可）：哈夫曼树由 $n_0$ 个叶子经两两合并而成，不存在度为 $1$ 的结点，且分支结点数 $n_2=n_0-1$，故

$$n=n_0+n_2=2n_0-1=1247\ \Longrightarrow\ n_0=\frac{1247+1}{2}=624 .$$

## 9. 易错点

1. **移项错 $1$**：由 $2n_0-1=1247$ 应得 $n_0=624$，写成 $n_0=(1247-1)/2=623$ 是本题最常见的失分（$623$ 是分支结点数）；
2. **忘了"$n_1=0$"**：若把一般二叉树的 $n=n_0+n_1+n_2$ 中 $n_1$ 当成未知量，则一个方程两个未知数、题不可解——"哈夫曼树没有度为 $1$ 的结点"正是本题可解的前提，必须写出来；
3. **以为要用权值/画树**：题面没给权值，也不需要画树；哈夫曼树的**形态**依赖权值，但**结点计数关系**与权值无关；
4. **误当满二叉树按层数算**：$2^{10}-1=1023$、$2^{11}-1=2047$，$1247$ 不等于任何 $2^{k}-1$，说明它不可能是满二叉树；哈夫曼树也一般不是完全二叉树，本题无权值 ⟹ 只能靠计数关系，不能往层数上想；
5. **把"叶子数"与"字符数"混为一谈后又漏算**：若题目改为"$m$ 个字符编码"，则叶子数就是 $m$、总结点数是 $2m-1$；本题是反向给总数求叶子，注意方向；
6. **实现细节干扰**：教材实现中数组 `HT` 声明为 $2n_0$ 大小且 `HT[0]` 不用，这只是存储空间分配，**不是**结点多一个，别把数组长度当结点数。

## 10. 一句话规律

哈夫曼树（正则二叉树）三件套：$n_1=0$、$n_2=n_0-1$（等于合并次数）、$n=2n_0-1$（必为奇数）；**已知总数求叶子就用 $(n+1)/2$，并用"$n_0+n_2=n$"与"$n_0=n_2+1$"两式互验**，差 $1$ 的错误立刻暴露。
