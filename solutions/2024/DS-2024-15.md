# DS-2024-15

## 1. 原题

设数组 `S[]={93,946,372,9,146,151,301,485,236,372,43,892}` 。

> 订正说明转录：源文数组因空格处被拆成多段行内代码（作 `S[]={93,946,` 372 `,9,…}`），据源文数据合并为完整一段（元素个数与各值不变）。

（1）采用最低位优先（$LSD$）基数排序将 $S$ 排列成升序序列。写出每一趟排序的结果。

（2）增量等于 $5$ 时进行希尔排序，写出第一趟排序的结果。

（3）以第一个元素为轴进行快速排序，写出第一趟排序结果。

（4）构造小根堆，写出调整后的小根堆。

## 2. 答案

以下序列均按下标 $1\sim12$ 书写，初始 $S=(93,946,372,9,146,151,301,485,236,372,43,892)$。

**（1）LSD 基数排序（基数 $r=10$，三趟分配—收集）**

| 趟 | 按哪一位分配 | 该趟结果 |
|---|---|---|
| 1 | 个位 | $151,301,372,372,892,93,43,485,946,146,236,9$ |
| 2 | 十位 | $301,9,236,43,946,146,151,372,372,485,892,93$ |
| 3 | 百位 | $9,43,93,146,151,236,301,372,372,485,892,946$ |

**（2）希尔排序，增量 $d_1=5$ 的第一趟结果**

$$43,301,372,9,146,93,892,485,236,372,151,946$$

**（3）快速排序，以第一个元素 $93$ 为轴的第一趟（一次划分）结果**

$$43,9,\underline{93},372,146,151,301,485,236,372,946,892$$

枢轴 $93$ 最终落在第 $3$ 个位置，左段 $\{43,9\}$ 全部 $\le 93$，右段 $\{372,146,151,301,485,236,372,946,892\}$ 全部 $\ge 93$。

**（4）调整后的小根堆**

## 3. 题目分析

- 已知：$12$ 个整数的定序表，元素取值均为不超过 $3$ 位的正整数，且 $372$ 出现两次（等值元素）；
- 目标：四个相互独立的小问，都只要求**写出中间过程结果**，不要求写代码——(1) 每一趟、(2)(3)(4) 第一趟/最终堆；
- 关键约束（各小问隐含的"过程规定"）：
  - (1) LSD 表示从最低位开始，每趟"先按当前位分配进 $10$ 个桶、再按桶号从小到大收集"，且**同一桶内保持上一趟的相对次序**（稳定）；
  - (2) "增量等于 $5$ 时的第一趟"指把表分成 $5$ 个间隔为 $5$ 的子序列，各子序列内部作直接插入排序，一趟即完成，不再继续缩小增量；
  - (3) "以第一个元素为轴"即取 $S[1]=93$ 作枢轴，作**一次划分**；本解析采用教材 `Partition` 的"挖坑填数 + 两端交替扫描"实现（结果与交换式实现略有差异，见第 9、12 节）；
  - (4) "构造小根堆"指自底向上、从最后一个非叶结点 $\lfloor n/2\rfloor=6$ 开始逐个向下调整，而不是把元素逐个插入建堆；
- 命题意图：一题覆盖"内部排序的过程可复现性"——基数、希尔、快排、堆四种最易写错过程的算法，考查学生对各算法"趟"的精确定义的执行能力。

## 5. 解题思路

1. **先看数据特征定策略**：全部是 $\le 3$ 位正整数、$n=12$——基数排序需 $3$ 趟（最大值 $946$ 是 $3$ 位数）；希尔、快排、堆都只需按定义机械执行，关键是**每一步都写清依据**，避免跳步出错；
2. (1) 每趟先列表定位数、再分桶、再按桶号收集；收集后**立刻检查桶内相对次序是否与上一趟一致**（稳定性是基数排序唯一的失分点）；
3. (2) 增量 $5$ → 分成 $5$ 组：$(S_1,S_6,S_{11}),\,(S_2,S_7,S_{12}),\,(S_3,S_8),\,(S_4,S_9),\,(S_5,S_{10})$；每组内部插入排序后**放回原位置**（不是把各组结果首尾相接！）；
4. (3) 枢轴 $93$ 先"取出"留下坑，按教材做法**先从右向左找比它小的**填入左坑，再**从左向右找比它大的**填入右坑，交替直到两指针相遇，相遇处即枢轴位置；
5. (4) 最后一个非叶结点编号 $\lfloor 12/2\rfloor=6$，调整顺序为 $6\to5\to4\to3\to2\to1$；每次"调整"是**沿较小子结点一路向下交换**（筛选），不是一层一次交换；
6. 全部做完后各加一道自检：(1) 最后一趟必须整体有序；(2)(3) 元素多重集合不变（尤其两个 $372$ 不能丢）；(4) 逐条验证 $S_i\le S_{2i},S_i\le S_{2i+1}$。

### 第一步：(1) LSD 基数排序

**第 1 趟（按个位分配）**

| 个位 | 分配到的元素（按原次序） |
|---|---|
| 0 | — |
| 1 | $151,\,301$ |
| 2 | $372,\,372,\,892$ |
| 3 | $93,\,43$ |
| 4 | — |
| 5 | $485$ |
| 6 | $946,\,146,\,236$ |
| 7 | — |
| 8 | — |
| 9 | $9$ |

按桶号 $0\to9$ 依次收集：
$$151,301,372,372,892,93,43,485,946,146,236,9$$

**第 2 趟（按十位分配，输入为第 1 趟结果）**

| 十位 | 分配到的元素（按第 1 趟次序） |
|---|---|
| 0 | $301,\,9$ |
| 3 | $236$ |
| 4 | $43,\,946,\,146$ |
| 5 | $151$ |
| 7 | $372,\,372$ |
| 8 | $485$ |
| 9 | $892,\,93$ |

收集：
$$301,9,236,43,946,146,151,372,372,485,892,93$$

**第 3 趟（按百位分配，输入为第 2 趟结果）**

| 百位 | 分配到的元素（按第 2 趟次序） |
|---|---|
| 0 | $9,\,43,\,93$ |
| 1 | $146,\,151$ |
| 2 | $236$ |
| 3 | $301,\,372,\,372$ |
| 4 | $485$ |
| 8 | $892$ |

**自检**：末趟整体升序 ✓；共 $12$ 个元素、两个 $372$ 都在 ✓；第 1 趟中 $372,372$ 的相对次序在后续各趟中始终未变（稳定性）✓。

### 第二步：(2) 希尔排序，增量 $d_1=5$ 的第一趟

按间隔 $5$ 分成 $5$ 组（括号内为原下标）：

| 组 | 下标 | 组内原值 | 组内插入排序后 | 回填结果 |
|---|---|---|---|---|
| 1 | $1,6,11$ | $93,151,43$ | $43,93,151$ | $S_1=43,S_6=93,S_{11}=151$ |
| 2 | $2,7,12$ | $946,301,892$ | $301,892,946$ | $S_2=301,S_7=892,S_{12}=946$ |
| 3 | $3,8$ | $372,485$ | $372,485$（已序） | $S_3=372,S_8=485$ |
| 4 | $4,9$ | $9,236$ | $9,236$（已序） | $S_4=9,S_9=236$ |
| 5 | $5,10$ | $146,372$ | $146,372$（已序） | $S_5=146,S_{10}=372$ |

按位置写回整表：
$$\boxed{43,301,372,9,146,93,892,485,236,372,151,946}$$

**自检**：与初始表比较，元素多重集合相同 ✓；每组内部已有序（如第 1 组 $43<93<151$、第 2 组 $301<892<946$）✓；跨组不作要求，故 $S_4=9$ 仍留在第 $4$ 位——这正是希尔排序"局部有序"的特征。

### 第三步：(3) 快速排序以 $93$ 为轴的第一趟

采用教材 `Partition` 的挖坑填数法：枢轴 $pivot=93$ 暂存于 $S[0]$，$i=1$、$j=12$，$S[1]$ 成为左坑。

| 序号 | 动作 | 说明 |
|---|---|---|
| 1 | $j$ 自右向左找 $<93$ | $S_{12}=892,S_{11}=43$ → 停在 $j=11$ |
| 2 | $S_{11}=43$ 填入左坑 $S_1$ | 表：$43,\_,372,9,146,151,301,485,236,372,\_,892$，右坑在 $11$ |
| 3 | $i$ 自左向右找 $>93$ | $S_2=946$ → 停在 $i=2$ |
| 4 | $S_2=946$ 填入右坑 $S_{11}$ | 左坑在 $2$ |
| 5 | $j$ 继续左移找 $<93$ | $S_{10}=372,S_9=236,S_8=485,S_7=301,S_6=151,S_5=146,S_4=9$ → 停在 $j=4$ |
| 6 | $S_4=9$ 填入左坑 $S_2$ | 右坑在 $4$ |
| 7 | $i$ 继续右移找 $>93$ | $S_3=372$ → 停在 $i=3$ |
| 8 | $S_3=372$ 填入右坑 $S_4$ | 左坑在 $3$ |
| 9 | $j$ 左移，$j=3=i$ | 相遇，划分结束 |
| 10 | 枢轴 $93$ 填入 $S_3$ | 返回枢轴位置 $3$ |

第一趟结果：
$$\boxed{43,9,\mathbf{93},372,146,151,301,485,236,372,946,892}$$

**自检**：枢轴左侧 $\{43,9\}$ 均 $<93$，右侧 $\{372,146,151,301,485,236,372,946,892\}$ 均 $>93$ ✓；$12$ 个元素一个不少 ✓。

### 第四步：(4) 构造小根堆

初始按完全二叉树层序排列（下标 $1\sim12$）：

```
                     1:93
                /             
        2:946                  3:372
      /       \             /        \
   4:9       5:146      6:151      7:301
   /  \      /  \       /  \       /
8:485 9:236 10:372 11:43 12:892
```

（注：下标 $8\sim12$ 分别是 $485,236,372,43,892$；结点 $6$ 只有左孩子 $12$。）

最后一个非叶结点为 $\lfloor 12/2\rfloor=6$，按 $6\to5\to4\to3\to2\to1$ 依次向下调整：

| 调整结点 | 该步比较与交换 | 调整后整表 |
|---|---|---|
| $i=6$（$151$） | 孩子 $S_{12}=892>151$，不交换 | $93,946,372,9,146,151,301,485,236,372,43,892$ |
| $i=5$（$146$） | 孩子 $S_{10}=372,S_{11}=43$，最小 $43<146$ → 交换 $S_5,S_{11}$ | $93,946,372,9,\mathbf{43},151,301,485,236,372,\mathbf{146},892$ |
| $i=4$（$9$） | 孩子 $S_8=485,S_9=236$，最小 $236>9$，不交换 | 同上 |
| $i=3$（$372$） | 孩子 $S_6=151,S_7=301$，最小 $151<372$ → 交换 $S_3,S_6$；$S_6$ 现值 $372$，其孩子 $S_{12}=892>372$，停止 | $93,946,\mathbf{151},9,43,\mathbf{372},301,485,236,372,146,892$ |
| $i=2$（$946$） | 孩子 $S_4=9,S_5=43$，最小 $9<946$ → 交换 $S_2,S_4$；到 $S_4=946$，其孩子 $S_8=485,S_9=236$，最小 $236<946$ → 交换 $S_4,S_9$；$S_9=946$ 无孩子，停止 | $93,\mathbf{9},151,\mathbf{236},43,372,301,485,\mathbf{946},372,146,892$ |
| $i=1$（$93$） | 孩子 $S_2=9,S_3=151$，最小 $9<93$ → 交换 $S_1,S_2$；到 $S_2=93$，其孩子 $S_4=236,S_5=43$，最小 $43<93$ → 交换 $S_2,S_5$；到 $S_5=93$，其孩子 $S_{10}=372,S_{11}=146$，最小 $146>93$，停止 | $\mathbf{9},\mathbf{43},151,236,\mathbf{93},372,301,485,946,372,146,892$ |

最终小根堆：
$$\boxed{9,43,151,236,93,372,301,485,946,372,146,892}$$

**堆性质逐条验证**：
$S_1=9\le(43,151)$ ✓；$S_2=43\le(236,93)$ ✓；$S_3=151\le(372,301)$ ✓；$S_4=236\le(485,946)$ ✓；$S_5=93\le(372,146)$ ✓；$S_6=372\le S_{12}=892$ ✓。全部父子关系满足小根堆条件，且元素多重集合与初始一致 ✓。

**(3) 快排以 $93$ 为轴第一趟**（挖坑填数，枢轴归位到第 $3$ 格）

$$9,43,151,236,93,372,301,485,946,372,146,892$$

## 9. 易错点

1. **(1) 中把"趟"理解成"一次比较"**：LSD 必须做满"最大位数"即 $3$ 趟，且每趟是"全部元素分配 + 全部元素收集"，漏一趟则结果无序；
2. **(1) 中桶内次序被打乱**：同一桶内必须按上一趟的先后次序排列（如第 2 趟十位为 $4$ 的桶是 $43,946,146$，正是它们在第 1 趟结果中的出现顺序），写反即破坏稳定性；
3. **(2) 中把各组排序后的结果首尾相接**成新表（错答 $43,93,151,301,892,946,\dots$）：希尔排序是**原位回填**，第 $1$ 组的三个值分别放到下标 $1,6,11$；
4. **(3) 中扫描顺序颠倒**（先左后右）或忘记"枢轴已挖出、$i=j$ 时必须先把枢轴填回相遇位置"，会得到重复或缺失元素的错误表；
5. **(3) 的实现口径**：若改用"左右各找一个再交换"的交换式划分，同一趟结果为 $9,43,93,372,146,151,301,485,236,372,946,892$——枢轴位置同样是第 $3$ 格，仅左段 $\{43,9\}$ 内部次序不同。两版都属正确的一趟划分，答题时应先声明所用的划分实现；
6. **(4) 中从 $i=1$ 开始调整**：建堆必须从最后一个非叶结点 $\lfloor n/2\rfloor=6$ **倒序**向上，否则一次调整无法保证堆性质；
7. **(4) 中调整只做一层交换就停**：如 $i=2$ 时 $946$ 换到 $S_4$ 后必须继续向下筛选（再与 $S_9=236$ 交换），漏掉这一步得到的不是堆；
8. 忘记 $S_{11}=43$ 是 $S_5$ 的孩子：结点 $5$ 的孩子是 $10,11$，$43$ 恰在此处被换到 $S_5$，是最终堆中"$93$ 的左孩子比 $93$ 大、右孩子 $146$ 也大"这一形态的来源。

## 10. 一句话规律

"写过程"类排序题的通用防错法：**先写出分组/分桶/父子对应的依据，再动笔填数，最后用两条不变式收口**——元素多重集合不变 + 该趟应满足的局部性质（桶内保序、组内有序、枢轴左小右大、父子大小关系）逐条回验。

## 11. 关联知识

- DS06.09：LSD 需 $d$ 趟、每趟 $O(n+r)$，且必须稳定；本题 $r=10,d=3$；
- DS06.05：希尔排序的"一趟"由增量序列决定，$d=5$ 分成 $5$ 组，本例组长为 $3,3,2,2,2$；
- DS06.06：一趟划分后枢轴位置即其最终有序位置，这是"快排第几趟后枢轴在哪"类题的通用结论；
- DS06.07：建堆 $O(n)$ 与"堆的下标父子关系 $i\to 2i,2i+1$"直接用于第 (4) 问；堆排序阶段还要再做 $n-1$ 次"堆顶与末尾交换 + 缩小堆重调"，本题未问；
