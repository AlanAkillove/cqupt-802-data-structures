# DS-2024-05

## 1. 原题

描述以下递归代码的功能。

```c
int func(TreeNode *root)
{
    if(root==NULL)
        return 0;
    if(root->left==NULL&&root->right==NULL)
        return 1;
    return func(root->left)+func(root->right);
}
```

## 2. 答案

**该递归函数统计并返回二叉树中叶子结点（终端结点，即度为 $0$ 的结点）的个数。**

三种出口对应三类子问题：

| 出口 | 条件 | 返回值 | 含义 |
|---|---|---|---|
| 1 | `root == NULL` | $0$ | 空树（空子树）中没有叶子 |
| 2 | `root->left==NULL && root->right==NULL` | $1$ | 当前结点就是叶子，计 $1$ |
| 3 | 其余 | $func(left)+func(right)$ | 非叶结点的叶子数 $=$ 两子树叶子数之和 |

补充（非题目所问，供自检）：时间 $O(n)$（$n$ 为结点数，每个结点被访问恰好一次），空间 $O(h)$（递归工作栈深度，$h$ 为树高；最坏单支树 $O(n)$，最好满树 $O(\log_2 n)$）。

## 3. 题目分析

- 已知：二叉树以**二叉链表**存储（`TreeNode` 含 `left`、`right` 两个孩子指针，题面未给结构体定义但由 `root->left`、`root->right` 可确定）；函数只有一个入口参数、返回 `int`；
- 目标：用一句话说明这段递归做什么——即"读代码 ⟹ 归纳出数学功能"，不需要改写或证明最优性；
- 关键约束（决定答案的是**第二个 `if`**）：
  1. 若只保留出口 1 与出口 3（把 $1+\text{左}+\text{右}$ 写成和），得到的就是教材中"求二叉树**结点总数**"的递归；本题出口 3 是 $func(left)+func(right)$，**没有为内部结点自身加 $1$**，而出口 2 专门为"左右皆空"的结点返回 $1$ ⟹ 计数对象是叶子而非全部结点；
  2. 出口 2 的判据 `left==NULL && right==NULL` 是二叉链表中"度为 $0$"的标准判据；单孩子结点（`left` 与 `right` 恰有一个为空）走出口 3，其返回值来自非空子树，空子树贡献 $0$，故单孩子结点自身不被计数——这正是"叶子数"而不是"结点数"的关键差别；
  3. 递归形态是"先左右、后合并"，即**后序（对称序变体）**框架；叶子判据与合并式都在"访问结点"这一步完成；
- 命题意图：考**递归代码的功能识别**（DS02.07 递归 + DS03.02.03 遍历框架）与**二叉树基本概念中"度/叶子"的判读**（DS03.02.01）。本题设置的对立面是结点总数、树深度这两个"长得几乎一样"的递归模板，判分点在于是否看清"哪一层加了 $1$、哪一层没加"。

解释：主标签落在遍历（DS03.02.03），因为函数结构上就是一次完整的二叉树遍历，唯一的判读难度来自"合并式里加的是谁"；叶子概念本身属 DS03.02.01，故列辅助。这里不涉线索化、不涉由序列重建二叉树，也不涉及具体存储规模计算。

## 5. 解题思路

1. **认出递归模板**：三个分支恰好是"空 ⟹ 基例、叶子 ⟹ 基例、否则左右子结果相加"，与教材两个经典递归（结点总数、树深）同形；
2. **比对差异定功能**：把三个候选功能的递归式写出来并列比较——

| 功能 | 递归式 $F(T)$ |
|---|---|
| 结点总数 | $T=\text{NULL}:0$；否则 $1+F(left)+F(right)$ |
| **叶子个数** | $T=\text{NULL}:0$；$T$ 为叶子：$1$；否则 $F(left)+F(right)$ |
| 树深度 | $T=\text{NULL}:0$；否则 $\max(F(left),F(right))+1$ |

题面给的正是中间一列（叶子分支返回 $1$、内部结点分支**不加** $1$、相加而非取最大再增 $1$），一眼排除"结点总数"（那里内部结点要加 $1$）与"树深度"（那里要 $\max$ 且加 $1$）；

3. **找一棵"能区分三种猜测"的树验证**：选一棵既有叶子、又有单孩子结点的树（第 6 节第二步的 $6$ 结点树），三种猜测各自算出不同结果（叶子数 $2$、结点数 $6$、深度 $4$），用代码实际执行的结果 $2$ 唯一定位到"叶子计数"；
4. **再用独立性质复核**：对该树数出度为 $2$ 的结点数 $n_2=1$，由 $n_0=n_2+1$ 得 $n_0=2$，与代码结果一致（第 6 节第三步）；
5. **写功能表述**：一句话给出"统计叶子结点个数"，并补一句"空树返回 $0$"以显出边界处理（答题时把返回值含义写清，不要只写"遍历二叉树"）。

## 6. 详细解答

### 第一步：递归式的形式化

设 $F(T)$ 为该函数在二叉树 $T$ 上的返回值，则

$$F(T)=\begin{cases}0, & T\ \text{为空树}\\[2pt] 1, & T\ \text{非空且 } root\text{ 的左右孩子皆空}\\[2pt] F(T_{left})+F(T_{right}), & \text{ otherwise}\end{cases}$$

**断言**：$F(T)=n_0(T)$（$T$ 中叶子结点个数）。

**归纳证明**（对结点数 $|T|$ 归纳）：
- $|T|=0$：空树 $n_0=0=F(T)$ ✓；$|T|=1$：单结点即叶子，$n_0=1=F(T)$ ✓；
- 设结论对所有结点数 $<k$ 的树成立；考虑 $|T|=k$。
  - 若 $root$ 为叶子（两子树皆空），$n_0(T)=1=F(T)$ ✓；
  - 若 $root$ 非叶子，$root$ 自身不是叶子，故 $n_0(T)=n_0(T_{left})+n_0(T_{right})$（叶子恰好完整分布在两棵子树中，不重不漏）；两棵子树结点数均 $<k$，由归纳假设 $n_0(T_{left})=F(T_{left})$、$n_0(T_{right})=F(T_{right})$，于是 $n_0(T)=F(T_{left})+F(T_{right})=F(T)$ ✓。$\blacksquare$

### 第二步：实例展开（区分三种可能的功能猜测）

取二叉树（叶子为 $4$、$6$；结点 $2,3,5$ 都只有 $1$ 个孩子，$1$ 有 $2$ 个孩子）：

```
        1
      /   \
     2     3
    /       \
   4         5
              \
               6
```

按代码逐层展开（右列注明命中的出口）：

| 调用 | 命中的出口 | 返回 |
|---|---|---|
| `func(NULL)`（结点 $2$ 的右孩子） | 出口 1 | $0$ |
| `func(4)` | 出口 2（左右皆空） | $1$ |
| `func(2)` | 出口 3 | $func(4)+func(NULL)=1+0=1$ |
| `func(NULL)`（结点 $3$ 的左孩子） | 出口 1 | $0$ |
| `func(NULL)`（结点 $5$ 的左孩子） | 出口 1 | $0$ |
| `func(6)` | 出口 2 | $1$ |
| `func(5)` | 出口 3 | $0+1=1$ |
| `func(3)` | 出口 3 | $0+1=1$ |
| `func(1)` | 出口 3 | $1+1=2$ |

**函数返回 $2$。** 三种候选功能在这棵树上的取值分别是：叶子数 $2$、结点总数 $6$、树深度 $4$（根在第 $1$ 层）——只有"叶子数"与实测结果吻合，故功能确定为**统计叶子结点个数**，且这棵树确实起到了"把三个易混答案分开"的判别作用。

### 第三步：用另一条性质交叉验证

该树中度为 $2$ 的结点只有 $1$ 个（结点 $1$），即 $n_2=1$；由二叉树的性质 $n_0=n_2+1$ 得

$$n_0=1+1=2,$$

与第二步代码返回的 $2$ 一致 ✓（这一验证完全独立于代码执行，只用了 DS03.02.01 的计数性质）。

再验两个小情形：
- 空树：`func(NULL)` $=0$，$n_0=0$ ✓；
- 单结点树：命中出口 2 返回 $1$，$n_0=1$（此时 $n_2=0$，$n_0=n_2+1=1$ 亦吻合）✓；
- 左单支 $3$ 结点树 $a\to b\to c$（全为左孩子）：叶子只有 $c$ ⟹ 应返回 $1$；执行 `func(a)=func(b)+0`，`func(b)=func(c)+0=1` ⟹ 返回 $1$ ✓（说明"单孩子结点不被计数"这一行为符合定义）。

（后台另以 C 程序实现 `func` 与一个"直接遍历数叶子"的参照实现 `naiveLeaves`，在上述 $6$ 结点树上同时得到 $2$，并对空树、单结点树结果一致；程序仅作验证，正文全部步骤可手工复现。）

### 第四步：复杂度（供自检与延伸作答）

- 每个结点恰好被访问一次，每次访问做常数次判断与相加 ⟹ 时间 $O(n)$（$n$ 为结点数）；
- 递归工作栈深度等于树高 $h$ ⟹ 空间 $O(h)$：满二叉树 $h=\lceil\log_2(n+1)\rceil$ 时 $O(\log_2 n)$，单支树时退化到 $O(n)$。

## 8. 考场标准答案

**功能**：以二叉链表存储的二叉树中，**统计叶子结点（度为 $0$ 的结点）的个数**并返回。

- `root==NULL`：空树（或某结点的空子树），叶子数为 $0$；
- `root->left==NULL && root->right==NULL`：当前结点为叶子，返回 $1$；
- 否则（$root$ 为度为 $1$ 或 $2$ 的非叶结点，自身不计）返回左、右子树的叶子数之和。

即 $F(T)=n_0(T)$。特别地：空树返回 $0$，只有根结点的树返回 $1$。

时间复杂度 $O(n)$（每个结点访问一次），空间复杂度 $O(h)$（$h$ 为树高，即递归栈深度；最坏 $O(n)$）。

## 9. 易错点

1. **答成"统计二叉树的结点总数"**：结点总数的递归式在非叶分支要写 $1+func(left)+func(right)$（为当前结点自己加 $1$），本题出口 3 **没有**这个 $+1$，加 $1$ 的位置被限制在"叶子"分支里，故只数叶子；
2. **答成"求二叉树的深度/高度"**：深度递归用 $\max(\cdot,\cdot)+1$，本题用加法 $+$ 不加 $1$，两者在上面的判别树上结果不同（$2$ 与 $4$）；
3. **答成"统计度为 $1$ 的结点数"**：恰好相反——单孩子结点走出口 3，返回的是子树的叶子数，其自身从不产生 $1$；
4. **忽略 `root==NULL` 这个基例**：若少了它，对空子树的调用会解引用空指针；它同时保证"非满二叉树"也能正确计数（每个空子树贡献 $0$）；
5. **表述含糊丢分**：只写"遍历二叉树""递归求值"不得分，必须写明**计数对象是叶子结点**、以及返回值是什么；把"终端结点/度为 $0$ 的结点"这一同义表述一并写出更稳。

## 10. 一句话规律

识别"三行式"二叉树递归的功能，只需盯两点：**① 非叶分支的合并式是加法还是 $\max$、有没有给当前结点再 $+1$；② 基例里那个 $\text{return }1$ 的判据是谁（空？叶子？）**。$F=F_{左}+F_{右}$ 且叶子返 $1$ ⟹ 数叶子；$F=F_{左}+F_{右}+1$ ⟹ 数结点；$F=\max(F_{左},F_{右})+1$ ⟹ 求深度。三个模板只差一处，务必对比着记。
