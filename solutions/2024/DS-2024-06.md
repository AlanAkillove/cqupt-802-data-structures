# DS-2024-06

## 1. 原题

设循环队列的表长为 $n$ , $f$ 指向元素的前一个位置， $r$ 指向最后一个元素的位置。该循环队列的长度为____________________。

## 2. 答案

$$\boxed{(r-f+n)\bmod n}$$

等价的分段写法：$r\ge f$ 时长度为 $r-f$；$r<f$（元素跨过数组尾部回绕）时长度为 $r-f+n$。

## 3. 题目分析

- **已知**：循环队列用表长（数组长度）为 $n$ 的一维数组实现，下标取 $0\sim n-1$，一切下标推进按模 $n$ 回绕；队头指针 $f$ 指向**队头元素的前一个位置**（$f$ 本身不是元素），队尾指针 $r$ 指向**最后一个元素的位置**（$r$ 本身是元素）；
- **目标**：写出队列长度（当前元素个数）关于 $f$、$r$、$n$ 的表达式——只含两个下标与表长的封闭公式；
- **关键约束**（全部由题面给的指针语义决定）：
  1. 元素占据的区间是"开左闭右"的循环区间 $f+1,\ f+2,\ \dots,\ r \pmod n$，即从 $f$ **再走一格**才开始数、数到 $r$ **含** $r$ 为止；
  2. 由语义 1 直接得到队空条件是 $r==f$（区间退化为一格不数），队满条件是 $(r+1)\bmod n == f$（$r$ 的下一格撞上 $f$，需**牺牲一个单元**区分空与满）；
  3. 长度必须落在 $0\sim n-1$，故所求公式在 $r<f$ 时不能给负值——这是"必须先加 $n$ 再取模"的原因；
- **命题意图**：表面是写一个式子，实质考**循环队列两指针语义与环形下标距离**（DS02.02）。题面刻意给出"前一位置/最后元素位置"这一**非教材主用**的约定（教材主用"$front$ 指队头元素、$rear$ 指队尾元素的下一位置"），考查考生是否真按语义数格子，而不是死背 $(rear-front+n)\bmod n$ 的形式。

## 4. 核心考点

核心考点：
DS02.02 栈和队列的顺序存储结构——循环队列中 $front$/$rear$ 的三种基本量（队空条件、队满条件、元素个数）随指针语义的变化，以及"加表长再取模"这一环形距离的标准写法

辅助考点：

解释：主标签落在 DS02.02，因为本题答案就是循环队列的求长公式，属该结构定义性内容之一；不涉及链队（DS02.03）与数组/串等其他结构。DS02.01 只作概念支撑，故列辅助而非主标签。

## 5. 解题思路

1. **先把语义翻译成"数哪几格"**：$f$ 不是元素、$r$ 是元素 ⟹ 元素为 $f+1,\dots,r$（循环意义下），"长度"就是从 $f$ 出发沿 $+1$ 方向走到 $r$ 需要跨过的**步数**；
2. **按是否回绕分两情形**：
   - 未跨数组尾（$r\ge f$）：步数 $=r-f$；
   - 跨数组尾（$r<f$）：先走 $f\to n-1$ 用去 $(n-1)-(f+1)+1=n-f-1$ 格（等价地，从 $f$ 前进到 $n-1$ 需 $n-1-f$ 步，再 $1$ 步到 $0$，再 $r+1$ 步到 $r$），合计 $r-f+n$；
3. **合并**：两种情形统一为 $(r-f+n)\bmod n$——加 $n$ 保证被除数非负，取模保证结果落在 $[0,n-1]$，两段的取值区间互不重叠，故合并无损（第 6 节第二步逐段验证）；
4. **代具体数验算**：取 $n=8$，用四组 $(f,r)$ 手工点数格子上界与公式值比对，特别检查"跨界"与"队满"两个极端；
5. **与队满/队空条件互相印证**：把 $r==f$ 与 $(r+1)\bmod n==f$ 代入公式，应分别得 $0$ 与 $n-1$，与"牺牲一个单元"的容量口径一致——这构成一条**独立于点数法**的验证路线。

## 6. 详细解答

### 第一步：由指针语义确定元素区间

设数组为 $Q[0..n-1]$。按题面约定，入队与出队的动作是"先动指针再存/取"：

```c
#define n 8                                   // 表长（循环队列数组长度）
typedef struct {
    QElemType data[n];
    int f, r;                                 // f 指队头元素的前一位置，r 指队尾元素位置
} CirQueue;

void EnQueue(CirQueue *Q, QElemType e) {      // 入队：r 先前进，再存放
    if ((Q->r + 1) % n == Q->f) { /* 队满，溢出 */ return; }
    Q->r = (Q->r + 1) % n;
    Q->data[Q->r] = e;
}
void DeQueue(CirQueue *Q, QElemType *e) {     // 出队：f 先前进，再取出
    if (Q->r == Q->f) { /* 队空 */ return; }
    Q->f = (Q->f + 1) % n;
    *e = Q->data[Q->f];
}
```

由 `EnQueue` 可见：新元素总是放在 $r$ 前进后的位置，故 $r$ 处**有**元素；由 `DeQueue` 可见：被取出的元素在 $f$ 前进后的位置，故 $f$ 处**无**（有效）元素。于是元素集合恰为循环区间

$$\{\,i \mid i \equiv f+1,\ f+2,\ \dots,\ r \pmod n\,\},$$

长度即"从 $f$ 到 $r$ 沿 $+1$ 方向的前进步数"。

### 第二步：分情形计数并合并

**情形 A（$r\ge f$，未回绕）**：元素占 $f+1,\dots,r$，共

$$L = r-(f+1)+1 = r-f .$$

**情形 B（$r<f$，回绕）**：元素分两段——尾段 $f+1,\dots,n-1$ 共 $(n-1)-(f+1)+1=n-f-1$ 个；首段 $0,\dots,r$ 共 $r-0+1=r+1$ 个。合计

$$L=(n-f-1)+(r+1)=r-f+n .$$

**合并为取模式**：令 $L_0=(r-f+n)\bmod n$。

- 情形 A 中 $r-f\in[0,\,n-1]$，故 $r-f+n\in[n,\,2n-1]$，模 $n$ 得 $r-f$ ✓（与 A 一致）；
- 情形 B 中 $r-f\in[-(n-1),\,-1]$，故 $r-f+n\in[1,\,n-1]$，该区间已在 $[0,n-1]$ 内，模 $n$ 不变，得 $r-f+n$ ✓（与 B 一致）。

两情形均被覆盖且互斥（$r\ge f$ 与 $r<f$），故

$$L=(r-f+n)\bmod n .$$

（若不写取模而写分段式，须注意"$r=f$"归入情形 A 得 $0$，即空队。）

### 第三步：四组具体值验算（取 $n=8$，下标 $0\sim 7$）

| $f$ | $r$ | 元素所在下标（从 $f{+}1$ 数到 $r$） | 手工点数 | 公式值 $(r-f+8)\bmod 8$ | 一致 |
|---|---|---|---|---|---|
| $0$ | $3$ | $1,2,3$ | $3$ | $(3-0+8)\bmod 8=3$ | ✓ |
| $3$ | $1$ | $4,5,6,7,0,1$（回绕） | $6$ | $(1-3+8)\bmod 8=6$ | ✓ |
| $5$ | $5$ | 无（空队） | $0$ | $(5-5+8)\bmod 8=0$ | ✓ |
| $1$ | $0$ | $2,3,4,5,6,7,0$（队满） | $7$ | $(0-1+8)\bmod 8=7$ | ✓ |

第二行是"必须回绕"的典型：若漏掉加 $n$，会算出 $1-3=-2$；第三、四行是两个端点：空队与队满。

### 第四步：与队空/队满条件的独立印证（第二条验证路线）

本题约定下：

- **队空** $r=f$：代入得 $(0+n)\bmod n=0$ ✓（空队长度 $0$）；
- **队满** $(r+1)\bmod n=f$，即 $r\equiv f-1\pmod n$：
  - 若 $f\ge 1$，则 $r=f-1<f$，属情形 B，$L=r-f+n=n-1$；
  - 若 $f=0$，则 $r=n-1\ge f$，属情形 A，$L=n-1-0=n-1$；
  两种位置都给出 $L=n-1$ ✓——恰为"牺牲一个单元"时循环队列的实际最大容量，说明公式在整个可达状态空间内与结构定义自洽，无须为边界另加分支。

### 第五步：与教材另一约定的对照（防止背错式子）

教材常用约定：$front$ 指队头元素所在下标、$rear$ 指**队尾元素的下一个位置**，此时元素区间为 $[\,front,\ rear)$，长度同样是

$$L=(rear-front+n)\bmod n .$$

两约定的关系是 $f\equiv front-1$、$r\equiv rear-1\pmod n$：**两个指针同时前移一格，差值不变**，故公式形式恰好相同。但若是"混合"约定（$front$ 指队头元素本身、$rear$ 指队尾元素本身，即两端都含），元素个数为 $(r-f+n)\bmod n+1$，与本题答案差 $1$。这说明本题的 $\bmod$ 式必须由**题面语义**推出，不能凭"公式长这样"直接默写。

（后台另以 C 程序实现本约定的 `EnQueue/DeQueue`，对上述四组 $(f,r)$ 用"逐步推进指针并实际存放/取出元素"的方式数出元素个数，与公式值全部一致；程序仅作验证，本节五步均可手工复现。）

## 8. 考场标准答案

$$(r-f+n)\bmod n$$

理由（考场书写一句话即可）：$f$ 不是元素、$r$ 是元素，元素占循环区间 $f+1\sim r$；$r\ge f$ 时个数 $=r-f$，$r<f$ 时个数 $=r-f+n$，统一写成 $(r-f+n)\bmod n$。

自检：空队 $r=f$ 时得 $0$；队满 $(r+1)\bmod n=f$ 时得 $n-1$，与"表长 $n$ 最多存 $n-1$ 个元素"吻合。

## 9. 易错点

1. **漏掉 $\bmod$（只写 $r-f$）**：元素回绕到数组前端时 $r<f$，式子给出负数，而长度不可能为负——这是本题最主要的丢分点；
2. **方向写反**（写成 $(f-r+n)\bmod n$）：$f$ 是"起点前一格"、$r$ 是"终点格"，前进方向是自 $f$ 到 $r$，反过来得到的是"空格数减一"；
3. **$\pm 1$ 错位**：把 $f$ 也数进元素里会得到 $r-f+1$；把 $r$ 误解为"队尾元素的下一个位置"则会得 $r-f-1$。务必按题面确认"哪一端是元素、哪一端不是"；
4. **把表长 $n$ 当成能存 $n$ 个元素**：本约定用 $r==f$ 判空、$(r+1)\bmod n==f$ 判满，须牺牲一个单元，最多存 $n-1$ 个；若答案写成能取到 $n$，就与队满状态矛盾；
5. **分段式边界漏项**：写成"$r>f$ 时 $r-f$，$r<f$ 时 $r-f+n$"而漏掉 $r=f$（空队）这一档，虽不影响取模式，但分段写法必须覆盖 $0\sim n-1$ 全部可能。

## 10. 一句话规律

循环结构里"两个下标之间隔了几个"一律先按题面确认**两端各自是不是元素**，再写成 $(\text{终}-\text{起}+\text{表长})\bmod\text{表长}$；把空、满两个极端状态代入验一遍，$\pm 1$ 与是否取模立刻自检完成。
