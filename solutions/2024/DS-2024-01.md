# DS-2024-01

## 1. 原题

有一个整数 $n$ ，其中 $n$ 为 $2$ 的幂。程序通过如下代码计算 $count$ 的值，并返回。请分析并给出该代码的时间复杂度。

```c
int get_count(int n)
{
    int count=0;
    int x=2;
    while(x<n/2)
    {
        x*=x;
        count++;
    }
    return count;
}
```

## 2. 答案

时间复杂度 $T(n)=O(\log_2\log_2 n)$，即**双重对数阶**（常写作 $O(\log\log n)$）。

循环次数（函数返回值）的精确表达式：设 $n=2^{m}$，则 $count=\lceil \log_2 (m-1)\rceil=\lceil \log_2(\log_2 n-1)\rceil$（$m\ge 2$）；$n=2$ 时循环一次也不执行，$count=0$。

## 3. 题目分析

- 已知：$n$ 是 $2$ 的幂（题面明确给出，这一条件让 $n/2$ 为精确的 $2^{m-1}$，也让"取对数"这一步不产生取整歧义）；循环变量初值 $x=2$；循环体只做两件事——`x*=x`（自乘）与 `count++`，均为 $O(1)$；循环条件 `x<n/2`；
- 目标：给出这段代码的时间复杂度。时间复杂度在此等于"循环体的执行次数 $\times$ 每轮常数代价"，所以**本题唯一的实质问题是数清循环跑了几轮**；
- 关键约束：
  1. 每轮 $x$ 变为**自身的平方**，而不是自身的两倍——$x$ 的序列是 $2,4,16,256,65536,\cdots$，增长是"指数套指数"；
  2. 判定用的是 $x$ 与 $n/2$ 的大小关系，$count$ 只是计数器，不参与循环控制；
  3. 循环可能在某轮之后 $x$ 已超过 `int` 表示范围（$2^{32}$ 溢出），但这不影响"多少轮退出"的数学结论，也不影响渐近阶；
- 命题意图：表面是"分析时间复杂度"，实质是考 DS00.02 中最核心的一个动作——**由循环变量的更新方式读出它的生长速率，再反解出轮数**。$\Theta(\log_2\log_2 n)$ 这一阶在教材中不多见，命题人正是用它来区分"背过几种典型循环"与"真会算语句频度"。

## 4. 核心考点

核心考点：
DS00.02 算法与算法分析——语句频度（循环体执行次数）、$T(n)=O(f(n))$ 的定义、由循环变量更新式（$x\leftarrow x^{2}$）确定增长阶

解释：整段代码没有任何数据结构（无表、无树、无图、无数组），只有一个 `while` 循环，全部解题动作是"写通项 → 解不等式 → 取对数"，落在教材第 1 章"算法的效率"这一节点上。

辅助考点：无（不需要任何其他章节知识；`n/2` 的整数除法性质属程序设计常识）。

## 5. 解题思路

1. **找循环不变量**：把 $x$ 在各轮结束时的值列出来——$2,4,16,256,65536,\cdots$，认出规律 $x$ 第 $k$ 轮后等于 $2^{2^{k}}$（可用归纳法一句话证明）；
2. **写终止条件**：设 $n=2^{m}$，则 $n/2=2^{m-1}$；循环在"$x$ 首次不小于 $2^{m-1}$"时停止，即求最小 $k$ 使 $2^{2^{k}}\ge 2^{m-1}$；
3. **两次取对数解不等式**：$2^{2^{k}}\ge 2^{m-1}\iff 2^{k}\ge m-1\iff k\ge\log_2(m-1)$，故 $count=\lceil\log_2(m-1)\rceil$；
4. **换回 $n$**：$m=\log_2 n$，于是 $count=\lceil\log_2(\log_2 n-1)\rceil=\Theta(\log_2\log_2 n)$；
5. **自检**：代几个具体的 $n$（$8,16,1024,2048$）手工模拟循环轮数，与公式逐项对齐（见第 6 节第三步）。

## 6. 详细解答

### 第一步：$x$ 的通项

记第 $k$ 轮循环体执行完毕后 $x$ 的值为 $x_k$，$x_0=2$（进入循环前的初值）。由 `x*=x` 得 $x_{k}=x_{k-1}^{2}$。

归纳证明 $x_k=2^{2^{k}}$：$k=0$ 时 $2^{2^{0}}=2=x_0$；设 $k-1$ 成立，则
$$x_k=\left(2^{2^{k-1}}\right)^{2}=2^{2^{k-1}\cdot 2}=2^{2^{k}}.\qquad\blacksquare$$

列出前若干项（这是本题唯一的"数据"）：

| 轮次 $k$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| $x_k=2^{2^k}$ | $2$ | $4$ | $16$ | $256$ | $65536$ | $2^{32}=4294967296$ |

### 第二步：解出循环次数

设 $n=2^{m}$（题面保证 $n$ 为 $2$ 的幂），则 $n/2=2^{m-1}$，整数除法无余数。

循环体第 $k$ 轮（$k\ge 1$）**执行的前提**是执行前 $x_{k-1}<2^{m-1}$；循环结束时 $count$ 是使 $x_{count}\ge 2^{m-1}$ 成立的最小非负整数，即

$$2^{2^{count}}\ \ge\ 2^{m-1}\ \Longleftrightarrow\ 2^{count}\ \ge\ m-1\ \Longleftrightarrow\ count\ \ge\ \log_2(m-1).$$

取最小的整数 $count$：

$$count=\left\lceil \log_2 (m-1)\right\rceil=\left\lceil \log_2(\log_2 n-1)\right\rceil\quad(m\ge 2).$$

当 $m=1$（$n=2$）时 $n/2=1$，$x_0=2\not<1$，循环不执行，$count=0$（此时 $m-1=0$，上式对数无定义，须单列）。

### 第三步：验算（逐值模拟与公式对照）

| $n$ | $m=\log_2 n$ | $n/2$ | 手工模拟：$x$ 的变化与轮数 | 模拟 $count$ | 公式 $\lceil\log_2(m-1)\rceil$ | 一致 |
|---|---|---|---|---|---|---|
| $4$ | $2$ | $2$ | $2\not<2$，不进循环 | $0$ | $\lceil\log_2 1\rceil=0$ | ✓ |
| $8$ | $3$ | $4$ | $2<4$ → $x=4$（1 轮）；$4\not<4$ 停 | $1$ | $\lceil\log_2 2\rceil=1$ | ✓ |
| $16$ | $4$ | $8$ | $2<8\to4$；$4<8\to16$；$16\not<8$ 停 | $2$ | $\lceil\log_2 3\rceil=2$ | ✓ |
| $64$ | $6$ | $32$ | $2\to4\to16\to256$，$256\ge32$ 停 | $3$ | $\lceil\log_2 5\rceil=3$ | ✓ |
| $1024$ | $10$ | $512$ | $2\to4\to16\to256\to65536$，$65536\ge512$ 停 | $4$ | $\lceil\log_2 9\rceil=4$ | ✓ |
| $2048$ | $11$ | $1024$ | $2\to4\to16\to256\to65536$，$65536\ge1024$ 停 | $4$ | $\lceil\log_2 10\rceil=4$ | ✓ |
| $2^{32}$ | $32$ | $2^{31}$ | $x$ 依次为 $2,4,16,256,65536,2^{32}$ | $5$ | $\lceil\log_2 31\rceil=5$ | ✓ |

（后台以程序对 $n=2^{m}$、$m=1\sim 26$ 逐值模拟，$count$ 与公式 $\lceil\log_2(m-1)\rceil$ 全部吻合；程序仅作验证，上表全部可手工复现。）

### 第四步：给出时间复杂度

循环体每轮做常数次工作（一次自乘、一次自增），故整段代码的语句频度

$$T(n)=\Theta(count)=\Theta\!\left(\log_2(\log_2 n-1)\right)=\boxed{O(\log_2\log_2 n)}.$$

直观检验：$n$ 从 $2^{10}=1024$ 涨到 $2^{20}$ 再涨到 $2^{40}$，$\log_2\log_2 n$ 只从 $3.3$ 变到 $4.3$、$5.3$——轮数几乎不增长，这正是双重对数阶的特征，也与表中 $n=2^{32}$ 时仍只需 $5$ 轮一致。

## 8. 考场标准答案

进入循环前 $x_0=2$；由 `x*=x` 得 $x_k=x_{k-1}^{2}=2^{2^{k}}$（归纳可证）。

设 $n=2^{m}$，则循环条件为 $2^{2^{k}}<2^{m-1}$，即 $2^{k}<m-1$。循环结束时 $count$ 是使 $2^{k}\ge m-1$ 的最小 $k$：

$$count=\lceil \log_2 (m-1)\rceil=\lceil \log_2(\log_2 n-1)\rceil .$$

每轮 $O(1)$ 工作，故

$$T(n)=O(\text{轮数})=O(\log_2\log_2 n ).$$

（例：$n=1024$ 时 $count=4$；$n=2^{32}$ 时 $count=5$。）

## 9. 易错点

1. **把 `x*=x` 看成 `x*=2` 或 `x+=x`**：那是 $x$ 每轮翻倍 ⟹ $\lceil\log_2 n\rceil$ 轮，答成 $O(\log_2 n)$。本题 $x$ 每轮**平方**，取一次对数就把"平方"降成"乘 2"，再取一次对数才得到轮数，故是**两层**对数；
2. **答成 $O(n)$ 或 $O(n/2)$**：误以为循环次数与 $n$ 成正比，忽略了 $x$ 的增长速度远超线性；
3. **在"取对数"时少减一个 $1$**：条件是 $x<n/2$ 而不是 $x<n$，写成 $\lceil\log_2\log_2 n\rceil$ 作为精确轮数在个别 $n$ 上会差 $1$（如 $n=16$：精确值 $2$，$\lceil\log_2\log_2 16\rceil=\lceil 1\rceil=1$ 就错了）；不过作为渐近阶两者同为 $O(\log_2\log_2 n)$，不影响复杂度结论；
4. **被 `int` 溢出带偏**：$x$ 到 $2^{32}$ 已超出 `int` 范围，但题目问的是这段代码的时间复杂度，按"每轮 $O(1)$、轮数由数学关系确定"分析即可，不必（也无法）据此改变结论；
5. **忘记 $n=2$ 的退化情形**：$n/2=1$，$x=2$ 一开始就不满足条件，$count=0$——讨论精确表达式时要单列。

## 10. 一句话规律

单变量循环的复杂度只看**循环变量的更新方式**：$x\leftarrow x+1$ 是 $O(n)$，$x\leftarrow 2x$ 是 $O(\log_2 n)$，$x\leftarrow x^{2}$ 是 $O(\log_2\log_2 n)$，$x\leftarrow\sqrt{x}$ 则反向为 $O(\log_2\log_2 n)$（从 $n$ 缩到常数需两层对数轮）；解题动作永远是"写通项 → 与边界比较 → 解出轮数"。
