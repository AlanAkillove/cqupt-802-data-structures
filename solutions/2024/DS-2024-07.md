# DS-2024-07

## 1. 原题

将中缀表达式 $a + b - a *(( c + d ) / e - f ) + g$ 转换为后缀表达式。

## 2. 答案

**后缀表达式为** `ab+acd+e/f-*-g+`

（紧凑写法共 $15$ 个字符：$8$ 个操作数 $a,b,a,c,d,e,f,g$ 与 $7$ 个运算符，其中 `+` 三个、`-` 两个、`*` 一个、`/` 一个；操作数的相对次序与中缀完全一致。）

## 3. 题目分析

- **已知**：中缀表达式 `a+b-a*((c+d)/e-f)+g`；操作数为单字母变量 $a\sim g$（其中 $a$ 出现两次）；运算符为 `+ - * /` 四则运算与两层圆括号；
- **目标**：写出等价的后缀表达式（逆波兰式），使两者对同一组赋值给出相同结果、且隐含的运算结合次序完全一致；
- **关键约束**（决定结果的三条规则）：
  1. **优先级**：`* /` 高于 `+ -`；
  2. **左结合**：同级运算自左向右，故开头的 `a + b - X + g` 必须读作 $((a+b)-X)+g$，**不是** $a+b-(X+g)$；
  3. **括号**：圆括号改变优先级，且最内层 `(c+d)` 先算，其结果作为 `/e` 的左对象，再减 $f$，整个 `((c+d)/e-f)` 作为 `a*` 的右对象；
  4. 后缀式中**不写括号**——原式中的 `(` `)` 只是优先级信息，转换后必须消失；结果串长度 $=$ 操作数个数 $+$ 运算符个数 $=8+7=15$；
- **命题意图**：考**栈作为表达式转换/求值的实现手段**（DS02.07）。本题的判别难度集中在两处：① `a+b-` 之后紧接 `a*(...)`，减号的右操作数是一整棵子树，处理时须把 `*` 连同括号内全部运算先"吞掉"再输出减号；② 结尾的 `+g` 是加在最外层，不能误挂到括号内部。这两处也正是本题与"简单三段式"转换题的差别。

## 4. 核心考点

核心考点：
DS02.07 栈、队列和数组的应用——表达式求值/改写中"操作数直接输出、运算符按优先级压栈与弹出"的调度过程，以及括号只作定界不入结果的规则

辅助考点：
DS02.01 栈和队列的基本概念——运算符栈的 LIFO 特性是"后压入的高优先级算符先弹出"、"左括号作为界标把栈分段"这两条机制的依据
DS03.02.03 二叉树的遍历——表达式（二叉树）与三种表达式的对应关系：中序＝中缀（加括号）、后序＝后缀、先序＝前缀；后序遍历的"先左、后右、再根"正是后缀式中运算符落在其两操作数之后的原因

解释：主标签落在 DS02.07，因为本题是教材 4.2.2"表达式计算"一节的直接考法；表达式树解法虽属于树章节，但它是同一转换问题的另一种实现视角，故列辅助。这里不涉及 DS02.02 的顺序栈实现细节（不考下标推进），故不另列。

## 5. 解题思路

1. **先给原式补全括号，把隐式结合次序显式化**：按左结合与优先级，原式等价于
   `((a+b) - (a*(((c+d)/e) - f))) + g`；
   这一步做完，后缀式已能"看"出来——每个运算符都紧跟在它的两个操作数之后；
2. **选一条主路线转换**（考场上推荐算符栈法，因为它可逐字扫描、不易丢字符）：自左向右扫描，操作数直接抄到输出串，运算符按"栈顶优先级不低于自己就先弹出、否则压栈；左括号直接压栈；右括号则一直弹出到遇到左括号"处理；
3. **用表达式树法复核**：把第 1 步的括号化式子画成二叉树（内部结点为运算符，叶子为变量），取**后序遍历**即得后缀式，与第 2 步结果比对；
4. **结构自检**：数一遍操作数与运算符个数（应分别为 $8$ 与 $7$，且与中缀一致）；从左向右扫后缀式，维护"可用结果数 $=操作数累计-运算符累计$"，要求中途恒 $\ge 1$、结束时恰为 $1$；
5. **语义自检**：取两组具体赋值，分别按中缀（按括号算）与按后缀（栈式求值）计算，两组数值都应相等；
6. **反向复核**：把后缀式还原为中缀（每个运算符把刚生成的两个子表达式包起来），应得到第 1 步完全带括号的原式。

## 6. 详细解答

### 第一步：显式化运算次序

原式 `a+b-a*((c+d)/e-f)+g`，按"先乘除后加减、同级左结合、括号优先"标注运算发生的先后：

| 顺序 | 运算 | 说明 |
|---|---|---|
| 1 | `c+d` | 最内层括号 |
| 2 | `(c+d)/e` | 括号内先除 |
| 3 | `((c+d)/e)-f` | 括号内后减 |
| 4 | `a+b` | 最外层第一个加（左结合先算）；该行与 1~3 行互不依赖，先后可交换 |
| 5 | `a*(...)` | 乘法高于减法，第 3 步结果与之相乘 |
| 6 | `(a+b)-(第5步)` | 外层减 |
| 7 | `(...)+g` | 外层加，最后进行 |

即原式 $=$ `(((a+b)-(a*(((c+d)/e)-f)))+g)`。

### 第二步：路线一——表达式树与后序遍历

按第一步的层次建树（运算符为内部结点，左/右孩子依次为其左/右操作数，变量为叶子）：

```
                    [+]
                /        \
            [-]            g
           /    \
       [+]        [*]
       /  \       /   \
      a    b     a    [-]
                     /    \
                   [/]      f
                   /  \
                [+]     e
                /  \
               c    d
```

（根的左子树是 `[-]`，其左孩子 `[+]` 对应 `a+b`、右孩子 `[*]` 对应 `a*(...)`；`[*]` 的右孩子 `[-]` 对应 `((c+d)/e)-f`，其左孩子 `[/]` 对应 `(c+d)/e`，`[/]` 的左孩子 `[+]` 对应 `c+d`。）

**后序遍历（左→右→根）**，逐结点写出访问序列：

- 左子树最深处：`c d +` → 访问 `[+]`；再访问其右兄弟 `e`，访问 `[/]` ⟹ `c d + e /`；
- 接着 `f`，访问其父 `[-]` ⟹ `c d + e / f -`；
- `[*]` 的左孩子是 `a`：`a c d + e / f -`，访问 `[*]` ⟹ `a c d + e / f - *`（注意 `a` 在 `*` 之前，但 `a` 属于 `*` 的左子树，先于其输出）；
- 左侧 `+` 子树：`a b +`；与上段拼接（本树根的左子树为 `[-]`，其左为 `[+]`，右为 `[*]`）⟹ `a b + a c d + e / f - *`，访问 `[-]` ⟹ `a b + a c d + e / f - * -`；
- 最后右子树 `g`，访问根 `[+]` ⟹ `a b + a c d + e / f - * - g +`。

去掉分隔即 **`ab+acd+e/f-*-g+`**。

（对照：**前缀式**为 `+-+ab*a-/+cdefg`（先序），**中缀**即原式（中序，需补括号）。三者互推是同一棵树，可用来快速核查字符有没有丢。）

### 第三步：路线二——算符栈逐步调度（逐行表）

规则：操作数→直接写入输出；运算符→与栈顶比优先级，**栈顶不低于自己则先弹出**（`* /` 对 `+ -` 为"低"，同级为"不低于"，遇 `(` 为"低"）；`(`→压栈；`)`→弹出直至遇 `(`，`(` 出栈但不输出；扫描结束→栈内余符依次弹出。下表栈为**底→顶**。

| # | 读入 | 输出串 | 算符栈 | 动作 |
|---|---|---|---|---|
| 1 | `a` | `a` | ∅ | 操作数直接输出 |
| 2 | `+` | `a` | `+` | 栈空，压入 |
| 3 | `b` | `ab` | `+` | 操作数 |
| 4 | `-` | `ab+` | `-` | 栈顶 `+` 与 `-` 同级（左结合）⟹ 弹出 `+`，再压 `-` |
| 5 | `a` | `ab+a` | `-` | 操作数 |
| 6 | `*` | `ab+a` | `-` `*` | `*` 高于栈顶 `-` ⟹ 压入 |
| 7 | `(` | `ab+a` | `-` `*` `(` | 左括号一律压栈（作界标） |
| 8 | `(` | `ab+a` | `-` `*` `(` `(` | 同上，形成第二层界标 |
| 9 | `c` | `ab+ac` | `-` `*` `(` `(` | 操作数 |
| 10 | `+` | `ab+ac` | `-` `*` `(` `(` `+` | 栈顶为 `(` ⟹ 直接压入 |
| 11 | `d` | `ab+acd` | `-` `*` `(` `(` `+` | 操作数 |
| 12 | `)` | `ab+acd+` | `-` `*` `(` | 弹出至 `(`：弹出 `+`；配对的 `(` 消去不输出 |
| 13 | `/` | `ab+acd+` | `-` `*` `(` `/` | 栈顶为 `(` ⟹ 压入 |
| 14 | `e` | `ab+acd+e` | `-` `*` `(` `/` | 操作数 |
| 15 | `-` | `ab+acd+e/` | `-` `*` `(` `-` | 弹出高于自己的 `/`；栈顶变 `(` ⟹ 停止再压 `-` |
| 16 | `f` | `ab+acd+e/f` | `-` `*` `(` `-` | 操作数 |
| 17 | `)` | `ab+acd+e/f-` | `-` `*` | 弹出至 `(`：弹出 `-`；`(` 消去 |
| 18 | `+` | `ab+acd+e/f-*-` | `+` | 先弹 `*`（更高）再弹 `-`（同级，左结合）；栈空 ⟹ 压 `+` |
| 19 | `g` | `ab+acd+e/f-*-g` | `+` | 操作数 |
| 20 | 结束 | `ab+acd+e/f-*-g+` | ∅ | 栈内余符全部弹出 |

第 18 行是本题的**关键一步**：外层最末的 `+` 把 `*` 与第二个 `-` 一并清空，才保证了 `-` 落在 `acd+e/f-*` 之后。

  +     >   >   <   <   <   >   >
  -     >   >   <   <   <   >   >
  *     >   >   >   >   <   >   >

  (     <   <   <   <   <   <   =
  )         >   >   >   >       >
  #     <   <   <   <   <   <   =

其中 `#` 为表达式定界符（对应上表第 20 行"栈内余符全部弹出"）。

### 第四步：结构自检（不需计算数值）

1. **个数核对**：后缀式 `ab+acd+e/f-*-g+` 中操作数 $=a,b,a,c,d,e,f,g$ 共 $8$ 个，与中缀中出现的 $8$ 个操作数（$a$ 两次）一一对应且**相对次序不变**；运算符 $=+,+ ,/,+,-,-,*,+$? 逐个数：`+`(第3字符)、`+`(第7)、`/`(第9)、`-`(第11)、`*`(第12)、`-`(第13)、`+`(第15) 共 $7$ 个，与中缀的 $7$ 个运算符个数相同（`+ + - * / - +` 的多重集合一致：$3$ 个 `+`、$2$ 个 `-`、$1$ 个 `*`、$1$ 个 `/` ✓）；总长 $8+7=15$ ✓；
2. **可算性检验**（后缀式合法判据）：自左向右扫描，令 $d=\#(操作数)-\#(运算符)$，要求中途 $d\ge 1$、终了 $d=1$：

| 已读 | a | ab | ab+ | ab+a | ab+ac | ab+acd | ab+acd+ | …e | …e/ | …f | …- | …* | …- | …g | …+ |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| $d$ | 1 | 2 | 1 | 2 | 3 | 4 | 3 | 4 | 3 | 4 | 3 | 2 | 1 | 2 | 1 |

全程 $d\ge1$ 且末值 $1$ ✓（若某处出现 $d=0$ 或负数，说明运算符多于可操作的结果，后缀式必错）。

### 第五步：语义验算（两组赋值）

**第一组**：$a{=}2,b{=}3,c{=}4,d{=}5,e{=}9,f{=}6,g{=}7$

- 中缀：`a+b=5`；`c+d=9`，`9/e=9/9=1`，`1-f=1-6=-5`；`a*(-5)=-10`；`5-(-10)=15`；`15+g=15+7=22`；
- 后缀（栈式求值）：`a b`→[2,3]；`+`→[5]；`a`→[5,2]；`c d`→[5,2,4,5]；`+`→[5,2,9]；`e`→[5,2,9,9]；`/`→[5,2,1]；`f`→[5,2,1,6]；`-`→[5,2,-5]；`*`→[5,-10]；`-`→[15]；`g`→[15,7]；`+`→**[22]** ✓ 一致。

**第二组**（换一组值以防巧合）：$a{=}1,b{=}2,c{=}3,d{=}4,e{=}5,f{=}6,g{=}7$

- 中缀：`a+b=3`；`c+d=7`，`7/5=1.4`，`1.4-6=-4.6`；`1*(-4.6)=-4.6`；`3-(-4.6)=7.6`；`7.6+7=14.6`；
- 后缀：`ab+`→3；`a`→[3,1]；`cd+`→[3,1,7]；`e/`→[3,1,1.4]；`f-`→[3,1,-4.6]；`*`→[3,-4.6]；`-`→[7.6]；`g+`→**[14.6]** ✓ 两组均一致。

### 第六步：反向复核（后缀 → 中缀）

对后缀式逐符还原，运算符把最近两个子表达式括起来：

`a b +`→`(a+b)`；`a`；`c d +`→`(c+d)`；`e /`→`((c+d)/e)`；`f -`→`(((c+d)/e)-f)`；`*`→`(a*(((c+d)/e)-f))`；`-`→`((a+b)-(a*(((c+d)/e)-f)))`；`g +`→`(((a+b)-(a*(((c+d)/e)-f)))+g)`。

与第一步的显式化结果**逐字符相同** ✓——最外层是 `+g`、减号的右操作数整块是 `a*(...)`，说明结合次序没有错位。

## 8. 考场标准答案

后缀表达式：

```
ab+acd+e/f-*-g+
```

书写格式（每字符依次）：`a` `b` `+` `a` `c` `d` `+` `e` `/` `f` `-` `*` `-` `g` `+`。

考场推导一句话概括：先把原式按优先级与左结合补全括号为 `((a+b)-(a*(((c+d)/e)-f)))+g`，再自最内层起把每个运算符移到其两个运算对象之后（即对表达式树取后序遍历），括号全部去掉了。

## 9. 易错点

1. **丢掉运算符**：`(c+d)/e-f` 一段中最容易漏写 `/`，把 `cd+e/f-` 误写成 `cd+ef-`——转换完必须数运算符个数（本题应为 $7$ 个）；
2. **外层结合方向搞反**：把 `a+b-X+g` 读成 `a+b-(X+g)`，会得到 `ab+X-g+` 之类的错误结果（`-` 与最后一个 `+` 的层次互换）。同级运算一律**左结合**，`+g` 是加在"整体之差"之后；
3. **把减号当成"负号"**：`-a*(...)` 中的 `-` 是二元运算符，其后紧跟的 `a` 是它的右操作数的一部分，不能提前把 `-` 输出（第 3 步表第 4～18 行的处理即为此）；
4. **右括号弹出时把 `(` 也写进输出**：`(` `)` 都不属于后缀式，只作定界；
5. **操作数次序被改动**：后缀式中操作数的相对次序必须与中缀相同（$a,b,a,c,d,e,f,g$）。若写成 $a,b,c,d,\dots$ 少了一个 $a$，说明漏抄了 `*` 的左操作数；
6. **误加空格或省略号**：填空题按字符序列书写，不加空格、不写"…"，`*` 与 `-` 相邻处（`.../f-*-g+`）三个连续符号极易抄错，务必逐字符回读。

## 10. 一句话规律

中缀转后缀**两条腿走路**：先用"补全括号"把结合次序定死，再从每个运算符的**子树根**出发取后序（或等价地用算符栈扫描）；写完必做三项自检——运算符/操作数个数不变、扫描时"结果数"始终 $\ge1$ 且终为 $1$、代两组具体值与中缀同值。

## 11. 关联知识
