# DS-2024-23

## 1. 原题

**23、** 编写代码及思想，计算二叉树的繁荣度。（即每一层的结点数乘以该层的层数）

（卷面本节无订正说明。）

## 2. 答案

**定义（依题面括注）**：设二叉树根结点位于第 $1$ 层，第 $i$ 层的结点数为 $n_i$，树高为 $h$，则

$$\text{繁荣度 } P=\sum_{i=1}^{h} i\times n_i$$

**主解（层次遍历 + 逐层计数）**：用队列做层次遍历。关键技巧是——**每一轮"处理一层"的开始时刻，队列里恰好装着本层的全部结点**，因此本层结点数可直接由 $rear-front$ 得到；把这一层的贡献 $level\times cnt$ 累加后整层出队、把孩子整层入队，$level$ 加 $1$。空树返回 $0$。

**备选解（递归传层号）**：每个结点恰好"贡献自己的层号"，故

$$P(t)=\begin{cases}0, & t=\varnothing\\[2pt] level+P(t_{\text{左}},\,level+1)+P(t_{\text{右}},\,level+1), & \text{否则}\end{cases}$$

初调用 `Prosper(T, 1)`。

**校验算例**：同卷 **DS-2024-17** 的那棵 $11$ 个结点的二叉树，层分布 $n_1..n_6=1,2,3,3,1,1$，

$$P=1\times1+2\times2+3\times3+4\times3+5\times1+6\times1=1+4+9+12+5+6=\boxed{37}$$

**复杂度**：时间 $O(n)$（每结点入队、出队各一次 / 递归访问各一次）；主解空间 $O(n)$（下标只增不回绕的顺序队列需按结点总数开数组；队列中**同时**存活的结点最多是“本层 + 下一层”，完全二叉树时约 $n$），备选解空间 $O(h)$。

## 3. 题目分析

- **输入**：一棵二叉树（按前两题一致的二叉链表 `BiTNode{data, lchild, rchild}` 存储），结点值与本问无关（只数结构）；
- **输出**：一个整数（或 `long`）——繁荣度 $P=\sum_i i\cdot n_i$；
- **"繁荣度"不是教材术语**：题面用括注给出了唯一定义，本解析严格按括注执行，不引入任何其他含义；凡是"生造名词 + 括注定义"的题，**括注就是标准**，答题时先把公式照抄一遍再写代码可避免理解分歧；
- **必须声明的一处口径**：**层号从 $1$ 开始**（树根在第 $1$ 层）。这与本卷填空第 **DS-2024-14** 题面"树根位于第一层"的约定一致；若改取"根在第 $0$ 层"，结果恰为 $P-n$（每个结点少计 $1$），故卷面务必写明；
- **等价变形（用于自查）**：$\sum_i i\cdot n_i=\sum_{\text{所有结点}}(\text{该结点的深度}+1)=\Big(\sum_{\text{所有结点}}\text{深度}\Big)+n$，即"全部结点的深度之和 + 结点数"。这个式子给出两条独立校验路径：结点总数 $n$ 与树高 $h$ 都可由别的算法单独算出对账；
- **命题意图**：考层次遍历的实现——不是"打印一层"而是"**统计一层**"，即能否处理"层与层的边界"。这正好同时考查 DS02 章的队列应用（循环队列的队满队空、$front/rear$ 语义）与 DS03 章的遍历；此外括注里的"每层结点数"暗示了答案要的是**按层聚合**而非按结点枚举，两种写法都可行，但按层聚合更贴合题意；
- **边界**：空树（$P=0$，且不应因递归的 $level$ 参数而错写成 $1$）、单结点（$P=1$）、只有左/右斜的单支树（$P=1+2+\cdots+n=n(n+1)/2$，可用于快速对拍）。

## 5. 解题思路

1. **先把公式写成程序语言**：需要两个量——$level$（当前层号）与 $n_{level}$（该层结点数），答案就是它们的乘积之和。于是问题落到"如何按层把结点分组"；
2. **层次遍历天然给出分组**：用队列访问时，"父结点全部出队之前，父们的孩子不会开始出队"，所以访问始终是按层推进的。但要拿到"$n_i$"就必须**知道这一层有几个**，逐个出队无法预知；
3. **关键的顿悟**：在处理第 $i$ 层的**瞬间**，队首到队尾之间正好只有第 $i$ 层的结点（第 $i-1$ 层已全部出队、其孩子即第 $i$ 层已全部入队，而第 $i+1$ 层还未产生）。所以 `cnt = rear - front` 就是 $n_i$——这是本题最核心的一句话，也是"打印层次遍历各层"这类题的通用模板；
4. **另一条更短的路**：既然 $P=\sum_{\text{结点}}$ 层号，可以不做分层，直接**递归把层号当参数传下去**：每个结点交回"自己的层号 + 两棵子树的贡献"，一行 `return level + ...` 就完成，且不需要队列。两条路的差别只在"是否显式分层"，结果相同——写主解（贴合题意），并用备选解互相验证（第 6 节第三步）；
5. **边界与类型**：`if (t == NULL) return 0;` 必须放在递归最前面，否则空树会因根层参数而返回 $1$；结点 $n$ 大时 $P$ 的上界是 $n(n+1)/2$（单支树），$n=10^5$ 时约 $5\times10^9$ 已超 32 位 $int$，应声明 `long`（考研手写一般不扣此分，但值得提一句）；
6. **自查**：先用一棵小满二叉树（$7$ 结点，层分布 $1,2,4$）手算 $P=1+4+12=17$，同时用"$\sum$ 深度 $+n=(0+1+1+2+2+2+2)+7=17$"验一遍；再拿同卷 DS-2024-17 的树跑两法（得 $37$）。

## 6. 详细解答

### 第一步：结构体与队列定义

```c
typedef struct BiTNode{
    int data;                          /* 数据域，本题不使用其值 */
    struct BiTNode *lchild;
    struct BiTNode *rchild;
}BiTNode,*BiTree;

#define MAXQ 100                       /* 队列容量：需 >= 结点总数 n */
typedef struct{
    BiTree q[MAXQ];
    int front, rear;                   /* front 指队头元素，rear 指队尾后一个位置 */
}SqQueue;
```

采用"不设循环"的简单顺序队列即可：整个过程中 $rear$ 单增、$front$ 单增，每结点至多入队一次，故 $rear$ 最终增至结点总数 $n$，**数组容量需按 $n$ 而非按最宽层取**（用 $cnt=rear-front$ 直接算层内个数，换来的就是这份简单）；若只想占用 $O(w)$（$w$ 为最宽层结点数），可改用循环队列，但此时层内个数应用 $(rear-front+MAXQ)\% MAXQ$ 计算，且队满与队空均满足 $front==rear$，需牺牲一个元素位或另设计数器；处理任意大的树时最省事的做法是改用**链队**（DS02.03），不受容量限制。

### 第二步：主解——层次遍历逐层累加

```c
int Prosperity(BiTree t)
{
    SqQueue Q;
    BiTree p;
    int level = 1;                     /* 根在第 1 层 */
    int sum = 0, cnt, i;

    if (t == NULL) return 0;           /* 空树的繁荣度为 0 */

    Q.front = Q.rear = 0;
    Q.q[Q.rear++] = t;                 /* 根入队 */

    while (Q.front != Q.rear) {        /* 队列不空 */
        cnt = Q.rear - Q.front;        /* 此刻队中恰是本层全部结点 => cnt = n_level */
        for (i = 0; i < cnt; i++) {    /* 整层处理 */
            p = Q.q[Q.front++];
            if (p->lchild) Q.q[Q.rear++] = p->lchild;
            if (p->rchild) Q.q[Q.rear++] = p->rchild;
        }
        sum += level * cnt;            /* 本层贡献：层号 × 本层结点数 */
        level++;                       /* 孩子已入队，进入下一层 */
    }
    return sum;
}
```

**为什么 `cnt = rear - front` 成立**（循环不变量）：进入 `while` 体时，队列中自上而下正好是"第 $level$ 层的 $n_{level}$ 个结点"，且队首之前无残留元素。基础情形：$level=1$，队列只有根，$cnt=1=n_1$ ✓。归纳：本层 $cnt$ 个结点全部出队，其间它们的孩子（恰为第 $level+1$ 层的全部结点，因为层次遍历保证"只有本层结点才产生下一层结点"）依次入队，故循环结束时 $front$ 等于本层结束位置、$rear$ 增加了 $n_{level+1}$，下一轮 $rear-front=n_{level+1}$ ✓。

### 第三步：备选解——递归传层号

```c
/* level 为 t 所在层的层号，首次调用 Prosper(T, 1) */
int Prosper(BiTree t, int level)
{
    if (t == NULL) return 0;                       /* 空树/空孩子不贡献 */
    return level                                   /* 自己贡献自己的层号 */
         + Prosper(t->lchild, level + 1)
         + Prosper(t->rchild,  level + 1);
}
```

正确性由"$P=\sum_{\text{结点}}\text{层号}$"直接得到：递归把每个结点访问恰好一次并交出它的 $level$，求和即所求。注意它与主解的分组视角不同——主解按层聚合（$\sum_i i\cdot n_i$），本解按结点累加（$\sum_j \text{level}_j$），两者是同一个和的两种枚举次序，故结果必相等，这正是互验的基础。

**第三种写法（延伸，先数层再乘）**：若题目还要求"输出每层结点数"，可用一个数组按层号统计：

```c
int cnt[MAXH];                        /* cnt[i] 记录第 i 层结点数，MAXH 为最大层数上限 */
void CountLevel(BiTree t, int level)  /* 先序统计 */
{
    if (t == NULL) return;
    cnt[level]++;
    CountLevel(t->lchild, level + 1);
    CountLevel(t->rchild, level + 1);
}
/* 调用后：P = Σ level * cnt[level]，并可同时得到树高 h */
```

它把"每层结点数"显式留下来，便于核对，代价是 $O(h)$ 的附加数组。

### 第四步：走查

**用例 1：满二叉树 $7$ 结点**（层分布 $1,2,4$）。主解执行轨迹：

| 轮 | 轮首队列（front→rear） | $cnt$ | 入队的孩子 | $sum$ | $level$ 变化 |
|---|---|---|---|---|---|
| 1 | $[\,1\,]$ | $1$ | $2,3$ | $1\times1=1$ | $1\to2$ |
| 2 | $[\,2,3\,]$ | $2$ | $4,5,6,7$ | $1+2\times2=5$ | $2\to3$ |
| 3 | $[\,4,5,6,7\,]$ | $4$ | （无） | $5+3\times4=17$ | $3\to4$ |
| 4 | 空 | — | — | $17$ | 退出 |

$P=17$；用等价式核对：$\sum$ 深度 $=0+1+1+2+2+2+2=10$，$10+7=17$ ✓；备选解 `Prosper(root,1)` 逐结点返回 $1+2+3+2+3+3+3$（按结点）亦为 $17$ ✓。

**用例 2：同卷 DS-2024-17 的树**（$A$ 为根，$A\!-\!B,G$；$B\!-\!C,D$；$D\!-\!E,F$；$G\!-\!H$；$H\!-\!I$（$H$ 的右孩子）；$I\!-\!J$（$I$ 的左孩子）；$J\!-\!K$（$J$ 的右孩子））。各层结点：

| 层 $i$ | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ | 合计 |
|---|---|---|---|---|---|---|---|
| 结点 | $A$ | $B,G$ | $C,D,H$ | $E,F,I$ | $J$ | $K$ | $11$ ✓ |
| $n_i$ | $1$ | $2$ | $3$ | $3$ | $1$ | $1$ | |

$$P=1\cdot1+2\cdot2+3\cdot3+4\cdot3+5\cdot1+6\cdot1=1+4+9+12+5+6=37$$

主解（队列）与备选解（递归传层号）跑同一棵树均得 $37$ ✓（本解析另以程序实现两法对拍，结果一致）。

**用例 3：边界**——空树 $P=0$（主解显式 `return 0`，备选解 `Prosper(NULL,1)=0`）；单结点 $P=1\times1=1$；$n$ 个结点的左斜链 $P=1+2+\cdots+n=\dfrac{n(n+1)}{2}$（$n=4$ 时 $P=10$，可与主解逐轮 $cnt$ 恒为 $1$ 对照）。

### 第五步：复杂度分析

设树有 $n$ 个结点、树高 $h$、最大宽度（最宽层的结点数）为 $w$。

- **主解**：每个结点入队一次、出队一次，每次 $O(1)$ ⇒ 时间 $O(n)$；空间：按不回绕的顺序队列写法，数组容量为 $O(n)$（$rear$ 最大取到 $n$）；队列中**同时**存活的最多 $n_i+n_{i+1}\le n$ 个结点（若采用循环队列则降到 $O(w)$，$w$ 为最宽层结点数），另有 $3$ 个整型变量；
- **备选解（递归）**：时间 $O(n)$；空间 $O(h)$ 的递归栈，最坏（单支）$O(n)$、最好 $O(\log n)$，**无队列开销**——若树很宽但很浅，递归法更省；若树很深但每层 $2$ 个结点（斜树），队列法更省（$w=2$）而递归栈深 $n$；
- **第三种写法**：时间 $O(n)$，空间 $O(h)$ 数组 + $O(h)$ 栈；
- **取值范围**：$P\le n(n+1)/2$，$n$ 较大时需 `long`（见第 3 节）。

## 8. 考场标准答案

**(1) 定义与思想**：繁荣度 $P=\sum_{i=1}^{h} i\times n_i$（$n_i$ 为第 $i$ 层结点数，根在第 $1$ 层）。用队列做层次遍历并**逐层**处理：每轮开始时队列里恰是第 $i$ 层的结点，故 $n_i=rear-front$；累加 $i\times n_i$ 后把本层全部出队、其孩子全部入队，层号自增，直到队空。空树返回 $0$。

**(2) 代码**：第 6 节第二步 `Prosperity`（结构体用题面/前一问的二叉链表 `BiTNode,*BiTree`）。

**(3) 备选一行式**（可附在卷面以展示等价性）：`int Prosper(BiTree t,int lv){ return t? lv+Prosper(t->lchild,lv+1)+Prosper(t->rchild,lv+1) : 0; }`，调用 `Prosper(T,1)`。

**(4) 复杂度**：时间 $O(n)$；空间——队列法 $O(n)$（不回绕数组按结点总数开；改循环队列可降到最宽层规模 $O(w)$），递归法 $O(h)$。

**(5) 示例**：$7$ 结点满二叉树 $P=1+4+12=17$；同卷 DS-2024-17 的树 $P=37$。

## 9. 易错点

1. **层号起点未声明**：根取第 $0$ 层会使结果少 $n$（$P$ 变为 $P-n$）。本卷 DS-2024-14 明确"树根位于第一层"，本题应沿用，并在答案里写一句"设根在第 $1$ 层"；
2. **层边界处理错**：写成"每出队一个结点就 `sum += level`"，然后在某处 `level++`——若把 `level++` 放在循环体内则同层被拆算，若放在循环体外则永不推进。**必须先用 `cnt = rear - front` 定住本层结点数，整层处理完再 `level++`**；
3. **`cnt` 取错时刻**：在 `for` 循环之后再算 `rear - front` 得到的是"下一层"的结点数（本层已出队、下层已入队），乘上当前层号即错位一层；
4. **空树没特判**：主解缺 `if (t == NULL) return 0;` 时会把空指针入队，下一轮就对 `p->lchild` 解引用空指针而崩溃（仅在“入队前判空”的写法下才侥幸返回 $0$）；备选递归法缺 `if (t == NULL) return 0;` 则会把空孩子当成“第 $level$ 层的一个结点”计入，整盘皆错——两法都必须显式写出空树出口；
5. **混淆"结点个数"与"度数/叶结点数"**：题面括注是"每一层的**结点数**"，指该层全部结点（含内部结点），不是叶结点，也不是分支数；
6. **队满溢出或用错队列语义**：不回绕的简单队列中 $rear$ 会一路增到 $n$，`MAXQ` 小于结点总数就写越界（第 6 节第一步）；若改写成循环队列，则 $cnt=rear-front$ 必须换为 $(rear-front+MAXQ)\% MAXQ$，且“队空 $front==rear$”与“队满”同条件一、需牺牲一个元素位或另设计数器，否则层次遍历会提前终止；
7. **递归时误用全局变量记层号**：写成全局 `level` 并在进入时 `level++`、退出时不还原，则右子树拿到的层号被左子树的深度污染（结果是"深度优先"的层号而非真实层号）；**层号必须以形参传递**；
8. **返回类型溢出**：$n$ 较大时 $P$ 上界 $\frac{n(n+1)}{2}$ 超 `int`（第 3 节）；
9. 把定义误读成"每层结点数 × 该层**编号从 0**"或"层结点数 × 剩余层数"：一切以括注"每一层的结点数乘以该层的层数"为准，答题时先照抄公式再写代码。

## 10. 一句话规律

凡"按层统计"的题目，先问自己一句：**"这一层有几个？"**——层次遍历里"每轮开始时队列中恰好是本层全部结点"，$cnt=rear-front$ 就是层边界的答案；若只需要"每结点贡献自己的层号"这类可加和量，则**递归传层号**能把代码缩到一行，并与队列法互为验证。
