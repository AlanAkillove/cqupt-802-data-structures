# DS-2024-02

## 1. 原题

下面给出一段关于链表操作的代码片段（带头结点），请将这些代码片段按正确的顺序排序，使其实现将结点 $s$ 插入到结点 $p$ 之前的功能（假设 $p$ 既不是头结点也不是尾结点），并分析时间复杂度。代码片段如下：

```c
void insertBefore(Node *head,Node *p,Node *s)
{
    if(______________)    return ;
    Node *prev=head;
    while(______________)
        prev=prev->next;
    if(_______)
    {
        s->next=p;
        ____________;
    }
}
```

① $prev -> next != p \&\& prev -> next !=NULL$

② $prev -> next = s$

③ $head==NULL || p==NULL || s==NULL$

④ $prev ->next == p$

## 2. 答案

自上而下的四个空依次填 **③、①、④、②**：

| 空位（函数中从上到下） | 应填片段 | 作用 |
|---|---|---|
| 第 1 空（`if(...) return;`） | ③ `head==NULL || p==NULL || s==NULL` | 非法入参直接退出 |
| 第 2 空（`while(...)`） | ① `prev->next != p && prev->next != NULL` | 从头结点向后找 $p$ 的**前驱**，两个条件防止越到表尾之外 |
| 第 3 空（`if(...)`） | ④ `prev->next == p` | 确认确实找到了 $p$（$p$ 不在链上时不改动结构） |
| 第 4 空（`s->next=p;` 之后） | ② `prev->next = s;` | 把前驱的后继改挂到 $s$，完成插入 |

时间复杂度 $O(n)$（$n$ 为链表中结点个数）；附加空间 $O(1)$。

## 3. 题目分析

- 已知：**带头结点**的单链表，`next` 是唯一可改的链接域；给定结点 $p$（题面保证 $p$ 既不是头结点也不是尾结点）与待插结点 $s$；函数同时收到表头指针 `head`，说明**没有现成的前驱**可用；
- 目标：把四个候选片段填回四个空，使函数实现"$s$ 插在 $p$ **之前**"；
- 关键约束：
  1. 单链表只能**顺着 `next` 向后**走，"$p$ 的前驱"无法由 $p$ 自身取得，必须从表头出发逐个后继检查 `prev->next == p`——这正是本函数存在 $O(n)$ 扫描的原因；
  2. 插入需要且只需要改**两条边**：$s\to next=p$ 与 $prev\to next=s$；顺序上先写 $s\to next$（`s->next=p` 骨架已给定），否则 $p$ 的后继信息会在 $prev\to next$ 被改写后仍然可取（本题不涉及），但"s 先接住 $p$、prev 再接住 s"是通用安全写法；
  3. 扫描必须**能安全停下来**：若 $p$ 根本不在链表上，`prev->next` 最终会变成 `NULL`，此时若无 `!= NULL` 判据，下一轮 `prev=prev->next` 会使 `prev` 为空，再取 `prev->next` 即解引用空指针；
  4. 第 3 空的 `if` 是"找到才插"的兜底：循环可能因 `prev->next==NULL` 而退出，此时不应执行插入；
- 命题意图：考**带头结点单链表上"已知结点、要在其之前插入"这一基本操作**（DS01.02.02）——它比"已知前驱插入"多了一次查前驱的扫描；四个候选片段恰好把"入参检查 / 定位循环 / 定位成功判定 / 改边"四个环节一一对应，排序错一个环节逻辑即断。

## 5. 解题思路

1. **先定"骨架 ↔ 角色"**：函数有四个空，分别处在"入口守卫""循环条件""插入前置检查""第二条边赋值"四个语法位置，角色已经写死，只需把候选片段按角色对号；
2. **入口守卫只能是③**：`if(...) return;` 的语义是"参数非法就不动手"，四个片段中只有 ③ 是"三个指针之一为空"的判断，且 ①④ 是 `prev` 相关的表达式，`prev` 在下一行才定义，语法上也不可能出现在第 1 空；
3. **循环条件只能是①**：`while(...)` 后跟 `prev=prev->next`，说明这是一个"沿表推进直到命中"的查找循环，条件必须同时含"没找到 $p$"与"没走到表尾外"两个判据，恰好是 ① 的两个 `&&` 分量；
4. **`if` 只能是④**：跳出循环有两种原因（找到 $p$ 或 `prev->next==NULL`），进入插入分支前必须区分，`prev->next == p` 就是这个判定；
5. **剩下的②填在最后**：`s->next=p;` 已给出第一条边，第二条边必是 `prev->next = s;`；
6. **复杂度**：扫描次数等于 $p$ 的位置序号，最坏 $n-1$ 次 ⟹ $O(n)$；插入两条赋值 $O(1)$；总 $O(n)$。若链表是**双向**的（DS01.02.03），$p\to prior$ 直接给出前驱，可降到 $O(1)$——这正是本题"必须扫"的对照说明。

## 6. 详细解答

### 第一步：目标形态

设带头结点的链表为 $head \to a_1 \to a_2 \to \cdots \to a_{i}=p \to \cdots$，$p$ 的前驱记作 $prev=a_{i-1}$。插入 $s$ 后要求

$$\cdots \to a_{i-1}\ \to\ s\ \to\ a_{i}(=p)\ \to\ \cdots$$

即需要且仅需要建立两条新边：$s\to next=p$、$prev\to next=s$；同时 $prev$ 必须先被**找到**。

### 第二步：四个空的逐一定位

| 语法位置 | 候选 | 判定理由（含排除过程） |
|---|---|---|
| `if(____) return;` | ③ | ①④ 都用到 `prev`，而 `prev` 在下一条语句才声明，语法不成立；② 是赋值语句，放进 `if` 的括号里语义不通（`prev->next=s` 作为条件恒为真值/非零），故只能是 ③ |
| `while(____) prev=prev->next;` | ① | 循环目标是"让 `prev` 停在 $p$ 的前驱上"。终止须有两个出口：`prev->next == p`（命中）或 `prev->next == NULL`（走到底，$p$ 不在表上）。① 正是这两条的合取。若只写 `prev->next != p`（漏 NULL 判据），$p$ 不在表上时 `prev` 会被推成 `NULL`，再算 `prev->next` 即空指针解引用 |
| `if(____)` | ④ | 出循环后需区分"命中"与"到底"，判据即 `prev->next == p`。填 ① 恒不成立（① 是继续循环的条件，退出时其值为假），填 ③ 与该分支无关，填 ② 不是条件 |
| `s->next=p; ____;` | ② | 第一条边已给，缺第二条边 `prev->next = s`。**必须在 `s->next=p` 之后**？——本题两式互不读写对方使用的指针（`s->next` 与 `prev->next` 是不同结点的域），故两条互换顺序同样正确；但必须先让 $s$ 接住 $p$，因为若表被并发解释为"$prev$ 已指向 $s$，而 $s\to next$ 还是旧值/未定义"就出现断链窗口，写成 `s->next=p; prev->next=s;` 最稳妥 |

故**排序为 ③①④②**。

### 第三步：手工走查（验算）

取带头结点链表 `head(0) → 10 → 20 → 30 → 40 → 50 → NULL`，令 $p$ 为数据 $30$ 的结点、$s$ 为数据 $25$ 的新结点。

| 步骤 | 执行内容 | `prev` 的值 | 判断结果 |
|---|---|---|---|
| 1 | 空 ③：`head==NULL \|\| p==NULL \|\| s==NULL` | — | 假 ⟹ 不 `return` |
| 2 | `prev = head` | 指向 $0$ | — |
| 3 | 空 ① 第 1 次：`prev->next(=10) != p && prev->next != NULL` | $0$ | 真 ⟹ `prev=10` |
| 4 | 空 ① 第 2 次：`prev->next(=20) != p && … != NULL` | $10$ | 真 ⟹ `prev=20` |
| 5 | 空 ① 第 3 次：`prev->next(=30) == p` | $20$ | 假 ⟹ 退出循环（扫描 2 步移动） |
| 6 | 空 ④：`prev->next == p` | $20$ | 真 ⟹ 进入插入分支 |
| 7 | `s->next = p;` | — | $25\to 30$ |
| 8 | 空 ②：`prev->next = s;` | — | $20\to 25$ |

沿 `next` 走：$0,10,20,\mathbf{25},30,40,50$ ✓（结点数由 $6$ 变 $7$，无结点丢失、无断链）

**边界 A（$p$ 不在表上）**：令 $p$ 为表外结点。循环依次把 $prev$ 推到 $50$，此时 `prev->next == NULL` ⟹ ① 第二个判据为假 ⟹ 退出；空 ④ `prev->next == p` 为假 ⟹ 不插入，链表保持原样且不出现空指针解引用 ✓（这就是 ① 必须带 `!= NULL` 的原因）

**边界 B（$p$ 是首元结点）**：题面已限定 $p$ 不是头结点，但即使 $p=a_1$，$prev$ 停在**头结点**上，空 ② 改写的是 `head->next`，表头指针本身不必更新——这正是"带头结点"给本题带来的便利。

**边界 C（$p$ 是尾结点）**：题面已限定 $p$ 不是尾结点；若真给尾结点，本算法仍会把 $s$ 插在其前（逻辑上无副作用），只是题意不需要讨论。

（后台以 C 程序按 ③①④② 组装出完整函数，在带头结点的 $5$ 数据结点表上执行三次测试：$p$ 为中间结点、$p$ 为首元结点、$p$ 不在表上，遍历结果分别为 $0,10,20,25,30,40,50$；$0,5,10,20,25,30,40,50$；原表不变，与手工走查逐项一致；程序仅作验证，正文可人工复现。）

### 第四步：时间复杂度分析

设链表含 $n$ 个结点（含头结点则 $n$ 记总结点数，量级相同）。

- 第 2 空的 `while`：每轮使 `prev` 后移一个结点，$p$ 在第 $i$ 个位置时执行 $i-1$ 次判断并移动 $i-1$ 次；最坏（$p$ 是最后一个结点或 $p$ 不在表上）为 $n-1$ 次 ⟹ $\Theta(n)$；
- 入参检查、`if` 判定、两条边的修改均为 $O(1)$；
- 总时间 $T(n)=O(n)$；只用了 `prev`、$s$ 等常数个指针变量，附加空间 $O(1)$，且为就地操作（不新建、不释放结点）。

## 8. 考场标准答案

```c
/* 带头结点的单链表：把 s 插入到 p 之前（p 不是头结点也不是尾结点） */
void insertBefore(Node *head, Node *p, Node *s)
{
    if (head == NULL || p == NULL || s == NULL)   /* 空1 填 ③ */
        return;
    Node *prev = head;
    while (prev->next != p && prev->next != NULL)  /* 空2 填 ① 找 p 的前驱，防越表尾 */
        prev = prev->next;
    if (prev->next == p)                          /* 空3 填 ④ 确认找到才插 */
    {
        s->next = p;                              /* 第一条边 */
        prev->next = s;                           /* 空4 填 ② 第二条边 */
    }
}
```

排列顺序：**③ ① ④ ②**。

时间复杂度 $O(n)$（$n$ 为链表长度，瓶颈是从头结点出发查找 $p$ 的前驱）；附加空间 $O(1)$。

## 9. 易错点

1. **把 ① 写成只判 `prev->next != p`**：漏掉 `!= NULL` 后，一旦 $p$ 不在链表上（或题意不保证 $p$ 一定在表内），循环会走出表尾并解引用空指针；
2. **漏掉第 3 空的 `if`（或把 ④ 填错）**：没有它，循环因"到达表尾"退出时仍会执行插入，把 $s$ 错误地接到尾结点之后（`prev->next == NULL` 时相当于把 $s$ 当作尾后结点插入，链表被破坏）；
3. **改边顺序颠倒导致断链**：先写 `prev->next = s` 而后写 `s->next = p`，中间窗口内 $p$ 及其后继虽仍可从 $p$ 取到，但一旦把 $s$ 的接入点理解成"从 `prev->next` 取 $p$"就丢链；标准答案一律写"先 `s->next=p`，后 `prev->next=s`"；
4. **误以为 $O(1)$**：题面给的是单链表且只给 $p$ 本身，"插到 $p$ 之前"必然要查前驱；若只给 $p$ 不给 `head`，单链表甚至无法完成该操作（可改用"把 $s$ 插到 $p$ **之后**再交换数据域"的技巧，那是另一道题）；
5. **把 ① 的两个判据写成 `||`**：`prev->next != p || prev->next != NULL` 恒为真（两者不可能同时为假），循环立即越界；两个"继续循环"条件之间是**与**关系。

## 10. 一句话规律

链表"填空/排序"题的通用做法：**先写出目标形态需要改哪几条边（单链表插入 2 条、双向 4 条），再按"入参守卫 → 定位循环（含越尾保护）→ 定位成功判定 → 改边"四个语法角色给候选片段对号**；复杂度则由"是否需要查前驱/查位置"决定，而这一点的分水岭就是单链表与双向链表的区别。
