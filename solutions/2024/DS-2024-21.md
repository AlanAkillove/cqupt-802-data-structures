# DS-2024-21

## 1. 原题

**21、** 编写代码及思想，判断一棵树是否为二叉排序树，结构体已给出。

```c
typedef struct BiTNode{
    int data;//数据域，存储结点值
    struct BiTNode *lchild;//指向左子树的指针
    struct BiTNode *rchild;//指向右子树的指针
}BiTNode,*BiTree;
```

（卷面本节无订正说明。）

## 2. 答案

**设计思想**：二叉排序树（BST）的充要条件是**中序遍历序列严格递增**。故只需按中序次序走一遍树，一路记住"上一个被访问的结点" `pre`，若出现 `pre->data >= t->data`（即后访问到的结点不大于先访问到的结点），说明序列不递增，判为否；全程无违例则判为是。空树按定义视为 BST。

**代码**（教材风格 C，主解见第 6 节第二步）：

```c
BiTree pre;                          /* 中序序列中的前驱结点 */

int IsBST(BiTree t)
{
    if (t == NULL) return 1;
    if (!IsBST(t->lchild)) return 0;
    if (pre != NULL && pre->data >= t->data) return 0;
    pre = t;
    return IsBST(t->rchild);
}

int JudgeBST(BiTree T) { pre = NULL; return IsBST(T); }
```

**复杂度**：时间 $O(n)$（每个结点被访问一次、比较至多 $n-1$ 次）；空间 $O(h)$，$h$ 为树高，退化成单支时最坏 $O(n)$，另需 $1$ 个指针变量。

**备选解**（不依赖遍历序列，直接翻译定义）：递归携带**开区间** $(low,high)$，要求 $low<t\to data<h$；进左子树把上界收到 $t\to data$，进右子树把下界抬到 $t\to data$。时间同为 $O(n)$，空间 $O(h)$，且不需要全局变量。

## 3. 题目分析

- **输入**：一棵以二叉链表存储的树，结点值类型为 `int`，根指针 `BiTree T`；
- **输出**：布尔值（本题用 `int` 作 `TRUE/FALSE`），指示它是否满足二叉排序树的定义；
- **口径声明**：题面说"一棵树"，但给出的结构体是**二叉链表**（`lchild/rchild` 两域），故按"一棵二叉树"处理；判据取教材对 BST 的**严格**定义——左子树所有结点值 $<$ 根 $<$ 右子树所有结点值，因而关键字互异时才有意义，出现相等值判为**否**；
- **关键约束（本题的难点所在）**：BST 的约束是**"整棵子树"级别**的，不是"父子之间"级别的。结点 $x$ 不仅要满足 $x$ 与其孩子的比较关系，还要满足 $x$ 与**所有祖先**以及祖先的其他子树之间的大小关系。因此"只看父与子"的局部检查必然漏判（第 6 节第一步给出反例）；
- **边界情况**：空树（视为 BST）、单结点树（是 BST）、含重复关键字（判否）、值域覆盖整个 `int`（区间法需要额外标志位）、树严重失衡（递归深度达 $n$）；
- **命题意图**：考两件事——① 是否真正理解"BST 的中序序列有序"这一等价判据，并能把它落地成**不需要额外数组**的流式判定（只记前驱）；② 是否会用"全局/引用变量配合递归"这一在树形递归中反复出现的技巧（与求树高、判平衡、结点计数同族）。

## 5. 解题思路

1. **先按"最直觉"的办法试**：对每个结点检查"左孩子 $<$ 我 $<$ 右孩子"。写成 `if (t->lchild && t->lchild->data >= t->data) return 0; ...`。这个版本快且短，但必须马上找反例——第 6 节第一步的 $30$ 为根、$40$ 的左孩子挂 $25$：每个结点和自己的孩子都比过了，全部通过，可它不是 BST（$25$ 落在 $30$ 的右子树里却小于 $30$）。**局部条件 ≠ 全局条件**，此路不通；
2. **补上"祖先信息"，得到两条正路**：
   - 路 A（自顶向下传信息）：递归时把"当前结点允许落在哪个开区间"作为参数传下去，进左子树收紧上界、进右子树收紧下界——这就是备选解；
   - 路 B（借用遍历序列）：把定义换成等价命题"**中序序列严格递增**"，则检查时只需知道"中序里我前面那个结点是谁、值多大"——一个指针 `pre` 就装下了全部祖先约束的传递结果；
3. **路 B 的实现要点**：`pre` 必须与递归同步移动，所以比较的时刻恰好是"中序访问当前结点"的时刻，即**在两次 `IsBST` 递归调用之间**（左子树返回后、进入右子树前）；写成"先比自己再 recurse"或"先 recurse 右子树"都会破坏次序；
4. **`pre` 用全局变量还是形参**？全局最简单；若嫌全局变量不洁，传 `BiTree *pre`（指针的指针）即可在同一份代码里消除全局状态，第 6 节第三步给出该变体；
5. **不必真的把中序存进数组**：存数组要 $O(n)$ 附加空间且要两趟；只记前驱是 $O(1)$ 附加空间、一趟完成——这是本题"写法高下"的分水岭；
6. **收尾自查**：拿正例（一棵真 BST，逐结点写 `pre` 的变化）与三个反例（深层违规、重复键、单边链）各走一遍，确认算法给出的结论与定义一致；两个独立实现（前驱法、区间法）结论相同即可交卷。

## 6. 详细解答

### 第一步：为什么"逐结点比父子"是错的

BST 的定义（教材）：或者为空树，或者满足——若左子树非空则**左子树上所有结点**的值均小于根的值；若右子树非空则**右子树上所有结点**的值均大于根的值；左右子树本身又各是一棵二叉排序树。

注意量词是"所有结点"，递归那句才把子树内部约束补上。于是下面这棵树：

```
        30
       /  \
     20    40
           /
         25
```

- 父子比较：$20<30$ ✓、$40>30$ ✓、$25<40$ ✓ —— 局部检查全部通过；
- 但它不是 BST：$25$ 位于根 $30$ 的**右子树**，却小于 $30$，违反"右子树上所有结点值均大于根"。

其根源在于"祖先的约束"没有随递归传递下去。补传递方式有二：把约束作为**区间**自顶向下传（备选解），或者干脆改判"中序序列是否递增"（主解，此时 $30$ 的中序前驱正是 $25$）。

### 第二步：主解——中序前驱法

```c
/* 结构体按题面给出 */
typedef struct BiTNode{
    int data;
    struct BiTNode *lchild;
    struct BiTNode *rchild;
}BiTNode,*BiTree;

BiTree pre;                              /* 中序序列里"刚刚访问过"的结点 */

int IsBST(BiTree t)
{
    if (t == NULL) return 1;             /* 空树（含叶子左右空孩子）是 BST */
    if (!IsBST(t->lchild)) return 0;     /* ① 先处理左子树：它们的值都应小于 t */
    if (pre != NULL && pre->data >= t->data)
        return 0;                        /* ② 中序前驱不小于当前 → 序列不递增 */
    pre = t;                             /* ③ 把"当前结点"登记为下一个结点的前驱 */
    return IsBST(t->rchild);             /* ④ 再处理右子树 */
}

int JudgeBST(BiTree T)
{
    pre = NULL;                          /* 每次判定前必须复位，否则残留上次的前驱 */
    return IsBST(T);
}
```

**正确性说明（不变量）**：`IsBST(t)` 返回时，若返回值为 $1$，则（a）以 $t$ 为根的子树是 BST；（b）`pre` 恰为**该子树在中序序列中的最后一个结点**（即子树中的最大值结点）。于是当左子树返回 $1$ 时，`pre` 正是"$t$ 在中序中的前驱"，② 处一次比较即覆盖了"$t$ 的左子树全体 $<t$"以及"$t$ 比更早的所有结点都大"这两类约束的全部信息（因为更早的结点已由更浅的调用逐一比较过，且此前一直递增，故只需比最大的那一个——即前驱）。这就是"一个指针装下全部祖先约束"的原因。

**正例走查**：$T_1=30\big(20(10,25),\,40(35,50)\big)$，中序应为 $10,20,25,30,35,40,50$。

| 序 | 到达的结点 | 进入 ② 时的 `pre` | 比较 | 判定 | ③ 之后 `pre` |
|---|---|---|---|---|---|
| 1 | $10$ | `NULL` | 跳过 | 通过 | $10$ |
| 2 | $20$ | $10$ | $10<20$ | 通过 | $20$ |
| 3 | $25$ | $20$ | $20<25$ | 通过 | $25$ |
| 4 | $30$ | $25$ | $25<30$ | 通过 | $30$ |
| 5 | $35$ | $30$ | $30<35$ | 通过 | $35$ |
| 6 | $40$ | $35$ | $35<40$ | 通过 | $40$ |
| 7 | $50$ | $40$ | $40<50$ | 通过 | $50$ |

返回 $1$ ✓（$T_1$ 确为 BST）。

**反例走查**：$T_2$ 即第一步图，中序 $=20,30,25,40$。

| 序 | 结点 | `pre` | 比较 | 结果 |
|---|---|---|---|---|
| 1 | $20$ | `NULL` | 跳过 | `pre = 20` |
| 2 | $30$ | $20$ | $20<30$ | `pre = 30` |
| 3 | $25$ | $30$ | $30\ge 25$ | **返回 0，判否** ✓ |

前驱法恰好在违规的那一对相邻元素上暴露问题，无需回溯到根去比。

### 第三步：两个变体（同一思想，工程上更干净）

**变体 A：去掉全局变量，用形参传前驱的地址**（判据、复杂度完全相同）

```c
int IsBST_p(BiTree t, BiTree *pre)
{
    if (t == NULL) return 1;
    if (!IsBST_p(t->lchild, pre)) return 0;
    if (*pre != NULL && (*pre)->data >= t->data) return 0;
    *pre = t;
    return IsBST_p(t->rchild, pre);
}
int JudgeBST_p(BiTree T) { BiTree q = NULL; return IsBST_p(T, &q); }
```

**变体 B：把前驱换成"前驱的值 + 是否已有前驱"**——不必保留指针，只需一个 `int last` 与一个 `int hasLast`，代价是要单独处理"第一个结点"。写法与上同，不再展开。

### 第四步：备选解——开区间法（直接翻译定义）

```c
/* 要求 low < t->data < high（严格，故等值也判否） */
int IsBSTRange(BiTree t, int low, int high)
{
    if (t == NULL) return 1;
    if (t->data <= low || t->data >= high) return 0;
    return IsBSTRange(t->lchild, low, t->data)      /* 左子树：上界收紧为根值 */
        && IsBSTRange(t->rchild,  t->data, high);   /* 右子树：下界抬升为根值 */
}
```

对 $T_2$：调用 `IsBSTRange(30, MIN, MAX)` → 左 $20\in(MIN,30)$ ✓ → 右 $40\in(30,MAX)$ ✓ → $40$ 的左子树 $25$ 须落在 $(30,40)$ 内，而 $25\le 30$ → 返回 $0$ ✓。与主解结论一致。

**区间法的值域陷阱**：首次调用的 $low,high$ 要"绝对松"。若取 `int` 型的 $-2^{31}$ 与 $2^{31}-1$，则当树中真的出现这两个极值时会被误判（$t\to data\le low$ 命中）。三种回避办法：① 边界改用 `long` 型 $-2^{31}-1$ 与 $2^{31}-1+1$；② 增加两个标志位 `hasLow/hasHigh`，为假时跳过该侧比较；③ 先单独检查根，再以根值向下传。主解不受此影响（它只比较结点之间，从不引入哨兵值），这是主解更稳的一点。

### 第五步：两种实现的对照与横向小结

| 维度 | 主解（中序前驱） | 备选解（开区间） |
|---|---|---|
| 判据来源 | "中序序列严格递增"（充要） | 定义直接改写（充要） |
| 传递的信息量 | 前驱结点 $1$ 个 | 上下界 $2$ 个值 |
| 是否短路 | 是，遇违例立即返回 | 左子树失败即 `&&` 短路 |
| 全局状态 | 需要 `pre`（或改传地址） | 无 |
| 值域极值风险 | 无 | 需处理（第 6 节第四步） |
| 时间 / 空间 | $O(n)$ / $O(h)$ | $O(n)$ / $O(h)$ |

**边界用例核对**（本解析另用第三种实现"把中序存入数组后逐项比较"作对照，三者在下列用例上结论一致）：

| 用例 | 树 | 期望 | 说明 |
|---|---|---|---|
| 空树 | `NULL` | 是 | 定义首条"或者为空树" |
| 单结点 | $7$ | 是 | 无比较对象 |
| 重复键 | $30$ 的左孩子为 $30$ | 否 | `>=` 命中，严格 BST 不允许等值 |
| 深层违规 | $T_2$ | 否 | 局部检查会漏判 |
| 左斜链 | $5\!-\!4\!-\!3\!-\!2$ | 是 | 中序 $2,3,4,5$ 递增；单边链也是合法 BST |
| 右斜链 | $2\!-\!3\!-\!4\!-\!5$ | 是 | 同上，但退化后查找性能降到 $O(n)$ |

### 第六步：复杂度分析

设树有 $n$ 个结点、树高为 $h$（完全二叉树时 $h=\lfloor\log_2 n\rfloor+1$，最坏单支时 $h=n$）。

- **时间**：每个结点恰好进入一次"② 比较 + ③ 登记"，每个空指针恰好触发一次 $t==NULL$ 返回，共 $2n+1$ 层调用，比较执行至多 $n-1$ 次 ⇒ $T(n)=O(n)$；区间法同样每结点一次 ⇒ $O(n)$。二者都优于"先中序存数组、再检查数组"的两趟 $O(n)$（同阶，但多耗 $O(n)$ 空间）。
- **空间**：递归栈深度不超过树高 ⇒ $O(h)$；附加变量仅 `pre` 一个指针 ⇒ $O(1)$。总体 $O(h)$，最坏 $O(n)$。
- 若希望空间与栈解耦，可把中序遍历改为**显式栈的非递归写法**（栈深仍为 $O(h)$，但便于中途退出与超时控制）；若树已被**中序线索化**（DS03.02.04），则可沿线索逐个走到后继，把附加空间降为真正的 $O(1)$（只有 `pre` 一个指针，无栈）。

## 8. 考场标准答案

**(1) 设计思想**（三句话）：二叉排序树 $\Leftrightarrow$ 中序遍历序列严格递增。故按"左—根—右"次序遍历一次，用全局指针 `pre` 保存中序中的前驱结点；访问当前结点时若 `pre` 非空且 `pre->data >= t->data`，即破坏递增性，立即返回 0；否则令 `pre = t` 继续遍历右子树。空树返回 1。

**(2) 代码**：见第 6 节第二步的 `IsBST` 与包装函数 `JudgeBST`（注意 `pre` 必须在入口处复位）。

**(3) 复杂度**：时间 $O(n)$，每结点访问一次；空间 $O(h)$（递归栈）+ $O(1)$ 附加，最坏 $O(n)$。

**(4) 备选写法（答题时可附一句）**：递归传递开区间 $(low,high)$，进左子树带上界 $t\to data$、进右子树下界 $t\to data$，同样 $O(n)$，且不需全局变量。

**(5) 只比父与子不可行**：$30$ 为根、$40$ 的左孩子挂 $25$ 时，全部父子比较通过但树不是 BST。

## 9. 易错点

1. **只检查父子关系**（最常见错解）：`t->lchild->data < t->data && t->rchild->data > t->data` 逐结点判，漏掉"结点须满足所有祖先的方向约束"，第 6 节第一步的反例即判不出来；
2. **比较符写成 `>` 而不是 `>=`**：$30$ 的左孩子恰好也存 $30$ 时被放行；BST 要求关键字互异，等值必判否（若答题时自愿采用"左 $\le$ 根 $<$ 右"的宽松定义，必须把主解与区间法的符号同时改，不能一处严一处松）；
3. **`pre` 忘记复位**：连续调用两次 `JudgeBST`（或把 `pre` 写成未初始化的全局量）时，第二次拿上次残留的结点作前驱，结果依赖调用历史；应在包装函数里 `pre = NULL;`；
4. **比较的位置不对**：把 ② 放到"进入函数第一句"（即先比根再递归），此时 `pre` 还是上一棵子树的后继，比较的是"不该相邻"的两个结点；必须在**左子树递归返回之后**比，才是中序相邻；
5. **左右子树顺序颠倒**：先递归右子树再比，等于按"右—根—左"遍历，判据变成"递减"，把合法的 BST 全判否；
6. **空树返回 0**：`if (t == NULL) return 0;` 会让所有叶结点（其两个孩子皆空）都判否，整棵树被误判；空树按定义是 BST，必须返回 $1$；
7. **真的把中序存进数组再比较**：不算错，但多花 $O(n)$ 空间且要两趟，题目要求"思想 + 代码"时写成只记前驱更简洁；
8. **区间法的哨兵值与真实数据撞车**：用 `INT_MIN/INT_MAX` 作首调边界时，树中若出现该极值即误判（第 6 节第四步给出三种回避）。

## 10. 一句话规律

凡"判断一棵二叉树是否满足某种**全局有序**性质"，条件反射是**中序遍历 + 只记住前驱**：一个指针就能装下所有祖先传来的大小约束，$O(n)$ 一趟搞定；反之"只比父子"必错，因为 BST 的定义里写的是"子树上**所有**结点"。
