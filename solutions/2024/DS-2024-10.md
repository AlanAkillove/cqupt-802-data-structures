# DS-2024-10

## 1. 原题

对序列 `{1,2,3,4,5,6,7}` 进行顺序插入构建平衡二叉树，平衡因子为 $0$ 的结点个数为____________________。

## 2. 答案

$$\boxed{7}$$

依次插入 $1,2,\dots,7$ 后得到的 AVL 为**满二叉树** $4\big(2(1,3),\,6(5,7)\big)$，树中一共只有 $7$ 个结点，而**每个结点**的平衡因子都是 $0$（含 $4$ 个叶子——叶子的左、右子树深度同为 $0$，平衡因子也是 $0$），故平衡因子为 $0$ 的结点个数 $=7$。

## 3. 题目分析

- **已知**：插入序列为严格递增的 $1,2,3,4,5,6,7$；"顺序插入构建平衡二叉树"即每次按二叉排序树的规则放入新结点，一旦破坏平衡就沿插入路径找到**最小不平衡子树**并做相应旋转（LL/RR 单旋、LR/RL 双旋）；
- **目标**：建完整棵树后，统计平衡因子为 $0$ 的结点个数；
- **关键约定**（决定计数口径，必须先固定）：
  1. **平衡因子** $BF=T_{left}\ \text{的深度}-T_{right}\ \text{的深度}$（教材定义），AVL 要求每个结点 $|BF|\le1$；本题递增序列产生的失衡都在右外侧，$BF$ 出现 $-2$；
  2. **空子树深度为 $0$** ⟹ **叶子结点的 $BF=0-0=0$**，即叶子必须计入"平衡因子为 $0$"的结点——本题的胜负点正在此处；
  3. 旋转**不改变**中序遍历次序（BST 有序性保持），故终态树的中序必为 $1,2,\dots,7$，结点总数恒为 $7$；
- **隐含约束**：序列递增 ⟹ 若不旋转就会退化成右单支链（深度 $7$）；每插入一个就旋转一次或几次，本题实际发生了 $4$ 次旋转（$RR$ 左旋），最终形态恰好是完美/满二叉树；
- **命题意图**：考 **AVL 的构造过程（插入 + 旋转）**（DS05.07.02）与**平衡因子的逐点计算**。题面选的序列"看似最坏（有序）"，实则旋转后得到最规整的形态，用来检验考生是否**真的把树建出来再数**，而不是套"$n$ 个结点的 AVL 有多少 $BF=0$"这类并不存在的公式。它与 DS-2021-16（"每个非终端结点平衡因子均为 $0$" $\Rightarrow$ 满二叉树 $2^{k}-1$ 个结点）恰为同一条性质的**正反两个方向**。

## 4. 核心考点

核心考点：
DS05.07.02 平衡二叉树——插入新结点后"沿插入路径回溯找最小不平衡子树 $\to$ 按 $LL/RR/LR/RL$ 旋转调整"的构造流程；平衡因子 $BF$ 的定义与逐点计算；旋转后树高下降、恢复平衡

辅助考点：
DS05.07.01 二叉搜索（排序）树——AVL 首先是 BST，"顺序插入 $1..7$"的插入位置由 BST 规则决定，且旋转保持中序有序（本题用中序 $=1..7$ 作为验算）
DS03.02.01 二叉树的定义及主要特征——深度 $k$ 的二叉树至多 $2^{k}-1$ 个结点、取等时为满二叉树、满二叉树每个结点左右子树同深（用于第二条路线直接判定"全部 $BF=0$"）

解释：主标签落在 DS05.07.02，因为不建 AVL 就无从谈起；BST 与满二叉树性质分别是"插入位置/验算"与"捷径论证"的依据，故列辅助。能力标签含 `TRACE`，因本题必须逐趟模拟插入与旋转过程。

## 5. 解题思路

1. **先固定两个口径**：$BF=$ 左深 $-$ 右深；空子树深度 $0$ $\Rightarrow$ 叶子 $BF=0$（否则计数会少 $4$）；
2. **逐趟插入，每趟做三件事**：① 按 BST 规则挂上新结点；② 从新结点向上沿插入路径找第一个 $|BF|=2$ 的结点（最小不平衡子树的根 $A$）；③ 看 $A$ 的失衡方向（插入落在 $A$ 的"右孩子之右孩子"即 $RR$ ⟹ 以 $A$ 为轴左旋；左外侧 $LL$ ⟹ 右旋；一左一右 $LR/RL$ ⟹ 先单旋化成同侧再旋转）；本题序列递增，四次失衡全为 $RR$；
3. **每趟把调整后的层次序列写下来**（形如"根 / 第二层 / 第三层"），既防手错，也方便最后一趟直接读出树高与形态；
4. **终态逐点算 $BF$ 并数 $BF=0$ 的个数**——注意要包含叶子；
5. **换一条独立路线复核**（结构论证）：数出终态树结点 $7$、深度 $3$；深度 $3$ 的二叉树最多 $2^3-1=7$ 个结点，取到上限即为满二叉树；满二叉树每个结点左右子树同深 $\Rightarrow$ 全部 $BF=0$ $\Rightarrow$ 答案是 $7$（不必依赖第 4 步的逐点算）；
6. **再验 BST 性质**：对终态树取中序遍历应为 $1,2,3,4,5,6,7$；若中序错乱说明某次旋转的孩子交接写反；
7. **排除误答**：$3$（只数了内部结点，漏掉 $4$ 个叶子）、$1$（只数根）、$4$（只数叶子）都是常见误算，见第 6 节第七步。

## 6. 详细解答

### 第一步：约定与旋转工具

结点与平衡因子的教材风格定义：

```c
typedef struct AVLTNode {
    int   key;                 /* 关键字 */
    int   bf;                  /* 平衡因子 = 左子树深度 - 右子树深度，|bf| <= 1 */
    struct AVLTNode *lchild, *rchild;
} AVLTNode, *AVLTree;
```

本题只用到 $RR$ 型失衡，其调整是**一次左旋**（单旋，旋转轴为最小不平衡子树的根 $A$，$B=A\to rchild$）：

```c
void LL_Rotate(AVLTNode *&pA)          /* 左旋：以 pA 为根的 RR 型最小不平衡子树 */
{
    AVLTNode *pB = pA->rchild;         /* B 为 A 的右孩子 */
    pA->rchild = pB->lchild;           /* B 的左子树让给 A 当右子树 */
    pB->lchild = pA;                   /* A 降为 B 的左孩子 */
    pB->bf = 0;  pA->bf = 0;           /* 单次左旋后 A、B 的平衡因子都归 0 */
    pA = pB;                           /* B 接替 A 在原树中的位置（引用参数） */
}
```

空子树深度记 $0$，叶子深度记 $1$；下文用 `x(bf±k)` 标注每个结点的平衡因子，层次序列自顶向下、从左到右书写。

### 第二步：逐趟插入与旋转轨迹

| 趟 | 插入 | 插入后（失衡处） | 判定 | 动作 | 旋转后的树（层次序列，含 $BF$） |
|---|---|---|---|---|---|
| 1 | $1$ | $1(0)$ | 平衡 | — | $1(0)$ |
| 2 | $2$ | $1(-1)\to2(0)$ | 平衡 | — | $1(-1)\ 2(0)$ |
| 3 | $3$ | $1(\mathbf{-2})\to2(-1)\to3(0)$ | $A{=}1$，$B{=}2$，插入在 $B$ 的右子树 $\Rightarrow RR$ | 以 $1$ 为轴**左旋** | $2(0)\ 1(0)\ 3(0)$ |
| 4 | $4$ | $2(-1)\ 1(0)\ 3(-1)\ 4(0)$ | 平衡（$|BF|\le1$） | — | $2(-1)\ 1(0)\ 3(-1)\ 4(0)$ |
| 5 | $5$ | $2(-1)\ \underline{3(\mathbf{-2})}\to4(-1)\to5$ | $A{=}3$，$B{=}4$，$RR$ | 以 $3$ 为轴**左旋** | $2(-1)\ 1(0)\ 4(0)\ 3(0)\ 5(0)$ |
| 6 | $6$ | $\underline{2(\mathbf{-2})}\to4(-1)\to5(-1)\to6$ | $A{=}2$，$B{=}4$，$C{=}5$，$RR$ | 以 $2$ 为轴**左旋** | $4(0)\ 2(0)\ 5(-1)\ 1(0)\ 3(0)\ 6(0)$ |
| 7 | $7$ | $4(0)\ 2(0)\ \underline{5(\mathbf{-2})}\to6(-1)\to7$ | $A{=}5$，$B{=}6$，$RR$ | 以 $5$ 为轴**左旋** | $4(0)\ 2(0)\ 6(0)\ 1(0)\ 3(0)\ 5(0)\ 7(0)$ |

四次旋转的形态细节（$RR$ 单旋的关键是"B 的左子树交接给 A"）：

- **第 3 趟**：链 $1\to2\to3$（全右）。左旋后 $2$ 上提为根，$1$ 成其左孩子，$3$ 仍是 $2$ 的右孩子（$B$ 原无左子树，交接给 $A$ 后 $A$ 成为叶子）。
- **第 5 趟**：$2$ 的右子树里链 $3\to4\to5$。以 $3$ 为轴左旋，$4$ 上提接回 $2$ 的右指针，$3$ 降为 $4$ 的左孩子，$5$ 为 $4$ 的右孩子。
- **第 6 趟**：链 $2\to4\to5\to6$，第一个 $|BF|=2$ 的是根 $2$（$BF=1-3=-2$），$B=4$、$C=5$，属 $RR$；以 $2$ 为轴左旋：$4$ 成为新根，$2$ 降为 $4$ 的左孩子，**$4$ 的原左子树 $3$ 交接给 $2$ 作右孩子**，$5(\to6)$ 仍挂在 $4$ 的右侧。结果根为 $4$，第二层 $2,5$，第三层 $1,3,6$。
- **第 7 趟**：往 $6$ 的右边插 $7$，使 $5$ 的 $BF=0-2=-2$，$B=6$、$C=7$，$RR$；以 $5$ 为轴左旋：$6$ 上提接回 $4$ 的右指针，$5$ 降为 $6$ 的左孩子（$6$ 原无左子树），$7$ 为 $6$ 的右孩子。

终态树（自第 7 趟层次序列 $4,2,6,1,3,5,7$ 还原）：

```
            4
          /   \
        2       6
       / \     / \
      1   3   5   7
```

### 第三步：终态逐点算平衡因子（路线一）

记结点深度：叶子为 $1$，空树为 $0$。

| 结点 | 左子树深度 | 右子树深度 | $BF$ | 是否计入 $BF=0$ |
|---|---|---|---|---|
| $4$（根） | $2$（以 $2$ 为根的子树） | $2$（以 $6$ 为根的子树） | $0$ | ✓ |
| $2$ | $1$（结点 $1$） | $1$（结点 $3$） | $0$ | ✓ |
| $6$ | $1$（结点 $5$） | $1$（结点 $7$） | $0$ | ✓ |
| $1$ | $0$ | $0$ | $0$ | ✓（叶子） |
| $3$ | $0$ | $0$ | $0$ | ✓（叶子） |
| $5$ | $0$ | $0$ | $0$ | ✓（叶子） |
| $7$ | $0$ | $0$ | $0$ | ✓（叶子） |

$7$ 个结点的 $BF$ 全为 $0$ ⟹ **答案 $7$**；且每个结点 $|BF|\le1$，确为 AVL ✓。

### 第四步：结构论证复核（路线二，不依赖逐点计算）

1. 结点总数 $=7$（插入 $7$ 个、旋转不增删结点）；
2. 终态树的根在第 $1$ 层，最深结点 $1,3,5,7$ 在第 $3$ 层 ⟹ 深度 $k=3$；
3. 深度为 $k$ 的二叉树至多 $2^{k}-1$ 个结点，而 $2^{3}-1=7$ **恰好等于本题结点数** ⟹ 该树把每一层都填满（第 $1,2,3$ 层分别有 $1,2,4$ 个结点），即为**满二叉树**；
4. 满二叉树中任一结点的左、右子树是两棵同深度的满二叉树 ⟹ 每个结点 $BF=0$；
5. 故 $BF=0$ 的结点个数 $=$ 结点总数 $=7$ ✓——与路线一独立吻合。

（这条路线同时说明：**本题不必数"哪几个点旋转过"，只要确认终态是满二叉树即可**。它的逆命题正是 DS-2021-16：一棵深度 $k$ 的 AVL 若每个非终端结点 $BF$ 均为 $0$，则结点数为 $2^{k}-1$。）

### 第五步：BST 有序性验算（防止孩子交接写反）

对第 2 节终态树取**中序遍历**（左—根—右）：

$$1,\ 2,\ 3,\ \underbrace{4}_{根},\ 5,\ 6,\ 7$$

得到严格递增序列 ✓，说明四次旋转中"B 的左子树交接给 A"这一步没有写反（若第 6 趟把 $3$ 误挂到 $2$ 的左侧，中序将出现 $3,1,2$ 的乱序）。

再验 AVL 的另一条不变式：任取结点，其左右子树深度差的绝对值 $\le1$——上表已给出全部差值为 $0$ ✓。

### 第六步：为什么"有序序列插入"仍能得到满二叉树（机制说明）

递增序列在 BST 中产生右单支链，每次失衡都是 $RR$ 型，一次左旋即恢复；左旋使根位置上移的结点恰好是"右子树变高"后新加入的中位值，于是根的选取自动趋向"把序列折半"：

| 趟 | 旋转后根 | 含义 |
|---|---|---|
| 3 | $2$ | $1,2,3$ 的中位 |
| 6 | $4$ | $1\sim5$ 之后（插入 $6$ 时）折半取 $4$ |
| 7 | $4$（右子树根换成 $6$） | 最终 $4$ 为根、$2,6$ 为第二层，正是 $1\sim7$ 的折半结构 |

因此"最坏输入（有序）$+$ AVL 自动折半"最终给出了最优形态（满二叉树），这是本题的趣味所在，也是答案恰好等于结点总数的原因。

## 8. 考场标准答案

**$7$**。

考场书写：

依次插入并调整（四次失衡均为 $RR$ 型，各作一次左旋），最终得到

```
        4
      /   \
     2     6
    / \   / \
   1   3 5   7
```

该树深度 $3$、$7$ 个结点，$2^{3}-1=7$ 恰为满二叉树；每个结点（含 $4$ 个叶子）的左、右子树深度相同，故平衡因子全为 $0$，个数 $=\boxed{7}$。

## 9. 易错点

1. **漏数叶子**（最主要失分点）：叶子的左、右子树都为空，深度差 $0$，$BF=0$，属于"平衡因子为 $0$ 的结点"；只数 $4,2,6$ 会得 $3$；
2. **以为"空子树深度 $-1$、叶子 $BF$ 另有规定"**：无论按"空树深度 $0$"还是"$-1$"约定，叶子两子树深度总相等，$BF$ 恒为 $0$，不影响计数；但内部结点的 $BF$ 数值口径要统一，别混用；
3. **只建 BST 不旋转**：得到右单支链 $1\to2\to\cdots\to7$，此时 $BF$ 依次为 $-6,-5,\dots,0$，只有 $7$ 号结点 $BF=0$，会误答 $1$——题面明确说"构建**平衡**二叉树"；
4. **旋转类型判错**：第 6 趟失衡根是 $2$ 而不是 $4$（要沿插入路径找**最小**不平衡子树，即最深的那个 $|BF|=2$ 结点——本题插入 $6$ 后只有 $2$ 的 $BF=-2$）；若误以 $4$ 为轴旋转会把树弄乱，中序不再递增；
5. **忘做孩子交接**：$RR$ 左旋时"B 的左子树要给 A 当右子树"，第 6 趟中 $3$ 必须从 $4$ 的左侧换到 $2$ 的右侧；漏掉这一步会丢结点（$1..7$ 不再全在树中）；
6. **以为双旋也会出现**：本题插入序列单调递增，路径始终"右—右"，不会遇到 $LR/RL$；若把某趟误判成双旋，会得到另一棵合法但形态不同的树，进而数错；
7. **误答成 $5$**：把"$BF=0$ 的结点"与"$|BF|\le1$ 的结点"混淆后再凭感觉扣数。AVL 定义要求**所有**结点 $|BF|\le1$，与"恰为 $0$"是两回事。

## 10. 一句话规律

AVL 构造题一律"**逐趟插入 $\to$ 沿插入路径找最深的那个 $|BF|=2$ 结点为轴旋转 $\to$ 每趟写下层次序列**"，建完再数；数"平衡因子为 $0$"时**先把叶子算进去**（叶子必为 $0$），再用"$n$ 个结点、深度 $k$、若 $n=2^{k}-1$ 即满二叉树 $\Rightarrow$ 全部 $BF=0$"这一结构性捷径互验，最后用中序是否有序检查旋转有没有写反。
