# DS-2016-04

## 1. 原题

若允许表达式内多种括号混合嵌套，则设计检查表达式中括号是否正确配对的算法，通常选用的辅助结构是（）。

A. 栈

B. 线性表

C. 队列

D. 二叉排序树

## 2. 答案

**A**（栈）。括号嵌套的本质是"**最后打开的括号必须最先闭合**"，这正是后进先出（LIFO）；把左括号逐个入栈，遇到右括号时与**栈顶**左括号配对并弹栈，配合"扫描结束时栈应为空"即可判定配对。

## 3. 题目分析

- 已知：表达式中含有多种括号（$()$、$[]$、$\{\}$ 等）且允许**混合嵌套**；
- 目标：选出实现配对检查最合适的辅助结构；
- 关键约束：需要反复访问的对象是"**最近一个尚未闭合的左括号**"——访问位置只在一端，且按打开的相反次序关闭；
- 命题意图：把"括号嵌套"这一语言结构翻译成"后进先出"，考查栈的典型应用；题面强调"多种括号混合嵌套"，是为了让"只用计数器"或"先进先出"的做法失效（单种括号时只需计数，不必保存种类），从而把区分度放在"是否理解 LIFO 与嵌套的对应关系"上。

## 4. 核心考点

核心考点：

辅助考点：

解释：本题不需要写出存储细节，只需判断"递归嵌套结构 ⟹ 栈"这一应用对应关系（属 DS02.07），而判断的依据是栈／队列各自的操作限制定义（属 DS02.01），故列两个节点。

## 5. 解题思路

1. 抓结构特征：嵌套意味着"最内层最先闭合"。写出来看：`([])` 中，`[` 在 `(` 之后打开，却必须在 `(` 闭合之前先闭合 ⟹ 闭合次序是打开次序的**逆序**；
2. 逆序访问 ⟹ 只能在同一端插入与删除 ⟹ LIFO ⟹ 栈（同时排除队列：队列是打开次序的**同序**输出）；
3. 检查"多种括号"这一限定：需要比对配对符号的**种类**，故必须保存左括号的类型，仅计数（$+1/-1$）不够，必须用能存信息的结构；
4. 用反例确认队列不可行：合法式 `([])` 用队列处理会把 `(` 与 `]` 比对而误判为不配对（见第 6 节）；
5. 线性表过于宽泛、二叉排序树与本题的"逆序配对"无关，排除 B、D。

## 6. 详细解答

**（1）为什么是栈**

设表达式字符流从左到右扫描。任一左括号 $L_1$ 先入栈、其后又打开了 $L_2$，则 $L_2$ 必须在 $L_1$ 之前闭合（否则两者区间交叉，不是合法嵌套）。所以"待配对左括号"的闭合次序恰好是它们的入栈次序的逆序，即 LIFO。栈的插入（`Push`）与删除（`Pop`）都限制在栈顶，天然匹配这一需求：

- 遇左括号 ⟹ 入栈（保存种类，供以后配对）；
- 遇右括号 ⟹ 与栈顶左括号种类核对：匹配则弹栈，不匹配或栈空则判为不配对；
- 扫描结束 ⟹ 栈空则全部闭合，栈非空则有多余左括号。

三种括号交叉而非嵌套的情形（如 `([)]`）在第 2 步就会被栈顶比对识破，算法仍是同一个，说明该方案对"多种括号混合嵌套"完备。

**（2）为什么队列不行（构造反例）**

队列是先进先出。对**合法**表达式 `([])`：

| 扫描字符 | 队列动作 | 队列状态 |
|---|---|---|
| `(` | 入队 | `(` |
| `[` | 入队 | `(` `[` |
| `]` | 出队得 `(`，与 `]` 种类不符 | — |

正确的 `([])` 被误判为"不配对"，说明 FIFO 与嵌套语义相悖。反过来，若把出队元素与右括号强行匹配，则 `[()]` 这类式子会被错误接受。故 C 不可用。

**（3）为什么 B、D 不选**

- B 线性表：栈本身就是"插入删除限制在一端的线性表"，用一般线性表意味着可以在任意位置插入删除，算法不再保证"最近打开者优先闭合"，命题要求的是**通常选用的辅助结构**，取最贴切的受限结构（栈），不取过于宽泛的上位概念；
- D 二叉排序树：用于按关键字动态查找／排序，其"中序有序"性质与括号的配对次序无关，构造与维护都无收益。

**答案**：A。

## 7. 选项分析

- A. 栈：正确。嵌套结构的闭合次序是打开次序的逆序，LIFO 与之一一对应，且栈顶比对可同时校验种类与层次；
- B. 线性表：不选。概念过宽，未利用"操作限制在一端"这一关键性质；写成一般线性表反而可能把非嵌套（交叉）情形判对；
- C. 队列：错。FIFO 输出的是"最早打开的左括号"，与"最先闭合"要求相反，用 `([])` 即产生误判（单种括号且只计数时队列问题不存在，但题面已声明多种括号混合嵌套）；
- D. 二叉排序树：错。与配对次序无关，属无关结构（其在教材中出现在查找章 DS05.07.01）。

## 8. 考场标准答案

选用**栈**。算法思想：顺序扫描表达式，遇左括号入栈；遇右括号则取栈顶元素核对种类，匹配则弹栈，否则（含栈空）判为不配对；扫描结束时栈为空则整体配对正确。

```c
/* brackets: 合法的左括号集合，match[c] 给出与右括号 c 配对的左括号 */
Status CheckBrackets(char expr[], Stack *S)
{
    int i = 0;
    InitStack(S);
    while (expr[i] != '\0') {
        char c = expr[i];
        if (c=='(' || c=='[' || c=='{') {          /* 左括号：入栈 */
            Push(S, c);
        } else if (c==')' || c==']' || c=='}') {   /* 右括号：与栈顶配对 */
            char top;
            if (StackEmpty(S) || Pop(S, &top)==ERROR || top != Match(c))
                return FALSE;                      /* 栈空或种类不符 */
        }
        i++;
    }
    return StackEmpty(S) ? TRUE : FALSE;           /* 还有左括号未闭合 */
}
```

时间复杂度 $O(n)$（$n$ 为表达式长度，每字符至多入栈、出栈各一次）；空间复杂度最坏 $O(n)$（表达式全为左括号时）。

## 9. 易错点

1. 认为"队列也能配对"：单种括号只计数时看不出差别，题面"多种括号混合嵌套"才暴露 FIFO 的错误——务必用 `([])` 验证；
2. 忘记**扫描结束后判栈空**：`((` 这类只有左括号的式子，逐字符比对不会报错，必须靠"结束时栈为空"来否定；
3. 忘记**遇右括号时判栈空**：`)` 开头或 `()` 之外的多余右括号应在弹栈前发现，否则越界访问；
4. 把"线性表"当答案：过于宽泛的上位概念不是"通常选用的辅助结构"，本题考的是选择哪种**受限**操作。

## 10. 一句话规律

凡是"后进先出／递归嵌套"式的匹配问题（括号配对、表达式求值、递归转非递归、函数调用返回次序）一律用栈；凡是"先后先出／同层次扩展"（层次遍历、缓冲、作业调度）一律用队列——判断依据是**待处理对象的关闭次序与打开次序是逆序还是同序**。
