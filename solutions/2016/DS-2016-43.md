# DS-2016-43

## 1. 原题

请设计一个算法，将有 $n$ 个元素的数组 $A$ 中元素 $A[0]$ 至 $A[n-1]$ 循环右移 $k$ 位，并要求只用一个元素大小的附加存储，元素移动或交换次数为 $O(n)$。要求先给出算法思想，再描述算法，必要时给予注释和说明。

本题无订正说明、无配图。

## 2. 答案

**算法思想（一句话）**：把数组看成前后两段 $A[0..n-k-1]=X$ 与 $A[n-k..n-1]=Y$，循环右移 $k$ 位就是要把 $XY$ 变成 $YX$；而对整段做"逆置"记为 $R(\cdot)$，则 $R(R(X)R(Y))=YX$——故**逆置前 $n-k$ 个元素、逆置后 $k$ 个元素、再逆置全部 $n$ 个元素**即可完成循环右移，每次逆置只需一个元素大小的临时变量。

**核心代码**（三次逆置法，见第 6、8 节）：

```c
Reverse(A, 0, n - k - 1);   /* X^r Y   */
Reverse(A, n - k, n - 1);   /* X^r Y^r */
Reverse(A, 0, n - 1);       /* Y  X    */
```

**复杂度**：元素交换次数 $\le n$（赋值次数 $\le 3n$），时间 $O(n)$；附加存储仅为逆置时的一个临时元素（另需若干下标变量），满足"一个元素大小的附加存储"。

**边界处理**：$n\le1$ 直接返回；先 $k \bmod n$ 归一（$k\ge n$ 或 $k$ 为 $n$ 的倍数时不移）；$k\bmod n=0$ 时直接返回。

## 3. 题目分析

- **输入**：含 $n$ 个元素的数组 $A[0..n-1]$（元素类型可为任意可拷贝类型，下面以 `int` 示意）与非负整数 $k$；
- **输出**：原地改变 $A$，使新数组满足 $A_{new}[i]=A_{old}[(i-k)\bmod n]$，即每个元素向右移动 $k$ 格、越过末端的从 $A[0]$ 处绕回；
- **数据结构选择**：顺序表（数组）。题目给定"数组"，且要求附加存储仅一个元素，故必须**原地**操作，不能开第二个数组；
- **核心不变量**（三次逆置法）：每步之后，数组始终是"若干段，每段都是原某段的逆序"这一结构；第三步结束时恰为 $YX$，即所求；
- **约束清单**：① 附加存储 $=1$ 个元素大小；② 移动或交换次数 $=O(n)$；③ 卷面还要求"先给出算法思想，再描述算法，必要时给予注释和说明"——即答案的**表达形式**也是硬性要求；
- **陷阱与边界**：空表（$n=0$）、单元素（$n=1$）、$k=0$、$k\ge n$（须先取余，否则下标 $n-k$ 为负导致越界）、$k=n$（整环复位）；
- **命题意图**：考"用有限的存储约束逼出结构性技巧"——若允许 $O(n)$ 附加空间，一行 `B[(i+k)%n]=A[i]` 即可；限制成一个元素后，唯一出路是利用**逆置算子**的对合性（$R(R(S))=S$）或**置换环**的封闭性。二者都是顺序表原地重排的通法（与本库"重排使负数在前""有序表原地合并"等题同源）。

## 5. 解题思路

1. **先把题意翻译成下标等式**：循环右移 $k$ 位 $\iff A_{new}[(i+k)\bmod n]=A_{old}[i]$。有了等式，任何候选算法都能用小例子手工判定对错——这是本题最重要的"可检验性"来源；
2. **先试最朴素的办法并排除**：
   - 开一个等长辅助数组 $B$，$B[(i+k)\bmod n]=A[i]$：$O(n)$ 时间但**附加空间 $O(n)$**，违反约束①，排除；
   - 循环 $k$ 次"整体右移一位"（每次先存末元素、再自右向左顺次后移）：只用一个附加元素，但移动 $nk$ 次，**$O(nk)$ 不满足 $O(n)$**，排除；
3. **观察结构**：右移 $k$ 位等价于"把尾部的 $k$ 个元素整体搬到头部"。设 $A=XY$（$|X|=n-k$，$|Y|=k$），目标是 $YX$——这就是**两段交换**问题；
4. **调用逆置算子**：对任意序列 $S$ 记 $S^r$ 为其逆置，则 $(S^r)^r=S$，且 $(ST)^r=T^rS^r$。于是
   $$YX=\bigl(X^rY^r\bigr)^r$$
   即"先分别逆置两段、再整体逆置"。逆置一段只需一个临时变量做对称交换 ⟹ 两个约束同时满足；
5. **想第二解法做交叉验证**：数组下标在" $\bmod\ n$ 加 $k$"映射下分解成 $g=\gcd(n,k)$ 个不相交的环，逐环轮转（每环用一个 temp 接力）也是原地 $O(n)$。两种解法互为验证，且环法的移动次数更少（$2n$）；
6. **必做走查**：取 $n=7,k=3$ 手算（第 6 节），与"按定义右移"逐项比对；再取 $k>n$、$k=n$、$n=1$ 各验一次边界。

## 6. 详细解答

### 主解：三次逆置法

**（1）算法思想（卷面第一问要求的内容）**

将 $A[0..n-1]$ 分成前后两段：前段 $X=A[0..n-k-1]$（$n-k$ 个元素）、后段 $Y=A[n-k..n-1]$（$k$ 个元素）。循环右移 $k$ 位的实质是把后段 $Y$ 整体移到前段 $X$ 之前，即完成 $XY\to YX$ 的变换。

利用逆置运算的两条性质：① 对合性 $(S^r)^r=S$；② 反分配性 $(ST)^r=T^rS^r$。于是

$$XY=\bigl((XY)^r\bigr)^r=(Y^rX^r)^r$$

而 $Y^rX^r$ 恰好可以这样得到：先把 $X$ 就地逆置、再把 $Y$ 就地逆置，数组就变成 $X^rY^r$——**注意此时 $X^r,Y^r$ 的位置仍是"前段、后段"**，与 $Y^rX^r$ 只差一次整体逆置。故三步为：

- 第 1 步：逆置 $A[0..n-k-1]$，数组由 $XY$ 变为 $X^rY$；
- 第 2 步：逆置 $A[n-k..n-1]$，数组变为 $X^rY^r$；
- 第 3 步：逆置 $A[0..n-1]$，数组变为 $(X^rY^r)^r=YX$，即所求。

逆置一段的操作是"首尾对称交换、双指针向中间靠拢"，每次交换只借用**一个元素大小**的临时变量，故附加存储满足要求。

**（2）算法描述（教材风格 C，含注释）**

```c
typedef int ElemType;        /* 元素类型按题设可为任意可拷贝类型 */

/* 逆置 A[left..right]（闭区间）。
   附加存储：仅一个元素 temp；交换次数 = (right-left+1)/2 的下取整 */
void Reverse(ElemType A[], int left, int right)
{
    ElemType temp;                       /* 唯一的元素级附加存储 */
    while (left < right) {               /* left==right（奇数段正中元素）
                                              或 left>right（空段）时不动 */
        temp       = A[left];
        A[left]    = A[right];
        A[right]   = temp;
        left++;  right--;                /* 双指针相向推进 */
    }
}

/* 把 A[0..n-1] 循环右移 k 位（原地，附加存储一个元素，移动次数 O(n)） */
void RotateRight(ElemType A[], int n, int k)
{
    if (n <= 1) return;                  /* 边界：空表或单元素，移了也不变 */
    k = k % n;                           /* 边界：k>=n 先归一到 0..n-1，
                                              否则下面 n-k 为负会越界 */
    if (k == 0) return;                  /* 边界：k 为 n 的倍数 ⟹ 恒等变换 */

    Reverse(A, 0, n - k - 1);            /* 第 1 步：逆置前 n-k 个  -> X^r Y   */
    Reverse(A, n - k, n - 1);            /* 第 2 步：逆置后 k 个    -> X^r Y^r */
    Reverse(A, 0, n - 1);                /* 第 3 步：逆置全体      -> Y  X    */
}
```

**（3）正确性说明**

设 $X=(A[0],\cdots,A[n-k-1])$、$Y=(A[n-k],\cdots,A[n-1])$。

- 第 1、2 步后数组内容为 $X^rY^r$；
- 由反分配性 $(X^rY^r)^r=(Y^r)^r(X^r)^r=YX$，第 3 步后数组内容为 $YX$；
- $YX$ 的前 $k$ 项正是原 $A[n-k..n-1]$、后 $n-k$ 项正是原 $A[0..n-k-1]$，即 $A_{new}[i]=A_{old}[(i-k)\bmod n]$ 对一切 $i$ 成立 ⟹ 恰为循环右移 $k$ 位。$\blacksquare$

**（4）样例走查** $n=7$，$A=(1,2,3,4,5,6,7)$，$k=3$（$X=(1,2,3,4)$，$Y=(5,6,7)$）

| 步骤 | 操作 | 数组状态 |
|---|---|---|
| 初 | — | $(1,2,3,\,4,\;\mathbf{5,6,7})$ |
| 1 | 逆置 $A[0..3]$ | $(4,3,2,\,1,\;\mathbf{5,6,7})$ |
| 2 | 逆置 $A[4..6]$ | $(4,3,2,\,1,\;\mathbf{7,6,5})$ |
| 3 | 逆置 $A[0..6]$ | $(\mathbf{5,6,7},\,1,2,3,\,4)$ |

按定义核对：右移 $1$ 位 $(7,1,2,3,4,5,6)$、右移 $2$ 位 $(6,7,1,2,3,4,5)$、右移 $3$ 位 $(5,6,7,1,2,3,4)$ ✓ 与三步结果一致。

**（5）第二组走查** $n=8$，$A=(1,\cdots,8)$，$k=5$（$X=(1,2,3)$，$Y=(4,\cdots,8)$）

$$\text{初}\;(1,2,3\,|\,4,5,6,7,8)\xrightarrow{1}(3,2,1\,|\,4,5,6,7,8)\xrightarrow{2}(3,2,1\,|\,8,7,6,5,4)\xrightarrow{3}(4,5,6,7,8\,|\,1,2,3)$$

按定义 $A_{new}[i]=A_{old}[(i-5)\bmod 8]$：$(4,5,6,7,8,1,2,3)$ ✓。

**（6）复杂度与约束核对**

`Reverse` 处理长度 $L$ 的段时做 $\lfloor L/2\rfloor$ 次交换、每次 $3$ 次赋值，故

$$\text{交换次数}=\Bigl\lfloor\tfrac{n-k}{2}\Bigr\rfloor+\Bigl\lfloor\tfrac{k}{2}\Bigr\rfloor+\Bigl\lfloor\tfrac{n}{2}\Bigr\rfloor\le\tfrac{n}{2}+\tfrac{n}{2}=n$$

$$\text{赋值次数}=3\times\text{交换次数}\le 3n$$

- 时间：$O(n)$（且与 $k$ 无关，$k$ 很大时也不会退化）；
- 附加存储：`temp` 一个元素 $+$ 常数个下标变量 $=O(1)$，满足"只用一个元素大小的附加存储"；
- 无递归，故不存在隐藏的递归栈开销。

**（7）边界情况逐项核对**

| 情形 | 处理 | 结果 |
|---|---|---|
| $n=0$（空表） | `if (n<=1) return;` 先挡 | 不进入任何下标计算，安全 |
| $n=1$ | 同上 | 不移 |
| $k=0$ | $k\bmod n=0$ → `if (k==0) return;` | 不移 |
| $k=n$ | $k\bmod n=0$ | 不移（正确：整环复位） |
| $k>n$，如 $n=7,k=10$ | $k\bmod n=3$ | 等价于右移 $3$ 位 ✓ |
| $k<0$（若题意含左移） | 本题未涉及；如需可先 $k=((k\%n)+n)\%n$ | — |
| $n-k$ 的下标 | 归一后 $1\le k\le n-1$，故 $n-k-1\ge0$、$n-k\le n-1$ | 两段均非空且不越界 |

**（8）备选解法：置换环法（移动次数更少，同样原地 $O(n)$）**

**思想**：位置 $i$ 的元素右移后应去 $(i+k)\bmod n$，该映射是 $\{0,\cdots,n-1\}$ 的一个置换，且分解为 $g=\gcd(n,k)$ 个长度为 $n/g$ 的不相交环。逐个环处理：把环起点元素暂存于 `temp`，沿环"接力"搬移，最后把 `temp` 填入环起点。

```c
int Gcd(int a, int b) { while (b) { int t = a % b; a = b; b = t; } return a; }

void RotateRight_Cycle(ElemType A[], int n, int k)
{
    if (n <= 1) return;
    k %= n;
    if (k == 0) return;
    int g = Gcd(n, k);                        /* 环的个数 */
    for (int s = 0; s < g; s++) {             /* 逐个环处理 */
        ElemType temp = A[s];                 /* 暂存环起点元素 */
        int cur = s;
        for (;;) {
            int next = (cur + k) % n;         /* temp 里的值应搬去的位置 */
            if (next == s) break;             /* 回到起点，本环闭合 */
            ElemType t = A[next];             /* 先取出该位置原值，再写入 */
            A[next] = temp;
            temp = t;
            cur  = next;
        }
        A[s] = temp;                          /* 最后挤出的值填入环起点 */
    }
}
```

**环法走查** $n=8$，$A=(1,\cdots,8)$，$k=2$：$\gcd(8,2)=2$，两个环——偶下标环 $0\to2\to4\to6\to0$、奇下标环 $1\to3\to5\to7\to1$。

环 $s=0$：$temp{=}1$；$A[2]{\leftarrow}1,temp{=}3$；$A[4]{\leftarrow}3,temp{=}5$；$A[6]{\leftarrow}5,temp{=}7$；$next{=}0$ 闭合，$A[0]{\leftarrow}7$。表变 $(7,2,1,4,3,6,5,8)$。
环 $s=1$：$temp{=}2$；$A[3]{\leftarrow}2,temp{=}4$；$A[5]{\leftarrow}4,temp{=}6$；$A[7]{\leftarrow}6,temp{=}8$；闭合，$A[1]{\leftarrow}8$。表变 $(7,8,1,2,3,4,5,6)$ ✓ 与"右移 $2$ 位"的定义值完全一致。

**复杂度**：每个元素恰好被"取出一次、写入一次"，赋值次数 $2n$（比逆置法的 $\le3n$ 更少）；附加存储 $1$ 个元素 $+$ 常数个下标变量 $=O(1)$；时间 $O(n)$。缺点是需要求 $\gcd$，且"接力时务必先取原值再写入"的顺序容易写错——故考场推荐写逆置法，环法作为备注或第二方案。

## 8. 考场标准答案

**(1) 算法思想**

把 $A[0..n-1]$ 分成前段 $X=A[0..n-k-1]$（$n-k$ 个）与后段 $Y=A[n-k..n-1]$（$k$ 个），循环右移 $k$ 位即 $XY\to YX$。由逆置的性质 $YX=(X^rY^r)^r$，只需三步：逆置前 $n-k$ 个元素、逆置后 $k$ 个元素、逆置全部 $n$ 个元素。每步逆置用首尾对称交换实现，只借用一个元素大小的临时变量，三段合计交换不超过 $n$ 次，故移动次数为 $O(n)$。先令 $k=k\bmod n$，$k=0$ 或 $n\le1$ 时直接返回。

**(2) 算法描述**

```c
void Reverse(ElemType A[], int left, int right)   /* 逆置 A[left..right] */
{
    ElemType temp;                                 /* 一个元素大小的附加存储 */
    while (left < right) {
        temp = A[left]; A[left] = A[right]; A[right] = temp;
        left++; right--;
    }
}

void RotateRight(ElemType A[], int n, int k)       /* 循环右移 k 位 */
{
    if (n <= 1) return;                            /* 空表/单元素 */
    k %= n;                                        /* k>=n 归一，防下标越界 */
    if (k == 0) return;                            /* 不移 */
    Reverse(A, 0, n - k - 1);                      /* X^r Y   */
    Reverse(A, n - k, n - 1);                      /* X^r Y^r */
    Reverse(A, 0, n - 1);                          /* Y  X    */
}
```

**(3) 复杂度分析**

交换次数 $\lfloor(n-k)/2\rfloor+\lfloor k/2\rfloor+\lfloor n/2\rfloor\le n$，赋值次数 $\le 3n$，故时间 $O(n)$；附加存储为一个临时元素与常数个下标变量，空间 $O(1)$，两项均满足题目要求。

**(4) 举例**（$n=7,k=3$）：$(1,2,3,4\,|\,5,6,7)\to(4,3,2,1\,|\,5,6,7)\to(4,3,2,1\,|\,7,6,5)\to(\mathbf{5,6,7}\,|\,\mathbf{1,2,3,4})$。

## 9. 易错点

1. **忘记先做 $k \bmod n$**：$k\ge n$ 时 $n-k$ 为负，`Reverse(A, n-k, n-1)` 的区间立刻越界（或成为空区间而"看起来没错"，实则结果错）；$k=n$ 时应不移，取余后 $k=0$ 自然返回；
2. **三步逆置的区间端点写错**：第 1 步是 $[0,\,n-k-1]$（共 $n-k$ 个）、第 2 步是 $[n-k,\,n-1]$（共 $k$ 个）。若第 1 步写成 $[0,n-k]$，两段重叠一个元素，结果错；
3. **顺序颠倒**：先整体逆置、再逆置两段，得到的是 $X^rY^r$（不是 $YX$）——那是**左移** $k$ 位的结果。三步的次序不可交换；
4. **误用"整体右移一位"重复 $k$ 次**：满足附加存储约束但移动 $nk$ 次，$O(nk)$ 不满足 $O(n)$，属最常见的失分写法（若写成这样，必须改法或说明 $k$ 为常数）；
5. 与**循环左移**混淆：左移 $k$ 位是 $YX\to XY$（$|Y|=k$ 在前），三步次序为"逆置前 $k$、逆置后 $n-k$、逆置全体"；右移 $k$ 位等价于左移 $n-k$ 位，可据此互查；
6. 环法的写入顺序：必须 `t=A[next]; A[next]=temp; temp=t;`（先取出再覆盖）。若写成 `A[next]=temp; temp=A[next];`，则 `temp` 被自己刚写入的值覆盖，整环变成同一个数；
7. 环法忘记 $\gcd$：只对 $s=0$ 一个环处理就结束，当 $\gcd(n,k)>1$ 时其余环完全没动（本例 $n=8,k=2$ 就有两个环）；
8. 声称"空间 $O(1)$"却不说明 `temp` 只有一个元素：本题的空间约束是**一个元素大小**，若递归实现逆置会额外产生 $O(\log n)$ 栈，属违规——故必须写非递归的双指针交换。

## 10. 一句话规律

"原地 $O(n)$ $+$ 只许一个附加元素"的顺序表重排题，条件反射想两把刀——**分段逆置（$(X^rY^r)^r=YX$）**与**置换环接力（$\gcd$ 个环）**；写之前先把题意翻成下标等式 $A_{new}[(i+k)\bmod n]=A_{old}[i]$，写完立刻用 $n=7,k=3$ 这类小例子逐项核对，边界一律先 $k\%=n$。
