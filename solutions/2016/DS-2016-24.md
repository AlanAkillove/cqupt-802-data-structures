# DS-2016-24

## 1. 原题

不论是顺序存储结构的栈还是链式存储结构的栈，其入栈和出栈操作的时间复杂度均为\_\_\_\_\_\_\_\_\_\_\_\_ （要求填写大 $O$ 表示的时间复杂度）。

## 2. 答案

**$O(1)$**（常数时间）。

即：顺序栈的 `Push`/`Pop` 是 $O(1)$，链栈的 `Push`/`Pop` 也是 $O(1)$，取栈顶 `GetTop` 同样是 $O(1)$。

## 3. 题目分析

- 已知：栈的两种存储结构——顺序栈（一组连续地址 + 栈顶下标 `top`）与链栈（结点 + 指针，以表头为栈顶）；操作只有入栈、出栈两种；
- 目标：给出两者的共同时间复杂度，并须以大 $O$ 形式书写（题干已明确要求，故不能只答"常数时间"）；
- 关键约束（为什么是常数）：栈只允许在**栈顶**这一端插入与删除，两种实现都能**直接定位到栈顶**——顺序栈靠下标 `top`，链栈靠头指针 `*S`，因此都不需要遍历、也不需要移动任何元素，基本操作次数与栈中元素个数 $n$ 无关；
- 隐含对照（题目说"不论……还是……"的用意）：同一"只在端点操作"的思想在别的结构上并不总成立——顺序表中部插入删除要移动约 $\frac{n-1}{2}$ 个元素，链表中部删除要先 $O(n)$ 找前驱；而**栈恰好把操作限制在能 $O(1)$ 定位的那一端**，这才是本题答案成立的根本原因；
- 命题意图：与队列对照记忆（循环队列入队出队亦为 $O(1)$，但"非循环"的顺序队列出队后可能要整体前移 $O(n)$），让考生明白"复杂度取决于操作端在结构中的定位方式"，而不是取决于"顺序存储还是链式存储"这一标签本身。

## 4. 核心考点

核心考点：
DS02.02 栈和队列的顺序存储结构（顺序栈 `elem[]` + `top`，入栈出栈只改一个下标并做一次赋值；栈满栈空判定本身也是 $O(1)$）

辅助考点：
DS02.03 栈和队列的链式存储结构（链栈以头指针即栈顶指针，头插法入栈、头删法出栈，均无需寻找前驱）
DS02.01 栈和队列的基本概念（"限定仅在表尾/栈顶进行插入和删除"这一操作性定义，是两端都能 $O(1)$ 定位的前提）
DS00.02 算法与算法分析（语句频度与时间复杂度的记法；大 $O$ 书写规范：常数时间记 $O(1)$，不写 $O(n^0)$、不写 $O(0)$）

解释：题目同时点名两种存储结构，主节点取题干先提到的顺序栈（DS02.02），链栈（DS02.03）为并列一半；两者的共同依据是栈的端点限定（DS02.01），书写形式由复杂度记号规范（DS00.02）决定。

## 5. 解题思路

1. 先回忆栈的定义：插入（push）与删除（pop）都只发生在栈顶 ⟹ 只需回答"栈顶能不能 $O(1)$ 定位"；
2. 顺序栈：`top` 就是栈顶下标，入栈 `elem[++top]=e`、出栈 `e=elem[top--]`，各是一条赋值 + 一条自增/自减 ⟹ 与 $n$ 无关 ⟹ $O(1)$；
3. 链栈：把表头当栈顶，入栈是头插（改 `p->next` 与头指针两个值）、出栈是头删（改头指针并释放）⟹ 与 $n$ 无关 ⟹ $O(1)$；若把表尾当栈顶则需 $O(n)$ 找前驱，故链栈**必须**用表头作栈顶——这是"链栈不带头结点/以头指针为栈顶"约定存在的理由；
4. 取两者交集并按题干"不论是……还是……"填 $O(1)$；
5. 反向自查：与顺序表、一般链表的插入删除复杂度对照，确认题目要的不是 $O(n)$；再确认书写为大 $O$ 形式（题干要求）。

## 6. 详细解答

**（1）顺序栈：两条语句完成一次操作**

```c
Status Push(SqStack *S, SElemType e)
{
    if (S->top >= S->stacksize - 1) return ERROR;   /* 栈满，常数时间判定 */
    S->elem[++(S->top)] = e;                        /* 先移栈顶指针，再存元素 */
    return OK;
}

Status Pop(SqStack *S, SElemType *e)
{
    if (S->top == -1) return ERROR;                 /* 栈空 */
    *e = S->elem[(S->top)--];                       /* 先取元素，再移栈顶指针 */
    return OK;
}
```

基本操作计数：入栈 = 一次自增 + 一次下标寻址 + 一次赋值 + 一次比较；出栈同量级。次数固定，与 $n$ 无关 ⟹ $T(n)=O(1)$。

> 说明：若顺序栈用 `realloc` 动态扩容，则某一次入栈可能要复制 $n$ 个元素，但 $n$ 次入栈的总复制代价为 $O(n)$，**均摊**仍是 $O(1)$，不改变本题答案。

**（2）链栈：头插与头删**

```c
Status PushStack(LinkStack *S, SElemType e)   /* S 为栈顶指针（即头指针），以表头为栈顶 */
{
    LinkStackPtr p = (LinkStackPtr)malloc(sizeof(StackNode));
    if (!p) return ERROR;
    p->data = e;
    p->next = *S;      /* 新结点指向原栈顶 */
    *S = p;            /* 栈顶指针下移到新结点 */
    return OK;
}

Status PopStack(LinkStack *S, SElemType *e)
{
    LinkStackPtr p = *S;
    if (!p) return ERROR;         /* 栈空 */
    *e = p->data;
    *S = p->next;                 /* 头删：栈顶指针指向次结点，无需找前驱 */
    free(p);
    return OK;
}
```

入栈改 2 个指针值 + 1 次 `malloc`，出栈改 1 个指针值 + 1 次 `free`，均与 $n$ 无关 ⟹ $O(1)$。

关键对比：**栈的删除不需要"找前驱"**。在一般单链表中删除第 $i$ 个结点要先从头走 $i-1$ 步（$O(n)$）；而链栈的栈顶正是头指针所指结点，删除它只需把头指针换成 `p->next`，省掉了遍历。反过来，若坚持"以表尾为栈顶"，每次入栈虽 $O(1)$（若有尾指针）而出栈却因取不到前驱退化为 $O(n)$——这正是"链栈以表头为栈顶"这一约定必须掌握的考点。

**（3）两种实现合流**

| 结构 | 定位栈顶的方式 | 入栈 | 出栈 | 复杂度 |
|---|---|---|---|---|
| 顺序栈 | 下标 `top` | `elem[++top]=e` | `e=elem[top--]` | $O(1)$ |
| 链栈 | 头指针 `*S` | 头插 | 头删 | $O(1)$ |

故"不论是顺序存储还是链式存储，入栈和出栈的时间复杂度均为 $O(1)$"。

**（4）与相邻结构的对照（说明"为什么只有栈两头都便宜"）**

| 结构／操作 | 插入 | 删除 | 说明 |
|---|---|---|---|
| 栈（顺序或链式） | $O(1)$ | $O(1)$ | 只在栈顶，且栈顶可直接定位 |
| 循环队列 | $O(1)$ | $O(1)$ | 只在两端，靠取模回绕（对照本卷 DS-2016-09） |
| 普通（非循环）顺序队列 | $O(1)$ | 可能 $O(n)$ | "队头元素后方空出过多时整体前移"，循环队列即为消除它而生 |
| 顺序表中部插入/删除 | $O(n)$ | $O(n)$ | 平均移动约 $\frac{n-1}{2}$ 个元素（对照本卷 DS-2016-07） |
| 单链表中部删除 | $O(1)$ 改链 | $O(n)$ | 改链是常数，但**找前驱**是线性（对照本卷 DS-2016-22 的后继覆盖法） |

结论：$O(1)$ 来自"**操作端恰好是可常数定位的那一端**"，与"顺序/链式"标签无关；栈两种实现都满足，故答案唯一。

**答案**：$O(1)$。

## 8. 考场标准答案

填 **$O(1)$**。

理由（可书写版）：栈的插入与删除都限定在栈顶。顺序栈凭下标 `top` 直接定位栈顶，入栈 `elem[++top]=e`、出栈 `e=elem[top--]`，各为一次自增（减）加一次赋值；链栈以表头作栈顶，入栈为头插、出栈为头删，只改动常数个指针且无需查找前驱。两者操作次数均与栈中元素个数 $n$ 无关，故时间复杂度都是 $O(1)$。

## 9. 易错点

1. 误填 $O(n)$：把"顺序表插入删除要移动元素"的经验套到顺序栈上。栈顶元素之后没有元素，**不需要移动任何元素**；
2. 只答"常数时间/常量级"而不写大 $O$：题干明确要求"填写大 $O$ 表示的时间复杂度"，须写 $O(1)$（也不接受 $O(n^0)$、$O(0)$ 之类写法）；
3. 忽略链栈的方向约定：若把链栈的栈顶设在**表尾**，出栈取不到前驱会退化为 $O(n)$，结论就不成立。答"链栈 $O(1)$"的前提是以表头为栈顶；
4. 与队列混淆：链队的出队 $O(1)$、循环队列两端 $O(1)$，但**非循环的顺序队列**出队后可能整体前移 $O(n)$（对照本卷 DS-2016-09）。"栈两端都便宜、队列要看是否循环"是常见的对比考点；
5. 漏看"入栈**和**出栈"：题问四个操作统一复杂度，个别考生只算入栈（顺序栈若采用"栈满即搬移"的错误实现会得出 $O(n)$）；
6. 把空间复杂度当答案：顺序栈空间 $O(MAXSIZE)$、链栈空间 $O(n)$，两者**并不相同**，本题问的是时间复杂度。

## 10. 一句话规律

判断受限结构（栈、队列、双端队列）操作的复杂度，只需问一句：**"操作发生的那一端，能否在不遍历、不移动元素的情况下直接定位？"** 能，则 $O(1)$；顺序实现靠下标/指针常驻，链式实现把头指针放在操作端，两种存储天然同阶。
