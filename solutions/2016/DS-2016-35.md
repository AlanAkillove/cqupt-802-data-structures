# DS-2016-35

## 1. 原题

在插入和选择排序中，若初始数据基本有序，则选用____________________ 排序。

## 2. 答案

**直接插入排序**（填"插入排序"亦可）。

## 3. 题目分析

- 已知：待排序列**初始基本有序**（多数元素已在最终位置附近，只有少量"逆序对"）；
- 目标：在题目给定的两个候选——**插入排序**与**选择排序**——中选出此时更合适的一种；
- 关键约束：候选集被"在插入和选择排序中"限死，不能答冒泡、希尔、快排（尽管冒泡在基本有序时也能提前结束，希尔受益于"预有序"，但它们不在候选集内）；
- 命题意图：考"比较次数是否依赖初态"这一分类标准。插入类的比较次数随有序程度**单调下降**（最好 $O(n)$），选择类的比较次数**与初态无关**（恒 $O(n^2)$）。故"基本有序"这一条件只能被插入排序兑现，对选择排序毫无价值；
- 表面问题背后的数据结构问题：算法效率对**输入分布**的敏感性——同一判据在本卷 DS-2016-18（快排在"完全无序"时最易发挥长处，"基本有序"反而退化）中方向相反，两题合起来即"算法—数据分布"配对表。

## 4. 核心考点

核心考点：
DS06.02.01 直接插入排序（每趟把 $R[i]$ 插入有序子表、比较/移动次数依赖初态、最好 $O(n)$、稳定、原地）

解释：答案成立的唯一依据就是直插的比较与移动次数随初态变化这一性质，属该节点的核心结论。

辅助考点：
DS06.04 简单选择排序（第 $i$ 趟须在无序区 $R[i\cdots n]$ 中扫描到底选最小，比较次数恒为 $n-i$，总量 $\dfrac{n(n-1)}{2}$，与初态无关）

解释：填空题考两者择一，必须把选择排序"与初态无关"的性质摆出来，比较才有落点；单讲插入排序快不足以说明"为什么不是选择"。

DS06.01 排序的基本概念（"趟"的含义、算法的时间开销按比较次数与移动次数分项统计）

解释：本题判据正是"比较次数是否随初态变化"，需要先明确按趟统计的口径。

## 5. 解题思路

1. 把"基本有序"量化：用**逆序对个数** $I$ 表示序列与有序序列的偏离程度。基本有序 ⟺ $I$ 远小于最坏值 $\dfrac{n(n-1)}{2}$，通常取 $I=O(n)$；
2. 分别写出两种排序的比较次数表达式（这是它们唯一的本质差别）：
   - 直接插入排序：第 $i$ 趟从后往前在 $R[1\cdots i-1]$ 中找插入位置，每遇到一个比 $R[i]$ 大的元素就多比较一次，故总比较 $=(n-1)+I$；移动次数 $=I+(n-1)$（每消除一个逆序对伴随一次后移）；
   - 简单选择排序：第 $i$ 趟必须把 $R[i+1\cdots n]$ 全部看完才敢确定最小者，比较 $n-i$ 次，总比较 $=\sum_{i=1}^{n-1}(n-i)=\dfrac{n(n-1)}{2}$，**$I$ 不出现在式子里**；
3. 代入条件 $I=O(n)$：直插降到 $O(n)$，选择仍是 $O(n^2)$ ⟹ 选插入；
4. 用极小数值的例子自检（完全有序、仅一处颠倒两种情形手算趟内比较次数）；
5. 反向确认：若初态完全无序/逆序，$I=\Theta(n^2)$，直插回到 $O(n^2)$ 而与选择同阶，此时"基本有序"这个前提就不成立——说明本题的答案确实由该前提给出，不是无条件偏好插入排序。

## 6. 详细解答

**（1）两种排序的代价表达式（长度为 $n$，逆序对数为 $I$）**

| 排序方法 | 比较次数 | 移动次数 | 是否随初态变化 | 最坏/最好 | 空间 | 稳定 |
|---|---|---|---|---|---|---|
| 直接插入排序 | $(n-1)+I$ | 后移 $I$ 次（另有每趟哨兵赋值＋回填 $2(n-1)$ 次） | **是**，$I$ 越小越省 | 最好 $n-1$（$I=0$）；最坏 $\dfrac{n(n-1)}{2}+n-1$ | $O(1)$ | 稳定 |
| 简单选择排序 | $\dfrac{n(n-1)}{2}$（恒定） | $\le 3(n-1)$ | **否** | 最好 $=$ 最坏 $=$ $\dfrac{n(n-1)}{2}$ | $O(1)$ | 不稳定 |

**（2）直接插入排序为什么"越有序越快"**

第 $i$ 趟（$2\le i\le n$）把 $R[i]$ 与 $R[i-1],R[i-2],\cdots$ 依次比较，直到遇到不大于它的元素就停下插入。设 $R[i]$ 在有序子表 $R[1\cdots i-1]$ 中需要越过的元素个数为 $c_i$（恰是以 $R[i]$ 为较大者的逆序对数），则该趟比较 $c_i+1$ 次（多出的那 1 次是“发现不大于它／碰到哨兵”的终止判定），元素后移 $c_i$ 次。于是

$$C_{\text{比}}=\sum_{i=2}^{n}(c_i+1)=(n-1)+\underbrace{\sum_{i=2}^{n}c_i}_{=\,I}=(n-1)+I$$

基本有序 ⟹ 每个 $c_i$ 都很小、$I=O(n)$ ⟹ $C_{\text{比}}=O(n)$，时间复杂度降为**线性**。极端情形 $I=0$（已经有序）只需 $n-1$ 次比较、元素一次也不后移。

**（3）简单选择排序为什么"有序也省不下来"**

第 $i$ 趟要在无序区 $R[i\cdots n]$ 中选出最小者，算法必须把该区的 $n-i$ 个关键字逐一与当前最小值比较完毕后才能确定归属：

$$C_{\text{比}}=\sum_{i=1}^{n-1}(n-i)=\dfrac{n(n-1)}{2}$$

表达式里没有 $I$，说明"基本有序"省不下**任何一次**比较。它的优点只在移动次数少（每趟至多 3 次记录移动，合计 $\le 3(n-1)$），因而适合"记录大而关键字小、移动代价高"的场景，与有序性无关。

**（4）数值对照（$n=100$，$I=100$，即平均每个元素只错位一个位置）**

- 直接插入排序：比较 $(100-1)+100=199$ 次，元素后移 $I=100$ 次；
- 简单选择排序：比较 $\dfrac{100\times 99}{2}=4950$ 次。

两者相差约 $25$ 倍，且 $n$ 越大差距越悬殊（$O(n)$ 对 $O(n^2)$）。

**（5）小规模手算自检**

取基本有序列 $R=(2,1,3,4,5)$（$n=5$，逆序对仅 $(2,1)$ 一个，即 $I=1$），按第 8 节算法逐趟执行：

| 趟 $i$ | 待插元素 | 比较过程 | 本趟比较次数 | 本趟后移 | 趟后序列 |
|---|---|---|---|---|---|
| 2 | $1$ | $1<2$ 真（后移 $2$），再与哨兵 $R[0]=1$ 比，假 ⟹ 停 | 2 | 1 | $1,2,3,4,5$ |
| 3 | $3$ | $3<2$? 假 ⟹ 停 | 1 | 0 | $1,2,3,4,5$ |
| 4 | $4$ | $4<3$? 假 ⟹ 停 | 1 | 0 | $1,2,3,4,5$ |
| 5 | $5$ | $5<4$? 假 ⟹ 停 | 1 | 0 | $1,2,3,4,5$ |
| 合计 | | | $5=(n-1)+I=4+1$ ✓ | $1=I$ ✓ | |

简单选择排序在同一序列上：第 1 趟在 $R[1\cdots5]$ 中比 $4$ 次、第 2 趟 $3$ 次、第 3 趟 $2$ 次、第 4 趟 $1$ 次，共 $10=\dfrac{5\times4}{2}$ 次，与 $I=1$ 无关。

$5$ 对 $10$（且 $n$ 越大差距越悬殊），与第（4）步结论同向 ✓；代入 $I=0$（如 $R=(1,2,3,4,5)$）直插恰得 $n-1=4$ 次比较，公式自检通过 ✓。

**（6）结论**

初始数据基本有序时，插入排序能把"有序"直接兑换成 $O(n)$ 的开销，选择排序不能 ⟹ 应选**直接插入排序**。

**答案**：直接插入排序（填"插入"）。

## 8. 考场标准答案

填 **直接插入**（插入）。

理由两句即可：

- 直接插入排序的比较次数为 $(n-1)+I$（$I$ 为逆序对数），基本有序时 $I=O(n)$，总代价降到 $O(n)$；
- 简单选择排序的比较次数恒为 $\dfrac{n(n-1)}{2}=O(n^2)$，与初始有序性无关，"基本有序"省不下一次比较。

对照算法（教材风格 C，两相对照更清楚）：

```c
/* 直接插入排序：R[1..n]，R[0] 作哨兵 */
void InsertSort(int R[], int n) {
    int i, j;
    for (i = 2; i <= n; i++) {
        R[0] = R[i];                      /* 哨兵，免每趟查越界 */
        j = i - 1;
        while (R[0].key < R[j].key) {     /* 基本有序时循环几乎不执行 */
            R[j + 1] = R[j];              /* 记录后移 */
            j--;
        }
        R[j + 1] = R[0];                  /* 插入 */
    }
}   /* 最好 O(n)，最坏 O(n^2)，空间 O(1)，稳定 */

/* 简单选择排序：每趟必须扫描完无序区，比较次数与初态无关 */
void SelectSort(int R[], int n) {
    int i, j, k;
    for (i = 1; i < n; i++) {
        k = i;
        for (j = i + 1; j <= n; j++)      /* 恒比较 n-i 次 */
            if (R[j].key < R[k].key) k = j;
        if (k != i) { Swap(R[i], R[k]); }
    }
}   /* 任何情形比较 n(n-1)/2 次 = O(n^2)，空间 O(1)，不稳定 */
```

## 9. 易错点

1. **答成"选择排序"**：把"选择排序移动次数少（$\le 3(n-1)$）"错记成"选择排序总比较次数少"。移动少不等于比较少，本题的耗时瓶颈是比较，且"基本有序"只对插入有效；
2. **答出候选集之外的算法**：填"冒泡排序""希尔排序"虽在基本有序时也有优势（冒泡可因本趟无交换而提前结束），但题目限定"在插入和选择排序中"，不在候选集内不得分；
3. **与快排的结论串味**：本卷 DS-2016-18 问"快排在何种数据下最易发挥长处"，答案是"完全无序"，"基本有序"恰是快排（取端点为枢轴时）的最坏情形 $O(n^2)$。"越有序越快"只适用于插入/冒泡类，不可推广为"所有排序都喜欢有序"；
4. **忽略"稳定"这一维度**：插入排序稳定、简单选择排序不稳定，这是插入排序的另一处优点，但本题判据是"基本有序"下的耗时，答题时不要用稳定性替代比较次数分析（否则会被判答非所问）；
5. 记不清直插的比较次数式子：正确记法是"每趟至少比较 1 次（发现前一个元素不大于它）＋每消除一个逆序对多比一次"，即 $(n-1)+I$；代入 $I=0$ 必须得 $n-1$，可用作公式自检。

## 10. 一句话规律

按初态选排序只看一句话：**比较次数里有没有“逆序对数 $I$”这一项**。插入类有（$C=(n-1)+I$，越有序越快，基本有序即 $O(n)$），选择类与堆排序没有（恒 $O(n^2)$、恒 $\Theta(n\log n)$），快排则有反向项（越有序越慢）——给“基本有序/局部有序”选直接插入，给“完全无序且要平均快”选快排，给“最坏也有保证且空间紧张”选堆排序。
