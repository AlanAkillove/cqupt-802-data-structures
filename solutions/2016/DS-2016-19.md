# DS-2016-19

## 1. 原题

非空的单循环链表的头指针为 $head$ ，尾指针为 $rear$ ，则下列条件成立的是（）。

A. $rear->next->next==head$

B. $rear->next==head$

C. $head->next==rear$

D. $head->next->next==rear$

## 2. 答案

**B**（$rear->next==head$）。单循环链表的定义性特征就是**终端结点的指针域回指表头**，故尾结点的 `next` 恰为 $head$。

## 3. 题目分析

- 已知：一个**非空**的**单循环**链表，同时给出头指针 $head$ 与尾指针 $rear$；
- 目标：在四个指针等式中挑出**恒成立**的那一个（"条件成立"应理解为"对任意满足题设的链表都成立"，而不是"可能存在某种链表使它成立"）；
- 关键约束：题设只给了"非空、单循环、有头指针与尾指针"，**没有给表长**，也没有说明是否带头结点 ⟹ 正确选项必须在任何表长、两种头结点约定下都成立；
- 命题意图：考循环链表的定义（尾指回头）与"头指针／尾指针分别指向什么"这两个约定，同时用 C、D 两个"只在特定表长成立"的等式检验考生是否会拿一个特例去验证全称命题。

## 4. 核心考点

核心考点：
DS01.02.03 链式存储：双向链表与循环链表（循环链表的定义：终端结点 `next` 指向头结点/首元结点；头指针与尾指针的语义）

辅助考点：
DS01.02.02 链式存储：单链表（`head->next`、`rear->next` 等指针链的含义，以及带头结点与不带头结点两种约定下空表、单结点表的形态）

解释：判断四个等式要靠"沿指针链一步步走"的基本功（DS01.02.02），而结论本身是循环链表的定义（DS01.02.03），故以后者为主节点。

## 5. 解题思路

1. 先固定语义：$head$ 是**头指针**（其值即表的入口地址），$rear$ 是**尾指针**（指向最后一个数据结点，即"终端结点"）；
2. 写定义：单循环链表 ⟹ 终端结点的next 不是 `NULL` 而是回指表的入口 ⟹ $rear->next==head$，直接命中 B；
3. 检查该结论对"带头结点"约定是否也成立：带头结点时 $head$ 指向头结点，循环链表的 `next` 回指的正是这个头结点，故仍是 $rear->next==head$ ✓ 两种约定同真，说明 B 不依赖约定，是稳健选项；
4. 排除 A、C、D：把它们改写成"表长满足什么方程"，看是否恒成立——
   - A：$rear->next==head$ 代入得 $head->next==head$，即头结点的next 指回自己，这是**空表**（带头结点）的特征，与"非空"矛盾；
   - C：$head->next==rear$ 表示入口结点的后继就是尾结点 ⟹ 表只有 $1$ 个数据结点（不带头结点）或 $1$ 个结点（带头结点），非一般情形；
   - D：$head->next->next==rear$ 表示表有 $2$ 个数据结点（不带头结点时），同样只是特例；
5. 用表长 $n=1,2,3$ 逐个代入验证（第 6 节表），确认只有 B 全表长成立。

## 6. 详细解答

**（1）两种约定下的结点链**

- **不带头结点**（$head$ 指向首元结点）：$head\to a_1\to a_2\to\cdots\to a_n=rear\xrightarrow{\;next\;}head$；
- **带头结点**（$head$ 指向头结点 $H$，$H->next$ 是首元结点）：$head\to H\to a_1\to\cdots\to a_n=rear\xrightarrow{\;next\;}H=head$。

两种情形都有 $rear->next==head$（循环链表的"循环点"就是尾结点的next 域回指表入口），故 **B 恒成立**。

**（2）全称检验：按表长代入**

记 $n$ 为数据结点个数（题设 $n\ge 1$），下表按"不带头结点"约定逐项判定（带头结点结论相同，见（3））：

| 表长 $n$ | 链表形态 | A. $rear->next->next==head$ | B. $rear->next==head$ | C. $head->next==rear$ | D. $head->next->next==rear$ |
|---|---|---|---|---|---|
| $1$ | $a_1\circlearrowleft$（$head=rear=a_1$） | $a_1->next->next=a_1=head$ ✓ | ✓ | $head->next=a_1=rear$ ✓ | $head->next->next=a_1=rear$ ✓ |
| $2$ | $a_1\to a_2\circlearrowleft$ | $rear->next->next=a_1->next=a_2\neq head$ ✗ | ✓ | $head->next=a_1\neq a_2=rear$ ✗ | $head->next->next=a_2=rear$ ✓ |
| $3$ | $a_1\to a_2\to a_3\circlearrowleft$ | ✗（$rear->next->next=a_1->next=a_2\neq head$） | ✓ | ✗（$head->next=a_2\neq a_3$） | ✓（$head->next->next=a_3=rear$） |

注：$n=3$ 时 D 也成立（从 $a_1$ 走两步恰为 $a_3$），$n=1$ 时四个选项全部成立——这正说明**逐例验证不能证明全称命题**，必须回到代数形式：不带头结点时 $head=a_1$、$rear=a_n$，而 $a_i->next=a_{i+1}$（$a_n->next=a_1$），于是

$$head->next->next=a_3\quad(\text{下标按模 }n\text{ 回绕}),\qquad rear=a_n$$

$D$ 成立 $\iff a_3=a_n$ $\iff n\in\{1,2,3\}$；同理 $C$（$a_2=a_n$）成立 $\iff n\in\{1,2\}$。题设只保证 $n\ge1$，故 $n\ge 4$ 时 C、D 均不成立；A 则对一切 $n\ge 2$ 不成立。**只有 B 与 $n$ 无关**。

**（3）带头结点约定下复核 B 与 A**

$head=H$，$H->next=a_1$，$a_n->next=H$：

- B：$rear->next=a_n->next=H=head$ ✓ 仍成立；
- A：$rear->next->next=H->next=a_1$，要它等于 $head=H$ 需 $a_1=H$，即表为空 ⟹ 与"非空"矛盾 ✗；
- C：$head->next=a_1=rear$ ⟺ $n=1$ ✗（特例）；
- D：$head->next->next=a_2=rear$ ⟺ $n=2$ ✗（特例）。

两种约定结论一致：**B 恒成立，A 恒不成立，C、D 只在特定表长成立**。

**（4）补充：为什么"给尾指针"是循环链表常见设计**

单循环链表若只给头指针，访问尾结点需 $O(n)$；同时保存 $rear$ 后，$rear->next$ 即 $head$，从而"表头插入""表尾插入"都能在 $O(1)$ 内完成（尾插：`s->next=rear->next; rear->next=s; rear=s;`）。这也解释了本题为何把 $head$ 与 $rear$ 同时给出——两指针通过 $rear->next==head$ 这一恒等式互相换算。

**答案**：B。

## 7. 选项分析

- A. $rear->next->next==head$：**错**。由定义 $rear->next==head$，故该式等价于 $head->next==head$，即表入口结点的next 指回自己——这是**空表（带头结点）**的特征，与题设"非空"直接矛盾；
- B. $rear->next==head$：**正确**。单循环链表的定义式：终端结点的指针域存放头指针的值，使整个链表首尾相接；
- C. $head->next==rear$：**错**。它表示"入口结点的后继就是尾结点"，只在表长为 $1$（不带头结点时另含 $n=2$ 的退化）成立，不是恒真条件；把它当正确答案属于"用一个结点的特例验证全称命题"；
- D. $head->next->next==rear$：**错**。它表示"从入口走两步到尾结点"，只在特定表长（$n=2$ 或 $n=3$，视约定而定）成立，同样不是恒真条件。

## 8. 考场标准答案

选 **B**。

单循环链表的定义即"终端结点的next 域指向头指针所指的结点"，故 $rear->next==head$ 恒成立（带头结点时回指头结点，$head$ 正是头结点地址，结论不变）。
A 等价于 $head->next==head$，只在空表时成立，与"非空"矛盾；C、D 分别只在表长为 $1\sim2$、$2\sim3$ 的特例下成立，不具一般性。

## 9. 易错点

1. **把"头指针"与"头结点"混为一谈**：$head$ 是指针变量（存放表入口地址），是否另有头结点取决于约定；本题结论对两种约定都成立，但判断 A、C、D 时必须先声明自己用哪种约定，否则表长统计会错位；
2. 用特例验证全称命题（误选 C/D）：画一个结点的表就断言 C 对——正确做法是把等式改写成"关于 $n$ 的方程"，看是否对所有 $n\ge1$ 成立；
3. 与**循环双链表**的判空条件混淆：带头结点的双向循环链表判空是 $head->next==head$（且 $head->prior==head$），而本题 A 选项正是该式的“单链表改写”，它在非空时不成立；
4. 忘记"非空"这一前提：若允许空表，带头结点时 A 也会成立，题目就失去唯一答案——题设的"非空"正是为排除 A。

## 10. 一句话规律

链表指针等式题的通用解法：**先用定义把 `next` 链按结点序号写出来（$a_i->next=a_{i+1}$，尾结点回指表入口），再把选项等式翻译成"下标方程"**，看它是否对所有合法表长成立——恒成立的才是答案，只在某个表长成立的是干扰项。
