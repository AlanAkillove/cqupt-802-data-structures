# DS-2016-22

## 1. 原题

设指针变量 $p$ 指向单链表中结点 $A$ ，则删除结点 $A$ 的语句序列为： $q=p->next;$ $p->data=q->data;$ $p->next=$ \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_ ;

$free(q)$ 。

## 2. 答案

空格处填 **`q->next`**（完整语句为 `p->next = q->next;`）。

即删除结点的语句序列为：

```c
q = p->next;          /* q 指向 A 的后继结点 B */
p->data = q->data;    /* 把 B 的数据拷贝到 A 所在结点 */
p->next = q->next;    /* A 所在结点越过 B，直接链到 B 的后继 C */
free(q);              /* 释放 B 所占的结点空间 */
```

## 3. 题目分析

- 已知：单链表，指针 $p$ **指向待删除结点 $A$ 本身**（不是前驱）；已给出三条语句，只缺第三条右值；末句为 `free(q)`，说明真正被释放的物理结点是 $q$ 所指的那个结点；
- 目标：补出让链表保持连续、且不泄漏不悬空的指针表达式；
- 关键约束一（单链表只能向后走）：只给 $p$ 而无前驱指针时，无法回头修改前驱的 `next`，因此本写法改走"用后继的内容覆盖 $A$，再删掉后继"这条路——这是全套语句的立意，也是理解空格的钥匙；
- 关键约束二（`free(q)` 已固定）：既然被释放的是 $q$（即 $A$ 的原后继 $B$），那么在释放之前，$B$ 的原后继 $C$ 必须已经被某个仍然存活的指针接住，否则 $C$ 及其后所有结点全部丢失。此时唯一存活的前驱就是 $p$，故必须由 `p->next` 去接 $C$；而 $C$ 正是 `q->next`；
- 命题意图：考"在只持有待删结点指针时的 $O(1)$ 删除技巧"（后继覆盖法），并检验考生是否理解"删除的实质是改链 + 释放"这两步的先后次序，而不是机械背诵 `p->next = p->next->next`。

## 4. 核心考点

核心考点：
DS01.02.02 链式存储：单链表（结点的 `data`/`next` 两域、删除操作必须"先接链后释放"、单链表只能由前向后访问因而不持有前驱指针）

辅助考点：
DS01.02.01 顺序存储（顺序表：插入/删除/查找与移动次数）——对照用：顺序表删除要移动 $\frac{n-1}{2}$ 量级的元素，链表删除只改一个指针，这正是本题能在 $O(1)$ 内完成的前提

解释：题目本身是让填单链表的指针表达式（DS01.02.02），填错即断链；与顺序表删除的代价对照有助于确认"为什么这里可以不动前驱"，故列为辅助。

## 5. 解题思路

1. 画出四结点局部链：$\cdots \to pre \to A(p) \to B \to C \to \cdots$，并标注 $q=p->next$ 使 $q$ 指向 $B$；
2. 看第二条 `p->data = q->data;`：把 $B$ 的数据搬到 $A$ 所在结点 ⟹ 逻辑上"$A$ 已被 $B$ 顶替"，链表里少的是 $B$；
3. 看末条 `free(q);`：要释放的是 $B$ ⟹ 释放前 $B$ 的后继 $C$ 必须已被接管；能接管它的只有 `p->next`（$pre$ 不可达）；
4. $C$ 在当时的表达式：$C$ 是 $B$ 的后继，即 `q->next`（注意此时 `q->next` 尚未被任何语句改动，仍是 $C$）⟹ 空格填 `q->next`；
5. 自检两条：① 若填 `p->next`（自身赋值）或 `NULL` 会怎样；② 若先 `free(q)` 再取 `q->next` 会怎样（悬空引用）。

## 6. 详细解答

**（1）逐语句追踪链形态**

设删除前局部链为（括号内为指针变量）

$$pre \longrightarrow A(p) \longrightarrow B(q) \longrightarrow C \longrightarrow \cdots$$

| 执行语句 | 执行后的效果 |
|---|---|
| `q = p->next;` | $q$ 指向 $A$ 的后继 $B$；链未变 |
| `p->data = q->data;` | $A$ 所在结点的内容变成 $B$ 的内容（数据域拷贝，链未变） |
| `p->next = q->next;` | $A$ 所在结点越过 $B$ 指向 $C$；此时 $B$ 已从链上脱离，$C$ 由 `p->next` 保住 |
| `free(q);` | 释放已脱离链的 $B$，无泄漏、无悬空 |

若第三条写成其他式子则出错：填 `p->next`（即 `p->next = p->next`）是空操作，随后 `free(q)` 释放仍在链上的 $B$ ⟹ $C$ 及其后全部丢失且 $p->next$ 成为悬空指针；填 `NULL` 则把 $B$ 之后的整段截断丢失。

**（2）等价的另一种写法**

由于执行第三条时 `p->next` 仍是 $B$，故 `q->next` 与 `p->next->next` 同值，空格填 `p->next->next` 在数值上也对。但按本语句序列的书写脉络（已引入辅助指针 $q$，且下句即 `free(q)`），标准答案是 **`q->next`**：它明确表达"把 $q$ 的后继接管过来，然后释放 $q$"，可读性与安全性都更好（若将来在中间插入修改 `p->next` 的语句，`p->next->next` 会立刻失效）。

**（3）实例核对（3 个结点）**

链表 $A_1 \to A_2 \to A_3$，$p$ 指向 $A_1$，欲删 $A_1$：

- `q = p->next` ⟹ $q$ 指 $A_2$；
- `p->data = q->data` ⟹ 头结点内容变为 $A_2$ 的；
- `p->next = q->next` ⟹ 头结点指向 $A_3$；
- `free(q)` ⟹ 释放原 $A_2$ 结点。
  结果链：$(A_2) \to A_3$，长度由 3 变 2，元素次序为原 $A_2,A_3$ ✓ 与"删除 $A_1$"的逻辑效果一致。

**（4）为什么这样做——与常规删除的对比**

常规的单链表删除要求持有**前驱**指针 $pre$：`q = pre->next; pre->next = q->next; free(q);`。本题只给指向待删结点的 $p$，单链表无法由 $p$ 回溯到 $pre$；若从头查找前驱需 $O(n)$。后继覆盖法把代价降为 $O(1)$，代价是三个副作用：

- **只能删除非尾结点**：$p$ 指向尾结点时 $q = p->next$ 为 `NULL`，`q->data`、`q->next` 均为空指针解引用（运行期崩溃）。尾结点必须另走"找前驱"的 $O(n)$ 路径，或使用双向链表（DS01.02.03，可由 $p->prior$ 直接拿到前驱）；
- **删除的是后继结点所占的物理位置**：若有外部指针正指向 $B$，它不会被更新，随后 `free(q)` 使其悬空；
- **`data` 是整体拷贝**：若结点存的是大结构或含指针的成员，`p->data = q->data` 的代价与浅拷贝风险要另计（严格说这已不是 $O(1)$ 的"指针操作"，但按数据结构课程约定仍记 $O(1)$）。

**（5）语句次序不可调换**

`p->next = q->next;` 必须在 `free(q);` **之前**。先释放再取 `q->next` 是典型的 use-after-free：`q->next` 读到的是已被归还的内存，链表从此断裂。同理 `p->data = q->data;` 也必须在 `free(q);` 之前。

**答案**：`q->next`（完整语句 `p->next = q->next;`）。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

填 `q->next`，即第三条语句为 `p->next = q->next;`。

一句话理由：`free(q)` 释放的是 $A$ 的后继结点 $B$，释放前必须让 $p$ 所在结点越过 $B$ 直接连到 $B$ 的后继，而 $B$ 的后继只能写成 `q->next`（单链表拿不到 $B$ 的前驱，$p$ 就是唯一可改的链入口）。整段实现的是"只持有待删结点指针时的 $O(1)$ 删除"——用后继内容覆盖待删结点，再物理删除后继。

## 9. 易错点

1. **填 `p->next`**（写成 `p->next = p->next;`）：等于没改链，`free(q)` 后 $B$ 之后整段丢失，$p->next$ 变悬空指针——这是最常见的错答；
2. 误以为此法真能删"尾结点"：$p$ 为尾结点时 `q` 为 `NULL`，程序崩溃。凡用后继覆盖法必须先判 `p->next != NULL`；
3. 次序颠倒：先 `free(q)` 再用 `q->next`（use-after-free）。同理不能在 `p->data = q->data` 之前释放 $q$；
4. 误填 `q->next->next`、`p->next->next->next` 之类（多走一步，把链接到 $C$ 之后，$C$ 丢失）；
5. 忽略"外部指向 $B$ 的指针会变悬空"：逻辑上删的是 $A$ 的内容、物理上删的是 $B$ 的结点，若题目另有迭代器/前驱指针指向 $B$，需另行处理；
6. 混淆本节点拷贝与顺序表删除：顺序表删除要前移 $n-i$ 个元素，链表只改一个指针（对照本卷 DS-2016-07（顺序表删除第 $i$ 个元素需移动 $n-i$ 次）、DS-2016-08（链表便于插入与删除）、DS-2016-02（很少插入删除时宜用顺序表））。

## 10. 一句话规律

链表删除题先问两句：**"我手里拿的是待删结点还是它的前驱？"** 拿的是前驱就 `pre->next = pre->next->next`；拿的是待删结点就用后继覆盖法 `q=p->next; p->data=q->data; p->next=q->next; free(q);`——**"改链"一定写在"free"之前**。
