# DS-2016-21

## 1. 原题

假设长度为 $n$ 的顺序表中查找每个数据元素的概率相等，即 $P_i=\frac{1}{n}$ ，则顺序查找算法的平均查找长度为____________________ 。

> 订正说明转录：源文作"顺序表查找每个数据元素"，据题意补"中"字。

## 2. 答案

$$ASL=\frac{n+1}{2}$$

（查找**成功**时的平均查找长度；若题目另问"查找失败"，无序表的顺序查找失败需比较 $n+1$ 次——见第 9 节口径说明。）

## 3. 题目分析

- 已知：长度为 $n$ 的顺序表；查找概率均匀分布 $P_i=\dfrac1n$（$i=1,2,\cdots,n$）；查找方法为顺序查找；
- 目标：求平均查找长度 $ASL$（Average Search Length）——"找到第 $i$ 个元素所需的关键字比较次数"的数学期望；
- 关键约束：顺序查找从表头开始逐个比较，故找到第 $i$ 个元素恰需 $C_i=i$ 次比较（第 $1$ 个一次命中，第 $n$ 个要比较 $n$ 次）；
- 命题意图：考 $ASL$ 的定义式 $ASL=\sum P_iC_i$ 与等差数列求和的结合，是 DS05.01（$ASL$ 概念）在 DS05.02（顺序查找）上的第一个基本结论，也是折半查找 $\log_2(n+1)-1$、分块查找等后续比较的基准量。

## 4. 核心考点

核心考点：
DS05.02 顺序查找法（从表的一端起逐个比较、第 $i$ 个元素的比较次数 $C_i=i$；无序表与有序表在成功情形下 $ASL$ 相同）

辅助考点：
DS05.01 查找的基本概念（平均查找长度 $ASL=\sum_{i=1}^{n}P_iC_i$ 的定义、"成功／失败"两种口径的区分）

解释：本题的推导完全建立在 $ASL$ 定义之上（DS05.01），而比较次数序列 $1,2,\cdots,n$ 由顺序查找的执行方式给出（DS05.02），后者是答题主体，故为主节点。

## 5. 解题思路

1. 先写定义：$ASL=\sum_{i=1}^{n}P_iC_i$，明确"$P_i$ 是被查元素为第 $i$ 个的概率，$C_i$ 是这种情况下的比较次数"；
2. 定 $C_i$：顺序查找自 $R[1]$ 起逐个与 $key$ 比较，第一次相等即成功 ⟹ $C_i=i$；
3. 代 $P_i=\frac1n$：$ASL=\frac1n\sum_{i=1}^{n}i$；
4. 用等差数列求和 $\sum_{i=1}^{n}i=\frac{n(n+1)}{2}$ 化简 ⟹ $\frac{n+1}{2}$；
5. 小表核对（$n=1,2,3$ 手算期望），并检查量级 $O(n)$ 是否符合"顺序查找线性时间"的常识。

## 6. 详细解答

**（1）按定义推导**

$$ASL_{succ}=\sum_{i=1}^{n}P_iC_i=\sum_{i=1}^{n}\frac1n\cdot i=\frac1n\cdot\frac{n(n+1)}{2}=\frac{n+1}{2}$$

**（2）小表核对**

| $n$ | 各 $C_i$ | 期望（手算） | $\frac{n+1}{2}$ |
|---|---|---|---|
| $1$ | $1$ | $1$ | $1$ ✓ |
| $2$ | $1,2$ | $\frac12(1+2)=1.5$ | $1.5$ ✓ |
| $3$ | $1,2,3$ | $\frac13(1+2+3)=2$ | $2$ ✓ |
| $4$ | $1,2,3,4$ | $\frac14\times10=2.5$ | $2.5$ ✓ |

**（3）带哨位（监视哨）版本的核对**

教材的顺序查找常写成把 $key$ 放入 $R[0]$ 作哨位、下标从 $n$ 递减比较的形式：

```c
int Search_Sq(SSTable ST, KeyType key)      /* ST.elem[1..n] 为数据，ST.elem[0] 作哨位 */
{
    int i = ST.length;
    ST.elem[0].key = key;                   /* 哨位：省去每轮的越界判定 */
    while (ST.elem[i].key != key) --i;      /* 从后向前比较 */
    return i;                               /* i==0 表示查找失败 */
}
```

该实现从第 $n$ 个元素开始比较，查找第 $i$ 个元素的比较次数为 $n-i+1$，于是

$$ASL=\frac1n\sum_{i=1}^{n}(n-i+1)=\frac1n\cdot\frac{n(n+1)}{2}=\frac{n+1}{2}$$

与前向查找结果**相同**（只是求和次序倒过来），说明本题答案与"从前向后"还是"从后向前（带哨位）"无关。

**（4）失败情形（口径对照，非本题答案）**

无序表查找失败时必须与全部 $n$ 个元素各比较一次，若把"比较 $n+1$ 次（含与哨位的一次）"计入口径，则 $ASL_{fail}=n+1$（不另设哨位判定即为 $n$）。本题题干说"查找每个数据元素的概率相等"，讨论对象是**表中的元素**，故属成功查找口径，取 $\frac{n+1}{2}$。

**（5）有序表的对照**

若表按关键字有序，成功查找的 $ASL$ 仍是 $\frac{n+1}{2}$（比较次数与下标一一对应，未变）；变的是失败情形：可在 $R[i].key>key$ 时提前结束，$ASL_{fail}\approx\frac{n}{2}+1$，比无序表省一半。这解释了 taxonomy 中 DS05.02 标注"含带哨位、有序表 ASL"的用意。

**答案**：$\dfrac{n+1}{2}$。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

顺序查找第 $i$ 个元素需比较 $C_i=i$ 次，$P_i=\frac1n$，故

$$ASL=\sum_{i=1}^{n}P_iC_i=\frac1n\sum_{i=1}^{n}i=\frac1n\cdot\frac{n(n+1)}{2}=\boxed{\dfrac{n+1}{2}}$$

量级为 $O(n)$。

## 9. 易错点

1. **口径混淆**：把"成功查找的 $ASL$"与"失败查找的 $ASL$（$n+1$ 或 $n$）"混用。题干"查找每个数据元素的概率相等"已限定为表中元素 ⟹ 成功口径；
2. 求和错项：写成 $\frac1n\sum_{i=1}^{n}(i+1)=\frac{n+3}{2}$（多加了一次"与哨位/越界标志的比较"）。按教材约定，$ASL$ 只统计**关键字与 $key$ 的比较次数**，哨位赋值不算比较；
3. 漏掉 $\frac1n$ 或误写成 $\frac{n(n+1)}{2}$（那是总比较次数，不是"平均"）；
4. 误以为"有序表成功查找 $ASL$ 更小"：成功情形两者同为 $\frac{n+1}{2}$，有序只改善失败情形（见第 6 节（5））；
5. 与折半查找混淆：$\frac{n+1}{2}$ 是顺序查找的结论，折半为 $\approx\log_2(n+1)-1$（本卷 DS-2016-32 考折半的最大比较次数）。

## 10. 一句话规律

一切 $ASL$ 题都走同一条路：**先按算法执行过程写出"查找第 $i$ 个元素要比较几次"的序列 $C_i$，再按题给概率 $P_i$ 加权求和**——顺序查找是 $C_i=i$（等差 ⟹ $\frac{n+1}{2}$），折半查找是 $C_i=$ 判定树中该结点层数（⟹ $\log$ 级）。
