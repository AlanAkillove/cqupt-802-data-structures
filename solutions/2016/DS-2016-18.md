# DS-2016-18

## 1. 原题

快速排序在下列哪种情况下最易发挥其长处（）

A. 被排序的数据总含有多个相同排序码

B. 被排序的数据已基本有序

C. 被排序的数据完全无序

D. 被排序的数据中的最大值和最小值相差悬殊

## 2. 答案

**C**（被排序的数据完全无序）。数据随机 ⟹ 枢轴的最终位置接近区间中点 ⟹ 划分均衡 ⟹ 递归树深 $O(\log n)$、总比较次数约 $2n\ln n$，达到快排的平均最优水平。

## 3. 题目分析

- 已知：快速排序这一算法（教材默认取子表首元素为枢轴）；
- 目标：判断四种输入分布中，哪一种最能让快排发挥"平均速度最快"的长处；
- 关键约束：快排的性能**只取决于每次划分是否均衡**，而均衡性由"枢轴在子表中的秩"决定，进而由输入数据的分布决定——这是本题唯一的判据链；
- 命题意图：反向考"快排最坏情形"。考生通常记住"有序时快排最坏"，本题把问法换成"何时最好"，需要对 A、B、D 三种情形各自的影响都有判断，尤其要能说明"关键字大量相同"为什么也是坏情形、"值域跨度大"为什么与快排无关。

## 4. 核心考点

核心考点：
DS06.06 快速排序（$partition$ 的工作方式、枢轴落点、平均 $O(n\log n)$ 与最坏 $O(n^2)$ 的分界、递归栈深度）

辅助考点：
DS06.11 排序算法应用（各内排序算法对数据分布的敏感性比较——冒泡/快排对"基本有序"的反应、基数排序对"值域跨度"的反应）
DS06.01 排序的基本概念（"趟"的概念：快排每一趟由一次划分完成，趟数即递归树深度）

解释：判定 C 正确需要 DS06.06 的划分均衡性分析；排除 B、D 需要横向比较其他算法的敏感条件（B 是冒泡/直接插入的甜点情形、D 是基数排序/计数排序的敏感条件），故列 DS06.11 为辅助；"发挥长处"具体指趟数少、总比较接近下界 $O(n\log n)$，用到 DS06.01 的"趟"与性能度量口径。

## 5. 解题思路

1. 先立判据：设某次划分把长度 $m$ 的子表分成 $k$ 与 $m-1-k$ 两部分，$k$ 越接近 $(m-1)/2$ 越好，$k=0$ 或 $m-1$ 最差（只削掉一个元素）；
2. 看枢轴落点由什么决定：取首元素为枢轴时，落点就是"首元素在子表中的秩"；数据完全随机 ⟹ 秩在 $1..m$ 上等可能 ⟹ 期望划分比例良好；
3. 对四个选项各自算落点：
   - B 基本有序 ⟹ 首元素几乎是子表最小者 ⟹ 每次 $k=0$ ⟹ 退化为 $O(n^2)$、栈深 $n$；
   - A 大量相同 ⟹ 教材 partition 中两个内循环条件为 `>=pivot` 与 `<=pivot`，相等时**右指针一路退到左指针**（见第 6 节（3））⟹ 同样极不均衡；
   - D 值域跨度大 ⟹ 划分只看相对大小，不看绝对数值 ⟹ 对快排无影响（该因素作用于基数排序的位数、计数排序的辅助空间）；
   - C 完全无序 ⟹ 无系统性偏置 ⟹ 均衡划分，$O(n\log n)$；
4. 结论：长处（平均最快、原地、常数小）只在 C 下得以体现。

## 6. 详细解答

**（1）性能与划分均衡性的定量关系**

一次划分对长度 $m$ 的子表作 $O(m)$ 次比较与移动。若每次划分把子表分成 $am$ 与 $(1-a)m$，递归树总代价满足

$$T(m)=T(am)+T((1-a)m)+cm$$

- $a=\frac12$（均衡）：$T(n)=\Theta(n\log n)$，树深 $\log_2 n$；
- $a\to 0$ 或 $1$（极不均衡）：$T(n)=\Theta(n^2)$，树深 $n$。

因此"快排何时最好"完全等价于"枢轴落点何时最接近中点"。

**（2）C：完全无序（随机）⟹ 平均最好**

枢轴取子表首元素，随机输入下首元素的秩在 $1..m$ 上均匀分布，期望划分比例为 $1:1$ 附近，可算得平均比较次数

$$C_{avg}=2(n+1)\ln n\approx 1.39\,n\log_2 n$$

（教材 10.3 节结论），且基于比较的内部排序的下界是 $\Omega(n\log_2 n)$，快排的系数 $1.39$ 接近下界，加上原地排序、循环体内指令少，实测常数最小——这正是"快排平均性能最佳"的含义，前提是数据无偏置，即"完全无序"。

**（3）A、B 的退化推导（用教材 `partition` 逐句看）**

教材划分（挖坑法）：

```c
int Partition(RcdType R[], int low, int high)
{
    RcdType pivot = R[low];                     /* 枢轴取子表首元素（暂存） */
    while (low < high) {
        while (low < high && R[high].key >= pivot.key) --high;  /* 相等也继续退 */
        R[low] = R[high];
        while (low < high && R[low].key <= pivot.key) ++low;    /* 相等也继续进 */
        R[high] = R[low];
    }
    R[low] = pivot;                             /* 枢轴落到最终位置 */
    return low;
}
```

- **B 基本有序**（如 $1,2,3,\cdots,n$）：枢轴 $=1$ 是子表最小者，第一个内循环把 `high` 从 $n$ 一直退到 $low$（每个元素都 $\ge$ 枢轴），划分结果为 $(0,\ m-1)$，枢轴落在子表最左端。$n$ 个元素共需 $n-1$ 趟划分，第 $i$ 趟比较 $n-i$ 次，总比较 $\sum_{i=1}^{n-1}i=\frac{n(n-1)}{2}=\Theta(n^2)$，递归栈深 $n$（可能栈溢出）。"基本有序"同理，只是把最坏变成接近最坏；
- **A 大量相同排序码**：设子表中所有元素关键字都等于枢轴，则 `R[high].key >= pivot` 恒真，`high` 同样一路退到 `low`，划分结果也是 $(0,m-1)$ —— 与 B 一样退化。即使只有"多个"相同码，相等元素被系统性地推到同一侧，划分的均衡性也被破坏（这正是需要"三路划分/Dutch national flag"改进的原因，教材未涉及）。故 A 不是发挥长处，而是暴露短处。

**（4）D 与快排无关**

快排的每一步只做**两两比较大小**，从不使用"关键字的数值差"来定位元素，因此值域跨度（最大最小相差多少）不影响比较次数与划分形态。同一组数据整体放大 $10^6$ 倍，快排的划分过程逐字不变。"值域跨度"真正影响的是**不基于比较**的排序：基数排序的分配趟数 $d=\lceil \log_r M\rceil$ 随最大值 $M$ 增大而增多，计数排序的辅助数组长度等于值域大小。故 D 是把别的算法的敏感条件搬来作干扰。

**（5）小结对照表**

| 输入形态 | 枢轴落点 | 划分均衡性 | 快排复杂度 | 对快排而言 |
|---|---|---|---|---|
| 完全无序（C） | 近似随机、期望居中 | 好 | $O(n\log n)$ | 最佳 ⟹ **答案** |
| 基本有序（B） | 落在端点 | 极差 | $O(n^2)$，栈深 $n$ | 最坏 |
| 大量相同码（A） | 落在端点（相等全归一侧） | 极差 | $O(n^2)$ | 最坏 |
| 值域跨度大（D） | 与跨度无关 | 不变 | 不变 | 无影响 |

**答案**：C。

## 7. 选项分析

- A. 被排序的数据总含有多个相同排序码：**错**。相等关键字在教材 `partition` 的 `>=`／`<=` 条件下被整体推向一侧，划分退化为 $(0,m-1)$，复杂度升到 $O(n^2)$；
- B. 被排序的数据已基本有序：**错**。这是快排的**最坏**情形（取端点为枢轴时），恰与"发挥长处"相反；"基本有序最有利"的是冒泡排序（可提前结束）和直接插入排序（每趟移动极少），本卷 DS-2016-35 即考该点，注意别把两个结论串味；
- C. 被排序的数据完全无序：**正确**。无偏置 ⟹ 枢轴落点接近中点 ⟹ 划分均衡 ⟹ 平均比较次数 $2n\ln n$、递归深度 $O(\log n)$，快排"平均最快、原地、常数小"的长处得以发挥；
- D. 被排序的数据中的最大值和最小值相差悬殊：**错**。快排只比较大小、不做数值映射，值域跨度不影响其性能；该条件影响的是基数排序（位数）与计数排序（辅助空间）。

## 8. 考场标准答案

选 **C**。

快排性能取决于每趟划分是否均衡，而均衡性取决于"枢轴在子表中的秩"。数据完全无序时枢轴落点近似随机、期望居中，递归树深 $O(\log n)$，总比较次数约 $2n\ln n\approx1.39\,n\log_2 n$，接近比较排序下界，故最能发挥快排平均速度快的长处。反之：基本有序（B）与大量相同关键字（A）都会使枢轴落在子表端点，划分退化为 $0$ 与 $m-1$，复杂度升至 $O(n^2)$ 且递归栈深达 $n$；值域跨度（D）与基于比较的快排无关。

## 9. 易错点

1. **把"基本有序"当成所有排序的好情形**（误选 B）：有序对插入、冒泡有利，对快排（取端点为枢轴）恰恰最不利——这是本题唯一但致命的反向陷阱；
2. 忽略相等关键字的危害（误选 A）：直觉上"有重复值应该更好排"，但教材划分把相等元素整体推到一侧，重复越多越接近最坏；
3. 把"值域跨度"与"数据分布"混淆（误选 D）：前者是绝对数值问题（影响基数/计数排序），后者是相对次序问题（影响快排、堆排序的比较次数）；
4. 表述失准：说"快排最好 $O(n\log n)$、最坏 $O(n^2)$"时应补上"最坏出现在每次划分极不均衡时（如已有序、全相等且取端点为枢轴）"，只说"有序时最坏"不够严谨（三数取中/随机枢轴即可缓解）；
5. 忘记空间代价：快排除原地划分外还需递归栈，最好 $O(\log n)$、最坏 $O(n)$，与"归并排序稳定占用 $O(n)$ 辅助空间"对比时不要写反。

## 10. 一句话规律

凡是"选枢轴 + 划分"型算法，判其好坏只看一个问题：**这种输入下枢轴会落在哪里**——落在中间就好，落在端点就坏；而"数据是否有序""值域多大"这类条件，要先问它影响的是比较类还是分配类算法，再决定归属。
