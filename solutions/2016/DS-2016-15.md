# DS-2016-15

## 1. 原题

下面哪一方法可以判断出一个有向图是否有环（即回路）（）。

A. 求节点的度

B. 拓扑排序

C. 求最短路径

D. 求关键路径

## 2. 答案

**B**（拓扑排序）。判据：**拓扑排序所得序列包含全部 $n$ 个顶点 ⟺ 有向图无环**；若某一轮所有未输出顶点的入度都大于 $0$（序列长度 $<n$），则剩余顶点中必存在环。

## 3. 题目分析

- 已知：一个有向图，要判断其有向边中是否构成回路（$v_1\to v_2\to\cdots\to v_k\to v_1$）；
- 目标：在四个"图上算法/量"中挑出**能给出该判定**的那一个；
- 关键约束：判环需要"全局结构信息"（能否把所有顶点排成与所有弧方向一致的线性序），局部量（度）与"路径长度类"算法（最短路径）都不提供这一信息；
- 命题意图：考拓扑排序的两个用途——一是 AOV 网检查工程先后关系是否矛盾（即有无环），二是为关键路径/拓扑序列提供前提；同时考"关键路径以拓扑排序为前提"这一层关系，避免把 D 误当成独立判据。

## 4. 核心考点

核心考点：
DS04.04.03 拓扑排序（AOV 网、拓扑序列存在性、"拓扑排序失败 ⟹ 有环"这一经典判据）

辅助考点：
DS04.04.04 关键路径（AOE 网求 $ve/vl$ 需先拓扑排序，其"能算"本身以无环为前提，故不构成独立判环方法）
DS04.01 图的基本概念（顶点的度／入度／出度只是局部信息，与是否成环无关）

解释：正确选项落在拓扑排序节点；D 之所以是干扰项，正是因为关键路径与拓扑排序同章同法（都是对有向无环图的顶点过程），需要清楚两者的**依赖方向**：拓扑排序 ⟶ 关键路径，而不是反过来。

## 5. 解题思路

1. 把"有环"翻译成可检测的结构特征：环上的每个顶点都至少有一条来自环内前驱的弧 ⟹ **环上顶点的入度永远不可能被减到 $0$**；
2. 拓扑排序恰是"反复摘除入度为 $0$ 的顶点"的过程，于是自然产生判据：若某轮再也找不到入度为 $0$ 的顶点而仍有顶点未输出 ⟹ 未输出的顶点构成（或包含）环；
3. 严格性核对：无环 ⟹ 至少存在一个入度为 $0$ 的顶点（否则沿入边可无限回溯，必成环），故无环时算法不会被卡住，能输出全部 $n$ 个顶点；两向都成立 ⟹ 该判据充要；
4. 排除其余三项：度是局部量（同度可环可不环）；最短路径算法（Dijkstra/Floyd）在含环图上照样收敛，环只影响"是否存在负权环"这类路径可优化性问题，不告诉你有无环；关键路径的计算前提就是无环（要先拓扑排序），不能反过来当判据。

## 6. 详细解答

**（1）拓扑排序判环的机制**

算法过程（教材 7.5.5）：

```
统计每个顶点的入度 indeg[]；
把所有 indeg[v]==0 的顶点压入栈/队列；
count = 0;
while (栈非空) {
    弹出 v;  输出 v;  count++;
    for (v 的每条出弧 <v,w>) if (--indeg[w] == 0) w 入栈;
}
if (count < n) 图中有环; else 图中无环;
```

- **充分性**（有环 ⟹ 卡住）：设 $C$ 是一个有向环，$C$ 中任一顶点的入度都包含"来自 $C$ 中前驱"的那条弧。$C$ 外顶点的摘除可能减少 $C$ 顶点的入度，但那条环内弧永远不会被减掉（要减它必须先输出它的前驱，而前驱也在环内）⟹ 环上顶点入度恒 $\ge 1$，永远不入栈 ⟹ $\text{count}<n$；
- **必要性**（无环 ⟹ 能输出全部）：对 $n$ 归纳。DAG 必有入度为 $0$ 的顶点（否则任取顶点沿入边回溯，$n+1$ 步内必重复 ⟹ 成环），摘除它所得仍为 DAG，由归纳假设可继续摘完。

故 `count < n` 与"存在有向环"等价，B 是**充要**判据。

**（2）实例模拟**

图：$a\to b,\ b\to c,\ c\to a,\ a\to d$（$n=4$，含环 $a,b,c$）。

| 步骤 | 入度状态 | 动作 |
|---|---|---|
| 初始 | $a:1,\ b:1,\ c:1,\ d:1$ | 无入度 $0$ 顶点，栈空 |
| 结束 | $\text{count}=0<4$ | **判定：有环** ✓ |

再去掉弧 $c\to a$（$a:0,b:1,c:1,d:1$）：输出 $a$ ⟹ $b:0,c:0$ 入栈 ⟹ 依次输出 $b,c,d$，$\text{count}=4=n$ ⟹ 无环 ✓。

**（3）其余三项为何不能判环**

- **A 求节点的度**：入度／出度是单点局部量。反例：环 $a\to b\to c\to a$ 的每个顶点入度 $=$ 出度 $=1$；而有向路径 $a\to b\to c$ 加孤立顶点 $d$ 后，$\{a,b,c\}$ 中度序列与环图完全相同（只是 $c$ 的出度为 $0$），可见"度"无法区分成环与不成环——把环上任意一条弧删去，各顶点度只变化 $1$，说明度分布对"是否闭合"不敏感；
- **C 求最短路径**：Dijkstra／Floyd 求的是路径长度，图中有正权环时算法仍正常收敛（环只是不会被选进最短路径），算法本身不报告"有无环"。唯一相关的是**负权环**检测（Bellman-Ford 型判定），但那既不在考纲算法之列，判的也不是"是否有环"这一拓扑性质；
- **D 求关键路径**：AOE 网求 $ve()$ 的递推顺序正是拓扑序列，$vl()$ 的递推是逆拓扑序列——**关键路径算法以"图无环"为前提**，其第一步就是做拓扑排序（教材 7.5.6 明确"若拓扑排序求得的序列顶点数小于 $n$，说明 AOE 网中有环，工程无法进行"）。也就是说，判环这件事仍然是拓扑排序在做，"求关键路径"只是拓扑排序的一个使用者，不能反过来当判据。

**答案**：B。

## 7. 选项分析

- A. 求节点的度：**错**。度只反映单个顶点的邻接数量，是局部信息；把环上的一条弧断开，度数几乎不变，故无法判"闭合"；
- B. 拓扑排序：**正确**。`count < n`（存在未输出的顶点）与"有向图中有环"互为充要，且算法顺带能定位环所在（未输出的顶点集即环的候选范围）；
- C. 求最短路径：**错**。最短路径算法对含环图同样能给出结果，其收敛性不以无环为条件（除负环影响 Dijkstra 的正确性外），不提供"有无环"的判定；
- D. 求关键路径：**干扰性最强的错误项**。关键路径的计算前提是无环（需先拓扑排序），它"用到"拓扑排序而不是"提供"判环方法；若图有环，$ve/vl$ 递推根本无法开始。

## 8. 考场标准答案

选 **B**（拓扑排序）。

理由：拓扑排序反复输出入度为 $0$ 的顶点并删去其出弧。环上顶点因始终保留一条来自环内前驱的入弧，入度不可能降为 $0$，故**当算法结束时若输出顶点数 $<n$，说明剩余顶点中存在有向环**；反之，无环（DAG）必有入度为 $0$ 的顶点，可逐个摘除而输出全部 $n$ 个顶点。该判据充要。度是局部量、最短路径算法与是否有环无关、关键路径本身须先拓扑排序，故 A、C、D 均不可作判据。

## 9. 易错点

1. **误选 D**：把"关键路径计算中会发现环"当成关键路径自身的功能——发现环的是它内部调用的拓扑排序，判据归属于拓扑排序；
2. 只写"拓扑排序能判环"而不给判据形式：应写成"拓扑序列顶点数 $<n$ ⟹ 有环"，这是本题的采分点；
3. 与无向图判环混淆：无向图判环可用"边数 $\ge$ 顶点数（连通分支内）"或 DFS 是否有回边（注意无向图中指向父亲的边不算回边），而本题是**有向**图，用入度摘除最省事；
4. 忘记拓扑排序对存储结构的要求：用邻接表时统计入度需扫描全部边表，复杂度 $O(n+e)$；若用邻接矩阵则 $O(n^2)$。

## 10. 一句话规律

"能否把所有顶点排成一个与所有弧方向一致的线性序"就是"有无环"的另一种说法——所以判环不必另想办法，做一遍拓扑排序，看输出是否满 $n$ 个顶点即可。
