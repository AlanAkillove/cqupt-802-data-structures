# DS-2020-13

## 1. 原题

已知一个长度为 $18$ 的有序顺序表，若采用折半查找法查找第 $12$ 个元素，则比较次数是（）。

> 订正说明转录：源文作"已知一个长度为 $18$ 的有序顺序表中"，"已知……中"句式杂揉，据题意删"中"字。

A. $3$

B. $4$

C. $5$

D. $6$

## 2. 答案

**B**（$4$ 次）。依次比较 $A[9]$、$A[14]$、$A[11]$、$A[12]$，第 $4$ 次命中。

## 3. 题目分析

- 已知：长度 $n=18$ 的**有序**顺序表（下标 $1\sim18$），待查找元素是**第 $12$ 个**，即目标就在表内（查找成功型）；
- 目标：数出折半查找过程中发生的**关键字比较次数**；
- 关键约束：每次取 $mid=\lfloor (low+high)/2\rfloor$，$A[mid]<key$ 时转右半（$low=mid+1$），$A[mid]>key$ 时转左半（$high=mid-1$），命中即停；
- 命题意图：查折半查找的**逐轮区间收缩能否手工执行**。成功查找第 $i$ 个元素的比较次数等于判定树中该结点的层次，因此本题等价于"结点 $12$ 在 $n=18$ 的判定树里第几层"。

## 4. 核心考点

核心考点：
DS05.04 折半查找法（区间收缩规则、$mid$ 取整约定、判定树与查找路径长度）

辅助考点：
DS05.01 查找的基本概念（"比较次数"以关键字比较为单位；成功查找的比较次数是 ASL 的基本量）

解释：解题手续完全是 `Search_Bin` 的机械模拟；而"第 $12$ 个元素要比几次"这一问法本身，是 DS05.01 中"成功查找平均长度按各元素比较次数加权"的单元素版本。

## 5. 解题思路

1. 先声明约定：下标 $1..18$、$mid=\lfloor(low+high)/2\rfloor$（教材整数除法口径）；
2. 逐轮写 $(low,\,mid,\,high)$ 三元组，用目标下标 $12$ 与 $mid$ 的大小决定收缩方向，直到 $mid=12$；
3. 数出轮数即比较次数；
4. 用**判定树**独立复核：结点 $12$ 的层次应等于该次数；
5. 做**约定不变性检验**：改用 $mid=\lceil(low+high)/2\rceil$ 或改用 $0$ 起下标，看次数是否改变（结论：仍为 $4$，答案不依赖取中口径）；
6. 用上界 $\lceil\log_2(n+1)\rceil=\lceil\log_2 19\rceil=5$ 校核：$4\le 5$ ✓（且说明 D 项 $6$ 根本不可能）。

## 6. 详细解答

**（1）逐轮执行（下标 $1..18$，$mid=\lfloor(low+high)/2\rfloor$）**

| 轮次 | $low$ | $high$ | $mid=\lfloor\frac{low+high}{2}\rfloor$ | 与目标下标 $12$ 比较 | 区间变化 |
|---|---|---|---|---|---|
| 1 | $1$ | $18$ | $9$ | $12>9$，转右半 | $low=10$ |
| 2 | $10$ | $18$ | $14$ | $12<14$，转左半 | $high=13$ |
| 3 | $10$ | $13$ | $11$ | $12>11$，转右半 | $low=12$ |
| 4 | $12$ | $13$ | $12$ | $12=12$，**查找成功** | 结束 |

被比较的元素依次为 $A[9]$、$A[14]$、$A[11]$、$A[12]$，共 **$4$ 次**。

**（2）判定树复核**

$n=18$ 的折半查找判定树按层展开（结点内写表下标，$mid=\lfloor(low+high)/2\rfloor$）：

| 层次 | 结点（表下标） | 个数 |
|---|---|---|
| $1$ | $9$ | $1$ |
| $2$ | $4$、$14$ | $2$ |
| $3$ | $2$、$6$、$11$、$16$ | $4$ |
| $4$ | $1$、$3$、$5$、$7$、$10$、$12$、$15$、$17$ | $8$ |
| $5$ | $8$、$13$、$18$ | $3$ |

内部结点总数 $1+2+4+8+3=18$ ✓（与表长一致）；树高 $5=\lceil\log_2(18+1)\rceil$ ✓。

结点 $12$ 是 $11$ 的右孩子、位于**第 4 层**，从根到它的路径为 $9\to14\to11\to12$，长度 $4$ ⟹ 成功查找 $A[12]$ 需比较 $4$ 次 ✓，与（1）一致。

**（3）取中口径与下标起点的不变性检验**

- 改用 $mid=\lceil(low+high)/2\rceil$（下标 $1..18$）：$10\to15\to13\to12$，仍 $4$ 次（次序不同）；
- 改用 $0$ 起下标（$0..17$，目标为下标 $11$）：$8\to13\to10\to11$，仍 $4$ 次。

即"比较 $4$ 次"对三种常见约定都成立，答案唯一。

**（4）算法描述（教材风格 C，说明上表每行的来源）**

```c
int cnt = 0;                                   /* 记录关键字比较次数 */
int SearchBin(SqList L, int k)                 /* L.r[1..L.length] 递增有序，k 为目标位置 */
{
    int low = 1, high = L.length, mid;
    while (low <= high) {
        mid = (low + high) / 2;                /* 向下取整 */
        ++cnt;
        if (L.r[mid].key == L.r[k].key) return mid;
        else if (L.r[mid].key > L.r[k].key) high = mid - 1;
        else low = mid + 1;
    }
    return 0;
}
```

代入 $n=18$、$k=12$，循环 $4$ 轮后返回，`cnt` $=4$。

**答案**：B。

## 7. 选项分析

- A. $3$：错。只走到 $A[9],A[14],A[11]$；此时区间为 $[12,13]$ 尚未取中，$A[12]$ 还没比较过，不能提前宣布找到（少算最后一轮是本题最主要的误区）；
- B. $4$：正确。逐轮执行与判定树层次两条独立方法均得 $4$；
- C. $5$：错。$5=\lceil\log_2(18+1)\rceil$ 是本表折半查找的**最大**比较次数（判定树树高），不是第 $12$ 个元素的比较次数；只有第 5 层的 $A[8]$、$A[13]$、$A[18]$ 才需要 $5$ 次；
- D. $6$：错。$6$ 已超过判定树树高 $5$，折半查找不可能比较 $6$ 次；这一误值来自把"每次区间大致减半"的除法次数（$18\to9\to4\to2\to1$ 共 $5$ 段）再多加一次，或误按顺序查找数下标差。

## 8. 考场标准答案

取 $low=1,high=18$，$mid=\lfloor(low+high)/2\rfloor$：

$$A[9]\ (12>9)\to A[14]\ (12<14)\to A[11]\ (12>11)\to A[12]\ (命中)$$

共比较 $4$ 次，选 **B**。

## 9. 易错点

1. **提前停止**：比到 $A[11]$ 见 $12>11$ 就以为"下一格就是它"，少算一次（错选 A）；必须把 $mid$ 取到 $12$ 那次比较计入；
2. **把上界当结果**：$\lceil\log_2(n+1)\rceil=5$ 是最大比较次数，不能直接当某个具体元素的比较次数（错选 C）；
3. **取中约定不统一**：$\lfloor\rfloor$ 与 $\lceil\rceil$ 得到的比较**次序**不同（本题次数恰好都是 $4$，但如 2006 年第 30 题那样问"依次比较哪些下标"时答案会不同），一题之内必须固定一种并写明；
4. 把"第 $12$ 个元素"误读成"关键码等于 $12$"：本题表内元素值未知，只能按下标（位置）模拟，二者在本题不矛盾，但换卷面表述时要分清。

## 10. 一句话规律

折半查找"某元素比较几次"一律手打 $(low,mid,high)$ 三列表逐轮收缩，次数即判定树中该结点的层次，且必不超过树高 $\lceil\log_2(n+1)\rceil$。
