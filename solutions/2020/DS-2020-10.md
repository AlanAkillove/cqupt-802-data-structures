# DS-2020-10

## 1. 原题

对于一个有向图，若一个顶点的度为 $k1$ ，出度为 $k2$ ，则对应逆邻接表中该顶点的入边表中的边结点数为（）。

A. $k1$

B. $k2$

C. $k1-k2$

D. $k1+k2$

## 2. 答案

**C**：入边表中的边结点数 $=$ 该顶点的入度 $=k1-k2$。

## 3. 题目分析

- 已知：有向图（按教材约定不含自环、两顶点间同向弧至多一条）、某顶点的**度** $k1$ 与**出度** $k2$；存储结构为**逆邻接表**；
- 目标：求该顶点对应的**入边表**（即以该顶点为弧头的弧所组成的链表）中的边结点个数；
- 关键约束：
  1. 有向图中顶点的度 $=$ 入度 $+$ 出度，故入度 $=k1-k2$；
  2. 逆邻接表的定义：表头向量下标 $i$ 的链表把所有**指向** $v_i$ 的弧 $\langle v_j,v_i\rangle$ 串起来，每个弧占一个边结点（记录弧尾 $v_j$），因此链表长度 $=$ $v_i$ 的入度；
  3. 对照：邻接表中 $v_i$ 的链表长度 $=$ 出度；十字链表则同一顶点的出边与入边分列两个表（`firstout`/`firstin`）；
- 表面问题：填一个表达式；背后的数据结构问题：**存储结构的"表长"与逻辑概念"度"之间的对应关系**——邻接表/逆邻接表分别把出度、入度"物化"为链表长度，这是图存储章节最基础也最容易混的一组映射。

## 4. 核心考点

核心考点：
DS04.02.02 邻接表法——有向图的邻接表与逆邻接表的构造规则（边结点存什么、表长代表什么）

解释：题目直接问"逆邻接表中入边表的边结点数"，答案由逆邻接表的构造定义唯一确定。

辅助考点：
1. DS04.01 图的基本概念——有向图中"度 $=$ 入度 $+$ 出度"，这是把已知的 $k1,k2$ 换算成入度的唯一桥梁；
2. DS04.02.01 邻接矩阵法——邻接矩阵中第 $i$ 行非零元个数 $=$ 出度、第 $i$ 列非零元个数 $=$ 入度，与本题"链表长度 $=$ 入度"是同一事实在两种存储下的表现，可互为验证。

## 5. 解题思路

1. **翻译目标**：入边表中的边结点数 ⟺ 以该顶点为弧头的弧的条数 ⟺ **入度**；
2. **用定义换算**：度 $=$ 入度 $+$ 出度 ⟹ 入度 $=k1-k2$；
3. **选答案**：C；
4. **实例验证**：造一个 $3$ 顶点 $3$ 弧的小图，逐点算出 $(k_1,k_2)$ 与实际入边表长度，检查是否恒有"长度 $=k_1-k_2$"（第 6 节（3））；
5. **反向排除**：把 A、B、D 各解释成一个已知量——A 是"度"（无向图才有此对应）、B 是"出度"（对应**邻接表**的表长）、D 无对应图论含义，从而确认只有 C 与"入度"一致。

想到这一点的线索：看到"逆"字就想到"方向反过来"——邻接表顺着弧的方向存（存弧头），逆邻接表逆着弧的方向存（存弧尾），所以后者的表长统计的是"进来的弧"，即入度；剩下的只是一步减法。

## 6. 详细解答

**（1）概念对应表**

| 存储结构 | 第 $i$ 个链表的构成 | 链表中边结点数 |
|---|---|---|
| 邻接表（有向图）| 所有以 $v_i$ 为**弧尾**的弧 $\langle v_i,v_j\rangle$，结点存 $v_j$ | 出度 $\mathrm{OD}(v_i)$ |
| **逆邻接表**（有向图）| 所有以 $v_i$ 为**弧头**的弧 $\langle v_j,v_i\rangle$，结点存 $v_j$ | **入度 $\mathrm{ID}(v_i)$** |
| 无向图的邻接表 | 与 $v_i$ 关联的每一条边一个结点 | 度 $\mathrm{TD}(v_i)$ |
| 邻接矩阵 $A$ | — | 行 $i$ 非零元数 $=$ 出度；列 $i$ 非零元数 $=$ 入度 |

**（2）推导**

由有向图顶点度的定义：
$$k1=\mathrm{TD}(v_i)=\mathrm{ID}(v_i)+\mathrm{OD}(v_i)=\mathrm{ID}(v_i)+k2$$
$$\Longrightarrow\ \text{逆邻接表中 } v_i \text{ 的入边表结点数}=\mathrm{ID}(v_i)=k1-k2$$

**（3）实例验证**

设有向图 $G$：$V=\{A,B,C\}$，弧集 $\{\langle A,B\rangle,\langle A,C\rangle,\langle B,C\rangle\}$。

逆邻接表（表头 $v_i$ → 入边，结点存弧尾）：

```
A -> NULL                 （A 无入边）
B -> A -> NULL            （1 个边结点）
C -> A -> B -> NULL       （2 个边结点）
```

邻接表（对照）：

```
A -> B -> C -> NULL       （2 个：出度 2）
B -> C -> NULL            （1 个：出度 1）
C -> NULL                 （0 个：出度 0）
```

逐点核对 $k1-k2$ 与入边表长度：

| 顶点 | 出度 $k2$ | 入度 | 度 $k1=k2+$入度 | $k1-k2$ | 逆邻接表入边表结点数 | 一致？ |
|---|---|---|---|---|---|---|
| $A$ | $2$ | $0$ | $2$ | $0$ | $0$ | ✓ |
| $B$ | $1$ | $1$ | $2$ | $1$ | $1$ | ✓ |
| $C$ | $0$ | $2$ | $2$ | $2$ | $2$ | ✓ |

三种典型情形（纯出、一进一出、纯入）全部吻合 ⟹ 公式成立。

**（4）自我验证（全局计数）**

对任意有向图，逆邻接表中边结点总数应等于弧数 $|E|$：
$$\sum_i \mathrm{ID}(v_i)=|E|=\sum_i \mathrm{OD}(v_i)$$
上例 $\sum\mathrm{ID}=0+1+2=3=|\text{弧}|$ ✓，且 $\sum(k1-k2)=(2-0)+(2-1)+(2-2)=0+1+2=3$ ✓ —— 两式一致，说明"$k1-k2$ 即入度"在总量上不丢边、不重边。若误选 A（$k1$），总和会是 $\sum\mathrm{TD}=2|E|=6$，恰为弧数的两倍，明显与"每条弧在逆邻接表中只登记一次"矛盾，可据此排除 A；若选 B（$k2$），得到的是邻接表的表长，与"逆"字矛盾；若选 D（$k1+k2$），总和为 $3|E|$，更不可能。

**答案：C**

## 7. 选项分析

- A（$k1$）：错。$k1$ 是**度**（入度 $+$ 出度）；只有**无向图**的邻接表中"表长 $=$ 度"，本题是有向图且用逆邻接表；若按 A，则全表结点数会是弧数的 $2$ 倍（每条弧被登记两次），与逆邻接表定义矛盾；
- B（$k2$）：**最具迷惑性**。$k2$ 是出度，对应的是**邻接表**中该顶点的表长；把"邻接表"与"逆邻接表"混记就会选 B；
- C：正确。入度 $=k1-k2$，逆邻接表的入边表长度即入度；
- D（$k1+k2$）：错。等于"出度 $+$ 入度 $+$ 出度 $=$ 入度 $+2\times$出度"，无对应图论量，是把"度"与"出度"误当作需要相加的两个独立量。

## 8. 考场标准答案

有向图中：$\mathrm{TD}=\mathrm{ID}+\mathrm{OD}$。

逆邻接表按**弧头**建表，第 $i$ 个链表登记所有以 $v_i$ 为弧头的弧，一条弧一个边结点，故

$$\text{入边表结点数}=\mathrm{ID}(v_i)=\mathrm{TD}(v_i)-\mathrm{OD}(v_i)=k1-k2$$

选 **C**。

（对照记忆：邻接表 $\to$ 出度 $k2$；逆邻接表 $\to$ 入度 $k1-k2$；两者表长之和 $=\sum\mathrm{TD}=2|E|$。）

## 9. 易错点

1. **邻接表与逆邻接表记反**：邻接表存"我指向谁"（弧头），逆邻接表存"谁指向我"（弧尾），表长分别是出度与入度；
2. **把"度"当成无向图专用**：有向图的度同样有定义，且恰为入度 $+$ 出度，本题正是靠这一等式做减法；
3. **忽略自环**：若允许自环，一条自环 $\langle v_i,v_i\rangle$ 对出度与入度各贡献 $1$（有的教材计度为 $2$），关系式会差 $1$；教材讨论的有向图一般不含自环，本题按此约定；
4. **与十字链表混用**：十字链表中同一顶点既有出边表（`firstout`）又有入边表（`firstin`），一条弧只占**一个**结点却同时挂在两个表上，因此"结点总数 $=|E|$"这一条在十字链表中依然成立，但"某顶点的两个表长之和 $=$ 度"，与本题的"逆邻接表单表长 $=$ 入度"表述不同，不要交叉套用。

## 10. 一句话规律

有向图存储的"表长"只认方向：**顺着弧存的是出度（邻接表），逆着弧存的是入度（逆邻接表）**，而入度 $=$ 度 $-$ 出度，一切数值题都归结为这一次减法。
