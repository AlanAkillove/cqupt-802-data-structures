# DS-2020-17

## 1. 原题

表达式 `a * b - c - d $ e $ f - g - h * i` 中，运算符的优先级由高到低依次为 `-,*,$`，且均右结合，则相应的后缀式是____________________。

## 2. 答案

后缀式（逆波兰式）：

```
a b c d - - * e f g h - - i * $ $
```

对应的加括号中缀式为 `( a * ( b - ( c - d ) ) ) $ ( e $ ( ( f - ( g - h ) ) * i ) )`。

## 3. 题目分析

- 已知：中缀表达式 `a * b - c - d $ e $ f - g - h * i`（$9$ 个单字母操作数、$8$ 个运算符：$4$ 个 `-`、$2$ 个 `*`、$2$ 个 `$`）；优先级**由高到低**为 `-` > `*` > `$`；三种运算符**均右结合**；
- 目标：写出等价的后缀式（运算符紧跟其两个运算对象之后）；
- 关键约束：
  1. 本题优先级与算术习惯（先乘除后加减）**相反**，`-` 是最紧的运算符，`$` 最松；
  2. 右结合意味着同级链 `x op y op z` 应解析为 `x op (y op z)`；
  3. 后缀式长度必为 $9+8=17$ 个记号，且任一前缀中操作数个数总比运算符个数多 $1$（合法性自检）；
- 命题意图：考"由优先级与结合性**唯一确定语法树**，再由树导出后缀式"这一机械流程，重点检验是否真按题给优先级（而非算术直觉）解析。

## 4. 核心考点

核心考点：
DS02.07 栈、队列和数组的应用（表达式求值：中缀/后缀/前缀表示的相互转换、运算符优先级与结合性对语法树的决定作用）

解释：表达式与二叉树的对应（中缀=中序、后缀=后序、前缀=前序）是本节的核心理论工具；本题要求按给定的优先级/结合性先建树再取后序，属该知识点的标准考法。栈在本过程中充当"暂存未完成运算符"的角色，故本题同时是"栈的应用"背景题。

## 5. 解题思路

1. **按优先级从低到高逐层切分**（最紧的先被"保护"成整体，最松的最后切）：
   - 第一刀切最松的 `$`（右结合 ⟹ 从右往左配对）；
   - 每一段内再切 `*`；
   - 最后剩下的段内切 `-`；
2. 每切一刀就把该层的运算符放到其两个运算对象之后（后缀写法），递归处理各段；
3. 得到后缀式后做**双重自检**：
   - 记号总数 $=17$、操作数与运算符个数分别相符；
   - 用后缀求值器（栈）与直接按加括号中缀式计算，两者对任意赋值必须相等。

## 6. 详细解答

**（1）第一层：按最低优先级 `$` 切分（右结合）**

原式含两个 `$`，位置在 `d` 与 `e` 之间、`e` 与 `f` 之间。右结合 ⟹ 先配右边那个 `$`：

$$\underbrace{a*b-c-d}_{X_0}\ \$\ \underbrace{e}_{X_1}\ \$\ \underbrace{f-g-h*i}_{X_2}\quad\Longrightarrow\quad X_0\ \$\ (X_1\ \$\ X_2)$$

**（2）第二层：各段内按 `*` 切分（右结合，本层每段至多一个 `*`）**

- $X_0=$ `a*b-c-d`：`*` 比 `-` 松，故 `*` 是 $X_0$ 的顶层运算符，其左操作数只能是 `a`（`a` 后面没有 `-` 可吸收），右操作数是 `b-c-d`：
  $$X_0=a*(b-c-d)$$
- $X_1=e$：无运算符；
- $X_2=$ `f-g-h*i`：`*` 最松（本段内），切在 `h` 与 `i` 前：左 $=$ `f-g-h`，右 $=$ `i`：
  $$X_2=(f-g-h)*i$$

**（3）第三层：按最高优先级 `-` 切分（右结合）**

- `b-c-d` 右结合 ⟹ $b-(c-d)$；
- `f-g-h` 右结合 ⟹ $f-(g-h)$。

**（4）完整中缀语法树**

$$\Big(a*\big(b-(c-d)\big)\Big)\ \$\ \Big(e\ \$\ \big((f-(g-h))*i\big)\Big)$$

树形（根为最后一个参与运算的 `$`，采用"子树列表"写法以避免连线错位）：

```
$
├── *                      ← 顶层 $ 的左操作数
│   ├── a
│   └── -
│       ├── b
│       └── -
│           ├── c
│           └── d
└── $                      ← 顶层 $ 的右操作数
    ├── e
    └── *
        ├── -
        │   ├── f
        │   └── -
        │       ├── g
        │       └── h
        └── i
```

**（5）由语法树后序遍历（左→右→根）读出后缀式**

| 步 | 访问结点 | 输出 |
|---|---|---|
| 1 | 叶子 $a$（顶层 `*` 的左孩子） | `a` |
| 2 | 叶子 $b$ | `b` |
| 3 | 叶子 $c$、$d$ 及其父 `-` | `c d -` |
| 4 | 结点 `-`（$b-(c-d)$ 的根） | `b` 后的第二个 `-`，得 `b c d - -` |
| 5 | 结点 `*` | `*`，至此左半为 `a b c d - - *` |
| 6 | 叶子 $e$ | `e` |
| 7 | 叶子 $f$、$g$、$h$ 与内层 `-` | `f g h - -` |
| 8 | 结点 `*`（$(f-(g-h))*i$） | 先取叶子 $i$ 再输出 `*`，得 `f g h - - i *` |
| 9 | 内层 `$`（$e\$\cdots$） | `$` |
| 10 | 顶层 `$` | `$` |

拼接得

```
a b c d - - * e f g h - - i * $ $
```

**（6）自检**

- 记号数：操作数 $9$（$a\sim i$）$+$ 运算符 $8$（`-`$4$、`*`$2$、`$`$2$）$=17$ ✓；
- 后缀合法性（扫描时"操作数个数 $-$ 运算符个数"始终 $\ge1$ 且末尾恰为 $1$）：逐位累计值依次为
  $1,2,3,4,3,2,1,2,3,4,5,4,3,4,3,2,1$ ✓；
- 代值复算：题面未定义 `$` 的具体运算，取一个**非交换、非结合**的二元运算 $x\$y=2x+3y+5xy$ 作检验（只有限定运算不满足交换律与结合律，才能暴露分组次序的错误）。取 $a{=}3,b{=}2,c{=}6,d{=}3,e{=}3,f{=}8,g{=}2,h{=}2,i{=}5$：
  - 按加括号中缀：左半 $3\cdot(2-(6-3))=-3$；右半内层 $(8-(2-2))\cdot5=40$，$3\$40=6+120+600=726$；顶层 $(-3)\,\$\,726=-6+2178-10890=-8718$；
  - 按后缀式用栈求值（逐个压栈、遇运算符弹两元计算）：同一中间量序列 $-3$、$40$、$726$，最终 $-8718$ ✓ 两法一致。

**答案**：`a b c d - - * e f g h - - i * $ $`

不适用（填空题）。

## 8. 考场标准答案

优先级 `-` $>$ `*` $>$ `$`，均右结合，逐层加括号：

$$(a*(b-(c-d)))\ \$\ \big(e\ \$\ ((f-(g-h))*i)\big)$$

按"左子树 → 右子树 → 根"后序读出后缀式：

$$\boxed{\,a\ b\ c\ d\ -\ -\ *\ e\ f\ g\ h\ -\ -\ i\ *\ \$\ \$\,}$$

## 9. 易错点

1. **按算术直觉先做乘除**：本题 `-` 优先级最高，`a * b - c` 必须解析为 `a * (b - c)` 而不是 `(a*b) - c`；这是本题最大的失分点，一旦此处错，整串后缀式全错；
2. **忽略右结合**：同级链 `b-c-d` 右结合是 `b-(c-d)`（后缀 `b c d - -`），若按左结合写成 `(b-c)-d`（后缀 `b c - d -`）则错；
3. **`$` 链的结合方向**：`X0 $ e $ X2` 右结合 ⟹ `X0 $ (e $ X2)`，后缀中两个 `$` 连排在末尾；若按左结合会得 `(X0 $ e) $ X2`，后缀为 `X0 e $ X2 $`（两个 `$` 不连排）——这是可用来检查结合性是否用对的最直接标志；
4. **`*` 的切分位置**：`f-g-h*i` 中 `*` 比 `-` 松，故 `*` 的左操作数是整段 `f-(g-h)` 而不是 `h`；若误按算术优先级把 `h*i` 先结合，会得出片段 `f g h i * - -`（对应 $f-(g-(h\cdot i))$），而正确片段是 `f g h - - i *`；
5. 抄写时漏掉一个运算符：务必用"操作数 $9$ + 运算符 $8$ = $17$"计数校验。

## 10. 一句话规律

中缀转后缀一律"从**最低**优先级开始切、同级按结合性定方向、每切一刀就把该运算符放到两段结果之后"，切完即得语法树，后缀式就是这棵树的后序遍历。
