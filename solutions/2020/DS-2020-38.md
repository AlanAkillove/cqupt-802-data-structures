# DS-2020-38

## 1. 原题

$ORDER$ 公司是一个专门为人们提供排序服务的公司，该公司的宗旨是："秩序是最美丽的"。他们的工作是通过一系列移动，将某些物品按顺序摆好。他们的服务是通过工作量来计算的，即移动东西的次数。所以，在工作前必须先考察工作量，以便向用户提出收费价格。

用户并不知道精确的移动次数，实质上，大多数人是凭感觉来认定这一列物品的混乱程度。根据 $ORDER$ 公司的经验，人们一般是根据"逆序对"的数目多少来称呼这一序列的混乱程度。

假设我们将序列中第 $i$ 件物品的参数定义为 $A_i$，那么排序就是指将 $A_1,A_2,\cdots,A_n$ 按从小到大的顺序排序。若 $i < j$，且 $A_i > A_j$，则 $<i,j>$ 就为一个"逆序对"。

例如：数组（$3,1,4,5,2$）的"逆序对"有 $<3,1>$、$<3,2>$、$<4,2>$、$<5,2>$，共 $4$ 个。

现在，$ORDER$ 公司请你写一个程序，在尽量短的时间内，统计出"逆序对"的数目。程序输入 $n,A_1,\cdots,A_i,\cdots,A_n$，$1 \leq n \leq 30000$，$A_i$ 为小于 $200$ 的正整数。输出序列 $A_1,\cdots,A_i,\cdots,A_n$ 的"逆序对"数目，即"逆序数"。并请分析你设计的算法的时间复杂度。

> 订正说明转录：源文一处作"将 $A_1,A_i,A_n$ 按从小到大的顺序排序"，据题意修正为"$A_1,A_2,\cdots,A_n$"；另一处公司名作"$OEDER$"，据题意统一为 $ORDER$。

## 2. 答案

主解：**改造归并排序**，在每趟"合并两个有序子序列"时统计跨越中点的逆序对，总时间复杂度 $O(n\log n)$，空间 $O(n)$。

备选解：利用 $A_i < 200$ 的**值域计数法**，从右向左扫描维护已见值的频次数组，对每个 $A_j$ 累加"比它小的已见值个数"，时间 $O(200n)=O(n)$（系数固定），空间 $O(200)$。

（考场写出任一正确解法并正确分析复杂度即可；"$n\le 30000$、要尽量短的时间"提示暴力 $O(n^2)$（约 $9\times10^8$ 次比较）不满足题意。）

## 3. 题目分析

- 已知：整数序列 $A_1,\cdots,A_n$，$n\le 30000$，$1\le A_i < 200$；
- 目标：统计满足 $i<j$ 且 $A_i>A_j$ 的下标对数目（不是列出，是计数）；
- 关键约束："在尽量短的时间内"——必须优于 $O(n^2)$；
- 命题意图：考**归并排序的分治思想迁移**（逆序数=归并过程中"右侧元素抢先出队"时左侧剩余元素数之和）；值域限制则额外留出"计数排序思想"的口子。

## 4. 核心考点

核心考点：
DS06.08 二路归并排序（分治框架 + 合并过程）

辅助考点：
DS01.02.01 顺序存储（数组原地划分与回写）；DS01.03 线性表的应用（计数/频次统计）

解释：逆序对统计是归并排序最经典的变形应用——合并时若取 $A_j$（右半）而左半还剩 $A_i,\cdots,A_{mid}$，则它们都与 $A_j$ 构成逆序对，一次计入 $mid-i+1$ 对。

## 5. 解题思路

1. 先想暴力：双重循环逐对检查 $i<j, A_i>A_j$，$O(n^2)$，$n=30000$ 时不可接受——排除；
2. 观察逆序对 $<i,j>$ 必"跨过"某次划分的左右两半（或全在其中一半，递归解决）——这正是归并的结构：把"跨半逆序对"的统计并入合并过程，且左右子问题递归统计"半内逆序对"，不漏不重；
3. 合并时左半 $A[i..mid]$、右半 $A[mid+1..j]$ 均已有序：当 $A[j]<A[i]$ 需取右元素时，左半剩余的 $mid-i+1$ 个元素都 $>A[j]$，一次性累加；
4. 另一线索：$A_i<200$ 说明值域只有 199 个不同取值，可用频次数组：从右往左扫，边扫边记"值 $v$ 出现过的次数"，对当前 $A_j$ 累加 $\sum_{v<A_j} cnt[v]$，即得所有以 $j$ 为右端的逆序对数。

## 6. 详细解答

### 主解：归并计数（教材风格 C 语言）

**基本设计思想**：与归并排序完全相同——将 $A[low..high]$ 分成两半，递归统计左半逆序数、右半逆序数；合并两个有序子序列时，凡右半元素 $A[j]$ 先于左半元素 $A[i]$ 进入临时数组，则左半剩余 $mid-i+1$ 个元素均大于 $A[j]$，与 $A[j]$ 各构成一个逆序对，累加之。合并结果回写原数组，保证上层归并的有序性。

```c
typedef int ElemType;

/* 对 A[low..high] 统计逆序数并归并排序，T 为等长辅助数组 */
long long MergeCount(ElemType A[], int low, int high, ElemType T[])
{
    if (low >= high) return 0;               /* 单元素无逆序对 */
    int mid = (low + high) / 2;
    long long cnt = MergeCount(A, low, mid, T)
                  + MergeCount(A, mid + 1, high, T);   /* 两半内部的逆序对 */

    int i = low, j = mid + 1, k = low;
    while (i <= mid && j <= high)
        if (A[i] <= A[j])
            T[k++] = A[i++];                 /* 左元素先出，不产生新逆序对 */
        else {
            T[k++] = A[j++];                 /* 右元素抢先出队 */
            cnt += mid - i + 1;              /* 左半剩余 mid-i+1 个都与 A[j] 成逆序对 */
        }
    while (i <= mid)  T[k++] = A[i++];       /* 拷贝剩余 */
    while (j <= high) T[k++] = A[j++];
    for (i = low; i <= high; i++) A[i] = T[i];  /* 回写，供上层归并使用 */
    return cnt;
}

long long InverseCount(int n, ElemType A[])   /* 主调用 */
{
    ElemType *T = (ElemType *)malloc(n * sizeof(ElemType));
    long long cnt = MergeCount(A, 0, n - 1, T);
    free(T);
    return cnt;
}
```

**样例走查** $A=(3,1,4,5,2)$：划分 $[3,1,4]$ 与 $[5,2]$；左半递归得 $<3,1>=1$；右半得 $<5,2>=1$；合并 $(1,3,4)$ 与 $(2,5)$：取 2 时左半剩余 $(3,4)$，累加 2 → 共 $1+1+2=4$ ✓ 与题面例子一致。

**复杂度分析**：与归并排序同递推 $T(n)=2T(n/2)+O(n)$，故时间 $O(n\log n)$；$n=30000$ 时约 $4.5\times10^5$ 次基本操作，远快于暴力。空间：辅助数组 $O(n)$ + 递归栈 $O(\log n)$。

### 备选解：值域计数法（利用 $A_i<200$）

```c
long long InverseCount2(int n, int A[])
{
    int cnt[200] = {0};                      /* cnt[v]: 值 v 在右侧已出现的次数 */
    long long total = 0;
    for (int j = n - 1; j >= 0; j--) {       /* 从右向左扫 */
        for (int v = 1; v < A[j]; v++)       /* 值域仅 1..199 */
            total += cnt[v];                 /* 已见且比 A[j] 小的都在 j 右侧，成逆序对 */
        cnt[A[j]]++;
    }
    return total;
}
```

**复杂度**：外层 $n$ 次、内层至多 199 次，时间 $O(200n)=O(n)$（$n=30000$ 时约 $6\times10^6$，实际也满足"尽量短"）；空间 $O(200)$。

## 8. 考场标准答案

(1) **设计思想**：借用二路归并——递归统计左右两半内部逆序数；合并有序两半时，右半元素先出队若干次，每次左半剩余多少个元素就贡献多少对逆序，累加 $mid-i+1$。排完序同时得到逆序总数。
(2) **代码**：见第 6 节主解 `MergeCount`。
(3) **复杂度**：递推 $T(n)=2T(n/2)+O(n)$，解得时间 $O(n\log n)$，附加空间 $O(n)$。

## 9. 易错点

1. 写成"当 `A[i]>A[j]` 时 cnt+1"——只计了当前一对，漏掉左半剩余全部元素，应为 `cnt += mid - i + 1`；
2. 合并后**忘记回写** `A[i]=T[i]`，上层合并的两半不有序，统计失效；
3. 等值元素归并时右元素先出（`A[i] <= A[j]` 的条件写反）会把 $A_i=A_j$ 误计为逆序对——题设 $i<j,A_i>A_j$ 是严格大于；
4. 数量级：最坏逆序数 $\frac{n(n-1)}{2}\approx 4.5\times10^8$，32 位 `int`（上限 $\approx 2.1\times10^9$）勉强放得下，但用 `long long` 更稳妥；
5. 值域法从**右端**往左扫（对每个 $j$ 数右侧更小者），方向弄反则统计成"顺序对"。

## 10. 一句话规律

逆序对计数题：看到"统计逆序数 + 要求快"就条件反射**改归并**——右元素先出队时累加左半剩余个数；若另给"值很小/取值范围有限"，则频次数组扫描是第二把刀。
