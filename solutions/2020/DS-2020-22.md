# DS-2020-22

## 1. 原题

设一棵树中只有度为 $0$ 和度为 $3$ 的结点，则该树的第 $i$ 层（$i \geq 1$）的结点个数最多为____________________。

## 2. 答案

**$3^{\,i-1}$**。

即第 $1$ 层最多 $1$ 个（根）、第 $2$ 层最多 $3$ 个、第 $3$ 层最多 $9$ 个、第 $4$ 层最多 $27$ 个……

## 3. 题目分析

- 已知：一棵树，结点只有两种度——$0$（叶子）或 $3$（恰有 $3$ 个孩子）；不存在度为 $1$、$2$ 的结点；
- 目标：第 $i$ 层（层次从 $1$ 开始计数，根在第 $1$ 层）结点个数的**最大值**；
- 关键约束：
  1. 每个结点的孩子数不超过 $3$ ⟹ 第 $i$ 层结点数 $\le 3\times$ 第 $i-1$ 层结点数（这是上界的唯一来源）；
  2. “只有度 $0$ 和度 $3$”意味着一旦某结点不是叶子，它就**必须**贡献 $3$ 个孩子——这保证上界能被“满 3 叉树”取到（不存在“想生 3 个只生 2 个”的空隙）；
  3. 层次编号以根为第 $1$ 层（题面 $i\ge 1$ 已暗示），故指数是 $i-1$ 而不是 $i$；
- 命题意图：考"树的度 $\to$ 每层结点上界"的归纳推理，并检验是否会被"只有度 0 和度 3"这一多余条件带偏（去算叶子数、总结点数），或把层次起点弄错。

## 4. 核心考点

核心考点：
DS03.01 树的基本概念（结点的度、树的度、层次与深度的定义、各层结点数的上界与结点计数关系）

解释：本题既用到"层次/度"的定义（决定归纳起点与倍数），又用到"分支数 $=$ 结点数 $-1$"这一计数关系（用于自检），二者同属 DS03.01，无需引入二叉树性质（DS03.02.01）——本题是**树**不是二叉树，孩子无边序、无左右之分，但每层上界的推导形式与二叉树 $2^{i-1}$ 完全平行。

## 5. 解题思路

1. 先定"树的度"：结点只有度 $0$ 与度 $3$，故树的度为 $3$（只要树高大于 $1$）；
2. 建立递推：第 $i$ 层的每个结点都是第 $i-1$ 层某个结点的孩子，而第 $i-1$ 层每个结点至多有 $3$ 个孩子 ⟹ $n_i\le 3n_{i-1}$；
3. 递推起点 $n_1=1$（根唯一）⟹ 归纳得 $n_i\le 3^{i-1}$；
4. 证**可达**：构造"深度为 $i$ 的满 3 叉树"（第 $1\sim i-1$ 层结点度均为 $3$，第 $i$ 层为叶子），它满足"只有度 0 和度 3"，且第 $i$ 层恰有 $3^{i-1}$ 个结点 ⟹ 上界即答案；
5. 自检：用 $n_0=2n_3+1$（下节推导）代满 3 叉树验证计数一致，防止把 $3^{i-1}$ 误写成 $3^i$ 或 $2\cdot3^{i-1}$。

## 6. 详细解答

**（1）上界的归纳证明**

记第 $k$ 层结点数为 $n_k$。

- 基础：$n_1=1=3^{0}$ ✓；
- 归纳：设 $n_{k}\le 3^{k-1}$。第 $k+1$ 层的每个结点是第 $k$ 层某结点的孩子，且第 $k$ 层每个结点的度 $\le 3$（题设只允许度 $0$ 或 $3$），不同结点的孩子互不相同（树中每个结点只有一个双亲），故
  $$n_{k+1}\le 3\,n_k\le 3\cdot 3^{k-1}=3^{k}$$

∴ 对一切 $i\ge 1$，$n_i\le 3^{\,i-1}$。

**（2）可达性构造**

取深度为 $i$ 的**满 3 叉树**：第 $1,2,\dots,i-1$ 层的每个结点都有 $3$ 个孩子，第 $i$ 层全是叶子。它显然"只有度为 $3$ 的结点（前 $i-1$ 层）和度为 $0$ 的结点（第 $i$ 层）"，且

| 层 $k$ | 结点数 | 结点类型 |
|---|---|---|
| $1$ | $1=3^0$ | 度 $3$ |
| $2$ | $3=3^1$ | 度 $3$ |
| $3$ | $9=3^2$ | 度 $3$ |
| $\vdots$ | $\vdots$ | $\vdots$ |
| $i-1$ | $3^{i-2}$ | 度 $3$ |
| $i$ | $3^{i-1}$ | 度 $0$（叶子） |

第 $i$ 层恰取到 $3^{i-1}$，故上界可达，答案就是 $3^{i-1}$。

**（3）计数关系自检（$n_0=2n_3+1$）**

设度为 $0$ 的结点有 $n_0$ 个、度为 $3$ 的结点有 $n_3$ 个。

- 结点总数：$n=n_0+n_3$；
- 边数：树中除根外每个结点恰有一条入边，故边数 $=n-1$；另一方面边数 $=$ 各结点孩子数之和 $=0\cdot n_0+3\,n_3=3n_3$；
- 联立：$n_0+n_3-1=3n_3\Longrightarrow n_0=2n_3+1$。

用（2）的满 3 叉树核对：$n_3=1+3+\cdots+3^{i-2}=\dfrac{3^{i-1}-1}{2}$，则

$$n_0=2\cdot\frac{3^{i-1}-1}{2}+1=3^{i-1}\ \checkmark$$

即叶子数恰为 $3^{i-1}$，与"第 $i$ 层最多 $3^{i-1}$ 个"完全吻合（满树时第 $i$ 层全是叶子），说明指数 $i-1$ 没有写错。

**（4）几个具体值**

$i=1\to1$；$i=2\to3$；$i=3\to9$；$i=4\to27$；$i=5\to81$。

**答案**：$3^{\,i-1}$。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

树的度为 $3$，第 $1$ 层只有根 $1$ 个结点；每个结点至多 $3$ 个孩子 ⟹ $n_i\le 3n_{i-1}\le\cdots\le 3^{i-1}n_1=3^{i-1}$。

深度为 $i$ 的满 3 叉树（前 $i-1$ 层度均为 $3$，第 $i$ 层为叶子）满足题设且第 $i$ 层恰有 $3^{i-1}$ 个结点，故

$$\boxed{\,3^{\,i-1}\,}$$

## 9. 易错点

1. **指数写成 $3^{i}$**：层次从 $1$ 开始（根在第 $1$ 层），第 $1$ 层只有 $1$ 个结点，代 $i=1$ 应得 $1$，只有 $3^{i-1}$ 满足——做完务必用 $i=1,2$ 两个最小情形回代检验；
2. **误按二叉树作答**：写成 $2^{i-1}$，把"树的度为 3"与"二叉树每个结点至多 2 个孩子"混淆；树的孩子数没有上限为 2 的限制，本题上限就是题设的 $3$；
3. **被"只有度 0 和度 3"带偏去算总结点数**：该条件只保证"非叶即满 3 个孩子"（用于说明上界可达），并不改变每层上界的推导；若误把它当"完全 3 叉树"再去套 $n=(3^h-1)/2$ 之类的公式，会把"第 $i$ 层"答成"深度 $i$ 的树总共"；
4. **忽略"树"与"有序树/二叉树"的区别**：树中孩子无序，不影响"每层结点数上界"的计数，但会影响遍历（见本卷第 21 题的"有序树"前提），不要把两题的条件互相套用。

## 10. 一句话规律

"第 $i$ 层最多几个"只看**树的度** $d$：答案是 $d^{\,i-1}$（根在第 $1$ 层）；题面给的其它度（如本题的度 $0$）只用来保证上界**可达**，不参与指数计算。作答后用 $i=1,2$ 回代、再用 $n_0=(d-1)n_d+1$ 核对计数。
