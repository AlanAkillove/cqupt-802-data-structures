# DS-2020-20

## 1. 原题

一棵二叉排序树（`BST,binary search/sort tree`）的后序遍历序列是 $15, 10, 23, 25, 20, 35, 42, 39, 30$。请给出这棵树的前序遍历序列：____________________。

## 2. 答案

**$30,\ 20,\ 10,\ 15,\ 25,\ 23,\ 39,\ 35,\ 42$**。

对应的树为

```
            30
        /        \
      20          39
     /  \        /  \
   10    25     35   42
     \  /
     15 23
```

## 3. 题目分析

- 已知：一棵 BST 的**后序**序列（$9$ 个关键字，互不相同）；
- 目标：同一棵树的**前序**序列；
- 关键约束：
  1. 后序"左→右→根" ⟹ 序列**最后一个元素必是整棵树的根**；
  2. BST 的性质 ⟹ 根把序列切成"全部小于根的左子树段"与"全部大于根的右子树段"，且这两段在后序中仍是**连续**的；
  3. 仅凭后序一般不能唯一确定二叉树，但有了"BST"这一额外约束，左右子树的划分由关键字大小唯一决定 ⟹ 树唯一 ⟹ 前序唯一；
- 命题意图：考"由遍历序列重建 BST"的机械流程，同时检验是否理解"BST 的中序序列必为升序"这一等价性质（它提供第二种重建途径）。

## 4. 核心考点

核心考点：
DS05.07.01 二叉搜索（排序）树（构造、中序有序性——本题正是用"左子树键值全小于根、右子树全大于根"来切分后序序列）

辅助考点：
DS03.02.03 二叉树的遍历（后序定根、前序读根，以及"由一种遍历序列 + BST 约束唯一还原二叉树"）

解释：题目的载体是 BST（决定重建规则），需要的操作技能是遍历序列互推（决定输出形式），故主考点 DS05.07.01、辅考点 DS03.02.03；不涉及 AVL 旋转（DS05.07.02）与删除操作。

## 5. 解题思路

1. **定根**：取后序末元素 $30$ 为根；
2. **分段**：把剩下的后序序列按"$<30$ / $>30$"切成两段（BST 保证不会出现交叉），左段是左子树的后序、右段是右子树的后序；
3. **递归**：对每一段重复 1~2 步（段末元素即该子树的根），直到段长为 $1$；
4. **读前序**：树建好后按"根→左→右"读一遍；
5. **换一条路复核**：利用"BST 的中序 $=$ 关键字升序排列"得到中序 $10,15,20,23,25,30,35,39,42$，用"中序 + 后序"这两条通用序列再重建一次；两次树形一致才动笔。最后再对重建的树求一次后序，看是否等于题面给的序列。

## 6. 详细解答

**（1）第一层：根 $=30$**

后序去掉末元素后为 $15,10,23,25,20,35,42,39$。按与 $30$ 的大小切分：

- 左子树后序 $L_1 = 15,10,23,25,20$（全部 $<30$）；
- 右子树后序 $R_1 = 35,42,39$（全部 $>30$）。

切分点唯一（$20$ 之后出现 $35>30$），说明划分无歧义。

**（2）左子树 $L_1=15,10,23,25,20$：根 $=20$**

- 小于 $20$ 的：$15,10$ ⟹ 左子树后序 $L_2 = 15,10$；
- 大于 $20$ 的：$23,25$ ⟹ 右子树后序 $R_2 = 23,25$。

**（3）$L_2=15,10$：根 $=10$**

- 剩余 $15>10$ ⟹ $15$ 是 $10$ 的**右孩子**（$10$ 无左孩子）。

**（4）$R_2=23,25$：根 $=25$**

- 剩余 $23<25$ ⟹ $23$ 是 $25$ 的**左孩子**（$25$ 无右孩子）。

**（5）右子树 $R_1=35,42,39$：根 $=39$**

- $35<39$ ⟹ 左孩子 $35$；$42>39$ ⟹ 右孩子 $42$。

**（6）重建结果与递归式**

$$T:\ 30\big(\underbrace{20(10(\varnothing,15),\;25(23,\varnothing))}_{\text{左子树}},\;\underbrace{39(35,42)}_{\text{右子树}}\big)$$

```
            30
        /        \
      20          39
     /  \        /  \
   10    25     35   42
     \  /
     15 23
```

**（7）前序遍历（根→左→右）**

| 访问次序 | 结点 | 说明 |
|---|---|---|
| 1 | $30$ | 整棵树根 |
| 2 | $20$ | 左子树根 |
| 3 | $10$ | $20$ 的左孩子根 |
| 4 | $15$ | $10$ 的右孩子 |
| 5 | $25$ | $20$ 的右孩子根 |
| 6 | $23$ | $25$ 的左孩子 |
| 7 | $39$ | 右子树根 |
| 8 | $35$ | $39$ 的左孩子 |
| 9 | $42$ | $39$ 的右孩子 |

前序：$30,20,10,15,25,23,39,35,42$。

**（8）第二法复核（中序 + 后序通用重建）**

BST 的中序序列即关键字升序：$10,15,20,23,25,30,35,39,42$。用"后序末定根、中序定根处切分"重建：

- 后序末 $30$，在中序中位于第 $6$ 位 ⟹ 左子树中序 $10,15,20,23,25$、右子树中序 $35,39,42$，与（1）的分段完全一致；
- 左段后序 $15,10,23,25,20$ 末为 $20$，中序中 $20$ 左侧 $10,15$、右侧 $23,25$；$10$ 的中序右侧有 $15$ ⟹ $15$ 是 $10$ 的右孩子；$25$ 的中序左侧有 $23$ ⟹ $23$ 是 $25$ 的左孩子；
- 右段后序 $35,42,39$ 末为 $39$，中序 $35\,|\,39\,|\,42$ ⟹ 左 $35$、右 $42$。

两次重建的树形逐结点相同 ✓。

**（9）回推后序自检**

对（6）的树求后序：左子树 $20$ 的后序 $=15,10,23,25,20$；右子树 $39$ 的后序 $=35,42,39$；整树后序 $=15,10,23,25,20,35,42,39,30$，与题面完全一致 ✓。元素个数 $9$、中序有序性均核对通过。

**答案**：$30,20,10,15,25,23,39,35,42$。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

后序末元素为根，用 BST 的"左小右大"对剩余序列切段，逐层递归：

$$30\to\big[\,20(10(\varnothing,15),\,25(23,\varnothing)),\;39(35,42)\,\big]$$

按"根左右"读出前序：

$$\boxed{\,30,\ 20,\ 10,\ 15,\ 25,\ 23,\ 39,\ 35,\ 42\,}$$

（写答案后立刻用"该树的后序是否还原题面序列"自检，$10$ 只有右孩子 $15$、$25$ 只有左孩子 $23$ 这两处最容易反。）

## 9. 易错点

1. **把后序首元素当根**：后序第一个元素 $15$ 是最左下端的叶子，根是**末元素** $30$；混淆前序/后序的定根位置是本题最常见错误；
2. **切段时不分 BST 直接按位置对半切**：一般二叉树的后序无法只凭自身重建，本题能重建全靠"关键字大小决定左右子树归属"；若按"前 4 个是左子树、后 3 个是右子树"这类位置直觉切，会得到 $15$ 为根的错误树；
3. **$15$、$23$ 的左右孩子方向搞反**：$15>10$ 故必为 $10$ 的右孩子，$23<25$ 故必为 $25$ 的左孩子；写成 $10$ 的左孩子、$25$ 的右孩子会破坏 BST 性质（此时中序不再是升序）；
4. **单支子树只靠“中序升序”定方向**：$10$ 与 $15$ 构成单支，“$10$ 的右孩子 $15$”与“$15$ 的左孩子 $10$”两种树的中序都是 $10,15$（都满足 BST），只能靠后序片段 $15,10$（**末元素为根**）判定 $10$ 是根；同理 $23,25$ 判定 $25$ 是根。写完必须回推一次后序（第 6 节（9））才能排除这类错挂。

## 10. 一句话规律

BST 的任一遍历序列都能重建整棵树：**后序末（或前序首）定根，用"左小右大"切段，递归到底**；重建后一律用"中序是否升序"和"回推原序列"两件事自检。

## 11. 关联知识

- 本题的通用形式是"两种遍历序列确定一棵二叉树"（DS03.02.03）：前序 + 中序、后序 + 中序均可唯一重建，而前序 + 后序不行；本题中"BST 约束"替代了中序的作用（因为中序就是关键字的升序排列）；
- 本卷第 26 题（长度 $9$ 的有序表折半查找 ASL）与本题同属"查找"章，但那是 DS05.04 的判定树；BST 的查找长度依赖树形（最坏退化为单支），两者常在同一份卷中对照出题；
- 若在本题的树上做删除操作（DS05.07.01），删除叶子 $15$、$23$ 最简单，删除含两孩子的 $20$、$30$ 需以中序直接前驱/后继替换——那正是本题树形的下一层考法。
