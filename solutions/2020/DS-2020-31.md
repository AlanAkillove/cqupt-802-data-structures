# DS-2020-31

## 1. 原题

下面这段 $C$ 代码，针对输入的简单算术表达式的后缀表达式，输出其计算结果。例如，输入 `5 2 * 3 3 2 + * +` ，该程序输出 $25$ 。请给出缺失的 5 行代码。

```c
#define EOF -1

void push(int); /* push the argument on the stack */
int pop(void); /* pop the top of the stack */
void flagError();

int main()
{
    int c,m,n,r;
    while((c=getchar())!=EOF)
    {
        if(isdigit(c))
            ___________(1)__________;
        else if((c=='+')||(c=='*'))
        {
            m=___________(2)__________;
            n=___________(3)__________;
            r=(c=='+')?n+m:n*m;
            ___________(4)__________;
        }
        else if(c!=' ')
            flagError();
    }
    printf("%d",___________(5)__________);
}
```

## 2. 答案

| 空 | 填写内容 |
|---|---|
| (1) | `push(c - '0')` |
| (2) | `pop()` |
| (3) | `pop()` |
| (4) | `push(r)` |
| (5) | `pop()` |

## 3. 题目分析

- 已知：后缀表达式（逆波兰式）以字符流形式输入，操作数为**一位十进制数字**，运算符只有 `+`、`*`，分隔符为空格；`push(int)`/`pop(void)` 已实现（栈为全局，接口只给出原型）；
- 目标：补全 5 处语句，使程序正确输出表达式的值；
- 关键约束：只能填语句/表达式，不能改动已有代码框架；`c` 是 `getchar()` 返回的**字符 ASCII 码**；
- 命题意图：考**栈在后缀表达式求值中的应用**——"遇数入栈、遇算符弹两元运算后结果回栈、扫描结束栈顶即答案"这一固定套路，外加"字符转数值"的 C 语言细节。

## 4. 核心考点

核心考点：

辅助考点：

解释：整段程序就是后缀求值算法，属 DS02.07 的经典应用；能填对空的前提是掌握栈的 LIFO 语义（DS02.01）与 `push`/`pop` 的输入输出约定（DS02.02）。

## 5. 解题思路

1. 先复述后缀求值的算法：从左到右扫描，**是操作数就入栈；是运算符就从栈顶弹出两个操作数运算，把结果压回栈**；扫描结束时栈里只剩一个元素，即表达式的值；
2. 用题面样例 `5 2 * 3 3 2 + * +` 手工验证这个套路确实得到 $25$（第 6 节走查表）；
3. 逐空定位：
   - (1) 在 `isdigit(c)` 分支里 → 该把读到的数字入栈；但 `c` 是字符码，`'5'` 的 ASCII 是 $53$，必须 `c-'0'` 才得到数值 $5$，否则样例不可能输出 $25$；
   - (2)(3) 在运算符分支里、且在算 `r` 之前 → 只能是把两个栈顶元素取出，即两次 `pop()`；
   - (4) 算出 `r` 之后 → 结果必须回栈，供后面的运算符使用：`push(r)`；
   - (5) 在 `printf` 里、扫描结束之后 → 输出栈中唯一剩余元素：`pop()`。
4. 检查 `m`、`n` 的弹出顺序是否影响结果：本题只有 `+`、`*`（可交换），故 (2)(3) 谁先谁后不影响数值；但若运算符含 `-`、`/`，"先弹出的是右操作数"，代码写作 `r = n-m` 恰好正确（后弹出的 `n` 在表达式中位置靠前，是左操作数）——这一点可作为"我的理解与出题人一致"的证据。

## 6. 详细解答

**栈状态走查**（输入 `5 2 * 3 3 2 + * +`，栈写作"底 → 顶"）：

| 读入字符 | 动作 | 执行语句 | 栈内容 |
|---|---|---|---|
| `5` | 数字入栈 | (1) `push(5)` | `5` |
| `2` | 数字入栈 | (1) `push(2)` | `5 2` |
| `*` | 弹出两数相乘 | (2)`m=pop()→2`，(3)`n=pop()→5`，`r=5*2=10`，(4)`push(10)` | `10` |
| `3` | 数字入栈 | `push(3)` | `10 3` |
| `3` | 数字入栈 | `push(3)` | `10 3 3` |
| `2` | 数字入栈 | `push(2)` | `10 3 3 2` |
| `+` | 弹出两数相加 | `m=2`，`n=3`，`r=3+2=5`，`push(5)` | `10 3 5` |
| `*` | 弹出两数相乘 | `m=5`，`n=3`，`r=3*5=15`，`push(15)` | `10 15` |
| `+` | 弹出两数相加 | `m=15`，`n=10`，`r=10+15=25`，`push(25)` | `25` |
| EOF | 退出循环 | (5) `printf("%d", pop())` → 输出 **25** ✓ | 空 |

与题面给定的输出 $25$ 完全一致，五空填法成立。

**逐空理由**：

- **(1) `push(c - '0')`**：`getchar()` 返回字符编码，`isdigit(c)` 只保证 `c` 是 `'0'`~`'9'`。要得到 $0$~$9$ 的数值必须减去 `'0'`。若写 `push(c)`，则栈中是 ASCII 码，`5*2` 会变成 `53*50=2650`，样例输出不可能是 $25$——这是用样例反证即可排除的错误填法。
- **(2)(3) `pop()`**：运算符需要两个栈顶操作数，取出后栈变浅，故两空都是 `pop()`。`m` 先弹出（原栈顶，表达式中靠右的操作数），`n` 后弹出（靠左的操作数）。
- **(4) `push(r)`**：部分结果必须回栈，否则后续运算符无操作数可用，且最后栈中不会只剩一个元素。
- **(5) `pop()`**：整个后缀式处理完，栈中恰有一个元素即所求值；`pop()` 兼具"取值"和"退栈"，与 `printf` 需要一个 `int` 实参匹配（若写成 `push`、`r` 均不合语法/语义：`r` 只在运算符分支内有效且末态是 $25$ 的巧合，不可依赖）。

**健壮性说明（非本题必答）**：`flagError()` 处理既非数字、非 `+`/`*`、又非空格的字符；若输入是空串或表达式非法，末态栈空，`pop()` 行为由栈实现决定——原程序未做栈空检查，这不影响五个空的填写。

## 8. 考场标准答案

```c
(1)  push(c - '0');      /* 数字字符转成数值后入栈 */
(2)  m = pop();          /* 先弹出的是右操作数 */
(3)  n = pop();          /* 后弹出的是左操作数 */
(4)  push(r);            /* 部分结果回栈 */
(5)  printf("%d", pop());/* 扫描结束，栈顶（唯一元素）即表达式的值 */
```

一句话原理：**后缀式求值 = 遇数入栈、遇算符弹两元算完回栈、结束取栈顶。**

## 9. 易错点

1. (1) 写成 `push(c)`：漏掉字符到数值的转换（`c-'0'`），这是本题最大的陷阱；
2. (4) 与 (5) 互换：把 `push(r)` 留到最后、把 `pop()` 写进运算符分支，逻辑完全颠倒；
3. 认为 (2)(3) 的先后无所谓所以不检查：本题 `+`/`*` 可交换所以数值无差别，但一旦扩展到 `-`/`/`，必须是"先弹右、后弹左"，`r = n-m` 的写法正说明出题人按此约定；
4. (1) 写成 `push(atoi(c))` 或 `push(c-'0'+1)` 等：`atoi` 需要字符串参数，`c` 是 `int`；
5. 误以为要多位数处理（如 `push(push(c))`、拼数逻辑）：`isdigit` 分支逐字符读入，本题约定操作数为一位数，无需扩展。

## 10. 一句话规律

看到"后缀表达式 + 栈"就默写四步：**数字压栈、符号弹两个、算完压回、最后栈顶是答案**；再注意 C 里 `getchar()` 拿到的是字符码，必须 `-'0'`。
