# DS-2017-31

## 1. 原题

现有森林如下图，请画出对应的二叉树。

![fig5](../../真题/2017/imgs/fig5.png)

图读法（据 fig5）：森林由两棵树组成。$T_1$ 的根为 $A$，$A$ 有三个孩子，自左向右为 $B$、$C$、$D$（三者均为叶子）；$T_2$ 的根为 $F$，$F$ 有一个孩子 $G$。共 $7$ 个结点。

## 2. 答案

按"**左孩子—右兄弟**"规则转换，得到的二叉树为：

```
            A
          /   \
         B     F
          \   /
           C G
            \
             D
```

即：$A$ 是根；$A$ 的**左**孩子 $B$、$A$ 的**右**孩子 $F$；$B$ 的**右**孩子 $C$；$C$ 的**右**孩子 $D$；$F$ 的**左**孩子 $G$；其余指针为空。

## 3. 题目分析

- 已知：森林由 $T_1$、$T_2$ 两棵树组成，$T_1$ 为三度根 $A$（孩子 $B,C,D$），$T_2$ 为 $F$ 带一个孩子 $G$；
- 目标：画出与之一一对应的二叉树（孩子兄弟表示法的树形）；
- 关键约束：转换规则只有两条——结点的**左指针指向它的第一个孩子**，**右指针指向它的下一个兄弟**；森林中第 $2,3,\cdots$ 棵树的根视为第 $1$ 棵树根的"兄弟"，挂在根的右链上；
- 命题意图：考转换规则的两个易混点——"多孩子如何变成二叉"（横向串成右链）与"森林中各树根挂在哪里"（根的右链），而不是照抄图形。

## 4. 核心考点

核心考点：
DS03.03.02 森林与二叉树的转换（左孩子右兄弟的连线规则、森林各根挂到右链）

辅助考点：
DS03.03.01 树的存储结构（孩子兄弟表示法，转换的存储层解释）
DS03.03.03 树和森林的遍历（用"先根↔二叉树前序、后根↔二叉树中序"的对应关系校验作图）

解释：本题不涉计算，全部难度在于按规则逐点连线；而检验画得对不对的最快手段就是遍历序列的对应关系，故把 DS03.03.03 列为辅助考点。

## 5. 解题思路

1. 先处理 $T_1$：$A$ 的孩子 $B,C,D$ 中，第一个孩子 $B$ 挂为 $A$ 的左孩子，$C$ 挂为 $B$ 的右孩子（$B$ 的兄弟），$D$ 挂为 $C$ 的右孩子（$C$ 的兄弟）——兄弟链一律向右下延伸；
2. 再处理 $T_2$：森林中 $T_2$ 的根 $F$ 是 $T_1$ 的根 $A$ 的"右兄弟"，故 $F$ 挂为 $A$ 的**右**孩子；
3. $F$ 的孩子 $G$ 挂为 $F$ 的**左**孩子；
4. 检查结点数（$7$ 个，不增不减）与"根结点的右链长度 = 森林中树的棵数 $-1$"；
5. 用遍历对应关系复核（见第 6 节）。

## 6. 详细解答

**逐结点连线表**

| 结点 | 在森林中的第一孩子 | 在森林中的下一个兄弟 | 二叉树中 lchild | 二叉树中 rchild |
|---|---|---|---|---|
| A | B | F（$T_2$ 的根） | B | F |
| B | 无 | C | 空 | C |
| C | 无 | D | 空 | D |
| D | 无 | 无 | 空 | 空 |
| F | G | 无 | G | 空 |
| G | 无 | 无 | 空 | 空 |

（$A$ 的"下一个兄弟"即森林中排在 $T_1$ 之后的 $T_2$ 的根，这是森林转二叉树与单树转换唯一的差别。）

**得到的二叉树（含空指针说明）**

```
            A
          /   \
        B      F
         \    /
          C  G
           \
            D
```

- $B,C,D$ 构成一条从 $A$ 的左孩子出发、不断向右下延伸的"兄弟链"，$B,C,D$ 都没有左孩子（它们在 $T_1$ 中是叶）；
- $F$ 在 $A$ 的**右**孩子位置，$G$ 在 $F$ 的**左**孩子位置；$F$ 无右孩子（森林中 $T_2$ 是最后一棵树）。

**复核一（结点数与右链长度）**：二叉树结点 $7$ 个 = 森林结点 $7$ 个 ✓；根 $A$ 的右链上只有 $F$ 一个结点，对应"森林共 $2$ 棵树" ✓。

**复核二（遍历序列对应关系）**

- 森林**先根**遍历：$T_1$ 先根 $A,B,C,D$；$T_2$ 先根 $F,G$ → $A\ B\ C\ D\ F\ G$；
- 所画二叉树的**前序**（根左右）：$A$ → 左子树 $B,C,D$ → 右子树 $F,G$ → $A\ B\ C\ D\ F\ G$ ✓ 一致；
- 森林**后根**遍历：$T_1$ 后根 $B,C,D,A$；$T_2$ 后根 $G,F$ → $B\ C\ D\ A\ G\ F$；
- 所画二叉树的**中序**（左根右）：$B$（无左）→ $C\to D$ 得 $B\ C\ D$ → 根 $A$ → $F$ 的左子树 $G$ 再 $F$ 得 $G\ F$ → $B\ C\ D\ A\ G\ F$ ✓ 一致。

两条对应关系同时成立，说明所画二叉树正确（"树/森林的先根↔二叉树前序、后根↔二叉树中序"是孩子兄弟转换的不变性质）。

## 7. 选项分析

不适用（问答题）。

## 8. 考场标准答案

采用"左孩子—右兄弟"规则：每个结点的左指针指向其在树中的第一个孩子，右指针指向其下一个兄弟；森林中后一棵树的根作为前一棵树根的右兄弟。

$$A\!\to\!lchild=B,\ A\!\to\!rchild=F;\quad B\!\to\!rchild=C,\ C\!\to\!rchild=D;\quad F\!\to\!lchild=G$$

```
            A
          /   \
         B     F
          \   /
           C G
            \
             D
```

其余未列出的指针均为空。

## 9. 易错点

1. 把 $F$ 接到 $A$ 的**左**孩子位置（或接到 $D$ 下面）——森林各树根只能挂在根结点的右链上；
2. 把 $B,C,D$ 三兄弟画成一条**左**链（左孩子链表示"父子"，会把 $C$ 变成 $B$ 的孩子）；
3. 把 $G$ 挂成 $F$ 的右孩子（右指针语义是"兄弟"，$G$ 是 $F$ 的孩子）；
4. 误以为转换会改变结点数或新增虚结点——转换只改指针语义，$7$ 个结点一个不多一个不少。

## 10. 一句话规律

森林转二叉树只需记住两句：孩子串成右链、根挂到右链；画完用"先根=前序、后根=中序"两条序列各核一遍，错一处即现形。

## 11. 关联知识

- 本题二叉树中"任一结点右子树为空 ⟺ 它在森林中无右兄弟"，正是 DS-2024-12（"对应二叉树中右子树为空的结点个数"）的判据来源；
- 逆向转换（二叉树 → 森林）：沿根的右链拆开各棵树，每个结点的左链拆开其孩子；树的孩子兄弟表示法与二叉链表存储形式完全相同，只是指针语义不同（DS03.03.01）。
- 树的三种存储结构（双亲/孩子/孩子兄弟）见 DS03.03.01，只有孩子兄弟表示法能与二叉树一一对应。
