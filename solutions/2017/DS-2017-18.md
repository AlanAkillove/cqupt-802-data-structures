# DS-2017-18

## 1. 原题

若用一个大小为 $6$ 的数组来实现循环队列，且当前 $rear$ 和 $front$ 的值分别为 $0$ 和 $3$。当从队列删除两个元素，再加入一个元素后，$rear$ 和 $front$ 的值分别为（）。

A. $1$ 和 $5$

B. $2$ 和 $4$

C. $4$ 和 $2$

D. $5$ 和 $1$

## 2. 答案

**A**（$rear=1$，$front=5$）

## 3. 题目分析

- 已知：数组容量 $M=6$；初始 $rear=0$、$front=3$；操作序列 = 出队、出队、入队；
- 目标：求操作后的 $rear$ 与 $front$（注意题目问的顺序是**先 rear 后 front**）；
- 关键约束：采用严蔚敏教材的循环队列约定——$front$ 指向**队头元素**，$rear$ 指向**队尾元素的下一个位置**；两个指针都只沿下标增大方向移动并对 $M$ 取模；
- 命题意图：考循环队列的两个指针各自随什么操作移动、如何取模，并用“先删后加”的混合作用检验是否真会按公式演算，而不是背“队头队尾”的直观印象。

## 4. 核心考点

核心考点：
DS02.02 栈和队列的顺序存储结构（循环队列的指针移动公式 `rear=(rear+1)%M`、`front=(front+1)%M`，以及队满队空的判定口径）

解释：本题不需要概念辨析，只需要把教材 EnQueue/DeQueue 里的两条赋值语句按顺序执行，并用"队列长度 $=(rear-front+M)\%M$"这一同一节内的公式做闭环校验，全部落在 DS02.02 之内，故不设辅助考点。

## 5. 解题思路

1. 明确约定：入队"先存元素再动 $rear$"，出队"先取元素再动 $front$"，两者都是 $+1$ 后 $\%\,M$；
2. 按操作顺序逐步更新：$front$ 动两次、$rear$ 动一次，中间结果也要取模（先删后加与先加后删结果相同，但按题目顺序算最稳）；
3. 用元素个数校验：初始 $(0-3+6)\%6=3$ 个，操作后应为 $3-2+1=2$ 个，检查 $(rear-front+6)\%6$ 是否等于 2；
4. 顺手确认过程不越界：容量 6 的循环队列最多存 $5$ 个元素，本题元素数始终 $\le 3$，不会触发队满，操作合法。

## 6. 详细解答

$M=6$，$front$ 指队头元素，$rear$ 指队尾元素的下一位置。

**初始**：$rear=0,\ front=3$，队列长度 $=(0-3+6)\%6=3$（占用的下标为 $3,4,5$）。

**第 1 次删除**：$front=(3+1)\%6=4$，长度 $2$；
**第 2 次删除**：$front=(4+1)\%6=5$，长度 $1$；
**再加入一个元素**：$Q.rear=0$ 处写入新元素后 $rear=(0+1)\%6=1$，长度 $2$。

结果：$rear=1$，$front=5$。

**校验一（元素个数守恒）**：

$$(rear-front+M)\%M=(1-5+6)\%6=2$$

与"原 3 个 $-\,2$ 个 $+\,1$ 个 $=2$ 个"一致 ✓

**校验二（占用位置直观核对）**：初始占用下标 $3,4,5$；两次出队后只剩 $5$；入队写在下标 $0$（原 $rear$ 处），$rear$ 移到 $1$ ⇒ 队列元素位于下标 $5$ 和 $0$，$front=5$、$rear=1$，正是"回绕"后的形态 ✓

**校验三（合法性）**：队满条件是 $(rear+1)\%M==front$。终态 $(1+1)\%6=2\ne 5$，未队满；过程中元素数最多 3，远小于容量上限 $M-1=5$，删除时长度也从未为 0（$3\to2\to1$），不会队空出错 ⇒ 操作全程合法 ✓

## 7. 选项分析

- A：正确。$rear=(0+1)\%6=1$、$front=(3+2)\%6=5$；
- B（$2$ 和 $4$）：错。把两次"删除"记到了 $rear$ 上、一次"加入"记到了 $front$ 上，即两个指针的动作互换：$(0+2)\%6=2$、$(3+1)\%6=4$。$rear$ 只随入队变化、$front$ 只随出队变化，不可混用；
- C（$4$ 和 $2$）：错。把指针移动方向搞反（以为出队让指针减、入队让指针也往回走）：$(0-2+6)\%6=4$、$(3-1+6)\%6=2$。循环队列两个指针**同向**移动，这是它与"双端队列"的区别；
- D（$5$ 和 $1$）：错。数值都算对了，但把作答顺序按 $front$、$rear$ 排列，与题目"问 $rear$ 和 $front$ 分别为"颠倒——本题最主要的失分陷阱。

## 8. 考场标准答案

循环队列指针公式（$M=6$）：入队 $rear=(rear+1)\%M$，出队 $front=(front+1)\%M$。

$$rear=(0+1)\%6=1,\qquad front=(3+1)\%6=4\to(4+1)\%6=5$$

校验：$(rear-front+M)\%M=(1-5+6)\%6=2=3-2+1$ ✓

故 $rear=1$、$front=5$，选 **A**。

## 9. 易错点

1. 审题顺序：题目先问 $rear$ 再问 $front$，选 D 即栽在这里；
2. 忘记取模回绕，写成 $front=3+2=5$（本题恰好一致）而 $rear=0+1=1$（也一致），因此本题不取模也对——但若初始 $rear=5$ 就必须回绕，平时练习要养成"$+1$ 立刻 $\%\,M$"的习惯；
3. 混淆"数组容量 $M$"与"最多可存元素数 $M-1$"（本约定下牺牲一个单元区分队空与队满），据此误判操作非法；
4. 若采用"增设 size 变量"或"牺牲单元以外"的约定，$rear$ 的初值含义会不同；本题按教材约定即可，不必自创口径。

## 10. 一句话规律

循环队列只有两条公式要记：$rear$ 随入队走、$front$ 随出队走，都是 $+1$ 后 $\%\,M$；算完必用 $(rear-front+M)\%M$ 核对元素个数是否等于"原有个数 $-$ 删 $+$ 加"。

## 11. 关联知识

- 本卷第 4 题（判循环队列队满的条件 $Q.front==(Q.rear+1)\%m$，见 DS-2017-04）与本题同属 DS02.02，一考判定条件、一考指针演算；
- 若队列采用链式存储（链队），则不存在"容量"与回绕问题（DS02.03）；
- 共享栈/多队列共用数组时会改变取模的模数，本题是单队列独占 $M=6$。
