# DS-2017-29

## 1. 原题

某表达式二叉树按后序遍历的结果为 `a,b,c,d,-,*,+,e,f,/,-` ，令 $a=6,b=3,c=4,d=2,e=5,f=1$ ，则该表达式的值等于____________________ 。

> 订正说明转录：源文题后原有编者批注"题目已修改为后序，原为先序"，属修订备注而非题面，已删除；本题按干净题面（后序遍历结果）处理。

## 2. 答案

$7$（对应表达式 $a+b*(c-d)-e/f$）

## 3. 题目分析

- 已知：表达式二叉树的后序遍历序列共 $11$ 个符号：$6$ 个操作数 $a,b,c,d,e,f$ 与 $5$ 个运算符 $-,\ *,\ +,\ /,\ -$；各字母取值 $a=6,b=3,c=4,d=2,e=5,f=1$；
- 目标：求该表达式的值；
- 关键约束：表达式二叉树中**叶结点必为操作数、非叶结点必为运算符**，且每个运算符结点恰有两个孩子（二元运算），因此后序序列可以**唯一**还原出这棵树；
- 命题意图：把"由遍历序列还原二叉树"与"逆波兰（后序）表达式求值"两件事压进一道填空，考的是栈式扫描（或建树）而不是把符号串硬当普通算式读。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（后序"左-右-根"，由后序序列唯一确定表达式二叉树）

辅助考点：
DS02.07 栈、队列和数组的应用（表达式求值：后序序列即逆波兰式，用栈自左向右扫描）
DS03.02.02 二叉树的存储结构（表达式二叉树的结点形态：叶=操作数，枝=运算符）

解释：后序遍历表达式树得到的正是逆波兰式，"遇到运算符就弹出两个操作数计算"是 DS02.07 的经典应用；而"由符号串还原树形"则回到 DS03.02.03 的由序列定树。

## 5. 解题思路

1. 判类型：序列是后序 ⟹ 每个运算符出现在它的两棵子树之后；
2. 方法一（栈模拟，推荐考场速算）：自左向右扫描，操作数入栈，运算符则弹出**栈顶两个**（先弹出的是右操作数）计算后把结果压回；
3. 方法二（建树后中序读式）：按同样规则反向建树，写出中序表达式 $a+b*(c-d)-e/f$，再按常规优先级代入求值；
4. 两法结果比对，确认 $7$。

## 6. 详细解答

**方法一：栈式扫描（逆波兰求值）**

记号：栈自左向右书写，左端为栈底。

| 读入符号 | 动作 | 栈内内容（底→顶） |
|---|---|---|
| $a$ | 入栈 | $6$ |
| $b$ | 入栈 | $6,3$ |
| $c$ | 入栈 | $6,3,4$ |
| $d$ | 入栈 | $6,3,4,2$ |
| $-$ | 弹出 $2,4$：$4-2=2$ | $6,3,2$ |
| $*$ | 弹出 $2,3$：$3\times2=6$ | $6,6$ |
| $+$ | 弹出 $6,6$：$6+6=12$ | $12$ |
| $e$ | 入栈 | $12,5$ |
| $f$ | 入栈 | $12,5,1$ |
| $/$ | 弹出 $1,5$：$5/1=5$ | $12,5$ |
| $-$ | 弹出 $5,12$：$12-5=7$ | $7$ |

扫描结束栈中唯一元素 $7$ 即为表达式的值。

**方法二：还原表达式二叉树**

后序"左子树、右子树、根"，从右端可知整棵树根结点是最后一个符号 `-`。按栈式建树（操作数→叶结点；运算符→弹出其右、左两棵子树挂上）得到：

```
                (-)
             /       \
          (+)         (/)
         /   \       /   \
      (a)   (*)    (e)   (f)
           /   \
        (b)   (-)
             /   \
           (c)   (d)
```

中序读取（加括号还原优先级）：$a + (b * (c - d)) - (e / f)$。

代入 $a=6,b=3,c=4,d=2,e=5,f=1$：

$$6 + 3\times(4-2) - 5/1 = 6 + 3\times 2 - 5 = 6+6-5 = 7\quad\checkmark$$

**一致性检查**：$6$ 个操作数、$5$ 个运算符共 $11$ 个结点，$n_0=6,\ n_2=5$ 满足 $n_0=n_2+1$ ✓（说明还原出的确是一棵合法的二叉表达式树，无多余或缺失符号）。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

后序序列即逆波兰式，自左向右扫描、遇运算符弹两数（先弹为右操作数）计算后压回：

$c-d=4-2=2,\quad b*2=3\times 2=6,\quad a+6=6+6=12,\quad e/f=5/1=5,\quad 12-5=\boxed{7}$

## 9. 易错点

1. 弹出顺序弄反：减、除不满足交换律，**先弹出的是右操作数、后弹出的是左操作数**；本题 $c-d$ 若误算成 $2-4=-2$，最终得 $6+3\times(-2)-5=-5$；
2. 把后序串直接当普通算式读成 $a-b*c+d-e/f$ 之类（必须先建树或用栈）；
3. 扫描时漏掉最后一个运算符（它是整棵树的根），结果停在 $12$ 或 $5$ 上——收尾必须把栈扫到只剩一个元素；
4. 若源文旧版（先序）残留，按先序建树会得到不同表达式——本题题面已明确为**后序**，按后序处理即可。

## 10. 一句话规律

表达式树 + 后序序列 = 逆波兰式：用"操作数入栈、运算符弹两数（先弹为右）"一表扫到底；要写表达式就还原树后中序读，并用 $n_0=n_2+1$ 自查符号个数是否配平。

## 11. 关联知识

- 同一棵树的中序遍历加括号即原算术表达式，先序遍历即波兰式（前缀），三者与本卷 DS-2017-24（由先序+中序求后序）构成"遍历序列互推"题族；
- 表达式求值的栈实现见 DS02.07（运算符栈/操作数栈的算界优先法），与本题"后序序列直接求值"是同一思想的两种形态；
