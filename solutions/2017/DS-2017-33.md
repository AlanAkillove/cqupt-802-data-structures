# DS-2017-33

## 1. 原题

设一个无向网 $G$ 的邻接矩阵 $A$ 如下：

（1）请根据给定的邻接矩阵 $A$ 画出网 $G$ 的图（$G$ 中顶点用 $v_i$ 表示）；

（2）如果对某个顶点的邻接点的访问顺序按序号从小到大排列，请写出从顶点 $v_1$ 出发，按"深度优先"和"广度优先"搜索方法遍历网 $G$ 所得到的顶点序列；

（3）从顶点 $v_1$ 出发，按照最小生成树的 $Prim$ 算法，画出网 $G$ 的一棵最小生成树。

![fig6](../../真题/2017/imgs/fig6.png)

矩阵读法（$A[i][j]$ 为边 $v_iv_j$ 的权，$\infty$ 表示无边，对角线为 $\infty$ 即无自环）：

$$
A=\begin{bmatrix}
\infty&\infty&4&2&\infty&\infty&\infty&\infty\\
\infty&\infty&\infty&\infty&1&7&\infty&\infty\\
4&\infty&\infty&\infty&\infty&\infty&6&\infty\\
2&\infty&\infty&\infty&3&\infty&5&\infty\\
\infty&1&\infty&3&\infty&\infty&\infty&8\\
\infty&7&\infty&\infty&\infty&\infty&\infty&9\\
\infty&\infty&6&5&\infty&\infty&\infty&\infty\\
\infty&\infty&\infty&\infty&8&9&\infty&\infty
\end{bmatrix}
$$

## 2. 答案

**(1)** $G$ 有 $8$ 个顶点、$9$ 条边：

$$v_1v_3(4),\ v_1v_4(2),\ v_2v_5(1),\ v_2v_6(7),\ v_3v_7(6),\ v_4v_5(3),\ v_4v_7(5),\ v_5v_8(8),\ v_6v_8(9)$$

**(2)** 从 $v_1$ 出发、邻接点按序号从小到大访问：

- DFS 序列：$v_1,\ v_3,\ v_7,\ v_4,\ v_5,\ v_2,\ v_6,\ v_8$
- BFS 序列：$v_1,\ v_3,\ v_4,\ v_7,\ v_5,\ v_2,\ v_8,\ v_6$

**(3)** Prim 生成树（按加入顺序）：

$$v_1v_4(2)\to v_4v_5(3)\to v_5v_2(1)\to v_1v_3(4)\to v_4v_7(5)\to v_2v_6(7)\to v_5v_8(8)$$

总代价 $2+3+1+4+5+7+8=30$。

## 3. 题目分析

- 已知：$8\times8$ 对称邻接矩阵（无向网），$\infty$ 表示无边；
- 目标：(1) 由矩阵还原带权图；(2) 在"邻接点按序号升序"这一确定性约定下写出 DFS、BFS 序列；(3) 以 $v_1$ 为起点执行 Prim 并画出生成树；
- 关键约束：三问共用同一份"邻接表"（每顶点的邻接点按序号升序排好），第 (2)(3) 问的确定性都来自这个约定；
- 命题意图：一道"图的四件套"综合题——读矩阵、画图、遍历、求最小生成树，考查邻接矩阵到逻辑结构的转换以及两种遍历（栈式深探 vs 队列式逐层）的机制差别，并要求 Prim 的"跨割最小边"选择过程规范成表。

## 4. 核心考点

核心考点：
DS04.02.01 邻接矩阵法（对称矩阵 → 边集；$\infty$ 的语义；由矩阵写出各顶点升序邻接表）

辅助考点：
DS04.03.01 深度优先搜索（回溯机制、序列唯一化约定）
DS04.03.02 广度优先搜索（逐层扩展、队列顺序决定序列）
DS04.04.01 最小（代价）生成树（Prim 的候选边集 $U$–$V\setminus U$ 逐步取最小）

解释：三问的公共前置是"把矩阵翻译成升序邻接表"，这一步错则后面全错；遍历与 Prim 则分别考"访问顺序"与"选边规则"两套不同的贪心。

## 5. 解题思路

1. 先把矩阵上三角的非 $\infty$ 元素逐个抄成边表（对称性可自查：$A[i][j]=A[j][i]$），得到 $9$ 条边；
2. 按顶点整理出升序邻接表（同时带上边权，供第 (3) 问用）；
3. DFS：模拟"取当前顶点升序邻接表中第一个未访问者深入，无路可走则回溯"，逐步记录访问栈；
4. BFS：模拟队列，逐层把未访问邻接点按升序入队，出队顺序即序列；
5. Prim：维护已选顶点集 $U$（初始 $\{v_1\}$），每轮在"一端在 $U$ 内、一端在 $U$ 外"的所有边中取权最小者，把对应顶点并入 $U$，重复 $7$ 轮；
6. 用 Kruskal（全局按权升序选无环边）独立复核第 (3) 问的边集与总代价。

## 6. 详细解答

### (1) 由邻接矩阵画出网 G

上三角非 $\infty$ 元素即边集（共 $9$ 条），据此画出 $8$ 个顶点与 $9$ 条带权边。按矩阵连通性检查：每个顶点的度为 $\deg(v_1)=2,\deg(v_2)=2,\deg(v_3)=2,\deg(v_4)=3,\deg(v_5)=3,\deg(v_6)=2,\deg(v_7)=2,\deg(v_8)=2$，和为 $18=2\times9$ ✓（握手定理校验读图无误）。

一种与矩阵吻合的画法（拓扑关系为准，几何位置可任意；权值标在边旁）：

```
   四边形环：   v3 ——6—— v7
               |         |
               4         5
               |         |
              v1 ——2——  v4

   挂链与三角： v4 ——3—— v5 ——1—— v2 ——7—— v6
                        \                /
                     8   \              /   9
                          ——   v8   ——
```

即图中存在环 $v_1\!-\!v_3\!-\!v_7\!-\!v_4\!-\!v_1$（边权依次 $4,6,5,2$），另有 $v_4\!-\!v_5$、$v_5\!-\!v_2$、$v_2\!-\!v_6$，以及 $v_5\!-\!v_8(8)$、$v_6\!-\!v_8(9)$（$v_5,v_6,v_8$ 构成三角形）。

为避免 ASCII 图的方位歧义，**以邻接表为权威描述**（第 (2)(3) 问均据此计算）：

| 顶点 | 升序邻接点（边权） |
|---|---|
| v1 | v3(4), v4(2) |
| v2 | v5(1), v6(7) |
| v3 | v1(4), v7(6) |
| v4 | v1(2), v5(3), v7(5) |
| v5 | v2(1), v4(3), v8(8) |
| v6 | v2(7), v8(9) |
| v7 | v3(6), v4(5) |
| v8 | v5(8), v6(9) |

考场作图建议：把 $v_1,v_3,v_7,v_4$ 画成一个四边形（$v_1v_3$、$v_3v_7$、$v_7v_4$、$v_4v_1$），$v_5$ 挂在 $v_4$ 下方、$v_2$ 挂在 $v_5$ 右侧、$v_6$ 挂在 $v_2$ 上方、$v_8$ 挂在 $v_5$ 与 $v_6$ 之间，各边标注上表权值即可。

### (2) 从 v1 出发的 DFS 与 BFS 序列

**DFS（邻接点升序）**

| 步骤 | 当前顶点 | 动作 | 已访问集合 |
|---|---|---|---|
| 1 | v1 | 访问 v1；升序邻接点 v3 未访问 → 深入 | {v1} |
| 2 | v3 | v1 已访问、v7 未访问 → 深入 v7 | {v1,v3} |
| 3 | v7 | 邻接点 v3 已访问、v4 未访问 → 深入 v4 | {v1,v3,v7} |
| 4 | v4 | 升序检查：v1(已)、v5(未) → 深入 v5 | {v1,v3,v7,v4} |
| 5 | v5 | 升序检查：v2(未) → 深入 v2 | +v5 |
| 6 | v2 | 邻接点 v5(已)、v6(未) → 深入 v6 | +v2 |
| 7 | v6 | 邻接点 v2(已)、v8(未) → 深入 v8 | +v6 |
| 8 | v8 | 邻接点 v5(已)、v6(已) → 回溯 v6→v2→v5 | +v8 |
| 9 | — | v5 余下邻接点 v4(已)、v8(已)；v4、v7、v3、v1 的邻接点（v4 的 v7、v1 的 v4）均已访问 → 结束 | 8 个 |

$$\text{DFS}: \boxed{v_1,\ v_3,\ v_7,\ v_4,\ v_5,\ v_2,\ v_6,\ v_8}$$

注意第 3、4 步：DFS 从 $v_7$ 又回到了序号更小的 $v_4$，所以 $v_4$ 出现在 $v_7$ **之后**，这是本题最容易被"想当然按层写"写错的地方。

**BFS（邻接点升序，队列模拟）**

| 轮 | 出队 | 新入队（升序） | 队列（front→rear） | 访问序列 |
|---|---|---|---|---|
| 0 | — | v1 | v1 | v1 |
| 1 | v1 | v3, v4 | v3 v4 | v1 v3 v4 |
| 2 | v3 | v7（v1 已访问） | v4 v7 | + v7 |
| 3 | v4 | v5（v1、v7 已访问） | v7 v5 | + v5 |
| 4 | v7 | 无（v3、v4 已访问） | v5 | — |
| 5 | v5 | v2, v8（v4 已访问） | v2 v8 | + v2 v8 |
| 6 | v2 | v6（v5 已访问） | v8 v6 | + v6 |
| 7 | v8 | 无（v5、v6 已访问） | v6 | — |
| 8 | v6 | 无 | 空 | 结束 |

$$\text{BFS}: \boxed{v_1,\ v_3,\ v_4,\ v_7,\ v_5,\ v_2,\ v_8,\ v_6}$$

（第 5 轮 $v_5$ 一次入队 $v_2,v_8$，故 $v_8$ 排在 $v_6$ 之前：$v_6$ 是 $v_8$ 之后才出队的 $v_2$ 的孩子，属下一层。）

### (3) 从 v1 出发的 Prim 算法

记 $U$ 为已并入生成树的顶点集，每轮在"两端分居 $U$ 与 $V\setminus U$"的边中取权最小者。

| 轮 | $U$（选前） | 跨割候选边（权） | 选中边 | 新顶点 |
|---|---|---|---|---|
| 1 | {v1} | v1–v3(4), v1–v4(2) | **v1–v4 (2)** | v4 |
| 2 | {v1,v4} | v1–v3(4), v4–v5(3), v4–v7(5) | **v4–v5 (3)** | v5 |
| 3 | {v1,v4,v5} | v1–v3(4), v4–v7(5), v5–v2(1), v5–v8(8) | **v5–v2 (1)** | v2 |
| 4 | {v1,v4,v5,v2} | v1–v3(4), v4–v7(5), v5–v8(8), v2–v6(7) | **v1–v3 (4)** | v3 |
| 5 | +v3 | v3–v7(6), v4–v7(5), v5–v8(8), v2–v6(7) | **v4–v7 (5)** | v7 |
| 6 | +v7 | v5–v8(8), v2–v6(7) | **v2–v6 (7)** | v6 |
| 7 | +v6 | v5–v8(8), v6–v8(9) | **v5–v8 (8)** | v8 |

$$\text{边集}=\{v_1v_4,\ v_4v_5,\ v_2v_5,\ v_1v_3,\ v_4v_7,\ v_2v_6,\ v_5v_8\},\quad \text{代价}=2+3+1+4+5+7+8=\boxed{30}$$

生成的树形（$7$ 条边连接 $8$ 个顶点，无回路 ✓）：

```
              v1
             /  \
           v3    v4
                /  \
              v5    v7
             /  \
           v2    v8
            \
             v6
```

连边关系：$v_1\!-\!v_3$、$v_1\!-\!v_4$、$v_4\!-\!v_5$、$v_4\!-\!v_7$、$v_5\!-\!v_2$、$v_5\!-\!v_8$、$v_2\!-\!v_6$。

**Kruskal 复核**：全部边按权升序 $v_2v_5(1),v_1v_4(2),v_4v_5(3),v_1v_3(4),v_4v_7(5),v_3v_7(6),v_2v_6(7),v_5v_8(8),v_6v_8(9)$，依次取不构成回路的边：取 $1,2,3,4,5$，跳过 $v_3v_7(6)$（$v_3,v_7$ 已连通），取 $7,8$，$v_6v_8(9)$ 成环舍去 —— 得同一边集，代价同为 $30$ ✓ 两法一致，说明该生成树确为最小。

## 7. 选项分析

不适用（问答题）。

## 8. 考场标准答案

**(1)** 由矩阵上三角读出 $9$ 条边：$v_1v_3(4),v_1v_4(2),v_2v_5(1),v_2v_6(7),v_3v_7(6),v_4v_5(3),v_4v_7(5),v_5v_8(8),v_6v_8(9)$，据此画 $8$ 顶点带权无向图（各顶点升邻接表见第 6 节表）。

**(2)** 邻接点按序号升序访问：

$$\text{DFS}:\ v_1\,v_3\,v_7\,v_4\,v_5\,v_2\,v_6\,v_8\qquad \text{BFS}:\ v_1\,v_3\,v_4\,v_7\,v_5\,v_2\,v_8\,v_6$$

**(3)** Prim 逐轮选边（$U$ 初为 $\{v_1\}$）：$v_1v_4(2)\to v_4v_5(3)\to v_5v_2(1)\to v_1v_3(4)\to v_4v_7(5)\to v_2v_6(7)\to v_5v_8(8)$，共 $7$ 条边，最小生成树代价 $30$。

## 9. 易错点

1. 读矩阵时把 $\infty$ 当 $0$ 边、或只读上三角漏边、或误以为对角线上的 $\infty$ 是"自环"（这里表示无自环）；
2. DFS 写成 BFS 的样子（$v_1v_3v_4v_7\cdots$）：DFS 是一条路走到底再回溯，本题 $v_7$ 会回溯到 $v_4$，故 $v_4$ 在 $v_7$ 之后；
3. 忘记"邻接点按序号升序"的约定，自行选择邻接顺序（那样序列不唯一，本题明确要求唯一序列）；
4. BFS 中把 $v_8$ 与 $v_6$ 顺序写反：$v_8$ 由 $v_5$ 入队、$v_6$ 由 $v_2$ 入队，$v_5$ 早于 $v_2$ 出队，故 $v_8$ 在前；
5. Prim 选边时把"全图最小边"当成候选（那是 Kruskal 的规则）：Prim 只能在**一端已入树**的边里选最小，例如第 1 轮不能选 $v_2v_5(1)$；
6. 第 5 轮 $v_7$ 可由 $v_4(5)$ 或 $v_3(6)$ 接入，必须选 $5$；写成 $v_3v_7(6)$ 则代价变 $31$，非最小。

## 10. 一句话规律

邻接矩阵综合题第一步永远是"抄成升序邻接表"：遍历题按表模拟栈/队列，Prim 题按表维护"跨割候选边"并每轮取最小，最后用 Kruskal 独立核一遍代价。
