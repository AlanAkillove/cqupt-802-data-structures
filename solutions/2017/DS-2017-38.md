## 2. 答案

**算法思想（头插法）**：把头结点 $L$ 与数据链拆开看待——先把 $L\to next$ 置为 $\text{NULL}$，使"逆置后的新表"以头结点为空表起步；然后反复从原表上摘下第一个结点 $p$（摘前必须先用 $q$ 保存 $p\to next$，否则断链找不到后继），把它**头插**到 $L$ 之后。原表结点逐个搬空，新表就是原表的逆序。全程只改指针域，不新建也不释放任何结点，故为**就地**。

```c
void InverseList(LinkList L)         /* L 为带头结点的单链表的头结点指针 */
{
    ListNode *p = L->next, *q;       /* p: 原表尚未处理的第一个结点 */
    L->next = NULL;                  /* 逆置结果表以头结点 + 空表起步 */
    while (p != NULL) {
        q = p->next;                 /* ① 先保存后继，②之后原链已断 */
        p->next = L->next;           /* ② 待插结点指向当前表头结点的首元 */
        L->next = p;                 /* ③ 头结点改指它（头插） */
        p = q;                       /* ④ 推进到下一个原结点 */
    }
}
```

**复杂度**：时间 $O(n)$（每个结点恰好处理一次，做常数次指针修改）；附加空间 $O(1)$（仅 $p$、$q$ 两个指针变量，结点个数不变，无辅助数组或新结点）——满足"就地"要求。

## 3. 题目分析

- **输入**：带头结点的单链表，头结点指针 `L`，数据结点自 `L->next` 起，结点类型为题面给定的 `ListNode`（`int data` + `next`），`LinkList` 是同一类型的指针别名；
- **输出**：同一条链表，数据结点次序完全颠倒；头结点仍是**原来那个头结点**（`L` 的值不变，无需返回新头指针，故函数可写成 `void`）；
- **约束**："就地" ⟹ 不得 `malloc` 新结点重新串一遍，也不得把 `data` 抄进数组再抄回来（后者既非指针操作训练，也需 $O(n)$ 辅助空间）；结点的 `data` 与结点总数全程不变，唯一可改的是 `next` 域；
- **数据结构选择**：保持单链表（不能借双向链表或顺序表代劳）；
- **核心不变量**：每轮开始时，`L` 之后是"已逆置部分"（原表前若干结点按逆序排列），`p` 指向"尚未处理部分"的原表头，两段之间已断开且由 `q` 保管着衔接边；
- **命题意图**：单链表指针操作最典型的"批量反转"，唯一的技巧点是**先保存后继再改指针**；带不带 `data` 头结点决定了返回值与初始化的写法，题面特意点明"带头结点"。

## 4. 核心考点

核心考点：

辅助考点：

解释：主考点是单链表的指针改造；"逆置后仍是同一线性表、仅次序相反"属 DS01.01 的逻辑视图；而"头插法生成的表与插入次序相反"正是本章建表算法的固有性质，本题就是把它用到极致。

## 5. 解题思路

1. 先明确"就地"只能用指针：每个结点仅一个 `next`，所以逆置 $=$ 对每个数据结点做一次 `next` 重定向；
2. 识别风险：一旦把 $p\to next$ 改成指向前驱（或头结点之后的当前首元），就再也找不到 $p$ 的后继 ⟹ **必须先 `q = p->next`**（本题全部易错点由此引出）；
3. 选实现路线（两条都对，考场上任选其一并写清思想）：
   - **路线 A（头插法，本题首选）**：借用头结点，`L->next = NULL` 起空表，原结点逐个头插 —— 因为"头插法建表"的结果本就与插入次序相反，天然得到逆置表，且头结点位置不变，函数可写成 `void`；
   - **路线 B（三指针反向挂）**：对 `L->next` 起的数据链做"保存后继 → 反向指 → 双指针后移"，用 `pre = NULL` 收尾，最后 `L->next = pre`；
4. 边界自查三例：空表（`L->next == NULL`）、仅一个结点、两个结点；另需说明 `L == NULL`（连头结点都没有）时本算法不应调用；
5. 验算：对结果再执行一次同一算法应还原为原表（**对合性**）；或反向核对头插顺序表，看第 $k$ 轮后新表是否为原表前 $k$ 个结点的逆序。

## 6. 详细解答

### 主解：头插法（教材风格 C，使用题面给定的 `ListNode` / `LinkList`）

```c
/* 已知 L 是带头结点的单链表的头结点指针，本算法将其逆置，原地完成 */
void InverseList(LinkList L)
{
    ListNode *p, *q;
    if (L == NULL) return;           /* 不带头结点的情形无定义，仅作健壮性 */
    p = L->next;                     /* p 指向原表的第一个数据结点 */
    L->next = NULL;                  /* 新表(逆置结果)先做成空表 */
    while (p != NULL) {              /* 原表未搬空则继续 */
        q = p->next;                 /* ① 保存 p 的后继，防止②③后断链 */
        p->next = L->next;           /* ② 把 p 的 next 指向当前新表首元结点 */
        L->next = p;                 /* ③ 头结点后继改为 p，p 成为新的首元 */
        p = q;                       /* ④ p 推进到原表的下一个结点 */
    }
}
```

**逐轮走查**（$n=4$，原表 $H\to a\to b\to c\to d\to\text{NULL}$，$H$ 即 `L`）：

| 轮 | 进入时 `p` | ① `q` | ②③ 后新表 | 轮末 `p` |
|---|---|---|---|---|
| 1 | a | b | $H\to a\to\text{NULL}$ | b |
| 2 | b | c | $H\to b\to a\to\text{NULL}$ | c |
| 3 | c | d | $H\to c\to b\to a\to\text{NULL}$ | d |
| 4 | d | NULL | $H\to d\to c\to b\to a\to\text{NULL}$ | NULL |

`p == NULL` 退出，数据链为 $d\to c\to b\to a$ ✓ 与原表完全相反，头结点 $H$ 未变、仍是 $L$。

**正确性论证**：

- **不变式**：第 $k$ 轮结束时，$L\to next$ 之后恰为原表前 $k$ 个结点的**逆序**串，且第 $k+1$ 个结点由 `p` 指住、其后原序未动；归纳基础 $k=0$（空表）成立，归纳步由 ①②③ 把 `p`（即原第 $k+1$ 个）插到段首而保持；
- **不丢结点**：每轮只改 `p->next` 一个指针域，改前已由 `q` 保存；全程无 `malloc`/`free`，结点数 $n$ 守恒，`data` 序列的元素多重集不变；
- **终止性**：每轮 `p` 严格后移一个结点，$n$ 轮后 `p == NULL` 退出；
- **新表尾正确**：最后一个被插的是原表首元 $a$，它被插后 `p = NULL` 使 $a\to next = \text{NULL}$（第 1 轮时 `L->next` 为 `NULL`），故新表尾恰为 $a$ 且正确以 `NULL` 结束——无需额外的"补 `NULL`"语句，这是本写法容易被质疑之处，走查表第 1 轮已验证。

**边界情况**

| 情形 | 执行过程 | 结果 |
|---|---|---|
| 空表（`L->next == NULL`） | `p = NULL`，循环不执行 | 仍为空表 ✓ |
| 仅 1 个结点 | 一轮：`q=NULL`、$p$ 插回 $L$ 后 | 表不变 ✓ |
| 2 个结点 | 两轮 | $b\to a$ ✓ |
| `L == NULL`（无头结点） | 算法前提不成立 | 题面已声明带头结点；代码首行判空仅为健壮性 |

**验算（对合性）**：对逆置结果再次调用 `InverseList`，按同一走查应还原为 $a\to b\to c\to d$ ✓（头插两次即"逆序的逆序"）。另可用"结点地址守恒"核验：算法结束时的 4 个数据结点与原表是同一批结点，仅 `next` 变了。

### 备选解：三指针反向挂（不依赖头结点的写法，同样原地）

```c
void InverseList2(LinkList L)        /* 对 L->next 起的数据链做指针反向 */
{
    ListNode *pre = L->next, *cur, *q;
    if (pre == NULL) return;         /* 空表 */
    cur = pre->next;
    pre->next = NULL;                /* 原首元逆置后成为新表尾 */
    while (cur != NULL) {
        q = cur->next;               /* 保存后继 */
        cur->next = pre;             /* 当前结点反向指向前驱 */
        pre = cur;                   /* 已处理段表头前移 */
        cur = q;                     /* 待处理段表头前移 */
    }
    L->next = pre;                   /* 原表尾成为新首元，接回头结点 */
}
```

两法对同一走查表给出相同结果，互为交叉验证；主解把"已处理段"记在头结点之后，天然省掉最后的"接回"语句，与"带头结点"的题设更贴合，故作为主答案。

### 复杂度分析

| 量 | 主解（头插法） | 备选解（三指针） |
|---|---|---|
| 结点访问次数 | $n$（每个一次） | $n$（每个一次） |
| 指针修改次数 | $2n$（`p->next` 与 `L->next` 各一次/轮） | $n+1$ |
| 时间复杂度 | $O(n)$ | $O(n)$ |
| 附加空间 | $O(1)$（`p`、`q` 两个指针变量） | $O(1)$（三个指针变量） |
| 是否就地 | 是（无结点增删，`data` 未搬动） | 是 |

## 8. 考场标准答案

**(1) 算法思想**：逆置后结点仍是原来的那批结点，只改指针。利用头结点：先把 $L\to next$ 置空，把新表做成空表；然后从原表逐个取下首元（取下前先用 $q$ 保存它的后继，否则断链），用**头插法**插到头结点 $L$ 之后。头插法生成的表与插入次序相反，故原表结点搬空后，$L$ 之后即为逆置结果。整个过程不新建、不删除结点，属就地算法。

**(2) 代码**：见第 6 节主解 `InverseList`（`p` 为待处理结点、`q` 保存后继，四步 ①存后继 ②挂当前首元 ③头结点改指 ④推进）。

**(3) 复杂度**：$n$ 个结点各处理一次、每轮常数次指针操作，时间 $O(n)$；仅用 `p`、`q` 两个辅助指针，附加空间 $O(1)$。

**(4) 边界**：空表 $n=0$ 时循环不执行；单结点时一轮后表不变；头结点本身位置不变，故无需返回值。

## 9. 易错点

1. **忘记先保存后继**：写成 `p = p->next;` 之后又 `p->next = L->next;`，或先改 `p->next` 再取 `p = p->next`——此时 `p->next` 已指向头结点之后，链表成环、原表丢失。顺序必须是 `q = p->next;` → 改指针 → `p = q;`；
2. 把第 ②③ 步顺序颠倒（先 `L->next = p;` 再 `p->next = L->next;`）：第二条会让 `p->next = p` 自指成环；
3. **忘记初始化** `L->next = NULL;`：新表的"当前首元"取不到正确值，最后一轮的表尾也无法形成 `NULL`；
4. 误按"不带头结点"处理而写成 `LinkList Inverse(LinkList L)` 并 `return` 新头指针——题面明确带头结点，`L` 始终是那个头结点，返回 `void` 更规范（若采用三指针法则必须最后 `L->next = pre` 接回）；
5. 用"搬 `data` 值"的伪就地写法（双指针把 $a_i.data$ 与 $a_{n+1-i}.data$ 互换）：单链表无法按下标取第 $i$ 个与倒数第 $i$ 个结点，这样做既需 $O(n)$ 辅助存储又偏离指针操作考查点；
6. 声称"就地"却在循环里 `malloc` 新结点重新建表再释放原表：空间虽仍 $O(1)$ 附加（若边插边放），但结点被销毁重建，不满足"在原链表上进行"的通常判分要求。

## 10. 一句话规律

带头结点单链表就地逆置 $=$ 头插法建表的直接复用：**摘一个、头插一个**，摘之前永远先 `q = p->next`；结点不增不减，时间 $O(n)$、附加空间 $O(1)$。
