# DS-2017-37

## 1. 原题

已知初始序列（ $52,80,63,44,48,91$ ），写出直接插入排序的各趟排序的结果。

## 2. 答案

按"第 $1$ 个关键字自成一个有序区，从第 $2$ 个记录起逐趟插入"的教材约定，共 $n-1=5$ 趟（每趟处理后**有序区为前若干位**，竖线仅为标注）：

| 趟 | 插入的记录 | 结果序列 |
|---|---|---|
| 初始 | — | $52\ |\ 80,63,44,48,91$ |
| 第 1 趟 | 80 | $52,80\ |\ 63,44,48,91$（位置不变） |
| 第 2 趟 | 63 | $52,63,80\ |\ 44,48,91$ |
| 第 3 趟 | 44 | $44,52,63,80\ |\ 48,91$ |
| 第 4 趟 | 48 | $44,48,52,63,80\ |\ 91$ |
| 第 5 趟 | 91 | $44,48,52,63,80,91$（位置不变，排序完成） |

## 3. 题目分析

- 已知：初始关键字序列 $(52,80,63,44,48,91)$，$n=6$，排序方法为**直接插入排序**（升序）；
- 目标：写出**每一趟**结束后的序列状态；
- 关键约束：直接插入排序的第 $i$ 趟只做一件事——把第 $i+1$ 个记录插入到前面已有序区间的正确位置，**其余记录的相对次序不变**（这是稳定排序的性质，也是核对答案的手段）；
- 命题意图：考"趟"的划分口径（一趟 = 插入一个记录，共 $n-1$ 趟）与插入时"从后往前比较、后移、填入"的过程是否清晰；此类题常追加询问比较次数/移动次数或稳定性。

## 4. 核心考点

核心考点：
DS06.02.01 直接插入排序（一趟插入一个记录；有序区逐趟向右扩张）

辅助考点：
DS06.01 排序的基本概念（"趟"的定义、稳定性——等值关键字不交换，本题无等值键但性质仍成立）

解释：本题的机械动作是"逐趟写出中间序列"，属 TRACE 型过程追踪；判分点在于趟数（$5$ 趟）与每趟只有"被插入的那个数"换了位置。

## 5. 解题思路

1. 定口径：$R[1]$ 自成有序区，第 $i$ 趟（$i=1\cdots n-1$）插入 $R[i+1]$；
2. 每趟从有序区**右端向左**扫描：比它大的都往后移一位，遇到比它小（或相等）的就把该记录填在其后；
3. 若扫描到有序区最左仍无更小者，则该记录插到第 $1$ 位（本题第 3、4 趟即如此）；
4. 若被插记录本身就大于有序区最大者，则本趟序列与上趟**完全相同**（第 1、5 趟即如此，不可漏写）；
5. 写完逐趟自查：每趟前缀必须递增、且整趟的元素多重集与初始相同；最后一趟应为全升序。

## 6. 详细解答

**算法（教材风格，$R[0]$ 作哨兵/暂存单元，记录下标 $1\sim6$）**：

```c
void InsertSort(SqList *L)                     /* L->r[1..n] 为待排记录 */
{
    for (i = 2; i <= L->length; i++)
        if (L->r[i].key < L->r[i-1].key) {     /* 待插记录小于有序区最大者才需移动 */
            L->r[0] = L->r[i];                 /* 哨兵：暂存待插记录，兼免越界判断 */
            for (j = i - 1; L->r[0].key < L->r[j].key; j--)
                L->r[j+1] = L->r[j];           /* 比它大的记录逐个后移 */
            L->r[j+1] = L->r[0];               /* 落位 */
        }
}
```

**第 1 趟**（$i=2$，插入 $80$）：$80>52$，外层条件不成立，不进内层循环，$80$ 原地。
$$(52,\mathbf{80},63,44,48,91)\qquad 比较\ 1\ 次，后移\ 0\ 次，\text{有序区}\,[52,80]$$

**第 2 趟**（$i=3$，插入 $63$）：$63<80$ ⟹ $80$ 后移到位置 3；$63>52$ ⟹ 循环停止，落位位置 2。
$$(52,80,\mathbf{63},44,48,91)\to(52,\mathbf{63},80,44,48,91)\qquad 比较\ 2\ 次，后移\ 1\ 次$$

**第 3 趟**（$i=4$，插入 $44$）：$44<80$、$44<63$、$44<52$ ⟹ 三者依次后移；$j$ 减到 $0$ 后与哨兵比较 $44<44$ 为假 ⟹ 落位位置 1。
$$(52,63,80,\mathbf{44},48,91)\to(\mathbf{44},52,63,80,48,91)\quad 比较\ 4\ 次(含\ 1\ 次哨兵比较)，后移\ 3\ 次$$

**第 4 趟**（$i=5$，插入 $48$）：$48<80$、$48<63$、$48<52$ ⟹ 后移 3 次；$48>44$ ⟹ 停止，落位位置 2。
$$(44,52,63,80,\mathbf{48},91)\to(44,\mathbf{48},52,63,80,91)\qquad 比较\ 4\ 次，后移\ 3\ 次$$

**第 5 趟**（$i=6$，插入 $91$）：$91>80$，外层条件不成立，原地。
$$(44,48,52,63,80,\mathbf{91})\qquad 比较\ 1\ 次，后移\ 0\ 次，整表有序$$

**汇总表（含比较/后移次数，便于回答追加提问）**

| 趟 | 待插记录 | 趟末序列 | 比较次数 | 后移次数 |
|---|---|---|---|---|
| 1 | 80 | 52, 80, 63, 44, 48, 91 | 1 | 0 |
| 2 | 63 | 52, 63, 80, 44, 48, 91 | 2 | 1 |
| 3 | 44 | 44, 52, 63, 80, 48, 91 | 4 | 3 |
| 4 | 48 | 44, 48, 52, 63, 80, 91 | 4 | 3 |
| 5 | 91 | 44, 48, 52, 63, 80, 91 | 1 | 0 |

合计：关键字比较 $1+2+4+4+1=12$ 次（含第 3 趟那 1 次哨兵比较），记录**后移** $0+1+3+3+0=7$ 次。若按"记录被赋值的次数"统计，还要加上 3 次"取出到哨兵位"与 3 次"落位写入"，共 $7+6=13$ 次——两种口径取决于课堂对"移动"的定义，**序列结果不受影响**。

**校验**

1. **多重集守恒**：每趟序列都是 $\{44,48,52,63,80,91\}$ 的排列，无增无删 ✓；
2. **有序区前缀单调**：趟末前缀长度依次为 $2,3,4,5,6$ 且均递增 ✓（若第 3 趟误写成 $52,44,63,80,\cdots$ 即前缀不单调，立刻可查出错）；
3. **稳定性旁证**：每趟只有被插记录跨越他数，其余记录的相对次序保持不变 ✓；
4. **终态正确**：第 5 趟为升序 $44,48,52,63,80,91$ ✓。

## 8. 考场标准答案

直接插入排序，$R[1]$ 自成有序区，共 $5$ 趟：

```
初始        ( 52 )  80  63  44  48  91
第1趟 插80  ( 52  80 ) 63  44  48  91
第2趟 插63  ( 52  63  80 ) 44  48  91
第3趟 插44  ( 44  52  63  80 ) 48  91
第4趟 插48  ( 44  48  52  63  80 ) 91
第5趟 插91  ( 44  48  52  63  80  91 )
```

括号内为有序区；第 1、5 趟插入记录位置不变，仍须写出以体现"趟数 $=n-1$"。

## 9. 易错点

1. **漏写"不变"的那趟**：第 1 趟（插 $80$）与第 5 趟（插 $91$）序列与上一趟相同，但它们是独立的趟，省略会被判趟数不足；
2. 一趟插入**多个**记录（如把"第 2 趟"写成 $52,63,80,44,91,48$）——直接插入排序一趟只定位一个记录；
3. 把直接插入排序与**冒泡/选择排序**的趟结果混淆：选择排序一趟从未序区挑出最小者换到前缀末尾之后（本题若用选择排序，第 1 趟就应写成 $44,80,63,52,48,91$ 开头的形态），冒泡一趟把最值"冒"到端点——第 1 趟仍只动 $80$ 才是插入排序（对比见本库 DS-2012-34 直接选择排序的第二趟结果）；
4. 移动次数与比较次数混计：比较次数是大小判断的次数（本题 $12$，含 1 次哨兵比较），后移次数是记录被搬动的次数（本题 $7$），二者不可互相顶替；
5. 未确认升序/降序：题面未注明时按升序作答，并在卷面写清"按非递减排序"。

## 10. 一句话规律

直接插入排序的趟结果只有一条规则：**第 $i$ 趟把第 $i+1$ 个记录放回前 $i+1$ 个记录的有序位置，其他元素一律不动**——所以每趟前缀必递增、且每趟只可能有一个数"跳位"。
