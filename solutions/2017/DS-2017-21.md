# DS-2017-21

## 1. 原题

有向图 $G$ 用邻接矩阵 $A[1\cdots n,1\cdots n]$ 存储，其第 $i$ 行的所有非 $0$ 元素的个数等于顶点 $i$ 的____________________。

## 2. 答案

**出度**（即以顶点 $i$ 为**尾**（起点）的弧的条数，记作 $TD_{out}(i)$ 或 $d^+(i)$）

## 3. 题目分析

- 已知：有向图 $G$，$n$ 个顶点，采用邻接矩阵 $A$（$n\times n$）存储；
- 目标：说明"第 $i$ 行非 0 元素个数"这一计数量的图论含义；
- 关键约束：邻接矩阵的定义——$A[i][j]=1$（或弧的权值）$\iff$ 存在弧 $\langle v_i,v_j\rangle$，$A[i][j]=0$（或 $\infty$）$\iff$ 不存在该弧。**行下标是弧的起点，列下标是弧的终点**；
- 命题意图：考邻接矩阵"行=出、列=入"这一方向约定，以及有向图入度/出度的定义。这是有向图与无向图在矩阵上表现不对称（矩阵不再对称）的直接后果。

## 4. 核心考点

核心考点：
DS04.02.01 邻接矩阵法（$A[i][j]$ 的语义、有向图矩阵不对称、按行/按列统计的含义）

辅助考点：
DS04.01 图的基本概念（有向顶点的入度 $d^-(i)$、出度 $d^+(i)$，度 $TD(i)=d^-(i)+d^+(i)$）

解释：题目表面问"数一行里的非零元素"，实质问的是"这一行记录了哪些弧、这些弧对顶点 $i$ 意味着什么"，两个节点缺一不可：不懂矩阵语义就写不出方向，不懂度的定义就不知道填"出度"还是"度"。

## 5. 解题思路

1. 写出一行的元素：第 $i$ 行是 $A[i][1],A[i][2],\cdots,A[i][n]$，每个非 0 元素 $A[i][j]$ 对应一条**从 $i$ 出发**指向 $j$ 的弧；
2. 数非 0 元素个数 = 数"以 $i$ 为起点的弧"的条数 = 出度的定义；
3. 自我检验：再问自己"第 $i$ 列呢？"——列的下标是终点，非 0 个数为入度；两者相加才是该顶点的度；
4. 用 3 顶点小图手算一遍确认（见第 6 节）。

## 6. 详细解答

**（1）按定义推导**

$$A[i][j]=\begin{cases}1\ (\text{或弧 }\langle v_i,v_j\rangle\text{ 的权值}),& \text{存在弧 }\langle v_i,v_j\rangle\\[2pt] 0\ (\text{或 }\infty),& \text{不存在}\end{cases}$$

第 $i$ 行非 0 元素个数

$$\sum_{j=1}^{n}[A[i][j]\ne 0]=\#\{\,j\mid \langle v_i,v_j\rangle\in E\,\}=d^+(i)$$

即顶点 $v_i$ 的**出度**。

**（2）对照：第 $i$ 列**

$$\sum_{k=1}^{n}[A[k][i]\ne 0]=\#\{\,k\mid \langle v_k,v_i\rangle\in E\,\}=d^-(i)$$

是**入度**。因此有向图中"行出列入"，顶点的度 $=d^-(i)+d^+(i)$，需整行加整列才能算出。

**（3）实例验证**

设 3 个顶点的有向图含弧 $\langle1,2\rangle,\langle1,3\rangle,\langle3,1\rangle$，邻接矩阵为

$$A=\begin{pmatrix}0&1&1\\ 0&0&0\\ 1&0&0\end{pmatrix}$$

- 第 1 行非 0 元素 2 个 → 顶点 1 的出度 $=2$（弧 $1\to2$、$1\to3$）✓
- 第 1 列非 0 元素 1 个 → 顶点 1 的入度 $=1$（弧 $3\to1$）✓
- 矩阵不对称，正说明有向图必须分行、分列统计。

**（4）两点补充说明（不影响答案）**

- 若图中允许**自环** $\langle v_i,v_i\rangle$，则 $A[i][i]\ne0$，它同时被计入第 $i$ 行与第 $i$ 列，即自环对出度、入度各贡献 1，与教材"自环计 2 度（入、出各 1）"的口径一致；
- 若为**带权有向网**，通常以 $\infty$ 表示不邻接，此时"非 0"应理解为"非 $\infty$（存在弧）"，结论仍是出度。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

邻接矩阵中 $A[i][j]\ne 0$ $\iff$ 存在弧 $\langle v_i,v_j\rangle$，第 $i$ 行统计的是**以 $v_i$ 为起点**的弧数，故填：

$$\textbf{出度}\ d^+(i)\quad(\text{第 } i \text{ 列的非 0 元素个数才是入度 } d^-(i))$$

## 9. 易错点

1. 填成"度"：只有**无向图**的邻接矩阵对称，行（或列）的非 0 元素个数才等于该顶点的度；本题明确是**有向图**，一行只反映一个方向；
2. 方向记反，填成"入度"：判据是"行下标 = 弧的起点"（$A[i][j]$ 表示 $i\to j$），若把矩阵定义记成 $A[i][j]$ 表示 $j\to i$（部分教材的转置约定），结论才会互换；按严蔚敏教材应填出度；
3. 忽略自环的计数口径（自环在行、列中各计 1）。

## 10. 一句话规律

有向图邻接矩阵"**行出列入**"：某顶点的出度看它那一行、入度看它那一列，度是两者之和；无向图矩阵对称，一行（或一列）就是度。

## 11. 关联知识

- 邻接矩阵求边数：有向图为所有非 0 元素个数，无向图为非 0 元素个数除以 2（矩阵对称，每条边存两处）；
- 邻接表中结论一脉相承：有向图某顶点边表的结点个数同样是该顶点的**出度**，求入度则需遍历全表（或另建逆邻接表），见 DS04.02.02；
- 本卷第 16 题（DS-2017-16 拓扑排序）中"入度为 0"的判定，在邻接矩阵上就是"第 $i$ 列全为 0"；
- 本题与第 30 题（一次遍历访问所有顶点 ⇒ 连通图）同属图的基本概念考查（DS04.01/DS04.02.01）。
