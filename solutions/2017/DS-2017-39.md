## 2. 答案

**算法思想**：平衡二叉树的定义本身是递归的——空树是 AVL；非空树须满足"根的左右子树高度差的绝对值 $\leqslant 1$"**且**"左、右子树都是 AVL"。而一个结点的高度只有在它的两棵子树高度都求出之后才能得到，所以采用**后序（自底向上）遍历**：让递归函数**返回以该结点为根的子树高度**，同时借用一个"不可能出现的合法高度值" $-1$ 作为"该子树已失衡"的标记（真实高度恒 $\geqslant 0$，故 $-1$ 不会与高度混淆）。上层一收到 $-1$ 就立即继续返回 $-1$（剪枝），于是每个结点只被访问一次。最终 `BalanceDepth(bt) != -1` 即为"是平衡二叉树"。

```c
/* 返回以 bt 为根的子树高度；若该子树不是平衡二叉树，则返回 -1 作为失衡标记 */
int BalanceDepth(bitree bt)
{
    int hl, hr;
    if (bt == NULL) return 0;                /* 空树：高度 0，按定义是平衡的 */
    hl = BalanceDepth(bt->lchild);           /* 后序：先取左子树的高度或标记 */
    if (hl == -1) return -1;                 /* 左子树已失衡，直接上抛，不再进右子树 */
    hr = BalanceDepth(bt->rchild);
    if (hr == -1) return -1;                 /* 右子树已失衡，上抛 */
    if (hl - hr > 1 || hr - hl > 1) return -1;   /* 本结点失衡 */
    return (hl > hr ? hl : hr) + 1;          /* 平衡：返回真实高度 */
}

int IsBalance(bitree bt)                     /* 1 = 是平衡二叉树，0 = 不是 */
{
    return (BalanceDepth(bt) == -1) ? 0 : 1;
}
```

**复杂度**：时间 $O(n)$（$n$ 为结点数，每个结点恰好进入递归一次，结点内只做常数次比较）；附加空间为递归工作栈 $O(h)$，$h$ 为树高——最坏（单支链）$O(n)$，树平衡时 $O(\log n)$。

对照的朴素写法（先序：每个结点重新调用一次求高度函数）时间为 $O(n\log n)\sim O(n^2)$，见第 6.4 节，考卷上应主动给出 $O(n)$ 版并说明理由。

## 3. 题目分析

- **输入**：一棵以二叉链表存储的**任意**二叉树，根结点指针 `bt`，结点为 `{int key; BinNode *lchild, *rchild;}`（题面用 `key` 作数据域，本解析不依赖其大小关系）；
- **输出**：布尔结果"是否为平衡二叉树"（返回 `1/0` 或 `TRUE/FALSE` 均可，卷面写明即可）；
- **关键约束与解读**：
  1. 题面说"给定某一二叉树"，故**不假定它是二叉排序树**，只检验平衡性；若还要求检验 BST 性质，只需另加一趟中序判升序（与本题无关，可在卷面作一句说明）；
  2. 定义中"且左、右子树都是平衡二叉树"意味着**只检查根的左右子树高度差不够**，必须逐结点验证——这是本题最大的陷阱；
  3. 高度口径全卷统一为**空树高度 $0$、单结点树高度 $1$**（与本卷 DS-2017-27 括注的"根结点为第 $1$ 层"一致，也与 DS-2013-11、DS-2014-34 等 AVL 计数题的"空树高度为 $0$"括注一致）；
  4. 边界：空树、单结点树、根带一个孩子者都应判为平衡，递归出口天然覆盖，无需特判。
- **命题意图**：把"递归给出的定义"直译成分治算法（DS05.07.02 定义侧），并考"一次遍历如何同时携带两种信息（高度 + 平衡性）"的设计技巧（DS03.02.03.03 后序遍历的应用、DS00.02 复杂度分析）。

## 5. 解题思路

1. **拆定义**：① $bt=\text{NULL}$ ⟹ 平衡；② 否则需 (a) 左子树 AVL、(b) 右子树 AVL、(c) $|h_L-h_R|\leqslant 1$ 三条同时成立——定义即递归，算法骨架自然递归；
2. **决定返回值携带什么**：只返回真假，则每层还要另求高度（重复遍历）；只返回高度，则丢失平衡信息。三种可选设计：
   - (a) 返回"结构体（高度 + 布尔）"——最直白但代码冗长；
   - (b) 返回值作布尔、以引用/指针参数带回高度（第 6.5 节写法）；
   - (c) **借用非法高度值 $-1$ 作标记**（主解）——真实高度 $\geqslant 0$，故 $-1$ 安全，最省空间最好写；注意不能选 $0$，因为 $0$ 是空树的合法高度，用 $0$ 作标记会把所有空子树误判成失衡；
3. **定遍历次序**：$h=\max(h_L,h_R)+1$ 依赖孩子 ⟹ 后序；由此标记沿祖先链上抛，一趟完成；
4. **剪枝**：`hl == -1` 立即 `return -1`，不再进入右子树——结论已定，多算无益（不剪枝复杂度仍是 $O(n)$，但会白跑子树且需额外变量）；
5. **样例手工走查**（第 6.3 节）：一棵 7 结点的平衡树、一棵在它上面加一个结点后就失衡的树（且**根的平衡因子仍合格**，专门用来暴露"只看根"的错误）、再加空树/单结点/双结点链/三结点链；
6. **交叉验证**：用朴素先序法（第 6.4 节）跑同一批样例，两法结论必须逐棵一致。

## 6. 详细解答

### 6.1 类型与约定

直接使用题面给定的类型：

```c
typedef struct tnode
{
    int key;
    struct tnode *lchild, *rchild;
} BinNode, *bitree;
```

高度约定：**空树高度 $0$，只有根结点的树高度 $1$**。于是叶子结点 $h_L=h_R=0$、高度差 $0$，必平衡——边界自然成立。

### 6.2 主解与正确性论证

```c
int BalanceDepth(bitree bt)
{
    int hl, hr;
    if (bt == NULL) return 0;                     /* 定义①：空树高度 0 且平衡 */
    hl = BalanceDepth(bt->lchild);                /* 定义②(a)：左子树 */
    if (hl == -1) return -1;                      /* 已失衡，剪枝上抛 */
    hr = BalanceDepth(bt->rchild);                /* 定义②(b)：右子树 */
    if (hr == -1) return -1;
    if (hl - hr > 1 || hr - hl > 1) return -1;    /* 定义②(c)：本结点平衡因子 */
    return (hl > hr ? hl : hr) + 1;               /* 平衡，返回真实高度 */
}

int IsBalance(bitree bt) { return (BalanceDepth(bt) == -1) ? 0 : 1; }
```

**命题**：`BalanceDepth(bt)` 的返回值 $r$ 满足——若以 `bt` 为根的子树是 AVL，则 $r$ 为其高度（$\geqslant 0$）；否则 $r=-1$。

**归纳证明**（对子树结点数 $n$）：

- $n=0$：走 `bt == NULL` 分支返回 $0$，即空树高度，空树按定义是 AVL ✓；
- $n>0$：左右子树结点数均 $<n$，由归纳假设 `hl`、`hr` 各为"真实高度"或"$-1$（该子树非 AVL）"。
  - 若 `hl == -1` 或 `hr == -1`：某子树非 AVL，定义② 的"且左右子树为二叉平衡树"不成立，整棵非 AVL，返回 $-1$ ✓（剪枝不漏判：结论已定，右子树无需再算）；
  - 否则两子树皆 AVL 且高度真实，仅剩检查 $|h_L-h_R|$：$\leqslant 1$ 时定义② 全部满足，该树是 AVL，返回 $\max+1$ 恰为其高度 ✓；$>1$ 时返回 $-1$ ✓。

$-1$ 作标记的安全性：任一子树的真实高度 $\geqslant 0$，故 $-1$ 永不与合法返回值冲突。

### 6.3 样例走查

**(a) 平衡树**（7 结点，树高 4）：

```
            30
          /    \
        20      40
        /      /   \
      10     35     50
                  /
                45
```

后序访问次序 $10,20,35,45,50,40,30$，逐结点记录：

| 结点 | $h_L$ | $h_R$ | $h_L-h_R$ | 返回值 |
|---|---|---|---|---|
| 10 | 0 | 0 | 0 | 1 |
| 20 | 1 | 0 | 1 | 2 |
| 35 | 0 | 0 | 0 | 1 |
| 45 | 0 | 0 | 0 | 1 |
| 50 | 1 | 0 | 1 | 2 |
| 40 | 1 | 2 | −1 | 3 |
| 30 | 2 | 3 | −1 | **4** |

`BalanceDepth(30) = 4 ≠ -1` ⟹ **是** AVL ✓（手算树高：$30$ 第 1 层、$20/40$ 第 2 层、$10/35/50$ 第 3 层、$45$ 第 4 层，共 $4$ ✓；每结点 $|BF|\le 1$ ✓）。

**(b) 失衡树**：在 (a) 的结点 $10$ 上再加一个左孩子 $5$：

```
            30
          /    \
        20      40
        /      /   \
      10     35     50
      /           /
     5           45
```

走查：$5\to1$；$10$：$h_L=1,h_R=0$，差 $1$ ⟹ 返回 $2$；$20$：$h_L=2,h_R=0$，差 $2>1$ ⟹ **返回 $-1$**；回到 $30$ 时 `hl == -1` ⟹ 立即 `return -1`（右子树 $40$ 及其下 $35,45,50$ **一次都不访问**，这就是剪枝）。

⟹ `IsBalance = 0`，非 AVL ✓。**失衡点是 $20$ 而不是根 $30$**：若不剪枝而是只看根，$30$ 的左子树高 $=3$（$20\to10\to5$）、右子树高 $=3$（$40\to50\to45$），高度差 $0\leqslant1$，会被**误判为平衡**——这正是"必须逐结点检查"的反例（呼应第 3 节约束 2）。

**(c) 其余边界**

| 输入 | 走查 | 结论 |
|---|---|---|
| 空树 `bt == NULL` | 返回 $0$ | 平衡（定义①）✓ |
| 单结点 | $h_L=h_R=0$ ⟹ 返回 $1$ | 平衡 ✓ |
| 根 + 一个左孩子 | 根 $h_L=1,h_R=0$，差 $1$ ⟹ 返回 $2$ | 平衡 ✓ |
| 3 结点纯左链 | 中间结点返回 $2$，根 $h_L=2,h_R=0$ 差 $2$ | 返回 $-1$ ⟹ 不平衡 ✓ |

### 6.4 对照实现（朴素自顶向下，用于交叉验证与复杂度对比）

```c
int Depth(bitree bt)                           /* 单纯求高度 */
{
    int hl, hr;
    if (bt == NULL) return 0;
    hl = Depth(bt->lchild);
    hr = Depth(bt->rchild);
    return (hl > hr ? hl : hr) + 1;
}

int IsBalance1(bitree bt)                      /* 先序：先判根，再递归判两子树 */
{
    int d;
    if (bt == NULL) return 1;                  /* 空树平衡 */
    d = Depth(bt->lchild) - Depth(bt->rchild);
    if (d > 1 || d < -1) return 0;
    return IsBalance1(bt->lchild) && IsBalance1(bt->rchild);
}
```

对 6.3 的 (a)(b)(c) 五类输入，两法结论**逐棵一致**（(a) 真、(b) 假、空树/单结点/单孩子 真、3 结点纯左链 假）✓ 互为验证。

代价差别：`IsBalance1` 在每个结点上都要重新调用 `Depth` 遍历其子树。完全二叉树时 $T(n)=2T(n/2)+O(n)=O(n\log n)$；链状退化时 $T(n)=T(n-1)+O(n)=O(n^2)$。主解每结点只访问一次，恒为 $O(n)$。

### 6.5 第三种等价写法（返回值作标志、指针参数带高度）

不想借用 $-1$ 语义时，可把两个信息分开传递（严蔚敏教材算法描述惯用引用参数，严格 C 下写作指针）：

```c
/* 返回该子树是否平衡；*d 带回子树高度（失衡时 *d 不再被上层使用） */
int JudgeBalance(bitree bt, int *d)
{
    int hl, hr, lok, rok;
    if (bt == NULL) { *d = 0; return 1; }             /* 空树：高度 0，平衡 */
    lok = JudgeBalance(bt->lchild, &hl);
    if (!lok) return 0;                               /* 左子树失衡，剪枝 */
    rok = JudgeBalance(bt->rchild, &hr);
    if (!rok) return 0;
    *d = (hl > hr ? hl : hr) + 1;
    return (hl - hr >= -1 && hl - hr <= 1);           /* 检查本结点的平衡因子 */
}
```

与主解同为 $O(n)$ 时间 / $O(h)$ 栈空间，三种写法任取其一即可。

### 6.6 复杂度分析

| 版本 | 时间 | 附加空间 | 说明 |
|---|---|---|---|
| 主解 `BalanceDepth` | $O(n)$ | $O(h)$（最坏 $O(n)$，平衡时 $O(\log n)$） | 每结点一次递归 + 常数次比较；剪枝可提前退出 |
| 6.5 `JudgeBalance` | $O(n)$ | $O(h)$ | 同上，信息分两路传递 |
| 朴素 `IsBalance1` | $O(n\log n)\sim O(n^2)$ | $O(h)$ | 每个结点重复求一次子树高度 |

## 8. 考场标准答案

**(1) 算法思想**：AVL 的定义是递归的——空树是 AVL；非空树须"根的左右子树高度差绝对值不超过 $1$"且"左、右子树都是 AVL"。结点的高度只能在两棵子树高度都求出后得到，故用**后序（自底向上）遍历**：递归函数返回子树高度，同时把"失衡"编码为返回一个非法高度值 $-1$（真实高度恒 $\geqslant 0$，不会混淆）；上层一旦收到 $-1$ 立即继续返回 $-1$（剪枝），使每个结点仅被访问一次。`BalanceDepth(bt) != -1` 即为平衡二叉树。

**(2) 算法**：见第 2 节 / 第 6.2 节的 `BalanceDepth` 与 `IsBalance`（空树返回 $0$；`hl==-1` 或 `hr==-1` 上抛；否则检查 $|h_L-h_R|$，$>1$ 返回 $-1$，$\leqslant1$ 返回 $\max+1$）。

**(3) 复杂度**：时间 $O(n)$，$n$ 为结点数；空间为递归工作栈 $O(h)$，$h$ 为树高，最坏单支时 $O(n)$，平衡时 $O(\log n)$。若改写成"每个结点重新求高度"的先序法，时间退化到 $O(n\log n)\sim O(n^2)$，故应给出上面的 $O(n)$ 版本。

**(4) 边界说明**：空树、单结点、根带单孩子均判为平衡；本算法只检验平衡性，不依赖 `key` 的大小关系（题面为"某一二叉树"，未要求是二叉排序树）。

## 9. 易错点

1. **只检查根的平衡因子**：如 6.3(b) 树，根的高度差为 $0$ 而结点 $20$ 的差为 $2$，会误判为 AVL——必须逐结点检查（题面定义中"且左、右子树为二叉平衡树"这句的作用）；
2. **用先序/中序求高度**：访问根时子树高度未知，无法在本层完成判断；写成"先序 + 每层重调 `Depth`"虽正确但复杂度升到 $O(n^2)$，本题应主动给 $O(n)$ 版；
3. **标记值选 $0$**：$0$ 是空树的合法高度，用它表示失衡会让所有空子树被当成"已失衡"，任何树都判为不平衡；必须取不可能出现的值 $-1$；
4. **漏写 `hl == -1` 的上抛判断**：把 $-1$ 当高度参与 $\max+1$ 计算，会得到 $0$ 或错误的高度差，结论随机出错；
5. **高度口径与全卷不一致**：把空树记作 $1$（或叶子记作 $0$）虽然不改变 $|h_L-h_R|$，但与本卷 DS-2017-27（"根结点为第 $1$ 层"）及 DS-2013-11（"空树高度为 $0$"）的口径不符，卷面若另问树高就会自相矛盾；
6. **递归出口缺失**（未写 `bt == NULL` 分支）导致空指针访问；答题时应显式写出并说明"空树按定义是 AVL"；
7. 误加"必须是二叉排序树"的条件：题面只说"某一二叉树 … 是否为平衡二叉树"，本算法只判平衡性；若确需同时判 AVL（BST + 平衡），应另加一趟中序检查升序，并在卷面写明这是额外要求。

## 10. 一句话规律

凡是"要用子树信息才能判断本结点"的二叉树问题（判平衡、求树高、判两树相似、表达式树求值……）一律**后序递归 + 让返回值携带信息**：把"高度"与"是否合格"编码进同一个整型返回值（用 $-1$ 当标记），一趟遍历同时拿到两个结论，还能天然剪枝。
