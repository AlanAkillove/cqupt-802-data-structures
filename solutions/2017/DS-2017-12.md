# DS-2017-12

## 1. 原题

若长度为 $n$ 的线性表采用顺序存储结构，在其第 $i$ 个位置插入一个元素时间复杂度为（）($1 \leq i \leq n+1$)。

> 订正说明转录：源文作"线性表表采用"，衍字"表"，据题意修正。

A. $O(0)$　B. $O(1)$　C. $O(n)$　D. $O(n^2)$

## 2. 答案

**C**（$O(n)$）

## 3. 题目分析

- 已知：顺序表（连续存放），当前长度 $n$，在第 $i$ 个位置（$1\le i\le n+1$）插入 1 个元素；
- 目标：该插入操作的时间复杂度量级；
- 关键约束：顺序表插入必须**先腾出位置**——把第 $i$ 个到第 $n$ 个元素依次后移一位，再写入新元素；
- 命题意图：考"顺序表插入的代价来自元素移动而非赋值本身"，移动次数 $n-i+1$ 是 $n$ 的一次函数。

## 4. 核心考点

核心考点：
DS01.02.01 顺序存储（插入/删除与移动次数）

辅助考点：
DS00.02 算法与算法分析（把 $n-i+1$ 次移动写成量级 $O(n)$，并区分最好/最坏口径）

解释：本题既要知道顺序表插入的实现细节（移动多少个元素），也要会把它表达为渐近量级，故两节点并列。

## 5. 解题思路

1. 写出插入的算法步骤：合法性检查 → 从最后一个元素起依次后移 → 写入 → 表长加 1；
2. 数移动次数：位置 $i$ 之后（含 $i$）共有 $n-i+1$ 个元素需后移；
3. 判断量级：$1\le i\le n+1$ 时该值为 $0\sim n$，最坏（$i=1$，表头插入）移动 $n$ 次，等概率平均移动 $n/2$ 次，两者都是 $n$ 的一次方；
4. 得 $O(n)$，选 C；顺带确认 D（$O(n^2)$）对应的是"插入 $n$ 个元素建表"而非单次插入。

## 6. 详细解答

顺序表插入的核心语句段（教材风格）：

```c
/* 在顺序表 L 的第 i 个位置插入 e，1 <= i <= L.length+1 */
for (j = L.length; j >= i; --j)   /* 从最后一个元素起依次后移 */
    L.elem[j] = L.elem[j-1];     /* 共移动 L.length - i + 1 次 */
L.elem[i-1] = e;                 /* 写入新元素 */
++L.length;
```

- 基本操作是"元素赋值（后移）"，次数 $M(i)=n-i+1$；
- 最坏情况：$i=1$（表头插入），$M=n$；
- 最好情况：$i=n+1$（表尾追加），$M=0$，即 $O(1)$；
- 平均情况（设各位置插入概率相等，$p_i=\dfrac{1}{n+1}$）：

$$E(M)=\sum_{i=1}^{n+1}\frac{n-i+1}{n+1}=\frac{1}{n+1}\cdot\frac{n(n+1)}{2}=\frac{n}{2}$$

无论取最坏口径（$n$）还是平均口径（$n/2$），量级都是 $n$ 的一次方：

$$T(n)=O(n)$$

**交叉验证**：与本卷填空第 25 题（"表长 $n$、等概率删除，平均移动元素个数"）对照——删除的平均移动次数为 $\frac{n-1}{2}$，插入为 $\frac{n}{2}$，两者同量级 $O(n)$，公式体系自洽。✓

## 7. 选项分析

- A（$O(0)$）：错。不存在零代价的插入；即便表尾追加也要写入元素并修改表长，是 $O(1)$ 而非 $O(0)$，该选项本身量级记法就不规范；
- B（$O(1)$）：错。仅"在表尾插入"这一特殊情形成立，且它对应的是**最好**情况；题目给定一般位置 $i$ 并要求时间复杂度，按最坏/平均口径不成立。若线性表采用**链式**存储且已持有第 $i-1$ 个结点的指针，插入才是 $O(1)$（对照 DS-2017-02）；
- C：正确。需移动 $n-i+1$ 个元素，最坏 $n$ 次、平均 $n/2$ 次，量级 $O(n)$；
- D（$O(n^2)$）：错。单次插入只移动一次连续区间，是线性的；$O(n^2)$ 对应"依次插入 $n$ 个元素建表"的总代价（$\sum \frac{i}{2}=\Theta(n^2)$）。

## 8. 考场标准答案

顺序表在第 $i$ 个位置插入须将第 $i\sim n$ 个元素依次后移，移动次数 $n-i+1$：

$$\text{最坏 } (i=1):\ n;\qquad \text{平均}\ \frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac{n}{2}$$

故时间复杂度为 $O(n)$，选 C。

## 9. 易错点

1. 把"插入 1 个元素"与"插入 $n$ 个元素建表"混淆而选 D；
2. 只看表尾插入的特例选 B——顺序表的**随机访问**是 $O(1)$，但**插入/删除**是 $O(n)$，两个性质不要串位；
3. 忘记 $i$ 的取值范围含 $n+1$（表尾），据此误以为"存在 $O(1)$ 的情况所以题目有问题"；时间复杂度按最坏（或平均）口径给出，与个别特殊位置无关。

## 10. 一句话规律

顺序表任何"要挪动一段元素"的操作（插入、删除、逆置、批量平移）都是 $O(n)$；只有按下标读、在表尾追加、修改单个元素才是 $O(1)$。

## 11. 关联知识

- 删除操作平均移动 $\frac{n-1}{2}$ 个元素（本卷第 25 题），与插入的 $\frac{n}{2}$ 只差一个位置口径；
- 链表插入不需移动元素，但需先查找到第 $i-1$ 个结点，整体仍是 $O(n)$（DS01.02.02，另见 DS-2017-02、本卷第 38 题就地逆置）；
- 顺序表插入前还要判断"是否满表"，若需扩容则涉及一次 $O(n)$ 的整表搬移，量级不变（DS01.02.01）。
