# DS-2017-04

## 1. 原题

判定一个循环队列 $Q$（最多元素为 $m$ 个）为满队列的条件是（）。

A. $Q.front==Q.rear$　B. $Q.front!=Q.rear$　C. $Q.front==(Q.rear+1)\%m$　D. $Q.front!=(Q.rear+1)\%m$

## 2. 答案

**C**（$Q.front==(Q.rear+1)\%m$）

## 3. 题目分析

- 已知：循环队列采用顺序存储，取模数为 $m$（题面称"最多元素为 $m$ 个"）；
- 目标：选出**队满**判据；
- 关键约束：循环队列中 $front$、$rear$ 会绕回，"相等"这一条件被队空、队满两种状态争用，必须人为区分；
- 命题意图：考教材"牺牲一个存储单元"方案下队满/队空判据的记忆与理解，并检验是否会把取模运算写错位置。

## 4. 核心考点

核心考点：
DS02.02 栈和队列的顺序存储结构（循环队列的队空/队满条件）

解释：本题不涉及队列的应用与链式实现，纯粹是循环队列这一顺序存储结构的边界条件，落在 DS02.02 定义范围内。

## 5. 解题思路

1. 先明确两个约定：$front$ 指向队头元素，$rear$ 指向队尾元素的**下一个**位置；入队 `Q.base[Q.rear]=x; Q.rear=(Q.rear+1)%m;`，出队 `x=Q.base[Q.front]; Q.front=(Q.front+1)%m;`；
2. 于是"再加一个元素就与 $front$ 重合"即为满 $\Rightarrow$ 判据 $(rear+1)\%m == front$；
3. 对照选项：C 正是该式（左右交换不影响）；
4. 用 $m=4$、依次入队 3 个元素的具体过程验证"满"发生在 $rear$ 的下一格撞上 $front$ 时。

## 6. 详细解答

**队空**：$front==rear$（两指针重合，无元素）。

**队满**：若允许 $rear$ 绕一圈再次与 $front$ 重合，则与队空无法区分。教材采用"牺牲一个单元"方案：约定 $rear$ 的下一个位置必须是空的，即

$$(Q.rear+1)\%m == Q.front \;\Rightarrow\; \text{队满}$$

此时队列实际可存放 $m-1$ 个元素（数组容量 $m$）。

**验证（$m=4$，初始 $front=rear=0$）**：

| 操作 | front | rear | $(rear+1)\%4$ | 状态 |
|---|---|---|---|---|
| 入 a | 0 | 1 | 2 | 非满 |
| 入 b | 0 | 2 | 3 | 非满 |
| 入 c | 0 | 3 | 0 $==front$ | 满（恰 3 个元素） |
| 再入 d | — | — | — | 溢出，判据已拦下 |

判据在存满 3 个元素（$=m-1$）时生效，符合"牺牲一个单元"的设计。✓

**关于题面措辞**：题干说"最多元素为 $m$ 个"，而该方案下数组大小为 $m$ 时最多容纳 $m-1$ 个元素；四个选项中只有 C 是标准队满判据（$m$ 在式中充当取模数即数组容量），故按教材口径取 C，其余选项在两种解释下都不是队满条件（见第 7 节）。

## 7. 选项分析

- A（$front==rear$）：错。这是**队空**条件（牺牲单元方案下），恰是本题的强干扰项；
- B（$front\neq rear$）：错。这是"队非空"条件，与满无关；
- C：正确。$(rear+1)\%m==front$ 表示 $rear$ 的下一格已被队头占据，无法再入队；
- D（$front\neq(rear+1)\%m$）：错。这是队满条件的**否定**，即"队列未满"，方向刚好相反。

## 8. 考场标准答案

循环队列约定 $rear$ 指队尾元素的下一位置，入队/出队均对 $m$ 取模；为与队空 $front==rear$ 区分，采用牺牲一个存储单元方案：

$$\text{队空： } Q.front==Q.rear \qquad \text{队满： } (Q.rear+1)\%m==Q.front \quad\Rightarrow\text{选 C}$$

（另一路方案是增设计数器/标志位区分，此时满条件为"元素个数 $==m$"，本题选项未涉及。）

## 9. 易错点

1. 把 $front==rear$ 同时当作队空与队满——这正是必须牺牲一个单元（或另设标志）的原因；
2. 取模位置写错：$(rear+1)\%m$ 不能写成 $rear+1\%m$ 或 $(rear\%m)+1$ 后再比较（$m$ 的倍数处会漏判绕回）；
3. 忘记该方案下"数组大小 $m$、可用容量 $m-1$"，在计算"能存几个元素"的填空题（如本卷第 18 题）中出错。

## 10. 一句话规律

循环队列的两个边界判据永远成对出现：空看"重合"，满看"下一格撞重合"，即 $front==rear$ 与 $(rear+1)\%\text{MaxSize}==front$。

## 11. 关联知识

- 若不牺牲单元，可用 $size$ 计数器或 $tag$ 标志区分队空队满，此时容量才等于 $m$；
- 队列元素个数公式：$(rear-front+m)\%m$（牺牲单元方案下满时为 $m-1$）；
- 本卷 DS-2017-18 给出 $rear$、$front$ 具体数值做进出队演算，用的正是同一套下标规则。
