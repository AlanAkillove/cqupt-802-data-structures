# DS-2017-34

## 1. 原题

对一组关键字： $49,38,65,97,76,13,27$ 采用快速排序方法进行排序，用第一关键字作支点/参考值（ $pivot$ ），请写出快速排序的第一趟的交换过程。

## 2. 答案

取 $pivot=49$，按教材 `Partition`（"挖坑填数"式交替移动）执行，第一趟过程为：

$$27,\ 38,\ 13,\ \underline{49},\ 76,\ 97,\ 65$$

即支点 $49$ 最终落到第 $4$ 个位置，其左子区 $\{27,38,13\}$ 全部 $<49$，右子区 $\{76,97,65\}$ 全部 $>49$（逐步骤见第 6 节表）。

## 3. 题目分析

- 已知：初始关键字序列 $(49,38,65,97,76,13,27)$，支点取第一个关键字 $49$；
- 目标：写出**第一趟**（一次划分）的交换/移动过程与结果，不要求继续排序；
- 关键约束：一趟划分只保证"支点归位、左小右大"，**不保证**左右子区内部有序；扫描必须按"先从右往左找比支点小的、再从左往右找比支点大的"交替进行；
- 命题意图：考 `Partition` 的执行细节（扫描方向、交替填坑、相遇时支点归位），并检验是否理解"一趟之后支点位置 $=4$"这一划分结果的含义（它同时也是下一层递归的分界点）。

## 4. 核心考点

核心考点：
DS06.06 快速排序（一趟划分的算法过程：双指针交替扫描、支点归位）

辅助考点：
DS06.01 排序的基本概念（"趟"的含义；划分后序列仍非有序）

解释：本题的评分点在过程而不在结果，必须逐轮写出"谁和谁比较、谁被移动/交换"，这正是 DS06.06 对划分过程的考查方式（本卷 DS-2017-37 直接插入排序的"各趟结果"是同族的过程题）。

## 5. 解题思路

1. 把 $pivot=49$ 取出暂存（$R[0]$ 作哨位），位置 $1$ 成为"空坑"；
2. 从右端 $j$ 向左扫，遇到 $<49$ 的元素就填进左边的坑，坑移到 $j$；
3. 再从左端 $i$ 向右扫，遇到 $>49$ 的元素就填进右边的坑，坑移到 $i$；
4. 交替进行直到 $i=j$（相遇），把 $pivot$ 填入该位置——它即支点的最终位置；
5. 检查结果不变量：左侧全 $<49$、右侧全 $>49$、元素集合与初始相同（无丢失/重复）。

## 6. 详细解答

下标 $1\sim7$，$R[0]$ 暂存支点 $49$；表中 `()` 标出当前空坑位置。

| 步骤 | 扫描动作 | 执行的操作 | 表状态 |
|---|---|---|---|
| 初态 | $i=1,\ j=7$，$pivot=R[0]=49$ | 位置 1 挖出成坑 | $(49),38,65,97,76,13,27$ |
| 1 | $j$ 自右向左找 $<49$：$R[7]=27<49$ 停 | $R[1]\leftarrow27$，坑移到 7，$i\to2$ | $27,38,65,97,76,13,(27)$ |
| 2 | $i$ 自左向右找 $>49$：$R[2]=38$ 越过，$R[3]=65>49$ 停 | $R[7]\leftarrow65$，坑移到 3，$j\to6$ | $27,38,(65),97,76,13,65$ |
| 3 | $j$ 继续向左：$R[6]=13<49$ 停 | $R[3]\leftarrow13$，坑移到 6，$i\to4$ | $27,38,13,97,76,(13),65$ |
| 4 | $i$ 向右：$R[4]=97>49$ 停 | $R[6]\leftarrow97$，坑移到 4，$j\to5$ | $27,38,13,(97),76,97,65$ |
| 5 | $j$ 向左：$R[5]=76>49$ → $j=4$，此时 $i=j=4$ | 扫描相遇，坑停在 4 | $27,38,13,(97),76,97,65$ |
| 6 | 支点归位 | $R[4]\leftarrow pivot=49$ | $27,38,13,\mathbf{49},76,97,65$ |

**第一趟结果**：$(27,\ 38,\ 13,\ 49,\ 76,\ 97,\ 65)$，`Partition` 返回支点位置 $4$。

**不变量复核**

- 左子区 $\{27,38,13\}$ 均 $<49$ ✓；右子区 $\{76,97,65\}$ 均 $>49$ ✓；
- 元素多重集 $\{13,27,38,49,65,76,97\}$ 与初态一致，无丢失、无重复 ✓；
- 支点 $49$ 已在其最终有序位置（排序后 $49$ 恰是第 $4$ 小）✓ ——这是快排"每趟至少定出一个元素的最终位置"的特征。

**教材风格的 Partition 代码（供对照过程）**

```c
/* R[1..n] 为一趟划分的表，R[0] 作支点哨位；返回支点最终位置 */
int Partition(int R[], int low, int high)
{
    int pivot = R[low];                     /* 取第一个关键字作支点 */
    while (low < high) {
        while (low < high && R[high] >= pivot) --high;   /* 从右找比支点小的 */
        R[low] = R[high];                                /* 填左边的坑 */
        while (low < high && R[low] <= pivot)  ++low;    /* 从左找比支点大的 */
        R[high] = R[low];                                /* 填右边的坑 */
    }
    R[low] = pivot;                         /* 支点归位 */
    return low;
}
```

**写法差异说明（重要）**：若课堂采用"左右指针相遇后**交换**"的另一路 partition（找到 $R[i]>pivot$ 与 $R[j]<pivot$ 后互换，最后把支点与 $R[j]$ 互换），同一初态得到

$$(13,\ 38,\ 27,\ \mathbf{49},\ 76,\ 97,\ 65)$$

支点位置同样是 $4$、左右子区的元素集合也相同（$\{13,27,38\}$ / $\{65,76,97\}$），只是子区内元素次序不同。两种写法都是合法的第一趟结果，**考试时按自己教材的写法一路写到底并画出每步过程即可**；本解析主答案取严蔚敏教材的移动（挖坑）版本。

## 7. 选项分析

不适用（问答题）。

## 8. 考场标准答案

$pivot=49$，$i=1,\ j=7$：

1. $j$ 左移至 $27$：$27$ 前移到位置 1；
2. $i$ 右移至 $65$：$65$ 后移到位置 7；
3. $j$ 左移至 $13$：$13$ 前移到位置 3；
4. $i$ 右移至 $97$：$97$ 后移到位置 6；
5. $j$ 左移至 $4$，与 $i$ 相遇 → 支点 $49$ 填入位置 4。

$$\text{第一趟结果}:\ (27,\ 38,\ 13,\ 49,\ 76,\ 97,\ 65)$$

（继续排序则对 $(27,38,13)$ 与 $(76,97,65)$ 分别递归。）

## 9. 易错点

1. 扫描方向弄反或漏掉"交替"：必须右→左找小的、左→右找大的，各找到即停，不能一次性扫完再动；
2. 判据写成 $R[high]>pivot$ / $R[low]<pivot$（漏掉等号）：遇相等元素时会反复移动，最坏退化为 $O(n^2)$；教材条件为 $\ge$ 与 $\le$；
3. 以为"一趟之后整个序列有序"：一趟只让支点归位，左右子区内部无序（本题 $27,38,13$ 与 $76,97,65$ 都未有序）；
4. 忘记最后一步"支点填入相遇位置"，把哨位 $R[0]$ 的 $49$ 漏在表外；
5. 中途把某个元素覆盖丢失——每填一个坑必产生新坑，元素总数守恒，可据此自查。

## 10. 一句话规律

快排一趟 = "挖坑—填坑—换位"：支点先出坑，右找小填左坑、左找大填右坑，相遇即支点归位；写完用"左小右大 + 多重集不变"两条同时自查。

## 11. 关联知识

- 一趟划分后支点位置等于该关键字的名次，故快排可用来做"选第 $k$ 小"；本题支点落在 $4$，正对应 $49$ 是第 $4$ 小；
- **同型题互验**：DS-2015-41 给序列 $49,38,65,97,76,13,27,50$（仅多一个 $50$），按同一划分写法得第一趟结果 $(27,38,13,49,76,97,65,50)$，其前 $7$ 位与本题完全一致；DS-2013-44、DS-2014-41 也是"写一趟划分结果"的同族题；
- 与本题对照：直接插入排序的"各趟"是前缀有序长度逐增（本卷 DS-2017-37），堆排序的"各趟"是自底向上调整（DS06.07），三者对"趟"的定义互不相同，不可混用。
