# DS-2017-02

## 1. 原题

链表不具有的特点是（）。

A. 可随机访问任一元素　B. 插入、删除不需要移动元素　C. 不必事先估计存储空间　D. 所需空间与线性表长度成正比

## 2. 答案

**A**（链表不能随机访问任一元素）

## 3. 题目分析

- 已知：链表（链式存储的线性表）的一般性质；
- 目标：找出**不属于**链表特点的选项（否定式提问）；
- 关键约束：链表的存储特征是"任意存储位置＋指针链接"，因而**逻辑相邻 $\ne$ 物理相邻**；
- 命题意图：考"顺序表与链表在随机访问、插入删除代价、空间预估、空间利用率四个维度的对照"。

## 4. 核心考点

核心考点：
DS01.02.02 链式存储：单链表（指针链接、只能顺序查找）

辅助考点：
DS01.02.01 顺序存储（随机访问是顺序表的特点，须与之对比才能判定 A 为"不具有"）

解释：四个选项恰好是两种存储结构的对照表，判定任一项都要先回忆顺序表对应性质，故主考点在链式存储、辅助考点在顺序存储。

## 5. 解题思路

1. 抓定义：链表结点在内存中**离散分布**，结点间靠 `next` 指针相连；
2. 由定义推存取方式：要访问第 $i$ 个结点，只能从头结点沿指针依次走过 $i-1$ 个结点 $\Rightarrow$ 访问时间为 $O(i)$，**不支持按下标直接定位**；
3. "随机访问（random access）"指通过首地址和下标在 $O(1)$ 时间内访问任意元素，这依赖"物理位置与逻辑位置成线性映射"，只有顺序存储满足；
4. 因此 A 是链表**不具有**的特点；再逐项确认 B、C、D 均为链表具有的特点。

## 6. 详细解答

**随机访问的定义**：给定线性表元素序号即可直接算出其存储地址并在常数时间内访问，即 $\text{addr}(a_i)=\text{addr}(a_1)+(i-1)\times d$（$d$ 为元素长度）。此式成立的前提是元素**连续存放**。

**链表的存储图像**：

```
head -> [a1|*] -> [a2|*] -> [a3|*] -> NULL
         地址分散，靠指针串联
```

访问 $a_i$ 必须自头结点起做 $i-1$ 次 `p = p->next`，代价 $O(i)$，故不具备随机访问性。→ A 符合题意。

**其余三项验证**：
- B：插入/删除只需修改前后结点的指针（$\text{InsertList}$ 中 `s->next=p->next; p->next=s;`），不移动其他元素 → 链表具有；
- C：链表按需 `malloc` 新结点，不必像顺序表那样预先声明数组最大长度 → 链表具有；
- D：$n$ 个结点占 $n$ 个结点空间（每结点含数据域＋指针域），总空间 $=n\times(\text{sizeof 结点})$，与长度成正比 → 链表具有。

**交叉验证**：若把题目换成"顺序表不具有的特点"，答案应为"插入删除不需要移动元素"（顺序表平均移动 $n/2$ 个元素），两题互为对照，说明 A 与 B 分属两种结构，判定自洽。✓

## 7. 选项分析

- A：错（即本题答案）。随机访问要求连续存放，链表只能顺序访问；
- B：对（链表具有）。插入删除只改指针，这是链表相对顺序表的核心优势；典型误区是认为"插入也要移动指针所指的内容"——移动的是指针指向，不是元素本身；
- C：对（链表具有）。顺序表才需要事先估计空间，估计过大浪费、估计过小溢出；
- D：对（链表具有）。误区是把"额外指针域"误解为"空间与长度不成正比"：指针是每结点固定开销，总量仍为 $O(n)$。

## 8. 考场标准答案

随机访问依赖"元素连续存放、地址可由下标直接计算"；链表结点离散分布、只能从头沿 `next` 顺序查找（第 $i$ 个需 $O(i)$），故**不能随机访问**。B、C、D 依次对应"改指针不移动元素""动态分配不需预估""空间 $=n\times$ 结点大小 $\propto n$"，均为链表特点。

$$\text{选 A}$$

## 9. 易错点

1. 否定式提问读成"链表具有的特点"，会误选 B/C/D；
2. 混淆"随机访问"与"随机存取结构/随机插入位置"：本题的随机访问是**按下标 $O(1)$ 定位**的存储性质，与"在第几个位置插入"无关；
3. 认为链表"空间不连续所以浪费很多"——D 说的是总量与长度成正比（线性关系），指针域只是常数倍系数。

## 10. 一句话规律

判断存储结构特点，一律回到"物理上是否连续"这一根属性：连续 $\Rightarrow$ 可随机访问、需预估空间、插入删除要移动；离散 $\Rightarrow$ 只能顺序访问、动态分配、插入删除改指针。

## 11. 关联知识

- 双向链表、循环链表仍不具备随机访问性（DS01.02.03）；静态链表用数组模拟指针，形式上可按下标访问，但逻辑上仍是顺序查找；
- 顺序表插入/删除的平均移动次数为 $n/2$ 与 $(n-1)/2$，见 DS-2017-12 与本卷填空第 25 题；
- 链表与顺序表的选择对照（DS01.03 应用）：频繁按位查找选顺序表，频繁插入删除选链表。
