# DS-2017-24

## 1. 原题

某二叉树的先序遍历序列是 $ABDGCEFH$，中序遍历序列是 $DGBAECHF$，那么该二叉树的后序遍历序列是____________________。

## 2. 答案

**GDBEHFCA**（即 $G,D,B,E,H,F,C,A$）

## 3. 题目分析

- 已知：同一棵二叉树的**先序**序列 $ABDGCEFH$ 与**中序**序列 $DGBAECHF$（8 个互异结点）；
- 目标：求**后序**序列；
- 关键约束：先序的第一个字符是（子）树的根；该根在中序中的位置把中序序列切成左、右两棵子树的结点集合；两侧结点数确定后，又能把先序串切回对应的两段——如此递归；
- 命题意图：考"先序 + 中序可唯一确定一棵二叉树"这一经典结论及其手工构造能力，最终再考一次后序遍历。直接套公式不行，必须真的把树画出来。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（由两种遍历序列确定二叉树，再由第三种序列读出结果）

解释：本题同时用到先序（定根）、中序（分左右）、后序（出答案）三种序列，三者的互推正是 DS03.02.03 这一节点的核心内容（其下 .01～.04 子节点用于标更细的能力，此处按规范上卷到 DS03.02.03，不再拆分辅助考点）。

## 5. 解题思路

1. 取先序首字符 = 根，在中序中定位该根，得到左、右子树的**结点集**；
2. 用左子树结点数 $k$ 回到先序串，切出先序中的左子树段（紧随根的 $k$ 个字符）与右子树段；
3. 对左、右子树递归执行 1～2，直到区间长度为 1（叶结点）或为 0（空）；
4. 画出树形后按"左→右→根"写后序；
5. **反查**：用还原出的树重新做一次先序与中序，与题目给定的两个串逐字符比对，全等才交卷。

## 6. 详细解答

**（1）第一层：定根 A**

先序 $A\,|\,BDG\,|\,CEFH$，中序 $DGB\,|\,A\,|\,ECHF$。
根为 $A$；中序中 $A$ 左侧 $DGB$（3 个）为左子树结点，右侧 $ECHF$（4 个）为右子树结点。
按结点数回切先序：左子树先序 $BDG$，右子树先序 $CEFH$。

**（2）左子树（先序 $BDG$，中序 $DGB$）**

根 $B$；中序 $DGB$ 中 $B$ 在**最后** ⇒ $B$ 的左子树结点为 $D,G$（2 个），右子树为空。
先序去掉 $B$ 剩 $DG$ ⇒ 左子树：先序 $DG$、中序 $DG$。
- 根 $D$；中序 $DG$ 中 $D$ 在**最前** ⇒ $D$ 的左子树为空，右子树为 $G$。
⇒ $B$ 的左孩子为 $D$，$D$ 的右孩子为 $G$。

**（3）右子树（先序 $CEFH$，中序 $ECHF$）**

根 $C$；中序中 $C$ 左侧 $E$（1 个）为左子树，右侧 $HF$（2 个）为右子树。
先序去掉 $C$ 后按 $1:2$ 切分：左子树先序 $E$，右子树先序 $FH$。
- 左子树：单结点 $E$ ⇒ $C$ 的左孩子为 $E$（叶）。
- 右子树：先序 $FH$、中序 $HF$ ⇒ 根 $F$；中序中 $F$ 左侧为 $H$ ⇒ $H$ 是 $F$ 的**左**孩子。
⇒ $C$ 的右孩子为 $F$，$F$ 的左孩子为 $H$。

**（4）还原的二叉树**

```
        A
      /   \
     B     C
    /     / \
   D     E   F
    \       /
     G     H
```

即：$D$ 是 $B$ 的**左**孩子（$B$ 无右孩子），$G$ 是 $D$ 的**右**孩子（$D$ 无左孩子），$E$ 是 $C$ 的左孩子，$F$ 是 $C$ 的右孩子，$H$ 是 $F$ 的**左**孩子（$F$ 无右孩子）。

**（5）求后序（左 → 右 → 根）**

- $B$ 的子树：左子树为 $D$，而 $D$ 无左孩子、右孩子为 $G$ ⇒ 先 $G,D$；$B$ 无右孩子 ⇒ 再访问 $B$ ⇒ $G,D,B$；
- $C$ 的左子树 $E$ ⇒ $E$；$C$ 的右子树 $F$（左孩子 $H$）⇒ $H,F$；再访问 $C$ ⇒ $E,H,F,C$；
- 最后访问根 $A$。

$$\text{后序}=G,D,B,E,H,F,C,A$$

**（6）反查验证（用还原的树重做先序与中序）**

- 先序（根左右）：$A$ → 左子树 $B,D,G$（$B$ 的左孩子 $D$，$D$ 的右孩子 $G$）→ 右子树 $C,E,F,H$ = $A,B,D,G,C,E,F,H$ ✓ 与题给 $ABDGCEFH$ 一致
- 中序（左根右）：左子树中序 $G,D,B$ → $A$ → 右子树中序 $E,C,H,F$ = $D,G,B,A,E,C,H,F$ ✓ 与题给 $DGBAECHF$ 一致
- 结点数核对：$8=8$，无重复无遗漏 ✓

两序列同时吻合，说明还原唯一正确，后序结果可靠。

**交叉验证（免画树的纯序列算法）**：后序可由"先序串与中序串递归 + 结果串按左右根拼接"直接写出：
$\text{post}(A)=\text{post}(BDG,DGB)+\text{post}(CEFH,ECHF)+A=(GDB)+(EHFC)+A=GDBEHFCA$ ✓

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

由先序定根、中序分左右，递归还原：

$$A\big(B\big(D(\varnothing,G),\varnothing\big),\;C(E,F(H,\varnothing))\big)$$

按"左—右—根"遍历得

$$\boxed{GDBEHFCA}$$

## 9. 易错点

1. **中序切分后忘记回头切先序**：只按中序分左右，会把先序串按错误长度分配（例如右子树先序误取 $CEF$），必须用"左子树结点数 $k$"这个整数来切先序的左段；
2. 把"$D$ 在 $B$ 的左侧（中序）"误当成"$D$ 是 $B$ 的左孩子"——中序只能确定**集合归属**，孩子方向要结合先序中 $D$ 紧跟 $B$ 且 $B$ 的左子树非空/为空来定；本题 $B$ 的中序右侧为空，故 $D$ 挂在左侧、而 $G$ 又因中序 $DG$ 中 $D$ 在前而成为 $D$ 的**右**孩子；
3. 后序写成先序或层序（本题树形不对称，写错方向立刻对不上任何校验）；
4. 只反查一种序列：先序 + 中序、后序 + 中序才能唯一确定二叉树，**先序 + 后序不能**，所以校验时务必用"中序"这一维。

## 10. 一句话规律

"先序 + 中序 → 后序"三步走：**先序定根、中序分左右、按左子树结点数回切先序**；画完树一定要用原两序列反查一遍再落笔。
