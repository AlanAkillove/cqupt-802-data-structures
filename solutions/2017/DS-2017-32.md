# DS-2017-32

## 1. 原题

已知某字符串 $S$ 中共有 $8$ 种字符，各种字符分别出现 $1$ 次、 $2$ 次、 $7$ 次、 $5$ 次、 $4$ 次、 $3$ 次、 $4$ 次和 $9$ 次，对该字符串用 `{0,1}` 进行前缀编码。

（1）请画出对应的 $Huffman$ 树，并给出各字符的前缀编码；

（2）请问该字符串 $S$ 的编码有多少位？

## 2. 答案

按题面出现顺序记八个字符为 $c_1\sim c_8$，权值（出现次数）依次为 $1,2,7,5,4,3,4,9$，总长 $\sum w_i=35$。

**(1) Huffman 树**（括号内为结点权值，约定左子树标 $0$、右子树标 $1$）：

```
                        (35)
                /                  \
            (15)                    (20)
           /    \                  /     \
       c3(7)    (8)             c8(9)    (11)
               /  \                      /   \
          c5(4)  c7(4)              c4(5)   (6)
                                                /  \
                                             (3)   c6(3)
                                            /  \
                                        c1(1)  c2(2)
```

各字符前缀编码：

| 字符 | 权 | 编码长度 | 一种编码 |
|---|---|---|---|
| c1 | 1 | 5 | 11100 |
| c2 | 2 | 5 | 11101 |
| c3 | 7 | 2 | 00 |
| c4 | 5 | 3 | 110 |
| c5 | 4 | 3 | 010 |
| c6 | 3 | 4 | 1111 |
| c7 | 4 | 3 | 011 |
| c8 | 9 | 2 | 10 |

**(2)** 字符串 $S$ 的编码总位数 $=$ WPL $= 98$ 位。

## 3. 题目分析

- 已知：$8$ 个字符的频度 $1,2,7,5,4,3,4,9$（合计 $35$ 个字符）；
- 目标：(1) 构造 Huffman 树并给出前缀编码；(2) 求整个串编码后的总位数；
- 关键约束：前缀编码要求任一字符的编码都不是另一字符编码的前缀 ⟹ 字符必须落在二叉树的**叶子**上；总位数 $=\sum w_i\times l_i$ 即树的带权路径长度 WPL；
- 命题意图：考 Huffman 建树的贪心过程（每步取两个最小权值合并）与"WPL 就是编码总长"这一层含义的对应，两问是同一棵树的两个侧面。

## 4. 核心考点

核心考点：
DS03.04.01 哈夫曼树与哈夫曼编码（建树过程、编码长度分配、WPL 计算）

辅助考点：
DS03.01 树的基本概念（路径长度、叶子深度，WPL 的定义载体）

解释：本题第 (1) 问的作图与编码即 Huffman 算法本身；第 (2) 问把"编码有多少位"翻译成 WPL，需要用到"权 $w_i$ 的编码长度 = 该叶子所在层数 $l_i$"这一对应。

## 5. 解题思路

1. 把权值排序：$1,2,3,4,4,5,7,9$；
2. 反复"取出两个最小、合并后放回"，共 $8-1=7$ 次合并，每次合并产生的新权值记入表；
3. 树成后自根向下标 $0/1$（左 $0$ 右 $1$），叶子的编码即路径上的数字串，长度即该叶子深度；
4. 第 (2) 问按 $\sum w_il_i$ 求和；再用"所有内部结点权值之和 = WPL"复核，两数相同即可定稿；
5. 检查是否最优：本题每步取的两个最小值都无并列歧义，故树的**形态唯一**（只可能左右子树互换、$0/1$ 定义互换），编码方案不唯一但长度分布与 WPL 唯一。

## 6. 详细解答

### (1) 建树过程

| 步骤 | 当前权值集合（升序） | 取出的两个最小 | 合并新权 |
|---|---|---|---|
| 初态 | 1, 2, 3, 4, 4, 5, 7, 9 | — | — |
| 1 | 3, 4, 4, 5, 7, 9, **(3)** | 1, 2 | 3（记 $n_1$） |
| 2 | 4, 4, 5, 7, 9, **(6)** | 3, 3（$n_1$ 与 $c_6$） | 6（$n_2$） |
| 3 | 5, 6, 7, 9, **(8)** | 4, 4（$c_5,c_7$） | 8（$n_3$） |
| 4 | 7, 8, 9, **(11)** | 5, 6（$c_4$ 与 $n_2$） | 11（$n_4$） |
| 5 | 9, 11, **(15)** | 7, 8（$c_3$ 与 $n_3$） | 15（$n_5$） |
| 6 | 15, **(20)** | 9, 11（$c_8$ 与 $n_4$） | 20（$n_6$） |
| 7 | **(35)** | 15, 20（$n_5$ 与 $n_6$） | 35（根） |

$8$ 个叶子 $\Rightarrow 7$ 次合并、$7$ 个度为 $2$ 的分支结点，总结点数 $8+7=15=2\times8-1$ ✓（$n_0=n_2+1$ 的必然结果，可用来检查树有没有建错结点个数）。

**由树读编码**（左 $0$ 右 $1$，见第 2 节的图）：

- 根 → 左 $n_5$ → 左 $c_3$：$c_3=00$；根 → 左 $n_5$ → 右 $n_3$ → 左/右：$c_5=010,\ c_7=011$；
- 根 → 右 $n_6$ → 左 $c_8$：$c_8=10$；根 → 右 $n_6$ → 右 $n_4$ → 左 $c_4$：$c_4=110$；
- $n_4$ → 右 $n_2$ → 左 $n_1$ → 左/右：$c_1=11100,\ c_2=11101$；$n_2$ → 右 $c_6$：$c_6=1111$。

**前缀性质检查**：权大的字符（$c_8=9,c_3=7$）码长最短（$2$ 位），权小的（$c_1=1,c_2=2$）码长最长（$5$ 位）；且所有编码都在叶子终止，无一条是另一条的前缀。完全前缀码校验：$\sum 2^{-l_i}=2\cdot\frac14+3\cdot\frac18+\frac1{16}+2\cdot\frac1{32}=\frac12+\frac38+\frac1{16}+\frac1{16}=\frac{8+6+1+1}{16}=1$ ✓（恰为 $1$ 说明树没有空叶子，是 Huffman 树的特征）。

### (2) 编码总位数

$$
\begin{aligned}
\text{总位数}&=\sum_{i=1}^{8} w_i l_i\\
&=1\times5+2\times5+7\times2+5\times3+4\times3+3\times4+4\times3+9\times2\\
&=5+10+14+15+12+12+12+18=98
\end{aligned}
$$

**复核（内部结点权值之和法）**：Huffman 树的 WPL 等于所有分支结点权值之和，即

$$3+6+8+11+15+20+35=98\quad\checkmark$$

两法一致，故 $S$ 的编码共 $98$ 位。

**对照等长编码**：$8$ 种字符若用 $3$ 位定长码，总长 $35\times3=105$ 位，Huffman 编码为 $98$ 位，节省 $7$ 位，量级合理。

## 7. 选项分析

不适用（问答题）。

## 8. 考场标准答案

**(1)** 权值排序 $1,2,3,4,4,5,7,9$，依次合并 $1+2=3$、$3+3=6$、$4+4=8$、$5+6=11$、$7+8=15$、$9+11=20$、$15+20=35$，得第 2 节所示 Huffman 树（$15$ 个结点，$8$ 个叶子）。左支标 $0$、右支标 $1$，读得编码：

$$c_3=00,\ c_8=10,\ c_4=110,\ c_5=010,\ c_7=011,\ c_6=1111,\ c_1=11100,\ c_2=11101$$

（编码方案不唯一，但各字符码长 $\{2,2,3,3,3,4,5,5\}$ 与树形唯一。）

**(2)**

$$\text{总位数}=\mathrm{WPL}=\sum w_il_i=98\ \text{位}$$

## 9. 易错点

1. 合并时未每轮重新排序，取到非最小的两个权（例如第 4 步误取 $7+8$，正确应取 $5+6$）——每轮都要在**当前集合**里取两个最小；
2. 忘记"新合并出的权值要放回集合继续参与比较"，导致树退化成链；
3. 把"WPL"与"字符种数 $\times$ 码长"混淆：第 (2) 问是 $\sum w_il_i$（按**出现次数**加权），不是 $\sum l_i=25$；
4. 用"叶子数 $=8$ ⟹ 树高 $=3$"的定长思维，误判码长；Huffman 树不是完全二叉树，各叶子深度可不同；
5. 编码写完后未验证前缀性质（如把 $c_6=1111$ 与 $c_1=11100$ 写混会破坏前缀性）。

## 10. 一句话规律

Huffman 题三查：查合并是否每轮取两最小、查结点数是否 $2n_0-1$、查 WPL 是否等于"内部结点权值之和"——三关全过，编码总位数基本不会错。
