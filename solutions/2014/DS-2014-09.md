# DS-2014-09

## 1. 原题

数组 $A$ 中，每个元素 $A[i][j]$ 的长度为 $4$ 个字节，行下标 $i$ 从 $1$ 到 $8$ ，列下标从 $1$ 到 $10$ ，从首地址 $S$ 开始连续存放在存储器内，该数组按行优先存放时，元素 $A[5][6]$ 的起始地址为（）。

> 订正说明转录：源文作“每个元素 $A$ 的长度”，据题意修正为“每个元素 $A[i][j]$ 的长度”（与 2012/2013 年同型题表述一致）。

A. $S+160$

B. $S+180$

C. $S+220$

D. $S+140$

## 2. 答案

**B**（$S+180$）。

## 3. 题目分析

- 已知：$R=8$ 行（$i:1\sim8$）、$C=10$ 列（$j:1\sim10$）共 $80$ 个元素；每个元素占 $L=4$ 字节；$A[1][1]$ 的起始地址为 $S$；存放方式**行优先**；
- 目标：求元素 $A[5][6]$ 的**起始地址**；
- 关键约束：① 下界都是 $1$，公式中要出现 $i-1$、$j-1$；② 行优先时"跳过一整行"的 stride 是**列数 $C=10$**（不是行数 $8$）；③ "起始地址"只累加该元素**之前**的元素所占字节，不含自身；
- 命题意图：二维数组地址计算通式，区分度集中在"stride 取列还是取行""下界要不要减 1""含不含自身"三处误算上。

## 4. 核心考点

核心考点：
DS02.04 多维数组的存储（行优先地址公式 $Loc(A[i][j])=S+\big((i-i_0)C+(j-j_0)\big)L$，$i_0,j_0$ 为下标下界）

解释：本题是 $i_0=j_0=1$ 的一般情形，与 DS-2013-09（同维界、每元素 3 字节、求 $A[8][5]$）、DS-2012-09（下标从 $0$ 起）同型；不涉及压缩存储（DS02.05），故不列辅助考点。

## 5. 解题思路

1. 定 stride：行优先 ⟹ 行内列下标变化最快，跨一整行加**列数 $10$**；
2. 数"它前面有几个元素"：前面完整行 $i-1=4$ 行 ⟹ $4\times10=40$ 个；本行内它之前 $j-1=5$ 个；合计 $45$ 个；
3. 换算字节并加首地址：$45\times4=180$ ⟹ $S+180$；
4. 三重自查：首元素 $A[1][1]$ 应得 $S$；末元素 $A[8][10]$ 应得 $S+(70+9)\times4=S+316$，且 $80\times4=320$ 字节的区间 $[S,S+319]$ 能容纳它；
5. 换一条路复算（先走到本行行首再沿行内前进）与列优先对照，确认其余三个选项的来源。

## 6. 详细解答

**参数**：$R=8$、$C=10$、$L=4$ 字节、$S=Loc(A[1][1])$。

**行优先地址公式（下标从 1 起）**

$$Loc(A[i][j])=S+\big((i-1)\times C+(j-1)\big)\times L$$

**代入** $(i,j)=(5,6)$：

$$(5-1)\times10+(6-1)=40+5=45\ (\text{个元素位于其前})$$
$$Loc(A[5][6])=S+45\times4=S+180$$

**第二种走法（交叉验证）**：先求第 $5$ 行行首，再沿行内右移。

$$Loc(A[5][1])=S+(5-1)\times10\times4=S+160$$
$$Loc(A[5][6])=Loc(A[5][1])+(6-1)\times4=S+160+20=S+180\ \checkmark$$

两法一致；且 $S+160$ 恰为选项 A——它不是错误答案，而是**另一个元素**（$A[5][1]$）的正确地址，说明 A 是"漏算行内偏移"的陷阱值。

**关键位置排表**

| 元素 | 前面元素数 $(i-1)C+(j-1)$ | 起始地址 |
|---|---|---|
| $A[1][1]$ | $0$ | $S$ |
| $A[1][10]$ | $9$ | $S+36$ |
| $A[2][1]$ | $10$ | $S+40$ |
| $A[4][10]$ | $39$ | $S+156$ |
| $A[5][1]$ | $40$ | $S+160$（选项 A） |
| $A[5][6]$ | $45$ | $S+180$ ✓ |
| $A[5][10]$ | $49$ | $S+196$ |
| $A[6][1]$ | $50$ | $S+200$ |
| $A[8][10]$ | $79$ | $S+316$ |

**总空间核对**：数组共 $8\times10=80$ 个元素，占 $320$ 字节，地址区间 $[S,\,S+319]$。$S+180$ 落在区间内且 $180=45\times4$ 与元素边界对齐 ✓；末元素起始 $S+316$（其后 3 字节属于它自身）✓。选项 C 的 $S+220$ 虽也在区间内，但 $220=55\times4$ 对应 $55$ 个前驱元素，比正确值多整行（$10$ 个），来源见第 7 节。

**列优先对照（若题面改为列优先）**：stride 变为行数 $R=8$，

$$Loc=S+\big((j-1)R+(i-1)\big)L=S+(5\times8+4)\times4=S+176$$

不在四个选项中，说明本题未把"行优先/列优先看反"设为陷阱，干扰集中在"漏项/多算行"上。

**答案**：B。

## 7. 选项分析

- A. $S+160$：错。$160=40\times4$，$40=(5-1)\times10$ ——只算了前 $4$ 整行，**漏掉本行内 $A[5][1]\sim A[5][5]$ 这 5 个前驱**（即把 $A[5][6]$ 当成 $A[5][1]$）；
- B. $S+180$：正确。$4\times10+5=45$ 个元素在前，$45\times4=180$ 字节；
- C. $S+220$：错。$220=55\times4$，$55=5\times10+5=(i\times C+(j-1))$——行偏移**漏减下界 1**（把"前面 5 整行"当作偏移，多算了整个第 5 行的 10 个元素）。下标从 $1$ 起必须先化为 $0$ 起；
- D. $S+140$：错。$140=35\times4$，$35=3\times10+5$——行偏移又少算了一整行（把"前 4 行"错当成"前 3 行"），属于纯粹的整行漏算型错误。

## 8. 考场标准答案

行优先、下界为 $1$，列数 $C=10$、元素长 $L=4$：

$$Loc(A[i][j])=S+\big((i-1)C+(j-1)\big)L$$
$$Loc(A[5][6])=S+(4\times10+5)\times4=S+45\times4=\boxed{S+180}$$

选 **B**。

## 9. 易错点

1. **stride 取错**：行优先时"跳一整行"乘的是列数 $10$；行数 $8$ 只在列优先时使用；
2. **忘记下界**：$i,j$ 从 $1$ 起，必须写 $(i-1)C+(j-1)$；直接代 $iC+j$ 会多 $\big(C+1\big)\times L=44$ 字节（算成 $S+224$），只漏减行则得选项 C；
3. **含不含自身**：起始地址 = 首地址 + 前面元素的总字节数，若把 $A[5][6]$ 自身也算进去得 $(45+1)\times4=184$（不在选项中，但属填空题典型误区）；
4. **漏乘 $L$**：把偏移元素个数 $45$ 直接当地址增量写成 $S+45$；
5. 混淆"起始地址"与"存放该元素的最后一个字节"：后者是 $S+180+3=S+183$。

## 10. 一句话规律

地址计算题的通式永远是"数它前面有几个元素，再乘单元大小"：行优先 ⟹ 前驱个数 $=(\text{行下标}-\text{行下界})\times\text{列数}+(\text{列下标}-\text{列下界})$；算完用首元素（必须得 $S$）与末元素（必须落在总字节数内）两个边界各验一次。
