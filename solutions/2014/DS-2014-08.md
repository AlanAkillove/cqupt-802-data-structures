# DS-2014-08

## 1. 原题

在长度为 $n$ 顺序实现的线性表的第 $i$ ( $1 \leq i \leq n$ )个位置之前插入一个元素，需要后移（）个元素。

A. $i$

B. $n-i+1$

C. $n$

D. $1$

## 2. 答案

**B**（后移 $n-i+1$ 个元素）。

## 3. 题目分析

- 已知：顺序存储的线性表，表长 $n$，元素记作第 $1\sim n$ 个；插入位置是"第 $i$ 个位置**之前**"，$1\le i\le n$；
- 目标：为给新元素腾出位置，需要向后移动（后移）多少个原有元素；
- 关键约束：顺序表必须保持"逻辑相邻 ⟹ 物理相邻"，插入后原第 $i$ 个元素要被挤到第 $i+1$ 个位置，因此**从第 $i$ 个到第 $n$ 个的元素全体都要移动**（含第 $i$ 个自身、含表尾）；
- 命题意图：考"移动区间的端点是否含自身"这一 $\pm1$ 细节，并与删除情形（前移 $n-i$ 个，见 DS-2012-02）配成一组对照。

## 4. 核心考点

核心考点：
DS01.02.01 顺序存储（顺序表插入操作的元素移动次数；教材 `ListInsert` 中"依次从最后一个元素起向后移动"的循环次数）

解释：本题只涉及顺序存储的搬移计数，与链表定位（本卷 DS-2014-07）恰好是同一操作在两种存储下的代价对照，故不列辅助考点。同一知识点在 DS-2005-01（第 $i$ 个元素之前插入需移动 $n-i+1$ 个）、DS-2012-02（第 $i$ 个位置删除需前移 $n-i$ 个）、DS-2012-22（等概率插入的平均移动 $\frac n2$）中各出现一次。

## 5. 解题思路

1. 画下标轴，把元素分成三段：$1\sim i-1$（不动）｜$i\sim n$（要搬）｜空位；
2. 数要搬的个数：区间 $[i,n]$ 的长度 $=n-i+1$（两端都含，因为 $a_i$ 自己也要让位）；
3. 用两个极端位置验算：$i=1$（插在表头）应移 $n$ 个、$i=n$（插在最后一项之前）应移 $1$ 个，只有 $n-i+1$ 同时满足；
4. 与删除对照防混：删除第 $i$ 个元素时移动区间是 $[i+1,n]$，共 $n-i$ 个——插入比删除恰好多搬一个（就是 $a_i$ 本身）。

## 6. 详细解答

**区间计数法**

插入前表内元素下标为 $1,2,\dots,n$。在第 $i$ 个位置之前插入 $e$，插入后要求

$$\underbrace{a_1,\dots,a_{i-1}}_{\text{位置不变}},\ e,\ \underbrace{a_i,\dots,a_n}_{\text{整体后移一格}}$$

需移动的元素恰是下标区间 $[i,n]$，个数为

$$n-i+1$$

**极端位置验算**

| 插入位置 | 移动区间 | 应移个数 | A $i$ | B $n-i+1$ | C $n$ | D $1$ |
|---|---|---|---|---|---|---|
| $i=1$（表头之前） | $[1,n]$ | $n$ | $1$ ✗ | $n$ ✓ | $n$ ✓ | $1$ ✗ |
| $i=2$ | $[2,n]$ | $n-1$ | $2$ ✗ | $n-1$ ✓ | $n$ ✗ | $1$ ✗ |
| $i=n$（末元素之前） | $[n,n]$ | $1$ | $n$ ✗ | $1$ ✓ | $n$ ✗ | $1$ ✓ |

只有 B 在三档位置上全部相符（A 仅在 $i=1,n$ 巧合相等，C 仅在 $i=1$ 对，D 仅在 $i=n$ 对）。

**代码核对**（教材 `ListInsert` 的搬移循环）

```c
for (j = L.length; j >= i; --j) L.elem[j+1] = L.elem[j];   /* j 从 n 递减到 i，共 n-i+1 次 */
L.elem[i] = e;  ++L.length;
```

循环变量 $j$ 依次取 $n,n-1,\dots,i$，执行次数 $=n-i+1$，与区间计数一致。顺序自后向前是为了避免覆盖。

**平均情形（延伸一步，非本题所问）**：若 $i$ 在 $1\sim n+1$ 上等概率取值（含表尾插入，此时移动 $0$ 个），平均移动次数为

$$\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac{n}{2}$$

——本题限定 $1\le i\le n$，问的是**单个指定位置**上的移动个数，不是平均数（平均数见 DS-2012-22、本卷 DS-2014-38）。

**答案**：B。

## 7. 选项分析

- A. $i$：错。$i$ 是"插入点**之前**有多少个元素"（即不需移动的个数），恰好与应移动者相反；$i=1$ 时它给 $1$，但插在表头要搬走全部 $n$ 个；
- B. $n-i+1$：正确。移动区间 $[i,n]$ 含两端，$a_i$ 本身也要让位；
- C. $n$：错。把任何位置都当成"插在表头"，忽略了 $i$ 的影响；
- D. $1$：错。把"新元素自己写入一个位置"误当成"只挪一个元素"，或只在 $i=n$ 这一档巧合正确。

## 8. 考场标准答案

第 $i$ 个位置之前插入，原第 $i\sim n$ 个元素必须整体后移一格（含 $a_i$ 自身），共

$$n-i+1\ \text{个}$$

（$i=1$ 时移 $n$ 个，$i=n$ 时移 $1$ 个。）选 **B**。

## 9. 易错点

1. **$\pm1$ 混淆**：插入是 $n-i+1$、删除是 $n-i$，差别就在"被插入位置上的原元素要不要搬"与"被删除元素本身已被取走"；
2. 把"第 $i$ 个位置之前插入"误读为"新元素成为第 $i$ 个元素、需先移开第 $i$ 个之后的元素"——结论其实相同，但若题目说"在第 $i$ 个元素**之后**插入"，移动区间就变成 $[i+1,n]$，即 $n-i$ 个，务必看清"之前/之后"；
3. 忽略本题取值范围只到 $i\le n$：完整插入还应包含 $i=n+1$（表尾插入，移动 $0$ 个），题干未列入，故选项中没有 $0$；若题目把范围写成 $1\le i\le n+1$（如 DS-2007-04、DS-2017-12），公式仍是 $n-i+1$，只是取值多了 $0$；
4. 搬移方向写反：必须**自后向前**依次后移，从 $a_i$ 开始后移会覆盖后继元素。

## 10. 一句话规律

顺序表上的移动计数一律"画出下标轴、圈出要搬的连续区间、用两端都含的区间长度公式 $\text{右}-\text{左}+1$ 求解"，最后再用表头/表尾两个极端位置各验一次，$\pm1$ 绝不会再错。
