# DS-2014-07

## 1. 原题

在长度为 $n$ 且带头结点的链式存储实现的线性表的第 $i$ ( $0 \leq i \leq n$ )个位置插入一个元素，需要查找运算（）次。

A. $1$

B. $n-i$

C. $i$

D. $n-2$

## 2. 答案

**C**（$i$ 次）。

## 3. 题目分析

- 已知：带头结点的单链表，表长 $n$；插入位置编号 $i$ 的取值范围是 $0\le i\le n$——这恰好是"$n$ 个结点的表有 $n+1$ 个可插入位置"那一套编号，$i=0$ 表示插在最前面（头结点之后），$i=n$ 表示插在表尾；
- 目标：统计完成一次插入所需的**查找（定位）次数**；
- 关键约束：链表没有随机存取，插入前必须先找到**新结点的前驱**；带头结点时前驱是"第 $i$ 个结点"（把头结点记作第 $0$ 个结点），从头结点到第 $i$ 个结点要走 $i$ 条 `next` 链；
- 命题意图：考"链表插入的代价 = 定位前驱的遍历代价"，并把顺序表的"移动 $n-i+1$ 个元素"（本卷 DS-2014-08）作为干扰项 B，把"已给结点指针的后插 $O(1)$"作为干扰项 A。

## 4. 核心考点

核心考点：
DS01.02.02 链式存储：单链表（`GetElem`/`ListInsert` 必须先遍历找前驱；头结点的编号作用）

辅助考点：
DS01.02.01 顺序存储（顺序表：插入/删除与移动次数）——选项 B 的 $n-i$ 正来自顺序表的移动计数，需辨明"移动的个数"与"查找的次数"是两回事

解释：本题问的是链式结构的定位代价，主考点在单链表；与顺序表的搬移次数对照才算完整，故列辅助。头结点之所以存在，就是为了让 $i=0$（插在表头）与其余位置的处理统一，这一点正是本题取值范围的用意。

## 5. 解题思路

1. 定编号：带头结点，令头结点为第 $0$ 个结点，数据元素依次是第 $1\sim n$ 个结点；"第 $i$ 个位置插入"即把新结点挂在第 $i$ 个结点之后，使其成为第 $i+1$ 个元素（$i=0$ 时成为第 1 个元素，$i=n$ 时成为最后一个元素，范围 $0\sim n$ 与"$n+1$ 个插入位置"完全吻合）；
2. 找前驱：必须从 `L`（头结点）出发沿 `next` 走 $i$ 步，每步算一次查找运算 ⟹ $i$ 次；
3. 用标准算法的循环验证：`while (p && j < i) { p = p->next; ++j; }`（`p` 初值为首地址、`j` 初值为 0）的循环体恰执行 $i$ 次；
4. 边界复核：$i=0$ 时 $0$ 次（前驱就是头结点，无需查找）、$i=n$ 时 $n$ 次（走到表尾）；若 $i>n$ 则查找失败；
5. 反证约定：若改用"插入后成为第 $i$ 个元素"（$1\le i\le n+1$）那一套编号，答案应是 $i-1$ 次，而 $i-1$ 不在选项中——说明题面的 $0\le i\le n$ 采用的正是"在第 $i$ 个结点之后插入"的约定，选 C。

## 6. 详细解答

**第一步：定位是谁**

带头结点单链表插入的标准写法：

```c
Status ListInsert(LinkList L, int i, ElemType e) {
    LinkList p = L;  int j = 0;
    while (p && j < i) { p = p->next; ++j; }      /* 查找到第 i 个结点（新元素的前驱） */
    if (!p) return ERROR;                          /* i > n，插入位置不合法 */
    LinkList s = (LinkList)malloc(sizeof(LNode));
    s->data = e;  s->next = p->next;  p->next = s; /* 以下两步与查找次数无关，O(1) */
    return OK;
}
```

循环条件 `j<i` 且 `p` 从**头结点**（第 $0$ 个结点）起走，循环体执行 $i$ 次，即做 $i$ 次"沿 `next` 移动指针"的查找运算。

**第二步：分位置核对（取 $n=5$）**

| 插入位置 $i$ | 新元素成为第几个 | 前驱结点 | 从头结点出发的 `next` 次数 |
|---|---|---|---|
| $0$ | 第 $1$ 个 | 头结点本身 | $0$ |
| $1$ | 第 $2$ 个 | 第 $1$ 个结点 | $1$ |
| $2$ | 第 $3$ 个 | 第 $2$ 个结点 | $2$ |
| $4$ | 第 $5$ 个 | 第 $4$ 个结点 | $4$ |
| $5$ | 第 $6$ 个（表尾） | 尾结点 | $5=n$ |

查找次数随 $i$ 线性增长，恰为 $i$；$i=n$ 时最坏 $n$ 次，故"按位插入"的时间复杂度仍是 $O(n)$（对照 DS-2007-04 顺序表插入的 $O(n)$，两者代价来源不同：一个是遍历，一个是搬移）。

**第三步：与"移动次数"区分（第二角度）**

同样一个 $i$，顺序表插入要后移 $n-i+1$ 个元素（本卷 DS-2014-08），单链表插入移动元素数为 $0$、但查找要 $i$ 次。两式一个随 $i$ 增、一个随 $i$ 减，取两个极端即可看出绝不可能相等：$i=0$ 时链表查 $0$ 次而顺序表移 $n+1$ 项（按本卷题面范围则为 $i=1$ 移 $n$ 项）；$i=n$ 时链表查 $n$ 次而顺序表只移 $1$ 项。故 B（$n-i$）是把顺序存储的搬移计数搬到了链表上。

**答案**：C。

## 7. 选项分析

- A. $1$：错。"常数次"只有在**已经给出前驱结点的指针**时才成立（如本卷 DS-2014-06 中尾指针直达尾结点、或 DS-2019-23 那类"在已知结点 $*p$ 之后插入"），本题只给位置序号，必须先遍历；
- B. $n-i$：错。这是顺序表相关的量（删除第 $i$ 个元素需前移 $n-i$ 个，见 DS-2012-02），链表的代价不在"搬移剩余结点"而在"走到位"；且 $i=0$ 时它给 $n$，与"插在最前面只需 0 次查找"矛盾；
- C. $i$：正确。头结点记作第 $0$ 个结点，走到第 $i$ 个结点（前驱）需 $i$ 次指针移动；
- D. $n-2$：错。与插入位置 $i$ 无关的常数，取 $n=5$ 时它恒为 $3$，而 $i=0$ 应查 $0$ 次、$i=5$ 应查 $5$ 次，两者都不符；任何不含 $i$ 的式子都无法描述"逐结点向后走"的过程；

## 8. 考场标准答案

选 **C**。

带头结点单链表中把头结点记为第 $0$ 个结点，在第 $i$（$0\le i\le n$）个位置插入即把新结点插入第 $i$ 个结点之后，须先从头结点沿 `next` 移动 $i$ 次找到该前驱，故查找运算 $i$ 次；随后的 `s->next=p->next; p->next=s;` 为 $O(1)$。最坏 $i=n$ 需 $n$ 次，故按位插入的时间复杂度为 $O(n)$。

## 9. 易错点

1. **两套位置编号混用**：本题 $0\le i\le n$ 表示"在第 $i$ 个结点之后插入"（答案为 $i$ 次）；若题目写成 $1\le i\le n+1$（如 DS-2007-04、DS-2017-12 的表述，"第 $i$ 个位置"指插入后成为第 $i$ 个元素），则前驱是第 $i-1$ 个结点，查找 $i-1$ 次。审题先看**取值范围**就能确定是哪一套；
2. 把顺序表的移动次数 $n-i+1$（或删除的 $n-i$）直接搬到链表上（选 B）：链表不搬元素，代价全在遍历；
3. 忘记"带头结点"这一条件：若不带头结点，$i=0$（插在表头）需要单独修改头指针，教材因此才引入头结点，使所有位置统一为"找前驱 + 后插"；
4. 只答"查找次数"却漏掉"插入本身的 $O(1)$"：若题目改问总时间复杂度，答案是 $O(n)$ 而不是 $O(1)$。

## 10. 一句话规律

链表上"按序号插入/删除"的代价永远等于"从头（结）点走到前驱需要几次指针移动"：先确认题目用的是"在第 $i$ 个结点之后"（走 $i$ 步）还是"成为第 $i$ 个元素"（走 $i-1$ 步），再看是带头结点（第 $0$ 个结点是头结点）还是不带头结点，一步一算即可。
