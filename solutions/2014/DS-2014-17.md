# DS-2014-17

## 1. 原题

下面的关键码序列中哪一个是堆（）？

A. $18,72,35,23,94,53$

B. $18,31,23,94,53,72$

C. $18,53,23,94,40,72$

D. $94,55,18,72,16,23$

## 2. 答案

**B**（$18,31,23,94,53,72$ 是**小根堆**）。

## 3. 题目分析

- 已知：四个长度为 $6$ 的关键码序列，按**层次序**（自上而下、自左而右）解释为一棵完全二叉树上结点的关键字；
- 目标：找出满足**堆定义**的那一个；
- 关键约束：
  1. 堆的定义：$n$ 个元素的序列 $\{k_1,\dots,k_n\}$ 满足
     $$k_i\le k_{2i}\ \wedge\ k_i\le k_{2i+1}\quad(\text{小根堆，凡 } 2i\le n,\ 2i+1\le n)\qquad\text{或}\qquad k_i\ge k_{2i}\ \wedge\ k_i\ge k_{2i+1}\quad(\text{大根堆})$$
     两种口径都算堆，判定时须**各试一遍**；
  2. 下标关系依赖"完全二叉树 $+$ 层序存储"：结点 $i$ 的左、右孩子编号为 $2i$、$2i+1$（$n=6$ 时的父子对为 $(1,2),(1,3),(2,4),(2,5),(3,6)$，共 $5$ 对）；
  3. 堆只约束**父子之间**，**不约束兄弟之间**，也不要求层内有序——这是本题最主要的失分点（例如 B 中 $31>23$ 是兄弟关系，$94,53,72$ 层内也不有序，都不违反堆定义）；
  4. 堆顶必为全序列的极值（小根堆取到最小值、大根堆取到最大值），由此可先定方向再检验，省去一半工作量；
- 命题意图：考"堆 $=$ 完全二叉树 $+$ 局部父子序"这一双重定义的落地能力。四个选项都是"只差一两处父子倒置"的近堆序列，逼考生真正按编号逐对比较，而不是凭"看起来像不像排序好的"下判断。

## 4. 核心考点

核心考点：
DS06.07 堆与堆排序（堆的定义：小根堆/大根堆的父子不等式；堆的完全二叉树形态）

辅助考点：
DS03.02.02 二叉树的存储结构（顺序存储：以数组下标表达完全二叉树的父子关系，$i$ 的孩子是 $2i,2i+1$——判堆的全部技术前提就在这一条编号规则上）
DS03.02.01 二叉树的定义及主要特征（完全二叉树"自上而下、自左而右"编号的形态约束：$n=6$ 时第 3 个结点只有左孩子，故只需检验 $(3,6)$ 一对）

解释：题目直接问"哪个是堆"，主标签只能是 DS06.07；但把一维序列读成父子关系的能力属 DS03.02.02 的顺序存储（堆正是完全二叉树顺序存储的应用），故列辅助。本库中同节点的相邻考法是"判别给定序列是否为堆并指明大/小根"（DS-2013-32）、"建初始堆须从哪个结点开始调整"（DS-2012-36、本卷 DS-2014-36）、"堆的层次遍历是否有序"（DS-2006-21，答案为否，恰可印证本题第 9 节第 2 条）。

## 5. 解题思路

1. **先画树形**：把每个选项的 $6$ 个数按层序填入完全二叉树

   ```
        1
      /   \
     2     3
    / \   /
   4   5 6
   ```

   待检验的父子对固定为 $(1,2),(1,3),(2,4),(2,5),(3,6)$ 共 $5$ 对；
2. **定方向**：看堆顶。若堆顶是该序列的最小值，只可能是小根堆；若是最大值，只可能是大根堆；若两者都不是，直接排除；
3. **逐对检验**：按编号从小到大检验 $5$ 对父子，一旦找到反例即判否，并记下"第一处违反的父子对"（便于复查）；
4. 四个选项中恰好三个各有一处父子倒置、一个全部满足，全部满足者即答案；
5. **反向自查**：把候选答案的每对父子再口算一遍（或换用"从最后一个非终端结点 $\lfloor n/2\rfloor=3$ 往前逐个检查子树是否已成堆"的第二种流程），确认无误。

## 6. 详细解答

记序列为 $A[1..6]$，需检验 $5$ 对父子：$(1,2),(1,3),(2,4),(2,5),(3,6)$。

**A. $18,72,35,23,94,53$**

```
         18
       /    \
     72      35
    /  \    /
   23  94  53
```

堆顶 $18$ 是全序列最小值 ⟹ 只可能是小根堆。检验：
$A[1]=18\le A[2]=72$ ✓；$A[1]=18\le A[3]=35$ ✓；$A[2]=72\le A[4]=23$ **✗**（$72>23$，父子倒置）。
（大根方向更早失败：$A[1]=18\ge A[2]=72$ ✗。） **不是堆**。

**B. $18,31,23,94,53,72$**

```
         18
       /    \
     31      23
    /  \    /
   94  53  72
```

堆顶 $18$ 为最小值 ⟹ 检验小根堆的 $5$ 对：

| 父子对 | 比较 | 结果 |
|---|---|---|
| $(1,2)$ | $18\le 31$ | ✓ |
| $(1,3)$ | $18\le 23$ | ✓ |
| $(2,4)$ | $31\le 94$ | ✓ |
| $(2,5)$ | $31\le 53$ | ✓ |
| $(3,6)$ | $23\le 72$ | ✓ |

五条全部满足 ⟹ **是小根堆**。

**C. $18,53,23,94,40,72$**

```
         18
       /    \
     53      23
    /  \    /
   94  40  72
```

堆顶 $18$ 为最小值 ⟹ 检验小根堆：$(1,2):18\le53$ ✓、$(1,3):18\le23$ ✓、$(2,4):53\le94$ ✓、$(2,5):53\le40$ **✗**（$53>40$）。
与 B 相比，C 恰好是把 B 中 $A[5]=53$ 与 $A[6]=72$ 位置上的 $40$ 换进来，破坏了结点 $2$ 与其右孩子的关系 ⟹ **不是堆**。

**D. $94,55,18,72,16,23$**

```
         94
       /    \
     55      18
    /  \    /
   72  16  23
```

堆顶 $94$ 是全序列最大值 ⟹ 只可能是大根堆。检验：$(1,2):94\ge55$ ✓、$(1,3):94\ge18$ ✓、$(2,4):55\ge72$ **✗**（$55<72$，左孩子比父亲大）。
（小根方向：$(1,2):94\le55$ ✗。）⟹ **不是堆**。若把 $55$ 与 $72$ 对调得 $94,72,18,55,16,23$，则五条大根关系全部成立，那才是一个大根堆——本题的 D 正是"差一次交换"的近堆序列。

**（5）第二种流程复核（自底向上看子树）**

$n=6$ 时最后一个非终端结点编号为 $\lfloor 6/2\rfloor=3$。按"从 $i=3$ 递减到 $1$，每个 $i$ 只需检查以自己为根的子树是否已满足堆性质"的判据再过一遍 B：

- $i=3$：子树 $\{A[3]=23;\ A[6]=72\}$，$23\le72$ ✓（单孩子只需比一次）；
- $i=2$：子树 $\{A[2]=31;\ A[4]=94,A[5]=53\}$，$31\le94$、$31\le53$ ✓；
- $i=1$：$\{18;31,23\}$，$18\le31$、$18\le23$ ✓。

三棵子树自底向上均成立 ⟹ 整棵树是堆，与第（2）条结论一致。对 A、C、D 套用同一流程，分别在 $i=2$、$i=2$、$i=2$ 处失败（都是"结点 2 的孩子"出问题），可见本题三个干扰项是围绕同一位置构造的。

**答案**：B。

## 7. 选项分析

- A. $18,72,35,23,94,53$：不是堆。堆顶是最小值 $18$，只能按小根堆判，但结点 $2$ 的 $72$ 大于其左孩子 $23$（$A[2]>A[4]$），违反 $k_i\le k_{2i}$；典型误判是"只看第 1 层 $18<72<35$ 就认为成立"，忘了要一路查到叶子；
- B. $18,31,23,94,53,72$：**是堆（小根堆）**。五条父子不等式全部成立（第 6 节表格逐条核对），且第 3 个结点按完全二叉树形态只有左孩子 $72$，$23\le72$ 亦成立；
- C. $18,53,23,94,40,72$：不是堆。$A[2]=53>A[5]=40$，违反"父亲不大于右孩子"；它与正确项 B 只差一个位置上的数（$40$ 与 $53$ 的相对位置），是本题最具迷惑性的干扰项；
- D. $94,55,18,72,16,23$：不是堆。堆顶是最大值 $94$，只能按大根堆判，但 $A[2]=55<A[4]=72$，左孩子反而比父亲大，违反 $k_i\ge k_{2i}$；
- 通用提醒：四个选项都**不是**有序序列，"是不是堆"与"排没排好序"无关（DS-2006-21 即考"堆的层次遍历是否有序"，答案为否）。

## 8. 考场标准答案

堆须满足：按层序构成完全二叉树后，任一结点不大于（小根）或不小于（大根）其孩子，$n=6$ 时即检验 $(1,2),(1,3),(2,4),(2,5),(3,6)$ 五对。

- A：$18$ 为最小值，试小根堆，$72>A[4]=23$ ✗；
- B：$18\le31,18\le23,31\le94,31\le53,23\le72$ 全部成立 ✓ 为小根堆；
- C：$53>A[5]=40$ ✗；
- D：$94$ 为最大值，试大根堆，$55<A[4]=72$ ✗。

故选 **B**。

## 9. 易错点

1. **用下标相邻关系代替父子关系**：把"$A[i]$ 与 $A[i+1]$、$A[i+2]$ 比较"当成判据。正确关系是 $i$ 与 $2i,2i+1$；例如 A 中 $72$ 与 $23$ 之间隔着两个元素，只有画树才看得出它们是父子；
2. **误以为堆要求层内或整体有序**：堆只有"父亲优于孩子"的局部约束，兄弟之间大小任意（B 中 $31>23$、$94>53$ 都合法）。若强加层内有序，会把正确答案 B 判错；
3. **只试一个方向**：只看小根堆就排除 D，或只看大根堆就排除 A、B。规范做法是先看堆顶是否为全序列极值来定方向（堆顶既非最大又非最小则直接排除），再逐对检验；
4. **漏查最后一个非终端结点**：$n=6$ 时结点 $3$ 有左孩子 $6$，必须检验 $(3,6)$ 这一对；若忘了它，C 中"结点 3 与 $72$"这类关系就不会被检查（本题 C 已先在 $(2,5)$ 处失败，但别题未必如此）；
5. **把"完全二叉树"读成"满二叉树"**：$n=6$ 的堆形态第 3 层只有两个结点（编号 $5,6$ 分别是结点 $2$ 的右孩子与结点 $3$ 的左孩子），编号 $6$ 的父亲是 $3$ 而非 $2$ 或 $4$——按 $\lfloor i/2\rfloor$ 求父结点才不出错；
6. **与"建初始堆"的操作题混淆**：本题只**判别**，不需要调整；本卷 DS-2014-36 问的是"建初始堆必须从哪个结点开始调整"（答案是从最后一个非终端结点，即 $\lfloor n/2\rfloor$ 号结点开始），两者一静一动，勿混用结论。

## 10. 一句话规律

判堆三步：**按层序画完全二叉树 → 由堆顶是否为极值定大根/小根方向 → 逐对检验 $(i,2i)$ 与 $(i,2i+1)$（$i=1..\lfloor n/2\rfloor$）**；只要有一对父子倒置就不是堆，兄弟与层内的大小关系一律不作要求。
