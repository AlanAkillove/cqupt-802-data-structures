# DS-2014-47

## 1. 原题

现有某比赛活动中某选手的 $n$ 个评分结果（百分制，已知都在 $60$ 以上的整数）已存入顺序表中，并且已按升序排序。为了分析相关规律，现需分析评分的 $k-$ 均值直方图（以当前分数为中位数（位置在中间）），计算最邻近的 $k$ 个分数平均值并取为整数，然后统计分数的频率得到。若当前分左边或右边数据不足时直接忽略（不计入统计数据），请设计一尽量快速的算法，求得打印直方图前的统计结果。

> 订正说明转录：源文作"直接忽略，不计入统计数据）"，括号孤立（有右括号无左括号），据题意修正为"直接忽略（不计入统计数据）"。

（1）先给出设计思想；

（2）再描述具体算法，必要时请给予注释说明。

## 2. 答案

**设计思想（一句话）**：升序表中"包含 $A[i]$ 且让 $A[i]$ 落在正中间"的最邻近 $k$ 个元素一定是**下标连续的一段** $A[i-L\,..\,i+R]$，其中 $L=\lfloor (k-1)/2\rfloor$、$R=k-1-L$；相邻两段的和只相差"新进入的右端元素"与"被丢掉的左端元素"，故用**滑动窗口**把每段均值的代价从 $O(k)$ 降为 $O(1)$；左/右不够取的中心直接跳过；得到的整数平均值作为组别，在长度为 $41$（$60\sim100$）的频次数组上累加即得"打印直方图前的统计结果"。

**复杂度**：时间 $O(n+V)$（$V$ 为分数值域档数，本题 $V=41$，即 $O(n)$），空间 $O(V)=O(1)$（一个频次数组，不需辅助窗口数组）。朴素做法要对每个中心重新累加 $k$ 个元素，为 $O(nk)$。

**样例**（第 6.3 节走查）：$A=(62,65,70,71,80,85,90)$、$n=7$、$k=3$ ⟹ 统计结果

| 平均值（组别） | $65$ | $68$ | $73$ | $78$ | $85$ |
|---|---|---|---|---|---|
| 频率 | $1$ | $1$ | $1$ | $1$ | $1$ |

（$A[0]=62$ 与 $A[6]=90$ 两个中心因左边/右边数据不足被忽略。）

## 3. 题目分析

- 已知：$n$ 个**整数**评分，均在 $[60,100]$（"百分制、都在 $60$ 以上"），已存入**顺序表**且**按升序排序**（即非递减，可能有相等值）；给定窗口大小 $k$；
- 目标：对每个"中心"取以它为中位数的最邻近 $k$ 个分数，求平均值并**取为整数**，再统计这些整数值的**频率**，输出"打印直方图前的统计结果"——即一张 `(平均值, 出现次数)` 的表，不需要真的画直方图；
- 关键约束与题意解读：
  1. **"以当前分数为中位数（位置在中间）"**：$k$ 个分数排好后 $A[i]$ 要在正中间，故 $k$ 为奇数时左右各 $(k-1)/2$ 个，含义明确；$k$ 为偶数时"正中间"无法严格成立，本解析统一取 $L=\lfloor (k-1)/2\rfloor$、$R=k-1-L$（左侧少一个、右侧多一个），并在第 6.5 节给出另一种约定下的差异；
  2. **"左边或右边数据不足时直接忽略（不计入统计数据）"**：下标 $i<L$ 或 $i>n-1-R$ 的中心**整个跳过**，既不产生数据点、也不计入频率分母——因此有效统计量恰为 $n-k+1$ 个（$n\geqslant k$ 时）；
  3. **"平均值并取为整数"**：本解析采用**截断取整**（向下取整）$avg=\lfloor S/k\rfloor$，因为这是 C 语言整数除法的天然结果、与"取为整数"的字面最贴合；第 6.5 节另给四舍五入口径 `(2*S+k)/(2*k)`；
  4. **"尽量快速"**：这是复杂度得分点——必须优于 $O(nk)$，并说明为什么能 $O(1)$ 递推；
  5. 值域 $[60,100]$ 只有 $41$ 档，故频次统计可以用**计数数组**（下标偏移 $60$ 或直接开到 $101$），不必排序、不必动态结构；
- 命题意图：把"顺序表的随机访问特性"（DS01.02.01）与"有序 + 统计"的应用场景（DS01.03）结合，考查能否发现**滑动窗口递推**这一关键不变量，同时考查边界处理（数据不足者忽略）与复杂度表述能力。

## 4. 核心考点

核心考点：
DS01.02.01 顺序存储——顺序表（必须在 $O(1)$ 时间访问 $A[i-L]$ 与 $A[i+R]$ 才能完成窗口递推，这正是"顺序表随机访问"优于链表之处；同时"升序"是对**下标**有序，只有顺序存储才能用下标算术表达"最邻近的 $k$ 个"）

辅助考点：
DS01.03 线性表的应用（有序表上的区间统计、用频次数组做直方图，与"有序表合并""集合运算"同属线性表应用类问题）；DS00.02 算法与算法分析（语句频度：主循环 $n-k+1$ 次、每次常数次操作；与朴素 $O(nk)$ 的对比；空间 $O(V)$ 为常数的论证）

解释：题面的数据结构是"已排序的顺序表"，算法的全部效率来源都是顺序存储的随机访问 + 下标连续性，故主标签定 DS01.02.01（与规范中"算法设计题按所操作的数据结构定 primary_topic"的约定一致）；"统计频率/直方图"是应用侧，归 DS01.03；"尽量快速"与复杂度分析归 DS00.02。

## 5. 解题思路

1. **先把自然语言翻译成下标关系**：中心 $i$、窗口长度 $k$、$A[i]$ 居中 ⟹ 左 $L$ 右 $R$ 个元素。关键一问：为什么这 $k$ 个元素是**连续下标段**？
   反证/交换论证：若最优集合跳过了 $[i-L,\,i+R]$ 内的某个下标 $j$，则它必须从该区间之外补一个元素，而区间外的元素到 $i$ 的距离（按值或按位次）都不小于被跳过的 $j$，替换后"最邻近"程度不会更好 ⟹ 连续段即最优，且 $A[i]$ 居中 ⟹ 段被唯一确定为 $[i-L,\,i+R]$；
2. **由"升序"得到第二个免费结论**：中心右移一格，窗口整体右移一格，和的变化只发生在两端 ⟹ $S_{i+1}=S_i-A[i-L-1]+A[i+R+1]$（代码中写成进入循环时的 `S += A[i+R] - A[i-L-1]`，$i$ 为新中心），于是每步 $O(1)$；
3. **确定有效中心范围**：$i$ 从 $L$ 到 $n-1-R$，共 $n-k+1$ 个；范围之外正是题面说的"左边或右边数据不足"，直接跳过（不要放进频率、也不要记为 $0$）；
4. **统计容器**：`hist[101]`（或 `hist[41]` 配下标偏移 $60$），因为平均值必落在 $[\min A,\max A]\subseteq[60,100]$，取整后仍在该区间内，下标不会越界；
5. **先写暴力再优化**（考场策略）：先给出对每个中心累加 $k$ 个元素的 $O(nk)$ 版本确保逻辑正确，再把累加改成递推——这样即使时间复杂度没拿满，正确性分也在；
6. **验证四件事**（第 6.3、6.4 节）：手算样例的 $5$ 个窗口和；$\sum freq$ 是否等于 $n-k+1$；平均值序列是否非减（窗口和被升序保证单调）；$k=1$ 时是否退化为普通频次直方图。

## 6. 详细解答

### 6.1 数据结构与参数定义

```c
typedef int ElemType;

typedef struct {
    ElemType *elem;        /* 基地址：支持 O(1) 随机访问（算法快的前提） */
    int       length;      /* 元素个数 n，且 elem[0..n-1] 已按升序排列 */
} SqList;

#define LOW   60                    /* 评分下界（题设"都在 60 以上"） */
#define HIGH  100                   /* 百分制上界 */
#define VSIZE (HIGH + 1)            /* 频次数组大小：直接用分数值作下标 0..100 */
```

设窗口内 $k$ 个分数之和为 $S$，则整数平均值 $avg=S/k$（C 的整数除法即截断取整）。

### 6.2 主解：滑动窗口统计（教材风格 C）

```c
/* k-均值直方图统计
   A  : 升序顺序表，elem[0..length-1] 均在 [60,100]
   k  : 窗口大小（最邻近分数个数），k >= 1
   hist[0..100] : 调用前必须清零；返回后 hist[v] = 平均值为 v 的中心个数
   返回值 : 参与统计的中心个数（有效窗口数）
*/
int KMeansHist(SqList A, int k, int hist[])
{
    int n = A.length;
    int i, L, R, m = 0;
    long S = 0;                        /* 窗口和：k 较大时用 long 防溢出 */

    if (A.elem == NULL || n <= 0 || k <= 0) return 0;   /* 空表或非法参数 */
    if (k > n) return 0;                               /* 所有中心左右都不足，全部忽略 */

    L = (k - 1) / 2;                                   /* 中心左侧元素数（k 偶时少一个） */
    R = k - 1 - L;                                     /* 中心右侧元素数 */

    for (i = 0; i < k; i++) S += A.elem[i];            /* 窗口 [L-L .. L+R] = [0 .. k-1] 的和 */

    for (i = L; i <= n - 1 - R; i++) {                 /* 仅遍历左右都够取的中心 */
        if (i > L)                                     /* 窗口整体右移一格 */
            S += A.elem[i + R] - A.elem[i - L - 1];    /* 进一个右端元素、丢一个左端元素 */
        hist[S / k]++;                                 /* 平均值取整数，作为直方图组别 */
        m++;
    }
    return m;                                          /* m = n - k + 1 */
}
```

**初始化与打印**：

```c
void PrintHist(int hist[])                            /* 打印直方图前的统计结果 */
{
    int v;
    for (v = LOW; v <= HIGH; v++)
        if (hist[v] > 0) printf("%d: %d\n", v, hist[v]);
}

/* 调用 */
int hist[VSIZE];
int v, cnt;
for (v = 0; v < VSIZE; v++) hist[v] = 0;              /* 计数数组必须先清零 */
cnt = KMeansHist(SA, k, hist);
PrintHist(hist);
```

### 6.3 样例走查

$A=(62,65,70,71,80,85,90)$，$n=7$，$k=3$ ⟹ $L=1$、$R=1$，有效中心 $i=1..5$（$5=n-k+1$ 个）；$i=0$（左边不足）与 $i=6$（右边不足）被忽略。

| 中心 $i$ | $A[i]$ | 窗口下标 | 窗口元素 | 和 $S$ | $S/k$ 截断 | 递推动作 |
|---|---|---|---|---|---|---|
| $1$ | $65$ | $0..2$ | $62,65,70$ | $197$ | $65$ | 初值（累加前 $3$ 个） |
| $2$ | $70$ | $1..3$ | $65,70,71$ | $206$ | $68$ | $+A[3]=71$、$-A[0]=62$ |
| $3$ | $71$ | $2..4$ | $70,71,80$ | $221$ | $73$ | $+A[4]=80$、$-A[1]=65$ |
| $4$ | $80$ | $3..5$ | $71,80,85$ | $236$ | $78$ | $+A[5]=85$、$-A[2]=70$ |
| $5$ | $85$ | $4..6$ | $80,85,90$ | $255$ | $85$ | $+A[6]=90$、$-A[3]=71$ |

**统计结果**：$65,68,73,78,85$ 各出现 $1$ 次（$\sum freq=5=n-k+1$ ✓；平均值序列 $65<68<73<78<85$ 非减 ✓，与 6.4 的单调性论证一致）。

### 6.4 正确性与复杂度

**窗口选取的正确性**：见第 5 节第 1 步的交换论证——$A[i]$ 居中 ⟹ 需左 $L$ 个、右 $R$ 个；升序 ⟹ 下标 $i-L..i+R$ 就是按位次"最邻近"的 $k$ 个；下标越界 ⟺ 左右数据不足 ⟺ 题面要求忽略。三者合起来正好把题面翻译成 $i\in[L,\,n-1-R]$ 上的窗口遍历。

**递推的正确性**：第 $i$ 个窗口是 $[i-L,\ i+R]$、第 $i+1$ 个是 $[i+1-L,\ i+1+R]$，两者相差"丢掉 $i-L$、加入 $i+1+R$"，故 $S_{i+1}=S_i+A[i+1+R]-A[i-L]$；代码里循环变量已自增到新中心 $i$，等价写作 `S += A[i+R] - A[i-L-1]`，且 $i=L$ 时不递推、直接用初值，避免越界访问 $A[-1]$。

**单调性（可用于自检）**：$S_{i+1}-S_i=A[i+R]-A[i-L]\geqslant 0$（升序、$i+R>i-L$），故窗口和及其截断均值随 $i$ 非减——若打印出的组别出现"先大后小"，说明递推或下标写错。

**复杂度**：初始化窗口 $O(k)$；主循环执行 $n-k+1$ 次，每次只做 $2$ 次下标访问、$2$ 次算术与 $1$ 次计数累加，故 $O(n)$；打印 $O(V)$（$V=41$）。总时间 $O(n+V)=O(n)$，空间 $O(V)=O(1)$（不随 $n$ 增长，无辅助数组）。与朴素法对比：

```c
/* 朴素对照版：每个中心重新累加 k 个元素，O(n*k) */
int KMeansHist_BF(SqList A, int k, int hist[])
{
    int i, j, L = (k - 1) / 2, R = k - 1 - (k - 1) / 2, m = 0;
    for (i = L; i <= A.length - 1 - R; i++) {
        int S = 0;
        for (j = i - L; j <= i + R; j++) S += A.elem[j];   /* 每次从头累加 */
        hist[S / k]++;  m++;
    }
    return m;
}
```

两版对第 6.3 节样例（$k=3$）以及同一序列上 $k=1$、$k=4$、$k=7$、$k=8$ 的运行结果完全相同（$k=1$ 得 $62,65,70,71,80,85,90$ 各 $1$ 次、$m=7$；$k=4$ 得 $67,71,76,81$ 各 $1$ 次、$m=4$；$k=7$ 唯一中心 $i=3$、窗口和 $523$、均值 $74$、$m=1$；$k=8>n$ 直接返回 $0$），互为验证。

### 6.5 口径讨论与偶数 $k$（并列说明，不静默取舍）

- **取整口径**：主解用截断（向下取整）$S/k$。若要四舍五入，把 `hist[S/k]++` 改成 `hist[(2*S + k) / (2*k)]++`（正整数情形下等价于 $\lfloor S/k+0.5\rfloor$）。以样例 $i=1$ 为例：$197/3=65.67$ ⟹ 截断 $65$、四舍五入 $66$；$k=4$ 时 $286/4=71.5$ ⟹ 截断 $71$、四舍五入 $72$。两种口径会给出不同的组别，故**答卷必须先声明口径**；
- **偶数 $k$**：$k=4$ 时主解取 $L=1,R=2$（中心左侧少一个）；另一常见约定取 $L=2,R=1$（右侧少一个）。两种约定下遍历到的**窗口集合完全相同**——都是长度为 $k$ 的连续段 $[0..k-1],[1..k],\dots,[n-k..n-1]$ 共 $n-k+1$ 个，只是每个窗口被算作"以哪个分数为中心"不同，故**频率统计结果不受影响**（对第 6.3 节样例两种约定都得到 $67,71,76,81$ 各 $1$ 次）。真正受口径影响的只有"打印时把平均值挂到哪个原始分数名下"，答题时把 $L=\lfloor (k-1)/2\rfloor$ 写明即可；硬约束是 $L+R+1=k$；
- **$k>n$**：任何中心都无法凑齐 $k$ 个分数，统计结果为空（主解直接返回 $0$），符合"左右数据不足则忽略"；
- **$k=1$**：$L=R=0$，每个元素都是自己的窗口，$avg=A[i]$，算法退化为普通频次直方图——可用来对拍（对第 6.3 节样例应输出 $62,65,70,71,80,85,90$ 各 $1$ 次，$m=n=7$）。

不适用（算法设计题）。

## 8. 考场标准答案

**(1) 设计思想**：评分已按升序存于顺序表，故"与 $A[i]$ 最邻近的 $k$ 个分数且使 $A[i]$ 居中"必是连续段 $A[i-L..i+R]$，其中 $L=\lfloor (k-1)/2\rfloor$、$R=k-1-L$。左（右）边不足即 $i<L$（$i>n-1-R$），该中心不统计。相邻两个中心对应的段只相差首尾两个元素，所以段和可递推：$S\leftarrow S+A[i+R]-A[i-L-1]$，每次 $O(1)$；平均值 $S/k$ 取整数后作为直方图的组别，在长度为 $101$（实际只用 $60\sim100$ 共 $41$ 档）的频次数组上累加。总代价由朴素 $O(nk)$ 降为 $O(n)$。

**(2) 具体算法**：`KMeansHist`（见第 6.2 节，含注释）——先判空表/非法 $k$/$k>n$；算 $L,R$；累加第一个窗口和；`for(i=L; i<=n-1-R; i++)` 内除首轮外做窗口滑动，`hist[S/k]++`。

**(3) 复杂度**：时间 $O(n+V)$，$V$ 为分数值域档数（$V=41$，视为常数）⟹ $O(n)$；空间 $O(V)=O(1)$（一个频次数组），递归栈无。样例 $(62,65,70,71,80,85,90)$、$k=3$ 的统计结果为 $65:1,\ 68:1,\ 73:1,\ 78:1,\ 85:1$（$62$ 与 $90$ 两个中心被忽略）。

## 9. 易错点

1. **把"最邻近 $k$ 个"误解为"值相差不超过 $k$"**：题面 $k$ 是**元素个数**（第 6.3 节 $k=3$ 即三个分数），不是差值阈值；
2. **忽略条件写错或漏掉一侧**：只判左边 $i\geqslant L$ 而忘了右边 $i\leqslant n-1-R$，会使 $A[n-1]$ 附近的中心越界访问；被忽略的中心**不能记为频率 $0$ 计入统计**，否则 $\sum freq$ 与 $n-k+1$ 不符；
3. **递推写成 `S += A[i+R] - A[i-L]`**：丢掉的应是"新窗口左端之外的那个"元素 $i-L-1$，写成 $i-L$ 就把窗口自己唯一的元素减掉了；$i=L$ 那一轮必须用初值、不递推（否则访问 $A[-1]$）；
4. **取整口径不明**：$197/3=65.67$，截断得 $65$、四舍五入得 $66$；不声明就会被判"组别错"，答题时要写"以下用整数除法截断（或：以下四舍五入）"；
5. **频次数组没清零 / 下标范围不够**：`hist` 是累加容器，必须先置 $0$；只开 $41$ 格则要写成 `hist[S/k-LOW]`，忘减偏移量会越界；
6. **没用"升序"这个前提**：若先排序再套用本算法则时间下界变成 $O(n\log n)$；题面已给出有序，**重新排序是多余的**，正确做法是直接依赖下标连续性（这也是本题"尽量快"的题眼）；
7. **改用链表或每轮重算**：链表不能随机访问，窗口递推退化；每轮重算退化为 $O(nk)$，都不满足"尽量快速"；
8. **$k$ 为偶数时纠结"正中位"**：应先声明约定（$L=\lfloor (k-1)/2\rfloor$）再给算法，不要出现左右个数加起来不等于 $k$ 的错误（$L+R+1=k$ 是硬约束）。

## 10. 一句话规律

"有序表 + 固定长度的邻近窗口 + 求每窗口某统计量"这类题，先问统计量能否**递推**：和、最大值之外的可减量都可以 $O(1)$ 滑动（本题是窗口和），把 $O(nk)$ 降到 $O(n)$；而"平均值取值范围很小"又允许用**计数数组**代替排序，于是整题只剩一趟线性扫描。
