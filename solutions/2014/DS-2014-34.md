# DS-2014-34

## 1. 原题

高度为 $5$ 的 $AVL$（平衡二叉树）至少有____________________ 个结点。（空树高度为 $0$）

## 2. 答案

$12$ 个结点。

即高度 $5$ 的 AVL 最少结点数 $N(5)=12$；由 $N(4)=7$ 可知 $11$ 个结点最多只能搭出高度 $4$，必须到 $12$ 个才"够高"。

## 3. 题目分析

- 已知：一棵 $AVL$ 树（**平衡二叉排序树**：树上任一结点的左、右子树高度之差的绝对值不超过 $1$），高度 $h=5$，且括号已约定**空树高度为 $0$**（故高度 $5$ 就是 $5$ 层结点，根在第 $1$ 层）；
- 目标：结点总数的**最小值**；
- 关键约束：
  1. 要让结点尽量省，根的两棵子树高度要"一高一矮"，但平衡条件把矮的那边卡在 $\ge h-2$，故极小时两子树高度只能是 $\{h-1,\;h-2\}$；
  2. 若取 $\{h-1,h-1\}$（同高）则结点是 $2N(h-1)+1$，比 $\{h-1,h-2\}$ 更"胖"，不是最少；若取 $\{h-1,h-3\}$ 则违反 $|BF|\le 1$，不合法；
  3. 最优子结构：这两棵子树本身也必须分别是高度 $h-1$、$h-2$ 时的**极小** AVL，否则可整体替换得更小；
  4. 与普通二叉树的区别：不带平衡条件时高度 $5$ 最少只要 $5$ 个结点（单支链，见本年度第 29 题的反向情形）；AVL 禁止"单链下降"，下界被抬高；
- 命题意图：考 AVL 的 Fibonacci 型最少结点数递推 $N(h)=N(h-1)+N(h-2)+1$ 及其初值，以及"空树高度为 $0$"这一约定对初值的影响。与本年度第 29 题（$20$ 个结点的二叉树高度至少为几）是同族"高度↔结点数"极值互推问题，但多了一道平衡条件的闸。

## 4. 核心考点

核心考点：

辅助考点：

解释：递推式完全依赖"$|$左子树高 $-$ 右子树高$|\le 1$"这一 AVL 特有约束——去掉它答案立刻变成 $5$，故主考点为 DS05.07.02；而递归分解、高度约定属二叉树一章的基本性质（DS03.02.01），列为辅助。本题不需要写查找过程，故不挂 TRACE。

## 5. 解题思路

1. **设元**：令 $N(h)$ 为高度 $h$ 的 AVL 树的最少结点数；
2. **列递推**：极小时根的子树高度为 $h-1$ 与 $h-2$，且各自也取极小 ⟹ $N(h)=N(h-1)+N(h-2)+1$；
3. **定初值**：按题面约定 $N(0)=0$（空树）、$N(1)=1$（只有一个根）；
4. **逐层算到 $h=5$**：$1,2,4,7,12$；
5. **构造回验**：按 $\{h-1,h-2\}$ 递归画出一棵高度 $5$、$12$ 个结点的 AVL，逐点检查平衡因子 $\in\{-1,0,1\}$，确认下界**可达**（只证下界不构造，可能算出取不到的数）；
6. **换闭式再验**：$N(h)=F_{h+2}-1$（$F$ 为 Fibonacci 数），$N(5)=F_7-1=13-1=12$ ✓。

## 6. 详细解答

**第一步：递推式的严格推导**

设 $T$ 是高度 $h$ 且结点最少的 AVL，根结点左、右子树高度为 $h_L,h_R$。

- $T$ 的高度 $=\max(h_L,h_R)+1=h$ ⟹ 较大者为 $h-1$；
- 平衡条件 $|h_L-h_R|\le 1$ ⟹ 较小者 $\ge h-2$；
- 较小者若 $=h-1$（同高），结点数为 $2N(h-1)+1>N(h-1)+N(h-2)+1$（因 $N(h-1)>N(h-2)$），不是极小；
- 故极小时 $\{h_L,h_R\}=\{h-1,h-2\}$，且两子树必须各自极小，于是

$$N(h)=N(h-1)+N(h-2)+1,\qquad N(0)=0,\;N(1)=1$$

**第二步：逐层计算**

| $h$ | $0$ | $1$ | $2$ | $3$ | $4$ | $5$ |
|---|---|---|---|---|---|---|
| $N(h)$ | $0$ | $1$ | $2$ | $4$ | $7$ | $\mathbf{12}$ |

$$N(2)=N(1)+N(0)+1=1+0+1=2$$
$$N(3)=N(2)+N(1)+1=2+1+1=4$$
$$N(4)=N(3)+N(2)+1=4+2+1=7$$
$$N(5)=N(4)+N(3)+1=7+4+1=12$$

（$h=2$ 时 $2$ 个结点即"根 $+$ 一个孩子"，平衡因子为 $1$，合法——这一步是整条递推最容易算错的关口，误取 $N(2)=3$ 会连锁得到 $N(5)=20$。）

**第三步：构造验证（下界可达）**

按 $T(h)\to\{T(h-1),\,T(h-2)\}$ 展开，得到高度 $5$、$12$ 个结点的极小 AVL（$n_i$ 为编号，左右方向可镜像）：

```
              n1(h5)
          /            \
     n2(h4)            n5(h3)
     /     \           /     \
  n3(h3)  n4(h2)   n6(h2)  n8(h1)
   /   \    /        /
n9(h2) n10 n11     n12
   \
   n7(h1)
```

各内部结点的子树高度核对：

| 结点 | 左子树高 | 右子树高 | 自身高度 | 平衡因子 |
|---|---|---|---|---|
| $n_1$ | 4 | 3 | 5 | $+1$ ✓ |
| $n_2$ | 3 | 2 | 4 | $+1$ ✓ |
| $n_5$ | 2 | 1 | 3 | $+1$ ✓ |
| $n_3$ | 2 | 1 | 3 | $+1$ ✓ |
| $n_4$ | 1 | 0 | 2 | $+1$ ✓ |
| $n_6$ | 1 | 0 | 2 | $+1$ ✓ |
| $n_9$ | 0 | 1 | 2 | $-1$ ✓ |
| $n_7,n_8,n_{10},n_{11},n_{12}$ | 0 | 0 | 1 | $0$ ✓ |

计数核对：左子树（$n_2$ 及后代）$7$ 个 $+$ 右子树（$n_5$ 及后代）$4$ 个 $+$ 根 $1$ 个 $=12$ ✓；按层计数 $1+2+4+4+1=12$ ✓（第 $5$ 层只有 $n_7$ 一个结点，故整树高度确为 $5$ ✓）。所有结点 $|BF|\le 1$，确为 AVL ⟹ $12$ 可取到。

**第四步：闭式与上界对照（交叉验证）**

- **Fibonacci 闭式**：$N(h)=F_{h+2}-1$，其中 $F_1=F_2=1,\,F_3=2,\,F_4=3,\,F_5=5,\,F_6=8,\,F_7=13$。代入 $h=5$：$N(5)=F_7-1=13-1=12$ ✓（与递推同值，构成独立校验）；
- **上界对照**：高度 $5$ 的 AVL **最多**结点数即满二叉树 $2^5-1=31$；**最少** $12$。本题问后者；
- **与本年度第 24 题对照**：第 $5$ 层上最多 $2^{5-1}=16$ 个结点是"层"的口径，$12$ 是"整棵树"的口径，两题同为 $h=5$ 但量不同，不可混用；
- **与不带平衡条件的情形对照**：高度 $5$ 的普通二叉树最少只需 $5$ 个结点（单支链）。$12>5$ 正是平衡条件的代价。

**答案**：$12$。

## 8. 考场标准答案

设 $N(h)$ 为高度 $h$ 的 AVL 最少结点数。极小时根的两子树高度为 $h-1$ 与 $h-2$，且各自也取极小：

$$N(h)=N(h-1)+N(h-2)+1,\quad N(0)=0,\;N(1)=1$$

$$N(2)=2,\;N(3)=4,\;N(4)=7,\;N(5)=7+4+1=\boxed{12}$$

## 9. 易错点

1. **初值/第二层取错**：误以为"高度 $2$ 的最少 AVL 必须有根加两个孩子"而取 $N(2)=3$，随后 $N(3)=6,N(4)=10,N(5)=17$ 全错。正确：$N(2)=2$（根 $+$ 一个孩子，$|BF|=1$ 合法）；
2. **高度约定混用**：题面括号给出"空树高度为 $0$"，即高度 $5$ 含 $5$ 层结点（与本年度第 24、29 题同一约定）。若误用"叶子高度为 $0$/根的高度为 $0$"的约定，"高度 $5$"变成 $6$ 层，会算出 $N(6)=N(5)+N(4)+1=20$；
3. **忘 $+1$**：写成 $N(h)=N(h-1)+N(h-2)$，漏掉根结点，得 $N(5)=11$；
4. **与"最少结点的普通二叉树/树"混淆**：没有平衡条件时高度 $5$ 最少 $5$ 个结点（单支）；有"禁止度为 $1$ 的结点"这类条件时是 $2h-1=9$。三种约束三个答案（$5/9/12$），先确认题目给的是哪一条；
5. **与"最多结点"或"完全二叉树"混淆**：$2^5-1=31$ 是最多；把 AVL 当成完全二叉树来"数最少"没有意义——AVL 允许不平衡到 $|BF|=1$ 的程度，正是这个"允许的偏斜"使结点数最省；
6. **只做逆问题时代入错误**：由 $N(5)=12$ 可得"$12$ 个结点的 AVL 最大高度为 $5$、$11$ 个结点最高 $4$"，若把 $12$ 当成"高度 $5$ 的上界"就会反向出错。

## 10. 一句话规律

"给定高度求 AVL 最少结点数"只有一条 Fibonacci 递推 $N(h)=N(h-1)+N(h-2)+1$（$N(0)=0,N(1)=1$）：根的另一个子树取"平衡条件允许的最矮"（差 $1$）且自身也要极小；列表算完后一定要画一棵出来验证 $|BF|\le 1$，并顺手记住对照表 $0,1,2,4,7,12,20,33,54$。
