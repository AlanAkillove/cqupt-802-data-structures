# DS-2014-06

## 1. 原题

如果某应用在线性表中最常用的操作是在最后一个元素之后插入一个元素和删除第一个元素，则采用（）存储方式最节省运算时间。

A. 仅有头指针的单链表

B. 仅有头指针的单循环链表

C. 双链表

D. 仅有尾指针的单循环链表

## 2. 答案

**D**（仅有尾指针的单循环链表）。

## 3. 题目分析

- 已知：应用只频繁使用两项操作——① 在**最后一个元素之后**插入；② 删除**第一个元素**；候选结构的差别仅在"是否循环、是否双向、保留哪个外链指针"；
- 目标：让这两项操作的时间代价之和最小（实质是两项都要 $O(1)$）；
- 关键约束：链表里只有**拿到某结点的地址**才能常用地修改它周围的指针。头结点/首元结点由头指针直接给出，尾结点则不然——除非结构能把尾结点暴露出来；
- 命题意图：考"单循环链表增设**尾指针**后，`rear->next` 即头结点，一个指针同时提供首、尾两个入口"这一教材结论；A、B、C 的共性缺陷都是"没有尾结点的现成地址"，双向指针解决的是"找前驱"而不是"找尾巴"。

## 4. 核心考点

核心考点：
DS01.02.03 链式存储：双向链表与循环链表（含双向循环）——循环链表中外链指针的选取（头指针 vs 尾指针）对操作代价的决定作用

辅助考点：
DS01.02.02 链式存储：单链表（表尾插入必须遍历定位）
DS01.02.01 顺序存储（顺序表：插入/删除与移动次数）——用于反证"表头删除"在顺序存储下要前移 $n-1$ 个元素

解释：决定性因素是"循环 + 尾指针"这一形态，属 DS01.02.03；判断 A、B、C 的代价要用单链表遍历（DS01.02.02），与顺序存储对照则要用移动次数结论（DS01.02.01，本卷 DS-2014-08 即该点）。本题与 DS-2013-04 题干、选项完全相同，属跨年度重复题。

## 5. 解题思路

1. 把操作翻译成"需要直达哪个结点"：尾插 ⟹ 需要**尾结点**；删首 ⟹ 需要**头结点（或首元结点）**；
2. 逐结构检查这两个地址能否 $O(1)$ 获得（见第 6 节表）：凡只给头指针的结构，找尾都要 $O(n)$；
3. 对候选 D 具体写出两项操作的指针修改语句，确认确实只花常数次，并检查表空、表长 1 的边界；
4. 顺带与"顺序表"对照，确认题目问的"最节省运算时间"落在链式一侧；
5. 结论 D。

## 6. 详细解答

**逐项代价核算**（设表长 $n$，各结构均带头结点，"仅××指针"表示只有那一个外链）

| 结构 | 在最后一个元素之后插入 | 删除第一个元素 | 瓶颈 |
|---|---|---|---|
| A. 仅头指针的单链表 | $O(n)$：须沿 `next` 走到 `next==NULL` 的尾结点 | $O(1)$：`head->next` 即首元 | 找尾 |
| B. 仅头指针的单循环链表 | $O(n)$：仍须走到 `next==head` 的那个结点，"循环"并未提供尾地址 | $O(1)$ | 找尾（与 A 同阶） |
| C. 双链表（头指针、非循环） | $O(n)$：`prior` 指针只帮"向前找前驱"，向尾仍要顺 `next` 走完 | $O(1)$：改 `head->next` 与新首元的 `prior` | 找尾 |
| D. 仅尾指针的单循环链表 | $O(1)$：`rear` 即尾结点 | $O(1)$：`rear->next` 即头结点 | 无 |

**D 的操作实现（验证确实常数次）**

带头结点，`rear` 指尾结点，则 `rear->next` 为头结点 `*h`。

① 尾部插入 `*s`：

```c
s->next = rear->next;   /* 新结点指向头结点 */
rear->next = s;         /* 原尾结点接上新结点 */
rear = s;               /* 尾指针随之移到新尾，仍是 O(1) */
```

② 删除第一个元素：

```c
h = rear->next;             /* 头结点 */
p = h->next;                /* 首元结点 = 第一个元素 */
if (p != h) {               /* 表非空 */
    h->next = p->next;          /* 头结点越过 p */
    if (p == rear) rear = h;    /* 删的是唯一结点：尾指针指回头结点 */
    free(p);
}
```

两项均为常数次指针操作 ⟹ $O(1)$。边界检查：表空（`rear == rear->next`，即 `rear` 指着头结点）时①仍正确（`s->next=h; h->next=s; rear=s`）；表长 1 时②中 `p == rear` 分支必须执行，否则 `rear` 悬空——这正是"仅尾指针"方案唯一需要额外小心的地方，也是它比"同时保存头、尾两个指针"更省空间却不更慢的原因。

**与顺序存储对照（确认题目方向）**：顺序表尾部插入 $O(1)$（只需可能扩容），但删除第一个元素要把其余 $n-1$ 个元素全部前移，为 $O(n)$（见本卷 DS-2014-08 的移动计数）；两项合计仍劣于 D 的 $O(1)+O(1)$。

**答案**：D。

## 7. 选项分析

- A. 仅有头指针的单链表：错。删除首元素 $O(1)$，但表尾插入必须遍历 $n$ 个结点才能找到尾，$O(n)$；
- B. 仅有头指针的单循环链表：错。循环只保证"从尾能回到头"，从头出发找尾依旧要走完整个表；把单向改成"环"而没有保留尾地址，代价不变——这是最容易与 D 混淆的一项；
- C. 双链表：错。`prior` 域解决的是"给定结点找前驱"（如 DS-2013-38 那类"删除 $*p$ 的前驱"），本题两项操作都不需要前驱，反而多付一个指针域的空间；找尾仍是 $O(n)$；
- D. 仅有尾指针的单循环链表：正确。`rear` 给尾结点地址（尾插 $O(1)$），`rear->next` 给头结点地址（删首 $O(1)$），一个指针换来两个入口。

## 8. 考场标准答案

选 **D**。

尾插需要尾结点地址、删首需要头结点地址。A、B、C 都只保留头指针，找尾结点一律 $O(n)$（`prior` 域帮不上忙）。只有"带头结点的单循环链表 + 尾指针 `rear`"能同时直达两端：尾插 `s->next=rear->next; rear->next=s; rear=s;`；删首通过 `rear->next` 取到头结点后摘除首元（表长为 1 时同步令 `rear=rear->next`）。两项均 $O(1)$，故最省运算时间。

## 9. 易错点

1. 误以为"循环"本身就带来尾部快速访问（选 B）：循环链表的价值取决于**保留哪个外链指针**，只留头指针时找尾仍是 $O(n)$；
2. 误以为"双向就能两头跑"（选 C）：`prior` 是"结点内向前"的能力，与"从表头跳到表尾"无关；只有**双向循环链表 + 尾指针**才两头都 $O(1)$；
3. 忽略删首时 `p==rear` 的特判：表里只剩一个元素时，删掉它之后必须把 `rear` 指回头结点，否则尾指针指向已释放结点；
4. 把"最节省运算时间"读成"最省空间"：D 的代价是每个结点一个指针域且省去头指针，空间也较小，但选项比较的是时间。

## 10. 一句话规律

链表选型题的固定解法是"把每个常用操作翻译成'要直达哪个结点'，再看该结点能否由现成的外链指针一步取得"——头指针给头、尾指针给尾、循环让尾指针顺带给出头、`prior` 域只给前驱。
