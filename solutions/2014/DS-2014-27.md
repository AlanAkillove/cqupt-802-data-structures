# DS-2014-27

## 1. 原题

采用特殊字符作为结尾的顺序存储方式存储，若两个串的长度分别为 $m$ 和 $n$ ，则两个串相等与否的比较运算的时间复杂度为____________________ 。

## 2. 答案

$O(\min(m,n))$（写作 $O(MIN(m,n))$；即比较次数与**两串中较短者**的长度同阶，最坏情形约 $\min(m,n)+1$ 次字符比较）。

## 3. 题目分析

- 已知：两个串以"**特殊字符作结尾的顺序存储**"表示——串值存放在一块连续字符数组中，串尾紧跟一个不会出现在串内容中的结束标记（如 `'\0'`），**数组中不另设长度域**，串长只能靠扫描到结束标记才知；两串长度分别为 $m$、$n$；
- 目标：判定两串是否相等这一运算的时间复杂度；
- 关键约束：
  1. 串相等的定义是"**长度相等且各对应位置上的字符都相同**"（两条件缺一不可）；
  2. 在"只有结束标记、没有长度域"的存储约定下，判等只能**从第 $1$ 个字符起同步扫描**：逐位比较，一旦某位不同即判不等；两串同时到达结束标记即判相等；
  3. 扫描过程中**较长的串永远扫不到自己超出较短串的那部分**——一遇到短串的结束标记与长串的实字符不匹配就终止了，故比较次数由 $\min(m,n)$ 决定，而不是 $m+n$ 或 $\max(m,n)$；
- 命题意图：把绪论的"最坏情况量级分析"落到串这一具体结构上，考两件事——① 是否清楚串相等的**充要**定义；② 是否会找**最坏情形**（前缀完全相同）并给出与 $m,n$ 相关的量级，而不是笼统写 $O(n)$。

## 5. 解题思路

1. **先写定义**：$S=T\iff len(S)=len(T)$ 且 $\forall i\le len(S): S[i]=T[i]$——两个条件在"无长度域"的存储下都得靠扫描字符来实现；
2. **定基本操作**：取"一次字符比较"为原操作，数最坏情况下比较多少次；
3. **找最坏情形**：两串**前缀完全相同**时才可能比得最久。分两种情况——
   - $m=n$：前 $m$ 位全同则再比结束标记即判相等，共 $m$ 次字符比较（连同结束标记一起比则 $m+1$ 次）；有一位不同即提前结束，不超过 $m+1$；
   - $m\ne n$（设 $m<n$）：即使前 $m$ 位全同，第 $m+1$ 位上 $S$ 已是结束标记、$T$ 仍是实字符，比较即判不等，共 $m+1=\min(m,n)+1$ 次；
4. **取量级**：两种情形都是 $\min(m,n)+1$ ⟹ $O(\min(m,n))$；
5. **验达界**：构造 $S=$`aaa`、$T=$`aaab`（$m=3,n=4$）实际比一遍，确认恰为 $4=\min+1$ 次，说明上界不是虚设。

## 6. 详细解答

**步骤 1：存储形态与比较算法**

题面约定的存储（以 `'\0'` 为结束标记）示意：

```
S: [ s1 ][ s2 ]...[ sm ][ '\0' ]        （占用 m+1 个字符单元）
T: [ t1 ][ t2 ]...[ tn ][ '\0' ]        （占用 n+1 个字符单元）
```

判等的标准实现是**同步下标扫描**（连同结束标记一起比较）：

```c
/* 串以 '\0' 结尾的顺序存储；返回 1 表示两串相等，0 表示不等 */
int StrEqual(char S[], char T[])
{
    int i = 0;
    while (S[i] != '\0' && T[i] != '\0' && S[i] == T[i])
        i++;                                  /* 每轮做字符比较 */
    return (S[i] == T[i]) ? 1 : 0;            /* 同为 '\0' 才相等 */
}
```

**步骤 2：最坏情况计数**

设 $p$ 为两串**从头起连续相同字符的个数**。循环在第 $p+1$ 位终止（$p$ 至多为 $\min(m,n)$）：

| 情形 | 终止原因 | 字符比较次数 |
|---|---|---|
| $m=n$ 且两串相同 | $p=m$，第 $m+1$ 位双方同为 `'\0'` | $m+1$（若只统计实字符则为 $m$） |
| $m=n$ 且首个不同位在第 $k$ 位 | $S[k]\ne T[k]$ | $k\le m=\min(m,n)$ |
| $m<n$，前 $m$ 位全同 | 第 $m+1$ 位 `'\0'` $\ne t_{m+1}$ | $m+1=\min(m,n)+1$ |
| $m<n$，首个不同位在第 $k\le m$ 位 | $S[k]\ne T[k]$ | $k\le\min(m,n)$ |

四类情形的最大值是 $\min(m,n)+1$，且该值**可达**（第 1、3 行即构造例子）。故最坏比较次数

$$T(m,n)=\min(m,n)+1=O\big(\min(m,n)\big)$$

**步骤 3：小规模枚举核对（第二法）**

把 $m,n\in\{1,2,3\}$ 的所有"最坏串对"（取两串前缀相同）逐一模拟，得最大比较次数：

| $m\backslash n$ | 1 | 2 | 3 |
|---|---|---|---|
| **1** | 2 | 2 | 2 |
| **2** | 2 | 3 | 3 |
| **3** | 2 | 3 | 4 |

表中每个元素恰为 $\min(m,n)+1$（例如 $m=1,n=3$：`a\0` 与 `aa\0` 比较，第 1 位 `a`=`a`，第 2 位 `'\0'`≠`a` ⟹ 2 次；$m=n=3$：`aaa` 与 `aaa` 比 3 位再加结束位 ⟹ 4 次）。表与公式完全吻合。

**步骤 4：为什么不是 $O(m+n)$ 或 $O(\max(m,n))$**

比较过程**从不越过较短串的结束标记**：一旦某位不匹配（或同时到串尾）算法立即结束，长串剩余部分一个字符也不会被读。因此长串比短串多出的那 $|m-n|$ 个字符**不参与比较**，量级只由 $\min(m,n)$ 决定。
（若实现方式改为"先各调一次 `StrLength` 求长度、再逐位比较"，则求长要分别扫到串尾，总代价 $O(m+n)$；但那样做等价于多付一次全串扫描，不是本题存储约定下的必要开销，标准答案取同步扫描的 $O(\min(m,n))$。此口径差异见第 12 节。）

**答案**：$O(\min(m,n))$。

## 8. 考场标准答案

串相等 $\iff$ 长度相等且对应位置字符全同。以结束标记为界、从首字符起同步逐位比较，最坏情形是"两串前缀完全相同"：

- $m=n$：比较 $m$ 个字符（含结束标记则 $m+1$ 次）后判等；
- $m\ne n$：比较到第 $\min(m,n)+1$ 位时短串的结束标记与长串实字符不匹配，判不等。

故最坏比较次数 $T(m,n)=\min(m,n)+1$，时间复杂度为 $O(\min(m,n))$。

## 9. 易错点

1. **答成 $O(m+n)$ 或 $O(\max(m,n))$**：以为要把两个串都扫完；实际算法在较短串结束处即终止，长串尾部不读；
2. **只答 $O(n)$**：题面有两个独立规模 $m$、$n$，写成单一 $n$ 丢掉了"由较短者决定"这一关键结论（本题的考点正在 $\min$ 上）；
3. **漏掉"长度相等"这一条件**：只比对应字符而不判结束标记，会把 `abc` 与 `abcd` 判为相等——正确实现必须让结束标记参与比较；
4. 与本年度第 32 题的口径混用：第 32 题问"存储空间要几格"（$=len+1$，是**空间**问题），本题问**时间**量级，两者都涉及"结束标记"，但一个是占一格、一个是多比一次，别互相套用结论。

## 10. 一句话规律

串（以及一切"以结束标记判尾的线性结构"）上的比较类运算，复杂度都按**最坏情况下实际读到的字符数**计：同步扫描两串时，读到的长度由**较短者**封顶，故为 $O(\min(m,n))$；只有需要把两串各自扫完（如分别求串长）才是 $O(m+n)$。
