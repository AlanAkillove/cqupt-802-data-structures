# DS-2014-30

## 1. 原题

已知某二叉树的先序序列 $ABCFDG$ ，中序序列 $CBDFAG$ ，那么它的后序遍历序列是____________________ 。

## 2. 答案

$CDFBGA$。

对应的二叉树为：$A$ 为根，左孩子 $B$、右孩子 $G$；$B$ 的左孩子 $C$、右孩子 $F$；$F$ 的左孩子 $D$。

## 3. 题目分析

- 已知：同一棵二叉树的**先序**序列 $ABCFDG$ 与**中序**序列 $CBDFAG$，各 $6$ 个结点、字符集合相同（$A,B,C,D,F,G$ 六个字母，无 $E$），且无重复关键字；
- 目标：写出该树的**后序**遍历序列；
- 关键约束：
  1. 先序"根→左→右"：每段序列的**第一个元素**就是该段对应子树的**根**；
  2. 中序"左→根→右"：在**中序**中找到根，其**左侧**是左子树的全部结点、**右侧**是右子树的全部结点；
  3. 两序列必须交替使用（先序给根、中序给划分），每次确定一棵子树；先序 + 中序 ⟹ 二叉树**唯一确定**；本题先序、中序长度均为 $6$，字符集一致，数据自洽；
- 命题意图：考"由两组遍历序列还原二叉树"的递归分治基本功，并要求在还原后按第三种顺序输出——真正考的是过程而非背结论。本题与上一年 DS-2013-25 同型（那里是先序 $ABCDEGF$ + 中序 $CBEGDFA$），可作为方法一致性的对照。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（由两种遍历序列确定二叉树、序列间互推）

辅助考点：
DS03.02.03.03 后序遍历（最终输出形式为"左→右→根"）

解释：题干的难点全部落在"用先序与中序把树重建出来"，这是 DS03.02.03 的核心应用；输出要求后序，故再挂后序遍历这一细粒度节点。

## 5. 解题思路

1. **定整棵树的根**：先序首元素 $A$ = 根；
2. **划左右**：在中序 $CBDFAG$ 中找 $A$，其左 $CBDF$（$4$ 个）为左子树、其右 $G$（$1$ 个）为右子树；
3. **回到先序切段**：先序去掉 $A$ 后取前 $4$ 个 $BCFD$ 为左子树的先序，余下 $G$ 为右子树的先序；
4. **递归**：对左子树（先序 $BCFD$、中序 $CBDF$）重复 1~3，直到区间长度为 $1$（叶子）；
5. **按后序读树**：左→右→根递归输出，得 $CDFBGA$；
6. **双向校验**：对新树重算先序、中序，必须分别得到 $ABCFDG$、$CBDFAG$；再用后序的两个特征（首元素是最左下的叶、末元素是根）快速核对。

## 6. 详细解答

**步骤 1：第一层划分**

- 先序 $A\,B\,C\,F\,D\,G$ ⟹ 根 $=A$；
- 中序 $C\,B\,D\,F\,A\,G$ ⟹ $A$ 左边 $CBDF$ 是左子树（$4$ 个结点），$A$ 右边 $G$ 是右子树（$1$ 个结点）；
- 先序中紧跟 $A$ 的 $4$ 个元素 $BCFD$ 即左子树先序，最后 $1$ 个 $G$ 即右子树先序。

**步骤 2：左子树（先序 $BCFD$，中序 $CBDF$）**

- 根 $=B$（先序首元素）；
- 中序 $C\,B\,D\,F$ ⟹ $B$ 左边 $C$ 为左子树（$1$ 个），$B$ 右边 $DF$ 为右子树（$2$ 个）；
- 先序去掉 $B$ 后取 $1$ 个得 $C$（左），余 $FD$ 为右子树先序。

**步骤 3：$B$ 的右子树（先序 $FD$，中序 $DF$）**

- 根 $=F$；
- 中序 $D\,F$ ⟹ $F$ 左边 $D$ 是其**左孩子**，右边为空 ⟹ $F$ 无右孩子；
- 先序余下 $D$ 与之吻合（$D$ 为叶）。

**步骤 4：$A$ 的右子树**

先序、中序都只剩 $G$ ⟹ $G$ 是 $A$ 的右孩子，且为叶。

**步骤 5：还原出的二叉树**

```
        A
      /   \
     B     G
    / \
   C   F
      /
     D
```

即 $A(L=B,R=G)$，$B(L=C,R=F)$，$F(L=D,R=\varnothing)$，$C$、$D$、$G$ 为叶结点。

**步骤 6：写出后序（左→右→根）并校验**

后序递归展开：

$$post(A)=post(B)\;post(G)\;A$$
$$post(B)=post(C)\;post(F)\;B=C\;\big(post(D)\;\varnothing\;F\big)\;B=C\;D\;F\;B$$
$$post(G)=G$$

故后序 $=C\,D\,F\,B\,G\,A$，即 **`CDFBGA`**。

**校验一（重算另两种遍历）**

- 先序（根左右）：$A$ → 左子树 $B\,C\,F\,D$ → 右子树 $G$ ⟹ `ABCFDG` ✓ 与题面一致；
- 中序（左根右）：左子树 $C\,B\,D\,F$ → $A$ → $G$ ⟹ `CBDFAG` ✓ 与题面一致。

**校验二（后序的结构特征）**

- 后序**末元素**必为根：`CDFBG`**`A`** ⟹ $A$ ✓；
- 后序**首元素**必为"一路向左走到底"的最左叶：树中最左下叶为 $C$ ✓；
- 结点总数 $6$、字符集 $\{A,B,C,D,F,G\}$ 不重不漏 ✓（先序、中序各 $6$ 个元素，后序也须 $6$ 个）。

**校验三（区间长度自洽）**：左子树 $4$ 个 + 右子树 $1$ 个 + 根 $1$ 个 $=6$ ✓；$B$ 的左 $1$ 个 + 右 $2$ 个 + 根 $1$ 个 $=4$ ✓。

**答案**：$CDFBGA$。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

由先序 $ABCFDG$ 知根为 $A$；在中序 $CBDFAG$ 中 $A$ 左侧 $CBDF$ 为左子树、右侧 $G$ 为右子树。
对左子树（先序 $BCFD$、中序 $CBDF$）：根 $B$，左孩子 $C$，右子树由 $D,F$ 构成；该右子树先序 $FD$、中序 $DF$ ⟹ 根 $F$、$D$ 为 $F$ 的左孩子。

$$A\big(B(C,\,F(D,\varnothing)),\,G\big)$$

后序（左右根）：$\boxed{CDFBGA}$。

## 9. 易错点

1. **只用先序不查中序**：把先序中 $B$ 后面的 $C$ 直接当成 $B$ 的左孩子是对的（本题巧合），但一般地"先序相邻两元素未必是父子"——必须用中序判定 $C$ 在 $B$ 的左侧还是右侧；
2. **$D$ 挂错位置**：$F$ 的孩子在左还是右由**中序** $DF$ 决定（$D$ 在 $F$ 左侧 ⟹ 左孩子）。若误挂成 $F$ 的右孩子，先序仍是 $FD$、但中序会变成 $FD$，与题面 $DF$ 矛盾——这正是"先序+中序唯一确定二叉树"的原因；
3. **忘记 $G$ 是右孩子而非左孩子**：中序中 $G$ 在 $A$ 的**右侧**，若挂到左侧，中序就变成 $GCBDFA$；
4. **输出顺序写成中序或先序**：本题要求后序，$CBDFAG$ 与 $ABCFDG$ 都已在题面出现，答成它们即答非所问；
5. **不核对结点个数**：漏掉某个结点（如把 $D$ 丢掉写成 $CFBGA$）是此类题最常见的失分方式，动笔后先数个数是否等于 $6$。

## 10. 一句话规律

**先序给"谁是根"，中序给"谁在根的哪一边"**：取先序首元素定根 → 在中序中划出左右子树区间 → 按区间长度回到先序切段 → 递归；解完必须"重算已知的两种序列"回对题面，这是最快的自检。
