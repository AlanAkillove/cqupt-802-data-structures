# DS-2014-16

## 1. 原题

在对 $n$ 个关键字进行简单选择排序的过程中，每一趟都要从无序区选出最小关键字元素，则在进行第 $i$ 趟排序之前，无序区中关键字元素个数为（）。

A. $i$

B. $i+1$

C. $n-i$

D. $n-i+1$

## 2. 答案

**D**（$n-i+1$）。

## 3. 题目分析

- 已知：简单选择排序（升序），共 $n$ 个记录；题面给出"趟"的操作定义——**每一趟从无序区中选出最小关键字元素**；问"第 $i$ 趟**之前**"无序区的元素个数；
- 目标：求出以 $n$、$i$ 表示的无序区长度表达式；
- 关键约束：
  1. 简单选择排序每趟**恰好确定一个**记录的最终位置（把本趟选出的最小值与无序区首元素交换，或直接放置），因此第 $i$ 趟开始前，最终位置已确定的记录恰有 $i-1$ 个，它们是 $R[1..i-1]$；
  2. "之前"二字是本题唯一的陷阱位置：第 $i$ 趟**之后**无序区长度才是 $n-i$（即 C 项），第 $i$ 趟**之中**被扫描的区间是 $R[i..n]$，长度 $n-i+1$；
  3. 趟数上界为 $n-1$：只剩 $1$ 个记录时无序区自然有序，不必再排；故 $1\le i\le n-1$，代入公式得第 $n-1$ 趟之前无序区有 $n-(n-1)+1=2$ 个元素，与"两个比一次即可"吻合；
  4. 题面说"选出最小关键字元素"，即每趟只处理一个方向（前插式），这与"每趟选最大放末尾"的对称写法结论相同（$n-i+1$ 不变），只是有序区在尾部；
- 命题意图：考"趟"这一动态过程的**状态计数**能力——能否在算法执行的任意时刻说清"有序区/无序区各多长"。这一能力直接服务于两类后续题型：写出第 $k$ 趟结束后的序列（DS-2012-34、DS-2007-36）与判断哪些排序"每趟至少确定一个元素的最终位置"（本卷 DS-2014-37）。

## 4. 核心考点

核心考点：
DS06.04 简单选择排序（第 $i$ 趟在 $R[i..n]$ 中选最小关键字，比较 $n-i$ 次后与 $R[i]$ 交换；每趟确定一个最终位置）

辅助考点：
DS06.01 排序的基本概念（"一趟排序"的定义：对尚未确定最终位置的所有元素进行一遍处理称为一趟——本卷 DS-2014-37 题干原文即此定义；只有先明确"每趟确定一个元素"，才能对有序区/无序区计数）

解释：题目问的是选择排序执行过程中区间长度的表达式，主标签属 DS06.04；但该表达式完全由"趟"的语义（每趟确定一个最终位置）推出，属 DS06.01 的"趟的概念"，故列辅助。同一算法在本库中还以"写出各趟结果"（DS-2007-36）、"第二趟结束后的序列状态"（DS-2012-34）、"比较次数与初态无关"（DS-2014-12、DS-2012-20、DS-2013-19）等形式出现，本题是这些题目的公共基础——区间计数。

## 5. 解题思路

1. 先立**不变式**：简单选择排序第 $t$ 趟结束后，$R[1..t]$ 是已确定最终位置的最小 $t$ 个记录，$R[t+1..n]$ 是无序区——这是"每趟选一个最小值放到前部"的直接结果；
2. 把"第 $i$ 趟之前"翻译成 $t=i-1$ 时刻的状态：有序区长度 $=i-1$，无序区长度 $=n-(i-1)=n-i+1$；
3. 用边界值快速验算与排除：
   - 取 $i=1$（第一趟之前，什么都没排过）：无序区应为 $n$。代入选项得 A$=1$、B$=2$、C$=n-1$、D$=n$ —— **仅 D 正确**，一个特例即可锁定；
   - 取 $i=n-1$（最后一趟之前）：应剩 $2$ 个，D 给 $n-(n-1)+1=2$ ✓，C 给 $1$ ✗（那是最后一趟**之后**的状态）；
4. 再用一次完整模拟复核（第 6 节第（3）条，$n=6$ 逐趟列表），确认每一趟开始时的无序区元素个数依次为 $6,5,4,3,2$，与 $n-i+1$ 逐项相符；
5. 结论 D。

## 6. 详细解答

**（1）不变式的建立**

升序简单选择排序的教材写法：

```c
void SelectSort(SqList *L, int n)      /* R[1..n]，每趟在无序区选最小，放到 R[i] */
{
    for (i = 1; i < n; ++i) {          /* 共 n-1 趟 */
        k = i;
        for (j = i+1; j <= n; ++j)     /* 扫描 R[i+1..n]，共 n-i 次比较 */
            if (L->r[j] < L->r[k]) k = j;
        if (k != i) { L->r[i] <-> L->r[k]; }   /* 与无序区首元素交换 */
    }
}
```

第 $i$ 趟做的事：在 $R[i..n]$ 中选出最小关键字，把它放到 $R[i]$。故

$$\text{第 } i \text{ 趟结束后}\ \Longrightarrow\ R[1..i]\ \text{已定位（且为全表最小的 } i \text{ 个）},\quad R[i+1..n]\ \text{为无序区}$$

**（2）"第 $i$ 趟之前"的区间计数**

"第 $i$ 趟之前"即"第 $i-1$ 趟刚结束"的时刻，把上式中的 $i$ 换成 $i-1$：

$$\text{有序区 } R[1..i-1]\ (i-1 \text{ 个}),\qquad \text{无序区 } R[i..n]\ (n-i+1 \text{ 个})$$

两者相加 $(i-1)+(n-i+1)=n$ ✓（总数守恒，可作为一步自检）。

第 $i$ 趟中要比较 $n-i$ 次——**这个数比无序区长度少 $1$**（$m$ 个元素比大小只需 $m-1$ 次两两比较），所以"比较次数 $n-i$"与"无序区 $n-i+1$ 个"并不矛盾，C 项正是把这两个量混为一谈而设的干扰。

**（3）$n=6$ 的完整模拟复核**

取序列 $R=(65,38,97,76,13,27)$（本库 DS-2007-36 所用序列），逐趟列表，"本趟前无序区长度"一列即待验证对象：

| 时刻 | 有序区（已定位） | 无序区 | 无序区个数 | $n-i+1$（$i$ 为本趟序号） |
|---|---|---|---|---|
| 第 1 趟前 | 空 | $65,38,97,76,13,27$ | $6$ | $6-1+1=6$ ✓ |
| 第 1 趟后 / 第 2 趟前 | $13$ | $38,97,76,65,27$ | $5$ | $6-2+1=5$ ✓ |
| 第 2 趟后 / 第 3 趟前 | $13,27$ | $97,76,65,38$ | $4$ | $6-3+1=4$ ✓ |
| 第 3 趟后 / 第 4 趟前 | $13,27,38$ | $76,65,97$ | $3$ | $6-4+1=3$ ✓ |
| 第 4 趟后 / 第 5 趟前 | $13,27,38,65$ | $76,97$ | $2$ | $6-5+1=2$ ✓ |
| 第 5 趟后 | $13,27,38,65,76$ | $97$ | $1$ | ——（无需再排） |

（逐趟选出的最小值依次为 $13,27,38,65,76$，它们与本趟无序区首元素的交换依次为 $65\!\leftrightarrow\!13$、$38\!\leftrightarrow\!27$、$97\!\leftrightarrow\!38$、$76\!\leftrightarrow\!65$、第 $5$ 趟最小值恰为 $R[5]$ 自身故不交换；共 $5=n-1$ 趟；第 $i$ 趟的比较次数依次为 $5,4,3,2,1$，总和 $15=\frac{6\times5}{2}$，与 DS-2014-12 中 $n=6$ 时的计数一致。注意每趟之后无序区的**内部次序**会因交换而改变（如 $27$ 被换到原 $38$ 的位置），但**个数**只减 $1$，与元素如何排列无关——这正是本题所问的量。）

表中"无序区个数"一列 $6,5,4,3,2$ 恰为 $n-i+1$ 在 $i=1..5$ 时的取值，而 C 项 $n-i$ 给出的是 $5,4,3,2,1$ —— 那是**每趟之后**的剩余个数，错位一格。

**（4）$i=1$ 特例的排除力**

第一趟之前，一个元素都没确定，无序区必然是全部 $n$ 个：

| 选项 | $i=1$ 时的值 | 是否等于 $n$ |
|---|---|---|
| A $i$ | $1$ | ✗ |
| B $i+1$ | $2$ | ✗ |
| C $n-i$ | $n-1$ | ✗ |
| D $n-i+1$ | $n$ | ✓ |

单此一项即可在考场定案；第（3）条的模拟是防"公式背反"的第二重保险。

**（5）对称写法的口径核对**

若采用"每趟从无序区选**最大**值放到表尾"的写法，则第 $i$ 趟之前有序区在尾部、含 $i-1$ 个元素，无序区仍是 $R[1..n-i+1]$，个数同为 $n-i+1$。可见本题答案与"选最小放前／选最大放后"无关，只依赖"每趟确定一个元素"这一条；题干已明确"从无序区选出最小关键字元素"，按前者理解即可。

**答案**：D。

## 7. 选项分析

- A. $i$：错。这是"第 $i$ 趟**之后有序区的元素个数**"，把有序区长度当成了无序区长度，方向整个弄反；$i=1$ 时给出 $1$，意味着第一趟开始前只剩一个元素，显然荒谬；
- B. $i+1$：错。既不是有序区也不是无序区的长度，无对应状态；$i=1$ 时给出 $2$，与"一开始 $n$ 个元素全部无序"矛盾（除非 $n=2$，而本题要对一般 $n$ 成立）；
- C. $n-i$：错，**且是最易误选的一项**。它有两个可能的身份：第 $i$ 趟**之后**的无序区长度，或第 $i$ 趟**之中**的比较次数（$n-i$ 次两两比较）。题干问的是"第 $i$ 趟**之前**"，须为 $n-i+1$；$m$ 个元素比出最小值要作 $m-1$ 次比较，二者差 $1$ 正是本题的分界；
- D. $n-i+1$：正确。第 $i$ 趟之前已确定 $i-1$ 个元素的最终位置，无序区为 $R[i..n]$，长度 $n-i+1$；$(i-1)+(n-i+1)=n$ 满足总数守恒。

## 8. 考场标准答案

简单选择排序每趟恰确定一个元素的最终位置，故第 $i$ 趟之前有序区 $R[1..i-1]$ 已有 $i-1$ 个元素，无序区为 $R[i..n]$，元素个数

$$n-(i-1)=n-i+1$$

自检：$i=1$ 时为 $n$（尚未排序），$i=n-1$（最后一趟）时为 $2$；每趟内比较 $n-i$ 次，恰比无序区长度少 $1$。选 **D**。

## 9. 易错点

1. **漏读"之前"二字**：把"第 $i$ 趟之前"读成"第 $i$ 趟之后"，直接选 C。本题四个选项中 C 与 D 只差 $1$，是典型的"状态时刻"陷阱，动笔前应在草稿上标出"第 $i-1$ 趟结束"这一时刻；
2. **把"比较次数"当"元素个数"**：第 $i$ 趟在长度为 $n-i+1$ 的区间里选最小值，比较 $n-i$ 次（DS-2014-12 用的就是这个式子），两个量差 $1$，记混就中 C；
3. **忽略"共 $n-1$ 趟"这一事实**：$i$ 的取值范围是 $1\le i\le n-1$，若误以为有 $n$ 趟，代入 $i=n$ 得 $n-n+1=1$，会怀疑"最后一趟只剩一个元素还排什么"，进而否定正确答案；
4. **换算法时表达式不同**：直接插入排序的第 $i$ 趟处理的是 $R[i+1]$（前 $i$ 个有序），冒泡排序第 $i$ 趟要把 $R[1..n-i+1]$ 中最大者冒到 $R[n-i+1]$，快速排序的"趟"更是以枢轴归位为界——各法"趟"的语义不同，不能把本题的 $n-i+1$ 套到别的算法上。

## 10. 一句话规律

选择类排序的"趟 ↔ 区间"换算只需一条不变式：**第 $i$ 趟之前已定 $i-1$ 个**，于是有序区 $i-1$、无序区 $n-i+1$、本趟比较 $n-i$ 三个式子一次记住；凡遇"第几趟前/后"的问法，先把它翻译成"第几趟结束"这一时刻再代入，就不会差 $1$。
