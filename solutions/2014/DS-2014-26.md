# DS-2014-26

## 1. 原题

某表达式语法树（二叉树）按后序遍历的结果为 $abc-d+*h-$ ，令 $a=2,b=6,c=4,d=5,h=8$ ，则表达式的值等于____________________ 。

## 2. 答案

$2$（该表达式为 $a*(b+c-d)-h$，代入得 $2\times(6+4-5)-8=10-8=2$）。

## 3. 题目分析

- 已知：一棵**表达式二叉树**（叶结点为运算量 $a,b,c,d,h$，非叶结点为二元运算符 $+,-,*$）的**后序**遍历序列 `abc-d+*h-`，以及各运算量的取值 $a=2,b=6,c=4,d=5,h=8$；
- 目标：求该表达式的值；
- 关键约束：
  1. 表达式二叉树的**后序遍历序列就是后缀表达式（逆波兰式）**：左子树 → 右子树 → 根，正好把运算符排在它的两个操作数之后；
  2. 后缀式求值时，运算符的两个操作数是**在它之前最近出现的两个值**，且**先取出的是左操作数、后取出的是右操作数**——减法、除法不满足交换律，次序颠倒就换题；
  3. 序列自洽性检查：$5$ 个运算量、$4$ 个运算符，恰满足"二叉树中 $n_0=n_2+1$"（叶结点数 = 度为 2 的结点数 + 1），说明这是一棵合法表达式树，运算符全为二元；
- 命题意图：把"二叉树遍历"与"表达式求值"两个知识点接在一起（DS03.04.02 的典型形态），考学生是否识别出"后序 = 后缀"，并能否正确处理减法的左右操作数次序。

## 4. 核心考点

核心考点：
DS03.04.02 树与二叉树的其他应用（表达式二叉树：由遍历序列确定表达式并求值）

辅助考点：
DS03.02.03.03 后序遍历（"左→右→根"与后缀式的对应关系）
DS02.07 栈、队列和数组的应用（后缀表达式的栈式求值算法）

解释：题面的"表达式语法树"直接把本题定位到二叉树应用一节（DS03.04.02）；解题的第一步是识别后序序列与后缀表达式的等价性（DS03.02.03.03），第二步的执行过程就是教材上讲表达式求值时引入的栈式算法（DS02.07），故列为辅助。

## 5. 解题思路

1. **认序列**：题面说是"表达式树的后序遍历"，而后序 = 左、右、根 ⟹ 序列 `abc-d+*h-` 是后缀式，可直接按后缀规则求值；
2. **栈式求值**：从左到右扫描，遇字母把其值压栈，遇运算符弹出**两个**栈顶值（先弹的是右操作数、后弹的是左操作数）做运算后回栈；扫描结束时栈顶即表达式的值；
3. **换方法复核**：不依赖栈，改为**还原表达式树**——最后一个运算符 `-` 是根，它左边 `abc-d+*` 是左子树、右边 `h` 是右子树，递归下去得到中缀式 $a*(b+c-d)-h$，再代入数值算一次；
4. **反向验证**：对还原出的树重新做一次后序遍历，若得到题面序列 `abc-d+*h-`，说明建树无误，两法结果必然一致。

## 6. 详细解答

**方法一：后缀表达式栈式求值**

按题面取值 $a=2,\ b=6,\ c=4,\ d=5,\ h=8$。逐符号扫描 `a b c d - + * h -`（栈底在左）：

| 步 | 读入符号 | 动作 | 栈内内容（栈顶在右） |
|---|---|---|---|
| 1 | $a$ | 压入 $2$ | $2$ |
| 2 | $b$ | 压入 $6$ | $2,6$ |
| 3 | $c$ | 压入 $4$ | $2,6,4$ |
| 4 | $d$ | 压入 $5$ | $2,6,4,5$ |
| 5 | $-$ | 弹出右 $=5$、左 $=4$，算 $4-5=-1$ | $2,6,-1$ |
| 6 | $+$ | 弹出右 $=-1$、左 $=6$，算 $6+(-1)=5$ | $2,5$ |
| 7 | $*$ | 弹出右 $=5$、左 $=2$，算 $2\times5=10$ | $10$ |
| 8 | $h$ | 压入 $8$ | $10,8$ |
| 9 | $-$ | 弹出右 $=8$、左 $=10$，算 $10-8=2$ | $2$ |

扫描结束栈中恰剩一个值 $2$ ⟹ 表达式的值为 $2$。

**方法二：还原表达式树 → 中缀式代入**

后缀式（=后序序列）还原树，规则是"从右往左看，运算符是它左侧那棵子树的根"：

- 末位 `-` 为**根**：右子树由 `h` 单独构成，左子树由 `abc-d+*` 构成；
- `abc-d+*` 的末位 `*` 为该子树根：左子树 = `a`，右子树 = `bc-d+`；
- `bc-d+` 的末位 `+` 为根：左子树 = `b`，右子树 = `cd-`；
- `cd-` 的末位 `-` 为根：左子树 = `c`，右子树 = `d`。

得到的树（缩进表示层次，L/R 表示左右孩子）：

```
        -
      /   \
     *     h
    / \
   a   +
      / \
     b   -
        / \
       c   d
```

按"左-根-右"读成中缀式（乘法优先级高于减法，需保留括号）：

$$a*\big(b+(c-d)\big)-h=a*(b+c-d)-h$$

代入数值：

$$2\times(6+4-5)-8=2\times5-8=10-8=\boxed{2}$$

**方法三：反向验证（对新树重算三种遍历）**

- 后序（左、右、根）：$c,d,-\Rightarrow$ 记 $c\,d\,-$；再 $b,(c\,d\,-),+\Rightarrow b\,c\,d\,-\,+$；再 $a,(\cdots),*\Rightarrow a\,b\,c\,d\,-\,+\,*$；再 $h,-\Rightarrow$ **`abc-d+*h-`** ✓ 与题面完全一致；
- 先序（根、左、右）应为 `-*a+b-cd` 后再读 $h$，即 `-*a+b-cdh`；中序（左、根、右）为 `a*b+c-d-h`，加括号还原即 $a*(b+(c-d))-h$；三种遍历互推自洽。

树还原正确，故方法一与方法二的 $2$ 不是巧合。

**答案**：$2$。

不适用（填空题）。

## 8. 考场标准答案

表达式树的后序序列即后缀式，按后缀规则求值：

$$a\ b\ c\ d\ -\ \to\ c-d=-1;\quad b+(c-d)=5;\quad a*5=10;\quad 10-h=2$$

还原成中缀式为 $a*(b+c-d)-h$，代入 $2*(6+4-5)-8=10-8=\boxed{2}$。

## 9. 易错点

1. **减法操作数次序颠倒**：把 $c-d$ 算成 $d-c=1$，则 $b+1=7$、$a*7=14$、$14-8=6$（错答 $6$）；把最后一步算成 $h-10=-2$（错答 $-2$）。口诀：**先弹出的是右操作数**；
2. **把后序当先序/中序读**：若按先序理解 `abc-d+*h-`，树形完全不同，无法得到合法表达式（先序应是"运算符在操作数之前"）；
3. **漏掉括号改变运算对象**：还原中缀式时写成 $a*b+c-d-h=12+4-5-8=3$（错答 $3$）——`+`、`*` 的嵌套关系要求 $b+c-d$ 整体与 $a$ 相乘，必须加括号；
4. 只看运算符个数不核对结构：$5$ 个运算量配 $4$ 个二元运算符，若某步弹出/压入数目不对（例如把 `*` 当成三个操作数）说明扫描过程已经出错，应及时回查。

## 10. 一句话规律

**表达式二叉树：先序 = 前缀（波兰式）、中序 = 中缀（加括号）、后序 = 后缀（逆波兰式）**；给任一序列求值，最稳的做法是"后序/先序 ⟹ 栈式或递归建树 ⟹ 转中缀 ⟹ 代入"，并牢记后缀运算中"先弹出者为右操作数"。
