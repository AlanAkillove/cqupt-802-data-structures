# DS-2014-45

## 1. 原题

假设用于通信的电文由字符集 `{X,Y,C,D,F}` 中的字母构成，这 $5$ 个字母在电文中出现的频率依次为 `{35,20,10,13,22}` 。请画出对应的编码哈夫曼树（ $Huffman$ ）。

## 2. 答案

频率与字符按"依次"对应：$X=35,\ Y=20,\ C=10,\ D=13,\ F=22$（总频率 $100$）。

**哈夫曼树**（方括号内为合并产生的分支结点权，左分支记 $0$、右分支记 $1$）：

```
                       [100]
                     /       \
                 [42]         [58]
                /    \        /    \
            Y(20)   F(22)  [23]    X(35)
                           /   \
                        C(10)  D(13)
```

**哈夫曼编码**（沿左分支写 $0$、右分支写 $1$，根到叶的路径即编码）：

| 字符 | $X$ | $Y$ | $F$ | $C$ | $D$ |
|---|---|---|---|---|---|
| 频率 | $35$ | $20$ | $22$ | $10$ | $13$ |
| 编码 | $10$ | $00$ | $01$ | $110$ | $111$ |
| 码长 | $2$ | $2$ | $2$ | $3$ | $3$ |

**带权路径长度** $WPL=35\times2+20\times2+22\times2+10\times3+13\times3=70+40+44+30+39=\boxed{223}$；树共 $2\times5-1=9$ 个结点。

## 3. 题目分析

- 已知：$5$ 个字符及其频率（权值）$35,20,10,13,22$，权值**两两互异**；
- 目标：画出"编码哈夫曼树"——即以字符频率为叶权构造最优二叉树；题面落点是"画树"，由树可直接读出各字符前缀编码，故解析把编码与 $WPL$ 一并给出（$WPL$ 是验证树正确的量化依据）；
- 关键约束：① 哈夫曼算法每一步在**当前所有活跃结点（原始叶 + 已生成的分支结点）**中取权值最小的两棵合并，新结点的权立即参与后续比较（不能只在原始叶中挑）；② 权值互异 ⟹ 本题每步的最小二元组唯一，从而**树的带权结构唯一**（各叶深度被确定）；③ 左右子树可互换、$0/1$ 规定可对调，故**具体编码字符串不唯一**，但码长分布 $\{2,2,2,3,3\}$ 与 $WPL=223$ 唯一；④ 哈夫曼树是正则二叉树（无度为 $1$ 的结点），$n$ 叶 $\Rightarrow 2n-1$ 个结点、$n-1$ 次合并；
- 命题意图：考 DS03.04.01 的构造流程与"频率大者靠近根"的最优性直观；$X(35)$ 与 $C(10),D(13)$ 的深度差、以及"$C,D$ 必须一起被合并两次"这两处是判卷重点。

## 4. 核心考点

核心考点：
DS03.04.01 哈夫曼树与哈夫曼编码（贪心建树：取两最小权合并、新权回池；$WPL=\sum w_i l_i$；前缀编码的构造——左 $0$ 右 $1$，任一字符编码都不是另一编码的前缀）

辅助考点：
DS03.01 树的基本概念（路径与路径长度、带权路径长度的定义，"树的结点总数 $=2n-1$"来自 $n$ 次合并中每减少 $2$ 个活跃结点、增加 $1$ 个结点的计数）；DS03.02.01 二叉树的定义及主要特征（$n_0=n_2+1$：本题 $5$ 个叶 ⟹ $4$ 个度为 $2$ 的分支结点 ⟹ 共 $9$ 个结点，用来核对画出的树有没有"单支结点"）

解释：主考点是建树与读码；两辅助考点分别支撑"$WPL$ 是什么"和"树应该长什么样（结点个数、度数分布）"，本题的自我验证正是靠这两条硬指标完成的。

## 5. 解题思路

1. **先把权值排序**：$C(10)<D(13)<Y(20)<F(22)<X(35)$，建树过程就是在这组数上反复"取两最小、相加、放回"；
2. **维护活跃结点集并逐步合并**（每步都在合并后重新比较大小，切勿按原表顺序配对）：
   - $\{10,13,20,22,35\}\to$ 取 $10,13$ 得 $23$；
   - $\{20,22,23,35\}\to$ 取 $20,22$ 得 $42$（注意此时 $23$ 已排在 $42$ 之前，说明新结点确实参与了比较）；
   - $\{23,35,42\}\to$ 取 $23,35$ 得 $58$（$C,D$ 组成的子树整体比 $X$ 轻，故与 $X$ 合并）；
   - $\{42,58\}\to$ 合并得根 $100$；
3. **由合并树反读深度**：根的两个孩子是 $42$（含 $Y,F$）与 $58$（含 $C,D$ 子树与 $X$），故 $Y,F,X$ 深度 $2$、$C,D$ 深度 $3$；
4. **算 $WPL$ 并双算校验**：叶权 $\times$ 码长求和 $=223$；另一法——"所有分支结点（含根）权值之和" $=23+42+58+100=223$，两法相等即建树无误（该等式的根据是每个叶的权在其到根的每条边上都被计入一次）；
5. **做前缀完备性检查**：$\sum 2^{-l_i}=3\cdot\frac14+2\cdot\frac18=\frac34+\frac14=1$，说明这组码长既可构造前缀码又把信道用满（Kraft 等号）；
6. 若怀疑是否还有更优形态，构造一个"把最大的 $X$ 提到深度 $1$"的对照树算 $WPL$（第 6.4 节）——得 $230>223$，反向确认贪心解更优。

## 6. 详细解答

### 6.1 逐步合并过程

| 步 | 活跃结点集（权值，排序后） | 取出的两最小 | 新结点权 | 剩余活跃集 |
|---|---|---|---|---|
| 初 | $\{10,13,20,22,35\}$ | — | — | — |
| 1 | $\{10,13,20,22,35\}$ | $C(10),D(13)$ | $N_1=23$ | $\{20,22,23,35\}$ |
| 2 | $\{20,22,23,35\}$ | $Y(20),F(22)$ | $N_2=42$ | $\{23,35,42\}$ |
| 3 | $\{23,35,42\}$ | $N_1(23),X(35)$ | $N_3=58$ | $\{42,58\}$ |
| 4 | $\{42,58\}$ | $N_2(42),N_3(58)$ | 根 $=100$ | $\{100\}$（结束） |

共 $4=n-1$ 次合并，生成 $4$ 个分支结点 $23,42,58,100$；结点总数 $5+4=9=2\times5-1$ ✓。

每步"取两最小"在权值互异时选择唯一，故本题的带权树形（哪个字符在第几层）是**确定的**，不存在"另一种合并顺序也得最优"的歧义。

### 6.2 树的结构与深度

```
                       [100]              深度 0（根）
                     /       \
                 [42]         [58]        深度 1
                /    \        /    \
            Y(20)   F(22)  [23]    X(35)   深度 2
                           /   \
                        C(10)  D(13)      深度 3
```

| 字符 | 权 | 深度（路径长） | 所属分支 |
|---|---|---|---|
| $Y$ | $20$ | $2$ | 根的左子树 $[42]$ |
| $F$ | $22$ | $2$ | 根的左子树 $[42]$ |
| $X$ | $35$ | $2$ | 根的右子树 $[58]$ 的右侧 |
| $C$ | $10$ | $3$ | $[58]$ 的左子树 $[23]$ |
| $D$ | $13$ | $3$ | $[58]$ 的左子树 $[23]$ |

检查"权大者浅"：$X(35)$ 深度 $2$ 最浅，$C(10),D(13)$ 深度 $3$ 最深 ✓；$[58]$ 的左孩子是分支结点 $[23]$（权 $23$）、右孩子是叶 $X(35)$，符合"每一步两最小者合并"的直接结果。

### 6.3 $WPL$ 的两种算法与编码读出

**法一（定义式）**：
$$WPL=\sum_{i} w_i l_i = 35\times2+20\times2+22\times2+10\times3+13\times3 = 70+40+44+30+39 = 223$$

**法二（分支结点权值和）**：每个叶的权在它到根的 $l_i$ 条边上各被计入一次，故
$$WPL=\sum_{\text{分支结点}} w = 23+42+58+100 = 223\ \checkmark$$

两法一致 ⟹ 深度分配与合并过程互证无误。

**编码读出**（根到叶路径，左 $0$ 右 $1$）：

| 字符 | 路径 | 编码 | 码长 |
|---|---|---|---|
| $Y$ | 左左 | $00$ | $2$ |
| $F$ | 左右 | $01$ | $2$ |
| $X$ | 右右 | $10$ | $2$ |
| $C$ | 右左左 | $110$ | $3$ |
| $D$ | 右左右 | $111$ | $3$ |

前缀性质：长度 $2$ 的三个码 $00,01,10$ 中未出现的 $11$ 恰是 $C,D$ 的公共前缀，故没有任何码字是另一个的前缀 ✓；且 $\sum 2^{-l_i}=3\times\frac14+2\times\frac18=1$，即这是一组"用满信道"的最优前缀码。

平均码长 $=\dfrac{223}{100}=2.23$ 位/字符；若改用等长编码需 $\lceil\log_2 5\rceil=3$ 位/字符，总位数 $300$，本题编码后为 $223$ 位，节省约 $25.7\%$。

### 6.4 最优性交叉验证（构造对照形态）

把频率最大的 $X$ 单独提为根的左孩子（深度 $1$），其余 $4$ 个字符组成根的右子树（该子树内部最优形态为 $10+13=23$、$20+22=42$、$23+42=65$，叶在子树内深度均为 $2$，整体上再加 $1$ 层）：

$$WPL' = 35\times1 + (20+22+10+13)\times1 + (23+42+65) = 35 + 65 + 130 = 230 > 223$$

再试彻底退化（除叶外每个结点只有一个孩子）的编码树，深度依次为 $X_{1},Y_{2},F_{3},C_{4},D_{4}$（仍满足 Kraft 等号，故是合法前缀码，但含度为 $1$ 的结点，不是哈夫曼树的形态）：$35+40+66+40+52=233>223$。两种自然的可比形态都不如 6.2 节的树，与哈夫曼贪心选择定理（权小者深度大）一致，确认 $223$ 为最小带权路径长度。

### 6.5 编码方案的非唯一性说明

本题的**树形与码长分布唯一**，但答卷上写出的具体 $0/1$ 串可以不同，下列都算正确：

- 每个分支结点的左右子树对调（例如令 $X=01$、$C=100$ 等）；
- 约定"左 $1$ 右 $0$"；
- 同一层的兄弟叶互换（$Y\leftrightarrow F$、$C\leftrightarrow D$）。

不变量是：$X,Y,F$ 码长 $2$、$C,D$ 码长 $3$、$WPL=223$、结点 $9$ 个。答卷时建议顺手标注"左分支记 $0$、右分支记 $1$"，以免被判为随意写码。

## 8. 考场标准答案

权值排序：$C(10)<D(13)<Y(20)<F(22)<X(35)$。

合并过程：① $10+13=23$（$C,D$ 合并）；② $20+22=42$（$Y,F$ 合并）；③ $23+35=58$（①的子树与 $X$ 合并）；④ $42+58=100$（根的左右子树）。

```
                  [100]
                /       \
            [42]         [58]
           /    \        /   \
        Y(20)  F(22)  [23]   X(35)
                      /   \
                   C(10)  D(13)
```

哈夫曼编码（左 $0$ 右 $1$）：$Y=00$、$F=01$、$X=10$、$C=110$、$D=111$。

$WPL=35\times2+20\times2+22\times2+10\times3+13\times3=223$（校验：分支结点权和 $23+42+58+100=223$）。树共 $2\times5-1=9$ 个结点，其中叶 $5$ 个、度为 $2$ 的结点 $4$ 个，无度为 $1$ 的结点。

## 9. 易错点

1. **只在原始叶中挑最小两权**：第 3 步应取"子树 $[23]$ 与 $X(35)$"，若误按"剩下的原始叶 $20,22,35$"顺序配对会把新结点漏出比较，树形完全走样（口诀：**新权回池再排序**）；
2. **把频率与字符错位**：题面"依次为"意味着 $X\!\to\!35,\,Y\!\to\!20,\,C\!\to\!10,\,D\!\to\!13,\,F\!\to\!22$；若把 $13$ 记给 $F$，则 $C,D$ 换成 $C,F$ 合并，深度分布变成 $\{2,2,2,3,3\}$ 但归属错误，编码也错；
3. **忘写权值或忘记叶子上标**：画"编码哈夫曼树"要在叶上标字符与频率、在分支结点标合并后的权，否则无法核对 $WPL$；
4. **误以为度为 $1$ 的结点可以出现**：哈夫曼树每次合并两棵，生成结点度数必为 $2$；若画出的树有单支结点，一定是错的（可用 $n_0=n_2+1$ 快速检查）；
5. **$WPL$ 与"总频率"混淆**：$WPL$ 是"频率 $\times$ 码长"之和（$223$），不是频率之和（$100$）；若题面给的是百分数频率，$223$ 即"电文编码后的总位数"，平均码长才是 $2.23$；
6. 把编码写成非前缀码（如给 $X$ 写 $0$、给 $Y$ 写 $01$）：必须严格沿树根到叶读路径，且注明左 $0$ 右 $1$。

## 10. 一句话规律

哈夫曼建树一句话：**把"最小的两个"合并成一个、把新权放回池里再排序，重复 $n-1$ 次**；验算靠两条——$WPL$ 既可用"叶权 $\times$ 码长"也可用"分支结点权之和"两算，结点总数必为 $2n-1$ 且没有度为 $1$ 的结点。
