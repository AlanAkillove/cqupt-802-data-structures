# DS-2014-03

## 1. 原题

若某栈的输入序列为 $1,2,3,\cdots,n$ ，输出序列的第 $2$ 个元素为 $n$ ，则第 $3$ 个输出元素为（）。

A. $1$ 或 $2$

B. $1$ 或 $n-1$

C. $n-1$ 或 $n-2$

D. $n-1$

## 2. 答案

**C**（$n-1$ 或 $n-2$）。

## 3. 题目分析

- 已知：进栈顺序固定为 $1,2,\dots,n$（严格递增，中途可任意穿插出栈）；输出序列记为 $p_1,p_2,\dots,p_n$，且 $p_2=n$；
- 目标：由 $p_2=n$ 这一条件推出 $p_3$ 的**所有可能取值**；
- 关键约束：① 栈的后进先出（LIFO）；② 要输出 $n$，必须已经把 $1\sim n$ 全部推进去（$n$ 最后进栈）；③ 题目只给了"第 2 个输出"这一个信息，因此 $p_1$ 有两种本质不同的取法，导致 $p_3$ 有两个候选值——问"第 3 个是什么"实际是问候选集合；
- 命题意图：考"根据输出序列的局部信息反推栈内状态"的能力，核心是抓住"$n$ 出栈的瞬间栈里还剩什么"，并检验学生会不会漏掉 $p_1=n-1$ 这一边界情形（这正是干扰项 D 的来源）。

## 4. 核心考点

核心考点：
DS02.01 栈和队列的基本概念（栈的 LIFO 特性与合法输出序列判定）

解释：本题不涉及栈的存储实现细节（顺序栈/链栈的数组下标与指针变化属 DS02.02、DS02.03，本卷 DS-2014-05 即该节点），只用“后进先出”一条性质即可完成全部推理，属该节点中“由部分输出信息推断后续元素”的一型，与 DS-2012-06（判断哪个序列不可能是出栈序列）、DS-2005-21 同一思路。

## 5. 解题思路

1. 把"$p_2=n$"翻译成时序：$n$ 是最后一个进栈的元素，它能出栈，说明 $1,2,\dots,n$ **都已进栈**；而在 $n$ 进栈之前，栈里已有若干元素并且**已经弹出过恰好一个**元素 $p_1$；
2. 于是 $n$ 出栈后栈内的形态由"$p_1$ 是谁"完全决定，分两类：
   - $p_1\neq n-1$：$n-1$ 未动过，它紧贴在 $n$ 下面 ⟹ $p_3=n-1$；
   - $p_1=n-1$：$n-1$ 已提前弹出，此时栈顶是 $n-2$ ⟹ $p_3=n-2$；
3. 说明两类都真的可构造（举 $n=4$ 的实例），因此候选集合是 $\{n-1,\ n-2\}$，不是其中某一个；
4. 对照选项：C 恰为该集合；D 漏第二类；A、B 把 $n=3$ 时的特例数值当成一般结论。

## 6. 详细解答

**第一步：确定 $n$ 出栈时刻的栈内内容**

进栈顺序为 $1<2<\cdots<n$。设 $n$ 进栈前已弹出的元素集合为 $S_{out}$，$n$ 进栈并随即（作为第 2 个输出）弹出的瞬间，栈自底向上是 $\{1,2,\dots,n-1\}\setminus S_{out}$ 按递增序排列的结果。由于 $p_1$ 是 $n$ 之前**唯一**被弹出的输出（$p_2$ 才是 $n$），故 $|S_{out}|=1$，记 $S_{out}=\{p_1\}$，$p_1\in\{1,\dots,n-1\}$。

**第二步：分情况取栈顶**

$n$ 弹出后，$p_3$ 就是当时的栈顶（不可能再有新元素进栈——$n$ 已是最后一个入栈者，故 $p_3$ 必为栈顶元素）：

- 若 $p_1\le n-2$：则 $n-1$ 仍在栈中且是最大的，位于栈顶 ⟹ $p_3=n-1$；
- 若 $p_1=n-1$：栈中最大者为 $n-2$，位于栈顶 ⟹ $p_3=n-2$。

两种情形互斥且穷尽，故

$$p_3\in\{n-1,\ n-2\}$$

**第三步：可构造性验证（取 $n=4$，此时 $n-1=3$、$n-2=2$）**

情形一（$p_3=n-1=3$）：`push1 pop1 push2 push3 push4 pop4 pop3 …`

| 操作 | 栈（底→顶） | 输出 |
|---|---|---|
| push 1, pop 1 | 空栈 | $1$ |
| push 2, push 3, push 4 | $[2,3,4]$ | —— |
| pop | $[2,3]$ | $4=p_2$ ✓ |
| pop | $[2]$ | $3=p_3=n-1$ ✓ |

情形二（$p_3=n-2=2$）：`push1 push2 push3 pop3 push4 pop4 pop2 …`

| 操作 | 栈（底→顶） | 输出 |
|---|---|---|
| push 1,2,3, pop 3 | $[1,2]$ | $3$ |
| push 4, pop 4 | $[1,2,4]$ → $[1,2]$ | $4=p_2$ ✓ |
| pop | $[1]$ | $2=p_3=n-2$ ✓ |

两类都能真正执行，说明答案不是唯一值而是两值之一。

**第四步：进一步排除"更多可能"**

$p_3$ 能否是 $n-3$？这要求在 $p_2$ 之前弹出两个 $\ge n-2$ 的元素，即 $p_1$ 之外还要有一个输出，与"$p_2=n$"矛盾。能否是 $1$ 或 $2$ 这类小值？只有当栈里只剩它时才会弹出，而 $|S_{out}|=1$ 保证 $n-1$、$n-2$ 至多少一个，故 $p_3\ge n-2>2$（当 $n\ge5$）。$n=3$ 时 $n-2=1$、$n-1=2$，候选集退化为 $\{1,2\}$——这正是 A 选项的来源，但它只是个别 $n$ 下的巧合，不是通式。

**答案**：C。

## 7. 选项分析

- A. $1$ 或 $2$：错。$n\ge5$ 时 $n-2\ge3$，两个候选值都不小于 $3$，$1$、$2$ 都取不到；只有 $n=3$ 时 $\{n-1,n-2\}=\{2,1\}$ 与 A 数值完全重合，属特例巧合（$n=4$ 时 A 的“$2$”偶然可取，但“$1$”仍不可能），拿特例当通式；
- B. $1$ 或 $n-1$：错。$n-1$ 这一半对，$1$ 这一半错（同上，$1$ 除非 $n=3$ 否则压在最底，绝不可能紧随 $n$ 之后出栈）；
- C. $n-1$ 或 $n-2$：正确。两类情形 $p_1\neq n-1$ 与 $p_1=n-1$ 分别对应，且都能构造；
- D. $n-1$：错。漏掉 $p_1=n-1$ 的边界情形（此时 $n-1$ 已经在 $n$ 之前出去过一次），把"可能之一"当成"必然"，是本题最强干扰项。

## 8. 考场标准答案

$p_2=n$ ⟹ $1\sim n$ 已全部进栈，且在 $n$ 进栈前只弹出过 $p_1$ 一个元素。

- $p_1\neq n-1$：$n-1$ 仍在栈顶 ⟹ $p_3=n-1$；
- $p_1=n-1$：栈顶降为 $n-2$ ⟹ $p_3=n-2$。

两种情形均可实现（如 $n=4$：$1,4,3,\dots$ 与 $3,4,2,\dots$），故 $p_3=n-1$ 或 $n-2$，选 **C**。

## 9. 易错点

1. **漏边界情形**：默认"$n$ 下面一定压着 $n-1$"，忘了 $n-1$ 可能早已作为 $p_1$ 出栈，从而误选 D；
2. 认为 $p_1$ 可以是任意值还不影响 $p_3$：实际 $p_1$ 恰好决定栈顶，本题的"两解"正来源于此；
3. 把“$p_3$ 有两个可能值”误读成“答案不确定、应选 D 类单一值”或误选“不确定”类选项：本题四个选项都是具体数值，要求的是**取值集合**，能取两个就必须选包含两个的那一项；
4. 默认 $n$ 很大却忽略 $n\ge3$ 的前提：$n=1,2$ 时"第 3 个输出元素"不存在，选项 A 的 $\{1,2\}$ 是 $n=3$ 的退化结果。

## 10. 一句话规律

栈的"由输出反推状态"题，一律抓住**目标元素出栈的那一瞬间**：先确定"它进栈前已经出去了几个、是谁"，栈顶便随之唯一确定；把"前驱元素是否已被提前弹出"作为分支逐一列举，就能保证不漏解。
