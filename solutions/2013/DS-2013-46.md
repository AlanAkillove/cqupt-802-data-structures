# DS-2013-46

## 1. 原题

某顺序表中的数据序列为降序序列，试设计一算法将数据序列变换为升序序列。要求：

（1）描述算法的基本设计思想；

（2）根据设计思想，描述算法的详细实现步骤，可使用伪代码、 $C$ 或 $C++$ 或 $JAVA$ 语言，关键之处给出简要注释；

（3）分析算法时间复杂度、空间复杂度。

## 2. 答案

**基本设计思想**：降序（非增）序列**倒过来读就是升序（非降）序列**，所以不必使用任何排序算法，只需把顺序表**原地逆置**——首尾配对交换：令 `i = 0`、`j = length-1`，交换 `elem[i]` 与 `elem[j]`，然后 `i++`、`j--`，重复直到 `i >= j`。

**实现**（教材风格 C，顺序表 `SqList`）：

```c
void DescToAsc(SqList *L)                 /* 原地把降序表变为升序表 */
{
    int i = 0, j = L->length - 1;         /* j 指向最后一个有效元素 */
    ElemType t;
    while (i < j) {                       /* 两下标相遇即止 */
        t = L->elem[i];                   /* 首尾交换 */
        L->elem[i] = L->elem[j];
        L->elem[j] = t;
        i++;  j--;                        /* 相向移动 */
    }
}
```

**复杂度**：时间 $O(n)$，$n$ 为顺序表的长度（表中元素个数）——恰好交换 $\lfloor n/2 \rfloor$ 次、每次 $3$ 次赋值，移动元素总数 $3\lfloor n/2 \rfloor$；空间 $O(1)$——只用 `i`、`j`、`t` 三个辅助变量，在原数组空间内完成。

## 3. 题目分析

- 已知：一个顺序存储的线性表（顺序表）$L$，其数据序列 $A[0]\ge A[1]\ge\cdots\ge A[n-1]$ 为**降序**（题面"降序序列"按包含相等元素的非增理解，结论对严格降序同样成立）；
- 目标：把数据序列变换为升序 $A[0]\le A[1]\le\cdots\le A[n-1]$，并写出设计思想、实现步骤与时间/空间复杂度；
- 输入 / 输出：输入为顺序表 $L$（含 `elem[]` 与 `length`）；输出为**同一个表**（原地修改），表长不变、元素多重集不变，只是排列次序反转；
- 关键约束：**表的存储结构是顺序的**，可以按下标随机访问，因此"首尾配对交换"能直接实现；这与 DS-2013-38 的链表场景（只能单向遍历）形成对照；
- 命题意图：考"先看数据的**初始状态**再选算法"的意识——已完全有序（哪怕是逆序）的数据，正确的做法是 $O(n)$ 的结构变换而不是 $O(n\log n)$ 甚至 $O(n^2)$ 的排序；同时考顺序表原地操作的下标控制与边界（空表、单元素、`length` 的语义）；
- 隐含对照（第 6.5 节展开）：若把它当排序题，则直接插入排序对逆序输入取最坏情形 $O(n^2)$；快速排序取首元素为支点在已有序（升序或降序）输入下每趟只分离出一个元素，同样退化到 $O(n^2)$（与 DS-2013-44、DS-2013-18 的结论相呼应）。

## 4. 核心考点

核心考点：
DS01.02.01 顺序存储（顺序表的下标随机访问特性使"首尾配对交换"成为 $O(1)$ 空间的原地操作；`length` 与合法下标范围 $0\sim length-1$ 的对应关系）

辅助考点：
DS06.01 排序的基本概念（"内部排序/趟/初始序列的状态对复杂度的影响"——本题的关键判断是"数据已有序，不需要排序算法"）；DS01.03 线性表的应用（有序表的逆置、合并等经典表操作，本库 DS-2012-45 的链表逆置与本题同族）

解释：作答的主体是顺序表上的下标操作，属 DS01.02.01；而"为什么不用排序"这一判断依据来自 DS06.01 关于初始状态与算法效率关系的基本概念。

## 5. 解题思路

1. 先观察数据的**初始状态**：题目直接告知是降序。降序与升序的关系只有一个——次序完全相反，即"逆置"，不涉及任何比较与选择；
2. 于是把问题从"排序"降级为"结构变换"：目标是 $B[i]=A[n-1-i]$。验证它确实得到升序（见 6.2 节的不等式证明），确认不需要排序算法；
3. 再看存储结构能否高效实现逆置：顺序表可随机访问 ⟹ 用两个相向移动的下标 $i\uparrow$、$j\downarrow$ 逐对交换，只需 $\lfloor n/2\rfloor$ 次交换、一个临时变量，无需辅助数组（若另开一个新表从后往前拷贝，则要 $O(n)$ 附加空间，原地写法更好）；
4. 定边界条件：循环条件写成 `i < j`（而非 `i <= j`），保证奇数长度时正中的元素不被"自己与自己交换"（虽不影响结果，但会多一次无谓赋值），并保证空表（`length = 0` ⟹ `j = -1`）与单元素表（`i = j = 0`）都不进入循环、不会越界；
5. 按"设计思想 → 实现步骤 → 复杂度"三段组织答案（本库算法设计题统一范式，参照 DS-2020-38），复杂度里**写明 $n$ 的含义**（$n$ = 顺序表长度 $L.length$）；
6. 自检：任取偶数长、奇数长、含相等元素、空表四种实例各跑一遍（6.3 节），核对元素守恒（每个数只出现一次）与升序性。

## 6. 详细解答

### 6.1 数据结构定义（教材风格）

```c
#define MAXSIZE 100                       /* 顺序表容量上限 */
typedef int ElemType;

typedef struct {
    ElemType elem[MAXSIZE];               /* 静态数组；动态申请时写 ElemType *elem */
    int length;                           /* 当前表长，有效下标 0 .. length-1 */
} SqList;
```

（若采用教材第 10 章排序表的写法 `r[1..length]`、`r[0]` 作哨兵，则本题初值应改为 `i = 1, j = L->length`，且**不得**交换 `r[0]`，见第 9 节第 3 条。）

### 6.2 正确性证明

设原表满足非增：$A[0]\ge A[1]\ge\cdots\ge A[n-1]$。逆置后得到 $B$，其中

$$B[i]=A[n-1-i],\qquad 0\le i\le n-1$$

对任意 $0\le i<j\le n-1$，有 $n-1-i>n-1-j$，由原表的非增性

$$A[n-1-i]\le A[n-1-j]\quad\Longrightarrow\quad B[i]\le B[j]$$

即 $B$ 的任意前位置元素都不大于后位置元素，故 $B$ 为非降（升序）序列 ∎

同时：交换操作是**成对互换**，每个元素始终留在表内，元素多重集不变、表长 $n$ 不变（不产生新元素、不丢失元素），因此变换过程无需另开数组，也不改变 $L.length$。

（严格降序时上述推导给出 $B[i]<B[j]$，即严格升序，结论同样成立。）

### 6.3 实例走查

**偶数长** $L=(90,78,78,55,32,10)$，$n=6$：

| 轮 | $i$ | $j$ | 交换 | 表状态 |
|---|---|---|---|---|
| 1 | $0$ | $5$ | $90\leftrightarrow10$ | $(10,78,78,55,32,90)$ |
| 2 | $1$ | $4$ | $78\leftrightarrow32$ | $(10,32,78,55,78,90)$ |
| 3 | $2$ | $3$ | $78\leftrightarrow55$ | $(10,32,55,78,78,90)$ |
| — | $3$ | $2$ | $i<j$ 不成立，退出 | $(10,32,55,78,78,90)$ ✓ |

交换 $3=\lfloor 6/2\rfloor$ 次，结果升序且含相等元素 $78,78$ ✓。

**奇数长** $L=(5,3,1)$，$n=3$：$i=0,j=2$ 交换 $5\leftrightarrow1$ 得 $(1,3,5)$；随后 $i=1,j=1$，条件 `i < j` 不成立 ⟹ 退出，正中的 $3$ 未被多交换一次 ✓。

**空表** $n=0$：`j = L->length - 1 = -1`，`i = 0`，`0 < -1` 为假 ⟹ 一次循环都不进入，不发生 `elem[-1]` 的越界访问 ✓。

**单元素** $n=1$：`i = 0, j = 0`，`0 < 0` 为假 ⟹ 不交换，$(7)$ 仍为升序 ✓。

### 6.4 实现步骤与算法

**实现步骤**：

1. 取两个下标变量 `i = 0`（首）、`j = L->length - 1`（尾）；
2. 判断 `i < j`：不成立则算法结束（元素已全为自身位置，或已完成全部配对）；
3. 成立则用临时变量 `t` 交换 `L->elem[i]` 与 `L->elem[j]`（三步赋值，顺序不可颠倒，否则覆盖数据）；
4. 令 `i++`、`j--`，回到第 2 步；
5. 算法不修改 `L->length`（逆置不改变表长），调用形如 `DescToAsc(&L);`。

```c
/* 算法：将按降序存放的顺序表 L 原地改造成升序表 */
void DescToAsc(SqList *L)
{
    int i = 0;                            /* 首元素下标 */
    int j = L->length - 1;                /* 末元素下标；空表时 j = -1 */
    ElemType t;                           /* 交换用的临时变量 */

    while (i < j) {                       /* i、j 相遇即全部配对完成 */
        t           = L->elem[i];         /* 首尾元素交换 */
        L->elem[i]  = L->elem[j];
        L->elem[j]  = t;
        ++i;                              /* 左下标右移 */
        --j;                              /* 右下标左移 */
    }
}
```

**核心不变量**：每轮循环结束时，`elem[0..i-1]` 恰是原表 `elem[n-i..n-1]` 的逆序放置（即最小的 $i$ 个元素已就位于表头），`elem[j+1..n-1]` 恰是原表 `elem[0..j]` 的逆序放置（最大的 $n-1-j$ 个元素已就位于表尾），中间 `elem[i..j]` 仍待处理；当 $i\ge j$ 时两段拼接覆盖整个表，全表逆置完成。

### 6.5 复杂度分析（写明各符号含义）

设 $n$ 为顺序表的**长度**（即 $L.length$，表中元素个数）。

- **时间**：循环执行 $\lfloor n/2 \rfloor$ 轮，每轮 $3$ 次元素赋值（交换）$+2$ 次下标修改 $+1$ 次条件判断，故
$$T(n)=3\lfloor n/2\rfloor+O(n)=O(n)$$
最好、最坏、平均情形完全相同（都与数据的具体取值无关，因为**不做任何比较**，只做固定次数的移动）；
- **空间**：仅 `i`、`j`、`t` 三个辅助变量，$S(n)=O(1)$（原地算法，未另开数组、未使用递归）；
- **最优性说明**：变换后每个元素的位置几乎都变了（除正中元素），任何算法至少要把 $n$ 个元素各自安置一次，故时间下界为 $\Omega(n)$；本算法 $O(n)$ 已达下界；
- **对照：若误用排序算法**（同一输入，降序表）——

| 方法 | 该输入下的时间 | 附加空间 | 说明 |
|---|---|---|---|
| 逆置（本解） | $O(n)$ | $O(1)$ | 交换 $\lfloor n/2\rfloor$ 次，无比较 |
| 直接插入排序 | $O(n^2)$ | $O(1)$ | 逆序输入是其最坏情形，比较 $\frac{n(n-1)}{2}$ 次、每次插入都要移动全部已排序元素 |
| 起泡排序 | $O(n^2)$ | $O(1)$ | 每趟只能把 1 个元素移到端点，需 $n-1$ 趟 |
| 简单选择排序 | $O(n^2)$ | $O(1)$ | 比较次数与初始状态无关 |
| 快速排序（取首元素为支点） | $O(n^2)$ | $O(\log n)$ | 已有序（升序或降序）输入下每趟只分离出 1 个元素，退化（见 DS-2013-44、DS-2013-18） |
| 二路归并排序 | $O(n\log n)$ | $O(n)$ | 与初始状态无关，但仍多余比较，且要辅助数组 |
| 另建新表逆序拷贝 | $O(n)$ | $O(n)$ | 时间同本解，但空间不优 |

结论：**已知数据完全逆序时，"逆置"是唯一正确量级的做法**。

## 8. 考场标准答案

**(1) 设计思想**：降序序列与升序序列互为逆序，故不需要排序，只要把顺序表**原地逆置**——第 $i$ 个元素与第 $n-1-i$ 个元素互换（$i$ 从 $0$ 到 $\lfloor n/2\rfloor-1$）。用两个相向移动的下标 `i`、`j` 逐对交换，直到 `i >= j`。逆置只做固定次数的移动、不做比较，且不改变表长与元素集合。

**(2) 实现步骤与代码**：

```c
void DescToAsc(SqList *L)          /* 降序顺序表原地变为升序 */
{
    int i = 0, j = L->length - 1;  /* i 指首、j 指尾；空表时 j = -1 */
    ElemType t;
    while (i < j) {                /* 相遇即结束，保证每对只交换一次 */
        t = L->elem[i]; L->elem[i] = L->elem[j]; L->elem[j] = t;
        ++i; --j;
    }
}
```

**(3) 复杂度**：时间 $O(n)$，$n$ 为顺序表长（交换 $\lfloor n/2\rfloor$ 次、共 $3\lfloor n/2\rfloor$ 次赋值，与元素取值无关）；空间 $O(1)$（仅 `i`、`j`、`t` 三个辅助变量，原地进行）。空表（$n=0$）与单元素表（$n=1$）时循环体不执行，直接结束。

## 9. 易错点

1. **把它当排序题**写插入/冒泡/快排：不但 $O(n^2)$，还掩盖了"数据已完全逆序"这一题设信息——本题得分点正是"逆置即可，无须排序"；
2. 循环条件写成 `i <= j`：中间元素"自己与自己交换"（结果不错但多一次赋值）；更严重的写法是 `while(i != j)` 配 `i++, j--`，在偶数长度时会交叉错位，导致重复交换而**复原**（如 $n=2$：交换后 `i=1,j=0`，若继续按 `elem[i]↔elem[j]` 再交换一次就变回降序）；
3. **下标起点与哨兵位**：若表按教材排序表方式从 $1$ 号单元存放到 `length` 号单元（`r[0]` 作哨兵/工作单元），则必须 `i = 1, j = L.length`，把 $0$ 号单元卷进交换会破坏哨兵并覆盖数据；
4. 初值 `j = L->length - 1` 写成 `j = L->length`（或 `MAXSIZE-1`）：前者越界访问 `elem[length]`（读到未定义数据），后者按表容量而非表长逆置，会把表尾之后的空单元换进表内；
5. 交换漏用临时变量：写成 `L->elem[i] = L->elem[j]; L->elem[j] = L->elem[i];` 两步，第一个值被覆盖，结果是两个位置都等于 `elem[j]`，元素丢失；
6. 误加"表长要变化"或对 `length` 重新赋值：逆置不增删元素，`L->length` 必须保持不变；
7. 复杂度只写 $O(n)$ 而未说明 $n$ 是表长、未回答空间复杂度（题面第（3）问明确要求时间、空间各分析一次）。

## 10. 一句话规律

顺序表上的"变换"类算法题，第一步永远是**看数据初始状态**：完全降序 ⟺ 完全逆序，则问题从"排序 $O(n\log n)$"降为"逆置 $O(n)$"——首尾配对交换、`i < j` 收尾、$O(1)$ 空间；而链表上做同样的事要 $O(n)$ 逐个改指针（DS-2012-45），顺序表的优势正是下标可直接跳到位。
