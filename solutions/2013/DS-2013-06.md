# DS-2013-06

## 1. 原题

在解决计算机主机与打印机之间速度不匹配问题时通常设置一个打印数据缓冲区，主机将要输出的数据依次写入该缓冲区，而打印机则依相同次序从该缓冲区中取出数据打印。则该缓冲区作为数据结构是一个（）结构。

A. 队列

B. 栈

C. 链表

D. 都不是

## 2. 答案

**A**（队列）。

## 3. 题目分析

- 已知：写入端（主机）"依次写入"，取出端（打印机）"**依相同次序**取出"——即先写入的数据先被取出；两端速度不匹配，需要缓冲；
- 目标：判定该缓冲区所对应的**逻辑结构**（抽象数据类型）；
- 关键约束：题干问的是"作为数据结构是什么结构"，应答出对数据存取次序的限制（逻辑结构层面），而不是回答"用什么方式存放"（存储结构层面）；
- 命题意图：考"实际场景 → 抽象结构"的建模能力，核心是把"先进先出"这一存取次序与队列的定义对应起来，并排除"链表"这一存储结构层次的干扰项。

## 4. 核心考点

核心考点：
DS02.01 栈和队列的基本概念（FIFO 与 LIFO 的特性区分）

辅助考点：
DS02.07 栈、队列和数组的应用（队列用于速度匹配/缓冲的典型场景）

解释：解题的决定性依据是“输出次序与输入次序相同 = 先进先出”这一**队列的特性定义**（DS02.01）；而“主机与打印机之间设缓冲区”属该结构的应用背景（DS02.07），故主考点取 DS02.01、辅助取 DS02.07。

## 5. 解题思路

1. 把场景写成存取规则：设主机依次写入 $d_1,d_2,\cdots,d_k$；"依相同次序取出"意味着取出序列也是 $d_1,d_2,\cdots,d_k$ ⟹ **先进先出（FIFO）**；
2. 与两种受限线性表的定义比对：栈是"后进先出（LIFO）"，只在同一端（栈顶）插入与删除；队列是"只在一端（队尾）插入、另一端（队头）删除"的 FIFO 结构 ⟹ 只能是队列；
3. 用物理直觉复核：打印必须按输出的先后次序进行，若用栈则最后写入的先打印，正文与页眉会倒序，明显不合要求；
4. 排除 C：链表是**存储结构**（用指针链接的实现方式），它不限制存取次序；"缓冲区"要求的是次序限制这一逻辑性质，故不选；
5. 由 2、4 得答案 A，D 自然不成立。

## 6. 详细解答

**第一步：抽取存取次序**

写入：$d_1$ 先入，$d_2$ 次入，……，$d_k$ 最后入。
取出要求"依相同次序" ⟹ 取出顺序为 $d_1,d_2,\cdots,d_k$。
即 $\text{out}(1)=\text{in}(1)$：**第一个进入的元素第一个离开**，这正是 FIFO。

**第二步：FIFO ⟹ 队列**

队列的定义：只允许在表尾（rear）进行插入（入队）、在表头（front）进行删除（出队）的受限线性表，其输出序列是输入序列的**同一排列**。
栈的定义：只允许在表尾（栈顶 top）进行插入与删除，输出序列是输入序列的**逆序排列**（$d_k,\cdots,d_2,d_1$）。
题目要求输出次序与写入次序相同 ⟹ 符合队列定义，不符合栈定义。

**第三步：为何本题场景必然需要"缓冲"**

主机产出数据的速度远高于打印机消费速度，两者速率不匹配；若无缓冲，主机须等待打印机，CPU 时间被浪费。设置一个 FIFO 缓冲区后，主机写入即可返回，打印机按自己节奏取出——这是"队列解决速度匹配"的标准用途（同类：进程/作业就绪队列、键盘输入缓冲区、打印机假脱机 Spooling 队列、层次遍历的等待表）。

**第四步：排除"链表"**

同一逻辑结构（队列）既可用**链式**实现（链队列：队头指针 + 队尾指针），也可用**顺序**实现（循环队列，见 DS-2013-08）。因此"链表"回答的是"怎么存"，而题干问的是"按什么次序存取"。而且链表的定义本身不含任何次序限制（可在任意位置插入/删除），无法表达"依相同次序取出"这一要求。

**答案**：A。

## 7. 选项分析

- A. 队列：正确。写入次序 = 取出次序 ⟺ FIFO ⟺ 队列的定义；且队列正是"主机—慢速外设"速度匹配场景的标准结构；
- B. 栈：错。栈的取出次序是写入次序的**逆序**，与题干"依相同次序取出"直接矛盾（那样会把文档的最后一行最先打印出来）；
- C. 链表：错。链表属存储结构层次的概念，不限定存取次序；且本题缓冲区完全可以用循环队列（数组）实现，"链表"并非必选，逻辑结构仍是队列；
- D. 都不是：错。A 已准确刻画其存取次序。

## 8. 考场标准答案

选 **A**。

主机"依次写入"、打印机"依相同次序取出" ⟹ 先进入者先离开，是先进先出（FIFO）的存取限制；队列即"队尾插入、队头删除"的 FIFO 受限线性表，常用于主机与慢速外设之间的速度匹配缓冲。栈为后进先出（次序相反），链表只是存储结构而不规定存取次序，故均不选。

## 9. 易错点

1. 混淆**逻辑结构与存储结构**而选 C："队列/栈"说的是次序限制，"链表/数组"说的是物理存放方式；判据是题干问"作为数据结构是什么结构"并给出了存取次序；
2. 因"缓冲区"一词联想成"一块连续存储区"而选 C 或 D：实现确实常用数组（循环队列），但抽象层次上它是队列；
3. 忽略题干“依相同次序”这一关键限定：若改成“后发出的数据先打印”（如某些撤销/回溯场景），答案才变成栈。

## 10. 一句话规律

"速度不匹配 + 缓冲 + 不改变先后次序"三件套 → 队列；一旦出现"次序颠倒/最近的一个优先/回溯撤销"→ 栈；问"用什么方式存放"才考虑链表或数组。
