# DS-2013-21

## 1. 原题

求整数 $n$ （ $ n \geq 0$ ）阶乘函数的递归算法如下，其时间复杂度是________ 。

```c
long Factorial(long n)
{
    if(n==0)
        return 1;
    else return n*Factorial(n-1);
}
```

## 2. 答案

$O(n)$（准确说是 $\Theta(n)$：函数被调用 $n+1$ 次，执行 $n$ 次乘法；递归工作栈深度亦为 $n+1$，故空间复杂度也是 $O(n)$）。

## 3. 题目分析

- 已知：一段教材风格的递归函数；入口条件 $n\ge 0$；递归出口为 `n==0`（返回 $1$）；递归分支 `return n*Factorial(n-1)` 中**只出现一次**自身调用，实参每次减 $1$；
- 目标：该算法的时间复杂度；
- 关键约束：
  1. 单次调用的非递归代价是**常数**：一次 `if` 的相等比较、（`else` 分支）一次乘法与一次函数调用开销，没有循环、没有额外递归分支；
  2. 递归深度由"实参从 $n$ 变到 $0$ 需要几步"决定：每次 $n\to n-1$，故链条长 $n+1$（含 `Factorial(0)` 这一次真正进入函数的调用）；
  3. 题面给的 $n\ge 0$ 正是递归可终止的前提——若传入负数，`n==0` 永不成立，会一路递归到栈溢出；
  4. 计数口径沿用绪论"语句频度"：把一次乘法、一次比较都记作 $O(1)$，即假设 `long` 运算为常数时间（见第 9 节第 5 条关于大整数的说明）；
- 命题意图：考"线性递归（每次只有一次自调用）的时间复杂度 $=$ 递归层数 $\times$ 每层代价"这一最基本模式，并与学生最容易犯的"一看到递归就往指数级想"对撞——真正的指数级来自**两次及以上**自调用（如递归求 Fibonacci、汉诺塔的 $2^n$ 型调用树），本函数不属此类。本题与本卷第 2 题（二重/三重循环的 $O(n^3)$）构成"循环型频度统计 ↔ 递归型频度统计"的对照，与紧随其后的第 22 题（直接给频度式取量级）构成"先自己求频度 ↔ 频度已给出"的递进。

## 4. 核心考点

核心考点：
DS00.02 算法与算法分析（语句频度、时间复杂度 $T(n)=O(f(n))$ 的定义；递归算法的代价按"调用次数 × 每次调用中的基本操作次数"统计）

辅助考点：
DS02.07 栈、队列和数组的应用（递归的实现依赖运行栈：每层调用压入一个栈帧保存返回地址与局部量 `n`，故递归深度同时就是附加空间 $O(n)$；把递归改写成显式栈或 `for` 循环是该节点的常规操作）

解释：题目问的是"时间复杂度"这一绪论概念，与具体数据结构无关，故主标签 DS00.02（同本库 DS-2005-20、DS-2007-37、DS-2012-21 的打标口径）；但"为什么递归不会凭空多算、它的代价实体是什么"要靠 DS02.07 的递归工作栈来解释，且本题空间结论直接由它给出，故列辅助。

## 5. 解题思路

1. 先确认递归**形态**：`else` 分支里 `Factorial` 只出现一次 ⟹ 调用结构是一条"链"而不是一棵"树"，因此不可能有 $2^n$ 型爆炸；
2. 再数链长：实参依次为 $n,n-1,n-2,\dots,1,0$，共 $n+1$ 个不同值，每个值对应一次函数调用 ⟹ 调用次数 $=n+1$；
3. 每次调用中"随问题规模增长"的操作只有一条（比较或乘法），记作常数 $c$，于是可写递归式 $T(n)=T(n-1)+c$，$T(0)=c$；
4. 展开求解：$T(n)=T(n-1)+c=T(n-2)+2c=\dots=T(0)+n\cdot c=(n+1)c$ ⟹ $\Theta(n)$，取 $O(n)$；
5. 换一种更初等的数法交叉验证：整个过程**执行的乘法次数恰为 $n$**（$1\times2\times\cdots\times n$），乘法是基本操作，频度 $=n$ ⟹ $O(n)$；两条路给出同一量级；
6. 用极小规模手工核对边界：$n=0$ 时调用 $1$ 次、乘法 $0$ 次；$n=1$ 时调用 $2$ 次、乘法 $1$ 次——若把答案误写成 $O(n-1)$、$O(n!)$ 之类，在这两个点上立刻对不上；
7. 顺手给出空间结论：栈深 $n+1\Rightarrow$ 附加空间 $O(n)$（本题未问，但简答时附一句更完整）。

## 6. 详细解答

**第一步：展开调用链**

设首次调用为 `Factorial(n)`，按代码逐步展开：

```
Factorial(n)  →  n * Factorial(n-1)
Factorial(n-1)→  (n-1) * Factorial(n-2)
   ⋮
Factorial(2)  →  2 * Factorial(1)
Factorial(1)  →  1 * Factorial(0)
Factorial(0)  →  return 1        （递归出口，不再向下调用）
```

进入函数的实参取值集合为 $\{0,1,\dots,n\}$，且每个值恰好出现一次（每次严格减 $1$），故

$$\text{调用次数}=n+1$$

**第二步：单次调用的频度**

| 分支 | 执行的基本操作 | 次数 |
|---|---|---|
| `if(n==0)` 成立（仅 `Factorial(0)` 这一次） | 一次相等比较、`return 1` | $c_1$（常数） |
| `else` 分支（其余 $n$ 次） | 一次相等比较、一次乘法、一次递归调用 | $c_2$（常数） |

没有循环、没有第二处递归调用，故每次调用的代价与 $n$ 无关。

**第三步：写递归式并求解**

$$T(n)=\begin{cases}c, & n=0\\[2pt] T(n-1)+c, & n\ge 1\end{cases}$$

迭代展开（逐次代入 $n$ 次）：

$$T(n)=T(n-k)+kc\ \xrightarrow{k=n}\ T(0)+nc=(n+1)c$$

因此 $T(n)=\Theta(n)$，按题面要求写时间复杂度 $O(n)$。

**第四步：用"乘法次数"独立复核**

另一种数法：把"两个整数相乘"取为基本操作。回代递归结果时实际作的是

$$n\times(n-1)\times\cdots\times 2\times 1$$

乘法算子共使用 $n$ 次（`Factorial(0)` 那次不作乘法），比较 `n==0` 共 $n+1$ 次，故频度 $T(n)=n+(n+1)=2n+1$，最高阶项 $2n$ ⟹ $O(n)$（与本库 DS-2013-22 的"$T(n)$ 取最高数量级项并舍系数"规则完全一致）。

**第五步：逐点枚举验证**

| $n$ | 调用次数 $n+1$ | 乘法次数 $n$ | 比较次数 $n+1$ | 频度 $2n+1$ | $\Theta(n)$ 是否吻合 |
|---|---|---|---|---|---|
| $0$ | $1$ | $0$ | $1$ | $1$ | ✓ |
| $1$ | $2$ | $1$ | $2$ | $3$ | ✓ |
| $2$ | $3$ | $2$ | $3$ | $5$ | ✓ |
| $3$ | $4$ | $3$ | $4$ | $7$ | ✓ |
| $5$ | $6$ | $5$ | $6$ | $11$ | ✓ |
| $10$ | $11$ | $10$ | $11$ | $21$ | ✓ |

每行 $n$ 翻倍时频度也近似翻倍（$n=5\to10$ 时 $11\to21$，$n=1\to2$ 时 $3\to5$），呈线性增长而非平方/指数，确认量级为 $n$。

**第六步：与等价的非递归写法对照（同一频度）**

```c
long Factorial_2(long n)      /* 把递归改写成循环，代价应相同 */
{
    long p = 1;
    for (long i = 2; i <= n; ++i)   /* 循环体执行 n-1 次（n>=2） */
        p = p * i;
    return p;
}
```

循环版乘法 $n-1$ 次（$n\ge1$，`Factorial_2(1)` 返回 $1$ 不需乘），递归版 $n$ 次，差一个常数，两者同为 $O(n)$ ⟹ 第五步的计数没有多算递归开销。

**第七步：空间复杂度（附带结论）**

递归版在返回前，栈上同时存在 `Factorial(n)`、`Factorial(n-1)`、…、`Factorial(0)` 共 $n+1$ 个栈帧（每帧保存实参 `n` 与返回地址），故附加空间 $S(n)=\Theta(n)$；循环版只需一个累乘变量，空间 $O(1)$。这正是"递归省思维、代价在栈"的典型一例（DS02.07）。

**答案**：$O(n)$。

## 8. 考场标准答案

$O(n)$。

设一次调用中除递归外的操作为常数时间 $c$，则
$$T(n)=T(n-1)+c\ ,\quad T(0)=c$$
逐次代入得 $T(n)=(n+1)c=\Theta(n)$。等价地：实参按 $n,n-1,\dots,0$ 各调用一次共 $n+1$ 次，乘法执行 $n$ 次，频度为 $2n+1$，故时间复杂度为 $O(n)$（递归工作栈深度 $n+1$，空间复杂度亦为 $O(n)$）。

## 9. 易错点

1. **一看到递归就答 $O(2^n)$**：指数级来自"一次调用产生两次以上自调用"（如双分支递归 $T(n)=2T(n-1)+c$、汉诺塔 $2^n-1$ 次移动）；本题 `else` 分支里 `Factorial` 只出现一次，是**线性递归**，调用结构是一条链；
2. **答成 $O(n!)$**：把"函数在计算阶乘"与"算法复杂度含 $n!$"混为一谈——复杂度衡量的是**执行的基本操作条数**，与被计算函数的数学增长速度无关（$n!$ 只是结果的数值大小）；
3. **调用次数与乘法次数各差 $1$ 引起误判**：调用 $n+1$ 次、乘法 $n$ 次，二者都属 $\Theta(n)$，不影响量级；但若题目改问"执行了多少次乘法"，必须答 $n$（$n=0$ 时为 $0$），不能填 $n+1$；
4. **忽略递归出口那一次调用**：`Factorial(0)` 是**进入函数**的一次调用（要执行 `if` 与 `return`），不是"不占用时间"，边界 $n=0$ 代入检验最容易在这里出错；
5. **漏掉 $n\ge0$ 与运算代价的前提**：题面 $n\ge0$ 保证终止（$n<0$ 时 `n==0` 永不成立 ⟹ 无限递归、栈溢出）；另需默认 `long` 乘法为 $O(1)$——教材与考研均按此模型计数。若严格考虑 $n!$ 是一个约 $n\log_2 n$ 位的大整数、其乘法不再是常数时间，量级会上升，这超出本课程口径（本题按"一次运算 $O(1)$"计），答 $O(n)$；
6. **只答时间、丢掉空间**：本题只问时间复杂度，但若题目追问空间，须记得线性递归的栈深同样是 $O(n)$，不可写 $O(1)$（那是第六步的循环版）。

## 10. 一句话规律

线性递归的复杂度就是"链长 × 每层代价"：实参每步减 $1$、函数体里只自调用一次 ⟹ 层数 $\Theta(n)$，配上常数的层内代价即 $O(n)$；只有当一次调用中出现两次及以上自调用时，才会冒出 $2^n$ 型的调用树。
