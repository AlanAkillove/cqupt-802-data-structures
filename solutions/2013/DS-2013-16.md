# DS-2013-16

## 1. 原题

设连通图 $G$ 采用邻接表存储，则深度优先遍历算法的时间复杂度是（）。

> 订正说明转录：源文作"设图连通 $G$"，据题意修正为"设连通图 $G$"。

A. $O(n)$

B. $O(n+e)$

C. $O(n^2)$

D. $O(n\times e)$

（按图论题惯例，$n$ 表示图的顶点数，$e$ 表示边或弧的条数；题面未另行说明，与 2014 年同型题、2007 年第 33 题用同一记号。）

## 2. 答案

**B**（$O(n+e)$）。

## 3. 题目分析

- 已知：连通图 $G$（因此从任一顶点出发的 DFS 即可访问全部 $n$ 个顶点，无需外层循环反复起新根），存储结构为**邻接表**；
- 目标：深度优先遍历（DFS）算法的时间复杂度；
- 关键约束：
  1. 复杂度由"两类基本操作"的次数相加，而不是相乘：① 每个顶点被访问并标记一次；② 每条边（无向图为两个边结点）在其一端被检查一次；
  2. 邻接表的特性决定第 ② 项的代价是"实际边数"而非 $n$：`FirstAdjVex`/`NextAdjVex` 沿单链表走，只经过该顶点真实存在的邻接点；
  3. 题面"连通"这一前提保证第 ① 项恰为 $n$ 次；若非连通图，`DFSTraverse` 需对每个连通分量重扫一次头向量，量级仍为 $O(n+e)$，结论不变；
- 命题意图：考"同一算法在不同存储结构上的复杂度差异"——邻接表 $O(n+e)$ 与邻接矩阵 $O(n^2)$ 是教材给出的成对结论，本题四个选项正是这两个答案加上两个由"加/乘混淆""漏项"生成的干扰项。与同卷 DS-2013-15（该选哪种存储）构成"存储 ↔ 效率"的一问一答。

## 4. 核心考点

核心考点：
DS04.03.01 深度优先搜索（DFS 的执行过程与时间复杂度分析；`visited` 标记保证每顶点只进一次）

辅助考点：
DS04.02.02 邻接表法（头向量 + 边结点的结构、沿链表取邻接点的代价、无向图边结点数为 $2e$）

解释：题目问的是遍历算法的代价，但代价的"算法侧"（访问顶点、回溯）与"存储侧"（取邻接点要多久）必须分开数，答案 $O(n+e)$ 完全由邻接表的取邻接点代价决定；同一算法换成邻接矩阵即为 $O(n^2)$，所以 DS04.02.02 是本题不可缺的一半。

## 5. 解题思路

1. 把 DFS 的开销拆成两笔账：**顶点账**与**边账**，各自数次数再相加（这是所有遍历复杂度分析的通用框架）；
2. 顶点账：`visited[i]` 一经置真就不再进入，$n$ 个顶点各访问一次，加上访问时的常数工作，共 $O(n)$；
3. 边账：对顶点 $v_i$ 取邻接点就是遍历其边链表，长度恰为 $\deg(v_i)$（无向图）；于是全部顶点加起来扫描的边结点数为 $\sum_{i}\deg(v_i)=2e$（有向图为 $\sum out(v_i)=e$）⟹ 边账 $O(e)$；
4. 合并：$T(n,e)=O(n)+O(e)=O(n+e)$；
5. **两个方向的自检**：① 极值检验——当 $e=\Theta(n^2)$（稠密）时 $O(n+e)$ 退化为 $O(n^2)$，与邻接矩阵口径一致，说明没漏主项；当 $e=n-1$（树/连通图下界）时得 $O(n)$，符合"树遍历就是线性"的常识；② 与教材另一结论（邻接矩阵 DFS 为 $O(n^2)$）对照，确认本题用的是邻接表那一行；
6. 排除法兜底：A 只有顶点账（等于没走边），C 是邻接矩阵的答案，D 是把"相加"错成"相乘"。

## 6. 详细解答

**第一步：写出教材风格的 DFS 与邻接表定义**

```c
/* 邻接表类型定义（教材 7.2.2 的要点） */
typedef struct ArcNode {
    int adjvex;                  /* 该边所到的顶点在头向量中的下标 */
    struct ArcNode *nextarc;     /* 指向下一条边的指针 */
} ArcNode;
typedef struct VNode {
    VertexType data;
    ArcNode *firstarc;           /* 指向第一条依附该顶点的边 */
} VNode, AdjList[MAX_VERTEX_NUM];

void DFSTraverse(ALGraph G)                 /* 对图 G 作深度优先遍历 */
{
    for (v = 0; v < G.vexnum; ++v) visited[v] = FALSE;   /* 扫一遍头向量：O(n) */
    for (v = 0; v < G.vexnum; ++v)                       /* O(n) 次判断 */
        if (!visited[v]) DFS(G, v);                      /* 连通图只发生 1 次 */
}

void DFS(ALGraph G, int v)
{
    VisitVex(G, v);  visited[v] = TRUE;                  /* 每个顶点仅一次 */
    for (p = G.vertices[v].firstarc; p; p = p->nextarc)  /* 走过 deg(v) 个边结点 */
        if (!visited[p->adjvex]) DFS(G, p->adjvex);
}
```

**第二步：数顶点账**

- `DFSTraverse` 的两个前置/主循环都要扫头向量，各 $O(n)$；
- 图连通 ⟹ 第一个未访问顶点起根后全部顶点被访问，后一个循环里的 $n-1$ 次 `if` 判断都不成立，不再递归；
- 每个顶点执行一次 `VisitVex` 与一次置 `visited`，$O(1)$/顶点 ⟹ 合计 $O(n)$。

**第三步：数边账（关键：邻接表只走真实存在的边）**

无向图中顶点 $v_i$ 的边链表长度等于 $\deg(v_i)$。DFS 每访问到一个顶点，就要**完整地**沿其链表走一遍以查看邻接点（无论邻接点是否已访问，结点都要被"看到"一次才能判断），故链表结点被访问的总次数为

$$\sum_{i=1}^{n}\deg(v_i)=2e\qquad(\text{握手定理；有向图为 }\sum out(v_i)=e)$$

⟹ 边账 $O(e)$（无向图写作 $O(2e)$，量级相同）。

**第四步：合并并检验退化情形**

$$T(n,e)=\underbrace{O(n)}_{\text{顶点}}+\underbrace{O(2e)}_{\text{边}}=O(n+e)$$

| 情形 | $e$ 的量级 | $O(n+e)$ 退化为 | 与常识/其它结论是否一致 |
|---|---|---|---|
| 生成树（连通图边数下界） | $n-1$ | $O(n)$ | ✓ 树的 DFS 显然线性 |
| 一般稀疏图 | $O(n)$ | $O(n)$ | ✓ |
| 稠密图 | $\Theta(n^2)$ | $O(n^2)$ | ✓ 与邻接矩阵的 $O(n^2)$ 同阶（此时邻接表也不占优，见 DS-2013-15） |
| 完全图 | $\frac{n(n-1)}{2}$ | $O(n^2)$ | ✓ |

小例验证：取 $n=4$、$e=3$ 的路径图 $v_1-v_2-v_3-v_4$，从 $v_1$ 出发：访问 $4$ 个顶点，扫描边结点 $2e=6$ 个，总基本操作 $\le 4+6=10$ 次，与 $n+e=7$ 同阶，而 $n^2=16$ 明显偏大、$n\times e=12$ 无对应操作来源。

**第五步：与邻接矩阵口径对照**

邻接矩阵上作 DFS 时，找 $v_i$ 的邻接点必须扫完第 $i$ 行的 $n$ 个元素（哪怕该行只有两个非零元），故边账变成 $n\times n$：$T=O(n^2)$，这正是选项 C 的出处，也是 2019 年第 29 题第 (4) 问"分别分析邻接矩阵与邻接表下遍历复杂度"的标准答案对。

**答案**：B。

## 7. 选项分析

- A. $O(n)$：错。只算了顶点账，等于承认"访问每个顶点"却否认"要看每条边"。仅在 $e=O(n)$（稀疏图/树）时结论偶然成立，题目未对 $e$ 作限定，不能作为一般结论；
- B. $O(n+e)$：正确。顶点各访问一次、边结点各被扫描一次（无向图 $2e$ 个），两项相加；
- C. $O(n^2)$：错。这是**邻接矩阵**上 DFS 的复杂度（找邻接点须扫整行）。若图的边数恰为 $\Theta(n^2)$，B 与 C 数值同阶，但题面指定邻接表存储，必须给 $O(n+e)$；这是本题最强干扰项；
- D. $O(n\times e)$：错。把两类开销**相乘**（"对每个顶点都把所有边走一遍"）——DFS 中每个顶点的边链表只走一次，总长 $\sum\deg(v_i)=2e$ 与 $n$ 无关，不存在这个乘积；教材中也没有任何常规图算法是这个量级。

## 8. 考场标准答案

选 **B**，$O(n+e)$（$n$ 为顶点数、$e$ 为边数）。

邻接表中访问顶点 $v_i$ 时需沿其边链表走一遍，链表长为 $\deg(v_i)$；DFS 中每个顶点恰好被访问一次（`visited` 标记），每条边至多被扫描两次（无向图两个边结点各一次），故

$$T(n)=O(n)+O\!\left(\sum_{i=1}^{n}\deg(v_i)\right)=O(n+2e)=O(n+e)$$

若改用邻接矩阵存储，则取邻接点须扫描整行，复杂度为 $O(n^2)$。

## 9. 易错点

1. **混淆两种存储结构的结论**：邻接矩阵 $O(n^2)$、邻接表 $O(n+e)$，看到"$n^2$"顺手就选（选 C）是本题最主要失分点，题干"采用邻接表存储"必须回读；
2. **漏掉顶点项**：只写 $O(e)$。非连通图或星型图中顶点数可能与边数同阶甚至更多（如 $n$ 个孤立点 $e=0$），故必须保留 $n$ 项，标准写法是 $O(n+e)$；
3. **把无向图的 $2e$ 当成新量级**：$O(n+2e)$ 与 $O(n+e)$ 等价，大 $O$ 吸收常数，但若题目问"共扫描多少个边结点"，答数就是 $2e$（另见 2018 年第 12 题）；
4. **误以为"连通"这个前提会改变答案**：不改变。连通只省掉外层重复起根的常数倍，量级仍是 $O(n+e)$；
5. **BFS 与 DFS 记成不同复杂度**：同一存储结构下二者复杂度相同（邻接表都是 $O(n+e)$，邻接矩阵都是 $O(n^2)$），差别只在辅助结构（栈/递归 与 队列）与访问顺序。

## 10. 一句话规律

图上遍历的复杂度一律"两笔账相加"：顶点账 $O(n)$（每点进一次、`visited` 定生死）+ 边账 $O(\text{被扫描的边结点总数})$；邻接表按真实边数算（无向 $2e$）得 $O(n+e)$，邻接矩阵按整行扫描算得 $O(n^2)$，DFS 与 BFS 同价。
