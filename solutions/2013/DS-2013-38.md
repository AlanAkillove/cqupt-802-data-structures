# DS-2013-38

## 1. 原题

在一个长度为 $n$ 的单链表 $L$ 中，现需删除链表中 $*p$ 结点的前驱结点，试简要说明该操作的实现思想，并分析时间复杂度。

## 2. 答案

**实现思想**：单链表的结点只有指向后继的 `next` 指针，无法由 $p$ 反向找到它的前驱，因此只能**从头开始顺序查找**——设工作指针 `pre` 指向头结点（有头结点时）或首元结点（无头结点时），沿 `next` 逐链接后移动，直到 `pre->next->next == p`，此时 `pre->next` 就是 $*p$ 的直接前驱结点 $q$；令 `pre->next = q->next`（即跨过 $q$ 指向 $p$），再释放 $q$。

**时间复杂度**：$O(n)$——最坏与平均情形都要从头走到 $p$ 附近，指针后移次数与 $p$ 的位置成正比（约 $n-1$ 次比较）；空间复杂度 $O(1)$，只用了两个指针。

**边界**：若 $p$ 就是首元结点，则它没有前驱，操作不合法（应先判空并返回错误）；若 $p$ 为 `NULL` 或 $p$ 不在链表 $L$ 中，同样无法完成。

## 3. 题目分析

- 已知：长度为 $n$ 的单链表 $L$（结点结构 `data` + `next`），以及链表中的某个结点 $*p$（题目以"结点"而非"位序"给出目标）；
- 目标：删除 $*p$ 的**直接前驱**结点（注意不是删除 $*p$ 本身），并说明思想、分析复杂度；
- 关键约束：**单链表的链接是单向的**——持有 $p$ 的地址却拿不到指向 $p$ 的那个指针，删除操作又必须修改"前驱的前驱"的 `next`，所以必须从头遍历；
- 命题意图：考"存储结构决定运算实现"这一线性表核心结论——同一"删除前驱"操作在单链表上为 $O(n)$、在双向链表上为 $O(1)$（有 `prior` 指针时两步摘链）；同时考"删除结点需要修改的是**它前一个结点**的指针"这一操作细节，以及"目标结点位于表头时前驱不存在"的边界意识。

## 4. 核心考点

核心考点：

辅助考点：

解释：题面问的是"思想 + 复杂度"，实现思想完全落在单链表的链接特性上（DS01.02.02），复杂度分析按 DS00.02 的语句频度口径给出；DS01.02.03 只作为对照，不是本题作答所必需。

## 5. 解题思路

1. 先问自己"删除一个结点需要改哪根指针"——需要**它的前驱结点**的 `next`。要删 $q=\,$p 的前驱$，就得有 $q$ 的前驱 $pre$，即需要**两级前驱**；
2. 再看"能否从 $p$ 出发拿到这些指针"：单链结点只有 `next`，从 $p$ 只能往后走，**不能回头** ⟹ 只能从表头顺走；
3. 把"顺走"写成判据：设 `pre` 为工作指针，若 `pre->next == q` 且 `q->next == p`，等价地 `pre->next->next == p`——用这个条件在遍历中判别，就不必显式保存 $q$；
4. 摘链两句：`q = pre->next; pre->next = q->next;`（即 `pre->next = p`），然后 `free(q)`；顺序不能颠倒——先改链再释放，否则 $q$ 的 `next` 丢失；
5. 边界自查：$p$ 是首元结点 → 遍历全程 `pre->next->next` 永远不等于 $p$（因为不存在这样的前驱），故须先判 $p$ 是否为首元结点（或让循环带 `pre->next != NULL && pre->next->next != NULL` 的保护条件），遍历完仍未命中即报错；
6. 复杂度：基本操作取"指针比较次数"，$p$ 在第 $i$ 个位置（$i\ge 2$）时 `pre` 依次停在头结点、第 $1,\cdots,i-2$ 个结点，共比较 $i-1$ 次，$i$ 等概率时平均 $\sum_{i=2}^{n}(i-1)/n=(n-1)/2$ ⟹ $O(n)$（与 6.5 节口径一致）。

## 6. 详细解答

### 6.1 结构假设与"为什么必须遍历"

设单链表带头结点，结点定义如下（教材风格）：

```c
typedef int ElemType;
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

删除任一结点 $q$，必须修改"指向 $q$ 的那个指针"，即 $q$ 的前驱结点 $pre$ 的 `next`。题给的是 $p$，而 $q$ 是 $p$ 的前驱，于是需要 $q$ 的前驱 $pre$——**比目标结点再往前一格**。单链表中唯一的行走方向是 `next`，$p$、$q$ 都无法向后退，故只能从表头 $L$ 出发逐格试探。

### 6.2 遍历判据

工作指针 `pre` 从 $L$（头结点）起，每一步检查

$$pre\to next\to next \stackrel{?}{=} p$$

成立时即有 $pre\to next = q$（$p$ 的直接前驱）、$q\to next = p$，摘链即成。检查后令 `pre = pre->next` 后移。循环须带保护条件 `pre->next != NULL && pre->next->next != NULL`（等价于 `pre->next && pre->next->next`），防止表尾空指针解引用。

### 6.3 完整算法（考场书写版）

```c
/* 删除带头结点单链表 L 中结点 *p 的直接前驱；成功返回 OK，失败返回 ERROR */
Status DelPredecessor(LinkList L, LNode *p)
{
    LNode *pre, *q;

    if (L == NULL || p == NULL || L->next == p)   /* 空表 / p 为 NULL / p 是首元结点：无前驱 */
        return ERROR;

    for (pre = L; pre->next && pre->next->next; pre = pre->next)
        if (pre->next->next == p)                 /* pre->next 即 p 的前驱 q */
            break;

    if (pre->next == NULL || pre->next->next == NULL)
        return ERROR;                             /* 遍历完未找到，说明 p 不在链表 L 中 */

    q = pre->next;                                /* 先保存待删结点 */
    pre->next = q->next;                          /* 跨过 q 直接指向 p（q->next 就是 p） */
    free(q);                                      /* 再释放，顺序不可颠倒 */
    return OK;
}
```

### 6.4 最小实例走查（3 个结点）

设 $L \to a_1 \to a_2 \to a_3 \to \text{NULL}$，$p = a_3$，要删的前驱是 $a_2$。

| 步骤 | `pre` | `pre->next->next` | 动作 |
|---|---|---|---|
| 初判 | — | — | $L\to next=a_1\neq p$，不属"p 为首元"情形，继续 |
| 1 | $L$ | $a_2\to next=a_3=p$ ✓ | 命中，退出循环 |
| 2 | $L$ | — | $q=a_2$；$L\to next=a_2\to next=a_3$；释放 $a_2$ |

结果 $L \to a_1 \to a_3 \to \text{NULL}$，长度 $n$ 变 $n-1$ ✓（$a_1$ 的 `next` 由 $a_2$ 改为 $a_3$，链不断）。

再走查 $p=a_2$（要删 $a_1$）：初判 $L\to next=a_1\neq a_2$；循环中 `pre=L` 时 `pre->next->next = a_2 = p` ✓ → $q=a_1$，$L\to next=a_1\to next=a_2$，释放 $a_1$，得 $L\to a_2\to a_3$ ✓。

边界走查 $p=a_1$：$L\to next==p$ 命中初判，返回 ERROR——首元结点无前驱，符合定义。

### 6.5 复杂度分析（按语句频度）

设 $n$ 为链表长度，$p$ 是第 $i$ 个结点（$1\le i\le n$）。

- 查找：`pre` 从头结点走到第 $i-2$ 个结点，比较 `pre->next->next == p` 执行 $i-1$ 次（含最后一次成功比较），故 $i=n$ 时最坏 $n-1$ 次；$i$ 等概率时
$$\frac{1}{n}\sum_{i=2}^{n}(i-1)=\frac{n-1}{2}\ \Longrightarrow\ T(n)=O(n)$$
- 摘链 + 释放：`pre->next = q->next; free(q);` 共 $O(1)$；
- 空间：仅 `pre`、`q` 两个指针变量，$S(n)=O(1)$（原地操作，不另开辟结点）。

### 6.6 补充讨论：两点常见延伸

1. **不带头结点**时写法相同，只是 `pre` 从首元结点出发，且要特判"要删的是首元结点"（即 $L$ 本身是 $p$ 的前驱）——此时须改头指针 $L=L\to next$。用**头结点**可以把这种情况统一进一般处理，这是教材采用头结点的原因之一。
2. **"值前移"技巧**（对照，非本题主答案）：若只要求"逻辑上少掉前驱结点的数据"且不关心哪个物理结点被释放，可令 $q\to data=p\to data$、$q\to next=p\to next$、释放 $p$，$O(1)$ 完成；但本题给定结点 $*p$，这样做会使调用者手中的 $p$ 变成悬空指针，故**不可取**，标准实现仍是 $O(n)$ 遍历。
3. 若链表是**双向链表**，则 `q = p->prior; q->prior->next = q->next; q->next->prior = q->prior; free(q);` 为 $O(1)$——两相对照说明"存储结构决定运算效率"。

## 8. 考场标准答案

**(1) 实现思想**：单链表的结点只含后继指针，由 $p$ 无法回溯，而删除结点又必须修改"待删结点的前驱"的指针，所以要从头结点开始顺序查找：设 `pre` 指向头结点，沿 `next` 后移，直到 `pre->next->next == p`，此时 `pre->next` 就是 $*p$ 的前驱 $q$；执行 `pre->next = q->next;`（即指向 $p$）后 `free(q);`。若 $p$ 为首元结点（$L->next == p$）则前驱不存在，需先判断并返回失败；遍历结束仍未匹配说明 $p$ 不在该链表中。

```c
for (pre = L; pre->next && pre->next->next; pre = pre->next)
    if (pre->next->next == p) { q = pre->next; pre->next = q->next; free(q); return OK; }
return ERROR;
```

**(2) 时间复杂度**：$O(n)$（最坏比较 $n-1$ 次，平均 $\frac{n-1}{2}$ 次，$n$ 为链表长度）；空间复杂度 $O(1)$。

## 9. 易错点

1. **误答 $O(1)$**：以为"已知结点地址就能删除"——删除需要的是**待删结点的前驱**，而本题待删结点是 $p$ 的前驱，需要"前驱的前驱"，单链表只能从头找；
2. 判据写成 `pre->next == p`：这样找到的是 $p$ 的前驱 $q$ 本身，摘链时会把 $p$ 删掉（删错对象）；正确判据是 `pre->next->next == p`；
3. **先 `free(q)` 后改链**：`pre->next = q->next` 中 $q\to next$ 已被释放，属悬空访问；顺序必须是"先保存 → 改链 → 释放"；
4. 漏判 $p$ 为首元结点（无前驱）与 $p$ 不在表中的情形，导致空指针解引用或死循环；
5. 循环条件漏掉 `pre->next->next != NULL` 的保护，走到表尾时越界访问；
6. 混淆"有头结点/无头结点"两种写法：无头结点时删除首元结点必须修改头指针 $L$，需单独处理。

## 10. 一句话规律

链表上"删除某结点的相邻结点"这类题，先问一句"改哪根指针、这根指针在哪个结点里"——单链表只能从头向后走，于是复杂度由**要走多少步**决定（$O(n)$）；而双向链表因自带 `prior` 可 $O(1)$，这正是"存储结构决定运算实现与效率"的标准例证。
