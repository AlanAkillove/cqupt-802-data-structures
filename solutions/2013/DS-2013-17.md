# DS-2013-17

## 1. 原题

对长度为 $n$ 的线性表进行等概率顺序查找，算法在查找成功情况下的平均比较次数是（）。

> 订正说明转录：源文作"顺序查找算法在查找成功情况下的平均比较次数是（）"，未交代查找表长度与等概率假设，选项含 $n$ 与 $\frac{n+1}{2}$ 无法区分，据题意补"对长度为 $n$ 的线性表进行等概率顺序查找"。

A. $n$

B. $n^2$

C. $\log_2 (n)$

D. $\frac{n+1}{2}$

## 2. 答案

**D**（$\dfrac{n+1}{2}$）。

## 3. 题目分析

- 已知（含订正补齐的两个前提）：查找表为**长度为 $n$ 的线性表**；采用**顺序查找**（自一端起逐个与给定值作关键字比较）；每个元素被查找的概率**相等**，即 $P_i=\frac1n\ (i=1,\dots,n)$；条件是**查找成功**（目标元素一定在表中）；
- 目标：查找成功时的平均比较次数，即查找成功的平均查找长度 $ASL_{succ}$；
- 关键约束：
  1. "平均"是对**查找概率**加权，不是对表长求和；缺"$P_i=\frac1n$"这一前提时 $ASL$ 可以是 $1\sim n$ 之间的任何值（把全部概率压在第 $1$ 个元素上，$ASL$ 就是 $1$），这正是订正说明补条件的理由；
  2. 比较次数按**关键字比较**计：目标在第 $i$ 个位置（从查找起点数）就要比较 $i$ 次；"找到一个元素"这一动作本身不再单独计数；
  3. 顺序查找不要求有序；表是否有序只影响**查找失败**时的平均长度（有序表可提前一个位置判失败），不影响成功情形的 $\frac{n+1}{2}$；
- 命题意图：考 $ASL$ 定义的直接代入与等概率求和 $\sum_{i=1}^{n}i=\frac{n(n+1)}{2}$；四个选项则分别取自"最坏情形""复杂度量级""折半查找"这三处相邻结论，用来检测学生能否把"平均次数"与"最坏次数""时间复杂度"三者分开。

## 4. 核心考点

核心考点：
DS05.02 顺序查找法（无序表顺序查找的成功平均查找长度 $\frac{n+1}{2}$；带哨位顺序查找同样只按关键字比较计数）

辅助考点：
DS05.01 查找的基本概念（平均查找长度 $ASL=\sum_{i=1}^{n}P_iC_i$ 的定义、"成功/失败"两种口径的区别）

解释：本题是 $ASL$ 定义在顺序查找上的第一次代入，属 DS05.02 的最基础结论；之所以必须带 DS05.01，是因为"平均比较次数""最坏比较次数""时间复杂度"三个概念的区分正是在那里建立的，A、B、C 三个干扰项都源于这一区分失败。

## 5. 解题思路

1. 先写定义：$ASL=\sum_{i=1}^{n}P_iC_i$，其中 $C_i$ 是"找到第 $i$ 个元素所需的关键字比较次数"；
2. 定 $C_i$：从表头开始逐个比较，目标恰在第 $i$ 个位置时前面 $i-1$ 次比较都失败、第 $i$ 次成功 ⟹ $C_i=i$（等价地，若从表尾起算，第 $i$ 个结点的比较次数为 $n-i+1$，两种写法求和结果相同）；
3. 定 $P_i$：等概率 ⟹ $P_i=\frac1n$（先自检 $\sum P_i=n\cdot\frac1n=1$，确认这是合法的概率分布）；
4. 代入求和：$ASL_{succ}=\frac1n\sum_{i=1}^{n}i=\frac1n\cdot\frac{n(n+1)}{2}=\frac{n+1}{2}$；
5. **用小表枚举核对**：$n=1,2,3$ 时手工列出各位置比较次数取平均，分别为 $1,1.5,2$，与 $\frac{n+1}{2}$ 逐项吻合，而 A（$n$）给出 $1,2,3$、C（$\log_2 n$）给出 $0,1,1.58$，均不符；
6. 辨析干扰项：A 是**最坏**比较次数（也是顺序查找的时间复杂度），C 是**折半查找**的成功 $ASL$ 量级（$\approx\log_2 n$，本卷第 31 题即考折半的比较次数），B 是把"逐个比较 $n$ 个元素"误解成 $n^2$ 的量级。

## 6. 详细解答

**第一步：定义与计数约定**

平均查找长度（教材 9.1）：

$$ASL=\sum_{i=1}^{n}P_iC_i$$

$P_i$ 为查找第 $i$ 个元素的概率，$C_i$ 为找到第 $i$ 个元素所需进行的**关键字比较次数**。

无序表顺序查找（教材 9.2，从表头起）：

```c
/* R[1..n] 为查找表，key 为给定值；返回找到元素的下标，找不到返回 0 */
int Search_Sq(SqTable R, int n, KeyType key)
{
    int i = 1;
    while (i <= n && R.r[i].key != key) ++i;   /* 每个位置比较一次关键字 */
    return (i <= n) ? i : 0;
}
```

目标在 $R.r[i]$ 时，循环条件中关键字比较恰好执行 $i$ 次 ⟹ $C_i=i$。

**第二步：代入等概率**

$$ASL_{succ}=\sum_{i=1}^{n}\frac{1}{n}\cdot i=\frac{1}{n}\cdot\frac{n(n+1)}{2}=\boxed{\dfrac{n+1}{2}}$$

等价的"从后往前"推导：把 $C_i$ 记为"从表头数第 $i$ 个元素"的比较次数，若改用"第 $i$ 个元素距表尾的位置"来编号，则 $C_i=n-i+1$，

$$ASL_{succ}=\frac1n\sum_{i=1}^{n}(n-i+1)=\frac1n\big(n+(n-1)+\cdots+1\big)=\frac{n+1}{2}$$

两法一致，说明结果与"从哪一端开始查找"无关（这正是顺序查找对称性的体现）。

**第三步：小表枚举核对**

| $n$ | 各位置比较次数 | 平均 | $\frac{n+1}{2}$ | A：$n$ | C：$\log_2 n$ |
|---|---|---|---|---|---|
| $1$ | $1$ | $1$ | $1$ ✓ | $1$ △ | $0$ ✗ |
| $2$ | $1,2$ | $1.5$ | $1.5$ ✓ | $2$ ✗ | $1$ ✗ |
| $3$ | $1,2,3$ | $2$ | $2$ ✓ | $3$ ✗ | $1.58$ ✗ |
| $4$ | $1,2,3,4$ | $2.5$ | $2.5$ ✓ | $4$ ✗ | $2$ ✗ |

（$\triangle$ $n=1$ 时 A 与正确答案偶然相等，故不能只代一个 $n$；$n\ge2$ 起 A 恒偏大。）

**第四步：量级与"平均/最坏"的关系**

$$ASL_{succ}=\frac{n+1}{2}=\Theta(n),\qquad \text{最坏情形}=n,\qquad \text{最好情形}=1$$

三者都是 $O(n)$ 级，但**数值不同**：题目问"平均比较次数"，必须给精确表达式 $\frac{n+1}{2}$，不能答 $n$（选项 A 是最坏值，同时被"平均"二字排除）。

**第五步：口径核对（为什么不是别的数）**

- **成功 vs 失败**：本题问成功。若问在 $n$ 个元素的**无序**表上**查找失败**，则每个关键字都要比一次，最后还要与哨位（下标越界判定）再验一次，$ASL_{unsucc}=n+1$；在**有序**表上失败则可提前判定——扫到第一个大于给定值的关键字即止，平均只走半张表（$\Theta(n)$ 量级，具体数值随“表尾判定是否计一次比较”约在 $\frac{n}{2}\sim\frac{n+2}{2}$ 之间），可见“成功/失败”与“有序/无序”两重口径都会改变答数；
- **是否设哨位**：带哨位的顺序查找（把 `R.r[0]=key` 作哨兵，省去每步的 `i<=n` 判断）改变的是**循环条件的比较次数**，关键字比较次数 $C_i$ 不变 ⟹ $ASL_{succ}$ 仍是 $\frac{n+1}{2}$；
- **表是否有序**：无序、有序两种表在**成功**情形下的 $ASL$ 相同（有序表只是能提前判失败，命中元素仍要逐个比较到它的位置）；
- **等概率前提**：若概率不等（如 2021 年第 22 题给 $P_1=\frac12,P_2=\frac13,P_3=\frac16$），$ASL$ 就随给定值排列而变，可能是 $\frac{n+1}{2}$ 之外的任何值——可见订正说明补的"$n$"与"等概率"两个条件正是本题可解的必要前提。

**答案**：D。

## 7. 选项分析

- A. $n$：错。$n$ 是**最坏**比较次数（目标在最后一个位置或根本不在表中），也是顺序查找的时间复杂度量级；$ASL$ 是期望值，等概率时恰为最坏值的一半（$\frac{n+1}{2}\approx\frac n2$）。本题最强干扰项，混淆"平均"与"最坏/复杂度"；
- B. $n^2$：错。顺序查找只做一趟线性扫描，不存在 $n\times n$ 次比较；$n^2$ 属"对 $n$ 个元素各查一遍"（如建表/去重的双重循环）这类量级，与单次查找无关；
- C. $\log_2 (n)$：错。这是**折半查找**（有序表 + 顺序存储）的成功 $ASL$ 量级（精确值为判定树各层路径长度之和除以 $n$，见本卷第 31 题、2005 年第 28 题）；顺序查找无法"对半分"，故不可能取得对数级；
- D. $\frac{n+1}{2}$：正确。$\frac1n\sum_{i=1}^{n}i$ 的闭合形式。

## 8. 考场标准答案

选 **D**。

顺序查找时，若被查元素在第 $i$ 个位置，则需比较 $i$ 次关键字，故 $C_i=i$；等概率时 $P_i=\frac1n$，于是

$$ASL_{succ}=\sum_{i=1}^{n}P_iC_i=\frac1n\sum_{i=1}^{n}i=\frac1n\cdot\frac{n(n+1)}{2}=\frac{n+1}{2}$$

（$n$ 为最坏比较次数，$\log_2 n$ 是折半查找的量级，均非"平均比较次数"。）

## 9. 易错点

1. **把"平均"当成"最坏"**：选 A。记住一对数字：成功平均 $\frac{n+1}{2}$、最坏 $n$、最好 $1$；
2. **与折半查找混用**：选 C。$\log_2 n$ 要求表**有序且顺序存储**，且它是"比较层次数"的量级，其精确 $ASL$ 由判定树算出，一般不是整数表达式 $\log_2 n$；
3. **忘记"等概率"前提**：本题的订正说明正是为此而补。若题目改为"查找概率分别为…,"，必须先读概率再加权，不能直接背 $\frac{n+1}{2}$；
4. **失败与成功口径搞混**：无序表查找**失败**的 $ASL$ 是 $n+1$（要比完表中 $n$ 个关键字再确认到表尾），不是 $\frac{n+1}{2}$；有序表失败则平均只走半张表。答题前先看题干有没有"查找成功"四字；
5. **把哨位比较计入**：设置哨兵（`R.r[0]=key`）只为省掉下标越界判断，关键字比较次数不变，别把 $C_i$ 多算 $1$。

## 10. 一句话规律

等概率顺序查找成功 $ASL=\frac{n+1}{2}$ 的来源只有两行——$C_i=i$、$P_i=\frac1n$，再套 $\sum i=\frac{n(n+1)}{2}$；凡问"平均"就用等概率加权，凡见"最坏/至多"才用 $n$，$\log_2 n$ 只属于折半（有序 + 顺序存储）与树高类问题。
