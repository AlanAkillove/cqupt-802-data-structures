# DS-2013-19

## 1. 原题

时间复杂度不受待排序序列初始状态的影响，总是 $O(n^2)$ 的是（）。

A. 直接插入排序

B. 快速排序

C. 简单选择排序

D. 归并排序

## 2. 答案

**C**（简单选择排序）。

## 3. 题目分析

- 已知：四个内部排序方法；衡量的是**时间复杂度对初始序列状态的依赖性**；
- 目标：找出**同时**满足两个条件的方法——① 最好/最坏/平均三档同为 $n^2$ 量级（即不受初态影响）；② 量级必须是 $n^2$ 而不是更低；
- 关键约束：
  1. 这是一道"双条件交集"题。只满足①的是归并排序（恒 $\Theta(n\log_2 n)$）与堆排序（恒 $\Theta(n\log_2 n)$，本题未列）；只满足②的是直接插入排序与冒泡排序的最坏情形（$\Theta(n^2)$，但最好情形分别降到 $\Theta(n)$）；两者交集只有简单选择排序；
  2. "不受初态影响"要看的是**基本操作（关键字比较）次数的表达式里是否含有刻画初态的量**（如逆序对数 $I$、枢轴划分位置）；
  3. 严格地说 $O(n\log_2 n)\subset O(n^2)$，"总是 $O(n^2)$"按大 $O$ 定义对归并排序也成立；教材与考研语境中该句式一律指"量级恰为 $n^2$"（$\Theta(n^2)$），本解析按此通行口径处理（见第 12 节）；
- 命题意图：让学生在"依赖性 × 量级"这张二维表上定位算法。D 是"只读前半句"的钩子，A 是"只记得 $n^2$ 档"的钩子；本卷 DS-2013-20（比较排序的时间下界）与本题构成上下位关系：先知道各法量级，才知道下界 $O(n\log_2 n)$ 意味着什么。

## 4. 核心考点

核心考点：
DS06.11 排序算法应用（各内部排序方法的最好/最坏/平均时间复杂度、空间复杂度、稳定性与"是否依赖初态"的横向对照表）

辅助考点：
DS06.04 简单选择排序（第 $i$ 趟必须在无序区 $R[i+1..n]$ 中逐元素比较取最小者，比较次数 $n-i$ 固定，这是"不受初态影响"的机制来源）
DS06.01 排序的基本概念（"趟"的概念与基本操作计数口径）

解释：答案的落点是"为什么选择排序的比较次数恒定"，这属于 DS06.04 的算法机制；而把四个方法放在一张表里比较依赖性，是 DS06.11 的考查方式，故主标签取 DS06.11。

## 5. 解题思路

1. 对每个方法写出**比较次数的表达式**，检查表达式里有没有"随初态变化的量"：
   - 简单选择排序：第 $i$ 趟比较 $n-i$ 次（内层循环无条件走完），总数 $\sum_{i=1}^{n-1}(n-i)=\frac{n(n-1)}{2}$ —— **恒定**；
   - 直接插入排序：第 $i$ 趟比较次数等于"前面已排部分中比 $R[i]$ 大的元素个数 $+1$"，总数 $=n-1+I$（$I$ 为原序列的逆序对数），$I$ 从 $0$（有序）到 $\frac{n(n-1)}{2}$（逆序）—— **随初态变**；
   - 快速排序：总比较次数 $=\sum(\text{各趟划分比较的元素数})$，取决于每层枢轴把区间切成什么尺寸：均衡切分 $\Theta(n\log_2 n)$，每次切出空区间 $\frac{n(n-1)}{2}$ —— **随初态变**；
   - 归并排序：趟数 $\lceil\log_2 n\rceil$ 固定、每趟合并总比较次数不超过 $n$ —— 恒定，但量级是 $n\log_2 n$；
2. 用条件②筛掉归并排序，得 C；
3. **数值验证**：取 $n=4$，对"已序"与"逆序"两种初态分别手工计比较次数，看哪个方法的两个数字相同且为 $\frac{4\times3}{2}=6$；
4. 排除性补充：本题若把选项 D 换成"堆排序"，同样因量级不符而排除；若把题干"总是 $O(n^2)$"改成"总是 $O(n\log_2 n)$"，答案就变成归并排序（见 2007 年第 16 题、2017 年第 11 题的问法）。

## 6. 详细解答

**第一步：简单选择排序为什么"不受初态影响"**

```c
/* R[1..n]，第 i 趟在 R[i..n] 中选关键字最小者，与 R[i] 交换（教材 10.3） */
for (i = 1; i < n; ++i) {
    k = i;
    for (j = i + 1; j <= n; ++j)          /* 本层恒执行 n-i 次关键字比较 */
        if (R[j].key < R[k].key) k = j;   /* 只记录位置，不提前退出 */
    if (k != i) { R[0] = R[i]; R[i] = R[k]; R[k] = R[0]; }   /* 一次交换 = 3 次移动 */
}
```

内层循环**没有"找到就 break"的提前终止**——它的任务是选出无序区的最小者，必须把无序区全部看完。于是第 $i$ 趟的比较次数恰为 $n-i$，与序列当前是否有序毫无关系：

$$C(n)=\sum_{i=1}^{n-1}(n-i)=(n-1)+(n-2)+\cdots+1=\frac{n(n-1)}{2}=\Theta(n^2)$$

移动的依赖性则另当别论：最好（已序）$0$ 次、最坏 $3(n-1)$ 次，但移动是 $O(n)$ 项，被 $\Theta(n^2)$ 的比较主导，不改变总量级。

**第二步：其余三法的"依赖性"核对**

| 方法 | 最好情形比较次数 | 最坏情形 | 平均 | 是否依赖初态 | 结论 |
|---|---|---|---|---|---|
| A 直接插入排序 | $n-1$（已序，每趟只比 1 次） | $\frac{n(n-1)}{2}+n$（逆序） | $\Theta(n^2)$ | **是** | 排除 |
| B 快速排序 | $\Theta(n\log_2 n)$（每层均衡划分） | $\frac{n(n-1)}{2}$（端点枢轴 + 序列已序/逆序） | $\Theta(n\log_2 n)$ | **是** | 排除 |
| C 简单选择排序 | $\frac{n(n-1)}{2}$ | $\frac{n(n-1)}{2}$ | $\Theta(n^2)$ | **否** | ✓ 且为 $n^2$ 档 |
| D 二路归并排序 | $\le n\lceil\log_2 n\rceil$ | $\le n\lceil\log_2 n\rceil$ | $\Theta(n\log_2 n)$ | 否 | 量级非 $n^2$，排除 |

要点：A 的比较次数写成 $n-1+I$（$I$ 为逆序对数）最清楚，$I$ 本身就是"初态"的量化；B 的依赖性来自"枢轴落点由数据分布决定"，而"已序序列 + 取第一个元素为枢轴 ⟹ 每次划分只削掉一个元素"是最经典的退化场景（本卷第 44 题即要求手写出以首元素为枢轴的快排第一趟划分）。

**第三步：$n=4$ 的实例验证**

| 初态 | 直接插入 | 快排（取首元素为枢轴） | 简单选择 | 归并（自底向上，长度 1→2→4） |
|---|---|---|---|---|
| $(1,2,3,4)$ 已序 | $3$ | $3+2+1=6$ | $3+2+1=6$ | $2+2=4$（一趟内各合并 2 次比较） |
| $(3,1,4,2)$ 一般 | $1+2+2=5$ | $3+1+1=5$ | $6$ | $4$ |
| $(4,3,2,1)$ 逆序 | $2+3+4=9$ | $3+2+1=6$ | $6$ | $4$ |

只有"简单选择"一列在三种初态下恒为 $6=\frac{4\times3}{2}$（插入排序 $3\sim9$、快排 $5\sim6$ 均随初态波动）；归并虽然也稳定（本例恒 $4$），但其数值是 $4\approx n\log_2 n=8$ 级别的"趟数 $\times$ 每趟"结构（$n=4$ 时自底向上合并比较次数恰为 $4$，远小于 $6$），量级为 $n\log_2 n$ 而非 $n^2$，不满足条件②。

**第四步：结论**

同时满足"与初始状态无关"和"$n^2$ 量级"的是简单选择排序。

**答案**：C。

## 7. 选项分析

- A. 直接插入排序：错。比较次数 $n-1+I$ 依赖逆序对数 $I$：已序时 $\Theta(n)$、逆序时 $\Theta(n^2)$，既受初态影响又不"总是 $n^2$"；
- B. 快速排序：错。时间取决于划分是否均衡，而划分位置由枢轴与数据分布共同决定：已序（或近乎有序）序列配端点枢轴时退化为 $\frac{n(n-1)}{2}$，随机分布时 $\Theta(n\log_2 n)$；此外它的**空间**（递归栈深度）也随初态在 $\Theta(\log_2 n)\sim\Theta(n)$ 之间波动；
- C. 简单选择排序：正确。每趟比较次数固定为 $n-i$，总数 $\frac{n(n-1)}{2}$，与初态无关且恒为 $n^2$ 量级；
- D. 归并排序：错，但**最强干扰项**。它确实"不受初态影响"，却恒为 $\Theta(n\log_2 n)$，落在题干后半句"$O(n^2)$"之外；它是本题"只读半句题干"的典型失分点（把这一问法反过来考，即 2007 年第 16 题"基本不受初态影响、为 $O(n\log_2 n)$ 且排序效果稳定" ⟹ 归并排序）。

## 8. 考场标准答案

选 **C**。

简单选择排序第 $i$ 趟须在无序区 $R[i+1..n]$ 中逐个比较选出最小者，比较次数恒为 $n-i$（与序列是否有序无关），故

$$C(n)=\sum_{i=1}^{n-1}(n-i)=\frac{n(n-1)}{2}=\Theta(n^2)$$

直接插入排序（$n-1+I$，$n\sim n^2$）与快速排序（$n\log_2 n\sim n^2$）的复杂度均随初始状态变化；归并排序虽不受初始状态影响，但恒为 $\Theta(n\log_2 n)$。故"不受初态影响且总是 $O(n^2)$"的只有简单选择排序。

## 9. 易错点

1. **只读"不受初始状态影响"就选 D**：题干有两个限定，量级必须是 $n^2$；归并与堆都不受影响但都是 $n\log_2 n$ 档；
2. **把"移动次数受影响"误当成"时间复杂度受影响"**：简单选择排序的移动次数确实随初态在 $0\sim3(n-1)$ 之间变化，但它是 $O(n)$ 项，被 $\Theta(n^2)$ 的比较次数吃掉，结论不变；
3. **记成"选择排序最好是 $O(n)$"**：$O(n)$ 那条属于**插入排序**在已序时的表现；两者都"一趟一趟做"，容易互换；
4. **忘记快排最坏情形就是"有序"**：本题 B 与 2012 年第 19 题（局部有序时选哪个方法 ⟹ 直接插入排序）共用这条事实，两处别记反；
5. **与堆排序混为一谈**：堆排序也属"选择类"，但其比较次数与初态基本无关且为 $O(n\log_2 n)$，本题没有该选项，若出现应按量级排除，不能因"是选择排序"就选它。

## 10. 一句话规律

内部排序里"比较次数与初始状态无关"的只有简单选择排序（$\Theta(n^2)$）、堆排序与归并排序（$\Theta(n\log_2 n)$）三种；再叠加题干的量级要求，$n^2$ 档 ⟹ 简单选择排序，$n\log_2 n$ 档 ⟹ 归并（稳定）或堆（不稳定）。
