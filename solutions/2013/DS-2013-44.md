# DS-2013-44

## 1. 原题

对关键字序列（ $51,32,66,92,75,16,25,46$ ）按从小到大进行快速排序。设选第 $1$ 个元素为支点/参考值（ $pivot$ ），写成排序过程中第 $1$ 趟的划分结果。

## 2. 答案

按教材 $Partition$ 算法（取 `L.r[low]` 为支点、"挖洞—填坑"式移动）执行第 $1$ 趟划分，结果为

$$(\ 46,\ 32,\ 25,\ 16,\ \mathbf{51},\ 75,\ 92,\ 66\ )$$

支点 $51$ 被放到最终位置（第 $5$ 个），其左侧 $46,32,25,16$ 全部小于 $51$，右侧 $75,92,66$ 全部大于 $51$；此后只需分别对左右两段递归排序。

## 3. 题目分析

- 已知：长度为 $8$ 的关键字序列 $(51,32,66,92,75,16,25,46)$，升序排序，支点（参考值）取第 $1$ 个元素 $51$；
- 目标：写出**第 $1$ 趟（一次划分 `Partition`）结束后的序列**——不是写出整个排序过程，也不是只写支点位置；
- 关键约束：快速排序的"一趟"= 一次划分，其不变量是"支点归位、左段全 $\le$ 支点、右段全 $\ge$ 支点"，但**段内相对次序会被打乱**，因此结果不唯一取决于所采用的划分实现（挖洞式 / 交换式），必须按教材算法执行并写明所用方法；
- 命题意图：考 `Partition` 的**手工执行**能力（双指针 $i,j$ 交替扫描、赋值移动的方向与顺序），以及"一趟划分后支点已在最终位置"这一核心结论——它也是 DS-2013-18、DS-2012-18 这类"判断哪个序列可能是快排第一趟结果"选择题的判据。

## 4. 核心考点

核心考点：
DS06.06 快速排序（一趟划分的定义与执行：选支点、从两端交替扫描、把逆序元素交换/移动过去、最后支点归位并返回其位置）

解释：本题主考点是把 $Partition$ 的过程一步步走完（TRACE），并要求结果能写成序列（CONSTRUCTION）；而"检查结果是否合法"用的是 DS06.11 的判定视角（支点归位 + 两侧分块）。

## 5. 解题思路

1. 先复述教材 $Partition$ 的做法：把 `L.r[low]`（即 $51$）存进 `L.r[0]` 作**哨兵/参考值**，此时位置 $1$ 出现"空洞"；
2. **先从右往左**找比支点小的元素，找到后把它填进左边的空洞（该元素原位置变成新空洞）；
3. 再**从左往右**找比支点大的元素，填进右边的空洞；如此交替，直到 $i$ 与 $j$ 相遇，把支点填入最后的空洞；
4. 每步都在纸上记一行"当前数组状态 + $i,j$ 的位置"，形成第 6.2 节的表——这样不会漏步也不会把赋值方向写反；
5. 结束后做**三重自检**：① 支点是否落在第 $5$ 位；② 左边 $4$ 个数是否都 $<51$；③ 右边 $3$ 个数是否都 $>51$；再核对元素多重集与原来相同（没有丢数、没有重复）；
6. 明确写出"本趟所用划分是教材的挖洞式"，因为交换式划分在同一输入下会得到不同的段内排列（见第 6.4 节并列方案）。

## 6. 详细解答

### 6.1 教材算法（严蔚敏 算法 9.4 / 8.12 `Partition`）

```c
int Partition(SqList *L, int low, int high)
{
    L->r[0] = L->r[low];                       /* 把支点存入 0 号单元作参考值 */
    pivotkey = L->r[low].key;
    while (low < high) {
        while (low < high && L->r[high].key >= pivotkey) --high;
        L->r[low] = L->r[high];                /* 比支点小的填到左边空洞 */
        while (low < high && L->r[low].key <= pivotkey) ++low;
        L->r[high] = L->r[low];                /* 比支点大的填到右边空洞 */
    }
    L->r[low] = L->r[0];                       /* 支点归位 */
    return low;                                /* 返回支点最终位置 */
}
```

要点：扫描方向是**先右后左**；比较用 $\ge$ 与 $\le$（等于支点的元素不移动，避免重复搬动）；每完成一次赋值，"空洞"就转移到被搬走元素的位置。

### 6.2 第 1 趟逐步执行（下标 $1\sim8$，支点 $pivot=51$）

| 步 | 动作 | 数组状态（下标 1…8） | 空洞位置 | $low$ | $high$ |
|---|---|---|---|---|---|
| 0 | `r[0]=r[1]=51`，位置 1 成空洞 | $(\_,32,66,92,75,16,25,46)$ | $1$ | $1$ | $8$ |
| 1 | 右扫：$r[8]=46<51$ 停 → $r[1]\leftarrow46$ | $(46,32,66,92,75,16,25,\_)$ | $8$ | $1$ | $8$ |
| 2 | 左扫：$46\le51$ 越过、$32\le51$ 越过、$r[3]=66>51$ 停 → $r[8]\leftarrow66$ | $(46,32,\_,92,75,16,25,66)$ | $3$ | $3$ | $8$ |
| 3 | 右扫：$r[7]=25<51$ 停 → $r[3]\leftarrow25$ | $(46,32,25,92,75,16,\_,66)$ | $7$ | $3$ | $7$ |
| 4 | 左扫：$r[4]=92>51$ 停 → $r[7]\leftarrow92$ | $(46,32,25,\_,75,16,92,66)$ | $4$ | $4$ | $7$ |
| 5 | 右扫：$r[6]=16<51$ 停 → $r[4]\leftarrow16$ | $(46,32,25,16,75,\_,92,66)$ | $6$ | $4$ | $6$ |
| 6 | 左扫：$r[5]=75>51$ 停 → $r[6]\leftarrow75$ | $(46,32,25,16,\_,75,92,66)$ | $5$ | $5$ | $6$ |
| 7 | 右扫：$high$ 减到 $5$，$low==high$ 退出循环 | — | $5$ | $5$ | $5$ |
| 8 | $r[5]\leftarrow r[0]=51$ 支点归位 | $(46,32,25,16,\mathbf{51},75,92,66)$ | — | | |

返回支点位置 $5$，即第 $1$ 趟划分结束：

$$(\ 46,\ 32,\ 25,\ 16,\ 51,\ 75,\ 92,\ 66\ )$$

### 6.3 结果校验

1. **支点归位**：$51$ 在第 $5$ 位，且 $Partition$ 返回值 $5$ 与之吻合 ✓；
2. **两侧分块**：左段 $\{46,32,25,16\}$ 均 $<51$ ✓；右段 $\{75,92,66\}$ 均 $>51$ ✓；
3. **元素守恒**：趟前多重集 $\{16,25,32,46,51,66,75,92\}$，趟后完全相同（无丢失、无重复）✓；
4. **步数合理性**：$8$ 个元素的一趟划分中，赋值移动 $6$ 次（每次移动都填一个空洞），比较次数与扫描过的元素数一致，符合"一趟 $O(n)$"的量级；
5. **下一步提示**（题目未问）：递归处理 $(46,32,25,16)$ 与 $(75,92,66)$，各自再取本段第一个元素为支点。

### 6.4 并列方案：交换式划分（左右指针相遇后交换支点）

若采用"两个指针分别扫描、发现逆序对就**交换**、最后把支点与 $j$ 所指元素交换"的写法（同一输入、同一支点），执行过程为：

| 步 | $i,j$ | 交换 | 数组状态 |
|---|---|---|---|
| 0 | $i=2,j=8$ | — | $(51,32,66,92,75,16,25,46)$ |
| 1 | $i=3(66),j=8(46)$ | $66\leftrightarrow46$ | $(51,32,46,92,75,16,25,66)$ |
| 2 | $i=4(92),j=7(25)$ | $92\leftrightarrow25$ | $(51,32,46,25,75,16,92,66)$ |
| 3 | $i=5(75),j=6(16)$ | $75\leftrightarrow16$ | $(51,32,46,25,16,75,92,66)$ |
| 4 | $i=6>j=5$ 停止 | $51\leftrightarrow r[5]=16$ | $(16,32,46,25,\mathbf{51},75,92,66)$ |

得 $(16,32,46,25,51,75,92,66)$。它与主答案**满足同一不变量**（$51$ 在第 $5$ 位、左小右大），只是段内排列不同。两式差异来自"赋值搬洞"与"成对交换"对元素移动路径的不同，教材《数据结构（C 语言版）》的 `Partition` 是前者，故本题主答案取 $(46,32,25,16,51,75,92,66)$，此处并列另一写法以便对照，不作静默取舍。

## 8. 考场标准答案

取 $pivot=51$（存入 $0$ 号单元，位置 $1$ 留空洞），从右向左找 $<51$ 者、从左向右找 $>51$ 者交替填洞：

```
(51,32,66,92,75,16,25,46)   pivot=51，空洞@1
(46,32,66,92,75,16,25, _)   ←46 填@1
(46,32, _,92,75,16,25,66)   66 →@8
(46,32,25,92,75,16, _,66)   ←25 填@3
(46,32,25, _,75,16,92,66)   92 →@7
(46,32,25,16,75, _,92,66)   ←16 填@4
(46,32,25,16, _,75,92,66)   75 →@6
(46,32,25,16,51,75,92,66)   i==j==5，pivot 归位@5
```

**第 1 趟划分结果：$(46,32,25,16,51,75,92,66)$**，支点位置为 $5$；左段 $4$ 个关键字均小于 $51$，右段 $3$ 个均大于 $51$。

## 9. 易错点

1. **扫描方向弄反**（先左后右）：会漏掉第一次填洞，得到 $(51,\dots)$ 这种支点未动的错误结果；教材是"先从右往左找小"；
2. 把"一趟划分"答成"一趟冒泡/一趟选择"的结果（如 $(32,51,66,75,16,25,46,92)$）：快排一趟的特征是**支点归位**且两侧分块，最大值不一定到位；
3. 比较条件写成 $>$ 与 $<$（漏掉等号）：遇到与支点相等的关键字时会反复搬动甚至死循环（本题无重复关键字，但写法上仍应按 $\ge/\le$）；
4. 忘记最后"支点归位"这一步，把空洞留在数组中（答案出现空格或元素少一个）；
5. 越界扫描：$low<high$ 的保护条件写在两个内层 `while` 中，漏写会让 $i,j$ 冲出对方位置而误判；
6. 只写支点位置不写整个序列（或只写"左段右段"）：题面要求"写成第 $1$ 趟的划分结果"，必须给出 $8$ 个位置的完整排列；
7. 采用交换式划分却不说明，导致答案与标准答案段内排列不同——应写明所用划分方式（两式都满足"支点归位、左小右大"）。

## 10. 一句话规律

快排"第 $1$ 趟结果"题的通用解法是把 $Partition$ 的**空洞**画出来：支点先抽走 → 右边找小的填左洞 → 左边找大的填右洞 → 交替直到两指针相遇 → 支点落进最后的洞；交卷前只需检查三件事：支点归位、左段全小、右段全大（且元素一个不少）。
