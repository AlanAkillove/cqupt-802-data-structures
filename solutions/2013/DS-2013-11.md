# DS-2013-11

## 1. 原题

高度为 $3$ 的二叉平衡树（空树高度为 $0$ ）最少有（）个结点。

A. $4$

B. $15$

C. $11$

D. $7$

## 2. 答案

**A**（$4$ 个结点）。

## 3. 题目分析

- 已知：二叉平衡树（AVL 树）——每个结点的左右子树**高度差的绝对值不超过 $1$**；高度约定为**空树高度 $0$**，故"高度 $3$"表示根到最深叶子经过 $3$ 层结点；
- 目标：满足"高度恰为 $3$"的 AVL 树的**最少**结点数 $N(3)$；
- 关键约束：要最省结点，根的两棵子树必须"一矮一高"，但平衡条件禁止相差超过 $1$，于是只能是高度 $2$ 与高度 $1$；并且这两棵子树本身也要是各自高度下的最省 AVL 树（最优化原理）；
- 命题意图：考 AVL 树"给定高度的最少结点数"这一 Fibonacci 型递推 $N(h)=N(h-1)+N(h-2)+1$，以及初值 $N(0)=0,N(1)=1$ 的正确取法——许多学生背得出递推式却把初值取错。

## 4. 核心考点

核心考点：
DS05.07.02 平衡二叉树（平衡因子的绝对值 $\le1$；给定高度的最少结点数）

辅助考点：
DS03.02.01 二叉树的定义及主要特征（高度的递归定义、结点由左右子树递归构成）

解释：递推式中"$h-1$ 与 $h-2$"完全来自 AVL 的平衡条件（去掉这一约束就退化为 DS-2013-12 的 $2h-1$），故主考点是 DS05.07.02；而"树高 = 子树高的最大值 + 1"这类递归结构性质属 DS03.02.01，列为辅助。

## 5. 解题思路

1. 设 $N(h)$ 为高度 $h$ 的 AVL 树最少结点数；由"树高 = max(左高, 右高) + 1"，要达到高度 $h$，必有一棵子树高 $h-1$；
2. 由平衡条件，另一棵子树的高度只能取 $h-1$ 或 $h-2$；要结点数最少当然取 $h-2$（高度 $h-1$ 的子树结点数一定更多）；
3. 两棵子树各自也须取本高度的极小形态 ⟹ $N(h)=N(h-1)+N(h-2)+1$；
4. 定初值：$N(0)=0$（空树）、$N(1)=1$（只有根）；递推得 $N(2)=1+0+1=2$、$N(3)=N(2)+N(1)+1=2+1+1=4$；
5. **双向验证**：① 构造——画出 4 结点高度 3 的树并逐点检查平衡因子；② 反证——穷举 3 个结点的所有高度 3 形态，说明必违反平衡条件。

## 6. 详细解答

**第一步：建立递推**

设 AVL 树根为 $r$，左右子树高度为 $h_L,h_R$，则 $h=\max(h_L,h_R)+1$，平衡条件要求 $|h_L-h_R|\le1$。
要 $h$ 层且结点最少：$\max(h_L,h_R)=h-1$，另一棵至多为 $h-1$、至少为 $h-2$，取较小者 $h-2$ 更省结点。故

$$N(h)=N(h-1)+N(h-2)+1,\qquad N(0)=0,\ N(1)=1$$

**第二步：递推计算**

| $h$ | $N(h)=N(h-1)+N(h-2)+1$ | $N(h)$ |
|---|---|---|
| 0 | ——（空树） | 0 |
| 1 | 只有根 | 1 |
| 2 | $N(1)+N(0)+1=1+0+1$ | 2 |
| **3** | $N(2)+N(1)+1=2+1+1$ | **4** |
| 4 | $N(3)+N(2)+1=4+2+1$ | 7 |
| 5 | $N(4)+N(3)+1=7+4+1$ | 12 |

（$N(5)=12$ 与 DS-2007-28 的结论一致，可作为本递推的独立交叉验证。）

**第三步：构造验证 $N(3)=4$ 可达**

```
        A          A：左子树高 2，右子树高 1，|差| = 1 ✓
       / \         B：左子树高 1，右子树高 0，|差| = 1 ✓
      B   D        C、D：叶子，|差| = 0 ✓
     /
    C
```
结点集 $\{A,B,C,D\}$，共 $4$ 个；树高 $=3$（$A\to B\to C$ 三层）；每个结点的平衡因子绝对值都不超过 $1$ ⟹ 这是一棵合法的高度 3 的 AVL 树，故 $N(3)\le4$。

**第四步：反证 $3$ 个结点不可能**

树高为 $3$ 意味着存在一条含 $3$ 个结点的路径（第 1、2、3 层各一个）。若总共只有 $3$ 个结点，则该树必为这条路径本身——**单支链** $A\to B\to C$。此时根 $A$ 的一棵子树高 $2$、另一棵高 $0$，平衡因子 $=2-0=2>1$，违反 AVL 定义 ⟹ $3$ 个结点不够。
（$2$ 个结点最多撑起高度 $2$，$1$ 个结点高度 $1$，故 $N(3)\ge4$。）

由第三、四步 $N(3)\le4$ 且 $N(3)\ge4$ ⟹ $N(3)=4$。

**答案**：A。

## 7. 选项分析

- A. $4$：正确。递推值，且已构造出 4 结点高度 3 的 AVL 树，并用穷举法证明 3 结点必失衡；
- B. $15$：错。$15=2^{4}-1$ 是**高度 4 的满二叉树**结点数，既不是"最少"也不是"高度 3"，是把两个公式（满二叉树计数）用错对象；
- C. $11$：错。$11$ 不对应本题任一标准误算路径（既不是 AVL 极小值序列 $1,2,4,7,12$ 中的项，也不是满二叉树值 $7$ 或 $15$），属纯数值干扰项；最接近的合法量是 $N(5)=12$，但那是高度 5 的最少结点数；
- D. $7$：错。$7$ 有两个易混来源：① 高度 3 的**满**二叉树结点数（那是"最多"而非"最少"）；② 高度 **4** 的 AVL 树最少结点数 $N(4)=7$。本题高度为 3，$7$ 是"多算了一层"的结果。

## 8. 考场标准答案

设 $N(h)$ 为高度 $h$ 的 AVL 树最少结点数，$N(0)=0,N(1)=1$。
根的两子树高度只能是 $h-1$ 与 $h-2$（相差不得超过 $1$），故
$$N(h)=N(h-1)+N(h-2)+1$$
$$N(2)=2,\quad N(3)=N(2)+N(1)+1=2+1+1=4$$
构造：根 $A$，左孩子 $B$（$B$ 有左孩子 $C$），右孩子 $D$，即为一棵 4 结点、高 3 的 AVL 树；而 3 结点只能是单支链，根的平衡因子为 2，不合法。选 **A**。

## 9. 易错点

1. **初值取错**：把 $N(1)$ 当作 $2$ 或把 $N(0)$ 当作 $1$，会推出 $N(3)=5$ 之类的错误值；题面已注明"空树高度为 $0$"，故单结点树高 $1$、$N(1)=1$、$N(2)=2$；
2. **与"无度 1 结点"的极值题混淆**：DS-2013-12 那种"只有度 0 和度 2 结点"的树，高度 3 时最少 $2h-1=5$ 个结点；两题外形相似（都是"给定高度求最少结点"），约束完全不同，必须先确认约束再选方法；
3. 误选 D（$7$）：把"高度 3 的 AVL 最少结点"当成"高度 3 的满二叉树"或顺延成 $N(4)$；
4. 只给递推结果不给构造/反证：本题选项含 $4$ 与 $7$，若不能说明"4 确实能构成 AVL"和"3 个结点为什么不行"，很难在两者之间确证。

## 10. 一句话规律

"给定高度求 AVL 最少结点数"永远是 Fibonacci 型递推 $N(h)=N(h-1)+N(h-2)+1$（$N(0)=0,N(1)=1$），序列为 $1,2,4,7,12,20,\cdots$；拿到题先默写前五项再对号入座，比现场推导更不容易出错。

## 11. 关联知识

- DS-2007-28（高度为 5 的 AVL 树最少结点数 $=12$）与本题同型，且落在同一递推数列上（$1,2,4,7,12$），两题互为依据：本题推出的 $N(5)=12$ 与该题结论一致，构成交叉验证；
- DS-2013-12（只有度 0 与度 2 结点、高度 $h$ 的二叉树最少结点数 $2h-1$）是与本题对照性最强的一题：把"平衡条件"换成"无度 1 结点"，下界从 Fibonacci 型变成线性型，可见约束强弱直接决定极值大小；
- DS-2006-05、DS-2012-11 与 DS-2007-26（同族"无度 1 结点 ⟹ $2h-1$"题）可与上条一起组成"给定高度求最少结点数"的两种约束对比练习；
- DS05.07.02 的另一半内容是插入/删除后的旋转调整（LL/RR/LR/RL 四种情形，见 2006 年原卷关于 AVL 插入调整的判断题），本题只用到"平衡因子 $\le1$"这一静态性质，未涉及旋转。
