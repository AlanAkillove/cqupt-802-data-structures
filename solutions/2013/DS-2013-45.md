# DS-2013-45

## 1. 原题

现有一棵二叉查找（排序）树（ `Binary Search Tree` ） $BST$ ，以二叉链表形式存储，进行中序遍历可得到从小到大排序的有序序列。试设计一算法，对该二叉查找树进行变换，使得对新的二叉树进行中序遍历可得到从大到小排序的有序序列。要求：

（1）描述算法的基本设计思想；

（2）根据设计思想，描述算法的详细实现步骤，可使用伪代码、 $C$ 或 $C++$ 或 $JAVA$ 语言，关键之处给出简要注释。

有关的数据结构已描述如下：

```c
struct Binary_node //二叉树结点
{ 
    int data; 
    struct Binary_node *left;
    struct Binary_node *right; 
};
```

## 2. 答案

**基本设计思想**：把二叉树**取镜像**——对每一个结点交换它的左、右孩子指针（递归地作用到整棵树）。原树中序为"左 → 根 → 右"且递增，镜像树的中序恰好是原中序的**逆序**，故为"从大到小"的递减有序序列。

**实现**（教材风格 C，基于题给 `struct Binary_node`）：

```c
typedef struct Binary_node BSTNode, *BSTree;

void InvertBST(BSTree t)            /* 递归交换每个结点的左右孩子 */
{
    if (t == NULL) return;          /* 空树：递归终止 */
    BSTree tmp = t->left;           /* 交换本结点的左右孩子指针 */
    t->left  = t->right;
    t->right = tmp;
    InvertBST(t->left);             /* 再对新的左右子树做同样变换 */
    InvertBST(t->right);
}
```

**复杂度**：时间 $O(n)$，$n$ 为树中结点个数（每个结点恰好被访问一次、做一次交换）；空间 $O(h)$，$h$ 为树的高度（递归工作栈深度），树平衡时 $O(\log n)$，退化成单支时 $O(n)$。结点本身原地修改，不新申请结点空间。

## 3. 题目分析

- 已知：一棵以二叉链表存储的 BST $t$，`data` 为 `int`，`left`/`right` 为孩子指针；性质：中序遍历 $t$ 得递增序列（设序列为 $v_1<v_2<\cdots<v_n$）；
- 目标：**改变树的结构**，使对新树做中序遍历得到 $v_n,v_{n-1},\cdots,v_1$（递减）；
- 输入 / 输出：输入为根指针 `t`（可能为 `NULL`）；输出为原地修改后的同一棵树，函数无返回值。结点个数、关键字集合都不变，只改变左右链接关系；
- 关键约束与认识要点：
  1. **中序遍历的次序由"左右孩子的身份"决定**，所以想让中序反向，就必须让每个结点的左右子树互换位置，而不是仅仅换数据或换访问顺序；
  2. 题面只要求"对新二叉树中序遍历得递减序列"，**并不要求新树仍是 BST**——事实上变换后必然不再是 BST（每个结点的左子树关键字都大于它自己）。这一点常被误解为"必须重建成 BST"；
  3. 若只要求"输出递减序列"而允许不改树，则把遍历改成"右 → 根 → 左"（反中序）即可 $O(n)$、$O(h)$；但题面明确要求"对该二叉查找树进行变换"，故必须以**修改指针**的方式作答（见 6.5 节对照说明）。
- 命题意图：考 BST 的中序有序性 + 二叉树遍历与递归的构造能力——即"遍历次序与树形之间的对应关系"能否反向使用；同时考 $O(n)$ 原地变换 vs $O(n\log n)$/重建树 的低效方案的取舍。

## 5. 解题思路

1. 先把要求翻译成等式：设原树 $T$ 的中序为 $I(T)$，题给条件 $I(T)=v_1,\cdots,v_n$（递增），要求新树 $T'$ 满足 $I(T')=v_n,\cdots,v_1$，即 $I(T')=reverse(I(T))$；
2. 回忆遍历定义 $I(T)=I(T_L),\ root,\ I(T_R)$。要让整体取逆，必须把"左边的部分"搬到右边去、且各部分内部也取逆 —— 这恰好是**逐结点交换左右子树**的递归结构：$I(\overline{T})=reverse(I(T_R)),\ root,\ reverse(I(T_L))$；
3. 由此得到"镜像/翻转"变换，并考虑实现方式：递归最自然（终止条件 `t == NULL`，主体"交换 + 两次递归"）；也可用非递归的显式栈（先序式遍历每个结点并交换），见 6.4 节；
4. 确认这是**最优**做法：每个结点至少要被处理一次 ⟹ 下界 $\Omega(n)$；本算法恰为 $O(n)$，且原地只改指针，不新建结点、不搬数据；
5. 边界自查：空树（`t == NULL` 直接返回）、单结点树（左右皆空，交换后仍是自己）、所有结点只有单侧子树（如本题 6.3 样例中 $15$ 只有右孩子，交换后变成只有左孩子）三种情形都不破坏正确性；
6. 验证：取一棵具体 BST 手工跑一遍，比较变换前后的中序序列是否恰为互逆（第 6.3 节用本库 DS-2013-42 的树作样例）。

## 6. 详细解答

### 6.1 记号与变换定义

对二叉树 $T$（可能为空 $\emptyset$），定义其**镜像** $\overline{T}$：

$$\overline{\emptyset}=\emptyset,\qquad \overline{T}=\big(root,\ \overline{T_R},\ \overline{T_L}\big)$$

即根的左孩子变成"原右子树的镜像"、右孩子变成"原左子树的镜像"。题给结构下，这正是"对每个结点交换 `left` 与 `right`，并对两棵子树递归执行"。

### 6.2 正确性证明（对结点数 $n$ 归纳）

**命题**：对任意二叉树 $T$，$I(\overline{T}) = reverse\big(I(T)\big)$。

- 基例：$n=0$（$T=\emptyset$）时两边都是空序列 ✓；$n=1$ 时 $I(T)=root=reverse(I(T))$ ✓。
- 归纳：设命题对结点数 $<n$ 的树成立。对 $n$ 个结点的 $T$，左子树 $T_L$ 有 $a$ 个结点、右子树 $T_R$ 有 $b$ 个结点，$a+b=n-1$，两者均 $<n$，可用归纳假设：
$$I(\overline{T_L})=reverse(I(T_L)),\quad I(\overline{T_R})=reverse(I(T_R))$$
于是由中序定义与镜像定义
$$I(\overline{T})=\underbrace{I(\overline{T_R})}_{reverse(I(T_R))},\ root,\ \underbrace{I(\overline{T_L})}_{reverse(I(T_L))}=reverse\big(I(T_L),\ root,\ I(T_R)\big)=reverse\big(I(T)\big)$$
（最后一步：把序列 $X,\ root,\ Y$ 整体取逆正是 $reverse(Y),\ root,\ reverse(X)$。）命题成立 ∎

**代入题设**：$T$ 是 BST，故 $I(T)=v_1<v_2<\cdots<v_n$，由命题 $I(\overline{T})=v_n,v_{n-1},\cdots,v_1$，严格递减 ✓ —— 这正是题目要求的"从大到小排序的有序序列"。

（附注：$\overline{T}$ 的每个结点的左子树关键字全部**大于**它，右子树全部小于它，与 BST 的定义相反，所以新树不再是 BST；题目对此无要求。）

### 6.3 样例走查（用 DS-2013-42 的树）

取 2013 年第 42 题重建出的二叉排序树，中序为 $15,25,37,49,51,66$：

```
              49                         49
            /    \                     /    \
         15        66        →       66      15
            \      /                  \      /
            37    51                  51    37
            /                              \
          25                                25
        原 BST（中序递增）              镜像后（中序递减）
```

逐结点交换：$49$ 的左右孩子 $15,66$ 互换；$15$ 原本只有右孩子 $37$ ⟹ 变成只有左孩子 $37$；$37$ 原本只有左孩子 $25$ ⟹ 变成只有右孩子 $25$；$66$ 原本只有左孩子 $51$ ⟹ 变成只有右孩子 $51$。

对新树做中序遍历（左 → 根 → 右）：

- 根 $49$ 的左子树 $66$：先访问 $66$（其左孩子为空），再进其右孩子 $51$ → 得 $66,51$；
- 访问 $49$；
- 根 $49$ 的右子树 $15$：先深入 $15$ 的左孩子 $37$，$37$ 无左孩子 → 访问 $37$，再进 $37$ 的右孩子 $25$ 访问 → 得 $37,25$，回溯访问 $15$；

合计 $66,\ 51,\ 49,\ 37,\ 25,\ 15$ —— 与原中序 $15,25,37,49,51,66$ 严格互逆 ✓，且递减有序。

（对照检查：若新树的中序与原中序不是互逆关系，则说明某个结点的左右孩子漏交换，可据此快速定位错误。）

### 6.4 实现步骤与代码

**实现步骤**（递归版，主答案）：

1. 若当前子树根 `t` 为 `NULL`，直接返回（递归终止，同时处理空树输入）；
2. 用一个临时指针 `tmp` 保存 `t->left`，令 `t->left = t->right`、`t->right = tmp`，完成本结点的左右孩子交换；
3. 对交换后的 `t->left` 递归调用本算法；
4. 对交换后的 `t->right` 递归调用本算法；
5. 主调函数只需 `InvertBST(t);`，树形即被原地变换，原根指针仍有效（根结点没有换位置，只换了孩子）。

```c
#include <stdio.h>

typedef struct Binary_node BSTNode, *BSTree;

/* ---- 主解：递归交换每个结点的左右孩子（镜像变换） ---- */
void InvertBST(BSTree t)
{
    BSTree tmp;
    if (t == NULL) return;            /* 空树/叶子孩子的递归边界 */
    tmp        = t->left;             /* 交换左、右孩子指针 */
    t->left    = t->right;
    t->right   = tmp;
    InvertBST(t->left);               /* 变换新的左子树（原右子树） */
    InvertBST(t->right);              /* 变换新的右子树（原左子树） */
}
```

**核心不变量**：任一时刻，"已经访问过的结点"其左右孩子已互换且其**整棵子树**已完成镜像，"未访问的结点"保持原样；因此算法中途被打断也只产生部分变换，不会破坏树的链接完整性（每个结点的 `left`/`right` 始终是原树中出现过的孩子指针，不会产生悬空指针）。

**非递归写法**（备选，用教材风格的顺序栈，适合担心递归栈深度过大溢出的场合）：先序式访问每个结点并交换：

```c
#define MAXN 100
void InvertBST_NonRec(BSTree t)
{
    BSTree stack[MAXN], p, tmp;
    int top = -1;
    if (t == NULL) return;
    stack[++top] = t;                        /* 根入栈 */
    while (top >= 0) {
        p = stack[top--];                    /* 出栈：待交换的结点 */
        tmp = p->left;  p->left = p->right;  p->right = tmp;
        if (p->left)  stack[++top] = p->left;    /* 新孩子入栈，继续交换 */
        if (p->right) stack[++top] = p->right;
    }
}
```

注意：关键是**每个结点只能被交换一次**。上例在出栈时交换、再把交换后的两个孩子入栈（集合与原孩子相同，只是左右互换了身份），每个结点恰处理一次；若“入栈前先交换一次、出栈时再交换一次”则会两次交换相互抵消而复原。

### 6.5 复杂度分析（写明 $n$ 的含义）

设 $n$ 为二叉排序树中**结点总数**，$h$ 为树的高度（根到最远叶子的路径上的结点数，$1\le h\le n$）。

- **时间**：每个结点被访问恰好一次，每次做 $3$ 次指针赋值与 $2$ 次递归调用，故
$$T(n)=T(n_L)+T(n_R)+O(1),\quad T(0)=O(1)\ \Longrightarrow\ T(n)=O(n)$$
即 $O(n)$，与树的形状无关；`t == NULL` 判断共执行 $2n+1$ 次（$n$ 个非空结点各一次、$n+1$ 个空孩子各一次：$n$ 个结点的二叉树恰有 $n+1$ 个空链域），总操作量线性。
- **空间**：原地修改，不新分配结点；额外空间只有递归工作栈，深度等于当前分支长度，最大为 $h$ ⟹ $S(n)=O(h)$。
  - 平衡 BST：$h=\lceil \log_2(n+1)\rceil$ ⟹ $O(\log n)$；
  - 极端单支（例如按有序序列逐个插入得到的树）：$h=n$ ⟹ $O(n)$；
  - 非递归版同样是 $O(h)$（栈中最多存一条路径上的"待处理结点"）。
- **下界说明**：任何正确算法必须处理每个结点（否则该结点未被交换，其所在子树的中序相对次序就不会反转），故 $\Omega(n)$ 不可避免，本算法已达最优。
- **对照的低效方案**：把原中序存入数组再倒序写回各结点的数据域（时间 $O(n)$、空间 $O(n)$，且树形不变、只搬数据，见第 9 节第 3 条）；或先取出递增序列再按从大到小逐个插入建树（时间最坏 $O(n^2)$）。二者都不优于主解。

### 6.6 若不要求"变换树"而只要求"输出递减序列"

则无需改动任何指针，只要把中序遍历的"左–根–右"改为"右–根–左"（反中序遍历），同样 $O(n)$ 时间、$O(h)$ 栈空间：

```c
void PrintDesc(BSTree t)                    /* 仅打印，不修改树 */
{
    if (t == NULL) return;
    PrintDesc(t->right);
    printf("%d ", t->data);
    PrintDesc(t->left);
}
```

此写法不满足题面"对该二叉查找树进行变换"的要求（树未被改变），列于此仅作对比，主答案仍为 6.4 节的 `InvertBST`。

## 8. 考场标准答案

**(1) 基本设计思想**：二叉排序树的中序遍历是递增序列；而一棵树与其镜像树的中序遍历序列互为逆序。因此对树中**每个结点都交换其左、右孩子指针**（递归地作用于左右子树），整棵树取镜像，结点个数与关键字都不变，变换后对该树中序遍历即得到从大到小的递减有序序列。算法原地进行，不新设结点。

**(2) 实现步骤与代码**：

1. 递归终止：`t == NULL` 返回；
2. 用 `tmp` 交换 `t->left` 与 `t->right`；
3. 递归处理交换后的左、右子树。

```c
typedef struct Binary_node BSTNode, *BSTree;

void InvertBST(BSTree t)
{
    BSTree tmp;
    if (t == NULL) return;                  /* 空树返回 */
    tmp      = t->left;                     /* 交换左右孩子 */
    t->left  = t->right;
    t->right = tmp;
    InvertBST(t->left);                     /* 变换左子树 */
    InvertBST(t->right);                    /* 变换右子树 */
}
/* 调用：InvertBST(t);  此后中序遍历 t 即得从大到小的序列 */
```

亦可非递归：用栈依次弹出结点、交换其左右孩子、再把两个孩子压回栈（注意"先交换后入栈"，否则会交换两次复原）。

**(3) 复杂度**：时间 $O(n)$，$n$ 为结点总数（每结点访问一次、做常数次指针赋值）；空间 $O(h)$，$h$ 为树高，即递归栈深度——平衡时 $O(\log n)$，最坏单支时 $O(n)$；结点空间 $O(1)$ 附加（原地）。

## 9. 易错点

1. **误以为"变换后还得是 BST"**，于是去重建树或改成"每个结点值变小"的操作：BST 的中序必递增，递减有序的二叉树必然不是 BST，题面只要求"中序得从大到小序列"；
2. 写成 `t->data` 的交换而不动指针：数据交换不能改变左右子树的相对位置，中序次序仍是递增，白做；
3. 只交换根的孩子、忘记递归处理子树：样例中若不处理 $15$、$37$、$66$ 各自的子树，中序会得 $51,66,49,15,25,37$（不是递减序列），可用来快速自检；
4. **交换与递归的顺序**：`tmp = t->left; t->left = t->right; t->right = tmp;` 之后对**新**的 `t->left`/`t->right` 递归（顺序写成"先递归再交换"也正确，但对同一子树递归两次/漏一次则错）；非递归版若对同一结点交换两次（入栈前一次、出栈后一次）则会相互抵消而复原；
5. 漏写 `if (t == NULL) return;`：空树输入或访问到空孩子时空指针解引用崩溃；
6. 复杂度只写 $O(n)$ 不写空间：应同时给出空间 $O(h)$ 并说明 $h$ 与 $n$ 的关系（平衡 $O(\log n)$、单支 $O(n)$）；
7. 误用"中序存数组再倒序写回"当主答案：那需要 $O(n)$ 附加数组空间，且改变的是结点内容而非树的链接，不如镜像变换简洁。

## 10. 一句话规律

"让中序反向"= "让左右子树整体换位"：**逐结点交换左右孩子**（取镜像），$I(\overline{T})=reverse(I(T))$，$O(n)$ 时间、$O(h)$ 栈空间即可完成；反之，凡是"遍历序列反向"的需求，都可由此式两边对照着想到——改遍历方向（不改树）或改树形（不改遍历）。
