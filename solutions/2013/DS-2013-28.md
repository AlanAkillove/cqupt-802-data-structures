# DS-2013-28

## 1. 原题

在一棵度为 $3$ 的树中，度为 $2$ 的结点个数是 $1$ ，度为 $0$ 的结点个数是 $6$ ，则度为 $3$ 的结点个数是____________________ 。

> 订正说明转录：源文作"度为 $0$ 的结点个数 $6$"，据题意补"是"字。

## 2. 答案

$2$ 个。

## 3. 题目分析

- 已知：一棵**度为 $3$ 的树**（树中结点的最大度为 $3$），$n_2=1$、$n_0=6$（$n_i$ 表示度为 $i$ 的结点个数）；
- 目标：$n_3$；
- 关键约束：① 树中结点总数 $n=n_0+n_1+n_2+n_3$；② 除根结点外每个结点恰被一条分支（边）指向，故**分支总数 $B=n-1$**；③ 分支总数也等于各结点孩子数之和 $B=\sum_i i\cdot n_i=0\cdot n_0+1\cdot n_1+2\cdot n_2+3\cdot n_3$；
- 未知量 $n_1$（度为 $1$ 的结点数）题面未给，但它会在方程中**自动消去**——这是本题的关键观察；
- 命题意图：考"树的结点数与分支数的恒等式"，即 $n_0=n_2+1$ 这一二叉树结论在一般树上的推广形式。

## 4. 核心考点

核心考点：
DS03.01 树的基本概念（结点的度、树的度、叶子、分支数与结点数的关系 $B=n-1$）

辅助考点：
DS03.02.01 二叉树的定义及主要特征（$n_0=n_2+1$ 是本题恒等式在 $m=2$ 时的特例，用作对照与验算）

解释：本题对象是"度为 $3$ 的树"而非二叉树，孩子数可为 $1,2,3$，故主考点必须落在树的基本概念（DS03.01）；二叉树的 $n_0=n_2+1$ 只是同一推导的一个特例，作辅助对照。

## 5. 解题思路

1. 先立恒等式：把 $n=\sum n_i$ 与 $B=n-1=\sum i\,n_i$ 两式相减，消去 $n_1$，得到**只含 $n_0$ 与 $i\ge2$ 各项**的关系式 $n_0=1+\sum_{i\ge2}(i-1)n_i$；
2. 代入已知量 $n_0=6$、$n_2=1$，解出 $n_3$；
3. 复核：解出的 $n_3$ 与 $n_1$ 无关，说明题面不给 $n_1$ 不是缺损；取 $n_1=0$ 与 $n_1=1$ 各验一次恒等式；
4. 再**显式构造**一棵满足条件的树（$n_3=2$、$n_2=1$、$n_0=6$），确认答案可达成、题设不矛盾。

## 6. 详细解答

**步骤 1：建立恒等式**（方法一）

$$n=n_0+n_1+n_2+n_3$$

$$B=n-1=0\cdot n_0+1\cdot n_1+2\cdot n_2+3\cdot n_3$$

两式相减（第一式减第二式）：

$$1=n_0+n_1+n_2+n_3-(n_1+2n_2+3n_3)=n_0-n_2-2n_3$$

即

$$\boxed{n_0=1+n_2+2n_3}\qquad(\star)$$

注意 $n_1$ 已完全消去，故题面无须给出度为 $1$ 的结点数。

**步骤 2：代入求解**

$$6=1+1+2n_3\ \Longrightarrow\ 2n_3=4\ \Longrightarrow\ n_3=2$$

**步骤 3：用一般叶子公式核对**（方法二）

对度为 $m$ 的树，由同一推导得

$$n_0=1+\sum_{i=2}^{m}(i-1)n_i=1+1\cdot n_2+2\cdot n_3$$

代入 $n_2=1$、$n_3=2$：$1+1+4=6=n_0$ ✓ 与题设吻合。

（$m=2$ 时该式退化为 $n_0=1+n_2$，即二叉树性质 $n_0=n_2+1$，可见本题正是该性质的三路推广。）

**步骤 4：整组数据自洽性检验**

取 $n_1=0$：$n=n_0+n_1+n_2+n_3=6+0+1+2=9$，分支数 $B=n_1+2n_2+3n_3=0+2+6=8=n-1$ ✓
取 $n_1=1$：$n=10$，$B=1+2+6=9=n-1$ ✓
取 $n_1=3$：$n=12$，$B=3+2+6=11=n-1$ ✓

无论 $n_1$ 取何值恒等式都成立，说明 $n_3=2$ 唯一确定。

**步骤 5：显式构造**（证明确有这样的树）

```
            r            ← 度 3
        /   |   \
       a    b    c        ← a 度 3，b 度 2，c 叶
     / | \  |\
    d  e  f g h           ← 全为叶
```

$r$ 有 $3$ 个孩子（$a,b,c$），$a$ 有 $3$ 个孩子（$d,e,f$），$b$ 有 $2$ 个孩子（$g,h$），$c,d,e,f,g,h$ 为叶子。
统计：$n_3=2$（$r,a$）、$n_2=1$（$b$）、$n_1=0$、$n_0=6$（$c,d,e,f,g,h$）——与题设完全一致 ✓

**答案**：$2$。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

设度为 $i$ 的结点有 $n_i$ 个。由 $n=\sum n_i$ 与"分支数 $=$ 结点数 $-\,1$"得

$$n_0+n_1+n_2+n_3-1=n_1+2n_2+3n_3\ \Longrightarrow\ n_0=1+n_2+2n_3$$

代入 $n_0=6$、$n_2=1$：$6=1+1+2n_3\Rightarrow n_3=\boxed{2}$。

（度为 $1$ 的结点数 $n_1$ 在推导中被消去，不影响结果。）

## 9. 易错点

1. **误以为条件不足**：因题面没给 $n_1$ 而放弃；实际上 $n_1$ 在"$n$ 与 $n-1$ 两式相减"时必然消去，这是本类题的固定结构；
2. 直接套用二叉树公式 $n_0=n_2+1$：那是"度只取 $0,1,2$ 的二叉树"的结论，本题存在度为 $3$ 的结点，正确形式是 $n_0=1+n_2+2n_3$；
3. 系数写错：度为 $i$ 的结点在 $(\star)$ 式中的系数是 $i-1$（不是 $i$），$n_3$ 前漏写 $2$ 会得到 $n_3=4$；
4. 把"树的度为 $3$"误解为"树有 $3$ 层"或"每个结点都有 $3$ 个孩子"：树的度是**各结点度的最大值**，允许存在度 $1,2$ 的结点。

## 10. 一句话规律

凡"给若干度数的结点个数、求剩下的那个"的树计数题，一律用 $n_0=1+\sum_{i\ge2}(i-1)n_i$（由 $n$ 与 $n-1$ 两式相减得来），$n_1$ 永远不出现。

- 本年度第 $12$ 题（只有度 $0$ 与度 $2$ 结点、高度为 $h$ 的二叉树至少有 $2h-1$ 个结点）用的就是 $(\star)$ 式在 $m=2$ 时的特例 $n_0=n_2+1$，两题可对照记忆；

- 该恒等式的树形解释：树中 $n-1$ 条分支全部由结点的孩子"贡献"，而每个结点（除根）恰被一条分支指向，故"孩子总数 $=$ 结点数 $-\,1$"。
