# DS-2006-10

## 1. 原题

具有 $n$ 个顶点和 $e$ 条边的图深度优先搜索算法的时间复杂度为（）。

A. $O(n)$

B. $O(n^3)$

C. $O(n^2)$

D. $O(n+e)$

## 2. 答案

**D**（$O(n+e)$，按题面把 $e$ 列为参数的口径，即邻接表存储下的遍历复杂度）。

## 3. 题目分析

- 已知：图有 $n$ 个顶点、$e$ 条边（题面未指明存储结构，也未指明有向/无向）；算法为深度优先搜索（DFS）遍历；
- 目标：整个遍历过程（不止一次递归调用）的时间复杂度；
- 关键约束：复杂度上界由"**访问每个顶点**"与"**检查每条边（弧）**"两类基本操作之和决定，两类操作各做常数次即为最优；
- 命题意图：考 DFS 复杂度的正确计数方式（每个顶点一次、每条边一次），而非记住某个孤立结论。

## 4. 核心考点

核心考点：
DS04.03.01 深度优先搜索（遍历全过程的代价构成）

辅助考点：
DS04.02.02 邻接表法（"求一个顶点的全部邻接点"的代价 $=$ 该顶点边表长度）
DS04.02.01 邻接矩阵法（"求全部邻接点"须扫描一行，代价 $O(n)$——选项 C 的来源）

解释：DFS 的框架不变，代价完全取决于"取邻接点"这一步在所选存储结构上的开销，因此必须在考点中并列两种存储结构。

## 5. 解题思路

1. 把总代价拆成"顶点工作 + 边工作"：`visited` 判定与访问输出对每个顶点做常数次工作 → $O(n)$；
2. 在邻接表上，顶点 $v_i$ 的边表长度为 $\deg(v_i)$（有向图为出度），而 $\sum_i \deg(v_i)=2e$（无向）或 $e$（有向），故所有边表被扫描的总长度是 $O(e)$；
3. 合并：$O(n)+O(e)=O(n+e)$；非连通图外层 `for` 只是把起点换成未访问顶点，不增加量级；
4. 反向确认：若用邻接矩阵，则每个顶点都要扫完整一行，代价 $O(n)$，总计 $O(n^2)$，此时 $e$ 不出现在结果里——与题面把 $e$ 写成参数不符，故本题取邻接表口径。

## 6. 详细解答

**邻接表口径（推导 D）**

设图 $G=(V,E)$，$|V|=n$，$|E|=e$。邻接表 DFS 的典型形式：

```c
void DFS(ALGraph G, int v)
{
    visited[v] = TRUE;                 /* 每顶点 1 次 */
    for(p = G.vertices[v].firstarc; p; p = p->nextarc)   /* 扫描 v 的边表 */
        if(!visited[p->adjvex]) DFS(G, p->adjvex);
}
```

- **顶点代价**：`visited[v]=TRUE` 与函数调用仅在该顶点首次被访问时执行，每个顶点至多一次，共 $n$ 次 → $O(n)$；
- **边代价**：`for` 循环对顶点 $v$ 执行 $\deg(v)$（有向图为出度）次循环体；由于每个顶点恰好被访问一次，其边表也**恰好被完整扫描一次**，故总循环次数

$$\sum_{v\in V}\deg(v)=\begin{cases}e,&\text{有向图}\\ 2e,&\text{无向图}\end{cases}\ =O(e)$$

- **外层扫描**：`DFSTraverse` 中的 `for(i=0;i<n;i++) if(!visited[i]) DFS(G,i);` 代价 $O(n)$，不改变量级。

合计

$$T(n,e)=O(n)+O(e)=O(n+e)$$

**邻接矩阵口径（对应选项 C）**

若以邻接矩阵存储，"求 $v$ 的邻接点"须检查矩阵的一整行，代价 $O(n)$；$n$ 个顶点共 $O(n^2)$，与 $e$ 无关。因此同一句"DFS 复杂度"在两种存储结构下分别是 $O(n+e)$ 与 $O(n^2)$。

**为何本题答案取 $O(n+e)$**：题面把"$e$ 条边"明确作为图的已知量写出，若结论与 $e$ 无关则该条件多余；且四个选项中同时含 $O(n^2)$ 与 $O(n+e)$，说明命题考查的是"逐顶点 + 逐边各计一次"这一最优计数（邻接表口径），故选 D。BFS 遍历的复杂度分析与本题完全同构，也是 $O(n+e)$。

## 7. 选项分析

- A. $O(n)$：错。忽略"必须查看边才能找到邻接点"，除非图根本没有边（$e=0$）才退化为 $O(n)$；
- B. $O(n^3)$：错。这一量级出现在"对每个顶点重复做全矩阵/全表扫描并嵌套"的错误估法中，标准 DFS 不做重复扫描；
- C. $O(n^2)$：错（在本题口径下）。它是**邻接矩阵**存储下 DFS 的复杂度，此时与 $e$ 无关，与题面给出 $e$ 这一条件不符；若题目明确"以邻接表存储"或"以邻接矩阵存储"，则 C、D 各有其唯一正确的场合；
- D. $O(n+e)$：正确。邻接表下每顶点访问一次、每边（弧）检查一次，$n$ 与 $e$ 两项都不可省（例如 $e=0$ 时需 $O(n)$ 才能确认所有顶点已处理，$n$ 固定时稀疏图的代价由 $e$ 主导）。

## 8. 考场标准答案

邻接表存储下，DFS 遍历中每个顶点恰好被访问一次（$O(n)$），每个顶点的边表恰好被完整扫描一次，合计扫描表结点 $\sum\deg(v)=O(e)$，故

$$T=O(n+e)\ \Rightarrow\ \text{选 D}$$

（注：邻接矩阵存储时为 $O(n^2)$，与 $e$ 无关；BFS 同为 $O(n+e)$。）

## 9. 易错点

1. **存储结构未指明时不要混用两个结论**：先答"每个顶点一次、每条边一次 $=O(n+e)$"，再补一句"邻接矩阵则为 $O(n^2)$"，比死背一条更稳；
2. 误以为"每次递归都要扫全图"而得 $O(n\cdot(n+e))$ 甚至 $O(n^3)$（选项 B）：`visited` 标记保证顶点不重复访问，边表也不重复扫描；
3. 忽略非连通图：外层还需 $O(n)$ 扫描起点，量级不变，但若只写 $O(e)$ 会漏掉无边顶点的情形。

## 10. 一句话规律

图算法的时间复杂度几乎总是"顶点工作 $O(n)$ + 边工作 $O(e)$（邻接表）或 $O(n^2)$（邻接矩阵）"两段拼出来的，先分清存储结构再相加。

## 11. 关联知识

- 同一计数用于 BFS：$O(n+e)$（邻接表）；
- 求生成森林（DFS）、判连通分量个数、判有向图是否强连通等算法都建立在这趟 $O(n+e)$ 的遍历之上；
- 若图以邻接矩阵存储而希望得到 $O(n+e)$ 级别的邻接点枚举，需先转换为邻接表（转换代价本身即 $O(n^2)$）。
