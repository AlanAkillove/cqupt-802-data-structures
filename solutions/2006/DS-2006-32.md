# DS-2006-32

## 1. 原题

从一维数组 $a[n]$ 中顺序查找出一个最大值元素的时间复杂度为\_\_。

## 2. 答案

$O(n)$。

## 3. 题目分析

- 已知：一维数组 $a[0\cdots n-1]$（或 $a[1\cdots n]$），共 $n$ 个元素，**无序**、未作预处理；
- 目标：用"顺序（逐个）扫描"的方式找出一个最大值元素，求其时间复杂度；
- 关键约束：数组无序，任何算法要确认最大值都必须使每个元素至少被"看过一次"；本题方法已限定为顺序查找，只需统计比较次数；
- 命题意图：考顺序查找这一最基本操作的代价量级——以"问题规模 $n$ 的一次函数"回答，并与折半（$O(\log_2 n)$，需有序）、散列（理想 $O(1)$，需建表）等查找方式的复杂度区分开。

## 4. 核心考点

核心考点：
DS05.02 顺序查找法（从一端到另一端逐个与当前记录比较；扫描全表求最大值为同一遍历模式）

辅助考点：
DS05.01 查找的基本概念（时间复杂度以关键字比较次数为基本操作计量）

解释：求最大值即"以 $a[0]$ 为当前最大、逐个向后比较并更新"，其比较模式与顺序查找完全一致（一趟扫全表）；复杂度分析口径按比较次数，属查找章基本概念。

## 5. 解题思路

1. 写出实现：设 $max$ 记录当前最大值下标，从 $i=1$ 到 $n-1$ 逐个比较 $a[i]$ 与 $a[max]$；
2. 计数：比较次数恰为 $n-1$，与数据分布无关（最好/最坏/平均同为 $n-1$），赋值次数 $\le n-1$；
3. 取量级 $T(n)=n-1=\Theta(n)=O(n)$；
4. 补一句下界说明：若有元素未被访问，把该元素改成更大值即得反例，故任何算法求最大值也需 $\Omega(n)$，$O(n)$ 已是该问题的最优量级。

## 6. 详细解答

**算法（教材风格 C）**

```c
int MaxElem(int a[], int n)        /* 返回最大值元素的下标 */
{
    int i, max = 0;                /* 初始设第 0 个元素最大 */
    for (i = 1; i < n; ++i)        /* 自左向右顺序扫描 */
        if (a[i] > a[max])  max = i;
    return max;
}
```

**比较次数**：循环体执行 $n-1$ 次，每次做 $1$ 次关键字比较，故
$$C(n)=n-1$$
该数值与输入序列的排列**无关**（不存在提前终止的分支），最好 $=$ 最坏 $=$ 平均 $=n-1$。移动（赋值）次数最坏 $n-1$（降序输入，每个元素都刷新最大值）、最好 $0$（升序输入），但都不改变量级。

**量级结论**：
$$T(n)=\Theta(n)\ \Rightarrow\ \text{时间复杂度}\ O(n)$$

**下界（说明 $O(n)$ 不可改进）**：设某算法存在未被读取的元素 $a_k$。把 $a_k$ 改为大于原最大值的新值，算法的输出无法反映这一改动（因其未读 $a_k$），必错。故任何正确算法至少读每个元素一次，比较次数 $\ge n-1$，即 $\Omega(n)$。本题的顺序扫描已达该下界。

**自检**：$n=1$ 时 $C=0$（无需比较，唯一元素即最大值），$n=2$ 时 $C=1$，与"$n-1$"一致；数组无论按行还是按列在一维存储下都是线性访问，空间复杂度 $O(1)$（只需一个 $max$ 变量）。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

逐个元素与"当前最大值"比较，一趟扫描完成，比较次数恰为 $n-1$（与数据分布无关），附加空间 $O(1)$：

$$T(n)=n-1=O(n)$$

## 9. 易错点

1. 写成 $O(n^2)$：把"顺序查找"与"顺序两两比较排序（如冒泡）"混淆，求最大值只需**一趟**扫描；
2. 写成 $O(\log_2 n)$：折半查找的对数级别**要求表有序**，且折半只能用于"按值查找"，不能用于求最大值；
3. 忽略"任一元素都要看"的必要性，误以为可用某种分治跳过一半元素——分治求最大值的两法比较仍是 $n-1$ 次，量级不变；
4. 边界 $n=0$（空表）未处理：实际算法应先判空，属实现细节，不影响复杂度结论。

## 10. 一句话规律

"扫描一遍找极值/计数/求和"这类操作一律 $O(n)$，且 $n-1$ 次比较就是该问题的下界；只有当数据**有序**（折半）或**有额外结构**（散列、索引）时，才可能出现亚线性代价。

## 11. 关联知识

- 本年度第 14 题（理想情况下散列表查找只需 $1$ 次比较）与本题对照：以建表空间换取亚常数的按值查找代价，但散列同样不能求最大值；
- 本年度第 30 题（折半查找比较序列）与本题同为"以比较次数度量时间"的口径；
- 同时求最大值与最小值，成对比较法需 $\lceil 3n/2\rceil-2$ 次比较，仍是 $O(n)$，但比较次数下界随目标改变（与 DS05.01 的 ASL 计量口径一致）；
- 若在一棵二叉排序树（本年度第 6 题、第 20 题涉及）中求最大值，可沿右链走到最右下结点，代价为树高而非 $O(n)$。
