# DS-2006-08

## 1. 原题

下列编码中（）不是前缀码。

A. `{00,01,10,11}`

B. `{0,1,00,11}`

C. `{0,10,110,111}`

D. `{10,110,1110,1111}`

## 2. 答案

**B**（`{0,1,00,11}` 不是前缀码，因为 `0` 是 `00` 的前缀）。

## 3. 题目分析

- 已知：四组二进制编码方案（每组 $4$ 个码字）；
- 目标：找出**违反前缀性质**的那一组；
- 关键定义：前缀码（异前缀码）——编码方案中**任一码字都不是另一个码字的前缀**；
- 命题意图：考前缀码定义的直接检验，以及"前缀码 $\iff$ 码字可挂在二叉树的叶子上一一对应 $\iff$ 译码无二义"这一等价关系。

## 4. 核心考点

核心考点：
DS03.04.01 哈夫曼树与哈夫曼编码（前缀码概念：哈夫曼编码是构造性前缀码，码字只出现在叶结点上）

解释：判定只需前缀码定义本身；用"二叉判定树"（左 $0$ 右 $1$，自根到叶的路径即码字）来核对，与教材讲哈夫曼编码时"叶结点代表字符、路径代表码字"的图景完全一致，故归入该节点，不需其他章节知识。

## 5. 解题思路

1. 逐组按长度排序，只用**短码字去比对长码字的前若干位**（长度相同的码字彼此不可能是前缀，可整组跳过）；
2. 一旦发现某短码字恰为某长码字的前缀，即判"不是前缀码"；
3. 对判为"是前缀码"的组，再用判定树法复核：把每个码字沿 $0/1$ 下行，若某码字的终点落在另一码字的路径中间（内部结点），则非前缀码；
4. 附加验证：给 B 组写出一段二义码串，证明确实不可靠译码。

## 6. 详细解答

**A. `{00,01,10,11}`**：$4$ 个码字等长（均为 $2$ 位）。等长且互不相同的码字两两不可能是前缀关系 ⇒ 是前缀码。

**B. `{0,1,00,11}`**：检验短码字 `0`（$1$ 位）与长码字 `00`：`00` 的第 $1$ 位就是 `0` ⇒ **`0` 是 `00` 的前缀**，违反定义 ⇒ 不是前缀码。
判定树视角：从根按 `0` 下行一步即到达码字 `0` 的终点，但还要继续下行才有 `00`，说明 `0` 占据了**内部结点**而非叶子；同理 `1` 是 `11` 的前缀，也占内部结点。
二义性演示：收到码串 `0011` 可读作 `00|11`，也可读作 `0|0|1|1`，还可读作 `0|0|11` —— 译文不唯一，正是"非前缀码"的后果。

**C. `{0,10,110,111}`**：短码字 `0` 与其它码字首位 `1` 不同 ⇒ 不可能是它们的前缀；`10` 与 `110` 比较第 $2$ 位（`0` vs `1`）、与 `111` 比较第 $2$ 位（`0` vs `1`）⇒ 均非前缀；`110` 与 `111` 第 $3$ 位不同且等长 ⇒ 非前缀。全部两两无前缀关系 ⇒ 是前缀码。
判定树：`0` 挂根的左叶；`10` 为"右、左"叶；`110`、`111` 为"右、右"的两个孩子叶——$4$ 个码字全是叶子 ✓。

**D. `{10,110,1110,1111}`**：`10` 与其余以 `11` 开头的码字第 $2$ 位不同 ⇒ 非前缀；`110` 与 `1110`/`1111` 第 $3$ 位（`0` vs `1`）不同 ⇒ 非前缀；`1110` 与 `1111` 第 $4$ 位不同且等长 ⇒ 非前缀。⇒ 是前缀码（一条"右斜链"上依次挂叶：`10`、`110`、`1110`、`1111`，均落在叶上）。

综上，只有 B 不是前缀码。

## 7. 选项分析

- A. `{00,01,10,11}`：是前缀码（定长码必为前缀码），不选；
- B. `{0,1,00,11}`：**不是前缀码**——`0` 是 `00` 的前缀、`1` 是 `11` 的前缀，译码有二义，应选；
- C. `{0,10,110,111}`：是前缀码（典型的不等长前缀码形态，与哈夫曼编码产物同型），不选；
- D. `{10,110,1110,1111}`：是前缀码，不选。错误直觉是"码字之间首尾相连就是前缀"，实际必须**完整包含**开头若干位才算（`110` 与 `1110` 只差在第 $3$ 位，不构成前缀）。

## 8. 考场标准答案

前缀码要求任一码字不为另一码字的前缀。

B 组中码字 `0` 是 `00` 的前缀（`1` 也是 `11` 的前缀），故 `{0,1,00,11}` **不是前缀码**；A 为定长码，C、D 各码字两两首位或首个不同位错开，均为前缀码。选 **B**。

## 9. 易错点

1. 把"码字中有相同的位串"误当成"前缀关系"：必须是从**第一位开始完整重合**（如 `0` 与 `00`）；`110` 与 `1110` 前两位相同但第三位不同，不构成前缀；
2. 漏检"短码字是长码字开头"的情况，只比较相邻书写的两个码字——正确做法是按长度排序后用每个短码字去比对所有更长码字；
3. 忽略等长码字天然安全：A 组可整组秒判，省时。

## 10. 一句话规律

判前缀码两法等价——"逐码字两比首位分歧点"或"画 $0/1$ 判定树看是否所有码字都在叶上"，有码字落在内部结点即非前缀码。

## 11. 关联知识

- 哈夫曼编码由"叶结点存放字符、左 $0$ 右 $1$"构造，天然满足前缀性质，是不等长编码中最经典的构造性前缀码；
- 前缀码 $\Rightarrow$ 唯一可译码（逆命题不成立，存在非前缀但唯一可译的编码）；
- 前缀码的译码是"从根沿码串下行，一到叶子即输出一个字符并回到根"，无需回看，故 B 组无法这样译码。
