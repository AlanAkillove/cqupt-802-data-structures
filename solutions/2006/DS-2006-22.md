# DS-2006-22

## 1. 原题

一棵树中的叶子结点数一定等于其对应的二叉树中的叶子结点数。（）

## 2. 答案

**×（错误）**——转换（孩子兄弟表示法）后，二叉树的叶结点要求"既无孩子又无兄弟"，而树的叶结点只要求"无孩子"；有兄弟的树叶子在二叉树中会带一条右链，不再是叶子。反例：根 $A$ 有两个孩子 $B,C$，树叶子数 $2$，对应二叉树叶子数 $1$。

## 3. 题目分析

- 已知：树与"其对应的二叉树"，对应关系即教材的树→二叉树转换（左指针＝第一个孩子，右指针＝下一个兄弟）；
- 目标：判断"叶子结点数"在这一转换下是否保持不变（题面用"一定"，是全称断言）；
- 关键约束：转换保持**结点总数**、保持树的先根序列与二叉树前序序列一致、保持树的后根序列与二叉树中序序列一致，但**不保持**"度"的分布——树中度为 $d$ 的结点在二叉树中变成"有左孩子、并可能带一串右孩子"；
- 命题意图：考孩子兄弟表示法下"树的叶/分支结点"与"二叉树的叶/分支结点"之间的准确对应，避免把"转换"误当成保持一切性质的同构。

## 4. 核心考点

核心考点：
DS03.03.02 森林与二叉树的转换（一棵树转换为一棵二叉树的具体连边规则，以及转换前后形态的变化）

辅助考点：
DS03.03.01 树的存储结构（孩子兄弟表示法的定义：`firstchild` 与 `nextsibling` 两域）
DS03.01 树的基本概念（树的叶结点 $=$ 度为 $0$ 的结点；二叉树的叶结点 $=$ 左右孩子皆空的结点——两个定义不等价）

解释：命题的全部难度在于"两种叶结点的定义不同"，这一区别只有把 DS03.03.01 的双域指针结构与两章的叶子定义并排写出才能看清。

## 5. 解题思路

1. 用孩子兄弟表示法把"二叉树结点 $x$ 是叶"翻译回树的语言：
   $$x\text{ 是二叉树叶}\iff x\text{ 无孩子}\ \text{且}\ x\ \text{无兄弟}$$
2. 而"树的叶"只要求 $x$ 无孩子；两者相差"有无兄弟"这一条；
3. 造反例：只要找一个"是叶子但有兄弟"的树结点即可——根的两个孩子 $B,C$ 中的 $B$ 正符合；
4. 统计核对：$2\ne1$ ⇒ 命题为假；
5. 顺带给出正确的对应关系（树的叶数 $=$ 二叉树中"无左孩子"的结点数）并说明二者何时恰好相等。

## 6. 详细解答

**（1）转换规则与叶子刻画。** 树转二叉树（孩子兄弟表示法）：每个结点保留两个指针

```c
typedef struct CSNode {
    ElemType data;
    struct CSNode *firstchild, *nextsibling;   /* 左＝第一个孩子，右＝下一个兄弟 */
} CSNode, *CSTree;
```

于是对树中任一结点 $x$：

- 二叉树中 $x$ 的**左孩子**存在 $\iff$ 树中 $x$ 有孩子；
- 二叉树中 $x$ 的**右孩子**存在 $\iff$ 树中 $x$ 有兄弟（即 $x$ 不是其双亲的最后一个孩子；树的根无兄弟，故根的右链也为空，见本卷第 23 题）。

因此：

$$\underbrace{x\text{ 是树的叶}}_{\text{树中无孩子}}\iff \text{二叉树中 }x\text{ 无左孩子},\qquad \underbrace{x\text{ 是二叉树的叶}}_{\text{左右孩子皆空}}\iff \text{树中 }x\text{ 无孩子且无兄弟}$$

第二个条件严格强于第一个，故"二叉树的叶子"是"树的叶子"的一个子集，中间被剔除的正是"叶子但有兄弟"的结点。

**（2）反例。** 树 $T$：根 $A$ 有两个孩子 $B$、$C$（$B$、$C$ 均为叶子）。

```
树 T：            对应二叉树 B_T：
   A                   A
  / \                 /
 B   C               B
                      \
                       C
```

- 树 $T$ 的叶子：$B,C$，共 $2$ 个；
- 二叉树 $B_T$ 的叶子：只有 $C$（$B$ 有右孩子 $C$，$A$ 有左孩子 $B$），共 $1$ 个；
- $2\ne1$，命题"一定相等"被否证 ⇒ ×。

**（3）规模更大的反例（说明差距可以任意大）。** 根 $A$ 有 $m$ 个孩子 $B_1,\cdots,B_m$（都是叶子）：树叶子数 $=m$；二叉树是 $A\to B_1\to B_2\to\cdots\to B_m$ 的一条右链，叶子数 $=1$。差为 $m-1$，可任意大。

**（4）正确的对应关系。** 由 (1) 的等价式立得：

$$\text{树的叶子数}=\text{二叉树中"无左孩子"的结点数}$$

（上例中 $B,C$ 都无左孩子，计数 $2$，与树的叶子数一致 ✓；若树只有根一个结点，它既是树的叶，也是二叉树中唯一“无左孩子”的结点，仍一致。）

二者相等的充要条件：每个"无孩子的结点"都同时"无兄弟"，即

$$\text{树中每个不是其双亲最后一个孩子的结点都必须有自己的孩子}$$

（特例：树退化为一条链——每个内部结点只有一个孩子——时两边都只有 $1$ 个叶子，相等；单结点树也相等。命题说的是"一定"，故仍为假。）

**（5）转换真正保持的东西（避免连带误解）**：结点总数相同；树的**先根**遍历 $=$ 二叉树的**前序**遍历，树的**后根**遍历 $=$ 二叉树的**中序**遍历；树中结点 $x$ 的度 $=$ 二叉树中以 $x$ 的左孩子为起点、沿右链可到达的结点数。度数分布既然变了，“度为 $0$ 的结点数”自然不必不变。

**结论**：×。

## 7. 选项分析

不适用（判断题）。

## 8. 考场标准答案

×。

孩子兄弟表示法中，结点的左指针指向第一个孩子、右指针指向下一个兄弟，故"二叉树的叶子"对应"树中既无孩子又无兄弟的结点"，比"树的叶子（仅无孩子）"多一个条件。

反例：根 $A$ 有两个孩子 $B,C$。树的叶子为 $B,C$（$2$ 个）；二叉树为 $A$ 带左孩子 $B$、$B$ 带右孩子 $C$，叶子只有 $C$（$1$ 个）。$2\ne1$。

正确的对应是：树的叶子数 $=$ 二叉树中无左孩子的结点数。

## 9. 易错点

1. 想当然认为"转换是同构、一切统计量都不变"：转换保持的是**结点集合与遍历序列**，不保持度的分布；
2. 反例造错：若取"根只有一个孩子、孩子又只有一个孩子"的链状树，两种叶子数都恰为 $1$，会误判为 √——必须取"某个叶子有兄弟"的树（根至少两个子女）才能暴露差别；
3. 把"二叉树中无左孩子"误写成"二叉树叶子"（漏掉右孩子的检查），这正是本题两个概念的差；
4. 与本题相邻的 DS-2006-23（根无右子树）容易相互干扰：根的右链为空说的是**根**，与叶子计数无关。

## 10. 一句话规律

树/二叉树转换一律回到"左＝孩子、右＝兄弟"这一个模型逐项翻译：树的度 $\to$ 左孩子 $+$ 右链长度，树的叶 $\to$ 二叉树的"无左孩子"，二叉树的叶 $\to$ 树的"无孩子且无兄弟"。

## 11. 关联知识

- 同一规则下，**森林**转二叉树时第一棵树的根的右链挂着其余各树的根，因此森林的叶子总数 $=$ 二叉树中无左孩子的结点数（本卷第 23 题即"一棵树"时根右链为空的情形）；
- 树的先根/后根遍历与二叉树前序/中序的对应（DS03.03.03）是本题第（5）条结论的标准用法：给定树的后根序与结点数可反推二叉树形态；
- 反向转换（二叉树→树/森林）时，凡"沿右链下去"的结点都要归并为同一双亲的孩子，因此一棵二叉树可能对应一棵树，也可能对应一个森林（根的右链非空即森林）；
- 度与叶子计数的通用关系：树中 $n=n_0+\cdots$ 且总分支数 $=n-1$，与二叉树的 $n_0=n_2+1$ 不同型，比较两结构的叶子数时不可混用公式（本卷第 17 题用的是后者）。
