# DS-2006-19

## 1. 原题

完全二叉树的某结点若无左孩子，则它必是叶结点。（）

## 2. 答案

**√（正确）**——完全二叉树按层连续编号，"左孩子不存在"意味着编号已越过 $n$，右孩子的编号更大因而也不存在，故该结点度为 $0$，是叶结点。

## 3. 题目分析

- 已知：一棵**完全二叉树**（深度为 $k$、含 $n$ 个结点，其结点按层自上而下、自左而右连续编号后与同深度满二叉树编号 $1\sim n$ 的位置一一对应）；某结点无左孩子；
- 目标：判断该结点必为叶结点（度为 $0$）；
- 关键约束：完全性保证了"结点的存在性只由编号是否 $\le n$ 决定"，且左孩子编号 $2i$ 严格小于右孩子编号 $2i+1$；一般二叉树**不**满足此约束（可以存在"只有右孩子"的结点）；
- 命题意图：考完全二叉树的编号性质 $2i$ / $2i+1$（也是顺序存储下标映射的基础），并考"无左孩子"与"无右孩子"这两个条件的不对称性。

## 4. 核心考点

核心考点：
DS03.02.01 二叉树的定义及主要特征（完全二叉树：结点编号 $i$ 的左孩子为 $2i$、右孩子为 $2i+1$；$\lfloor n/2\rfloor+1\sim n$ 均为叶子）

辅助考点：
DS03.02.02 二叉树的存储结构（顺序存储正是靠上述编号关系用下标 $2i+1$、$2i+2$（自 $0$ 编号）定位孩子，"孩子不存在 $\iff$ 下标越界"即本题的判据来源）

解释：证明只用到"孩子编号是 $2i$、$2i+1$，越界即不存在"这一条完全二叉树性质，它同时是顺序存储的地址公式，故以性质为主、存储结构为辅。

## 5. 解题思路

1. 把"无左孩子"翻译成不等式：编号 $i$ 的左孩子编号为 $2i$，不存在 $\iff 2i>n$；
2. 由 $2i>n$ 立即得 $2i+1>2i>n$，故右孩子也不存在；
3. 左、右孩子皆无 $\Rightarrow$ 度为 $0$ $\Rightarrow$ 是叶结点；
4. 用 $n=6$（含"有左无右"结点的情形）与 $n=7$ 两棵树穷举所有结点验证，并构造一般二叉树的反例说明"完全"二字不可去掉。

## 6. 详细解答

**证明（编号法）。** 设完全二叉树有 $n$ 个结点，按层自左至右编号 $1,2,\cdots,n$。由完全二叉树的定义，结点 $i$ 的

- 左孩子存在 $\iff 2i\le n$；
- 右孩子存在 $\iff 2i+1\le n$。

题设"无左孩子"，即 $2i>n$。因为 $2i+1>2i$，所以 $2i+1>n$，右孩子亦不存在。左右孩子均无 $\Rightarrow$ 结点 $i$ 的度为 $0$ $\Rightarrow$ $i$ 是叶结点。∎

等价结论：无左孩子的结点集合为 $i>\lfloor n/2\rfloor$，即编号 $\lfloor n/2\rfloor+1,\cdots,n$ 的结点，它们**全部**是叶子；反之编号 $\le\lfloor n/2\rfloor$ 的结点必有左孩子（是分支结点）。这也给出完全二叉树叶子数 $n-\lfloor n/2\rfloor=\lceil n/2\rceil$（本卷第 26 题即其数值应用）。

**实例穷举（$n=6$）**

```
        1
      /   \
     2     3
    / \   /
   4   5 6
```

| 编号 | 左孩子 | 右孩子 | 是否叶 |
|---|---|---|---|
| 1 | 2 ✓ | 3 ✓ | 否 |
| 2 | 4 ✓ | 5 ✓ | 否 |
| 3 | 6 ✓ | 无（$2\cdot3+1=7>6$） | 否 |
| 4,5,6 | 无（$8,10,12>6$） | 无 | 是 |

"无左孩子"的结点是 4、5、6，全是叶子 ✓；结点 3 恰好演示了**逆命题不成立**的情形——"无右孩子"并不必然是叶子（3 有左孩子 6）。

**实例穷举（$n=7$，满二叉树）**：编号 1,2,3 都有左、右孩子；4~7 无左孩子且都是叶子 ✓。

**"完全"这一前提不可去掉。** 若只要求是一般二叉树，下述树的根只有右孩子：

```
    1
     \
      2
```

结点 $1$ 无左孩子却是分支结点，命题为假。完全性排除了这种"跳过左位先填右位"的形态——按定义，结点只能从左到右依次填充，右孩子出现之前左孩子必须已存在。

**结论**：√。

## 7. 选项分析

不适用（判断题）。

## 8. 考场标准答案

√。

完全二叉树中编号 $i$ 的结点，左孩子为 $2i$、右孩子为 $2i+1$（不超过 $n$ 才存在）。若左孩子不存在，则 $2i>n$，从而 $2i+1>n$，右孩子也不存在，该结点度为 $0$，必为叶结点。等价地：编号 $\lfloor n/2\rfloor+1\sim n$ 的结点全是叶子。

（注意区分：无**右**孩子不一定是叶子，如 $n=6$ 时结点 $3$ 有左孩子 $6$ 而无右孩子。）

## 9. 易错点

1. 把"无左孩子"与"无右孩子"混为一谈：只有"无左孩子 $\Rightarrow$ 无右孩子"这一个方向在完全二叉树中成立，反之不成立（$n$ 为偶数时编号 $n/2$ 的结点是有左无右的分支结点）；
2. 忘记"完全"这一前提，用一般二叉树"只有右孩子的结点"作例子时误判为 ×——命题正是靠完全性才成立；
3. 与顺序存储下标口径混淆：若下标从 $0$ 开始，孩子为 $2i+1$、$2i+2$，判据变成"$2i+1\ge n$"，结论相同但公式不同（本卷第 3、28 题都用 $0$ 起始编号，第 26、28 题需注意口径统一）。

## 10. 一句话规律

完全二叉树里"孩子存在性"就是"编号 $\le n$"的不等式问题：左孩子编号小、右孩子编号大，所以**左不存在必推出右不存在**，凡"缺左"的结点一定是叶子。

## 11. 关联知识

- 由本题立即得到完全二叉树的叶子数 $=\lceil n/2\rceil$、分支结点数 $=\lfloor n/2\rfloor$（本卷第 26 题 $n=100$ 时为 $50$）；
- 本题的 $2i/2i+1$ 关系是 DS03.02.02 顺序存储与 DS06.07 堆（以数组存储的完全二叉树）全部下标运算的基础：堆中"无左孩子 $\iff$ 已是最后一层"同样意味着该位置是叶子；
- 编号最小的叶子是 $\lfloor n/2\rfloor+1$（$1$ 起始编号）；本卷第 28 题改用 $0$ 起始编号，同一结点的位置变为 $\lfloor n/2\rfloor$（即 $\lceil (n-1)/2\rceil$），与本题结论同源；
- 对照命题"完全二叉树的某结点若无右孩子，则它必是叶结点"为 ×，反例即 $n=6$ 的结点 $3$。
