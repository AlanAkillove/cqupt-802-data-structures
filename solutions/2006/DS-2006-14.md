# DS-2006-14

## 1. 原题

在理想情况下，散列表中查找元素所需的比较次数为（）。

A. $n$

B. $0$

C. $\frac{n}{2}$

D. $1$

## 2. 答案

**D**（$1$ 次）。

## 3. 题目分析

- 已知：查找对象是**散列表**（哈希表），其查找过程为"用散列函数把关键字映射为地址 → 到该地址探查 → 冲突则按冲突解决方法继续探查"；题设条件为"**理想情况**"，即散列函数完美、不发生冲突（等价于装填因子 $\alpha=n/m\to 0$）；
- 目标：该条件下查找一个元素所需的**关键字比较次数**；
- 关键约束：散列查找的代价与表长 $n$ **无关**，只与"平均探查几个槽、每槽比较几次"有关；
- 命题意图：考散列方法"按地址直接访问"的本质优势——查找长度是 $O(1)$，理想情况下 $O(1)$ 的常数恰为 $1$；同时用选项 A、C（顺序查找的 $n$ 与 $\approx n/2$）与 B（把"直接地址计算"误解为"不用比较"）设干扰。

## 4. 核心考点

核心考点：
DS05.06.02 散列表构造与 ASL 计算（"理想情况"即无冲突，成功查找的探查次数为 1，$ASL_{succ}=1$）

辅助考点：
DS05.06.01 散列函数与冲突处理方法（无冲突时不需要任何探查序列，这正是"理想"的含义）
DS05.01 查找的基本概念（平均查找长度 ASL 以"关键字比较次数"为度量单位，而非"地址计算次数"）

解释：本题不在问某个具体散列表的 ASL 数值，而是问散列查找这一方法的**理论下界**，属于散列表性能（ASL 口径）的概念层结论；又因"比较次数"的度量口径决定了能否排除 B，故列 DS05.01 为辅助。

## 5. 解题思路

1. 把散列查找拆成两步：① 计算 $H(k)$ 得到地址（**不做关键字比较**）；② 把该地址中记录的关键字与 $k$ 比较（**至少 1 次**）；
2. "理想情况"意味着第 ① 步算出的地址就是目标所在槽，探查序列长度 $=1$，故总比较次数 $=1$；
3. 用 ASL 公式复核：线性探测 $ASL_{succ}=\frac12\left(1+\frac{1}{1-\alpha}\right)$、链地址 $ASL_{succ}\approx 1+\frac{\alpha}{2}$，令 $\alpha\to 0$（无冲突）都趋于 $1$；
4. 检查量级：结果不含 $n$，凡带 $n$ 的选项必为其他查找方法（顺序查找）的结论。

## 6. 详细解答

**逐步计数法。** 散列表上查找关键字 $k$ 的标准过程：

```c
/* 散列查找（教材风格骨架，冲突处理以线性探查为例） */
int HashSearch(HashTable HT, KeyType k)
{
    int h = H(k) % m;          /* ① 计算散列地址：只做算术运算，不比较关键字 */
    while (HT.elem[h].key != NULLKEY && HT.elem[h].key != k)  /* ② 每探查一个槽比较一次 */
        h = (h + 1) % m;
    return (HT.elem[h].key != NULLKEY) ? h : -1;   /* -1 表示查找失败 */
}
```

- 理想情况定义为"不发生冲突"，即 $k$ 的散列地址 $h$ 处若非空则必是 $k$ 本身；
- 于是第 ② 步只需比较**一次**：命中即结束（若该槽为空，则判定查找失败，其"探查/比较"次数同样为 $1$）；
- 第 ① 步的取模运算不计入"比较次数"。

故 $ASL_{succ}=1$，与记录数 $n$、地址数 $m$ 均无关，选 D。

**公式极限法（交叉验证）。** 记装填因子 $\alpha=\dfrac{\text{表中记录数 }n}{\text{散列地址总数 }m}$。教材给出的两种典型冲突处理方法在**查找成功**时的平均探查次数近似式：

| 冲突处理方法 | $ASL_{succ}$（近似式） |
|---|---|
| 线性探查法 | $\frac12\left(1+\frac{1}{1-\alpha}\right)$ |
| 链地址法 | $1+\frac{\alpha}{2}$ |

理想情况即"无冲突"，对应 $\alpha\to 0$（或散列函数完美）：

$$\lim_{\alpha\to 0}\frac12\left(1+\frac{1}{1-\alpha}\right)=\frac12(1+1)=1,\qquad \lim_{\alpha\to 0}\left(1+\frac{\alpha}{2}\right)=1$$

两条公式在理想情形都收敛到 $1$，与逐步计数法一致 ✓。

**为何不是 0（选项 B）**：散列函数只能给出"候选地址"，地址本身不携带"这里就是我要找的关键字"这一信息；要确认命中必须把槽中关键字与给定值比较（哪怕只是"槽是否为空"的判断，也算一次探查）。$0$ 次比较意味着不需要任何信息即可判定存在性，这已超出"关键字比较次数"这一度量口径。

**为何与 $n$ 无关（选项 A、C）**：$n$ 与 $\frac{n}{2}$ 分别是顺序查找在**最坏**与**平均**（$\frac{n+1}{2}\approx\frac n2$）时的比较次数。散列方法的意义正是摆脱"比较次数随 $n$ 增长"，若答案含 $n$ 就退化为顺序查找了。

## 7. 选项分析

- A. $n$：错误。顺序查找最坏情形的比较次数，散列查找即使在冲突严重时也远小于此（冲突成一条链时才退化到 $O(n)$，那正是"最不理想"而非"理想"）；
- B. $0$：错误。把"按地址直接访问"误解为"不需要比较"；地址计算不算比较，但确认命中必须比较一次；
- C. $\frac{n}{2}$：错误。顺序查找（等概率成功）的平均比较次数 $\frac{n+1}{2}$ 的近似值，属另一类查找方法；
- D. $1$：正确。无冲突时一次探查、一次比较即得结论，$ASL=1$，这也是散列查找的理论下界。

## 8. 考场标准答案

散列查找分"计算地址"与"关键字比较"两步，前者不计比较次数。理想情况 $=$ 散列函数无冲突（$\alpha\to0$），给定关键字 $k$ 经 $H(k)$ 直接落到其所在槽，只需与该槽关键字比较 $1$ 次即可判定成功。

$$ASL_{succ}=1\ (\text{与 }n\text{ 无关})\ \Rightarrow\ \text{选 D}$$

（注：$n$、$\frac n2$ 是顺序查找的最坏/平均比较次数，不要迁移到散列。）

## 9. 易错点

1. 选 B：混淆"直接地址访问"与"零次比较"——判定"命中/未命中"至少需一次关键字比较；
2. 选 A/C：把顺序查找、折半查找的结论套到散列上；散列的 ASL 只与 $\alpha$ 有关、与 $n$ 无直接关系；
3. 忽视"理想情况"的限定：真实散列表 $\alpha>0$ 时 $ASL>1$（如本卷第 40 题的线性探查实例，成功查找平均比较次数明显大于 1），"1"是下界而非常态。

## 10. 一句话规律

散列查找的比较次数一律按"**探查了几个槽**"来数：理想（无冲突）为 $1$，冲突越密（$\alpha$ 越大）越长；凡是含 $n$ 的答案，说明已经退化成了顺序查找。

## 11. 关联知识

- 散列查找的性能三要素：散列函数、处理冲突的方法、装填因子 $\alpha$（本库 DS-2006-40 为该知识点的具体构造与 ASL 计算题）；
- 冲突处理的四种常用方法（线性探查、二次探查、再散列、链地址）在 $\alpha$ 相同情况下 $ASL$ 不同，其中链地址法对 $\alpha$ 增长最不敏感；
- 等概率下顺序查找成功 $ASL=\frac{n+1}{2}$、折半查找成功 $ASL\approx\log_2(n+1)-1$（本卷第 30 题考折半查找的比较序列），可与之对照记忆"三种查找的增长趋势"。
