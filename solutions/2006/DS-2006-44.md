# DS-2006-44

## 1. 原题

定义二叉树中两个结点之间的最小距离为：这两个结点的最近公共祖先结点分别到这两个结点的路径的长度之和。请设计一个算法，找出给定二叉树中任意两个结点之间的最小距离。

> 订正说明转录：源文作"到这两个路径的长度之和"，据题意补"结点"二字。

## 2. 答案

**算法 = 求最近公共祖先（LCA）+ 从 LCA 向下量两段路径长度**：

1. `w = LowestCommonAncestor(root, p, q)`：后序式递归，若 $p$、$q$ 分居某结点左右两侧，该结点即最近公共祖先；
2. `dp = DownPathLen(w, p)`、`dq = DownPathLen(w, q)`：从 $w$ 向下到目标结点的路径长度（以**边数**计）；
3. 最小距离 $= d_p+d_q$；两结点不相同时至少为 $1$，$p$ 为 $q$ 的祖先时退化为 $d_q$，$p=q$ 时为 $0$。

时间 $O(n)$，空间 $O(h)$（$n$ 为结点数，$h$ 为树高，$h\le n$）。代码见第 6、8 节。

**口径声明（两处）**：

- **路径长度按边数计**（根到自身为 $0$）。若按"路径上的结点数"计，所有结果整体 $+1$，算法不变；
- **"任意两个结点"理解为"（由调用者）任取的两个给定结点"**，即算法的输入是树与这两个结点（关键字或指针），输出它们之间的最小距离——这是题面定义（"这两个结点的最近公共祖先"）所预设的读法。若按字面改读成"全树所有结点对中距离最小者"，则只要 $n\ge2$ 答案恒为"某条边的两端"，即恒为 $1$（边数口径），无需算法；该理解不构成一道算法设计题，故不采用（见第 12 节）。

## 3. 题目分析

- 输入：二叉树 `root`（二叉链表存储）与树中两个结点 $p$、$q$（本实现以关键字 `ElemType` 标识，假设关键字唯一；若给定指针，把 `rt->data == p` 换成 `rt == p` 即可）；
- 输出：按题面定义的最小距离（整数）；结点不存在时返回 $-1$ 表示失败；
- 数据结构选择：二叉链表（无父指针）→ 不能"从结点上溯"，只能"自根下行"，所以必须用**递归回溯**来定位最近公共祖先；
- 核心不变量：`LowestCommonAncestor(rt, p, q)` 返回非空 $w$ 时，$w$ 是"子树 $rt$ 中包含 $p$、$q$ 两结点的最深结点"；若 $p$、$q$ 有一个不在 $rt$ 中，则返回的是"存在的那个结点"（故主函数还要用第二次下行查找来确认两结点都在）；
- 边界情况：空树；$p=q$；$p$、$q$ 之一是另一者的祖先；两结点在同一子树内（祖先链上）；只有一个结点存在于树中；关键字重复（本实现假设无重复）；
- 命题意图：考**递归遍历的综合应用**——把"最近公共祖先"这一结构概念翻译成"左右子树各含一个目标结点的最深结点"，再用两次下行得到路径长度。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（递归遍历的"自底向上"信息回传；本题用后序式：先查左右子树，再决定当前结点是否为 LCA）

辅助考点：
DS03.01 树的基本概念（路径、路径长度、祖先/最近公共祖先的定义——题面定义式 $d(p,q)=d(w,p)+d(w,q)$ 本身即 DS03.01 的语言）；DS03.02.02 二叉树的存储结构（二叉链表中只有 `lchild`/`rchild` 下行之链，无父结点指针，决定了必须从根出发）

解释：算法的两个子过程都是"对二叉树做一次递归遍历"，区别只在回传的信息（结点指针 / 路径长度），故主考点为遍历；而"距离 = 两路径长度之和"的定义与祖先概念属 DS03.01。

## 5. 解题思路

1. 先翻译题面定义：距离 $=d(w,p)+d(w,q)$，$w$ 为最近公共祖先 → 问题拆成**两块独立可解的子问题**：求 $w$、求两段下行长度；
2. 求 $w$ 的关键观察：在二叉树中，$p$、$q$ 的最近公共祖先恰是"**左、右子树中各含有 $p$、$q$ 中一个**"的那个最深结点；若两者同在某子树中，则答案在那个子树里（或当前结点本身就是其中之一）；
3. 这一观察天然是**后序递归**：先问左子树、再问右子树，两边都"找到"（返回非空）时当前结点即为 $w$，否则把非空的那一侧上抛；
4. 下行长度用一次普通递归：`s->data == x` 返回 $0$，否则返回子树结果 $+1$，找不到返回 $-1$；
5. 处理"只有一个结点存在"的陷阱：此时第 3 步会把那个存在的结点误当 $w$ 抛出，故主函数必须再用第 4 步分别确认 $d_p,d_q$ 都 $\ge 0$，否则判失败；
6. 用四类情形（跨侧、同侧、祖先关系、同一结点）各造一棵小树走查。

## 6. 详细解答

### 存储结构（教材风格）

```c
typedef struct BTNode {
    ElemType data;                    /* 结点标识，假设全树互不相同 */
    struct BTNode *lchild, *rchild;
} BTNode, *BTree;
```

### (1) 最近公共祖先

```c
BTree LowestCommonAncestor(BTree rt, ElemType p, ElemType q)
/* 返回子树 rt 中 p、q 的最近公共祖先；若两者均不在 rt 中返回 NULL；
   若仅有一个在 rt 中，返回那个结点本身（由调用方通过 (2) 复核）。      */
{
    if (rt == NULL) return NULL;
    if (rt->data == p || rt->data == q) return rt;   /* rt 恰为其一，它已是能保证的最深祖先 */

    BTree L = LowestCommonAncestor(rt->lchild, p, q);
    BTree R = LowestCommonAncestor(rt->rchild, p, q);

    if (L != NULL && R != NULL) return rt;           /* p、q 分居两侧：rt 即最近公共祖先 */
    return (L != NULL) ? L : R;                      /* 同侧：把子树的结果原样上抛 */
}
```

### (2) 自某结点向下的路径长度

```c
int DownPathLen(BTree s, ElemType x)
/* 返回从结点 s 到值为 x 的结点的路径长度（边数）；x 不在该子树中返回 -1 */
{
    if (s == NULL) return -1;
    if (s->data == x) return 0;                      /* 终点就是自身，长度 0 */

    int d = DownPathLen(s->lchild, x);
    if (d >= 0) return d + 1;                        /* 在左子树中找到，加一条边 */
    d = DownPathLen(s->rchild, x);
    if (d >= 0) return d + 1;                        /* 在右子树中找到 */
    return -1;                                       /* 左右都没有 */
}
```

### (3) 主算法

```c
int MinDistance(BTree root, ElemType p, ElemType q)
/* 按题面定义求二叉树 root 中结点 p 与 q 之间的最小距离；
   树空或 p、q 不全在树中时返回 -1。 */
{
    BTree w  = LowestCommonAncestor(root, p, q);
    if (w == NULL) return -1;                        /* 两结点都不在树中 */

    int dp = DownPathLen(w, p);
    int dq = DownPathLen(w, q);
    if (dp < 0 || dq < 0) return -1;                 /* 只有一个在树中：判失败 */

    return dp + dq;                                  /* p == q 时 dp = dq = 0，距离 0 */
}
```

### 正确性说明

- **`LowestCommonAncestor` 的正确性**按结点的三种位置关系分类讨论：
  ① $p$、$q$ 分别在 $rt$ 的左、右子树中 $\Rightarrow$ 任何公共祖先都必须是 $rt$ 或其祖先，而 $rt$ 自身是公共祖先，故 $rt$ 即**最近**公共祖先，代码由 `L && R` 命中；
  ② 两者同在左（右）子树中 $\Rightarrow$ 最近公共祖先也在该子树内，代码把子递归结果原样上抛，正确；
  ③ 其中之一就是 $rt$（如 $p=rt$）$\Rightarrow$ $p$、$q$ 的最近公共祖先就是 $p$，代码在第二行直接返回 $rt$，正确（此时不必再进子树，且提前返回不影响 ①② 的判定：若 $rt$ 是其一，它必是答案）；
  ④ 两者都不在 $rt$ 中 $\Rightarrow$ 左右子树递归均返回 `NULL`，整体 `NULL`。四类穷尽，故除"仅有一个在树中"这一被主函数复核掉的情形外，返回值正确。
- **`DownPathLen` 的正确性**：二叉树中根到结点的路径唯一，递归取"子树结果 $+1$"即路径的边数；找不到返回 $-1$ 作失败标记。
- 由题面定义 $d(p,q)=d(w,p)+d(w,q)$，主函数即定义的直接实现。

### 手工走查

```
            A
         /     \
        B       C
       / \     / \
      D   E   F   G
         / \
        H   I
```

| $p,q$ | 最近公共祖先 $w$ | $d_p$ | $d_q$ | 最小距离 | 说明 |
|---|---|---|---|---|---|
| $H, I$ | $E$ | 1 | 1 | **2** | 情形①（分居 $E$ 两侧） |
| $D, I$ | $B$ | 1 | 2 | **3** | 情形①（$D$ 在左、$I$ 在右） |
| $B, H$ | $B$ | 0 | 2 | **2** | 情形③（其一即祖先） |
| $D, F$ | $A$ | 2 | 2 | **4** | 跨最大分支 |
| $E, E$ | $E$ | 0 | 0 | **0** | 同一结点 |
| $H, Z$（$Z$ 不在树中） | 返回 $H$ | 0 | $-1$ | **$-1$** | 复核后判失败 |

再取一棵极简树核对：`1(2(4,5),3(_,6))`（结点 $3$ 只有右孩子 $6$）：$d(4,5)=2$、$d(4,6)=4$、$d(2,4)=1$、$d(1,6)=2$，与"逐条数边"结果一致 ✓。

### 复杂度分析

设 $n$ 为二叉树的**结点数**，$h$ 为树高（$h\le n$，完全二叉树时 $h=\lfloor\log_2 n\rfloor+1$，链状退化时 $h=n$）。

- `LowestCommonAncestor`：最坏需访问每个结点一次（$p$、$q$ 都在最深处时遍历全树），$O(n)$；
- 两次 `DownPathLen`：各自从 $w$ 出发至多访问 $w$ 的子树，合计 $O(n)$；
- **总时间 $O(n)$**；这也是下界——不访问结点无法确认其存在性；
- **空间 $O(h)$**：三条递归链的栈深之和为常数倍树高，最坏 $O(n)$（单支树）；未使用任何附加数据结构（若需多次查询，可预先把"结点 $\to$ 根路径"存入数组，把单次查询降为 $O(h)$，属空间换时间）。

### 变体

1. **一趟递归求完**：自底向上同时回传"本子树中含 $p$/$q$ 的个数"与"最深匹配结点"，并在全局变量里累加深度差，可把三类调用合并为一次遍历（同为 $O(n)$，考场写上面三段式更清晰）；
2. **用根到结点的路径长度**：记 $\deg(x)$ 为根到 $x$ 的边数，则 $d(p,q)=\deg(p)+\deg(q)-2\deg(w)$。先一次 DFS 记录 $p$、$q$ 的深度与祖先链，再取两链最后一个公共元素为 $w$，适合"已给定结点指针且要多次查询"的情形；
3. **若题意限定"两个叶子结点之间的最小距离"**（另一常见命题口径）：改为一次递归，对每个结点用 $g(u)=\min\{g(l),g(r)\}+1$ 维护"到最近叶子的距离"，并在左右子树都含叶子时用 $g(l)+g(r)+2$ 更新全局最小值，同样 $O(n)$ 时间、$O(h)$ 空间。

## 8. 考场标准答案

**(1) 设计思想**：按题面定义，距离 = 最近公共祖先 $w$ 到两结点的路径长度之和。① 用后序递归求 $w$——若当前结点就是 $p$ 或 $q$ 则返回自身；否则递归左右子树，左右**均返回非空**说明两结点分居两侧，当前结点即 $w$，否则把非空一侧的结果上抛。② 从 $w$ 出发用两次递归分别求到 $p$、$q$ 的边数 $d_p$、$d_q$（找不到返回 $-1$，用于识别"结点不在树中"）。③ 返回 $d_p+d_q$。

**(2) 代码**：见第 6 节 (1)(2)(3) 三段（`LowestCommonAncestor`、`DownPathLen`、`MinDistance`）。

**(3) 复杂度**：$n$ 为结点数、$h$ 为树高。时间 $O(n)$（一次求 LCA + 两次下行，各至多访问全树一次）；空间 $O(h)$ 递归栈，最坏 $O(n)$。路径长度按边数计，故同一结点距离为 $0$、父子结点距离为 $1$。

## 9. 易错点

1. 求 LCA 时写成"先递归左右再看当前结点是否等于 $p/q$"，顺序颠倒会让情形③（其一即祖先）返回错误的更深结点——必须**先判当前结点**，命中即返回；
2. 忘记"只有一个结点在树中"时 `LowestCommonAncestor` 会返回那个存在的结点，若不复核 $d_p,d_q$ 就会给出错误距离（如 $d(p,\text{不存在})=d_p+(-1)$）；
3. 路径长度口径不统一：一边按边数、一边按结点数，结果差 $1$ 或 $2$；答题开头应写明"路径长度取边数"；
4. 二叉链表**没有父指针**，不能"从结点上溯"，凡写"沿双亲走到祖先"的做法都需先说明如何得到父链（或改用递归下行）；
5. 误以为要"枚举所有结点对取最小"（$O(n^2)$ 甚至 $O(n^3)$）——题面的"任意两个"是"任取给定"，不是"遍历求全局最小"；
6. 假设关键字唯一却不做重复处理：树中存在同关键字结点时按值查找会命中第一个，结果依赖结点位置，应先声明"关键字互异"。

## 10. 一句话规律

二叉树上"两点距离"题的固定套路：**后序递归求最近公共祖先（左右都非空即当前结点）+ 自祖先下行数边数**，答案 $=d_p+d_q$；同一公式改写成 $\deg(p)+\deg(q)-2\deg(w)$ 就是"根到结点距离"版本。
