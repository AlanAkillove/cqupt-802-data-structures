# DS-2006-07

## 1. 原题

一棵前序序列为 $1,2,3,4$ 的二叉树，其中序序列不可能是（）。

A. $4,1,2,3$

B. $4,3,2,1$

C. $2,4,3,1$

D. $3,4,2,1$

## 2. 答案

**A**（$4,1,2,3$ 不可能是中序序列）。

## 3. 题目分析

- 已知：二叉树有 $4$ 个结点，其**前序**序列固定为 $1,2,3,4$（即结点标号就是前序访问次序）；
- 目标：在四个候选**中序**序列中找出与任何二叉树形态都不兼容的那一个；
- 关键约束：前序首元素必为根；根在中序序列中的位置把序列切成"左子树结点集 | 根 | 右子树结点集"，而左子树结点必须正好占用前序中紧跟根的那一段（**连续前缀**）；
- 命题意图：考"由前序 + 中序唯一确定二叉树"这一重建过程的**相容性判定**——不是套结论，而是逐步重建看是否出现矛盾。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（由序列确定二叉树、两种遍历序列的相容条件）

辅助考点：
DS03.02.03.01 前序遍历（根最先、左子树整体先于右子树）
DS03.02.03.02 中序遍历（左—根—右的三段结构）

解释：本题的判据完全来自前序"子树结点在序列中占据连续段"与中序"左|根|右三段"这两条定义性质，属遍历互推的标准用法。

## 5. 解题思路

1. 定根：前序 $1,2,3,4$ ⇒ 根为 $1$；
2. **前缀判据**：设中序中 $1$ 左边有 $k$ 个元素，则这 $k$ 个元素构成的左子树在**前序**中必须占据 $1$ 之后的前 $k$ 个位置，即必须等于集合 $\{2,3,\dots,k+1\}$（右子树相应地是 $\{k+2,\dots,4\}$）；
3. 用该判据快速筛查四个选项，再对通过筛查的选项**递归**做同样的检查并真正画出树，确认可行；
4. 交叉验证：非递归中序遍历中，结点"进栈次序 = 前序、出栈（访问）次序 = 中序"，故候选中序必须是 $1,2,3,4$ 的合法出栈序列。

## 6. 详细解答

### 第一步：根的分段检查

| 选项 | 中序序列 | $1$ 左边元素 | $k$ | 左子树应占前序段 | 判定 |
|---|---|---|---|---|---|
| A | $4,1,2,3$ | $\{4\}$ | 1 | 应为 $\{2\}$ | ✗ 出现 $4$，矛盾 |
| B | $4,3,2,1$ | $\{4,3,2\}$ | 3 | 应为 $\{2,3,4\}$ | ✓ 继续 |
| C | $2,4,3,1$ | $\{2,4,3\}$ | 3 | 应为 $\{2,3,4\}$ | ✓ 继续 |
| D | $3,4,2,1$ | $\{3,4,2\}$ | 3 | 应为 $\{2,3,4\}$ | ✓ 继续 |

A 中根 $1$ 的左子树只含 $1$ 个结点，那这个结点在前序中必紧跟 $1$，即标号应为 $2$；但中序却要求它是 $4$——同一位置不可能既是 $2$ 又是 $4$，故 **A 不可能**。

### 第二步：为 B、C、D 构造出真实的树（证明确实可能）

**B：中序 $4,3,2,1$**
$1$ 的左子树 $=\{2,3,4\}$，前序段 $2,3,4$，根 $2$；中序中 $2$ 在末尾 ⇒ $2$ 无右子树，左子树 $\{3,4\}$，前序段 $3,4$，根 $3$；中序 $4,3$ ⇒ $4$ 是 $3$ 的左孩子。

```
   1        （B：全部挂在左链）
  /
 2
/
3
/
4
```
前序 $1,2,3,4$ ✓；中序（最左先）$4,3,2,1$ ✓。

**C：中序 $2,4,3,1$**
$1$ 的左子树 $\{2,3,4\}$，前序段 $2,3,4$ ⇒ 根 $2$；中序中 $2$ 在最前 ⇒ $2$ 无左孩子，右子树 $\{4,3\}$，前序段 $3,4$ ⇒ 根 $3$；中序 $4,3$ ⇒ $4$ 为 $3$ 的左孩子。

```
1
 \
  2
   \
    3
   /
  4
```
前序 $1,2,3,4$ ✓；中序 $2,4,3,1$ ✓。

**D：中序 $3,4,2,1$**
$1$ 的左子树 $\{2,3,4\}$，根 $2$；中序中 $2$ 右边无元素 ⇒ $2$ 无右孩子，左子树 $\{3,4\}$，前序段 $3,4$ ⇒ 根 $3$；中序 $3,4$ ⇒ $4$ 为 $3$ 的右孩子。

```
    1
   /
  2
 /
3
 \
  4
```
前序 $1,2,3,4$ ✓；中序 $3,4,2,1$ ✓。

### 第三步：栈序列交叉验证

非递归中序遍历的实现是"沿左链依次进栈（进栈次序即前序 $1,2,3,4$），弹栈时访问（弹栈次序即中序）"，因此合法候选必是 $1,2,3,4$ 的某个出栈序列：

- B $4,3,2,1$：push 1,2,3,4 → pop 4,3,2,1 ✓
- C $2,4,3,1$：push 1,2 → pop 2；push 3,4 → pop 4,3,1 ✓
- D $3,4,2,1$：push 1,2,3 → pop 3；push 4 → pop 4,2,1 ✓
- A $4,1,2,3$：要先输出 $4$ 必须把 $1,2,3,4$ 全部进栈，此时栈顶是 $3$，第二个输出只能是 $3$，绝不可能是 $1$ ✗

两种方法结论一致：不可能的只有 A。

## 7. 选项分析

- A. $4,1,2,3$：**不可能**。根 $1$ 前只有 $1$ 个元素，说明左子树只有 $1$ 个结点，该结点按前序必为 $2$，与中序要求的 $4$ 冲突（栈观点：$4$ 先出栈则 $3$ 必紧随其后）；
- B. $4,3,2,1$：可能。全部结点依次挂左孩子的单支树；
- C. $2,4,3,1$：可能。$1\to$ 左 $2\to$ 右 $3\to$ 左 $4$；
- D. $3,4,2,1$：可能。$1\to$ 左 $2\to$ 左 $3\to$ 右 $4$。

## 8. 考场标准答案

前序为 $1,2,3,4$ ⇒ 根为 $1$，且 $1$ 的左子树结点集必是前序的一个**连续前缀** $\{2,\dots,k+1\}$（$k$ 为中序中 $1$ 左侧元素个数）。

- A：中序 $4,1,2,3$ 中 $1$ 左侧是 $\{4\}$，$k=1$ 却要求该结点为 $2$，矛盾 ⇒ 不可能；
- B、C、D：$1$ 左侧均为 $\{2,3,4\}$，递归重建分别得（$1$ 左 $2$，$2$ 左 $3$，$3$ 左 $4$）、（$1$ 左 $2$，$2$ 右 $3$，$3$ 左 $4$）、（$1$ 左 $2$，$2$ 左 $3$，$3$ 右 $4$），三者前序都是 $1,2,3,4$ ⇒ 均可能。

答案选 **A**。

## 9. 易错点

1. 误用"中序与出栈序列无关"的直觉，逐个瞎猜形态；正确做法是先看**根把序列切成哪两段**，再看这两段的元素集合是否与前序的分段一致；
2. 只在根一层做检查会漏判：例如若候选为 $1,3,4,2$，根层（$1$ 左侧为空，$k=0$）自动通过，必须再对右子树 $\{2,3,4\}$ 递归一层（根 $2$、其左侧 $\{3,4\}$ 恰为前序段 $3,4$ ✓）、再下一层（根 $3$、右侧 $4$ ✓）才能确认它可行（对应树：$1\to$ 右 $2\to$ 左 $3\to$ 右 $4$）。本题除 A 在首层即矛盾外，其余三项只需再递归一层，但方法上必须递推到空子树为止；
3. 忘了“形态不唯一”：仅有前序时 $4$ 个结点对应 $14$ 种形态（卡特兰数），不能只抽一种典型形态拍脑袋，必须按相容性逐选项判定。

## 10. 一句话规律

"给一序、判另一序可能否"的题，用**根定位 + 集合分段**法：根在中序中的位置决定左子树元素个数 $k$，而左子树元素必须恰好是前序中紧跟根的 $k$ 个，逐层递归，矛盾即不可能。

## 11. 关联知识

- 前序 + 中序（或后序 + 中序、层次 + 中序）可唯一确定一棵二叉树；前序 + 后序不能；
- $n$ 个结点的二叉树形态数为卡特兰数 $C_n=\frac{1}{n+1}\binom{2n}{n}$，$n=4$ 时为 $14$，与"前序固定时可能中序序列的个数"一致（本方法可推广：两者构成双射）；
- 非递归中序遍历的进栈/弹栈次序对应关系，也是 DS02.01 中"合法出栈序列判定"（卡特兰数同源）在树上的体现。
