# DS-2006-24

## 1. 原题

任何有向图的结点都可以排成拓扑排序，而且拓扑序列不唯一。（）

## 2. 答案

**×（错误）**——题干两个断言都不成立：① 只有**有向无环图**（AOV 网）才存在拓扑序列，含环的有向图一个也排不出；② 拓扑序列也可能唯一（如各顶点被弧串成一条链时）。

## 3. 题目分析

- 已知：拓扑序列的定义——有向图 $G=(V,A)$ 的顶点序列 $v_1,v_2,\cdots,v_n$，若 $\langle v_i,v_j\rangle\in A$ 则 $i<j$（每条弧的起点排在终点之前）；
- 目标：判断"任何有向图都有拓扑序列"与"拓扑序列不唯一"这两个全称断言；
- 关键约束：这是一个由"而且"连接的**联言命题**，两支中任一支为假整个命题即为假；此处两支皆为假；
- 命题意图：考拓扑排序的存在条件（无环）与唯一性条件（每步可选的零入度顶点是否唯一），这也是教材用拓扑排序"检测有向图是否有环"的两个基本结论。

## 4. 核心考点

核心考点：
DS04.04.03 拓扑排序（AOV 网、拓扑序存在性 $\iff$ 无环、拓扑排序算法每轮取入度为 $0$ 的顶点、由输出个数 $<n$ 判环）

辅助考点：
DS04.01 图的基本概念（有向图、弧、路径与环、强连通——"环上顶点互相制约"这一矛盾的来源）

解释：前半句需要"环"的概念来说明矛盾，后半句需要构造具体的弧关系来讨论解的个数，均属图的基本概念与拓扑排序定义的直接结合。

## 5. 解题思路

1. 把命题拆成两支，分别尝试否证；
2. 前半句：造一个最小的有向环 $a\to b\to c\to a$，穷举 $3!=6$ 种排列，说明每种都违反至少一条弧 ⇒ 存在拓扑序列要求"无环"；
3. 用算法视角复核：拓扑排序每轮必须挑一个**入度为 $0$** 的顶点；环上各点入度都不为 $0$ 且彼此依赖，永远挑不出来；
4. 后半句：造一个"每步只有唯一选择"的图——单向链 $a\to b\to c$，其拓扑序列只有 $a,b,c$ 一种 ⇒ "不唯一"并非必然；
5. 两支都假 ⇒ 命题 ×；并写出正确的表述。

## 6. 详细解答

**（1）前半句为假：有环则不存在拓扑序列。**

设 $G_1$：$V=\{a,b,c\}$，$A=\{\langle a,b\rangle,\langle b,c\rangle,\langle c,a\rangle\}$。拓扑序列须同时满足

$$a\prec b,\qquad b\prec c,\qquad c\prec a$$

三条传递得 $a\prec a$，矛盾。穷举验证 $6$ 种排列：

| 排列 | 被违反的弧 |
|---|---|
| $a,b,c$ | $\langle c,a\rangle$ |
| $a,c,b$ | $\langle b,c\rangle$、$\langle c,a\rangle$ |
| $b,a,c$ | $\langle a,b\rangle$、$\langle c,a\rangle$ |
| $b,c,a$ | $\langle a,b\rangle$ |
| $c,a,b$ | $\langle b,c\rangle$ |
| $c,b,a$ | $\langle a,b\rangle$、$\langle b,c\rangle$ |

无一种合格 ⇒ $G_1$ 根本没有拓扑序列，"任何有向图都可以排成拓扑排序"为假。

**算法视角**：拓扑排序的实现是"统计各顶点入度 → 反复输出入度为 $0$ 的顶点并把它邻接点的入度减 $1$"。$G_1$ 中 $a,b,c$ 的入度都是 $1$，第一步就无顶点可取，输出的拓扑序列长度 $0<n=3$——教材正是用"拓扑排序结束时输出顶点数是否等于 $n$"来**判定有向图有环**。因此拓扑序的存在性等价于图为 AOV 网（有向无环图）。

```c
Status TopSort(MGraph G)         /* 拓扑排序，输出顶点数 < G.vexnum 即说明有环 */
{
    int indeg[MAXV], i, k = 0, v;
    Stack S; InitStack(&S);
    for (i = 0; i < G.vexnum; ++i) indeg[i] = G.indegree[i];
    for (i = 0; i < G.vexnum; ++i) if (!indeg[i]) Push(&S, i);
    while (!StackEmpty(S)) {
        Pop(&S, v); VisitVex(G, v); ++k;             /* 第 k 个输出 */
        for (i = 0; i < G.vexnum; ++i)
            if (G.arcs[v][i]) if (!(--indeg[i])) Push(&S, i);
    }
    return (k == G.vexnum) ? OK : ERROR;             /* 有环 */
}
```

**（2）后半句为假：拓扑序列可以唯一。**

设 $G_2$：$V=\{a,b,c\}$，$A=\{\langle a,b\rangle,\langle b,c\rangle\}$（一条有向链）。它无环，拓扑序列存在；而 $a$ 是唯一入度为 $0$ 的顶点，删去 $a$ 后 $b$ 是唯一入度为 $0$ 的顶点，再删 $b$ 只剩 $c$。故拓扑序列只有

$$a,\ b,\ c$$

**唯一一个**，"拓扑序列不唯一"并非必然成立。

一般地：拓扑序列**不唯一** $\iff$ 算法某一步同时存在两个及以上入度为 $0$ 的顶点。标准结论是——**拓扑序列唯一的充要条件是拓扑序中每对相邻顶点之间都存在弧**（即图中存在一条经过全部顶点各一次的路径 $v_1\to v_2\to\cdots\to v_n$，它把顶点完全排序）；反之，若某对相邻顶点间无弧，交换它们仍得合法拓扑序，序列就不唯一。$G_2$ 恰满足该条件，故唯一。

**（3）正确表述。**

> 若是有向**无环**图（AOV 网），则其顶点可以排成拓扑序列；当存在某一步有多个入度为 $0$ 的顶点可选时拓扑序列不唯一，而当各步可选顶点唯一（例如所有顶点被一条有向路径串起来）时拓扑序列唯一。含环的有向图不存在拓扑序列。

**结论**：两个断言均不成立，×。

## 7. 选项分析

不适用（判断题）。

## 8. 考场标准答案

×。两点错：

1. 只有**有向无环图**才存在拓扑序列。反例：$a\to b\to c\to a$ 有向环，需同时满足 $a\prec b\prec c\prec a$，矛盾，$6$ 种排列无一合法（拓扑排序算法中表现为"取不到入度为 $0$ 的顶点"，输出顶点数 $<n$，据此判环）。
2. 拓扑序列**可能唯一**。反例：有向链 $a\to b\to c$，每步只有唯一零入度顶点，拓扑序列只有 $a,b,c$ 一种。

## 9. 易错点

1. 忽略存在性条件：把教材"拓扑排序"章节默认在 AOV 网上讨论的前提丢掉，误以为任何有向图都能拓扑排序；
2. 忽略唯一性方向：因为常见例题（多个源点可选）拓扑序列都不唯一，就把"不唯一"当成一般规律——判"唯一/不唯一"要看每一步零入度顶点个数；
3. 联言命题只否一支就下结论：本题两支都错，答题时两条反例都要写，只写一条会被判理由不完整；
4. 与关键路径（AOE 网，边带权）混淆：拓扑排序定义在 AOV（顶点表活动）上，AOE 也必须无环，但讨论的是边（活动）与关键路径，不要混用术语。

## 10. 一句话规律

带"任何……而且……"的判断题，先拆成若干断言逐个找反例；拓扑排序的两条命门永远是"**有没有环**"和"**某步可选项是否唯一**"。

## 11. 关联知识

- 拓扑排序算法的时间：邻接表下 $O(n+e)$（每个顶点入栈一次、每条弧检查一次），与本卷第 10 题（DFS 复杂度 $O(n+e)$）同一计数方式；邻接矩阵下为 $O(n^2)$；
- 拓扑排序可用于判环：输出顶点数 $<n\iff$ 有向图中存在环，这是教材给出的标准判据；
- 一个 $n$ 顶点有向图，若拓扑序列唯一，则其弧数至少 $n-1$（那条串起全部顶点的路径）；若弧数少于 $n-1$ 则必有多个源点、拓扑序必不唯一——两者可作为快速判断的小结论；
- 关键路径（DS04.04.04）在拓扑序上求事件最早发生时间 ve、在逆拓扑序上求最迟发生时间 vl，其前提正是本题的"必须无环"。
