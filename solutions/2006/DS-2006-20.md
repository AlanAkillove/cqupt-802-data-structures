# DS-2006-20

## 1. 原题

向二叉检索树中插入一个新结点，需要比较的次数不可能大于此二叉树的高度。（）

## 2. 答案

**√（正确）**——按本卷"仅含根结点的二叉树高度为 $1$"的口径，插入时的比较次数 $=$ 新结点所在层数 $-1\le h$，最多与树高相等，不可能超过。

## 3. 题目分析

- 已知：二叉检索树（即二叉排序树 BST：左子树所有关键字 $<$ 根 $<$ 右子树所有关键字，左右子树递归满足）；插入操作为"从根出发查找失败位置，把新结点作为叶子挂上"；
- 目标：判断"比较次数 $\le$ 树高 $h$"是否恒成立（"不可能大于"即 $\le$）；
- 关键约束：① 一次比较 $=$ 新关键字与**树中一个已有结点**的关键字比较一次；② 空指针（失败位置）不含关键字，不参与比较；③ 高度口径采用本卷统一的"结点数/层数"口径（见第 12 节口径说明）；
- 命题意图：考 BST 插入与"查找失败"是同一过程，其比较次数由路径上的**结点数**决定，从而把"树高"与"插入代价"这两个量准确对应起来（也是 BST 平均性能 $O(\log n)$、最坏 $O(n)$ 结论的来源）。

## 4. 核心考点

核心考点：
DS05.07.01 二叉搜索（排序）树（插入算法：沿比较路径下行到空链，新结点必为叶子）

辅助考点：
DS05.01 查找的基本概念（比较次数作为查找长度的度量；"查找失败"结点的层次与比较次数差 $1$ 的口径）

解释：插入前必须先做一次"查找插入位置"的失败查找，所以插入代价的分析与查找失败 ASL 完全同构；树高 $h$ 界定了任何一条比较路径的长度上限。

## 5. 解题思路

1. 写清插入的逐层比较过程，确认"每经过一个已有结点比较一次，遇到空指针停止"；
2. 设新结点落在第 $d$ 层，则它上面有 $d-1$ 个已有结点，比较次数 $=d-1$；
3. 因第 $d-1$ 层非空（那里有它的父结点），而树中最深的层是第 $h$ 层，故 $d-1\le h$；
4. 检查两个极值：空树（$h=0$，$0$ 次比较）与单支链（$h=n$，插到链尾需 $n$ 次比较 $=h$，取等号但不超过），确认"$\le$"是紧界；
5. 反思口径：若把高度定义为边数（单结点高 $0$），同一结论要写成"不超过树高 $+1$"——本题按卷面口径判 √。

## 6. 详细解答

**算法过程（教材风格）。** 在 BST $T$ 中插入 $key$：

```c
Status BST_Insert(BiTree *T, KeyType key)      /* 若不存在关键字为 key 的结点则插入 */
{
    BiTree p = *T, f = NULL;                   /* f 始终为 p 的双亲 */
    int cnt = 0;                               /* 关键字比较次数 */
    while (p != NULL) {
        ++cnt;
        if (key == p->data.key) return ERROR;  /* 已存在，不插入 */
        f = p;
        p = (key < p->data.key) ? p->lchild : p->rchild;
    }
    p = (BiTree)malloc(sizeof(BTNode));
    p->data.key = key; p->lchild = p->rchild = NULL;
    if (f == NULL) *T = p; else if (key < f->data.key) f->lchild = p; else f->rchild = p;
    return OK;
}
```

由循环可见：**每次迭代恰好做一次关键字比较，且迭代次数 $=$ 路径上已有结点的个数**。循环在 $p==NULL$ 时退出，空位置本身没有关键字，不产生比较。

**与树高的关系。** 设插入前树高为 $h$（"仅含根结点的树高为 $1$"的层数口径）。新结点被挂在某个空链上，成为第 $d$ 层结点，其父结点在第 $d-1$ 层。

- 比较次数 $=d-1$（第 $1$ 层到第 $d-1$ 层各一个结点）；
- 父结点存在 $\Rightarrow$ 第 $d-1$ 层非空 $\Rightarrow d-1\le h$；

$$\text{比较次数}=d-1\le h$$

故"不可能大于此二叉树的高度"成立，√。（注意：这里比较的是**插入前**的树高 $h$；若以插入后的新树高 $h+1\ge d$ 为准，$d-1<h+1$ 更是自动成立。）

**界是紧的（可以取等号，但不会超过）**

| 情形 | 树形 | $h$ | 插入位置 | 比较次数 |
|---|---|---|---|---|
| 空树 | — | $0$ | 新根 | $0$ |
| 单结点 | $(5)$ | $1$ | 左/右孩子 | $1=h$ |
| 平衡 3 结点 | $2(1,3)$ | $2$ | 任意空链 | $2=h$ |
| 单支链（全右） | $1\to2\to3$ | $3$ | 插入 $4$（比到链尾） | $3=h$ |

最坏情形（插入到最深的叶子之下）比较次数正好等于 $h$，因此"$\le$"既成立又不能再改进为"$< $"。这也解释了 BST 的插入代价是 $O(h)$：形态平衡时 $h=\lfloor\log_2 n\rfloor+1$（$O(\log n)$），退化为链时 $h=n$（$O(n)$）。

**反向检查（能否构造出超过 $h$ 的情形）**：要使比较次数 $>h$，路径上必须有至少 $h+1$ 个已有结点，即树存在第 $h+1$ 层，与 $h$ 是最大层号矛盾。故不存在反例。

**结论**：√（按本卷高度口径）。

## 8. 考场标准答案

√。

BST 插入是"从根开始沿比较路径下行到空链、把新结点作为叶子挂上"的过程：每经过一个已有结点比较一次，空位置不比较。设新结点在第 $d$ 层，则比较次数 $=d-1$；由于其父结点在第 $d-1$ 层存在，$d-1$ 不超过插入前树高 $h$（层数口径）。故比较次数最多等于树高（插入到最深叶子之下时取等号），不可能大于树高。

（推论：插入代价 $O(h)$；这也正是 BST 需要 AVL 旋转来压住 $h$ 的理由。）

## 9. 易错点

1. **多算一次**：把"新结点自己所在层"也算进比较次数（误认为还要和空指针或和自己比较一次），得出"$d>h$ 故为 ×"——空链不含关键字，不构成比较；
2. **高度口径**：若题目所在的教材用"路径边数"定义高度（单结点树高 $0$），则同一事实应表述为"不超过树高 $+1$"。本卷第 4、5、17 题括号中均已约定"仅含根结点的二叉树高度为 $1$"，按此口径判 √；
3. 与"查找成功"的比较次数混淆：查找成功时比较次数 $=$ 目标结点所在层数 $\le h$；查找失败（=插入）时比较次数 $=$ 层数 $-1\le h$，两者都不超过 $h$，但**失败结点的层号**是 $h+1$，别看错对象；
4. 误以为插入需要像 AVL 那样"额外比较再做旋转"，从而把调整代价计入——普通 BST 插入没有旋转。

## 10. 一句话规律

"插入/查找失败要比较几次"一律数**路径上已有结点的个数**（不含空位置），它等于新结点的层数减一，因而被树高 $h$ 卡住；凡是这类"不超过某个结构参数"的判断题，先把"计数对象"精确到结点上再比大小。
