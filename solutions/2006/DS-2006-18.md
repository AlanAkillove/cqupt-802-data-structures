# DS-2006-18

## 1. 原题

按中序遍历二叉树时，某个结点的直接后继是它的右子树中第一个被访问的结点。（）

## 2. 答案

**×（错误）**——该结论只在"该结点有右子树"时成立；若结点无右子树，其中序后继是某个**祖先**结点（甚至没有后继），与"右子树"无关。

## 3. 题目分析

- 已知：中序遍历规则 $\text{Inorder}(T)=\text{Inorder}(L_T)\to T\to\text{Inorder}(R_T)$；题面断言"某个结点"（即任意结点）的直接后继是"它的右子树中第一个被访问的结点"；
- 目标：判断这一**全称**断言是否成立；
- 关键约束：全称命题只需一个反例即假；而"右子树中第一个被访问的结点"这个说法对**没有右子树**的结点根本没有指称对象；
- 命题意图：考中序后继的完整分类（有右子树 / 无右子树但有"向左上来的祖先" / 完全无后继三种情形），这正是线索二叉树要用 $rtag$ 区分"右孩子"与"右线索"的原因。

## 4. 核心考点

核心考点：
DS03.02.03.02 中序遍历（"左—根—右"的递归次序决定了结点访问完之后的去向）

辅助考点：
DS03.02.04 线索二叉树（中序线索化把"空的右孩子指针"改存后继线索，本身就说明大量结点的后继不在其右子树中）

解释：要判定该命题必须把所有结点分情形讨论，属遍历次序的性质分析；而"为什么需要线索"这一问题恰是该命题为假的算法学表达，故列线索二叉树为辅助。

## 5. 解题思路

1. 任取结点 $x$，按 $x$ 有无右子树分两大类，共三种情形枚举（见第 6 节表）；
2. 找出"无右子树但仍有后继"的实例：最简的两个结点树 $A$ 有左孩子 $B$，中序序列 $B,A$，$B$ 的后继是 $A$，而 $B$ 无右子树 ⇒ 反例成立；
3. 顺带确认：当右子树**存在**时，"右子树中第一个被访问的结点"（即右子树的最左下结点）确实是后继——说明命题是"对一半、漏一半"，属于典型的以偏概全；
4. 结论：×。

## 6. 详细解答

**中序后继的完整分类。** 设二叉树带双亲指针（或用递归栈），任取结点 $x$：

| 情形 | 条件 | 中序直接后继 |
|---|---|---|
| ① | $x$ 的右子树非空 | 右子树中**最左下**的结点（即右子树里第一个被访问的结点）——题面说法在此成立 |
| ② | $x$ 的右子树为空，且存在祖先 $a$ 使 $x$（或其上行路径）位于 $a$ 的左子树中，取最近的这样的 $a$ | 该祖先 $a$ —— 后继**不在** $x$ 的右子树中（右子树为空） |
| ③ | $x$ 的右子树为空，且从根到 $x$ 的路径全程走右枝 | $x$ 是中序最后一个结点，**没有后继** |

**反例（否证全称命题）**

```
    A
   /
  B
```

中序遍历：先 $B$（$B$ 无孩子，访问）、再 $A$。序列为 $B, A$。结点 $B$ 的直接后继是 $A$，而 $B$ 的右子树为空——"它的右子树中第一个被访问的结点"不存在。命题对 $B$ 不成立 ⇒ 全称断言为假。

更强的反例（三结点完全二叉树）：

```
      2
     / \
    1   3
```

中序序列 $1,2,3$。结点 $1$ 的后继是父结点 $2$（情形②）；结点 $3$ 无后继（情形③）。两个结点都不满足题面说法。

**为何容易误判为对**：教材在讲"中序遍历的非递归实现/线索化"时，确实给出"$x$ 有右子树则后继是右子树最左下结点"这一条，很多记忆把它当成了无条件结论。完整的求后继代码（中序线索链表，$tag=0$ 表示孩子指针、$tag=1$ 表示线索）是：

```c
Status Next_Inorder(BiThrTree x, BiThrTree *y)   /* 求中序后继 */
{
    if (x->rtag == 1)            /* 情形②③：右链本就是线索，指向后继（③时为空） */
        *y = x->rchild;
    else {                       /* 情形①：有右孩子 → 右子树中最左下的结点 */
        *y = x->rchild;
        while ((*y)->ltag == 0) *y = (*y)->lchild;
    }
    return OK;
}
```

函数必须先用 $rtag$ 判断，正说明"后继在右子树中"只是三种情形之一；若题面成立，`rtag` 分支就是多余的。

**结论**：×。正确表述应为——"若结点的右子树非空，则其中序直接后继是其右子树中最左下（第一个被访问）的结点；若右子树为空，则其后继是沿 parent 向上第一个'本结点在其左子树中'的祖先，这样的祖先不存在时该结点无后继（是中序序列的最后一个）。"

## 7. 选项分析

不适用（判断题）。

## 8. 考场标准答案

×。反例：结点 $A$ 只有左孩子 $B$，中序序列为 $B,A$，$B$ 的直接后继是祖先 $A$，而 $B$ 没有右子树。

正确结论：仅当结点有右子树时，其后继才是右子树中最左下的结点；右子树为空时后继是某个祖先（向上第一个"本结点属于其左子树"的祖先），若不存在这样的祖先则该结点是中序序列的最后一个，无后继。

## 9. 易错点

1. 只记住了"有右子树"那一半结论，忽略了"无右子树仍可能有后继"的情形②——这是本题唯一的失分点；
2. 反过来矫枉过正：认为"后继一定是父结点"也不对（情形①的后继在右子树中，情形②的祖先不一定是直接双亲，如 $x$ 是其父的右孩子、父是其祖父的左孩子时，后继是祖父）；
3. 与**前序**遍历混淆：前序中"根的下一个"才是"左子树中最先访问的结点"这类规则，各遍历的后继规则不可互相套用；
4. 忘记情形③（无后继）：讨论"直接后继"时应先确认后继存在。

## 10. 一句话规律

判断"遍历序列中某结点后继/前驱"的命题，一律按"有/无左右子树"分三种情形枚举；凡结论只描述其中一种而冠以"某个结点"的，都是假的。

## 11. 关联知识

- 中序对称的前驱规则：左子树非空则前驱是左子树最右下结点；否则沿 parent 向上第一个"本结点在其右子树中"的祖先；
- 线索二叉树的定义正是为在**无 parent 指针**的二叉链表上高效求前驱/后继：$n$ 个结点的二叉链表共有 $2n$ 个指针域，其中空域 $n+1$ 个（DS03.02.02 二叉树的存储结构），线索化就是用这些空域存前驱/后继。
- 本卷第 23 题（树转二叉树后根无右子树）与本题的"右子树"表述无关，注意区分"右子树为空"在两章中的不同含义；
- 由序列反推二叉树（本卷第 7 题前序与中序配对）依赖的也是同一条"中序：根把序列分成左、右两部分"的性质。
