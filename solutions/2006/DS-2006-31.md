# DS-2006-31

## 1. 原题

要将序列 `{60,10,8,40,90,70,100}` 建成堆，只需把 $8$ 与\_\_相交换。

> 订正说明转录：源文未指明堆的类型；经核对源文解析篇按小根堆构造，$8$ 与 $60$ 交换一次即成堆，"只需"成立。做题时请按小根堆处理。

## 2. 答案

$60$。

按小根堆口径，一次交换为 $8 \leftrightarrow 60$（即结点 $8$ 与堆顶 $60$ 互换），得到小根堆

$$\{8,\,10,\,60,\,40,\,90,\,70,\,100\}$$

## 3. 题目分析

- 已知：序列 $(60,10,8,40,90,70,100)$，共 $n=7$ 个元素，按出现顺序存入完全二叉树（层序）；
- 目标：按**小根堆**定义（任一结点 $\le$ 其孩子）建堆，且题面断言"只需把 $8$ 与某元素交换一次"，要求填出该元素；
- 关键约束：堆是完全二叉树，下标 $i$ 的孩子为 $2i,2i+1$（$1$ 起编号）；建堆用自最后非叶结点 $\lfloor n/2\rfloor$ 起逐个向上筛选；
- 命题意图：考筛法建堆的过程，特别是"哪一趟会发生交换、和哪个孩子交换（小根堆取较小的孩子）"。

## 4. 核心考点

核心考点：
DS06.07 堆与堆排序（堆的定义、筛法建堆、调整时与"较小的孩子"交换）

辅助考点：无（完全二叉树下标关系是堆的固有前提，不另标）

解释：题目只涉及堆这一数据结构本身的构造过程，不涉及排序各趟，也不涉及堆作优先队列的应用，故只打主考点。

## 5. 解题思路

1. 把 $7$ 个元素按层序画成完全二叉树，标出下标 $1\sim7$；
2. 确定最后一个非叶结点 $\lfloor 7/2\rfloor=3$，按 $i=3,2,1$ 的顺序逐个"下筛"；
3. 小根堆下筛规则：与**值较小的孩子**比较，若孩子更小则交换，否则该趟不动；
4. 记录发生交换的结点对：只有 $i=1$ 一趟需要交换，交换对象正是 $8$（结点 $3$）与 $60$（结点 $1$），由此确定空格填 $60$；
5. 交叉验证：交换后的序列逐条检查小根堆性质；再按大根堆口径重做，确认其需要多次交换，与题面"只需"矛盾，反证题意只能是小根堆（与订正说明一致）。

## 6. 详细解答

**初始完全二叉树**（$1$ 起编号，括号为下标）

```
            60(1)
          /       \
      10(2)       8(3)
      /   \       /   \
  40(4) 90(5) 70(6) 100(7)
```

**筛法建堆（小根堆，$i$ 从 $\lfloor 7/2\rfloor=3$ 递减到 $1$）**

- $i=3$：结点 $8$，孩子 $70,100$。较小孩子 $70>8$，已满足"父 $\le$ 子"，**不交换**；
- $i=2$：结点 $10$，孩子 $40,90$。较小孩子 $40>10$，**不交换**；
- $i=1$：结点 $60$，孩子 $10,8$。较小孩子为 $8$（结点 $3$），$8<60$ ⟹ **交换 $60$ 与 $8$**；
  交换后 $60$ 落到结点 $3$，继续下筛：结点 $3$ 的孩子为 $70,100$，均大于 $60$，下筛终止。

一趟交换即完成全部调整，结果：

```
            8(1)
          /      \
      10(2)      60(3)
      /   \      /   \
  40(4) 90(5) 70(6) 100(7)
```

对应序列 $\{8,10,60,40,90,70,100\}$。

**成堆验证**（逐结点检查"父 $\le$ 子"）
$8\le10$、$8\le60$；$10\le40$、$10\le90$；$60\le70$、$60\le100$ ✓ 全部满足，确为小根堆。

**唯一性验证（若按大根堆会怎样）**：大根堆要求"父 $\ge$ 子"。同样自 $i=3$ 下筛：
- $i=3$：$8$ 与较大孩子 $100$ 交换 → $\{60,10,100,40,90,70,8\}$；
- $i=2$：$10$ 与 $90$ 交换 → $\{60,90,100,40,10,70,8\}$；
- $i=1$：$60$ 与较大孩子 $100$ 交换 → $\{100,90,60,40,10,70,8\}$，再在结点 $3$ 处继续下筛，$60$ 与 $70$ 交换 → $\{100,90,70,40,10,60,8\}$。

共 $4$ 次交换，且没有任何"只与 $8$ 交换一次"的做法能得到大根堆（例如把 $8$ 与 $60$ 交换得 $\{8,10,60,\dots\}$，根为 $8$ 违反大根堆）。故题面"只需把 $8$ 与 __ 交换"只在小根堆口径下成立，与订正说明一致，答案唯一：$60$。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

按小根堆、层序建完全二叉树，从最后非叶结点 $\lfloor7/2\rfloor=3$ 起自下而上筛选：结点 $3$（$8$）、结点 $2$（$10$）均满足堆性质；结点 $1$（$60$）的较小孩子为 $8$，$8<60$ ⟹ 交换 $60$ 与 $8$，交换后 $60$ 所在结点 $3$ 的孩子 $70,100$ 均大于 $60$，筛选终止。

$$\{60,10,8,40,90,70,100\}\ \longrightarrow\ \{8,10,60,40,90,70,100\}$$

故空格填 $60$。

## 9. 易错点

1. **堆型未指明**（本题已用订正说明统一为小根堆）：小根堆下筛与**较小**孩子交换，大根堆与**较大**孩子交换，混用会得到完全不同的交换对；
2. 误以为"建堆就是把根调到最小"，只调根一趟——正确做法是自 $\lfloor n/2\rfloor$ 起逐个结点下筛（本题恰好只有最后一趟发生交换）；
3. 交换对象写成"根结点"而未给出元素值 $60$，或写成 $10$（结点 $2$，另一孩子）——筛选时取**值较小**的孩子，$8<10$；
4. 交换后忘记继续下筛：本题 $60$ 落到结点 $3$ 后仍需检查其孩子（$70,100>60$ 才终止），若孩子更小还要继续换。

## 10. 一句话规律

筛法建堆一律"自 $\lfloor n/2\rfloor$ 到 $1$ 逐个下筛、每次与（小根堆取较小 / 大根堆取较大）的孩子交换、交换后沿该路径继续下筛"；题面说"只需交换一次"本身就暗示了堆型，可反推验证。
