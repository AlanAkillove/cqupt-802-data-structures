# DS-2006-21

## 1. 原题

对一个堆按层次遍历，一定能得到一个有序序列。（）

## 2. 答案

**×（错误）**——堆只保证"任一结点 $\le$（或 $\ge$）其双亲/子女"的**父子偏序**，同一层的兄弟之间、不同支路之间毫无大小关系；层次遍历按数组原序输出，一般不是有序序列。

## 3. 题目分析

- 已知：堆的定义——$n$ 个元素的序列 $(k_1,\cdots,k_n)$ 按完全二叉树顺序存储，满足 $k_i\le k_{2i}$ 且 $k_i\le k_{2i+1}$（小根堆）或反向（大根堆）；层次遍历即按编号 $1,2,\cdots,n$ 依次输出；
- 目标：判断"堆 $\Rightarrow$ 层序序列有序"这一全称断言；
- 关键约束：层次遍历的输出恰是数组本身的存储次序（堆的顺序存储），故命题等价于"堆数组是递增（递减）数组"；
- 命题意图：考"堆 = 部分有序"与"有序序列 = 完全有序"的区别，并考"堆排序之所以要反复取堆顶调整，而不是直接读数组"这一动机。

## 4. 核心考点

核心考点：
DS06.07 堆与堆排序（堆的定义只给父子约束；输出有序序列必须经 $n-1$ 次"交换堆顶与堆尾 + 向下调整"）

辅助考点：
DS03.02.03.04 层次遍历（完全二叉树的层序 $=$ 数组下标序，这是"遍历结果就是原数组"这一判断的依据）

解释：解题要先明确层次遍历在顺序存储下读到的就是 $k_1..k_n$，再核对堆定义是否强制该序列有序——结论是否定的，故只需一个反例。

## 5. 解题思路

1. 把定义写成不等式，逐项列出堆**要求**什么、**不要求**什么：要求 $k_i\le k_{2i},k_i\le k_{2i+1}$；不要求 $k_{2i}\le k_{2i+1}$（兄弟间）、不要求 $k_{3}\le k_{4}$（不同支路）；
2. 有序序列要求**任意** $i<j$ 都有 $k_i\le k_j$，这比"父子约束"强得多；
3. 造反例：取最小的能体现"兄弟无序"的规模 $n=3$，小根堆 $(1,3,2)$ 满足定义但 $3>2$，层序不递增；再用 $n=7$ 的完整反例加强；
4. 结论：×。（"一定能"被一次反例否证；另外指出正确的输出有序的方法是堆排序。）

## 6. 详细解答

**（1）定义比对**

小根堆要求（$1\le i$，$2i\le n$，$2i+1\le n$）：

$$k_i\le k_{2i},\qquad k_i\le k_{2i+1}$$

这是一组**局部**约束，等价于"每个结点是从它到根路径上的最小值"，并不涉及 $k_{2i}$ 与 $k_{2i+1}$ 之间、也不涉及 $k_{2}$ 与 $k_{3}$ 之间的大小。

而"层次遍历得到有序序列"要求对全部 $1\le i<j\le n$ 有 $k_i\le k_j$（完全有序）。$n-1$ 条父子约束要推出 $\frac{n(n-1)}{2}$ 条全局比较，缺口显然存在。

**（2）反例（最小）** $n=3$，数组 $(1,3,2)$：

```
      1
     / \
    3   2
```

检查：$k_1=1\le k_2=3$ ✓，$k_1=1\le k_3=2$ ✓ —— 合法小根堆。层次遍历输出 $1,3,2$，$3>2$，**不是**有序序列。

**（3）反例（$n=7$，$1\sim 7$ 的排列）** 数组 $(1,3,2,6,7,4,5)$：

```
          1
       /     \
      3       2
     / \     / \
    6   7   4   5
```

逐条验证父子约束：$1\le3$、$1\le2$；$3\le6$、$3\le7$；$2\le4$、$2\le5$ ✓ 全部满足，是合法小根堆。层次遍历 $=1,3,2,6,7,4,5$，其中 $3>2$、$7>4$ 等多处逆序。

大根堆同理：把上述树整体取反序，$(7,5,6,2,1,4,3)$ 满足 $k_i\ge k_{2i},k_i\ge k_{2i+1}$（$7\ge5,7\ge6$；$5\ge2,5\ge1$；$6\ge4,6\ge3$ ✓），层序也不是递减序列。

**（4）什么情况下"碰巧"有序**：只有当数组同时满足全局递增时，它既是堆又有序——例如 $(1,2,3,4)$ 这类"按层递增填满"的特殊堆；堆的形态为单支链（$n$ 个结点只有一条链）时也必然有序。命题说的是"一定能"，特例不能救它。

**（5）正确做法**：要从不完整的堆中取出有序序列，必须执行堆排序的循环——

```c
void HeapSort(int r[], int n)          /* 小根堆 r[1..n]：反复输出堆顶 */
{
    int i;
    for (i = n; i > 1; --i) {
        Swap(r[1], r[i]);              /* 堆顶（当前最小）换到末尾已定区 */
        HeapAdjust(r, 1, i - 1);       /* 对前 i-1 个元素重新调整为堆 */
    }
}
```

对反例 $(1,3,2,6,7,4,5)$ 演算：交换 $r_1,r_7$ 得 $(5,3,2,6,7,4,\mid 1)$，向下调整（$5$ 与子 $3,2$ 中较小者 $2$ 换，再与子 $4$ 换）得 $(2,3,4,6,7,5\mid 1)$；再交换 $r_1,r_6$、调整得 $(3,5,4,6,7\mid 2,1)$……最终数组为 $(7,6,5,4,3,2,1)$。

可见：**有序来自“反复取顶 + 调整”，而不是来自遍历**；且小根堆按上述写法得的是**降序**（最小元被换到末尾），教材的堆排序因此使用**大根堆**以直接得升序（而本卷第 31 题的建堆按小根堆口径处理，见该题订正说明）。

**结论**：×。

## 8. 考场标准答案

×。

堆仅满足 $k_i\le k_{2i}$、$k_i\le k_{2i+1}$（小根堆），即"父子有序"，兄弟之间与不同支路之间没有约束；而完全二叉树的层次遍历恰是按 $1,2,\cdots,n$ 输出数组本身。

反例：$(1,3,2,6,7,4,5)$ 是合法小根堆（$1\le3,1\le2;3\le6,3\le7;2\le4,2\le5$），其层序 $1,3,2,6,7,4,5$ 中存在 $3>2$、$7>4$，不是有序序列。

堆只能保证堆顶是极值；要得到有序序列必须做堆排序（反复交换堆顶与当前堆尾并向下调整），代价 $O(n\log_2 n)$。

## 9. 易错点

1. 把"堆有序（heap-ordered）"与"序列有序（sorted）"当成一回事——堆是**部分有序**结构，这是本章的核心概念区分；
2. 只想到堆顶最小就以为整体递增：第二位与第三位是根的两个孩子，它们之间完全没有比较关系；
3. 与"堆排序各趟结果"混淆：堆排序过程中数组 $r[1..n]$ 会被改写成"末尾是已输出的最小值、前段仍是堆"的混合状态，既不是原始堆也不是最终有序表（本卷第 31 题考建堆的单步交换，注意与"排序各趟"区分）；
4. 反例要**先验证自己是堆**再说明它不有序，否则举例无效（例如随手写 $(3,1,2)$ 并不是小根堆）。

## 10. 一句话规律

判断"某结构遍历出来是否有序"，就把结构定义写出不等式集合，再与"有序要求的全序比较集合"对比：**少一条约束就造一个反例**（堆缺的是兄弟之间与跨支路的约束）。

## 11. 关联知识

- 堆的两个正确性质：堆顶（$k_1$）必为全局极值；从任一结点到根的路径上的关键字单调（小根堆中自根向下不减）——这两个才是可放心使用的结论；
- 优先队列用堆实现：入队 $O(\log n)$、出队 $O(\log n)$，但"查看整个队列的次序"没有意义（DS02.07 栈、队列和数组的应用中优先队列即此结构）；
- 若需要"层序遍历即有序"的结构，应选**二叉排序树的中序遍历**（本卷第 6 题）或顺序表本身，不要用堆；
- 堆排序的比较次数与初始状态无关（本卷第 12 题），而建堆只需 $O(n)$：本题的"父子约束"正是这两条结论的共同基础。
