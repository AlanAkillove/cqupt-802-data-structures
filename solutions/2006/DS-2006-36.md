# DS-2006-36

## 1. 原题

对二叉树中结点进行按层次顺序（每一层从左至右）的访问操作称为二叉树的层次遍历，遍历所得到的结点序列称为二叉树的层次序列。现已知一棵二叉树的层次序列为 $ABCDEFGHIJ$，中序序列为 $DBGEHJACIF$，请画出该二叉树。

## 2. 答案

```
                 A
               /   \
              B     C
             / \     \
            D   E     F
               / \   /
              G   H I
                   \
                    J
```

各结点孩子关系：$A\!:\!(B,C)$；$B\!:\!(D,E)$；$C\!:\!(\varnothing,F)$；$D\!:\!(\varnothing,\varnothing)$；$E\!:\!(G,H)$；$F\!:\!(I,\varnothing)$；$G$、$I$、$J$ 为叶子；$H\!:\!(\varnothing,J)$。

## 3. 题目分析

- 已知：$10$ 个结点（$A\sim J$）的**层次序列** $ABCDEFGHIJ$ 与**中序序列** $DBGEHJACIF$；
- 目标：唯一确定这棵二叉树并画出；
- 关键约束：① 层次序列中第一个被访问的结点必是（子）树的根；② 中序序列中根把序列分成"左子树结点集"与"右子树结点集"；③ 两序列结点集合必须相同（用于校验回忆版数据是否自洽）；
- 命题意图：考"由两种遍历序列互推二叉树"的方法，重点是层次 + 中序这一组合（不同于常练的前序 + 中序）：层次序列不能直接给出"根的左子树区间"，必须靠"集合归属 + 谁先出现"来定子树根。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历（由序列确定二叉树）

辅助考点：
DS03.02.03.04 层次遍历（"同层从左至右、祖先先于后代"⇒ 结点集中最先出现者是根）
DS03.02.03.02 中序遍历（"左–根–右"⇒ 根把中序序列一分为二）

解释：构造过程交替使用两种遍历各自的性质——用中序定"哪些结点在左边"，用层次定"该子树的根是谁"，二者缺一不能唯一还原，故主考点 DS03.02.03 与两个遍历细目（.04 层次、.02 中序）同时列出。

## 5. 解题思路

1. **定根**：层次序列首元素 $A$ 是整棵树的根；
2. **分集**：在中序序列中找到 $A$，其左 $DBGEHJ$ 为左子树结点集 $S_L$（$6$ 个），其右 $CIF$ 为右子树结点集 $S_R$（$3$ 个）；用 $|S_L|+|S_R|+1=10$ 校验；
3. **定子树根**：在层次序列中扫描，$S_L$ 中最早出现者为左子树根，$S_R$ 中最早出现者为右子树根；
4. **递归**：对每个子树重复 2~3 步，直到结点集为单元素（叶子）或为空；
5. **回代验证**：对画出的树重新做层次遍历与中序遍历，与题面两个序列逐字符比对。

## 6. 详细解答

记层次序列中各结点的出现次序：$A(1),B(2),C(3),D(4),E(5),F(6),G(7),H(8),I(9),J(10)$。

**第 1 步（根 $A$）**
中序 $D\,B\,G\,E\,H\,J\;\big|\;A\;\big|\;C\,I\,F$ ⟹ $S_L=\{D,B,G,E,H,J\}$（$6$ 个），$S_R=\{C,I,F\}$（$3$ 个）。$6+3+1=10$ ✓。

**第 2 步（$S_L$ 的根）**
层次次序中 $S_L$ 的元素：$B(2),D(4),E(5),G(7),H(8),J(10)$，最早为 $B$ ⟹ 左子树根 $B$。
中序中 $B$ 的位置：$D\;\big|\;B\;\big|\;G\,E\,H\,J$ ⟹ $B$ 的左子树 $=\{D\}$，$B$ 的右子树 $=\{G,E,H,J\}$。

**第 3 步（$S_R$ 的根）**
层次次序中 $S_R$ 的元素：$C(3),F(6),I(9)$，最早为 $C$ ⟹ 右子树根 $C$。
中序 $C\;\big|\;I\,F$：$C$ 之前无元素 ⟹ $C$ **无左孩子**；$C$ 之后 $\{I,F\}$ ⟹ $C$ 的右子树 $=\{I,F\}$。

**第 4 步（$\{D\}$）** 单元素 ⟹ $D$ 是 $B$ 的左孩子，且为叶子。

**第 5 步（$B$ 的右子树 $\{G,E,H,J\}$）**
层次次序：$E(5),G(7),H(8),J(10)$，最早为 $E$ ⟹ 根 $E$。
中序中该段为 $G\;\big|\;E\;\big|\;H\,J$ ⟹ $E$ 左子树 $=\{G\}$，$E$ 右子树 $=\{H,J\}$。

**第 6 步（$C$ 的右子树 $\{I,F\}$）**
层次次序：$F(6),I(9)$，最早为 $F$ ⟹ 根 $F$。
中序中该段为 $I\;\big|\;F$ ⟹ $F$ 左子树 $=\{I\}$，$F$ **无右孩子**。

**第 7 步（$\{G\}$、$\{H,J\}$、$\{I\}$）**
$\{G\}$、$\{I\}$ 为单元素叶子；$\{H,J\}$：层次次序 $H(8),J(10)$，根为 $H$，中序为 $H\;\big|\;J$ ⟹ $H$ 无左孩子、右孩子为 $J$。

**汇总（孩子表）**

| 结点 | 左孩子 | 右孩子 |
|---|---|---|
| A | B | C |
| B | D | E |
| C | — | F |
| D | — | — |
| E | G | H |
| F | I | — |
| G | — | — |
| H | — | J |
| I | — | — |
| J | — | — |

树形：

```
                 A
               /   \
              B     C
             / \     \
            D   E     F
               / \   /
              G   H I
                   \
                    J
```

**回代验证**
- 层次遍历：第 1 层 $A$；第 2 层 $B,C$；第 3 层 $D,E,F$；第 4 层 $G,H,I$；第 5 层 $J$ ⟹ $ABCDEFGHIJ$ ✓
- 中序遍历（左–根–右）：$D,B,(G,E,(H,J))\Rightarrow DBGEHJ$；根 $A$；$(\varnothing,C,(I,F))\Rightarrow CIF$ ⟹ $DBGEHJACIF$ ✓
- 结点数 $10$、叶子 $4$ 个（$D,G,I,J$），高度 $5$；层次序列每层结点数 $1,2,3,3,1$ 均 $\le 2^{i-1}$（第 $4$ 层 $3\le8$、第 $5$ 层 $1\le16$）✓ 二叉树每层容量约束成立。

**唯一性说明**：每一步"子树根"由层次序列中该结点集内最先出现者唯一确定，"左右划分"由中序序列中根的位置唯一确定；递归到单元素集合时结构封闭，故满足两个序列的二叉树**只有一棵**（不存在多解）。

## 7. 选项分析

不适用（问答题：作图并给出二叉树结构）。

## 8. 考场标准答案

**方法**：层次序列首元素定（子）树根 → 在中序序列中定位该根，两侧即左、右子树结点集 → 在层次序列中取该集合内最先出现者为子树根，递归至单元素。

**过程要点**：根 $A$；$S_L=\{D,B,G,E,H,J\}$（中序 $A$ 左侧）根为 $B$，$S_R=\{C,I,F\}$ 根为 $C$；$B$ 左 $=\{D\}$、右 $=\{G,E,H,J\}$（根 $E$）；$C$ 无左、右 $=\{I,F\}$（根 $F$）；$E$ 左 $=\{G\}$、右 $=\{H,J\}$（根 $H$，$H$ 右 $=J$）；$F$ 左 $=I$。

**结果图**（与第 2 节同）：

```
        A
       / \
      B   C
     / \   \
    D   E   F
       / \ /
      G  H I
          \
           J
```

**检验**：层次 $ABCDEFGHIJ$ ✓，中序 $DBGEHJACIF$ ✓。

## 9. 易错点

1. 用"前序 + 中序"的老套路直接读层次序列首元素之外的下一个当左子树根：本题 $B$ 之后是 $C$，而 $C$ 属右子树，必须按**集合归属**筛选后再取最早出现者；
2. 漏掉"空子树"：$C$ 无左孩子、$F$ 无右孩子、$H$ 无左孩子，画图时若强行补齐就与中序 $CIF$（$C$ 前无元素）矛盾；
3. 把中序片段 $HJ$ 误判成"$H$ 的左子树是 $J$"：$J$ 在 $H$ 右侧，应为右孩子，回代层次序列时 $H(8)$ 先于 $J(10)$ 只保证 $H$ 是根，方向由中序决定；
4. 不校验集合大小：若两序列结点集不一致（回忆版数据出错）会在某步出现"集合内找不到根"，应及时发现而非强行构造。

## 10. 一句话规律

"层次 + 中序"还原二叉树的通用套路是：**层次序列负责'谁是根'（集合内最先出现者），中序序列负责'谁在左、谁在右'**，交替递归并最后回代两个序列双向验证；前/后序 + 中序是其特例（前序首元素、后序末元素同样给出根）。

## 11. 关联知识

- 同一棵树的前序是否等于层次序列？不一定：自本树读出前序为 $ABDEGHJCFI$，与层次 $ABCDEFGHIJ$ 不同，说明两者“定根”的依据（首元素）虽相同，但其余元素的含义不同，不可混用；
- 由 $n$ 个结点的中序与层次序列构造可写成 $O(n\log n)$～$O(n^2)$ 的递归算法（先用数组记录每个结点的层次序号，再对每段取序号最小者作根），与本卷第 42~45 题这类算法设计题的书写风格一致；
- 本年度第 7 题（前序为 $1,2,3,4$ 时中序不可能的序列）与本题同为"两遍历序列的相容性"判断，可用本题"中序中根分左右"这一性质直接验证；
- 本年度第 18 题（中序某结点的直接后继是否为其右子树最左结点）与本树回代时的读序细节相关，可借此树自查：$A$ 的中序后继是 $C$。
