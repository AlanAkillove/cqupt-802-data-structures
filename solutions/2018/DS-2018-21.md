# DS-2018-21

## 1. 原题

某后缀表达式为 `abcd-*+ef/-` ，令 $a=2,b=3,c=4,d=5,e=6,f=2$ ，则表达式的值等于____________________ 。

## 2. 答案

$$-4$$

该后缀式对应的中缀表达式为 $a+b*(c-d)-e/f$，代入得 $2+3\times(4-5)-6/2=2-3-3=-4$。

## 3. 题目分析

- 已知：一个由 $6$ 个操作数与 $5$ 个运算符组成的后缀（逆波兰）表达式，字符连写无空格；操作数均为单字母，运算符为 $-,\ast,+,/,-$；各字母取值已给出；
- 目标：求表达式的值；
- 关键约束：后缀式中**运算符紧跟其两个运算对象**，且二元运算符总是取"栈顶"与"次栈顶"两个元素，**次栈顶在左、栈顶在右**——对 $-$、$/\,$这类不满足交换律的运算，次序不能颠倒；
- 命题意图：考后缀表达式求值的标准栈算法，重点不在算术而在**弹出顺序**与"扫描到运算符时操作数已就绪"这一不变式。同时要能把后缀式还原为中缀式（或直接建表达式树）作双向验证。

## 4. 核心考点

核心考点：
DS02.07 栈、队列和数组的应用（后缀表达式求值：遇操作数入栈、遇运算符弹两目计算后压回；中缀/后缀/前缀的互译）

辅助考点：
DS02.01 栈和队列的基本概念（栈"后进先出"，正是它保证了最近读入的两个操作数被优先取用）

解释：主体是表达式求值这一经典栈应用（DS02.07）；理解为什么弹出顺序是"右、左"依赖 LIFO 的定义（DS02.01）。

## 5. 解题思路

1. 先把连写的符号串切分成单个运算对象：`a b c d - * + e f / -`（共 $11$ 个符号，$6$ 个操作数、$5$ 个运算符，符合"二元表达式运算符数 $=$ 操作数数 $-1$"的自检）；
2. 自左向右扫描，遇运算对象（字母）把其**值**压栈，遇运算符弹出栈顶 $y$、次栈顶 $x$，算 $x\ op\ y$ 后压回；
3. 扫描结束时栈内应只剩 $1$ 个元素，即所求值；若栈中元素多于 $1$ 个，说明切词或弹出次序出错；
4. 反向验证：把后缀式还原为中缀式（每个运算符把左右两子式夹在中间加括号），再按"先乘除后加减、括号优先"求值，与第 3 步结果比对。

## 6. 详细解答

**（1）栈模拟（主方法）**

约定：运算符弹出顺序为"先弹右操作数 $y$，再弹左操作数 $x$"，计算 $x\ op\ y$。

| 读入符号 | 动作 | 栈内内容（左端为栈底，右端为栈顶） |
|---|---|---|
| $a$ | 压 $2$ | $2$ |
| $b$ | 压 $3$ | $2,3$ |
| $c$ | 压 $4$ | $2,3,4$ |
| $d$ | 压 $5$ | $2,3,4,5$ |
| $-$ | 弹 $y=5,x=4$，算 $4-5=-1$ | $2,3,-1$ |
| $\ast$ | 弹 $y=-1,x=3$，算 $3\times(-1)=-3$ | $2,-3$ |
| $+$ | 弹 $y=-3,x=2$，算 $2+(-3)=-1$ | $-1$ |
| $e$ | 压 $6$ | $-1,6$ |
| $f$ | 压 $2$ | $-1,6,2$ |
| $/$ | 弹 $y=2,x=6$，算 $6/2=3$ | $-1,3$ |
| $-$ | 弹 $y=3,x=-1$，算 $-1-3=-4$ | $-4$ |

扫描完毕，栈中恰剩一个元素 $-4$ ✓。

**（2）还原中缀式并独立求值（第二种推法）**

按后缀式自左向右构造中缀串（运算符把最近的两个子式夹在中间）：

$$c\ d-\ \Rightarrow\ (c-d);\qquad b\ (c-d)\ast\ \Rightarrow\ b*(c-d);\qquad a\ [\cdot]\ +\ \Rightarrow\ a+b*(c-d)$$

$$e\ f/\ \Rightarrow\ e/f;\qquad [\cdot]\ [\cdot]\ -\ \Rightarrow\ a+b*(c-d)-e/f$$

其中 $[\cdot]$ 代表上一步已归并好的子式。

代入数值：

$$2+3\times(4-5)-6\div 2=2+3\times(-1)-3=2-3-3=-4\ \checkmark$$

两法一致。

**（3）算法骨架（教材风格 C）**

```c
typedef struct { SElemType *elem; int base, top; } Stack;    /* 栈存运算对象的值 */

int EvalPostfix(char *S)          /* S 为后缀表达式，运算对象取 0~9 的单个数字字符 */
{
    int i, x, y;
    Stack s;
    InitStack(&s);
    for (i = 0; S[i] != '\0'; ++i) {
        if (IsDigit(S[i])) {
            Push(&s, S[i] - '0');                 /* 操作数入栈 */
        } else {
            Pop(&s, &y);  Pop(&s, &x);            /* 先弹右操作数，再弹左操作数 */
            switch (S[i]) {
                case '+': Push(&s, x + y); break;
                case '-': Push(&s, x - y); break;   /* 注意是 x-y，不是 y-x */
                case '*': Push(&s, x * y); break;
                case '/': Push(&s, x / y); break;
            }
        }
    }
    Pop(&s, &x);
    return x;                                      /* 此时栈应已空 */
}
```

本题的 $6$ 个字母需先按题给值换成数字再送入上述框架；若按字母本身入栈，则需另建"字母 $\to$ 值"的查表步骤，弹出次序与运算方向不变。

**（4）表达式树视角（第三种看法）**

后缀式即表达式树的后序遍历，据此重建该树（本库 DS-2014-26 的同型做法：叶子为运算对象，内部结点为运算符）：

```
                 -
              /     \
            +         /
           / \       / \
          a   *     e   f
             / \
            b   -
               / \
              c   d
```

建树过程与符号串一一对应：$a,b,c,d$ 四个叶子依次等待运算符；第一个 $-$ 取 $c,d$ 为左右子得子式 $c-d$；$\ast$ 以 $b$ 为左子、以上面的 $-$ 为右子；$+$ 以 $a$ 为左子、以 $\ast$ 为右子；随后 $e,f$ 两个叶子供给 $/$ 得 $e/f$；最后的 $-$ 以 $+$ 为左子、以 $/$ 为右子成为根。

回读校验：对该树作后序遍历（左 $\to$ 右 $\to$ 根）依次得 $a,b,c,d,-,\ast,+,e,f,/,-$，正是 `abcd-*+ef/-` ✓。自底向上求值：$c-d=-1$，$b*(-1)=-3$，$a+(-3)=-1$，$e/f=3$，$-1-3=-4$ ✓。

**答案**：$-4$。

## 7. 选项分析

不适用（填空题）。本题无备选支；若把弹出次序写反，末一步会变成 $3-(-1)=4$ 而得错值 $+4$（详见第 9 节第 1 条），可用"末步到底是 $x-y$ 还是 $y-x$"自查。

## 8. 考场标准答案

**$-4$**。

按后缀求值规则扫描：$c,d,-\Rightarrow 4-5=-1$；$b,\underline{-1},*\Rightarrow 3\times(-1)=-3$；$a,\underline{-3},+\Rightarrow 2+(-3)=-1$；$e,f,/\Rightarrow 6/2=3$；$\underline{-1},\underline{3},-\Rightarrow -1-3=-4$。等价中缀式 $a+b*(c-d)-e/f=-4$。

## 9. 易错点

1. **弹出次序颠倒**：把 $-$、$/$ 算成"栈顶 $op$ 次栈顶"，则 $c-d$ 变成 $5-4=1$、末步变成 $3-(-1)=4$，最终得 $+4$（错）——后缀求值必须是"次栈顶 $op$ 栈顶"；
2. 运算优先级误加：后缀式本身已消除优先级，若再"凭中缀习惯"把 $+$ 提到 $\ast$ 之前处理（如先算 $a+b$）会得 $-4$ 之外的错值；正确做法是严格按符号出现次序处理；
3. 把符号串切错词：`abcd-*+ef/-` 中 $6$ 个字母都是操作数，不要误看成 $ab$、$cd$、$ef$ 这类多位数；切词后可用"运算符个数 $=$ 操作数个数 $-1$"自检（本题 $5$ 与 $6$ ✓）；
4. 整型除法与实数除法的口径：本题 $6/2=3$ 无舍入歧义；若换成 $7/2$，按 C 语言整数除法则为 $3$，而数学除法则为 $3.5$，答卷需按题目给的类型口径处理；
5. 见 $-4$ 因"结果为负"而自我怀疑：后缀式含减法与负中间量属正常，判断依据只有"扫描完栈中是否恰剩一个元素"。

## 10. 一句话规律

后缀（前缀）表达式求值只有一条铁律：**从左到右扫描，操作数压栈，运算符弹出两个数——次栈顶在左、栈顶在右——算完压回；算完栈里必须只剩一个数**，两数顺序错了就会把减法除法整个反号。
