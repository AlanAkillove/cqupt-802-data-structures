# DS-2018-29

## 1. 原题

已知一个图的顶点集 $V$ 和边集 $E$ 分别为：

$V=$ { $1,2,3,4,5,6,7$ } ；

$E=$ { $<2,1>,<3,2>,<3,6>,<4,3>,<4,5>,<4,6>,<5,1>,<5,7>,<6,1>,<6,2>,<6,5>$ } ；

若存储它采用邻接表，并且每个顶点邻接表中的边结点都是按照终点序号从小到大的次序链接的：

（1）画出该图的邻接表存储图示；

（2）按拓扑排序算法进行排序，试给出得到的拓扑排序的序列。

> 订正说明转录：源文作"拓朴排序"，据题意修正为规范术语"拓扑排序"。

## 2. 答案

**（1）邻接表**（顶点表下标 $1\sim 7$，边表按终点序号升序）

```
[1] ──> ^
[2] ──> |1|^
[3] ──> |2| ──> |6|^
[4] ──> |3| ──> |5| ──> |6|^
[5] ──> |1| ──> |7|^
[6] ──> |1| ──> |2| ──> |5|^
[7] ──> ^
```

**（2）拓扑序列**：$4,\ 3,\ 6,\ 5,\ 7,\ 2,\ 1$（教材栈式算法、同批入栈者按序号升序压入的结果；序列不唯一，队列式实现得 $4,3,6,2,5,1,7$，亦为正确答案）

## 3. 题目分析

- 已知：$7$ 个顶点、$11$ 条弧的有向图，弧以 $\langle u,v\rangle$ 有序对形式给出（起点在前），并**明确规定**每个顶点的边表按终点序号升序链接；
- 目标：(1) 画出邻接表；(2) 按拓扑排序算法（教材算法，用**栈**存放零入度顶点）给出拓扑序列；
- 关键约束：
  1. 邻接表只登记**出边**：弧 $\langle u,v\rangle$ 挂在 $u$ 的边表上，$v$ 的表头不增加结点——因此"入度"不能直接读出，必须逐条弧统计；
  2. "边表按终点序号升序"这一约定使第 (1) 问的图**唯一确定**，也使第 (2) 问中"同一时刻多个零入度顶点"的处理次序有了默认依据；
  3. 拓扑序列要求对**每一条**弧 $\langle u,v\rangle$，$u$ 都排在 $v$ 之前；序列不唯一是本类题的固有性质，答卷应给出"按所写算法执行"的那一条并演算过程；
- 命题意图：把"图的存储"与"图上算法"绑在一起考——邻接表的边表次序直接决定拓扑排序中顶点被"删去"的先后，从而考查学生是否真正按算法步骤执行，而非凭直觉排一个满足偏序的序列。

## 4. 核心考点

核心考点：
DS04.02.02 邻接表法——有向图邻接表（出边表）的结构：顶点表 + 边表结点 `adjvex/next`，$n$ 个顶点 $e$ 条弧 ⟹ 表头向量长 $n$、边表结点总数 $e$（对照本卷 DS-2018-12 的无向图 $2e$ 结论）

辅助考点：
DS04.04.03 拓扑排序（AOV）——入度统计、零入度顶点入栈、删顶点即将其所有弧的终点入度减 $1$、输出序列长度不足 $n$ 即说明有环
DS04.01 图的基本概念——有向图中 $\sum$ 入度 $=\sum$ 出度 $=$ 弧数，是第 6.1 节建表后的自检依据

解释：第 (1) 问是纯粹的存储结构翻译（DS04.02.02），第 (2) 问是 DS04.04.03 的算法执行；两问串成"存储结构 → 算法行为"的因果链。

## 5. 解题思路

1. 先把 $11$ 条弧按起点分组，每组内按终点序号升序排列——这一步同时完成"建表"与"排序约定"；
2. 统计入度：对每条弧 $\langle u,v\rangle$ 令 $in[v]++$；用 $\sum in=11$ 与"边表结点总数 $=11$"双向核对；
3. 拓扑排序按教材算法执行：零入度顶点入栈 → 弹栈输出 → 把它边表中所有终点的入度减 $1$ → 谁减到 $0$ 谁入栈 → 重复到栈空；
4. 关键细节：同一时刻有多个零入度顶点时，按题面"序号从小到大"的默认约定入栈（先小后大依次压入，则大者在栈顶先出）；本题实际每步栈中至多 $1\sim 2$ 个元素，需在第 $3$ 次弹栈后注意 $2$ 与 $5$ 同时在栈中；
5. 得到序列后**逐弧复核**"起点在终点之前"，$11$ 条全满足才算对；再确认序列长度 $=7$（若小于 $7$ 说明图中有环，本题无环）。

## 6. 详细解答

### 6.1 第 (1) 问：建邻接表

**按起点分组弧集**（组内终点升序）：

| 起点 $u$ | 出边（终点升序） | 出度 |
|---|---|---|
| $1$ | 无 | $0$ |
| $2$ | $1$ | $1$ |
| $3$ | $2,6$ | $2$ |
| $4$ | $3,5,6$ | $3$ |
| $5$ | $1,7$ | $2$ |
| $6$ | $1,2,5$ | $3$ |
| $7$ | 无 | $0$ |

合计 $0+1+2+3+2+3+0=11=|E|$ ✓（与原弧集条数一致，说明无漏抄、无重抄）。

**邻接表图示**（边表结点写作 `adjvex`，`^` 为空指针）：

```
 顶点表            边表（出边，终点序号升序）
[1] |^
[2] |1|^
[3] |2|→|6|^
[4] |3|→|5|→|6|^
[5] |1|→|7|^
[6] |1|→|2|→|5|^
[7] |^
```

结构说明（教材定义）：

```c
typedef ArcNode { int adjvex; struct ArcNode *nextarc; } ArcNode;   /* 边表结点 */
typedef VNode   { int inDegree; ArcNode *firstarc; } VNode, AdjList[7];
```

顶点表可另存一列**入度**（求拓扑排序时要用），由弧集逐条统计：

| 顶点 | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ | $7$ |
|---|---|---|---|---|---|---|---|
| 入度 | $3$ | $2$ | $1$ | $0$ | $2$ | $2$ | $1$ |
| 来源弧 | $\langle2,1\rangle,\langle5,1\rangle,\langle6,1\rangle$ | $\langle3,2\rangle,\langle6,2\rangle$ | $\langle4,3\rangle$ | — | $\langle4,5\rangle,\langle6,5\rangle$ | $\langle3,6\rangle,\langle4,6\rangle$ | $\langle5,7\rangle$ |

校验：$\sum in = 3+2+1+0+2+2+1 = 11 = |E|$ ✓；出度序列 $0,1,2,3,2,3,0$ 之和亦为 $11$ ✓。

### 6.2 第 (2) 问：拓扑排序（教材栈式算法）

算法：① 把所有 $in=0$ 的顶点入栈；② 栈顶顶点出栈并输出；③ 将该顶点每个邻接点的 $in$ 减 $1$，减到 $0$ 者入栈；④ 重复 ②③ 至栈空；⑤ 输出顶点数 $<n$ 则图中有环。

初始入度：$in=[3,2,1,0,2,2,1]$（下标 $1\sim 7$）。

| 步 | 栈内元素（右为栈顶） | 弹出并输出 | 该顶点的出边终点及其入度变化 | 新入栈 |
|---|---|---|---|---|
| 0 | $[4]$ | — | 初始只有 $4$ 入度为 $0$ | $4$ |
| 1 | $[\,]$ → $[3]$ | $4$ | $3:1\to0$；$5:2\to1$；$6:2\to1$ | $3$ |
| 2 | $[\,]$ → $[6]$ | $3$ | $2:2\to1$；$6:1\to0$ | $6$ |
| 3 | $[2,5]$ | $6$ | $1:3\to2$；$2:1\to0$；$5:1\to0$ | $2$，然后 $5$（按序号升序压入，$5$ 在栈顶） |
| 4 | $[2,7]$ | $5$ | $1:2\to1$；$7:1\to0$ | $7$ |
| 5 | $[2]$ | $7$ | 无边表 | — |
| 6 | $[1]$ | $2$ | $1:1\to0$ | $1$ |
| 7 | $[\,]$ | $1$ | 无边表 | — |

输出次序（弹栈顺序）：

$$\boxed{4,\ 3,\ 6,\ 5,\ 7,\ 2,\ 1}$$

**逐弧合法性复核**（序列位置：$4@1,\ 3@2,\ 6@3,\ 5@4,\ 7@5,\ 2@6,\ 1@7$）：

| 弧 | 起点位置 $<$ 终点位置 | 弧 | 起点位置 $<$ 终点位置 |
|---|---|---|---|
| $\langle2,1\rangle$ | $6<7$ ✓ | $\langle5,1\rangle$ | $4<7$ ✓ |
| $\langle3,2\rangle$ | $2<6$ ✓ | $\langle5,7\rangle$ | $4<5$ ✓ |
| $\langle3,6\rangle$ | $2<3$ ✓ | $\langle6,1\rangle$ | $3<7$ ✓ |
| $\langle4,3\rangle$ | $1<2$ ✓ | $\langle6,2\rangle$ | $3<6$ ✓ |
| $\langle4,5\rangle$ | $1<4$ ✓ | $\langle6,5\rangle$ | $3<4$ ✓ |
| $\langle4,6\rangle$ | $1<3$ ✓ | | |

$11$ 条弧全部满足"先起后终"，且输出顶点数 $7=n$ ✓，故序列是合法的拓扑序列，同时说明该图是 AOV 网（无环）。

**为什么序列不唯一 / 另一实现的结果**：第 $3$ 步之后栈中同时有 $2$ 和 $5$，LIFO 使 $5$ 先出；若改用**队列**（FIFO）存放零入度顶点，则 $2$ 先出，得到

$$4,\ 3,\ 6,\ 2,\ 5,\ 1,\ 7$$

同样逐弧校验通过（$2@4$ 早于 $1@6$；$5@5$ 早于 $1@6,7@7$……）。两解都对，考场上按题面"拓扑排序算法"（严蔚敏版用栈）写出栈式结果最稳妥，并可注明"拓扑序列不唯一"。

## 8. 考场标准答案

**(1)** 邻接表（顶点表 $1\sim 7$，边表按终点序号升序）：

```
[1] ^
[2] 1^
[3] 2→6^
[4] 3→5→6^
[5] 1→7^
[6] 1→2→5^
[7] ^
```

入度列：$in[1..7]=3,2,1,0,2,2,1$。

**(2)** 取零入度顶点 $4$ 入栈：弹 $4$（$in[3]\to0$）→ 弹 $3$（$in[6]\to0$）→ 弹 $6$（$in[2],in[5]\to0$，$5$ 在栈顶）→ 弹 $5$（$in[7]\to0$）→ 弹 $7$ → 弹 $2$（$in[1]\to0$）→ 弹 $1$。

拓扑序列：$4,3,6,5,7,2,1$（拓扑序列不唯一，如队列式实现得 $4,3,6,2,5,1,7$ 亦正确）。

## 9. 易错点

1. **把弧挂到起点上还是终点上**：邻接表存出边，$\langle2,1\rangle$ 的结点挂在 $2$ 的表上（`adjvex=1`）；若反向挂成就成了逆邻接表，拓扑排序会整体反序；
2. 边表未按终点升序：如 $4$ 的表写成 $6→5→3$，虽然仍是合法的图，但与题面约定不符，第 (1) 问要扣分，且会带出错乱的拓扑次序；
3. 入度统计漏项：$1$ 的入度是 $3$（来自 $2,5,6$），最容易漏掉 $\langle6,1\rangle$；一旦 $in[1]$ 记成 $2$，$1$ 会被提前入栈，得到非法序列；
4. 栈/队列不分：教材拓扑排序用**栈**，同批零入度顶点是后进先出；把 $2,5$ 按"先进先出"处理得到的其实是另一种合法实现，答卷须写明自己用的是哪种结构，避免被判"过程与结果不符"；
5. 忘记"输出个数 $<n$ 即有环"这一步判定（本题 $7$ 个全输出，说明无环），若题目换成有环图，就必须回答"无法得到拓扑序列"；
6. 只给序列不给演算过程：本题要求"按拓扑排序算法进行排序"，须呈现入度变化表或逐步划掉顶点的过程。

## 10. 一句话规律

有向图邻接表 + 拓扑排序是一套题：**先按起点分组、组内终点升序链表，再由弧集反填入度（用 $\sum in=|E|$ 自检），然后"零入度入栈 → 弹出输出 → 邻接点减 $1$ → 减到 $0$ 就入栈"**；序列不唯一不是错误，但必须让"入度变化表"替你的序列作证，最后逐弧验证起点在终点之前。
