# DS-2018-16

## 1. 原题

采用顺序查找方法查找长度为 $n$ 的线性表时，在等概率情况下查找成功的平均查找长度为____________________ 。

## 2. 答案

$$ASL_{succ}=\frac{n+1}{2}$$

（口径：查找**成功**、每个元素被查找的概率同为 $\dfrac1n$、只统计关键字比较次数。查找失败另算，见第 6 节（4）。）

## 3. 题目分析

- 已知：长度为 $n$ 的线性表（存储方式不限，顺序或链式皆可），查找方法为顺序查找，各元素查找概率相等 $P_i=\dfrac1n$；
- 目标：求查找成功时的平均查找长度 $ASL$；
- 关键约束：顺序查找从表的一端起逐个比较，第一次比较相等即成功 ⟹ 找到第 $i$ 个元素的比较次数 $C_i=i$（与表的存储方式无关，只与"第几个被找到"有关）；
- 命题意图：考 $ASL=\sum P_iC_i$ 这一定义式与等差求和的结合，它是 DS05 章一切查找性能比较的基准量（折半 $\approx\log_2(n+1)-1$、分块、散列都要与它对照）。

## 4. 核心考点

核心考点：
DS05.02 顺序查找法（逐个比较的执行过程 ⟹ $C_i=i$；无序表与有序表在成功情形下 $ASL$ 相同）

辅助考点：
DS05.01 查找的基本概念（平均查找长度定义式、"成功／失败"两种口径）

解释：推导主体是 $ASL$ 定义（DS05.01）在顺序查找执行过程（DS05.02）上的落地；因为题干已明确"查找成功"，主考点落在顺序查找本身的比较次数序列。

## 5. 解题思路

1. 写定义：$ASL=\sum_{i=1}^{n}P_iC_i$，认清 $P_i$ 是"被查元素恰为第 $i$ 个"的概率、$C_i$ 是这种情况下的比较次数；
2. 定 $C_i$：顺序查找自 $R[1]$ 起逐个与 $key$ 比较，第一次相等即成功 ⟹ $C_i=i$；
3. 代 $P_i=\dfrac1n$，用等差求和 $\sum_{i=1}^n i=\dfrac{n(n+1)}{2}$ 化简；
4. 用小表（$n=1,2,3,4$）手算期望核对，并检查量级 $O(n)$ 是否符合"顺序查找线性时间"的常识。

## 6. 详细解答

**（1）按定义推导**

$$ASL_{succ}=\sum_{i=1}^{n}P_iC_i=\sum_{i=1}^{n}\frac1n\cdot i=\frac1n\cdot\frac{n(n+1)}{2}=\frac{n+1}{2}$$

**（2）小表核对**

| $n$ | 各 $C_i$ | 手算期望 | $\dfrac{n+1}{2}$ |
|---|---|---|---|
| $1$ | $1$ | $1$ | $1$ ✓ |
| $2$ | $1,2$ | $\frac12(1+2)=1.5$ | $1.5$ ✓ |
| $3$ | $1,2,3$ | $\frac13(1+2+3)=2$ | $2$ ✓ |
| $4$ | $1,2,3,4$ | $\frac14\times10=2.5$ | $2.5$ ✓ |

**（3）带监视哨实现的核对（第二种推法）**

教材的顺序查找常写成把 $key$ 放入 $R[0]$ 作哨位、下标自 $n$ 递减比较的形式：

```c
int Search_Sq(SSTable ST, KeyType key)     /* ST.elem[1..n] 为数据，ST.elem[0] 作哨位 */
{
    int i = ST.length;
    ST.elem[0].key = key;                  /* 哨位：省去每轮的越界判定 */
    while (ST.elem[i].key != key) --i;     /* 自后向前比较 */
    return i;                              /* i == 0 表示查找失败 */
}
```

该实现从第 $n$ 个元素开始比，查找第 $i$ 个元素的比较次数为 $n-i+1$，于是

$$ASL=\frac1n\sum_{i=1}^{n}(n-i+1)=\frac1n\cdot\frac{n(n+1)}{2}=\frac{n+1}{2}$$

与"自前向后"求和次序相反、结果相同 ✓，说明答案不依赖实现方向。

**（4）失败情形（口径对照，非本题答案）**

无序表查找失败须与全部 $n$ 个元素各比较一次；若把"与哨位的一次比较"也计入，则 $ASL_{fail}=n+1$（不另设哨位、以越界为终止条件则为 $n$）。题干已限定"查找成功"，故取 $\dfrac{n+1}{2}$。

**（5）有序表的对照**

若表按关键字有序，成功查找的 $ASL$ 仍是 $\dfrac{n+1}{2}$（比较次数与下标仍一一对应）；变的是失败情形——可在 $R[i].key>key$ 时提前终止，$ASL_{fail}\approx\dfrac{n}{2}+1$，比无序表省约一半。

**答案**：$\dfrac{n+1}{2}$。

## 7. 选项分析

不适用（填空题）。

## 8. 考场标准答案

顺序查找找到第 $i$ 个元素需比较 $C_i=i$ 次，等概率时 $P_i=\dfrac1n$，故

$$ASL=\sum_{i=1}^{n}P_iC_i=\frac1n\sum_{i=1}^{n}i=\frac1n\cdot\frac{n(n+1)}{2}=\boxed{\dfrac{n+1}{2}}$$

时间量级为 $O(n)$。

## 9. 易错点

1. 漏掉 $\dfrac1n$ 或写成 $\dfrac{n(n+1)}{2}$（那是**总**比较次数，不是"平均"）；
2. 求和错项写成 $\frac1n\sum_{i=1}^{n}(i+1)=\frac{n+3}{2}$（多算了一次与哨位/越界标志的比较；按教材约定 $ASL$ 只统计关键字比较次数）；
3. **口径混淆**：把成功查找的 $\frac{n+1}{2}$ 与失败查找的 $n+1$（或 $n$）混用；题干"查找成功的平均查找长度"已限定口径；
4. 误以为"表有序就能降低成功查找的 $ASL$"：有序只改善失败情形，成功情形仍是 $\frac{n+1}{2}$；
5. 与折半查找结论串味：$\frac{n+1}{2}$ 属顺序查找，折半是 $\approx\log_2(n+1)-1$（本库 DS-2020-26 即折半两类 $ASL$ 的完整计算）。

## 10. 一句话规律

一切 $ASL$ 题同一条路：**先按算法执行过程写出"查找第 $i$ 个元素要比较几次"的序列 $C_i$，再按题给概率 $P_i$ 加权求和**——顺序查找 $C_i=i$（等差 ⟹ $\frac{n+1}{2}$），折半查找 $C_i=$ 判定树中该结点所在层数（⟹ $\log$ 级）。
