# DS-2018-26

## 1. 原题

已知二叉树的先序序列和中序序列分别为 $ABDGCEFH$ 和 $DGBAECHF$ ：

（1）画出该二叉树；

（2）写出此二叉树的后序序列；

（3）画出此二叉树对应的森林。

## 2. 答案

**（1）二叉树**

```
        A
      /   \
     B     C
    /     / \
   D     E   F
    \       /
     G     H
```

（$A$ 的左孩子 $B$、右孩子 $C$；$B$ 的左孩子 $D$、无右孩子；$D$ 无左孩子、右孩子 $G$；$C$ 的左孩子 $E$、右孩子 $F$；$F$ 的左孩子 $H$、无右孩子。共 $8$ 个结点。）

**（2）后序序列**：$GDBEHFCA$

**（3）对应的森林**（$3$ 棵树）

```
  T1          T2        T3
  A            C         F
  |            |         |
  B            E         H
 / \
D   G
```

即 $T_1$：根 $A$，$A$ 有唯一孩子 $B$，$B$ 有两个孩子 $D$、$G$；$T_2$：根 $C$，其唯一孩子 $E$；$T_3$：根 $F$，其唯一孩子 $H$。

## 3. 题目分析

- 已知：先序 $ABDGCEFH$、中序 $DGBAECHF$（同一棵二叉树的两种遍历，$8$ 个互异结点名）；
- 目标：(1) 唯一确定这棵二叉树并画出；(2) 写出后序序列；(3) 按"左孩子—右兄弟"规则的逆规则把二叉树还原成森林；
- 关键约束：
  1. **先序 + 中序可唯一确定一棵二叉树**（先序给根、中序给左右子树的划分），这是第 (1) 问成立的依据；若给的是先序+后序或中序+层序则不能唯一确定；
  2. 结点名互不相同，无重复关键字引起的多解；
  3. 第 (3) 问的转换规则是**二叉树 → 森林**（孩子兄弟表示法的逆向）：某结点的左链指向它的第一个孩子，右链指向它的下一个兄弟；根 $A$ 若沿右链还有结点，则说明原森林不止一棵树；
- 命题意图：把"由两序定树"与"树/森林与二叉树的三角转换"两个基本功合并成一道题，并用第 (2) 问提供一个免费的自检通道（由画出的树重算三序）。

## 4. 核心考点

核心考点：
DS03.02.03 二叉树的遍历——先序"根左右"、中序"左根右"的结构差异，使得先序首字母必为根、中序中该字母左侧必为左子树，从而可递归重建树

辅助考点：
DS03.03.02 森林与二叉树的转换——第 (3) 问直接考逆转换（右链是兄弟、左链是孩子），并要求理解"森林先根遍历 $=$ 二叉树先序、森林后根遍历 $=$ 二叉树中序"
DS03.02.01 二叉树的定义及主要特征——本题出现"只有右子树的结点 $D$"，用来检验是否清楚二叉树左右有序（$D$ 的孩子必须判明是左还是右，不能画成"随便一个孩子"）

解释：三问共用同一棵树，主考点是"由遍历序列确定二叉树"（DS03.02.03）；森林转换是本题的第二块主体（DS03.03.02）；而"单孩子结点方向"这一最容易画错的地方，其判据来自 DS03.02.01 的有序性。

## 5. 解题思路

1. 先序首字母 $A$ 是整棵树的根 → 到中序里找 $A$，把中序切成"左：$DGB$"与"右：$ECHF$"，两侧结点数 $3$ 和 $4$；
2. 回到先序，去掉 $A$ 后按 $3:4$ 切分：左子树用 $BDG$、右子树用 $CEFH$；
3. 对左右两部分各递归执行"先序首字母定子根、中序定区间"，直到区间只剩一个字母（叶子）或为空；
4. 递归过程中**只认中序的左右侧**决定孩子是左还是右——这是 $D$ 的孩子 $G$ 画在右侧、$F$ 的孩子 $H$ 画在左侧的唯一依据；
5. 建完树立刻"反向遍历"：由图重算先序与中序，与题面逐字符比对；一致才继续做 (2)(3)；
6. 第 (3) 问从根出发沿右链走一遍：右链上每遇到一个结点就是一棵新树的根（$A\to C\to F$，故 $3$ 棵树）；再对每个树根沿左链—右链交替（左链下第一个孩子、孩子的右链是它的兄弟）逐层展开孩子。

## 6. 详细解答

### 6.1 第 (1) 问：递归建树

**第 1 层（整棵树）**：先序 $A|BDG|CEFH$ 首字母 $A$ 为根；中序 $DGB\,|\,A\,|\,ECHF$ 得左子树结点集 $\{D,G,B\}$（$3$ 个）、右子树结点集 $\{E,C,H,F\}$（$4$ 个）。
按结点数切先序：$A$ 之后前 $3$ 个 $BDG$ 属左子树，后 $4$ 个 $CEFH$ 属右子树。

**第 2 层（左子树，先序 $BDG$／中序 $DGB$）**：根为 $B$；中序中 $B$ 左侧为 $DG$、右侧为空 ⟹ $B$ 有左子树（含 $D,G$）、**无右子树**。

**第 3 层（$B$ 的左子树，先序 $DG$／中序 $DG$）**：根为 $D$；中序中 $D$ 左侧为空、右侧为 $G$ ⟹ $D$ **无左孩子**，$G$ 是 $D$ 的**右孩子**。
（若把 $G$ 误画成 $D$ 的左孩子，则中序会变成 $GD$，与题面 $DG$ 矛盾。）

**第 2 层（右子树，先序 $CEFH$／中序 $ECHF$）**：根为 $C$；中序切分：$C$ 左侧 $E$（$1$ 个）、右侧 $HF$（$2$ 个）⟹ 先序去掉 $C$ 后按 $1:2$ 切：$E$ 属左子树、$FH$ 属右子树。
- $C$ 的左孩子 $=E$（单结点，无孩子）；
- $C$ 的右子树：先序 $FH$／中序 $HF$ ⟹ 根 $F$；中序中 $F$ 左侧为 $H$、右侧为空 ⟹ $H$ 是 $F$ 的**左孩子**，$F$ 无右孩子。

**汇总（父子关系表）**

| 结点 | 左孩子 | 右孩子 | 度 |
|---|---|---|---|
| $A$ | $B$ | $C$ | $2$ |
| $B$ | $D$ | — | $1$ |
| $C$ | $E$ | $F$ | $2$ |
| $D$ | — | $G$ | $1$ |
| $E$ | — | — | $0$ |
| $F$ | $H$ | — | $1$ |
| $G$ | — | — | $0$ |
| $H$ | — | — | $0$ |

结点数 $8$。按度统计：叶子 $n_0=3$（$E,G,H$）、度 $1$ 结点 $n_1=3$（$B,D,F$）、度 $2$ 结点 $n_2=2$（$A,C$），满足 $n_0=n_2+1$ ✓，且 $3+3+2=8$ ✓。

**回读校验**：由上表重算三序
- 先序（根左右）：$A$ →（$B$ →（$D$ →（—，$G$）$=DG$）$=BDG$）→（$C$ →（$E$）（$F$ →（$H$，—）$=FH$）$=CEFH$）$=ABDGCEFH$ ✓ 与题面一致
- 中序（左根右）：$DGB$ → $A$ → $E$ → $C$ → $HF$ $=DGBAECHF$ ✓ 与题面一致

两序均吻合，说明所画二叉树唯一正确。

### 6.2 第 (2) 问：后序序列

后序 = 左右根，按 6.1 的结构自底向上写：

- $B$ 的左子树 $(D,G)$：$D$ 无左、右孩子为 $G$ ⟹ 后序 $G,D$；加根 $B$ ⟹ $GDB$；
- $C$ 的左子树 $E$ ⟹ $E$；$C$ 的右子树 $(F,H)$：$H$ 是左孩子 ⟹ 后序 $H,F$；加根 $C$ ⟹ $EHFC$；
- 整棵树：$GDB$ + $EHFC$ + $A$

$$\text{后序序列}=\boxed{GDBEHFCA}$$

（快速校验：后序末字母必为根 $A$ ✓；后序首字母必为"最先访问到的叶子"，即最左支底端的 $G$——$A$ 的左孩子 $B$ 的左孩子 $D$ 无左孩子，故为 $G$ ✓。）

### 6.3 第 (3) 问：二叉树 → 森林

转换规则（孩子兄弟表示法的逆用）：**左链 = 第一个孩子，右链 = 下一个兄弟**。

① 确定树的棵数：从根 $A$ 出发沿右链走：$A \xrightarrow{右} C \xrightarrow{右} F$，$F$ 无右链 ⟹ 森林共 $3$ 棵树，根依次 $A$、$C$、$F$。

② 展开每棵树的结点层次（"左链下孩子、孩子再沿右链排兄弟"）：

- $T_1$（根 $A$）：$A$ 的左链 $=B$ ⟹ $B$ 是 $A$ 的孩子；$B$ 的右链为空 ⟹ $B$ 是独子。$B$ 的左链 $=D$ ⟹ $D$ 是 $B$ 的长子；$D$ 的右链 $=G$ ⟹ $G$ 是 $D$ 的弟弟。$G$ 的左链为空 ⟹ $G$ 无孩子。
  $$T_1:\ A\Rightarrow B,\qquad B\Rightarrow D,\ G$$
- $T_2$（根 $C$）：$C$ 的左链 $=E$ ⟹ $E$ 是 $C$ 的孩子；$E$ 的右链为空 ⟹ 独子；$E$ 的左链为空 ⟹ 无孩子。
  $$T_2:\ C\Rightarrow E$$
- $T_3$（根 $F$）：$F$ 的左链 $=H$ ⟹ $H$ 是 $F$ 的孩子；$H$ 的右链、左链均空。
  $$T_3:\ F\Rightarrow H$$

③ 校验（森林与二叉树的遍历对应关系）：
- 森林**先根遍历**应等于二叉树先序：$T_1\,A,B,D,G$ → $T_2\,C,E$ → $T_3\,F,H$ = $ABDGCEFH$ ✓
- 森林**后根遍历**应等于二叉树中序：$T_1\,D,G,B,A$ → $T_2\,E,C$ → $T_3\,H,F$ = $DGBAECHF$ ✓

两向吻合，森林画法正确。注意 $T_1$ 中 $B$ 的两个孩子 $D$、$G$ 是**兄弟**关系（不是 $D$ 的孩子），这正是"右链 $=$ 兄弟"最容易读反的地方。

## 8. 考场标准答案

**(1)** 由"先序定根、中序分左右"递归建树：

```
        A
      /   \
     B     C
    /     / \
   D     E   F
    \       /
     G     H
```

**(2)** 后序序列：$G\ D\ B\ E\ H\ F\ C\ A$

**(3)** 按"左孩右兄"逆向转换，根沿右链得 $A,C,F$ 三棵树：

```
  T1          T2        T3
  A            C         F
  |            |         |
  B            E         H
 / \
D   G
```

## 9. 易错点

1. **单孩子的方向**：$D$ 与 $G$ 只能由中序判定为"$G$ 在 $D$ 右侧 ⟹ 右孩子"，$F$ 与 $H$ 则是"$H$ 在 $F$ 左侧 ⟹ 左孩子"。凭手感画成左孩子，树就变了（中序会读成 $GD$ 或 $FH$ 反序）；
2. 先序切分区间靠的是**中序给出的左右子树结点数**（$3:4$），不是"对半分"，也不是"按字母顺序"；
3. 第 (3) 问把二叉树直接照搬画成一棵树：错在忽略"根的右链"——$A$ 有右链 $C$、$C$ 又有右链 $F$，说明这是**森林**里的三棵独立的树，不是 $A$ 的右子树；
4. 森林中把 $G$ 画成 $D$ 的孩子：$D$ 与 $G$ 在二叉树中是"左孩子—右兄弟"链上的相邻两结点，在树中是**兄弟**（同为 $B$ 的孩子）；
5. 后序写成 $GDBEHFCA$ 时漏字母或错序（尤其 $EHFC$ 段：$E$ 在 $H$ 之前，因为 $E$ 是 $C$ 的左子树整体，$H,F$ 是 $C$ 的右子树）；
6. 校验方向单一：只重算先序不足以发现左右孩子互换的错误（先序不变而中序变），必须**同时回读中序**。

## 10. 一句话规律

"先序 + 中序"定树就是**先序给根、中序给左右区间、按区间长度回切先序**三句话递归套用；画完一定要用两序各回读一遍（先序查父子、中序查左右），再往森林转时记住一句口诀——**左孩子是FirstChild、右链是NextSibling，根的右链有多长森林就有几棵树**。
