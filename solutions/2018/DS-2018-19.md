# DS-2018-19

## 1. 原题

设一循环队列 $Q$ 中，$rear$ 指针指向队尾元素的下一个位置，$front$ 指针指向队首元素，则判断队列中元素为空的条件是____________________ 。

## 2. 答案

$$Q.rear == Q.front$$

（即 $rear$ 与 $front$ 相等。此处"相等"指在环形数组上的下标位置重合，不是指针变量地址意义上的相等。）

## 3. 题目分析

- 已知：循环队列，容量记为 $m$（数组下标 $0\sim m-1$）；约定 $front$ 指向**队首元素本身**，$rear$ 指向**队尾元素的下一个位置**（即下一个新元素将要落入的空位）；
- 目标：写出"队列为空"的判定条件；
- 关键约束：在该约定下，$[front,\,rear)$ 这段环形区间恰好覆盖所有在队元素，$rear$ 永远停在"第一个空闲格"上。队列里一个元素都没有时，这段区间长度为零 ⟹ 两端重合；
- 命题意图：考循环队列的**指针约定与判空/判满条件**的对应关系。本题把约定明确写进题干，正是为了让考生区分"约定一（$rear$ 指队尾下一格）"与"约定二（$rear$ 指队尾元素本身）"下不同的判空式——脱离约定谈判空条件是无意义的。

## 4. 核心考点

核心考点：
DS02.02 栈和队列的顺序存储结构（循环队列的 $front$/$rear$ 语义、队空队满条件、牺牲一个存储区与设标志位两种方案）

辅助考点：
DS02.01 栈和队列的基本概念（队列"队首删除、队尾插入"的操作定义决定了两个指针必须各自守住的位置）

解释：答案完全由循环队列的存储约定推出（DS02.02）；DS02.01 只提供了"为什么需要两个指针"的概念背景，故列为辅助。

## 5. 解题思路

1. 把约定写成不变式：任意时刻，从 $front$ 出发沿环走 $\mathit{len}$ 步到达 $rear$，$\mathit{len}$ 就是在队元素个数，即 $\mathit{len}=(rear-front+m)\bmod m$；
2. 令 $\mathit{len}=0$，得 $rear-front\equiv 0\pmod m$；又因两指针取值都在 $0\sim m-1$ 内，同余即相等 ⟹ $rear=front$；
3. 用最小操作序列反验：初始置 $front=rear=0$（空），入队 $a$ 后 $rear=1\ne front$（不空），出队 $a$ 后 $rear$ 回落到与 $front$ 重合（重新为空）——判空式在两个方向上都成立；
4. 顺带确认该约定下"仅凭 $rear==front$"不能同时判满，故须牺牲一格，判满为 $(rear+1)\bmod m == front$，以排除"是不是该填队满条件"的误读。

## 6. 详细解答

**（1）不变式**

按题干约定，$front$ 指向队首元素、$rear$ 指向队尾元素的下一个位置，于是循环队列始终满足：

> 在队元素 $=$ 从 $front$ 起（含）到 $rear$ 止（不含）沿环形扫描所经过的那些单元。

队列为空 ⟺ 这段区间为空 ⟺ 起点与终点重合：

$$Q.rear == Q.front$$

**（2）由长度公式反解（第二种推法）**

该约定下的在队长度公式为

$$\mathit{len}=(Q.rear-Q.front+m)\bmod m$$

令 $\mathit{len}=0$：$(Q.rear-Q.front+m)\bmod m=0$，即 $Q.rear-Q.front\equiv 0\pmod m$。由于 $0\le Q.front,Q.rear\le m-1$，两者之差落在 $(-m,\,m)$ 内，能被 $m$ 整除的只有 $0$，故 $Q.rear=Q.front$ ✓。

**（3）最小序列逐步验证**

取 $m=4$（下标 $0,1,2,3$），初始 $front=rear=0$：

| 操作 | front | rear | 在队元素 | $rear==front$ ? | 实际空/非空 |
|---|---|---|---|---|---|
| 初始化 | $0$ | $0$ | 无 | 是 | 空 ✓ |
| 入队 $a$ | $0$ | $1$ | $a$ | 否 | 非空 ✓ |
| 入队 $b$ | $0$ | $2$ | $a,b$ | 否 | 非空 ✓ |
| 出队 $a$ | $1$ | $2$ | $b$ | 否 | 非空 ✓ |
| 出队 $b$ | $2$ | $2$ | 无 | **是** | 空 ✓ |
| 入队 $c$（$rear$ 绕回） | $2$ | $3$ | $c$ | 否 | 非空 ✓ |
| 入队 $d$ | $2$ | $0$ | $c,d$ | 否 | 非空 ✓（$rear$ 已回绕，长度 $=(0-2+4)\bmod4=2$） |
| 出队 $c$、出队 $d$ | $0$ | $0$ | 无 | **是** | 空 ✓ |

回绕之后判空式仍然成立，说明"$rear==front$"是循环队列通用的判空条件，而非只在未回绕时成立。

**（4）配套的队满条件（说明为何不能靠同一式子判满）**

正因为空与满都表现为 $rear==front$（把 $m$ 个格子全填满时 $rear$ 沿环走一圈重新追上 $front$），在该约定下必须**牺牲一个存储单元**来区分队空与队满：

- 队空：$Q.rear == Q.front$
- 队满：$(Q.rear+1)\bmod m == Q.front$
- 长度：$(Q.rear-Q.front+m)\bmod m$

（另两种可行方案是增设 `count` 计数器或增设 `tag` 标志位，此时 $m$ 个格子可全用；但题干采用的是最经典的"牺牲一格"约定，判空式不受该方案影响，仍为 $rear==front$。）

**（5）对照另一种常见约定（防串味）**

| 约定 | $front$ 含义 | $rear$ 含义 | 队空 | 队满（牺牲一格） |
|---|---|---|---|---|
| 本题约定 | 队首元素 | 队尾元素的下一位置 | $rear==front$ | $(rear+1)\bmod m==front$ |
| 约定二 | 队首元素的前一位置 | 队尾元素本身 | $rear==front$ | $(rear+1)\bmod m==front$ |
| 约定三（不牺牲一格，须设 tag） | 队首元素 | 队尾元素本身 | $rear==front$（配合 $tag=0$） | $rear==front$（配合 $tag=1$） |

前两行的判空式**形式相同**，都是 $rear==front$；差别体现在入队/出队的书写次序上（约定二中出队要先移 $front$）。所以本题填 $rear==front$ 与约定二不冲突；但若题干改为"$front$ 指向队首元素的前一个位置、$rear$ 指向队尾元素"并要求用长度式验证，仍得同一答案。

**答案**：$Q.rear == Q.front$。

## 7. 选项分析

不适用（填空题）。本题无备选支；作答时须一并写明所依存的指针约定（题干已给），否则同一式子在别的约定下可能变成队满条件。

## 8. 考场标准答案

$$\boxed{Q.rear == Q.front}\ \text{（或写作 } rear == front \text{，或"两个指针相等")}$$

理由：按"$front$ 指队首元素、$rear$ 指队尾元素的下一个位置"的约定，区间 $[front,rear)$ 沿环覆盖全部在队元素，区间为空时两端重合；等价地，由 $\mathit{len}=(rear-front+m)\bmod m$ 令 $\mathit{len}=0$ 亦解得 $rear==front$。此时队满条件须用 $(rear+1)\bmod m==front$ 与之区分。

## 9. 易错点

1. 填成 $(rear+1)\bmod m == front$——那是**队满**条件，本题问的是队空；两个条件写反是本题最常见的失分方式；
2. 填成 $rear == front$ 却漏了"循环"语境，误写成"$rear$ 追上 $front$"式的口语描述而未给出等式；答卷应给出可判定的表达式；
3. 忘记 $rear$ 与 $front$ 相等并不总意味着空：在不牺牲一格的方案里，满时同样 $rear==front$，必须靠 $tag$ 或 $count$ 区分；若答卷只写 $rear==front$ 而不交代约定，严谨性略欠（本题题干已交代约定，故无此隐患）；
4. 误填 `Q.elements == 0` 或 `count == 0`：题干未定义计数器成员，凭空引入字段属答非所问；
5. 把长度式 $(rear-front+m)\bmod m$ 当成判空条件抄上去：那是长度，不是判据（令其为 $0$ 才是）。

## 10. 一句话规律

循环队列的四个式子同源一桩：**先按题干约定写出"$front$ 到 $rear$ 的环形区间覆盖在队元素"这一不变式，再令区间长度为 $0$ 得判空（$rear==front$）、令其为"满"得判满（牺牲一格 ⟹ $(rear+1)\bmod m==front$）**——约定变了，式子的推导入口就变，绝不能死背。
