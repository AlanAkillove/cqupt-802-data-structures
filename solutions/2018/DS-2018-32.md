# DS-2018-32

## 1. 原题

现有关键字序列 `{45,24,37,53,12,93,47,60}`，按以下要求完成：

（1）根据给定的关键字序列构造一棵二叉查找（排序）树，以二叉链表形式存储，进行中序遍历可以得到从小到大排列的有序序列，请写出构造过程（不要求算法）

（2）在（1）的基础上，请编写一个函数 `int LeafCount（Binary_tree BT）`，求此二叉树的叶子结点个数。

有关的数据结构已描述如下：

```c
typedef struct Binary_node{ //二叉树结点
    int data;
    Binary_node *left;
    Binary_node *right;
}Binary_node,*Binary_tree;

int LeafCount(Binary_tree bt);//计算树bt的叶结点的个数
```

> 订正说明转录：源文代码中函数名作 `LeftCount`，与题干要求的 `int LeafCount（Binary_tree BT）`（求叶子结点个数）不一致，据题意统一为 `LeafCount`。

## 2. 答案

**（1）构造结果**（插入顺序 45→24→37→53→12→93→47→60）：

```
            45
          /    \
        24      53
       / \     /  \
      12  37  47   93
                  /
                 60
```

中序遍历：`12 24 37 45 47 53 60 93`（严格递增，验证构造正确）。

**（2）`LeafCount` 的递归实现**（第 8 节给可书写版）：空树返回 $0$；叶子（`left==NULL && right==NULL`）返回 $1$；否则返回左右子树叶子数之和。

对（1）的树：`LeafCount = 4`，叶子为 $12,37,47,60$。

## 3. 题目分析

- 已知：含 $8$ 个互不相同关键字的序列，以及二叉链表结点类型 `Binary_node{data,left,right}`；
- 目标：(1) 按**给定顺序**逐个插入建成二叉排序树并画出（不写建树算法，只写过程）；(2) 写出统计叶子结点个数的函数；
- 关键约束：
  1. 二叉排序树的形态由**插入顺序**唯一决定，与序列是否有序无关——不能先排序再"平衡地"建树；
  2. 插入规则：从根起，比当前结点小走 `left`，大走 `right`，走到空指针就把新结点挂上；本题关键字互异，无需讨论等值处理；
  3. (2) 中"叶子"指二叉树意义的叶子，即 `left` 与 `right` **同时为空**，不是"某一支为空"；
- 命题意图：前半考 DS05.07.01 的构造过程与"中序有序"这一判别性质；后半考二叉链表上**最典型的递归范式**——把"空树"与"叶子"作为两类递归出口，非叶结点合并子树结果。两问共用同一棵树，第二问的答案可用第一问的图直接数出，起到自校验作用。

## 5. 解题思路

1. 建树不要求算法，但过程必须**逐关键字写清比较路径**：把每个新关键字从根开始的一次次比较按顺序记下来，最后一个"空指针"就是它的落点；
2. 画完树立刻自检：写中序序列，若为升序且恰好是原序列的 $8$ 个关键字，则父子关系与左右分支必无错（这是二叉排序树的判定定理，也是本题题干提示的用法）；
3. 求叶子数：叶子是"两链域皆空"的结点。递归只需回答三件事——树为空（$0$）、树是叶子（$1$）、其他（左右子树答案相加）；这个三段式对空树、单结点树都成立，无需额外特判；
4. 结果再核一遍：数出度为 $2$ 的结点有 $45,24,53$ 共 $3$ 个，由 $n_0=n_2+1$ 得 $n_0=4$，与递归计数一致；
5. 顺手分析复杂度：每个结点恰被访问一次，时间 $O(n)$；递归栈深度等于树高，本题 $h=4$，最坏（单支链退化）为 $O(n)$。

## 6. 详细解答

### （1）构造过程

初始为空树，按序列顺序逐个插入。

| 序 | 关键字 | 从根开始的比较路径 | 落点（挂接位置） |
|---|---|---|---|
| 1 | $45$ | 树空 | 作为根结点 |
| 2 | $24$ | $24<45$ → 走到 `45.left`，为空 | $24$ 为 $45$ 的**左孩子** |
| 3 | $37$ | $37<45$ → 左；$37>24$ → 右，`24.right` 为空 | $37$ 为 $24$ 的**右孩子** |
| 4 | $53$ | $53>45$ → 右，`45.right` 为空 | $53$ 为 $45$ 的**右孩子** |
| 5 | $12$ | $12<45$ → 左；$12<24$ → 左，`24.left` 为空 | $12$ 为 $24$ 的**左孩子** |
| 6 | $93$ | $93>45$ → 右；$93>53$ → 右，`53.right` 为空 | $93$ 为 $53$ 的**右孩子** |
| 7 | $47$ | $47>45$ → 右；$47<53$ → 左，`53.left` 为空 | $47$ 为 $53$ 的**左孩子** |
| 8 | $60$ | $60>45$ → 右；$60>53$ → 右；$60<93$ → 左，`93.left` 为空 | $60$ 为 $93$ 的**左孩子** |

得到的二叉排序树（第 2 节图即其最终形态）：

```
            45                                  层次 1
          /    \
        24      53                              层次 2
       / \     /  \
      12  37  47   93                           层次 3
                  /
                 60                             层次 4
```

**自检（中序遍历）**：中序 = 左–根–右

- 以 $24$ 为根的子树：$12,\ 24,\ 37$
- 以 $53$ 为根的子树：$47,\ 53,\ (93$ 的子树 $60,\ 93)$ → $47,\ 53,\ 60,\ 93$
- 整棵树：$12,24,37,\ \mathbf{45},\ 47,53,60,93$

$8$ 个关键字全部出现且严格递增 ✓，说明建树的每次左右分支选择都正确。

> 注：若把序列改成已排好序的 `12,24,37,45,47,53,60,93`，同一插入规则会退化成一条只有右孩子的单支链（树高 $8$）。本题序列"中间值 45 先插入"，故形态较均衡（树高 $4$）。

### （2）`LeafCount` 算法

**递归定义**（设 $T$ 为二叉链表）：

$$
LeafCount(T)=
\begin{cases}
0, & T=\texttt{NULL}\ (\text{空树无叶子})\\
1, & T\neq\texttt{NULL}\ \wedge\ T\text{ 为叶子}\\
LeafCount(T\to left)+LeafCount(T\to right), & \text{其他}
\end{cases}
$$

```c
int LeafCount(Binary_tree bt)
{
    if (bt == NULL)                       /* 空树：叶子数 0（也是递归到空孩子时的出口） */
        return 0;
    if (bt->left == NULL && bt->right == NULL)
        return 1;                         /* 叶子：两链域皆空 */
    return LeafCount(bt->left) + LeafCount(bt->right);   /* 非叶：两子树叶子数相加 */
}
```

**在（1）的树上手工执行**（自底向上给出各结点返回值）：

| 结点 | `left` | `right` | 返回值 |
|---|---|---|---|
| $12$ | NULL | NULL | $1$（叶子） |
| $37$ | NULL | NULL | $1$（叶子） |
| $47$ | NULL | NULL | $1$（叶子） |
| $60$ | NULL | NULL | $1$（叶子） |
| $93$ | →$60$ | NULL | $1+0=1$ |
| $24$ | →$12$ | →$37$ | $1+1=2$ |
| $53$ | →$47$ | →$93$ | $1+1=2$ |
| $45$ | →$24$ | →$53$ | $2+2=\mathbf{4}$ |

**独立复核（按度计数）**：树中度为 $2$ 的结点为 $45,24,53$，$n_2=3$；度为 $1$ 的结点为 $93$，$n_1=1$。由二叉树性质 $n_0=n_2+1=4$，且 $n=n_0+n_1+n_2=4+1+3=8$ ✓ 与序列长度一致。故叶子数 $4$ 与图上直接数出的 $\{12,37,47,60\}$ 完全吻合。

**备选写法（非递归，遍历计数）**——若担心树退化成单支链导致递归过深，可改用栈/队列遍历：

```c
int LeafCount_NR(Binary_tree bt)
{
    if (bt == NULL) return 0;
    Binary_tree stack[100]; int top = -1;      /* 栈容量按结点规模取足 */
    int cnt = 0;
    stack[++top] = bt;
    while (top >= 0) {
        Binary_tree p = stack[top--];
        if (p->left == NULL && p->right == NULL) cnt++;   /* 访问一个结点即判一次 */
        if (p->right) stack[++top] = p->right;
        if (p->left)  stack[++top] = p->left;
    }
    return cnt;
}
```

时间同为 $O(n)$，空间由递归栈改为显式栈，量级不变（仍 $O(h)$），但可自控溢出风险。

```c
{

        return 0;
    if (bt->left == NULL && bt->right == NULL)

```

## 9. 易错点

1. 把"叶子"误判成"只有一个孩子"或"某链域为空"——判据必须是 `left==NULL && right==NULL`（写成 `||` 会把度为 $1$ 的结点当成叶子并**停止向下递归**，本题恰因 $93$ 之下只有一个叶子 $60$ 而仍得 $4$（巧合）；只要单支结点下方还有两个以上叶子就会少数，例如给 $60$ 再挂两个孩子 $55,65$，正确答案为 $5$，`||` 写法在 $93$ 处即返回 $1$，只得 $4$）；
2. 忘记 `bt == NULL` 这一出口：单写"孩子为空返回 1"的递归，遇到空树（`BT` 本身为 `NULL`）会解引用空指针；
3. 建树时**先排序再插入**或"看着顺眼就平衡着挂"——二叉排序树形态由插入顺序决定，本题 $45$ 先插入才有较均衡的形态；
4. 插入 $60$ 时漏掉与 $93$ 的比较（$60>53$ 只保证走 $53$ 的右支，仍要与 $93$ 比一次才落到 $93$ 的左孩子）；
5. 递归返回处写成 `LeafCount(left) + LeafCount(right) + 1`——那是**总结点数**的写法，叶子数不能加 $1$；
6. 树高退化的隐患：若插入序列本身有序，递归深度达 $n$，与本题第 30 题"递归程序在链表很长时不实用"是同一问题（见 DS-2018-30），答卷时给出非递归版本可加分。

## 10. 一句话规律

二叉排序树"按输入顺序、比一次走一步、遇空就挂"，形态只由插入顺序决定；二叉链表上的整体统计量（叶子数、结点数、高度）一律写成"空树出口 + 叶子/单结点出口 + 左右子树结果合并"的三段式递归，画完树再用中序升序和 $n_0=n_2+1$ 各核一遍。
