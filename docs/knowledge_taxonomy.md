# 802 数据结构知识体系（Knowledge Taxonomy）

> Phase 2 交付物。根节点为 **2027 重庆邮电大学 802 数据结构考试大纲**（`考试大纲/2027重庆邮电大学802数据结构考试大纲.md`，Level 1）。
> 一级章节 DS01–DS06 与考纲六部分**严格一一对应**；扩展节点依据官方指定教材《数据结构（C 语言版）》严蔚敏、吴伟民（Level 2）细化，且全部位于考纲节点之下。
> **禁止**用 408 知识体系覆盖本体系；对考纲内但 408 资料中低权重的内容（串匹配、广义表、外部排序等）不得删除。

## 使用规则

1. 所有打标签、统计一律使用本文件中的 canonical ID + 中文名称，禁止自由措辞；
2. 每题**恰好一个** `primary_topic`；`secondary_topics` ≤ 3，仅在题目确实综合时用；
3. 细化仅限有明确统计意义的层级（如二叉树遍历分前/中/后/层序），不为个题造一次性标签；
4. 考纲外但题目实际出现的知识点 → 记入 `docs/taxonomy_candidates.md` 走候选流程，**不直接新增**；
5. 覆盖报告（`reports/syllabus_coverage.md`）以本文件**全部叶子节点**为统计口径，0 题节点也必须显示。

## ID 编码

`DS<章>.<节>[.<小节>]`，章两位数 00–06（DS00 为绪论基础知识章，见下方说明），节/小节顺序编号。

## DS00 绪论（基础知识章）

> DS00 是从官方考纲**总体考查目标**中显式抽出的横向基础知识节点，并结合指定教材第 1 章细化而成。2027 考纲「考查目标」第 1、2 条已明确要求「掌握数据结构的基本概念、基本原理和基本方法」以及「对算法进行基本的时间复杂度与空间复杂度的分析」，这些目标横跨 DS01–DS06 六部分、不归入任一具体章节，故单列 DS00 承载；2005/2007/2012 等年份题面亦直接考查对应内容（Level 2）。经 `docs/taxonomy_candidates.md` 候选流程评审通过后新增。

## 交叉横断说明（防止误打标）

- **算法复杂度分析**（时间/空间）：不是独立知识点，按题主结构归章，能力标签用 `COMPLEXITY_ANALYSIS`；
- **程序阅读/填空题**：primary_topic 归被考查的数据结构章节，能力标签用 `CODE_READING`/`CODE_COMPLETION`；
- **堆**：统一归 DS06.07（考纲中堆仅出现在堆排序节下）；堆作优先队列应用时 secondary 可加 DS02.07；
- **二叉排序树/AVL 的查找 ASL**：主 DS05.07.x，ASL 概念为 DS05.01 辅助；
- **算法设计题**（如"重排数组使负数在前"）：primary_topic 按所操作的数据结构定（DS01.02.x 等），能力用 `ALGORITHM_DESIGN` + `ALGORITHM_IMPLEMENTATION`。
